## 0. 結論サマリ

- FX5は **6種類のインバータ通信命令**で三菱FREQROLインバータと通信する（計算機リンク）。
- **駆動接点のOFF→ONの立上りで通信開始**。通信中に駆動接点がOFFしても最後まで実行する。常時ONなら繰り返し通信する。
- どの命令も **通信実行状態出力デバイス（3点占有）** を持つ:
  `(d)+0`=実行中、`(d)+1`=正常完了、`(d)+2`=異常完了
- **複数の命令を同時駆動してよい**が、**通信が完了するまで指令接点をOFFしない**。完了フラグで自分の指令をリセットする作りにする。
- プロトコル形式を[インバータ通信]にしていないCHでは命令は使えない（3600H）。
- **CJ-P間 / FOR-NEXT間 / P-RET間 / I-IRET間では使用できない。**

## 1. 命令一覧

| 命令 | 機能 | 制御方向 |
|---|---|---|
| `IVCK` | インバータの運転監視（状態読出し） | シーケンサ ← インバータ |
| `IVDR` | インバータの運転制御（設定値書込み） | シーケンサ → インバータ |
| `IVRD` | インバータのパラメータ読出し | シーケンサ ← インバータ |
| `IVWR` | インバータのパラメータ書込み | シーケンサ → インバータ |
| `IVBWR` | インバータのパラメータ一括書込み | シーケンサ → インバータ |
| `IVMC` | インバータの複数コマンド（2書込み＋2読出しを同時実行） | 双方向 |

全命令共通のオペランド:

| オペランド | 内容 | 範囲 |
|---|---|---|
| (s1) | インバータの局番 | K0〜31 |
| (n) | 通信CH | FX5S/FX5UJ: K2〜K4、FX5U: K1〜K4、FX5UC: K1, K3〜K4 |
| (d) / (d2) | 通信実行状態を出力する先頭ビットデバイス | **3点占有** |

> (d)/(d2) には T, ST, C を使用できない。他の制御と重複させないこと。

## 2. パラメータ設定（GX Works3）

設定場所は他のシリアル機能と同じ（内蔵RS-485→[485シリアルポート]、通信ボード→[拡張ボード]、通信アダプタ→ADP1〜6）。

| 分類 | 項目 | 設定値 |
|---|---|---|
| 基本設定 | 拡張ボード（CH2のみ） | **FX5-485-BD** |
| 基本設定 | プロトコル形式 | **インバータ通信** |
| 詳細設定 | データ長 | 7bit / 8bit |
| 詳細設定 | パリティ | なし / 奇数 / 偶数 |
| 詳細設定 | ストップビット | 1bit / 2bit |
| 詳細設定 | ボーレート | 4800 / 9600 / 19200 / 38400 / 57600 / 115200bps |
| 固有設定 | 応答待ち時間 | 1〜32767(ms) |
| SM/SD設定 | FX3シリーズ互換用SM/SD | 使用しない / CH1 / CH2 |

> 詳細設定は**接続するインバータの通信仕様に合わせる**こと。

## 3. 通信実行状態出力デバイスと同時動作デバイス

| デバイス | 名称 | 動作 | 同時に動作するデバイス |
|---|---|---|---|
| (d) / (d2) +0 | 命令実行中フラグ | 命令実行中ON、それ以外OFF | インバータ通信中<br>CH1: SM8920 / CH2: SM8930 / CH3: SM8940 / CH4: SM8950 |
| (d) / (d2) +1 | 命令正常完了フラグ | 正常完了時ON、駆動接点立上り時OFF | 命令実行完了 SM8029 |
| (d) / (d2) +2 | 命令異常完了フラグ | 異常完了時ON、駆動接点立上り時OFF | — |

- `SM8029` は**正常/異常に関係なく**完了時にONする。`(d)+2` は異常時のみONなので、**正常/異常の判別は `(d)+1` / `(d)+2` で行う**。
- `SM8029` や `SM892x` は**1つの命令が占有せず、他のインバータ通信命令と共通**。他の命令の実行で変化する。
- **結果を得たい命令の直下にフラグ判定回路を置くこと。**

---

## 4. 命令の同時駆動と通信タイミング

- インバータ通信命令は複数プログラムして同時に駆動できる。
- 同一シリアルポートで複数駆動された場合、**現在の通信が終了したあと、プログラム中の次に記述された命令が通信する**（プログラム記述順）。
- 命令は**シリアルポートを取得後 11ms 待機してから通信を開始**する。
- 他の命令でインバータ通信中フラグ（SM8920等）がONしている間は、駆動接点がONでも**SM8920がON→OFFになるまで待機**する。
- 通信中の命令が終了してから次の命令が通信を始めるまでの間、SM8920はOFFになる。

> ⚠ SM8920がOFFになった瞬間に自分の指令接点がOFFしていると、その命令は実行されない。**完了フラグでリセットするまで指令接点をONで保持する。**

## 5. 各命令の仕様

### 5.1 IVCK（運転監視）

```
[駆動接点]──[ IVCK  (s1)  (s2)  (d1)  (n)  (d2) ]
ST: ENO := IVCK(EN, s1, s2, n, d1, d2);
```

| オペランド | 内容 |
|---|---|
| (s1) | インバータの局番 K0〜31 |
| (s2) | インバータの**読出し専用命令コード**（§6.1） |
| (d1) | 読出値の格納先デバイス |
| (n) | 通信CH |
| (d2) | 命令実行状態出力（3点占有） |

**プログラム例**（局番0のステータス H7A を読み出して M100〜M107 に格納、Y0〜Y3へ出力）

```
SM400(RUNモニタ)
──┤├──[ IVCK  K0  H7A  K2M100  K1  M200 ]

M100 ──( Y0 )   ; インバータ運転中
M101 ──( Y1 )   ; 正転中
M102 ──( Y2 )   ; 逆転中
M107 ──( Y3 )   ; 異常発生
```

### 5.2 IVDR（運転制御）

```
[駆動接点]──[ IVDR  (s1)  (s2)  (s3)  (n)  (d) ]
ST: ENO := IVDR(EN, s1, s2, s3, n, d);
```

| オペランド | 内容 |
|---|---|
| (s2) | インバータの**書込み専用命令コード**（§6.2） |
| (s3) | 書込む設定値、または設定データ格納先デバイス |

**使用例**

```
[ IVDR  K0  H0FD  H9696  K1  M300 ]   ; インバータリセット（局番0）
[ IVDR  K0  H0FB  K0     K1  M303 ]   ; 計算機リンク運転を指定（E700シリーズは H2）
```

### 5.3 IVRD（パラメータ読出し）

```
[駆動接点]──[ IVRD  (s1)  (s2)  (d1)  (n)  (d2) ]
ST: ENO := IVRD(EN, s1, s2, n, d1, d2);
```

| オペランド | 内容 |
|---|---|
| (s2) | インバータのパラメータ番号（第2パラメータ指定コードも可・§7） |
| (d1) | 読出値の格納先デバイス |

**プログラム例**（局番6から4つのパラメータを読み出す）

```
X1  ──[ SET M0 ]
M0  ──[ IVRD  K6  K902   D100  K1  M200 ]   ; C2  端子2周波数設定バイアス周波数
      [ IVRD  K6  K1902  D101  K1  M210 ]   ; C3  端子2周波数設定バイアス
      [ IVRD  K6  K903   D102  K1  M220 ]   ; 125 端子2周波数設定ゲイン周波数
      [ IVRD  K6  K1903  D103  K1  M230 ]   ; C4  端子2周波数設定ゲイン
SM8029 ──[ RST M0 ]
```

### 5.4 IVWR（パラメータ書込み）

```
[駆動接点]──[ IVWR  (s1)  (s2)  (s3)  (n)  (d) ]
ST: ENO := IVWR(EN, s1, s2, s3, n, d);
```

| オペランド | 内容 |
|---|---|
| (s2) | インバータのパラメータ番号 |
| (s3) | 書込む設定値、または設定データ格納先デバイス |

### 5.5 IVBWR（パラメータ一括書込み）

```
[駆動接点]──[ IVBWR  (s1)  (s2)  (s3)  (n)  (d) ]
ST: ENO := IVBWR(EN, s1, s2, s3, n, d);
```

| オペランド | 内容 |
|---|---|
| (s2) | パラメータの書込み個数（**書込み個数の制限なし**） |
| (s3) | 書込むパラメータテーブルの先頭デバイス |

**テーブル構造（2ワード／1点、占有 = (s2)×2 ワード）**

| デバイス | 内容 |
|---|---|
| (s3)+0 | パラメータ番号1 |
| (s3)+1 | パラメータ書込み値1 |
| (s3)+2 | パラメータ番号2 |
| (s3)+3 | パラメータ書込み値2 |
| … | … |

**プログラム例**（局番5にPr.1=120Hz, Pr.2=5Hz, Pr.7=1s, Pr.8=1s を一括書込み）

```
SM402(イニシャルパルス)
──┤├──[ MOVP K1     D200 ][ MOVP K12000 D201 ]   ; Pr.1 上限周波数 120Hz
          [ MOVP K2     D202 ][ MOVP K500   D203 ]   ; Pr.2 下限周波数 5Hz
          [ MOVP K7     D204 ][ MOVP K10    D205 ]   ; Pr.7 加速時間 1s
          [ MOVP K8     D206 ][ MOVP K10    D207 ]   ; Pr.8 減速時間 1s
          [ SET M10 ]

M10 ──[ IVBWR  K5  K4  D200  K1  M200 ]
SM8029 ──[ RST M10 ]
```

**IVBWR専用のエラーデバイス**

| CH1 | CH2 | CH3 | CH4 | 内容 |
|---|---|---|---|---|
| SM8921 | SM8931 | SM8941 | SM8951 | IVBWR命令エラー |
| SD8921 | SD8931 | SD8941 | SD8951 | IVBWR命令エラーパラメータ番号 |

### 5.6 IVMC（複数コマンド）

```
[駆動接点]──[ IVMC  (s1)  (s2)  (s3)  (d1)  (n)  (d2) ]
ST: ENO := IVMC(EN, s1, s2, s3, n, d1, d2);
```

| オペランド | 内容 |
|---|---|
| (s2) | 送受信データタイプ指定（下表） |
| (s3) | インバータに書込むデータの先頭デバイス（**2ワード**） |
| (d1) | インバータからの読出値の格納先先頭デバイス（**2ワード**） |

**送受信データタイプ (s2)**

| (s2) | 送信データ1 (s3) | 送信データ2 (s3)+1 | 受信データ1 (d1) | 受信データ2 (d1)+1 |
|---|---|---|---|---|
| 0000H | 運転指令(拡張) | 設定周波数(RAM) | インバータステータスモニタ(拡張) | 出力周波数(回転速度) |
| 0001H | 運転指令(拡張) | 設定周波数(RAM) | インバータステータスモニタ(拡張) | 特殊モニタ |
| 0010H | 運転指令(拡張) | 設定周波数(RAM, EEPROM) | インバータステータスモニタ(拡張) | 出力周波数(回転速度) |
| 0011H | 運転指令(拡張) | 設定周波数(RAM, EEPROM) | インバータステータスモニタ(拡張) | 特殊モニタ |

**IVMC固有の注意**

- `(d1)` にインデックス修飾などで**範囲外のデバイス番号**を指定すると、受信データは格納されないが、**(s3)の値はインバータに書き込まれる場合がある**。
- `(s2)` に規定値以外を設定すると、**予期しないデータで書込み・読出しが行われる**。
- `IVMC` は**交信した時点のインバータ状態**を読み出す。したがって**IVMCで書き込んだ状態が読めるのは次の読出し命令（IVCKまたはIVMC）から**。

**対応インバータ**: FREQROL-E700（2009年2月以降生産品）、F800 / A800 / F700PJ / F700P / E700EX / D700

**プログラム例**（局番0に運転指令＋設定周波数を書込み、ステータス＋出力周波数を読出し）

```
SM400 ──[ IVMC  K0  H0000  D10  D20  K1  M200 ]

; D10 = 運転指令(拡張)  HF9 b1=正転, b2=逆転
; D11 = 設定周波数(RAM) 例: K6000=60Hz, K4000=40Hz, K2000=20Hz
; D20 = インバータステータスモニタ(拡張) → [ MOV D20 K4M100 ]
; D21 = 出力周波数(回転速度)             → [ MOV D21 D50 ]
```

## 6. インバータ命令コード

### 6.1 運転監視（IVCKの (s2)・読出し専用）

| 命令コード | 読出し内容 |
|---|---|
| H7B | 運転モード |
| H6F | 出力周波数/回転数 |
| H70 | 出力電流 |
| H71 | 出力電圧 |
| H72 | 特殊モニタ |
| H73 | 特殊モニタ選択No. |
| H74〜H77 | 異常内容 |
| H79 | インバータステータスモニタ(拡張) |
| H7A | インバータステータスモニタ |
| H6D | 設定周波数(RAM)読出 |
| H6E | 設定周波数(EEPROM)読出 |
| H7F / H6C | リンクパラメータ拡張設定 / 第2パラメータ切換（**IVCKでは指定不可**。IVRDで第2パラメータ指定コードを使うと自動処理される） |

> ⚠ **周波数の読出しを行う場合は、IVCK命令の直前で命令コード HFF（リンクパラメータ拡張設定）に "0" を書き込む。** 書き込まないと正常に読み出せない場合がある。
> 表に無い命令コードは通信エラーの原因になるため使用しない。

### 6.2 運転制御（IVDRの (s2)・書込み専用）

| 命令コード | 書込み内容 |
|---|---|
| HFB | 運転モード |
| HF3 | 特殊モニタ選択No. |
| HF9 | 運転指令(拡張) |
| HFA | 運転指令 |
| HED | 設定周波数書込(RAM) |
| HEE | 設定周波数書込(EEPROM) |
| HFD | **インバータリセット** |
| HF4 | 異常内容一括クリア |
| HFC | パラメータオールクリア |
| HFF | リンクパラメータ拡張設定 |

**HFD（インバータリセット）の注意**

- `(s3)` には **H9696** を指定する（**H9966は使用しない**）。
- インバータからの応答がないため、**接続されていない局番にリセットを実行してもエラーにならない**。
- 実行完了まで**約2.2秒**かかる。

> ⚠ **周波数の書込みを行う場合も、IVDR命令の直前で命令コード HFF に "0" を書き込む。**

## 8. 命令の所要時間（送受信回数）

| 命令 | 1命令での送受信回数 |
|---|---|
| IVCK | 1 |
| IVDR | 1 |
| IVRD | 第2パラメータ切替え不要: 2 / 必要: 3 |
| IVWR | 第2パラメータ切替え不要: 2 / 必要: 3 |
| IVBWR | (s2)×2 ＋ 第2パラメータ切替えが必要なパラメータの個数 |
| IVMC | 1 |

> 命令駆動から `SM8029` がONするまでが所要時間。**IVBWRは書込み個数に比例して長くなる**ため、スキャンやシーケンスの設計時に考慮する。

| SM8153 | SM8158 | インバータ通信エラーラッチ |
| SM8154 | SM8159 | IVBWR命令エラー |
| SD8063 | SD8438 | シリアル通信エラーコード |
| SD8152 | SD8157 | インバータ通信エラーコード |
| SD8154 | SD8159 | IVBWR命令エラーパラメータ番号 |
| SD8419 | SD8439 | シリアル通信動作モード |

> `SM8029` はインバータ通信命令以外（位置決め命令など）の完了フラグとしても使われる。**判定接点は必ず該当命令の直下に置く。** プログラムやエンジニアリングツールでON/OFFしないこと。

## 10. ラダー実装パターン

### 10.1 完了フラグで指令をリセットする基本形（推奨）

```
X1(起動) ──[ SET M0 ]              ; 指令のラッチ
M0 ──[ IVCK  (s1) (s2) (d1) (n)  M100 ]   ; 通信の実行
M101 ──[ 正常完了処理 ][ RST M0 ]  ; 命令正常完了 → 指令リセット
M102 ──[ 異常完了処理 ][ RST M0 ]  ; 命令異常完了 → 指令リセット
```

### 10.2 SM8029で指令をリセットする形

```
X1 ──[ SET M0 ]
M0 ──[ IVCK  (s1) (s2) (d1) (n)  (d2) ]
SM8029 ──[ RST M0 ]                ; 正常/異常を問わず完了でリセット
```

### 10.3 エラーコードを退避する形

```
M0 ──[ IVWR  (s1) (s2) (s3)  K1  M100 ]
M102(命令異常完了)
──┤├──[ MOV SD8500 D50 ]   ; エラーコードを退避
          [ SET M50 ]          ; エラー表示
```

### 10.4 STL（ステート）内で使う場合

```
- ステートの移行条件に SM8029 のON条件を加え、通信中にステートが移行しないようインタロックする
- ZRST等によるステート一括リセットは、インバータ通信中（SM8920/8930/8940/8950）がOFFの条件で実行する

X1(リセット入力)  SM8920(b接点)
──┤├──────────┤/├──[ ZRST S0 S4095 ]
```

### 10.5 RUN時にパラメータを書き込む初期化パターン

```
SM402(イニシャルパルス)
──┤├──[ ZRST M510 M607 ][ ZRST D200 D707 ]   ; ラッチデバイスのクリア
          [ SET M10 ]                            ; 書込み指令(局番0)
          [ SET M510 ]                           ; 書込み指令(局番1)

M10 ──[ IVDR  K0  H0FD  H9696  K1  M300 ]   ; インバータリセット
      [ IVDR  K0  H0    H0FB   K0  M303 ]   ; 計算機リンク運転を指定
      [ MOVP K1 D200 ][ MOVP K12000 D201 ]  ; Pr.1 = 120Hz
      [ MOVP K2 D202 ][ MOVP K500   D203 ]  ; Pr.2 = 5Hz
      [ MOVP K7 D204 ][ MOVP K10    D205 ]  ; Pr.7 = 1s
      [ MOVP K8 D206 ][ MOVP K10    D207 ]  ; Pr.8 = 1s
      [ IVBWR K0 K4 D200 K1 M306 ]
M306(完了) ──[ RST M10 ]
```

> E700シリーズでは「計算機リンク運転の指定」は `H2` を書き込む。

## 11. プログラム作成上の注意（違反するとバグになる）

1. **通信が完了するまで指令接点をOFFしない。** 完了フラグ（`(d)+1` / `(d)+2` / `SM8029`）で自分の指令をリセットする。
2. 結果判定の接点は**必ず該当命令の直下**に置く（フラグは命令間で共通のため）。
3. プロトコル形式が[インバータ通信]でないCHでは命令が使えない（3600H）。
4. **他の通信（RS2命令など）で使用中のシリアルポートでは、インバータ通信命令と通信プロトコル支援命令は使えない**（1810H）。
5. 以下のプログラムフロー内では**使用不可**: `CJ`-`P` 間（条件ジャンプ）、`FOR`-`NEXT` 間（繰り返し）、`P`-`RET` 間（サブルーチン）、`I`-`IRET` 間（割込みルーチン）。
6. STL内で使う場合はステート移行に `SM8029` のインタロックをかける。ステート一括リセットはインバータ通信中フラグOFFを条件にする。
7. 周波数の読み書きの直前に **HFF（リンクパラメータ拡張設定）に "0" を書き込む**。
8. インバータリセットは `(s3)=H9696`。約2.2秒かかる。
9. **インバータ側でパスワード機能を使う場合の注意**（対応機種: F800/A800/F700PJ/F700P/A700/E700/E700EX/D700）:
   - 通信エラー時、シーケンサは**自動で最大3回までリトライ**する。そのため Pr.297「パスワード解除ミスの回数表示」が有効だと、**1回の誤ったパスワード書込みで解除ミス回数が3回になる**ことがある。
   - 解除ミス回数が5回になると、正しいパスワードでも解除できなくなり、**パラメータオールクリアが必要**になる。
   - **Pr.297へ書き込む場合は、シーケンスプログラムによる自動リトライ（命令の再駆動）を行わない。**
   - パスワード登録時は Pr.297 を書き込んだ後に**読み返して確認**する（読み返し値が0〜4なら正常登録）。

### 12.1 エラーフラグとエラーコード格納先

### 12.4 演算エラー（命令自体のエラー）

**エラーフラグ**: `SM0` / `SM1` / `SM56` / `SM8067`

| コード | 内容 |

## 13. ラダー生成前チェックリスト

- [ ] CHのプロトコル形式を[インバータ通信]にしたか
- [ ] 局番 `(s1)` はK0〜31か、CH `(n)` はそのCPUで有効か
- [ ] `(d)`/`(d2)` に3点連続の空きビットデバイスを確保したか
- [ ] 指令接点を完了フラグでリセットする構造にしたか（完了前にOFFしない）

- [ ] 周波数の読み書き前に HFF に "0" を書いたか
- [ ] インバータリセットの (s3) を H9696 にしたか
- [ ] CJ/FOR/P-RET/I-IRET の中に命令を置いていないか
- [ ] STL使用時、SM8029とSM892xでインタロックしたか
- [ ] IVBWRのテーブルを「番号・値」の2ワード単位で組み、(s2)×2ワードを確保したか

- [ ] 同一CHでRS2命令や通信プロトコル支援命令を使っていないか
