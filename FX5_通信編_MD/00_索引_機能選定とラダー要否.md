## 2. 用途からの機能選定

### Ethernet

| やりたいこと | 使う機能 |
|---|---|
| 任意のバイト列をTCP/UDPで送受信したい | **ソケット通信機能** |
| 相手機器のプロトコル（電文フォーマット）に合わせて送受信したい | **通信プロトコル支援機能（内蔵Ethernet）** |
| 他のシーケンサ・他社PLCとデバイスデータをやり取りしたい（プログラムレス） | **シンプルCPU通信機能** |
| 外部機器（GOT・PC）からFX5のデバイスを読み書きさせたい | **SLMP機能（サーバ）** / **MODBUS/TCP（スレーブ）** |
| FX5から他機のデバイスを読み書きしたい | **SLMP機能（クライアント・`SP.SLMPSND`）** / **シンプルCPU通信** |
| MODBUS/TCPスレーブ機器を制御したい | **MODBUS/TCP（マスタ）＝通信プロトコル支援機能** |
| ロギングファイルをサーバに送りたい／サーバからファイルを取りたい | **ファイル転送機能(FTPクライアント)** |
| SDメモリカードのファイルをPCから取りたい | **ファイル転送機能(FTPサーバ)** |
| GX Works3なしでIPアドレスを変えたい | **IPアドレス変更機能** |

### シリアル

| やりたいこと | 使う機能 |
|---|---|
| バーコードリーダ・プリンタなどと自由なフォーマットで送受信したい | **無手順通信機能（`RS2`）** |
| 相手機器のプロトコルを登録して手順どおり交信したい | **通信プロトコル支援機能（`S(P).CPRTCL`）** |
| 三菱FREQROLインバータを制御・監視したい | **インバータ通信機能** |
| MODBUSスレーブ機器（RTU）を制御したい | **MODBUSシリアル通信（マスタ・`ADPRW`）** |
| FX5をMODBUS RTUスレーブにしたい | **MODBUSシリアル通信（スレーブ）** |
| FX5同士（最大8台）でデバイスを共有したい | **簡易PC間リンク機能** |
| FX5同士（2台）で高速にデバイスを共有したい | **並列リンク機能** |
| PC・表示器からFX5のデバイスを読み書きさせたい | **MCプロトコル機能** |

## 3. シリアルポートの排他制約（最重要）

**同じシリアルポート（チャンネル）で複数の通信機能を重複使用することはできない。**
通信設定でチャンネル番号を重複指定することもできない。

以下の命令で指定したチャンネル番号が、他の通信機能のチャンネル番号と重複していると異常が起こる:

| 機能 | 命令 |
|---|---|
| インバータ通信 | `IVCK`, `IVDR`, `IVRD`, `IVWR`, `IVBWR`, `IVMC` |
| 無手順通信 | `RS2` |
| 通信プロトコル支援機能 | `S(P).CPRTCL` |

**通信異常が起きたら、まず同じチャンネルで上記命令を重複使用していないか確認する。**
重複している場合は不要な命令を削除するかチャンネル番号を修正し、**電源OFF→ONまたはリセット**する。
（重複時の代表的なエラーコード: **1810H**「指定したチャンネルを他の命令で使用」、**7001H**「通信CHパラメータ設定重複エラー」）

### チャンネル割付

| CH | 接続先 |
|---|---|
| CH1 | CPUユニット内蔵RS-485ポート |
| CH2 | 通信ボード（FX5-232-BD / FX5-485-BD / FX5-422-BD-GOT） |
| CH3, CH4 | 通信アダプタ（FX5-232ADP / FX5-485ADP）。CPUユニットに近い順にCH3, CH4 |

- **通信ボードと通信アダプタは合計3台以上接続できない。**
- FX5S / FX5UJ は CH2〜CH4、FX5U は CH1〜CH4、FX5UC は CH1, CH3, CH4。
- 簡易PC間リンク・並列リンクは **1チャンネルのみ**、通信プロトコル支援機能は **2チャンネルまで**、MODBUSシリアル・無手順通信は **最大4チャンネル**。

### シリアル通信動作モード（SD8503 / SD8513 / SD8523 / SD8533）

現在そのCHがどの機能で動いているかを確認できる。

| 値 | 実行中の通信機能 |
|---|---|
| 0 | MELSOFT接続またはMCプロトコル |
| 3 | 簡易PC間リンク通信 |
| 5 | 無手順通信 |
| 6 | 並列リンク通信 |
| 7 | インバータ通信 |
| 9 | MODBUS RTU通信 |
| 12 | 通信プロトコル支援 |
| 上記以外 | 未使用 |

## 4. Ethernetのポート番号ルール（全機能共通）

- **推奨範囲**: 1024〜5548, 5570〜61439（0400H〜15ACH, 15C2H〜EFFFH）
- 1〜1023: WELL KNOWN PORT のため使用しない
- **5549〜5569（15ADH〜15C1H）: システム使用。指定禁止**
- 61440〜65534（F000H〜FFFEH）: 他の通信機能が使用するため使用しない
- iQ Sensor Solution対応機能を使用する場合、45237(B0B5H) と 61440〜65534 を指定しない

**各機能が使用するポート番号（重複禁止）**

| 機能 | ポート番号 |
|---|---|
| ファイル転送機能(FTPサーバ) | 20 (14H), 21 (15H) |
| ファイル転送機能(FTPクライアント) | 62000〜65534 (F230H〜FFFEH) |
| Webサーバ機能 | 80 (50H)（デフォルト・変更可） |
| 時刻設定機能(SNTPクライアント) | 123 (7BH) |
| SLMP機能 | 61440 (F000H), 61441 (F001H) |
| CC-Link IEフィールドネットワークBasic | 61450 (F00AH) |
| MODBUS/TCP（スレーブ） | 502（推奨・変更可） |

### Ethernetの同時接続台数

| ユニット | 最大台数（ソケット通信・MELSOFT接続・SLMPなどの合計） |
|---|---|
| CPUユニット | 8台（コネクションNo.1〜8） |
| Ethernetユニット | 32台（コネクションNo.1〜32） |
| CC-Link IE TSNマスタ・ローカルユニット | 8台 |
| EtherNet/IPユニット | 32台 |
| モーションユニット | 8台 |

> MELSOFT接続の1台分は上記に含まれない。**1つの機能でコネクションを使うと、他の機能で使えるコネクションが減る。**

## 5. Ethernet専用命令に共通するルール

1. **完了デバイスのある命令は、実行完了までコントロールデータ・要求データを変更しない。**
2. **割込みプログラム中でEthernet専用命令を実行しない。**
3. 完了デバイス `(d)` に **T, ST, C は使用できない**。
4. 完了デバイスの使い方（全命令共通）:
   - `(d)+0`: 命令完了スキャンのEND処理でON、次のEND処理でOFF（**1スキャンON**）
   - `(d)+1`: **異常完了時のみ**同じタイミングでON（正常完了時はOFFのまま）
   - → `(d)+0` と `(d)+1` の組合せで正常/異常を判定する
5. CPUユニット専用命令の `(U)` には **文字列 `"U0"` を直接書く**（ラベル・デバイス指定不可）。Ethernetユニット用命令の `(U)` は装着位置番号（FX5UJ: 1H〜8H、FX5U/FX5UC: 1H〜10H）。
6. **オープン完了信号でインタロックする**（CPU: `SD10680.n` / ユニット: `Un\G152`, `Un\G153`）。
7. イニシャル処理の完了を確認する（CPU: `SD10683.b0` / ユニット: `Un\G158.b0`）。

## 6. シリアル通信命令に共通するルール

1. **プロトコル形式が対応する設定になっていないと命令は動作しない**（多くの機能で **3600H**）。
2. **同一チャンネルで複数の通信命令を併用しない**（**1810H**）。
3. **シリアル通信エラー（`SM8500`/`SM8510`/`SM8520`/`SM8530`）は通信が正常に戻ってもOFFしない。**
   クリアは 電源OFF→ON / STOP→RUN / リセット / `SM50`(エラー解除)のON。
4. エラーコードは `SD8500` / `SD8510` / `SD8520` / `SD8530`（CH1〜CH4）に格納される。
5. FX3シリーズ互換用SM/SDは、**通信設定で指定したチャンネルのみ**動作する。

## 9. よく出るエラーコードの横断表

| コード | 意味 | 主に発生する機能 |
|---|---|---|
| 1810H | 指定したチャンネルを他の命令で使用している | シリアル全般（RS2 / インバータ / CPRTCL / ADPRW） |
| 2820H | 指定デバイスがデバイス点数の範囲を超えている | 全専用命令 |
| 2821H | 指定したデバイス範囲が重複している | SP.ECPRTCL |
| 2822H | 指定できないデバイスを指定した | 全専用命令 |
| 3405H | 指定可能な範囲外のデータを入力した（コネクション番号、局番、CH番号など） | 全専用命令 |
| 3582H | 割込みルーチンで使用できない命令を使用した | ソケット通信命令 |
| 3600H | 指定したチャンネルにパラメータ設定していない | シリアル全般 |
| 7001H | 通信CHパラメータ設定重複エラー | シリアル全般 |
| 7010H | パリティ／オーバラン／フレーミングエラー | シリアル全般 |
| 7F24H | サムチェックエラー | MCプロトコル / 通信プロトコル支援 |
| 7F67H / 7F68H / 7F69H | オーバーラン／フレーミング／パリティエラー | MCプロトコル / 通信プロトコル支援 |
| C020H | 送受信データ長が許容範囲を超えている | ソケット通信 |
| C029H | コントロールデータの内容がおかしい | GP.*系ソケット通信命令 |
| C035H | レスポンス監視タイマ内に相手機器の生存確認ができなかった | Ethernet全般 |
| C1BAH | イニシャル未完了状態で専用命令を実行した | Ethernet専用命令 |
| CFB2H | 自局ポート番号が重複して使用されている | Ethernet全般 |
| 2160H | IPアドレスの重複を検出した | Ethernet全般 |
