## 0. 結論サマリ

- 並列リンク＝**FX5同士を1:1で接続し、M/Dデバイスを自動で相互更新**する機能。
- **専用命令は存在しない。** パラメータでリンクデバイスを割り付ければ、通常のMOV等で読み書きするだけ。
- モードは2種類。**親局と子局は必ず同じリンクモードに設定する。**
  - 通常並列リンクモード: M各局100点 + D各局10点
  - 高速並列リンクモード: M不使用、D各局2点
- **受信デバイス（相手からの情報が入るデバイス）を自局で書き換えてはならない。**
- リンクデバイスの更新は**シーケンスプログラムと同期**する（簡易PC間リンクと異なり、ラダー演算途中での更新は発生しない）。
- **並列リンクは1チャンネルのみ設定可能。**

## 1. 通信仕様（変更不可）

| 項目 | 仕様 |
|---|---|
| 接続台数 | 最大2台（1:1） |
| 伝送規格 | RS-485規格準拠 |
| プロトコル形式 | 並列リンク |
| 通信方式 | 半二重双方向 |
| ボーレート | 115200bps（固定） |
| データ長 | 7bit（固定） |
| パリティ | 偶数（固定） |
| ストップビット | 1bit（固定） |
| スタートビット | 1bit（固定） |
| ヘッダ/ターミネータ/サムチェック | 固定 |
| 制御手順 | 形式1（CR, LF付加なし） |
| 最大総延長距離 | FX5-485ADPのみ: 1200m以下 / 上記以外（内蔵RS-485ポート、FX5-485-BD混在）: 50m以下 |

### リンク時間（リンクデバイスが更新されるサイクル）

| リンクモード | リンク時間 |
|---|---|
| 通常並列リンクモード | **15ms ＋ 親局の演算周期(ms) ＋ 子局の演算周期(ms)** |
| 高速並列リンクモード | **5ms ＋ 親局の演算周期(ms) ＋ 子局の演算周期(ms)** |

## 2. パラメータ設定（GX Works3）

設定場所: 内蔵RS-485→[485シリアルポート]、通信ボード→[拡張ボード]（FX5-485-BD）、通信アダプタ→ADP1〜6。

| 分類 | 項目 | 設定値 |
|---|---|---|
| 基本設定 | 拡張ボード（CH2のみ） | FX5-485-BD |
| 基本設定 | プロトコル形式 | **並列リンク** |
| 固有設定 | 局設定 | **0: 親局** / **1: 子局** |
| 固有設定 | リンクモード | **0: 通常** / **1: 高速** |
| 固有設定 | エラー判定時間 | 10〜32767(ms) |
| リンクデバイス | リンクデバイスBit | FX5S: M0〜M32568 / FX5UJ: M0〜M7480 / FX5U・FX5UC: M0〜M32568 |
| リンクデバイス | リンクデバイスWord | 通常モード: D0〜D7980 / 高速モード: D0〜D7988 |
| SM/SD設定 | 互換用SM/SD | 使用しない / CH1 / CH2 |

**設定例**

| 項目 | 親局 | 子局 |
|---|---|---|
| プロトコル形式 | 並列リンク | 並列リンク |
| 局設定 | 親局 | 子局 |
| リンクモード | 通常 | 通常 |
| エラー判定時間 | 500 | 500 |
| リンクデバイスBit | M4000 | M6000 |
| リンクデバイスWord | D990 | D1990 |

> **使用可能チャンネル**: 内蔵RS-485ポート(CH1)、通信ボード(CH2)、通信アダプタ(CH3/CH4)。FX5UCはCH1, CH3, CH4。

## 3. リンクデバイスの割付（最重要）

x1/y1 = 親局のD/Mリンクデバイス先頭番号、x2/y2 = 子局のD/Mリンクデバイス先頭番号。

### 通常並列リンクモード（M各局100点、D各局10点）

| 局 | 用途 | 内部リレー(M) | データレジスタ(D) |
|---|---|---|---|
| 親局 | **送信用**（親→子） | M(y1)〜M(y1+99) | D(x1)〜D(x1+9) |
| 親局 | **受信用**（子→親） | M(y1+100)〜M(y1+199) | D(x1+10)〜D(x1+19) |
| 子局 | **受信用**（親→子） | M(y2)〜M(y2+99) | D(x2)〜D(x2+9) |
| 子局 | **送信用**（子→親） | M(y2+100)〜M(y2+199) | D(x2+10)〜D(x2+19) |

### 高速並列リンクモード（M不使用、D各局2点）

| 局 | 用途 | データレジスタ(D) |
|---|---|---|
| 親局 | 送信用（親→子） | D(x1), D(x1+1) |
| 親局 | 受信用（子→親） | D(x1+10), D(x1+11) |
| 子局 | 受信用（親→子） | D(x2), D(x2+1) |
| 子局 | 送信用（子→親） | D(x2+10), D(x2+11) |

### 設定例に当てはめた具体的なデバイス（親局 M4000/D990、子局 M6000/D1990）

**親局**

| 用途 | 通常並列リンクモード | 高速並列リンクモード |
|---|---|---|
| 送信（親→子） | M4000〜M4099（100点）、D990〜D999（10点） | D990, D991（2点） |
| 受信（子→親） | M4100〜M4199（100点）、D1000〜D1009（10点） | D1000, D1001（2点） |

**子局**

| 用途 | 通常並列リンクモード | 高速並列リンクモード |
|---|---|---|
| 受信（親→子） | M6000〜M6099（100点）、D1990〜D1999（10点） | D1990, D1991（2点） |
| 送信（子→親） | M6100〜M6199（100点）、D2000〜D2009（10点） | D2000, D2001（2点） |

> ⚠ **受信デバイスの内容を自局で変更しないこと。** 正常に動作しなくなる。

**シリアル通信動作モードのコード（SD8503等）**

| 値 | 実行中の通信機能 |
|---|---|
| 0 | MELSOFT接続またはMCプロトコル |
| 3 | 簡易PC間リンク通信 |
| 5 | 無手順通信 |

| ビット | 名称 | 並列リンクでの値 |
|---|---|---|
| b0 | データ長 | 0: 7ビット |
| b2, b1 | パリティビット | (1,1): 偶数(EVEN) |
| b3 | ストップビット | 0: 1ビット |
| b7〜b4 | ボーレート | (1,1,0,1): 115200bps |

## 5. ラダー実装パターン

### 5.1 親局

```
<<リンクエラー表示プログラム>>
SM9090(b接点) ──( Y10 )     ; 並列リンクが中断または設定不良のときY10 ON

<<リンクデバイス（親局→子局）書込みプログラム>>
SM400 ──[ MOV K1X0  K1M4000 ]   ; X0〜X3 を送信用リンクデバイスへ
                                   ; 通常: M4000〜M4099 / 高速: D990, D991
X10  ──[ MOV C0     D990    ]   ; C0の現在値を送信用ワードリンクデバイスへ
                                   ; 通常: D990〜D999 / 高速: D990, D991

<<リンクデバイス（子局→親局）読出しプログラム>>
SM400 ──[ MOV K1M4100 K1Y0  ]   ; 受信用リンクデバイスを Y0〜Y3 へ出力
                                   ; 通常: M4100〜M4199 / 高速: D1000, D1001
X10  ──[ MOV D1000   D10    ]   ; 受信値を D10 に読み出し C1 の設定値にする
                                   ; 通常: D1000〜D1009 / 高速: D1000, D1001
        [ OUT C1  D10 ]
```

### 5.2 子局

```
<<リンクエラー表示プログラム>>
SM9090(b接点) ──( Y10 )

<<リンクデバイス（子局→親局）書込みプログラム>>
SM400 ──[ MOV K1X0  K1M6100 ]   ; 通常: M6100〜M6199 / 高速: D2000, D2001
X10  ──[ MOV C0     D2000   ]   ; 通常: D2000〜D2009 / 高速: D2000, D2001

<<リンクデバイス（親局→子局）読出しプログラム>>
SM400 ──[ MOV K1M6000 K1Y0  ]   ; 通常: M6000〜M6099 / 高速: D1990, D1991
X10  ──[ MOV D1990   D10    ]   ; 通常: D1990〜D1999 / 高速: D1990, D1991
        [ OUT C1  D10 ]
```

### 5.3 立上げ時の通信テストプログラム（運転時は不要）

**親局**

```
SM400 ──[ MOV K1X0    K1M4000 ]   ; 自局X0〜X3を送信用へ
        [ MOV K1M4100 K1Y0    ]   ; 子局からの受信をY0〜Y3へ
```

**子局**

```
SM400 ──[ MOV K1X0    K1M6100 ]   ; 自局X0〜X3を送信用へ
        [ MOV K1M6000 K1Y0    ]   ; 親局からの受信をY0〜Y3へ
```

**テスト手順**

1. 親局・子局の通信設定とプログラムを書き込み、**電源OFF→ONまたはリセット**
2. 使用チャンネルの **SD / RD LEDが点滅**しているか確認（消灯ならトラブルシューティングへ）
3. 親局の X0〜X3 を操作し、子局の Y0〜Y3 がONするか確認
4. 子局の X0〜X3 を操作し、親局の Y0〜Y3 がONするか確認

## 6. プログラム作成上の注意（違反するとバグになる）

1. **他局（受信用）のリンクデバイスの内容を自局で変更しない。**
2. **リンクエラー発生時、リンクデバイスの情報はエラー発生前の状態を保持する。** → `SM9090`（並列リンク運転中）でインタロックし、安全に動作するようプログラムする。
3. **親局と子局のリンクモードは必ず一致させる。**
4. 並列リンクのリンクデバイス更新は**シーケンスプログラムと同期**しており、ラダー演算途中でのリンクデバイス更新は発生しない。
5. 並列リンクは**1チャンネルのみ**設定可能。
6. リンク時間は演算周期に依存する（通常: 15ms＋両局の演算周期、高速: 5ms＋両局の演算周期）。応答性が必要なら**高速並列リンクモード**を選ぶ。
7. **シリアル通信エラーは通信が正常に戻ってもクリアされない。** クリアは 電源OFF→ON / STOP→RUN / リセット / `SM50`(エラー解除)のON。

## 7. トラブルシューティング（並列リンクのみ）

### 7.1 確認するフラグ

| 確認内容 | FX5専用 | FX3互換 |
|---|---|---|
| 並列リンク運転中 | **SM9090** | SM8072 |
| シリアル通信エラー | SM8500 / SM8510 / SM8520 / SM8530（CH1/2/3/4） | SM8063 / SM8438 |
| シリアル通信エラーコード | SD8500 / SD8510 / SD8520 / SD8530 | SD8063 / SD8438 |

### 7.2 エラーコード一覧

| コード | エラー名称 | エラー処理 |
|---|---|---|
| 2220H | パラメータ未検出 | 再度プロジェクトの書き込みを行う |
| 2221H | パラメータ異常 | パラメータの設定値を修正し、再度プロジェクトを書き込む |
| 7001H | 通信CHパラメータ設定重複エラー | 他の通信でシリアルポートを使用していないか確認する |
| 7010H | パリティエラー、オーバランエラー、フレーミングエラー | 配線を確認する |
| 7812H | 並列リンクキャラクタエラー | 配線・ノイズ環境を確認する |
| 7813H | 並列リンクサムエラー | 配線・ノイズ環境を確認する |
| 7814H | 並列リンクフォーマットエラー | 配線・局設定・リンクモード設定を確認する |

## 8. ラダー生成前チェックリスト

- [ ] プロトコル形式を[並列リンク]にし、1チャンネルだけに設定したか
- [ ] 局設定を親局=0 / 子局=1 で設定したか
- [ ] **親局と子局のリンクモードを一致させたか**
- [ ] リンクデバイス先頭番号から占有される範囲（通常: M100点×2 + D10点×2、高速: D2点×2）を他用途と重複させていないか
- [ ] 高速モードでビットデバイス(M)を使おうとしていないか
- [ ] 自局が書き込むのは**送信用リンクデバイスだけ**になっているか（受信用に書き込んでいないか）
- [ ] リンクエラー時のインタロックに `SM9090` を使っているか
- [ ] リンク時間（通常15ms＋両局演算周期 / 高速5ms＋両局演算周期）が制御要件に合っているか
