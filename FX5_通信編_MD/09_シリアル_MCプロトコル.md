## 0. 結論サマリ

- MCプロトコル機能＝**相手機器（パソコン・表示器など）からFX5のデバイスにアクセスさせる機能**。FX5側は**応答する側（スレーブ）**。
- **FX5側にラダーは不要。** パラメータでプロトコル形式を[MCプロトコル]に設定すれば自動的に応答する。
- ラダーで書くことがあるのは次の2つだけ:
  1. **通信エラー監視**（`SM8500`系／`SD8500`系）
  2. **グローバル信号の受信処理**（`SM8680`系：相手機器からのグローバルコマンド受信でON/OFF）
- FX5のシリアルポートで使えるフレーム: **A互換1Cフレーム** と **QnA互換3C/4Cフレーム**。

## 1. パラメータ設定（GX Works3）

設定場所: 内蔵RS-485→[485シリアルポート]、通信ボード→[拡張ボード]、通信アダプタ→ADP1〜6。

| 分類 | 項目 | 設定値 |
|---|---|---|
| 基本設定 | 拡張ボード（CH2のみ） | FX5-232-BD / FX5-485-BD / FX5-422-BD-GOT |
| 基本設定 | プロトコル形式 | **MCプロトコル** |
| 詳細設定 | データ長 | 7bit / 8bit |
| 詳細設定 | パリティ | なし / 奇数 / 偶数 |
| 詳細設定 | ストップビット | 1bit / 2bit |
| 詳細設定 | ボーレート | 300〜115200bps |
| 詳細設定 | サムチェック | 付加する / 付加しない |
| 固有設定 | **局番設定** | **0〜15** |
| 固有設定 | **伝文形式** | 形式1(X,Y 8進) / 形式1(X,Y 16進) / 形式4(X,Y 8進) / 形式4(X,Y 16進) / 形式5 |
| 固有設定 | タイムアウト時間 | 1〜32767(ms) |
| 固有設定 | 伝文ウェイト時間 | 0〜150(ms)（**10の倍数**で設定） |
| SM/SD設定 | ラッチ設定（詳細設定・局番設定） | ラッチする / ラッチしない |
| SM/SD設定 | 互換用SM/SD（FX3シリーズ互換） | 使用する / 使用しない（**1Cフレームのみ有効**） |

**固定値（設定不要）**: スタートビット 1bit / ヘッダ 付加しない / ターミネータ 付加しない / 制御手順 なし

> - **1Cフレームの場合、形式5は使用できない。**
> - **1Cフレームの場合、伝文ウェイト時間の設定は無効。**
> - 「ラッチする」に未対応のCPUユニットに「ラッチする」設定を書き込むと **パラメータ未検出（エラーコード 2220H）** が発生する。CPUユニットをバージョンアップするか「ラッチしない」に変更する。

### ラッチ設定と対応デバイス

| 内容 | 設定 | 対応デバイス |
|---|---|---|
| 詳細設定（通信フォーマット） | ラッチする / ラッチしない | SM8502, SM8512, SM8522, SM8532 |
| 局番設定 | ラッチする / ラッチしない | SM8740, SM8750, SM8760, SM8770 |

## 4. ラダー実装パターン

### 4.1 通信エラー監視（推奨）

```
SM8500(CH1 シリアル通信エラー)
──┤├──[ MOV SD8500 D100 ]   ; エラーコードを退避
        [ SET M900 ]          ; エラー表示・警報

; エラー解除（通信が正常に戻ってもOFFしないため、手動/条件で解除する）
X10(エラーリセット) ──[ SET SM50 ]   ; SM50: エラー解除
```

> `SM8500`系は **電源OFF→ON / STOP→RUN / リセット / `SM50`(エラー解除)のON** でクリアされる。

### 4.2 グローバル信号の受信処理

相手機器から **GWコマンド（1Cフレーム）** を受信すると `SM8680`（CH1）等がON/OFFする。複数局に同報で指示を出す用途に使う。

```
SM8680(CH1 グローバルON)
──┤├──[ 全局一斉停止処理など ]
```

### 4.3 局番をプログラムで変更する（ラッチ設定ありの場合）

```
; SM8740(CH1 局番設定ラッチ設定有効フラグ)がONしていることが前提
[ MOV K3 SD8740 ]   ; CH1の局番を3に設定 → 電源OFF→ONまたはリセットで反映
```

### 4.4 MCプロトコルが有効か確認する

```
SM8503(CH1 MCプロトコル使用有無)
──┤├──( MCプロトコル動作中表示 )
```

## 5. 設計上の注意

1. **FX5側はプログラム不要**。相手機器がアクセスしてくる。不要な回路を作らない。
2. **局番設定は0〜15**。マルチドロップ時は重複させない。
3. **伝文ウェイト時間は10の倍数で設定**（0〜150ms）。1Cフレームでは無効。
4. **1Cフレームでは形式5を使用できない。**
5. **FX3シリーズ互換用SM/SDは1Cフレームのみ有効。**
6. 同一シリアルポートを他の通信機能と併用できない（7001H: 通信CHパラメータ設定重複エラー）。
7. **相手機器が「書込み」コマンドでFX5の制御用デバイスを書き換えられる。** アクセスされるデバイス範囲を設計時に検討する（RUN中書込み不可設定なら 7167H が返る）。
8. `SM8500`系のエラーフラグは自動復帰しない。

## 6. トラブルシューティング（MCプロトコルのみ）

### 6.1 エラーフラグ・エラーコード格納先

| CH1 | CH2 | CH3 | CH4 | 名称 |
|---|---|---|---|---|
| SM8500 | SM8510 | SM8520 | SM8530 | シリアル通信エラー |
| SD8500 | SD8510 | SD8520 | SD8530 | シリアル通信エラーコード |

### 6.2 1CフレームのNAK応答時エラーコード（相手機器へ返すコード）

エラーコードは 00H〜FFH を **ASCIIコード2桁(16進)** で送信する。同時に複数のエラーが生じた場合、**先に発生したエラーコードが優先**され、伝送シーケンスはすべて初期化される。

| コード | エラー項目 | エラー内容 | 処置方法 |
|---|---|---|---|
| 02H | サムチェックエラー | 受信データ中のサムチェックコードと、受信データから作成したサムチェックが一致しない | 相手機器の送信データとサムチェック内容を確認し、どちらかを変更して再交信する |
| 03H | プロトコルエラー | パラメータで設定した制御手順と異なる制御手順で交信した／指定したコマンドが存在しない | パラメータと制御手順の内容を確認して修正する／コマンド詳細を参照して指定コマンドを修正する |
| 06H | キャラクタ部エラー | 制御手順が異なる／存在しないデバイス番号を指定した／デバイス番号を指定キャラクタ数（5または7キャラクタ）で指定していない | キャラクタA・B・C部の内容を修正する／デバイス範囲を修正する |
| 07H | キャラクタエラー | デバイスに書き込むデータが16進数以外のASCIIコードになっている | 書き込むデータを確認・修正して再交信する |
| 10H | PC番号エラー | 該当PC番号の局が存在しない | 伝文中のPC番号を確認して修正する（**FX5シーケンサはすべてFFH**） |
| 18H | リモートエラー | リモートRUN/STOPができない（他のツールでリモートSTOP操作が行われている） | リモートSTOP操作を行ったツールでリモートRUN操作を行ってから、再度リモートRUN/STOPを行う |

### 6.3 CPUユニット側のエラーコード（`SD8500`系に格納）

| コード | エラー項目 | エラー内容 | 処置方法 |
|---|---|---|---|
| 7001H | シリアル通信共通エラー | **通信CHパラメータ設定重複エラー** | 他の通信でシリアルポートを使用していないか確認する |
| 7010H | シリアル通信共通エラー | 通信中にパリティ／オーバラン／フレーミングエラーが発生した | 配線と通信設定を確認する |
| 7143H | デバイス番号エラー | 先頭デバイス番号が範囲外 | 相手機器の送信伝文を確認・修正して再交信する |
| 7164H | 要求内容エラー | 要求内容またはデバイス指定方法に誤りがある | 相手機器の送信伝文／要求内容を確認・修正する |
| 7167H | RUN中不可 | **RUN中書込み不可の設定時に書込みコマンドを指定した** | RUN中書込み可に設定変更して再交信する |
| 7168H | — | RUN中に実行できないコマンドを指定した | CPUをSTOPにして再交信する |
| 7E40H | コマンドエラー | 存在しないコマンド、またはサブコマンドを指定した | 相手機器の送信伝文を確認・修正する |
| 7E41H | データ長エラー | ランダム読出し/書込み時、交信可能点数を越えて指定した | 相手機器の送信伝文を確認・修正する |
| 7E42H | データ数エラー | 要求点数がコマンドに対して範囲を越えている | 相手機器の送信伝文を確認・修正する |
| 7E43H | デバイスエラー | 存在しないデバイスを指定した／該当コマンドで指定できないデバイスを指定した／先頭デバイス番号が範囲外 | 相手機器の送信伝文を確認・修正する |
| 7F21H | 受信ヘッダ部エラー | コマンド(フレーム)部分の指定に誤りがある／バイナリに変換できないASCIIコードを受信した | 相手機器の送信伝文を確認・修正する |
| 7F22H | コマンドエラー | 存在しないコマンドまたはデバイスを指定した／リモートパスワード長に誤りがある | 相手機器の送信伝文を確認・修正する |
| 7F23H | MCプロトコル伝文エラー | キャラクタ部のあとのデータ（ETX、CR-LFなど）がない、または誤った指定をした | 相手機器の送信伝文を確認・修正する |
| 7F24H | サムチェックエラー | 計算したサムチェック／水平パリティ／誤りチェックコードが受信値と合わない | 相手機器のサムチェックコード・水平パリティコード・CRC-16を見直す |
| 7F26H | コマンドエラー | リモートパスワード登録時、アンロック処理前に別のコマンドを受信した | アンロック処理が正常終了後に交信する |
| 7F40H | タイムアウトエラー | 受信した伝文が不足したためタイムアウトが発生した | 受信エラーでデータ抜けがないか／DTR制御で受信が中断していないか／伝文が不足していないか（相手機器の伝送プログラム）を確認する |
| 7F67H | オーバーランエラー | 受信処理を完了する前に次のデータを受信した | 通信速度を下げて再交信する |
| 7F68H | フレーミングエラー | 相手局の電源ON/OFFによる回線の乱れ／ノイズ／マルチドロップで複数機器が同時送信 | ノイズ対策する／マルチドロップ時は同時送信しないようインタロックをとる |
| 7F69H | パリティエラー | パリティビットの設定が合っていない／回線の乱れ／ノイズ／同時送信 | FX5と相手機器の設定を合わせる／ノイズ対策する／インタロックをとる |
| 4000H〜4FFFH | — | CPUユニットが検出したエラー（MCプロトコル通信機能以外で発生） | `MELSEC iQ-F FX5S/FX5UJ/FX5U/FX5UCユーザーズマニュアル(ハードウェア編)` を参照 |

## 7. ラダー生成前チェックリスト

- [ ] プロトコル形式を[MCプロトコル]にしたか
- [ ] 局番（0〜15）・伝文形式・タイムアウト時間・伝文ウェイト時間（10の倍数）を設定したか
- [ ] 1Cフレームで形式5を選んでいないか
- [ ] **FX5側にラダーを書こうとしていないか**（応答は自動。必要なのはエラー監視とグローバル信号処理のみ）
- [ ] 通信エラー監視（`SM8500`系 → `SD8500`系の退避）を入れたか
- [ ] エラーフラグが自動復帰しないことを踏まえた解除手段（`SM50`など）を用意したか
- [ ] グローバルコマンドを使う場合、`SM8680`系の処理を作ったか
- [ ] 相手機器から書き換えられるデバイス範囲を検討したか
- [ ] 同一シリアルポートを他の通信機能と併用していないか
