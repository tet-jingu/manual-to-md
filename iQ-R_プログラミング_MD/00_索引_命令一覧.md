## 表記の読み方

| 表記 | 意味 |
|---|---|
| `(P)` | パルス実行形式がある（例: `MOV(P)` → `MOV` と `MOVP`） |
| `_U` | 符号なし／BCD 演算形式（例: `+_U`、`CMP_U`） |
| `○` | 比較演算子が入る（例: `LD○` → `LD=`, `LD<>`, `LD>`, `LD<=`, `LD<`, `LD>=`） |
| `D` 接頭 | 32ビット（ダブルワード）版（例: `DMOV`、`DCMP`） |
| `E` 接頭 | 単精度実数版（例: `E+`、`ECMP`）／`ED` 接頭は倍精度実数版 |
| `$` 接頭 | 文字列版（例: `$MOV`、`$+`） |
| `Z.` / `ZP.` / `G.` / `GP.` / `J.` / `JP.` / `S.` / `SP.` 接頭 | ユニット／ネットワーク指定の専用命令 |
