## 1-1 システム構成 (1-2〜1-5 / 原本 p.22-25)

### システム構成の概要 (1-2〜1-4 / 原本 p.22-24)

> 《KV-7000シリーズ》を使用する際のシステム構成は、以下のようになります。
> 各ユニットは、必ず電源がOFFの状態で接続してください。

#### KV-5000/3000シリーズの拡張ユニットを使用する場合 (1-2 / 原本 p.22)

【図】システム構成図 (1-2 / 原本 p.22)。左から右へ次の順にユニットを並べて接続する。

| 番号 | ユニット | 型式・備考 |
|---|---|---|
| ① | AC電源ユニット | KV-PU1 (DC24V 1.8A) |
| ② | CPUユニット | KV-7500/7300 |
| ③ | KV-7000シリーズ用 拡張ユニット（入出力、特殊） | — |
| ④ | バス接続ユニット | （CPUユニットに付属） |
| ⑤ | KV-5000/3000シリーズ用 拡張ユニット（入出力、特殊） | — |
| ⑥ | エンドユニット | — |

図中のその他の機器:

- SDメモリカード KV-M16G/M4G/M1G … CPUユニット②に挿入
- パソコン … CPUユニット②と接続。パソコンにはラダーサポートソフト KV STUDIO
- エクステンションユニット KV-EB1S / KV-EB1R … ⑤の拡張ユニットの位置から分岐して接続。KV-EB1S と KV-EB1R の間は ケーブル（1m）（OP-42142）/ ケーブル（2m）（OP-42141）で接続

> **ポイント**
> バス接続ユニット、KV-5000/3000シリーズの拡張ユニットを使用する場合のみ、右端にエンドユニットが必要です。

#### ①電源について (1-3 / 原本 p.23)

##### AC100～240Vを使用する (1-3 / 原本 p.23)

> AC100～240VでKV-7000シリーズを動作させる場合は、AC電源ユニット《KV-PU1》を一番左側に接続して使用します。CPUユニット1台に対して《KV-PU1》は1台のみ接続可能です。

- → 「2-3 AC電源ユニット」

##### DC24Vを使用する (1-3 / 原本 p.23)

> DC24VでKV-7000シリーズを動作させる場合は、AC電源ユニット《KV-PU1》は使用しません。DC24Vは《KV-7500/7300》のDC電源入力端子台から供給します。

- → 「2-2 CPUユニット」

#### ②CPUユニットについて (1-3 / 原本 p.23)

> CPUユニットの左側にはAC電源ユニット、右側には拡張入出力ユニットや拡張特殊ユニット、バス接続ユニットが接続できます。右側にバス接続ユニットを使用してKV-5000/3000シリーズ用の拡張ユニットを接続する場合は、必ずエンドユニットを接続します。

- → 「2-2 CPUユニット」

> アクセスウィンドウによるデバイス値のモニタや、SDメモリカード、またはユーザメモリへのラダープログラムやデバイスデータの読み書きができます。

- → 「5章 CPU内蔵機能」

> KV-7000シリーズでは、モジュール・ファンクションブロック・マクロ・ローカルデバイス・KVスクリプトなどの機能を使用してプログラミングを効率化できます。

- → 「4章 ラダープログラミング」
- → 『スクリプトプログラミングマニュアル』
- → 『KV STUDIOユーザーズマニュアル』

#### ③KV-7000シリーズ用拡張ユニットについて (1-3 / 原本 p.23)

> KV-7000シリーズ用拡張入出力ユニットや拡張特殊ユニットは必ずCPUユニットの右側、バス接続ユニットの左側に接続します。（KV-5000/3000シリーズの拡張ユニットを使用しない場合、バス接続ユニットは接続不要です。）
> 1台のCPUユニットに16台までのKV-7000シリーズ用拡張ユニットが接続できます。

- → 「2-4 KV-7000シリーズ用拡張入出力ユニット（KV-SIR32XT）」
- → 『各拡張特殊ユニットのユーザーズマニュアル』

> **参考**
> バス接続ユニット接続時はKV-5000/3000シリーズ用の拡張ユニットを接続しない場合でも、エンドユニットは必要です。

#### ④バス接続ユニットについて (1-4 / 原本 p.24)

> KV-7000シリーズにKV-5000/3000シリーズ用拡張入出力ユニットや拡張特殊ユニット使用時に取り付けます。バス接続ユニット使用時は、右側に必ずエンドユニットを取り付けてください。

- → 「2-8 バス接続ユニット」

#### ⑤KV-5000/3000シリーズ用拡張ユニットについて (1-4 / 原本 p.24)

> KV-5000/3000シリーズ用拡張入出力ユニットや拡張特殊ユニットをKV-7000シリーズに接続して使用する場合は、必ずバス接続ユニットの右側に取り付けて使用してください。一番右端の拡張ユニットの右側に、必ずエンドユニットを接続します。
> エクステンションユニットを2セット使用すると、KV-7000シリーズ用の拡張ユニットと合わせて最大48台まで接続できます。（一部の拡張特殊ユニットを除く）

- → 『KV-5000/3000シリーズ用の各拡張特殊ユニットのユーザーズマニュアル』

#### ⑥エンドユニットについて (1-4 / 原本 p.24)

> バス接続ユニット、KV-5000/3000シリーズ用拡張入出力ユニットや拡張特殊ユニットの右側に接続してください。接続されていない場合、エラーが発生し、動作できません。

> **ポイント**
> KV-7000シリーズCPUユニットおよび、KV-7000シリーズ用拡張ユニットのみ接続している場合、エンドユニットは必要ありません。

### 通信機器との接続方法 (1-5 / 原本 p.25)

> KV-7000シリーズとパソコンやタッチパネルと通信する場合の通信経路について説明します。

#### パソコンと通信する場合 (1-5 / 原本 p.25)

【図】KV-7500/7300 とパソコンの接続経路 (1-5 / 原本 p.25)。KV-7500/7300 とパソコンの間を次の3経路(両方向矢印)で接続する。

| 経路 | 注記 |
|---|---|
| USBポート（USB通信） | — |
| イーサネットポート（イーサネット通信） | ※1 |
| シリアルポート（RS-232C） | ※2※3 |

- ※1 KV-7300の場合、別途イーサネットユニットが必要

> **ポイント**
> VT/DTや、EtherNet/IP™などのネットワークを経由して通信することもできます。

【図】KV-7500/7300 とタッチパネルの接続経路 (1-5 / 原本 p.25)。接続先は VT3シリーズ / VT5シリーズ(イーサネットの経路は VT3-E3 を経由する図)。

| 経路 | 注記 | 図中の接続先 |
|---|---|---|
| シリアルポート（RS-232C） | ※1 | VT3シリーズ / VT5シリーズ |
| シリアルポート（RS-422A/485） | ※2 | VT3シリーズ / VT5シリーズ |

## 1-2 ユニットの予約について (1-6 / 原本 p.26)

> KV-7000シリーズでは、ユニットの予約機能を使用して、ユニット構成が異なる場合でも、同じプロジェクトでユニットの管理ができます。たとえば、拡張アナログ入力ユニットをオプションで取り付けるような装置の場合でも、同じプロジェクトで動作するため、プロジェクトの管理が簡単になります。

【図】ユニット予約の例 (1-6 / 原本 p.26)

- プロジェクトA: ユニット番号 0 = CPUユニット(KV-7500)、1・2 = KV-SIR32XT、3 = KV-SAD04 を「ユニット予約」(点線枠)
- 構成A: CPU + KV-SIR32XT ×2(3番の位置は空=点線) → 動作可能
- 構成B: CPU + KV-SIR32XT ×2 + KV-SAD04 → 動作可能
- どちらの構成も同じプロジェクトAで動作する

> **ポイント**
> - ユニットを予約設定している際に、実際の構成にはユニットが存在する場合は、ユニット構成エラーは発生せず、正常に動作します。
> - 予約設定をしているユニット以外について、ユニットエディタで設定したユニット情報と、実際に接続されている機器情報と異なる場合、ユニット台数エラーまたはユニット種別エラーが発生し、動作できません。
> - 実際の構成に存在しないユニット（予約設定している）番号を命令語（マクロ命令など）のオペランドに使用すると、変換時はエラーが発生せず、実行時に演算エラー（軽度エラー）が発生します。なお、以下の方法で演算エラーを回避できます。
>   - 拡張ユニット有無リレーを実行条件にANDで加える
>   - CPUシステム設定（エラー発生時の動作設定）で、CPU動作を続行（無視）にする
> - KV-5000/3000シリーズの拡張ユニットを使用している場合、ユニット番号の変更を反映するためには電源入り切りが必要になる拡張ユニットがあります。

> **参考**
> - 各ユニット番号の拡張ユニットの接続確認には、拡張ユニットn有無リレー（CR4001～）を使用できます。
> - 予約ユニットの右側に拡張ユニットを追加することもできます。
> - 複数台の同じユニットを連続して予約設定にし、実際の構成にそれよりも少ない台数のユニットを接続した場合、接続されたユニットは左から詰めて並べられたユニット番号として動作します。たとえば、ユニット番号、1、2、3にKV-SIR32XTを予約設定し、2台のKV-SIR32XTを使用すると、ユニット番号、1、2のユニットとして認識して動作します（1、3などとユニット番号の間隔を空けては使用できません）。
