### / キーの使い方 (付-34〜付-35 / 原本 p.564-565)

#### / キーを押すと、カーソル位置の設定が入れ替わります。 (付-34〜付-35 / 原本 p.564-565)

> 変更できる設定は次のとおりです。

##### a接点、b接点 立ち上がり、立ち下がり (付-34 / 原本 p.564)

【図】(原本 p.564) 接点 MR04000 の表示の切り換わり。

| 操作 | 変化 |
|---|---|
| Ctrl + /(スラッシュ) | a接点 → a接点の立ち上がり(↑) → a接点の立ち下がり(↓) → a接点(元に戻る) |
| Ctrl + /(スラッシュ) | b接点 → b接点の立ち上がり(↑) → b接点の立ち下がり(↓) → b接点(元に戻る) |
| /(スラッシュ) | a接点 ⇔ b接点、a接点の立ち上がり ⇔ b接点の立ち上がり、a接点の立ち下がり ⇔ b接点の立ち下がり(上下の段が入れ替わる) |

> **ポイント** Ctrl + / キーを押すと次のように変化します。

【図】(原本 p.564) ヨコ接続線だけのセル → ↑ の付いたセル → ↓ の付いたセル → 元のセル、の順に Ctrl + /(スラッシュ)で切り換わる。

##### SET、RES (付-34 / 原本 p.564)

【図】(原本 p.564) コイル R01000 の SET ⇔ RES が /(スラッシュ)で切り換わる。

##### サフィックス (付-35 / 原本 p.565)

【図】(原本 p.565) MOV 命令(オペランド #123 / +123、DM1000)のサフィックスが /(スラッシュ)を押すたびに次の順で切り換わる。

MOV(#123) → MOV.S(+123) → MOV.D(#123) → MOV.L(+123) → MOV.F(+123) → MOV.DF(#123) → MOV(元に戻る)

#### 命令語のないセル上でキーを押すと、b接点が入力されます。 (付-35 / 原本 p.565)
