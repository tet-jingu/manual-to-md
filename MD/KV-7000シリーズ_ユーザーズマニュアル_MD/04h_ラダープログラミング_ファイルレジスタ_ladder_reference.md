## 4-12 ファイルレジスタ (4-176〜4-185 / 原本 p.274-283)

### 概要 (4-176 / 原本 p.274)

> ファイルレジスタは、すべての領域を連番方式で扱う「ZF」と、領域を16個のバンク（0～15）に分割するバンク切換方式で扱う「FM」があります。

【図】バンク切換方式と連番方式の対応 (原本 p.274)

| バンク | バンク切換方式 | 連番方式 |
|---|---|---|
| バンク0 | FM0 ～ FM32767 | ZF0 ～ ZF32767 |
| バンク1 | FM0 ～ FM32767 | ZF32768 ～ ZF65535 |
| バンク2 | FM0 ～ … | ZF65536 ～ … |
| (バンク3〜13: 原本の図では波線で描画なし) | … | … |
| バンク14 | … ～ FM32767 | … ～ ZF491519 |
| バンク15 | FM0 ～ FM32767 | ZF491520 ～ ZF524287 |

> 補足(本ファイル作成者): 原本の図はバンク2の先頭とバンク14の末尾のみを示し、その間を波線で区切っている。バンク n の ZF 範囲は ZF(32768×n) ～ ZF(32768×n＋32767)。

> 例えば、バンク1のFM0とZF32768は同じデータ格納場所を指します。
> → デバイス番号の詳細やデータの取り扱い方などは「4-4 デバイスと定数」ファイルレジスタ　ZF/FM（4-36ページ）を参照してください。

### バンク切換 (4-176 / 原本 p.274)

> バンクを切り換えるには、「FRSET命令」を使用します。
> 現在指定されているバンクをカレントバンクと呼びます。

例

〈ニモニックリスト〉

```
LDP R000
MPS
AND<> CM710 #1
FRSET #1
MPP
MOV FM0 DM0
LDP R001
MPS
AND<> CM710 #0
FRSET #0
MPP
MOV FM0 DM0
```

| ラダー行 | 原本の図中注記 |
|---|---|
| R000(立ち上がり) ─ CM710(ファイルレジスタ カレントバンク) <> #1 ─ FRSET #1 | カレントバンクがバンク1でない場合にカレントバンクをバンク1に切換 |
| └ MOV FM0 DM0 | FM0(=ZF32768)の値をDM0にコピー |
| R001(立ち上がり) ─ CM710(ファイルレジスタ カレントバンク) <> #0 ─ FRSET #0 | カレントバンクがバンク0でない場合にカレントバンクをバンク0に切換 |
| └ MOV FM0 DM0 | FM0(=ZF0)の値をDM0にコピー |

> → 「FRSET命令」4-180ページ

> **参考**
> - カレントバンクの番号はCM710で確認できます。
> - KVモード（上位リンク）の「BE」コマンドを使用して、バンクを切り換えることができます。
>
> → 『KV-L2*Vユーザーズマニュアル』『KV-LE2*Vユーザーズマニュアル』

### 初期値設定 (4-177 / 原本 p.275)

> ファイルレジスタ（連番方式）の値をあらかじめ設定する場合は、《KV STUDIO》のワークスペース上から開く「デバイス初期値設定」ダイアログで設定します。

【図】デバイス初期値設定 ダイアログ (原本 p.275 / スクリーンショット。表示例: 初期値有効デバイス ZF0～ZF999 点数1000、デバイス ZF、表示形式 10進数16BIT)

> このダイアログで設定したプロジェクトをCPUユニットに転送すると、PRG→RUNモード切り換え時に設定した初期値を自動的に読み出します。
> → 『KV STUDIOユーザーズマニュアル「デバイス初期値設定」』

### ファイルレジスタ一括設定 (4-177〜4-179 / 原本 p.275-277)

> 専用命令語を使用して、CPUユニットに挿入したメモリカードや、内蔵のCPUメモリを対象に、ファイルレジスタのデータ（ファイルレジスタ設定値）を保存･読出しができます。
> FRSTM命令 : 指定したバンクのファイルレジスタをメモリカードまたはCPUメモリに保存
> FRLDM命令 : メモリカードまたは CPU メモリに保存したファイルから指定したバンクのファイルレジスタに読出
> → 「FRSTM命令」4-182ページ、「FRLDM命令」4-184ページ

【図】ファイルレジスタとストレージの関係 (原本 p.275)

| 項目 | 内容 |
|---|---|
| ファイルレジスタ側 | バンク0(FM0～FM32767)、バンク1(FM0～FM32767)、…(波線省略)…、バンク999※(FM0～FM32767) |
| FRSTM命令 | ファイルレジスタ → メモリカードまたはCPUメモリ |
| FRLDM命令 | メモリカードまたはCPUメモリ → ファイルレジスタ |
| メモリカードまたはCPUメモリ | ストレージごとに最大1000ファイル |

- ※メモリカード/CPUメモリを使用した場合。内蔵のデバイスのみを使用した場合は15までです。

(図では「バンク999※」と記載されているが、FRSTM/FRLDM のバンク番号 n2 は 0～15、ファイル番号 S が 0～999 である。図の「バンク999」はファイル番号(最大1000ファイル)を指すものと思われる。原文ママ・要確認)

> あらかじめ最大1000ファイルまでのファイルレジスタ設定値をメモリカードまたはCPUメモリに用意して、必要な時に読み出せば、デバイス数を気にせずに段取り替え用途で使用できます。

#### ファイルレジスタ設定値の管理 (4-178 / 原本 p.276)

> メモリカードまたはCPUメモリ内に保存されているファイル（ファイルレジスタ設定値）は、《KV STUDIO》で編集できます。ワークスペース上から開く「ファイルレジスタ設定」ダイアログで編集、新規作成、CSVファイルのインポートなども可能です。フィルレジスタ設定値は、プロジェクトごとに管理されます。
> → 『KV STUDIOユーザーズマニュアル「ファイルレジスタ設定」』

(「フィルレジスタ設定値」は原文ママ。「ファイルレジスタ設定値」の誤植と思われる)

【図】ファイルレジスタ設定 ダイアログ (原本 p.276 / スクリーンショット。表示例: 保存先 1:CPUメモリ、設定No 000、「CPUメモリでファイルレジスタ設定を使用する場合、メモリカードは不要です。」、デバイス FM0～、表示形式 10進数16BIT)

#### ファイルレジスタ設定値の転送 (4-178〜4-179 / 原本 p.276-277)

> 《KV STUDIO》で新規作成・編集したファイルレジスタ設定値をメモリカードまたはCPUメモリに書き込んだり、メモリカードまたはCPUメモリ内のファイルレジスタ設定値ファイルを読み出す方法は以下のとおりです。

【図】転送経路 (原本 p.276)

| 経路 | 転送元 ⇔ 転送先 |
|---|---|
| PLC転送・読出 | パソコンの KVSプロジェクト(ラダープログラム、ファイルレジスタ設定値 …) ⇔ CPUユニットの メモリーカード / CPUメモリ |
| インポート・エクスポート | パソコンの KVSプロジェクト ⇔ パソコン側の メモリーカード |

##### PLC転送・読出 (4-179 / 原本 p.277)

> PLC転送・読出時に他のプロジェクト情報と同様に通信します。転送時、他のプロジェクト情報はCPUユニット本体に、ファイルレジスタ設定のみメモリカードまたはCPUメモリに保存されます。
> → 『KV STUDIOユーザーズマニュアル「モニタ」』

##### インポート・エクスポート (4-179 / 原本 p.277)

> ストレージ転送ツールを使用して、インポート・エクスポートをおこないます。
> → 『KV STUDIOユーザーズマニュアル「ファイルレジスタ設定」』

#### 動作説明 (4-180 / 原本 p.278)

> **FRSET**　実行条件がONのとき、ファイルレジスタのカレントバンク番号を n で指定した番号に切り換えます。
> **@FRSET**　実行条件の立ち上がりで、1スキャンだけ実行します。

- ※2 ビットデバイスを指定した場合、連続する2ビットを占有します。ワードデバイスを指定した場合、連続する2ワードのそれぞれ最下位ビットを通知ビットデバイスとして使用します。最下位ビット以外は変化しません。

#### 動作説明 (4-182 / 原本 p.280)

> **FRSTM**　実行条件の立ち上がりで、バンク番号 n2 のファイルレジスタ全てを、バイナリ形式で n1 で指定したストレージへ一括保存します（ファイルは常に上書きされます）。
> 　ファイル番号 S は数値で指定します。
> 　作成されるファイル名は、¥FR¥FR（ファイル番号3桁）.FRUとなります。

例

> S に10が格納されている場合、¥FR¥FR010.FRUが作成されます。

> D には完了通知が、 D ＋1には異常終了のエラー通知が書き込まれます。
> - D は命令実行開始時にOFFし、ストレージへの書き込み処理終了時にONします。命令が正常終了、異常終了のどちらでもONします。
> - D ＋1は命令が正常終了でOFFし、異常終了でONします。
>
> 「FR」フォルダがない場合は、新規作成されます。

> **ポイント**
> ストレージ命令実行中リレー（CR3214）がONしているときに、命令は実行されません。
> CR3214を使用して排他制御をおこなってください。
