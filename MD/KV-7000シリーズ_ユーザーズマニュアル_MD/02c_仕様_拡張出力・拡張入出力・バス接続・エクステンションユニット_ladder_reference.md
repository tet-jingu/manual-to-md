## 2-6 拡張出力ユニット (2-26〜2-34 / 原本 p.52-60)

> KV-5000/3000シリーズ拡張出力ユニット《KV-B8RC/KV-B16RC/KV-B16TC(P)/KV-C32TC(P)/KV-C64TC(P)/KV-B16TD/KV-C32TD/KV-C64TD》の各部の名称と機能、および仕様について説明します。

### 各部の名称と機能 (2-26 / 原本 p.52)

【図】KV-B8RC/KV-B16RC/B16TC(P)/KV-B16TD（正面）/ KV-C32TC(P)/KV-C32TD（正面）/ KV-C64TC(P)/KV-C64TD（正面）/（側面）(2-26 / 原本 p.52)

- 端子台タイプ(KV-B…): ②ダイレクトアクセススイッチ、③出力端子台
- コネクタタイプ(KV-C32…: コネクタ1個、KV-C64…: コネクタ2個): ①出力コネクタ、②ダイレクトアクセススイッチ
- 側面: ④ロックレバー(上下)

| 番号 | 名　称 | 機　能 |
|---|---|---|
| ① | 出力コネクタ | 出力用コネクタです。 |
| ② | ダイレクトアクセススイッチ | スイッチをONすることにより、CPUのアクセスウインドウで拡張ユニットの状態をモニタできます。また、スイッチの色により、拡張ユニットの状態がわかります。<br>緑点灯：正常動作のとき<br>緑点滅：緑点灯状態でスイッチをONし、ユニットが選択されたとき<br>赤点灯：ユニットエラーが発生したとき(一部例外を除く※1)<br>赤点滅：赤点灯状態でスイッチをONし、ユニットが選択されたとき |
| ③ | 出力端子台 | 出力用端子台です。取りはずしが可能です。（M3ビス） |
| ④ | ロックレバー | ユニットの連結をロックします。 |

- ※1 以下の場合、ユニットエラー状態ではなくても赤点灯します。<br>　①電源投入時、CPUユニットのユニット情報がCPU1台の構成になっているとき<br>このとき、アクセスウインドウでエラー表示されます。
- ※ KV-C32TC/C64TC/C32TCP/C64TCP/KV-C32TD/KV-C64TD接続用34ピンコネクタはオプションで用意しています。

> **参考**
> ダイレクト処理が可能です。KV-B16RA/B16TA/C32TA(P)/C64TA(P)も使用可能ですが、ダイレクト処理はできません。
> → 「ダイレクト処理について」4-63ページ

## 2-9 エクステンションユニット KV-EB1S/KV-EB1R (2-43〜2-46 / 原本 p.69-72)

### 各部の名称と機能 (2-43 / 原本 p.69)

【図】KV-EB1S / KV-EB1R (2-43 / 原本 p.69)。KV-EB1S(前段の右端)と KV-EB1R(後段の左端)を⑥OPケーブルで接続する図。

- KV-EB1R: ①電源監視LED、②延長コネクタ、③DC電源入力端子台(24V / 0V)、④供給電源切換スイッチ（底面）、⑤KV-U7接続用コネクタ（横面）

| 番号 | 名　称 | 機　能 |

| ① | 電源監視LED | 電源監視用のLEDです。※1 |
| ② | 延長コネクタ | 延長ケーブル接続用のコネクタです。 |
| ③ | DC電源入力端子台 | DC24V電源入力用の端子台です。(3.5Aまで)※2、※3 |

- ※1 LEDが橙または赤点灯の場合、電源電圧が低下している可能性があります。電源を確認してください。

- ※4 KV-U7を接続する場合、拡張するユニットの消費電流に注意してください。

> **ポイント**
> 供給電源切換スイッチを切り換えるときは、必ず電源をOFFにしてください。

### 接続・設置について (2-44 / 原本 p.70)

> KV-EB1Sは延長する前の段の一番右端に接続します。
> KV-EB1Rは延長した後の段の一番左側に接続します。

【図】ユニット構成例（最大）(2-44 / 原本 p.70)

- 1段目: KV-7500/7300 ＋ 最大16ユニット ＋ 右端に KV-EB1S
- 2段目: 左端に KV-EB1R ＋ ユニット ＋ 右端に KV-EB1S
- 3段目: 左端に KV-EB1R ＋ ユニット
- 段と段の間隔(縦): 60mm以上

#### 接続ケーブルと段数について (2-44 / 原本 p.70)

- 延長ケーブル1m（OP-42142）使用時<br>縦段数3段まで（最大48ユニット接続可）
- 延長ケーブル2m（OP-42141）使用時<br>縦段数2段まで（最大32ユニット接続可）

#### 設置について (2-44 / 原本 p.70)

> エクステンションユニット使用時、上段と下段のユニットの間隔は、熱の影響を考慮して60mm以上離してください。
> 盤内の温度（ユニット下面での温度）が、ユニットの使用周囲温度を超える場合は、強制空冷や周囲との間隔を広げ通風をよくするなどの方法で温度を下げてください。

### 供給電源切換について (2-45 / 原本 p.71)

> 拡張ユニットへ供給する電源を切り換えることができます。

#### 前段の電源を使用する (2-45 / 原本 p.71)

【図】供給電源切換スイッチ(POWER: INT / EXT)を INT 側にした状態 (2-45 / 原本 p.71)

> OPケーブルで送られる前段からの電源を使用する場合は、供給電源切換スイッチを「INT」に設定します。
> KV-U7または別電源を使用せずに運転可能ですが、合計の消費電流が使用する電源の定格を越えないように注意してください。

#### 外部電源を使用する (2-45 / 原本 p.71)

【図】供給電源切換スイッチを EXT 側にした状態 (2-45 / 原本 p.71)

> KV-U7または別電源を使用する場合は、供給電源切換スイッチを「EXT」に設定します。

##### KV-U7を使用する (2-45 / 原本 p.71)

【図】KV-U7 を KV-EB1R の左側に接続した図 (2-45 / 原本 p.71)

> KV-U7をKV-EB1Rの左側に接続します。

##### 別電源を使用する (2-45 / 原本 p.71)

> 別電源をDC電源端子台に接続します。

> **注記**
> KV-EB1Rから別電源を供給する場合は、以下のことに注意してください。
> - 電源投入時：KV-EB1R側から先に電源を供給してください。
> - 電源断　　：KV-7500/7300側から先に電源断してください。
>
> (エラー発生時はアクセスウィンドウ、または《KV STUDIO》でエラークリア後、PROG→RUNすれば動作します。)

> **ポイント**
> - KV-EB1 を使用し 3 段増設して各電源に別電源使用の場合、電源ケーブルにフェライトコア（北川工業：RFC-10）を2ターン挿入する、KV-U7使用の場合、FGを接地するなどのノイズ対策をおこなってください。
