## 5-8 アクセスウィンドウ (5-84〜5-137 / 原本 p.406-459)

> CPUユニットや拡張ユニットの各データのモニタや変更が簡単にできるアクセスウィンドウの機能について説明します。

### アクセスウィンドウでできること (5-84〜5-87 / 原本 p.406-409)

> KV-7000シリーズは、小型の2色バックライト付LCD表示器を搭載しています。
> RUN中は白、PRGモード時（停止中）は赤になります。

#### 機能一覧 (5-85〜5-86 / 原本 p.407-408)

> 《KV-7500/7300》の本体には、アクセスウィンドウが装備されているので、データの変更･モニタが簡単にできます。また、万一のエラー発生時にエラーコードが確認できます。
> アクセスウィンドウには、以下の機能があります。

| 機能 | 説明 | 参照 |
|---|---|---|
| ユニットのモニタ | CPUに接続されたユニットのダイレクトアクセススイッチを押すと、アクセスウィンドウ上でそのユニットの状態をモニタすることができます。 | → 「ユニットのモニタ」（5-88ページ） |
| デバイスモード | 内部デバイスの表示、設定内容の変更が可能です。 | → 「デバイスモード」（5-91ページ） |
| ストレージ | メモリカードやCPUメモリ内のプロジェクトセーブやロード、ファイル管理、空き容量の確認などの操作を行うことができます。 | → 「ストレージ」（5-112ページ） |
| エラークリア | CPUユニットの重度エラーをクリアします。 | → 「エラークリア」（5-100ページ） |
| デジタルトリマ | デジタル方式でトリマの設定を行うことができます。最大分解能は4294967296です。 | → 「デジタルトリマ」（5-101ページ） |
| ユニットテスト | 拡張ユニットの入出力などの状態を確認できます。 | → 「ユニットテスト」（5-103ページ） |
| 時刻表示／設定 | CPUの内部時計の表示、時刻設定を行います。 | → 「時計」（5-105ページ） |
| CPUモニタ | CPUの内蔵機能の状態をモニタすることができます。また、本体に入っているプログラムのプロジェクト名や、本体のシリアル番号、バージョンを確認できます。 | → 「CPUモニタ」（5-107ページ） |
| アラームモニタ | 任意に設定したアラームのモニタや履歴を確認することができます。 | → 「アラーム」（5-109ページ） |
| アクセスウィンドウ設定 | アクセスウィンドウのコントラストなど、アクセスウィンドウの表示に関する設定を行うことができます。 | → 「アクセスウィンドウ設定」（5-125ページ） |
| Language | 表示する言語を、日本語、英語、中国語（簡体字）から選択できます。 | |
| RAMクリア | デバイスの値をクリアすることができます。 | → 「RAMクリア」（5-127ページ） |
| オールクリア | 設定した内容をすべてクリアすることができます。 | → 「オールクリア」（5-128ページ） |
| CPUメモリクリア | CPUメモリ内のデータをクリアできます。 | |

#### 各部の名称と機能 (5-87 / 原本 p.409)

> ①アクセスウィンドウ…各デバイスの現在値や設定値、およびエラーメッセージなどが表示されます。
> 　各ユニットのダイレクトアクセススイッチが押されると、各ユニットの情報が表示されます。
> ②設定操作キー…各モード間の移行、および各モードでの設定変更に使用します。それぞれのキーの機能は、各モードごとに異なります。詳細は、各モードの操作方法を参照してください。

【図】CPUユニット前面: ①アクセスウィンドウ(LCD)、②設定操作キー(MENU / ▲ / ENTER / ◀ / ▼ / ▶)

### ユニットのモニタ (5-88〜5-90 / 原本 p.410-412)

> CPUに接続されたI/Oユニットなどの拡張ユニットや特殊ユニットのダイレクトアクセススイッチを押すと、アクセスウィンドウ上で、そのユニットのモニタおよび設定ができます。
> 拡張ユニット、特殊ユニットの画面から、もとの画面に戻るには、現在アクセスウィンドウに表示されているユニットのダイレクトアクセススイッチをもう一度押すか、「MENU」キーを2回押してください。

> **参考**
> ユニットエラーが発生した場合にはダイレクトアクセススイッチが赤色になり、アクセスウィンドウにエラー内容を表示します。

> → ユニットのモニタ内容や設定内容は、各ユニットのマニュアルを参照してください。

#### 設定操作キーの機能 (5-88 / 原本 p.410)

> ユニットのモニタおよび設定時のキー機能は次のとおりです。

| 設定操作キー | 通　常 | 数値変更時 |
|---|---|---|
| MENU | メニュー表示 | 通常表示に戻ります。 |
| ENTER | 1秒以上押しつづけると、設定変更を実行します。 | 1秒以上押しつづけると、設定変更を実行します。 |
| ▲ | ページを切り換えます。設定変更時は選択肢を変更します。 | 設定値から変化量を加算します。 |
| ▼ | ページを切り換えます。設定変更時は選択肢を変更します。 | 設定値から変化量を減算します。 |
| ◀ | メニュー表示 | 変化量の桁を変更します。 |
| ▶ | 使用しません | 変化量の桁を変更します。 |

> **参考**
> **設定操作キーのデバイス番号**

| ▲ | CR4400 | AW 上キー押下中 |

| ◀ | CR4402 | AW 左キー押下中 |
| ▶ | CR4403 | AW 右キー押下中 |

#### 操作方法（入出力ユニットの場合） (5-89〜5-90 / 原本 p.411-412)

> KV-SIR32XTを例に操作方法を説明します。

**ユニットモニタへの移行**

1. **ユニット部のダイレクトアクセススイッチを押します。**<br>選択されたユニットのダイレクトアクセススイッチが点滅します。
2. **リレーのON/OFF状態が表示されます。**<br>アクセスウィンドウは選択されているユニットによって次のようになります。

   【図】「KV-SIR32XT 000 / 入力 76543210 / L____■ / H____■___」(英語「IN」)。ビット7～0の ON/OFF を L(下位)/H(上位) の2段で表示。

   「▲」「▼」キーでページを切り換えます。

> **ポイント**
> ユニットモニタは中国語表記に対応していません。

**メニュー表示**

1. **ユニットのダイレクトアクセススイッチが点滅（選択）している状態で、「MENU」キーを押す。**<br>ユニットのメニューが表示されます。

   【図】「･モニタ ･設定 時定数000 ･設定 時定数100 ･設定 入力レンジ」(英語「･Monitor ･Set InFilter000 ･Set InFilter100 ･Input Range」)

**設定変更**

> 入力時定数を変更する例で説明します。

1. **設定時定数000を選択し、続いて「ENTER」キーを押す。**<br>現在の時定数の設定状態が確認できます。<br>【図】「KV-SIR32XT 000 / 時定数 / 1us」
2. **この状態で「ENTER」キーを1秒以上押します。**<br>設定値が点滅し変更モードに入ります。（RUN中は不可、PRGモード時のみ変更可）
3. **上下キーで設定値を変更し、「ENTER」キーを1秒以上押します。**<br>点滅が止まり設定されます。（MENUキーを押すとキャンセルになります。）<br>【図】「KV-SIR32XT 000 / 時定数 / 100us」

### デバイスモード (5-91〜5-98 / 原本 p.413-420)

> PLCデバイスの値がモニタ、および変更できます。

#### 表示･設定変更できるデバイス (5-91 / 原本 p.413)

> 表示設定変更できるデバイスは次のとおりです。

| 表　示 | 名　称 | 表　示 | 名　称 |
|---|---|---|---|
| R | リレー | ZF | ファイルレジスタ（連番方式） |
| MR | 内部補助リレー | W | リンクレジスタ |
| LR | ラッチリレー | CM | コントロールメモリ |
| B | リンクリレー | TM | テンポラリメモリ |
| CR | コントロールリレー | T | タイマ |
| DM | データメモリ | C | カウンタ |
| EM | 拡張データメモリ | TRM | デジタルトリマ |
| FM | ファイルレジスタ（バンク切換方式） | Z | インデックスレジスタ |

### エラー内容の確認 (5-99 / 原本 p.421)

> CPUユニットのエラーには軽度エラーと重度エラーの2種類があります。

| | 軽度エラー | 重度エラー |
|---|---|---|
| アクセスウィンドウの色 | 白 | 赤 |
| アクセスウィンドウの表示 | エラー内容を表示しながら点滅<br>(例「CPUエラー W128 / ラダー演算エラー」) | エラー内容を表示しながら点滅<br>(例「CPUエラー E52 / ユニット未接続」) |
| CPUの状態 | RUNモードのまま（ラダープログラムは動作します） | PROGRAMモードに切換（ラダープログラムは停止します） |
| エラークリア方法 | • アクセスウィンドウのいずれかのキーを押す<br>• ラダープログラム上で CR3909 を SETする | CPU が PROGRAM モードになるため、ラダープログラムからはエラークリアできません。エラークリア方法は → 「エラークリア」（5-100ページ）を参照してください。 |

> **参考**
> 重度エラー発生中はアクセスウィンドウのいずれかのキーを押すとエラーの表示は消えますが、エラーはクリアされません。アクセスウィンドウを操作しない状態が30秒以上続くか、RUN⇔PRG切換スイッチをRUNに切り換えるとエラー内容を再表示します。

#### エラー発生時の対処 (5-99 / 原本 p.421)

1. **エラーコードを確認します。**<br>アクセスウィンドウに表示されるエラーコードを確認します。軽度エラーと重度エラーでエラーコードの表示が下記のように異なります。<br>　軽度エラー･･･「W○○○」<br>　重度エラー･･･「E○○○」<br>右図の例では、エラーコード52の重度エラーが発生していることが分かります。<br>【図】「CPUエラー E52 / ユニット未接続」
2. **エラー内容と対処法を確認します。**<br>→ 「PLC本体エラー一覧」（付-2ページ）でエラー内容と対処法を確認し、エラー原因を取り除きます。

   | 番号 | 分類 | メッセージ | 内容 | 対処 |
   |---|---|---|---|---|
   | 52 | 設定エラー | ユニット未接続<br>Unit Unconnected<br>单元未连接 | ユニット設定情報では拡張ユニットありになっているのに、実際には接続されていません。 | 電源をOFFにしてから、ユニットエディタで設定した拡張ユニットを接続してください。 |

   拡張ユニットで発生したエラーの場合は、各ユニットのユーザーズマニュアルを確認してください。

   > **参考**
   > 重度エラー発生中はCR3905がONし、CM5105にエラーコードが格納されます。軽度エラー発生中はCR3906がONし、CM5155にエラーコードが格納されます。これらのCRやCMを使用することで、タッチパネルからエラー内容を確認できます。→ 「最新エラー詳細（CM）」（4-67ページ）
3. **エラークリアを実行します。**<br>軽度エラーが発生している場合は、アクセスウィンドウのいずれかのキーを押すか、ラダープログラム上でCR3909をSETしてください。<br>重度エラーが発生している場合は、アクセスウィンドウを操作してエラークリアする必要があります。<br>エラークリアの方法については、→ 「エラークリア」（5-100ページ）を参照してください。

- **入出力ユニットの場合**　例）KV-C16XTD<br>【図】「KV-C16XTD / IN 76543210 / 000 / 008」→「OUT 76543210 / 016 / 024」<br>「▲」「▼」キーで確認するリレー位置を16ビット（出力リレーは8ビット）ずつ移動できます。<br>「◀」「▶」キーでカーソル位置を変更できます。<br>「ENTER」キーでカーソル位置の出力状態（ON/OFF）を反転できます。
