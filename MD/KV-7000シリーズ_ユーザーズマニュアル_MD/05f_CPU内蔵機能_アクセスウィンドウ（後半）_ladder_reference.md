## 5-8 アクセスウィンドウ(後半) (5-109〜5-137 / 原本 p.431-459)

### アラーム (5-109〜5-111 / 原本 p.431-433)

> アラームリレー（CR3300～CR3415）にデバイスコメントとしてメッセージを登録しておくと、アラームリレーがONした場合にメッセージを自動的にアクセスウィンドウ上に表示します。また、発生したアラームの履歴を確認したりクリアすることもできます。

#### 使用方法 (5-109 / 原本 p.431)

> アラームで使用するデバイスは次のとおりです。

| コントロールリレー | R/W | 内容 |
|---|---|---|
| CR3300～CR3415 | R/W | アラームリレー（32個）です。あらかじめデバイスコメントを登録しておきます。 |
| CR3500 | R | アラームリレーが1つでもONしているとCR3500がONします。ONしているアラームがすべてOFFすると、自動的にCR3500もOFFします。 |
| CR3501 | R/W | ON→OFF履歴を保存します。 |
| CR3502 | R/W | OFF→ON時にアラームリレーの履歴をクリアします。 |

(CR3501・CR3502 の行はテキスト抽出で脱落していたため画像から補った)

> **ポイント**
> アラームリレーは必ずSET、RES命令で操作してください。動作中のアラームリレーのリセットかつアラーム履歴の一括クリアはARES命令でも可能です。

**アラームメッセージの登録**

> アラームリレー（CR3300～CR3415）にデバイスコメントを登録します。

> **ポイント**
> アクセスウィンドウに表示できるメッセージは全角8文字（半角16文字）までです。デバイスコメントを設定していない場合はアラームリレーの番号を表示します。

**アラーム履歴について**

> アラーム履歴は、CPUユニットに最大16件まで保存されます。
> 16件を超える場合は、古い履歴から順に削除して新しい履歴を保存します。
> 1件につき、「アラームリレー番号」「時刻（年月日時分秒）」「ON/OFFの状態」を保存します。
> - ON→OFF履歴リレー（CR3501）がOFFの場合<br>アラームリレーがOFF→ONの場合のみ履歴を保存します。
> - ON→OFF履歴リレー（CR3501）がONの場合<br>アラームリレーがOFF→ONとON→OFFの両方とも履歴を保存します。
>
> CR3502をONすると、アラームリレーの履歴をクリアします。クリアが完了すると、CR3502はOFFします。

#### 操作できる項目 (5-110 / 原本 p.432)

> アクセスウィンドウから操作できる機能は次のとおりです。

| 日本語 | 英語 | 中国語 | 設定内容 |
|---|---|---|---|
| モニタ | Monitor | 报警监控器 | ONしているアラームリレーをリアルタイムでモニタできます。 |
| 履歴モニタ | Monitor Record | 日志监控器 | アラームリレーのON/OFF履歴をモニタできます。 |
| 履歴クリア | Clear Record | 日志清除 | アラームリレーのON/OFF履歴をクリアします。 |

#### 操作方法 (5-110〜5-111 / 原本 p.432-433)

**アラームへの移行**

1. **「MENU」キーを押します。**<br>メニューが表示されます。（他ページが選択されている場合は「MENU」キーを押してください。）
2. **「8.アラーム」を選択して、「ENTER」キーを押します。**<br>アラームのメニューが表示されます。<br>【図】「･モニタ ･履歴モニタ ･履歴クリア」

**モニタ**

1. **アラームのメニューで「モニタ」を選択して、「ENTER」キーを押します。**<br>アラームモニタが表示されます。<br>複数のアラームリレーがONしている場合、「▲」「▼」キーを押すと別のアラームを表示します。<br>【図】「アラームモニタ / 01/03 / 速度上限異常」(英語「Alarm Monitor / 01/03 / Spd. Limit Over」)

> ①[01/03]<br>現在表示中のアラーム番号／発生しているアラーム総数です。<br>複数のアラームが発生している場合は、アラームリレー番号の小さいものを優先して表示します。
> ②[速度上限異常]<br>現在表示しているアラームの対象デバイスのデバイスコメントです。

> **参考**
> - いずれかのキーを押すと、点滅が止まります。
> - 他の画面を表示中でも、アラームが一つでも発生すると自動的にアラームモニタが表示されます。

**履歴表示** (5-111 / 原本 p.433)

1. **アラームのメニューで「履歴モニタ」を選択して、「ENTER」キーを押します。**<br>アラーム履歴が表示されます。<br>「▲」「▼」キーを押すと、1つ前/後の履歴を表示します。<br>【図】「履歴 01/04 / 温度ワーニング / 2015/3/13 / 12:13:14 ↓」(英語「Record 01/04 / Temp. Warn.」)

> ①[01/04]<br>現在表示中のアラーム履歴番号／履歴総数です。<br>番号は最新の履歴が[01]になります。
> ②[温度ワーニング]<br>現在表示している履歴の対象デバイスのデバイスコメントです。
> ③[↓]<br>アラームリレーがONからOFFになったときの履歴であることを示しています。OFFからONになったときの履歴は「↑」で表示されます。
> ④[2015/3/13 12:13:14]<br>履歴が記録された時刻を示しています。

**履歴クリア**

1. **アラームのメニューで「履歴クリア」を選択して、「ENTER」キーを押します。**<br>履歴クリアの確認メッセージが表示されます。<br>【図】「履歴クリア / クリアしますか?」(英語「Clear Record / Clear OK?」)
2. **「ENTER」キーを1秒以上押しつづけます。**<br>履歴クリアが終了すると、次の表示になります。<br>【図】「履歴クリア / クリア完了」(英語「Clear Record / Clear Done」)

> 「MENU」キーを押すとアラームメニュー表示に戻ります。

### ストレージ (5-112〜5-124 / 原本 p.434-446)

> メモリカードやCPUメモリへのデータ保存やファイルの読み出しなどをアクセスウィンドウ上から操作できます。
> メモリカードやCPUメモリ機能の詳細は、→ 「5-2 メモリカード」（5-4ページ）、「5-3 CPUメモリ（ユーザメモリ）」（5-27ページ）を参照してください。

> アクセスウィンドウから操作できるメモリカード操作は次のとおりです。

| 日本語 | 英語 | 中国語 | 設定内容 |
|---|---|---|---|
| ロード | Load | 加载 | 任意のプロジェクトフォルダ内のデータをCPUユニットに読み出します。 |
| セーブ | Save | 保存 | CPUユニットのデータをメモリカードやCPUメモリに保存します。ラダープログラム、デバイス値、デバイスコメント、ユニット設定情報、ロギング設定情報などが保存されます。 |
| ファイル管理 | File Management | 文件管理 | メモリカードやCPUメモリ内のディレクトリ、ファイルを一覧表示します。また、一覧の中から任意のファイルをコピー、移動、削除できます。 |
| 空き容量 | Free Space | 可用空间 | メモリカードやCPUメモリの空き容量を表示します。 |

> **ポイント**
> 「ロード」はPRGモード時のみ可能です。

#### 操作方法 (5-113〜5-124 / 原本 p.435-446)

**ストレージへの移行**

1. **「MENU」キーを押します。**<br>メニューが表示されます。（他ユニットが選択されている場合は「MENU」キーを2回押してください。）
2. **「4.ストレージ」を選択して、「ENTER」キーを押します。**<br>ストレージのメニューが表示されます。<br>【図】「･ロード ･セーブ ･ファイル管理 ･空き容量」

**ロード**

1. **ストレージのメニューで「ロード」を選択して、「ENTER」キーを押します。**<br>メモリカードとCPUメモリのどちらのストレージを選択するか表示されます。<br>【図】「0:メモリカード / 1:CPUメモリ」
2. **「▲」「▼」でストレージを選択し、「ENTER」または「▶」キーを押します。**<br>メモリカードまたはCPUメモリのルートフォルダにある（プロジェクト）フォルダが表示されます。<br>（ファイルは表示されません。フォルダ名は"<D>KVSAVE01"のように、最初の3文字が<D>で表されます。）<br>【図】「[0:メモリカード] / <D>KVSAVE01 / <D>KVSAVE02 / <D>UserDoc」

   > **参考**
   > フォルダ名が長い場合はスクロールして表示されます。
3. **「▲」「▼」でフォルダを選択し、「ENTER」または「▶」キーを押します。**<br>ロード実行の確認メッセージが表示されます。<br>【図】「KVSAVE01 / 2015/3/13 / 12:13:14 / ロードしますか?」(英語「Load OK?」)
4. **「ENTER」キーを1秒以上押し続けて、ロードを実行します。**<br>ロード実行中は次の表示になります。<br>ロードを開始すると、途中でキャンセルはできません。<br>【図】「ロード / KVSAVE01.YCD / 99%」

   > **ポイント**
   > - ライトプロテクトされている場合は、下図の表示が出ます。<br>「ENTER」キーを1秒押しつづけると、強行してロードが実行されます。<br>「MENU」キーを押すと、ロードがキャンセルされます。<br>【図】「ロード / ライトプロテクトされています / 強行しますか?」(英語「Load / Write protected / Force load?」)
   > - ロード実行時にCPUメモリの空き容量が少なく、CPUメモリ容量設定を変更できない時には、下図の表示が出ます。<br>「ENTER」キーを1秒押しつづけると、CPUメモリクリアが実行されます。<br>「MENU」キーを押すと、ロードがキャンセルされます。<br>【図】「ロード / 容量不足 / ユーザメモリを / クリアしますか?」(英語「Load / Memory Full / Clear User Mem?」)
5. **ロードが完了すると次の表示になります。**<br>【図】「ロード / ロード完了」(英語「Load / Load Done」)<br>「MENU」「ENTER」「◀」「▶」キーを押すとストレージのメニューに戻ります。

**セーブ** (5-115 / 原本 p.437)

1. **ストレージのメニューで「セーブ」を選択して、「ENTER」キーを押します。**<br>メモリカードとCPUメモリのどちらのストレージを選択するか表示されます。<br>【図】「0:メモリカード / 1:CPUメモリ」
2. **「▲」「▼」でストレージを選択し、「ENTER」または「▶」キーを押します。**<br>CPUのデータをセーブするか確認メッセージが表示されます。<br>【図】「セーブ / セーブしますか?」(英語「Save OK?」)
3. **「ENTER」キーを1秒以上押し続けて、セーブを実行します。**<br>KVSAVE??(?? は二桁の半角数字）という名前のディレクトリを検索し、使われていない最小の二桁の数字のディレクトリを作成してセーブします。<br>セーブ実行中は現在セーブ中のファイル名と進捗が表示されます。<br>【図】「セーブ / KVSAVE01.YLB / 65%」
4. **セーブが完了すると、セーブされたプロジェクトフォルダ名が表示されます。**<br>【図】「セーブ / セーブ完了 / KVSAVE01」(英語「Save / Save Done / KVSAVE01」)<br>「MENU」「ENTER」「◀」「▶」キーを押すとストレージのメニューに戻ります。

5. **2度目の確認画面が表示されている状態で、「ENTER」キーを1秒以上押し続けるとユーザメモリクリアが実行されます。**<br>ユーザメモリクリア実行中は次の画面表示になります。ユーザメモリクリアが実行され終了すると、完了メッセージが表示されます。

> **ポイント**
> 「ENTER」キーを1秒以上押し続けなければ[お待ちください･･･]のメッセージは表示されず、無視されます。

### KV STUDIOを使用したアクセスウィンドウ設定 (5-130 / 原本 p.452)

> KV STUDIOからアクセスウィンドウ設定を使用して、以下の設定ができます。

> - ユーザメッセージ設定

#### 表示言語設定 (5-130 / 原本 p.452)

> アクセスウィンドウのデバイスコメントをコメント1～コメント8のどれを表示するかを設定できます。

>
> 表示コメント番号設定の設定値を変更すると、以下を表示する際のコメントが切り換わります。
> - デバイスモニタのコメント表示

> - ユーザメッセージ

> **ポイント**

> - CMの値を変更して、電源切り入りを実行すると初期の表示言語を設定できます。<br>（KV STUDIOとCMの両方で表示コメント番号の設定がされている場合は、KV STUDIOの設定が優先されます。）

(表示コメント番号設定の説明で「電源投入時の表示言語は」「初期の表示言語を設定できます」とあるのは、表示言語設定の文と同文。文脈上は「表示コメント番号」と思われる。原文ママ・要確認)

#### ユーザメッセージ設定 (5-130 / 原本 p.452)

> KV STUDIOから、アクセスウィンドウに表示するメッセージを一覧で設定できます。

### ユーザメッセージ (5-135 / 原本 p.457)

> ユーザメッセージ機能とは、メッセージエディタにて設定した半角64（全角32）文字までのメッセージをアクセスウィンドウに表示させる機能です。
> ユーザメッセージに使用できるCRは63個用意されており、CRをONするだけで表示する文字列を変更できます。また表示コメント番号設定で、コメント1～8を切り換えると最大8言語のユーザメッセージを使用できます。

#### 表示方法 (5-135 / 原本 p.457)

> ユーザメッセージを表示させる方法には以下の2つがあります。

**①AWSHOW命令を使用する。**

> 専用の命令語を使用することでコントロールリレー（CR）を気にすることなく簡単にユーザメッセージを表示させることができます。
> 複数IDのユーザメッセージが同時にONした場合、数値の若いユーザメッセージが優先して表示されます。
> 各命令語についての詳細は、→ 『KV-8000/70005000/3000/1000･KV Nanoシリーズ命令語リファレンスマニュアル「5-14 アクセスウィンドウ命令」』を参照してください。

```
実行条件 ─┤├─[AWSHOW S]     入力方法: A W S H O W ␣ S ↵
```

(「KV-8000/70005000/…」は原文ママ。「7000/5000」のスラッシュ脱落)

**②コントロールリレー（CR）を使ってラダープログラムを作成する。**

> ID1のユーザメッセージを表示するには、CR4601をONします。
> CR4601～CR4915をONすると、対応するIDのユーザメッセージが表示されます。

> 補足(本ファイル作成者): CR4601～CR4615(15点)＋CR4700～CR4715(16点)＋CR4800～CR4815(16点)＋CR4900～CR4915(16点)＝63点で、「CRは63個」と整合する。IDとCRの対応は原本に表なし(ID1＝CR4601のみ記載)。

#### 表示例 (5-135 / 原本 p.457)

【図】「温度異常 / 冷却水の量を / 確認してください」(英語「Temp. Warn. / Check the amount / of Water」)

> 表示中はCR4500からCR4503で指定した行が点滅します。
> 次の場合に表示は元に戻ります。
> - アクセスウィンドウの「ENTER」キーを押したとき。このとき対応しているCRはOFFします。
> - 対応しているCRをOFFしたとき。
> - AWHIDE命令を実行したとき。

> **ポイント**
> - 電源投入時に表示するユーザメッセージIDを設定できます。
> - ユーザメッセージ表示時に「ENTER」キーを押すとユーザメッセージを解除するかどうかを設定できます。
> - 現在表示中のユーザメッセージIDはCM1720で確認することができます。
> - ユーザメッセージ表示中に「MENU」キーを押した場合、アクセスウィンドウの右上に「M」が表示されます。<br>【図】「1.デバイスモー[M] 2.エラークリア 3.ユニットテスト 4.ストレージ」<br>ユーザメッセージ中に他のメニューを表示することはできますが、キー操作が30秒以上なかった場合ユーザメッセージ表示画面に自動的に切り換わります。
> - 複数のユーザメッセージIDのCRがSETされた場合、右端にスクロールボタン(▲ / ▼)が表示されます。スクロールボタンが表示されている間に、「▲」または「▼」キーを押すと別のIDのユーザメッセージを表示できます。

(CR4500～CR4503 による点滅行の指定方法(ビットと行の対応)は原本に記載なし。要確認)

### 操作禁止設定 (5-136 / 原本 p.458)

| コメント切換 | 設定変更 |

> **ポイント**
> デバイスモードでデバイス書き込み禁止を設定すると、以後、アクセスウィンドウで解除できなくなります。

### キーロック (5-137 / 原本 p.459)

> キーロックは、アクセスウィンドウのキー操作を禁止する機能です。設定変更できないようにする場合や表示する画面を固定する場合に使用します。

#### 操作方法 (5-137 / 原本 p.459)

> 設定／解除いずれの場合も、「◀」キーを押しながら「MENU」キーを3秒以上押し続けてください。

**キーロックされていない場合**

> 次の画面が表示され、キーロック状態になります。
> 【図】「AWメッセージ / キーロック」(英語「AW Message / Key Lock」)
> キーロック状態でキーロック解除以外の操作をおこなうと、上の画面が表示されます。

**キーロックされている場合**

> 次の画面が表示され、キーロックが解除されます。
> 【図】「AWメッセージ / キーロック解除」(英語「AW Message / Lock Release」)

> **ポイント**
> - キーロック中は、ダイレクトアクセススイッチを押しても選択されません。
> - ユニットのモニタ、ユニットテスト中は、キーロックできません。
