## 2-4 KV-7000シリーズ用拡張入出力ユニット（KV-SIR32XT） (2-15〜2-18 / 原本 p.41-44)

> 《KV-SIR32XT拡張入出力ユニット》の各部の名称と機能、および仕様について説明します。

### 各部の名称と機能 (2-15 / 原本 p.41)

【図】KV-SIR32XT（正面）（側面） (2-15 / 原本 p.41)

- 正面: ①ダイレクトアクセススイッチ(上部)、②入出力表示灯(0〜15 ×2段 ×2列)、③入出力表示灯切換スイッチ(IN/OUT)、④入出力コネクタ(2個。左が IN、右が OUT の表示)
- 側面: ⑤ロックレバー(上下)、⑥GND連結コネクタ、⑦拡張ユニット接続コネクタ

| 番号 | 名称 | 機能 |
|---|---|---|
| ① | ダイレクトアクセススイッチ | スイッチをONすることにより、CPUのアクセスウィンドウで拡張ユニットの状態をモニタできます。また、スイッチの色により、拡張ユニットの状態がわかります。<br>緑点灯 : 正常動作のとき<br>緑点滅 : 緑点灯状態でスイッチをONし、ユニットが選択されたとき<br>赤点灯 : ユニットエラーが発生したとき（一部例外を除く※1）<br>赤点滅 : 赤点灯状態でスイッチをONし、ユニットが選択されたとき |
| ② | 入出力表示灯 | ユニットの入出力状態を表示します。<br>赤点灯 : 導通状態<br>消灯 : 非導通状態 |
| ③ | 入出力表示灯切換スイッチ | 入出力表示の切換スイッチです。<br>IN : 入力の状態を表示<br>OUT : 出力の状態を表示 |
| ④ | 入出力コネクタ | 入出力用のコネクタです。 |
| ⑤ | ロックレバー | ユニットの連結をロックします。 |
| ⑥ | GND連結コネクタ | 接続したユニットとGNDを連結します。 |
| ⑦ | 拡張ユニット接続コネクタ | KV-7500/7300またはKV-7000シリーズ用拡張ユニットと連結します。 |

- ※1 以下の場合、ユニットエラー状態ではなくても赤点灯します。<br>電源投入時、CPUユニットのユニット情報がCPU1台の構成になっている、ユニット台数エラー、ユニット種別エラーが発生しているなどCPUユニットがシステムエラーになっているとき<br>このとき、アクセスウィンドウでエラー表示されます。
- ※ KV-SIR32XT接続用40ピンコネクタはオプションで用意しています。

## 2-5 拡張入力ユニット (2-19〜2-25 / 原本 p.45-51)

### 各部の名称と機能 (2-19 / 原本 p.45)

【図】KV-B16XC（正面）/KV-C32XC（正面）/KV-C64XC（正面）/（側面）(2-19 / 原本 p.45)

- KV-B16XC: ①入力電圧切換スイッチ(24V/5V)、③ダイレクトアクセススイッチ、④入力端子台

- KV-C64XC: ②入力コネクタ(2個。左 L、右 H)、③ダイレクトアクセススイッチ(入力電圧切換スイッチなし)
- 側面: ⑤ロックレバー(上下)

| 番号 | 名　称 | 機　能 |
|---|---|---|
| ① | 入力電圧切換スイッチ | 入力電圧を切り換えます。5V⇔24V |
| ② | 入力コネクタ | 入力用コネクタです。 |
| ③ | ダイレクトアクセススイッチ | スイッチをONすることにより、CPUのアクセスウインドウで拡張ユニットの状態をモニタできます。また、スイッチの色により、拡張ユニットの状態がわかります。<br>緑点灯：正常動作のとき<br>緑点滅：緑点灯状態でスイッチをONし、ユニットが選択されたとき<br>赤点灯：ユニットエラーが発生したとき(一部例外を除く※1)<br>赤点滅：赤点灯状態でスイッチをONし、ユニットが選択されたとき |
| ④ | 入力端子台 | 入力用端子台です。取りはずしが可能です。（M3ビス） |
| ⑤ | ロックレバー | ユニットの連結をロックします。 |

- ※1 以下の場合、ユニットエラー状態ではなくても赤点灯します。<br>　①電源投入時、CPUユニットのユニット情報がCPU1台の構成になっているとき<br>このとき、アクセスウインドウでエラー表示されます。
- ※ KV-C32XC/C64XC接続用34ピンコネクタはオプションで用意しています。
