## 5-5 USB通信 (5-77 / 原本 p.399)

> CPUユニットのUSBポートを使用して、《KV STUDIO》でラダープログラムのモニタ･デバッグができます。USBポートを使用してコマンド通信などはできません。

> **参考**
> KV COM+ for Excel/KV COM+ Libraryを使用すれば、PLCデバイス値の読み書きが可能です。

### パソコンとの接続方法 (5-77 / 原本 p.399)

> USBケーブル（OP-35331）をパソコンとKV-7000シリーズに接続します。

### USBドライバのインストール (5-77 / 原本 p.399)

> Windows 10/8/7/Vista/XPのパソコン使用時は、自動的に認識されるためインストールする必要はありません。

> **ポイント**
> - 《KV-7000シリーズ》をパソコンのUSBコネクタに接続する前に、必ず《KV STUDIO》をインストールしてください。
> - USBポートのSGは電源0Vと共通です。接続先のSGと電位差が発生すると、CPUユニットおよび接続先の機器が故障する原因となります。

## 5-6 シリアル通信（KV-7300のみ） (5-78〜5-82 / 原本 p.400-404)

> ≪KV-7300≫のシリアルポート（モジュラーコネクタ）を使用して、USBポートと同様にKV STUDIOでラダープログラムのモニタが可能です。また、RS-232C準拠のインターフェースをもつ外部機器を接続して通信することができます。当社タッチパネルディスプレイVT5/VT3シリーズとの接続も可能です。

### 通信仕様 (5-78 / 原本 p.400)

| 項目 | 仕様 |
|---|---|
| 通信規格 | RS-232C |
| 通信方式 | 全2重 |
| 同期方式 | 調歩同期 |
| 通信速度 | 9600，19200，38400，57600，115200bit/s（初期状態は9600bit/s） |
| データビット長 | 8bit |
| パリティチェック | 偶数 |
| ストップビット長 | 1bit |

> **ポイント**
> - 通信仕様は、接続する外部機器と同じ設定にしてください。設定が異なっていると、正しく通信できません。
> - 接続する機器の設定は、それぞれの機器の取り扱い説明書をお読みください。

### シリアル通信でできること (5-78 / 原本 p.400)

| 機能名称 | 内容 |
|---|---|
| KVモード（上位リンク） | キーエンス独自のプロトコルで通信するときに使用するモードです。CPUユニット側で通信プログラムは必要ありません。詳細については → 『KV-L21Vユーザズマニュアル』を参照してください。 |
| KV STUDIOモード | 当社製ラダーサポートソフトやタッチパネルディスプレイVT5/VT3シリーズなどと通信するときに使用します。 |

> **参考**
> - KV-7300のシリアル通信でKVモード（上位リンク）を使用する場合、KV-L21Vと以下の差分があります。
>   - 機種の問い合わせ（?K）コマンドのレスポンスには、54（35H、34H)を返します。
>   - デバイス範囲がMR0～399915となります。
>   - CTH, CTCは使用できません。
>   - 拡張ユニットバッファメモリのアドレス範囲は0～59999です。
>   - RDCではプロジェクト言語設定に従って変換された文字列が読み出されます。
>   - KV-7300、及びKV-7000シリーズに接続されたシリアルユニットに対するバンク切り換え（BE）コマンドにバンク番号0～15が設定できます。

(MR 範囲「MR0～399915」は 4-10 のローカルデバイス一覧(MR 合計64000点=4000ch → MR0～MR399915)と整合する)

### パソコンとの接続方法 (5-79 / 原本 p.401)

> KV-7300とパソコンとの接続は、専用の接続ケーブル（OP-26487）とD-Sub9ピンコネクタ（OP-26486）を使用します。

【図】KV-7300 のモジュラコネクタへ OP-26487(ケーブル長:2.5m) → OP-26486 → パソコンの RS-232Cコネクタへ

KV側ピン番号: モジュラコネクタを正面から見て左から 1 2 3 4 5 6

| KV側(モジュラコネクタ) | 方向 | パソコン側(D-Sub9ピンコネクタ) |
|---|---|---|
| RD 3 | ← | 3 SD |
| SD 5 | → | 2 RD |
| — | | 4 DR ─ 6 ER をコネクタ内で短絡 |
| — | | 7 RS ─ 8 CS をコネクタ内で短絡 |
| SG 4 | ─ | 5 SG |

(図のパソコン側ピン表記は上から「3 SD / 2 RD / 4 DR / 6 ER / 7 RS / 8 CS / 5 SG」。D-Sub9 の標準では DR は6番、ER は4番(p.403 の図ではそのとおり)であり、p.401 では 4/6 の番号と信号名の対応が入れ替わっている。原文ママ・要確認)

### VT5/VT3シリーズとの接続方法 (5-80 / 原本 p.402)

> KV-7300と弊社タッチパネルディスプレイVT5/VT3シリーズとの接続は、専用のKVシリーズプロコンポート直結ケーブル（OP-86917：5m、OP-86916：1m、OP-26484 : 5m、OP-35403 : 1m）を使用します。

| 接続先 | 接続 | ケーブル |
|---|---|---|
| VT5のCOM1と接続する | KV-7300 モジュラコネクタへ ─ VT5シリーズ COM1へ | OP-86917(5m) / OP-86916(1m) |
| VT3のPORT2と接続する | KV-7300 モジュラコネクタへ ─ VT3シリーズ PORT2へ | OP-26484：5m / OP-35403：1m |
| VT3のPORT3と接続する | KV-7300 モジュラコネクタへ ─ VT3シリーズ PORT3へ | OP-24025：5m / OP-24045：1m ＋ OP-26486 |

(PORT3 用の OP-24025 / OP-24045 は本文の「専用のKVシリーズプロコンポート直結ケーブル」の列挙には含まれていない。原文ママ)

> **参考**
> KV-7300側の設定は必要ありません。
> VT5/VT3側の設定は、→ 『VT5/VT3PLC接続マニュアル』を参照してください。

KVユニット側ピン番号: 1 2 3 4 5 6(モジュラコネクタ)
ユニット側1,2番ピンは5V電源

### PLCデバイス値の読み書き (5-82 / 原本 p.404)

> キーエンス独自のプロトコルでKV-7300のデバイス値や動作状態を外部機器から読み書きできます。
> KV-L2*VのKVモード（上位リンク）と全く同じ仕様で、KV-7300は外部機器から送信されてきたコマンドに対して自動的にレスポンスを返信します。KV-7300側で通信プログラムは必要ありません。
> → 『KV-L2*Vユーザーズマニュアル』「5章　KVモード（上位リンク）のプログラミング」

【図】パソコン(ホスト) →(コマンド)→ KV-7300 →(レスポンス)→ パソコン。

| 方向 | フレーム |
|---|---|
| コマンド | 「コマンド CR」 または 「コマンド CR LF」 |
| レスポンス | 「レスポンス CR LF」 |

> **ポイント**
> - 上位リンクコマンドにレスポンスを返信するためには、ユニットエディタで動作モードをKVモード(上位リンク）に設定し、ボーレートを相手機器とあわせてください。
> - コマンドの1バイトと1バイトの間が1秒以上になるとタイムアウトエラーとなり、エラーレスポンスを返信します。
