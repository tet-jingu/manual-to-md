# README - このフォルダの使い方

このフォルダは `MELSERVO-J4サーボアンプ技術資料集 （トラブルシューティング編）.pdf`(三菱電機 汎用ACサーボ MELSERVO-J4シリーズ全般 [A]/[B]/[WB]/[RJ010]/[GF]/MR-J4-03A6/MR-J4-DU_/MR-CV_/MR-CR55K対応、全162ページ・全4章+付録)を、プロジェクトナレッジに常駐させるための参照用Markdownに変換したものです。

> 原本PDFは `manual-to-md` フォルダ直下にあります。編集・移動しないでください。

## 変換方針

第1章より前のフロントマター(p.1-7: 安全上のご注意・マニュアルについて・目次)と、末尾の改訂履歴・保証について・サービスのお問い合わせ・商標(p.150-162)を除く**全章・付録を全文収録**しています。個々のアラーム/警告の発生要因・調査方法・調査結果・処置は、原文の記述を要約せず全文転記しました。原本の縦結合セル(同一の発生要因・調査方法が複数の調査結果に対応する箇所)は、検索・突合せのしやすさを優先して行ごとに展開し、値をrepeatして記載しています(値自体の改変・省略はありません)。

- 第1章はページ数が非常に多い(120ページ)ため、1.1-1.3/1.4を4分割/1.5-1.7の計6パートに分けて並行変換し、後で1ファイルに結合しました。結合時に原本PDFと突き合わせて境界部分の欠落・重複を点検し、欠落は無し、重複1箇所([AL.70]の詳細番号70.3後半〜70.Fが2パートにまたがって重複記載)は統合して1回のみの記載にしています。
