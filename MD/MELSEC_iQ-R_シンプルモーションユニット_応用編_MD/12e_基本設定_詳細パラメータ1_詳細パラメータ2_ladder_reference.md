##### [Pr.11]バックラッシュ補正量 (12.3 / 印刷 p.504 / 原本 p.506)

歯車を介して機械が移動するときの，バックラッシュによる誤差分の補正をすることができます。
バックラッシュ補正量を設定すると，位置決め時に方向が変化するたびに補正量分だけ余分に指令を出力します。

【図】バックラッシュの説明図(12.3 / 印刷 p.504 / 原本 p.506)
- 送りネジ(ハッチング部)とワーク(移動体)のかみ合いを示す断面図。
- 左向き矢印で「[Pr.44]原点復帰方向」を示す。
- 送りネジの歯とワークの歯のすき間を「バックラッシュ(補正量)」として示す。

- バックラッシュ補正は機械原点復帰後，有効になります。したがって，バックラッシュ補正量を設定・変更したときは，必ず一度機械原点復帰を行ってください。
- 下記式(1)を満たすような"[Pr.2]1回転あたりのパルス数(AP)"，"[Pr.3]1回転あたりの移動量(AL)"，"[Pr.4]単位倍率(AM)"，"[Pr.11]バックラッシュ補正量"を設定することが可能です。

式(1): 0 ≦ (([Pr.11]バックラッシュ補正量) × ([Pr.2]1回転あたりのパルス数(AP)))/(([Pr.3]1回転あたりの移動量(AL)) × ([Pr.4]単位倍率(AM))) (=A) ≦ 4194303 (pulse): (1) (小数点以下切り捨て)

式(1)の範囲外となる設定をした場合は，エラー「バックラッシュ補正量エラー」(エラーコード: 1AA0H)が出ます。

##### [Pr.84]サーボOFF → ON時の再始動許容値範囲設定 (12.3 / 印刷 p.519 / 原本 p.521)

###### サーボOFF → ON時の再始動機能とは (12.3 / 印刷 p.519 / 原本 p.521)

サーボOFF → ON時の再始動機能は，シンプルモーションユニットで停止中(緊急停止，強制停止を含む)にサーボOFF → ONを行った場合に位置決めの継続運転(位置決め始動，再始動)を行うことです。
サーボOFF → ON時の再始動は，停止時のシンプルモーションユニットの最終指令位置とサーボOFF → ON時の現在値との差が再始動許容範囲設定用バッファメモリで設定した値以下の場合に行うことができます。

- サーボ非常停止時の処理
  - 緊急停止，強制停止入力時のシンプルモーションユニットの最終指令位置と緊急停止，強制停止解除時の現在値との差が再始動許容範囲設定用バッファメモリで設定した値以下の場合は，停止中となり再始動を行うことができます。
  - 緊急停止，強制停止入力時のシンプルモーションユニットの最終指令位置と緊急停止，強制停止解除時の現在値との差が再始動許容範囲設定用バッファメモリで設定した値より大きい場合には，待機中となり再始動できません。

【図】サーボ非常停止時の処理(12.3 / 印刷 p.519 / 原本 p.521)
- 緊急停止: 解除中 → 入力中 → 解除中。
- 軸動作状態: 運転中 → (緊急停止入力で)サーボOFF中 → (緊急停止解除でサーボON)停止中／待機中。
- 緊急停止入力の時点の位置を「最終指令位置」として保持。
- 緊急停止解除(サーボON)後，差が許容範囲以下なら「再始動可」(停止中)，大きければ「再始動不可」(待機中)。

- サーボON信号のOFF → ON処理
  - サーボON信号がON → OFFしたときのシンプルモーションユニットの最終指令位置とサーボON信号がOFF → ONしたときの現在値との差が，再始動許容範囲設定用バッファメモリで設定した値以下の場合は，停止中となり再始動が行えます。
  - サーボON信号がON → OFFしたときのシンプルモーションユニットの最終指令位置とサーボON信号がOFF → ONしたときの現在値との差が，再始動許容範囲設定用バッファメモリで設定した値より大きい場合には，待機中となり再始動できません。

【図】サーボON信号のOFF → ON処理(12.3 / 印刷 p.519 / 原本 p.521)
- サーボON信号([Md.108]サーボステータス1: b1): ON → OFF → ON。
- 軸動作状態: 位置決め中 → (停止指令で)停止中 → (サーボON信号OFFで)サーボOFF中 → (サーボON信号ONで)停止中／待機中。
- サーボON後，差が許容範囲以下なら「再始動可」(停止中)，大きければ「再始動不可」(待機中)。

###### 設定方法 (12.3 / 印刷 p.520 / 原本 p.522)

サーボOFF → ON時に再始動を行う場合は，下記のバッファメモリに再始動許容範囲を設定してください。
n: 軸No. - 1(軸17～軸32の場合は，n: 軸No. - 17)

| 項目 | 設定範囲 | 工場出荷時の初期値 | バッファメモリアドレス 軸1～軸16 | バッファメモリアドレス 軸17～軸32 |
|---|---|---|---|---|
| [Pr.84]サーボOFF → ON時の再始動許容値範囲設定 | 0，1～327680 [pulse]<br>ただし，0は再始動不可 | 0 | 64+150n<br>65+150n | 1000064+150n<br>1000065+150n |

- 設定例

軸1の再始動許容範囲を10000 pulseに設定するプログラムを下記に示します。

> **Point**
> - 再始動時の初回にサーボOFF時の最終指令位置とサーボON時の現在値との差分を一度に出力します。このとき，再始動許容範囲設定が大きい場合には，サーボ側で過負荷などになることがあります。サーボOFF → ON時の再始動許容範囲の設定は，一度の出力で機械系に影響のでない値を設定してください。
> - サーボOFF → ON時の再始動は，1回目のサーボOFF → ON時のみ有効です。2回目以降のサーボOFF → ON時は，サーボOFF → ON時の再始動許容範囲の設定を無視します。
> - サーボOFFは，機械系が完全に止まった状態で行ってください。サーボOFF→ON時の再始動は，サーボOFF中に外圧などで機械系が動作するシステムには適用できません。
> - 再始動は，軸の動作状態が"停止中"のみ実行できます。軸の動作状態が"停止中"以外になった場合は，再始動できません。
> - サーボOFF中にシーケンサレディ信号[Y0]をOFF → ONした場合は，再始動できません。再始動要求を行った場合は，ワーニング「再始動不可」(ワーニングコード: 0902H)となります。
> - 停止指令がON中には再始動を行わないでください。停止中に再始動を行うと，エラー「始動時停止信号ON」(エラーコード: 1908H)となり，軸の動作状態が"ERR"状態になります。このためエラーリセットを行っても，再始動できなくなります｡
> - 再始動は，位置決め始動信号がONのままでも実行できます。ただし停止中に，位置決め始動信号がOFF → ONしないようにしてください。位置決め始動信号がOFF → ONすると，"[Cd.3]位置決め始動番号"に設定されている位置決めデータNo.／指定のポイントの位置決めデータNo.から位置決めを行います。
> - 連続運転中断要求により位置決め終了した場合は，再始動できません。再始動要求を行った場合は，ワーニング「再始動不可」(ワーニングコード: 0902H)になります。
>
> 【図】[非常停止入力時の動作] / [再始動を行ったときの動作](12.3 / 印刷 p.520 / 原本 p.522)
> - [非常停止入力時の動作]: 非常停止入力の位置が「(最終指令位置)」。その後「サーボOFF中の移動」により「サーボOFFでの停止位置」まで機械がずれる。
