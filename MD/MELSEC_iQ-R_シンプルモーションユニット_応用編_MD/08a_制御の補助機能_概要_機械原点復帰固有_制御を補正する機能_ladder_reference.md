## 8 制御の補助機能 (8 / 印刷 p.219 / 原本 p.221)

本章では，主機能に機能を付加したり，組み合わせて使用する「補助機能」の詳細や使い方について説明しています。
補助機能には，機械原点復帰固有の補助機能や，制御の補正など全般的に関わる機能など，さまざまな機能があります。これらの補助機能を使うことで，より適正な，きめ細かい制御を行うことができます。
各補助機能は，パラメータの設定やプログラムの作成などによって，主機能と共に使用します。各補助機能の設定や実行手順をよくお読みになり，必要な設定を行ってください。

### 8.1 補助機能の概要 (8.1 / 印刷 p.219 / 原本 p.221)

「補助機能」は，主機能を実行する際，制御の補正，制限，機能の付加などを行う機能です。これらの補助機能は，パラメータの設定や，エンジニアリングツールからの操作，補助機能用のプログラムなどによって実行します。

### 8.2 機械原点復帰固有の補助機能 (8.2 / 印刷 p.221 / 原本 p.223)

機械原点復帰固有の補助機能には「原点復帰リトライ機能」，「原点シフト機能」があります。各機能は，パラメータの設定によって実行されます。

#### 原点復帰リトライ機能[RD77MS] (8.2 / 印刷 p.221 / 原本 p.223)

位置決め制御中にワークが原点を越えてしまっていた場合など，ワークの位置によっては機械原点復帰を行っても原点方向にワークが動かないことがあります。このような場合，通常はJOG運転などで近点ドグの手前にワークを移動させて，再度，機械原点復帰を始動することになりますが，原点復帰リトライ機能を使うことで，ワークがどこにあっても，機械原点復帰を行うことができます。

##### 制御内容 (8.2 原点復帰リトライ機能 / 印刷 p.221 / 原本 p.223)

原点復帰リトライ機能の動作を以下に示します。

###### ■ワークが上下限リミットの範囲内にある場合の原点復帰リトライ動作 (8.2 / 印刷 p.221 / 原本 p.223)

【図】ワークが上下限リミットの範囲内にある場合の原点復帰リトライ動作の速度波形(8.2 / 印刷 p.221 / 原本 p.223)
- 横軸の上側が"[Pr.44]原点復帰方向"への移動、下側が逆方向への移動を示す速度波形。図中の番号1.〜6.は下記手順に対応
- 1.(図右寄り): 機械原点復帰始動で原点復帰方向へ加速し定速移動
- 2.: ハードウェアリミットスイッチの「リミット信号OFF状態」の領域に入った点(リミット信号OFF検出)から減速
- 3.: 速度0で停止後、逆方向へ加速し、逆方向の定速で長く移動(近点ドグを通過して戻る)
- 4.: 近点ドグ(ON区間)を逆方向に抜けた点(近点ドグOFF)から減速
- 5.(図左端): 停止後、再び原点復帰方向へ加速し、近点ドグONで減速→クリープ速度→零点信号で一旦速度が落ち込む波形を経て
- 6.: 零点信号のタイミングで停止(機械原点復帰完了)
- 下段に近点ドグ(ON区間)、ハードウェアリミットスイッチ(リミット信号OFF状態)、零点信号(パルス2つ)のタイミングを表示

1. 機械原点復帰始動により"[Pr.44]原点復帰方向"へ移動を開始する。
2. リミット信号OFF検出により減速する。
3. リミット信号OFF検出で停止後，"[Pr.46]原点復帰速度"で"[Pr.44]原点復帰方向"と逆方向に移動する。
4. 近点ドグOFFで減速する。
5. 近点ドグOFFで停止後，"[Pr.44]原点復帰方向"へ機械原点復帰を行う。(原点復帰方式によってはエンコーダの零点を最低1回は通過する必要があります。)
6. 機械原点復帰完了。

###### ■ワークが上下限リミットの範囲外にある場合の原点復帰リトライ動作 (8.2 / 印刷 p.222 / 原本 p.224)

- 「ワーク → 原点」の方向が"[Pr.44]原点復帰方向"と同一方向の場合は，通常の機械原点復帰の動作を行います。"[Pr.44]原点復帰方向"を「0: 正方向」とした場合の例です。

【図】「ワーク→原点」の方向が原点復帰方向と同一の場合(8.2 / 印刷 p.222 / 原本 p.224)
- 機械原点復帰始動位置はハードウェア下限リミットスイッチ付近(移動範囲の下限端の外側寄り)。[Pr.44]原点復帰方向は右(正方向)
- 始動後、正方向へ加速・定速移動し、近点ドグONで減速→クリープ速度→零点信号で原点に停止する通常の近点ドグ式と同じ波形
- 下段にハードウェア下限リミットスイッチ、近点ドグ、ハードウェア上限リミットスイッチ、零点信号、移動範囲(下限リミットスイッチ〜上限リミットスイッチ間)を表示

【図】「ワーク→原点」の方向が原点復帰方向と逆の場合(8.2 / 印刷 p.222 / 原本 p.224)

#### 電子ギア機能 (8.3 / 印刷 p.230 / 原本 p.232)

##### 電子ギアの基本的な考え方 (8.3 電子ギア機能 / 印刷 p.230 / 原本 p.232)

電子ギアとは，プログラムで指令した移動量どおりに機械が動くようにするために，モータを何回転(何パルス分回転)させればよいのか決定する項目です。

【図】電子ギアの構成(8.3 / 印刷 p.230 / 原本 p.232)
- シンプルモーションユニット内: 指令値 →(制御単位)→ AP / (AL × AM) →(pulse)→ サーボアンプ
- サーボアンプ →(pulse)→ モータ(M) → 減速機 → 機械(ボールネジ)
- モータのエンコーダ(ENC) →(pulse: フィードバックパルス)→ サーボアンプ。シンプルモーションユニットへは pulse で戻り、制御単位に換算される

電子ギアの考え方の基本は，次式で表されます。
[Pr.2](モータ1回転あたりのパルス数) ＝ AP
[Pr.3](モータ1回転あたりの移動量) ＝ AL
[Pr.4](単位倍率) ＝ AM
単位倍率を考慮したモータ1回転あたりの機械の移動量 ＝ ΔSと置く。

```
電子ギア ＝ AP / ⊿S ＝ AP / (AL × AM)   ・・・(1)
```

となり，この関係式が成立するような，AP，AL，AMの値を設定します。
しかし，AP，AL，AMに設定できる数値には設定可能な範囲がありますので，上記の関係式から計算(約分)した値をAP，AL，AMの設定範囲に入るようにする必要があります。

###### ■ボールネジ + 減速機の場合 (8.3 電子ギア機能 / 印刷 p.231-232 / 原本 p.233-234)

例
ボールネジピッチ10 mm，モータHG-KR(4194304 pulse/rev)，減速比9/44の場合

【図】モータ(M) → 減速機(減速比 9/44) → ボールネジ → 機械(8.3 / 印刷 p.231 / 原本 p.233)

まず，モータが1回転(AP)したときに，負荷(機械)が何 mm移動するか(ΔS)を求めます。

```
AP(モータ1回転あたりのパルス数)        ＝ 4194304 [pulse]
⊿S(モータ1回転あたりの機械の移動量)  ＝ ボールネジピッチ × 減速比
                                     ＝ 10 [mm] × 9/44
                                     ＝ 10000.0 [μm] × 9/44   ← 制御単位がmmの場合 最小指令単位は0.1 μm となります。
```

> **Point**
> モータHK-KT(67108864 pulse/rev)を使用する場合，MR-J5(W)-Bのサーボパラメータを以下のように設定します。
> 電子ギア分子(PA06): 16
> 電子ギア分母(PA07): 1
> したがって，AP(モータ1回転あたりのパルス数)は下記の値となります。
> AP(モータ1回転あたりのパルス数)
> = 67108864 [pulse] × 1/16
> = 4194304 [pulse]
>
> 【図】HK-KT使用時の構成(8.3 / 印刷 p.231 / 原本 p.233)
> - シンプルモーションユニット: 指令値 →(制御単位)→ AP / (AL × AM) →(pulse)→ サーボアンプ(電子ギア分子(PA06): 16、電子ギア分子(PA07): 1 と図中に表記)
> - サーボアンプ →(pulse×16)→ モータ(M) → 減速比 9/44 → 機械
> - ENC →(pulse: フィードバックパルス)→ サーボアンプ →(制御単位 / pulse/16)→ シンプルモーションユニット

これを，前記の式(1)に代入します。
このとき，減速比の9/44は分数のままで計算を行います。

```
AP / ⊿S ＝ 4194304 [pulse] / (10000.0 [μm] × 9/44)
        ＝ (4194304 × 44) / (10000.0 × 9)
        ＝ 184549376 / 90000.0
        ＝ 23068672 / 11250.0 ＝ 23068672(AP) / (11250.0(AL) × 1(AM))
        ＝ 23068672(AP) / (1125.0(AL) × 10(AM))
```

よって設定するAP，AL，AMは以下となります。この2例の設定値はほんの一例です。これ以外にも設定値はあります。

| 設定値 | 設定項目 |
|---|---|
| AP ＝ 23068672 | [Pr.2] |
| AL ＝ 11250.0 | [Pr.3] |
| AM ＝ 1 | [Pr.4] |

あるいは

| 設定値 | 設定項目 |
|---|---|
| AP ＝ 23068672 | [Pr.2] |
| AL ＝ 1125.0 | [Pr.3] |
| AM ＝ 10 | [Pr.4] |

##### 誤差補正方法 (8.3 電子ギア機能 / 印刷 p.236 / 原本 p.238)

パラメータに設定した「電子ギア」によって位置制御を行った場合，指令移動量(L)と実際の移動量(L')に誤差が生ずる場合があります。シンプルモーションユニットでは，この誤差を電子ギアで調節して補正します。
誤差補正を行うために使用する「誤差補正量」を以下のように定義します。

```
誤差補正量 ＝ 指令移動量(L) / 実際の移動量(L')
```

誤差補正量を盛り込んだ電子ギアは以下のようになります。

```
AP / (AL × AM) × L / L' ＝ AP' / (AL' × AM')
```

【図】誤差補正量を盛り込んだ電子ギアの構成(8.3 / 印刷 p.236 / 原本 p.238)
- 補正前: シンプルモーションユニット内で 指令値 →(制御単位)→ AP / (AL × AM) → L / L' →(pulse)→ サーボアンプ。L / L' は「誤差が生じない場合は1(通常)」
- 「誤差分を見込んだ電子ギア」として、補正後は 指令値 →(制御単位)→ AP' / (AL' × AM') →(pulse)→ サーボアンプ の1段にまとめる

###### ■計算例 (8.3 電子ギア機能 / 印刷 p.236 / 原本 p.238)

[条件]
1回転あたりのパルス数(AP): 4194304 [pulse]
1回転あたりの移動量(AL) : 5000.0 [μm]
単位倍率(AM) : 1

[位置決め結果]
指令移動量(L) : 100 [mm]
実移動量(L') : 101 [mm]

[補正値]

```
AP / (AL × AM) × L / L' ＝ 4194304 / (5000.0 × 1) × 100 / 101 ＝ 4194304(AP') / (5050(AL') × 1(AM'))
```

1回転あたりのパルス数(AP'): 4194304 ・・・[Pr.2]
1回転あたりの移動量(AL') : 5050.0 ・・・・[Pr.3]
単位倍率(AM') : 1 ・・・・・・[Pr.4]

補正後の"[Pr.2]1回転あたりのパルス数(AP')"，"[Pr.3]1回転あたりの移動量(AL')"，"[Pr.4]単位倍率(AM')"をパラメータに設定し，シンプルモーションユニットに書き込みます。設定した内容は，シーケンサレディ信号[Y0]の立ち上がり(OFF → ON)時に有効になります。

#### 近傍通過機能 (8.3 / 印刷 p.237 / 原本 p.239)

補間制御を使った連続軌跡制御を行う場合は，近傍通過機能の動作を行います。
「近傍通過機能」は，補間制御による連続軌跡制御を行う場合，位置決めデータの切り換わり時に発生する機械振動を抑える機能です。
[近傍通過]
連続して実行されている各位置決めデータの最後に生じる移動量の余りを次の位置決めデータに受け渡します。位置合わせを行わないことにより，出力速度の低下をなくし，速度変更時に発生する機械振動を抑えることができます。
位置合わせを行わないため，"[Da.6]位置決めアドレス／移動量"に設定した位置の近傍を通過するような軌跡で制御されます。

##### 制御内容 (8.3 近傍通過機能 / 印刷 p.237 / 原本 p.239)

2軸直線補間制御で連続軌跡制御を行った場合の軌跡を以下に示します。

###### ■近傍通過の軌跡 (8.3 / 印刷 p.237 / 原本 p.239)

【図】近傍通過の軌跡と速度波形(8.3 / 印刷 p.237 / 原本 p.239)
- 位置決めデータNo.3の軌跡(左下から右上への直線)が[Da.6]位置決めアドレスの手前で、位置決めデータNo.4の軌跡へ移る。[Da.6]位置決めアドレスの点そのもの(破線の経路)は通らず、その近傍(図中の丸印)を通過する
- 速度波形(V-t): 位置決めデータNo.3 の区間で加速→定速、No.3→No.4 の切換点でも定速のまま「速度の落込みは発生しない」、No.4 の終わりで減速停止

##### 制御上の注意事項 (8.3 近傍通過機能 / 印刷 p.238 / 原本 p.240)

- 連続軌跡制御を行っているとき，位置決めデータで指定した移動量が小さい場合に，出力速度が指令速度に達しないことがあります。
- 補間運転時は移動方向のチェックを行っていないため，移動方向が変わっても減速停止しません。(下図参照)このため，移動方向が変わると急反転することがあります。急反転を回避する場合は，通過点の位置決めデータを連続軌跡制御「11」にしないで，連続位置決め制御「01」にしてください。
