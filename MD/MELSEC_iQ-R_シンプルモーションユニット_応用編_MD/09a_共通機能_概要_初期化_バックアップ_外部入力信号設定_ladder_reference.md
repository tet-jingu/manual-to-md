## 9 共通機能

(9章 / 印刷 p.317 / 原本 p.319)

本章では，必要に応じて実行するシンプルモーションユニットの「共通機能」の詳細や使い方について説明しています。
共通機能には，パラメータの初期化，実行データのバックアップなどシンプルモーションユニットを使用する上で必要となる機能があります。
本章により各共通機能の設定や実行手順を確認し，必要に応じて共通機能を使用してください。

### 9.1 共通機能の概要

(9.1 / 印刷 p.317 / 原本 p.319)

##### 制御上の注意事項

(9.2 / 印刷 p.319 / 原本 p.321)

- パラメータの初期化は，位置決め制御を行っていないとき(シーケンサレディ信号[Y0]がOFF時)に実行してください。シーケンサレディ信号[Y0]がONのときに実行すると，ワーニング「シーケンサレディ中」(ワーニングコード: 0905H)となります。
- フラッシュ ROMの書込み回数は10万回です。10万回を超えると，フラッシュ ROMへの書込みができなくなり，エラー「フラッシュ ROMライトエラー」(エラーコード: 1931H)になります。
- パラメータの初期化を行ったあとは，「CPUユニットのリセット」または「CPUユニットの電源再立上げ」を行う必要があります。
- シーケンサレディ信号[Y0]をONしたとき，シンプルモーションユニットに設定したパラメータに異常があると，準備完了信号[X0]がONせず，制御を行うことができません。
- 初期化したパラメータを使用する場合は，ユニット拡張パラメータ格納先設定を「シンプルモーションユニット」に設定したユニットパラメータを，CPUユニットに書き込んでください。ユニット拡張パラメータ格納先設定が「CPUユニット」のユニットパラメータをCPUユニットへ書き込んでいる場合は，エンジニアリングツールにて設定したユニット拡張パラメータがバッファメモリへ反映されますので，エンジニアリングツールを使用してパラメータの初期化を行ってください。[RD77GF]

> **制約事項**
> フラッシュ ROMの書込み時間と，パラメータの初期化処理時間は下記となります。
> - フラッシュ ROM書込み時間: 最大5秒[RD77MS]，最大4秒[RD77GF]
> - パラメータの初期化処理時間: 約5秒*1[RD77MS]，最大30秒[RD77GF]
>
> パラメータの初期化中は，電源のON/OFF，CPUユニットのリセットを行わないでください。
> フラッシュ ROM／保存用内部メモリへの書込み中に，電源OFFもしくはCPUユニットのリセットを行い強制的に処理を中断すると，フラッシュ ROM／保存用内部メモリにバックアップされているデータが消失します。

*1 位置決め制御以外の空き時間が短い場合，30秒ほどかかる場合もあります。

### 9.3 実行データのバックアップ機能

(9.3 / 印刷 p.320 / 原本 p.322)

(9.3 / 印刷 p.321 / 原本 p.323)

- フラッシュ ROMへの書込みは，位置決め制御を行っていないとき(シーケンサレディ信号[Y0]がOFF時)に実行してください。シーケンサレディ信号[Y0]がONのときに実行すると，ワーニング「シーケンサレディ中」(ワーニングコード: 0905H)となります。
- フラッシュ ROMの書込み回数は，10万回です。書込み回数が10万回を超えると，フラッシュ ROMへの書込みができなくなることがあり，その場合はエラー「フラッシュ ROMライトエラー」(エラーコード: 1931H)になります。

- バックアップしたパラメータを使用する場合は，ユニット拡張パラメータ格納先設定を「シンプルモーションユニット」に設定したユニットパラメータを，CPUユニットに書き込んでください。[RD77GF]

> **制約事項**
> フラッシュ ROMの書込み時間は下記となります。
> - フラッシュ ROM書込み時間: 最大5秒[RD77MS]，最大4秒[RD77GF]
>
> フラッシュ ROM書込み実行中は，電源のON/OFF，CPUユニットのリセットを行わないでください。
> フラッシュ ROM／保存用内部メモリへの書込み中に，電源OFFもしくはCPUユニットのリセットを行い強制的に処理を中断すると，フラッシュ ROM／保存用内部メモリにバックアップされているデータが消失します。

#### 外部入力信号に対する入力論理の設定方法

(9.4 / 印刷 p.324 / 原本 p.326)

シンプルモーションユニットに接続された外部機器またはサーボアンプの外部入力信号(上／下限リミット信号(FLS/RLS)，近点ドグ(DOG)，停止信号(STOP)，および外部指令信号／切換え信号(DI))に合わせて信号の論理を切換えできます。
この機能によって，入力信号でb接点扱いの上／下限リミット信号を使用しないシステムでは，パラメータの論理設定を"正論理"に変更することにより配線をしなくても制御可能になります。
上／下限リミット信号を使用する場合は，必ず負論理(b接点)で使用してください。
論理選択のインタフェースは，外部信号の入力種別と信号種別により，設定箇所を分別します。
外部入力信号(上／下限リミット信号，近点ドグ信号，停止信号)の論理設定方法は以下のとおりです。

| "[Pr.116]FLS信号選択"～"[Pr.119]STOP信号選択"の入力種別 | 信号種別 | 設定箇所 |

| 0: シンプルモーションユニット[RD77MS] | FLS/RLS/DOG/STOP | [Pr.150]入力端子論理選択 |
| 0: シンプルモーションユニット[RD77MS] | 手動パルサ | [Pr.151]手動パルサ／INC同期エンコーダ入力論理選択 |
| 1: サーボアンプ | FLS/RLS/DOG | [Pr.22]入力信号論理選択 |
| 2: バッファメモリ | FLS/RLS/DOG/STOP | [Pr.22]入力信号論理選択 |
| 3: リンクデバイス[RD77GF] | FLS | [Pr.913]リンクデバイス論理設定 |
| 3: リンクデバイス[RD77GF] | RLS | [Pr.923]リンクデバイス論理設定 |
