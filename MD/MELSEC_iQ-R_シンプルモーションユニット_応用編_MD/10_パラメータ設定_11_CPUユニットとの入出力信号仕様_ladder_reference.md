## 10 パラメータ設定 (10 / 印刷 p.419 / 原本 p.421)

シンプルモーションユニットのパラメータ設定について説明します。パラメータを設定することにより，プログラムによるパラメータ設定が不要になります。
パラメータ設定は，ユニットパラメータ，シンプルモーションユニット設定(ユニット拡張パラメータ[RD77GF])の2種類があります。

### 10.1 パラメータ設定手順 (10.1 / 印刷 p.419 / 原本 p.421)

1. エンジニアリングツールにシンプルモーションユニットを追加します。
   - 操作: ナビゲーションウィンドウ⇨"パラメータ"⇨"ユニット情報"⇨右クリック⇨[新規ユニット追加]
2. パラメータ設定は，ユニットパラメータ，シンプルモーションユニット設定の2種類があり，下記画面のツリーから選択して設定します。
   - 操作: ナビゲーションウィンドウ⇨"パラメータ"⇨"ユニット情報"⇨対象ユニット
3. エンジニアリングツールにて，CPUユニットに設定を書き込みます。
   - 操作: [オンライン]⇨[シーケンサへの書込み]
4. CPUユニットのリセット，または電源のOFF→ONにより設定が反映されます。

### 10.2 ユニットパラメータ (10.2 / 印刷 p.419 / 原本 p.421)

ユニットパラメータを設定します。ユニットパラメータには以下の設定があります。

[RD77MS]
- リフレッシュ設定

[RD77GF]

ユニットパラメータ(モーション)
- ユニット動作設定(ユニット拡張パラメータ格納先設定)
- リフレッシュ設定

ユニットパラメータ(ネットワーク)*1
- 必須設定
- 基本設定
- 応用設定

*1 詳細は下記マニュアルの"パラメータ設定"を参照してください。
MELSEC iQ-R シンプルモーションユニットユーザーズマニュアル(ネットワーク編)

ユニットパラメータは下記画面のツリーから選択します。
- 操作: ナビゲーションウィンドウ⇨"パラメータ"⇨"ユニット情報"⇨対象ユニット⇨"ユニットパラメータ"

#### リフレッシュ設定 (10.2 / 印刷 p.420 / 原本 p.422)

##### リフレッシュ設定[RD77MS] (10.2 / 印刷 p.420 / 原本 p.422)

シンプルモーションユニットのバッファメモリの内容を，CPUユニットのデバイスやユニットラベルへ転送する場合と，CPUユニットのデバイスやユニットラベルの内容を，シンプルモーションユニットのバッファメモリへ転送する場合に設定します。このリフレッシュ設定により，プログラムによる読出しまたは書込みが不要になります。
転送先は，"リフレッシュ先"にて下記から選択します。

###### ■ユニットラベル (10.2 / 印刷 p.420 / 原本 p.422)

各バッファメモリの対応するユニットラベルへ，バッファメモリの内容を転送します。またバッファメモリへ，各バッファメモリの対応するユニットラベルの内容を転送します。軸1の"位置決め始動番号"を"有効"に設定することにより，すべての軸の項目が自動で"有効"に設定されます。

###### ■リフレッシュデータレジスタ(RD) (10.2 / 印刷 p.420 / 原本 p.422)

CPUユニットのリフレッシュデータレジスタ(RD)へ，バッファメモリの内容を転送します。またバッファメモリへ，CPUユニットのリフレッシュデータレジスタ(RD)の内容を転送します。"先頭デバイス名"に先頭デバイスを設定することにより，すべての項目の転送先が自動で設定されます。

###### ■指定デバイス (10.2 / 印刷 p.420 / 原本 p.422)

CPUユニットの指定したデバイスへ，バッファメモリの内容を転送します。またバッファメモリへ，CPUユニットの指定したデバイスの内容を転送します。指定できるデバイスは，X，Y，M，L，B，D，W，R，ZR，RDです。ビットデバイスのX，Y，M，L，Bを使用する場合，16点で割り切れる番号(例: X10，Y120，M16など)を設定してください。また，設定されたデバイスNo.から16点分に，バッファメモリのデータが格納，およびバッファメモリに，設定されたデバイスNo.から16点分のデータが格納されます。

> **例**
> CPUユニットの指定したデバイスへ，バッファメモリの内容を転送する項目にX10を設定すると，X10~X1Fにデータが格納されます。

> **注意事項**
> - リフレッシュデータレジスタ(RD)を使用する場合
>   リフレッシュ設定の"リフレッシュ先"をリフレッシュデータレジスタ(RD)に設定したGX Works3プロジェクトにおいて，GX Works3のバージョンを"1.115V"より前のバージョンから"1.115V"以降のバージョンへバージョンアップを実施した後，GX Works3のリフレッシュ設定画面を表示すると"先頭デバイス名"が空白表示となりますが，"1.115V"より前のバージョンで設定したリフレッシュ設定はそのまま引き継がれますので設定上問題ありません。(エラーとはなりません。)
>   なお，リフレッシュ設定を変更する場合は，リフレッシュデータレジスタ(RD)を使用したユーザプログラム，パラメータを見直してください。設定変更によりリフレッシュ項目にデバイス番号が自動設定されますが，設定変更する前後でデバイス番号が同じにならない場合があります。

##### リフレッシュ設定[RD77GF] (10.2 / 印刷 p.421 / 原本 p.423)

シンプルモーションユニットのバッファメモリの内容を，CPUユニットのデバイスやユニットラベルへ転送する場合に設定します。このリフレッシュ設定により，プログラムによる読出しが不要になります。
転送先は，"リフレッシュ先"にて下記から選択します。

###### ■ユニットラベル (10.2 / 印刷 p.421 / 原本 p.423)

各バッファメモリの対応するユニットラベルへ，バッファメモリの内容を転送します。軸1の"送り現在値"を"有効"に設定することにより，すべての軸の項目が自動で"有効"に設定されます。

###### ■リフレッシュデータレジスタ(RD) (10.2 / 印刷 p.421 / 原本 p.423)

CPUユニットのリフレッシュデータレジスタ(RD)へ，バッファメモリの内容を転送します。"先頭デバイス名"に先頭デバイスを設定することにより，すべての項目の転送先が自動で設定されます。

###### ■指定デバイス (10.2 / 印刷 p.421 / 原本 p.423)

CPUユニットの指定したデバイスへ，バッファメモリの内容を転送します。指定できるデバイスは，X，Y，M，L，B，D，W，R，ZR，RDです。ビットデバイスのX，Y，M，L，Bを使用する場合，16点で割り切れる番号(例: X10，Y120，M16など)を設定してください。また，設定されたデバイスNo.から16点分に，バッファメモリのデータが格納されます。

> **例**
> X10を設定すると，X10~X1Fにデータが格納されます。

#### リフレッシュ処理時間 (10.2 / 印刷 p.424 / 原本 p.426)

リフレッシュ処理時間[μs]はCPUユニットのスキャンタイムを構成する要素です。スキャンタイムについては下記を参照してください。
MELSEC iQ-R CPUユニットユーザーズマニュアル(応用編)
リフレッシュ設定時にかかる，リフレッシュ処理時間[μs]を示します。

[RD77MS]
- リフレッシュ処理時間[μs] = 読出しリフレッシュ (CPUへ転送するリフレッシュ )時間 + 書込みリフレッシュ時間(インテリジェント機能ユニットへ転送するリフレッシュ )

"リフレッシュ先"の設定により，読出しリフレッシュ時間と書込みリフレッシュ時間が異なります。

[RD77GF]
- リフレッシュ処理時間[μs] = 読出しリフレッシュ (CPUへ転送するリフレッシュ )時間

"リフレッシュ先"の設定により，読出しリフレッシュ時間が異なります。

## 転記時の要確認一覧

- (印刷 p.426 / 原本 p.428) ユニット拡張パラメータ格納先設定の表「CPUユニット」の内容が「CPUユニットまたSDメモリカードに格納されます。」となっている。「または」の脱字の疑いがあるが原文どおり転記した。
- (印刷 p.425 / 原本 p.427) 読出し/書込みリフレッシュ時間の算出例で、式中の係数 0.98 / 11.6 / 0.58 / 9.10 は本書の表(0.05 μs・0.01 μs のみ記載)に出てこない。CPUユニットユーザーズマニュアル(応用編)の計算式由来と思われるが、本書内では説明なし。原文どおり転記した。
- (印刷 p.425 / 原本 p.427) 書込みリフレッシュ時間の算出例の末尾「よって書込みリフレッシュ時間は316.10 μsになります」に句点が無い(原文どおり)。
- (印刷 p.428-429 / 原本 p.430-431) X 側一覧の BUSY に付いた *1 の脚注は X 表の直下に無く、Y 表の下(印刷 p.430)の「*1 制御軸数を超える軸番号のBUSY信号，位置決め始動信号は使用不可です。」が両表共通の脚注と思われる。印刷 p.428 の「*1 制御軸数を超える軸番号の入出力信号は使用不可です。」は本文「使用しています*1」に対する脚注。
- (印刷 p.421 / 原本 p.423) リフレッシュ設定[RD77GF]の節の直後にある「設定項目」の画面例のウィンドウタイトルは「0000:RD77MS16 ユニットパラメータ」(RD77MS の画面)。原文どおり記載した。
- (印刷 p.422 / 原本 p.424) 設定項目表の「インテリジェント機能ユニットへ転送」グループは [RD77MS] のみ。RD77GF のリフレッシュ設定は CPU への転送のみ(10.2 本文と一致)。
