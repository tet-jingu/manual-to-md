## 付録 (付録 / 印刷 p.752-769 / 原本 p.754-771)

### 付3 SSCNETIII(/H)対応機器[RD77MS] (付3 / 印刷 p.752-769 / 原本 p.754-771)

#### 汎用インバータFR-A700シリーズ (付3 / 印刷 p.752 / 原本 p.754)

内蔵オプションFR-A7APおよびFR-A7NSを使用することで，汎用インバータFR-A700シリーズをSSCNETⅢ経由で接続することができます。

##### 接続方法 (付3 FR-A700 / 印刷 p.752 / 原本 p.754)

###### ■システム構成 (付3 FR-A700 / 印刷 p.752 / 原本 p.754)

FR-A700シリーズを使用したシステム構成を以下に示します。
FR-A700シリーズを使用する場合，"[Pr.97]SSCNET設定"を「0: SSCNETⅢ」に設定してください。

【図】FR-A700シリーズを使用したシステム構成(付3 / 印刷 p.752 / 原本 p.754)
- シンプルモーションユニット(ベースユニット上)から SSCNETⅢケーブル MR-J3BUS_M(-A/-B) で SSCNETⅢ に接続
- SSCNETⅢ 上に 汎用インバータ FR-A700シリーズ(図では2台)と サーボアンプ MR-J3(W)-B(図では1台)がデイジーチェーンで接続され、それぞれにモータが接続されている
- 接続軸数: RD77MS2: 最大2軸 / RD77MS4: 最大4軸 / RD77MS8: 最大8軸 / RD77MS16: 最大16軸

###### ■パラメータ設定 (付3 FR-A700 / 印刷 p.752 / 原本 p.754)

FR-A700シリーズを接続する場合，以下のパラメータをバッファメモリに設定後，フラッシュ ROM書込みを行ってください。電源ONまたはCPUユニットリセット時に，設定値が有効となります。

- "[Pr.97]SSCNET設定": 「0: SSCNETⅢ」
- "[Pr.100]接続機器": 「00004100H: FR-A700(汎用インバータ)」，「00004101H: FR-A700-NA(汎用インバータ)」，「00004102H: FR-A700-EC(汎用インバータ)」，「00004103H: FR-A700-CHT(汎用インバータ)」

###### ■FR-A700シリーズのパラメータ管理 (付3 FR-A700 / 印刷 p.752 / 原本 p.754)

FR-A700シリーズに設定するパラメータはシンプルモーションユニットで管理しません。インバータ正面の操作パネル(FR-DU07/FR-PU07)，またはインバータセットアップソフトウェアFR Configuratorを直接FR-A700シリーズに接続して設定します。FR-A700シリーズの設定項目の詳細は，FR-A700シリーズの取扱説明書を確認してください。

> **Point**
> FR-A700シリーズとシンプルモーションユニットを接続した状態において，インバータ側のパラメータ"[Pr.77]パラメータ書込選択"が初期状態では一部のパラメータしか設定できません。FR-A700シリーズのパラメータを書き換える場合は，「2: 運転中もパラメータを書き込む」を設定してください。

###### ■リセット選択／PU抜け検出／PU停止選択 (付3 FR-A700 / 印刷 p.753 / 原本 p.755)

FR-A700シリーズにてPU停止を実行した場合，シンプルモーションユニットからの指令は停止しないため位置誤差過大などが発生します。インバータ側のパラメータ"[Pr.75]リセット選択／PU抜け検出／PU停止選択"を「0～3」に設定してください。FR-A700シリーズを停止する場合は，シンプルモーションユニットの停止指令および緊急停止を使用するか，FR-A700シリーズの出力停止(MRS)を使用してください。

##### 制御上の注意事項 (付3 FR-A700 / 印刷 p.756 / 原本 p.758)

###### ■絶対位置システム(ABS)／インクリメンタルシステム(INC) (付3 FR-A700 / 印刷 p.756 / 原本 p.758)

FR-A700シリーズを使用した場合，絶対位置システム(ABS)は使用できません。サーボパラメータ「絶対位置検出システム(PA03)」に「1: 絶対位置検出システムで使用する」を設定した場合も，インクリメンタルシステムとして動作します。

- シンプルモーションユニット電源投入時，原点復帰要求がONとなり送り現在値は0となります。(インバータのみ電源OFF → ONした場合も送り現在値は0となります。)
- 絶対位置システム時のワーニング「原点データ不正」(ワーニングコード: 093CH)，「SSCNET通信異常」(ワーニングコード: 093EH)は検出しません。

###### ■制御モード (付3 FR-A700 / 印刷 p.756 / 原本 p.758)

使用可能な制御モードを以下に示します。

- 位置制御モード(位置制御，位置ループを含む速度制御)
- 速度制御モード(位置ループを含まない速度制御)
- トルク制御モード(トルク制御)

ただし，拡張制御「速度・トルク制御」の押当て制御モードへの切換えはできません。押当て制御モードへの切換えを行うとエラー「押当て制御未対応」(エラーコード: 19E7H)となり現在の制御を停止します。
また，"[Pr.90]速度・トルク制御モード動作設定"の「トルク初期値選択(b4～b7)」で，「1: フィードバックトルク」は設定できません。設定した場合，制御モード切換え時にワーニング「トルク初期値選択不可」(ワーニングコード: 09E5H)となり，切換え直後の指令値は「0: 指令トルク」を選択した場合と同じになります。

###### ■ドライバ間通信 (付3 FR-A700 / 印刷 p.756 / 原本 p.758)

ドライバ間通信には対応していません。サーボパラメータにドライバ間通信を設定した場合，電源投入時にエラー「ドライバ間通信設定エラー」(エラーコード: 1C93H)が発生します。

###### ■モニタデータ (付3 FR-A700 / 印刷 p.756 / 原本 p.758)

"[Md.107]パラメータエラー番号"には，常に「0」が格納されます。また，「絶対位置消失中」([Md.108]サーボステータス1: b14)は常時OFFします。

###### ■速度・トルク制御の制御モード切換え (付3 FR-A700 / 印刷 p.756 / 原本 p.758)

FR-A700シリーズを接続した軸は，制御モードの切換え時間がサーボアンプ接続軸より長くなります。

| 切換え操作 | サーボアンプ接続時の切換え時間 | FR-A700シリーズ接続時の切換え時間 |
|---|---|---|
| 位置制御モード → 速度制御モード | 6～11 ms | 19～24 ms |
| 速度制御モード → 位置制御モード | 6～11 ms | 19～24 ms |
| 位置制御モード → トルク制御モード | 6～11 ms | 19～24 ms |
| トルク制御モード → 位置制御モード | 6～11 ms | 19～24 ms |
| 速度制御モード → トルク制御モード | 6～11 ms | 19～24 ms |
| トルク制御モード → 速度制御モード | 6～11 ms | 19～24 ms |

##### FR-A700シリーズが検出したエラー／ワーニング (付3 FR-A700 / 印刷 p.756 / 原本 p.758)

FR-A700シリーズでエラーが検出された場合，"[Md.23]軸エラー番号"にエラーコード(1C80H)が格納されます。また，"[Md.114]サーボアラーム"には，FR-A700シリーズのアラーム番号が格納されます。ただし，"[Md.107]パラメータエラー番号"には，常に「0」が格納されます。
FR-A700シリーズでワーニングが検出された場合，"[Md.24]軸ワーニング番号"にワーニングコード(0C80H)が格納されます。また，"[Md.114]サーボアラーム"には，FR-A700シリーズのワーニング番号が格納されます。
エラー，ワーニングの詳細については，FR-A700シリーズの取扱説明書を確認してください。

###### ■インポジション範囲 (付3 FR-A800 / 印刷 p.757 / 原本 p.759)

サーボパラメータ「インポジション範囲(PA10)」はインバータ側のパラメータ"[Pr.426]位置決め完了幅"で設定します。アドバンスト同期制御でカム軸の位置を復元する場合，サーボパラメータ「インポジション範囲(PA10)」によるチェックが行われますが，FR-A800シリーズではサーボパラメータの設定を行わないため「インポジション範囲」を100[pulse](固定値)としてチェックします。

- トルク制御モード(トルク制御)

#### パルス変換ユニット (付3 / 印刷 p.762 / 原本 p.764)

SSCNETⅢ対応パルス変換ユニットは，SSCNETⅢの指令をパルス出力に変換するためのユニットです。
SSCNETⅢ対応パルス変換ユニットは，インタフェースユニット(MR-MT1010)とパルス出力ユニット(MR-MT1200)の組み合わせで構成されています。
パルス変換ユニットを接続することにより，パルス指令インタフェース対応のステッピングモータドライバなどを位置制御することができます。
パルス変換ユニットを使用した場合，運転機能や動作がサーボアンプを使用した場合と異なります。
本節では，サーボアンプを使用した場合と異なる部分のみを記載しています。
また，パルス変換ユニットについての詳細は，最寄りの代理店または支社にお問い合わせください。

##### [Pr.86]パルス変換ユニット原点復帰要求設定 (付3 パルス変換ユニット / 印刷 p.766 / 原本 p.768)

パルス変換ユニット使用時，サーボOFF時の原点復帰要求フラグの動作を設定します。
0: サーボOFF時に原点復帰要求ON
1: サーボOFF時に原点復帰要求ONしない

##### [Pr.87]パルス変換ユニットクリア信号出力後待機時間 (付3 パルス変換ユニット / 印刷 p.767 / 原本 p.769)

原点復帰時に，クリア信号を出力してから位置整定が完了するまでの待機時間を設定します。"[Pr.87]パルス変換ユニットクリア信号出力後待機時間"が設定範囲外の場合，シーケンサレディ信号[Y0]ON時にエラー「パルス変換ユニットクリア信号出力後待機時間範囲外エラー」(エラーコード: 1B14H)となり，準備完了信号[X0]がONしません。
近点ドグ式による原点復帰のパルス変換ユニットクリア信号出力後待機時間および動作例を，下図に示します。(カウント式1でも零点信号ONによる即停止以降の制御は同一です。)

【図】近点ドグ式原点復帰のパルス変換ユニットクリア信号出力後待機時間および動作例(付3 / 印刷 p.767 / 原本 p.769)
- 速度(V)波形: 機械原点復帰始動で加速し "[Pr.46]原点復帰速度" で移動 → 近点ドグON で減速し "[Pr.47]クリープ速度" で移動 → 近点ドグOFF 後に減速停止 → 再び零点方向へ移動し、最初の零点信号(PG)で即停止(図中「1.」の位置。速度が垂直に0へ落ちる) → 待機後、「3.」で "[Pr.53]原点シフト量" の台形移動を行い停止
- 近点ドグ: OFF → ON(原点復帰速度からの減速開始点)→ クリープ速度移動中に OFF
- 零点信号(PG): 近点ドグON中(クリープ速度移動中)にも1パルスあるが、近点ドグOFFによる停止後の最初のパルスで即停止となる
- クリア出力(CLEAR): 即停止のタイミング(1.)で OFF → ON。ON幅は *1(パルス変換ユニットのパラメータ「クリア信号出力パルス時間幅(PB12)」の設定時間)、その後 OFF
- 「2.」: クリア出力(CLEAR)ON から "[Pr.87]パルス変換ユニットクリア信号出力後待機時間" の経過まで
- 指令パルス出力: 有効 → 「1.」〜待機時間経過まで 禁止 → 待機時間経過後 有効(原点シフト移動)
- 機械原点復帰始動(位置決め始動始動信号): OFF → ON(始動)。原点復帰完了フラグON後に OFF(図中矢印)
- 原点復帰要求フラグ([Md.31]ステータス: b3): 図では始動と同時に OFF → ON で描かれ、原点シフト量の移動完了時に OFF
- 原点復帰完了フラグ([Md.31]ステータス: b4): 原点シフト量の移動完了時に OFF → ON(原点復帰要求フラグOFFからの矢印)
- [Md.26]軸動作状態: 待機中 → 原点復帰中 → (完了時)待機中
- [Md.20]送り現在値 / [Md.21]送り機械値: 有効 → 移動した値を格納 → (完了時)原点復帰アドレス

*1 パルス変換ユニットのパラメータ「クリア信号出力パルス時間幅(PB12)」の設定時間

＜処理＞
1. シンプルモーションユニットでは，零点検出開始タイミング(ここでは近点ドグ信号OFFによる停止)を検出後，パルス変換ユニットで最初の零点信号(PG)を検出すると指令パルス出力を停止します。その後，クリア出力(CLEAR)をONします。
2. クリア出力(CLEAR)ON後，パルス変換ユニットクリア信号出力後待機時間分待機します。
3. パルス変換ユニットクリア信号出力後待機時間経過後，原点シフト量が設定されていると，移動させて原点復帰処理を完了します。

> **Point**
> - フィードバックパルス入力「無効」の場合，"[Pr.86]パルス変換ユニット原点復帰要求設定"を「1: サーボOFF時に原点復帰要求ONしない」に設定すると，サーボOFF時にフォローアップが行われず，原点復帰要求もONしないため，位置ずれが発生します。この場合，"[Pr.86]パルス変換ユニット原点復帰要求設定"は必ず「0: サーボOFF時に原点復帰要求ON」の設定としてください。
> - "[Pr.87]パルス変換ユニットクリア信号出力後待機時間"に，パルス変換ユニットのパラメータ「クリア信号出力パルス幅時間(PB12)」の設定より短い時間を設定した場合には，「クリア信号出力パルス幅時間(PB12)」の設定が使用されます。
> - フィードバックパルス入力「有効」の場合，"[Pr.87]パルス変換ユニットクリア信号出力後待機時間"内に位置が整定しないと，現在位置とフィードバック位置がずれた状態で，原点復帰が完了することがあります。この場合，原点復帰動作の位置整定時間に合わせて，"[Pr.87]パルス変換ユニットクリア信号出力後待機時間"を設定してください。

###### ■サーボOFF (付3 パルス変換ユニット / 印刷 p.768 / 原本 p.770)

- パルス変換ユニットのFBパルス入力設定スイッチの設定が無効の場合，サーボOFF中にモータを回転させないでください。モータを回転すると，位置ずれが発生します。
- 原点復帰完了後，"[Pr.86]パルス変換ユニット原点復帰要求設定"が「0: サーボOFF時に原点復帰要求ON」の場合，サーボOFF状態となると，「原点復帰要求フラグ」([Md.31]ステータス: b3)がONします。サーボON後に再度，原点復帰を行ってください。

- モータ回転数は，実際の回転数ではなく，パルス出力をパルス変換ユニットのパラメータ「1回転パルス数設定Low(PA15)」，「1回転パルス数設定High(PA16)」で速度(r/min単位)に換算した値となります。

- パルス変換ユニット接続軸に対して，トルク変更機能によりトルク変更を行っても無視されます。

###### ■アンプなし運転 (付3 パルス変換ユニット / 印刷 p.769 / 原本 p.771)

パルス変換ユニット接続軸に対して，アンプなし運転は使用できません。アンプなし運転を実行した場合，接続していない状態とし，サーボレディ ONしません。

*1 パルス変換ユニット接続軸でアンプなし運転を実行する場合は，"[Pr.100]接続機器"を「00000100H: MR-J3-_B_，MR-J3W-_B(2軸一体)」または「00000FFFH: 仮想サーボアンプ(MR-J3-B)」に設定してください。

###### ■ドライバ間通信 (付3 パルス変換ユニット / 印刷 p.769 / 原本 p.771)

パルス変換ユニット接続軸に対して，マスタ／スレーブ軸の設定は行えません。
