## 8 制御の補助機能 (8章 / 印刷 p.263-284 / 原本 p.265-286 の範囲)

### 8.5 制御内容を変更する機能 (8.5 / 印刷 p.263 / 原本 p.265)

制御内容を変更する機能には「速度変更機能」，「オーバーライド機能」，「加減速時間変更機能」，「トルク変更機能」，「目標位置変更機能」があります。各機能は，パラメータの設定やプログラムの作成・書込みによって実行します。

主機能との組合せについては，下記マニュアルの"主機能と補助機能の組合せ"を参照してください。

☞ MELSEC iQ-R シンプルモーションユニットユーザーズマニュアル(スタートアップ編)

また，上記の「速度変更機能」と「オーバーライド機能」は，どちらも速度を変更する機能ですが，以下に示す違いがあります。用途に応じて使い分けてください。

「速度変更機能」
- 任意のタイミングで，実行中の制御のみ，速度変更を行う。
- 変更後の速度を直接設定する。

「オーバーライド機能」
- 実行するすべての制御について，速度を変更する。
- 変更後の速度を指令速度に対するパーセント(％)で設定する。

> **Point**
> 手動パルサ運転，速度・トルク制御では，「速度変更機能」と「オーバーライド機能」は使用できません。

#### 速度変更機能 (8.5 / 印刷 p.263 / 原本 p.265)

「速度変更機能」は，制御中の速度を，任意のタイミングで，新たに指定した速度に変更する機能です。

変更後の速度は直接バッファメモリに設定し，速度変更指令([Cd.15]速度変更要求)もしくは外部指令信号によって，速度変更を実行します。

ただし，機械原点復帰の場合は近点ドグONを検出し，クリープ速度へ減速開始後の速度変更はできません。速度変更機能が有効でクリープ速度より低速のとき，近点ドグONを検出すると，速度変更が無効となりクリープ速度へ加速します。

##### 制御内容 (8.5 速度変更機能 / 印刷 p.263 / 原本 p.265)

速度変更中の動作を以下に示します。

【図】速度変更中の動作(速度波形と[Md.40]速度変更処理中フラグ)(8.5 / 印刷 p.263 / 原本 p.265)
- 速度V1で位置決め中に「V2への速度変更」を行うと，V1→V2へ減速し，V2で定速運転する。
- V2で運転中に「V3への速度変更」を行うと，V2→V3へ減速し，V3で定速運転後に停止する。
- 破線で「V1による位置決め時の動作」(速度変更しなかった場合の波形)が併記されている。
- [Md.40]速度変更処理中フラグ: 0 → 速度変更処理中(V1→V2の加減速中)に 1 → 0 → 速度変更処理中(V2→V3)に 1 → 0。

##### 制御上の注意事項 (8.5 速度変更機能 / 印刷 p.263-264 / 原本 p.265-266)

- 連続軌跡制御中の速度変更では，次の位置決めデータに速度の指定がない(カレント速度)場合，次の位置決めデータが"[Cd.14]速度変更値"で制御されます。また，次の位置決めデータに速度の指定がある場合，次の位置決めデータの"[Da.8]指令速度"で制御されます。

【図】連続軌跡制御中の速度変更(8.5 / 印刷 p.263 / 原本 p.265)
- 位置決め制御P1をP1での指定速度で運転中に速度変更指令を入れると，[Cd.14]速度変更値まで加速する。
- 次の制御P2に切り換わったとき，[a] 速度の指定がない(カレント速度)場合は[Cd.14]速度変更値のまま運転する。
- [b] 速度の指定がある場合は，P2での指定速度(図では[Cd.14]速度変更値より低い速度)へ減速して運転する。

- 連続軌跡制御中に速度変更を行う場合，変更を行うだけの残距離が確保できないときは，速度変更は無視されます。
- 位置制御中に速度変更を行い，停止指令で停止する。その後，再始動を行ったときの速度は，"[Cd.14]速度変更値"の値になります。

【図】速度変更後の停止・再始動(8.5 / 印刷 p.264 / 原本 p.266)
- [Da.8]指令速度で運転中に速度変更指令で[Cd.14]速度変更値へ減速する。
- 停止指令で減速停止する。
- 再始動指令で再始動すると，[Da.8]指令速度ではなく[Cd.14]速度変更値まで加速して運転する。

- "[Cd.14]速度変更値"に「0」を設定して速度変更を行った場合，下記のようになります。

> - "[Cd.15]速度変更要求"をONした時，速度変更0フラグ([Md.31]ステータス: b10)がONします。(補間制御時は，基準軸側の速度変更0フラグがONします。)
> - 軸は停止しますが，"[Md.26]軸動作状態"は変化せず，BUSY信号はONのままです。(停止信号を入力すると，BUSY信号がOFFし，"[Md.26]軸動作状態"は「停止中」になります。)この場合，"[Cd.14]速度変更値"に「0」以外を設定すると，速度変更0フラグ([Md.31]ステータス: b10)がOFFし，運転を続行することができます。
> - 動作例

【図】速度変更値0による停止と運転続行の動作例(8.5 / 印刷 p.264 / 原本 p.266)
- 位置決め始動信号[Y10, Y11, Y12, Y13]: OFF→ON。BUSY信号がOFFした後にOFF。
- BUSY信号[X10, X11, X12, X13]: 位置決め始動信号のONを受けてOFF→ON。位置決め運転の終了(停止)でOFF。
- [Cd.14]速度変更値: 最初は 0。途中で 1000 に変更。
- [Cd.15]速度変更要求: 1回目のON(パルス)時は[Cd.14]=0 → 位置決め運転は減速停止し，速度変更0フラグ([Md.31]ステータス: b10)が OFF→ON。BUSY信号はONのまま。
- [Cd.14]を 1000 に変更後，[Cd.15]速度変更要求を再度ON → 速度変更0フラグがOFFし，位置決め運転が再加速して運転を続行，その後減速停止してBUSY信号がOFF。

- 以下に示す場合は，ワーニング「減速・停止速度変更」(ワーニングコード: 0990H)となり速度変更ができません。

> - 停止指令による減速中
> - 位置制御時の自動減速中

- "[Cd.14]速度変更値"に設定した値が"[Pr.8]速度制限値"を超える場合は，ワーニング「速度制限値オーバー」(ワーニングコード: 0991H)となり，速度は"[Pr.8]速度制限値"で制御されます。
- 補間制御時に速度変更を行う場合は，基準軸に必要な設定を行います。
- 連続して速度変更を行う場合は，速度変更の間隔が10 ms以上となるようにしてください。(速度変更の間隔が短いと，シンプルモーションユニットが追従できなくなり，正常に指令が行われない場合があります。)
- 複数の軸に対して同時に速度変更要求を行った場合，1軸ずつ順次速度変更処理を行います。したがって，軸間で速度変更開始のタイミングにずれが生じます。
- 機械原点復帰時に速度変更0はできません。速度変更要求は無視されます。
- 速度変更機能による減速時は，減速開始フラグはONしません。
- 速度制御モード中，トルク制御モード中および押当て制御モード中は，速度変更機能を使用できません。速度制御モード中および押当て制御モード中の速度変更については，下記を参照してください。

#### オーバーライド機能 (8.5 / 印刷 p.268 / 原本 p.270)

「オーバーライド機能」は，実行するすべての制御について，指令速度を指定した割合(0～300％)で変更する機能です。

速度を変更する割合(％)を"[Cd.13]位置決め運転速度オーバーライド"に設定することによって，速度変更を実行します。

##### 制御内容 (8.5 オーバーライド機能 / 印刷 p.268 / 原本 p.270)

オーバーライド機能の動作を以下に示します。

- "[Md.22]送り速度"はオーバーライド機能によって変更された値をモニタしています。
- "[Cd.13]位置決め運転速度オーバーライド"に「100(％)」を設定した場合は，速度は変化しません。
- "[Cd.13]位置決め運転速度オーバーライド"に「100(％)」未満の値を設定し，"[Md.22]送り速度"が「1」未満になる場合は，ワーニング「最低速度未満」(ワーニングコード: 0904H)となり，そのときの速度単位の「1」で制御されます。
- "[Cd.13]位置決め運転速度オーバーライド"に「0(％)」を設定した場合，速度は「0」となり，速度変更0フラグ([Md.31]ステータス: b10)が「1」となります。このとき，ワーニング「最低速度未満」(ワーニングコード: 0904H)は発生しません。
- 位置制御中，速度・位置切換え制御，および位置・速度切換え制御の位置制御中に，オーバーライド機能によって速度変更を行う場合，変更を行うだけの残距離が確保できないときは，変更できる速度で動作します。
- オーバーライド機能によって変更された速度が"[Pr.8]速度制限値"以上の場合は，ワーニング「速度制限値オーバー」(ワーニングコード: 0991H)となり，速度は"[Pr.8]速度制限値"で制御され，"[Md.39]速度制限中フラグ"がONします。

【図】オーバーライド機能の動作(8.5 / 印刷 p.268 / 原本 p.270)
- [Da.8]指令速度: 50(全期間)。
- [Cd.13]位置決め運転速度オーバーライド値の変化: 100 → 0 → 50 → 150 → 100 → 200。
- [Md.22]送り速度: 50 → 0 → 25 → 75 → 50 → 75。
- オーバーライド値 0 の区間で速度は 0 となり，速度変更0フラグ([Md.31]ステータス: b10)がONしている。オーバーライド値を 50 にするとフラグはOFFし，速度25で運転再開。
- 150 にすると 75 へ加速。その後オーバーライド値を 100 に変更した時点は減速中で，「減速時はオーバーライド値の影響を受けない」(速度波形はそのまま減速停止)。
- 次の運転で送り速度 50 の定速中にオーバーライド値を 200 に変更 → 送り速度は 100 ではなく 75。「残距離を確保できないため上げられる速度で運転する」。

##### 制御上の注意事項 (8.5 オーバーライド機能 / 印刷 p.268 / 原本 p.270)

- 連続軌跡制御中にオーバーライド機能によって速度変更を行う場合，変更を行うだけの残距離が確保できないときは，速度変更はキャンセルされます。
- 以下に示す場合は，ワーニング「減速・停止速度変更」(ワーニングコード: 0990H)となり，オーバーライド機能による速度変更ができません。("[Cd.13]位置決め運転速度オーバーライド"に設定した値は減速停止後から有効となります。)

> - 停止指令による減速中
> - 位置制御時の自動減速中

- 補間制御時にオーバーライド機能によって速度変更を行う場合は，基準軸に必要な設定を行います。
- オーバーライド機能により連続して速度変更を行う場合は，速度変更の間隔が10 ms以上となるようにしてください(速度変更の間隔が短いと，シンプルモーションユニットが追従できなくなり，正常に指令が行われない場合があります。)
- 機械原点復帰の場合，近点ドグONを検出し，クリープ速度へ減速開始後は速度変更を行うことはできません。また，原点復帰中オーバーライド有効にし，速度が変更されている状態で，近点ドグONを検出すると，オーバーライドが無効となりクリープ速度へ加速します。[RD77MS]
- オーバーライド機能による減速時には，減速開始フラグはONしません。
- 速度制御モード中，トルク制御モード中および押当て制御モード中は，オーバーライド機能を使用できません。
- ドライバ原点復帰中はオーバーライド機能を使用できません。

##### 制御内容 (8.5 トルク変更機能 / 印刷 p.274-275 / 原本 p.276-277)

軸制御データのトルク変更値(正転トルク変更値，逆転トルク変更値)は常時変更可能で，トルク変更値を書き込んだ時点で変更した値でトルク制限を行います。

#### 目標位置変更機能 (8.5 / 印刷 p.277 / 原本 p.279)

「目標位置変更機能」は，位置制御中(1軸直線制御)の目標位置を任意のタイミングで，新たに指定した目標位置に変更する機能です。また，目標位置変更と同時に指令速度の変更も可能です。

変更後の目標位置および指令速度は直接バッファメモリに設定し，"[Cd.29]目標位置変更要求フラグ"によって，目標位置変更を実行します。

##### 制御内容 (8.5 目標位置変更機能 / 印刷 p.277 / 原本 p.279)

目標位置変更機能の制御内容を以下に示します。

###### ■始点からの位置が位置決めアドレスより変更後アドレスの方が遠い場合 (8.5 / 印刷 p.277 / 原本 p.279)

【図】変更後アドレスが遠い場合の速度波形(8.5 / 印刷 p.277 / 原本 p.279)
- 定速運転中に目標位置変更要求(パルス)を入れると，元の位置決めアドレスでの減速(破線)を行わず，そのままの速度で運転を続け，変更後アドレスで停止するように減速する。

###### ■アドレス変更と同時に速度が変更される場合 (8.5 / 印刷 p.277 / 原本 p.279)

【図】アドレスと速度を同時に変更する場合の速度波形(8.5 / 印刷 p.277 / 原本 p.279)
- 変更前速度で運転中に目標位置変更要求を入れると，変更後速度まで加速して運転し，変更後アドレスで停止するように減速する(破線は元の位置決めアドレスでの減速)。

###### ■運転の向きが変化する場合 (8.5 / 印刷 p.277 / 原本 p.279)

【図】運転の向きが変化する場合の速度波形(8.5 / 印刷 p.277 / 原本 p.279)
- 正方向に定速運転中に目標位置変更要求を入れ，変更後アドレスが既に通過した側にある場合，減速して折り返し位置で一旦停止し，逆方向(速度マイナス側)に加速・定速運転して変更後アドレスで停止する。
- 破線は元の位置決めアドレスまでの運転。

##### 制御上の注意事項 (8.5 目標位置変更機能 / 印刷 p.278-279 / 原本 p.280-281)

- 運転の向きが変化する場合，位置決めの移動方向が反転する位置(折り返し位置)で一旦停止してから，変更後アドレスへの位置決めを行います(☞ 277ページ 運転の向きが変化する場合)。この折り返し位置は，目標位置変更要求時の位置に減速停止に必要な距離を加えた位置です。

【図】折り返し位置(8.5 / 印刷 p.278 / 原本 p.280)
- 目標位置変更要求時の位置から減速を開始し，「減速停止に必要な距離」(灰色部分)を進んだ位置が折り返し位置となる。

- 目標位置変更要求時に変更後アドレスが移動方向側にある場合でも，変更後アドレスまでの移動量が減速停止に必要な距離よりも小さい場合，運転の向きが反転します。その際は，目標位置変更要求を早めて変更後アドレスまでの移動量を大きくするか，減速時間を短くして減速停止に必要な距離を小さくするなどの調整を行ってください。

【図】■変更後アドレスまでの移動量が減速停止に必要な距離よりも小さい場合(8.5 / 印刷 p.278 / 原本 p.280)
- 灰色: 減速停止に必要な距離(斜線の部分を含む)。斜線: 変更後アドレスまでの移動量。
- 変更後アドレスは折り返し位置より手前にあるため，折り返し位置で停止後に反転して変更後アドレスへ戻る。

【図】■目標位置変更要求を早める場合(8.5 / 印刷 p.278 / 原本 p.280)
- 灰色: 減速停止に必要な距離。斜線: 変更後アドレスまでの移動量(灰色の部分を含む)。
- 目標位置変更要求時の位置を早める(左へずらす)ことで，変更後アドレスまでの移動量が減速停止に必要な距離以上となり，反転せずに変更後アドレスで停止する(破線は早めなかった場合の波形と折り返し位置)。

【図】■減速時間を短くする場合(8.5 / 印刷 p.278 / 原本 p.280)
- 灰色: 減速停止に必要な距離。斜線: 変更後アドレスまでの移動量(灰色の部分を含む)。
- 減速時間を短くする(減速の傾きを急にする)ことで減速停止に必要な距離が小さくなり，反転せずに変更後アドレスで停止する(破線は元の減速時間での波形と折り返し位置)。

- 指令速度を変更する場合，速度制限値を超える設定をした場合はワーニング「速度制限値オーバー」(ワーニングコード: 0991H)となり，変更後の速度は速度制限値となります。また，指令速度変更によって目標値までの残距離が確保できなくなる場合はワーニング「残距離不足」(ワーニングコード: 0994H，0995H)となります。
- 以下の場合，目標位置変更要求は無視され，ワーニング「目標位置変更不可」(ワーニングコード: 099BH～09A1H)となります。

> - 補間制御中
> - 目標位置変更値(アドレス)がソフトウェアストロークリミット範囲外
> - 停止要因による減速停止中
> - 運転パターンが連続軌跡制御の位置決めデータ実行時
> - 速度変更0フラグ([Md.31]ステータス: b10)がONしているとき

- 指令速度を変更した場合，カレント速度も変更されます。連続した位置決めで次の位置決め速度がカレント速度を使用するような場合は，次の位置決め運転は速度変更値での運転となります。これに対して，次の位置決めデータで速度が設定されている場合はその速度がカレント速度となりカレント速度で運転を行います。
- 位置制御で自動減速中に目標位置変更要求があり，かつ移動方向が反転する場合には，一旦停止後に変更後アドレスへの位置決め制御を行います。また，移動方向が反転しない場合には，再度指令速度まで加速して変更後アドレスへの位置決めを行います。
- "[Md.48]減速開始フラグ"がON中に目標位置変更を行って，再び定速になったり出力が反転しても減速開始フラグはONのままとなります。(☞ 309ページ 減速開始フラグ機能)
- 単位degree時のABS直線1に対して目標位置変更を行うと，移動方向が反転しない場合でも，一旦減速停止した後に変更後アドレスへの位置決めを行うことがあります。

> **制約事項**
> 連続して目標位置変更を行う場合は，目標位置変更と目標位置変更の間隔が10 ms以上となるようにしてください。また，目標位置変更後の速度変更，オーバーライドや，速度変更後，オーバーライド後の目標位置変更も同様に10 ms以上の間隔をあけて行ってください。

### 8.6 始動に関連する機能 (8.6 / 印刷 p.281 / 原本 p.283)

始動に関連する機能には「先読み始動機能」があります。機能は，パラメータの設定やプログラムの作成・書込みによって実行します。

#### 先読み始動機能 (8.6 / 印刷 p.281 / 原本 p.283)

「先読み始動機能」は，実行禁止フラグONの状態で位置決め始動要求を行うと，実行禁止フラグONの間はサーボ起動を行わず，実行禁止フラグOFFを検出すると，演算周期以内にサーボ起動を開始する機能です。軸が待機状態のうちに始動開始要求を行い，軸を動作させるタイミングで実行禁止フラグをOFFします。

##### 制御内容 (8.6 先読み始動機能 / 印刷 p.281 / 原本 p.283)

先読み始動機能は，実行禁止フラグ([Cd.183])ONの状態で位置決め始動信号をONすることにより行います。実行禁止フラグONの状態で位置決め始動を行うと位置決めデータ解析までは行いますが，サーボ起動は行いません。実行禁止フラグONの間は"[Md.26]軸動作状態"は「5: 解析中」のままとなります。実行禁止フラグがOFFすると，演算周期以内にサーボ起動を開始し，"[Md.26]軸動作状態"は各制御方式に合わせた状態(位置制御中，速度制御中など)となります。"[Md.503]先読みデータ解析状態"が「2: 完了」になった後に，実行禁止フラグをOFFしてください。(下図参照)

###### ■動作例 (8.6 先読み始動機能 / 印刷 p.281 / 原本 p.283)

【図】先読み始動機能のタイミングチャート(8.6 / 印刷 p.281 / 原本 p.283)
- [Cd.183]実行禁止フラグ: 位置決め始動信号より前にON。

##### 制御上の注意事項 (8.6 先読み始動機能 / 印刷 p.281 / 原本 p.283)

- 位置決めデータ解析後，実行禁止フラグOFF待ち状態となります。実行禁止フラグOFF待ち状態に位置決めデータの変更を行った場合，変更データは反映されません。位置決めデータの変更を行う場合は位置決め始動信号ONの前に行ってください。
- 位置決め始動信号がONしてから，位置決めデータ解析が完了する前に実行禁止フラグがOFFされる(Ta < 始動時間，Ta: 上図参照)場合，先読み始動機能は無効です。
- "[Cd.3]位置決め始動番号"で，先読み始動機能により位置決め始動できるデータNo.はNo.1～600のみです。No.7000～7004，9001～9004を設定して先読み始動機能を行った場合は，エラー「始動番号範囲外」(エラーコード: 19A3H)となります。
- 実行禁止フラグのONは，必ず位置決め始動信号と同時もしくは位置決め始動信号をONする前に行ってください。位置決め始動信号ON後，Taの間に実行禁止フラグをONしても先読み始動にならない場合があります。実行禁止フラグOFFの状態で位置決め始動後，実行禁止フラグをONしても先読み始動機能は無効です。(次の位置決め始動時に有効となります。)
