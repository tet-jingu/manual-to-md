## 9 共通機能

### 9.19 サーボパラメータ変更機能[RD77GF] (9.19 / 印刷 p.404 / 原本 p.406)

サーボパラメータを転送する機能です。サーボアンプにより管理されているサーボパラメータをシンプルモーションユニットにより変更することが可能です。

#### 制御内容 (9.19 / 印刷 p.404 / 原本 p.406)

以下にサーボパラメータの格納場所と転送タイミングを示します。

【図】サーボパラメータの格納場所と転送方向(9.19 / 印刷 p.404 / 原本 p.406)
- エンジニアリングツール ⇔ サーボアンプ: 「書込み，読出し」(双方向矢印)
- サーボアンプ → RD77GF バッファメモリ内「サーボパラメータ展開エリア」: (1)単体読出し、(2)指定サイズ読出し
- RD77GF バッファメモリ内「サーボパラメータ展開エリア」→ サーボアンプ: (3)単体書込み、(4)指定サイズ書込み
- RD77GF 内には別に「保存用内部メモリ」があり、その中に「サーボパラメータバックアップエリア」がある(図中、展開エリアとの間の矢印は描かれていない)

> **Point**
> - エンジニアリングツールで編集したサーボアンプのパラメータは，エンジニアリングツールにて，サーボアンプに書き込んでください。
> - シンプルモーションユニットでは，サーボアンプ内のパラメータの読出し，書戻しが可能です。

##### (1)[サーボアンプ → 展開エリア]単体読出し (9.19 / 印刷 p.404 / 原本 p.406)

1. "[Cd.131]パラメータNo."に読み出すパラメータのオブジェクトインデックスを指定する。
2. "[Cd.130]サーボパラメータ読み出し／書き込み要求"に「100」をセットする。
   - シンプルモーションユニットがSLMPのSDO Uploadコマンドを使用してパラメータを読み出します。
3. "[Cd.130]サーボパラメータ読み出し／書き込み要求"が「0」になることを確認する。
   (読出し完了)
4. "[Cd.132]変更データ"に読み出した値がセットされる。
   - 格納されるデータのサイズはサーボアンプの技術資料集を参照してください。

【図】(1)単体読出し(9.19 / 印刷 p.404 / 原本 p.406)
- サーボアンプ パラメータ領域のうち、"[Cd.131]パラメータNo."(オブジェクトインデックス)で指した1オブジェクトが対象
- "[Cd.130]サーボパラメータ読み出し／書き込み要求: 100" で、RD77GF バッファメモリの "[Cd.132]変更データ"(1〜2ワード)へ読み出す

##### (2)[展開エリア → サーボアンプ]単体書込み (9.19 / 印刷 p.405 / 原本 p.407)

1. "[Cd.131]パラメータNo."に読み出すパラメータのオブジェクトインデックスを指定する。
2. "[Cd.132]変更データ"に書き込むデータをセットする。
   - 書き込むオブジェクトのサイズはサーボアンプの技術資料集を参照してください。
3. "[Cd.130]サーボパラメータ読み出し／書き込み要求"にオブジェクトのワード数「1」または「2」をセットする。
   - シンプルモーションユニットがSLMPのSDO Downloadコマンドを使用してパラメータを書き込みます。
4. "[Cd.130]サーボパラメータ読み出し／書き込み要求"が「0」になることを確認する。
   (書込み完了)

【図】(2)単体書込み(9.19 / 印刷 p.405 / 原本 p.407)
- RD77GF バッファメモリの "[Cd.132]変更データ"(1〜2ワード)から、サーボアンプ パラメータ領域の "[Cd.131]パラメータNo."(オブジェクトインデックス)で指したオブジェクトへ書き込む
- 要求値: "[Cd.130]サーボパラメータ読み出し／書き込み要求: 1または2(ワード)"

> **Point**
> 書き込んだパラメータをサーボアンプの不揮発性メモリに保存する場合は，サーボトランジェント伝送機能で，Store parameters(1010H)オブジェクトを操作してください。詳細はサーボアンプの技術資料集を参照してください。

##### (3)[サーボアンプ → 展開エリア]指定サイズ読出し (9.19 / 印刷 p.405 / 原本 p.407)

1. "[Cd.121]パラメータサイズ"に読み出すパラメータ個数を，"[Cd.122]パラメータオフセット"に読み出すパラメータの先頭オブジェクトを指定する。
2. "[Cd.120]サーボパラメータ操作要求"に「1000」をセットする。
   - シンプルモーションユニットがSLMPのSDO Uploadコマンドを使用してパラメータを読み出します。
3. "[Cd.120]サーボパラメータ操作要求"が「0」になることを確認する。
   (読出し完了)
4. "[Cd.125]要求データ"に読み出した値がセットされる。
   - バッファメモリに格納されるデータの配置はオブジェクトのサイズに依存します。読み出すデータのオブジェクトのサイズはサーボアンプの技術資料集を参照してください。

【図】(3)指定サイズ読出し(9.19 / 印刷 p.405 / 原本 p.407)
- サーボアンプ パラメータ領域の "[Cd.122]パラメータオフセット"(オブジェクトインデックス N)から N, N+1, … と "[Cd.121]パラメータサイズ(個数)" 分の範囲が対象
- 図中の要求値表記は "[Cd.120]サーボパラメータ操作要求: 1"(本文・データ一覧では「1000」。要確認一覧参照)
- RD77GF バッファメモリの「サーボパラメータ展開エリア」(最大1024ワード)へ読み出す

##### (4)[展開エリア → サーボアンプ]指定サイズ書込み (9.19 / 印刷 p.406 / 原本 p.408)

1. "[Cd.121]パラメータサイズ"に書き込むパラメータ個数と1オブジェクトあたりのサイズ(バイト数)を，"[Cd.122]パラメータオフセット"に書き込み先パラメータの先頭オブジェクトを指定する。
2. "[Cd.125]要求データ"に書き込むデータをセットする。
   - バッファメモリに格納するデータの配置はオブジェクトのサイズに依存します。書き込むデータのオブジェクトのサイズはサーボアンプの技術資料集を参照してください。
3. "[Cd.120]サーボパラメータ操作要求"に「1000」をセットする。
   - シンプルモーションユニットがSLMPのSDO Downloadコマンドを使用してパラメータを書き込みます。
4. "[Cd.120]サーボパラメータ操作要求"が「0」になることを確認する。
   (書込み完了)

【図】(4)指定サイズ書込み(9.19 / 印刷 p.406 / 原本 p.408)
- RD77GF バッファメモリの「サーボパラメータ展開エリア」(最大1024ワード)から、サーボアンプ パラメータ領域の "[Cd.122]パラメータオフセット"(オブジェクトインデックス N)以降 N, N+1, … へ書き込む
- 範囲は "[Cd.121]パラメータサイズ(1オブジェクトのバイト数とオブジェクト個数)"
- 図中の要求値表記は "[Cd.120]サーボパラメータ操作要求: 2"(本文手順3は「1000」、データ一覧では書込みは「1001」。要確認一覧参照)

> **Point**
> 書き込んだパラメータをサーボアンプの不揮発性メモリに保存する場合は，サーボトランジェント伝送機能で，Store parameters(1010H)オブジェクトを操作してください。詳細はサーボアンプの技術資料集を参照してください。

#### 制約事項 (9.19 / 印刷 p.406 / 原本 p.408)

##### "[Cd.130]サーボパラメータ読み出し／書き込み要求"を使用する場合 (9.19 / 印刷 p.406 / 原本 p.408)

- 以下の状態で要求を行うと"[Cd.130]サーボパラメータ読み出し／書き込み要求"に「3: エラー」が格納されます。
  - サーボアンプとの通信が確立していない，または通信異常
  - サーボアンプがSLMPコマンドに対応していない
  - サーボアンプからエラー応答を受信
- サーボパラメータ転送中に"[Cd.130]サーボパラメータ読み出し／書き込み要求"を変更しても受け付けられません。"[Cd.130]サーボパラメータ読み出し／書き込み要求"が「0」になるのを確認してから変更してください。
- 転送できるパラメータエリアのサイズは，1軸あたり最大2ワードです。

##### "[Cd.120]サーボパラメータ操作要求"を使用する場合 (9.19 / 印刷 p.406 / 原本 p.408)

- 以下の状態で要求を行うと"[Cd.120]サーボパラメータ操作要求"に「-1: 操作エラー」が格納されます。
  - サーボアンプとの通信が確立していない，または通信異常
  - "[Cd.121]パラメータサイズ"が範囲外
  - サーボアンプがSLMPコマンドに対応していない
  - サーボアンプからエラー応答を受信
- サーボパラメータ転送中に"[Cd.120]サーボパラメータ操作要求"を変更しても受け付けられません。"[Cd.120]サーボパラメータ操作要求"が「0」になるのを確認してから変更してください。
- 転送できるパラメータエリアのサイズは，1軸あたり最大1024ワードです。
- "[Cd.130]サーボパラメータ読み出し／書き込み要求"と，"[Cd.120]サーボパラメータ操作要求"を同時に要求した場合，"[Cd.130]サーボパラメータ読み出し／書き込み要求"を先に受付けます。

##### ブロック始動データの書換え方法 (9.20 / 印刷 p.415 / 原本 p.417)

1. "[Cd.223]始動ブロックNo.指定"にブロックNo.を指定してください。
2. "[Cd.224]ブロック始動データ種別指定"に「0: ブロック始動データ」を指定してください。
3. "[Cd.225]ブロック始動データ番号指定"にブロック始動データ番号を指定してください。
4. "[Cd.226]位置決めデータ／ブロック始動データ設定値"に設定値を指定してください。
5. "[Cd.222]ブロック始動データ制御要求"を「_ _01H: 書込み要求」にしてください。"[Cd.222]ブロック始動データ制御要求"のbit8〜bit9を操作することにより，各データの書込み要否を指定できます。
6. "[Cd.223]始動ブロックNo.指定"で指定したブロックNo.の"[Cd.225]ブロック始動データ番号指定"で指定したブロック始動データ番号に"[Cd.226]位置決めデータ／ブロック始動データ設定値"が書き込まれます。書込みに成功した場合，"[Cd.222]ブロック始動データ制御要求"は「0000H: 制御要求なし(制御完了)」となります。
7. "[Cd.223]始動ブロックNo.指定"，"[Cd.224]ブロック始動データ種別指定"，"[Cd.225]ブロック始動データ番号指定"の設定値が範囲外の場合，"[Cd.222]ブロック始動データ制御要求"が，「00FFH: 書込み／読出しエラー」となります。"[Cd.222]ブロック始動データ制御要求"は常時検出です。「00FFH: 書込み／読出しエラー」から手動で「0000H: 制御要求なし(制御完了)」へ戻す必要はありません。
