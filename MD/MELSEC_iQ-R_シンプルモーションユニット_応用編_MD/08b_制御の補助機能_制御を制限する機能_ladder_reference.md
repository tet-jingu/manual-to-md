## 8 制御の補助機能 (8 / 印刷 p.239- / 原本 p.241-)

### 8.4 制御を制限する機能 (8.4 / 印刷 p.239 / 原本 p.241)

制御を制限する機能には「速度制限機能」，「指令パルス制限機能」，「トルク制限機能」，「ソフトウェアストロークリミット機能」，「ハードウェアストロークリミット機能」，「緊急停止機能」があります。各機能は，パラメータの設定やプログラムの作成・書込みによって実行します。

#### 速度制限機能 (8.4 / 印刷 p.239 / 原本 p.241)

「速度制限機能」は，制御中の指令速度が「速度制限値」を超えるような場合，指令速度を「速度制限値」の設定範囲内に制限する機能です。

##### 制御上の注意事項 (8.4 / 印刷 p.239 / 原本 p.241)

- 2～4軸速度制御時にいずれかの軸が"[Pr.8]速度制限値"を超える場合は，速度制限値を超えた軸を速度制限値で制御します。補間を行っている他の軸は，指令速度の比によって速度が抑えられます。
- 2軸円弧補間制御時は，基準軸が"[Pr.8]速度制限値"を超える場合は，基準軸を速度制限値で制御します。(補間軸側は速度制限が機能しません。)
- 2～4軸直線補間制御，2～4軸定寸送り制御時は，いずれかの軸が"[Pr.8]速度制限値"を超える場合は，速度制限値を超えた軸を速度制限値で制御します。補間を行っている他の軸は，移動距離の比によって速度が抑えられます。
- 3軸ヘリカル補間制御時は，円弧補間軸の合成速度または直線補間軸の速度が"[Pr.8]速度制限値"を超えないように制御します。(ただし，直線補間軸に設定されたピッチ数("[Da.10]Mコード／条件データNo.／LOOP～LEND繰り返し回数／ピッチ数")が小さい場合など，円弧補間軸の合成移動量よりも直線補間軸の移動量が長くなる場合，直線補間軸の速度を"[Pr.8]速度制限値"で抑えられなくなります。)

> **Point**
> 補間制御時「基準軸速度」を設定した場合は，長軸側が基準軸になるように設定してください。短軸側を基準軸に設定すると，長軸側の速度を"[Pr.8]速度制限値"で抑えられなくなります。

#### 指令パルス制限機能[RD77MS] (8.4 / 印刷 p.241 / 原本 p.243)

「指令パルス制限機能」は，シンプルモーションユニットの1演算周期あたりの指令量がサーボアンプの動作可能な指令量を超えるような場合，指令パルスをサーボアンプの動作可能な指令量範囲内に制限する機能です。
サーボアンプの動作可能な指令量(最大指令パルス)は，下記式にて判定します。

```
サーボモータ最大回転速度[r/min] × エンコーダ分解能[pulse/rev] × 演算周期[ms]
------------------------------------------------------------------------------ [pulse]
                         60 [s] × 1000 [ms]
```

「指令パルス制限機能」は，バックラッシュ補正機能やインチング運転使用時，指令パルスが一時的に最大指令パルスを超えるような場合に使用することにより，サーボアラームの発生を防ぐことができます。

##### 制御内容 (8.4 / 印刷 p.241 / 原本 p.243)

指令パルス制限機能の動作を以下に示します。

###### ■動作例 (8.4 / 印刷 p.241 / 原本 p.243)

【図】指令パルス制限機能の動作例(縦軸 pulse / 横軸 t)(8.4 / 印刷 p.241 / 原本 p.243)
- 横軸は演算周期ごとの棒グラフ(「演算周期当たりの移動量」)。破線で「最大指令パルス」のレベルが示されている。
- 1番目の演算周期: 指令量が最大指令パルスを大きく超えており、最大指令パルスを超えた部分(網掛け、矢印(1))が「指令パルス持ち越し量」として次の演算周期に送られる(矢印)。
- 2番目の演算周期: 持ち越された(1)を加えた結果、再び最大指令パルスを超え、超過分(2)が持ち越し量として次の演算周期へ送られる。この周期の出力は最大指令パルスで頭打ち。
- 3番目の演算周期: 持ち越された(2)が加算されて出力され、最大指令パルス以下に収まる。
- 以降の演算周期は持ち越し無しで、最大指令パルス未満の移動量が出力される。

指令パルスが一時的に最大指令パルスを超えるような場合，最大指令パルスで制限します。制限された指令パルスは次の演算周期に遅延して出力します。また，制限された指令パルスは，"[Md.504]指令パルス持ち越し量"(-2147483648～2147483647)にて確認できます。

###### ■制御上の注意事項 (8.4 / 印刷 p.242 / 原本 p.244)

- 最大指令パルスを超える指令パルスが継続して下記の計算式により算出された回数を超えた場合，ワーニング「持ち越し指令パルスオーバー」(ワーニングコード: 0934H)が出力されます。制御は継続されますが，ワーニング出力後の"[Md.504]指令パルス持ち越し量"がエンコーダ分解能のパルス数を超えた場合，持ち越された指令パルスは全て指令に加算して出力します。

```
最大指令パルス超過回数[回] = エンコーダ分解能[pulse/rev] / 最大指令パルス[pulse]
```

<例1> エンコーダ分解能4194304 [pulse]，サーボモータ最大回転速度6000 [r/min]の場合

| 演算周期[ms] | 最大指令パルス超過回数[回] |
|---|---|
| 0.444 | 23 |
| 0.888 | 12 |
| 1.777 | 6 |
| 3.555 | 3 |

<例2> エンコーダ分解能1703936 [pulse]，サーボモータ最大回転速度180 [r/min]の場合

| 演算周期[ms] | 最大指令パルス超過回数[回] |
|---|---|
| 0.444 | 751 |
| 0.888 | 376 |
| 1.777 | 188 |
| 3.555 | 94 |

- 軸エラーが発生した場合，持ち越された指令パルスは全て出力されます。
- シンプルモーションユニットが位置決め完了状態となっても，持ち越された指令パルスが掃き出されるまで指令を出力します。
- 持ち越された指令パルスの出力が完了する前に移動方向が反転した場合，残りの持ち越し指令パルスは反転後の位置決め指令に加算されます。
- 指令パルス制限動作中("[Md.504]指令パルス持ち越し量"が0以外)の場合，"[Pr.125]指令パルス制限"を「0: 無効」に設定できません。指令パルス制限機能を無効にする場合，"[Md.504]指令パルス持ち越し量"が0のときに行ってください。
- 速度制御モード，トルク制御モードでは，位置制御から速度制御またはトルク制御への切換え時に"[Md.504]指令パルス持ち越し量"が0以外の場合，持ち越された指令パルスが全て出力されます。

##### ソフトウェアストロークリミットチェック上の注意事項 (8.4 / 印刷 p.249 / 原本 p.251)

- 「ソフトウェアストロークリミット機能」を正常に機能させるには，事前に機械原点復帰を実行する必要があります。
- 補間制御時は，基準軸と補間軸すべての現在値についてストロークリミットチェックを行います。いずれか1つの軸のみがエラーとなった場合でも，すべての軸が始動しません。
- 2軸円弧補間制御，3軸ヘリカル補間制御(基準軸と円弧補間軸)時は，制御の途中で"[Pr.12]ソフトウェアストロークリミット上限値"／"[Pr.13]ソフトウェアストロークリミット下限値"を超えることがあります。この場合，ストロークリミットを超えても減速停止を行いません。ストロークリミットを超える可能性がある場合は，必ず，外部にリミットスイッチを設置してください。

#### ハードウェアストロークリミット機能 (8.4 / 印刷 p.252 / 原本 p.254)

> **警告**
> - ハードウェアストロークリミットの配線が必要な場合は，必ず負論理で配線し，b接点を使用してください。正論理に設定し，a接点を用いますと，重大な事故が発生する可能性があります。

「ハードウェアストロークリミット機能」は，物理的な可動範囲の上限／下限にリミットスイッチを設置し，リミットスイッチからの信号入力で制御を停止(減速停止)させる機能です。
物理的な可動範囲の上限／下限に達する前に制御を停止させることにより，機器の破損を防止します。
ハードウェアストロークリミットには，以下信号を使用できます。(☞ 510ページ [Pr.116]FLS信号選択，[Pr.117]RLS信号選択，[Pr.118]DOG信号選択，[Pr.119]STOP信号選択)
- シンプルモーションユニットの外部入力信号[RD77MS]
- サーボアンプの外部入力信号
- CPU経由外部入力信号(シンプルモーションユニットのバッファメモリ)
- CC-Link IE フィールドネットワーク上の入力信号(リンクデバイス)[RD77GF]

##### ハードウェアストロークリミットの配線 (8.4 / 印刷 p.254 / 原本 p.256)

ハードウェアストロークリミット機能を使用する場合は，使用する機器の上限・下限ストロークリミットに対応する信号端子を，次のように配線してください。

###### ■シンプルモーションユニットの外部入力信号の場合[RD77MS] (8.4 / 印刷 p.254 / 原本 p.256)

シンプルモーションユニット／サーボアンプの上限／下限ストロークリミットの端子を，下図のように配線してください。DC24 Vの +/- の極性はどちらでも可能です。

例
"[Pr.150]入力端子論理選択"が初期値の場合

【図】シンプルモーションユニットの FLS/RLS 配線例(8.4 / 印刷 p.254 / 原本 p.256)
- シンプルモーションユニットの端子 FLS、RLS、COM。
- FLS 端子 — リミットスイッチ接点 — 共通線、RLS 端子 — リミットスイッチ接点 — 共通線。2つの接点の他端は1点で結ばれる。
- 共通線 — DC24 V — COM 端子。(DC24 V の極性はどちらでも可)
- 接点記号はb接点(常時閉)として描かれている(警告の「負論理で配線し，b接点を使用」と整合)。

###### ■サーボアンプの外部入力信号の場合 (8.4 / 印刷 p.254 / 原本 p.256)

信号の入力可否や配線の詳細は，使用するサーボアンプの技術資料集またはマニュアルを参照してください。

- [RD77MS]

MR-J3/MR-J4シリーズサーボアンプおよびMR-J5(W)-Bでは，下図のように配線してください。DC24 Vの +/- の極性はどちらでも可能です。

例
"[Pr.22]入力信号論理選択"が初期値の場合

【図】サーボアンプの FLS/RLS 配線例(8.4 / 印刷 p.254 / 原本 p.256)
- サーボアンプの端子 DI1(FLS)、DI2(RLS)、DICOM。
- DI1(FLS) — リミットスイッチ接点 — 共通線、DI2(RLS) — リミットスイッチ接点 — 共通線。
- 共通線 — DC24 V — DICOM 端子。(DC24 V の極性はどちらでも可)
- 接点記号はb接点(常時閉)として描かれている。

- [RD77GF]

MR-J4-GFを使用する場合，LSP/LSN信号に関するパラメータ設定・配線を行ってください。(☞ 252ページ 制御内容)

###### ■CPU経由外部入力信号(シンプルモーションユニットのバッファメモリ)の場合 (8.4 / 印刷 p.255 / 原本 p.257)

配線は使用する外部入力信号を入力するユニットのマニュアルを参照してください。

###### ■リンクデバイスの場合[RD77GF] (8.4 / 印刷 p.255 / 原本 p.257)

配線は使用するリモート入力ユニットのマニュアルを参照してください。
ストロークリミット信号の論理設定は"[Pr.913]上限リミット信号(FLS): リンクデバイス論理設定"および"[Pr.923]下限リミット信号(RLS): リンクデバイス論理設定"に従います。

> **Point**
> 「送り現在値」が増加する方向に設置されているリミットスイッチを上限リミットスイッチとし，｢送り現在値」が減少する方向に設置されているリミットスイッチを，下限リミットスイッチとして配線してください。
> 上限／下限リミットスイッチの取付け位置を逆にした場合，ハードウェアストロークリミット機能は正常に動作しません。なお，サーボモータは停止しません。
> サーボアンプによっては「送り現在値」の増減とモータの回転方向／移動方向の対応をパラメータにより変更できます。詳細はサーボアンプの技術資料集またはマニュアルを参照してください。

##### ハードウェアストロークリミット機能を使用しない場合 (8.4 / 印刷 p.255 / 原本 p.257)

[RD77MS]
"[Pr.22]入力信号論理選択"もしくは"[Pr.150]入力端子論理選択"でFLSとRLSの論理を"負論理"(初期値)として常時ONの信号を入力するか，"[Pr.22]入力信号論理選択"もしくは"[Pr.150]入力端子論理選択"でFLSとRLSの論理を"正論理"として入力を常時OFFしてください。

[RD77GF]
"[Pr.22]入力信号論理選択"でFLSとRLSの論理を"負論理"(初期値)として常時ONの信号を入力するか，"[Pr.22]入力信号論理選択"でFLSとRLSの論理を"正論理"として入力を常時OFFしてください。

##### 制御上の注意事項 (8.4 / 印刷 p.258 / 原本 p.260)

- シンプルモーションユニットの制御可能範囲外(上限／下限リミットスイッチの外側)で停止している場合や，ハードウェアストロークリミットを検出して停止した場合は，「原点復帰制御」，「主要な位置決め制御」，「高度な位置決め制御」の始動，制御モード切換えはできません。再度制御を行う場合は，ワークを「JOG運転」，「インチング運転」もしくは「手動パルサ運転」でシンプルモーションユニットの制御可能範囲に移動させてください。
- "[Pr.22]入力信号論理選択"もしくは"[Pr.150]入力端子論理選択"が初期値で，FLS(上限リミット信号)とDICOM間，RLS(下限リミット信号)とDICOM間が開放されている場合(配線していない場合も含む)は，シンプルモーションユニットで位置決め制御ができません。
- MR-J4-GF接続時，サーボパラメータ「機能選択D-4(PD41)」の「ストロークリミット有効状態選択」と「機能選択C-6(PC19)」の「[AL.99ストロークリミット警告]選択」の設定により，ハードウェアストロークリミット停止時の動作と発生するエラーが異なります。[RD77GF]

###### サーボパラメータ「機能選択D-4(PD41)」が「0: ストロークリミット常時有効」の場合[RD77GF] (8.4 / 印刷 p.259 / 原本 p.261)

【図】PD41=「0: ストロークリミット常時有効」時のストロークリミット停止と復帰(8.4 / 印刷 p.259 / 原本 p.261)
- 上段(位置): 実線 [Md.20]送り現在値・[Md.21]送り機械値、破線 [Md.101]実現在値。
- 中段(速度 V): 実線 [Md.22]送り速度・[Md.28]軸送り速度、破線 [Md.103]モータ回転数。
- 下段: LSP/FLSまたはLSN/RLS信号、[Md.117]Statusword b12: Operation mode specific (Target position ignored)。
- 時点1.: LSP/FLS(またはLSN/RLS)信号がOFF(検出)、同時に [Md.117] b12 がOFF側へ変化。[Md.103]モータ回転数(破線)は急峻に0へ(サーボアンプ側の停止)、[Md.22]/[Md.28](実線)はシンプルモーションユニットの減速でより緩やかに0へ。
- 1.〜2.: [Md.101]実現在値(破線)は時点1. 付近で一定値になるが、[Md.20]/[Md.21](実線)は減速中も増加を続け、時点2. で停止。この時点で位置指令と実現在値の間に差がある。
- 時点3.: ストロークリミット内へ向かう方向に手動運転開始。[Md.22]/[Md.28] は負方向に立ち上がり [Md.20]/[Md.21] は減少していくが、[Md.103]モータ回転数は0のままで [Md.101]実現在値は変化しない。
- 時点4.: [Md.20]/[Md.21] が実現在値(信号を検出した指令位置)まで戻った時点で、LSP/FLS(LSN/RLS)信号と [Md.117] b12 がON側に戻り、[Md.103] が立ち上がって [Md.101] も [Md.20]/[Md.21] と一緒に減少し始める。

1. LSP/FLSまたはLSN/RLS信号検出にてシンプルモーションユニット／サーボアンプそれぞれで停止処理を実施します。
2. シンプルモーションユニット側の停止処理完了後，モータ実現在値と位置指令との間に差が生じた状態で停止します。(サーボアンプはシンプルモーションユニットからのストロークリミット外への位置指令を無視します。)
3. 停止後，ストロークリミット内へ移動する方向に手動運転を実施すると，シンプルモーションユニット側の位置指令(送り現在値や送り機械値)，指令速度は更新されますが，サーボモータは動作しません。
4. シンプルモーションユニットからの位置指令が"LSP/FLSまたはLSN/RLS信号を検出した指令位置"となると，サーボモータはストロークリミット内への動作を開始します。

> **Point**
> - サーボアンプのストロークリミット検出時に，補間状態やアドバンスト同期制御の入力軸・出力軸の関係を保ったまま停止させるには，サーボパラメータ「機能選択D-4(PD41)」の「ストロークリミット有効状態選択」を「1: 原点復帰モードのみ有効」に設定してください。
> - ハードウェアストロークリミットによる停止によってモータ実現在値と位置指令との間に差が生じている状態で外部入力信号がON(リミット解除)となると，シンプルモーションユニットの位置指令までモータが急激に動作します。ストロークリミット内へ手動運転を実施してモータ実現在値と位置指令の差を復元してください。("[Cd.100]サーボOFF指令"にてサーボOFF状態とすることで，フォローアップを実施しモータ実現在値へ位置指令を復元することも可能です。復元後，再度サーボON状態とし手動運転でストロークリミット内へ移動を行ってください。)
> - ストロークリミット検出によって，シンプルモーションユニットの指令位置がモータ実現在値よりストロークリミット側に停止した場合，ストロークリミット内への手動運転を実施すると，モータ実現在値はコントローラからの指令位置へ追従する動作となります。

#### 緊急停止機能 (8.4 / 印刷 p.260 / 原本 p.262)

> **警告**
> - 緊急停止の配線が必要な場合は，必ず負論理で配線し，b接点を使用してください。
> - "[Pr.82]緊急停止有効／無効設定"を「1: 無効」とした場合，シンプルモーションユニットの外部でシステム全体が安全に働くように，サーボアンプの強制停止端子(EM1)を必ず使用した安全回路を設けてください。

「緊急停止機能」は，緊急停止用信号によって，サーボアンプの全軸を一括停止させる機能です。(初期値は，「0: 有効(外部入力信号)」[RD77MS]「1: 無効」[RD77GF]です。)
"[Pr.82]緊急停止有効／無効設定"により，緊急停止入力の有効／無効を選択できます。

緊急停止信号送信後のサーボアンプの動作については，サーボアンプの技術資料集またはマニュアルを参照してください。

###### ■動作例 (8.4 / 印刷 p.260 / 原本 p.262)

【図】緊急停止機能の動作例タイミングチャート(8.4 / 印刷 p.260 / 原本 p.262)
- 信号: 各種運転 / シーケンサレディ信号[Y0] / 全軸サーボON[Y1] / 位置決め始動信号[Y10] / 緊急停止入力(EMIの入力電圧もしくは[Cd.158]緊急停止入力) / [Md.50]緊急停止入力 / [Md.108]サーボステータス1(b1: サーボON) / [Pr.82]緊急停止有効／無効設定。
- [Pr.82] は全期間「1以外」(緊急停止入力有効)。
- 初期: Y0 ON → Y1 ON → [Md.108] b1 ON。Y10 ON で各種運転開始。[Md.50]=1。
- 1回目の緊急停止要因発生: 緊急停止入力(EMI入力電圧または[Cd.158])がHigh→Lowに落ちた時点で、各種運転が停止し、[Md.50] が 1→0、[Md.108] b1 が ON→OFF。その後 Y10 がOFF、Y1 がOFF。
- 緊急停止入力がHighに戻る(解除)と [Md.50] は 0→1 に戻るが、Y1 がOFFのため [Md.108] b1 はOFFのまま。
- その後 Y0 OFF→ON、Y1 ON で [Md.108] b1 が ON に戻り、Y10 ON で再び運転。
- 2回目の緊急停止要因発生: 同様に [Md.50] 1→0、[Md.108] b1 ON→OFF、運転停止、Y10 OFF。このとき Y1 はONのまま。
- 緊急停止入力解除で [Md.50] 0→1 となり、Y1 がONのままなので [Md.108] b1 も直ちに OFF→ON に戻る。

##### 制御上の注意事項 (8.4 / 印刷 p.262 / 原本 p.264)
