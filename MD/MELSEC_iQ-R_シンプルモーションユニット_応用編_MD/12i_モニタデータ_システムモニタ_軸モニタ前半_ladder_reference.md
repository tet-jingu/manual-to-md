##### [Md.3]始動情報 (12.7 / 印刷 p.564 / 原本 p.566)

始動情報(再始動フラグ，始動元，始動軸)が格納されます。

- 再始動フラグ: 一旦停止してからの再始動かどうか
- 始動元: どこから始動信号が入ったか
- 始動軸: どの軸を始動したのか

格納される情報は，下図のようになります。

【図】[Md.3]始動情報のビット構成(12.7 / 印刷 p.564 / 原本 p.566)。バッファメモリ(b15〜b0)のモニタ値を4桁(16進)で表示する図。画像から読み取ったビット割付け:

| ビット | 内容 |
|---|---|
| b15 | 再始動フラグ |
| b14〜b10 | 未使用(図中「0 0 0 0 0」) |
| b9〜b8 | 始動元 |
| b7〜b0 | 始動軸 |

●再始動フラグ

| 格納内容 | 格納値 |
|---|---|
| 再始動フラグOFF | 0 |
| 再始動フラグON | 1 |

●始動元

| 格納内容 | 格納値 |
|---|---|
| CPUユニット | 00 |
| 外部信号 | 01 |
| エンジニアリングツール | 10 |

●始動軸

| 格納内容 | 格納値 |
|---|---|
| 軸1 | 1 |
| 軸2 | 2 |
| 軸3 | 3 |
| 軸4 | 4 |
| 軸5 | 5 |
| ⋮(原本の図でも途中は縦点線で省略表示) | ⋮ |
| 軸32 | 20 |

・2軸ユニットでは軸1～軸2の範囲，
　4軸ユニットでは軸1～軸4の範囲，
　8軸ユニットでは軸1～軸8の範囲，
　16軸ユニットでは軸1～軸16の範囲が有効です。

## 転記時の要確認一覧

- [Md.3]始動情報(印刷 p.564 / 原本 p.566): 始動軸の表で「軸32」の格納値が「20」(軸1〜軸5は 1〜5 と10進のように並ぶ)。始動軸は b7〜b0 の8ビットに格納されるため、「20」は16進(20H = 32)を表すと考えられるが、原本に「H」の表記は無い。原文どおり「20」と転記した。
