## 3 主要な位置決め制御 (第3章 / 印刷 p.54 / 原本 p.56)

本章では，主要な位置決め制御(「位置決めデータ」を使った制御機能)の詳細や使い方について説明しています。
主要な位置決め制御には，アドレス情報を使用して指定の位置に位置決めを行う「位置制御」，回転体などを一定の速度で制御する「速度制御」，「速度制御」から「位置制御」に移行する「速度・位置切換え制御」，また「位置制御」から「速度制御」に移行する「位置・速度切換え制御」などがあります。
各制御に合わせて，必要な設定を行ってください。

### 3.1 主要な位置決め制御の概要 (3.1 / 印刷 p.54 / 原本 p.56)

「主要な位置決め制御」は，シンプルモーションユニットに格納する「位置決めデータ」を使って行う制御です。
位置制御や速度制御などはこの「位置決めデータ」に必要な項目を設定し，その位置決めデータを始動することによって実行します。
「主要な位置決め制御」の制御方式は，位置決めデータの設定項目の"[Da.2]制御方式"に設定します。
「主要な位置決め制御」として定義される制御は，"[Da.2]制御方式"の設定によって以下に示す制御を行います。ただし，"[Da.2]制御方式"で設定する速度制御は，サーボアンプへの指令に位置ループを含む速度制御となります。位置ループを含まない速度制御を行う場合は，「速度・トルク制御」を使用してください。(☞ 197ページ 速度・トルク制御)

#### 主要な位置決め制御の運転パターン (3.1 / 印刷 p.57 / 原本 p.59)

「主要な位置決め制御」(「高度な位置決め制御」)では，始動した位置決めデータ以降の連続する位置決めデータを，続けて実行するかどうかを"[Da.1]運転パターン"に設定することができます。「運転パターン」には下記の3種類あります。

| 位置決め制御 | 運転パターン |
|---|---|
| 位置決め終了 | 単独位置決め制御(運転パターン: 00) |
| 位置決め続行 | 連続位置決め制御(運転パターン: 01) |
| 位置決め続行 | 連続軌跡制御(運転パターン: 11) |

##### 単独位置決め制御(位置決め終了) (3.1 / 印刷 p.57 / 原本 p.59)

指定の1データの位置決めのみを実行する場合に設定します。ドウェルタイムを指定している場合は，指定時間経過後，位置決めが完了します。
ブロック位置決めのときは，このデータ(運転パターン「00」のデータ)がブロックの終わりのデータとなります。(このデータを実行したあと，停止します。)

###### 動作例 (3.1 / 印刷 p.57 / 原本 p.59)

【図】単独位置決め制御(運転パターン 00)の速度波形と信号タイミング(3.1 / 印刷 p.57 / 原本 p.59)
- 速度波形: 台形(加速 → 定速 → 減速)で「位置決め終了(00)」1データを実行。速度0到達後に「ドウェルタイム」区間がある。
- 位置決め始動信号 [Y10, Y11, Y12, Y13]: OFF → ON で始動。ドウェルタイム経過後(BUSY信号OFF後)に OFF。
- 始動完了信号([Md.31]ステータス: b14): 位置決め始動信号のONを受けて ON。位置決め始動信号の OFF を受けて OFF。
- BUSY信号 [X10, X11, X12, X13]: 位置決め始動信号のONを受けて ON(加速開始と同時)。ドウェルタイム経過時に OFF。
- 位置決め完了信号([Md.31]ステータス: b15): ドウェルタイム経過時(BUSY信号OFFと同じタイミング)に ON し，一定時間後に OFF。

##### 連続位置決め制御 (3.1 / 印刷 p.58 / 原本 p.60)

- 1つの位置決めデータの位置決めが完了するごとに必ず自動減速し，シンプルモーションユニットの指令速度がゼロになってから，次の位置決めデータの運転を行うための加速を行います。ドウェルタイムを指定している場合は，指定時間経過後に加速を行います。
- 連続位置決め制御(運転パターン「01」)による運転では，自動的に次のNo.の位置決めを実行します。最後の位置決めデータには必ず運転パターン「00」を設定し，位置決めを終了してください。運転パターンが位置決め続行(「01」または「11」)の場合は，運転パターン「00」が見つかるまで運転を続行します。このため運転パターンに位置決め終了(「00」)がない場合は，位置決めデータNo.600まで運転を行い，位置決めデータNo.600の運転パターンが位置決め終了でなかった場合は，再度位置決めデータNo.1から運転を行います。

###### 動作例 (3.1 / 印刷 p.58 / 原本 p.60)

【図】連続位置決め制御(運転パターン 01 → 01 → 00)の速度波形と信号タイミング(3.1 / 印刷 p.58 / 原本 p.60)
- 速度波形: 1データ目「位置決め続行(01)」をアドレス(+)方向に台形で実行し速度0まで減速。「ドウェルタイム未指定」のため速度0到達直後に2データ目「位置決め続行(01)」をアドレス(+)方向に(1データ目より高い速度で)台形実行。2データ目の減速完了後に「ドウェルタイム」区間を経て，3データ目「位置決め終了(00)」をアドレス(-)方向に台形実行。3データ目の減速完了後に「ドウェルタイム」区間がある。
- 位置決め始動信号 [Y10, Y11, Y12, Y13]: OFF → ON で始動。全データ完了(BUSY信号OFF)後に OFF。
- 始動完了信号([Md.31]ステータス: b14): 位置決め始動信号のONを受けて ON。位置決め始動信号の OFF を受けて OFF。
- BUSY信号 [X10, X11, X12, X13]: 始動で ON。途中のデータ切換えでは OFF せず，最後のデータ(00)のドウェルタイム経過時に OFF。
- 位置決め完了信号([Md.31]ステータス: b15): 各データの位置決め完了ごとに ON し一定時間後に OFF(計3回)。1データ目: 減速完了時(ドウェルタイム未指定)。2データ目: ドウェルタイム経過時(3データ目の加速開始時)。3データ目: ドウェルタイム経過時(BUSY信号OFFと同じタイミング)。

##### 連続軌跡制御 (3.1 / 印刷 p.59 / 原本 p.61)

###### 連続軌跡制御 (3.1 / 印刷 p.59 / 原本 p.61)

- 「現在運転中の位置決めデータNo.」と，「次に運転を行う位置決めデータNo.」の指令速度との間で減速停止しないで速度変更を行います。現在の速度と次の速度が等しい場合は，速度変更を行いません。
- 指令速度の設定が「-1」の場合，速度は前回の位置決め運転の速度を継続します。
- ドウェルタイムが設定されていても無視されます。
- 連続軌跡制御(運転パターン「11」)による運転では，自動的に次のNo.の位置決めを実行します。最後の位置決めデータは，必ず運転パターン「00」を設定して位置決めを終了してください。運転パターンが位置決め続行(「01」または「11」)の場合は，運転パターンが位置決め終了(「00」)になるまで運転を続行します。このため運転パターンに位置決め終了がない場合は，位置決めデータNo.600まで運転を行い，位置決めデータNo.600の運転パターンが位置決め終了でなかった場合は，再度位置決めデータNo.1から運転を行います。
- 速度切換えには，速度変更を現在の位置決め側の最後で行う「前倒し速度切換えモード」と，次の位置決め側の最初で行う「標準速度切換えモード」があります。(☞ 508ページ [Pr.19]速度切換えモード)
- 連続軌跡制御では設定されているアドレス／移動量よりも手前で位置決め完了となり，「次に運転を行う位置決めデータNo.」に切り換わることがあります。これは，指令速度での位置決めを優先するためで，指令速度未満の残距離分だけ手前となります。指令速度未満の残距離(Δ1)は，0 ≦ Δ1 ≦ (位置決め完了時の速度で演算周期の間に移動する距離)です。残距離(Δ1)は，次の位置決めデータNo.にて出力されます。

【図】連続軌跡制御(運転パターン 11 → 11 → 00)の速度波形と信号タイミング(3.1 / 印刷 p.59 / 原本 p.61)
- 速度波形: 1データ目「位置決め続行(11)」をアドレス(+)方向に加速 → 定速。データ切換え時に減速停止せず，2データ目「位置決め続行(11)」の高い速度へ加速して定速。2データ目から3データ目「位置決め終了(00)」への切換え時も停止せず，3データ目の低い速度へ減速して定速，その後速度0まで減速。3データ目(00)の減速完了後に「ドウェルタイム」区間がある。
- 位置決め始動信号 [Y10, Y11, Y12, Y13]: OFF → ON で始動。BUSY信号OFF後に OFF。
- 始動完了信号([Md.31]ステータス: b14): 位置決め始動信号のONを受けて ON。位置決め始動信号の OFF を受けて OFF。
- BUSY信号 [X10, X11, X12, X13]: 始動で ON。最後のデータ(00)のドウェルタイム経過時に OFF。
- 位置決め完了信号([Md.31]ステータス: b15): 1→2データ目切換え時，2→3データ目切換え時，最後のドウェルタイム経過時(BUSY信号OFFと同じタイミング)にそれぞれ ON し一定時間後に OFF。

###### 速度の扱い (3.1 / 印刷 p.61 / 原本 p.63)

- 連続軌跡制御の指令速度は，各位置決めデータで設定します。シンプルモーションユニットは各位置決めデータに指定されている速度で位置決めを行います。
- 連続軌跡制御で指令速度に「-1」を設定することができます。指令速度に「-1」を設定すると，1つ前の位置決めデータで使用していた速度で制御を行います。エンジニアリングツールで位置決めデータを設定している場合，エンジニアリングツールの指令速度には「カレント速度」が表示されます。「カレント速度」とは，現在実行している位置決め制御速度です。
- 等速制御を行う場合に指令速度に「-1」を設定しておくと，各位置決めデータに速度を設定する必要がなくなります。
- 指令速度に「-1」が設定されている場合に，1つ前の位置決めデータで速度変更またはオーバーライドの変更を行うと，速度変更後，またはオーバーライドの速度で制御を継続できます。
- 始動時最初の位置決めデータの指令速度に「-1」を設定した場合は，エラー「指令速度なし」(エラーコード: 1A12H～1A14H)となり位置決め始動できません。

###### 速度の切換え(標準速度切換えモード: 次の位置決めデータ実行時に速度切換えを行う。)(☞ 508ページ [Pr.19]速度切換えモード) (3.1 / 印刷 p.62 / 原本 p.64)

- 「現在運転中の位置決めデータ」と「次に運転を行う位置決めデータ」の指令速度がそれぞれ異なる場合，「現在運転中の位置決めデータ」の位置決めが完了した時点で，加速または減速して「次に運転を行う位置決めデータ」に設定した速度に切り換えます。
- 「次に運転を行う位置決めデータ」に設定した指令速度への加減速処理は「次に運転を行う位置決めデータ」のパラメータを使用します。指令速度が同じ場合は，速度切換えを行いません。

例

【図】標準速度切換えモードの速度波形と信号タイミング(3.1 / 印刷 p.62 / 原本 p.64)
- [Da.1]運転パターン: 11 → 11 → 11 → 01 → 00 の5データ。
- 位置決め(速度波形): 1データ目(11)で低速まで加速して定速。2データ目(11)の開始時点で加速して(図中「速度切換え」)中速で定速。3データ目(11)の開始時点で加速して高速で定速。4データ目(01)の開始時点で減速して低速で定速，4データ目の終わりで速度0まで減速し「ドウェルタイム」。5データ目(00)を台形で実行し，速度0まで減速後「ドウェルタイム」。
- すなわち速度の切換え(加速・減速)は，次のデータの区間の先頭で行われている。
- 位置決め始動信号 [Y10, Y11, Y12, Y13]: 始動で ON，BUSY信号OFF後に OFF。
- 始動完了信号([Md.31]ステータス: b14): 位置決め始動信号のONを受けて ON，位置決め始動信号OFFを受けて OFF。
- BUSY信号 [X10, X11, X12, X13]: 始動で ON，5データ目(00)のドウェルタイム経過時に OFF。
- 位置決め完了信号([Md.31]ステータス: b15): 各データの切換え時(1→2，2→3，3→4，4→5データ目。4→5は4データ目のドウェルタイム経過時)と，最後のドウェルタイム経過時(BUSY信号OFFと同じタイミング)にそれぞれ ON し一定時間後に OFF。

- 速度切換え条件は，目標速度に対して移動量が少なく，加減速を行っても目標速度に達しない場合，目標速度に近づくように加減速を行います。また，自動減速を行う必要のあるとき(例えば，運転パターンが「00」，「01」の場合)に移動量を超えてしまうようなときは，指定された位置決めアドレスで即停止し，ワーニング「移動量不足」(ワーニングコード: 0998H)となります。

| [P2で速度切換えができない場合] | [自動減速時に移動量が小さい場合] |
|---|---|
| 速度の関係がP1 = P4，P2 = P3，P1 < P2の場合 | 自動減速を行うために必要な移動量が確保できないので，速度 ≠ 0の状態で即停止となります。 |
| 【図】P1で加速して定速。P2の区間(短い)の先頭から加速するがP2の区間内では目標速度に達せず，P3の区間に入ってから目標速度(P2 = P3の速度)に到達して定速。P3の区間の終わり(P4の区間の先頭)からP4の速度(= P1の速度)へ減速して定速，P4の終わりで速度0へ減速。(原本 p.64) | 【図】Pnを定速で運転。Pn+1の区間の先頭から減速するが，「位置決めアドレス」に到達した時点で速度が0になっておらず，そこで速度0へ垂直に落ちる(即停止)。(原本 p.64) |

###### 速度の切換え(前倒し速度切換えモード: 現在実行している位置決めデータの最後で速度が切り換わる。)(☞ 508ページ [Pr.19]速度切換えモード) (3.1 / 印刷 p.63 / 原本 p.65)

- 「現在運転中の位置決めデータ」と「次に運転を行う位置決めデータ」の指令速度がそれぞれ異なる場合，「現在運転中の位置決めデータ」の位置決め完了時に「次に運転を行う位置決めデータ」に設定した速度に切り換えます。
- 「次に運転を行う位置決めデータ」に設定した指令速度への加減速処理は「次に運転を行う位置決めデータ」のパラメータを使用します。指令速度が同じ場合は速度切換えを行いません。

例

【図】前倒し速度切換えモードの速度波形と信号タイミング(3.1 / 印刷 p.63 / 原本 p.65)
- [Da.1]運転パターン: 11 → 11 → 11 → 01 → 00 の5データ。
- 位置決め(速度波形): 1データ目(11)で低速まで加速して定速，1データ目の区間の終わりで中速へ加速し，境界で中速に到達。2データ目(11)は中速で定速，区間の終わりで高速へ加速し境界で到達。3データ目(11)は高速で定速，区間の終わりで低速へ減速し境界で到達。4データ目(01)は低速で定速，終わりで速度0まで減速し「ドウェルタイム」。5データ目(00)を台形で実行し，速度0まで減速後「ドウェルタイム」。
- すなわち速度の切換え(加速・減速)は，現在のデータの区間の最後で行われ，境界で次のデータの速度になっている。
- 位置決め始動信号 [Y10, Y11, Y12, Y13]: 始動で ON，BUSY信号OFF後に OFF。
- 始動完了信号([Md.31]ステータス: b14): 位置決め始動信号のONを受けて ON，位置決め始動信号OFFを受けて OFF。
- BUSY信号 [X10, X11, X12, X13]: 始動で ON，5データ目(00)のドウェルタイム経過時に OFF。
- 位置決め完了信号([Md.31]ステータス: b15): 各データの切換え時(1→2，2→3，3→4，4→5データ目。4→5は4データ目のドウェルタイム経過時)と，最後のドウェルタイム経過時(BUSY信号OFFと同じタイミング)にそれぞれ ON し一定時間後に OFF。

- 速度切換え条件は，目標速度に対して移動量が少なく，加減速を行っても目標速度に達しない場合，目標速度に近づくように加減速を行います。また，自動減速を行う必要のある場合(例えば，運転パターンが「00」，「01」の場合)に移動量を超えてしまうようなときは，指定された位置決めアドレスで即停止し，ワーニング「移動量不足」(ワーニングコード: 0998H)となります。

| [P1でP2の速度に速度切換えができない場合] | [自動減速時に移動量が小さい場合] |
|---|---|
| 速度の関係がP1 = P4，P2 = P3，P1 < P2の場合 | 自動減速を行うために必要な移動量が確保できないので，速度 ≠ 0の状態で即停止となります。 |
| 【図】P1の区間で速度0から加速を続け，P1の速度で定速にならないままP1/P2の境界でP2の速度(高速)に到達。P2・P3は高速で定速。P3の区間の終わりでP4の速度(= P1の速度)へ減速して境界で到達，P4は定速の後，速度0へ減速。(原本 p.65) | 【図】Pnを定速で運転し，Pnの区間の終わりから減速を開始。Pn+1の区間に入っても減速中で，「位置決めアドレス」に到達した時点で速度が0になっておらず，そこで速度0へ垂直に落ちる(即停止)。(原本 p.65) |

##### 制御単位が「degree」の場合の位置決め制御方法 (3.1 / 印刷 p.68 / 原本 p.70)

###### アブソリュート方式の場合(ソフトウェアストロークリミット無効時) (3.1 / 印刷 p.68 / 原本 p.70)

現在値を基準にして，指定アドレスへ近い方向での位置決めを行います。(「近回り制御」という。)

例
(1)現在値が315°で45°へ移動させる場合は，右回りの方向で位置決めを行います。
(2)現在値が45°で315°へ移動させる場合は，左回りの方向で位置決めを行います。

【図】近回り制御(3.1 / 印刷 p.68 / 原本 p.70)
- (1) 315° → 45° の場合: 円の上側を 315° から 0° を通って 45° へ右回りの矢印。
- (2) 45° → 315° の場合: 円の上側を 45° から 0° を通って 315° へ左回りの矢印。

位置決め方向を指定する場合(近回り制御を行わない場合)，"[Cd.40] degree時ABS方向設定"により，近回り制御を無効にし，指定した方向への位置決めが行えます。

"[Cd.40] degree時ABS方向設定"に書き込まれた値が有効となるのは，位置決め制御始動時のみです。
連続位置決め制御，連続軌跡制御の場合は運転中に設定を変更しても始動時の設定のまま運転を続行します。
n: 軸No. - 1(軸17～軸32の場合は，n: 軸No. - 17)

|---|---|---|---|---|
| [Cd.40]<br>degree時ABS方向設定 | degreeのABSの移動方向を指定<br>0: 近回りを行う(方向設定無効)<br>1: ABS右回り<br>2: ABS左回り | 4350+100n | 1004350+100n | 0 |

このため「近回り制御」での位置決めができないことがあります。

- 円の上端 0°，345.00000° と 315.00000° に半径線。

> **Point**
> 位置決めアドレスは，0°～359.99999°の範囲内です。
> 1回転以上の位置決めを行う場合は，インクリメント方式で行ってください。

###### インクリメント方式の場合 (3.1 / 印刷 p.69 / 原本 p.71)

インクリメント方式の場合は，指定方向へ指定移動量分の位置決めを行います。
移動方向は，移動量の符号により決まります。

| 移動方向 | 回転方向 |
|---|---|
| 移動方向が正の場合 | 右回り |
| 移動方向が負の場合 | 左回り |

> インクリメント方式の場合は，360°以上の位置決めを行うこともできます。

> [ソフトウェアストロークリミット上限値 ＝ ソフトウェアストロークリミット下限値]
> 設定は，設定範囲内(0°～359.99999°)の値にしてください。

#### 補間制御 (3.1 / 印刷 p.70 / 原本 p.72)

##### 補間制御とは (3.1 / 印刷 p.70 / 原本 p.72)

「2，3，4軸直線補間制御」，「2，3，4軸定寸送り制御」，「2，3，4軸速度制御」，「2軸円弧補間制御」，「3軸ヘリカル補間制御」では，2～4つの軸方向に設定されたモータを使って，指定の軌跡を描くように制御します。このような制御を「補間制御」と呼びます。
補間制御では，制御方式を設定した軸を「基準軸」，もう一方を「補間軸」と定義します。
シンプルモーションユニットは「基準軸」に設定された位置決めデータに従って「基準軸」の制御を行い，それに応じて直線や円弧の軌跡を描くように「補間軸」を制御します。

##### 補間制御の始動 (3.1 / 印刷 p.71 / 原本 p.73)

補間制御を始動する場合は，基準軸("[Da.2]制御方式"に補間制御を設定した軸)の位置決めデータNo.を始動します。(補間軸を始動する必要はありません。)
基準軸，補間軸とも始動を行うと，下記エラーかワーニングとなり位置決め始動できません。
- 基準軸: 相手軸BUSY補間(エラーコード: 1998H)
- 補間軸: 制御方式設定エラー (エラーコード: 1A24H)，運転中始動(ワーニングコード: 0900H)

##### 補間制御の連続位置決め (3.1 / 印刷 p.71 / 原本 p.73)

運転パターンに「連続位置決め制御」，「連続軌跡制御」を指定して補間制御を行う場合は，始動した位置決めデータから「位置決め終了」を設定した位置決めデータまでのすべての位置決めデータの制御方式に，補間制御を設定する必要があります。
また，途中の位置決めデータから補間軸数，補間対象軸を変更することはできません。変更した場合，エラー「制御方式設定エラー」(エラーコード: 1A25H)となり，位置決めを停止します。

##### 補間制御時の速度 (3.1 / 印刷 p.72 / 原本 p.74)

補間制御時の速度は「合成速度」と「基準軸速度」のどちらかを指定することができます。
("[Pr.20]補間速度指定方法"で設定します。)
ただし，以下の補間制御では「基準軸速度」のみ指定できます。
「合成速度」を設定し，位置決め始動を行うとエラー「補間モードエラー」(エラーコード: 199AH)になり，始動しません。
- 4軸直線補間
- 2軸速度制御
- 3軸速度制御
- 4軸速度制御

##### 注意事項 (3.1 / 印刷 p.72 / 原本 p.74)

- 2～4軸速度制御時にいずれかの軸が"[Pr.8]速度制限値"を超える場合は，速度制限値を超えた軸を速度制限値で制御します。補間を行っている他の軸は，指令速度の比によって速度が抑えられます。
- 2軸円弧補間制御時は，基準軸が"[Pr.8]速度制限値"を超える場合は，基準軸を速度制限値で制御します。(補間軸側は速度制限が機能しません。)
- 2～4軸直線補間制御，2～4軸定寸送り制御時は，いずれかの軸が"[Pr.8]速度制限値"を超える場合は，速度制限値を超えた軸を速度制限値で制御します。補間を行っている他の軸は，移動距離の比によって速度が抑えられます。
- 3軸ヘリカル補間制御時は，円弧補間軸の合成速度または直線補間軸の速度が"[Pr.8]速度制限値"を超えないように制御します。(ただし，直線補間軸に設定されたピッチ数("[Da.10]Mコード／条件データNo.／LOOP～LEND繰り返し回数／ピッチ数")が小さい場合など，円弧補間軸の合成移動量よりも直線補間軸の移動量が長くなる場合，直線補間軸の速度を"[Pr.8]速度制限値"で抑えられなくなります。)
- 2～4軸補間において，運転途中で補間軸の組合わせを切り換えることはできません。

> **Point**
> 補間制御時「基準軸速度」を設定した場合は，長軸側が基準軸になるように設定してください。短軸側を基準軸に設定すると，長軸側の速度を"[Pr.8]速度制限値"で抑えられなくなります。

##### 補間制御中の軸動作状態 (3.1 / 印刷 p.73 / 原本 p.75)

補間制御中は"[Md.26]軸動作状態"に「補間中」が格納されます。補間運転終了時は「待機中」が格納され，補間制御中にエラーが発生した場合は，基準軸，補間軸とも減速停止し「エラー発生中」となります。
