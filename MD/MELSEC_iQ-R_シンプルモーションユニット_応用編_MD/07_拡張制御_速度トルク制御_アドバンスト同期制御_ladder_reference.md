## 7 拡張制御 (7 / 印刷 p.197 / 原本 p.199)

本章では，拡張制御の詳細や使い方を説明しています。

拡張制御には，サーボアンプへの指令に位置ループを含まない速度制御・トルク制御を行う速度・トルク制御と，ギア，シャフト，変速機，カムなどを使用して機械的に行う仕組みを，「アドバンスト同期制御パラメータ」を使用してソフトウェアに置き換え，入力軸に同期した制御を行うアドバンスト同期制御があります。

各制御に合わせて，必要な設定を行ってください。

### 7.1 速度・トルク制御 (7.1 / 印刷 p.197 / 原本 p.199)

#### 速度・トルク制御の概要 (7.1 / 印刷 p.197 / 原本 p.199)

「速度・トルク制御」では，サーボアンプへの指令に位置ループを含まない速度制御，トルク制御を行います。

また，ボトルのキャップ締めやねじ締めなどを行う場合に，位置決め動作中モータを停止させずにトルク制御に切り換える「押当て制御モード」も使用できます。[RD77MS]

「速度・トルク制御」は，制御モードを「位置制御モード」から，「速度制御モード」，「トルク制御モード」または「押当て制御モード」へ切り換えて実行します。

| 制御モード | 制御 | 備考 |
|---|---|---|
| 位置制御モード | 位置決め制御，原点復帰制御，JOG運転，インチング運転，手動パルサ運転 | サーボアンプへの指令に位置ループを含む制御を行います。 |
| 速度制御モード | 速度・トルク制御 | サーボアンプへの指令に位置ループを含まない制御を行います。 |
| トルク制御モード | 速度・トルク制御 | サーボアンプへの指令に位置ループを含まない制御を行います。 |
| 押当て制御モード[RD77MS] | 速度・トルク制御 | サーボアンプへの指令に位置ループを含まない制御を行います。<br>位置決め制御中または速度制御中に切換え可能です。 |

「速度・トルク制御」を行うサーボアンプは，各制御モードに対応したソフトウェアバージョンを使用してください。

###### ■制御モードの切換え方法 (7.1 / 印刷 p.201 / 原本 p.203)

速度制御またはトルク制御へ切り換えるには，"[Cd.139]制御モード指定"に切り換える制御モードを設定後，"[Cd.138]制御モード切換え要求"を「1」にします。

速度制御モード，トルク制御モードに切り換える場合は，"[Cd.138]制御モード切換え要求"に「1」を設定する前に，各制御モードで使用する制御データを設定する必要があります。

制御モード切換え要求時，切換え条件が成立している場合は，"[Md.26]軸動作状態"が「30: 制御モード切換え中」となり，BUSY信号がONします。切換えが完了するとシンプルモーションユニットにより自動的に"[Cd.138]制御モード切換え要求"に「0」が格納されます。

切換え条件が成立していない場合，ワーニング「BUSY中制御モード切換え」(ワーニングコード: 09E6H)または「零速度OFF中制御モード切換え」(ワーニングコード: 09E7H)となり，制御モードは切り換わりません。

###### ■制御モードの切換え時の注意事項 (7.1 / 印刷 p.202 / 原本 p.204)

- 制御モード切換え時，始動完了信号および位置決め完了信号はONしません。
- "[Md.26]軸動作状態"が「30: 制御モード切換え中」，「31: 速度制御モード中」，「32: トルク制御モード中」のときは，BUSY信号がONします。
- 速度制御モードからトルク制御モードへ切換え時，一瞬モータ回転数が変動することがあります。このため，速度制御モードからトルク制御モードへの切換えはモータを停止状態にしてから切り換えることを推奨します。
- ワークを押し当てるような使い方をする場合は，押当て制御モードを使用してください。速度制御モード中にトルクを制限して押し当てるような使い方をする場合には，下記のとおりに設定してください。
  > - MR-J5(W)-Bの場合: サーボパラメータ「機能選択B-1 モデル適応制御選択(PB25.0)」に「2: 無効(PID制御)」を設定する。
  > - MR-J4(W)-Bの場合: サーボパラメータ「機能選択B-1(PB25)」に「2: 無効(PID制御)」を設定する。
- 速度・トルク制御における速度制御モード中は，速度制御中フラグ([Md.31]ステータス: b0)はONしません。

###### ■位置制御モード ⇔ 速度制御モード切換え時の動作 (7.1 / 印刷 p.202 / 原本 p.204)

位置制御モードから速度制御モードへ切換え時，切換え直後の指令速度は"[Pr.90]速度・トルク制御モード動作設定"の「速度初期値選択(b8～b11)」で指定した速度となります。

| 「速度初期値選択」設定値([Pr.90]: b8～b11) | 位置制御モードから速度制御モードへ切換え直後のサーボアンプへの指令速度 |
|---|---|
| 0: 指令速度 | 切換え直後にサーボアンプへ指令する速度は0となります。 |
| 1: フィードバック速度 | 切換え時にサーボアンプより受信したモータ回転数となります。 |
| 2: 自動選択 | 押当て制御モード使用時の設定のため無効となります。<br>制御モードの切換え時，「0: 指令速度」と同じ動作となります。 |

速度制御モードから位置制御モードへ切換え時，切換え直後の指令位置は切換え時の送り現在値となります。

###### ■制御モードの切換え時の注意事項 (7.1 / 印刷 p.206 / 原本 p.208)

- 制御モード切換え時，始動完了信号および位置決め完了信号はONしません。
- "[Md.26]軸動作状態"が「33: 押当て制御モード中」，"[Md.124]制御モード切換え状態"が「1: 位置制御モード ⇔ 押当て制御モード，速度制御モード ⇔ 押当て制御モード切換え中」のときは，BUSY信号がONします。
- 押当て制御モード使用時は，押当て制御に対応したサーボアンプを使用してください。押当て制御に未対応のサーボアンプを使用した場合，押当て制御モードへの切換え要求時にエラー「押当て制御未対応」(エラーコード: 19E7H)となり現在の制御を停止します。(位置決め制御中は，"[Pr.39]停止グループ3急停止選択"の設定に従い停止します。速度制御中は，位置制御モードに切り換わり，即停止します。)

###### ■位置制御モード ⇔ 押当て制御モード切換え時の動作 (7.1 / 印刷 p.206 / 原本 p.208)

押当て制御モードに切り換える場合は，"[Cd.138]制御モード切換え要求"に「1」を設定する前に押当て制御モードの制御に必要な制御データを設定します。

| 1: フィードバックトルク | 切換え時のモータトルク値となります。 |

| 「速度初期値選択」設定値([Pr.90]: b8～b11) | 位置制御モードから押当て制御モードへ切換え直後のサーボアンプへの指令速度 |

この場合，制御モード切換え要求を行ってから設定条件が成立するまでは，現在の制御を継続し，"[Md.124]制御モード切換え状態"は「2: 制御モード切換え条件成立待ち」になります。設定した条件が成立すると"[Md.124]制御モード切換え状態"は「1: 位置制御モード ⇔ 押当て制御モード，速度制御モード ⇔ 押当て制御モード切換え中」となります。

切換えが完了すると"[Cd.138]制御モード切換え要求"および"[Md.124]制御モード切換え状態"に「0」が格納されます。

また，"[Cd.154]制御モード自動切換えパラメータ"が設定範囲外の場合，制御モード切換え要求時にエラー「制御モード自動切換えパラメータ範囲外」(エラーコード: 19E4H)となり，現在の処理は停止します。(位置決め制御中は，"[Pr.39]停止グループ3急停止選択"の設定に従い停止します。速度制御中は，位置制御モードに切り換わり，即停止します。)

> **Point**
> - 自動切換えは位置制御モードから押当て制御モードへの切換え時のみ有効です。速度制御モードから押当て制御への切換えや，押当て制御モードから他の制御モードへの切換え時は自動切換え設定がされていても条件成立待ちにならず，ただちに制御モード切換えを行います。
> - 切換え条件を設定してモード切換え要求を行った場合は，設定条件が成立するまで，制御モード切換え条件成立待ちが継続します。このため，自動切換えを想定した位置決めを途中で中断すると，別の位置決め動作で予期せぬ制御モードの切換えが行われることがあります。制御モード切換え条件成立待ちは"[Cd.138]制御モード切換え要求"に「1以外: 要求なし」をセットするか，軸停止信号ONにより解除できます。エラーが発生した場合も条件成立待ちは解除されます。(いずれの場合も"[Cd.138]制御モード切換え要求"に「0」が格納されます。)
> - 制御モード切換え条件成立待ちのとき，現在値変更や定寸送り制御，速度制御("[Pr.21]速度制御時の送り現在値"を「2: 送り現在値の0クリアを行う」に設定時)により現在値が更新されると，更新後の現在値により自動切換えの判定が行われます。このため設定条件によっては，位置決め始動直後に押当て制御モードに切り換わる場合があります。このような切換えを行いたくない場合は，位置決め始動後，"[Cd.138]制御モード切換え要求"に「1: 切換え要求」を設定してください。

##### 速度制御モード (7.1 / 印刷 p.211 / 原本 p.213)

###### ■速度制御モードの動作 (7.1 / 印刷 p.211 / 原本 p.213)

速度制御モードでは，"[Cd.140]速度制御モード時指令速度"に設定した速度で速度制御を行います。

正転の場合は正の値を，逆転の場合は負の値を設定します。"[Cd.140]速度制御モード時指令速度"は，速度制御モード中，常時変更可能です。

加減速処理は台形加減速処理となります。"[Pr.8]速度制限値"に対する加減速時間を"[Cd.141]速度制御モード時加速時間"，"[Cd.142]速度制御モード時減速時間"に設定してください。[Cd.141]，[Cd.142]は，速度制御モード切換え要求時の値が有効となります。

速度制御モード中の指令速度は，"[Pr.8]速度制限値"で制限されます。速度制限値を超える速度を指令した場合，ワーニング「速度制限値オーバー」(ワーニングコード: 0991H)となり速度制限値で制御されます。

サーボアンプへの指令速度は，"[Md.122]指令中速度"で確認してください。

【図】速度制御モードの速度波形と加減速時間(7.1 / 印刷 p.211 / 原本 p.213)
- 縦軸 V: 上側に [Pr.8]速度制限値、30000、20000、0、-10000、-20000、下側に [Pr.8]速度制限値(負側)の破線
- [Cd.140]速度制御モード時指令速度: 0 → 20000 → 30000 → 0 → -10000 → -20000 → 0 の順に変更
- 加速の傾きは、0 から [Pr.8]速度制限値 まで加速する時間が [Cd.141]速度制御モード時加速時間 となる傾き(破線で [Pr.8] まで延長して表示)。減速の傾きは、[Pr.8]速度制限値 から 0 まで減速する時間が [Cd.142]速度制御モード時減速時間 となる傾き
- 正側: 0 → 20000 まで加速し一定 → 30000 まで加速し一定 → 0 まで減速
- 負側: 0 → -10000 まで加速し一定 → -20000 まで加速し一定 → 0 まで減速(負側も同様に [Cd.141]/[Cd.142] を [Pr.8] に対する時間として表示)
- 注記: "[Md.122]指令中速度"にサーボアンプへの指令速度が格納されます。

##### 押当て制御モード[RD77MS] (7.1 / 印刷 p.215 / 原本 p.217)

###### ■押当て制御モードの動作 (7.1 / 印刷 p.215 / 原本 p.217)

押当て制御モードは，位置制御モードにおける位置決め中，または速度制御モードにおける速度指令中から停止せずにトルク制御を実施できるモードです。

押当て制御モード中は"[Cd.147]押当て制御モード時速度制限値"に設定した速度へ加減速を行いながら，"[Cd.150]押当て制御モード時目標トルク"に設定した指令トルクでトルク制御を行います。

"[Cd.147]押当て制御モード時速度制限値"および"[Cd.150]押当て制御モード時目標トルク"は押当て制御モード中，常時変更可能です。指令トルクの設定値とサーボモータのトルク発生方向の関係は，サーボパラメータ「回転方向選択／移動方向選択(PA14)」と「機能選択C-B トルク制御時POL反映選択(PC29)」の設定によらず固定となります。

| 「回転方向選択／移動方向選択(PA14)」の設定値 | "[Cd.150]押当て制御モード時目標トルク"の設定値 | サーボモータのトルク発生方向*1 |
|---|---|---|
| 0: 位置決めアドレス 増加時CCW方向に回転 | 正の値(正方向) | CCW方向にトルク発生 |
| 0: 位置決めアドレス 増加時CCW方向に回転 | 負の値(逆方向) | CW方向にトルク発生 |
| 1: 位置決めアドレス 増加時CW方向に回転 | 正の値(正方向) | CCW方向にトルク発生 |
| 1: 位置決めアドレス 増加時CW方向に回転 | 負の値(逆方向) | CW方向にトルク発生 |

*1 詳細は下図を参照してください。

【図】サーボモータの回転方向(CCW方向 / CW方向)(7.1 / 印刷 p.215 / 原本 p.217)
- 左の組: モータ斜視図と軸端側から見た正面図で「CCW方向」を示す(軸端側から見て反時計回り)
- 右の組: 同様に「CW方向」を示す(軸端側から見て時計回り)

> **制約事項**
> 「回転方向選択／移動方向選択(PA14)」の設定によらず，"[Cd.150]押当て制御モード時目標トルク"は，モータCCW方向へのトルク指令を行う場合には正の値を，モータCW方向へのトルク指令を行う場合には負の値を設定します。
> 設定を誤るとモータが逆転することもありますので，注意して設定してください。

> **Point**
> - モータの回転方向は"[Cd.150]押当て制御モード時目標トルク"による指定に従います。"[Cd.147]押当て制御モード時速度制限値"はモータの回転方向に応じた設定を行ってください。
> - トルク発生方向の逆方向に関しては速度の制限はかかりません。

###### ■トルク指令の設定方法 (7.1 / 印刷 p.215 / 原本 p.217)

押当て制御モード中は指令トルクが0%から"[Pr.17]トルク制限設定値"に達するまでの時間を"[Cd.151]押当て制御モード時トルク時定数(正方向)"，"[Pr.17]トルク制限設定値"から0%に減少するまでの時間を"[Cd.152]押当て制御モード時トルク時定数(負方向)"に設定してください。[Cd.151]，[Cd.152]は，押当て制御モード切換え要求時の値が有効となります。

押当て制御モード中の指令トルクは，"[Pr.17]トルク制限設定値"で制限されます。

トルク制限設定値を超えるトルクを指令した場合，ワーニング「トルク制限値オーバー」(ワーニングコード: 09E4H)となりトルク制限設定値で制御されます。

サーボアンプへの指令トルクは，"[Md.123]指令中トルク"で確認してください。

なお，押当て制御中は「トルク制限中」("[Md.108]サーボステータス1": b13)はONしません。現在のトルク値は"[Md.104]モータ電流値"で確認してください。

###### ■速度制限値の設定方法 (7.1 / 印刷 p.216 / 原本 p.218)

加減速処理は台形加減速となります。

加減速時間は"[Pr.8]速度制限値"に対する加減速時間を，"[Cd.148]押当て制御モード時加速時間"，"[Cd.149]押当て制御モード時減速時間"に設定してください。[Cd.148]，[Cd.149]は，押当て制御モード切換え時の値が有効となります。

###### ■押当て制御モード時の注意事項 (7.1 / 印刷 p.216 / 原本 p.218)

押当て制御モード中に使用できないサーボアンプの機能については，接続するサーボアンプの技術資料集またはマニュアルを参照してください。

> **Point**
> 押当て制御中に発振など振動が発生する場合は，サーボパラメータ「トルクフィードバックループゲイン(PB03)」の値を小さくして改善するかどうか確認してください。

> **制約事項**
> 押当て制御モード中にサーボアンプのストロークリミット信号は使用できないため，押当て制御モード中は稼働範囲に制限がないシステム構成としてください。
> 指令位置に制限をかける必要がある場合は，シンプルモーションユニット側のソフトウェアストロークリミット機能を使用してください。
