#### 1軸直線制御 (3.2 / 印刷 p.77 / 原本 p.79)

1軸直線制御("[Da.2]制御方式" ＝ ABS直線1，INC直線1)では，1台のモータを使って，設定した軸方向の位置制御を行います。

##### 1軸直線制御(ABS直線1) (3.2 / 印刷 p.77 / 原本 p.79)

###### ■動作図 (3.2 / 印刷 p.77 / 原本 p.79)

アブソリュート方式の1軸直線制御では，現在の停止位置(始点アドレス)から，"[Da.6]位置決めアドレス／移動量"に設定したアドレス(終点アドレス)へ位置決めを行います。

**例**

始点アドレス(現在の停止位置)が1000，終点アドレス(位置決めアドレス)が8000の場合は，正方向に移動量7000(8000 - 1000)の位置決めを行います。

【図】1軸直線制御(ABS直線1)の例 (3.2 / 印刷 p.77 / 原本 p.79)
- 数直線上に 0，1000，8000 の目盛り。1000 に「始点アドレス(現在の停止位置)」、8000 に「終点アドレス(位置決めアドレス)」の引出し線
- 1000 → 8000 へ正方向の矢印。範囲寸法に「位置決め制御(移動量7000)」

##### 1軸直線制御(INC直線1) (3.2 / 印刷 p.78 / 原本 p.80)

###### ■動作図 (3.2 / 印刷 p.78 / 原本 p.80)

インクリメント方式の1軸直線制御では，現在の停止位置(始点アドレス)から，"[Da.6]位置決めアドレス／移動量"に設定した移動量の位置決めを行います。移動方向は，移動量の符号により決まります。

【図】1軸直線制御(INC直線1)の移動方向 (3.2 / 印刷 p.78 / 原本 p.80)
- 左が逆方向、右が正方向の軸。中央の点が「始点アドレス(現在の停止位置)」
- 始点から左向き矢印が「移動量が負の場合の移動方向」、右向き矢印が「移動量が正の場合の移動方向」

**例**

【図】1軸直線制御(INC直線1)の例 (3.2 / 印刷 p.78 / 原本 p.80)

- 5000 → -2000 へ逆方向の矢印。範囲寸法に「逆方向への位置決め制御(移動量-7000)」

#### 2軸直線補間制御 (3.2 / 印刷 p.79 / 原本 p.81)

「2軸直線補間制御」("[Da.2]制御方式" = ABS直線2，INC直線2)では，2台のモータを使って，それぞれに設定した軸方向について補間しながら，直線の軌跡で位置制御を行います。(補間制御については☞ 70ページ 補間制御)

##### 2軸直線補間制御(ABS直線2) (3.2 / 印刷 p.79 / 原本 p.81)

###### ■動作図 (3.2 / 印刷 p.79 / 原本 p.81)

アブソリュート方式の2軸直線補間制御では，2軸を使用して現在の停止位置(始点アドレス)から，"[Da.6]位置決めアドレス／移動量"に設定したアドレス(終点アドレス)へ直線補間位置決めを行います。

【図】2軸直線補間制御(ABS直線2)の動作 (3.2 / 印刷 p.79 / 原本 p.81)
- 横軸: 逆方向 ← → 正方向(X軸)、縦軸: 正方向(Y軸) ↑ ↓ 逆方向
- 始点アドレス(X1, Y1)(現在の停止位置) から 終点アドレス(X2, Y2)(位置決めアドレス) へ直線で移動(「X軸，Y軸の直線補間による動き」)
- X1～X2 が「X軸の移動量」、Y1～Y2 が「Y軸の移動量」

**例**

始点アドレス(現在の停止位置)が(1000, 1000)，終点アドレス(位置決めアドレス)が(10000, 4000)の場合は，次のようになります。

【図】2軸直線補間制御(ABS直線2)の例 (3.2 / 印刷 p.79 / 原本 p.81)
- 横軸 軸1(目盛り 0，1000，5000，10000)、縦軸 軸2(目盛り 1000，4000)
- 始点アドレス(現在の停止位置) (1000, 1000) から 終点アドレス(位置決めアドレス) (10000, 4000) へ直線
- 軸1の移動量(10000 - 1000 ＝ 9000)、軸2の移動量(4000 - 1000 ＝ 3000)

###### ■制約事項 (3.2 / 印刷 p.79 / 原本 p.81)

下記の場合は，エラーとなり，位置決め始動できません。位置決め制御中の場合は，エラー検出時に即停止します。

- "[Pr.20]補間速度指定方法"で「0: 合成速度」を設定したとき，各軸の移動量が「1073741824( = 2^30)」を超える場合は，位置決め始動時にエラー「直線移動量範囲外」(エラーコード: 1A15H，1A16H)となります。("[Da.6]位置決めアドレス／移動量"に設定できる最大移動量は「1073741824( = 2^30)」です。)

定寸送り制御では，現在の停止位置(始点アドレス)のアドレス([Md.20]送り現在値)を「0」にしてから，"[Da.6]位置決めアドレス／移動量"に設定した移動量の位置決めを行います。移動方向は，移動量の符号により決まります。

- 移動量が正のとき: 正方向(アドレス増加方向)への位置決め
- 移動量が負のとき: 逆方向(アドレス減少方向)への位置決め

**例**

【図】1軸定寸送り制御 (3.2 / 印刷 p.89 / 原本 p.91)
- 「位置決め始動」点から「指定移動量」ずつ正方向へ5回連続して移動する矢印。各区間の始点に「0」と表示
- 各始点に「位置決め始動時に"[Md.20]送り現在値"を0にする」の引出し線
- 下段: 「停止位置」を中心に、逆方向側が「移動量が負の場合の移動方向」、正方向側が「移動量が正の場合の移動方向」

**例**

【図】2軸定寸送り制御 (3.2 / 印刷 p.89 / 原本 p.91)

###### ■制約事項 (3.2 / 印刷 p.90 / 原本 p.92)

- "[Da.1]運転パターン"に「連続軌跡制御」を設定した場合，エラー「連続・連続軌跡制御不可」(エラーコード: 1A1EH～1A20H)となり，始動できません。(定寸送り制御では「連続軌跡制御」を設定できません。)

> **Point**
>
> 移動量を実際の指令パルス数に換算すると，1パルスあたりの移動量により，小数点以下の端数を生じます。
> この端数は通常シンプルモーションユニット内部で保持され，次回の位置決め時に反映されます。
> 定寸送り制御については，移動距離を一定( ＝ 指令パルス数一定)とするため，始動時に端数パルスを0クリアした後，制御を実行します。
>
> [端数パルスの累積／切捨てについて]
>
> 1パルスあたりの移動量 = 1.0 [μm]で，2.5 [μm]の移動を2回実行した場合
>
> → 指令パルスに換算: 2.5 [μm] ÷ 1.0 = 2.5 [pulse]
>
> 【図】端数パルスの累積／切捨て (3.2 / 印刷 p.91 / 原本 p.93)
> - 移動量: 2.5 μm を2回(2.5 μm → 2.5 μm)
> - INC直線1: 1回目 2 pulse、2回目 3 pulse ( ＝ 2.5 ＋ 0.5 )。注記「シンプルモーションユニット内部で保持した0.5 pulseを2回目の位置決めに繰り越す」
