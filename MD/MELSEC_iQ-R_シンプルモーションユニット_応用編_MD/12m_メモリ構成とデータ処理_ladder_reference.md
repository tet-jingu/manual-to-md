## 12 位置決め制御に使用するデータ (12章 / 印刷 p.647-667 / 原本 p.649-669)

### 12.9 メモリ構成とデータ処理 (12.9 / 印刷 p.647 / 原本 p.649)

本節では，シンプルモーションユニットのメモリの構成とデータの転送について説明しています。

シンプルモーションユニットの内部には4つのメモリが装備されています。これらのメモリの構成や役割を知ることで，「電源を投入したとき」や「シーケンサレディ信号[Y0]がOFFからONに変わったとき」などのシンプルモーションユニット内部のデータ転送処理が理解しやすくなります。また，データの保存や変更の際に行う転送処理を正しく行うことができます。

##### ユニット拡張パラメータの注意事項[RD77GF] (12.9 / 印刷 p.653 / 原本 p.655)

- ユニット拡張パラメータのファイルの書込みは，ユニット拡張パラメータ格納先設定と同じ書込み先を指定してください。異なる書込み先を指定した場合，書き込んだユニット拡張パラメータが有効になりません。また，以下の条件でシンプルモーションユニットにてワーニング「ユニット拡張パラメータ格納先警告」(ワーニングコード: 0B0FH)が発生します。
  - ユニット拡張パラメータ格納先設定が「シンプルモーションユニット」で，CPUユニット側のユニット拡張パラメータの変更を検出した場合。(電源投入時に警告を出力します)
  - ユニット拡張パラメータ格納先設定が「CPUユニット」で，シンプルモーションユニット側のフラッシュ ROMに書込みが生じた場合。(パラメータ初期化，フラッシュ ROM書込み要求時に警告を出力します。また，電源投入時にシンプルモーションユニット側のフラッシュ ROMはCPUユニット側のユニット拡張パラメータで上書きされます。)
- ユニット拡張パラメータ格納先設定にて設定した格納先にユニット拡張パラメータのファイルがない場合やファイルサイズが4MBを超える場合は，エラー「ユニット拡張パラメータ取得異常(エラーコード: 1937H)」が電源投入時に発生します。
- CPUユニットのSDメモリカードに格納したユニット拡張パラメータを使用する場合は，ユニット拡張パラメータ格納先設定を「CPUユニット」に設定してください。また，CPUユニットの"メモリカードパラメータ"にて，ユニット拡張パラメータを使用できるように設定してください。

##### (7)エンジニアリングツールの要求によるフラッシュ ROM書込み (12.9 / 印刷 p.656 / 原本 p.658)

エンジニアリングツールの[フラッシュ ROM書込み要求]によって，以下の転送処理を行います。この転送処理は，上記(6)と同様の転送処理です。

> **Point**

##### (10)サーボパラメータの転送[RD77MS] (12.9 / 印刷 p.656-660 / 原本 p.658-662)

バッファメモリ／内部メモリに格納されていた「サーボパラメータ」を，下記のタイミングによりサーボアンプに転送処理を行います。

- サーボアンプとの通信開始時に転送する。バッファメモリの「サーボパラメータ」をサーボアンプに転送する。
- "[Pr.155]Qシリーズ互換機能設定"のbit0がONの場合，シーケンサレディ信号[Y0]がOFF → ONされると，バッファメモリ／内部メモリエリアの「サーボパラメータ」を保存用内部メモリとサーボアンプに転送します。サーボパラメータ転送完了後，準備完了信号[X0]がONします。シーケンサレディ信号[Y0]ON → 準備完了信号[X0]がONするまでの時間が，転送機能を無効にしている場合よりも延びます。

(原本では上記の直後に、見出し・説明文の無い枠で次のパラメータ一覧が掲載されている)

- 「オートチューニングモード(PA08)」
- 「オートチューニング応答性(PA09)」
- 「フィードフォワードゲイン(PB04)」
- 「負荷慣性モーメント比／負荷質量比(PB06)」
- 「モデル制御ゲイン(PB07)」
- 「位置制御ゲイン(PB08)」
- 「速度制御ゲイン(PB09)」
- 「速度積分補償(PB10)」
- 「速度微分補償(PB11)」

> **Point**
> - サーボアンプへパラメータ転送後(サーボアンプのLED表示は，"b_"，"C_"，または"d_")，プログラムもしくはエンジニアリングツールにて「回転方向選択／移動方向選択(PA14)」を変更し，シーケンサレディ信号[Y0]をONすると，ワーニング「SSCNET通信異常」(ワーニングコード: 093EH)が発生します。「回転方向選択／移動方向選択(PA14)」を変更した場合は，サーボアンプへパラメータ転送を行ってください。
> - シーケンサレディ信号[Y0]OFF → ON時のサーボパラメータ転送機能によるパラメータ転送実行中にサーボアンプとの通信が切れた場合，該当軸のパラメータ転送処理は中断されます。また，シーケンサレディ信号[Y0]OFF → ON時のサーボパラメータ転送機能によるパラメータ転送途中に，転送処理が中断された軸があった場合，準備完了信号[X0]はONしません。
>   上記の場合は，再度サーボアンプとの通信を確立させ，シーケンサレディ信号[Y0]のOFF → ON操作を行ってください。

###### ■サーボアンプとの通信開始について (12.9 / 印刷 p.657 / 原本 p.659)

サーボアンプとの通信は，下記の条件がともに成立している場合に，有効となります。

- シンプルモーションユニットとサーボアンプの電源が投入されている。
- シンプルモーションユニットのバッファメモリエリア内のサーボネットワーク構成パラメータ"[Pr.100]接続機器"に「0」以外の値が設定されている。

電源投入時およびCPUユニットリセット時は，フラッシュ ROM／保存用内部メモリに格納されているデータがバッファメモリ／内部メモリに転送されます。

したがって，保存用内部メモリに格納されているサーボネットワーク構成パラメータ"[Pr.100]接続機器"≠「0」，かつサーボアンプ，シンプルモーションユニットの順に立上がった場合には(CPUユニットのRUN LEDが点灯する以前でも)，サーボアンプとの通信を開始し，保存用内部メモリに格納されていたサーボパラメータがサーボアンプへ転送されます。

###### ■プログラム／エンジニアリングツールから設定したサーボパラメータをサーボアンプへ転送する方法 (12.9 / 印刷 p.657 / 原本 p.659)

保存用内部メモリに格納されているサーボネットワーク構成パラメータ"[Pr.100]接続機器"の値を「0」としてください。(工場出荷値は「0」)

その後，電源投入，もしくはCPUユニットリセットにより保存用内部メモリに格納されているサーボネットワーク構成パラメータ"[Pr.100]接続機器"の値「0」が有効となり，サーボアンプとの通信を開始しません。

ただし，プログラム／エンジニアリングツールからサーボネットワーク構成パラメータ("[Pr.100]接続機器"の値を「0」以外)を設定したあと，シーケンサレディ信号[Y0]をOFF → ONすると，サーボアンプとの通信を開始します。

###### ■保存用内部メモリに書き込んだサーボパラメータをサーボアンプへ転送する方法 (12.9 / 印刷 p.657 / 原本 p.659)

サーボパラメータをバッファメモリ／内部メモリに設定し，フラッシュ ROM書込みを行います。

その後，電源投入，もしくはCPUユニットリセットにより保存用内部メモリに格納されているサーボパラメータがバッファメモリ／内部メモリに転送されます。

サーボアンプへ転送するサーボパラメータを保存用内部メモリに書込み後は，プログラム／エンジニアリングツールからサーボパラメータの設定は不要となります。

###### ■サーボパラメータ転送後にサーボパラメータを個別に変更する方法 (12.9 / 印刷 p.659 / 原本 p.661)

以下の軸制御データにてシンプルモーションユニットからサーボアンプのパラメータを個別に変更することができます。

n: 軸No. - 1

| 設定項目 | | 設定内容 | バッファメモリアドレス |
|---|---|---|---|
| [Cd.130] | サーボパラメータ読み出し／書き込み要求 | サーボパラメータの書込み要求を設定する。<br>"[Cd.131]パラメータNo.(変更するサーボパラメータの設定)"，"[Cd.132]変更データ"を設定後，「0001H」または「0002H」を設定する。<br>0001H: 1ワード書込み要求<br>0002H: 2ワード書込み要求 | 4354+100n |
| [Cd.131] | パラメータNo.(変更するサーボパラメータの設定) | 変更するサーボパラメータを設定する。 | 4355+100n |
| [Cd.132] | 変更データ | "[Cd.131]パラメータNo.(変更するサーボパラメータの設定)"で指定したサーボパラメータの変更値を設定する。 | 4356+100n<br>4357+100n |

> **Point**
> - シンプルモーションユニットのサーボパラメータエリア(保存用内部メモリおよびバッファメモリ／内部メモリ)とサーボアンプのパラメータの両方を変更します。
> - サーボパラメータのうち，サーボアンプの電源再投入にて有効となるパラメータを変更した場合は，変更後，サーボアンプの電源を2回再投入する必要があります。(パラメータを設定すると，サーボアンプのRAM上のデータは変更されますが，サーボアンプのEEPROMのデータは変更されません。サーボアンプの電源再投入時により，サーボアンプでは変更前のEEPROMのデータがRAMに上書きされ立上がります。その後，シンプルモーションユニットとのイニシャル交信にてサーボアンプのEEPROMに変更したデータが書き込まれるため，もう一度サーボアンプの電源を再投入することで，RAMデータへも変更データが反映されます。)
> - 以下の状態で，"[Cd.130]サーボパラメータ読み出し／書き込み要求"に「0001H: 1ワード書込み要求」または「0002H: 2ワード書込み要求」を設定すると，「0003H: 読出し／書込み失敗」となります。
>   - サーボアンプとの通信が確立していない，または通信異常である。
>   - "[Cd.131]パラメータNo."が設定範囲外である。
>   - 指定のワード数の書込みにサーボアンプが対応していない。
