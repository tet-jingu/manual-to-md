### 12.5 ブロック始動データ (12.5 / 印刷 p.552-555 / 原本 p.554-557)

ブロック始動データの設定項目[Da.11]～[Da.14]の説明の前に，ブロック始動データの構成を以下に示します。

シンプルモーションユニットのバッファメモリに格納されるブロック始動データは，下記のような構成になっています。

【図】ブロック始動データの構成(12.5 / 印刷 p.552 / 原本 p.554)
- 「1ポイント目」「2ポイント目」…「50ポイント目」の表が重なった図。各表は「設定項目」「バッファメモリアドレス*1」の2列で、左端に「始動ブロック0」と表記されている。
- 1ポイント目(太枠で囲まれた部分が1つのブロック始動データ):
  - 1ワード目(b15〜b0。b15, b8b7, b0 の目盛り): 上位側が[Da.11]形態、下位側が[Da.12]始動データNo. → バッファメモリアドレス 22000＋400n
  - 2ワード目(b15〜b0。b15, b8b7, b0 の目盛り): b15〜b8 が[Da.13]特殊始動命令、b7〜b0 が[Da.14]パラメータ → バッファメモリアドレス 22050＋400n
- 2ポイント目: 22001＋400n / 22051＋400n
- 50ポイント目: 22049＋400n / 22099＋400n
- n: 軸No. - 1
- 図の右側の説明文(原文):
  - ●ブロック始動データは左に示すバッファメモリアドレスに，軸ごとに50ポイントまで設定(格納)することができます。
  - ●1つのブロック始動データは［太枠］の項目で構成されます。
  - ●軸ごとに始動ブロック0～4の5ブロックで構成されます。始動ブロック2～4まではバッファメモリに割り当てられていませんのでエンジニアリングツールにて設定してください。[RD77MS]

\*1 軸17～軸32のバッファメモリアドレスは，下記を参照してください。

以降に，ブロック始動データの設定項目[Da.11]～[Da.14]について説明します。(バッファメモリアドレスは，「1ポイント目のブロック始動データ(ブロックNo.7000)」の場合を示しています。)

> **Point**
> - 「ブロック始動データ」を使った高度な位置決め制御を行う場合，"[Cd.3]位置決め始動番号"に「7000～7004」の番号を設定し，"[Cd.4]位置決め始動ポイント番号"に「1～50」の何ポイント目の「ブロック始動データ」を実行するかを設定します。
> - この「7000～7004」の番号を「ブロックNo.」と呼びます。
> - シンプルモーションユニットでは，「ブロックNo.」ごとに「ブロック始動データ(50ポイント)」，「条件データ(10個)」を設定することができます。

#### [Da.13]特殊始動命令 (12.5 / 印刷 p.555 / 原本 p.557)

「高度な位置決め制御」を行う場合の「特殊始動命令」を設定します。("[Da.12]始動データNo."に設定した位置決めデータをどのように始動するかを設定します。)

| 設定値 | 設定内容 |
|---|---|
| 00H: ブロック始動(通常始動) | 1回の始動によって，任意のブロックの位置決めデータを，設定した順序で実行する。 |
| 01H: 条件始動 | 指定した位置決めデータに対して，「条件データ」に設定した条件判定を行い，条件が成立している場合は「ブロック始動データ」を実行し，成立していない場合は，その「ブロック始動データ」を無視して次のポイントの「ブロック始動データ」を実行する。 |
| 02H: ウェイト始動 | 指定した位置決めデータに対して，「条件データ」に設定した条件判定を行い，条件が成立している場合は「ブロック始動データ」を実行し，成立していない場合は，条件が成立するまで制御を停止(ウェイト)する。 |
| 03H: 同時始動 | 「条件データ」で指定した軸の指定したNo.の位置決めデータを同時に実行(同タイミングで指令を出力)する。最大4軸まで可能。 |
| 04H: 繰り返し始動(FORループ) | 「FORループ」を設定したブロック始動データから，「NEXT」を設定したブロック始動データまでを，設定した回数だけ繰り返して実行する。 |
| 05H: 繰り返し始動(FOR条件) | 「FOR条件」を設定したブロック始動データから，「NEXT」を設定したブロック始動データまでを，「条件データ」に設定した条件が成立するまで繰り返して実行する。 |
| 06H: NEXT始動 | 「04H: 繰り返し始動(FORループ)」，「05H: 繰り返し始動(FOR条件)」を設定した場合，繰り返しの最後に設定する。 |

## 転記時の要確認一覧

- (印刷 p.561 / 原本 p.563) [Da.18]パラメータ 1 の表で、01H〜04H(P2を使わない演算子)の行も 05H/06H と同じ結合セルで「P1 ≤ P2になるように「P1」の値を設定する。P1 > P2になる設定をした場合は…エラー」と書かれている。原文どおり転記した。
- (印刷 p.561 / 原本 p.563) [Da.18]の表の X/Y ビット番号「10H～3FH*1」に付いた脚注*1 が「制御軸数を超える軸番号の設定値は使用不可です。」となっており、ビット番号の注記としては内容が合わない(脚注の流用の可能性)。原文どおり転記した。
- (印刷 p.563 / 原本 p.565) [Da.24]〜[Da.26]の説明表の「同時始動対象軸」列が「2軸補間の場合」「3軸補間の場合」「4軸補間の場合」となっている(同ページのPointは「2軸同時始動」「3軸同時始動」)。「同時始動」の誤記の可能性があるが、原文どおり「補間」とした。
- (印刷 p.552 / 原本 p.554) ブロック始動データ構成図の1ワード目ビット図は目盛りが b15, b8b7, b0 のみで[Da.11]/[Da.12]の境界ビットが明記されていない。境界は印刷 p.554 の設定値一覧のビット図([Da.11]=b15、b14〜b12=0、[Da.12]=b14〜b0)を正として記載した。
- (印刷 p.556 / 原本 p.558) 条件データ構成図で、1ワード目([Da.15]/[Da.16])は各No.とも1アドレス(22100/22110/22190＋400n)のみ記載され、次の項目が +2 から始まる(22101/22111/22191＋400n は図に記載なし)。原文どおりとした。
