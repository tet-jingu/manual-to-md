##### [Pr.43]原点復帰方式 (12.3 / 印刷 p.524 / 原本 p.526)

| 設定値 | 内容 | 参照 |
|---|---|---|
| 0: 近点ドグ式[RD77MS] | 近点ドグONで減速後，零点信号で停止し機械原点復帰完了とする。 | ☞ 38ページ 近点ドグ式[RD77MS] |
| 4: カウント式1[RD77MS] | 近点ドグONで減速後，指定距離を移動し，零点信号で停止し機械原点復帰完了とする。 | ☞ 40ページ カウント式1[RD77MS] |

##### [Pr.44]原点復帰方向 (12.3 / 印刷 p.525 / 原本 p.527)

- 上段の図: 原点が下限リミットのすぐ右(アドレス減少側)にあり，矢印(1)は右から左(アドレス減少方向)へ向く。吹き出し「下限リミット側に原点を設定した場合，原点復帰方向は(1)の矢印の向きとなる。[Pr.44]には「1」を設定する。」

##### [Pr.50]近点ドグON後の移動量設定[RD77MS] (12.3 / 印刷 p.529 / 原本 p.531)

【図】[原点復帰動作] 速度波形と減速距離の算出(12.3 / 印刷 p.529 / 原本 p.531)
- 図中の値: [Pr.8]速度制限値: Vp = 200k pulse/s(点線)，[Pr.46]原点復帰速度: Vz = 10k pulse/s，[Pr.47]クリープ速度: Vc = 1k pulse/s，減速時間: Tb = 300 ms

- 計算式(原本の分数を1行に書き起こし):

  - = 175
