### 3.2 位置決めデータの設定 (3.2 / 印刷 p.136-144 / 原本 p.138-146)

(本ファイルは 3.2 の途中「現在値変更」から始まる。3.2 の冒頭〜「現在値変更」の直前は前ファイルを参照。)

#### 現在値変更 (3.2 / 印刷 p.136 / 原本 p.138)

現在値変更では，停止している軸の"[Md.20]送り現在値"を任意のアドレスに変更する制御を行います。(現在値の変更を行っても"[Md.21]送り機械値"は変更されません。)

現在値の変更には以下に示す2つの方法があります。

- 位置決めデータを使った現在値変更の場合
- 現在値変更用始動番号(No.9003)を使った現在値変更の場合

位置決めデータを使った現在値変更の場合の方法による現在値変更は複数ブロックの連続位置決め中などに使用します。

##### 位置決めデータを使った現在値変更の場合 (3.2 / 印刷 p.136 / 原本 p.138)

「現在値変更」("[Da.2]制御方式" = 現在値変更)では，"[Md.20]送り現在値"を，"[Da.6]位置決めアドレス／移動量"に設定したアドレスに変更します。

###### ■動作図 (3.2 / 印刷 p.136 / 原本 p.138)

以下に現在値変更の動作タイミングを示します。位置決め始動信号をONすると，"[Md.20]送り現在値"を"[Da.6]位置決めアドレス／移動量"に設定した値に変更します。

【図】位置決めデータを使った現在値変更の動作タイミング(3.2 / 印刷 p.136 / 原本 p.138)
- 位置決め始動信号 [Y10, Y11, Y12, Y13]: OFF → ON(パルス状にON後、OFF)
- [Md.20]送り現在値: 位置決め始動信号のONの立上り(破線)のタイミングで 50000 → 0 に変化
- 図中注記(矢印): 「現在値変更の位置決めデータで指定の位置決めアドレスに変更する」
- 図中注記(枠): 「上図は，位置決めアドレスが“0”の場合を示す｡」

###### ■制約事項 (3.2 / 印刷 p.136 / 原本 p.138)

- "[Da.1]運転パターン"に「連続軌跡制御」を設定した場合，エラー「現在値変更不可」(エラーコード: 1A1CH，1A1DH)となり，始動できません。(現在値変更では「連続軌跡制御」を設定できません。)
- 直前の位置決めデータの"[Da.1]運転パターン"に「連続軌跡制御」が設定してある場合の位置決めデータでは，"[Da.2]制御方式"に「現在値変更」を設定できません。(例えば，位置決めデータNo.1の運転パターンが「連続軌跡制御」の場合，位置決めデータNo.2では，「現在値変更」を設定できません。)このような設定をしていた場合，エラー「現在値変更不可」(エラーコード: 1A1CH，1A1DH)となり，減速停止します。
- "[Pr.1]単位設定"に「degree」を設定し，"[Da.6]位置決めアドレス／移動量"に設定した値が設定範囲(0～359.99999 [degree])外の場合，エラー「現在値変更範囲外」(エラーコード: 1997H)となり，始動できません。
- "[Da.6]位置決めアドレス／移動量"に設定した値が，ソフトウェアストロークリミット([Pr.12]，[Pr.13])の設定範囲外の場合，位置決め始動時にエラー「ソフトウェアストロークリミット+」(エラーコード: 1A18H)または「ソフトウェアストロークリミット-」(エラーコード: 1A1AH)となり，始動できません。
- 現在値変更値がソフトウェアストロークリミット範囲外の場合はエラー「ソフトウェアストロークリミット+」(エラーコード: 1994H)または「ソフトウェアストロークリミット-」(エラーコード: 1996H)となります。
- "[Pr.55]原点復帰未完時動作設定"に「0: 位置決め制御を実行しない」を設定し，かつ原点復帰要求がONのときに，位置決めデータ(No.1～600)を使用した現在値変更はできません。エラー「原点復帰未完時始動」(エラーコード: 19A6H)となります。
- 絶対位置システムを使用している場合，電源投入後またはCPUユニットリセット後に行うサーボアンプとの通信開始時，"[Md.20]送り現在値"は"[Md.21]送り機械値"と同一に戻ります。

###### ■制約事項 (3.2 / 印刷 p.138 / 原本 p.140)

- 単位設定が「degree」で，指定した値が設定範囲外の場合はエラー「現在値変更範囲外」(エラーコード: 1997H)になります。
- 指定した値がソフトウェアストロークリミット範囲外である場合はエラー「ソフトウェアストロークリミット+」(エラーコード: 1994H)または「ソフトウェアストロークリミット-」(エラーコード: 1996H)になります。
- 停止指令，MコードON信号ON中は，現在値変更することができません。
- Mコード出力機能は無効となります。
- 絶対位置システムを使用している場合，電源投入後またはCPUユニットリセット後に行うサーボアンプとの通信開始時，"[Md.20]送り現在値"は"[Md.21]送り機械値"と同一に戻ります。

> **Point**
> "[Pr.55]原点復帰未完時動作設定"に「0: 位置決め制御を実行しない」を設定し，かつ原点復帰要求がONのときでも，現在値変更用始動番号(No.9003)を使用した現在値変更は可能です。

###### ■現在値変更手順 (3.2 / 印刷 p.138 / 原本 p.140)

1. 現在値を"[Cd.9]現在値変更値"に書き込む
2. [9003]を"[Cd.3]位置決め始動番号"に書き込む
3. 位置決め始動信号をONする

###### ■動作例 (3.2 / 印刷 p.139 / 原本 p.141)

【図】現在値変更用始動番号(No.9003)の始動用タイムチャート(3.2 / 印刷 p.139 / 原本 p.141)
- 速度波形 V-t: 通常の位置決め(台形: 加速・定速・減速)を行い停止した後、「データNo.9003の始動」(図中注記)が行われる。No.9003 の始動では速度波形は出ない(軸は移動しない)
- シーケンサレディ信号 [Y0]: 最初にON。準備完了信号 [X0] は [Y0] のONを受けてON(矢印)。以降両信号ともON継続
- 1回目(通常の位置決め):
  - 位置決め始動信号 [Y10] ON → 始動完了信号([Md.31]ステータス: b14)ON、BUSY信号 [X10] ON(矢印)。同タイミングで速度波形が立上る
  - 速度が0になる(位置決め完了)タイミングで BUSY信号 [X10] OFF → 位置決め完了信号([Md.31]ステータス: b15)ON(矢印)
  - その後 位置決め始動信号 [Y10] OFF → 始動完了信号 OFF(矢印)。位置決め完了信号は一定時間ON後にOFF
- 2回目(データNo.9003の始動):

#### JUMP命令 (3.2 / 印刷 p.141 / 原本 p.143)

JUMP命令では，「連続位置決め制御」時もしくは「連続軌跡制御」時に，位置決めデータに設定した位置決めデータNo.へJUMPする制御を行います。

JUMP命令には以下に示す2つのJUMPがあります。

| JUMP命令 | 内容 |
|---|---|
| 無条件JUMP | JUMP命令の実行条件を設定しない場合(条件データNo.に0を設定した場合) |
| 条件付きJUMP | JUMP命令の実行条件を設定する場合(条件は「高度な位置決め制御」で使用する「条件データ」に設定します。) |

JUMP命令を使用することによって，「連続位置決め制御」時もしくは「連続軌跡制御」時に，同一位置決め制御の繰り返しや，実行条件による位置決めデータNo.の選択ができます。

##### 動作 (3.2 / 印刷 p.141 / 原本 p.143)

###### ■無条件JUMPの場合 (3.2 / 印刷 p.141 / 原本 p.143)

JUMP命令を無条件で実行し，"[Da.9]ドウェルタイム／JUMP先位置決めデータNo."に設定された位置決めデータNo.にジャンプします。

###### ■条件付きJUMPの場合 (3.2 / 印刷 p.141 / 原本 p.143)

JUMP命令の実行条件は，ブロック始動の条件データを使用します。

- ブロック位置決め(No.7000～7004始動の場合): 各ブロックの条件データを使用します。
- 位置決めデータNo.1～600を始動した場合: 始動ブロック0の条件データを使用します。
- JUMP命令の"[Da.10]Mコード／条件データNo.／LOOP～LEND繰り返し回数／ピッチ数"に設定した実行条件が成立している場合，JUMP命令を実行し，"[Da.9]ドウェルタイム／JUMP先位置決めデータNo."に設定された位置決めデータNo.にジャンプします。
- JUMP命令の"[Da.10]Mコード／条件データNo.／LOOP～LEND繰り返し回数／ピッチ数"に設定した実行条件が成立していない場合，JUMP命令を無視し，次の位置決めデータNo.を実行します。

##### 制約事項 (3.2 / 印刷 p.141 / 原本 p.143)

- 条件付きJUMP命令使用時は，JUMP命令の位置決めデータNo.から4つ前の位置決めデータを実行するまでに，JUMP命令の実行条件を成立させてください。JUMP命令の4つ前の位置決め制御を行う前にJUMP命令の実行条件が成立していない場合は，JUMP命令の実行条件が成立していないものとして処理されます。(シンプルモーションユニットは連続軌跡制御／連続位置決め制御実行中に，4つ後の位置決めデータNo.の位置決めデータの計算を行っています。)
- JUMP命令は，運転パターンが「連続位置決め制御」または「連続軌跡制御」の位置決めデータNo.に設定してください。運転パターンが「位置決め終了」の位置決めデータNo.には設定できません。
- 条件付きJUMP命令のみで，条件が成立するまでループするような位置決め制御はできません。JUMP命令でループを行った場合，ループ中は軸動作状態が解析中となり，他の軸の位置決めデータ解析(始動)は行いませんので，JUMP命令の飛び先には，制御方式がJUMP命令，NOP命令以外の位置決めデータを指定してください。
