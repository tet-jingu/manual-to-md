## 14 トラブルシューティング (14章 / 印刷 p.689 / 原本 p.691)

シンプルモーションユニットを使用する上で発生するエラーの内容，およびトラブルシューティングについて説明します。

### 14.1 トラブルシューティング手順 (14.1 / 印刷 p.689-692 / 原本 p.691-694)

トラブルが発生した場合，下記の順にトラブルシューティングを実施します。

1. 各ユニットが正しく装着されているか確認してください。<br>(マニュアル: MELSEC iQ-R ユニット構成マニュアル)
2. 電源ユニット，CPUユニットのLEDを確認してください。<br>(マニュアル: MELSEC iQ-R CPUユニットユーザーズマニュアル(スタートアップ編))
3. 各ユニットのLEDの点灯状態を確認し，ユニットに異常がないか確認してください。(☞ 689ページ LEDによる確認)
4. エンジニアリングツールのユニット診断を使用して，ユニットに異常がないか確認してください。(☞ 692ページ ユニット状態の確認)

#### LEDによる確認 (14.1 / 印刷 p.689-691 / 原本 p.691-693)

LEDの表示状態を確認することで，エンジニアリングツールが無い状態での一次診断を行うことができ，トラブルの発生原因の範囲を狭めることが可能となります。
各種LEDとシンプルモーションユニットの状態の対応関係を下記に示します。

### 14.3 エラーとワーニングの内容 (14.3 / 印刷 p.695-698 / 原本 p.697-700)

#### エラーの種類 (14.3 / 印刷 p.695 / 原本 p.697)

シンプルモーションユニットが検出するパラメータ設定範囲エラー，運転始動時／運転中のエラーとサーボアンプが検出するエラーがあります。

##### シンプルモーションユニットが検出するパラメータ設定範囲エラー (14.3 / 印刷 p.695 / 原本 p.697)

電源ON時およびシーケンサレディ信号[Y0]の立上がり(OFF → ON)時にパラメータのチェックを行い，パラメータの設定内容に誤りがあった場合エラーとなります。
本エラーが発生した場合，準備完了信号[X0]はONしません。
本エラーを解除するには，設定エラーのパラメータを正しい値に修正後，シーケンサレディ信号[Y0]をONしてください。

##### シンプルモーションユニットが検出する運転始動時／運転中のエラー (14.3 / 印刷 p.695 / 原本 p.697)

位置決め制御，JOG運転，手動パルサ運転時などの運転始動時／運転中に発生するエラーです。補間運転時に軸エラーが発生した場合，エラーコードは基準軸と補間相手軸の両方に格納されます。
ただし，下記の場合は位置決め始動データテーブルの各ポイントに設定されている位置決めデータの解析時に，基準軸にのみ軸エラー番号が格納されます。
- 補間相手軸がBUSY中である場合
- 位置決めデータ，パラメータのうち，補間制御に関係しないデータでエラーが発生した場合

また，位置決め運転の同時始動時にエラーが発生した場合，同時始動がかかる前と同時始動がかかった後で軸エラーの格納内容が異なります。
- 同時始動にかかる前(軸番号不正，他軸BUSY中など)の場合は，始動軸に対してエラー「同時始動前エラー」(エラーコード: 1990H～1991H)となります。
- 同時始動がかかった後(位置決めデータのエラー，ソフトウェアストロークリミットエラーなど)の場合は，エラーが発生した軸に該当するエラーコードが格納されます。この場合，同時始動を行うことができないことによって，エラーが発生していないすべての軸にエラー「同時始動不可」(エラーコード: 199EH)が格納されます。

エラーが発生した軸は，軸動作状態が「エラー発生中」になります。
運転中にエラーが発生すると，移動中の軸は減速停止し軸動作状態が「エラー発生中」となります。
補間運転中は，片方の軸でもエラーが発生すると両軸とも減速停止します。

##### サーボアンプが検出するエラー (14.3 / 印刷 p.695 / 原本 p.697)

サーボアンプ，サーボモータなどのハードウェア異常やサーボパラメータ異常の場合に発生するエラーです。
エラー発生時はサーボOFFとなり，軸は停止します。
エラー要因を取り除き，エラーリセット，コントローラリセットまたはサーボアンプの電源をOFFにしてから再投入してください。

#### ワーニングの種類 (14.3 / 印刷 p.697 / 原本 p.699)

シンプルモーションユニットが検出するシステムワーニング，軸ワーニングと，サーボアンプが検出するワーニングがあります。

##### シンプルモーションユニットが検出するシステムワーニング (14.3 / 印刷 p.697 / 原本 p.699)

- システム制御データの設定ワーニング: 軸1の軸ワーニングとなります。
- 位置決めデータの設定ワーニング: 各軸の軸ワーニングとなります。ただし，補間制御時の設定ワーニングの場合は基準軸が軸ワーニングとなります。

##### シンプルモーションユニットが検出する軸ワーニング (14.3 / 印刷 p.697 / 原本 p.699)

- 位置決め運転，JOG運転，手動パルサ運転などの運転始動時／運転中に発生したワーニング
- システムワーニングによって発生したワーニング: 軸ワーニングが発生しても軸動作状態は変化しません。

##### サーボアンプが検出するワーニング (14.3 / 印刷 p.697 / 原本 p.699)

サーボアンプ，サーボモータなどのハードウェア異常やサーボパラメータが適切でない場合に発生するワーニングです。
ワーニングによってはサーボOFFしませんが，そのまま放置するとエラ－になったり，正常な運転ができなくなったりします。
ワーニング要因を取り除くとサーボアンプではワーニングが自動的に解除されますが，シンプルモーションユニットではワーニングが発生したままの状態を継続します。
必要に応じてエラーリセットを行ってください。

##### エラー，ワーニングの解除方法 (14.3 / 印刷 p.698 / 原本 p.700)

- "[Md.24]軸ワーニング番号"のクリア
- "[Md.26]軸動作状態"が「エラー発生中」から「待機中」へ移行
- "軸ワーニング検出([Md.31]ステータス: b9)"のOFF

> **Point**
