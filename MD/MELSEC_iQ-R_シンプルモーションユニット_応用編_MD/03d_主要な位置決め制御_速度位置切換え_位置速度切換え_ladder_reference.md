### 3.2 位置決めデータの設定(続き) (3.2 / 印刷 p.116 / 原本 p.118)

#### 速度・位置切換え制御(INCモード) (3.2 / 印刷 p.116-122 / 原本 p.118-124)

「速度・位置切換え制御(INCモード)」("[Da.2]制御方式" ＝ 正転 速・位，逆転 速・位)は，位置決めデータで設定した軸方向について，"[Da.8]指令速度"に設定した速度のパルスを出力し続け，「速度・位置切換え信号」を入力すると，"[Da.6]位置決めアドレス／移動量"に設定した移動量の位置制御を行います。

速度・位置切換え制御(INCモード)には，正転方向へ始動する「正転 速・位」と，逆転方向へ始動する「逆転 速・位」の2種類があります。

速度・位置切換え制御(INCモード)の選択は，詳細パラメータ1"[Pr.81]速度・位置機能選択"で設定します。

n: 軸No. - 1(軸17～軸32の場合は，n: 軸No. - 17)

| 設定項目 | | 設定値 | 設定内容 | バッファメモリアドレス 軸1～軸16 | バッファメモリアドレス 軸17～軸32 |
|---|---|---|---|---|---|
| [Pr.81] | 速度・位置機能選択 | 0 | 速度・位置切換え制御(INCモード) | 34+150n | 1000034+150n |

設定値が0，2以外の場合は，設定値を0とみなしてINCモードで動作します。

###### ■動作例 (3.2 / 印刷 p.117 / 原本 p.119)

【図】速度・位置切換え制御(INCモード)の速度波形と信号タイミング(3.2 / 印刷 p.117 / 原本 p.119)
- 速度波形: 始動後 "[Da.8]指令速度" まで加速し定速で運転(速度制御)。速度・位置切換え信号のON時点から位置制御に移り、"[Da.6]位置決めアドレス／移動量"に設定した移動量(図の斜線部)を移動して減速停止。その後ドウェルタイム。
- 区間表示: 速度制御 → 位置制御 → ドウェルタイム
- 位置決め始動信号[Y10, Y11, Y12, Y13]: OFF→ON で始動。ドウェルタイム終了後にOFF。
- BUSY信号[X10, X11, X12, X13]: 位置決め始動信号のONを受けてON。ドウェルタイム終了時にOFF。
- 位置決め完了信号([Md.31]ステータス: b15): ドウェルタイム終了時(BUSY信号OFFと同じタイミング)にON、位置決め始動信号OFFを受けてOFF(図の矢印による)。
- 速度・位置切換え信号: 速度制御中の1点でOFF→ON(短いパルス)。このON時点が速度制御→位置制御の境界。
- [Cd.24]速度・位置切換え許可フラグ: 位置決め始動信号のONより前にOFF→ON。ドウェルタイム終了時(BUSY信号OFFのタイミング)にOFF。
- 速度制御中フラグ([Md.31]ステータス: b0): BUSY信号ONと同時にON、速度・位置切換え信号ONの時点(位置制御への切換え)でOFF。
- [Cd.45]速度⇔位置切換えデバイス選択: 値 0。図中注記「位置決め始動時に設定内容を取込みます。」

"[Pr.1]単位設定"が「2: degree」，"[Pr.21]速度制御時の送り現在値"が「1: 送り現在値更新あり」の設定で"[Da.2]制御方式"「正転 速・位」実行中に，送り現在値90.00000 [degree]の位置で速度・位置切換え信号が入力された場合の動作を以下に示します。
("[Da.6]位置決めアドレス／移動量"の設定値は270.00000 [degree])

【図】degree単位での動作例(円周図)(3.2 / 印刷 p.117 / 原本 p.119)
- 左図: 0.00000° から正転し、90.00000° の位置で「速度・位置切換え信号ON」。
- 右図: 90.00000° から270.00000 移動し、図中記載「90.00000 + 270.00000 = 360.00000 = 0.00000 [degree]で停止」。

##### 動作タイミングと処理時間 (3.2 / 印刷 p.118-119 / 原本 p.120-121)

###### ■動作例 (3.2 / 印刷 p.118 / 原本 p.120)

【図】速度・位置切換え制御(INCモード)の動作タイミングと処理時間(3.2 / 印刷 p.118 / 原本 p.120)
- 位置決め始動信号[Y10, Y11, Y12, Y13]: ONで始動。位置決め完了後(BUSY信号OFFの後)にOFF。
- BUSY信号[X10, X11, X12, X13]: 位置決め始動信号ONから t1 後にON。位置制御での停止から t5 後(位置決め完了信号ONと同時)にOFF。
- MコードON信号([Md.31]ステータス: b12)(WITHモード): BUSY信号ONと同時にON。[Cd.7]MコードOFF要求のONから t2 後にOFF。
- [Cd.7]MコードOFF要求: MコードON信号をOFFさせるためにON、MコードON信号OFFと同時にOFF。
- 始動完了信号([Md.31]ステータス: b14): BUSY信号ONと同時にON。位置決め始動信号OFFから t3 後にOFF。
- [Md.26]軸動作状態: 待機中 → 速度制御中 → 位置制御中 → 待機中。速度制御中→位置制御中の切換えは速度・位置切換え指令ONから t6 後。位置制御中→待機中はBUSY信号OFFのタイミング。
- 位置決め動作: BUSY信号ONから t4 後に加速開始。速度制御区間 → 位置制御区間 → 減速停止。図中注記「速度・位置切換え信号がONするまでは速度制御を行います。」「位置制御の移動量は外部からの速度・位置切換え信号の入った時点からとなります。」
- 速度・位置切換え指令: 速度制御中に短いパルスでON。そこから t6 後に位置制御へ切換え。
- [Cd.23]速度・位置切換え制御移動量変更レジスタ: 図では、始動時点から速度制御中は一方のレベル、位置制御への切換え時点(t6 経過時点)で値が切り換わる線で描かれている(始動前は破線)。
- 位置決め完了信号([Md.31]ステータス: b15): 始動前は破線(前状態)、始動時にOFF。位置制御の停止から t5 後にON、ON後 t7 経過でOFF。
- MコードON信号([Md.31]ステータス: b12)(AFTERモード): 位置決め完了信号ONと同時にON。[Cd.7]MコードOFF要求ONから t2 後にOFF。
- 原点復帰完了フラグ([Md.31]ステータス: b4): 始動前は破線(前状態)、始動時(BUSY信号ONのタイミング)にOFF。

##### 位置制御の移動量の変更 (3.2 / 印刷 p.121 / 原本 p.123)

「速度・位置切換え制御(INCモード)」では，速度制御中に位置制御での移動量を変更することができます。

- 速度・位置切換え制御(INCモード)の速度制御中に，位置制御での移動量を変更することができます。速度・位置切換え制御(INCモード)の速度制御中以外のときに移動量の変更要求があった場合，移動量の変更要求は無視されます。
- 速度制御中に，プログラムによって「変更後の移動量」を，"[Cd.23]速度・位置切換え制御移動量変更レジスタ"に格納します。速度・位置切換え信号のON時に，"[Cd.23]速度・位置切換え制御移動量変更レジスタ"の内容が位置制御の移動量となります。
- 外部からの速度・位置切換え信号入力で位置制御に切り換わった時点からの移動量が軸モニタエリアの"[Md.29]速度・位置切換え制御の位置決め移動量"に格納されます。

【図】位置制御の移動量の変更タイミング(3.2 / 印刷 p.121 / 原本 p.123)
- 速度波形: 「速度・位置切換え制御(INCモード)始動」で加速→定速(速度制御)、速度・位置切換え信号ONで位置制御(斜線部)→減速停止。その後、別の「位置制御始動」で次の位置決め(斜線部)。
- 「移動量変更可」の区間: 速度・位置切換え制御(INCモード)始動から速度・位置切換え信号ONまで。
- 速度・位置切換え信号: 速度制御中に OFF→ON(短いパルス)。
- [Cd.23]速度・位置切換え制御移動量変更レジスタ: 0 → P2(移動量変更可の区間内で書込み) → P3(速度・位置切換え信号ON後に書込み)。図中注記「P2が位置制御の移動量となる」「速度・位置切換え信号ON後の設定は無視されます。」
- 速度・位置切換えラッチフラグ([Md.31]ステータス: b1): 速度・位置切換え制御(INCモード)始動時に ON→OFF、速度・位置切換え信号ONでON、次の位置制御始動時にOFF。

> **Point**
> - プログラムで"[Cd.23]速度・位置切換え制御移動量変更レジスタ"にデータを書き込むだけで，移動量の変更要求があったことが認識されます。
> - 変更後の移動量が有効になるのは，速度・位置切換え制御(INCモード)実行後で，速度・位置切換え信号が入力される前までです。
> - 軸モニタエリアの「速度・位置切換えラッチフラグ」([Md.31]ステータス: b1)により，位置制御での移動量変更可否インタロック条件として使用できます。

##### 制約事項 (3.2 / 印刷 p.122 / 原本 p.124)

- "[Da.1]運転パターン"に「連続軌跡制御」を設定した場合，エラー「連続・連続軌跡制御不可」(エラーコード: 1A1EH～1A20H)となり，始動できません。
- 直前の位置決めデータの"[Da.1]運転パターン"に「連続軌跡制御」が設定してある場合の位置決めデータでは，"[Da.2]制御方式"に「速度・位置切換え制御」を設定できません。(例えば，位置決めデータNo.1の運転パターンが「連続軌跡制御」の場合，位置決めデータNo.2では，「速度・位置切換え制御」を設定できません。)このような設定をしていた場合，エラー「連続・連続軌跡制御不可」(エラーコード: 1A1EH～1A20H)となり，減速停止します。
- "[Da.8]指令速度"にカレント速度(-1)を設定した場合は，エラー「指令速度なし」(エラーコード: 1A12H～1A14H)となります。
- 速度制御中のソフトウェアストロークリミット範囲のチェックは，以下を満足する場合のみ行います。

- 速度安定領域(定速状態)で速度・位置切換え信号をONしてください。指令速度に到達していない状態で切換え信号をONすると，溜りパルス量のバラツキが大きいため，停止位置にバラツキが生じる可能性があります。サーボモータ使用時においては，位置制御に切換え時の"[Md.101]実現在値"を基に推定したモータ位置から"[Da.6]位置決めアドレス／移動量"分移動します。このため加減速中等にONした場合，溜りパルス量のバラツキが大きいため停止位置にバラツキが生じます。また"[Md.29]速度・位置切換え制御の位置決め移動量"が同じでも"[Da.8]指令速度"が異なると，溜りパルス量が変化するため停止位置が変化します。

##### 速度制御の指令速度の変更 (3.2 / 印刷 p.134 / 原本 p.136)

「位置・速度切換え制御」では，位置制御中に速度制御での指令速度を変更することができます。

- 位置・速度切換え制御の位置制御中に速度制御での指令速度を変更することができます。位置・速度切換え制御の位置制御中以外のときに指令速度の変更要求があった場合，指令速度の変更要求は無視されます。
- 位置制御中に，プログラムによって，「変更後の指令速度」を"[Cd.25]位置・速度切換え制御速度変更レジスタ"に格納します。位置・速度切換え信号のON時に，"[Cd.25]位置・速度切換え制御速度変更レジスタ"の内容が速度制御の指令速度となります。

【図】速度制御の指令速度の変更タイミング(3.2 / 印刷 p.134 / 原本 p.136)
- 速度波形: 「位置・速度切換え制御始動」で加速→定速(位置制御、斜線部)。位置・速度切換え信号ONで速度制御に移り、変更後の指令速度(V2、元より低い速度)まで減速して定速運転。停止信号ONで減速停止。その後、別の「位置制御始動」で次の位置決め(斜線部)。
- 「速度変更可」の区間: 位置・速度切換え制御始動から位置・速度切換え信号ONまで。
- 位置・速度切換え信号: 位置制御中に OFF→ON(短いパルス)。
- [Cd.25]位置・速度切換え制御速度変更レジスタ: 0 → V2(速度変更可の区間内で書込み) → V3(位置・速度切換え信号ON後に書込み)。図中注記「V2が速度制御の指令速度となる」「位置・速度切換え信号ON後の設定は無視されます。」
- 位置・速度切換えラッチフラグ([Md.31]ステータス: b5): 位置・速度切換え制御始動時に ON→OFF、位置・速度切換え信号ONでON、次の位置制御始動時にOFF。
- 停止信号: 速度制御中に OFF→ON(短いパルス)。このONで減速停止。

> **Point**
> - プログラムで"[Cd.25]位置・速度切換え制御速度変更レジスタ"にデータを書き込むだけで，指令速度の変更要求があったことが認識されます。
> - 変更後の指令速度が有効になるのは，位置・速度切換え制御実行後で，位置・速度切換え信号が入力される前までです。
> - 軸モニタエリアの「位置・速度切換えラッチフラグ」([Md.31]ステータス: b5)により，速度制御での速度変更可否インタロック条件として使用できます。

##### 制約事項 (3.2 / 印刷 p.135 / 原本 p.137)

- "[Da.1]運転パターン"に「連続位置決め制御」，「連続軌跡制御」を設定した場合はエラー「連続・連続軌跡制御不可」(エラーコード: 1A1EH～1A20H)となり，始動しません。
- 直前の位置決めデータの"[Da.1]運転パターン"に「連続軌跡制御」が設定してある場合の位置決めデータでは，"[Da.2]制御方式"に「位置・速度切換え制御」を設定できません。(例えば，位置決めデータNo.1の運転パターンが「連続軌跡制御」の場合，位置決めデータNo.2では，「位置・速度切換え制御」を設定できません。)このような設定をしていた場合，エラー「連続・連続軌跡制御不可」(エラーコード: 1A1EH～1A20H)となり，減速停止します。
- 速度制御中のソフトウェアストロークリミット範囲のチェックは，"[Pr.21]速度制御時の送り現在値"に，「1: 送り現在値の更新を行う」を設定している場合のみ行います。また，単位が「degree」の場合は，ソフトウェアストロークリミット範囲のチェックを行いません。
- 位置制御の始点アドレスまたは終点アドレスがソフトウェアストロークリミット範囲を超えている場合は始動時にエラー「ソフトウェアストロークリミット+」(エラーコード: 1993H)または「ソフトウェアストロークリミット-」(エラーコード: 1995H)となり，始動しません。
- 指定された移動量分移動するまでに位置・速度切換え信号が入力されなかった場合は，減速停止します。また，位置制御での自動減速中に位置・速度切換え信号の入力があった場合は，再度指令速度まで加速して速度制御を続行します。停止信号による減速停止時に位置・速度切換え信号が入力された場合は，速度制御に切り換わり停止します。再始動指令によって，速度制御で再始動を行います。
- 指令速度の変更時に，変更された速度が"[Pr.8]速度制限値"以上の場合は，ワーニング「速度制限値オーバー」(ワーニングコード: 0991H)となり，"[Pr.8]速度制限値"で制御を続行します。
- "[Da.6]位置決めアドレス／移動量"の設定値が負の場合，エラー「アドレス範囲外」(エラーコード: 1A30H，1A31H)となります。
- Mコードを使用する場合は，出力タイミングにWITHモードを設定してください。AFTERモードを設定した場合，Mコードは出力されず，MコードON信号もONしません。
