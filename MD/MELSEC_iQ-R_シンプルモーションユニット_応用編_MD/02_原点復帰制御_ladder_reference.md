## 2 原点復帰制御 (2 / 印刷 p.33 / 原本 p.35)

本章では，原点復帰制御の詳細や使い方について説明します。

### 2.1 原点復帰制御の概要 (2.1 / 印刷 p.33 / 原本 p.35)

#### 2つの原点復帰制御 (2.1 / 印刷 p.33 / 原本 p.35)

「原点復帰制御」は，位置決め制御を行う際に起点となる位置(＝原点)を確立し，その起点に向かって位置決めを行う制御です。
電源投入時などシンプルモーションユニットが「原点復帰要求」を要求した場合や位置決め停止後など，原点以外の位置にある機械系を原点に復帰させたいときに使用します。
シンプルモーションユニットでは，原点復帰作業の流れに沿って，下記2つの制御を「原点復帰制御」として定義しています。この2つの原点復帰制御は「原点復帰用パラメータ」を設定し，シンプルモーションユニットにあらかじめ用意された「位置決め始動No.9001」，「位置決め始動No.9002」を"[Cd.3]位置決め始動番号"に設定して，位置決め始動信号をONすることによって実行することができます。

| 原点復帰方法 | 原点復帰方法 動作内容 |
|---|---|
| 機械原点復帰(位置決め始動No.9001) | 機械の原点位置を確立するための原点復帰動作を行います。原点復帰完了で確立された原点を基準に，それ以降の位置決め制御を行います。システムの電源投入時などで，機械原点が確立していない(シンプルモーションユニットの現在値モニタと実際の機械位置が一致していない)時に機械原点復帰を行う必要があります。 |
| 高速原点復帰(位置決め始動No.9002) | 機械原点復帰によって確立した原点へ向かって位置決めを行います。位置決め始動No.9002を指定して始動することで高速原点復帰動作となるため，位置決めデータの設定なしで，原点へ戻る位置決めを行うことができます。 |

「高速原点復帰」を実行するには，事前に「機械原点復帰」を行う必要があります。

> **注意**
> - 絶対位置システムを使用している場合，新規立上げしたとき，またはコントローラ，絶対位置対応モータ等を交換したときは，必ず原点復帰を行ってください。なお，原点復帰要求信号をプログラムなどで確認した後，位置決め動作を行うようにしてください。そのまま位置決め動作を行うと，機械の衝突等の原因となります。

「原点復帰要求フラグ」がONしている間は，シンプルモーションユニット内に格納しているアドレス情報が保証できません。
機械原点復帰を実行し，正常に完了すると「原点復帰要求フラグ」がOFFし，「原点復帰完了フラグ」([Md.31]ステータス: b4)がONします。
以下の場合，シンプルモーションユニットは「原点復帰要求フラグ」([Md.31]ステータス: b3)をONし，機械原点復帰を実行する必要があることを示します。

> **Point**
> 原点復帰要求がONした理由は，イベント履歴に記録されます。[RD77GF]

##### 絶対位置システムでないとき (2.1 / 印刷 p.33 / 原本 p.35)

- 原点復帰要求フラグは，下記の場合にONします。
  - システム電源投入時またはリセット時
  - サーボアンプ電源投入時
  - 機械原点復帰始動時(機械原点復帰が正常に完了しない限り，原点復帰要求フラグはOFFしません。)
- 原点復帰要求フラグは，機械原点復帰完了でOFFします。

##### 絶対位置システムのとき (2.1 / 印刷 p.34 / 原本 p.36)

- 原点復帰要求フラグは，下記の場合にONします。
  - システム立上げ後，一度も機械原点復帰を実施していないとき
  - 機械原点復帰始動時(機械原点復帰が正常に完了しない限り，原点復帰要求フラグはOFFしません。)
  - シンプルモーションユニット内の絶対位置データがメモリ異常などの要因により消失したとき(ワーニング「原点データ不正」(ワーニングコード: 093CH)発生)
  - サーボパラメータの「回転方向選択／移動方向選択(PA14)」が変更されたとき
  - サーボアラーム「絶対位置消失」(アラーム番号: 25)が発生したとき([Md.108]サーボステータス1: b14 ON)(☞ 461ページ 軸モニタデータ)
  - サーボ警告「絶対位置カウンタ警告」(警告番号: E3)が発生したとき([Md.108]サーボステータス1: b14 ON)(☞ 461ページ 軸モニタデータ)
  - サーボアンプやモータエンコーダの変更を検出したとき[RD77GF]
  - 仮想サーボアンプ接続時に前回原点確立時の接続サーボアンプがMR-J4-GFでないとき[RD77GF]
- 原点復帰要求フラグは，機械原点復帰完了でOFFします。

##### 原点復帰を必要としない場合 (2.1 / 印刷 p.34 / 原本 p.36)

原点復帰を行う必要のないシステムでは，「原点復帰要求フラグ」([Md.31]ステータス: b3)を無視して制御を行うことができます。
この場合は，「原点復帰用パラメータ([Pr.43]～[Pr.57])」をすべて初期値，またはエラーにならない値に設定する必要があります。

#### 機械原点復帰の動作概要 (2.2 / 印刷 p.36 / 原本 p.38)

##### 機械原点復帰の動作 (2.2 / 印刷 p.36 / 原本 p.38)

機械原点復帰では，機械原点の確立を行います。
このとき，シンプルモーションユニットやCPUユニット，サーボアンプに記憶されているアドレス情報は使用しません。
機械原点復帰後は，機械的に確立した位置を位置決め制御の起点である「原点」とします。

【図】機械原点復帰の概念図(2.2 / 印刷 p.36 / 原本 p.38)
- モータ(M)直結のボールねじ上のワークが，矢印「機械原点復帰」の方向(モータ側)へ移動する
- ねじ軸上に「原点」(▲)があり，その下側(機械側)に「近点ドグ」が設置されている

機械原点復帰によって行われる「原点」の確立方法は，"[Pr.43]原点復帰方式"によって異なります。
以下に基本的な「機械原点復帰」始動時の動作を示します。

###### ■"[Pr.43]原点復帰方式"が「ドライバ原点復帰式」以外のとき[RD77MS] (2.2 / 印刷 p.36 / 原本 p.38)

1. 機械原点復帰を始動する。
2. 原点復帰用パラメータ([Pr.43]～[Pr.57])によって設定した方向や速度で動作を開始する。
3. "[Pr.43]原点復帰方式"に設定した方式で「原点」を確立し，停止する。
   ☞ 37ページ 機械原点復帰の原点復帰方式～45ページ スケール原点信号検出式[RD77MS]
4. "[Pr.45]原点アドレス"に「a」を設定していた場合，位置をモニタしている"[Md.20]送り現在値"と"[Md.21]送り機械値"に現在位置として「a」を格納する。
5. 機械原点復帰が完了する。

> **Point**
> ワークの移動エリアからの原点位置が常時同一の方向でない場合(原点を機械の上限または下限付近に設定しない場合)は，原点復帰リトライ機能を使用してください。
> 原点復帰リトライ機能を使用しないと機械原点復帰が完了しない可能性があります。

###### ■"[Pr.43]原点復帰方式"が「ドライバ原点復帰式」のとき (2.2 / 印刷 p.36 / 原本 p.38)

1. サーボアンプの原点復帰パラメータを設定する。*1
2. 機械原点復帰を始動する。
3. サーボアンプ側に設定した方向や速度で動作を開始する。
4. 「原点」を確立し，停止する。
5. "[Pr.45]原点アドレス"に「a」を設定していた場合，位置をモニタしている"[Md.20]送り現在値"と"[Md.21]送り機械値"に現在位置として「a」を格納する。
6. 機械原点復帰が完了する。

- *1 [RD77GF]
  必要に応じ，サーボトランジェント伝送機能を使用して設定変更を行う。設定の変更方法はサーボアンプの技術資料集を参照してください。

> **Point**
> ドライバ原点復帰式における「原点」の確立方法は，サーボアンプの設定によって異なります。詳細はサーボアンプの技術資料集またはマニュアルを参照してください。

#### 機械原点復帰の原点復帰方式 (2.2 / 印刷 p.37 / 原本 p.39)

機械原点復帰では，位置決めシステムの構成や用途によって，機械原点の確立方法(原点位置や機械原点復帰完了の判定方法)を指定します。
この原点復帰方式には，以下に示す方式があります。(原点復帰方式は，原点復帰用パラメータで設定する項目の1つで，原点復帰基本パラメータの"[Pr.43]原点復帰方式"に設定します。)

| [Pr.43]原点復帰方式 | 動作内容 |
|---|---|
| 近点ドグ式[RD77MS] | 近点ドグのOFF → ONによって減速を開始する。("[Pr.47]クリープ速度"まで減速する)<br>近点ドグがON → OFFとなったあと，一度停止し，その後再度動き始め，エンコーダの最初の零点信号で停止し，機械原点復帰完了とする。<br>その位置を原点とする。 |
| カウント式1[RD77MS] | 近点ドグのOFF → ONによって減速を開始し"[Pr.47]クリープ速度"で移動する。<br>近点ドグがOFF → ONとなった位置から，"[Pr.50]近点ドグON後の移動量設定"に設定した距離を移動したあと，一度停止し，その後再度動き始め，エンコーダの最初の零点で停止し，機械原点復帰完了とする。 |
| カウント式2[RD77MS] | 近点ドグのOFF → ONによって減速を開始し"[Pr.47]クリープ速度"で移動する。<br>近点ドグがOFF → ONとなった位置から，"[Pr.50]近点ドグON後の移動量設定"に設定した距離を移動した位置で停止し，機械原点復帰完了とする。 |
| データセット式[RD77MS] | 機械原点復帰を行ったときの位置を原点とする。<br>送り現在値，送り機械値が原点アドレスに書き換わる。 |
| スケール原点信号検出式[RD77MS] | 近点ドグのOFF → ONによって，"[Pr.44]原点復帰方向"と逆方向へ"[Pr.46]原点復帰速度"で移動し，最初の零点信号の検出で一度減速停止する。その後，"[Pr.44]原点復帰方向"へ"[Pr.47]クリープ速度"で移動し，検出した最寄りの零点で停止し，機械原点復帰完了とする。 |
| ドライバ原点復帰式 | ドライバ原点復帰式の詳細は，以下を参照してください。[RD77MS]<br>☞ 770ページ オリエンタルモーター株式会社製ステッピングモーターユニットαSTEP/5相<br>☞ 780ページ 株式会社アイエイアイ製IAI電動アクチュエータ用コントローラ<br>サーボアンプを原点復帰モードに切換え，サーボアンプに設定された原点復帰を起動します。原点復帰完了後，サーボアンプを元の制御モードに戻します。[RD77GF] |

◎: 必須，○: 必要に応じて使用，—: 不要

| [Pr.43]原点復帰方式 | 制御に必要な信号: 近点ドグ | 制御に必要な信号: 零点信号 | 制御に必要な信号: 上／下限リミット |
|---|---|---|---|
| 近点ドグ式[RD77MS] | ◎ | ◎ | ○ |
| カウント式1[RD77MS] | ◎ | ◎ | ○ |
| カウント式2[RD77MS] | ◎ | — | ○ |
| データセット式[RD77MS] | — | — | — |
| スケール原点信号検出式[RD77MS] | ◎ | ◎ | — |

- *1 制御に必要な信号はサーボアンプの原点復帰仕様を確認してください。

> **Point**
> クリープ速度
> 微速。高速から急激に停止させると停止精度が悪いため，低い速度に切り換える必要があります。この速度は，"[Pr.47]クリープ速度"に設定します。

#### 近点ドグ式[RD77MS] (2.2 / 印刷 p.38 / 原本 p.40)

原点復帰方式「近点ドグ式」の動作概要を以下に示します。

##### 動作図 (2.2 / 印刷 p.38 / 原本 p.40)

【図】近点ドグ式 機械原点復帰のタイミングチャート(2.2 / 印刷 p.38 / 原本 p.40)
- 速度波形(V-t): 1.で始動し加速 → "[Pr.46]原点復帰速度"で定速 → 2.「近点ドグONで減速」→ 3.以降"[Pr.47]クリープ速度"で定速 → 近点ドグOFF後(図中A点)いったん速度0まで減速停止 → 再度クリープ速度で動き始め → 4.最初の零点で停止 → 5.完了
- 図中の[ポイント]: 「原点復帰始動後，A点へ移動するまでの間にエンコーダの零点を最低1回は通過する必要があります。」
- [Md.34]近点ドグON後の移動量*1: 近点ドグON(2.)から停止位置(4.)までの距離
- 近点ドグ: 2.でOFF→ON、3.の後(A点)でON→OFF
- 零点信号: パルス状(LOWのパルス)。近点ドグOFFの直前に1回、停止位置(4.)に1回。2つの零点の間隔が「サーボモータ1回転分」
- 図中の注記: 「近点ドグOFFの位置はなるべく零点信号HIGHの中央になるよう調整してください。近点ドグOFFの位置が零点信号にかかった場合，機械原点復帰の停止位置に，サーボモータ1回転分の誤差が生じることがあります。」
- 機械原点復帰始動(位置決め始動信号): 1.でOFF→ON、完了(5.)後にON→OFF(完了フラグのONを受けてOFFする矢印)
- 原点復帰要求フラグ([Md.31]ステータス: b3): 始動(位置決め始動信号ON)を受けてOFF→ON、5.でON→OFF
- 原点復帰完了フラグ([Md.31]ステータス: b4): 始動時OFF、5.でOFF→ON
- [Md.26]軸動作状態: 待機中 → (1.)原点復帰中 → (5.)待機中
- [Md.34]近点ドグON後の移動量: 不定 → (1.)0 → (5.)*1の値
- [Md.20]送り現在値 / [Md.21]送り機械値: 不定 → (1.)移動した値を格納 → (5.)原点復帰アドレス

1. 機械原点復帰を始動する。
("[Pr.44]原点復帰方向"に設定した方向に，"[Pr.51]原点復帰加速時間選択"で指定した加速をはじめ，"[Pr.46]原点復帰速度"で移動する。)
2. 近点ドグONを検出し，減速を開始する。
3. "[Pr.47]クリープ速度"まで減速し，以後クリープ速度で移動する。
(減速中は近点ドグはONでなければならない。減速中に近点ドグがOFFしたときは，そのまま減速停止する。)
4. 近点ドグOFF後停止する。その後再度動き始め，最初の零点で停止する。
5. 原点復帰完了フラグ([Md.31]ステータス: b4)がOFF → ONし，原点復帰要求フラグ([Md.31]ステータス: b3)がON → OFFする。

##### 動作上の注意 (2.2 / 印刷 p.39 / 原本 p.41)

- 原点復帰リトライ機能が設定されていないとき("[Pr.48]原点復帰リトライ"の設定が「0」のとき)，機械原点復帰完了後に再度機械原点復帰を行うと，エラー「原点上始動」(エラーコード: 1940H)となります。
- 近点ドグ上から機械原点復帰を行うと，"[Pr.47]クリープ速度"で始動します。
- 近点ドグは，原点復帰速度から"[Pr.47]クリープ速度"に減速するまでの間ONしておく必要があります。
- 機械原点復帰を停止信号で停止させた場合，再度機械原点復帰を行ってください。停止信号での停止後に再始動指令をONした場合，エラー「原点復帰再始動不可」(エラーコード: 1946H)となります。
- 原点復帰始動後，A点へ移動するまでの間にエンコーダの零点を最低1回通過する必要があります。ただし，「機能選択 C-4(PC17)」で「1: 電源投入後モータZ相通過不要」を選択した場合，零点を通過していなくても原点復帰が可能です。クリープ速度まで減速する前に近点ドグがOFFすると，ワークはそのまま減速停止し，エラー「ドグ検出タイミング異常」(エラーコード: 1941H)となります。

【図】クリープ速度まで減速する前に近点ドグがOFFした場合のタイミングチャート(2.2 / 印刷 p.39 / 原本 p.41)
- 速度波形: 始動 → "[Pr.46]原点復帰速度"で定速 → 近点ドグONで減速開始 → "[Pr.47]クリープ速度"(破線で示す)に達する前に近点ドグがOFF → そのまま速度0まで減速停止
- 近点ドグ: 減速開始時にOFF→ON、減速途中でON→OFF(短いONパルス)
- 機械原点復帰始動(位置決め始動信号): 始動でOFF→ON、停止(エラー)後にON→OFF
- 原点復帰要求フラグ([Md.31]ステータス: b3): 始動を受けてOFF→ON、停止後もONのまま
- 原点復帰完了フラグ([Md.31]ステータス: b4): OFFのまま
- [Md.26]軸動作状態: 待機中 → 原点復帰中 → (停止時)エラー中
- [Md.34]近点ドグON後の移動量: 不定 → 0(以後0のまま)
- [Md.20]送り現在値 / [Md.21]送り機械値: 不定 → 移動した値を格納 → 停止時のアドレス

#### カウント式1[RD77MS] (2.2 / 印刷 p.40 / 原本 p.42)

原点復帰方式「カウント式1」の動作概要を以下に示します。
「カウント式1」の原点復帰では，以下が可能です。
- 近点ドグ上での機械原点復帰
- 機械原点復帰完了後の再度機械原点復帰

##### 動作図 (2.2 / 印刷 p.40 / 原本 p.42)

【図】カウント式1 機械原点復帰のタイミングチャート(2.2 / 印刷 p.40 / 原本 p.42)
- 速度波形(V-t): 始動・加速 → "[Pr.46]原点復帰速度"で定速 → 近点ドグONで減速 → "[Pr.47]クリープ速度"で定速 → 近点ドグON位置から"[Pr.50]近点ドグON後の移動量設定"分(網掛け面積)移動した位置(図中A点)でいったん速度0 → 再度動き始め最初の零点で停止
- 図中の[ポイント]: 「原点復帰始動後，A点へ移動するまでの間にエンコーダの零点を最低1回は通過する必要があります。」
- [Md.34]近点ドグON後の移動量*1: 近点ドグONから停止位置までの距離
- 近点ドグ: 減速開始位置でOFF→ON。ON区間は停止位置を越えて継続(図注記「近点ドグのOFFは，原点位置から十分な距離をとってください。」)
- 零点信号: パルス状。「"[Pr.50]近点ドグON後の移動量設定"で設定した値分移動後の最初の零点」で停止。零点の間隔は「サーボモータ1回転分」
- 図中の注記: 「近点ドグON後の移動量設定は，なるべく零点信号HIGHの中央になるように調節してください。近点ドグON後の移動量設定が零点信号にかかった場合，機械原点復帰の停止位置に，サーボモータ1回転分の誤差が生じることがあります。」
- 機械原点復帰始動(位置決め始動信号): 始動でOFF→ON、完了後にON→OFF
- 原点復帰要求フラグ([Md.31]ステータス: b3): 始動を受けてOFF→ON、完了でON→OFF
- 原点復帰完了フラグ([Md.31]ステータス: b4): 完了でOFF→ON
- [Md.26]軸動作状態: 待機中 → 原点復帰中 → 待機中
- [Md.34]近点ドグON後の移動量: 不定 → 0 → *1の値
- [Md.20]送り現在値 / [Md.21]送り機械値: 不定 → 移動した値を格納 → 原点アドレス

1. 機械原点復帰を始動する。
("[Pr.44]原点復帰方向"に設定した方向に，"[Pr.51]原点復帰加速時間選択"で指定した加速をはじめ，"[Pr.46]原点復帰速度"で移動する。)
2. 近点ドグONを検出し，減速を開始する。
3. "[Pr.47]クリープ速度"まで減速し，以後クリープ速度で移動する。
4. 近点ドグON後から"[Pr.50]近点ドグON後の移動量設定"で設定した移動量を移動した後停止する。その後再度動き始め，最初の零点で停止する。
5. 原点復帰完了フラグ([Md.31]ステータス: b4)がOFF → ONし，原点復帰要求フラグ([Md.31]ステータス: b3)がON → OFFする。

##### 動作上の注意 (2.2 / 印刷 p.41 / 原本 p.43)

- "[Pr.50]近点ドグON後の移動量設定"が，"[Pr.46]原点復帰速度"から"[Pr.47]クリープ速度"までの減速距離より少ない場合，エラー「カウント式移動量異常」(エラーコード: 1944H)となります。
- 機械原点復帰中に速度変更機能(☞ 263ページ 速度変更機能)で"[Pr.46]原点復帰速度"より速い速度へ速度変更すると，"[Pr.50]近点ドグON後の移動量設定"の設定値によっては，"[Pr.47]クリープ速度"まで減速するための距離が確保できない場合があります。この場合，エラー「カウント式移動量異常」(エラーコード: 1944H)となり，機械原点復帰を停止します。
- 近点ドグON中に機械原点復帰を始動した場合の動作を以下に示します。

###### ■近点ドグON上での機械原点復帰始動時の動作 (2.2 / 印刷 p.41 / 原本 p.43)

【図】近点ドグON上で始動したときの速度波形(カウント式1)(2.2 / 印刷 p.41 / 原本 p.43)
- 速度軸の下側(原点復帰方向と逆方向)へ: 始動位置(図中1.)から逆方向に加速(2.) → 原点復帰速度で逆方向移動 → 近点ドグOFFで減速停止(3.)
- 停止後，上側(原点復帰方向)へ加速(4.) → 近点ドグON検出(近点ドグOFF→ON)で減速 → クリープ速度 → "[Pr.50]近点ドグON後の移動量設定"(網掛け面積)を移動後いったん停止 → 再度動き始め，最初の零点で停止(5.)
- 近点ドグ: 逆方向移動中にOFFとなり，原点復帰方向移動中に再度ONとなる(ON区間は停止位置を越えて継続)
- 零点信号: パルス状。5.の停止位置は"[Pr.50]"分移動後の最初の零点

1. 原点復帰始動を行う。
2. 指定した原点復帰方向とは逆へ原点復帰速度で移動する。
3. 近点ドグOFF検出で減速処理を行う。
4. 停止後，指定した原点復帰方向へ機械原点復帰を行う｡
5. 近点ドグON検出で"[Pr.50]近点ドグON後の移動量設定"に設定した移動量を移動したあとの最初の零点検出で，機械原点復帰完了となる。

- 近点ドグのOFFは，原点位置から十分な距離をとってください。機械原点復帰中に近点ドグがOFFしても，動作上支障はありませんが，以下の理由で，近点ドグのOFFは，原点位置から十分な距離をとることを推奨します。

> 機械原点復帰完了時に近点ドグをOFF後，連続で機械原点復帰を行った場合，ハードウェアストロークリミット(上／下限リミット)にかかるまで，原点復帰速度で動作します。十分な距離を取れない場合は，原点復帰リトライ機能の使用を検討してください。

- 機械原点復帰を停止信号で停止させた場合，再度機械原点復帰を行ってください。停止信号での停止後に再始動指令をONした場合，エラー「原点復帰再始動不可」(エラーコード: 1946H)となります。
- 原点復帰始動後，A点へ移動するまでの間にエンコーダの零点を最低1回通過する必要があります。ただし，「機能選択 C-4(PC17)」で「1: 電源投入後モータZ相通過不要」を選択した場合，零点を通過していなくても原点復帰が可能です。

#### カウント式2[RD77MS] (2.2 / 印刷 p.42 / 原本 p.44)

#### データセット式[RD77MS] (2.2 / 印刷 p.44 / 原本 p.46)

原点復帰方式「データセット式」の動作概要を以下に示します。
「データセット式」は，近点ドグを使用しない原点復帰方法です。
データセット式原点復帰では，機械原点復帰を行ったときの位置が原点としてシンプルモーションユニットに登録され，送り現在値，送り機械値が原点アドレスに書き換わります。

- 電源を投入してから機械原点復帰を実行するまでに，必ず零点を通過しておく必要があります。零点を1度も通過せずに原点復帰を実行するとエラー「原点復帰零点未通過」(エラーコード: 197AH)となります。エラー「原点復帰零点未通過」(エラーコード: 197AH)になった場合は，エラーリセット後，サーボモータが1回転以上動くようにJOG運転等を行った後，再度機械原点復帰を実行してください。ただし，「機能選択 C-4(PC17)」で「1: 電源投入後モータZ相通過不要」を選択した場合，零点を通過していなくても原点復帰が可能です。

- バックラッシュ補正を使用する場合には，原点復帰実施前の原点位置へのJOG運転，手動パルサ運転での移動方向と"原点復帰方向"を合わせてください。

##### ドライバ原点復帰式後のバックラッシュ補正 (2.2 / 印刷 p.49 / 原本 p.51)

シンプルモーションユニットで"[Pr.11]バックラッシュ補正量"を設定した場合，ドライバ原点復帰後の位置決め等の軸動作では，シンプルモーションユニットの"[Pr.44]原点復帰方向"からバックラッシュ補正の要否の判断を行います。"[Pr.44]原点復帰方向"と同一方向に位置決め行う場合は，補正は行いませんが，"[Pr.44]原点復帰方向"と反対方向に位置決め行う場合は，バックラッシュ補正を行います。
ただし，ドライバ原点復帰時はドライバ側のパラメータの原点復帰方向を基に原点復帰を行うため，シンプルモーションユニットの"[Pr.44]原点復帰方向"とドライバ側の原点復帰の最終移動方向を同一方向に合わせてください。

> **制約**

> - 近点ドグ信号を使用する原点復帰方式でZ相を基準としない方式を使用する際は，アンプ内蔵のDIを使用することを推奨します。

##### 高速原点復帰の動作 (2.3 / 印刷 p.51 / 原本 p.53)

機械原点復帰を行って原点が確立した後，近点ドグや零点信号を使用せず原点位置への位置決めを行います。
以下に基本的な高速原点復帰始動時の動作を示します。

【図】高速原点復帰の動作図(2.3 / 印刷 p.51 / 原本 p.53)

##### 動作上の注意 (2.3 / 印刷 p.52 / 原本 p.54)

- 機械原点復帰を行って原点位置が確立した後しか高速原点復帰を行うことができません。エラー「原点復帰要求ON」(エラーコード: 1945H)となります。(原点復帰要求フラグ([Md.31]ステータス: b3)がOFFしている必要があります。)
- 現在値変更や定寸送り制御を使用して端数パルスが0クリアされた場合は，高速原点復帰を行うと，クリアされた分の誤差が発生します。
- 速度制御などで無限長送りをし，一度でも送り機械値がオーバーフロー／アンダーフローした場合は，正常に高速原点復帰を行うことができません。
- 原点復帰完了フラグ([Md.31]ステータス: b4)はONしません。
- 高速原点復帰中の軸状態は位置制御中となります。
