## 4 高度な位置決め制御 (4章 / 印刷 p.145 / 原本 p.147)

本章では，高度な位置決め制御(「ブロック始動データ」を使った制御機能)の詳細や使い方について説明しています。
高度な位置決め制御では，主要な位置決め制御で設定した「位置決めデータ」を条件判定を使って制御したり，複数軸の異なる「位置決めデータ」を同時に始動したりといった，「位置決めデータ」を使った，応用的な制御を行います。
各制御の設定や実行手順をよくお読みになり，必要な設定を行ってください。

### 4.1 高度な位置決め制御の概要 (4.1 / 印刷 p.145 / 原本 p.147)

「高度な位置決め制御」は，「位置決めデータ」の実行順序や実行条件を設定し，より応用的な位置決めを行う制御です。(実行順序や実行条件は「ブロック始動データ」と「条件データ」に設定します。)
「高度な位置決め制御」では，以下に示すような応用的な位置決め制御を行うことができます。

| 高度な位置決め制御 | 内容 |
|---|---|
| ブロック\*1始動(通常始動) | 1回の始動によって，任意のブロックの位置決めデータを，設定した順序で実行する。 |
| 条件始動 | 指定した位置決めデータに対して，「条件データ」に設定した条件判定を行い，「ブロック始動データ」を実行する。<br>• 条件が成立している場合は，「ブロック始動データ」を実行する。<br>• 条件が成立していない場合は，その「ブロック始動データ」を無視して次のポイントの「ブロック始動データ」を実行する。 |
| ウェイト始動 | 指定した位置決めデータに対して，「条件データ」に設定した条件判定を行い，「ブロック始動データ」を実行する。<br>• 条件が成立している場合は，「ブロック始動データ」を実行する。<br>• 条件が成立していない場合は，条件が成立するまで制御を停止(ウェイト)する。 |
| 同時始動\*2 | 「条件データ」で指定した軸の，指定した位置決めデータを，同時に実行(同タイミングで指令を出力)する。 |
| 繰り返し始動(FORループ) | 「FORループ」を設定した「ブロック始動データ」から，「NEXT」を設定した「ブロック始動データ」までを，設定した回数だけ繰り返して実行する。 |
| 繰り返し始動(FOR条件) | 「FOR条件」を設定した「ブロック始動データ」から，「NEXT」を設定した「ブロック始動データ」までを，「条件データ」に設定した条件が成立するまで繰り返して実行する。 |

- \*1 "[Da.1]運転パターン"に「連続位置決め制御」または「連続軌跡制御」が設定されている位置決めデータから，「単独位置決め制御(位置決め終了)」が設定されている連続する位置決めデータまでを「1ブロック」と定義する。
- \*2 「同時始動」には，「ブロック始動データ」による方式の他に，制御方式による「複数軸同時始動制御」があります。詳細は下記を参照してください。
  ☞ 25ページ 複数軸同時始動

[RD77GF]
リンクデバイスと外部入力信号を組み合わせて使用することで，パラメータ設定だけで応用的な位置決め始動が可能になります。

例
- スイッチがONの間だけ同じ動作パターンを繰り返す
- タッチパネルで運転パターンを設定してから始動する
- 始動する位置決め番号をタッチパネルで選択してから始動する

##### 高度な位置決め制御の補助機能 (4.1 / 印刷 p.145 / 原本 p.147)

「高度な位置決め制御」は「主要な位置決め制御」で設定する「位置決めデータ」を使用した制御です。組合わせ可能な補助機能については，下記マニュアルの"主機能と補助機能の組合せ"を参照してください。
☞ MELSEC iQ-R シンプルモーションユニットユーザーズマニュアル(スタートアップ編)
ただし，「高度な位置決め制御」に先読み始動機能を組合わせることはできません。

##### 高度な位置決め制御に必要なデータ (4.1 / 印刷 p.146 / 原本 p.148)

「高度な位置決め制御」は，「ブロック始動データ」と「条件データ」に必要な項目を設定し，その「ブロック始動データ」を始動することによって実行します。実行時には，「ブロック始動データ」に指定された「条件データ」によって実行可否などの判断を行います。
「ブロック始動データ」は，ブロックNo.と呼ばれる7000～7004の番号ごとに設定することができ，軸ごとに50ポイントまで設定することができます。(このデータは位置決めデータと区別するため，「ポイント」と呼ばれる番号で管理します。例えば，1つ目のブロック始動データを「1ポイント目のブロック始動データ」，もしくは「ポイントNo.1のブロック始動データ」と呼びます。)
「条件データ」は，ブロックNo.と呼ばれる7000～7004の番号ごとに設定することができ，軸ごとに10個まで設定することができます。
「ブロック始動データ」と「条件データ」は，ブロックNo.ごとに1セットとして設定を行います。
以下にシンプルモーションユニットに格納する「ブロック始動データ」と「条件データ」の設定項目と設定内容の概要を示します。

| 設定項目(区分) | 項目番号 | 設定項目 | 設定内容 |
|---|---|---|---|
| ブロック始動データ | [Da.11] | 形態 | 自分自身の「ブロック始動データ」のみ実行して制御を終了するか，次のポイントに設定した「ブロック始動データ」を実行するかを設定する。 |
| ブロック始動データ | [Da.12] | 始動データNo. | 実行する「位置決めデータNo.」を設定する。 |
| ブロック始動データ | [Da.13] | 特殊始動命令 | [Da.12]に設定した位置決めデータを，どのように始動するかを設定する。 |
| ブロック始動データ | [Da.14] | パラメータ | [Da.13]に設定した命令に応じて，どの条件で始動するかを設定する。(「条件データNo.」や「繰り返し回数」を指定します。) |

| 設定項目(区分) | 項目番号 | 設定項目 | 設定内容 |
|---|---|---|---|
| 条件データ | [Da.15] | 条件対象 | 「デバイス」，「バッファメモリの格納内容」，「位置決めデータNo.」「リンクデバイス[RD77GF]」の，どの要素に対して条件を設定するかを指定する。 |
| 条件データ | [Da.16] | 条件演算子 | [Da.15]に設定した対象について，どのような判定を行うかを設定する。 |
| 条件データ | [Da.17] | アドレス | [Da.15]に設定した内容が「バッファメモリの格納内容」の場合のみ，条件判定を行うバッファメモリのアドレスを設定する。 |
| 条件データ | [Da.18] | パラメータ1 | [Da.15]，[Da.16]，[Da.23]に設定した内容に応じて，必要な条件を設定する。 |
| 条件データ | [Da.19] | パラメータ2 | [Da.15]，[Da.16]，[Da.23]に設定した内容に応じて，必要な条件を設定する。 |
| 条件データ | [Da.23] | 同時始動軸数 | 同時始動を行う場合，同時に始動する軸数を設定する。 |
| 条件データ | [Da.24] | 同時始動対象軸番号1 | 同時始動を行う場合，「同時始動対象軸」を設定する。 |
| 条件データ | [Da.25] | 同時始動対象軸番号2 | 同時始動を行う場合，「同時始動対象軸」を設定する。 |
| 条件データ | [Da.26] | 同時始動対象軸番号3 | 同時始動を行う場合，「同時始動対象軸」を設定する。 |

#### NEXT始動使用上の制約事項 (4.3 / 印刷 p.157 / 原本 p.159)

「NEXT始動」は，繰り返し始動(FORループ)，繰り返し始動(FOR条件)実行時の繰り返しの最後を示すための命令です。
(☞ 155ページ 繰り返し始動(FORループ)，☞ 156ページ 繰り返し始動(FOR条件))
「ブロック始動データ」に「6: NEXT始動」を設定する場合の制約事項を以下に示します。
- 「4: FORループ」，「5: FOR条件」を実行する前に「6: NEXT始動」を実行すると，「0: ブロック始動」と同様の処理を行います。
- 「4: FORループ」，「5: FOR条件」以降に「6: NEXT始動」がない場合，繰り返し処理を行いません。(ただし「エラー」にはなりません。)
- 「4: FORループ」～「6: NEXT始動」，「5: FOR条件」～「6: NEXT始動」のネスティングはできません。ネスティングを行った場合は，ワーニング「FOR～NEXTネスト構造」(ワーニングコード: 09F1H)となります。

### 4.5 高度な位置決め制御の始動プログラム (4.5 / 印刷 p.162 / 原本 p.164)

#### 高度な位置決め制御の始動 (4.5 / 印刷 p.162 / 原本 p.164)

高度な位置決め制御を実行するためには，主要な位置決め制御の場合と同様に，制御を始動するためのプログラムを作成する必要があります。
以下に，軸1に設定された「1ポイント目のブロック始動データ」(ブロックNo.7000とする)を始動する場合の手順を示します。

【図】高度な位置決め制御の始動の流れ(CPUユニット → シンプルモーションユニット → サーボアンプ)(4.5 / 印刷 p.162 / 原本 p.164)
- 1. CPUユニットから「7000」をシンプルモーションユニットのバッファメモリ "[Cd.3]位置決め始動番号" へ。
- 2. CPUユニットから「1」をバッファメモリ "[Cd.4]位置決め始動ポイント番号" へ。
- 3. CPUユニットから「ON」を入出力信号 Y10 へ。
- 4. シンプルモーションユニットからサーボアンプへ「指定した位置決めデータで制御」。

> **Point**
> 位置決め完了した次のスキャンで位置決め始動を行う場合は，Y10をOFF後，始動完了信号([Md.31]ステータス: b14)がOFFしてから始動を行うようにするため，始動完了信号([Md.31]ステータス: b14)をインタロック条件として入れてください。

1. "[Cd.3]位置決め始動番号"に「7000」を設定する。
   (ブロック始動データを使った「高度な位置決め制御」であることを確定する。)
2. 始動する「ブロック始動データ」のポイント番号を設定する。(この場合は「1」とする。)
3. 始動信号をONする。
4. 「1ポイント目ブロック始動データ」に設定した位置決めデータが始動される。
