###### ■機種コード (12.3 / 印刷 p.487 / 原本 p.489)

シンプルモーションユニットで軸制御を行う，モーションモードに対応したスレーブ機器を設定します｡

【図】[Pr.100]接続機器のビット配置 例)(12.3 / 印刷 p.487 / 原本 p.489)

メーカ(ベンダ)コードについては，各スレーブ機器のマニュアルを参照してください。

> **Point**
> - シンプルモーションユニットで軸制御を行うスレーブ機器は，エンジニアリングツールのネットワーク構成設定の「ネットワーク同期通信設定」の設定に関わらず，同期通信が有効になります。
> - シンプルモーションユニットで軸制御を行うスレーブ機器は，エンジニアリングツールのネットワーク構成設定で1局～最大制御軸番号の範囲で設定してください。

接続機器と異なる設定値が設定された場合，またはモーションモードで動作していないスレーブ機器と接続した場合「接続機器設定エラー」(エラーコード: 193EH)を出力します。

###### ■A相／B相モード (12.3 / 印刷 p.489 / 原本 p.491)

A相がB相に比べ90°進んでいる場合は正転します。

B相がA相に比べ90°進んでいる場合は逆転します。

- A相／B相 4逓倍

A相／B相の立上りまたは立下りで位置決めアドレスを増加／減少させます。

【図】A相／B相 4逓倍の入力波形と位置決めアドレスの増減([Pr.151]手動パルサ／INC同期エンコーダ入力論理選択 正論理／負論理 別)(12.3 / 印刷 p.489 / 原本 p.491)
- 波形はA相(Aφ)・B相(Bφ)の2信号。正論理・負論理それぞれに「正転」「逆転」の波形がある。負論理の波形は正論理の波形を反転(HIGH/LOW逆)したもの。
- 正論理・正転: A相・B相のすべての立上りおよび立下り(図ではA相2パルス分で計8エッジ)ごとに位置決めアドレス +1(+1+1+1+1+1+1+1+1)。
- 正論理・逆転: 同様にすべてのエッジごとに -1(-1 -1 -1 -1 -1 -1 -1 -1)。
- 負論理・正転: すべてのエッジごとに +1(+1+1+1+1+1+1+1+1)。負論理・逆転: すべてのエッジごとに -1(-1 -1 -1 -1 -1 -1 -1 -1)。

- A相／B相 2逓倍

A相／B相の立上り2回または立下り2回で位置決めアドレスを増加／減少させます。

【図】A相／B相 2逓倍の入力波形と位置決めアドレスの増減(正論理／負論理 別)(12.3 / 印刷 p.489 / 原本 p.491)
- 正論理・正転: A相2パルス分の波形で +1 が4回(+1 +1 +1 +1)。図の破線は2エッジ(A相とB相の立上り同士、または立下り同士)をまとめて1カウントとすることを示す。
- 正論理・逆転: -1 が4回(-1 -1 -1 -1)。
- 負論理・正転: +1 が4回(+1 +1 +1 +1)。負論理・逆転: -1 が4回(-1 -1 -1 -1)。

- A相／B相 1逓倍

A相／B相の立上り2回および立下り2回で位置決めアドレスを増加／減少させます。

【図】A相／B相 1逓倍の入力波形と位置決めアドレスの増減(正論理／負論理 別)(12.3 / 印刷 p.489 / 原本 p.491)
- 正論理・正転: A相2パルス分の波形で +1 が2回(+1 +1)。図の破線はA相・B相の立上り2回と立下り2回の計4エッジをまとめて1カウントとすることを示す。
- 正論理・逆転: -1 が2回(-1 -1)。
- 負論理・正転: +1 が2回(+1 +1)。負論理・逆転: -1 が2回(-1 -1)。

##### [Pr.9]加速時間0，[Pr.10]減速時間0 (12.3 / 印刷 p.501 / 原本 p.503)

"[Pr.9]加速時間0"には，速度0から"[Pr.8]速度制限値"(JOG運転制御時は"[Pr.31]JOG速度制限値")に達するまでの時間を，"[Pr.10]減速時間0"には，"[Pr.8]速度制限値"(JOG運転制御時は"[Pr.31]JOG速度制限値")から速度が0になるまでの時間を設定します。

【図】加速時間0・減速時間0と実加減速時間の関係(12.3 / 印刷 p.501 / 原本 p.503)
- 縦軸 速度、横軸 時間。上の水準が[Pr.8]速度制限値、その下の水準が位置決め速度。
- 破線の斜線は、速度0から[Pr.8]速度制限値までの加速の傾き、および[Pr.8]速度制限値から速度0までの減速の傾きを示す。
- [Pr.9]加速時間0 は、速度0から[Pr.8]速度制限値に達するまでの時間(破線の傾きの時間)として示される。[Pr.10]減速時間0 は、[Pr.8]速度制限値から速度0になるまでの時間として示される。
- 位置決め速度が[Pr.8]速度制限値より低いため、同じ傾きで位置決め速度に達するまでの「実加速時間」は[Pr.9]加速時間0より短く、位置決め速度から0になるまでの「実減速時間」は[Pr.10]減速時間0より短く示されている。

- 位置決め速度の設定がパラメータの速度制限より遅い場合の実加減速時間は，比較的に短くなります。したがって，位置決め速度の最大値はパラメータの速度制限値と等しいか，速度制限値以下の近い値としてください。
- 原点復帰時，位置決め時およびJOG運転時共に有効となります。
- 補間位置決め時は，基準軸の加減速時間が有効となります。
