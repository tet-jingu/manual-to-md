### 9.5 リンクデバイス外部信号割付け機能[RD77GF] (9.5 / 印刷 p.336 / 原本 p.338)

リンクデバイスをシンプルモーションユニットの外部信号に割り付ける機能です。上／下限リミット信号や近点ドグ信号といった信号を，リンクデバイスに割り付けることが可能です。

#### 割り付け可能な信号 (9.5 / 印刷 p.336 / 原本 p.338)

シンプルモーションユニットで使用する下記の信号をCC-Link IE フィールドネットワークのリンクデバイスに割り付けることができます。複数の外部信号に，同一のリンクデバイスを割り付け可能です。

### 9.7 アンプなし運転機能 (9.7 / 印刷 p.347 / 原本 p.349)

アンプなし運転機能は，サーボアンプを接続せずシンプルモーションユニットの位置決め制御を行うことができる機能です。この機能により装置立ち上げ時のユーザプログラムのデバッグや位置決め動作のシミュレートを行います。

#### RD77MSのアンプなし運転 (9.7 / 印刷 p.347 / 原本 p.349)

##### 制御内容 (9.7 / 印刷 p.347 / 原本 p.349)

アンプなし運転機能は，通常運転モード(サーボアンプを接続して位置決め等を行うモード)から，アンプなし運転モード(サーボアンプを接続せず位置決め等を行うモード)へと，モードを切り換えることで使用します。

アンプなし運転モード中は，サーボアンプを接続していない状態で，通常運転モードと同じく各軸の運転が可能です。位置決め制御の始動方法についても通常運転モードと同様の手順となります。

アンプなし運転を行った後，アンプなし運転モードから通常運転モードへ切り換えることで，サーボアンプを接続した通常の運転が可能です。

通常運転モードとアンプなし運転モードを切り換えたときの現在値(送り現在値，送り機械値)の管理について以下に示します。

| 「絶対位置検出システム(PA03)」*1の設定 | 運転モード切換え時の現在値管理: 通常運転モード → アンプなし運転モード | 運転モード切換え時の現在値管理: アンプなし運転モード → 通常運転モード |
|---|---|---|
| 「0: 無効(インクリメンタルシステムで使用する。)」のとき | 送り現在値，送り機械値は，「0」となります。 | 送り現在値，送り機械値は，「0」となります。(サーボアンプとの通信開始時) |
| 「1: 有効(絶対位置検出システムで使用する。)」のとき | 最後にサーボアンプの電源をOFFしたアドレスでアンプなし運転モードを開始します。<br>ただし，通常運転モードで原点位置が確立されていない場合は，送り現在値，送り機械値は，「0」となります。 | 実際のモータ位置に従って，送り現在値，送り機械値を復元します。(サーボアンプとの通信開始時)<br>ただし，アンプなし運転モードへ切り換える前の通常運転モードで原点位置が確立されていない場合は，送り現在値，送り機械値を復元できません。原点復帰を行う必要があります。<br>また，アンプなし運転モード中に実際のモータ位置から「-2147483648(-2^31)～2147483647(2^31-1) [pulse]」の範囲を超える移動を行ったあと通常運転モードへ切り換えた場合，送り現在値，送り機械値を正しく復元できないことがあります。 |

*1 MR-J3(W)-B/MR-J4(W)-Bの場合です。MR-J5(W)-Bの場合は，「絶対位置検出システム選択(PA03.0)」を設定してください。

- アンプなし運転モードへ切り換える前に下記のいずれかを操作した軸のみ，アンプなし運転モード中に接続状態となります。

##### 運転モード切換え手順 (9.7 / 印刷 p.349-350 / 原本 p.351-352)

- 通常運転モードからアンプなし運転モードへの切換え
  1. 運転中の軸を全て停止させ，全軸のBUSY信号がOFFとなったことを確認する
  2. シーケンサレディ信号[Y0]をOFFする
  3. 準備完了信号[X0]がOFFとなったことを確認する
  4. "[Cd.137]アンプなし運転モード切換え要求"に「ABCDH」を設定する
  5. "[Md.51]アンプなし運転モード状態"が「1: アンプなし運転モード中」となったことを確認する
- アンプなし運転モードから通常運転モードへの切換え
  1. 運転中の軸を全て停止させ，全軸のBUSY信号がOFFとなったことを確認する
  2. シーケンサレディ信号[Y0]をOFFする
  3. 準備完了信号[X0]がOFFとなったことを確認する
  4. "[Cd.137]アンプなし運転モード切換え要求"に「0000H」を設定する
  5. "[Md.51]アンプなし運転モード状態"が「0: 通常運転モード中」となったことを確認する

###### ■動作例 (9.7 / 印刷 p.350 / 原本 p.352)

通常運転モードとアンプなし運転モードの切換えの動作を以下に示します。

【図】通常運転モード⇔アンプなし運転モード切換えのタイミングチャート(9.7 / 印刷 p.350 / 原本 p.352)
- 図の区間: 左から「通常運転モード」→「アンプなし運転モード」→「通常運転モード」。モードの境界(破線)は "[Md.51]アンプなし運転モード状態" が変化する時点。
- 各種運転(速度V-時間t): 通常運転モードで運転中の軸が減速停止 → アンプなし運転モード中に加速・定速・減速停止の運転 → 通常運転モードに戻った後に再び加速して運転。
- BUSY信号[X10, X11, X12, X13]: 通常運転モードでの運転停止でOFF → アンプなし運転モード中の運転開始でON、停止でOFF → 通常運転モードでの運転開始でON。
- シーケンサレディ信号[Y0]: BUSY信号OFF後にOFF → それを受けて準備完了信号[X0]がOFF(矢印でY0のOFF→X0のOFFの因果を表示)。
- "[Cd.137]アンプなし運転モード切換え要求": [X0]がOFFした後に「0000H」→「ABCDH」へ変化 → それを受けて "[Md.51]アンプなし運転モード状態" が「0」→「1」(ここからアンプなし運転モード)。
- アンプなし運転モードへ移行後、[Y0]をON → [X0]がON → 運転を始動(BUSY ON)。
- 運転停止(BUSY OFF)後、[Y0]をOFF → [X0]がOFF → "[Cd.137]" を「ABCDH」→「0000H」へ変化 → "[Md.51]" が「1」→「0」(ここから通常運転モード)。
- 通常運転モードへ移行後、[Y0]をON → [X0]がON → 運転を始動(BUSY ON)。

###### ■運転モード切換え手順のPoint (9.7 / 印刷 p.350 / 原本 p.352)

- 同期用フラグ[X1]以外の全ての入力信号がOFFであることを確認してから，通常運転モードとアンプなし運転モードの切換えを行ってください。同期用フラグ[X1]以外のいずれかの入力信号がONの状態で通常運転モードとアンプなし運転モードの切換えを行った場合，エラー「通常運転モード → アンプなし運転モード切換え時エラー」(エラーコード: 18B0H)またはエラー「アンプなし運転モード → 通常運転モード切換え時エラー」(エラーコード: 18B1H)となり運転モードの切換えは行われません。
- サーボアンプを接続した状態で運転モードを切り換えた場合，サーボアンプとの通信は以下のようになります。
  - 通常運転モードからアンプなし運転モードへの切換え時: 接続中の全ての軸の通信が切断されます(サーボアンプのLED表示は"AA"となります)。
  - アンプなし運転モードから通常運転モードへの切換え時: 接続されているサーボアンプとの通信が開始されます。
- サーボアンプを接続していない状態でも運転モードの切換えは可能です。
- アンプなし運転モード中は，"[Pr.82]緊急停止有効／無効設定"の設定内容にかかわらず，緊急停止は無効となります。
- "[Cd.137]アンプなし運転モード切換え要求"は，「0000H」「ABCDH」のみ有効です。アンプなし運転モードへの切換えは，"[Cd.137]アンプなし運転モード切換え要求"が「0000H」から「ABCDH」となったときのみ受付けられます。通常運転モードへの切換えは，"[Cd.137]アンプなし運転モード切換え要求"が「ABCDH」から「0000H」となったときのみ受付けられます。

#### RD77GFのアンプなし運転 (9.7 / 印刷 p.351 / 原本 p.353)

##### 制御内容 (9.7 / 印刷 p.351 / 原本 p.353)

アンプなし運転機能は，通常運転モード(サーボアンプを接続して位置決め等を行うモード)から，アンプなし運転モード(サーボアンプを接続せず位置決め等を行うモード)へと，モードを切り換えることで使用します。

アンプなし運転モード中は，仮想サーボアンプ軸として接続し，サーボアンプを接続していない状態で，通常運転モードと同じく各軸の運転が可能です。位置決め制御の始動方法についても通常運転モードと同様の手順となります。

###### ■制御内容のPoint (9.7 / 印刷 p.351 / 原本 p.353)

- 通常運転モードとアンプなし運転モードの切換えは，全軸一括で行われます。
- アンプなし運転モード中の軸は，"仮想サーボアンプ軸"として接続されます。仮想サーボアンプ軸での動作，制約については下記を参照してください。

- 通常運転モード→アンプなし運転モード切換え時に，CC-Link IE フィールドネットワークに接続されていない軸のみ仮想サーボアンプ軸へ切換ります。CC-Link IE フィールドネットワーク接続中の軸(局)が存在する場合，該当の軸(局)は仮想サーボアンプ軸となりません。("[Md.51]アンプなし運転モード状態"は「0: 通常運転モード中」のままです。)また，アンプなし運転モード→通常運転モード切換え時も，CC-Link IE フィールドネットワークに接続されていない軸(局)のみ仮想サーボアンプ軸が切断されます。
- アンプなし運転モードから通常運転モードへ切り換えた場合，軸を接続するために再度CC-Link IE フィールドネットワークの復列処理を行う必要があります。

##### 運転モード切換え手順 (9.7 / 印刷 p.353 / 原本 p.355)

- 通常運転モードからアンプなし運転モードへの切換え
  1. すべての軸がネットワークから解列していることを確認する
  2. "[Cd.137]アンプなし運転モード切換え要求"に「ABCDH」を設定する
  3. "[Md.51]アンプなし運転モード状態"が「1: アンプなし運転モード中」となったことを確認する
- アンプなし運転モードから通常運転モードへの切換え
  1. 運転中の軸を全て停止させ，全軸のBUSY信号がOFFとなったことを確認する
  2. 軸がネットワークから解列していることを確認する
  3. "[Cd.137]アンプなし運転モード切換え要求"に「0000H」を設定する
  4. "[Md.51]アンプなし運転モード状態"が「0: 通常運転モード中」となったことを確認する

"[Cd.700]仮想サーボアンプ操作指令"によって，直接仮想サーボアンプに切り換えることもできます。詳細については，下記を参照してください。

###### ■運転モード切換え手順のPoint (9.7 / 印刷 p.353 / 原本 p.355)

- アンプなし運転モード中は，"[Pr.82]緊急停止有効／無効設定"の設定内容にかかわらず，緊急停止は無効となります。
