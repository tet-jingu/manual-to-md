## 1 始動と停止 (1章 / 印刷 p.19 / 原本 p.21)

シンプルモーションユニットの位置決め制御の始動と停止方法を示します。

### 1.1 始動 (1.1 / 印刷 p.19 / 原本 p.21)

シンプルモーションユニットでは，制御ごとに始動トリガを動作させ，位置決め制御を開始させます。制御ごとの始動信号を下記に示します。本節では，位置決め始動信号と外部指令信号による始動を記載します。

| 制御内容 | | 始動トリガ |
|---|---|---|
| 主要な位置決め制御 | — | • 位置決め始動信号[Y10～Y2F]をONする。*1<br>• 外部指令信号(DI)をONする。 |
| 高度な位置決め制御 | — | • 位置決め始動信号[Y10～Y2F]をONする。*1<br>• 外部指令信号(DI)をONする。 |
| 原点復帰制御 | — | • 位置決め始動信号[Y10～Y2F]をONする。*1<br>• 外部指令信号(DI)をONする。 |
| 手動制御 | JOG運転 | "[Cd.181]正転JOG始動信号"または"[Cd.182]逆転JOG始動信号"をONする。 |
| 手動制御 | インチング運転 | "[Cd.181]正転JOG始動信号"または"[Cd.182]逆転JOG始動信号"をONする。 |
| 手動制御 | 手動パルサ運転 | 手動パルス発生器を操作する。 |

*1 制御軸数を超える軸番号の位置決め始動信号は使用不可です。

手動制御以外の制御では，下記の始動方式を選択できます。
- 通常始動(☞ 150ページ ブロック始動)
- 複数軸同時始動(☞ 25ページ 複数軸同時始動)

制御する際に指定する位置は，位置決めデータ，ブロック始動データ，条件データを使用します。使用できるデータは，始動方式によって異なります。

#### 位置決め始動信号による始動 (1.1 / 印刷 p.21-22 / 原本 p.23-24)

位置決め始動信号によって始動した時の動作を示します。
- 位置決め始動信号のONにより，始動完了信号([Md.31]ステータス: b14)およびBUSY信号がONし，位置決め運転が開始します。BUSY信号のONにより，軸が運転中であることがわかります。
- 位置決め始動信号がOFFすると始動完了信号([Md.31]ステータス: b14)もOFFします。位置決めを終了しても位置決め始動信号がONの場合，始動完了信号([Md.31]ステータス: b14)もONのままです。
- BUSY信号がON中に，再度位置決め始動信号がONすると，ワーニング「運転中始動」(ワーニングコード: 0900H)となります。
- 位置決め運転終了時の処理は，次の位置決め制御の有無によって異なります。

| 次の位置決め制御の有無 | 処理内容 |
|---|---|
| 位置決めを行わない | • ドウェルタイムが設定されている場合は，設定した時間が経過するまでウェイトしたあと，位置決めが完了します。<br>• 位置決めが完了すると，BUSY信号がOFFし，位置決め完了信号([Md.31]ステータス: b15)がONします。ただし，速度制御の場合や位置決め完了信号出力時間が「0」の場合はONしません。<br>• "[Pr.40]位置決め完了信号出力時間"に設定した時間が経過すると，位置決め完了信号([Md.31]ステータス: b15)がOFFします。 |
| 位置決めを行う | • ドウェルタイムが設定されている場合は，設定した時間が経過するまでウェイトします。<br>• ドウェルタイムの設定時間が経過すると，次の位置決めの始動を行います。 |

##### 動作例 (1.1 / 印刷 p.21 / 原本 p.23)

【図】位置決め始動信号による始動の動作例(速度波形と信号のタイミングチャート)(1.1 / 印刷 p.21 / 原本 p.23)
- 図の信号: 位置決め(速度波形 V-t)、全軸サーボON[Y1]、位置決め始動信号[Y10, Y11, Y12, Y13]、始動完了信号([Md.31]ステータス: b14)、BUSY信号[X10, X11, X12, X13]、位置決め完了信号([Md.31]ステータス: b15)
- 全軸サーボON[Y1]がOFF→ONした後、位置決め始動信号がOFF→ONする。
- 位置決め始動信号のONを受けて(矢印)、始動完了信号(b14)とBUSY信号が同じタイミングでONし、速度波形(位置決め)が立ち上がる。
- 速度波形は複数の位置決めデータが連続する形(加速→定速→加速→定速→加速→定速→減速→定速→減速停止)で、各位置決めデータの切替わり(縦破線)ごとに位置決め完了信号(b15)が短時間ONのパルスとして出る(図では切替わり3か所でON→OFF)。
- 速度が0になった後、「ドウェルタイム」の矢印区間をおいて次の位置決めが始動する。各位置決めの終了(停止後ドウェルタイム経過)時点でも位置決め完了信号(b15)が一定時間ONする。
- この間BUSY信号と始動完了信号はONのまま(位置決め始動信号もONのまま)。
- 最後の位置決め終了(ドウェルタイム経過)でBUSY信号がOFFし、それを受けて(矢印)位置決め完了信号(b15)がONし、一定時間後にOFFする。
- その後、位置決め始動信号がOFFし、それを受けて(矢印)始動完了信号(b14)がOFFする。

> **Point**
> 移動量0の位置制御を実行した場合も，BUSY信号はONしますが，ON時間が短いためプログラムでON状態を検出できない場合があります。(始動完了信号([Md.31]ステータス: b14)，位置決め完了信号([Md.31]ステータス: b15)，MコードON信号([Md.31]ステータス: b12)は，プログラムでON状態を検出できます。)

##### 動作タイミングと処理時間 (1.1 / 印刷 p.22 / 原本 p.24)

位置制御の動作タイミングと時間についての詳細を示します。
- 動作例

【図】位置制御の動作タイミングと処理時間 t1～t6(1.1 / 印刷 p.22 / 原本 p.24)
- 図の信号: 位置決め始動信号[Y10, Y11, Y12, Y13]、BUSY信号[X10, X11, X12, X13]、MコードON信号([Md.31]ステータス: b12)(WITHモード)、[Cd.7]MコードOFF要求、始動完了信号([Md.31]ステータス: b14)、[Md.26]軸動作状態、位置決め動作、位置決め完了信号([Md.31]ステータス: b15)、MコードON信号([Md.31]ステータス: b12)(AFTERモード)、[Cd.7]MコードOFF要求、原点復帰完了フラグ([Md.31]ステータス: b4)
- t1: 位置決め始動信号のONから、BUSY信号のONまでの時間。
- BUSY信号のONと同時に、MコードON信号(WITHモード)がON、始動完了信号(b14)がON、[Md.26]軸動作状態が「待機中」→「位置制御中」に変わる。
- t2(WITHモード): [Cd.7]MコードOFF要求のONから、MコードON信号(WITHモード)のOFFまでの時間。MコードON信号のOFFと同時に[Cd.7]MコードOFF要求もOFFとして描かれている。
- t4: BUSY信号のONから、位置決め動作(速度波形)の立上り開始までの時間。
- t5: 位置決め動作の終了(速度0)から、BUSY信号のOFF・位置決め完了信号(b15)のON・[Md.26]軸動作状態「位置制御中」→「待機中」までの時間。
- t6: 位置決め完了信号(b15)のON時間(BUSY信号OFF時点でONし、t6経過後にOFF)。
- MコードON信号(AFTERモード)は、BUSY信号のOFFと同じタイミングでONする。t2(AFTERモード): [Cd.7]MコードOFF要求のONから、MコードON信号(AFTERモード)のOFFまでの時間。
- 位置決め始動信号はBUSY信号のOFF後にOFFし、t3: 位置決め始動信号のOFFから、始動完了信号(b14)のOFFまでの時間。

#### 停止処理の分類 (1.2 / 印刷 p.29 / 原本 p.31)

運転中の停止には，減速停止，急停止，即停止の3種類があります。

##### 減速停止 (1.2 / 印刷 p.29 / 原本 p.31)

「減速時間0～3」([Pr.10]，[Pr.28]，[Pr.29]，[Pr.30])による停止です。「減速時間0～3」の，どの時間を制御に使用するかは位置決めデータ([Da.4])に設定します。

##### 急停止 (1.2 / 印刷 p.29 / 原本 p.31)

"[Pr.36]急停止減速時間"による停止です。

##### 即停止 (1.2 / 印刷 p.29 / 原本 p.31)

減速処理を行わない停止です。
シンプルモーションユニットは指令を即停止します。サーボアンプの停止方法については，各サーボアンプの技術資料集またはマニュアルを参照してください。

【図】減速停止・急停止・即停止の速度波形(1.2 / 印刷 p.29 / 原本 p.31)
- 減速停止: 位置決め速度で運転中に「停止要因」が入ると、そこから直線的に減速して「停止」する。減速の傾きは[Pr.8]速度制限値から速度0までを「設定減速時間」で減速する傾き(破線)と同じで、停止要因から停止までの時間が「実減速時間」として示されている。
- 急停止: 位置決め速度で運転中に「急停止要因」が入ると、そこから直線的に減速して「停止」する。傾きは[Pr.8]速度制限値から速度0までを「[Pr.36]急停止減速時間」で減速する傾きと同じで、急停止要因から停止までの時間が「実急停止減速時間」として示されている。
- 即停止: 位置決め速度で運転中に「停止要因」が入ると、減速せずに速度0(垂直)で「停止」する。

> **Point**
> 「減速停止」と「急停止」の選択は，詳細パラメータ2の「停止グループ1～3の急停止選択」で行います。(工場出荷時の設定は「減速停止」になっています。)

- 減速中に急停止に指定されている停止要因が発生した場合は，その時点から急停止処理が行われます。減速中の急停止処理は，急停止時間が減速停止時間より短いときのみ行われます。

### 1.3 再始動 (1.3 / 印刷 p.31 / 原本 p.33)

位置制御中に停止要因が発生して停止した場合，「再始動指令」([Cd.6]再始動指令)により，停止位置から位置制御の終点までの位置決めを再開することができます。(「連続運転の中断」の場合は，「再始動」はできません。)
INC直線1などインクリメント方式の位置制御において，停止位置から残りの位置決めを行う場合に有効です。(残距離の算出を行う必要がありません。)

#### 動作 (1.3 / 印刷 p.31 / 原本 p.33)

停止指令による減速停止完了後，"[Md.26]軸動作状態"が「停止中」の状態で"[Cd.6]再始動指令"に「1: 再始動指令」を書き込むと，再始動を行います。

【図】再始動の動作(速度波形)(1.3 / 印刷 p.31 / 原本 p.33)
- 始動後、位置決めデータNo.10 → 位置決めデータNo.11 → 位置決めデータNo.12 と連続して運転するパターン。
- 位置決めデータNo.11の途中で「停止指令による停止処理」により減速して速度0で停止する。
- その後「再始動指令による位置決めデータNo.11の続行」により再加速し、No.11の残りを運転した後、No.12 へ移って運転し、停止する。

#### 制約事項 (1.3 / 印刷 p.31 / 原本 p.33)

- 再始動は，"[Md.26]軸動作状態"が「停止中(停止指令による減速停止が完了した状態)」のみ実行できます。軸動作状態が「停止中」以外になった場合は，再始動できません。この場合，ワーニング「再始動不可」(ワーニングコード: 0902H)となり，そのときの処理が続行されます。
- 停止指令がON中には，再始動を行わないでください。停止中に再始動を行うと，エラー「始動時停止信号ON」(エラーコード: 1908H)となり，"[Md.26]軸動作状態"が「エラー発生中」になります。このためエラーリセットを行っても，再始動できなくなります。
- 再始動は，位置決め始動信号がONのままでも実行できます。ただし停止中に，位置決め始動信号がOFF → ONしないようにしてください。
- "[Md.26]軸動作状態"が「停止中」に位置決め始動信号をOFF → ONした場合も，通常の位置決め始動("[Cd.3]位置決め始動番号"に設定されている位置決めデータの始動)を行います。
- 連続運転中断要求により位置決めを終了した場合は，再始動できません。再始動要求を行った場合は，ワーニング「再始動不可」(ワーニングコード: 0902H)となります。
- 補間運転で停止中のときは，基準軸の"[Cd.6]再始動指令"に「1: 再始動指令」を書き込み，再始動してください。
- 停止中にシーケンサレディ信号[Y0]をOFF → ONした場合は，再始動できません。再始動要求を行った場合は，ワーニング「再始動不可」(ワーニングコード: 0902H)となります。
- 機械原点復帰および高速原点復帰の停止時は，エラー「原点復帰再始動不可」(エラーコード: 1946H)となり，再始動できません。
- 補間運転停止後，補間相手軸のいずれかが1回でも位置決め動作した場合，ワーニング「再始動不可」(ワーニングコード: 0902H)となり，再始動できません。

【図】再始動用タイムチャート(1.3 / 印刷 p.32 / 原本 p.34)
- 図の信号: 速度波形(V-t)、位置決め始動信号[Y10]、[Cd.180]軸停止、全軸サーボON[Y1]、シーケンサレディ信号[Y0]、準備完了信号[X0]、始動完了信号([Md.31]ステータス: b14)、BUSY信号[X10]、位置決め完了信号([Md.31]ステータス: b15)、エラー検出信号([Md.31]ステータス: b13)、[Md.26]軸動作状態、[Cd.6]再始動指令

- 定速運転中に[Cd.180]軸停止がONし、速度波形が減速して速度0になる。速度0のタイミングでBUSY信号がOFFし、[Md.26]軸動作状態は 8 → 1 に変わる。
- その後(矢印)、位置決め始動信号[Y10]と[Cd.180]軸停止がOFFし、位置決め始動信号のOFFを受けて(矢印)始動完了信号(b14)がOFFする。
- [Cd.6]再始動指令が 0 → 1 になると、それを受けて(矢印)BUSY信号がONし、[Md.26]軸動作状態が 1 → 8 に変わり、速度波形が再び立ち上がる。[Cd.6]再始動指令はその後 1 → 0 に戻る。
- 再始動時、位置決め始動信号[Y10]はOFFのまま、始動完了信号(b14)もOFFのまま(ONしない)。
- 再始動後の運転が減速停止し、ドウェルタイム経過でBUSY信号がOFFし、それを受けて(矢印)位置決め完了信号(b15)がONし、一定時間後にOFFする。[Md.26]軸動作状態は 8 → 0 に変わる。
- エラー検出信号(b13)は全期間OFF。
- 位置決め完了信号(b15)は、最初の停止(軸停止による減速停止)ではONしていない。
