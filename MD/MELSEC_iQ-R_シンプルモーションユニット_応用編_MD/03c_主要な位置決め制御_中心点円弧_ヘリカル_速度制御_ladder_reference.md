#### 中心点指定の2軸円弧補間制御

(3.2 / 印刷 p.96 / 原本 p.98)

「2軸円弧補間制御」("[Da.2]制御方式" = ABS円弧右，INC円弧右，ABS円弧左，INC円弧左)では，2台のモータを使って，それぞれに設定した軸方向について補間しながら，円弧アドレスを中心点とした円弧の軌跡で位置制御を行います。(補間制御については☞ 70ページ 補間制御)

以下に制御方式に応じた回転方向，制御可能な円弧の中心角，位置決め経路を示します。

| 制御方式 | 回転方向 | 制御可能な円弧の中心角 | 位置決め経路 |
|---|---|---|---|
| ABS　円弧右 | 右回り | 0° < θ ≦ 360° | 【図】右回り(下記) |
| INC　円弧右 | 右回り | 0° < θ ≦ 360° | 【図】右回り(下記) |
| ABS　円弧左 | 左回り | 0° < θ ≦ 360° | 【図】左回り(下記) |
| INC　円弧左 | 左回り | 0° < θ ≦ 360° | 【図】左回り(下記) |

【図】制御方式ごとの位置決め経路(3.2 / 印刷 p.96 / 原本 p.98)
- 右回り(ABS円弧右／INC円弧右): 中心点が経路の下側にあり、始点(現在の停止位置)から上に凸の円弧を時計回りに描いて終点(位置決めアドレス)へ移動する。中心角は 0° < θ ≦ 360°。
- 左回り(ABS円弧左／INC円弧左): 中心点が経路の上側にあり、始点(現在の停止位置)から下に凸の円弧を反時計回りに描いて終点(位置決めアドレス)へ移動する。中心角は 0° < θ ≦ 360°。

##### 円弧補間の誤差補正

(3.2 / 印刷 p.96 / 原本 p.98)

中心点指定の2軸円弧補間制御では，始点アドレスと中心点アドレスから算出した円弧の軌跡と，"[Da.6]位置決めアドレス／移動量"に設定した終点アドレスの位置がずれる場合があります。(☞ 518ページ [Pr.41]円弧補間誤差許容範囲)

###### ■算出した誤差 ≦ "[Pr.41]円弧補間誤差許容範囲"

(3.2 / 印刷 p.96 / 原本 p.98)

誤差補正を行いながら，設定されている終点アドレスに2軸円弧補間制御を行います。(「うず巻き補間」という。)

【図】うず巻き補間による軌跡(3.2 / 印刷 p.96 / 原本 p.98)
- 始点アドレスと中心点アドレスから計算した円弧(破線)上の「計算による終点アドレス」と、「設定した終点アドレス」とがずれており、その差が「誤差」。
- 実際の軌跡(実線、「うず巻き補間による軌跡」)は始点から徐々に半径を変えて、設定した終点アドレスに到達する。図の例では設定した終点アドレスは計算による終点アドレスより中心点側(内側)にある。

中心点指定の2軸円弧補間制御では，始点アドレスと中心点アドレスから算出した半径を用いた円弧上を，指令速度で動作しているという仮定で角速度を算出し，始点から移動した角速度に比例して半径の補正を行っています。

したがって，(始点アドレスと中心点アドレスから算出した半径(始点半径))と(終点アドレスと中心点アドレスから算出した半径(終点半径))に差(誤差)のある場合，合成速度は指令速度と異なり以下のようになります。

| 条件 | 合成速度 |
|---|---|
| 始点半径 > 終点半径 | 誤差がない場合に比べ，終点アドレスに近づくほど速度が遅くなります。 |
| 始点半径 < 終点半径 | 誤差がない場合に比べ，終点アドレスに近づくほど速度が速くなります。 |

(注: 原本の表は見出し行なし。列見出し「条件」「合成速度」は本ファイルで付けたもの)

##### 中心点指定の2軸円弧補間制御(ABS円弧右，ABS円弧左)

(3.2 / 印刷 p.97-98 / 原本 p.99-100)

###### ■動作図

(3.2 / 印刷 p.97 / 原本 p.99)

アブソリュート方式，中心点指定の2軸円弧補間制御では，現在の停止位置(始点アドレス)から，"[Da.6]位置決めアドレス／移動量"に設定したアドレス(終点アドレス)へ，"[Da.7]円弧アドレス"に設定した中心点のアドレス(円弧アドレス)を中心とする円弧の軌跡で位置決めを行います。

【図】ABS円弧の動作図(3.2 / 印刷 p.97 / 原本 p.99)
- 直交座標(正方向／逆方向)上で、始点アドレス(現在の停止位置)から終点アドレス(位置決めアドレス)へ、円弧の中心点(円弧アドレス)を中心とする円弧(「円弧補間による動き」)で移動する。
- 始点アドレスと円弧の中心点の距離が「半径」として示されている。

終点アドレス(位置決めアドレス)を始点アドレスと同一すると，始点アドレスと円弧の中心点を半径とする真円の位置決めができます。

【図】ABS円弧の真円位置決め(3.2 / 印刷 p.97 / 原本 p.99)
- 始点アドレス(現在の停止位置) = 終点アドレス(位置決めアドレス) とし、円弧の中心点(円弧アドレス)を中心とする真円を1周する。

中心点指定の2軸円弧補間制御では，始点アドレスと中心点アドレスから算出した半径を用いた円弧上を，指令速度で動作しているという仮定で角速度を算出し，始点から移動した角速度に比例して半径の補正を行っています。

したがって，(始点アドレスと中心点アドレスから算出した半径(始点半径))と(終点アドレスと中心点アドレスから算出した半径(終点半径))に差(誤差)のある場合，合成速度は指令速度と異なり以下のようになります。

| 条件 | 合成速度 |
|---|---|
| 始点半径 > 終点半径 | 誤差がない場合に比べ，終点アドレスに近づくほど速度が遅くなります。 |
| 始点半径 < 終点半径 | 誤差がない場合に比べ，終点アドレスに近づくほど速度が速くなります。 |

###### ■制約事項

(3.2 / 印刷 p.98 / 原本 p.100)

下記の場合は，2軸円弧補間制御は設定できません。
- "[Pr.1]単位設定"に「degree」が設定されている場合
- 基準軸と補間軸で"[Pr.1]単位設定"に設定した単位が異なる場合(「mm」，「inch」の混在は可)
- "[Pr.20]補間速度指定方法"に「基準軸速度」が設定されている場合

下記の場合は，エラーとなり，位置決め始動できません。位置決め制御中の場合は，エラー検出時に即停止します。
- 半径が「536870912( = 2^29)」を超える場合(2軸円弧補間制御が可能な最大半径は，「536870912( = 2^29)」です。): 位置決め始動時にエラー「半径範囲外」(エラーコード: 1A32H)となります。
- 始点アドレス = 中心点アドレス: 中心点設定エラー (エラーコード: 1A2DH)
- 終点アドレス = 中心点アドレス: 中心点設定エラー (エラーコード: 1A2EH)
- 中心点アドレスが-2147483648(-2^31)〜2147483647(2^31 - 1)の範囲外: 中心点設定エラー (エラーコード: 1A2FH)

##### 送り現在値

##### 制約事項(速度制御)

(3.2 / 印刷 p.115 / 原本 p.117)

- "[Da.1]運転パターン"は，「位置決め終了」を設定してください。「連続位置決め制御」，「連続軌跡制御」を設定した場合，エラー「連続・連続軌跡制御不可」(エラーコード: 1A1EH〜1A20H)となり，始動できません。(速度制御では「連続位置決め制御」，「連続軌跡制御」を設定できません。)
- Mコードを使用する場合は，出力タイミングにWITHモードを設定してください。AFTERモードを設定した場合，Mコードは出力されず，MコードON信号もONしません。

###### ■速度制限値の制約

(3.2 / 印刷 p.115 / 原本 p.117)

制御軸(1〜4軸)のうち，いずれか1つの軸が速度制限値を超える場合は，速度制限値を超えた軸を速度制限値で制御します。このとき，その他の軸は"[Da.8]指令速度"の比によって速度が制限されます。

例

軸1と軸2を使用した場合

| 設定項目 | 名称 | 軸1の設定 | 軸2の設定 |
|---|---|---|---|
| [Pr.8] | 速度制限値 | 4000.00 mm/min | 5000.00 mm/min |
| [Da.8] | 指令速度 | 8000.00 mm/min | 6000.00 mm/min |

上表のような設定の場合，速度制御中の運転速度は以下のようになります。
- 軸1: 4000.00 mm/min([Pr.8]で速度制限されます。)
- 軸2: 3000.00 mm/min(軸1の指令速度と軸2の指令速度の比で速度制限されます。)

速度制限の結果，基準軸の速度が1未満となる場合は速度1で動作します。また，バイアス速度設定時はバイアス速度が最低速度となります。
