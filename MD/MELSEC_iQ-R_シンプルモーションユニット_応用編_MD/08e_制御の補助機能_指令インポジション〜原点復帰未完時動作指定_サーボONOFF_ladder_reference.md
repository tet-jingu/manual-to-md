#### 指令インポジション機能 (8.9 / 印刷 p.305 / 原本 p.307)

「指令インポジション機能」は，位置制御の自動減速時に停止位置までの残距離をチェックし，フラグを1にする機能です。
このフラグを「指令インポジションフラグ」と呼びます。指令インポジションフラグは，位置制御の完了を事前に示す前倒し信号として使用します。

##### 制御内容 (8.9 指令インポジション機能 / 印刷 p.305 / 原本 p.307)

指令インポジション機能の制御内容を以下に示します。

- 位置制御の自動減速時に停止位置までの残距離が"[Pr.16]指令インポジション範囲"に設定した値以下になったとき，指令インポジションフラグ([Md.31]ステータス: b2)に「1」を格納します。

###### ■指令インポジションの範囲チェック (8.9 指令インポジション機能 / 印刷 p.305 / 原本 p.307)

(距離)≦("[Pr.16]指令インポジション範囲"の設定値)

【図】位置決め時の速度波形と指令インポジションフラグ([Md.31]ステータス: b2)(8.9 / 印刷 p.305 / 原本 p.307)
- 縦軸 V、横軸 t。「位置決め」の速度波形は、始動後に速度を3段階で上げていき(途中で速度が段階的に増加)、最後に自動減速して停止する。
- 位置決め始動時、指令インポジションフラグは ON → OFF に変化する(始動前にONだったフラグが始動でOFFになる)。
- 自動減速中、停止位置までの残距離が「指令インポジション範囲設定値」(減速スロープ末尾の網掛け部分)に入った時点で、フラグが OFF → ON になる。フラグは停止後もONのまま。

- 指令インポジションの範囲チェックは，演算周期ごとに行います。

##### 制御上の注意事項 (8.9 指令インポジション機能 / 印刷 p.305 / 原本 p.307)

- 以下に示す場合は，指令インポジションの範囲チェックを行いません。
  - 速度制御中
  - 速度・位置切換え制御の速度制御中
  - 位置・速度切換え制御の速度制御中
  - 速度制御モード中
  - トルク制御モード中
  - 押当て制御モード中

【図】位置制御と速度・位置切換え制御での指令インポジションの範囲チェック(8.9 / 印刷 p.305 / 原本 p.307)
- 1つ目の運転(位置制御始動): 始動から加速・定速・減速。全区間(網掛け)で指令インポジションの範囲チェックを実行。減速スロープ末尾の「指令インポジション範囲設定値」に入った時点でフラグ OFF → ON。
- 2つ目の運転(速度・位置切換え制御始動): 始動時点でフラグ ON → OFF。速度制御区間(始動〜「速度 → 位置切換え」)では範囲チェックを実行しない。
- 「速度 → 位置切換え」以降(網掛け)で範囲チェックを実行し、減速スロープ末尾の「指令インポジション範囲設定値」に入った時点でフラグ OFF → ON。
- 図下の矢印「指令インポジションの範囲チェックの実行」は、1つ目の運転の始動から2つ目の運転の始動直前まで、および2つ目の運転の「速度 → 位置切換え」以降を示す。

- 以下に示す場合は，指令インポジションフラグはOFFされます。("[Md.31]ステータス: b2"に「0」が格納されます。)
  - 位置制御始動時
  - 速度制御始動時
  - 速度・位置切換え制御，位置・速度切換え制御始動時
  - 原点復帰制御始動時
  - JOG運転始動時
  - インチング運転始動時
  - 手動パルサ運転許可時
- 補間制御時は，基準軸の"[Pr.16]指令インポジション範囲"，指令インポジションフラグ([Md.31]ステータス: b2)を使用します。"[Pr.20]補間速度指定方法"が「合成速度」の場合，指令インポジションの範囲チェックは合成軸(始点アドレス，終点アドレスを結ぶ直線／円弧)上の残距離で行います。

#### 加減速処理機能 (8.9 / 印刷 p.307 / 原本 p.309)

「加減速処理機能」は，各制御の加減速を，装置に適した加減速カーブに調整する機能です。
加減速時間を設定することで，加減速カーブの傾きを変化させることができます。
また加減速カーブは，以下の2つの方式から選択することができます。
- 台形加減速
- S字加減速

速度・トルク制御の加減速処理は，下記を参照してください。

##### 「加減速方式の設定」の制御内容と設定 (8.9 加減速処理機能 / 印刷 p.307-308 / 原本 p.309-310)

「加減速方式の設定」では，加減速処理の方式を選択し，設定します。設定した加減速処理はすべての加減速(インチング運転，手動パルサ運転，速度・トルク制御を除く)に適用されます。
「加減速処理の方式」には以下に示す2つの方式があります。

###### ■台形加減速処理方式 (8.9 加減速処理機能 / 印刷 p.307 / 原本 p.309)

ユーザ設定の加速時間・減速時間と速度制限値を基に，直線的に加速・減速する方式です。

【図】台形加減速の速度波形(8.9 / 印刷 p.307 / 原本 p.309)
- 縦軸 V、横軸 t。0から直線的に加速 → 定速 → 直線的に減速して0になる台形。

###### ■S字加減速処理方式 (8.9 加減速処理機能 / 印刷 p.307-308 / 原本 p.309-310)

始動時，停止時のモータの負担を軽減する方式です。
ユーザ設定の加速時間・減速時間，速度制限値と"[Pr.35]S字比率"(1～100％)を基に，徐々に加速・減速する方式です。

##### サーボON(サーボ動作可) (8.10 / 印刷 p.315 / 原本 p.317)

以下にサーボONの手順を示します。

1. サーボアンプのLED表示が"b_"の状態であることを確認する。
   (全軸サーボON[Y1]の初期値は"OFF"です。)
2. "[Cd.100]サーボOFF指令"に「0」を設定する。
3. 全軸サーボON[Y1]をONする。

以上でサーボアンプはサーボON(サーボ動作可)になります。(サーボアンプのLED表示は，"d_"となります。)

##### サーボOFF(サーボ動作不可) (8.10 / 印刷 p.315 / 原本 p.317)

以下にサーボOFFの手順を示します。

1. "[Cd.100]サーボOFF指令"に「1」を設定する。(サーボアンプのLED表示は，"c_"となります。)
   (そのあと，"[Cd.100]サーボOFF指令"に「0」を再び設定すると，サーボ動作可能状態になります。)
2. 全軸サーボON[Y1]を"OFF"する。
   (サーボアンプのLED表示は，"b_"となります。)

> **Point**
> - サーボOFF中にサーボモータが外力で回った場合は，フォローアップ処理を行います。
> - サーボON/OFFは停止中(位置制御モード)に行ってください。位置制御モードの位置決め中，手動制御中，原点復帰中，速度制御モード中，トルク制御モード中および押当て制御モード中のサーボOFF要求は，無視されます。
> - 全軸をサーボOFFする場合，"[Cd.100]サーボOFF指令"を「0」のままで，全軸サーボON[Y1]をON → OFFにしても全軸サーボOFFになります。

#### フォローアップ機能 (8.10 / 印刷 p.316 / 原本 p.318)

##### フォローアップ機能 (8.10 フォローアップ機能 / 印刷 p.316 / 原本 p.318)

「フォローアップ機能」は，サーボOFF状態でモータの回転量(実現在値)をモニタし，モータの回転量を送り現在値に反映させる処理です。
このためサーボOFF中にサーボモータが回転しても，次にサーボONしたときサーボモータは溜りパルス量だけ回転することがなく，停止位置から位置決めを行うことができます。

##### フォローアップの実行 (8.10 フォローアップ機能 / 印刷 p.316 / 原本 p.318)

フォローアップ処理は，サーボOFF中常時行います。

【図】全軸サーボON[Y1]・各軸サーボOFF指令とフォローアップ処理実行区間(8.10 / 印刷 p.316 / 原本 p.318)
- 初期状態: 全軸サーボON[Y1] = OFF、各軸サーボOFF指令 = 0、サーボON/OFF状態 = OFF。この区間はフォローアップ処理実行。
- 全軸サーボON[Y1] が OFF → ON になると、サーボON/OFF状態が ON になる。
- 各軸サーボOFF指令が 0 → 1 になると、サーボON/OFF状態が OFF になる(Y1はONのまま)。この区間はフォローアップ処理実行。
- 各軸サーボOFF指令が 1 → 0 に戻ると、サーボON/OFF状態が再び ON になる。
- 全軸サーボON[Y1] が ON → OFF になると、サーボON/OFF状態が OFF になる。この区間はフォローアップ処理実行。
- 全軸サーボON[Y1] が再び OFF → ON になると、サーボON/OFF状態が ON になる。
- その後「サーボアラーム発生」により、Y1がONのままでもサーボON/OFF状態が OFF になる。この時点以降はフォローアップ処理実行(図では、その後全軸サーボON[Y1]もOFFになる)。
- 各フォローアップ処理実行区間は、いずれもサーボON/OFF状態がOFFの区間と一致する。

> **Point**
> フォローアップ機能は絶対位置システムの有無に関わらず，シンプルモーションユニットとサーボアンプの電源ON中でサーボOFF中のときには，フォローアップ処理を行います。
