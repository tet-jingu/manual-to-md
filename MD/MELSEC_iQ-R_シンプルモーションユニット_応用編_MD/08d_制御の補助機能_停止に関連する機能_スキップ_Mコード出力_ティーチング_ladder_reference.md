## 8 制御の補助機能 (8章 / 印刷 p.285-304 / 原本 p.287-306)

### 8.8 停止に関連する機能 (8.8 / 印刷 p.285 / 原本 p.287)

停止に関連する機能には「減速停止時停止指令処理機能」，「連続運転中断機能」，「ステップ機能」があります。各機能は，パラメータの設定やプログラムの作成・書込みによって実行します。

#### 減速停止時停止指令処理機能 (8.8 / 印刷 p.285 / 原本 p.287)

「減速停止時停止指令処理機能」は，減速停止処理中(自動減速中を含む)に停止要因が発生した場合の減速カーブを選択する機能です。

加減速処理が台形，S字のいずれの場合においても有効な機能です。

停止要因の詳細は，下記を参照してください。

☞ 27ページ 停止処理

「減速停止時停止指令処理機能」には下記に示す2つの機能があります。

##### 制御内容 (8.8 / 印刷 p.285 / 原本 p.287)

減速停止時停止指令処理機能の動作を以下に示します。

###### ■減速カーブ再作成 (8.8 / 印刷 p.285 / 原本 p.287)

停止要因発生時の速度から停止まで，設定されている減速時間に従った減速カーブを再作成します。

位置制御時の自動減速中に停止要因が発生した場合，現在実行している位置決めデータで指定した位置決めアドレスへ到達した時点で，即停止となります。

【図】減速カーブ再作成の速度波形(8.8 / 印刷 p.285 / 原本 p.287)
- 縦軸 V、横軸 t。「減速停止処理(自動減速)開始」から速度が下がり始める。
- 自動減速中に「停止要因発生」。その時点から「設定されている減速時間に従った減速カーブ」(実線)に切り替わる。
- 実線の減速カーブは途中の「指定した位置決めアドレス到達で即停止」の点で垂直に速度0へ落ちる。
- 比較として「停止要因未発生の場合の減速カーブ」(破線)と、停止要因発生時点から再作成された減速カーブの延長(点線)が描かれている。

###### ■減速カーブ継続 (8.8 / 印刷 p.285 / 原本 p.287)

停止要因発生後も現在の減速カーブを継続します。

位置制御時の自動減速中に停止要因が発生した場合，現在実行している位置決めデータで指定した位置決めアドレスへ到達する前に減速停止処理が完了することがあります。

【図】減速カーブ継続の速度波形(8.8 / 印刷 p.285 / 原本 p.287)
- 「減速停止処理(自動減速)開始」から減速を始め、途中で「停止要因発生」があっても、同じ減速カーブのまま滑らかに速度0まで減速する(カーブの折れ・即停止なし)。

##### 制御上の注意事項 (8.8 / 印刷 p.286 / 原本 p.288)

- 手動制御(JOG運転，インチング運転，手動パルサ運転)，速度・トルク制御では，減速停止時停止指令処理機能は無効となります。
- 減速停止時停止指令処理機能は，停止要因発生時の停止方法として，"[Pr.37]停止グループ1急停止選択"～"[Pr.39]停止グループ3急停止選択"に「0: 通常の減速停止」を設定している場合に有効となります。
- 減速停止時停止指令処理機能は，"[Pr.37]停止グループ1急停止選択"～"[Pr.39]停止グループ3急停止選択"で，「1: 急停止」を設定している場合は無効となります。(停止要因発生時の速度から停止まで，"[Pr.36]急停止減速時間"に従った減速カーブを再作成します。)位置制御(速度・位置切換え制御，位置・速度切換え制御の位置制御を含む)の場合，停止要因が発生するタイミングと"[Pr.36]急停止減速時間"の設定値によっては，即停止する場合があります。

【図】急停止選択時の速度波形 2例(8.8 / 印刷 p.286 / 原本 p.288)
- 左図「(指定した位置決めアドレスの手前で急停止)」: 「減速停止処理(自動減速)開始」後に「停止要因発生(急停止要因)」。そこから「急停止減速時間に従った減速カーブ」(実線)で急減速し、指定した位置決めアドレスの手前で速度0になる。点線は「停止要因未発生の場合の減速カーブ」。
- 右図「(指定した位置決めアドレス到達で即停止)」: 同様に「停止要因発生(急停止要因)」後に「急停止減速時間に従った減速カーブ」で減速するが、減速途中で指定した位置決めアドレスに到達し、その時点で垂直に速度0になる(即停止)。破線・点線は「停止要因未発生の場合の減速カーブ」等。

#### 連続運転中断機能 (8.8 / 印刷 p.287 / 原本 p.289)

位置決め制御では，連続位置決め制御，連続軌跡制御時に制御を中断することができます(連続運転中断機能)。「連続運転の中断」を行った場合，実行中の位置決めデータの動作が終了した時点で制御を停止します。連続運転の中断を実行するには，"[Cd.18]連続運転中断要求"に「1: 連続制御，連続軌跡制御を中断する。」を設定します。

##### 連続運転中断時の動作 (8.8 / 印刷 p.287 / 原本 p.289)

【図】停止指令ON時の場合(8.8 / 印刷 p.287 / 原本 p.289)
- 始動から位置決めデータNo.10(加速→定速)、No.11(減速して低い定速)、No.12 と続く連続運転。
- No.11 実行中に「停止指令」が ON すると、その時点から「停止指令ON時の停止処理」として減速し、No.11 の途中で停止する。破線は停止しなかった場合の No.11 の残り と No.12 の波形。

【図】[Cd.18]に"1"を設定した場合(8.8 / 印刷 p.287 / 原本 p.289)
- 同じ No.10→No.11→No.12 の運転で、No.11 実行中に「[Cd.18]に"1"設定時」が ON。
- 直ちには減速せず No.11 を最後まで実行し、No.11 の終点で「連続運転中断要求時の停止処理」として停止する。No.12 は実行されない(破線)。

##### 制約事項 (8.8 / 印刷 p.288 / 原本 p.290)

- 「連続運転中断要求」を行った場合は，位置決めの終了になります。このため停止後は，「再始動」を行うことはできません。"[Cd.6]再始動指令"を行った場合は，ワーニング「再始動不可」(ワーニングコード: 0902H)になります。
- 「連続運転中断要求」を行ったあと，停止指令をONしても，「連続運転中断要求」は解除されません。このため停止指令ONで停止後に「再始動」を行うと，「連続運転中断要求」を行った位置決めデータNo.を終了した時点で停止します。

【図】2軸の軌跡図(8.8 / 印刷 p.288 / 原本 p.290)
- 横軸 軸2、縦軸 軸1。原点から「位置決めデータNo.10による位置決め」(斜め直線)、続いて「位置決めデータNo.11による位置決め」(水平直線)。
- No.11 実行中に「連続運転中断要求」。No.11 の終点が「連続運転中断機能による位置決めの終了」となり、「位置決めデータNo.12の位置決めは実行しません」(破線)。

- 連続軌跡制御で「連続運転中断要求」を行ったとき，残距離不足で減速停止できない場合は，下記に示す位置決めデータまで連続運転の中断を先送りします。

  - 残距離の確保できる位置決めデータNo.
  - 位置決め終了(パターン: 00)の位置決めデータNo.
  - 連続位置決め制御(パターン: 01)の位置決めデータNo.

【図】残距離不足時の中断先送り(8.8 / 印刷 p.288 / 原本 p.290)
- 始動→位置決めデータNo.10→No.11→No.12 の速度波形。
- No.10 の終盤(No.11 との境界の直前)に「連続運転中断要求」。注記「連続運転中断要求があっても残距離不足で実行していた位置決めNo.で停止できない」(No.10 終点で止まる破線の減速は実行されない)。
- 運転は No.11 に移り、No.11 の終点で「位置決めデータNo.10で停止できなかった場合の停止処理」として停止する。No.12 は実行されない(破線)。

- Mコード信号がONしている状態でスキップ信号をONすると，Mコード信号がOFFするまで次データへの移行は行いません。

#### Mコード出力機能 (8.9 / 印刷 p.297 / 原本 p.299)

「Mコード出力機能」は，実行中の位置決めデータに関連した補助作業(クランプ，ドリル回転，工具交換など)の指令を行うための機能です。

位置決め実行時にMコードON信号([Md.31]ステータス: b12)がONすると，Mコードと呼ばれる番号が"[Md.25]有効Mコード"に格納されます。

CPUユニットから，この"[Md.25]有効Mコード"を読み出して，補助作業の指令に使用します。Mコードは位置決めデータごとに設定することができます。(位置決めデータの設定項目"[Da.10]Mコード／条件データNo.／LOOP～LEND繰り返し回数／ピッチ数"に設定します。)

また，「Mコード出力機能」では，Mコードを出力(格納)するタイミングを設定することができます。

##### MコードON信号の出力タイミング (8.9 / 印刷 p.297 / 原本 p.299)

「Mコード出力機能」では，Mコードを出力(格納)するタイミングを設定することができます。(Mコードは，MコードON信号がONされたとき，"[Md.25]有効Mコード"に格納されます。)

Mコードを出力するタイミングには，以下に示す「WITHモード」と「AFTERモード」の2種類があります。

###### ■WITHモード (8.9 / 印刷 p.297 / 原本 p.299)

位置決め開始時に，MコードON信号をONし，Mコードを"[Md.25]有効Mコード"に格納します。

【図】例 WITHモード(8.9 / 印刷 p.297 / 原本 p.299)
- 位置決め始動[Y10, Y11, Y12, Y13] OFF→ON、BUSY信号[X10, X11, X12, X13] OFF→ON。
- 1つ目の位置決め([Da.1]運転パターン 01)の開始と同時に MコードON信号([Md.31]ステータス: b12)が OFF→ON、[Md.25]有効Mコード に m1 が格納される(*1)。
- [Cd.7]MコードOFF要求 を 0→1→0 とすると、1 を受けて MコードON信号が OFF する。

- 2つ目の位置決め終了(ドウェルタイム後)で BUSY信号 OFF、位置決め始動 OFF。

*1 m1，m2は設定されているMコードを示す。

###### ■AFTERモード (8.9 / 印刷 p.297 / 原本 p.299)

【図】例 AFTERモード(8.9 / 印刷 p.297 / 原本 p.299)

##### 制御上の注意事項 (8.9 / 印刷 p.298 / 原本 p.300)

- 補間制御時は基準軸のMコードON信号がONされます。
- "[Da.10]Mコード／条件データNo.／LOOP～LEND繰り返し回数／ピッチ数"に「0」を設定すると，MコードON信号はONしません。(Mコードは出力されず，"[Md.25]有効Mコード"は前回出力された値が保持されます。)
- 位置決め始動時に，MコードON信号がONしている場合は，エラー「MコードON信号ON始動」(エラーコード: 19A0H)となり，始動しません。
- シーケンサレディ信号[Y0]がOFFすると，MコードON信号をOFFし，"[Md.25]有効Mコード"に「0」を格納します。
- 連続軌跡制御の場合，位置決め動作時間が短いと，MコードON信号をOFFする時間が取れず，ワーニング「MコードON信号ON」(ワーニングコード: 0992H)となる場合があります。その場合は，その部分の位置決めデータの"[Da.10]Mコード／条件データNo.／LOOP～LEND繰り返し回数／ピッチ数"に「0」を設定して，Mコードが出力しないようにすることにより，ワーニングを回避できます。
- 速度制御でAFTERモードの場合，Mコードは出力されずMコードON信号はONしません。
- "[Cd.3]位置決め始動番号"に「9003」を設定した現在値変更を行う場合，Mコード出力機能は無効となります。

【図】ティーチング時のタイミングチャート(8.9 / 印刷 p.304 / 原本 p.306)
- シーケンサレディ信号[Y0] OFF→ON、それを受けて準備完了信号[X0] OFF→ON。全軸サーボON[Y1] OFF→ON。
