## 付録 (付録 / 印刷 p.770-790 / 原本 p.772-792)

### 付3 SSCNETIII(/H)対応機器[RD77MS] (付3 / 印刷 p.770-790 / 原本 p.772-792)

#### オリエンタルモーター株式会社製ステッピングモーターユニットαSTEP/5相 (付3 / 印刷 p.770 / 原本 p.772)

オリエンタルモーター株式会社製ステッピングモーターユニットαSTEP/5相とSSCNETⅢ/Hで接続することができます。
ステッピングモーターユニットについての詳細は，下記にお問い合わせください。

- お問合せ先: オリエンタルモーター株式会社 ネットワーク対応製品専用ダイヤル(TEL: 0120-925-410)(フリーコール)

##### 接続方法 (付3 αSTEP/5相 / 印刷 p.770 / 原本 p.772)

###### ■システム構成 (付3 αSTEP/5相 / 印刷 p.770 / 原本 p.772)

αSTEP/5相を使用したシステム構成を以下に示します。

【図】αSTEP/5相を使用したシステム構成(付3 / 印刷 p.770 / 原本 p.772)
- シンプルモーションユニット(ベースユニット上)から SSCNETⅢケーブル MR-J3BUS_M(-A/-B) で SSCNETⅢ/H に接続
- SSCNETⅢ/H 上に ステッピングモーターユニット αSTEP/5相(図では1台のユニットに4軸分のモータが接続)と サーボアンプ MR-J5(W)-B/MR-J4(W)-B(図では2台)がデイジーチェーンで接続され、それぞれにモータが接続されている
- 接続軸数: RD77MS2: 最大2軸 / RD77MS4: 最大4軸 / RD77MS8: 最大8軸 / RD77MS16: 最大16軸

###### ■パラメータ設定 (付3 αSTEP/5相 / 印刷 p.770 / 原本 p.772)

αSTEP/5相を使用する場合，以下のパラメータを設定してください。

n: 軸No. - 1

| 設定項目 | 名称 | 設定値 | 工場出荷時の初期値 | バッファメモリアドレス |
|---|---|---|---|---|
| [Pr.100] | 接続機器 | 00032029H: 5相(ST)<br>0003202AH: αSTEP(AZ) | 0 | 58020+32n<br>58021+32n |

> **Point**
> システム設定では，接続するステッピングモータの数によらず，ご使用のステッピングモーターユニットで接続可能な軸数分の軸設定を行う必要があります。
> (例として，2軸ユニット使用時は，接続するモータが1軸でも，システム設定で2軸分の設定が必要です。)
> αSTEP/5相に設定するサーボパラメータは，シンプルモーションユニットで管理しません。

##### 制御上の注意事項 (付3 VCⅡ/VPH / 印刷 p.778-779 / 原本 p.780-781)

###### ■絶対位置システム(ABS)／インクリメンタルシステム(INC) (付3 VCⅡ/VPH / 印刷 p.778 / 原本 p.780)

ABS/INC設定は，接続するVCⅡシリーズ／VPHシリーズで実施してください。

###### ■無限長送り (付3 VCⅡ/VPH / 印刷 p.778 / 原本 p.780)

VCⅡシリーズ／VPHシリーズの仮想エンコーダパルス数機能を使用した場合，無限長送りが可能になります。本機能を使用しない場合は，エンコーダ多回転カウンタ × エンコーダ分解能 + エンコーダ1回転内位置が-2147483648～2147483647の範囲を超えるとサーボアラーム61468(F01CH)「アブソエンコーダオーバーフロー異常」が発生し，運転を停止します。

###### ■原点復帰 (付3 VCⅡ/VPH / 印刷 p.778 / 原本 p.780)

VCⅡシリーズ／VPHシリーズのパラメータ「SSCNETⅢ通信モード時の機能選択」の1桁目に「1」を設定した場合，零点を通過していなくても原点復帰が可能です。(電源投入後の原点復帰は，モータZ相を通過不要で実行できます。)「0」に設定した場合，モータのZ相(モータ基準位置信号)を通過せず原点復帰を実行するとエラー「原点復帰零点未通過」(エラーコード: 197AH)が発生します。
VPHシリーズのパラメータ「マーカ通過選択」を「原点復帰可」に設定した場合，電源投入後にモータZ相を通過不要で原点復帰が実行可能になります。「マーカ通過後原点復帰可」に設定した場合，モータのZ相を通過せず原点復帰を実行すると，エラー「原点復帰零点未通過」(エラーコード: 197AH)が発生します。

###### ■制御モード (付3 VCⅡ/VPH / 印刷 p.778 / 原本 p.780)

使用可能な制御モードを以下に示します。

- 位置制御モード(位置制御，位置ループを含む速度制御)
- 速度制御モード(位置ループを含まない速度制御)
- トルク制御モード(トルク制御)

ただし，拡張制御「速度・トルク制御」の押当て制御モードへの切換えはできません。押当て制御モードへの切換えを行うとエラー「押当て制御未対応」(エラーコード: 19E7H)となり現在の制御を停止します。
また，"[Pr.90]速度・トルク制御モード動作設定"の「トルク初期値選択(b4～b7)」で，「1: フィードバックトルク」は設定できません。設定した場合，制御モード切換え時にワーニング「トルク初期値選択不可」(ワーニングコード: 09E5H)となり，切換え直後の指令値は「0: 指令トルク」を選択した場合と同じになります。

###### ■サーボパラメータ (付3 VCⅡ/VPH / 印刷 p.779 / 原本 p.781)

- サーボパラメータの管理

シンプルモーションユニットでは，VCⅡシリーズ／VPHシリーズのパラメータを管理しません。そのため，シンプルモーションユニットとVCⅡシリーズ／VPHシリーズが通信している状態で，VCⅡシリーズ／VPHシリーズ側のパラメータを変更してもシンプルモーションユニットのバッファメモリには反映されません。

- サーボパラメータ変更要求

サーボパラメータの変更要求("[Cd.130]サーボパラメータ読み出し／書き込み要求"～"[Cd.132]変更データ")は実行可能です。
ただし，VCⅡシリーズ／VPHシリーズのサーボパラメータは2ワード単位で管理されているため，必ず，"[Cd.130]サーボパラメータ読み出し／書き込み要求"を「0002H: 2ワード書込み要求」にしてパラメータ書込みを実施してください。VCⅡシリーズ／VPHシリーズに対して1ワード書込みを実施した場合，パラメータ書込みが失敗し，"[Cd.130]サーボパラメータ読み出し／書き込み要求"に「0003H: 読み出し／書き込み失敗」が格納されます。
サーボパラメータ変更要求によりVCⅡシリーズ／VPHシリーズのサーボパラメータを変更した場合，VCⅡ／VPHデータ編集ソフトからサーボパラメータ変更後のパラメータ値を確認することはできません。また，VCⅡシリーズ／VPHシリーズの電源をOFFした場合，サーボパラメータ変更要求により変更したパラメータは無効になり，VCⅡ／VPHデータ編集ソフトから書き込んだ値が有効になります。

原点復帰の動作やパラメータ([Pr.116]FLS信号選択，[Pr.117]RLS信号選択，[Pr.118]DOG信号選択)の"[Pr.22]入力信号論理選択"はIAI電動アクチュエータ用コントローラの仕様に依存するため，IAI電動アクチュエータ用コントローラのマニュアルを参照して合わせてください。シンプルモーションユニットで設定可能なパラメータについては，下記を参照してください。

###### ■サーボアンプ電子ギア設定 (付3 MR-J5 / 印刷 p.789 / 原本 p.791)

シンプルモーションユニットで回転型サーボモータを使用する場合，エンコーダ分解能を4194304 pulse/revとして制御します。そのため，HK-KTモータなどエンコーダ分解能が67108864 pulse/revであるサーボモータを使用する場合は，サーボパラメータ「電子ギア分子(PA06)」を16，「電子ギア分母(PA07)」を1に設定してください。
また，"[Pr.2]1回転あたりのパルス数(AP)"などの電子ギアは，エンコーダ分解能を4194304 pulse/revとして算出してください。設定の詳細は下記を参照してください。
☞ 230ページ 電子ギア機能

例: HK-KT (67108864 pulse/rev)を使用する場合

【図】HK-KT使用時の電子ギア構成(付3 / 印刷 p.789 / 原本 p.791)
- シンプルモーションユニット内: 指令値 →(制御単位)→ 電子ギア AP/(AL × AM) → サーボアンプへ「pulse」で指令。フィードバックは「pulse/16」で戻り、電子ギアを通して制御単位に換算される
- サーボアンプ(電子ギア分子(PA06): 16 / 電子ギア分母(PA07): 1)→ モータ(M)へ「pulse×16」→ 減速機 → 機械
- モータのエンコーダ(ENC)からサーボアンプへ「pulse」のフィードバックパルス

MR-J5(W)-Bとの接続時にサーボパラメータ「電子ギア分子(PA06)」，「電子ギア分母(PA07)」の設定が異なる場合は，エラー「アンプ電子ギア設定エラー」(エラーコード: 1C84H)が発生します。エラーが発生した場合，サーボパラメータ「電子ギア分子(PA06)」，「電子ギア分母(PA07)」を設定後，シーケンサレディ信号[Y0]をOFF → ONし，サーボアンプと再接続してください。
エラー「アンプ電子ギア設定エラー」(エラーコード: 1C84H)が発生した場合，サーボアンプのLED表示状態は"b_"となります。ただし，全軸サーボON[Y1]をONしても，サーボアンプはサーボON状態となりません。
なお，エラー「アンプ電子ギア設定エラー」(エラーコード: 1C84H)が発生した軸以降に接続されたサーボアンプは，全軸サーボON[Y1]をONすると，サーボON状態となります。
