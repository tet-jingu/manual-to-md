## 5 手動制御 (5章 / 印刷 p.166 / 原本 p.168)

本章では，手動制御の詳細や使い方について説明しています。
手動制御には，JOG始動信号をONすることによって実行するJOG運転とインチング運転，シンプルモーションユニットまたはCC-Link IE フィールドネットワーク機器に接続した手動パルス発生器から，指令を行う手動パルサ運転があります。
本章では，CPUユニットからのプログラムを使った手動制御について説明しています。

### 5.1 手動制御の概要 (5.1 / 印刷 p.166 / 原本 p.168)

#### 3つの手動制御 (5.1 / 印刷 p.166 / 原本 p.168)

「手動制御」は，位置決めデータを使用せず，外部からの信号入力に応じて任意に位置決め動作を行う制御です。
この「手動制御」には以下に示す3つの制御があります。

##### [JOG運転] (5.1 / 印刷 p.166 / 原本 p.168)

「JOG運転」は，任意の移動量だけ移動させる(JOG始動信号をONしている間，指令を出力し続ける)場合の制御方法です。
位置決めシステムの接続確認，位置決めデータのアドレスを求める(☞ 300ページ ティーチング機能)，リミット信号「OFF」によって運転が停止した場合に，リミット信号が「ON」する方向にワークを移動させる，という場合に使用します。

【図】JOG運転のイメージ(5.1 / 印刷 p.166 / 原本 p.168)
- モータ(M)とボールねじ上のワーク。図中注記「JOG始動信号がONしている間，移動をつづける」(右向き矢印)
- JOG始動信号: OFF → ON(立上り)し，ONを保持したのち ON → OFF。ONしている間ワークが移動する

##### [インチング運転] (5.1 / 印刷 p.166 / 原本 p.168)

「インチング運転」は，手動操作で微少移動量分の指令を演算周期で出力する制御方法です。JOG運転で軸制御データの「インチング移動量」を設定すると，設定された移動量だけ移動します。(ただし，「インチング移動量」の設定が0の場合はJOG運転として動作します。)

【図】インチング運転のイメージ(5.1 / 印刷 p.166 / 原本 p.168)
- モータ(M)とボールねじ上のワーク。図中注記「JOG始動信号がONして演算周期で出力されるパルスの移動量だけ移動する」(右向き矢印)
- JOG始動信号: OFF → ON(立上り)し，ONを保持したのち ON → OFF

##### [手動パルサ運転] (5.1 / 印刷 p.167 / 原本 p.169)

「手動パルサ運転」は，手動パルス発生器から入力されたパルス数に応じて位置決めを行う(入力されたパルス数の指令を出力する)場合の制御方式です。精密な位置決めの際の微調整などを手動で行い，位置決めアドレスを求める場合に使用します。

- 図中注記「位置／速度指令に応じて移動する」

- 図中注記「位置／速度指令に応じて移動する」

### 5.2 JOG運転 (5.2 / 印刷 p.168 / 原本 p.170)

#### JOG運転の動作概要 (5.2 / 印刷 p.168 / 原本 p.170)

##### 動作 (5.2 / 印刷 p.168 / 原本 p.170)

JOG運転では，正転JOG始動信号[Cd.181]もしくは逆転JOG始動信号[Cd.182]をONすることによって，ONしている間シンプルモーションユニットからサーボアンプに指令を出力し，指定の方向にワークを移動させます。
以下にJOG運転の動作例を示します。

###### ■動作例 (5.2 / 印刷 p.168 / 原本 p.170)

1. 始動信号をONすると，始動信号で指定した方向に，"[Pr.32]JOG運転加速時間選択"で指定した加速時間で加速をはじめる。このとき，BUSY信号OFF → ONとなる。
2. 加速中のワークが"[Cd.17]JOG速度"に設定した速度に達すると，この速度を維持して移動を続ける。(2.～3.では定速移動する。)
3. 始動信号をOFFすると，"[Cd.17]JOG速度"に設定した速度から，"[Pr.33]JOG運転減速時間選択"で指定した減速時間で減速をはじめる。
4. 速度が0になると停止する。このとき，BUSY信号ON → OFFとなる。

【図】JOG運転の動作例 タイミングチャート(5.2 / 印刷 p.168 / 原本 p.170)
- 速度波形: 正転JOG運転は 1. で「[Pr.32]で選択した加速時間による加速」で立ち上がり，2. で[Cd.17]JOG速度に到達して定速，3. で「[Pr.33]で選択した減速時間による減速」，4. で速度0。その後，逆転JOG運転(負方向)の台形波形
- シーケンサレディ信号[Y0]・全軸サーボON[Y1]・準備完了信号[X0]: 1. より前にすべて OFF → ON し，以後ONのまま
- [Cd.181]正転JOG始動: 1. で OFF → ON，3. で ON → OFF
- [Cd.182]逆転JOG始動: 4. の後(正転停止後)に OFF → ON，逆転JOG運転の減速開始時点で ON → OFF
- BUSY信号[X10, X11, X12, X13]: 1. で OFF → ON，4.(速度0)で ON → OFF。逆転JOG始動ONで再び OFF → ON，逆転の速度0で ON → OFF

> **制約事項**
> 上下限リミットの近くでJOG運転を行う場合は，ハードウェアストロークリミット機能を使用してください。(☞ 252ページ ハードウェアストロークリミット機能)
> ハードウェアストロークリミット機能を使用しない場合，ワークが移動範囲を越え，事故の原因となることがあります。

##### 動作上の注意 (5.2 / 印刷 p.169 / 原本 p.171)

JOG運転を行う前に，以下に示す内容を知っておく必要があります。
- 安全のため，"[Cd.17]JOG速度"は最初小さめの値を設定して動きを確かめ，徐々に値を大きくしてください。
- JOG始動時において，「JOG速度」が設定範囲外もしくは0の場合は，エラー「JOG速度範囲外」(エラーコード: 1980H)となり始動しません。
- "[Pr.31]JOG速度制限値"が"[Pr.8]速度制限値"より大きい値を設定した場合，エラー「JOG速度制限値エラー」(エラーコード: 1AB7H，1AB8H)となり始動しません。
- "[Cd.17]JOG速度"が"[Pr.31]JOG速度制限値"に設定された速度を超えている場合，"[Pr.31]JOG速度制限値"で動作し，シンプルモーションユニットはワーニング「JOG速度制限値」(ワーニングコード: 0981H，0982H)となります。
- 軸ワーニングとなった場合でもJOG運転は継続されます。
- "[Cd.16]インチング移動量"には0を設定してください。0以外を設定した場合，インチング運転として動作します。(☞ 177ページ インチング運転)

##### ストロークリミットエラー発生時の動作について (5.2 / 印刷 p.169 / 原本 p.171)

運転中にハードウェアストロークリミットエラー，もしくはソフトウェアストロークリミットエラーによって運転が停止した場合，エラーリセットを行った後，反対方向(正常範囲内方向)へのJOG運転を行うことができます。(リミット範囲外方向へのJOG始動信号がONした場合，再度エラーとなります。)

【図】ストロークリミットとJOG運転(5.2 / 印刷 p.169 / 原本 p.171)
- 縦軸V。JOG運転で定速移動中，上限／下限リミット信号が ON → OFF になった時点から減速して停止
- リミット信号ONの範囲が「JOG運転可」，OFFになった位置から先(リミット範囲外方向)が「JOG運転不可」

##### 動作タイミングと処理時間 (5.2 / 印刷 p.169-170 / 原本 p.171-172)

JOG運転時の動作のタイミングと時間についての詳細を示します。

###### ■動作例 (5.2 / 印刷 p.169 / 原本 p.171)

【図】JOG運転時の動作タイミング(5.2 / 印刷 p.169 / 原本 p.171)
- [Cd.181]正転JOG始動: OFF → ON，その後 ON → OFF
- [Cd.182]逆転JOG始動: OFFのまま
- BUSY信号[X10, X11, X12, X13]: [Cd.181]のONから t1 後に OFF → ON。位置決め動作の速度が0になってから t4 後に ON → OFF
- [Md.26]軸動作状態: 待機中(0) → BUSY信号ONと同時に JOG運転中(3) → BUSY信号OFFと同時に 待機中(0)
- 位置決め動作: BUSY信号ONから t3 後に加速開始。[Cd.181]OFFから t2 後に減速完了(速度0)
- 位置決め完了信号([Md.31]ステータス: b15): BUSY信号ONの時点でOFF(それ以前は破線で表示)，以後OFFのまま(JOG運転では位置決め完了信号はONしない)

### 5.3 インチング運転 (5.3 / 印刷 p.177 / 原本 p.179)

#### インチング運転の動作概要 (5.3 / 印刷 p.177 / 原本 p.179)

##### 動作 (5.3 / 印刷 p.177 / 原本 p.179)

インチング運転では，正転JOG始動信号[Cd.181]もしくは逆転JOG始動信号[Cd.182]をONすると，演算周期でサーボアンプに指令を出力し，指定の移動量だけワークを移動させます。
以下にインチング運転の動作例を示します。

1. 始動信号をONすると，始動信号で指定した方向に，インチング運転する。このとき，BUSY信号OFF → ONとなる。
2. ワークが"[Cd.16]インチング移動量"で設定した移動量だけ移動する。
3. 速度が0になると停止する。このときBUSY信号ON → OFFとなる。また位置決め完了信号OFF → ONとなる。
4. 位置決め完了信号が"[Pr.40]位置決め完了信号出力時間"で設定した時間経過後にON → OFFとなる。

###### ■動作例 (5.3 / 印刷 p.177 / 原本 p.179)

【図】インチング運転の動作例 タイミングチャート(5.3 / 印刷 p.177 / 原本 p.179)
- 速度波形: 1. から 3. までの短い矩形パルス(加減速なし)が「正転インチング運転」。2. はその移動区間
- シーケンサレディ信号[Y0]・全軸サーボON[Y1]・準備完了信号[X0]: 1. より前に OFF → ON し以後ON
- [Cd.181]正転JOG始動: 1. で OFF → ON。3. より後(4. より前)に ON → OFF
- BUSY信号[X10, X11, X12, X13]: 1. で OFF → ON，3. で ON → OFF
- 位置決め完了信号([Md.31]ステータス: b15): 3. で OFF → ON，「[Pr.40]位置決め完了信号出力時間」経過後の 4. で ON → OFF

##### 動作上の注意 (5.3 / 印刷 p.178 / 原本 p.180)

インチング運転を行う前に，以下に示す内容を知っておく必要があります。
- インチング運転では，加減速処理を行いません。

(指定されたインチング移動量分の指令は演算周期で出力されます。インチング運転の移動方向が逆になり，バックラッシュ補正を行う場合は，バックラッシュ補正量とインチング移動量を同一演算周期で出力します。)
