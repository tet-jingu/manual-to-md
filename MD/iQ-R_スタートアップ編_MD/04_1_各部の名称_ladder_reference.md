## 1.1 CPUユニット (1.1 / 原本p.23 / PDF p.25)

CPUユニットの各部の名称を示します。

### R00CPU (原本p.23-24 / PDF p.25-26)

【図】R00CPU外観図(前面・側面・底面の3面。render確認済み)。詳細は原本 p.23 を参照。

- 前面図: LED表示部(番号(1)(2)(3)(4)(5))・USBポート(前面下部)を配置。
- 側面図: SDメモリカードスロットに相当する拡張SRAMカセット用コネクタ(11)・バッテリコネクタ(12)・RUN/STOP/RESETスイッチ(8)・USBポート(9)・Ethernetポート系LED(6)(7)を配置。
- 底面図: 製造情報表示部(15)・取付けフック(13)(14)を配置。

番号(1)～(15)の詳細は下表のとおり。

#### R00CPU 各部の名称表 (原本p.24)

| 番号 | 名称 | 内容 |
|---|---|---|
| (1) | READY LED | ハードウェアの動作状態と異常内容の程度が表示されます。(83ページ CPUユニットのLEDの確認)<br>READY LED・ERROR LEDの点灯状態<br>点灯・消灯: 正常動作中<br>点灯・点灯: 軽度異常発生中<br>点灯・点滅: 中度異常発生中<br>点滅・点灯: 軽度異常発生中<br>点滅(2s間隔)・消灯: イニシャル処理中<br>消灯・点灯/点滅: 重度異常発生中 |
| (2) | ERROR LED | 上記(1)の表を参照。 |
| (3) | P RUN LED | プログラムの動作状態が表示されます。<br>点灯: プログラム実行中(RUN状態)<br>点滅: プログラム一時中断中(PAUSE状態)<br>消灯: プログラム停止中(STOP状態)，または停止エラー発生中 |
| (4) | USER LED | アナンシェータ(F)の状態が表示されます。(MELSEC iQ-R CPUユニットユーザーズマニュアル(応用編))<br>点灯: アナンシェータ(F)ON中<br>消灯: 正常動作中 |
| (5) | FUNC LED | 下記の各機能使用時に点灯/点滅します。<br>・LED表示設定<br>・外部入出力の強制ON/OFF<br>・プログラム復元情報書込み<br>・実行条件付きデバイステスト<br>機能による点灯/点滅状態については，各機能を参照してください。<br>MELSEC iQ-R CPUユニットユーザーズマニュアル(応用編) |
| (6) | SPEED LED | 下記を参照してください。<br>MELSEC iQ-R Ethernet/CC-Link IEユーザーズマニュアル(スタートアップ編) |
| (7) | SD/RD LED | 同上 |
| (8) | RUN/STOP/RESETスイッチ | CPUユニットの動作状態を操作するスイッチです。(80ページ プログラムの実行)<br>RUN: プログラムを実行する。<br>STOP: プログラムを停止する。<br>RESET: CPUユニットをリセットする。(約1秒RESET側に倒したままにする。)<br>RUN/STOP/RESETスイッチの操作は，指先で行ってください。ドライバなどの工具を使用するとスイッチ部を破損させる恐れがあるため，使用しないでください。 |
| (9) | USBポート*1 | USB対応周辺機器と接続するためのコネクタです。(コネクタタイプ miniB) |
| (10) | Ethernetポート | 下記を参照してください。<br>MELSEC iQ-R Ethernet/CC-Link IEユーザーズマニュアル(スタートアップ編) |
| (11) | バッテリ収納スペース | バッテリ(FX3U-32BL)装着時，バッテリ本体を収納するためのスペースです。 |
| (12) | バッテリコネクタ | バッテリ(FX3U-32BL)を接続するためのコネクタです。 |
| (13) | LEDカバー | LED，USBポート，バッテリのカバーです。USB対応周辺機器との接続やバッテリの着脱をする場合は，本カバーを開けて操作します。USB対応周辺機器との接続やバッテリの着脱をしない場合は，じんあいなどの異物混入を防止するため，本カバーを閉じてください。 |
| (14) | スイッチカバー | RUN/STOP/RESETスイッチのカバーです。RUN/STOP/RESETスイッチの操作をする場合は，本カバーを開けて操作します。RUN/STOP/RESETスイッチを操作しない場合は，じんあいなどの異物混入を防止するため，本カバーを閉じてください。 |
| (15) | 製造情報表示部 | ユニットの製造情報(16桁)を表示します。 |

*1 USBコネクタにケーブルを常時接続する場合，ケーブルはクランプによる固定処理を行ってください。ケーブルのふらつきや移動，不注意の引っ張りなどによるコネクタのはずれを防止します。
