## ReadDeviceBlock2(デバイスの一括読出し) (11.5 / 566-569 / 原本 p.568-571)

### 使用可能コントロール (11.5 / 566 / 原本 p.568)

下記のコントロールで使用可能です。

- 32ビット用: DotUtlType
- 64ビット用: DotUtlType64

### 機能 (11.5 / 566 / 原本 p.568)

2バイトデータで配列ラベルの一括読出しを行います。

### 書式 (11.5 / 566 / 原本 p.568)

**■Visual Basic .NET**

```vb
IRet = object.ReadDeviceBlock2(szLabel, iSize, sData)
```

| データ型 | 引数 | 内容 | Input/Output |
|---|---|---|---|
| Integer | IRet | 戻り値 | Output |
| String | szLabel | ラベル名 | Input |
| Integer | iSize | 読出し点数 | Input |
| Short | sData(n) | 読み出したデバイス値 | Output |

**■Visual C#**

```csharp
iRet = object.ReadDeviceBlock2(ref szLabel, iSize, ref sData)
```

| データ型 | 引数 | 内容 | Input/Output |
|---|---|---|---|
| int | iRet | 戻り値 | Output |
| String | szLabel | ラベル名 | Input |
| int | iSize | 読出し点数 | Input |
| short[n] | sData | 読み出したデバイス値 | Output |

### 戻り値 (11.5 / 566 / 原本 p.568)

正常終了: 0を返します。
異常終了: 0以外を返します。(☞617ページ エラーコード)

### 説明 (11.5 / 566 / 原本 p.568)

- ラベル名szLabelで指定したデバイスから，読出し点数iSize分のデバイスを一括して読み出します。
- 読み出したデバイス値は，sDataに格納されます。
- 読み出したデバイス値sDataには，読出し点数iSize以上の配列を確保してください。

> **Point**
> - 読出し点数に指定できる最大読出し点数は，下記の満たす範囲です。
>   読出し開始デバイス番号 + 読出し点数 ≦ 最終デバイス番号
> - ビット型配列のラベルを指定する場合，デバイス番号は0または16の倍数のみ指定できます。
> - ラベル名に指定しているデータ型に対応するワード数を読出し点数に指定してください。
>   読み出したデバイス値には，読出し点数に指定した点数分のメモリエリアを用意してください。
>   メモリエリアがない場合は，アプリケーションエラーなどの重大な現象が発生するおそれがあります。
> - ラベル名に対応するデバイスが存在しない場合はエラーとなり，読み出せません。
>   複数のラベル名に対応するデバイスが一部存在しない場合もエラーとなり，読み出せません。
> - ビットデバイスの桁指定およびインデックス修飾は，使用できません。
> - ロングタイマの接点(LTS)，ロングタイマのコイル(LTC)，ロング積算タイマの接点(LSTS)，ロング積算タイマのコイル(LSTC)のデバイスの読出しはできません。ReadDeviceRandom2関数，またはGetDevice2関数を使用してください。

## ReadDeviceRandom2(デバイスのランダム読出し) (11.5 / 575-583 / 原本 p.577-585)

### 使用可能コントロール (11.5 / 575 / 原本 p.577)

下記のコントロールで使用可能です。

- 32ビット用: DotUtlType
- 64ビット用: DotUtlType64

### 機能 (11.5 / 575 / 原本 p.577)

2バイトデータでデバイスのランダム読出しを行います。

### 書式 (11.5 / 575 / 原本 p.577)


| Integer | iSize | 読出し点数 | Input |


| データ型 | 引数 | 内容 | Input/Output |
|---|---|---|---|
| Integer | IRet | 戻り値 | Output |


※Visual C#の戻り値のデータ型「Int」(先頭大文字)は原本表記のまま。

### 戻り値 (11.5 / 575 / 原本 p.577)

正常終了: 0を返します。
異常終了: 0以外を返します。(☞617ページ エラーコード)

### 説明 (11.5 / 576 / 原本 p.578)

- ラベル名szLabel(szLabelList)で指定したデバイス群を，読出し点数iSize分のデバイス値だけ読み出します。
- 読み出したデバイス値は，sDataに格納されます。
- 読み出したデバイス値sDataには，読出し点数iSize以上の配列を確保してください。

> **Point**
> - 読出し点数に指定できる最大読出し点数は，0x7FFFFFFF点までです。
> - ラベル名に指定しているデータ型に対応するワード数を読出し点数に指定してください。読み出したデバイス値には，読出し点数に指定した点数分のメモリエリアを用意してください。メモリエリアがない場合は，アプリケーションエラーなどの重大な現象が発生するおそれがあります。
> - ラベル名に対応するデバイスが存在しない場合はエラーとなり，読み出せません。
>   複数のラベル名に対応するデバイスが一部存在しない場合もエラーとなり，読み出せません。
> - ダブルワードデバイスを指定した場合，本関数では下位1ワード(2バイト)分のデータのみ格納されます。(エラーは発生しません。)ダブルワードデバイスの読出しを行う場合は，ReadDeviceRandom関数またはReadDeviceBlock関数を使用してください。
> - ビットデバイスの桁指定およびインデックス修飾は，使用できません。
> - 構造体は5階層まで定義できます。ただし，静的システムラベルは1階層目の構造体までのみ使用できます。
