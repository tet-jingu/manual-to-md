## 3.1 MX Componentのインストール (3.1 / 41 / 原本 p.43)

MX Componentをパソコンにインストールしてください。インストール方法については，下記を参照してください。
📖MX Component Version 5 インストール手順書

### 注意事項 (3.1 / 41 / 原本 p.43)

- 上書きインストールを行う場合は，すでにインストールされているフォルダと同じフォルダにインストールしてください。
- インストーラをダウンロードして使用する場合，スペースを含まないディレクトリに保存し実行してください。
- MX Componentをアンインストールした場合に，スタートメニューに項目が残ることがあります。その場合は，パソコンを再起動してください。

### バージョンの確認 (3.1 / 41 / 原本 p.43)

各ユーティリティのヘルプからバージョンを確認できます。

**操作手順**

[ヘルプ]⇒[バージョン情報]を選択します。

### マニュアルを開く (3.1 / 41 / 原本 p.43)

各ユーティリティのヘルプからe-Manualが開けます。

**操作手順**

[ヘルプ]⇒[ヘルプ]を選択します。

## 3.2 使用するコントロールの把握 (3.2 / 42 / 原本 p.44)

MX Componentを使用してユーザプログラムを開発する場合，処理の内容や通信設定方法によって使用するコントロールが異なります。
開発の内容にあったコントロールを確認してください。

| 処理の内容 | 対応言語 | 通信設定 | コントロールの種類 | コントロール名(上段: 32ビット用，下段: 64ビット用) |
|---|---|---|---|---|
| デバイスデータの読書き | • Visual Basic .NET<br>• Visual C#<br>• Visual C++<br>• VBA | 通信設定ユーティリティで設定 | Actコントロール | ActUtlType<br>ActUtlType64 |
| デバイスデータの読書き | (同上) | プログラムで設定 | Actコントロール | ActProgType<br>ActProgType64 |
| トラブルシュート処理 | (同上) | 通信設定方法に関わらず同一のコントロールを使用 | Actコントロール | ActSupportMsg<br>ActSupportMsg64 |
| ロギングファイルの転送 | (同上) | 通信設定ユーティリティで設定 | Actコントロール(ロギングファイル転送用) | ActUtlDataLogging<br>ActUtlDataLogging64 |
| ロギングファイルの転送 | (同上) | プログラムで設定 | Actコントロール(ロギングファイル転送用) | ActProgDataLogging<br>ActProgDataLogging64 |
| ラベルデータの読書き*1 | • Visual Basic .NET<br>• Visual C# | 通信設定ユーティリティでの設定のみ可能 | .Net コントロール | DotUtlType<br>DotUtlType64 |

※原本では「対応言語」(Visual Basic .NET / Visual C# / Visual C++ / VBA)は上5行でセルを共有。

> *1 ラベル管理ユーティリティで作成したラベルでアクセスします。グローバルラベルでアクセスする場合は，「デバイスデータの読書き」のActコントロールを使用してください。

## 3.3 通信設定方法の選択 (3.3 / 42 / 原本 p.44)

通信設定方法(開発タイプ)として通信設定ユーティリティを使用する方法(ユーティリティ設定タイプ)またはプログラムを使用する方法(プログラム設定タイプ)のどちらかを選択してください。
ユーティリティ設定タイプとプログラム設定タイプの違いについて示します。

| 開発タイプ | 特長 | ユーザプログラム内での指定方法 | 使用可能なコントロール |
|---|---|---|---|
| ユーティリティ設定タイプ | 通信設定ユーティリティを使用して，各通信の複雑なパラメータを意識することなくユーザプログラムが作成できます。通信設定は，通信設定ウィザードに従って設定します。<br>各通信設定は論理局番を付与してパソコン内に保存されます。 | 通信設定ウィザードで設定した論理局番を，Actコントロールおよび.Netコントロールのプロパティ，またはユーザプログラム内部で指定します。 | • ActUtlType<br>• ActUtlDataLogging<br>• ActSupportMsg<br>• DotUtlType<br>• ActUtlType64<br>• ActUtlDataLogging64<br>• ActSupportMsg64<br>• DotUtlType64 |
| プログラム設定タイプ | 通信設定ユーティリティを使用しないで，ユーザプログラムを作成します。*1<br>ユーザプログラムにて，柔軟に通信設定が変更できます。 | Actコントロールのプロパティウィンドウに直接入力またはユーザプログラム内部で設定します。<br>なお，設定が必要となるプロパティは，各Actコントロールにより異なります。 | • ActProgType<br>• ActProgDataLogging<br>• ActSupportMsg<br>• ActProgType64<br>• ActProgDataLogging64<br>• ActSupportMsg64 |

> *1 暗号化通信を行う場合は，通信設定ユーティリティで証明書管理機能を使用して証明書を登録する必要があります。
