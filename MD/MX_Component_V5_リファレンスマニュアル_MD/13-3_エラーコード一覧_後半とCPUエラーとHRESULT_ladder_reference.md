### エラーコード確認時の注意事項 (13.2 / 644 / 原本 p.646)

CPU，ユニットおよびネットワークボードが返すエラーコード確認時の注意事項を以下に示します。

#### プロパティ設定ミス (13.2 / 644 / 原本 p.646)

使用しているシステム構成と設定したプロパティ値が一致しない場合，上位2バイトが正しいエラー検出ユニットを示しません。
例えば，QCPU(Qモード)に対して，ActCpuTypeにFXCPUのプロパティ値を設定している場合では，上位2バイトはFXCPUがエラー検出ユニットとなる場合があります。
このような場合は，システム構成と設定した全プロパティの値を確認の上，再度通信を行ってください。
また，ActUtlTypeコントロールを使用している場合は，通信設定ユーティリティの設定内容を確認ください。

#### 他局アクセス時 (13.2 / 644 / 原本 p.646)

他局アクセス時には，使用している経由ユニット(CC-Link IEコントローラネットワーク，MELSECNET/H，CC-Link，シリアルコミュニケーション通信，Ethernetユニット)のエラーコードが，下位2バイトに入る場合があります。
このような場合には，エラー検出ユニットを示す上位2バイトが必ずしもエラー発生したユニットと一致しない場合がありますので，システム構成を確認の上，使用しているCPU，経由ネットワークユニットおよびネットワークボードのマニュアルも合わせてご確認ください。

## 13.3 HRESULT型のエラーコード (13.3 / 645 / 原本 p.647)

ディスパッチI/Fを使用の場合，HRESULT型の戻り値は例外処理を行うことで取得できます。
ActコントロールのHRESULT型の戻り値を以下に示します。

| 戻り値 | 終了状態 | 内　　容 |
|---|---|---|
| S_OK | 正常終了 | 関数処理が正常に終了しました。 |
| S_FALSE | 正常終了 | 関数処理(ActiveXコントロールとしての)は正常終了しましたが，操作(シーケンサへのアクセス)は失敗しました。 |
| E_POINTER | 異常終了 | 関数に渡されたポインタが異常です。 |
| E_OUTOFMEMORY | 異常終了 | メモリ確保またはオブジェクト作成に失敗しました。 |
| E_FAIL | 異常終了 | 不特定のエラーが発生しました。 |

> **Point**
> ディスパッチI/Fは，HRESULT型の戻り値を取得するための例外処理を行っていない場合，ActコントロールからE_POINTER(E_XXXXX定義の戻り値)などが返ったときにOSレベルでエラーダイアログを表示します。

## 13.4 イベントビューアに表示されるエラーコード (13.4 / 645 / 原本 p.647)

MX ComponentがWindowsのイベントビューアに表示するエラーコードについて説明します。
MX Componentでは，ラベル情報を管理するために，MMS(システムラベルデータベース)サービスとラベル管理サービスを使用します。
ラベル管理サービスでエラーが発生した場合，イベントビューアのシステムログにエラー内容が表示されます。
MX Componentのラベル管理サービスに関するエラーは，イベントビューアのソース欄に「MXLabelService」と表示されます。
エラーと処置方法を以下に示します。

|---|---|---|
| 3 | MMS Service not started. | • MMS(システムラベルデータベース)サービスが起動完了するまでしばらくお待ちください。起動完了しない場合は，プログラムを終了し，パソコンを再起動してください。<br>• MX Componentを再インストールしてください。<br>• 弊社，電話技術相談窓口に連絡してください。 |
| 5 | MXLabelService error.(%1,%2)<br>please perform one of the followings.<br>-Re-start Personal computer.<br>-Re-install the application and try again. | • プログラムを終了し，パソコンを再起動してください。<br>• MX Componentを再インストールしてください。<br>• 弊社，電話技術相談窓口に連絡してください。 |
