## 7.1 ラベル管理ユーティリティを使ったラベルの作成(続き)

### システムラベルについて (7.1 / 134 / 原本 p.136)

システムラベルとは，シーケンサやモーションコントローラのデバイスをシステムラベルとして公開することにより，複数のアプリケーションで共有して使用することができるラベルです。
これにより，プログラミング効率が向上します。
また，デバイスの設定が一括して変更されるため，アプリケーションでのデバイスの変更は不要です。

#### システムラベルを使用する (7.1 / 134 / 原本 p.136)

MX Componentのラベル管理ユーティリティを使用してラベルを登録し，コントロールから使用します。

【図】システムラベル使用の構成 (7.1 / 134 / 原本 p.136)
- ユーザアプリケーション(Visual Basic .NET / Visual C# / VBA)→ MX Component(ラベル管理ユーティリティ，システムラベルデータベース)↔ シーケンサ
- 図中のコード例(原本表記のまま):

```
Act.LogifalNumber=1;
Act.Open();
ret=Act.GetDevice(”温度”, Data);
Act.Close();
```

※「LogifalNumber」は原本図の表記のまま(ActLogicalStationNumber の意と思われる。要確認)。

> **Point**
> - システムラベルについて
>   デバイスと1対1で定義し，登録します。
>   構造体を使用できます。構造体とは，いろいろなデバイスを1つの集合体にまとめたものです。
>   データ型を設定します。データ型は，すべて配列にすることができます。
>   MELSOFT Navigatorで使用するシステムラベルを流用することができます。
> - システムラベルデータベースについて
>   システムラベルデータベースは，システムラベルを管理するためのデータベースです。
> - システムラベルVer.2について
>   MX Component Version 4.07H以降にて，システムラベルVer.2へ登録できます。
>   構造体型，配列型のシステムラベルも登録できます。
>   構造体型のシステムラベルは，MX Component Version 4.11M以降にて，5階層の構造体まで使用できます。

#### MX Componentでシステムラベルを登録して使用する (7.1 / 135-140 / 原本 p.137-142)

ラベル管理ユーティリティでシステムラベルを登録します。

##### システムラベルを登録する (7.1 / 135-136 / 原本 p.137-138)

**操作手順**

1. ラベル管理ユーティリティを起動します。
2. ラベルスペース一覧の"名称未定義"を選択して右クリックし，[ラベルスペースの名前変更]を選択します。
   ラベルスペース名を変更します。
3. ナビゲーションウィンドウの"システムラベルリスト"を選択して右クリックし，[システムラベルリスト]⇒[新規作成]を選択します。
   システムラベルリスト名を設定します。
   設定したシステムラベルリスト名を選択すると，システムラベルリストが表示されます。
4. システムラベル名，データ型，デバイス名を設定します。(☞124ページ システムラベルリスト)
5. ナビゲーションウィンドウの"論理局番"を選択して右クリックし，[論理局番]⇒[登録]を選択します。
6. 論理局番を選択し，[登録]ボタンをクリックします。
   通信設定を行う場合は，[通信設定]ボタンをクリックし，通信設定ウィザードで設定を行ってください。(☞58ページ 通信設定ウィザード画面の操作)
   論理局番がナビゲーションウィンドウに表示されます。
7. [メニュー ]⇒[ラベルスペースの保存]を選択します。
   システムラベルが登録されます。
8. [メニュー ]⇒[システムラベルデータの最新化]を選択します。
   コントロールから参照するラベルが最新に更新されます。

【図】手順の画面 (7.1 / 135-136 / 原本 p.137-138)
- 手順2: ラベルスペース一覧の右クリックメニュー = ラベルスペースの追加(N) / ラベルスペースの追加Ver.2 / ラベルスペースの名前変更(A) / ラベルスペースの削除(D)

##### システムラベルを削除する (7.1 / 137 / 原本 p.139)

**操作手順**

1. 削除するシステムラベルの"削除"にチェックを入れます。
2. [メニュー ]⇒[ラベルスペースの保存]を選択します。
   システムラベルが削除されます。
3. [メニュー ]⇒[システムラベルデータの最新化]を選択します。
   コントロールから参照するラベルが最新に更新されます。

【図】手順1の画面例 (7.1 / 137 / 原本 p.139): 行1 スタートランプ / ビット / M0 の"削除"にチェック

##### システムラベルを登録する(構造体型) (7.1 / 138-140 / 原本 p.140-142)

**操作手順**

1. ラベル管理ユーティリティを起動します。
2. ラベルスペース一覧の"名称未定義"を選択して右クリックし，[ラベルスペースの名前変更]を選択します。
   ラベルスペース名を変更します。
3. ナビゲーションウィンドウの"構造体"を選択して右クリックし，[構造体]⇒[新規作成]を選択します。
   構造体名を設定します。
   設定した構造体名を選択すると，構造体設定の一覧が表示されます。
4. 構造体メンバのラベル名，データ型を設定します。(☞129ページ 構造体設定)
5. ナビゲーションウィンドウの"システムラベルリスト"を選択して右クリックし，[システムラベルリスト]⇒[新規作成]を選択します。
   システムラベルリスト名を設定します。
   設定したシステムラベルリスト名を選択すると，システムラベルリストが表示されます。
6. システムラベル名，データ型を設定します。(☞124ページ システムラベルリスト)
   システムラベルリストのデバイス欄で"詳細設定"をクリックします。
7. デバイスを指定します。
8. [メニュー ]⇒[ラベルスペースの保存]を選択します。
   システムラベルが登録されます。
9. [メニュー ]⇒[システムラベルデータの最新化]を選択します。
   コントロールから参照するラベルが最新に更新されます。

#### MELSOFT Navigatorで使用するラベルを流用する (7.1 / 141-142 / 原本 p.143-144)

ラベル管理ユーティリティで，既存のワークスペースからシステムラベルを参照し登録します。

**操作手順**

1. ラベル管理ユーティリティを起動します。
2. ラベルスペース一覧の"名称未定義"を選択して右クリックし，[ラベルスペースの名前変更]を選択します。
   ラベルスペース名を変更します。
3. ナビゲーションウィンドウの"参照ワークスペース"を選択して右クリックし，[ワークスペース]⇒[参照登録]を選択します。
4. 参照登録するワークスペースを選択します。
   (☞130ページ ワークスペースの参照登録/解除)
   ナビゲーションウィンドウに参照登録したワークスペース名が表示されます。
   システムラベルリスト名を選択すると，参照しているシステムラベルの一覧が表示されます。
5. [メニュー ]⇒[ラベルスペースの保存]を選択します。
   システムラベルが登録されます。
   複数のワークスペースを参照する場合は，ラベルスペースを追加後，手順2.～4.を行ってください。
6. [メニュー ]⇒[システムラベルデータの最新化]を選択します。
   コントロールから参照するラベルが最新に更新されます。

【図】手順の画面 (7.1 / 141-142 / 原本 p.143-144)
- 手順3: 「ワークスペース(W)」⇒「参照登録(N)」
- 手順4: "開く(ワークスペース)"画面 = 保存先パス C:\MELSEC\Navigator(画面上は¥表記)，ワークスペース一覧に WS_001，ワークスペース名 WS_001，[開く] [キャンセル]
- 登録後: ナビゲーションウィンドウに「参照ワークスペース:WS_001」

#### GX Works2でのデバイス変更をMX Componentへ反映する (7.1 / 143-144 / 原本 p.145-146)

参照登録したシステムラベルのデバイス割付をGX Works2で変更後，ラベル管理ユーティリティで変更内容を反映します。

**操作手順**

1. ラベル管理ユーティリティを起動します。
   ラベル管理ユーティリティのステータスバーにシステムラベル通知アイコンが表示されます。
2. ラベルスペース名を選択します。
3. システムラベル通知アイコンを右クリックし，[システムラベルデータベースの変更内容]を選択します。
   (☞131ページ 変更通知)
4. 変更内容の取り込みを確認する画面で[はい]ボタンをクリックします。
   システムラベルリスト名を選択すると，システムラベルリストが表示されます。
5. [メニュー ]⇒[ラベルスペースの保存]を選択します。
   システムラベルが登録されます。
   複数のワークスペースを参照する場合は，ラベルスペース一覧よりほかのラベルスペース名を選択後，手順2.～4.を行ってください。
   複数のワークスペースを参照している場合は，システムラベル通知アイコンが表示されたままとなります。
6. [メニュー ]⇒[システムラベルデータの最新化]を選択します。
   コントロールから参照するラベルが最新に更新されます。

【図】手順の画面 (7.1 / 143-144 / 原本 p.145-146)
- 手順1: ステータスバー左端のシステムラベル通知アイコン(「S」に赤い＊印)
- 手順3: アイコン右クリックメニュー「システムラベルデータベースの変更内容(E)」
- 手順4後の例: システムラベルリスト Label1 = スタートランプ / ビット / X0(デバイスが変更後の値に更新)

> **Point**
> ワークスペースの参照登録を行わずにシステムラベルを使用している場合，変更通知は表示されません。

#### 別のパソコンでシステムラベルを使用する (7.1 / 145-147 / 原本 p.147-149)

エクスポートを行うパソコンとは別のパソコンでシステムラベルを使用します。

##### ラベルスペースのエクスポート (7.1 / 145 / 原本 p.147)

ラベルスペースのエクスポートを行い，ファイルを作成します。

**操作手順**

1. 通信設定ユーティリティを起動します。
2. [メニュー ]⇒[通信設定のエクスポート]を選択します。
3. 保存するファイル名を入力します。
4. ラベル管理ユーティリティを起動します。
5. [メニュー ]⇒[エクスポート]を選択します。
6. 保存するファイル名を入力します。
