## 5.1 ユーティリティを使った設定 (5.1 / 56-70 / 原本 p.58-72)

通信設定ユーティリティを使って通信を行う手順や通信設定ユーティリティの操作，設定方法について説明します。

### 作業の流れ (5.1 / 56 / 原本 p.58)

1. 通信設定ユーティリティを使って論理局番ごとの設定を作成する
2. ユーザプログラムの中のActLogicalStationNumberプロパティに論理局番を指定する

### 論理局番について (5.1 / 56 / 原本 p.58)

論理局番とは，通信回線をオープンさせるために必要な接続先情報を，通信設定ユーティリティを使用し1つのデータにまとめ，そのデータに論理的な番号を付けたものです。

**例**
CPU COM通信時

【図】論理局番の考え方(CPU COM通信時) (5.1 / 56 / 原本 p.58)
- パソコン側: CPU COM通信 (COM1)，タイムアウト時間
- パソコン ― CPUユニット間: 伝送速度，伝送制御
- CPUユニットのEthernetユニット(局番: 1) ― Ethernet（ネットワークNo.1）― Ethernetユニット(局番: 3)のCPUユニット(通信対象CPU)
- 図中注記: 通信対象CPUまでの接続先情報を1つのデータにまとめ，そのデータに論理局番を割り付けます。(破線で囲まれた範囲 = パソコン側設定〜通信対象CPUまで)

Windowsのスタートで"MELSOFT"から通信設定ユーティリティを起動します。

### 通信設定ウィザード画面の操作 (5.1 / 58-61 / 原本 p.60-63)

ユーティリティ設定タイプで通信するために必要な論理局番の設定をします。

#### 通信設定ウィザードの概要 (5.1 / 58 / 原本 p.60)

ユーティリティ設定タイプで通信するのに必要な論理局番を，ウィザード形式で設定します。

【図】通信設定ウィザードの設定範囲 (5.1 / 58 / 原本 p.60)
- パソコン(MX Component) … ウィザード(1)，(6)
- パソコン〜接続局間の「接続ネットワーク」… ウィザード(2)
- 接続局 … ウィザード(3)
- 接続局〜経由局間の「経由ネットワーク」… ウィザード(4)
- 経由局 … ウィザード(5)

通信設定ウィザードの各画面で設定する内容は下記のとおりです。

| 通信設定ウィザード | 画面名 | 内容 |
|---|---|---|
| ウィザード(1) | はじめに | 論理局番を設定します。 |
| ウィザード(2) | パソコン側 | パソコン・接続局(CPUユニットおよびユニット)間の接続ネットワークを設定します。 |
| ウィザード(3) | シーケンサ側 | 接続局(CPUユニットおよびユニット)を設定します。 |
| ウィザード(4) | ネットワーク | 接続局(CPUユニットおよびユニット)・経由局(CPUユニットおよびユニット)間の経由ネットワークを設定します。 |
| ウィザード(5) | 相手先設定 | 経由局CPUを設定します。 |
| ウィザード(6) | 完了 | 論理局番にコメントを付けます。 |

#### 通信設定ウィザード画面の表示方法 (5.1 / 58 / 原本 p.60)

**画面表示**

- [メニュー ]⇒[通信設定ウィザード]を選択します。
- ユーティリティ画面の[ウィザード]ボタンをクリックします。

【図】[メニュー(M)]の展開 (5.1 / 58 / 原本 p.60)
- メニュー項目: 通信設定(T) / 一覧表示(L) / 通信テスト(C) / 通信設定のインポート(I)... / 通信設定のエクスポート(E)... / 通信設定ウィザード(W)... / 通信設定ユーティリティの終了(X)

#### 通信設定ウィザード画面の表示の流れ (5.1 / 59-60 / 原本 p.61-62)

通信設定ウィザード画面は，ウィザード(1)から順にウィザード(6)まで表示されます。
通信設定ウィザード画面が表示される順に沿って説明します。

> **Point**
> - 通信設定ウィザード画面は，設定内容によって表示または設定可能項目の内容が異なります。
>   表示されている設定可能項目をすべて設定してください。
> - 通信設定ウィザード画面は，設定内容によって表示されない画面もあります。
> - 一時的な断線などが原因でMX Componentにて設定したタイムアウト時間の間，コントロールやシーケンサモニタユーティリティが応答待ちになる場合があります。
>   タイムアウトエラーが発生するように，適切なタイムアウト時間を設定してください。

**操作手順**

ウィザード(1) - はじめに

1. 論理局番を入力または選択します。
   論理局番は，0～1023まで登録可能です。

【図】通信設定ウィザード - はじめに (5.1 / 59 / 原本 p.61)
- 画面文言: 「通信設定ウィザードは，通信情報の作成を支援します。」「「戻る」をクリックして，選択した項目をいつでも変更できます。」「開始するには「次へ」をクリックしてください。」「論理局番を選択してください。」，論理局番(ドロップダウン)

ウィザード(2) - パソコン側

2. パソコン側のインタフェースを選択します。
   "パソコン側I/F"の選択項目(☞61ページ パソコン側I/Fの各通信に対応した選択項目)

【図】通信設定ウィザード - パソコン側 (5.1 / 59 / 原本 p.61)
- 画面例: パソコン側I/F = シリアル，通信設定: 接続ポート = COM1，タイムアウト = 10000 ms

ウィザード(3) - シーケンサ側

3. シーケンサ側のインタフェースを選択します。
   GOT経由を選択した場合(☞60ページ GOT経由を選択した場合)

【図】通信設定ウィザード - シーケンサ側 (5.1 / 59 / 原本 p.61)
- 画面例: シーケンサ側I/F = CPUユニット，通信設定: CPUタイプ = Q00UJ，伝送速度 = 9600 bps，伝送制御 = DTR or RTS Control

ウィザード(4) - ネットワーク

4. 通信経路を選択します。

【図】通信設定ウィザード - ネットワーク (5.1 / 60 / 原本 p.62)
- 画面例: 局番タイプ = 他局，通信経路 = MELSECNET/H，通信経路設定: モード = MELSECNET/H

ウィザード(5) - 相手先設定

5. 相手先設定を選択します。

【図】通信設定ウィザード - 相手先設定 (5.1 / 60 / 原本 p.62)
- 画面例: CPUタイプ = R00，ネットワークNo. = 1，局番 = 1，マルチCPU号機 = 指定なし

ウィザード(6) - 完了

6. コメントを入力し，[完了]ボタンをクリックします。
   コメントは半角で32文字まで入力可能です。
   通信設定ウィザードで論理局番の登録が完了すると，通信設定画面に設定内容が表示されます。

【図】通信設定ウィザード - 完了 (5.1 / 60 / 原本 p.62)
- 画面文言: 「通信設定ウィザードは情報の収集を完了しました。」「「完了」をクリックすると，通信情報を作成します。」，コメント入力欄，[完了]

### ユーザ認証情報管理 (5.1 / 64-65 / 原本 p.66-67)

ユーザ認証情報管理機能を使用し，MXコントローラのユーザ認証情報をMX Componentに登録します。
ユーザ認証機能が有効であるMXコントローラと通信を行うには，MXコントローラにログオン可能なユーザ認証情報の登録が必要です。
プログラム設定タイプのコントロールを使用する場合，本機能での登録は不要です。
本機能はMXコントローラのみ対応しています。

**画面表示**

### 通信設定のエクスポートとインポート (5.1 / 68-69 / 原本 p.70-71)

#### エクスポート (5.1 / 68 / 原本 p.70)

> **Point**

> - 通信設定ユーティリティの設定内容を保存しておきたい場合，ファイルのエクスポートを行ってください。
> - MX Component Version 4.11M以前の通信設定ユーティリティでインポートする場合はファイルの種類で*.actを選択し，保存したファイルを使用します。
