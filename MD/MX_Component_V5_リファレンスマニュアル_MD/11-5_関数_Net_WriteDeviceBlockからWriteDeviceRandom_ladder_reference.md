## WriteDeviceBlock(デバイスの一括書込み) (11.5 / 512-517 / 原本 p.514-519)

### 使用可能コントロール (11.5 / 512 / 原本 p.514)

下記のコントロールで使用可能です。

- 32ビット用: DotUtlType
- 64ビット用: DotUtlType64

### 機能 (11.5 / 512 / 原本 p.514)

配列ラベルの一括書込みを行います。

### 書式 (11.5 / 512 / 原本 p.514)

#### Visual Basic .NET (11.5 / 512 / 原本 p.514)

```vb
IRet = object.WriteDeviceBlock(szLabel, iSize, iData)
```

| データ型 | 引数 | 内容 | Input/Output |
|---|---|---|---|
| Integer | IRet | 戻り値 | Output |
| String | szLabel | ラベル名 | Input |
| Integer | iSize | 書込み点数 | Input |
| Integer | iData(n) | 書き込むデバイス値 | Input |

#### Visual C# (11.5 / 512 / 原本 p.514)

```csharp
iRet = object.WriteDeviceBlock(ref szLabel, iSize, iData)
```

| データ型 | 引数 | 内容 | Input/Output |
|---|---|---|---|
| int | iRet | 戻り値 | Output |
| String | szLabel | ラベル名 | Input |
| int | iSize | 書込み点数 | Input |
| int[n] | iData | 書き込むデバイス値 | Input |

### 戻り値 (11.5 / 512 / 原本 p.514)

正常終了: 0を返します。
異常終了: 0以外を返します。(☞617ページ エラーコード)

### 説明 (11.5 / 512-513 / 原本 p.514-515)

- ラベル名szLabelで指定したデバイスから，書込み点数iSize分のデバイスを一括して書き込みます。
- 書き込むデバイス値は，iDataに格納します。
- 書き込むデバイス値iDataには，書込み点数iSize以上の配列を確保してください。

> **Point**
> - 書込み点数に指定できる最大書込み点数は，下記の満たす範囲です。
>   書込み開始デバイス番号 + 書込み点数 ≦ 最終デバイス番号
> - ビット型配列のラベルを指定する場合，デバイス番号は0または16の倍数のみ指定できます。
> - ラベル名に指定しているデータ型に対応するワード数を書込み点数に指定してください。書き込むデバイス値には，書込み点数に指定した点数分のメモリエリアを用意してください。メモリエリアがない場合は，アプリケーションエラーなどの重大な現象が発生するおそれがあります。
> - ラベル名に対応するデバイスが存在しない場合はエラーとなり，書込みできません。
>   複数のラベル名に対応するデバイスが一部存在しない場合もエラーとなり，書込みできません。
> - ビットデバイスの桁指定およびインデックス修飾は，使用できません。
> - ロングタイマの接点(LTS)，ロングタイマのコイル(LTC)，ロング積算タイマの接点(LSTS)，ロング積算タイマのコイル(LSTC)のデバイスの書込みはできません。WriteDeviceRandom関数，またはSetDevice関数を使用してください。
> - システムラベルVer.2を使用する場合，MX Componentのラベル管理ユーティリティで定義したデータ型とMELSOFT Navigatorで管理するデータ型は一致している必要があります。
>   データ型が一致していない場合，実際に読み出されるデータの長さが不正となったり，複数のラベルを指定した場合に読み出したデバイス値の配列とラベル名の対応がずれる場合があります。
> - RnSFCPUのセーフティモードで安全デバイスに対して実行した場合は，エラーコード"0x010A42A5"(セーフティモードでは実施できない操作を行った)が返されます。

※「≦」はテキスト抽出で欠落していたため，原本画像で確認して補った。

| int[n] | iData | 読み出したデバイス値 | Output |

### 戻り値 (11.5 / 518 / 原本 p.520)

正常終了: 0を返します。
異常終了: 0以外を返します。(☞617ページ エラーコード)

### 説明 (11.5 / 519 / 原本 p.521)

- ラベル名szLabel(szLabelList)で指定したデバイス群を，読出し点数iSize分のデバイス値だけ読み出します。
- 読み出したデバイス値は，iDataに格納されます。
- 読み出したデバイス値iDataには，読出し点数iSize以上の配列を確保してください。

> **Point**
> - 読出し点数に指定できる最大読出し点数は，0x7FFFFFFF点までです。
> - ラベル名に指定しているデータ型に対応するワード数を読出し点数に指定してください。読み出したデバイス値には，読出し点数に指定した点数分のメモリエリアを用意してください。メモリエリアがない場合は，アプリケーションエラーなどの重大な現象が発生するおそれがあります。
> - ラベル名に対応するデバイスが存在しない場合はエラーとなり，読み出せません。
>   複数のラベル名に対応するデバイスが一部存在しない場合もエラーとなり，読み出せません。
> - ビットデバイスの桁指定およびインデックス修飾は，使用できません。
> - 構造体は5階層まで定義できます。ただし，静的システムラベルは1階層目の構造体までのみ使用できます。
> - システムラベルVer.2を使用する場合，MX Componentのラベル管理ユーティリティで定義したデータ型とMELSOFT Navigatorで管理するデータ型は一致している必要があります。
>   データ型が一致していない場合，実際に読み出されるデータの長さが不正となったり，複数のラベルを指定した場合に読み出したデバイス値の配列とラベル名の対応がずれる場合があります。

| 時間 | 2*2 |

| 構造体 | 構造体メンバのデータ型に対応するワード数の合計値 |

> *1 配列ラベルに対してラベル名のみ(要素指定なし)でアクセスする場合，読出し点数には本表の読出し点数と配列要素数との積を指定してください。

### 戻り値 (11.5 / 529 / 原本 p.531)

正常終了: 0を返します。
異常終了: 0以外を返します。(☞617ページ エラーコード)

### 説明 (11.5 / 530 / 原本 p.532)

- ラベル名szLabel(szLabelList)で指定したデバイス群を，書込み点数iSize分のデバイス値だけ書き込みます。
- 書き込むデバイス値を，iDataに格納します。
- 書き込むデバイス値iDataには，書込み点数iSize以上の配列を確保してください。

> **Point**
> - 書込み点数に指定できる最大書込み点数は，0x7FFFFFFF点までです。
> - ラベル名に指定しているデータ型に対応するワード数を書込み点数に指定してください。書き込むデバイス値には，書込み点数に指定した点数分のメモリエリアを用意してください。メモリエリアがない場合は，アプリケーションエラーなどの重大な現象が発生するおそれがあります。
> - ラベル名に対応するデバイスが存在しない場合はエラーとなり，書き込めません。
>   複数のラベル名に対応するデバイスが一部存在しない場合もエラーとなり，書き込めません。
> - ビットデバイスの桁指定およびインデックス修飾は，使用できません。
> - QモーションCPUへアクセスを行うと，エラーが返ります。
> - システムラベルVer.2を使用する場合，MX Componentのラベル管理ユーティリティで定義したデータ型とMELSOFT Navigatorで管理するデータ型は一致している必要があります。
>   データ型が一致していない場合，実際に読み出されるデータの長さが不正となったり，複数のラベルを指定した場合に読み出したデバイス値の配列とラベル名の対応がずれる場合があります。
> - 構造体は5階層まで定義できます。ただし，静的システムラベルは1階層目の構造体までのみ使用できます。
> - RnSFCPUのセーフティモードで安全デバイスに対して実行した場合は，エラーコード"0x010A42A5"(セーフティモードでは実施できない操作を行った)が返されます。
