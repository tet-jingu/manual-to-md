### ニモニックリストの使い方

(原本 p.19-20 / 印刷ページ 17-18)

参考ラダープログラムが紹介されている各ページには、ニモニックリストが記載されています。
このニモニックリストを利用すると、ラダープログラムが簡単に入力できます。

1. 「Adobe Reader」でマニュアルを表示させます。
2. 「選択ツール」を使用して、ニモニックリストをコピーします。
3. 《KV STUDIO》のラダー編集エリアで、参考ラダープログラムを挿入したいセルをクリックし、メニューから【編集（E）】【リスト編集（L）】を選択して、［リスト編集］ダイアログボックスを表示します。
   - 別手順: `Ctrl` ＋ `D`
   - 表示した［リスト編集］ダイアログボックスに、コピーしたニモニックリストを貼り付けます。貼り付けは、［リスト編集］ダイアログボックスの右クリックメニューから［貼り付け（P）］を選択します。
4. 〔挿入（I）〕ボタンをクリックすると、参考ラダープログラムが表示されます。

【図】参考ラダープログラム挿入後の KV STUDIO 画面 (原本 p.20)
- 画面左のプロジェクトツリー: ユニット構成 / デバイスコメント / ラベル / 運転記録設定 / CPUシステム設定 / プログラム:SAMLPE / ファンクションブロック / マクロ / デバイス初期値 / ファイルレジスタ設定 / ユーザドキュメント

### 用語について

(原本 p.20 / 印刷ページ 18)

このマニュアルの説明では一部を除き、次のような用語を使用しています。

| 用語 | 説明 |
|---|---|
| プログラマブルコントローラ | プログラムを変更することで自由に機器を制御できる電子装置で、PLC（Programmable Logic Controller）とも呼ばれています。 |
| 《KV-8000シリーズ》《KV-8000》 | 当社製プログラマブルコントローラKV-8000/8000Aです。 |
| 《KV-7000シリーズ》 | 当社製プログラマブルコントローラKV-7500/7300です。 |
| 《KV-5000/3000シリーズ》 | 当社製プログラマブルコントローラKV-5500/5000/3000です。 |
| CPUユニット | 《KV-8000》《KV-7500/7300》《KV-5500/5000/3000》です。 |
| 拡張ユニット | 《KV-8000シリーズ》で使用できるCPUユニット以外の拡張I/Oユニット、拡張特殊ユニットです。 |
| バス接続ユニット | 《KV-8000シリーズ》で《KV-5000/3000シリーズ》用の拡張ユニットを使用する際に、必要になる接続ユニットです。バス接続ユニット使用時は右端にエンドユニットを取り付ける必要があります。 |
| S-Unit | KV-8000シリーズのCPUインナーバスに対応した拡張ユニットです。 |
| X-Unit | KV-8000シリーズのCPUインナーバスに対応した高機能拡張ユニットです。 |
| CPUインナーバス | KV-8000シリーズCPUからバス接続ユニットまでの、ユニット割込に対応した高速インナーバスのことです。 |
| エンドユニット | 《KV-5000/3000シリーズ》用の拡張ユニットを使用する際に右端に取り付けるユニットです。 |
| 《KV STUDIO》 | KV-8000シリーズのプログラム作成をサポートするソフトウェアです。 |
| ラダープログラム | 《KV STUDIO》で作成されたプログラムです。 |
