## 5-9 アクセスウィンドウ(続き)

(5-9 / 原本 p.517-544 / 5-141〜5-168)

5-9 の前半(アクセスウィンドウの概要〜ストレージの直前、原本 p.487-516)は別ファイル `05e_` を参照。

### ストレージ

(5-9 / 原本 p.517 / 5-141)

メモリカードやCPUメモリへのデータ保存やファイルの読み出しなどをアクセスウィンドウ上から操作できます。

メモリカードやCPUメモリ機能の詳細は、「5-2 メモリカード」（5-3ページ）、「5-3 CPUメモリ（ユーザメモリ）」（5-27ページ）を参照してください。

#### ■ 操作できる項目

(5-9 / 原本 p.517 / 5-141)

アクセスウィンドウから操作できるメモリカード操作は次のとおりです。

| 日本語 | 英語 | 中国語 | 設定内容 |
|---|---|---|---|
| ロード | Load | 加载 | 任意のプロジェクトフォルダ内のデータをCPUユニットに読み出します。 |
| セーブ | Save | 保存 | CPUユニットのデータをメモリカードやCPUメモリに保存します。ラダープログラム、デバイス値、デバイスコメント、ユニット設定情報、ロギング設定情報などが保存されます。 |
| ファイル管理 | File Management | 文件管理 | メモリカードやCPUメモリ内のディレクトリ、ファイルを一覧表示します。また、一覧の中から任意のファイルをコピー、移動、削除できます。 |
| 空き容量 | Free Space | 可用空间 | メモリカードやCPUメモリの空き容量を表示します。 |

(原本の表 4行 → md 4行)

> **ポイント**
> 「ロード」はPRGモード時のみ可能です。

#### ■ 操作方法

(5-9 / 原本 p.518-529 / 5-142〜5-153)

##### ● ストレージへの移行

(5-9 / 原本 p.518 / 5-142)

1. 「MENU」キーを押します。
   メニューが表示されます。（他ユニットが選択されている場合は「MENU」キーを2回押してください。）
2. 「4.ストレージ」を選択して、「ENTER」キーを押します。
   ストレージのメニューが表示されます。

【図】ストレージのメニュー画面 (原本 p.518) — 日本語 / 英語 / 中国語 の表示:
- 日本語: `・ロード` `・セーブ` `・ファイル管理` `・空き容量`
- 英語: `・Load` `・Save` `・File Management` `・Free Space`
- 中国語: `・加载` `・保存` `・文件管理` `・可用空间`
- キー操作: 「ENTER」

##### ● ロード

(5-9 / 原本 p.518-519 / 5-142〜5-143)

1. ストレージのメニューで「ロード」を選択して、「ENTER」キーを押します。
   メモリカードとCPUメモリのどちらのストレージを選択するか表示されます。
   - 画面: `0:メモリカード` / `1:CPUメモリ` (英語 `0:Memory Card` / `1:CPU Memory`、中国語 `0:存储卡` / `1:CPU存储器`)
2. 「▲」「▼」でストレージを選択し、「ENTER」または「▶」キーを押します。
   メモリカードまたはCPUメモリのルートフォルダにある（プロジェクト）フォルダが表示されます。（ファイルは表示されません。フォルダ名は"<D>KVSAVE01"のように、最初の3文字が<D>で表されます。）
   - 画面: `[0:メモリカード]` `<D>KVSAVE01` `<D>KVSAVE02` `<D>UserDoc` (英語 `[0:Memory Card ]`、中国語 `[0:存储卡]`)

   > **参考**
   > フォルダ名が長い場合はスクロールして表示されます。

3. 「▲」「▼」でフォルダを選択し、「ENTER」または「▶」キーを押します。
   ロード実行の確認メッセージが表示されます。
   - 画面: `KVSAVE01` `2015/3/13` `12:13:14` `ロードしますか?` (英語 `Load OK?`、中国語 `是否加载?`)
4. 「ENTER」キーを1秒以上押し続けて、ロードを実行します。
   ロード実行中は次の表示になります。
   ロードを開始すると、途中でキャンセルはできません。
   - 画面: `ロード` `KVSAVE01.YCD` `99%` (英語 `Load`、中国語 `加载`)

   > **ポイント**
   > - ライトプロテクトされている場合は、下図の表示が出ます。
   >   「ENTER」キーを1秒押しつづけると、強行してロードが実行されます。
   >   「MENU」キーを押すと、ロードがキャンセルされます。
   >   - 画面: `ロード` `ライトプロテクト` `されています` `強行しますか？` (英語 `Load` `Write protected` `Force load?`、中国語 `加载` `写保护` `是否强制执行?`)
   > - ロード実行時にCPUメモリの空き容量が少なく、CPUメモリ容量設定を変更できない時には、下図の表示が出ます。
   >   「ENTER」キーを1秒押しつづけると、CPUメモリクリアが実行されます。
   >   「MENU」キーを押すと、ロードがキャンセルされます。
   >   - 画面: `ロード` `容量不足` `ユーザメモリを` `クリアしますか?` (英語 `Load` `Memory Full` `Clear User Mem?`、中国語 `加载` `空间不足` `是否清除` `用户文档?`)
   > - ロード実行時にプロジェクトロードが禁止されている場合、下図の表示が出ます。
   >   「MENU」キーを押すとロードがキャンセルされます。
   >   - 画面: `ロード` `ロード禁止中です` (英語 `Load` `Loading is prohibited.`、中国語 `加载` `禁止装载`)

5. ロードが完了すると次の表示になります。
   - 画面: `ロード` `ロード完了` (英語 `Load` `Load Done`、中国語 `加载` `加载完成`)

   「MENU」「ENTER」「◀」「▶」キーを押すとストレージのメニューに戻ります。

##### ● セーブ

(5-9 / 原本 p.520 / 5-144)

1. ストレージのメニューで「セーブ」を選択して、「ENTER」キーを押します。
   メモリカードとCPUメモリのどちらのストレージを選択するか表示されます。
   - 画面: `0:メモリカード` / `1:CPUメモリ` (英語 `0:Memory Card` / `1:CPU Memory`、中国語 `0:存储卡` / `1:CPU存储器`)
2. 「▲」「▼」でストレージを選択し、「ENTER」または「▶」キーを押します。
   CPUのデータをセーブするか確認メッセージが表示されます。
   - 画面: `セーブ` `セーブしますか?` (英語 `Save` `Save OK?`、中国語 `保存` `是否保存?`)
3. 「ENTER」キーを1秒以上押し続けて、セーブを実行します。
   KVSAVE??（?? は二桁の半角数字）という名前のディレクトリを検索し、使われていない最小の二桁の数字のディレクトリを作成してセーブします。
   セーブ実行中は現在セーブ中のファイル名と進捗が表示されます。
   - 画面: `セーブ` `KVSAVE01.YLB` `65%` `..` (英語 `Save`、中国語 `保存`)
4. セーブが完了すると、セーブされたプロジェクトフォルダ名が表示されます。
   - 画面: `セーブ` `セーブ完了` `KVSAVE01` (英語 `Save` `Save Done` `KVSAVE01`、中国語 `保存` `Save Done` `KVSAVE01`)

   「MENU」「ENTER」「◀」「▶」キーを押すとストレージのメニューに戻ります。

    ```
    MOV.D  #160  CM1784
    ```

    ```
    MOV.D  #1611  CM1784
    ```

    ```
    MOV.D  $1FFF  CM1784
    ```

  **例**


### ユーザメッセージ

(5-9 / 原本 p.542 / 5-166)

ユーザメッセージ機能とは、メッセージエディタにて設定した半角64（全角32）文字までのメッセージをアクセスウィンドウに表示させる機能です。
ユーザメッセージに使用できるCRは63個用意されており、CRをONするだけで表示する文字列を変更できます。また表示コメント番号設定で、コメント1～8を切り換えると最大8言語のユーザメッセージを使用できます。

#### ■ 表示方法

(5-9 / 原本 p.542 / 5-166)

ユーザメッセージを表示させる方法には以下の2つがあります。

**①AWSHOW命令を使用する。**

専用の命令語を使用することでコントロールリレー（CR）を気にすることなく簡単にユーザメッセージを表示させることができます。
複数IDのユーザメッセージが同時にONした場合、数値の若いユーザメッセージが優先して表示されます。

各命令語についての詳細は、『KV-8000/7000/5000/3000/1000・KV Nanoシリーズ命令語リファレンスマニュアル「5-14 アクセスウィンドウ命令」』を参照してください。

【図】ラダープログラム / 入力方法 (原本 p.542)
- ラダープログラム: 実行条件(a接点) → `AWSHOW` ボックス(オペランド `S`)
- 入力方法: キー入力 `A` `W` `S` `H` `O` `W` `␣`(スペース) `S` `↵`(Enter)

```
LD      実行条件
AWSHOW  S
```

**②コントロールリレー（CR）を使ってラダープログラムを作成する。**

ID1のユーザメッセージを表示するには、CR4601をONします。
CR4601～CR4915をONすると、対応するIDのユーザメッセージが表示されます。

#### ■ 表示例

(5-9 / 原本 p.542 / 5-166)

- 画面: `温度異常` `冷却水の量を` `確認してください` (英語 `Temp. Warn.` `Check the amount` `of Water`、中国語 `温度异常` `请确认冷却水的量`)

表示中はCR4500からCR4503で指定した行が点滅します。
次の場合に表示は元に戻ります。
- アクセスウィンドウの「ENTER」キーを押したとき。このとき対応しているCRはOFFします。
- 対応しているCRをOFFしたとき。
- AWHIDE命令を実行したとき。

> **ポイント**
> - 電源投入時に表示するユーザメッセージIDを設定できます。
> - ユーザメッセージ表示時に「ENTER」キーを押すとユーザメッセージを解除するかどうかを設定できます。
> - 現在表示中のユーザメッセージIDはCM1720で確認することができます。
> - ユーザメッセージ表示中に「MENU」キーを押した場合、アクセスウィンドウの右上に「M」が表示されます。
>   - 画面: `1.デバイスモーM` `2.エラークリア` `3.ユニットテスト` `4.ストレージ` (右上に反転表示の「M」。英語 `1.Device Mode M`、中国語 `1.软元件模式 M`)
>
>   ユーザメッセージ中に他のメニューを表示することはできますが、キー操作が30秒以上なかった場合ユーザメッセージ表示画面に自動的に切り換わります。
> - 複数のユーザメッセージIDのCRがSETされた場合、右端にスクロールボタン（▲ / ▼）が表示されます。スクロールボタンが表示されている間に、「▲」または「▼」キーを押すと別のIDのユーザメッセージを表示できます。

### 操作禁止設定

(5-9 / 原本 p.543 / 5-167)

アクセスウィンドウ上での操作を機能別に禁止できます。
操作禁止の設定が可能な機能と項目は次のとおりです。

| 機能 | 項目 |
|---|---|
| ユニットモニタ | 設定変更 |
| デバイスモード | デバイス値変更 |
| トリマ | デバイス値変更 |
| アラーム | アラーム履歴クリア |
| ロード・セーブ | ロード、セーブ |
| Language | 設定変更 |
| オールクリア/RAMクリア/初期化 | 実行 |
| ユーザメモリクリア | 実行 |
| ストレージ | ファイル移動、コピー、削除 |
| 時計 | 設定変更 |
| コメント切換 | 設定変更 |

(原本の表 11行 → md 11行)

操作禁止設定はCM1738に機能ごとに1ビットずつ割り当てられていて、「ON」の場合に禁止します。

【図】CM1738 のビット割付 (原本 p.543) — 図を表に起こしたもの

| CM1738 ビット | 内容 |
|---|---|
| 0 | ユニットモニタ（設定変更禁止） |
| 1 | デバイスモード（デバイス値変更禁止） |
| 2 | トリマ(デバイス値変更禁止) |
| 3 | アラーム（アラーム履歴クリア禁止） |
| 4 | ロード･セーブ（操作禁止） |
| 5 | Language（設定変更禁止） |
| 6 | オールクリア、RAMクリア、初期化（実行禁止） |
| 7 | ユーザメモリクリア（実行禁止） |
| 8 | ストレージ（移動･コピー･削除　操作禁止） |
| 9 | 時計（設定変更禁止） |
| 10 | AW設定（設定変更禁止） |
| 11〜15 | システム予約 |

(原本の図 12区分 → md 12行)

禁止されている操作をすると、次の画面が表示されます。
- 画面: `AWメッセージ` `操作禁止` (英語 `AW Message` `Input disabled`、中国語 `访问窗消息` `操作去能`)

**例**

- デジタルトリマの書き込み禁止設定
  ```
  MOV  $0004  CM1738
  ```
- デバイスモードでの書き込み禁止設定
  ```
  MOV  $0002  CM1738
  ```
- ロード･セーブ操作禁止
  ```
  MOV  $0010  CM1738
  ```
- AW設定の設定変更禁止
  ```
  MOV  $0400  CM1738
  ```

(原本のラダー図は実行条件なしで母線から直接 MOV ボックスに接続。上記は各ボックス命令をそのままニモニック表記したもの)

> **ポイント**
> デバイスモードでデバイス書き込み禁止を設定すると、以後、アクセスウィンドウで解除できなくなります。

> 補足(原文にはない): 機能・項目の表では最終行が「コメント切換」、ビット割付図の bit10 は「AW設定（設定変更禁止）」と表記されている(原本どおり転記)。

### キーロック

(5-9 / 原本 p.544 / 5-168)

キーロックは、アクセスウィンドウのキー操作を禁止する機能です。設定変更できないようにする場合や表示する画面を固定する場合に使用します。

#### ■ 操作方法

(5-9 / 原本 p.544 / 5-168)

設定／解除いずれの場合も、「◀」キーを押しながら「MENU」キーを3秒以上押し続けてください。

##### ● キーロックされていない場合

(5-9 / 原本 p.544 / 5-168)

次の画面が表示され、キーロック状態になります。
- 画面: `AWメッセージ` `キーロック` (英語 `AW Message` `Key Lock`、中国語 `访问窗消息` `锁键`)

キーロック状態でキーロック解除以外の操作をおこなうと、上の画面が表示されます。

##### ● キーロックされている場合

(5-9 / 原本 p.544 / 5-168)

次の画面が表示され、キーロックが解除されます。
- 画面: `AWメッセージ` `キーロック解除` (英語 `AW Message` `Lock Release`、中国語 `访问窗消息` `解锁`)

> **ポイント**
> - キーロック中は、ダイレクトアクセススイッチを押しても選択されません。
> - ユニットのモニタ、ユニットテスト中は、キーロックできません。
