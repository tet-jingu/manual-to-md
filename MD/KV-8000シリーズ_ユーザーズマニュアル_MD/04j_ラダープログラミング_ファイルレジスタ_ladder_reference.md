## 4-14 ファイルレジスタ

(4-14 / 原本 p.324 / 4-226)

### 概要

(4-14 / 原本 p.324 / 4-226)

ファイルレジスタは、すべての領域を連番方式で扱う「ZF」と、領域を16個のバンク（0～15）に分割するバンク切換方式で扱う「FM」があります。

【図】バンク切換方式と連番方式の対応 (原本 p.324)

| バンク | バンク切換方式 | 連番方式 |
|---|---|---|
| バンク0 | FM0～FM32767 | ZF0～ZF32767 |
| バンク1 | FM0～FM32767 | ZF32768～ZF65535 |
| (バンク2) | FM0～ | ZF65536～ |
| (バンク14) | ～FM32767 | ～ZF491519 |
| バンク15 | FM0～FM32767 | ZF491520～ZF524287 |

(原本の図 5段(途中は波線で省略表記) → md 5行。バンク2・バンク14の段は原本図では名称の記載がなく、波線の前後の端の番号のみ記載)

例えば、バンク1のFM0とZF32768は同じデータ格納場所を指します。

デバイス番号の詳細やデータの取り扱い方などは「4-4 デバイス」ファイルレジスタ　ZF/FM（4-39ページ）を参照してください。

### バンク切換

(4-14 / 原本 p.324 / 4-226)

バンクを切り換えるには、「FRSET命令」を使用します。
現在指定されているバンクをカレントバンクと呼びます。

**例**

使用デバイス

| デバイス | 内容 |
|---|---|
| R000 | 実行条件(立ち上がり) → バンク1へ切換・FM0読出 |
| R001 | 実行条件(立ち上がり) → バンク0へ切換・FM0読出 |
| CM710 | ファイルレジスタ カレントバンク |
| FM0 | ファイルレジスタ(カレントバンク) |
| DM0 | コピー先 |

(原本の表 なし(ラダー図のデバイス) → md 5行)

〈ニモニックリスト〉(原本掲載のまま)

```
LDP R000
MPS
AND<> CM710 #1
FRSET #1
MPP
MOV FM0 DM0
LDP R001
MPS
AND<> CM710 #0
FRSET #0
MPP
MOV FM0 DM0
```

ラダー図に付いた説明(原文のまま):
- FRSET #1: カレントバンクがバンク1でない場合にカレントバンクをバンク1に切換
- MOV FM0 DM0 (R000側): FM0(＝ZF32768)の値をDM0にコピー
- FRSET #0: カレントバンクがバンク0でない場合にカレントバンクをバンク0に切換
- MOV FM0 DM0 (R001側): FM0(＝ZF0)の値をDM0にコピー

「FRSET命令」4-230ページ

> **参考**
> - カレントバンクの番号はCM710で確認できます。
> - KVモード（上位リンク）の「BE」コマンドを使用して、バンクを切り換えることができます。
>   『KV-XL202/XL402ユーザーズマニュアル』

### 初期値設定

(4-14 / 原本 p.325 / 4-227)

ファイルレジスタ（連番方式）の値をあらかじめ設定する場合は、《KV STUDIO》のワークスペース上から開く「デバイス初期値設定」ダイアログで設定します。

【図】「デバイス初期値設定」ダイアログ (原本 p.325)
- 左枠「初期値有効デバイス」: 列「デバイス」「点数」、登録行「ZF0～ZF999」「1000」、ボタン［設定(S)］［削除(D)］
- 上部: 「デバイス(V)」= ZF、「表示形式(T)」= 10進数16BIT、チェック「初期値有効デバイスのみ表示(O)」
- 一覧: 列「デバイス」「+0」〜「+9」「STRING」、行 ZF0, ZF10, … ZF130(値はすべて0)
- ボタン: ［CSV/TXTインポート(I)］［CSV/TXTエクスポート(E)］［PLCから値の読出(R)］［OK］［キャンセル］

このダイアログで設定したプロジェクトをCPUユニットに転送すると、PRG→RUNモード切り換え時に設定した初期値を自動的に読み出します。

『KV STUDIOユーザーズマニュアル「デバイス初期値設定」』

### ファイルレジスタ一括設定

(4-14 / 原本 p.325-327 / 4-227〜4-229)

専用命令語を使用して、CPUユニットに挿入したメモリカードや、内蔵のCPUメモリを対象に、ファイルレジスタのデータ（ファイルレジスタ設定値）を保存・読出しができます。

- FRSTM命令 : 指定したバンクのファイルレジスタをメモリカードまたはCPUメモリに保存
- FRLDM命令 : メモリカードまたは CPU メモリに保存したファイルから指定したバンクのファイルレジスタに読出

「FRSTM命令」4-232ページ、「FRLDM命令」4-234ページ

【図】ファイルレジスタ一括設定の概念図 (原本 p.325)
- 左: バンク0, バンク1, …, バンク999※ (各バンク FM0～FM32767)
- 右: 「メモリカードまたはCPUメモリ」(ストレージごとに最大1000ファイル)
- FRSTM命令: バンク → メモリカードまたはCPUメモリ の向き
- FRLDM命令: メモリカードまたはCPUメモリ → バンク の向き
- ※メモリカード/CPUメモリを使用した場合。内蔵のデバイスのみを使用した場合は15までです。

あらかじめ最大1000ファイルまでのファイルレジスタ設定値をメモリカードまたはCPUメモリに用意して、必要な時に読み出せば、デバイス数を気にせずに段取り替え用途で使用できます。

#### ■ ファイルレジスタ設定値の管理

(4-14 / 原本 p.326 / 4-228)

メモリカードまたはCPUメモリ内に保存されているファイル（ファイルレジスタ設定値）は、《KV STUDIO》で編集できます。ワークスペース上から開く「ファイルレジスタ設定」ダイアログで編集、新規作成、CSVファイルのインポートなども可能です。フィルレジスタ設定値は、プロジェクトごとに管理されます。

『KV STUDIOユーザーズマニュアル「ファイルレジスタ設定」』

- 「設定No.(N)」= 000、案内文「CPUメモリでファイルレジスタ設定を使用する場合、メモリカードは不要です。」
- 「コメント(C)」入力欄、「表示形式(T)」= 10進数16BIT
- 一覧: 列「デバイス」「+0」〜「+9」「STRING」、行 FM0, FM10, … FM220(値はすべて0)
- ボタン: ［CSV/TXTインポート(I)］［CSV/TXTエクスポート(E)］［PLCから値の読出(R)］［OK］［キャンセル］

## FRSET / @FRSET ファイルレジスタ バンク切り換え

(4-14 FRSET / 原本 p.328-329 / 4-230〜4-231)

| 命令 | 名称 | 概要 |
|---|---|---|
| FRSET / @FRSET | ファイルレジスタ バンク切り換え | ファイルレジスタのカレントバンク番号を指定した番号に切り換えます。 |

(原本の表 1行 → md 1行)

### 書式

(4-14 FRSET / 原本 p.328 / 4-230)

| ラダープログラム | 入力方法 |
|---|---|
| 実行条件 ─┤FRSET n├ | `FRSET␣n↵` |
| 実行条件 ─┤↑FRSET n├ (立ち上がり) | `@FRSET␣n↵` |

(原本の表 2行 → md 2行)

| オペランド | 説明 | 占有サイズ |
|---|---|---|
| n | 切り換え後のカレントバンク番号、またはその格納先を指定します。（KV-8000/7000シリーズの場合、0～15、KV-5500/5000/3000の場合、0～3） | 16ビット |

(原本の表 1行 → md 1行)

> 使用可能デバイス表: 本命令ページには使用可能デバイス表の掲載なし。

### 動作説明

(4-14 FRSET / 原本 p.328 / 4-230)

| 命令 | 動作 |
|---|---|
| FRSET | 実行条件がONのとき、ファイルレジスタのカレントバンク番号を n で指定した番号に切り換えます。 |
| @FRSET | 実行条件の立ち上がりで、1スキャンだけ実行します。 |

(原本の表 2行 → md 2行)

### 演算フラグ

(4-14 FRSET / 原本 p.328 / 4-230)

| フラグ | 内容 |
|---|---|
| CR2009 | 変化なし |
| CR2010 | 変化なし |
| CR2011 | 変化なし |

## FRSTM ファイルレジスタ一括保存

### 書式

(4-14 FRSTM / 原本 p.330 / 4-232)

> 使用可能デバイス表: 本命令ページには使用可能デバイス表の掲載なし。

### 動作説明

(4-14 FRSTM / 原本 p.330 / 4-232)

**FRSTM**

実行条件の立ち上がりで、バンク番号 n2 のファイルレジスタ全てを、バイナリ形式で n1 で指定したストレージ（KV-5000/3000シリーズの場合、メモリカード）へ一括保存します（ファイルは常に上書きされます）。
ファイル番号 S は数値で指定します。
作成されるファイル名は、￥FR￥FR（ファイル番号3桁）.FRU※ となります。

※KV-5000/3000シリーズの場合は、ファイルの拡張子はFRBとなります。
「FR」フォルダがない場合は、新規作成されます。

> **例**
> S に10が格納されている場合、￥FR￥FR010.FRU（またはFR010.FRB）が作成されます。

D には完了通知が、 D +1には異常終了のエラー通知が書き込まれます。
- D は命令実行開始時にOFFし、ストレージへの書き込み処理終了時にONします。
  命令が正常終了、異常終了のどちらでもONします。
- D +1は命令が正常終了でOFFし、異常終了でONします。
  CM2390にエラーコードが格納されます。

> **ポイント**
> ストレージ命令実行中リレー（CR3214）がONしているときに、命令は実行されません。
> CR3214を使用して排他制御をおこなってください。

> エラーコード表: 本命令ページにはCM2390に格納されるエラーコードの一覧は掲載なし。
