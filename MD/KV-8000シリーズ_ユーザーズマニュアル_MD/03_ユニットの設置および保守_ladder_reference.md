## 3-1 ユニットの接続

(3-1 / 原本 p.74-77 / 3-2〜3-5)

各ユニットの組み立て方法や、DINレールなどへの取り付け方法について説明しています。

### ユニット接続時の注意

(3-1 / 原本 p.74 / 3-2)

各ユニットを接続するときは、必ず次のことを守ってください。
- 各ユニットは、必ず電源がOFFの状態で接続してください。

【図】接続順 (原本 p.74): 左から 電源ユニット → CPUユニット → KV-8000/7000シリーズ用拡張ユニット → バス接続ユニット → KV-5000/3000シリーズ用拡張ユニット → エンドユニット(右のユニットを左のユニットへ差し込む向きの矢印)

> **ポイント**
> - CPUユニットの時計データはバックアップ用コンデンサで保持しています。長期間通電しなかった場合、時計データが消失している可能性があります（消失した場合、CPUエラー85「時計データ消失」が発生します）。時計データの保持が必要な場合は、オプションのバッテリ（KV-B1）を取り付けて使用してください。
> - バス接続ユニットを使用する場合、右端にエンドユニットが必要です。エンドユニットがない場合、エンドユニットなしエラーが発生します。
> - バス接続ユニットを使用しない場合、右端のユニットには拡張ユニット連結コネクタカバーを取り付けて使用してください。

**■ 最大接続ユニット台数**

1台のCPUユニットには、KV-8000/7000シリーズ用拡張ユニット、KV-5000/3000シリーズ用拡張ユニットの混在で最大48台のユニットが接続できます（電源ユニット、バス接続ユニットは除く）。
- CPUユニットには最大16台までのKV-8000/7000シリーズ用拡張ユニットが接続できます
- バス接続ユニットを使用することでKV-5000/3000シリーズ用拡張ユニットが接続できます
- CPUユニット横の接続台数が16台を超える場合は、エクステンションユニットを使用することで、各段16台、合計48台のユニットが接続できます（KV-8000/7000シリーズ用拡張ユニットは、1段目にのみ接続できます）

拡張ユニットには一部48台接続できない機種もあります。
各ユニットのマニュアルを参照してください。

【図】ユニット構成例（最大） (原本 p.74)
- 1段目: CPUユニット + 最大16台（バス接続ユニット含まず）。途中にバス接続ユニット、右端に KV-EB1S
- 2段目: 左端に KV-EB1R、右端に KV-EB1S
- 3段目: 左端に KV-EB1R
- 段間: 60mm以上(縦方向)

### ユニットの組み立て

(3-1 / 原本 p.75-76 / 3-3〜3-4)

**■ KV-8000/7000シリーズ拡張ユニットを接続する場合**

ここでは、CPUユニットとKV-SIR32XTを接続する場合を例に説明します。

1. 右側のユニットの上下に付いているロックレバーをはずします
   - くぼみに指をかけ、ユニットの前面方向にスライドさせるとはずれます。
2. 左側のユニットのロックレバースロットに、右側のユニットのロックレバーを挿し込んで接続します
   - 2つのユニットが平行になるようにして持ち、コネクタの位置を合わせると簡単に接続できます。
3. 右側のユニットの上下に付いているロックレバーをロックします
   - 手順1と同じ要領で、くぼみに指をかけ、ユニットの背面方向にスライドさせます。このときユニットとユニットの間にすき間がないかどうか確認します。すき間があれば、正しく接続されていません。

【図】KV-8000（左側）と KV-SIR32XT（右側）の接続手順図 (原本 p.75)

**■ KV-5000/3000シリーズ拡張ユニットを接続する場合**

ここでは、CPUユニットにバス接続ユニットとKV-B16XCを接続する場合を例に説明します。

1. 右端に取り付けられたKV-8000/7000シリーズ拡張ユニットの拡張ユニット接続コネクタカバーをはずします
2. バス接続ユニットを取り付けます
   - KV-8000/7000シリーズ拡張ユニットを接続する場合の取付手順を参照してください。
3. KV-5000/3000シリーズ拡張ユニットのロックレバーをはずします
   - ロックレバーに指をかけ、ユニットの前面方向にスライドさせるとはずれます。
4. バス接続ユニットのロックレバースロットに、KV-5000/3000シリーズ拡張ユニットのロックレバーを差し込んで接続します
5. 右側のユニットの上下に付いているロックレバーをロックします
   - 手順3 と同じ要領で、ロックレバーに指をかけ、ユニットの背面方向にスライドさせます。このときユニットとユニットの間にすき間がないかどうか確認します。すき間があれば、正しく接続されていません。
6. 右端にエンドユニット取り付けます

【図】KV-8000＋バス接続ユニット（左側）と KV-B16XC（右側）の接続手順図 (原本 p.76)

> **ポイント**
> バス接続ユニットを使用した場合、右端にエンドユニットを取り付けないとエンドユニット未接続エラーが発生します。

### DINレールへの取り付け

(3-1 / 原本 p.77 / 3-5)

接続されたユニットをDINレールに取り付ける方法と取りはずす方法を説明します。

**■ 取りつけるときは**

1. 各ユニットの上側のDINレール取り付け用ツメに、DINレールの上側の溝を引っかけます
2. 各ユニットの下側のDINレール取り付け用ツメに、DINレールの下側をはめます
   - 下側の黒いツメはバネで動くようになっています。「カチン」と音がするまで押しあてます。
   - 取り付けにくい場所は全てのロックをはずしておき、DINレールに取り付けてから、ロックをしてください。
3. 下側のDINレール取り付け用ツメが、押し込まれている状態（ロック状態）になっていることを確認します

**■ 取りはずすときは**

1. 下側のDINレール取り付け用ツメを下側に引き出します
2. 取り付けるときと逆の要領でDINレールをユニットから取りはずします

【図】DINレール取り付け図 (原本 p.77): 上部のツメ / DIN レール / 下部の黒いツメ(押し込まれている状態・引き出している状態・はずれている状態)

## 3-2 ユニットの設置

(3-2 / 原本 p.78-79 / 3-6〜3-7)

各ユニットを設置する環境についての注意や、盤内の取り付け位置について説明します。

### 設置環境

(3-2 / 原本 p.78 / 3-6)

次のような場所には設置しないでください。
- 直射日光があたる場所
- 周囲温度が0～＋55℃の範囲を超える場所
- 周囲湿度が5～95%RHの範囲を超える場所
- 急激な温度変化で結露する場所
- 腐食性ガスや可燃性ガスのある場所
- 塵埃、塩分、鉄粉、油煙が多い場所
- 振動や衝撃が直接加わる場所
- 水、油、薬品などのしぶきがかかる場所
- 強磁界、強電界の発生する場所
- 標高2000mを超える場所

### 取り付け位置

(3-2 / 原本 p.78-79 / 3-6〜3-7)

**■ 設置の向き**

盤内に取り付けるときは、必ずCPUユニットの前面が手前に向くようにします。

【図】設置の向き (原本 p.78): 盤内でのユニット配置例(CPUユニット・KV-S32XTD・KV-S40AD 等)。詳細は原本 p.78 参照。

**■ 周囲との間隔**

周囲の壁や他の機器とは、必ず30mm以上離して設置してください。

【図】(原本 p.79): 各ユニットの上、左、下に30mm。放熱のために、30mmの間隔をあける

> **ポイント**
> 盤内の温度（ユニット中央下部の温度）が、使用周囲温度を超える場合は、強制空冷や周囲との間隔を広げ通風をよくするなどの方法で温度を下げてください。
> エクステンションユニット使用時、上段と下段のユニット間隔は熱の影響を考慮して60mm以上離してください。

## 3-3 配線時の注意

(3-3 / 原本 p.80-91 / 3-8〜3-19)

コネクタの組み立て方法や各ユニットの結線と内部回路、および各ユニットの配線方法について説明します。

### 各ユニットへの配線時の注意

(3-3 / 原本 p.80-82 / 3-8〜3-10)

入出力機器や拡張入出力ユニットに配線するときの注意について説明します。必ず、配線前にお読みください。

**■ 入出力機器への配線時の注意**

入出力機器に配線するときは、次のことに注意してください。
- 入力線と出力線は、それぞれ分離して配線してください。
- 入出力信号線に動力用配線を近づけると、高電圧・大電流の影響を受け動作異常が発生することがあります。入出力信号線と動力用配線は100mm以上離して配線してください。
- 入出力信号線は、AC100VやAC200Vの線とは分離して配線してください。
- 配管を使っての配線時には、配管が確実に接地されていることを確認してください。
- 配線時には、必ず全ての電源をOFFしてください。感電や製品損傷の恐れがあります。
- 配線作業などの後、通電、運転する場合は、必ず製品に付属の端子カバーを取り付けてください。感電の恐れがあります。

**動力用配線と分離できないときは・・・**
一括シールドのケーブルを使い、PLC側で接地してください。
（環境によっては、PLCと逆側や、両側で接地する必要が生じる場合があります。）

【図】(原本 p.80): 一括シールドケーブルで PLC とセンサなど(DC24V)を接続し、シールドを PLC 側で D種接地。図中に RL の表記(**要確認**: 図の詳細は原本 p.80 参照)。

**■ 接地時の注意**

- 機器ごとに別々に接地（接地工事はD種接地）してください。また、この場合の接地抵抗は100Ω以下とします。
- 別々に接地できないときは、共用で接地します。ただし、この場合の電線はすべて同じ長さにします。
- 接地にはFG端子を使用してください。（電源端子は接地しないでください）

**■ 接点保護について**

クラッチやモータ、ソレノイドなどの誘導負荷を使う場合、負荷電源投入時に突入電流が流れたり、負荷電源遮断時に逆起電圧が発生したりします。突入電流や逆起電圧は、接点の寿命を短くする大きな要因となります。この現象の発生を抑えるために、接点保護回路を設けるようにしてください。

【図】接点保護回路の例 (原本 p.81)
- AC負荷の場合①: 接点 — AC電源 — 負荷(L)、負荷(L)に並列に CR回路
- DC負荷の場合①: 接点 — DC電源 — 負荷(L)、負荷(L)に並列に ダイオード
- AC負荷の場合②: 接点 — AC電源 — 負荷(L)、バリスタを a の位置(接点に並列)または b の位置(負荷に並列)に取り付け
  - 電源電圧 24～ 48Vのとき　bの位置へ / 100～200Vのとき　aの位置へ　取り付けてください。
- DC負荷の場合②: 接点 — DC電源 — 負荷(L)、負荷(L)に並列に ダイオード＋ツェナーダイオード(直列)

- 負荷コイル定格は、接点容量以下のものを使用してください。
- ダイオードは、逆耐電圧が回路電圧の10倍以上のもので、順方向電流が負荷の電流以上のものを使用してください。
- ダイオード、バリスタ、およびCR回路は、リレーコイル端子に直接取り付けてください。

**■ コネクタへの結線作業**

(原本 p.89-90 / 3-17〜3-18)

専用圧接工具を使って結線する方法について説明します。前もって、「コンタクト」「ハウジング」「電線」をご用意ください。

1. コンタクトのキャリア部の折り切り位置から、矢印の方向に折るように切り離します
2. コンタクトを、専用圧接工具のコンタクト収納部にまっすぐ突き当たるまで差し込みます（図A）
3. 電線を、コンタクトの圧接溝に沿うように、まっすぐ突き当たるまで差し込みます（図B）
4. クランプ部が、完全に電線を抱き込む形になるまで専用圧接工具のハンドルを握ります
5. 電線を軽く引っ張り、専用圧接工具の収納部から電線が圧接されたコンタクトを取り出します
6. コンタクトが付いていない状態のハウジングの溝に沿うように、まっすぐ突き当たるまで差し込みます
7. コンタクトが差し込まれた状態のハウジングをコネクタに装着し、カバーを取り付けます
8. 電線を図のように結束バンドで固定します

【図】(原本 p.89-90): コンタクト折り切り位置・キャリア部 / 図A・図B(圧接パンチ・カバー・ガイド・コンタクト・電線) / クランプ部が電線を抱き込む・奥まで電線を差し込む / ハウジングにネジを付ける / 結束バンド

**■ コンタクトを取りはずすには**

コネクタからコンタクトを取りはずすには、次のようにします。
1. 抜きたい端子を、専用圧接工具のフレームの矢印のところに合わせます
2. コンタクトを押さえながら、電線を引っ張り出します

【図】(原本 p.90): コンタクト引き抜き用ピンをハウジングに合わせ、コンタクトを押さえて電線を引っ張る

### PCなどの外部機器とUSBで通信する場合の注意点

(3-3 / 原本 p.91 / 3-19)

CPUユニットの電源0VとUSBポートのSGは導通しています。接続先のSGと電位差が発生すると、CPUユニットおよび接続先の機器が故障する原因となります。たとえば、プラス接地（24V側接地）した場合、電位差が発生し下図の経路で電流が流れて、機器が破損することがあります。下図の様な配線はしないでください。

【図】(原本 p.91): 外部電源(+24V/0V) → CPUユニット(+24V/0V、USBポートSG) ⇔ USB ⇔ PCなどの外部機器(USBポートSG、FG)。外部電源の+24V側と外部機器のFGがそれぞれ接地されていると、接地 → 外部機器FG/SG → USB → CPUユニットSG/0V → 外部電源 の経路で電流が流れる。

> **参考**
> 上記問題は以下の方法で防止できる場合があります。
> - 24V側接地（プラス接地）をしない
> - KV-PU1を使用する
> - CPUユニットに接続されている電源に絶縁電源を使用する
> - PCなど外部機器のFGを接地しない
> - アイソレータを使用して、USBの信号線を電気的に絶縁する

## 3-4 保守

(3-4 / 原本 p.92-98 / 3-20〜3-26)

ユニットの点検やお手入れの方法、およびバッテリーやリレーの交換方法について説明しています。

### 点検とお手入れについて

(3-4 / 原本 p.92 / 3-20)

**■ 点検**

CPUユニットや各ユニットを長期間使用していると、コネクタの接続部分がゆるむなど、そのまま使い続けると動作に支障を来たすおそれが生じます。
このため、CPUユニットや各ユニット本体、配線部分などは定期的に点検するようにしてください。
おもな点検項目は次のとおりです。
- 各ユニット接続部分のコネクタが、はずれたりゆるんだりしていませんか？
- コネクタ接続部分が、はずれたりゆるんだりしていませんか？
- 端子台のネジがゆるんでいませんか？
- ユニットと各機器間の配線ケーブルなどが破損していませんか？

**■ お手入れ**

CPUユニットや各ユニットを長期間使用していると、汚れが付着してきます。
付着した汚れは、清潔な乾いた布でふき取ってください。
また、コネクタ部分などの細かい部分に付着しているホコリや汚れは、一旦コネクタをはずし、綿棒などを使って取るようにしてください。

### 保守について

(3-4 / 原本 p.92-93 / 3-20〜3-21)

**■ バッテリーについて**

ラダープログラム・デバイスコメント・各種設定情報などはフラッシュROMに、デバイス値・エラー履歴などは不揮発RAMに、それぞれ記憶されています。
ただし、時計データはバックアップ用コンデンサで保持されているため、データがクリアされる場合があります。時計データのバックアップが必要な場合バッテリ（KV-B1）を使用してください。
→「時計データの設定方法」（3-22ページ）

**■ バッテリー低下時について**

アクセスウィンドウに[CPUエラーE83]または[CPU Error E83]が表示されたら、すぐにリチウム電池を交換する必要があります。
バッテリーエラー発生時はCR2306がONします。
バッテリーエラーが発生してからデータを保持できる期間は最低1週間（常温）です。
エラーチェックは、電源立ち上げ後および、24時間毎におこないます。
バッテリーを使用していない場合、バックアップ用のコンデンサの電圧が低下すると、[CPUエラーE85]または[CPU Error E85]が表示されます。

**■ 廃棄について**

CPUユニットを廃棄する場合、各種規制に従い適切に廃棄を行ってください。
CPUユニットを廃棄する際は、データ漏洩を防ぐためにPLC内部の全てのデータを消去することを推奨します。
CPUユニット内のストレージに残された情報を復元できないように完全に消去するには、「初期化」を実施してください。→「初期化」（5-158ページ）

**■ バッテリー切れについて**

(原本 p.93 / 3-21)

バッテリーが切れると時計データの値は消えますが、データメモリやラダープログラム自体は消えません。時計データの情報が消えても動作に問題がないラダープログラムの場合は、アクセスウィンドウでエラークリアをすると一時的にプログラムを動作させることができます。
電池は次の製品をお買い求めください。
交換用リチウム電池　型番 : KV-B1

> **参考**
> バッテリーを使用していない場合、バッテリー切れエラーは発生しません。

**■ バッテリーレス運転について**

CPUユニットはバッテリーを使用しない状態で動作させることも可能です。
設定は不要ですが、バックアップ用コンデンサの電圧が低下すると、時計データがクリアされ、[CPUエラーE85]または[CPU Error E85]が表示されます。

なお、以下の方法でエラーを回避できます。
- CPUシステム設定（エラー発生時の動作設定）で、時刻異常のCPU動作を続行（無視）にする。

**■ バッテリー交換手順**

1. バックアップ用電池のカバーを外して、古い電池を取り外します
   - 電源OFF中に交換する場合は、交換前に10分間以上通電し、交換作業を10分以内に完了させてください。
2. 新しい電池を挿入します
3. 電源をONして、アクセスウィンドウにエラーが表示していないことを確認します

【図】(原本 p.93): CPUユニット正面下部(▼BAT 表示の位置)のバックアップ用電池カバーを開けて電池を取り外す/挿入する

> **注記**
> - バッテリの寿命は以下のとおりです。
>   25℃ : 5年
>   40℃ : 2年
>   75℃ : 1年
> - 電源ON中もバッテリの交換可能です。
> - 電池交換前に10 分以上通電しないと、データが消失することがあります。電池交換は10分以内でおこなってください。
> - CPUユニットに使用されるバッテリーを火中に投じたり、分解しないでください。また、本バッテリーは充電式ではありませんので、充電しないでください。爆発の危険性があります。
> - KV-B1以外の電池を使用されますと火災または爆発の恐れがありますので必ず指定の電池を使用してください。

### 復旧方法について

(3-4 / 原本 p.94 / 3-22)

**■ 時計データの設定方法**

CPUユニットの時計データは内蔵のバックアップ用コンデンサで保持されており、通電しない状態で保持した場合、時計データはクリアされてしまいます。時計データを常に保持する場合は、バッテリー（KV-B1）を取り付けて使用してください。
時計データがクリアされると、CR2311がONします。

※ バックアップ用コンデンサを満充電するためには30分以上通電してください。

バックアップ用コンデンサの保持時間（満充電時）

| 温度 | TYP | MIN |
|---|---|---|
| 25℃ | 60日 | 15日 |
| 40℃ | 40日 | 10日 |
| 75℃ | 12日 | 3日 |

(原本の表 3行 → md 3行)

必要に応じて、以下のいずれかの方法で設定してください。
- 《KV STUDIO》のモニタ実行中に、メニューから【デバッグ（D）】→【カレンダタイマの設定（C）】
- ラダープログラムでWTIME命令を使用する
- アクセスウィンドウから時計で設定する
- タッチパネル（VT5/VT3シリーズ）を使用している場合、PLC時刻同期機能を使用する
  （修復機能を使用している場合、自動で時刻を調整できます）
  →『VT STUDIOリファレンスマニュアル』

> **参考**
> 時計データがクリアされると、以下の様な機能が正常に動作しない場合があります。
> - ロギング・トレース機能（ロギング/トレース実行時間が異なります）
> - エラーモニタ機能（エラー発生時の時刻が異なります）
> - ウィークリー接点命令

### 復旧方法

(3-4 / 原本 p.95 / 3-23)

**■ エラー発生時のクリア方法**

CPUユニットでエラーが発生した場合、以下の方法でエラークリアを実行できます。
- アクセスウィンドウからエラークリアを実行します。→「エラークリア」（5-129ページ）
- 《KV STUDIO》でモニタ中は、エラー発生時に起動するポップアップウィンドウからクリアできます。
- ラダープログラムでエラークリア要求リレー（CR3909）をSETします。（軽度エラーのみ）
- 電源の切り入りを実行します。

> **ポイント**
> - CR に BOOL の配列型変数を割り当てた場合、配列の要素番号は数値で指定してください。
>   デバイスや変数で指定した場合、SET命令が正しく動作しません。
> - システムに関わる重大なエラーの一部では、電源の再起動が必要になる場合があります。

**■ PLCの状態をクリアする方法**

CPUユニットの状態を出荷状態にしたり、プログラム内で使用されるデバイスの値をクリアしたりできます。

**出荷状態にする場合**

ラダープログラムやデバイスコメント、各種設定情報、デバイス値・エラー履歴・イベント履歴・CPUメモリなどをクリアします。
以下のいずれかの方法を使用してクリアしてください。
- 《KV STUDIO》のメニューから【ツール（T）】→【PLCクリア（1）】を選択し、[PLCクリア]ダイアログボックスで、「オールクリア」、または「初期化」にチェックして〔実行（E）〕ボタンをクリックします。
- アクセスウィンドウからオールクリア、または初期化を実行します。

> **注記**
> - 初期化を実行すると、CPUユニット内のストレージを全て無効なデータで上書きし、中のデータは完全にクリアされます。
> - オールクリア/初期化中は電源を切らないでください。完了したかどうかはアクセスウィンドウの表示内容で確認できます。

**デバイスの値をクリアする場合**

デバイス値・エラー履歴などをクリアします。
以下のいずれかの方法を使用してクリアしてください。
- 《KV STUDIO》のメニューから【ツール（T）】→【PLCクリア（1）】を選択し、[PLCクリア]ダイアログボックスで、「RAMクリア」にチェックして〔実行（E）〕ボタンをクリックします。
- アクセスウィンドウからRAMクリアを実行します。

**CPUメモリ（ユーザメモリ）をクリアする場合**

CPUメモリ内のユーザドキュメント・ファイルレジスタ設定・ロギングデータ・プロジェクトセーブデータなどをクリアします。
以下のいずれかの方法を使用してクリアしてください。
- 《KV STUDIO》のメニューから【ツール（T）】→【PLCクリア（1）】を選択し、[PLCクリア]ダイアログボックスで、「ユーザメモリクリア」にチェックして〔実行（E）〕ボタンをクリックします。
- アクセスウィンドウからユーザメモリクリアを実行します。

**全履歴をクリアする場合**

CPUユニットのエラー履歴、電源ON/OFF履歴、PLCイベント履歴をすべてクリアします。
以下の方法でクリアしてください。
- ラダープログラムでイベントログクリアリレー（CR3910）をSETします。

> **ポイント**
> - CR に BOOL の配列型変数を割り当てた場合、配列の要素番号は数値で指定してください。
>   デバイスや変数で指定した場合、SET命令が正しく動作しません。

### システムプログラムアップデートについて

(3-4 / 原本 p.96-98 / 3-24〜3-26)

システムプログラムをKV STUDIOやメモリカードからアップデートすることで、CPU機能バージョンをバージョンアップできます。アップデート手順は以下のとおりです。

**KV STUDIOからアップデートする場合**

1. KV STUDIOのメニューで【ツール(T)】→【CPU機能バージョン確認(X)】→【システムプログラム更新(U)】から確認できます。
   - 【図】(原本 p.96): KV STUDIO のツールメニュー → 機能バージョン確認(X) → PLC(P)... / システムプログラム更新(U)...

> **ポイント**
> - システムプログラムアップデートはUSBで接続した場合のみ実行できます（イーサネット接続など他の接続方法の場合実行できません）。

2. 接続しているKV-8000シリーズが最新バージョンかどうか確認し、最新バージョンでない場合は、〔更新〕ボタンをクリックしてシステムバージョンアップを開始します。
   - 【図】[システムプログラム更新]ダイアログ (原本 p.96): 列 = 機種 / 現在バージョン / 更新 / 更新後バージョン / シリアル番号。〔最新情報を取得(G)〕〔更新(U)〕〔キャンセル〕ボタン。ダイアログ内の注意表示:
     - USBでPLCと接続してください。
     - システムプログラムを更新したユニットはオールクリア状態になります。
     - 更新完了まで電源を切らないでください。

> **ポイント**
> - システムアップデート実行中は電源を切らないでください。
> - システムプログラムアップデートを実行すると、ユニット内部のプログラムは消去されます。システムプログラムアップデート前に、プログラムをバックアップしてください。
> - システムプログラムを最新にアップデートするには、事前にKV STUDIOを最新にアップデートしてください。
> - KV STUDIO Ver.11.63以降を使用している場合、システムプログラムバージョンが2.7以降だと更新後バージョンの右側の［…］を押下することで、更新後バージョンのチェックコードを確認できます。ホームページのKV STUDIO変更履歴の中で公開しているチェックコードと比較して一致しているかを確認することで、当社製の正常なアップデートファイルかどうかを確認できます。

(原本 p.97 / 3-25)

> **ポイント**
> - システムプログラムが最新の場合、以下のダイアログが表示されます。
>   (【図】[システムプログラム更新]ダイアログ。更新後バージョン欄の表示例)

3. 完了すると以下のダイアログが表示されます。
   - 【図】ダイアログ文言: 「システムプログラムを更新しました。」〔OK〕

> **ポイント**
> - システムプログラムアップデート実行時にCPUユニットとパソコンの間で他の通信が実行される場合、以下のダイアログが表示され、システムアップデートは実行されません。
>   (【図】ダイアログ文言: 「パソコン上で他のアプリケーションがPLC と通信しているので更新を開始できませんでした。他のアプリケーションのPLC通信を停止した後に、再度更新を開始してください。」〔OK〕)

**メモリカードからアップデートする場合**

(原本 p.98 / 3-26)

1. KV STUDIOのメニューで【ファイル(F)】→【メモリカード(M)】→【保存(W)】でメモリカードデータを作成します。
2. 保存したメモリカードデータをメモリカードに格納しロードを実行します。

> **ポイント**
> - メモリカードからのロード（オートロード / ランロード含む）については「ロード」（5-142ページ）「オートローディング機能」（5-45ページ）を参照してください。
> - メモリカードデータをCPUメモリに格納してロードを実行した場合、ロードは失敗します。
