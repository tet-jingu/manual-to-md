- 設定 時定数100

### アクセスウィンドウを操作する

(6-9 / 原本 p.606 / 6-38)

アクセスウィンドウは、CPUユニットにある設定操作キーで操作します。

| 設定操作キー | 通　常 | 数値変更時 |
|---|---|---|
| MENU | メニュー表示 | メニュー表示 |
| ENTER | 1秒以上押しつづけると、設定変更を実行します。 | 1秒以上押しつづけると、設定変更を実行します。 |
| ▲ | ページを切り換えます。設定変更時は選択肢を変更します。 | 設定値から変化量を加算します。 |
| ▼ | ページを切り換えます。設定変更時は選択肢を変更します。 | 設定値から変化量を減算します。 |
| ◀ | メニュー表示 | 変化量の桁を変更します。(◀・▶ 共通の結合セル) |
| ▶ | 使用しません。 | (同上) |

(原本の表 6行 → md 6行)

※設定変更はCPUユニットがPROGRAMモード時のみ可能です。

## 6-10 ユニットモニタ

(6-10 / 原本 p.610 / 6-42)

ラダーサポートソフト《KV STUDIO》のユニットモニタ機能は、モニタするユニットで使用しているリレーやDMの値を、ユニットにあわせて最適に表示する機能です。ここでは、ユニットモニタの見かたや操作方法について説明します。

### ユニットモニタの概要

(6-10 / 原本 p.610 / 6-42)

ユニットモニタは、モニタするユニットで使用しているリレーやDMの値を、ユニットにあわせて最適に表示するウィンドウです。

ユニットモニタには次のような特長があります。
- ユニット毎に割り付けられているDM、リレーを最初から登録した状態で表示できます。
- ユニット毎に表示内容やレイアウトが雛形として用意されているため、モニタが簡単です。
- リレーやDMの割付状況を気にしなくても、モニタしたいユニットを選択するだけで、選択したユニットのモニタができます。

> **ポイント** ユニットモニタは、モニタ・オンラインエディット中にのみメニューから選択できます。

### ユニットモニタの表示

(6-10 / 原本 p.610 / 6-42)

次の手順でモニタしたいユニットを表示します。

1. **メニューから【モニタ/シミュレータ】【ユニットモニタ】を選択します。**
   「ユニットモニタ選択」ダイアログボックスが表示されます。
2. **モニタしたいユニットを選択して、「表示」ボタンをクリックします。**

【図】「ユニットモニタ選択」ダイアログ (原本 p.610)
- リスト: `0:KV-8000A`(選択中) / `1:KV-SSC02` / `2:KV-SAD04`
- ボタン: `表示(D)` / `閉じる(C)`

**別手順**
- ワークスペースのユニット設定で、モニタしたいユニットを選択し、ダブルクリックします。または、右クリックメニューから「ユニットモニタ」を選択します。
- ユニットエディタ上で、モニタしたいユニットを選択し、右クリックメニューから「ユニットモニタ」を選択します。または、メニューから【表示】【ユニットモニタ】を選択します。

【図】プロジェクトツリーからの表示 (原本 p.610)
- 「プロジェクト」ペイン: `ユニット構成` 配下に `[0] KV-8000A`、`[1] KV-SIR32XT R34000/R34200`(選択中)
- 右クリックメニュー: `ユニットエディタ(U)` / `デバイス割付表示(D)` / `ユニットモニタ(C)`(赤枠で強調)
- ツリー下部に `構造体`、`運転記録設定` が見える
- 矢印の先に「32+32点混合入出力ユニットモニタ」ウィンドウ:
  - タイトル行: `1:KV-SIR32XT[1]`、タブ: `0-31` / `32-63`
  - 左列: `入力` `先頭リレー番号 R34000` `□時定数表示`、`00:`〜`15:`(`03: 手動入力`、`10: セーフティ`、`11: エラー入力` のコメント付き)、下部 `0000` `16進`
  - 右列: `入力` `先頭リレー番号 R34100` `□時定数表示`、`00:`〜`15:`、下部 `0000` `16進`

## 6-11 I/Oユニット参考プログラム例

(6-11 / 原本 p.611 / 6-43)

≪KV-SIR32XT≫を使用した場合に使用できるサンプルプログラムをご紹介します。
以下のプログラムではKV-SIR32XTをR000から割り付けた場合の例で説明します。

### ■ 信号変換器を使用した割り込みの応用例

(6-11 / 原本 p.611 / 6-43)

割り込み処理を使用した微小パルスを一定の幅のパルスに変換して出力します。
- 入力リレーR000で入力した微小パルスを、出力リレーR200からON幅1秒のパルスに変換します。
- 入力リレーR000の立ち上がりから1秒間、出力リレーR200がONします。
