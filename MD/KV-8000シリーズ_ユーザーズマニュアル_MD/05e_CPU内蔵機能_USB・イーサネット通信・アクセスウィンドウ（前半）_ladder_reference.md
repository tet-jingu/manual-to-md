## 5-7 USB通信

(5-7 / 原本 p.487 / 5-111)

CPUユニットのUSBポートを使用して、《KV STUDIO》でラダープログラムのモニタ･デバッグができます。USBポートを使用してコマンド通信などはできません。

> **参考**
> KV COM+ for Excel/KV COM+ Libraryを使用すれば、PLCデバイス値の読み書きが可能です。

### パソコンとの接続方法

(5-7 / 原本 p.487 / 5-111)

USBケーブル（OP-35331）をパソコンとCPUユニットに接続します。

> **ポイント**
> - CPUユニットをパソコンのUSBコネクタに接続する前に、必ず《KV STUDIO》をインストールしてください。
> - USBポートのSGは電源0Vと共通です。接続先のSGと電位差が発生すると、CPUユニットおよび接続先の機器が故障する原因となります。

### USBドライバのインストール

(5-7 / 原本 p.487 / 5-111)

Windows 11/10/8/7のパソコン使用時は、自動的に認識されるためインストールする必要はありません。

## 5-9 アクセスウィンドウ

(5-9 / 原本 p.489 / 5-113)

### アクセスウィンドウでできること

(5-9 / 原本 p.489-492 / 5-113〜5-116)

KV-8000シリーズは、小型の2色バックライト付LCD表示器を搭載しています。
RUN中は白、PRGモード時（停止中）は赤になります。

- Unit Monitor: 「KV-SAD04 CH0 / A/D変換データ / +8521」 / 「KV-SAD04 CH0 / A/D Conv Data / +8521」(中国語画面も英語表記)

- Display device: 「DM0 1354 / DM1 4059」(3言語共通)

**■ 機能一覧**

(5-9 / 原本 p.490-491 / 5-114〜5-115)

CPUユニットに搭載されているアクセスウィンドウでデバイスデータを変更・モニタできます。また、万一のエラー発生時にエラーコードが確認できます。
アクセスウィンドウには、以下の機能があります。

- **ユニットのモニタ**: CPUに接続されたユニットのダイレクトアクセススイッチを押すと、アクセスウィンドウ上でそのユニットの状態をモニタできます。 →「ユニットのモニタ」（5-117ページ）
- **デバイスモード**: 内部デバイスの表示、設定内容の変更が可能です。 →「デバイスモード」（5-120ページ）
- **ストレージ**: メモリカードやCPUメモリ内のプロジェクトセーブやロード、ファイル管理、空き容量の確認などの操作を行えます。 →「ストレージ」（5-141ページ）
- **エラークリア**: CPUユニットの重度エラーをクリアします。 →「エラークリア」（5-129ページ）
- **デジタルトリマ**: デジタル方式でトリマの設定を行えます。最大分解能は4294967296です。 →「デジタルトリマ」（5-130ページ）
- **ユニットテスト**: 拡張ユニットの入出力などの状態を確認できます。 →「ユニットテスト」（5-132ページ）
- **時刻表示／設定**: CPUの内部時計の表示、時刻設定を行います。 →「時計」（5-134ページ）
- **CPUモニタ**: CPUの内蔵機能の状態をモニタできます。また、本体に入っているプログラムのプロジェクト名や、本体のシリアル番号、バージョンを確認できます。 →「CPUモニタ」（5-136ページ）
- **アラームモニタ**: 任意に設定したアラームのモニタや履歴を確認できます。 →「アラーム」（5-138ページ）
- **アクセスウィンドウ設定**: アクセスウィンドウのコントラストなど、アクセスウィンドウの表示に関する設定を行えます。 →「アクセスウィンドウ設定」（5-154ページ）
- **Language**: 表示する言語を、日本語、英語、中国語（簡体字）から選択できます。
- **RAMクリア**: デバイスの値をクリアできます。 →「RAMクリア」（5-156ページ）
- **オールクリア**: 設定した内容をすべてクリアできます。 →「オールクリア」（5-157ページ）
- **初期化**: CPUメモリの全エリアに無効なデータを書き込むことで設定した内容を復元できないようにクリアできます。 →「初期化」（5-158ページ）
- **CPUメモリクリア**: CPUメモリ内のデータをクリアできます。

**■ 操作方法**

(5-9 / 原本 p.497 / 5-121)

**● デバイスモードへの移行**

1. 「MENU」キーを押します。
   - メニューが表示されます。（他ユニットが選択されている場合は「MENU」キーを2回押してください。）
2. [1.デバイスモード]を選択して、「ENTER」キーを押します。
   - デバイスモードに切り換わり、モニタ表示の画面が表示されます。
   - 画面: 「R0 / OFF / R1 / ON」
   - 「▲」「▼」キーでモニタするデバイス番号を変更できます。

**● モニタするデバイス種別の変更**

1. デバイスモードの状態で「◀ / ▶」キーを押します。
   - 画面: 「R0 / OFF / R1 / ON」
2. デバイスの種類が一覧で表示されます。
   - 「▲」「▼」キーで表示したいデバイスを選択してください。
   - ここでは例として[TM]を選択します。
   - 画面: 「・R / ・MR / ・LR / ・B」
   - デバイスの種類はR→MR→LR→B→CR→DM→EM→FM→ZF→W→CM→TM→T→C→TRM→Zの順になっています。Zを選択している状態で「▼」キーを押すと、再びRが選択されます。
   - 同様に、Rを選択している状態で「▲」キーを押すと、Zが選択されます。
3. [･TM]が点滅表示します。(原本 p.498 / 5-122)
   - 画面: 「・ZF / ・W / ・CM / ・TM(点滅)」
   - ここで「ENTER」キーを押すと表示したいデバイス記号を決める画面になります。
   - 現在のデバイス番号が上から3行目に点滅表示されます。
   - 画面: 「[デバイス番号] / TM / 0 / 100」、英語「[Display Number] / TM / 0 / 100」、中国語「[软元件编号] / TM / 0 / 100」
   - 4行目に表示されている数値は、デバイス番号の変化量です。
   - デバイス番号は「▲」キー、「▼」キーで変化します。
   - 図の場合、「▲」キーを押すと、100ずつデバイス番号が大きくなります。
   - デバイス番号の変化量は、「◀ / ▶」キーで10倍または1/10倍になります。
   - 「▲」キー、「▼」キー、「◀ / ▶」キーで、表示したいデバイス番号を決めてください。
   - 「ENTER」キーを押すと、指定した番号のTMの表示になります。
   - 画面: 「TM56 / 0 / TM57 / 0」

- C : カウンタ設定値

     - 重度エラー・・・「E○○○」

|---|---|---|---|---|
| 52 | 設定エラー | ユニット未接続 / Unit Unconnected / 单元未连接 | ユニット設定情報では拡張ユニットありになっているのに、実際には接続されていません。 | 電源をOFFにしてから、ユニットエディタで設定した拡張ユニットを接続してください。 |

   - バージョンが表示されます。

【図】バージョン画面 (原本 p.513): 画面「CPU: / (2行目空欄) / 1.000 / 1111111」

### アラーム

(5-9 / 原本 p.514-516 / 5-138〜5-140)

アラームリレー（CR3300～CR3415）にデバイスコメントとしてメッセージを登録しておくと、アラームリレーがONした場合にメッセージを自動的にアクセスウィンドウ上に表示します。また、発生したアラームの履歴を確認したりクリアすることもできます。

**■ 使用方法**

アラームで使用するデバイスは次のとおりです。

| コントロールリレー | R/W | 内容 |
|---|---|---|
| CR3300～CR3415 | R/W | アラームリレー(32個)です。あらかじめデバイスコメントを登録しておきます。 |
| CR3500 | R | アラームリレーが1つでもONしているとCR3500がONします。ONしているアラームがすべてOFFすると、自動的にCR3500もOFFします。 |
| CR3501 | R/W | ON→OFF履歴を保存します。 |
| CR3502 | R/W | OFF→ON時にアラームリレーの履歴をクリアします。 |

(原本の表 4行 → md 4行)

> **ポイント**
> アラームリレーは必ずSET、RES命令で操作してください。動作中のアラームリレーのリセットかつアラーム履歴の一括クリアはARES命令でも可能です。

**● アラームメッセージの登録**

アラームリレー（CR3300～CR3415）にデバイスコメントを登録します。

> **ポイント**
> アクセスウィンドウに表示できるメッセージは全角8文字（半角16文字）までです。デバイスコメントを設定していない場合はアラームリレーの番号を表示します。

**● アラーム履歴について**

アラーム履歴は、CPUユニットに最大16件まで保存されます。
16件を超える場合は、古い履歴から順に削除して新しい履歴を保存します。
1件につき、「アラームリレー番号」「時刻（年月日時分秒）」「ON/OFFの状態」を保存します。
- ON→OFF履歴リレー（CR3501）がOFFの場合
  アラームリレーがOFF→ONの場合のみ履歴を保存します。
- ON→OFF履歴リレー（CR3501）がONの場合
  アラームリレーがOFF→ONとON→OFFの両方とも履歴を保存します。

CR3502をONすると、アラームリレーの履歴をクリアします。クリアが完了すると、CR3502はOFFします。

**■ 操作できる項目**

(原本 p.515 / 5-139)

アクセスウィンドウから操作できる機能は次のとおりです。

| 日本語 | 英語 | 中国語 | 設定内容 |
|---|---|---|---|
| モニタ | Monitor | 报警监控器 | ONしているアラームリレーをリアルタイムでモニタできます。 |
| 履歴モニタ | Monitor Record | 日志监控器 | アラームリレーのON/OFF履歴をモニタできます。 |
| 履歴クリア | Clear Record | 日志清除 | アラームリレーのON/OFF履歴をクリアします。 |

(原本の表 3行 → md 3行)

**■ 操作方法**

**● アラームへの移行**

1. 「MENU」キーを押します。
   - メニューが表示されます。（他ページが選択されている場合は「MENU」キーを押してください。）
2. 「8.アラーム」を選択して、「ENTER」キーを押します。
   - アラームのメニューが表示されます。
   - 画面: 「・モニタ / ・履歴モニタ / ・履歴クリア」、英語「・Monitor / ・Monitor Record / ・Clear Record」、中国語「・报警监控器 / ・日志监控器 / ・日志清除」

**● モニタ**

1. アラームのメニューで「モニタ」を選択して、「ENTER」キーを押します。
   - アラームモニタが表示されます。
   - 複数のアラームリレーがONしている場合、「▲」「▼」キーを押すと別のアラームを表示します。
   - 画面: 「アラームモニタ / 01/03 / 速度上限異常」、英語「Alarm Monitor / 01/03 / Spd. Limit Over」、中国語「报警监控器 / 01/03 / 速度上限异常」
   - ①[01/03]: 現在表示中のアラーム番号／発生しているアラーム総数です。複数のアラームが発生している場合は、アラームリレー番号の小さいものを優先して表示します。
   - ②[速度上限異常]: 現在表示しているアラームの対象デバイスのデバイスコメントです。

> **参考**
> - いずれかのキーを押すと、点滅が止まります。
> - 他の画面を表示中でも、アラームが一つでも発生すると自動的にアラームモニタが表示されます。

**● 履歴表示**

(原本 p.516 / 5-140)

1. アラームのメニューで「履歴モニタ」を選択して、「ENTER」キーを押します。
   - アラーム履歴が表示されます。
   - 「▲」「▼」キーを押すと、1つ前/後の履歴を表示します。
   - 画面: 「履歴 01/04 / 温度ワーニング / 2015/3/13 / 12:13:14 ↓」、英語「Record 01/04 / Temp. Warn. / …」、中国語「日志 01/04 / 温度警告 / …」
   - ①[01/04]: 現在表示中のアラーム履歴番号／履歴総数です。番号は最新の履歴が[01]になります。
   - ②[温度ワーニング]: 現在表示している履歴の対象デバイスのデバイスコメントです。
   - ③[ ↓ ]: アラームリレーがONからOFFになったときの履歴であることを示しています。OFFからONになったときの履歴は「↑」で表示されます。
   - ④[2015/3/13 12:13:14]: 履歴が記録された時刻を示しています。

**● 履歴クリア**

1. アラームのメニューで「履歴クリア」を選択して、「ENTER」キーを押します。
   - 履歴クリアの確認メッセージが表示されます。
   - 画面: 「履歴クリア / クリアしますか?」、英語「Clear Record / Clear OK?」、中国語「日志清除 / 是否清除?」
2. 「ENTER」キーを1秒以上押しつづけます。
   - 履歴クリアが終了すると、次の表示になります。
   - 画面: 「履歴クリア / クリア完了」、英語「Clear Record / Clear Done」、中国語「日志清除 / 清除完成」
   - 「MENU」キーを押すとアラームメニュー表示に戻ります。
