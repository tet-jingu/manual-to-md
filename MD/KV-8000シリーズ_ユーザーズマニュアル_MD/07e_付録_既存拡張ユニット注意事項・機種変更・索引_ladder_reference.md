### 使用時の制限事項

(付録10 / 原本 p.660 / 付-44)

KV-8000シリーズで既存のKVシリーズの拡張ユニットを使用する場合、以下の制限事項が発生します。

#### ■ KV-XLE02 (付録10 / 原本 p.660 / 付-44)

- 機能バージョン1.2以降のユニットのみ接続可能です。
- KV-8000Aの場合メールの送受信機能が使用できません。

#### ■ KV-XCM02 (付録10 / 原本 p.660 / 付-44)

- KV-8000Aの場合メールの送受信機能が使用できません。

#### ■ KV-XL202/XL402 (付録10 / 原本 p.660 / 付-44)

- 機能バージョン1.1以降のユニットのみ接続可能です。

#### ■ KV-XH16ML/XH04ML/XH64EC/XH32EC/XH16EC (付録10 / 原本 p.660 / 付-44)

- KV-8000Aの場合、同期接点出力が使用できません。

#### ■ KV-L21V/KV-L20V (付録10 / 原本 p.660 / 付-44)

- 上位リンクモードを使用した場合、KV-L21V/KV-L20V経由で読み書きできるRの範囲はR00000～R99915まで、MRの範囲はMR00000～MR99915までです。（XYMモード使用時はM00000～M64000ま
- で使用できます）
- 上位リンクモードを使用した場合、KV-L21V/KV-L20V経由で読み書きできる拡張ユニットバッファメモリは0～32767です。
- プロトコルモードを使用した場合、KV-L21V/KV-L20V経由で読み書きできる拡張ユニットバッファメモリは0～32767です。
- リンクモードを使用した場合、KV-L21V/KV-L20V経由で読み書きできるRの範囲はR00000～R99915まで、MRの範囲はMR00000～MR99915までです。

> 補足(原文にはない): 1項目目の「（XYMモード使用時はM00000～M64000まで使用できます）」は、原本では行の途中で箇条書き記号が入り2項目に分かれて印刷されている(原本 p.660)。上は原本のレイアウトのまま転記。

#### ■ KV-LE21V/KV-LE20V (付録10 / 原本 p.660 / 付-44)

(付録10 / 原本 p.660 / 付-44)

- KV-LE21V/KV-LE20Vを経由した場合、VM65536以降にはアクセスできません。
- 上位リンクモードを使用した場合、KV-LE21V/KV-LE20V経由で読み書きできるRの範囲はR00000～R99915まで、MRの範囲はMR00000～MR99915まで（XYMモード使用時はM00000～M64000まで使用できます）、VMの範囲はVM00000～VM63999までです。
- MCプロトコルモードを使用した場合、KV-LE21V/KV-LE20V経由で読み書きできる拡張ユニットバッファメモリは0～32767です。
- FTPサーバ機能を使用した場合、R100000以上のデバイスファイルは表示されません。
- FTPサーバ機能を使用した場合、6ケタ以上のMR（たとえば、MR100000以上のデバイス）の末尾一桁は表示できません。
- FTPサーバ機能を使用した場合、CPUメモリへの読み書きはできません。
- FTPクライアント機能を使用した場合、CPUメモリへの読み書きはできません。
- KV-8000Aの場合メールの送受信機能が使用できません。

#### ■ KV-EP21V (付録10 / 原本 p.661 / 付-45)

(付録10 / 原本 p.661 / 付-45)

- KV-EP21Vを経由した場合、VM65536以降にはアクセスできません。
- 上位リンクモードを使用した場合、KV-LE21V/KV-LE20V経由で読み書きできるRの範囲はR00000～R99915まで、MRの範囲はMR00000～MR99915まで（XYMモード使用時はM00000～M64000まで使用できます）、VMの範囲はVM00000～VM63999までです。
- MCプロトコルモードを使用した場合、KV-LE21V/KV-LE20V経由で読み書きできる拡張ユニットバッファメモリは0～32767です。
- FTPサーバ機能を使用した場合、R100000以上のデバイスファイルは表示されません。
- FTPサーバ機能を使用した場合、6ケタ以上のMR（たとえば、MR100000以上のデバイス）の末尾一桁は表示できません。
- FTPサーバ機能を使用した場合、CPUメモリへの読み書きはできません。
- FTPクライアント機能を使用した場合、CPUメモリへの読み書きはできません。
- メッセージ通信機能を使用した場合、KV-EP21V経由で読み書きできる拡張ユニットバッファメモリは0～32767です。
- KV-8000Aの場合メールの送受信機能が使用できません。

> 補足(原文にはない): KV-EP21V の項の2・3項目目は、原本でも「KV-LE21V/KV-LE20V経由で」と記載されている(原本 p.661)。原文のまま転記。

#### ■ KV-LM21V/KV-LM20V (付録10 / 原本 p.661 / 付-45)

- メガリンクモードを使用した場合、KV-LM21V/KV-LM20V経由で読み書きできる拡張ユニットバッファメモリは0～32767、VMは0～63999です。
- シリアルPLCリンクモードを使用した場合、KV-LM21V/KV-LM20V経由で読み書きできるリンクビットデバイスはB0000～B1FFF、リンクレジスタはW0000～W3FFFです。

#### ■ KV-FL20V (付録10 / 原本 p.661 / 付-45)

- KV-FL20Vで読み書きできるリンクビットデバイスはB0000～B3FFF、リンクレジスタはW0000～W3FFF、R1000～R99915です。

#### ■ KV-CL20 (付録10 / 原本 p.661 / 付-45)

- トランジェント伝送機能を使用する場合、T/C/CRに対する書き込みはできません。

#### ■ KL-N20V (付録10 / 原本 p.661 / 付-45)

- 通信状態確認モードで起動する場合、ダイレクトアクセススイッチが緑点灯するまでダイレクトアクセススイッチを押し続けてください。ダイレクトアクセススイッチを離すのが早いと、正常に起動できずにCPUエラーE63[電源再投入が必要]が発生する場合があります。

(付録11 / 原本 p.662 / 付-46)

1. 《KV STUDIO》のメニューから【ファイル（F）】→【機種変更（L）】を選択して、機種変更を実行します。

- チェックボックス「別名でバッ…」とリンク「機種変更時の注…」はドロップダウンに隠れて文言の後半が見えない。**要確認**: 隠れた文言の全文は原本 p.662 参照

> **参考**
