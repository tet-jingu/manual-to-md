## 5-11 カムスイッチ

(5-11 / 原本 p.558 / 5-182)

エンコーダからの値を角度変換してカム動作を擬似的に実行できます。

### カムスイッチ機能の概要

(5-11 / 原本 p.558 / 5-182)

あらかじめ設定している複数の範囲設定と、エンコーダなどから入力された現在値を比較します。
現在値がどの範囲設定にあるか検出し、該当する範囲設定に対応する出力先デバイスをONします。

【図】カムスイッチ機能の概要 (原本 p.558)
- 入力: ・エンコーダ ・CPU内部のデバイス → 現在値
- 現在値を、範囲設定(OFF設定値 / ON設定値 の組)①〜㉜と「比較」する
- 範囲設定①〜㉜それぞれに出力先デバイス①〜㉜が対応
- ONする範囲:
  - ①ON≦（現在値）＜①OFF
  - ②ON≦（現在値）＜②OFF
  - ︙
  - ㉛ ON≦（現在値）＜㉛OFF
  - ㉜ ON≦（現在値）＜㉜OFF

入力方式によりそれぞれ専用の命令語を用意しています。

【図】入力方式と命令 (原本 p.558)
- アブソリュート式エンコーダ →(外部入力 5ビット～15ビット)→ 外部入力「汎用入力」→ カムスイッチ命令「ABSENC命令」→ 出力
- 「CPU内部のデバイス」→ カムスイッチ命令「MCMP命令」→ 出力

### カムスイッチ命令

(5-11 / 原本 p.558 / 5-182)

### MCMP 多段コンパレータ

(5-11 MCMP / 原本 p.559 / 5-183)

| 命令 | 名称 | 機能 |
|---|---|---|
| MCMP | 多段コンパレータ | 多段コンパレータの動作を行います。 |

(原本の表 1行 → md 1行)

#### 書式 (ラダープログラム / 入力方法)

(5-11 MCMP / 原本 p.559 / 5-183)

- ラダープログラム: 実行条件(a接点) → MCMP 命令ボックス(上段: S1 / S2 / D、下段: n)
- 入力方法: `M C M P ␣ S1 ␣ S2 ␣ D ␣ n ↵`

```
MCMP S1 S2 D n
```

#### オペランド

(5-11 MCMP / 原本 p.559 / 5-183)

| オペランド | 説明 | 占有サイズ |
|---|---|---|
| S1 | 比較するデータブロックの先頭デバイスを指定します。※1 | 32× n ビット |
| S2 | 比較するデバイスを指定します。※2 | 16ビット |
| D | 比較結果を格納する先頭デバイスを指定します。※3 | n ビット |
| n | 比較するデータ数または、それを格納しているデバイスを指定します。（1～32）※4 ※5 | 16ビット |

(原本の表 4行 → md 4行)

- ※1 ビットデバイスを指定した場合、チャンネルの先頭から連続した n ×32ビットを扱います。
  ワードデバイスを指定した場合、 n ×2ワードを扱います。
- ※2 ビットデバイスを指定した場合、連続した16ビットを扱います。
  チャンネルの先頭以外（R002,R106,R1012など）を指定した場合、次のチャンネルにまたがって16ビット扱います。
- ※3 ビットデバイスを指定した場合、 n ビットを占有します。
  ワードデバイスを指定した場合、各ワードデバイスの最下位ビットが結果の格納先になります。最下位ビット以外は変化しません。
- ※4 “$”は使用できません。
- ※5 ビットデバイスを指定した場合、連続する16ビットを占有します。
  ワードデバイスを指定した場合、1ワードを占有します。

> 補足(原文にはない): 使用可能デバイス表は本マニュアルのこのページには掲載されていません(デバイスの扱いは上記※1〜※5のみ)。コントロールデータ・完了デバイスを持つ命令ではありません。

#### 動作説明

(5-11 MCMP / 原本 p.560 / 5-184)

実行条件がONのとき S1 から始まる n 個の32ビットのデータ（16ビット符号無しBINデータ2つ:OFF設定値、ON設定値）と S2 で指定したデバイスに格納されている16ビット符号無しBINデータを比較し、結果を D から始まるビットデバイスに格納します。

【図】MCMP のデータ配置と比較結果の例 (原本 p.560)
- 1組の32ビットデータのうち、bit31〜bit16 が OFF設定値(S1+1, S1+3, S1+5 …)、bit15〜bit0 が ON設定値(S1, S1+2, S1+4 …)。n 個(n ×2ワード)
- 最終組は OFF設定値 S1+2(n −1)+1 / ON設定値 S1+2(n −1)、その前は S1+2(n −2)+1 / S1+2(n −2)
- 例: S2 = 30 のとき

| 組 | OFF設定値(デバイス / 値) | ON設定値(デバイス / 値) | 結果デバイス | 結果 |
|---|---|---|---|---|
| 1 | S1 +1 / 30 | S1 / 12 | D | OFF |
| 2 | S1 +3 / 40 | S1 +2 / 30 | D +1 | ON |
| 3 | S1 +5 / 30 | S1 +4 / 80 | D +2 | OFF |
| n −1 | S1 +2(n −2)+1 / 10 | S1 +2(n −2) / 30 | D + n −2 | ON |
| n | S1 +2(n −1)+1 / 30 | S1 +2(n −1) / 30 | D + n −1 | OFF |

(原本の図中の例 5行 → md 5行。3組目と n −1組目の間は原本で点線省略表記)

**OFF設定値＞ON設定値の場合**
OFF設定値＞ S2 ≧ON設定値の範囲のとき、 D がONします。

**OFF設定値＜ON設定値の場合**
OFF設定値＞ S2 または S2 ≧ON設定値の範囲のとき、 D がONします。

**OFF設定値＝ON設定値の場合**
常に、 D がOFFします。

> **ポイント**
> 実行条件がOFFしても、出力は変化しません。

#### 演算フラグ

(5-11 MCMP / 原本 p.560 / 5-184)

| フラグ | 内容 |
|---|---|
| CR2009 | 変化なし |
| CR2010 | 変化なし |

(原本の表 4行 → md 4行)

※ CR2012がONした場合、命令は実行されません。
CR2012がONした場合、CM5150～CM5176にエラーの詳細情報が格納されます。
参照: 「最新エラー詳細（CM）」（4-87ページ）

#### サンプルプログラム

(5-11 MCMP / 原本 p.561 / 5-185)

データメモリDM0の値を設定値と比較して出力リレーを以下の条件でON/OFFします。

- DM0が#100以上#200未満の場合はR30000をON
- DM0が#300以上#400未満の場合はR30001をON
- DM0が#500以上#600未満の場合はR30002をON
- DM0が#700以上#800未満の場合はR30003をON
- DM0が#900以上#1000未満の場合はR30004をON
- DM0が#1100以上#1200未満の場合はR30005をON

使用デバイス

| デバイス | 用途(原本の記載) |
|---|---|
| CR2008 | 運転開始時1スキャンON(設定値の書き込み条件) |
| DM10〜DM21 | 比較データブロック(DM10=#100, DM11=#200, DM12=#300, DM13=#400, DM14=#500, DM15=#600, DM16=#700, DM17=#800, DM18=#900, DM19=#1000, DM20=#1100, DM21=#1200) |
| R000 | MCMP の実行条件 |
| DM0 | 比較するデータ(S2) |
| R30000〜R30005 | 比較結果の出力リレー(D) |
| #6 | 比較データ数(n) |

(原本記載デバイス 6行 → md 6行)

〈ニモニックリスト〉(原本のまま)

```
LD CR2008
MOV #100 DM10
MOV #200 DM11
MOV #300 DM12
MOV #400 DM13
MOV #500 DM14
MOV #600 DM15
MOV #700 DM16
MOV #800 DM17
MOV #900 DM18
MOV #1000 DM19
MOV #1100 DM20
MOV #1200 DM21
LD R000
MCMP DM10 DM0 R30000 #6
```

> 補足(原文にはない): 上記では下位ワード(DM10, DM12 …)にON設定値、上位ワード(DM11, DM13 …)にOFF設定値が入るため、各組は OFF設定値＞ON設定値 のケース(ON設定値≦DM0＜OFF設定値でON)になります。

(p.562 / 5-186 は「MEMO」のみの空白ページのため除外)

- ※5 Nは D2 ＋0で指定した比較データ数です。

#### 動作説明 — 比較動作

(5-11 ABSENC / 原本 p.564 / 5-188)

実行条件がONのとき S1 から始まる［ D2 ＋0］個の32ビットのデータ（16ビット符号無しBINデータ2つ:OFF設定値、ON設定値）と［ D2 ＋4］で指定したデバイスに格納された現在角度の値を比較し、結果を D1 から始まるビットデバイスに格納します。

【図】ABSENC のデータ配置と比較結果の例 (原本 p.564)
- 1組の32ビットデータのうち、bit31〜bit16 が OFF設定値(S1 +1, S1 +3, S1 +5 …)、bit15〜bit0 が ON設定値(S1, S1 +2, S1 +4 …)。[ D2 +0]個([ D2 +0]×2ワード)
- 最終組は OFF設定値 S1 +2([ D2 +0]−1)+1 / ON設定値 S1 +2([ D2 +0]−1)
- 例: D2 +4 (現在角度) = 30 のとき

| 組 | OFF設定値(デバイス / 値) | ON設定値(デバイス / 値) | 結果デバイス | 結果 |
|---|---|---|---|---|
| 1 | S1 +1 / 30 | S1 / 12 | D1 | OFF |
| 2 | S1 +3 / 40 | S1 +2 / 30 | D1 +1 | ON |
| 3 | S1 +5 / 30 | S1 +4 / 80 | D1 +2 | OFF |
| N −1 | S1 +2([ D2 +0]−2)+1 / 10 | S1 +2([ D2 +0]−2) / 30 | D1 + n −2 | ON |
| N | S1 +2([ D2 +0]−1)+1 / 30 | S1 +2([ D2 +0]−1) / 30 | D1 + n −1 | OFF |

(原本の図中の例 5行 → md 5行。結果デバイスの末尾2行は原本図の表記「D1 + n −2」「D1 + n −1」のまま)

**OFF設定値＞ON設定値の場合**
OFF設定値＞［ D2 ＋4］≧ON設定値の範囲のとき、 D1 がONします。

**OFF設定値＜ON設定値の場合**
OFF設定値＞［ D2 ＋4］または［ D2 ＋4］≧ON設定値の範囲のとき、 D1 がONします。

**OFF設定値＝ON設定値の場合**
常に、 D1 がOFFします。

#### 出力応答エラーについて（ D2 ＋5 bit0）

(5-11 ABSENC / 原本 p.565 / 5-189)

【図】出力応答エラーのタイミング (原本 p.565)
- 縦の点線が1スキャンの区切り。 D2 ＋5 bit0 は左から OFF → OFF → OFF → OFF → ON(エラー)
- 出力先①: 1スキャン目で ON(Ⓐ)、次のスキャンで OFF
- 出力先②: 出力先①がOFFするのと同じスキャンで ON(Ⓑ)、3スキャン後に OFF(Ⓒ)
- 出力先③: 出力先②のON後のスキャンで ON、出力先②と同じスキャンで OFF
- 出力先④: 出力先③と同じスキャンで ON(Ⓒ)、その後のスキャンで OFF(Ⓓ)
- 出力先⑤: 出力先④がOFFするスキャンで ON(Ⓓ)、次のスキャンで OFF(Ⓐ)。出力先④のOFFと出力先⑤のONが同時のスキャンで bit0 が ON(エラー)
- **要確認**: 図中の記号(○□△◇☆⬠)は設定値の異同を表すと見られるが、図中に凡例はない。記号と各出力のスキャン位置の正確な対応は 原本 p.565 参照

〈エラーにならない場合〉
- Ⓐ…1スキャン内で変化した出力先が1つの場合。
- Ⓑ…1スキャン内で変化した2つ以上の出力先のON設定値と、OFF設定値が同じ。
  - ・出力先①のOFF設定値＝出力先②のON設定値
- Ⓒ…1スキャン内で変化した2つ以上の出力先のON設定値どうし、OFF設定値どうしが同じ。
  - ・出力先②のOFF設定値＝出力先③のOFF設定値
  - ・出力先③のON設定値＝出力先④のON設定値

〈エラーになる場合〉
1スキャン内で変化した2つ以上の出力先のON設定値とOFF設定値が違う場合。または、ON設定値どうし、OFF設定値どうしが違う場合
- 例）Ⓓ…1スキャン内で変化した2つ以上の出力先のON設定値とOFF設定値が違う
  - 出力先④のOFF設定値≠出力先⑤のON設定値

> **ポイント**
> • 動作中に設定値を変更すると即座に出力が反映されます。出力に反映させたくない場合は実行条件をOFFしてください。
> • 実行条件にCR2002（常時ON）のコントロールリレーを使用しないでください。
> • 実行条件がOFFしても、出力は変化しません。
> • 割り込みプログラムおよび初期化モジュール内では使用できません。

## 5-12 時計機能

(5-12 / 原本 p.567 / 5-191)

CPUユニットでは、内蔵時計ICによって、「年、月、日、時、分、秒、曜日」を計時しています。
エラー・電源ON/OFF履歴、トレース機能などの時刻記録に使用します。
時計の精度は常温時（＋25℃）において、±60s/月です。

> **参考**
> • 内蔵時計は大容量キャパシタにより保持されているため、2週間以上（＋25℃）非通電状態が継続すると時計データはクリアされ、2000/1/1になります。
> • 時計データがクリアされると、CR2311がONします。時計データを書き込むとOFFします。
> • KV-B1を使用すると内蔵時計をバッテリでバックアップできます

### 時計データの読み出し

(5-12 / 原本 p.567 / 5-191)

時計データはコントロールメモリCM700～CM706に格納されています。
時計データのフォーマットは次のとおりです。

| デバイス | 内容 (bit15〜bit0) | 範囲 |
|---|---|---|
| CM700 | 年 | 0～99 |
| CM701 | 月 | 1～12 |
| CM702 | 日 | 1～31 |
| CM703 | 時 | 0～23 |
| CM704 | 分 | 0～59 |
| CM705 | 秒 | 0～59 |
| CM706 | 曜日 | 0～6 |

(原本の図 7行 → md 7行)

- 年は、西暦2000年の下2ケタを示します。
- データは、すべて16ビットBINデータ形式で記述します。
- 曜日は、0：(日)、1：(月)、2：(火)、3：(水)、4：(木)、5：(金)、6：(土) になります。

• このデータは直接ラダーで読み出すことができます。（読み出し専用です）
