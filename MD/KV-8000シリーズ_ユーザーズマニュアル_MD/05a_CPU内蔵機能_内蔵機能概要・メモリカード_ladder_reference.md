## 5-2 メモリカード

(5-2 / 原本 p.379-402 / 5-3〜5-26)

### メモリカードでできること

(5-2 / 原本 p.379-381 / 5-3〜5-5)

メモリカードを使って、ラダープログラムやコメント、および各種ユニットの設定情報をやりとりできます。また、《KV STUDIO》がなくてもメモリカードだけを使用して、CPUユニットのアクセスウィンドウやタッチパネルから、ラダープログラムの転送やデバイス値の保存、および読み出しができます。

- **メモリカードからCPUユニットへのデータ読み出し**
  アクセスウィンドウでメモリカードに保存された任意の（プロジェクト）フォルダを選択して、データを読み出せます。
  また、メモリカードに保存された「KVSAVE＊＊」（＊＊は番号：01～99）という名前の（プロジェクト）フォルダに格納しているデータを、CR5500 の OFF → ON 時に読み出せます。ドライブ番号はCM1880、フォルダ番号はCM1881で指定します。
  データはラダープログラム、デバイス、コメント、ユニット設定情報、ロギング設定情報などのプログラムデータと、DM、EM、W、FM、ZF、CM、R、MR、LR、CRなどのデバイスファイルデータがあります。
  「プロジェクトデータの保存・読み出し」（5-13ページ）
- **自動読み出し機能**
  電源投入時に、「AutoLoad」、または「AtLoad＊＊」（＊＊ : 01～99）という名前の（プロジェクト）フォルダに格納されているデータを自動的にCPUユニットに読み出します。また「RunLoad」、または「RnLoad＊＊」（＊＊ : 01～99）という名前のフォルダに保存しておくと、PRG→RUN切替時に自動的に読み出します。
  「オートローディング機能」（5-24ページ）
- **CPUユニットからメモリカードへのデータ保存**
  CPUユニットからメモリカードへ、プログラムファイル（ラダープログラム、デバイス、コメント、ユニット設定情報、ロギング設定情報）と全領域のデバイスファイル（DM、EM、W、FM、ZF、CM、R、MR、LR、B、CR）を保存できます。保存されたファイルは新規に作成された（プロジェクト）フォルダに格納されます。フォルダ名は自動的につけられ、動作正常終了時にアクセスウィンドウに表示されます。
  「プロジェクトデータの保存・読み出し」（5-13ページ）
- **レシピロード・セーブ機能**
  デバイス・変数の値をデータテーブルとして複数保存しておき、データテーブルを切り換えることでCPUユニット内のデバイス・変数の値を切り換えられます。段取り替えなどの用途に活用できます。
  「レシピロード・セーブ」（5-50ページ）

> **ポイント**
> レシピロード・セーブ機能を使用する場合はCPU機能バージョンを2.0以降にバージョンアップしてください。

- **ロギング・トレース機能**
  記録するデバイスと取り込むタイミング（トリガ）を《KV STUDIO》で登録すれば、メモリカードにデータを自動的に格納します。CSV形式で保存されますので、Microsoft Excelなどの表計算ソフトに取り込んでそのまま使用することができます。
  「5-5 ロギング・トレース」（5-57ページ）
- **運転記録機能**
  保存するデータの種類と保存するタイミング（トリガ）を設定すると、トリガ発生時にCPUのデバイス値やカメラ入力ユニットの映像データを自動的にメモリカードに保存します。保存したデータは《KV STUDIO》のリプレイ機能で再生できます。
  「5-6 運転記録機能」（5-86ページ）
- **ラダープログラムによるメモリカード制御**
  ストレージ命令を使用すると、ラダープログラムからメモリカードにアクセスできます。
  ラダープログラムでCPUユニットのデバイスのデータ値をメモリカードに保存したり、メモリカードからデバイスのデータ値を別のCPUユニットで読み込んだりできます。メモリカードの空き容量も確認できます。
  「ストレージ命令」（5-26ページ）

**● メモリカードの活用例**

(5-2 / 原本 p.380 / 5-4)

- ラダープログラムのメンテナンスが簡単。装置のメンテナンスや、仕様変更によるラダーデータの送付などにすばやく対応できます。
  - 【図】メモリカードに保存 → メモリカードから、ラダープログラムを読み込み。専用の端末を必要としません。
- デバイス値のロギングが容易。ログから集計し、資料作成が簡単になります。
  - 【図】データログの保存 → メモリカードから、ログを取得。パソコンで集計や資料作成などに。(図中表示例: 生産数 01254 / 生産集計の表)
- 異常要因の特定が容易。異常発生時のラダープログラムを1スキャンずつ確認したり、カメラで撮影したコマ送りの映像と照らし合わせて確認したりできるため、装置の異常要因の特定に活用できます。
  - 【図】異常発生 → 運転記録の保存 → メモリカードから運転記録を取得。

**■ メモリカードのデータを読み書きする方法**

(5-2 / 原本 p.382-383 / 5-6〜5-7)

メモリカードのデータを読み書きするには次の3つの方法があります。
①パソコンに直接接続して読み書きを実行する
②ストレージ転送ツールを使用してPLC経由で読み書きを実行する
③FTPサーバ機能を使用してPLC経由で読み書きを実行する

**①パソコンに直接接続して読み書きを実行する**

使用するパソコンにより、接続方法が異なります。

●USBポートを装備している場合

パソコンUSBポートに、USB用カードリーダライタを接続します。次に、メモリカードをカードリーダライタに接続します。

【図】(原本 p.382): メモリカード KV-M16G/M4G/M1G → カードリーダライタ → USBを搭載したパソコン

カードリーダライタ
USBポートを持つパソコンで、メモリカードのデータを読み書きするためのユニットです。
USBポートを持たないパソコンでは使用できません。
メモリカード用USBカードリーダの詳細については、カードリーダライタに添付の取扱説明書を参照してください。

●SDカードスロットを装備している場合

メモリカードをカードスロットに挿入します。

**②ストレージ転送ツールを使用してPLC経由で読み書きを実行する**

(5-2 / 原本 p.383 / 5-7)

KV STUDIOのメニューの【ツール（T）】→【ストレージ転送ツール】を起動します。
別手順: メニュー→KEYENCE KV STUDIO **→ストレージ転送ツール
（**は使用しているKV STUDIOのバージョンです）

メモリカード内のフォルダと、パソコン内のフォルダをバックアップまたはリストアします。
全データの一括転送にのみ対応しており、ファイルやフォルダを指定した読み書きには対応していません。

【図】ストレージ転送ツール画面 (原本 p.383):
- PLC側ストレージ種別選択(D): ◉ 0:メモリカード / ○ 1:CPUメモリ (ユーザメモリ領域)
- パソコン側フォルダ選択(P): [入力欄] ¥0_CARD [...]
- パソコン⇔PLC の転送ボタン(←/→)、通信設定(C)

詳細な内容については 『KV STUDIOユーザーズマニュアル』を参照してください。

**③FTPサーバ機能を使用してPLC経由で読み書きを実行する**

FTPサーバ機能に対応したCPUユニットやイーサネットユニットを使用すると、イーサネットケーブル経由でPLC内のメモリカードのデータを読み書きできます。
メモリカード内のデータは「0_CARD」フォルダに格納されています。

【図】エクスプローラ画面 (原本 p.383): アドレス ftp://192.168.0.10/ に「0_CARD」「1_CPUMEM」の2フォルダが表示されている。

**■ CPUユニットで使用する**

(5-2 / 原本 p.384 / 5-8)

●メモリカードを装着する

1. メモリカードスロットカバーを開きます。
2. メモリカードをメモリカードスロットに差し込みます。
   ラベル面が右側になるようにカチッという音がするまで差し込んでください。
3. メモリカードを装着した後、メモリカードスロットカバーをカチッとロックされるまで閉じます。

●メモリカードを取り出す

1. メモリカードアクセス中LEDが消えていることを確認し、メモリカードスロットカバーを開きます。
2. メモリカードを差し込む方向（奥側）にメモリカードを押します。
   カチッという音がして、メモリカードが掴める状態になったら、まっすぐにメモリカードを引き抜きます。
3. メモリカードを取り出した後、メモリカードスロットカバーをカチッとロックされるまで閉じます。

【図】メモリカード装着・取り出し図 (原本 p.384): CPUユニット前面のメモリカードスロットとメモリカードアクセス中LEDの位置を示す。

**■ 使用上の注意事項**

(5-2 / 原本 p.385 / 5-9)

メモリカードを使用する上での一般的な注意事項を以下に記します。

> **注記**
> - 次の場合、メモリカードに保存したデータが失われる恐れがあります。記録したデータが失われた場合は、弊社は一切その責任を負いかねます。あらかじめご了承ください。
>   - ユーザまたは第三者がメモリカードを誤った使用方法で使用したとき
>   - メモリカードが、静電気・電気的ノイズの影響を受けたとき
>   - メモリカードへの保存や消去などのアクセス中に、メモリカードを取り出したり、その他の機器の電源をOFFにしたとき。
> - 大切なデータは、CD/DVDなどの他のメディアに保存して、常にバックアップすることをおすすめします。
> - 本体のメモリカードアクセス中LEDが点灯中（カードへのデータの読み込み・書き込み）は、絶対にカードを抜いたり、本体の電源を切らないでください。カード内のデータが破損することがあります。

> **ポイント**
> - ノイズが厳しい環境では、メモリカードへのアクセスに時間がかかることがあります。
>   （最悪の場合は、カードの破損・FATの破損などが発生することがあります。）
>   その場合は、電源ケーブルにフェライトコアを巻いてご使用ください。
> - また、強い電磁界を発生する機器から、離して設置してください。
> - メモリカードスロットカバーが開いている状態では、メモリカードにアクセスを開始しません。必ず、メモリカードスロットカバーを閉じて使用してください。
> - メモリカードアクセス中にメモリカードスロットカバーを開いた場合、その時点で行っていた処理は最後まで実行しますが、以降はメモリカードへの処理を受け付けなくなります。
> - SDメモリカードは、出荷時にパフォーマンスが最大限に活用できるようにフォーマットされています。SDメモリカードをWindowsでフォーマットした場合、使用は可能ですがSDメモリカードへのデータ書き込み速度が低下するなどパフォーマンスを最大限に発揮できなくなることがあります。
>   万が一、出荷時の状態にリフォーマットをする必要がある場合は、最寄りの営業所までお問い合わせください。

●保存方法

CPUユニットのアクセスウィンドウ上からプロジェクトデータを保存すると、プロジェクトフォルダ「KVSAVE ＊＊」（＊＊は番号 : 01～99）を自動的に作成します。番号は、メモリカード内のフォルダ名として存在しない最小の二桁の数字になります。

●読み出し方法

「メモリカード」（5-3ページ）

> **参考**
> - 一部のデータのみ読み出す方法
>   通常は、（プロジェクト）フォルダ内のすべてのデータを一括でメモリカードから読み出します。
>   DMのデータのみ、あるいはプログラムデータのみといったように、特定のデータのみをメモリカード内のフォルダに保管しておくことで、メモリカードからCPUユニットに特定のデータのみを読み出しできます。
>   メモリカードに保存されたフォルダから、パソコンで不必要なファイルを削除します。
> - 電源投入時に「AutoLoad」（フォルダ指定の場合は「AtLoad＊＊」（＊＊ : 01～99））という名前の（プロジェクト）フォルダに格納されているプロジェクトデータを自動的に読み出します。
> - PRG→RUN時に「RunLoad」（フォルダ指定の場合は「RnLoad＊＊」（＊＊ : 01～99））という名前の（プロジェクト）フォルダに格納されているプロジェクトデータを自動的に読み出します。

**■ コントロールリレーを使用してロード/セーブする場合**

(5-2 / 原本 p.392-394 / 5-16〜5-18)

●ロード

(5-2 / 原本 p.392-393 / 5-16〜5-17)

プログラムのロードはRUNモード中は実行できません。PRGモードに切り換えて、コントロールリレーを操作してください。

【図】ロード時のタイムチャート (原本 p.392)
- 信号(上から): プロジェクトロード実行要求（CR5500） / プロジェクトロード実行完了（CR5504） / プロジェクトロード実行失敗（CR5505） / プロジェクトロードドライブ番号（要求）（CM1880） / プロジェクトロードフォルダ番号（要求）（CM1881） / プロジェクトロード実行完了コード（CM1884） / プロジェクトロードドライブ番号（完了）（CM1882） / プロジェクトロードフォルダ番号（完了）（CM1883）
- CM1880・CM1881: CR5500 のON(①)より前に値が確定する(値変化の×印が①の前)
- ①CR5500 ON → ②CR5504 ON(矢印)。このとき CM1884・CM1882・CM1883 が値変化
- ③CR5500 OFF(CR5504 のONを受けて。矢印)。CR5504 はON保持
- ④CR5500 再度ON → CR5504 がOFF
- ⑤ロード失敗: CR5504 と CR5505 が同時にON。CM1884 が値変化、CM1882・CM1883 は変化なし
- ⑥CR5500 OFF(CR5505 のONを受けて)。CR5504・CR5505 はON保持

プロジェクトロード成功時
①プロジェクトロード時ドライブ番号（要求）とプロジェクトロード時フォルダ番号（要求）にロードしたいメモリカードデータの入ったドライブ番号、フォルダ番号をセットし、プロジェクトロード実行要求リレーをONします。（モニタや、タッチパネル、通信）
②プロジェクトロードが実行完了すると、プロジェクトロード実行完了リレーが ON します。プロジェクトロードドライブ番号（完了）、プロジェクトロードフォルダ番号（完了）にはロードしたメモリカードデータを読み出したドライブ番号とフォルダ番号が格納されます。（CPUユニット）
③プロジェクトロード実行完了リレーが ON したら、プロジェクトロード実行要求リレーを OFF します。（モニタや、タッチパネル、通信など）次回プロジェクト実行要求リレーがOFF→ONすると、プロジェクトロード実行完了リレーがOFFします。（CPUユニット）

プロジェクトロード失敗時
④プロジェクトロード時ドライブ番号（要求）とプロジェクトロード時フォルダ番号（要求）にロードしたいメモリカードデータの入ったドライブ番号、フォルダ番号をセットし、プロジェクトロード実行要求リレーをONします。（モニタや、タッチパネル、通信）
⑤プロジェクトロードが失敗すると、プロジェクトロード実行完了リレーとプロジェクトロード実行失敗リレーが ON します。プロジェクトロードドライブ番号（完了）とプロジェクトロードフォルダ番号（完了）は更新されません。（CPUユニット）完了時の結果については、プロジェクトロード時完了コード（CM1884)の内容を確認してください。完了コードの内容については、「ロード・セーブ実行時のエラーコード」（5-19ページ）を参照してください。
⑥プロジェクトロード実行失敗リレーが ON したら、プロジェクトロード実行要求リレーを OFF します。（モニタや、タッチパネル、通信など）次回プロジェクト実行要求リレーがOFF→ONすると、プロジェクトロード実行完了リレー、プロジェクトロード実行失敗リレーがOFFします。（CPUユニット）

参考プログラム
プロジェクトロードは、RUNモード中は実行できないため、参考プログラムはありません。

●セーブ

(5-2 / 原本 p.393-394 / 5-17〜5-18)

プログラムのセーブを、ラダープログラムでコントロールリレーを制御しておこなう場合は、SET命令またはKEEP命令で実行してください。

【図】セーブ時のタイムチャート (原本 p.393)
- 信号(上から、原本の表記のまま): プロジェクトセーブ実行要求（CR5502） / プロジェクトセーブ実行完了（CR5506） / プロジェクトセーブ実行失敗（CR5507） / プロジェクトセーブドライブ番号（要求）（CM1888） / プロジェクトセーブフォルダ番号（要求）（CM1889） / プロジェクトセーブ実行完了コード（CM1892） / プロジェクトセーブドライブ番号（完了）（CM1890） / プロジェクトロードフォルダ番号（完了）（CM1891）
- CM1888・CM1889: CR5502 のON(①)より前に値が確定する
- ①CR5502 ON → ②CR5506 ON(矢印)。このとき CM1892・CM1890・CM1891 が値変化
- ③CR5502 OFF(CR5506 のONを受けて)。CR5506 はON保持
- ④CR5502 再度ON → CR5506 がOFF
- ⑤セーブ失敗: 図では CR5506 と CR5507 が同時にON。CM1892 が値変化、CM1890・CM1891 は変化なし
- ⑥CR5502 OFF(CR5507 のONを受けて)。CR5506・CR5507 はON保持
- **要確認**: ⑤の説明文は「プロジェクトセーブ実行失敗リレーがONします」のみで実行完了リレー(CR5506)に触れていないが、図では CR5506 も⑤でONしている。原本 p.393-394 参照。

プロジェクトセーブ成功時
①プロジェクトセーブ時ドライブ番号（要求）にセーブ先のドライブ番号を格納し、プロジェクトセーブ実行要求リレーをONします。指定したフォルダに格納したい場合にはプロジェクトセーブ時フォルダ番号（要求）にフォルダ番号を格納しておきます。（ラダーやモニタ、タッチパネル、通信など）
②プロジェクトセーブが実行完了すると、プロジェクトセーブ実行完了リレーが ON します。プロジェクトセーブ時ドライブ番号（完了）にはセーブ先のドライブ番号が、プロジェクトセーブ時フォルダ番号（完了）にはセーブ先のフォルダ番号が格納されます。（CPUユニット）
③プロジェクトセーブ実行完了リレーが ON したら、プロジェクトセーブ実行要求リレーを OFF します。（ラダーやモニタ、タッチパネル、通信など）次回プロジェクト実行要求リレーがOFF→ONすると、プロジェクトセーブ実行完了リレーがOFFします。（CPUユニット）

プロジェクトセーブ失敗時
④プロジェクトセーブ時ドライブ番号（要求）にセーブ先のドライブ番号を格納し、プロジェクトセーブ実行要求リレーをONします。（ラダーやモニタ、タッチパネル、通信など）
⑤プロジェクトセーブが失敗すると、プロジェクトセーブ実行失敗リレーがONします。（CPUユニット）
⑥プロジェクトセーブ実行失敗リレーが ON したら、プロジェクトセーブ実行要求リレーを OFF します。（ラダーやモニタ、タッチパネル、通信など）次回プロジェクト実行要求リレーがOFF→ONすると、プロジェクトセーブ実行完了リレー、プロジェクトセーブ実行失敗リレーがOFFします。（CPUユニット）

(5-2 / 原本 p.399 / 5-23)

1. メモリカードをパソコンに接続します。
   「メモリカードのデータを読み書きする方法」（5-6ページ）
2. KV STUDIOのメニューから【モニタ/シミュレータ（N）】→【デバイス値一括変更/読出（D）】を選択します。

【図】デバイス値一括変更/読出ウィンドウ (原本 p.399): メニュー ファイル(F) / 編集(E) / PLC(P) / デバイス追加(D)。列: プログラム / デバイス / 現在値 / 表示形式 / コメント。表示例: グローバル DM0〜DM5 (現在値 0、10進数16BIT)、MR000〜MR002 (－、2進数1BIT)。

3. デバイス値一括変更/読出ウィンドウのメニューから、【ファイル（F）】→【メモリカード読出（R）】または【メモリカード保存（Z）】を選択します。
   読出 : 読み出すドライブとフォルダ名を指定します。
   保存 : 登録されているデバイスと現在値が保存されます。

> **参考**
> KV STUDIOのデバイス初期値設定を使用すれば、同様にデバイス値をメモリカードで管理できます。

### オートローディング機能

(5-2 / 原本 p.400-401 / 5-24〜5-25)

電源投入時やPRG→RUN時にメモリカードに保存されているプロジェクトデータを自動的に読み出します。
コントロールメモリ（CM）を使用して、複数のフォルダから読み出すフォルダを選択することができます。

**■ 電源投入時に読み出す**

(5-2 / 原本 p.400 / 5-24)

1. 《KV STUDIO》を使用して、「AutoLoad」、または「AtLoad＊＊」（＊＊ : 01～99）のフォルダ名称でメモリカードにプロジェクトデータを書き込みます。
   「ラダープログラムなど（デバイスファイル以外）」（5-22ページ）
2. CPUユニットのメモリカードスロットにメモリカードを挿入し、メモリカードスロットカバーをカチッとロックされるまで閉じます。
3. CPUユニットの電源を投入します。
   自動的にデータが読み出されます。

●読み出すフォルダの指定方法

読み出すフォルダを指定する場合は、あらかじめCM1790に数値を格納します。

- CM1790の値が0の場合
  フォルダ名「AutoLoad」が読み出されます。
  「AutoLoad」フォルダがメモリカードに存在しない場合は、オートロードされません。電源投入前のプログラムで動作します。エラーは発生しません。
- CM1790の値が01～99の場合
  フォルダ名「AtLoad＊＊」（＊＊ : CM1790の値（01～99））が読み出されます。

フォルダ番号の指定手順
1. 電源投入している状態で、タッチパネルなどの外部機器からCM1790に数値を格納します。
2. 電源を切ります。
3. 電源を投入します。
4. CM1790で指定したフォルダが読み出されます。
5. 読み出し完了後、CM1790に0が格納され、CM1792に読み出したフォルダ番号が格納されます。

> **参考**
> オートロード完了後、CM1790に0が格納されるので、次回電源投入時、同じフォルダ番号は読み出されません。ただし、CM1790に0が格納されている状態でメモリカードに「AutoLoad」フォルダがあると、次回電源投入時に読み出されるので注意してください。
> オートロード実行時の状態はオートロード完了コード（CM1791）で確認できます。完了コードの内容については、「ロード・セーブ実行時のエラーコード」（5-19ページ）を参照してください。

> **ポイント**
> - 《KV STUDIO》のCPUシステム設定でライトプロテクト/プロジェクトロード禁止されている場合はエラー（オートローディング失敗）が発生し、PRGモードになります。エラークリア後、RUNモードで動作するとオートロード実行前のプログラムで動作 します。
>   以下の場合はエラー（オートローディング失敗）が発生し、PRGモードになります。
>   - CM1790の値が100以上の場合
>   - CM1790で指定したフォルダがメモリカードにない場合
> - PLC本体に格納されているプロジェクトの機能バージョンと転送するプロジェクトの機能バージョンが異なる場合、CPUのオールクリア/初期化が必要になります。

**■ PRG→RUN時に読み出す**

(5-2 / 原本 p.401 / 5-25)

1. 《KV STUDIO》を使用して、「RunLoad」、または「RnLoad＊＊」（＊＊ : 01～99）のフォルダ名称でメモリカードにプロジェクトデータを書き込みます。
   「ラダープログラムなど（デバイスファイル以外）」（5-22ページ）
2. CPUユニットのメモリカードスロットにメモリカードを挿入し、メモリカードスロットカバーをカチッとロックされるまで閉じます。
3. CPUユニットをPRG→RUNに切り換えます。
   自動的にデータが読み出され、運転を開始します。

●読み出すフォルダの指定方法

読み出すフォルダを指定する場合は、あらかじめCM1794に数値を格納します。

- CM1794の値が0の場合
  フォルダ名「RunLoad」が読み出されます。
  「RunLoad」フォルダがメモリカードに存在しない場合は、オートロードされません。PRG→RUN前のプログラムで動作します。エラーは発生しません。
- CM1794の値が01～99の場合
  フォルダ名「RnLoad＊＊」（＊＊はCM1794の値01～99）が読み出されます。

フォルダ番号の指定手順
1. タッチパネルなどの外部機器からCM1794に数値を格納します。
2. PRG→RUNに切り換えます。
3. CM1794で指定したフォルダが読み出されます。
4. 読み出し完了後、CM1794に0が格納され、CM1796に読み出したフォルダ番号が格納されます。

> **参考**
> オートロード完了後、CM1794に0が格納されるので、次回電源投入時、同じフォルダ番号は読み出されません。ただし、CM1794に0が格納されている状態でメモリカードに「RunLoad」フォルダがあると次回PRG→RUNすると読み出されるので注意してください。
> ランロード実行時の状態はランロード完了コード（CM1795）で確認できます。完了コードの内容については、「ロード・セーブ実行時のエラーコード」（5-19ページ）を参照してください。

> **ポイント**
> - 《KV STUDIO》のCPUシステム設定でライトプロテクト/プロジェクトロード禁止されている場合はエラー（オートローディング失敗）になりRUNモードにできません。エラークリア後、メモリカードを抜いてRUNモードで動作するとオートロード実行前のプログラムで動作します。
>   以下の場合はエラー（オートローディング失敗）になりRUNモードにできません。エラークリア後、メモリカードを抜いてRUNモードで動作するとオートロード実行前のプログラムで動作します。
>   - CM1794の値が100以上の場合
>   - CM1794で指定したフォルダがメモリカードにない場合
> - PLC本体に格納されているプロジェクトの機能バージョンと転送するプロジェクトの機能バージョンが異なる場合、CPUのオールクリア/初期化が必要になります。

### ストレージ命令

(5-2 / 原本 p.402 / 5-26)

ストレージ命令を使用すると、ラダープログラムでデバイスのデータを読み書きできます。

【図】ストレージ命令の概要 (原本 p.402): KV-8000(A) → メモリカード に MMKDIR命令 / MRKDIR/MDEL命令 / MWRIT命令(実線矢印)、メモリカード → KV-8000(A) に MREAD命令(実線矢印) と MFREE命令(破線矢印)。メモリカード ⇔ パソコン(Microsoft Excelなど) で 読み出し / 書き込み。図中の吹き出し文言:
- MMKDIR命令を実行するとメモリカードにフォルダが作成されます。例：“¥ABC”フォルダを作成します。
- MRKDIR/MDEL命令を実行すると、指定したフォルダやファイルが削除されます。
- MWRIT命令を実行すると指定した連続するデバイスのデータ値がメモリカードに保存されます。例：DM000～DM009のデータ値をメモリカードにCSV形式で保存
- MREAD命令を実行すると、保存されているデータ値をメモリカードから読み出して、指定した連続するデバイスに書き込みます。例：CSV形式で保存されているDM0～DM9用のデータ値をメモリカードから読み出して、PLCに書き込む
- MFREE命令を実行するとメモリカードの空き容量を調べて、結果を指定したデバイスにバイト単位で書き込みます。
- 例：メモリカード内のフォルダ｢ABC｣のファイル｢XYZ｣にCSV形式でDM0～DM9のデータ値を保存している場合
  ```
  ¥ABC¥XYZ.CSV
  12345, -123,0,678,9876,12, -45,67890,345,876
   ↑                                        ↑
  DM0用 ・・・・・・・・・・・・・・・・・・ DM9用
  ```

> **参考**
> - ストレージ命令はメモリカードのほかにCPUメモリに対しても読み書きできます。
> - ストレージ命令のエラーコードは CM2390 に格納されます。CM2390 の内容については、「KV-8000/7000/5000/3000/1000/KV Nanoシリーズ命令語リファレンスマニュアル」を参照してください。

> 補足(原文にはない): 本マニュアル p.402 はストレージ命令の概要のみで、各命令の書式・オペランド・エラーコードは原本に記載がない(命令語リファレンスマニュアル参照)。そのため命令ページのチェックリスト(書式・オペランド表等)は本範囲では該当なし。
