## 6-6 PWM出力機能

(6-6 / 原本 p.587 / 6-19)

≪KV-SIR32XT≫の出力端子を使用して最大100kHz、0.1µs単位でパルス幅を指定してPWM出力する機能です。
PWM出力の周期と、ON時間を設定してパルス幅を調整して出力します。

【図】PWM出力波形 (原本 p.587)
- 縦軸 ON / OFF。パルスの立上りから立下りまでが「ON時間」
- 立上りから次の立上りまでが「PWM出力周期」

> **ポイント**
> - PWMは最大で8点まで同時に使用でき、個別に設定できます。各設定の中で出力する端子・周期・パルス数などを設定して使用します。
> - 1台のKV-8000シリーズに最大16台のKV-SIR32XTを接続可能なので、最大128点のPWM出力機能を使用できます。

### ■ 動作モード

(6-6 / 原本 p.587 / 6-19)

**● パルス数指定モード**

PWM制御して出力するパルス数を指定してパルス出力できます。

**● 連続パルス出力モード**

停止処理が実行されるまで連続してパルスを出力し続けます。

### ■ 使用方法

(6-6 / 原本 p.587 / 6-19)

設定はすべてラダープログラムでおこないます。

【図】使用方法のフロー (原本 p.587)
- PWM 設定 → 出力開始 → パルス出力中
- 「PWM 設定変更」から「パルス出力中」へ矢印(出力中に設定変更可能)

> **参考**
> パルス出力中に設定を変更すると1×PWM周期以内に出力する波形を変更できます。

### ● デバイス

(6-6 / 原本 p.589 / 6-21)

- **PWMn（n：0～7）出力許可**
  PWM出力を実行するかどうかを選択します。
  0 : 出力しない
  1 : PWM出力実行
  0ビット目をONするとPWM出力を開始します。その他のビットは使用しません。
- **PWMn（n：0～7）出力端子**
  PWM出力を実行する出力端子を選択します。
  0～31：OUT200～OUT315
- **PWMn（n：0～7）周期**
  PWM出力の周期を0.1µs～429496729.5µsの範囲で設定します。
  実際の回路の遅延時間を考慮して10.0μs以上の値に設定することを推奨します。
  出力中に変更した場合、PWM出力の周期が完了したタイミングで反映されます。
- **PWMn（n：0～7）ON時間**
  PWM出力のON時間を0.0µs～429496729.5µsの範囲で設定します。
  ON時間に0.0µsを設定した場合常時OFFとなります。
  出力中に変更した場合、PWM出力の周期が完了したタイミングで反映されます。
- **PWMn（n：0～7）出力パルス数**
  PWM出力の出力パルス数を1～4294967295パルスの範囲で設定します。
  0に設定した場合、出力許可がOFFになるまで継続してパルスを出力します。
  出力許可に1が書き込まれたタイミングの設定値が動作に反映されます。出力許可中は書き換えは可能ですが、反映はされません。
- **PWMn（n:0～7）出力状態モニタ**
  PWM出力状態を表示します。PWM出力許可に0を格納すると、ビット0～2はOFFします。
  ビット0 : ON : 出力許可状態、OFF : 出力禁止状態
  ビット1 : ON : 出力完了状態、OFF : 出力未完了状態
  ビット2 : ON : ほかの出力機能が実行中のため、出力できませんでした。
  OFF：ほかの出力機能は実行されていません。
- **PWMn（n:0～7）出力端子モニタ**
  PWMn（n：0～7）で設定している出力端子0～31：OUT200～OUT315を表示します。
- **PWMn（n:0～7）出力パルス数モニタ**
  PWMn（n：0～7）で出力したパルス数を表示します。
  PWM出力許可に0を格納するとゼロクリアされます。
- **機能モニタn（n:200～315）**
  出力に使用している機能を表示します。
  ビット0 : ON : 汎用出力中（出力に割り付けられたリレーがON）
  ビット1 : ON : PWM出力中
- **出力モニタ**
  各端子の出力状態をモニタできます。

### ■ 参考プログラム

(6-6 / 原本 p.590 / 6-22)

OUT200でPWM出力する場合のプログラム例です。
周期100.0μs（10kHz）、ON時間が70.0μsのパルスを10000パルス出力します。

使用デバイス(ラダー図のコメントより)

| デバイス | コメント(原本) |
|---|---|
| CR2008 | 運転開始時1スキャンON |
| CR2002 | 常時ON |
| MR000 | PWM設定書き込み |
| MR001 | PWM実行 |
| DM1 | PWM出力端子 |
| DM2 | PWM周期 |
| DM4 | PWM ON時間 |
| DM6 | PWM出力パルス数 |
| DM10 | PWM出力状態モニタ |
| DM10.1 | 出力完了 |
| #1 (UWRIT/UREADの第1オペランド) | KV-SIR32XT |
| #257 | PWM出力端子 |
| #256 | PWM0 出力許可 |
| #320 | PWM出力状態モニタ |

(原本の使用デバイス 14件 → md 14行)

回路ごとの説明(原本ラダー図右側の文言):
- CR2008 回路(MOV / MOV.D ×3): 設定値を格納します。
- MR000 回路(UWRIT #1 #257 DM1 #7): 設定値を書き込みます。
- MR001 回路(UWRIT #1 #256 #1 #1): PWM出力を実行します。
- CR2002 回路の DM10.1 分岐(UWRIT #1 #256 #0 #1): PWM出力が完了したのを確認してPWM出力を停止します。

原本 <ニモニックリスト>:

```
LD CR2008
MOV #0 DM1
MOV.D #1000 DM2
MOV.D #700 DM4
MOV.D #10000 DM6
LDP MR000
UWRIT #1 #257 DM1 #7
LDP MR001
UWRIT #1 #256 #1 #1
LD CR2002
MPS
UREAD #1 #320 DM10 #1
MPP
AND DM10.1
UWRIT #1 #256 #0 #1
```

> 補足(原文にはない): MR000 / MR001 は原本ラダー図では立上り接点、DM10.1 はa接点。UWRIT の #7 は DM1〜DM7(出力端子・周期・ON時間・出力パルス数)の7ワードを #257〜#263 へ書き込む点数と読める。

### U_RDBF / @U_RDBF バッファリングデータ読み出し

(6-7 / 原本 p.592-593 / 6-24〜6-25)

命令見出し: U_RDBF(U) / @U_RDBF(U) — バッファリングデータ読み出し — バッファリングした入力データをバッファメモリから読み出します。

**書式(ラダープログラム)**
- `実行条件 ─[U_RDBF n1 n2 D n3]`
- `実行条件 ─[@U_RDBF n1 n2 D n3]`(実行条件の立ち上がりで実行)

**入力方法(キー入力)**
- `U _ R D B F ␣ n1 ␣ n2 ␣ D ␣ n3 ↵`
- `@ U _ R D B F ␣ n1 ␣ n2 ␣ D ␣ n3 ↵`

**オペランド**

| オペランド | 説明 | 占有サイズ |
|---|---|---|
| n1 | ユニット番号を指定します。※1 | ― |
| n2 | チャンネル番号、またはそれの格納先を指定します。※2 | 16ビット |
| D | 読み出した値の格納先の先頭を指定します。 | n3 ビット |
| n3 | 読み出すデータ数（0～8192）を指定します。※2 | 16ビット |

(原本の表 4行 → md 4行)

- ※1 定数、および定数に設定した変数のみ指定可能です。
- ※2 ビットデータを指定した場合、連続する16ビットを占有します。ワードデータを指定した場合は1ワードを占有します。

> 補足(原文にはない): 本マニュアルのこの命令ページには、使用可能デバイス表・コントロールデータ表・完了デバイスは記載されていない。

**動作説明**

- **U_RDBF**: 実行条件がONの時、n1 で指定したユニット番号の n2 で指定したチャンネルのバッファリングデータを n3 ワード読み出して、D を先頭に格納します。

> **ポイント**
> バッファリングの識別番号選択で0以外の値を設定した場合は、1つのデータサイズが2ワードになるため、読み出す点数は、2倍した値を入力してください。

- **@U_RDBF**: 実行条件の立ち上がりで、1スキャンだけ実行します。

**演算フラグ**

| フラグ | 動作 |
|---|---|
| CR2009 | 変化なし |
| CR2010 | 変化なし |
| CR2011 | 変化なし |
