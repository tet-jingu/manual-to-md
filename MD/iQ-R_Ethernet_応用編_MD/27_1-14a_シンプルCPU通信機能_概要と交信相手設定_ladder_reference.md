## 1.14 シンプルCPU通信機能(RJ71EN71，RnENCPU(ネットワーク部)) (1.14 / 原本 p.181)

RJ71EN71およびRnENCPU(ネットワーク部)にエンジニアリングツールから簡単な設定を行うだけで，指定のデバイスを指定のタイミングで送受信できる機能です。送受信は指定した交信相手と1: 1で行います。

シーケンサと，デバイスのデータを送受信したい場合に使用してください。

| 交信相手 | 種別 | 詳細 |
|---|---|---|
| MELSEC iQ-Rシリーズ | CPUユニット，Ethernetユニット | 184ページ 機器種別 |
| MELSEC-Qシリーズ | CPUユニット，Ethernetユニット | 同上 |
| MELSEC-Lシリーズ | CPUユニット，Ethernetユニット | 同上 |
| MELSEC iQ-Fシリーズ | CPUユニット | 同上 |
| MELSEC iQ-Lシリーズ | CPUユニット | 同上 |
| MELSEC-A/AnSシリーズ | Ethernetユニット | 同上 |
| MELSEC-Fシリーズ | Ethernetブロック・アダプタ | 同上 |
| 他社シーケンサ製品 | — | 同上 |
| SLMP対応機器 | QnA互換3Eフレーム | 同上 |
| MODBUS/TCPスレーブ機器 | — | 同上 |

【図】シンプルCPU通信機能の対応交信相手(原本 p.181)。RJ71EN71を中心にEthernetで、MELSEC iQ-R/iQ-F/L/F/Q/iQ-Lの各シリーズ、SLMP対応機器、MODBUS/TCP対応機器が接続される構成。

> Point
> ルータを経由したアクセスも可能です。設定する場合は，サブネットマスクとデフォルトゲートウェイも設定してください。(309ページ 自ノード設定)
>
> シンプルCPU通信機能を使用するときは，エンジニアリングツールおよびユニットのバージョンを確認してください。(218ページ バージョンによる制約)

## 設定方法 (原本 p.183)

本機能を使用するための設定について説明します。

1. "応用設定"の"シンプルCPU通信設定"にある"シンプルCPU通信使用有無"を"使用する"に設定します。
   操作: [ナビゲーションウィンドウ][パラメータ][ユニット情報][RJ71EN71][ポート1 ユニットパラメータ(Ethernet)][応用設定][シンプルCPU通信設定]
2. "シンプルCPU通信設定"の"<詳細設定>"をダブルクリックすると，設定画面が表示されます。(325ページ シンプルCPU通信設定(RJ71EN71，RnENCPU(ネットワーク部)))
3. 設定後，自局のCPUユニットにユニットパラメータを書き込み，CPUユニットのリセットまたは電源OFF→ONすると，シンプルCPU通信が開始されます。

交信設定を要求時にした場合は，下記を参照してください。(204ページ 交信設定を要求時にした場合の動作)

### 通信パターン

下記の項目から通信パターンを選択します。

| 設定項目 | 内容 |
|---|---|
| 読出 | 指定した交信相手(転送元)のデバイスデータを自局(転送先)の指定したデバイスに読み出します。 |
| 書込 | 自局(転送元)の指定したデバイスデータを指定した交信相手(転送先)のデバイスに書き込みます。 |

### 交信設定: 実行間隔

下記の項目から交信方法を選択します。

 - 実際の実行間隔は，交信相手やEthernet回線の負荷などに影響を受けるため，設定した実行間隔より長くなることがあります。対策については，下記を参照してください。(427ページ シンプルCPU通信機能使用時)
 - 通信開始待ち時間設定時は，通信開始待ち時間経過後からデータ送受信が実行されます。(206ページ 通信開始待ち時間)

| 設定項目 | 内容 | 設定範囲 |
|---|---|---|
| 定期 | デバイスデータの送受信を指定した実行間隔で実施します。 | — |
| 実行間隔 | 実行間隔を設定します。 | 1ms~65535ms(1ms単位) |
| 要求時 | デバイスデータの送受信を要求時のみ実施します。 | — |

## 交信相手(IPアドレス) (原本 p.184)

"転送先"をクリックして"交信相手設定"画面を開き，交信相手を設定および登録します。交信相手の登録数は，最大64です。

エンジニアリングツールでの設定可能数は最大512ですが，交信相手の登録数は，最大64です。

下記の項目が1つでも異なると，別の交信相手としてカウントされます。

 - 機器種別
 - IPアドレス
 - UDP/TCP
 - ポート番号
 - 自局ポート番号

ただし，下記の機器は，同じ機器種別としてカウントされます。

 - SIEMENS S7シリーズとSIEMENS S7シリーズ(拡張)
 - オムロン(CS/CJシリーズ)とオムロン(NJ/NXシリーズ)

### IPアドレス，UDP/TCP，ポート番号 (原本 p.185)

交信相手のIPアドレス，交信に使用するプロトコル，ポート番号，および自局ポート番号を設定します。

 - マルチCPUシステム構成時は，Ethernetケーブルを接続している号機のIPアドレスを指定してください。
 - 自局ポート番号の1~1023は一般的に予約されたポート番号(WELL KNOWN PORT NUMBERS)，61440~65534は他の通信機能で使用するため，1024~4999，5010~61439を使用することを推奨します。
 - 交信相手が三菱A/AnSおよび三菱FX3を除く三菱電機シーケンサの場合，自局ポート番号は61696~65534を動的に使用するため，本機能を使用する場合は，OPEN命令およびGP.CONOPEN命令において自局ポート番号に61696~65534を指定しないようにしてください。指定した場合は命令が異常完了する場合があります。
 - 複数の設定で同じ交信相手を指定する場合，自局ポート番号に異なる値を設定することを推奨します。ただし，相手機器側の接続数が上限を超えている場合，自局ポート番号に同じ値を設定して，接続数を削減してください。

### オプション(16進数) (原本 p.186)

交信相手のオプション設定値を指定します。

*1 使用する場合は，エンジニアリングツールおよびユニットのバージョンを確認してください。(218ページ バージョンによる制約)

> 注意事項
> ゲートウェイ機器を介してMODBUS RTU/ASC対応機器と交信する際，00H(ブロードキャスト)を設定した場合の注意事項を示します。
> - スレーブ機器は応答を返さないため，タイムアウトエラー : CFB0Hが発生します。読出は指定しないでください。
> - 1つの設定でビットデバイス，ワードデバイスの両方を指定しないでください。いずれか一方のみ指定してください。
> - 複数設定する場合，自局ポート番号はすべて異なった値にしてください。
>
> また通信タイムアウト時間，通信リトライ，および異常監視時間は下記のとおり設定してください。この設定により，2回目の交信を通信タイムアウト時間後に実施し，3回目以降の交信は通信タイムアウト時間2の周期で実施します。
> - 通信リトライ回数=0
> - 通信タイムアウト時間=異常監視時間

## 対象号機 (原本 p.188)

交信相手が下記で，マルチCPUシステム構成時は，交信相手の"対象号機"を指定します。

| 交信相手 | 対象号機 |
|---|---|
| 三菱iQ-R(内蔵Ethernet): RnCPU，RnENCPU，RnPCPU，RnSFCPU | 1~4号機 |
| 三菱Q(内蔵Ethernet): QnUDE(H)CPU，QnUDVCPU，QnUDPVCPU(QCPUユーザーズマニュアル(マルチCPUシステム編)) | 1~4号機 |
| 三菱iQ-R(Ethernetユニット): RJ71EN71，RnENCPU | 1~4号機 |
| 三菱Q(Ethernet): QJ71E71-100，QJ71E71(QCPUユーザーズマニュアル(マルチCPUシステム編)) | 1~4号機 |
| 横河FA-M3シリーズ*1 | 1~4号機 |
| 富士電機MICREX-SXシリーズ | 1~8号機 |

*1 交信相手が横河FA-M3シリーズで，"対象号機"が"指定なし"の場合，自動的に1号機が対象となります。(RJ71EN71およびRnENCPU(ネットワーク部)のファームウェアバージョンが"42"以降のとき)
