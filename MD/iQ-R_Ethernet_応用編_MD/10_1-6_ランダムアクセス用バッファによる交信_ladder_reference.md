## 1.6 ランダムアクセス用バッファによる交信 (1.6 / 原本 p.93)

ランダムアクセス用バッファによる交信では，相手機器を固定することなく，任意の相手機器(Ethernet搭載ユニットは除く)からRJ71EN71またはRnENCPU(ネットワーク部)に対して，自由に読出しおよび書込みができます。Ethernetに接続されている相手機器共通のバッファエリアとしてランダムアクセス用バッファを使用します。

### 注意事項 (原本 p.93)

CPUユニット(RnENCPUの場合はCPU部)では，ランダムアクセス用バッファによる交信はできません。

### 設定方法 (原本 p.93)

"基本設定"の"相手機器接続構成設定"で設定します。(311ページ 相手機器接続構成設定)

1. "ユニット一覧"にある下記から相手機器を選択し，"機器一覧"または"機器構成図"にドラッグ＆ドロップします。
2. 相手機器との"交信手段"を"ランダムアクセスバッファ "に設定します。
3. 相手機器IPアドレスを設定します。
4. その他，通信に必要なパラメータをコネクションに設定します。(311ページ 相手機器接続構成設定)

| 相手機器名 | 内容 |
|---|---|
| UDP接続機器 | UDP/IPで相手機器と交信する場合に選択します。 |
| Active接続機器 | Ethernet搭載ユニットから相手機器に対してオープン処理を行い(Activeオープン)，TCP/IPで交信する場合に選択します。 |
| Unpassive接続機器 | 不特定の相手機器からのオープン処理を受けて(Unpassiveオープン)，TCP/IPで交信する場合に選択します。 |
| Fullpassive接続機器 | 特定の相手機器からのオープン処理を受けて(Fullpassiveオープン)，TCP/IPで交信する場合に選択します。 |

【図】ランダムアクセス用バッファと複数相手機器の関係(原本 p.93)。RJ71EN71またはRnENCPU(ネットワーク部)が1つのランダムアクセス用バッファを持ち、複数の相手機器それぞれが個別に「書込み」「読出し」を行える構成。

## 通信のしくみ (原本 p.94)

ランダムアクセス用バッファによる交信の通信のしくみについて説明します。

### データの流れ (原本 p.94)

ランダムアクセス用バッファによる交信のデータの流れを示します。

RJ71EN71またはRnENCPU(ネットワーク部)と相手機器との交信処理には専用のパケットを使用します。

CPUユニットからランダムアクセス用バッファへのアクセスは，プログラムで行います。

プログラムとは非同期で行われるため，同期が必要な場合は，ソケット通信による交信または固定バッファによる交信を使用してください。

### データ交信可能な相手機器 (原本 p.94)

下記の相手機器と交信できます。

 - RJ71EN71が接続されているEthernet内の機器
 - RnENCPU(ネットワーク部)が接続されているEthernet内の機器
 - ルータ経由で接続されている機器

## 相手機器からの読出し手順 (原本 p.94)

相手機器からの読出し要求により，RJ71EN71またはRnENCPU(ネットワーク部)からデータを送信する場合の処理手順を示します。

1. ユニットパラメータ設定後，RJ71EN71またはRnENCPU(ネットワーク部)のイニシャル処理の正常完了を確認します。('イニシャル状態'(Un\G1900024.0): ON)
2. オープン処理を行い，RJ71EN71またはRnENCPU(ネットワーク部)と相手機器のコネクションを確立します。(513ページ TCP/IP通信，UDP/IP通信)
3. プログラムでRJ71EN71またはRnENCPU(ネットワーク部)のランダムアクセス用バッファにデータを書き込みます。
4. 上記の処理とは非同期で，相手機器からRJ71EN71またはRnENCPU(ネットワーク部)に対して読出し要求を送信します。(RJ71EN71またはRnENCPU(ネットワーク部)側: コマンドの受信)
5. 相手機器からの読出し要求を受信すると，RJ71EN71またはRnENCPU(ネットワーク部)は要求してきた相手機器に対してランダムアクセス用バッファに書き込まれているデータを送信します。(RJ71EN71またはRnENCPU(ネットワーク部)側: レスポンスの送信)
6. 通信が終了したら，コネクションをクローズします。

【図】相手機器からの読出し手順の構成図(原本 p.94)。CPUユニット(TO命令での書込み)→ランダムアクセス用バッファ(RJ71EN71またはRnENCPU(ネットワーク部)内)→相手機器の順で、手順3(TO命令書込み)・手順4(読出し要求(コマンド)受信)・手順5(レスポンス・読出しデータ送信、ACKはTCPのみ)が流れる。

## 相手機器からの書込み手順 (原本 p.95)

相手機器がRJ71EN71またはRnENCPU(ネットワーク部)のランダムアクセス用バッファに対してデータを書き込む場合の処理手順を示します。

1. ユニットパラメータ設定後，RJ71EN71またはRnENCPU(ネットワーク部)のイニシャル処理の正常完了を確認します。('イニシャル状態'(Un\G1900024.0): ON)
2. オープン処理を行い，RJ71EN71またはRnENCPU(ネットワーク部)と相手機器のコネクションを確立します。(513ページ TCP/IP通信，UDP/IP通信)
3. RJ71EN71またはRnENCPU(ネットワーク部)のランダムアクセス用バッファに対して，相手機器からデータを書き込みます。(RJ71EN71またはRnENCPU(ネットワーク部)側: コマンドの受信)
4. RJ71EN71またはRnENCPU(ネットワーク部)は相手機器から要求された書込み処理を行い，書込み要求を送信してきた相手機器に対して書込み結果を返信します。(RJ71EN71またはRnENCPU(ネットワーク部)側: レスポンスの送信)
5. 上記の処理とは非同期でプログラムにより，ランダムアクセス用バッファに書き込まれたデータを読み出します。
6. 通信が終了したら，コネクションをクローズします。

## ランダムアクセス用バッファの物理アドレスおよび論理アドレス (原本 p.96)

コマンド中で指定するRJ71EN71またはRnENCPU(ネットワーク部)のランダムアクセス用バッファの先頭アドレスについて説明します。

ランダムアクセス用バッファの指定アドレスは，相手機器による指定アドレスとFROM/TO命令による指定アドレスが異なるので注意してください。

 - 物理アドレス: プログラムのFROM/TO命令で指定するアドレス
 - 論理アドレス: 相手機器がコマンド中の先頭アドレス項目に指定するアドレス

【図】物理アドレスと論理アドレスの対応(原本 p.96)。バッファメモリ上のランダムアクセス用バッファ範囲で、物理アドレス20000〜26143が論理アドレス0〜6143に対応する。

## 注意事項 (原本 p.96)

ランダムアクセス用バッファによる交信時の注意事項を示します。

### プログラム作成上の注意事項

#### イニシャル処理およびオープン処理の完了

イニシャル処理およびコネクションのオープン処理が完了していることが必要です。

#### CPUユニットからの送信要求

CPUユニットから送信要求できません。また，CPUユニットへの受信完了確認が行われません。CPUユニットと相手機器間で，データ送信/受信の同期をとる必要がある場合は，固定バッファ交信で行ってください。

#### ランダムアクセス用バッファのアドレス

相手機器が指定するアドレスと，FROM/TO命令で指定するアドレスが異なります。詳細については，下記を参照してください。(96ページ ランダムアクセス用バッファの物理アドレスおよび論理アドレス)

## データフォーマット (原本 p.96)

通信データは，ヘッダとアプリケーションデータで構成されます。

### ヘッダ (原本 p.96)

ヘッダは，TCP/IP，UDP/IP用ヘッダです。RJ71EN71またはRnENCPU(ネットワーク部)が自動で付加および削除するため，設定する必要はありません。

ヘッダ部の内訳:

 - TCP/IP: イーサネット(14バイト)＋IP(20バイト)＋TCP(20バイト)
 - UDP/IP: イーサネット(14バイト)＋IP(20バイト)＋UDP(8バイト)

### アプリケーションデータ (原本 p.97)

アプリケーションデータは，下記のデータコードをバイナリコード/ASCIIコードで表します。バイナリコード/ASCIIコードの切換えは，"基本設定"の"自ノード設定"で設定します。(309ページ 自ノード設定)

#### ■フォーマット

##### バイナリコードでの交信時

【図】バイナリコード交信のアプリケーションデータ構成(原本 p.97)

コマンド伝文(交信要求元側): サブヘッダ(2バイト、`□H 00H`) → 先頭アドレス(2バイト、L→H) → データ長設定(2バイト、L→H) → テキスト(コマンド、最大1017ワード。読出し要求時はなし)

レスポンス(交信要求先側): サブヘッダ(1バイト) → 終了コード(1バイト) → テキスト(レスポンス、最大1017ワード。書込み要求時はなし)

##### ASCIIコードでの交信時

【図】ASCIIコード交信のアプリケーションデータ構成(原本 p.97)

コマンド伝文(交信要求元側): サブヘッダ(4バイト、H,L,30H,30H) → 先頭アドレス(4バイト、H→L) → データ長設定(4バイト、H→L) → テキスト(コマンド、最大1016ワード。読出し要求時はなし)

レスポンス(交信要求先側): サブヘッダ(2バイト、H→L) → 終了コード(2バイト、H→L) → テキスト(レスポンス、最大1016ワード。書込み要求時はなし)

#### ■サブヘッダ

サブヘッダは，RJ71EN71またはRnENCPU(ネットワーク部)が自動で付加および削除するため，設定する必要はありません。

サブヘッダのビットパターン(b7〜b0): `0 1 1 0 0 0 0 1` = `□1H 00H`

 - b3〜b0(コマンド/レスポンス種別。ランダムアクセス用バッファによる交信時は下記の値): 読出し時: 61H／書込み時: 62H
 - b7(コマンド/レスポンスフラグ。コマンド時のみ、レスポンスはなし): コマンド時: 0／レスポンス時: 1

##### 読出し時のサブヘッダ例(表)

| データフォーマット | コマンド(相手機器→RJ71EN71またはRnENCPU(ネットワーク部)) | レスポンス(RJ71EN71またはRnENCPU(ネットワーク部)→相手機器) |
|---|---|---|
| バイナリコード | ビットパターン`0 1 1 0 0 0 0 1`(b7〜b0) = 61H 00H(サブヘッダ) | ビットパターン`1 1 1 0 0 0 0 1`(b7〜b0) = E1H(サブヘッダ) |
| ASCIIコード | ビットパターン`0 1 1 0 0 0 0 1`(b7〜b0)。"6"↔6H，"1"↔1H。バイト列: 36H 31H 30H 30H(サブヘッダ) | ビットパターン`1 1 1 0 0 0 0 1`(b7〜b0)。"E"↔EH，"1"↔1H。バイト列: 45H 31H(サブヘッダ) |

書込み時のサブヘッダは、原本に読出し時と同様の表は掲載されていない(上記のビット式(62H/E2H)から導出可能)。

#### ■先頭アドレス (原本 p.99)

データの読出し/書込みを行うランダムアクセス用バッファ範囲の先頭アドレスを論理アドレスで表します。(96ページ ランダムアクセス用バッファの物理アドレスおよび論理アドレス)

 - バイナリコードでの交信時: 先頭アドレスをバイナリ値で指定します。(2バイト、L,H)
 - ASCIIコードでの交信時: 先頭アドレスを16進数で表現したときのASCIIコードで指定します。(4バイト、H,-,-,L)

#### ■データ長設定 (原本 p.99)

読出し/書込みするデータのワード数をランダムアクセス用バッファ範囲で表します。

 - バイナリコードでの交信時: ワード数をバイナリ値で指定します。(最大1017ワード。2バイト、L,H)
 - ASCIIコードでの交信時: ワード数を16進数で表現したときのASCIIコードで指定します。(最大508ワード。4バイト、H,-,-,L)

#### ■テキスト (原本 p.100)

##### バイナリコードでの交信時

【図】テキスト(バイナリコード)の構成(原本 p.100)。データ長分(最大1017ワード)の各ワードが(L)(H)の順で伝文に並び、ランダムアクセス用バッファの指定アドレスnから n+1, n+2, …, n+読出しワード数設定値まで、各ワード(H)(L)の2バイト構成で対応する。

##### ASCIIコードでの交信時

【図】テキスト(ASCIIコード)の構成(原本 p.100)。データ長×2(最大1016ワード)分、各(H)〜(L)がASCII-バイナリ変換を介して、ランダムアクセス用バッファの指定アドレスnから最大508ワード分格納される。

##### 例 (原本 p.100)

ランダムアクセス用バッファの指定アドレスn=12H 34H，n+1=56H 78H を、テキストとして `31H 32H 33H 34H` `35H 36H 37H 38H` (ASCII文字"1234" "5678"に相当)で表す。

#### ■終了コード (原本 p.100)

レスポンスに付加される終了コードには，エラーコードが格納されます。(456ページ データ交信で相手機器に返される終了コード)

## コマンド/レスポンスフォーマット例 (原本 p.101-104)

コマンドとレスポンスのフォーマット例を示します。

### 相手機器からの書込み要求によるバッファへの書込み (原本 p.101-102)

#### バイナリコードでの交信時

コマンドフォーマット(相手機器→RJ71EN71): `62H 00H`(サブヘッダ) `00H 00H`(先頭アドレス L,H = 0) `0AH 00H`(データ長 L,H = 10) `34H 12H` `78H 56H` `BCH 9AH` … `BCH 9AH`(テキスト10ワード、各(L)(H))

対応するランダムアクセス用バッファ(物理アドレス／論理アドレス): 20000／0=12H 34H、20001／1=56H 78H、20002／2=9AH BCH、…、20009／9=9AH BCH(10ワード分)。物理アドレスは20000〜26143，論理アドレスは0〜6143。

レスポンスフォーマット(RJ71EN71→相手機器): `E2H`(サブヘッダ) `00H`(終了コード)

#### ASCIIコードでの交信時

コマンドフォーマット(相手機器→RJ71EN71): サブヘッダ`36H 32H 30H 30H` 先頭アドレス(H,-,-,L)`00H 00H 00H 00H` データ長(H,-,-,L)`00H 00H 00H 41H` テキスト(20ワード)`31H 32H 33H 34H` `35H 36H 37H 38H` `39H 41H 42H 43H` … `39H 41H 42H 43H`

ASCII-バイナリ変換後、ランダムアクセス用バッファの物理アドレス20000/論理アドレス0=12H 34H、20001/1=56H 78H、20002/2=9AH BCH、…、20009/9=9AH BCH(10ワード分)。

レスポンスフォーマット(RJ71EN71→相手機器): サブヘッダ`45H 32H` 終了コード`30H 30H`

### 相手機器からの読出し要求によるバッファからの読出し (原本 p.105-106)

#### バイナリコードでの交信時

コマンドフォーマット(相手機器→RJ71EN71): サブヘッダ`61H 00H` 先頭アドレス(L,H)`14H 00H`(=20) データ長(L,H)`0AH 00H`(=10)

対応するランダムアクセス用バッファ: 物理アドレス20020/論理アドレス20=12H 34H、20021/21=56H 78H、20022/22=9AH BCH、…、20029/29=9AH BCH(10ワード分)。

レスポンスフォーマット(RJ71EN71→相手機器): サブヘッダ`E1H` 終了コード`00H` テキスト(10ワード、各(L)(H))`34H 12H` `78H 56H` `BCH 9AH` … `BCH 9AH`

#### ASCIIコードでの交信時

コマンドフォーマット(相手機器→RJ71EN71): サブヘッダ`36H 31H 30H 30H` 先頭アドレス(H,-,-,L)`00H 00H 31H 34H`(=20) データ長(H,-,-,L)`00H 00H 00H 41H`(=10)

レスポンスフォーマット(RJ71EN71→相手機器): サブヘッダ`45H 31H` 終了コード`30H 30H` テキスト(20ワード)`31H 32H 33H 34H` `35H 36H 37H 38H` `39H 41H 42H 43H` … `39H 41H 42H 43H`

ASCII-バイナリ変換後の対応: ランダムアクセス用バッファの物理アドレス20020/論理アドレス20=12H 34H、20021/21=56H 78H、20022/22=9AH BCH、…、20029/29=9AH BCH(10ワード分)。

## ランダムアクセス用バッファによる交信例 (原本 p.105)

相手機器からの書込み操作の例を示します。

1. 受信データの最後に受信完了フラグを設けます。
2. 受信完了フラグを監視します。
3. 受信完了フラグがONしたら，ランダムアクセス用バッファからCPUユニットへデータを転送します。

【図】ランダムアクセス用バッファによる交信例の構成(原本 p.105)。相手機器→RJ71EN71のランダムアクセス用バッファ(物理アドレス21710〜21719に受信データ、21720に受信完了フラグ=1)→CPUユニットのデバイスメモリ(D10000〜D10009に受信データ)の順でデータが転送される。

### プログラム(ニモニック)

```
LDP   U0\G21720.0                                   受信完了フラグ
BMOV  U0\G21710   D10000   K10                       ランダムアクセス用バッファ(21710〜21719)をD10000〜D10009へ転送
```
