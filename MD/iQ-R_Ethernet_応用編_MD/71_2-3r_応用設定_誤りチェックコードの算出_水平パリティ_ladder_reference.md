## 例: 水平パリティの算出 (原本 p.371)

水平パリティコードの算出方法を，下記データを例にして示します。

【図】水平パリティのXOR計算図(原本 p.371)

対象データ: "0" "1" "2" "3" "4" "5" "6" "7" "8" → 算出範囲は"1"〜"8"("0"は算出範囲外)。算出結果として末尾に水平パリティを付加。

計算過程(すべて8ビットのXORを左から順に累積):

```
"1"(31H) = 0011 0001
                        XOR
"2"(32H) = 0011 0010  →  = 0000 0011
                        XOR
"3"(33H) = 0011 0011  →  = 0011 0000
                        XOR
"4"(34H) = 0011 0100  →  = 0000 0100
                        XOR
"5"(35H) = 0011 0101  →  = 0011 0001
                        XOR
"6"(36H) = 0011 0110  →  = 0000 0111
                        XOR
"7"(37H) = 0011 0111  →  = 0011 0000
                        XOR
"8"(38H) = 0011 1000  →  = 0000 1000 (2進)

水平パリティ = 08 (16進)
```
