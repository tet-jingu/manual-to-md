## 1.3 通信プロトコルによる交信 (1.3 / 原本 p.33)

相手機器側(計測器・バーコードリーダなど)のプロトコルに合わせて，相手機器とCPUユニット間でデータを送受信できます。

デバイスやバッファメモリを通信パケットに組み込むので，通信ごとに変化するデータにも対応できます。

エンジニアリングツールで相手機器との通信に必要なプロトコルの設定を行います。

プロトコルの設定は，あらかじめ用意された通信プロトコルライブラリから選択するか，任意に作成および編集ができます。

登録可能なプロトコル数とパケット数は下記のとおりです。

 - 登録可能プロトコル数: 最大128
 - 登録可能パケット数: 最大256
 - パケットデータエリアサイズ: 最大12288バイト

パケット数が上限に達した場合，プロトコル数が上限に達していなくても，プロトコルの追加はできなくなります。また，パケットデータエリアサイズが上限に達した場合，プロトコル数，パケット数が上限に達していなくても，プロトコル，パケットの追加はできなくなります。

【図】通信プロトコルの設定・実行の流れ(原本 p.33)。3ステップで構成。
- ①プロトコル設定: GX Works3の通信プロトコル支援機能より簡単に設定できます。
- ②プロトコルの書込み: 設定したプロトコルをEthernet搭載ユニットに書き込みます。
- ③プロトコルの実行: 専用命令でプロトコルを実行します。1つの専用命令で複数のプロトコルを実行できます。
- 図の下部注記: 相手機器に合わせたプロトコルでデータ交信が可能。GX Works3(左)→①→Ethernet搭載ユニット(中央)、Ethernet搭載ユニット⇔相手機器(右)間で「送信」「受信」の双方向矢印。

### 使用するコネクション (原本 p.33)

通信プロトコルによる交信では，P1コネクタのコネクションNo.1~16が使用できます。

P2コネクタでは通信プロトコルによる交信を使用できません。

> Point
> - 2つ以上のECPRTCL命令を同一コネクションに対して同時に実行した場合，先に実行中の命令が完了するまで，後の命令は無視されて実行されません。
> - ペアリング設定されたコネクションに対して，2つ以上のECPRTCL命令を，2つ(ペア)の異なるコネクションを指定して同時に実行した場合，先に実行中の命令が完了するまで，後の命令は異常完了します。

## データ交信の手順 (原本 p.34)

通信プロトコル支援機能を使用することで，下記の手順で相手機器とのデータ交信ができます。

1. 通信プロトコル支援機能でプロトコルを選択，作成または編集し，プロトコル設定データを書き込みます。(34ページ プロトコル設定データの作成)
2. ユニットパラメータを設定します。(40ページ 設定方法)
3. パラメータをCPUユニットへ書き込み，Ethernet搭載ユニットのイニシャル処理の正常完了を確認します。('イニシャル状態'(Un\G1900024.0): ON)
4. オープン処理を行い，Ethernet搭載ユニットと相手機器のコネクションを確立します。(513ページ TCP/IP通信，UDP/IP通信)
5. ECPRTCL命令でプロトコルを実行します。(510ページ 通信プロトコル交信用命令)
6. 通信が終了したら，コネクションをクローズします。

交信データコードは，選択した設定にかかわらず，バイナリコード交信となります。

### プロトコル設定データの作成 (原本 p.34)

通信プロトコル支援機能を使用してプロトコル設定データを作成します。

操作: [ツール][通信プロトコル支援機能]

1. プロトコル設定データの対象ユニットを選択します。
   RnENCPUの場合は，下記の項目を選択してください。
   - CPU部: "Ethernet内蔵CPU"
   - ネットワーク部: "Ethernetユニット"

### プロトコル設定データの新規作成 (原本 p.35)

プロトコル設定データを新規に作成します。

操作: [ファイル][新規作成]

| 項目 | 内容 |
|---|---|
| プロトコル番号 | プログラムの専用命令で使用するプロトコル番号が表示されます。 |
| メーカ | 設定するプロトコルの対象となる機器のメーカ名が表示されます。 |
| 型式 | 設定するプロトコルの対象となる型式が表示されます。 |
| プロトコル名 | 設定するプロトコルの名称が表示されます。 |
| 通信タイプ | 設定するプロトコルの通信タイプが表示されます。送信のみ: 1つの送信パケットを1回送信します。受信のみ: 最大16まで登録した受信パケットの中で一致するパケットがあれば受信します。送信&受信: 1つの送信パケットを送信後，最大16まで登録した受信パケットの中で一致するパケットがあれば受信します。 |
| 送信/受信 | パケットの送信方向が表示されます。空欄: 送信の場合／(1)~(16): 受信の場合，受信パケット番号が()内に表示されます。 |
| パケット名 | パケットの名称が表示されます。 |
| パケット設定 | パケット構成要素の変数有無および変数設定状態が表示されます。変数未設定，構成要素なし，構成要素エラーの場合は，Ethernet搭載ユニットにプロトコルを書き込めません。変数なし: 構成要素中に変数がない場合／変数設定済: 変数が全件設定済みの場合／変数未設定: 変数未設定の項目が1件でもある場合／構成要素未設定: 編集可能なプロトコルで構成要素がない場合／構成要素エラー: 構成要素が要件を満たしていない場合 |

### プロトコル詳細設定 (原本 p.37)

プロトコルの送受信パラメータを設定します。

操作: "プロトコル設定"画面→任意のプロトコルの行を選択→[編集][プロトコル詳細設定]

*1 通信プロトコルライブラリから選択したプロトコルの場合は，設定を変更できません。

> Point
> [送受信パラメータ一括設定]ボタンをクリックし，設定プロトコル番号範囲，受信設定および送信設定を設定することで，複数のプロトコルに対して送受信パラメータを設定できます。

| 項目(大分類) | 項目 | 内容 |
|---|---|---|
| 接続機器情報*1 | メーカ | プロトコルのメーカ名を設定します。 |
| 接続機器情報*1 | 種別 | プロトコルの機器種別を設定します。 |
| 接続機器情報*1 | 型式 | プロトコルの型式を設定します。 |
| 接続機器情報*1 | バージョン | プロトコルの機器バージョンを設定します。 |
| 接続機器情報*1 | 説明 | プロトコルの機器の説明を設定します。 |
| プロトコル設定情報*1 | プロトコル番号 | 選択したプロトコルのプロトコル番号が表示されます。 |
| プロトコル設定情報*1 | プロトコル名 | プロトコルの名称を設定します。 |
| プロトコル設定情報*1 | 通信タイプ | プロトコルの通信タイプを設定します。 |
| 受信設定 | 受信待ち時間 | ユニットが受信データ待ち状態になってからの待ち時間を設定します。断線などにより相手機器と通信不可となり，指定時間内に一致するパケットデータを受信できない場合，ユニットは異常と判断し，受信データ待ち状態を解除します。 |
| 送信設定 | 送信待機時間 | ユニットに設定されたプロトコルが実行状態になってから，データを実際に送信するまでの待機時間を設定します。これにより，ユニットの送信タイミングに対して，相手機器が受信可能となるまでの時間を調整できます。 |

### プロトコル設定データの書込み (原本 p.38)

プロトコル設定データをEthernet搭載ユニットに書き込みます。

操作: [オンライン][ユニット書込]

プロトコル設定データを書き込むユニットおよびメモリを選択し，書き込んでください。

CPUユニットへ書き込む場合，プロトコル設定データは，ユニット拡張パラメータに書き込まれます。

下記のデータはプロトコル設定データとして書き込まれないため，読み出しても表示されません。ただし，通信プロトコルライブラリより選択したプロトコルの場合は表示されます。

 - メーカ
 - パケット名
 - プロトコル詳細設定の種別，バージョン，説明
 - パケット設定の構成要素名

プロトコル設定データを書き込んだ後は，下記のタイミングで有効になります。

 - 電源OFF→ON時
 - CPUユニットのリセット時
 - CPUユニットのSTOP→RUN時

ブート運転を使用することにより，SDメモリカードに書き込まれた通信プロトコル設定をCPUユニットのメモリに転送できます。

ブート運転については，使用するCPUユニットのマニュアルを参照してください。

#### 複数の対象メモリにプロトコル設定データが書き込まれた場合 (原本 p.39)

複数の対象メモリにプロトコル設定データが書き込まれた場合，下記の動作となります。

プロトコル設定データはCPU内蔵メモリに書き込むことによって，ユニット交換後も同じプロトコル設定データが使用できます。

CPU内蔵メモリの容量が足りなくなった場合は，SDメモリカードに書き込んでください。

また，プロトコル設定データは，インテリジェント機能ユニットにも書き込めますが，ユニットを交換した際に再度書込みが必要になります。

凡例: ○=通信プロトコル設定が書き込まれている，×=通信プロトコル設定が書き込まれていない

| CPUユニット(内蔵Ethernetポート部) | SDメモリカード | RJ71EN71，RnENCPU(ネットワーク部) | 動作 |
|---|---|---|---|
| ○ | ○ | × | "メモリカードパラメータ"画面の"メモリカード内のファイル/データの使用有無設定"にある"ユニット拡張パラメータ"の設定内容に従って動作します。 |
| ○ | × | ○ | プロトコル設定データが有効になった時点で，RJ71EN71またはRnENCPU(ネットワーク部)の通信プロトコル設定は，CPUユニットのメモリまたはSDメモリカードの通信プロトコル設定で上書きされます。 |
| × | ○ | ○ | プロトコル設定データが有効になった時点で，RJ71EN71またはRnENCPU(ネットワーク部)の通信プロトコル設定は，CPUユニットのメモリまたはSDメモリカードの通信プロトコル設定で上書きされます。 |
| ○ | ○ | ○ | "メモリカードパラメータ"画面の"メモリカード内のファイル/データの使用有無設定"にある"ユニット拡張パラメータ"の設定内容に従って動作します。また，プロトコル設定データ有効になった時点で，RJ71EN71またはRnENCPU(ネットワーク部)の通信プロトコル設定は，CPUユニットのメモリまたはSDメモリカードの通信プロトコル設定で上書きされます。 |

## 設定方法 (原本 p.40)

"基本設定"の"相手機器接続構成設定"で行います。(311ページ 相手機器接続構成設定)

1. "ユニット一覧"にある下記から相手機器を選択し，"機器一覧"または"機器構成図"にドラッグ＆ドロップします。
2. 相手機器との"交信手段"を"通信プロトコル"に設定します。
3. その他，通信に必要なパラメータをコネクションに設定します。

| 相手機器名 | 内容 |
|---|---|
| UDP接続機器 | UDP/IPで相手機器と交信する場合に選択します。 |
| Active接続機器 | Ethernet搭載ユニットから相手機器に対してオープン処理を行い(Activeオープン)，TCP/IPで交信する場合に選択します。 |
| Unpassive接続機器 | 不特定の相手機器からのオープン処理を受けて(Unpassiveオープン)，TCP/IPで交信する場合に選択します。 |
| Fullpassive接続機器 | 特定の相手機器からのオープン処理を受けて(Fullpassiveオープン)，TCP/IPで交信する場合に選択します。 |
