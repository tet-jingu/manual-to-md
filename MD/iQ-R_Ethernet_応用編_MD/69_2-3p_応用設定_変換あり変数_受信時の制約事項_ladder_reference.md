## 受信時の制約事項 (原本 p.367)

- ”変換内容”が”ASCII 16進数→HEX”の場合，”0”~”9”，”A”~”F”，”a”~”f”以外の文字列を受信すると照合不一致となります。
- ”変換内容”が”ASCII 10進数→HEX”の場合，”0”~”9”以外の文字列を受信すると照合不一致となります。ただし下記の場合は照合不一致となりません。

| 項目 | 動作 |
|---|---|
| 符号有無 | ”符号なし”以外の場合，符号文字が受信できます。ただし，符号文字を1データの先頭以外で受信した場合は，照合不一致となります。 |
| 小数点桁 | ”小数点なし”以外の場合，”.(ピリオド)”が受信できます。ただし，”.(ピリオド)”を設定した桁数以外で受信した場合，または”.(ピリオド)”を1データの先頭や最後で受信した場合は，照合不一致となります。 |
| 区切り文字 | ”区切り文字なし”以外の場合，区切り文字が受信できます。ただし，区切り文字をデータの区切り以外で受信した場合，または”区切り文字なし”以外の場合に区切り文字を含まないデータを受信すると照合不一致となります。 |

原本の表行数(目視カウント): 3行。上表は全3行を転記。

- ”桁数”が”桁数可変”のとき，受信したデータの桁数が下記の上限を超えている場合，照合不一致となります。

| 変換データ型 | 変換内容 | 受信データ数の上限 |
|---|---|---|
| ワード | ASCII 10進数→HEX | 最大5桁 |
| ワード | ASCII 16進数→HEX | 最大4桁 |
| ダブルワード | ASCII 10進数→HEX | 最大10桁 |
| ダブルワード | ASCII 16進数→HEX | 最大8桁 |
| 単精度実数 | ASCII 10進数→HEX | 最大7桁 |
| 単精度実数 | ASCII 16進数→HEX | 設定不可 |
| 倍精度実数 | ASCII 10進数→HEX | 最大15桁 |
| 倍精度実数 | ASCII 16進数→HEX | 設定不可 |

原本の表行数(目視カウント): 8行。上表は全8行を転記。

- ”桁数”が”桁数可変”のときに，受信したデータが区切り文字のみ，または空文字列のみの場合，0を受信したものとして，対応する受信データ格納エリアを0で上書きします。

**例**

”データ数/最大データ数”が3，受信したデータが「,,」の場合: 「0,0,0」を受信したとみなします。

- ”データ数固定/データ数可変”が”データ数可変”の場合，データ受信時に”桁数”で指定した桁数よりも少ないデータを受信すると，照合不一致となるときがあります。ただし，”桁数”が”桁数可変”かつ”区切り文字”を設定したときに，受信したデータに区切り文字が連続する箇所(データなし)がある場合，0を受信したものとして対応する受信データ格納エリアを0で上書きします。

**例: ”桁数”設定が4桁の場合**

【図】桁数不足によるエラーの例(原本 p.367)
- 受信データ: [変換あり変数: "1" "2" "3"][固定データ: ETX]
- ”桁数”設定が4桁に対し，受信したデータが3桁で”変換あり変数”の終わりとなった場合はエラーとなります。

- 変換あり変数が可変長構成要素の場合，”データ数/最大データ数”よりも多いデータ数を受信すると，”データ数/最大データ数”分のデータのみ格納し，残りの受信データは切り捨てます。(プロトコルは正常完了します。ただし，下記の場合は照合不一致となります。)
  - ”データ数固定/データ数可変”が”データ数固定”，”桁数”が”桁数可変”，”データ数/最大データ数”が2以上
  - ”データ数固定/データ数可変”が”データ数固定”，”桁数”が”桁数可変”，”データ数/最大データ数”が1，”区切り文字”が”区切り文字なし”

## 受信時の制約事項(続き) (原本 p.368)

- 相手機器から受信するパケットデータのうち，変数に該当するデータが変換あり変数直後の固定データと区別できる必要があります。区別できない場合，受信処理を正常にできない場合があります。(たとえば，変換あり変数直後の固定データの値が変換あり変数で使用されていると，変換あり変数直後の固定データと認識し照合，受信処理を行います。)
- ”変換データ型”が”単精度実数”または”倍精度実数”の場合，範囲外のデータを受信すると照合不一致となります。
- ”小数点桁”が1~15のとき，パラメータで設定した小数点桁と，受信したデータの小数点桁が一致しない場合は，照合不一致となります。(たとえば，”桁数”が”桁数可変”，”小数点桁”が1のときに，受信したデータが1.23の場合，パラメータで設定した小数点桁が1桁で，受信したデータの小数点桁が2桁のため，照合不一致となります。)
