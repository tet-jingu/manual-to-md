## 1.15 シンプルCPU通信機能(CPUユニット(内蔵Ethernetポート部)) (1.15 / 原本 p.220)

CPUユニット(内蔵Ethernetポート部)にエンジニアリングツールから簡単な設定を行うだけで，指定のデバイスを指定のタイミングで送受信できる機能です。送受信は指定した交信相手と1: 1で行います。

| 交信相手 | 種別 | 詳細 |
|---|---|---|
| MELSEC iQ-Rシリーズ | CPUユニット(内蔵Ethernet) | 222ページ 機器種別 |
| MELSEC-Qシリーズ | CPUユニット(内蔵Ethernet)，Ethernetユニット*1 | 同上 |
| MELSEC-Lシリーズ | CPUユニット(内蔵Ethernet)，Ethernetユニット*1 | 同上 |
| MELSEC iQ-Fシリーズ*1 | CPUユニット(内蔵Ethernet) | 同上 |
| MELSEC iQ-Lシリーズ*1 | CPUユニット(内蔵Ethernet) | 同上 |
| MELSEC-A/AnSシリーズ*1 | Ethernetユニット | 同上 |
| MELSEC-Fシリーズ*1 | Ethernetブロック・アダプタ | 同上 |
| SLMP対応機器 | QnA互換3Eフレーム | 同上 |

*1 設定可能な交信相手および種別は，CPUユニットおよびエンジニアリングツールのバージョンを確認してください。(550ページ 機能の追加と変更)

【図】シンプルCPU通信機能(CPUユニット内蔵Ethernetポート部)の対応交信相手(原本 p.220)。RCPU(CPUユニット内蔵Ethernetポート)を中心にハブ経由でMELSEC iQ-R/iQ-F/L/A-AnS・F/Q/iQ-L各シリーズ、SLMP対応機器が接続される構成。

> Point
> ルータを経由したアクセスも可能です。設定する場合は，サブネットマスクとデフォルトゲートウェイも設定してください。(309ページ 自ノード設定)
>
> シンプルCPU通信機能を使用する場合は，CPUユニットのバージョンを確認してください。(550ページ 機能の追加と変更)

## 設定方法 (原本 p.221)

本機能を使用するための設定について説明します。

1. "応用設定"の"シンプルCPU通信設定"にある"シンプルCPU通信使用有無"を"使用する"に設定します。
   操作: [ナビゲーションウィンドウ][パラメータ]→対象ユニット→[ユニットパラメータ][応用設定][シンプルCPU通信設定]
2. "シンプルCPU通信設定"の"<詳細設定>"をダブルクリックすると，設定画面が表示されます。(327ページ シンプルCPU通信設定(CPUユニット(内蔵Ethernetポート部)))
3. 設定後，自局のCPUユニットにユニットパラメータを書き込み，CPUユニットのリセットまたは電源OFF→ONすると，シンプルCPU通信が開始されます。

### 通信パターン

下記の項目から通信パターンを選択します。

| 設定項目 | 内容 |
|---|---|
| 読出 | 指定した交信相手(転送元)のデバイスデータを自局(転送先)の指定したデバイスに読み出します。 |
| 書込 | 自局(転送元)の指定したデバイスデータを指定した交信相手(転送先)のデバイスに書き込みます。 |

### 交信設定: 実行間隔

下記の項目から交信方法を選択します。

*1 "要求時"を設定する場合は，CPUユニットおよびエンジニアリングツールのバージョンを確認してください。(550ページ 機能の追加と変更)

 - 実際の実行間隔は，交信相手やEthernet回線の負荷などに影響を受けるため，設定した実行間隔より長くなることがあります。対策については，下記を参照してください。(427ページ シンプルCPU通信機能使用時)
 - 通信開始待ち時間設定時は，通信開始待ち時間経過後からデータ送受信が実行されます。(229ページ 通信開始待ち時間)

| 設定項目 | 内容 | 設定範囲 |
|---|---|---|
| 定期 | デバイスデータの送受信を指定した実行間隔で実施します。 | — |
| 実行間隔 | 実行間隔を設定します。 | 10ms~65535ms(1ms単位) |
| 要求時*1 | データの送受信を要求時のみ行います。 | — |

## 交信相手(IPアドレス) (原本 p.222)

"転送先"をクリックして"交信相手設定"画面を開き，交信相手を設定および登録します。交信相手の登録数は，最大64です。

### 機器種別

交信相手の機器種別を下記から選択します。

*1 RnENCPUは，CPU部のEthernetポートに接続した場合に交信できます。

*2 FX5U CPUユニット，FX5UC CPUユニットでは，ファームウェアバージョンが"1.110"以降で使用できます。

*3 Ethernetインタフェースユニットを管理するCPUユニットが交信相手になります。

*4 AnCPU，AnSCPU，QCPU(Aモード)を含みます。

*5 装着可能なCPUユニット，およびその対応バージョンについては，下記を参照してください。(550ページ 機能の追加と変更)

### IPアドレス，TCP/UDP，ポート番号，自局ポート番号

交信相手のIPアドレス，交信に使用するプロトコル，ポート番号，および自局ポート番号を設定します。

 - マルチCPUシステム構成時は，Ethernetケーブルを接続している号機のIPアドレスを指定してください。
 - 交信相手が三菱A/AnS，三菱FX3，SLMP対応機器以外の交信においては，自局で使用するポート番号は，61696~65534を動的に使用します。そのため，本機能使用中は，ソケット通信機能のコネクションの確立命令(SP.SOCOPEN)において，自局ポート番号に61696~65534を指定しないでください。指定した場合は，命令が異常完了する場合があります。
 - 自局ポート番号の1~1023は一般的に予約されたポート番号(WELL KNOWN PORT NUMBERS)，61440~65534は他の通信機能で使用するため，1024~4999，5010~61439を使用することを推奨します。
 - 複数の設定で同じ交信相手を指定する場合，異なる自局ポート番号を設定してください。

## 交信相手側での設定 (原本 p.223)

交信相手ごとに，交信相手側での設定が異なります。

*1 交信相手のCPUユニットがSTOPまたは停止エラー中に本機能を実行する場合に設定します。

*2 交信相手のCPUユニットがRUN時に本機能を実行する場合にONします。

| 交信相手 | 必要な設定 |
|---|---|
| 三菱iQ-R(内蔵Ethernet)，三菱iQ-F(内蔵Ethernet)，三菱iQ-L(内蔵Ethernet) | 自動オープンUDPポートによって交信するため，設定は不要です。 |
| 三菱Q(内蔵Ethernet)，三菱L(内蔵Ethernet) | "オープン設定"で交信相手の台数分，下記の設定を行ってください。・プロトコル: "UDP"・オープン方式: "MELSOFT 接続" |
| 三菱Q(Ethernetユニット)，三菱L(Ethernetユニット) | ネットワークNo.と局番を設定してください。 |
| 三菱A/AnS(Ethernetユニット) | プログラミングツールでイニシャル処理プログラムを作成して，下記の設定をしてください。・IPアドレスおよびポート番号・通信方式: "UDP"・ストップ中交信指示エリア(Un\G496)のビット15およびビット0~7(使用するコネクションNo.に対応したビットをONにします。)*1。イニシャル処理プログラムについては下記を参照してください。(A対応Ethernetインタフェースユニットユーザーズマニュアル(詳細編))。ユニット前面のディップスイッチで下記の設定をしてください。・SW2(データコード設定): OFF・SW7(CPU交信タイミング設定): ON*2 |
| 三菱FX3(Ethernetブロック・アダプタ) | "Ethernet ポート設定"の"交信データコード設定"を"バイナリコード交信"に設定してください。"オープン設定"で交信相手の台数分，下記の設定を行ってください。・IPアドレスおよびポート番号・プロトコル: "UDP"・オープン方式: "MCプロトコル" |
| SLMP対応機器(QnA互換3Eフレーム) | SLMP対応機器側で，SLMP(MCプロトコルのQnA互換3Eフレーム)を使用できるように設定してください。(各機器のマニュアル)交信データコードはバイナリに設定してください。プロトコルはUDPに設定してください。 |

## 対象号機 (原本 p.223)

交信相手が下記で，マルチCPUシステム構成時は，交信相手の"対象号機"を指定します。

 - 三菱iQ-R(内蔵Ethernet): RnCPU，RnENCPU，RnPCPU，RnSFCPU
 - 三菱Q(内蔵Ethernet): QnUDE(H)CPU，QnUDVCPU，QnUDPVCPU(QCPUユーザーズマニュアル(マルチCPUシステム編))

## 指定可能デバイス (原本 p.224)

転送元および転送先デバイスの指定可能なデバイスは，交信相手により異なります。各設定No.において，ビットデバイスとワードデバイスは同時に設定できます。

指定可能デバイスの指定可能なサイズは，ビットデバイスは16点単位，ワードデバイスは1点単位となります。ビットデバイスについては，デバイス番号は0または16の倍数で指定してください。

 - デバイス点数は，設定No.1~64の合計(最大8192ワード)で設定します。
 - 1設定あたりの点数は，最大512ワード(ビットデバイス最大8192点，ワードデバイス最大512点)です。

> 注意事項
> 安全デバイスは指定できません。
