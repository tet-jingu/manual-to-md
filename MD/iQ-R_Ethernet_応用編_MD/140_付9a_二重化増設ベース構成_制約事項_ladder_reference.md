## 付9 二重化増設ベース構成で増設ベースユニットに装着して使用する場合 (原本 p.529)

RJ71EN71を二重化増設ベース構成の増設ベースユニットに装着して使用する場合について説明します。

### 制約のある機能・仕様 (原本 p.529)

二重化増設ベース構成の増設ベースユニットに装着した場合に制約のある機能および仕様について示します。

**使用できるネットワークの組合せ**

\*1 使用する場合は，増設ベースユニットに対応するCPUユニット，およびエンジニアリングツールのバージョンを確認してください。

| ネットワーク種別 | GX Works3での設定 | 制約事項 |
|---|---|---|
| Ethernet | RJ71EN71(E+E) | ファームウェアバージョンが"50"以降で使用できます。\*1 |
| CC-Link IEコントローラネットワーク | RJ71EN71(CCIEC) | 使用できません。 |
| CC-Link IEフィールドネットワーク | RJ71EN71(CCIEF) | 使用できません。 |
| Ethernet+CC-Link IEコントローラネットワーク | RJ71EN71(E+CCIEC) | 使用できません。 |
| Ethernet+CC-Link IEフィールドネットワーク | RJ71EN71(E+CCIEF) | 使用できません。 |
| Q互換Ethernet | RJ71EN71(Q) | ファームウェアバージョンが"50"以降で使用できます。\*1 |

原本の表行数(目視カウント): 6行。上表は全6行を転記(render確認済み)。

**機能**

| 機能 | 制約事項 |
|---|---|
| MELSOFT製品およびGOTとの接続 | "系指定なし"を指定した場合は，制御系のCPUユニットにアクセスします。<br>A系のCPUユニットが制御系のときにアクセスする場合，接続先指定の二重化CPU指定で"A系"または"制御系"または"系指定なし"を指定した場合に通信できます。<br>A系のCPUユニットが待機系のときにアクセスする場合，接続先指定の二重化CPU指定で"A系"または"待機系"を指定した場合に通信できます。 |
| 通信プロトコルによる交信 | 使用できません。 |
| ソケット通信による交信 | 使用できません。 |
| 固定バッファによる交信 | ネットワーク種別が"Q互換Ethernet"の場合のみ使用できます。(531ページ 固定バッファによる交信例) |
| MODBUS/TCPによる交信 | ネットワーク種別が"Q互換Ethernet"の場合は使用できません。 |
| リンク専用命令による交信 | 中継局または対象局には指定できますが，自局からはリンク専用命令を実行できません。 |
| ファイル転送機能(FTPサーバ) | 使用できません。 |
| IPフィルタ | ネットワーク種別が"Q互換Ethernet"の場合は使用できません。 |
| シンプルCPU通信機能 | ネットワーク種別が"Q互換Ethernet"の場合は使用できません。 |
| シンプル機器通信機能 | 使用できません。 |
| IPアドレス変更機能 | ネットワーク種別が"Q互換Ethernet"の場合は使用できません。 |

原本の表行数(目視カウント): 11行。上表は全11行を転記(render確認済み)。

**専用命令**

RJ71EN71の専用命令は，すべて使用できません。

使用する場合は，基本ベースユニットに装着してください。

> **Point**
> ERRCLEAR命令については，ネットワーク種別が"Q互換Ethernet"の場合，'ERR LED消灯要求'(Y17)を使用することで代替できます。(460ページ ネットワーク種別が"Q互換Ethernet"の場合)

**ユニットFB**

RJ71EN71のユニットFBは，すべて使用できません。

### ユニットパラメータ (原本 p.530)

**応用設定**

- "二重化設定"の"二重化設定使用有無"には，"使用しない"を選択してください。
- "割込み設定"は設定しないでください。
- "ネットワーク動的ルーチング設定"の"動的ルーチング設定"は"無効"にしてください。
- "IPパケット中継設定"の"IPパケット中継機能使用有無"は"使用しない"を選択してください。

### オープン/クローズ処理 (原本 p.530)

専用命令によるオープン/クローズ処理はできません。

### 注意事項 (原本 p.530)

- MELSOFT接続，他局からのSLMP交信，または他局からの専用命令での交信中に系切替えが発生した場合，通信タイムアウトになることがあります。
- シンプルCPU通信による交信中に系切替えが発生した場合，CPU応答監視タイマがタイムアウトすることがあります。必要に応じて再度実行してください。
- MODBUS/TCPによる交信中に系切替えが発生した場合，CPU応答監視タイマがタイムアウトすることがあります。必要に応じて再度実行してください。
- MELSEC-Qシリーズからの置換えについては，RJ71EN71のネットワーク種別で"Q互換Ethernet"を選択した場合のみ可能です。
