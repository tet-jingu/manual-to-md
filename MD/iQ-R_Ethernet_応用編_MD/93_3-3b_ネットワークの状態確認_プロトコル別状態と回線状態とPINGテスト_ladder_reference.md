## PINGテスト (原本 p.411)

PINGテストは，同一Ethernet上にEthernet機器が存在することを確認するテストです。

エンジニアリングツールの接続先のネットワークに対して存在確認用のパケットを送信し，応答が返ってくることにより交信可否を確認します。

”Ethernet診断”画面[PINGテスト]ボタン

**実行手順**

”入力項目”に必要な項目を設定し，[実行]ボタンをクリックすることで，PINGテストを実行し，”結果”欄にテスト結果が表示されます。

- エンジニアリングツールとCPUユニットをUSBケーブルで接続して，RJ71EN71またはRnENCPU(ネットワーク部)からPINGテストを実行する場合は，PING実行局を指定するためにネットワークNo.と局番の設定が必要になります。
- ”接続先指定 Connection”画面の”他局指定”において”他局指定無し”以外を指定してEthernet診断を起動した場合は，PINGテストを使用できません。

**異常終了時の処置**

異常の場合は，下記の内容を確認して再度テストを実行してください。

- ベースユニットへのEthernet搭載ユニットの装着状態
- Ethernetへの接続状態
- CPUユニットに書き込まれている各パラメータの内容
- CPUユニットの動作状態(異常が発生していないか)
- エンジニアリングツールとPINGテスト対象局に設定されている各IPアドレス
- Ethernet搭載ユニットを交換したときに相手機器もリセットしたか
