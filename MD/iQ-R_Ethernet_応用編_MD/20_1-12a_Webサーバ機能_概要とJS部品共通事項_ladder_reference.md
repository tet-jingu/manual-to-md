## 1.12 Webサーバ機能 (1.12 / 原本 p.142)

Webブラウザを使用して，CPUユニットへのデバイスデータ書込み/読出しを行える機能です。Ethernet接続されているパソコンの汎用のWebブラウザだけでなく，タブレットやスマートフォンの汎用のWebブラウザからもEthernet経由で，CPUユニットへのデバイスデータ書込み/読出しを行えます。また，お客様独自のWebページを作成したり，表示させたりできます。

Webサーバ機能をご使用いただくときに必要な仕様，パラメータ設定，使用までの手順，システム構成，機能，トラブルシューティングなどについては，下記を参照してください。

MELSEC iQ-R/MELSEC iQ-F Webサーバ機能ガイドブック

本マニュアルでは，ユーザWebページで使用可能なJavaScript部品とCGI部品について説明します。

> 注意事項
> 外部機器からの不正アクセスに対して，シーケンサシステムの安全を保つ必要があるときは，本機能以外の対策も盛り込んでください。不正アクセスにより発生するシステムトラブル上の諸問題に対して，当社は一切その責任を負うことができません。Webサーバ機能におけるユーザ認証は，外部機器からの不正アクセス(プログラムやデータの破壊など)を防止するための1つの手段であり，不正アクセスを完全に防止するものではありません。
>
> 不正アクセスの対策例を示します。
> - ファイアウォールを設置する
> - 中継局としてパソコンを設置し，アプリケーションプログラムで送受信データの中継を制御する
> - アクセス権を制御できる外部機器を中継局として設置する(アクセス権を制御できる外部機器については，ネットワーク接続業者，または機器販売業者にお問い合わせください)

## JavaScript部品 (原本 p.143)

ユーザWebページのライブラリにあるJavaScript部品を使うと，ユーザWebページでデバイスの読出し/書込みが簡単にできます。ユーザWebページのJavaScript部品ライブラリ(RUserWebLib.js)には，下記の部品が含まれています。

| 部品名(関数名) | 内容 | 参照 |
|---|---|---|

| レベル表示部品(WSLevel) | デバイス値の全体(上限値と下限値の範囲)に対する割合を表示します。 | 148ページ レベル表示部品(WSLevel) |
| 図形表示部品(WSFigure) | デバイス値が設定した値になると，指定した図形を表示します。 | 150ページ 図形表示部品(WSFigure) |
| 画像表示部品(WSPicture) | デバイス値が設定した値になると，指定した画像ファイルを表示します。 | 152ページ 画像表示部品(WSPicture) |
| ヒストリカルグラフ部品(WSHstgrp) | デバイスデータを，時系列の折れ線グラフで表示します。 | 153ページ ヒストリカルグラフ表示部品(WSHstgrp) |
| 書込みボタン部品(WSWtrBtn) | 指定したデバイスに，指定した値を書き込みます。 | 155ページ 書込みボタン部品(WSWtrBtn) |

### 各JavaScript部品の共通事項 (原本 p.143)

#### スタイルシート

ユーザWebページの文字サイズ，色，線色，背景色のスタイルは，記述が省略できます。記述を省略した場合や記述が誤っている場合，スタイルシート(UserWebStyle.css)に従った下記のデフォルト表示となります。

文字フォントは，ユーザWebページを表示する端末によって変わります。

> 注意事項
> ユーザWebページのライブラリにあるスタイルシートを変更する場合，スタイルシートのクラス名称は変更しないでください。また同じ名称のスタイルクラスは定義しないでください。

| 項目 | デフォルト |
|---|---|
| 文字色 | Black |
| 背景色 | White |
| 線色 | Black |
| レベル表示塗りつぶし色 | Blue |
| グラフ線色 | Blue |
| 文字サイズ | 20 |
| ボタン文字色 | WEBブラウザの設定に従います。 |
| ボタン背景色 | WEBブラウザの設定に従います。 |
| ボタン線色 | WEBブラウザの設定に従います。 |

## JavaScript部品のパラメータの設定 (原本 p.144)

 - 設定の要否が任意のパラメータを省略した場合，デフォルトの設定で表示されます。任意のパラメータの設定が異常な場合も，デフォルトの設定で表示されます。
 - 各パラメータは指定されたデータ形式で設定してください。指定されたデータ形式以外で設定した場合(例えば数値で設定するパラメータに'1'などの文字列を設定した場合)，パラメータ異常となります。
 - X座標，Y座標を省略した場合，部品は左上端(座標0,0)に配置されます。
 - パラメータに指定するRGB値，またはカラー名などのHTML仕様には範囲チェックが行われません。異常な設定した場合の動作はブラウザによって異なります。
 - Un\GやJn\Xなどの\付のデバイス名を指定する時は，Un\\GやJn\\Xのように\を重ねて指定します。(\はエスケープシーケンスになっています。)

### 更新周期 (原本 p.145)

ユーザWebページの更新周期は，HTML上の変数updateIntervalに設定します。この更新周期は，すべてのユーザWeb部品に共通して適用されます。HTMLに変数updateIntervalの記載がない，または変数updateIntervalが1~120*1の範囲外の場合，5秒周期(デフォルト)で動作します。

*1 CPUユニットのファームウェアバージョンにより，設定範囲が異なります。詳細については，下記を参照してください。(MELSEC iQ-R/MELSEC iQ-F Webサーバ機能ガイドブック)

#### 例: 10秒周期で更新したい場合

```html
<script>
 var updateInterval = 10;
 </script>
```
