## シンプルCPU通信診断 (原本 p.414)

シンプルCPU通信診断によって，シンプルCPU通信機能の交信状態を確認できます。

[診断][シンプルCPU通信診断]

\*1 CPUユニット(内蔵Ethernetポート部)の交信設定が”要求時”の場合は，要求時交信開始要求をOFFONし，通信が正常に行える状態になった際に，前回エラー発生時のエラーコードをクリアします。

| 項目 | 内容 |
|---|---|
| 設定No. | シンプルCPU通信の設定No.が表示されます。 |
| 通信パターン | パラメータで設定した通信パターン(読出/書込)が表示されます。 |
| 交信設定 | パラメータで設定した交信設定(定期/要求時)が表示されます。 |
| 交信相手 | パラメータで設定した交信相手が表示されます。RJ71EN71またはRnENCPU(ネットワーク部)でシンプルCPU通信を実施した場合に確認できます。 |
| 状態 | 通信状態(”未設定”，”準備中”，”要求待ち”，”実行中”，”停止中”，”リトライ中”，”監視中”，”交信不可”)が表示されます。二重化システムの系切替え時は”準備中”と表示されます。 |
| IPアドレス | パラメータで設定した交信相手のIPアドレスが表示されます。 |
| ポート番号 | パラメータで設定した交信相手のポート番号が表示されます。 |
| 対象号機 | パラメータで設定した対象号機が表示されます。 |
| 実行間隔[ms](現在)／実行間隔[ms](最大)／実行間隔[ms](最小) | 実行間隔の現在値，最大値，最小値がms単位で表示されます。リトライ中と監視中は値が更新されず，停止中は”実行間隔[ms](現在)”に0が表示されます。二重化システムの系切替え時は，0が表示されます。”応用設定”の”シンプルCPU通信設定”の”交信設定”が”要求時”の場合は”-----”が表示されます。 |
| 正常完了回数／異常完了回数／リトライ回数 | 正常完了，異常完了，リトライした累積回数が表示されます。0~4294967295: 累積回数。4294967295を超えた場合は1からカウントを継続します。 |
| 最新エラーコード | エラー発生時はエラーコードが表示され，エラー未発生時は”エラー無し”と表示されます。通信が正常に行える状態になったあとでも，前回エラー発生時のエラーコードは表示されたままとなります。\*1なお，新たに別エラーが発生した場合は，エラーコードを更新(上書き)します。 |
| エラー詳細... | 選択している設定No.で発生しているエラーのエラー内容と処置方法が表示されます。 |
| [最新エラーコードをクリア]ボタン | エラーコードをクリアします。なお，本操作でCPUバッファメモリ上の該当設定No.のエラーコード(Un\G1194~Un\G1257)もクリアされます。 |
| (自局)IPアドレス | 接続中の自局IPアドレスが表示されます。・RJ71EN71またはRnENCPU(ネットワーク部)の”基本設定”の”自ノード設定”で設定したIPアドレスが表示されます。・RJ71EN71を二重化システムで使用している場合は，制御系IPアドレスが表示されます。・プロセスCPU(二重化モード)では，接続しているA系のIPアドレスまたはB系のIPアドレスが表示されます。 |

原本の表行数(目視カウント): 14行。上表は全14行を転記。

- ”正常完了回数”，”異常完了回数”，”リトライ回数”，”最新エラーコード”，”エラー詳細”は，系切替えが実行されてもトラッキングされず，A系B系それぞれに情報が保持されます。そのため，”正常完了回数”，”異常完了回数”，”リトライ回数”は系ごとの累積となり，A系とB系で”最新エラーコード”，”エラー詳細”が異なります。
- 二重化システム構成時にシンプルCPU通信診断で対象ユニットをRJ71EN71に指定する場合は，診断したい局にエンジニアリングツールを直結接続し，自号機を指定(”二重化CPU指定”が”系指定なし”)にしてください。
- リモートヘッドユニットの二重化システム構成時，エンジニアリングツールを待機系のリモートヘッドユニットに接続していると，シンプルCPU通信診断は起動できません。制御系にエンジニアリングツールを接続して起動してください。
- 二重化システム構成時，”システムモニタ”の”基本ベース情報”でA系/B系の表示を切り替えると，ユニット診断画面からシンプルCPU通信診断は起動できません。
- ”接続先指定”の”他局指定”において”他局(異種ネットワーク)”を指定した場合，”異種ネットワーク通信経路”に”CC-Link”，または”C24”を指定してシンプルCPU通信診断は起動できません。
- ”接続先指定”の”他局指定”において”他局指定無し”以外を指定している場合は，”接続先指定”の”他局指定”で診断を実施するEthernet搭載ユニットを指定してください。他のEthernet搭載ユニットを指定した場合，同一ベース上のEthernet搭載ユニットであってもシンプルCPU通信診断を起動することはできません。また，エンジニアリングツールを直結している局が所属するネットワークを含め，最大8ネットワーク先(中継局数: 7局)の局まで，シンプルCPU通信診断を起動できます。

**注意事項**

通信経路に下記が含まれる場合，シンプルCPU通信診断は起動できません。

- MELSECNET/H
- シリアルコミュニケーションユニットのマルチドロップ接続
- パソコン用インタフェースボード
- GOT(トランスペアレント機能使用)
- MELSEC-Q/Lシリーズネットワークユニット

エンジニアリングツールのバージョンが古いと，”交信設定”を”要求時”に設定した場合に実行間隔が”0”と表示されるなど，正しく表示されないことがあります。

正しく診断するには，エンジニアリングツールのバージョンを最新にしてください。
