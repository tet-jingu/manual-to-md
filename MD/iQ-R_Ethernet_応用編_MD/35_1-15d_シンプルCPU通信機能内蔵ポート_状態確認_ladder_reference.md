## シンプルCPU通信実行時の動作 (原本 p.233)

### 自局の動作

CPUユニットの動作状態に依存せずに動作するため，停止エラーによるSTOP中もシンプルCPU通信を行います。ただし，初期の通信異常は，該当の設定No.のみ交信を停止し，異常とならなかった設定No.は動作します。

CPUユニットのEND処理のタイミングで，交信相手からの応答があれば，シンプルCPU通信用のシステムエリアへデータ転送を行います。

### 交信相手の動作

交信相手によって動作が異なります。

*1 読出し/書込みの順序は下記です。通信パターン"読出"時: ビットデバイス→ワードデバイス／通信パターン"書込"時: ワードデバイス→ビットデバイス

| 交信相手 | 1設定におけるデータの動作 |
|---|---|
| 三菱iQ-R(内蔵Ethernet)，三菱Q(内蔵Ethernet)，三菱L(内蔵Ethernet)，三菱iQ-F(内蔵Ethernet)，三菱iQ-L(内蔵Ethernet) | 下記に示す場合を除き1設定内でのデータは同じタイミングで送信します。・ビットデバイス(TS，TC，STS，STC，CS，CC)とワードデバイスを同時に指定した場合*1(上記の場合は異なるタイミングでの送信となります。) |
| 三菱Q(Ethernetユニット)，三菱L(Ethernetユニット) | 1設定内でのビットデバイスまたはワードデバイスで指定したデータは，同じタイミングでの送信となります。ただし，ビットデバイスとワードデバイスを同時に設定した場合，ビットデバイスとワードデバイスは異なるタイミングのデータ送信となります。 |
| 三菱A/AnS(Ethernetユニット) | 1設定内でのデータサイズが下記であれば，同じタイミングでの送信となります。*1・"通信パターン"が"書込"時: ビットデバイス640点，ワードデバイス256点以内・"通信パターン"が"読出"時: ビットデバイス2048点，ワードデバイス256点以内 |
| 三菱FX3(Ethernetブロック・アダプタ) | 1設定内でのデータサイズが下記であれば，同じタイミングでの送信となります。*1・"通信パターン"が"書込"時: ビットデバイス160点，ワードデバイス64点以内・"通信パターン"が"読出"時: ビットデバイス512点，ワードデバイス64点以内 |
| SLMP対応機器(QnA互換3Eフレーム) | 1設定内でのビットデバイスまたはワードデバイスで指定したデータは，同じタイミングでの送信となります。ただし，ビットデバイスとワードデバイスを同時に設定した場合，ビットデバイスとワードデバイスは異なるタイミングでのデータとなります。*1 |

### 定期交信停止要求・定期交信再開要求 (原本 p.235)

CPUバッファメモリ上の該当設定No.のシンプルCPU通信状態が下記のいずれかの場合に，該当設定No.の停止要求をOFF→ONすると，交信を停止できます。

 - 3H: 実行中
 - 5H: リトライ中
 - 6H: 監視中

> Point
> - 本設定は，交信設定が"要求時"の場合は無効です。また，交信設定が"定期"の場合でも，シンプルCPU通信状態が上記以外の場合は無効です。
> - 停止要求をOFF→ONすると，次回の実行間隔で送信するタイミングで停止します。そのため，停止要求を受け付けた状態で，交信相手からの応答がない場合，通信タイムアウト時間経過後に停止します。リトライ中は，リトライ回数に依存せずに通信タイムアウト時間経過後に停止します。
> - 停止中に同じ交信相手を設定した他の設定No.で異常となった場合，自身のシンプルCPU通信エラーコードには値が格納されません。

また，CPUバッファメモリ上の該当設定No.のシンプルCPU通信状態が「4H: 停止中」の場合に，該当設定No.の再開要求をOFF→ONすると，交信を再開できます。(状態が「4H: 停止中」以外の場合，再開要求は無効となります。)

> Point
> 再開時に同じ交信相手を設定した他の設定No.で異常となっている場合は再開できません。

#### 例: 設定No.1の交信停止・再開要求時の動作

【図】交信停止・再開要求のタイミングチャート(原本 p.235)

- 定期交信停止要求(Un\G1094.0): プログラムなどでON(停止要求あり) → システムでOFF(交信停止)。
- 定期交信再開要求(Un\G1098.0): プログラムなどでON(再開要求あり) → システムでOFF(交信再開)。
- 実行状態フラグ(Un\G1102.0): 停止要求前はON、交信停止でOFF、交信再開でON。
- シンプルCPU通信状態(Un\G1130): 3H(実行中、END処理単位)→4H(停止中、0)→3H(実行中、END処理単位)。
- 実行間隔(現在値)(Un\G1258): (現在値)→0(停止中)→(現在値)。
