## ”送受信パラメータ設定”画面 (原本 p.378)

各プロトコルに対して，タイムアウト設定と受信時データエリアを設定します。

| 項目 | 内容 | 設定範囲 |
|---|---|---|
| 通信タイムアウト時間 | 交信相手からの応答を待つ時間を設定します。”通信タイムアウト時間”は実行間隔以上となるよう設定してください。”交信設定”が”要求”かつ“通信タイプ”が”受信のみ”の場合のみ0(無限待ち)が設定できます。 | ・10~65535(1ms単位で指定)・0(無限待ち)(デフォルト: 1000) |
| リトライ回数 | 交信相手からの応答なし時，通信タイムアウト時間まで待つ動作を繰り返す回数を設定します。 | 0~255(デフォルト: 3) |
| 異常時監視時間 | 通信異常発生時に監視する時間を設定します。”異常時監視時間”は，”通信タイムアウト時間”より大きくなるように設定してください。”交信設定”が”要求”の場合は設定できません。 | 1~300(1s単位で指定)(デフォルト: 30) |
| 受信システムエリアクリア | プロトコル実行前に，ユニットのシステムエリア(受信データエリア)をクリアするかどうかを選択します。”しない”が選択されている場合，ユニットがプロトコル実行前に受信したデータも，プロトコルの受信対象となります。“通信タイプ”が”受信のみ”の場合は設定できません。 | ・する・しない(デフォルト: する) |

原本の表行数(目視カウント): 4行。上表は全4行を転記。

## ”デバイス一括設定”画面 (原本 p.379)

設定したいプロトコル範囲と設定項目を選択することで任意のデバイスを一括設定できます。

\*1 ”リソース設定”が”通常”の場合は1~256，”拡張1”および”拡張2”の場合は1~512になります。

| 項目 | 内容 | 設定範囲 |
|---|---|---|
| 設定プロトコル番号範囲指定\*1 | 一括設定するプロトコルの開始番号および終了番号を選択します。 | ・1~256・1~512(デフォルト: 1) |
| 先頭デバイス番号 | 一括設定するデバイスの先頭番号を設定します。デバイスが設定されている項目は一括設定を行い，空白の項目は一括設定を行いません。 | 下記の指定可能デバイスを参照してください。247ページ 指定可能デバイス(デフォルト: 空白) |

原本の表行数(目視カウント): 2行。上表は全2行を転記。

## ”デバイス一覧”画面 (原本 p.380)

シンプル機器通信で使用しているデバイスを表示し，デバイスの重複を確認できます。

空欄の場合は，[一覧作成]ボタンをクリックしてください。

”デバイス一覧”画面をフロート表示することで，設定デバイス一覧を確認しながらプログラムを編集できます。

**注意事項**

下記の操作を行った場合，デバイス一覧がクリアされます。

- ”リソース設定”を変更した場合
- ”交信相手設定”の任意のセルを編集した場合
- ”プロトコル設定”画面の[OK]ボタンをクリックした場合
- 他ポートのパラメータを設定し，[適用]ボタンをクリックした場合(RJ71EN71(E+E)のみ)

| 項目 | 内容 |
|---|---|
| [一覧作成]ボタン | 設定デバイスの一覧を作成します。 |
| デバイス | シンプル機器通信で使用しているデバイスを表示します。 |
| 分類 | ”デバイス”が設定されている分類を表示します。 |
| ポート | ”デバイス”が設定されているEthernetポートを表示します。 |
| 設定No. | ”デバイス”が設定されているプロトコルの設定No.を表示します。 |
| プロトコル番号 | ”デバイス”が設定されているプロトコルのプロトコル番号を表示します。 |
| プロトコル名 | ”デバイス”が設定されているプロトコルのプロトコル名を表示します。 |
| パケット番号 | ”デバイス”が設定されているパケットのパケット番号を表示します。”分類”が”変数”以外に設定されているデバイスについては表示されません。・送信: 送信パケットを示します。・受信(n): 受信パケットを示します。(n: 受信パケット番号(1~16)) |
| パケット名 | ”デバイス”が設定されているパケットのパケット名を表示します。”分類”が”変数”以外に設定されているデバイスについては表示されません。 |
| 構成要素番号 | ”デバイス”が設定されている構成要素の構成要素番号を表示します。”分類”が”変数”以外に設定されているデバイスについては表示されません。 |
| 構成要素名 | ”デバイス”が設定されている構成要素の構成要素名を表示します。”分類”が”変数”以外に設定されているデバイスについては表示されません。 |

原本の表行数(目視カウント): 10行。上表は全10行を転記。
