## IPアドレス算出方式 (原本 p.390)

ネットワークNo.と局番をもとに，相手局のIPアドレスを下記算出式から求め，相手先UDPポート番号はEthernet搭載ユニットのシステムで固定のUDPポート番号を使用する方式です。

```
相手局のIPアドレス = (自局のIPアドレス 論理積 CC-Link IEコントローラネットワーク，CC-Link IEフィールドネットワーク，
                       MELSECNET/H，MELSECNET/10 ルーチング用ネットマスクパターン)
                       論理和 (相手先のネットワークNo.，局番)
```

IPアドレス算出方式の変換処理は下記のようになります。

- 他局アクセスの交信要求伝文(コマンドフレーム)を受信すると，Ethernet搭載ユニット内に記憶した交信要求伝文中の相手先のネットワークNo.と局番をもとにIPアドレスを算出し，交信要求伝文を次の局(中継局/相手先局)へ送信します。
- 交信要求伝文に対する応答伝文(レスポンス)は，返信先のIPアドレスと上記記憶データをもとに返信します。

### IPアドレス算出例 (原本 p.390)

自局IPアドレスのクラスにより，論理積，論理和の取り方が違い，次のように計算します。

**(クラスAの場合)**

- 自局IPアドレスが79238102Hのとき
- 他のネットワークのルーチング用ネットマスクパターンがFF000000Hのとき
- 相手先のネットワークNo.が03H，局番が05Hのとき

| 項目 | 値 |
|---|---|
| 自局IPアドレス | 79.23.81.02 |
| ネットマスクパターン(論理積) | FF.00.00.00 |
| = 論理積値 | 79.00.00.00 |
| ネットワークNo.と局番(論理和) | 03.05 |
| = 相手局IPアドレス | 79.00.03.05 |

**(クラスBの場合)**

- 自局IPアドレスが8438FA0AHのとき
- 他のネットワークのルーチング用ネットマスクパターンがFFFF0000Hのとき
- 相手先のネットワークNo.が03H，局番が05Hのとき

| 項目 | 値 |
|---|---|
| 自局IPアドレス | 84.38.FA.0A |
| ネットマスクパターン(論理積) | FF.FF.00.00 |
| = 論理積値 | 84.38.00.00 |
| ネットワークNo.と局番(論理和) | 03.05 |
| = 相手局IPアドレス | 84.38.03.05 |

**(クラスCの場合)**

- 自局IPアドレスがCA65300AHのとき
- 他のネットワークのルーチング用ネットマスクパターンがFFFFFF00Hのとき
- 相手先の局番が02Hのとき(ネットワークNo.は使用しません)

| 項目 | 値 |
|---|---|
| 自局IPアドレス | CA.65.30.0A |
| ネットマスクパターン(論理積) | FF.FF.FF.00 |
| = 論理積値 | CA.65.30.00 |
| 局番(論理和) | 02 |
| = 相手局IPアドレス | CA.65.30.02 |

### IPアドレス構成 (原本 p.391)

**クラスAのIPアドレス構成**

ビット31: クラス、ビット30〜24: ネットワークアドレス、ビット23〜0: ホストアドレス

**クラスBのIPアドレス構成**

ビット31〜30: クラス、ビット29〜16: ネットワークアドレス、ビット15〜0: ホストアドレス

**クラスCのIPアドレス構成**

ビット31〜29: クラス、ビット28〜8: ネットワークアドレス、ビット7〜0: ホストアドレス
