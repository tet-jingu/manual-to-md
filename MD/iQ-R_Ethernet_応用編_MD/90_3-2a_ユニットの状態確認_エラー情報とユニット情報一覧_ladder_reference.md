## 3.2 ユニットの状態確認 (原本 p.402)

Ethernet搭載ユニットの”ユニット診断”画面で下記の機能が使用できます。

## エラー情報 (原本 p.402)

現在発生しているエラーの内容と処置方法を確認します。

| 機能 | 用途 |
|---|---|
| エラー情報 | 現在発生しているエラーの内容と処置方法が表示されます。電源ONの直後に発生したエラーの”発生日時”には，”-”が表示されることがあります。発生日時を確認したい場合は[イベント履歴]ボタンをクリックし，イベント履歴を参照してください。 |
| ユニット情報一覧 | Ethernet搭載ユニットの各種ステータス情報が表示されます。 |
| 補助機能 Ethernet診断 | Ethernetでの異常発生時に，原因を確認してトラブルを解決します。(406ページ ネットワークの状態確認) |

原本の表行数(目視カウント): 3行。上表は全3行を転記。

| 項目 | 内容 |
|---|---|
| 状態 | 重度: ハードウェア異常やメモリ異常などにより，ユニットが動作を停止するエラーです。中度: ユニット動作に関わるパラメータ異常などにより，ユニットが動作を停止するエラーです。軽度: 通信失敗など，ユニットが動作を続行するエラーです。 |
| 詳細情報 | 各エラーの詳細情報が最大３つまで表示されます。 |
| 原因 | エラーの原因となる詳細な内容が表示されます。 |
| 処置方法 | エラーに対する処置方法が表示されます。 |

原本の表行数(目視カウント): 4行。上表は全4行を転記。

## ユニット情報一覧 (原本 p.403)

[ユニット情報一覧]タブに切り替えることで，Ethernet搭載ユニットの各種ステータス情報を確認します。(表示される項目はユニットごとに異なります。)

\*1 ネットワーク種別を”Ethernet”に設定している場合の表示です。

”CC-Link IE Control”に設定している場合は下記を参照してください。

MELSEC iQ-R CC-Link IEコントローラネットワークユーザーズマニュアル(応用編)

”CC-Link IE Field”に設定している場合は下記を参照してください。

MELSEC iQ-R CC-Link IEフィールドネットワークユーザーズマニュアル(応用編)

| 項目 | 内容 |
|---|---|
| LED情報 | Ethernet搭載ユニットのLEDの状態が表示されます。 |
| 個別情報(P1: Ethernet)\*1 ネットワークNo. | 選択したユニットに設定しているネットワークNo.が表示されます。 |
| 個別情報(P1: Ethernet)\*1 局番 | 選択したユニットに設定している局番が表示されます。 |
| 個別情報(P1: Ethernet)\*1 トランジェント伝送グループNo. | 選択したユニットに設定しているトランジェント伝送グループNo.が表示されます。 |
| 個別情報(P1: Ethernet)\*1 送信フレーム設定 | 選択したユニットに設定している送信フレーム設定が表示されます。 |
| 個別情報(P1: Ethernet)\*1 ジャンボフレーム設定 | 選択したユニットに設定しているジャンボフレーム設定が表示されます。 |
| 個別情報(P1: Ethernet)\*1 通信速度設定 | 選択したユニットに設定している通信速度設定が表示されます。 |
| 個別情報(P1: Ethernet)\*1 IPアドレス(第1オクテット)~IPアドレス(第4オクテット) | 選択したユニットに設定しているIPアドレスが表示されます。 |

| 個別情報(P2: Ethernet)\*1 | (P1コネクタと同様) |
