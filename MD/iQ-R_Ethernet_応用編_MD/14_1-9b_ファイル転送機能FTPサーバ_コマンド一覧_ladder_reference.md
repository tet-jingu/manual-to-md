## FTPコマンドの見方 (原本 p.121)

Ethernet搭載ユニットがサポートしている，FTPクライアント(相手機器)側のFTPコマンドで指定するファイルの指定方法について説明します。

CPUユニットでは，ファイルをドライブ名とファイル名に区別して指定します。

FTPでファイルを指定する場合は，下記の並びで対象ファイルを指定してください。*1

*1 デフォルトのディレクトリ区切り文字は「\」です。ディレクトリ区切り文字を「/」としたい場合は，下記を参照してください。(122ページ FTPサーバ機能ファイルパス名切替え)

*2 ドライブ2に格納されたファイルを指定するときのみフォルダ名を指定可能です。

指定形式の[ ]で囲まれた部分については，省略可能を示します。

### ドライブ名(ドライブNo.)

ファイル転送する対象メモリのドライブ名を指定します。

対象メモリおよびドライブ名の対応については，使用するCPUユニットのマニュアルを参照してください。

ドライブ名を省略した場合は，データメモリ(ドライブ4)を指定したことになります。ただし，FTPサーバ機能ファイルパス名切替えが有効な場合は，その設定に従います。(122ページ FTPサーバ機能ファイルパス名切替え)

### フォルダ名，ファイル名，拡張子

フォルダ名およびファイル名については，使用するCPUユニットのマニュアルに記載の規則に従って指定してください。

拡張子はCPUユニットで決められている名前を付けます。

複数のファイルを対象にできるFTPコマンドを使用するときは，ファイル名と拡張子を「*」または「?」でワイルドカード指定します。(FTPクライアントによっては，他にもファイル名に使用できる文字などに制約があります。)

| 項目 | 内容 |
|---|---|
| 指定形式 | [ドライブ名:\]フォルダ名*2\ファイル名.拡張子 |
| 指定例 | `3:\MAINSEQ1.QDR`(ドライブ2以外)／`2:\LOGGING\LOG01\00000001\LOG01_00000001.CSV`(ドライブ2) |
| 指定内容 | 下記を参照: 121ページ ドライブ名(ドライブNo.)，121ページ フォルダ名，ファイル名，拡張子 |

`*`: 「*」を指定した位置から任意の文字例(なしも含む)のすべてのファイルを対象にします。

`?`: 「?」を指定した位置が任意の文字(なしの場合は含まない)のすべてのファイルを対象にします。(「?」は複数使用できます。)

## FTPサーバ機能ファイルパス名切替え (原本 p.122)

CPUユニット(内蔵Ethernetポート部)にて，FTPコマンドで指定するファイルパスのディレクトリの区切り文字を，「\」から「/」へ切り替えることができます。

またファイルパス名におけるドライブNo.の省略を設定することができます。

ディレクトリの区切り文字を「/」に切り替えたあとのCPUユニットのファイル指定方法は下記のとおりです。

 - 「/」へ切り替えたときも，CPUユニットはディレクトリの区切り文字が「\」のコマンドを受信できます。ただし，CPUユニットから送信されるディレクトリの区切り文字は「/」となります。
 - 区切り文字を切り替えた後に再度切替え設定をした場合，あとから設定した内容で切り替わります。
 - Linux標準サポートのFTPクライアントを使用してファイルパス名を指定するFTPコマンドを実行する場合，CPUユニットと使用するパソコンで同じフォルダ構成とする必要があります。

> 制約事項
> 本機能はシーケンサCPUの場合のみ使用できます。本機能を使用する場合，CPUユニットのバージョンを確認してください。(550ページ 機能の追加と変更)

### 特殊リレー/特殊レジスタによる切替え

 - SM1512(FTP サーバ機能ファイルパス名切替設定有効フラグ)をOFF→ONにすると，CPUユニットのファイルパス名のディレクトリ区切り文字が「/」に切り替わります。またSD1512(FTP サーバ機能ファイルパス名切替設定)に設定値を格納していると，ファイルパス名におけるドライブNo.を省略することができます。
 - SM1512がONの間，ディレクトリ区切り文字の切替えが有効です。SM1512をOFFにすると切替えが解除されて，区切り文字が「/」から「\」へ戻ります。
 - 設定エラーのときSM1513(FTP サーバ機能ファイルパス名切替設定エラー)がONになり，SD1513(FTP サーバ機能ファイルパス名切替設定エラー要因)にエラー要因が格納されます。設定エラーがないときはSM1513はOFFになります。
 - SD1514(FTP サーバ機能ファイルパス名切替設定状況)に現在の設定状況が格納されます。SM1512がOFFのとき，SD1514には0が格納されます。

特殊リレーおよび特殊レジスタの詳細については，使用するCPUユニットのマニュアルを参照してください。

> 注意事項
> FTPコマンドの実行中に，SM1512をOFF→ONやON→OFFにしないでください。誤動作の原因となります。

| 切替え方法 | 内容 |
|---|---|
| 特殊リレー/特殊レジスタによる切替え | 特殊リレー SM1512(FTP サーバ機能ファイルパス名切替設定有効フラグ)の操作により，ディレクトリの区切り文字を切り替えます。たとえば，FTPクライアントがLinuxOSのみで，常時ディレクトリの区切り文字を「/」にしたい場合に使用します。 |
| FTPコマンドによる切替え | quoteコマンドにサブコマンド(path-delimiter)を指定することで，ディレクトリの区切り文字を切り替えます。たとえば，FTPクライアントにWindowsとLinuxOSが混在し，クライアント側でアクセスするたびに区切り文字を切り替えたい場合に使用します。 |

| 項目 | 内容 |
|---|---|
| 指定形式 | `[ドライブ名:/]ファイル名.拡張子` |
| 指定例 | `3:/MAINSEQ1.QDR` |

| 特殊リレー | 名称 |
|---|---|
| SM1512 | FTP サーバ機能ファイルパス名切替設定有効フラグ |
| SM1513 | FTP サーバ機能ファイルパス名切替設定エラー |

| 特殊レジスタ | 名称 |
|---|---|
| SD1512 | FTP サーバ機能ファイルパス名切替設定 |
| SD1513 | FTP サーバ機能ファイルパス名切替設定エラー要因 |
| SD1514 | FTP サーバ機能ファイルパス名切替設定状況 |

### FTPコマンドによる切替え (原本 p.123)

 - quote コマンドでpath-delimiter [モード]のサブコマンドを指定して実行すると，CPU ユニットのファイルパス名のディレクトリの区切り文字が「\」から「/」へ切り替わります。[モード]に設定値を入力することでファイルパス名におけるドライブNo.を省略することもできます。
 - path-delimiter off を実行すると，設定が解除されます。
 - path-delimiter status を実行することで，現在の設定を確認できます。

quoteコマンドの詳細は，下記を参照してください。(127ページ Ethernet搭載ユニット専用サブコマンド)

現在の設定は，SM1512(FTP サーバ機能ファイルパス名切替設定有効フラグ)とSD1514(FTP サーバ機能ファイルパス名切替設定状況)でも確認できます。

| FTPコマンド(quoteのサブコマンド) | 機能 |
|---|---|
| path-delimiter | ファイル指定時のファイルパス名の設定を変更します。(コマンド実行後，SM1512がONし，SD1514に現在の設定値が格納されます。) |
| path-delimiter off | ファイル指定時のファイルパス名の設定変更をOFFにします。 |
| path-delimiter status | ファイル指定時のファイルパス名の設定状態を表示します。 |
