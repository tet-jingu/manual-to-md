## データ格納エリア指定の詳細 (原本 p.356)

**”データ数固定/データ数可変”が”データ数固定”の場合**

指定したデバイス番号以降がデータ格納エリアとなります。

- 送信パケットの場合: プログラムにより送信データを格納します。
- 受信パケットの場合: Ethernet搭載ユニットが受信データを格納します。

【図】データ数固定の場合のデータ格納エリア配置(原本 p.356)
- 指定デバイス(+0〜+n、ワード)全体がデータ格納エリア。
- 送信パケット: データ格納エリアの一部(先頭寄り)が送信パケットのデータ格納エリアに対応。
- 受信パケット: 同様に受信パケットのデータ格納エリアに対応。

**”データ数固定/データ数可変”が”データ数可変”の場合**

指定したデバイス番号の先頭1ワードがデータ数格納エリア，指定したデバイス番号+1以降がデータ格納エリアとなります。

【図】データ数可変の場合のデータ格納エリア配置(原本 p.356)
- 指定デバイス+0: データ数格納エリア
- 指定デバイス+1〜+n: データ格納エリア
- 送信パケットの場合: プログラムにより送信データを格納します。
- 受信パケットの場合: Ethernet搭載ユニットが受信データを格納します。

**データ格納エリアの占有サイズ**

データ格納エリアを占有するサイズは，”変換データ型”および”小数点桁”の設定により異なります。

| 変換データ型 | 小数点桁 | 1データあたりのデータ格納エリアの占有サイズ |
|---|---|---|
| ワード | 小数点なし，1~4 | 1ワード |
| ワード | 小数点可変 | 2ワード |
| ダブルワード | 小数点なし，1~9 | 2ワード |
| ダブルワード | 小数点可変 | 4ワード |
| 単精度実数 | 小数点なし，1~6 | 2ワード |
| 単精度実数 | 小数点可変 | 2ワード |
| 倍精度実数 | 小数点なし，1~14 | 4ワード |
| 倍精度実数 | 小数点可変 | 4ワード |

原本の表行数(目視カウント): 8行。上表は全8行を転記。

## 1データあたりのデータ格納エリア構成 (原本 p.357)

1データあたりのデータ格納エリア構成を説明します。

**例: ”変換データ型”: ”ワード”，”小数点桁”: ”小数点なし”または1~4**

【図】データ格納エリア配置(原本 p.357) — 0H: 数値データ(1ワード)のみ。

**例: ”変換データ型”: ”ワード”，”小数点桁”: ”小数点可変”**

【図】データ格納エリア配置(原本 p.357) — 0H: 数値データ、1H: 小数点位置。

小数点位置には，送信/受信データの小数点位置を下表のように格納します。

| 送信/受信データ(桁数が5桁の場合) | 0H: 数値データ | 1H: 小数点位置\*1 |
|---|---|---|
| 12345 | 12345(3039H) | 1(1H) |
| 1234.5 | 12345(3039H) | 10(AH) |
| 123.45 | 12345(3039H) | 100(64H) |
| 12.345 | 12345(3039H) | 1000(3E8H) |
| 1.2345 | 12345(3039H) | 10000(2710H) |

原本の表行数(目視カウント): 5行。上表は全5行を転記。

\*1 送信パケットの場合，小数点位置に表中の値以外を格納するとエラーになります。

**例: ”変換データ型”: ”ダブルワード”，”小数点桁”: ”小数点なし”または1~9**

【図】データ格納エリア配置(原本 p.357) — 0H(L)・1H(H): 数値データ(2ワード)のみ。

**例: ”変換データ型”: ”ダブルワード”，”小数点桁”: ”小数点可変”**

【図】データ格納エリア配置(原本 p.357) — 0H(L)・1H(H): 数値データ、2H(L)・3H(H): 小数点位置。

小数点位置には，送信/受信データの小数点位置を下表のように格納します。

| 送信/受信データ(桁数が10桁の場合) | 0H~1H: 数値データ | 2H~3H: 小数点位置\*1 |
|---|---|---|
| 1234567890 | 1234567890(499602D2H) | 1(1H) |
| 123456789.0 | 1234567890(499602D2H) | 10(AH) |
| 12345678.90 | 1234567890(499602D2H) | 100(64H) |
| 1234567.890 | 1234567890(499602D2H) | 1000(3E8H) |
| (中間の桁位置、省略記号) | ： | ： |
| 1.234567890 | 1234567890(499602D2H) | 1000000000(3B9ACA00H) |

原本の表行数(目視カウント): 6行(中間の省略行「:」を含む、原本どおり)。上表は全6行を転記。

\*1 送信パケットの場合，小数点位置に表中の値以外を格納するとエラーになります。

**例: ”変換データ型”: ”単精度実数”**

【図】データ格納エリア配置(原本 p.358) — 0H(L)・1H(H): 数値データ(2ワード)のみ。小数点桁の設定にかかわらず単精度実数データが2ワードに格納される。

**例: ”変換データ型”: ”倍精度実数”**

【図】データ格納エリア配置(原本 p.358) — 0H(L)・1H・2H・3H(H): 数値データ(4ワード)のみ。小数点桁の設定にかかわらず倍精度実数データが4ワードに格納される。
