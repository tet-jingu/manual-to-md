## Ethernet搭載ユニット専用サブコマンド (原本 p.127)

FTPコマンドのquoteコマンドに付加して送信するEthernet搭載ユニット専用サブコマンドについて説明します。

### change

機能: CPUユニットに格納されているファイルの属性を表示，または変更します。

指定形式1(属性を表示するとき): `quote change ファイルパス名`

正常終了時の実行結果として，下記のいずれかが表示されます。
 - 指定ファイルが読出し専用(Read Only)ファイルのとき: `-----R`
 - 指定ファイルが書込みおよび読出し可能なファイルのとき: `-----W`

指定形式2(属性を変更するとき): `quote change ファイルパス名 属性`

属性は下記のいずれかで指定します。
 - 読出し専用(Read Only)ファイルにするとき: `r`
 - 書込みおよび読出し可能なファイルにするとき: `w`

指定例1: SDメモリカードに格納されているファイルの属性を表示させる場合 `quote change 2:\PRG1.PRG`

指定例2: SDメモリカードに格納されているファイルの属性を変更する場合 `quote change 2:\PRG1.PRG r`

### cpuchg

機能: マルチCPUシステム構成時のアクセス先CPUユニットを指定します。または，現在のアクセス先CPUユニットを表示します。

指定形式: `quote cpuchg [アクセス先CPUユニット]`

アクセス先CPUユニット: ファイルアクセスを行いたいCPUユニットを指定する。指定方法:
 - 未入力: 現在のアクセス先CPUユニットを確認する。
 - controlPLC: アクセス先CPUユニットを管理CPUに指定する。
 - no1: アクセス先CPUユニットをCPU1号機に指定する。
 - no2: アクセス先CPUユニットをCPU2号機に指定する。
 - no3: アクセス先CPUユニットをCPU3号機に指定する。
 - no4: アクセス先CPUユニットをCPU4号機に指定する。

正常終了時の実行結果:
 - アクセス先CPUユニットを設定するとき: `200 Command Okey`
 - アクセス先CPUユニットを表示するとき: `200 Target cpu is "アクセス先CPUユニット"`

指定したアクセス先CPUユニットが存在しない場合: `557 Cpu not found`

指定例1: アクセス先CPUユニットを管理CPUに指定する場合 `quote cpuchg controlPLC`

指定例2: 現在設定されているアクセス先CPUユニットを表示する場合 `quote cpuchg`

注意: RJ71EN71へのopen/userコマンド実行によるログイン後のアクセス先CPUユニットは，RJ71EN71の管理CPUです。

### fastmode (原本 p.128)

機能: 高速書込みモードを設定します。高速書込みモード設定時には，下記の処置が行われないため，プログラム(.PRG)やFBファイル(.PFB)の"$MELPRJ$"フォルダへの書込みを高速にできます。
 - 作業用テンポラリファイル(FTP_I***_#.TMP)の作成
 - プログラムキャッシュメモリに書き込まれたファイルのプログラムメモリへの自動転送

指定形式: `quote fastmode [モード]`

モード: 設定または解除を指定します。
 - on: 設定
 - off: 解除

正常終了時の実行結果:
 - 高速書込みモードを設定するとき: `200 Command successful`
 - 高速書込みモードを解除するとき: `200 Command successful`
 - 高速書込みモードが設定されている場合に状態を表示するとき: `200 Fastmode is ON`
 - 高速書込みモードが解除されている場合に状態を表示するとき: `200 Fastmode is OFF`

指定例1: 高速書込みモードを設定する場合 `quote fastmode on`

指定例2: 高速書込みモードを解除する場合 `quote fastmode off`

指定例3: 高速書込みモードの状態を表示する場合 `quote fastmode`

注意:
 - CPUユニットへログインしたとき，高速書込みモードは解除されます。
 - 高速書込みモード設定時は，ファイル書込みコマンド(put，mput)，ファイル削除コマンド(delete，mdelete)，ファイル名変更コマンド(rename)でプログラムキャッシュメモリの内容を変更した場合，プログラムメモリへの自動転送が実施されません。そのため，プログラムキャッシュメモリの内容変更後は，プログラムメモリへの転送コマンド(quote pm-write)を実行してください。なお，プログラムキャッシュメモリの内容変更後，プログラムメモリへの転送コマンドを実行せずにリセットした場合は，不正なプログラムファイルが残ります。その場合はファイル削除コマンド(delete，mdelete)にて不正なプログラムファイルを削除し，再度書込みを実施してください。

### passwd-rd

機能: ファイル転送の対象ファイルに登録されている読出しパスワード(ファイルパスワード)をEthernet搭載ユニットに設定します。またはFTPに設定されている読出しパスワードを表示/クリアします。

本コマンドは，ファイル転送の対象ファイルに読出しパスワードが登録されている場合にのみ使用してください。指定ファイルへアクセスするときに，CPUユニットがパスワードチェックを行います。

指定形式: `quote passwd-rd [読出しパスワード]`

正常終了時の実行結果:
 - 読出しパスワードを設定するとき: `200 Command successful`
 - 読出しパスワードを表示するとき: `200 Read-password is "読出しパスワード"`
 - 読出しパスワードをクリアするとき: `200 Command successful`
 - 読出しパスワードが設定されていない状態で表示したとき: `200 Read-password is not set.`

指定例1: 読出しパスワード(ABCD1234@efgh)を指定する場合 `quote passwd-rd ABCD1234@efgh`

指定例2: 現在，FTPに設定されている読出しパスワードを表示する場合 `quote passwd-rd`

指定例3: 現在，FTPに設定されている読出しパスワードをクリアする場合 `quote passwd-rd c` または `quote passwd-rd C`

注意:
 - Ethernet搭載ユニットのFTPには読出しパスワードを1つ設定できます。ファイル転送の対象ファイルが変わる場合，切換え先のファイルも読出しパスワードが登録されているときは，対象ファイルの読出しパスワードを再設定してください。
 - Ethernet搭載ユニットへログインしたとき，読出しパスワードは初期化(クリア)されます。

### passwd-wr (原本 p.129)

機能: ファイル転送の対象ファイルに登録されている書込みパスワード(ファイルパスワード)をEthernet搭載ユニットに設定します。またはFTPに設定されている書込みパスワードを表示/クリアします。

本コマンドは，ファイル転送の対象ファイルに書込みパスワードが登録されている場合にのみ使用してください。指定ファイルへアクセスするときに，CPUユニットがパスワードチェックを行います。

指定形式: `quote passwd-wr [書込みパスワード]`

正常終了時の実行結果:
 - 書込みパスワードを設定するとき: `200 Command successful`
 - 書込みパスワードを表示するとき: `200 Write-password is "書込みパスワード"`
 - 書込みパスワードをクリアするとき: `200 Command successful`
 - 書込みパスワードが設定されていない状態で表示したとき: `200 Write-password is not set.`

指定例1: 書込みパスワード(ABCD1234@efgh)を指定する場合 `quote passwd-wr ABCD1234@efgh`

指定例2: 現在，FTPに設定されている書込みパスワードを表示する場合 `quote passwd-wr`

指定例3: 現在，FTPに設定されている書込みパスワードをクリアする場合 `quote passwd-wr c` または `quote passwd-wr C`

注意:
 - Ethernet搭載ユニットのFTPには書込みパスワードを1つ設定できます。ファイル転送の対象ファイルが変わる場合，切換え先のファイルも書込みパスワードが登録されているときは，対象ファイルの書込みパスワードを再設定してください。
 - Ethernet搭載ユニットへログインしたとき，書込みパスワードは初期化(クリア)されます。

### password-unlock

機能: CPUユニットに設定されているリモートパスワードを指定して，アンロック処理を行います。本コマンドは，FTP交信ポートがリモートパスワードチェックの対象ポートに指定されている場合に使用します。

指定形式: `quote password-unlock [リモートパスワード]`

 - リモートパスワード: CPUユニットのパラメータに設定されているリモートパスワードを指定。

正常終了時の実行結果: `200 Command Okey`

リモートパスワードが一致しない場合: `556 Password Error`

リモートパスワードのアンロック処理が行われる前に，他コマンドを要求した場合: `555 Password Locked`

指定例: リモートパスワード(123456)を指定する場合 `quote password-unlock 123456`

注意:
 - ログインしたとき，FTP交信ポートがリモートパスワードチェックの対象ポートに指定されている場合は，ロック状態になっています。
 - 各種FTP操作の前に本コマンドを実行してアンロック処理を行うことにより，CPUユニットのファイル操作が可能になります。
 - FTP交信ポートがリモートパスワードチェックの対象ポートに指定されていない場合に，リモートパスワードのアンロック処理を行ったときは正常完了します。

### password-lock

機能: CPUユニットに設定されているリモートパスワード機能のロック処理を行います。本コマンドは，FTP交信ポートがリモートパスワードチェックの対象ポートに指定されている場合に実行します。

指定形式: `quote password-lock`

正常終了時の実行結果: `200 Command Okey`

指定例: ロックする場合 `quote password-lock`

### path-delimiter (原本 p.130)

機能: ファイル指定時のファイルパス名の区切りの設定を変更します。また，モードの指定によりドライブNo.を省略することができます。

指定形式: `quote path-delimiter [モード]`

モード: 下記の16進数4桁で設定します。
 - `0000`または省略: ファイルパス名のディレクトリ区切り文字を「/」に設定します。(クライアントがLinuxOS等の場合)
 - `0022`: ファイルパス名のディレクトリ区切り文字を「/」に設定し，FTPクライアントからのファイルパス指定において，ドライブNo.の省略が可能になります。省略した際のドライブNo.は，ドライブ2(SDメモリカード)になります。
 - `0032`: ファイルパス名のディレクトリ区切り文字を「/」に設定し，FTPクライアントからのファイルパス指定において，ドライブNo.の省略が可能になります。省略した際のドライブNo.は，ドライブ3(デバイス/ラベルメモリ)になります。
 - `0042`: ファイルパス名のディレクトリ区切り文字を「/」に設定し，FTPクライアントからのファイルパス指定において，ドライブNo.の省略が可能になります。省略した際のドライブNo.は，ドライブ4(データメモリ)になります。

ドライブNo.省略設定で，ファイルパス名にドライブNo.指定のあるコマンドをCPUユニットが受信したとき，コマンドで指定されたドライブNo.を優先して動作します。

正常終了時の実行結果: `200 path-delimiter is ON[モード]`

モードの設定値が範囲外のときは: `504 Parameter not accepted, not implemented.`

設定を解除する場合は，`path-delimiter off`を使用します。

指定例1: ディレクトリの区切り文字を「/」に設定する場合 `quote path-delimiter 0000`

指定例2: ディレクトリの区切り文字を「/」で，ファイルパス名のドライブNo.を省略する場合
 - `quote path-delimiter 0022` … ドライブ2の場合
 - `quote path-delimiter 0032` … ドライブ3の場合
 - `quote path-delimiter 0042` … ドライブ4の場合

### path-delimiter off

機能: path-delimiterによるファイルパス名の設定変更を解除します。

指定形式: `quote path-delimiter off`

実行結果: `200 path-delimiter is OFF`

### path-delimiter status

機能: ファイル指定時のファイルパス名の設定状態を表示します。

指定形式: `quote path-delimiter status`

正常終了時の実行結果:
 - 設定ON時: `200 path-delimiter is ON(モード)`
 - 設定OFF時: `200 path-delimiter is OFF`

注意: 設定ON時の"ON(モード)"には16進数4桁で設定値が表示されます。

### run

機能: CPUユニットをRUN状態(リモートRUN)にします。RUN状態にする際に，デバイスメモリのクリアを指定することができます。

指定形式: `quote run [モード [クリアモード]]`

モード: リモートRUNを強制実行するか否かを指定
 - 0: 通常RUN(デフォルト)
 - 1: 強制RUN

クリアモード: リモートRUN時の演算開始時に，CPUユニットのデバイスメモリのクリア(初期化)処理を指定
 - 0: デバイスをクリアしない(デフォルト)
 - 1: ラッチ範囲以外をクリアする
 - 2: ラッチ範囲を含めたすべてをクリアする

正常終了時の実行結果: `200 Command successful`

指定例1: 通常RUN，デバイスメモリをクリアしないを指定して，リモートRUNさせる場合 `quote run`

指定例2: 強制RUN，デバイスメモリをクリアしないを指定して，リモートRUNさせる場合 `quote run 1`

指定例3: 強制RUN，デバイスメモリはラッチ範囲以外をクリアするを指定して，リモートRUNさせる場合 `quote run 1 1`

注意:
 - 強制RUNはCPUユニットをリモートSTOPした機器のトラブルにより，リモートRUNができない場合，他の機器で強制的にリモートRUNをするときのみ使用します。通常RUNでは，他機器がSTOP/PAUSE状態にしているユニットを，RUN状態にできません。
 - クリアモードによる演算開始時のデバイスメモリのクリアは，システムで取り決めて指定してください。CPUユニットは指定されたクリアを行った後，デバイス初期値の設定に従いRUNします。

### status (原本 p.131)

機能: CPUユニットの動作情報を表示します。ファイル転送を実行する際に，動作情報を確認するためのコマンドです。

指定形式: `quote status`

正常終了時の実行結果:
 - CPUユニットがRUN状態のとき: `"RUN"`
 - CPUユニットがSTOP状態のとき: `"STOP"`
 - CPUユニットがPAUSE状態のとき: `"PAUSE"`

### stop

機能: CPUユニットをSTOP状態(リモートSTOP)にします。

指定形式: `quote stop`

正常終了時の実行結果: `200 Command successful`

注意: プログラムメモリには，本コマンドでCPUユニットをSTOP状態にしてから書き込んでください。

### pm-write

機能: プログラムキャッシュメモリに書き込んだファイルを，電源OFF時も保持するためにプログラムメモリに転送します。

指定形式: `quote pm-write`

正常終了時の実行結果: `200 Command successful`

注意:
 - MELSEC iQ-RシリーズのCPUユニットでは，ファイルをプログラムキャッシュメモリに書き込んだ後，自動的にプログラムメモリに転送するため，本コマンドを使用しなくても電源OFF時にファイルを保持できます。MELSEC-Qシリーズからの置換え時にFTPクライアントのプログラムで本コマンドを使用していても，プログラムを変更することなく使用できます。
 - CPUユニットをSTOP状態にしてから書き込んでください。
