## 変換内容がHEX→ASCII 16進数／ASCII 16進数→HEXの場合の動作 (原本 p.359)

【図】変換データ型が”ワード”または”ダブルワード”の場合の動作フロー(原本 p.359, RJ71EN71内部処理)

**データ送信(”0123,”を送信する例)**

1. CPUデバイス/GデバイスからD0=123H(変換データ型が”ワード”の場合)を取得。送信データ(数値データ)とする。
2. 送信データのバイナリ→ASCII変換: ”123”←123H
3. 桁埋め文字付加: 桁数が”4”，桁埋め文字が”0”の場合、桁数不足(桁文字: 0)または桁数不足(桁文字: 半角スペース)で埋め、”桁数満足/桁数可変”ならそのまま。”0123”←”123”
4. 区切り文字付加: 区切り文字が”半角カンマ”の場合、”0123,”←”0123”
5. データ送信: ”0123,”

(データ数/最大データ数の設定により、上記2〜4のブロックを繰り返す)

**データ受信(”0123,”を受信する例)**

1. データ受信: ”0123,”
2. 区切り文字削除: 区切り文字が”半角カンマ”の場合、”0123”→”0123,”(区切り文字を除去)
3. 桁埋め文字削除: 桁数が”4”，桁埋め文字が”0”の場合、”123”→”0123”(桁埋め文字を除去。桁埋め文字なし・桁数可変の場合はスキップ)
4. 受信データのASCII→バイナリ変換: 123H→”123”
5. CPUデバイス/Gデバイスへ格納: D0=123H(変換データ型が”ワード”の場合)

【図】変換データ型が”単精度実数”または”倍精度実数”の場合の動作フロー(原本 p.359、送信例”00000125,”/受信例”00000125,”)

- 単精度実数の場合はD0,D1の2ワード(例: 00000125H)を対象に、同様のバイナリ→ASCII変換／桁埋め文字付加／区切り文字付加の流れで”00000125,”を送受信する。桁数が”8”，桁埋め文字が”0”の場合の例。
- 送信: ”00000125,”←”00000125”←”125H”(D0,D1=00000125H)
- 受信: ”00000125,”→”00000125”→”125”→”125H”(D0,D1=00000125H)

## 変換内容がHEX→ASCII 10進数／ASCII 10進数→HEXの場合の動作 (原本 p.360)

【図】変換データ型が”ワード”または”ダブルワード”の場合の動作フロー(原本 p.360、送信/受信例”-__1.23,”。”_”は半角スペースを表す)

**データ送信**

1. CPUデバイス/GデバイスからD0=-123(FF85H)を取得(変換データ型が”ワード”，符号有無が”符号なし”以外の場合)。
2. ASCII10進(符号なし)またはASCII10進(符号あり)への送信データのバイナリ→ASCII変換、符号文字付加: ”-123”←-123
3. 小数点付加: 小数点桁が”2”の場合、”-1.23”←”-123”
4. 桁埋め文字付加: 桁数が”5”，桁埋め文字が”半角スペース”の場合(桁数不足(桁文字:0)/桁数不足(桁文字:半角スペース)/桁数満足桁数可変)、”-__1.23”←”-1.23”
5. 区切り文字付加: 区切り文字が”半角カンマ”の場合、”-__1.23,”←”-__1.23”
6. データ送信: ”-__1.23,”

**データ受信**(送信と逆の手順: 区切り文字削除→桁埋め文字削除→小数点削除→ASCII→バイナリ変換(”符号あり・正の符号文字(なし)”以外を設定した場合は符号文字削除)→CPUデバイス/Gデバイスへ格納。”-__1.23,”→”-__1.23”→”-1.23”→”-123”→D0=-123(FF85H))

【図】変換データ型が”単精度実数”または”倍精度実数”の場合の動作フロー(原本 p.360、送信/受信例”-__1.25,”)

- 単精度実数の場合、小数点桁が”2”，桁数が”5”，桁埋め文字が”半角スペース”の設定で、D0,D1=-1.25(BFA00000H)を”-__1.25,”に変換して送信、または逆に受信して格納する。

## 桁埋め文字について (原本 p.361)

送信時は”桁数”で指定した桁数に満たない場合，”桁埋め文字”で指定したデータを上位に埋めます。

受信時は”桁埋め文字”の指定に関係なく，”0”，”_(スペース)”どちらの場合でも桁埋め文字として処理を行います。

”桁数”の指定が6桁の場合は，下記のとおりです。(表中の”_”はスペースを表します)

| 受信データ | 動作 |
|---|---|
| 000120 | 先頭3桁を桁埋め文字とする。 |
| __0120 | 先頭3桁を桁埋め文字とする。 |
| 0_0120 | 先頭3桁を桁埋め文字とする。 |
| ___120 | 先頭3桁を桁埋め文字とする。 |
| _.00120 | 先頭3桁を桁埋め文字とする。 |
| 00012_ | 照合不一致とする。 |
| ___12_ | 照合不一致とする。 |
| 0001_0 | 照合不一致とする。 |
| 0._1200 | 照合不一致とする。 |
| _(スペースのみ) | 照合不一致とする。 |

原本の表行数(目視カウント): 10行。上表は全10行を転記。
