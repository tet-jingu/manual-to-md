## ヒストリカルグラフ表示部品(WSHstgrp) (原本 p.153)

デバイス値を時系列の折れ線グラフで表示します。デバイス値を更新周期毎に読み出し，レコード数到達後は，古いレコードを消しながら表示を左へシフトします。

【図】ヒストリカルグラフ表示部品の座標構成(原本 p.153)。画面上でxPos,yPosを起点に、grWidth×grHeightのグラフ領域(upperMargin/lowerMargin/leftMargin/rightMarginで余白調整)があり、縦軸upper(上限)〜lower(下限)、横軸に日時(例: 2018-04-30 00:56:38 〜 2018-04-30 00:57:58)、背景色grBkCol、グラフ線色grElm[0].lnCol、文字色dispCol、横軸本数xLine、レコード数pointNumで折れ線グラフが表示される。

 - (1) 更新周期分
 - (2) 更新周期分が，表示範囲外となります。

grElm[n]は，表示したいデバイスの分だけ設定します。(n: 0~31)

凡例: ○=必須，ー=任意

| パラメータ | 項目 | 設定内容 | 設定の要否 |
|---|---|---|---|
| grElmNum | グラフ要素数 | 1~32 | ○ |
| devFormat | デバイスのデータ形式 | 0: 16bit符号付き／1: 16bit符号なし／2: 32bit符号付き／3: 32bit符号なし／4: 単精度実数／5: 倍精度実数／6: ビット | ○ |
| grElm[0].devName | デバイス名 | デバイス種別 + デバイス番号 | ○ |
| grElm[0].lnCol | グラフ線色 | RGB値またはカラー名。例: #FF0000(RGB値)，red(カラー名) | ー |
| grElm[1].devName | デバイス名 | デバイス種別 + デバイス番号 | ー |
| grElm[1].lnCol | グラフ線色 | RGB値またはカラー名 | ー |
| ⋮ | (grElm[2]〜grElm[30]も同様のパターン) | | ー |
| grElm[31].devName | デバイス名 | デバイス種別 + デバイス番号 | ー |
| grElm[31].lnCol | グラフ線色 | RGB値またはカラー名 | ー |
| grBkCol | グラフ背景色 | RGB値またはカラー名 | ー |
| dspCol | 文字色 | RGB値またはカラー名 | ー |
| pointNum | レコード数 | 5~100 | ○ |
| upper | 上限値 | 指定したデータ形式の範囲内で任意の数値(10進数) | ○ |
| lower | 下限値 | 同上 | ○ |
| yLine | 縦軸間隔(レコード) | 0~99 | ○ |
| xLine | 横軸の本数 | 同上 | ○ |
| grHeight | グラフ高さ | 正の実数(px単位) | ○ |
| grWidth | グラフ幅 | 同上 | ○ |
| xPos | X座標 | ヒストリカルグラフ表示部品左上端の横座標(px単位) | ー |
| yPos | Y座標 | ヒストリカルグラフ表示部品左上端の縦座標(px単位) | ー |
| rightMargin | 右余白 | 正の実数(px単位)(省略時は0) | ー |
| leftMargin | 左余白 | 同上 | ー |
| upperMargin | 上余白 | 同上 | ー |
| lowerMargin | 下余白 | 同上 | ー |

原本の表行数(目視カウント): grElmNum〜devFormatの2行 + grElm[0]〜grElm[31]各2行(64行) + grBkCol〜lowerMarginの13行 = 79行。上表はgrElm[0]・grElm[1]・grElm[31]を代表として全項目を転記し，grElm[2]〜grElm[30]は同一パターンの反復として注記した。

> 注意事項
> - 必須パラメータはすべて記述してください。必須パラメータの記述がない場合，または設定値が範囲外の場合はエラーが発生します。
> - ヒストリカルグラフ部品で扱う数値は10進数固定です。
> - 通信負荷の高い状態が続くと，デバイスの値を取りこぼす場合があります。

## 書込みボタン部品(WSWtrBtn) (原本 p.155)

指定デバイスに，指定した値を書き込みます。

【図】書込みボタン部品の座標構成(原本 p.155)。画面上でxPos,yPosを起点に、btnWidth×btnHeightのボタン(クラス要素wrBtn、表示テキストbtnTxt「設定」の例)が配置される。

凡例: ○=必須，ー=任意

| パラメータ | 項目 | 設定内容 | 設定の要否 |
|---|---|---|---|
| devName | デバイス名 | デバイス種別 + デバイス番号 | ○ |
| devBase | デバイスの進数 | K: 10進数／H: 16進数／B: 2進数 | ○ |
| devFormat | デバイスのデータ形式 | 0: 16bit符号付き／1: 16bit符号なし／2: 32bit符号付き／3: 32bit符号なし／4: 単精度実数／5: 倍精度実数／6: ビット | ○ |
| wrVal | 書込み値 | 設定範囲は，デバイスの進数，データ形式による。入力値は文字列で指定します。例: wrVal: '1' | ○ |
| wrBtn | 書込みボタン | class要素名。スタイルシートのセレクタに使用します。 | ー |
| btnTxt | ボタン上に表示するテキスト | 任意 | ー(省略時は空白を表示) |
| btnWidth | ボタンの幅 | 正の実数(px単位) | ○ |
| btnHeight | ボタンの高さ | 同上 | ○ |
| wrComfirm | 書込み確認メッセージ | 0: 表示しない／1: 表示する | ー(省略時は0) |
| language | メッセージ言語 | 0: 日本語／1: 英語／2: 中国語(簡体字) | ー(省略時は1) |
| xPos | X座標 | 書込みボタン部品左上端の横座標(px単位) | ー |
| yPos | Y座標 | 書込みボタン部品左上端の縦座標(px単位) | ー |

原本の表行数(目視カウント): 12行。上表は全12行を転記。

> 注意事項
> - 必須パラメータはすべて記述してください。必須パラメータの記述がない場合，または設定値が範囲外の場合はエラーが発生します。
> - 書込みボタンの指定がない場合，UserWebStyle.cssで指定しているデフォルトのスタイルになります。

## ログオフボタン部品(WSLogoutBtn) (原本 p.156)

ログオフするためのボタンを配置します。ログオフボタンをクリックすると，ユーザ用ログインページ(Log-in_User.html)が表示されます。

【図】ログオフボタン部品の座標構成(原本 p.156)。画面上でxPos,yPosを起点に、btnWidth×btnHeightのボタン(クラス要素logOutBtn、表示テキストbtnTxt「ログオフ」の例)が配置される。

凡例: ○=必須，ー=任意

| パラメータ | 項目 | 設定内容 | 設定の要否 |
|---|---|---|---|
| logOutBtn | ログオフボタン | ボタン部品のclass要素名(スタイルシートのセレクタに使用します。) | ー |
| btnTxt | ボタン上に表示するテキスト | 任意 | ー(省略時は空白を表示) |
| btnWidth | ボタンの幅 | 正の実数(px単位) | ○ |
| btnHeight | ボタンの高さ | 同上 | ○ |
| xPos | X座標 | ログオフボタン左上端の横座標(px単位) | ー |
| yPos | Y座標 | ログオフボタン左上端の縦座標(px単位) | ー |

原本の表行数(目視カウント): 6行。上表は全6行を転記。

> 注意事項
> - 必須パラメータはすべて記述してください。必須パラメータの記述がない場合，または設定値が範囲外の場合はエラーが発生します。
> - ログオフボタン部品を使用する場合，必ずユーザ用ログインページ(Log-in_User.html)をSDメモリカードに格納しておいてください。
> - ログオフボタンの指定がない場合，UserWebStyle.cssで指定しているデフォルトのスタイルになります。
