## 図形表示部品(WSFigure) (原本 p.150)

デバイス値が設定した範囲の値になったときに，指定した色で図形を表示できます。デバイス値の監視は定周期で実行されます。

### figType = 'Oval' (だ円)の場合

【図】だ円図形の座標構成(原本 p.150)。画面上でxPos,yPosを起点に、figWidth×figHeightのだ円が配色defColで表示される。range[n].high≥現在値≥range[n].lowの場合、だ円の色がrange[n].colに変わる。

### figType = 'Rect' (長方形)の場合

【図】長方形図形の座標構成(原本 p.150)。画面上でxPos,yPosを起点に、figWidth×figHeightの長方形が配色defColで表示される。

### figType = 'Tri' (三角形)の場合

図形の高さ(figHeight)を負数で設定すると，下向きの三角形が表示されます。

【図】三角形図形の座標構成(原本 p.150)。画面上でxPos,yPosを起点に、figWidth×figHeightの三角形が配色defColで表示される。

range[n]は，表示させたい表示色の範囲分だけ設定します。(n: 0~4)

凡例: ○=必須，ー=任意

| パラメータ | 項目 | 設定内容 | 設定の要否 |
|---|---|---|---|
| devName | デバイス名 | デバイス種別 + デバイス番号 | ○ |
| devFormat | デバイスのデータ形式 | 0: 16bit符号付き／1: 16bit符号なし／2: 32bit符号付き／3: 32bit符号なし／4: 単精度実数／5: 倍精度実数／6: ビット | ○ |
| figType | 図形の種類 | Oval: だ円(円を指定する場合，図形の高さ = 幅に設定)／Rect: 長方形(正方形を指定する場合，図形の高さ = 幅に設定)／Tri: 三角形 | ○ |
| figHeight | 図形の高さ | 実数(px単位)。負数を設定した場合は，絶対値として扱われます。 | ○ |
| figWidth | 図形の幅 | 同上 | ○ |
| defCol | デフォルトの表示色 | RGB値またはカラー名(デバイス値が設定範囲外のときに表示されます。) | ○ |
| rangeNum | 設定範囲個数 | 1~5 | ○ |
| range[0].low | 設定範囲1の下限 | 指定したデータ形式の範囲内で任意の数値(10進数) | ○ |
| range[0].high | 設定範囲1の上限 | 同上 | ○ |
| range[0].col | 設定範囲1内の時の表示色 | RGB値またはカラー名 | ○ |
| range[1].low | 設定範囲2の下限 | 指定したデータ形式の範囲内で任意の数値(10進数) | ー |
| range[1].high | 設定範囲2の上限 | 同上 | ー |
| range[1].col | 設定範囲2内の時の表示色 | RGB値またはカラー名 | ー |
| ⋮ | (range[2]〜range[3]も同様のパターン) | | ー |
| range[4].low | 設定範囲5の下限 | 指定したデータ形式の範囲内で任意の数値(10進数) | ー |
| range[4].high | 設定範囲5の上限 | 同上 | ー |
| range[4].col | 設定範囲5内の時の表示色 | RGB値またはカラー名 | ー |
| xPos | X座標 | 図形表示部品左上端の横座標(px単位) | ー |
| yPos | Y座標 | 図形表示部品左上端の縦座標(px単位) | ー |

原本の表行数(目視カウント): devName〜rangeNumの7行 + range[0]〜range[4]各3行(15行) + xPos/yPosの2行 = 24行。上表はrange[0]・range[1]・range[4]を代表として全項目を転記し，range[2]〜range[3]は同一パターンの反復として注記した。

> 注意事項
> - 必須パラメータはすべて記述してください。必須パラメータの記述がない場合，または設定値が範囲外の場合はエラーが発生します。
> - 設定範囲が重複している場合，設定範囲の若い番号の図形を表示します。例えばデバイス値が設定範囲1と設定範囲2の両方にある場合，設定範囲1の表示となります。

## 画像表示部品(WSPicture) (原本 p.152)

デバイス値が設定した範囲の値になったときに，指定した画像ファイルを表示できます。デバイス値は定周期で監視します。

【図】画像表示部品の座標構成(原本 p.152)。画面上でxPos,yPosを起点に、pictWidth×pictHeightの範囲にデフォルト画像defPicture(「STOP」の例)が表示される。range[n].high≥現在値≥range[n].lowの場合、range[n].pictureで指定した画像(「RUN」の例)に切り替わる。

range[n]は，画像を表示させたい範囲の分だけ設定します。(n: 0~4)

凡例: ○=必須，ー=任意

| パラメータ | 項目 | 設定内容 | 設定の要否 |
|---|---|---|---|
| devName | デバイス名 | デバイス種別 + デバイス番号 | ○ |
| devFormat | デバイスのデータ形式 | 0: 16bit符号付き／1: 16bit符号なし／2: 32bit符号付き／3: 32bit符号なし／4: 単精度実数／5: 倍精度実数／6: ビット | ○ |
| pictHeight | 画像ファイル表示範囲の高さ | 実数(px単位)。負数を設定した場合は，絶対値として扱われます。 | ○ |
| pictWidth | 画像ファイル表示範囲の幅 | 同上 | ○ |
| defPicture | デフォルトの表示画像ファイル名 | 拡張子: .jpg，.jpeg，.gif，.png(デバイス値が設定範囲外のときに表示されます。) | ○ |
| rangeNum | 設定範囲個数 | 1~5 | ○ |
| range[0].low | 設定範囲1下限 | 指定したデータ形式の範囲内で任意の数値(10進数) | ○ |
| range[0].high | 設定範囲1上限 | 同上 | ○ |
| range[0].picture | 設定範囲1内の時の表示画像ファイル名 | 拡張子: .jpg，.jpeg，.gif，.png | ○ |
| range[1].low | 設定範囲2下限 | 指定したデータ形式の範囲内で任意の数値(10進数) | ー |
| range[1].high | 設定範囲2上限 | 同上 | ー |
| range[1].picture | 設定範囲2内の時の表示画像ファイル名 | 拡張子: .jpg，.jpeg，.gif，.png | ー |
| ⋮ | (range[2]〜range[3]も同様のパターン) | | ー |
| range[4].low | 設定範囲5下限 | 指定したデータ形式の範囲内で任意の数値(10進数) | ー |
| range[4].high | 設定範囲5上限 | 同上 | ー |
| range[4].picture | 設定範囲5内の時の表示画像ファイル名 | 拡張子: .jpg，.jpeg，.gif，.png | ー |
| xPos | X座標 | 図形表示範囲左上端の横座標(px単位) | ー |
| yPos | Y座標 | 図形表示範囲左上端の縦座標(px単位) | ー |

原本の表行数(目視カウント): devName〜rangeNumの6行 + range[0]〜range[4]各3行(15行) + xPos/yPosの2行 = 23行。上表はrange[0]・range[1]・range[4]を代表として全項目を転記し，range[2]〜range[3]は同一パターンの反復として注記した。

> 注意事項
> - 必須パラメータはすべて記述してください。必須パラメータの記述がない場合，または設定値が範囲外の場合はエラーが発生します。
> - 1画面内の画像ファイルの合計サイズは，100Kバイト以下を目安としてください。
> - 設定範囲が重複している場合，設定範囲の若い番号の画像を表示します。例えばデバイス値が設定範囲1と設定範囲2の両方にある場合，設定範囲1の表示となります。
