## 1.9 ファイル転送機能(FTPサーバ) (1.9 / 原本 p.115)

相手機器との間でファイルを転送するためのプロトコルであるFTP(File Transfer Protocol)のサーバ機能をサポートしています。FTPクライアント機能を備えた相手機器は，CPUユニット内のファイルに簡単に直接アクセスできます。

FTPクライアント機能を備えた相手機器からCPUユニットのファイルに対して，下記の操作を行うことができます。

 - CPUユニットからのファイルの読出し(ダウンロード)
 - CPUユニットへのファイルの書込み(アップロード)
 - CPUユニット内のファイル名閲覧

> Point
> マルチCPUシステム構成でファイル転送機能(FTPサーバ)を使用する場合，ログイン直後のアクセス先CPUユニットは下記のCPUユニットとなります。アクセス先のCPUユニットを変更する場合はcpuchgコマンドを実行してください。
> - 管理CPU(RJ71EN71接続時)
> - Ethernetケーブルで接続しているCPUユニット(CPUユニット接続時)

【図】FTPサーバの構成(原本 p.115)。相手機器(FTPクライアント)とEthernet搭載ユニット(FTPサーバ)がEthernetで接続され、Ethernet搭載ユニット内の保管ファイル(プログラム・データ・パラメータ)に対して「読出し」「書込み」が行われる。

## データ交信の手順 (原本 p.116)

FTPによる通信を行うための設定について説明します。

### Ethernet搭載ユニット側の設定

ファイル転送機能(FTPサーバ)を使用するためには，"応用設定"の"FTPサーバ設定"にある"FTPサーバ使用有無"を"使用する"に設定します。

その他の設定項目の詳細については，下記を参照してください。(321ページ FTPサーバ設定)

## 相手機器(FTPクライアント)側の操作 (原本 p.117)

Ethernet搭載ユニットのファイル転送機能(FTPサーバ)を使用するときの，相手機器側の手順および必要処理について説明します。説明中では，その操作で使用するFTPコマンドと入力形式を示します。(`Enter`は，CR，Enter，またはReturnキーの入力を示します)

【図】相手機器(FTPクライアント)側の操作フローチャート(原本 p.117)

```
開始
→ FTPクライアントの起動 (ftp Enter)
→ Ethernet搭載ユニットへのログイン (open 「Ethernet搭載ユニットのIPアドレス」 Enter)
→ 「FTPはリモートパスワードの対象か？」
    NO  → (A: ループ起点)へ
    YES → リモートパスワードのアンロックをする。(quote password-unlock 「リモートパスワード」 Enter) → (A)へ

(A) 「ファイル転送が終了したか？」
    YES → (C: 終了処理)へ
    NO  → 「FTPサーバへファイルを書き込むか？」
        NO  → (B: 読出し処理)へ
        YES → (D: 書込み処理)へ

(B) 読出し処理
    ファイル変換無しを通知する。(binary Enter)
    → ファイル一覧を確認する。(dir Enter または ls Enter)
    → 「読み出すファイルは存在するか？」
        NO  → (A)へ戻る
        YES → 「対象ファイルにファイルパスワードが設定されているか？」
            NO  → ファイルを読み出す。(get 「ファイル名」 Enter) → (A)へ戻る
            YES → ファイルパスワードを入力する。(quote passwd-rd 「読出しパスワード」 Enter)
                  → ファイルを読み出す。(get 「ファイル名」 Enter) → (A)へ戻る

(D) 書込み処理
    ファイル変換無しを通知する。(binary Enter)
    → 「高速書込みモードを設定するか？」
        NO  → ファイル一覧を確認する。(dir Enter または ls Enter)
        YES → 高速書込みモードを設定する。(quote fastmode on Enter) → ファイル一覧を確認する。(dir Enter または ls Enter)
    → 「書き込むファイルは存在するか？」
        NO  → 「対象ファイルにファイルパスワードが設定されているか？」(上書き確認なしで直接分岐)
        YES → 「上書きしてよいか？」
            NO  → (書込み中止。操作をやり直す)
            YES → 「対象ファイルにファイルパスワードが設定されているか？」
    「対象ファイルにファイルパスワードが設定されているか？」
        NO  → ファイルを削除，またはリネームする。(delete 「ファイル名」 Enter ／ rename 「現ファイル名」「新ファイル名」 Enter)
        YES → ファイルパスワードを入力する。(quote passwd-wr 「書込みパスワード」 Enter)
              → ファイルを削除，またはリネームする。(delete 「ファイル名」 Enter ／ rename 「現ファイル名」「新ファイル名」 Enter)
    → ファイルを書き込む。(put 「ファイル名」 Enter) → (A)へ戻る

(C) 終了処理
    「高速書込みモードを設定したか？」
        NO  → 「FTPはリモートパスワードの対象か？」(E)へ
        YES → 「プログラムキャッシュメモリの内容を変更したか？」
            NO  → (E)へ
            YES → プログラムメモリに書き込む。(quote pm-write Enter) → (E)へ

(E) 「FTPはリモートパスワードの対象か？」
    NO  → Ethernet搭載ユニットとの接続を切断する。(bye Enter) → 完了
    YES → リモートパスワードのロックをする。(quote password-lock Enter)
          → Ethernet搭載ユニットとの接続を切断する。(bye Enter) → 完了
```

## Ethernet搭載ユニットへのログイン (原本 p.118)

FTPを起動し，Ethernet搭載ユニットへログインするまでの操作を説明します。

### 例

Microsoft Windowsのコマンドプロンプトから FTPを起動します。

ログイン名とパスワードは，"応用設定"の"FTPサーバ設定"で設定したものを使用します。Ethernet搭載ユニット(FTPサーバ)は，相手機器(FTPクライアント)からのログイン名とパスワードを受信時，ログイン名とパスワードが合っているかをチェックします。

ログイン名とパスワードが合っているときはEthernet搭載ユニットへのファイル転送が許可され，異なるときはファイル転送が許可されません。

### リモートパスワードのロックおよびアンロックについて

リモートパスワード設定により，FTP交信ポートがリモートパスワードチェックの対象に指定されている場合は，下記のコマンドでリモートパスワードのロック状態からアンロック状態にしてください。(quote password-unlock リモートパスワード)また，終了時には，下記のコマンドでリモートパスワードをアンロック状態からロック状態にしてください。(quote password-lock)

> Point
> FTP交信ポートがリモートパスワードチェックの対象ポートに指定されている場合は，リモートパスワードをアンロック状態にするまで一部のコマンドは使用できません。
> ロック状態でも使用できるコマンド，アンロック状態でなければ使用できないコマンドについては，下記を参照してください。(119ページ FTPコマンド一覧)

### ファイルパスワードの入力について

対象ファイルにファイルパスワードが設定されている場合，アクセス前に下記のコマンドでファイルパスワードを入力しておく必要があります。

 - 書込みパスワード(quote passwd-wr 書込みパスワード)
 - 読出しパスワード(quote passwd-rd 読出しパスワード)

### FTPで転送できるファイル

ファイル転送機能(FTPサーバ)で転送可能(読出し/書込み/削除可能)なファイルについては，使用するCPUユニットのマニュアルに記載の実行可能なファイル操作を参照してください。

操作手順(概要):

1. FTPの起動(FTP)
2. FTPサーバとの接続(open Ethernet搭載ユニットのIPアドレス)
3. ログイン名の指定(ログイン名)
4. パスワードの指定(パスワード)
