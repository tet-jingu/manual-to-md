### エラーログ領域エリア (原本 p.480)

**エラー発生回数(Un\G227)**

| アドレス | 内容 |
|---|---|
| Un\G227 | エラーログブロックエリアに登録したエラー数が格納されます。<br>65536回以上のエラーが発生した場合は，FFFFH(65535)でカウントを停止します。<br>エラー発生回数格納エリアのカウントが停止しても，下記のエリアへのエラー情報の格納処理は続行されます。<br>・エラーログ書込みポインタ(Un\G228)<br>・エラーログブロックエリア(Un\G229~Un\G372) |

**エラーログ書込みポインタ(Un\G228)**

| アドレス | 内容 |
|---|---|
| Un\G228 | 最新のエラーログを登録しているエラーログブロックNo.が格納されます。<br>0: エラーなし(エラーログの登録なし)<br>1以上: 最新のエラーログを登録しているエラーログブロックNo.<br>ポインタ値が16のときはエラーログブロック16のエリアに，最新エラーログが登録されていることを示します。<br>エラーが17個以上発生すると，再度エラーログブロック1のエリアからエラーログが登録されます。 |

**エラーログブロック1(Un\G229~Un\G237)**

> **Point**
> エラーログ領域エリアに格納される値は，Ethernetユニット装着局の電源投入時，リセット操作時，またはERRCLEAR命令実行時にクリアされます。
> (ただし，ネットワーク種別がQ互換Ethernetの場合，UINI命令の実行，およびバッファメモリの'交信条件設定エリア'(Un\G31)による再イニシャル処理ではクリアされません)
> ERRCLEAR命令の詳細は，下記を参照してください。
> MELSEC iQ-Rプログラミングマニュアル(ユニット専用命令編)

| アドレス | 名称 | 内容 |
|---|---|---|
| Un\G229 | エラーコード・終了コード | エラー内容を示すエラーコードおよびデータ交信においてレスポンスに付加する終了コードが格納されます。<br>432ページ エラーコード一覧<br>456ページ データ交信で相手機器に返される終了コード |
| Un\G230 | サブヘッダ | エラーになった伝文のサブヘッダコードがb0~b7に格納されます。(b8~b15には0が格納されます)<br>0: 未使用，サブヘッダコードが不明 |
| Un\G231 | コマンドコード | エラーになった伝文のコマンドコード，またはデータリンク用命令のリクエストタイプとサブリクエストタイプの各下位バイトの値が格納されます。<br>■コマンドコード<br>・b15~b0: コマンドコード<br>■リクエストタイプとサブリクエストタイプ<br>・b15~b8: サブリクエストタイプ<br>・b7~b0: リクエストタイプ<br>0: 未使用，コマンドコードが不明 |
| Un\G232 | コネクションNo. | エラーが発生したコネクションNo.がb0~b7に格納されます。(b8~b15には0が格納されます)<br>0: 未使用，コネクションNo.が不明<br>1~128: ユーザコネクション<br>129以上: システムコネクション |
| Un\G233 | 自局ポート番号 | エラーが発生したときの自局ポート番号が格納されます。<br>0: 未使用，自局ポート番号が不明 |
| Un\G234，Un\G235 | 交信相手IPアドレス | エラーが発生したときの交信相手のIPアドレスが格納されます。<br>0: 未使用，交信相手IPアドレスが不明 |
| Un\G236 | 交信相手ポート番号 | エラーが発生したときの交信相手のポート番号が格納されます。<br>0: 未使用，交信相手ポート番号が不明 |
| Un\G237 | システムエリア | ― |

### 各プロトコル別の状態 (原本 p.481)

**IPパケット(Un\G5000~Un\G5029)**

|---|---|

| Un\G5004~Un\G5005 | 送信総数 |
| Un\G5022~Un\G5023 | 同時送信エラー検出回数(受信バッファフル回数) |
| Un\G5029 | 受信アボート回数 |

| アドレス | 名称 |
|---|---|
| Un\G5040~Un\G5041 | 受信総数 |
| Un\G5042~Un\G5043 | 受信サムチェックエラー破棄総数 |
| Un\G5044~Un\G5045 | 送信総数 |
| Un\G5046~Un\G5047 | 受信echo request総数 |
| Un\G5048~Un\G5049 | 送信echo replay総数 |
| Un\G5050~Un\G5051 | 送信echo request総数 |
| Un\G5052~Un\G5053 | 受信echo replay総数 |
