## 受信パケットの照合動作 (原本 p.543)

プロトコルの通信タイプに受信を含む場合に相手機器と交信するときの，受信パケット(期待するパケット)の照合動作について説明します。

### 受信データと受信パケット(期待するパケット)の照合一致 (原本 p.543)

受信データを受信パケット(期待するパケット)と比較し，照合一致した時点で受信処理を完了します。

【図】照合一致の図(原本 p.543)
- 「受信パケット(期待するパケット)」ボックスと「受信データ」ボックスが上下に並び、双方向矢印で「照合一致」と示される。
- 「受信データ」から「受信完了」へ矢印。

### 複数の受信パケット(期待するパケット)を指定している場合 (原本 p.543)

通信プロトコル支援機能では，最大16個の受信パケット(期待するパケット)を登録することができます。データを受信すると，1番目に登録した受信パケット(期待するパケット)から順に照合を行います。照合一致する受信パケット(期待するパケット)が見つかった時点で受信処理を完了します。

【図】複数受信パケットの照合フロー(原本 p.543)
- 「受信パケット(期待するパケット)」No.1〜No.16(最大16個まで登録可能)が横に並ぶ。
- 「受信データ」がNo.1と照合(照合不一致、×印) → No.2と照合(照合不一致、×印) → No.3と照合(照合一致、○印) → 「受信完了」。
- No.4以降(No.16まで)は照合されない(No.3で一致したため)。

### 受信データが全受信パケット(期待するパケット)と照合一致しない場合 (原本 p.543)

登録された全受信パケット(期待するパケット)と照合一致しない場合，受信データを破棄します。

【図】全不一致時の照合フロー(原本 p.543)
- 「受信パケット(期待するパケット)」No.1〜No.16(16個(最大)登録した場合)が横に並ぶ。
- 「受信データ」がNo.1と照合(照合不一致，×印) → No.2と照合(照合不一致，×印) → … → No.16と照合(照合不一致，×印) → 「破棄」。
