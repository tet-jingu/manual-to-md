## 動作 (原本 p.253)

本機能は”交信設定”と”通信タイプ”の組み合わせで，下記の通信方式をサポートします。

各タイミングチャートは特に指定がない限り，P1と接続している設定No.1のプロトコル番号1を例に記載しています。

また，”通信タイプ”が”送信のみ”以外のタイミングチャートは，プロトコル設定で受信パケットの”デバイス”にのみCPUユニットのデバイスを設定している場合を例に記載しています。

| 交信設定 | 通信タイプ | 通信方式 |
|---|---|---|
| 定期 | 送信&受信 | RJ71EN71またはRnENCPU(ネットワーク部)がクライアントとなり，交信相手(サーバ)とデータの送受信を定周期で行います。 |
| 定期 | 送信のみ | RJ71EN71またはRnENCPU(ネットワーク部)が交信相手に対して，定周期でデータを送信します。 |
| 定期 | 受信のみ | RJ71EN71またはRnENCPU(ネットワーク部)が交信相手からの，送信データを常時受信します。 |
| 要求 | 送信&受信 | RJ71EN71またはRnENCPU(ネットワーク部)がクライアントとなり，交信相手(サーバ)とデータの送受信を，要求時に1回のみ行います。 |
| 要求 | 送信のみ | RJ71EN71またはRnENCPU(ネットワーク部)が交信相手に対して，要求時に1回のみデータを送信します。 |
| 要求 | 受信のみ | RJ71EN71またはRnENCPU(ネットワーク部)が交信相手からの，送信データを要求時に1回のみ受信します。 |

原本の表行数(目視カウント): 6行。上表は全6行を転記。

## 交信開始前の自局の動作 (原本 p.253)

### 正常時の動作(”機能起動/停止指示初期値”が”起動する”の場合) (原本 p.253, PDF p.255で目視確認)

(1) 電源OFFON，またはリセットリセット解除後のシステム処理(準備処理)が行われます。このとき，ʼ各プロトコルの開始要求ʼ(Un\G1249348.0)のデフォルト値は，各プロトコルの交信設定が定期の場合はON(開始)となります。

(2) システム処理が完了し，リンクアップを検出した2s後に，通信開始待ち時間の計測が開始されます。”機能起動/停止指示初期値”を”起動する”に設定している場合，ʼ機能起動/停止指示ʼ(Un\G1249300.0)がON(起動する)になります。

(3) 通信開始待ち時間経過後，ʼ準備完了ʼ(Un\G1249308.0)がON(準備完了)され，データ送受信が実行されます。

(4) システム処理が完了すると，ʼ接続状態ʼ(Un\G1249309)が1H(準備中)となります。

(5) 通信開始待ち時間が経過すると，ʼ接続状態ʼ(Un\G1249309)が3H(実行中)となります。ʼ接続状態ʼ(Un\G1249309)が3H(実行中)となったタイミングでコネクションをオープンします。

【図】正常時(起動する)タイミングチャート(原本 p.253)
- 電源ON/OFF・リセット/リセット解除 → リンクアップ → システム処理(2s) → 通信開始待ち時間 → 交信開始(TCP: オープン要求 / UDP: 要求伝文送信。ARP未解決時はARP送信から実施)
- ʼ機能起動/停止指示ʼ(Un\G1249300.0): システムがONし、(2)のタイミングでON(起動する)固定
- ʼ準備完了ʼ(Un\G1249308.0): OFF → (3)通信開始待ち時間経過後にON(準備完了)
- ʼ各プロトコルの開始要求ʼ(Un\G1249348.0)(交信設定: 定期): システムにより(1)のタイミングでON(開始)
- ʼ接続状態ʼ(Un\G1249309): 0H → (4)1H(準備中) → (5)3H(実行中)
- ʼ各プロトコルの実行状態ʼ(Un\G1249444.0): OFF → 3H遷移後にON(実行中)
- ʼ各プロトコルの実行間隔(現在値)ʼ(Un\G1249476): 0固定→現在値
- ʼシンプル機器通信エラーコードʼ(Un\G1249306)／ʼエラー発生プロトコル番号ʼ(Un\G1249305): 0H(デフォルト)のまま

### 正常時の動作(”機能起動/停止指示初期値”が”停止する”の場合) (原本 p.254)

(1) 電源OFFON，またはリセットリセット解除後のシステム処理が完了し，リンクアップを検出した2s後に，通信開始待ち時間の計測が開始されます。

(2) 通信開始待ち時間経過後，ʼ準備完了ʼ(Un\G1249308.0)がON(準備完了)され，ʼ接続状態ʼ(Un\G1249309)が4H(機能停止中)となります。

(3) 任意のタイミングで，ʼ機能起動/停止指示ʼ(Un\G1249300.0)をON(起動する)します。

(4) ʼ各プロトコルの実行状態ʼ(Un\G1249444.0)がON(実行中)，ʼ接続状態ʼ(Un\G1249309)が3H(実行中)となり，交信相手との交信が開始されます。ʼ接続状態ʼ(Un\G1249309)が3H(実行中)となったタイミングでコネクションをオープンします。

【図】正常時(停止する)タイミングチャート(原本 p.254)
- 電源ON/OFF・リセット/リセット解除 → リンクアップ → システム処理(2s) → 通信開始待ち時間
- ʼ機能起動/停止指示ʼ(Un\G1249300.0): OFF(デフォルト) → (3)プログラムでON(起動する)
- ʼ準備完了ʼ(Un\G1249308.0): OFF → (2)通信開始待ち時間経過後にON(準備完了)
- ʼ各プロトコルの開始要求ʼ(Un\G1249348.0)(交信設定: 定期): システムによりON
- ʼ接続状態ʼ(Un\G1249309): 0H → 1H(準備中) → (2)4H(機能停止中) → (4)3H(実行中)
- ʼ各プロトコルの実行状態ʼ(Un\G1249444.0): OFF → (4)ON(実行中)
- ʼ各プロトコルの実行間隔(現在値)ʼ(Un\G1249476): 0固定→現在値
- ʼシンプル機器通信エラーコードʼ(Un\G1249306)／ʼエラー発生プロトコル番号ʼ(Un\G1249305): 0H(デフォルト)のまま

### 異常時の動作(パラメータ異常) (原本 p.254)

ユニット起動時にパラメータ異常が発生した場合，バッファメモリのシンプル機器通信用エリアは，0またはOFFとなります。
