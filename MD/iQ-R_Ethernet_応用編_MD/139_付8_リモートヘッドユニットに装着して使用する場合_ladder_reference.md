## 付8 リモートヘッドユニットに装着して使用する場合 (原本 p.528)

RJ71EN71をリモートヘッドユニットに装着して使用する場合の制約について説明します。

### 制約のある機能・仕様 (原本 p.528)

**機能**

RJ71EN71をリモートヘッドユニットに装着した場合に制約のある機能について示します。

ユニットパラメータ

RJ71EN71をCPUユニットに装着した場合と，リモートヘッドユニットに装着した場合で相違点があります。詳細については下記を参照してください。

MELSEC iQ-R CC-Link IEフィールドネットワークリモートヘッドユニットユーザーズマニュアル(応用編)

本マニュアルでは，RJ71EN71固有の制約事項について説明します。

オープン/クローズ処理

コネクションのオープン/クローズ処理は相手機器側から行ってください。

| 機能 | 制約事項 |
|---|---|
| SLMPによる交信 | ・使用可能なコマンドがCPUユニットと異なります。(SLMPリファレンスマニュアル)<br>・操作可能なファイルがCPUユニットと異なります。(MELSEC iQ-R CC-Link IEフィールドネットワークリモートヘッドユニットユーザーズマニュアル(応用編)) |
| 通信プロトコルによる交信 | 使用できません。 |
| ソケット通信による交信 | 使用できません。 |
| 固定バッファによる交信 | 使用できません。 |
| MODBUS/TCPによる交信 | ・ネットワーク種別が"Q互換Ethernet"の場合は使用できません。<br>・リモートヘッドユニットを使用してエンジニアリングツールのプロジェクトを作成する場合，MODBUSデバイス割付パラメータに設定されているデフォルト値は使用できません。はじめに値をクリアしてから設定してください。 |
| リンク専用命令による交信 | 中継局または対象局には指定できますが，自局からはリンク専用命令が実行できません。 |
| ファイル転送機能(FTPサーバ) | ・操作可能なファイルがCPUユニットと異なります。(MELSEC iQ-R CC-Link IEフィールドネットワークリモートヘッドユニットユーザーズマニュアル(応用編))<br>・データメモリに書き込めるファイルの数がCPUユニットと異なります。(MELSEC iQ-R CC-Link IEフィールドネットワークリモートヘッドユニットユーザーズマニュアル(スタートアップ編)) |
| 時刻設定機能(SNTPクライアント) | 使用できません。 |
| IPフィルタ機能 | ネットワーク種別が"Q互換Ethernet"の場合は使用できません。 |
| シンプルCPU通信機能 | ネットワーク種別が"Q互換Ethernet"の場合は使用できません。 |
| シンプル機器通信機能 | 使用できません。 |
| IPアドレス変更機能 | ネットワーク種別が"Q互換Ethernet"の場合は使用できません。 |
| 二重化システム対応機能 | リモートヘッドユニットの二重化システムにRJ71EN71を装着することはできますが，RJ71EN71を二重化システム構成にはできません。 |
