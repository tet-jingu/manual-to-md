## 1.17 IPアドレス変更機能 (原本 p.276)

パラメータ設定を変更することなく，Ethernet搭載ユニットのIPアドレスなどを変更できます。

**例: CPUユニット(内蔵Ethernetポート部)の場合**

> Point
> - CPUユニット(内蔵Ethernetポート部)で本機能を使用する場合，GOTから特殊リレー，特殊レジスタの値を操作することでも本機能を使用できます。特殊リレーおよび特殊レジスタの詳細については，使用するCPUユニットのマニュアルを参照してください。
> - RJ71EN71またはRnENCPU(ネットワーク部)で本機能を使用する場合，GOTからバッファメモリの値を操作することでも本機能を使用できます。(461ページ バッファメモリ)

> 制約事項
> - RJ71EN71またはRnENCPU(ネットワーク部)で本機能を使用する場合は，ユニットのファームウェアバージョンを確認してください。またCPUユニット(内蔵Ethernetポート部)のネットワークNo.と局番は，ネットワークNo./局番による交信に対応したファームウェアバージョンのCPUユニットで変更できます。(550ページ 機能の追加と変更)
> - RJ71EN71で，ネットワーク種別に”Q互換Ethernet”を選択した場合は，IPアドレス変更機能を使用できません。

【図】GOT-CPUユニット間のIPアドレス設定フロー図(原本 p.276)
- ❶ デバイス書込み操作により，特殊レジスタ(SD)にIPアドレスを格納(GOTからバス接続でCPUユニットへ)
- ❷ 特殊リレー(SM)をONすると，特殊レジスタ(SD)のIPアドレスをIPアドレス格納エリア(システムメモリ)に格納
  - 特殊レジスタ(SD): SD1518=ネットワークNo., SD1519=局番, SD1520-1521=IPアドレス, SD1522-1523=サブネットマスクパターン, SD1524-1525=デフォルトゲートウェイIPアドレス
  - 書込み実行(SM1520をON)で右側の「IPアドレス格納エリア(システムメモリ)」(同一項目構成)へ矢印で転送
- ❸ CPUユニットの電源OFF→ONまたはリセット操作
- ❹ IPアドレス格納エリア(システムメモリ)に格納されたIPアドレスで動作

## Ethernet搭載ユニットのIPアドレス (原本 p.277)

Ethernet搭載ユニットのIPアドレスは，イニシャル処理時にユニットパラメータで設定した値が設定されます。本機能を使用した場合，イニシャル処理時に設定するIPアドレスは，パラメータで設定した値ではなく，IPアドレス格納エリアに格納された値が設定されます。

**例: CPUユニット(内蔵Ethernetポート部)の場合**

【図】パラメータ使用時とIPアドレス変更機能使用時の比較図(原本 p.277)

[パラメータを使用する場合]
- パラメータファイル(ユニットパラメータ): IPアドレス=192.168.3.39, サブネットマスクパターン=255.255.255.0, デフォルトゲートウェイIPアドレス=192.168.3.254, ネットワークNo.=3, 局番=39
- → CPUユニット側も同一値(192.168.3.39 / 255.255.255.0 / 192.168.3.254 / 3 / 39)が設定される
- 「パラメータファイルのIPアドレスが設定されます。」

[IPアドレス変更機能を使用する場合]
- パラメータファイル(ユニットパラメータ): IPアドレス=192.168.3.39, サブネットマスクパターン=255.255.255.0, デフォルトゲートウェイIPアドレス=192.168.3.254, ネットワークNo.=3, 局番=39(変更なし、×印で無効化)
- IPアドレス格納エリア(システムメモリ): IPアドレス=192.168.3.40, サブネットマスクパターン=255.255.255.0, デフォルトゲートウェイIPアドレス=192.168.3.254, ネットワークNo.=5, 局番=20
- → CPUユニット側はIPアドレス格納エリアの値(192.168.3.40 / 255.255.255.0 / 192.168.3.254 / 5 / 20)が設定される
- 「IPアドレス格納エリア(システムメモリ)のIPアドレスが設定されます。」

## IPアドレスの書込みおよびクリア操作 (原本 p.277-278)

### CPUユニット(内蔵Ethernetポート部)の場合 (原本 p.277)

IPアドレス格納エリア(システムメモリ)にIPアドレスの値を書き込みます。書込みおよびクリア操作は特殊リレー，特殊レジスタで行います。

【図】特殊レジスタ→IPアドレス格納エリア(システムメモリ)転送図(原本 p.277)
- 特殊レジスタ: SD1518=ネットワークNo., SD1519=局番, SD1520-1521=IPアドレス, SD1522-1523=サブネットマスクパターン, SD1524-1525=デフォルトゲートウェイIPアドレス
- 書込み実行(SM1520をON)により、IPアドレス格納エリア(システムメモリ)の同一項目へ転送

### RJ71EN71，RnENCPU(ネットワーク部)の場合 (原本 p.278)

IPアドレス格納エリア(フラッシュ ROM)にIPアドレスの値を書き込みます。書込みおよびクリア操作はバッファメモリで行います。

【図】バッファメモリ→IPアドレス格納エリア(フラッシュROM)転送図(原本 p.278)
- バッファメモリ: Un\G11700-11701=IPアドレス, Un\G11702-11703=サブネットマスク, Un\G11704-11705=デフォルトゲートウェイ, Un\G11706=ネットワークNo., Un\G11707=局番, Un\G11708=トランジェント伝送グループNo.
- 書込み実行(Un\G11709.0をON)により、IPアドレス格納エリア(フラッシュROM)の同一項目(IPアドレス／サブネットマスクパターン／デフォルトゲートウェイIPアドレス／ネットワークNo./局番／トランジェント伝送グループNo.)へ転送

## 使用方法(書込み操作) (原本 p.279)

### CPUユニット(内蔵Ethernetポート部)の場合

下記の手順で実行できます。

1. ʼIPアドレス設定ʼ(SD1518~SD1525)に変更したい値を格納します。
2. ʼIPアドレス格納エリア書込み要求ʼ(SM1520)をOFFONします。
3. 下記の特殊リレー，特殊レジスタで書込み結果を確認します。
4. 電源のOFFONまたはリセットします。
5. IPアドレス格納エリア(システムメモリ)に格納されたIPアドレスが有効な値であれば，格納されたIPアドレスがCPUユニット(内蔵Ethernetポート部)のIPアドレスとして設定されます。(無効な値または未設定の場合は，ユニットパラメータで設定した値がCPUユニット(内蔵Ethernetポート部)のIPアドレスとして設定されます)
6. バッファメモリでIPアドレスを確認します。(471ページ CPUユニット(内蔵Ethernetポート部))

### RJ71EN71，RnENCPU(ネットワーク部)の場合

下記の手順で実行できます。

1. ʼIPアドレス設定ʼ(Un\G11700~Un\G11705)およびʼネットワークNo./局番による交信ʼ(Un\G11706~Un\G11708)に変更したい値を格納します。
2. ʼIPアドレス格納エリア書込み要求ʼ(Un\G11709.0)をOFFONします。
3. 下記のバッファメモリで書込み結果を確認します。
4. 電源のOFFONまたはリセットします。
5. IPアドレス格納エリア(フラッシュ ROM)に格納されたIPアドレスが有効な値であれば，格納されたIPアドレスがRJ71EN71またはRnENCPU(ネットワーク部)のIPアドレスとして設定されます。(無効な値または未設定の場合は，ユニットパラメータで設定した値がRJ71EN71またはRnENCPU(ネットワーク部)のIPアドレスとして設定されます)
6. バッファメモリでIPアドレスを確認します。(461ページ RJ71EN71，RnENCPU(ネットワーク部))
