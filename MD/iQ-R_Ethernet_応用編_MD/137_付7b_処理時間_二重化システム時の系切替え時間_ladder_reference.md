## 二重化システム時の系切替え時間 (原本 p.524)

二重化システムの制御系に装着されたEthernet搭載ユニットが，通信異常または断線検出時に制御系CPUユニットに対して系切替え要求を発行した場合の系切替え時間を示します。系切替え時間は，通信異常または断線検出してから制御系CPUユニットが切り替わるまでの時間です。

**計算式**

系切替え時間の計算式を示します。\*1

| 系切替え要因 | 系切替え時間[ms] |
|---|---|
| 通信異常検出時(生存確認異常) | Tsi+(Ti×(Tr+1))+St+Tsw |
| 通信異常検出時(ULPタイムアウト発生) | Ttu+St+Tsw |
| 断線検出時 | Td+St+Tsw |

\*1 計算式の各変数の意味は，下記のとおりです。

| 変数 | 意味 |
|---|---|
| Tsi | 相手先 生存確認開始間隔タイマ[ms](382ページ データ交信用のタイマ設定) |
| Ti | 相手先 生存確認間隔タイマ[ms](382ページ データ交信用のタイマ設定) |
| Tr | 相手先 生存確認再送回数(382ページ データ交信用のタイマ設定) |
| St | 1スキャンタイム[ms](使用するCPUユニットのマニュアル) |
| Tsw | CPU系切替え時間[ms](使用するCPUユニットのマニュアル) |
| Ttu | TCP ULPタイマ値[ms](382ページ データ交信用のタイマ設定) |
| Td | 断線検出監視時間[ms](396ページ 二重化設定) |

原本の表行数(目視カウント): 系切替え要因表3行+変数表7行=10行。上表は全10行を転記(render確認済み)。

### タイミングチャート (原本 p.525)

各系切替え要因でのタイミングチャートを示します。

**通信異常検出時(生存確認異常)**

【図】通信異常検出時(生存確認異常)のタイミングチャート(原本 p.525)
- 起点: 「相手機器との交信が一定期間ない」(Tr=2の場合)
- RJ71EN71(A系): 「制御系動作」から「待機系動作」へ切り替わる。
- A系CPUスキャンタイム: 起点からTsi経過後、Ti間隔で3回(Tr=2なので生存確認再送2回+初回で計3区切り)スキャンタイムのブロックが続き、最後のTi区間内で「系切替え要求を発行」する。
- A系: 「制御系」から「待機系」へTsw経過後に切り替わる。
- B系: 「待機系」から「制御系」へ、A系の切替えと同じタイミングで切り替わる。
- B系CPUスキャンタイム: A系からB系への切替え時点からスキャンタイムのブロックが始まる。
- RJ71EN71(B系): 「待機系動作」から「制御系動作」へ切り替わる。
- 「系切替え時間」: 交信途絶発生時点から、RJ71EN71(B系)が制御系動作に切り替わるまでの区間として矢印で示される(Tsi+Ti×3の期間+Tswにほぼ相当)。

**通信異常検出時(ULPタイムアウト発生)**

【図】通信異常検出時(ULPタイムアウト発生)のタイミングチャート(原本 p.525)
- 起点: 「相手機器から応答がない」
- RJ71EN71(A系): 「制御系動作」から「待機系動作」へ切り替わる。
- A系CPUスキャンタイム: 起点からTtu経過後に「系切替え要求を発行」する。
- A系: 「制御系」から「待機系」へTsw経過後に切り替わる。
- B系: 「待機系」から「制御系」へ、A系の切替えと同じタイミングで切り替わる。
- B系CPUスキャンタイム: 切替え時点からスキャンタイムのブロックが始まる。
- RJ71EN71(B系): 「待機系動作」から「制御系動作」へ切り替わる。
- 「系切替え時間」: 応答途絶発生時点から、RJ71EN71(B系)が制御系動作に切り替わるまでの区間(Ttu+Tswにほぼ相当)。

**断線検出時**

【図】断線検出時のタイミングチャート(原本 p.525)
- 起点: 「断線発生」
- RJ71EN71(A系): 「制御系動作」から「待機系動作」へ切り替わる。
- A系CPUスキャンタイム: 起点からTd経過後に「系切替え要求を発行」する。
- A系: 「制御系」から「待機系」へTsw経過後に切り替わる。
- B系: 「待機系」から「制御系」へ、A系の切替えと同じタイミングで切り替わる。
- B系CPUスキャンタイム: 切替え時点からスキャンタイムのブロックが始まる。
- RJ71EN71(B系): 「待機系動作」から「制御系動作」へ切り替わる。
- 「系切替え時間」: 断線発生時点から、RJ71EN71(B系)が制御系動作に切り替わるまでの区間(Td+Tswにほぼ相当)。
