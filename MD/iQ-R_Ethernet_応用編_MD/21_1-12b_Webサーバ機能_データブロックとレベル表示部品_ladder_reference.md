## データブロック部品(WSDatblk) (原本 p.146)

指定したデバイスデータを表形式で表示します。デバイスの現在値は中央揃えで表示され，定周期で更新されます。

### direction = 0 (縦方向)の場合

【図】データブロック部品の座標構成(縦方向。原本 p.146)。画面上でxPos,yPosを起点に、5行(blkSize=5)×2組(dev[0]〜dev[4]、dev[5]〜dev[9])のブロックが並ぶ。各行は「部品00n(devNamCol/devNamBkCol/devNamWidth/devNamHeight)」セルと「値(devValCol/devValBkCol/devValWidth/devValHeight)」セルで構成され、セル間の線色はlnCol。

### direction = 1 (横方向)の場合

【図】データブロック部品の座標構成(横方向。原本 p.146)。部品001〜005(blkSize=5)の行と、その値(1000,900,800,700,600)の行、さらに部品101〜105の行と値(500,400,300,200,100)の行が横方向に並ぶ。

dev[n]は，表示したいデバイスの分だけ設定します。(n: 0~31)

凡例: ○=必須，ー=任意

| パラメータ | 項目 | 設定内容 | 設定の要否 |
|---|---|---|---|
| dev[0].dsp | デバイス表示名1 | データブロックで表示させる任意の名称 | ○*1 |
| dev[0].name | デバイス名1 | デバイス種別 + デバイス番号 | ○ |
| dev[0].base | デバイス1のデータ進数 | K: 10進数／H: 16進数／B: 2進数 | ○ |
| dev[0].format | デバイス1のデータ形式 | 0: 16bit符号付き／1: 16bit符号なし／2: 32bit符号付き／3: 32bit符号なし／4: 単精度実数／5: 倍精度実数／6: ビット | ○ |
| ⋮ | (dev[1]〜dev[30]も同様のパラメータ構成。dev[0]は必須，dev[1]以降は任意) | | ー |
| dev[31].dsp | デバイス表示名32 | データブロックで表示させる任意の名称 | ー |
| dev[31].name | デバイス名32 | デバイス種別 + デバイス番号 | ー |
| dev[31].base | デバイス32のデータ進数 | K: 10進数／H: 16進数／B: 2進数 | ー |
| dev[31].format | デバイス32のデータ形式 | 0: 16bit符号付き／1: 16bit符号なし／2: 32bit符号付き／3: 32bit符号なし／4: 単精度実数／5: 倍精度実数／6: ビット | ー |
| direction | 表示方向 | 0: 縦方向／1: 横方向 | ー(省略時は0) |
| blkSize | ブロックサイズ | 1~32(表示方向が縦方向の場合は行数，横方向の場合は列数を示します。) | ○ |
| devNamDisp | デバイス名表示 | 0: 表示しない／1: 表示する | ー(省略時は1) |
| devNamCol | デバイス名文字色 | RGB値またはカラー名。例: #FF0000(RGB値)，red(カラー名) | ー |
| devNamBkCol | デバイス名背景色 | 同上 | ー |
| devNamWidth | デバイス名セル幅 | 正の実数(px単位)(表示方向が横方向の場合はデバイス値セル幅，縦方向の場合はデバイス値セル高さの設定値が優先されます。) | ○*1 |
| devNamHeight | デバイス名セル高さ | 同上 | ○*1 |
| devValCol | デバイス値文字色 | RGB値またはカラー名 | ー |
| devValBkCol | デバイス値背景色 | RGB値またはカラー名 | ー |
| devValWidth | デバイス値セル幅 | 正の実数(px単位) | ○ |
| devValHeight | デバイス値セル高さ | 正の実数(px単位) | ○ |
| lnCol | 線色 | RGB値またはカラー名 | ー |
| xPos | X座標 | データブロック部品左上端の横座標(px単位) | ー |
| yPos | Y座標 | データブロック部品左上端の縦座標(px単位) | ー |

原本の表行数(目視カウント): dev[0]〜dev[31]まで各4行(dsp/name/base/format)の反復+共通パラメータ13行。上表はdev[0]・dev[31]を代表例として全項目を転記し，中間のdev[1]〜dev[30]は同一パターンの反復として注記した(原本どおり反復のため省略ではない)。

*1 デバイス名を表示しない場合(devNamDisp = 0)，設定がなくてもエラーにはなりません。

> 注意事項
> - 必須パラメータはすべて記述してください。必須パラメータの記述がない場合，または設定値が範囲外の場合はエラーが発生します。
> - データ形式を単精度実数および倍精度実数とする場合，データ進数は10進数になります。

## レベル表示部品(WSLevel) (原本 p.148)

指定したデバイスの現在値を，上限値と下限値の範囲に対するレベルで表示します。指定した値を上回った/下回った場合に配色を変えて表示できます。デバイスの現在値は定周期で更新されます。

### direction = 0 (縦方向)の場合

【図】レベル表示部品の座標構成(縦方向。原本 p.148)。画面上でxPos,yPosを起点に、levWidth×levLengthのレベル表示エリアがあり、上からupperVal→upperAlmVal(bkCol背景)→levCol(レベル色)の範囲→lowerAlmVal→lowerValの順。警報値線色almLnCol。下部に現在値セル(devValHeight×devValWidth、devValCol文字色/devValBkCol背景色)が「123」のように表示される。
- 現在値 > upperAlmValの場合: 上限超過を示すupperCol(赤)で表示され、下部devValに「243」のような現在値が表示される。
- 現在値 < lowerAlmValの場合: 下限未達を示すlowerCol(緑)で表示され、下部devValに「45」のような現在値が表示される。

### direction = 1 (横方向)の場合

【図】レベル表示部品の座標構成(横方向。原本 p.148)。levLength×levWidthのレベル表示エリアが横方向に配置され、下部にdevValHeight×devValWidthの現在値セル(「123」)が表示される。

凡例: ○=必須，ー=任意

| パラメータ | 項目 | 設定内容 | 設定の要否 |
|---|---|---|---|
| devName | デバイス名 | デバイス種別 + デバイス番号 | ○ |
| direction | レベル方向 | 0: 縦方向／1: 横方向 | ー(省略時は0) |
| upperVal | 上限値 | 指定したデータ形式の範囲内で任意の数値(10進数) | ○ |
| lowerVal | 下限値 | 同上 | ○ |
| upperAlmVal | 警報値上限 | 同上 | ○ |
| lowerAlmVal | 警報値下限 | 同上 | ○ |
| dspAlmLn | 警報値線表示 | 0: 表示しない／1: 表示する | ー(省略時は1) |
| dspVal | 現在値表示 | 0: 表示しない／1: 表示する | ー(省略時は1) |
| valFormat | データ形式 | 0: 16bit符号付き／1: 16bit符号なし／2: 32bit符号付き／3: 32bit符号なし／4: 単精度実数／5: 倍精度実数 | ー(省略時は0) |
| levCol | レベル表示色 | RGB値またはカラー名 | ー |
| upperCol | 警報値上限を上回ったときの表示色 | RGB値またはカラー名 | ー(省略時はレベル表示色と同じ) |
| lowerCol | 警報値下限を下回ったときの表示色 | RGB値またはカラー名 | ー(省略時はレベル表示色と同じ) |
| bkCol | 背景色 | RGB値またはカラー名 | ー |
| almLnCol | 警報値線色 | RGB値またはカラー名 | ー |
| levLength | レベル長さ | 正の実数(px単位) | ○ |
| levWidth | レベル幅 | 正の実数(px単位) | ○ |
| xPos | X座標 | レベル表示部品左上端の横座標(px単位) | ー |
| yPos | Y座標 | レベル表示部品左上端の縦座標(px単位) | ー |
| devValWidth | 現在値セル幅 | 正の実数(px単位) | ○ |
| devValHeight | 現在値セル高さ | 正の実数(px単位) | ○ |
| devValCol | 現在値文字色 | RGB値またはカラー名 | ー |
| devValBkCol | 現在値背景色 | RGB値またはカラー名 | ー |

原本の表行数(目視カウント): 21行。上表は全21行を転記。

> 注意事項
> 必須パラメータはすべて記述してください。必須パラメータの記述がない場合，または設定値が範囲外の場合はエラーが発生します。
