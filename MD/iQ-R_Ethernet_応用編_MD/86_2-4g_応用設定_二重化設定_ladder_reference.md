## 二重化設定 (原本 p.396)

二重化システムでEthernet搭載ユニットを使用する場合に設定します。

| 項目 | 内容 | 設定範囲 |
|---|---|---|
| 二重化設定使用有無 | 二重化機能を使用するかどうかを選択します。ポート1とポート2は同じ設定にしてください。RJ71EN71を基本ベースユニットに装着する場合は，”使用する”を選択してください。RJ71EN71を増設ベースユニットに装着する場合は，”使用しない”を選択してください。 | ・使用する・使用しない(デフォルト: 使用する) |
| 自ノード(A系)IPアドレス | ”基本設定”の”自ノード設定”で設定したIPアドレスが表示されます。未設定の場合は表示されません。 | — |
| B系IPアドレス | B系のIPアドレスを設定します。”自ノード(A系)IPアドレス”と同じクラス，サブネットアドレスになるように設定してください。IPアドレスを設定しない状態(空白のまま)でパラメータを書き込むと，下記のIPアドレスが設定されます。・RJ71EN71のP1コネクタ: 192.168.3.42・RJ71EN71のP2コネクタ: 192.168.4.42・CPUユニット(内蔵Ethernetポート部): 192.168.3.41 | ・空白・0.0.0.1~223.255.255.254(デフォルト: 空白) |
| 自ノード(A系)局番 | ”基本設定”の”自ノード設定”で設定した局番が表示されます。未設定の場合は表示されません。 | — |
| B系局番\*1 | B系の局番を設定します。”基本設定”の”自ノード設定”で局番を設定している場合に設定します。 | 1~120(デフォルト: 2) |
| 制御系IPアドレスの使用可否\*2 | 制御系IPアドレスを使用するかどうかを選択します。・”使用する”を選択した場合は，制御系IPアドレスを設定してください。制御系IPアドレス使用時は，系切替えが発生した場合でも制御系IPアドレスでアクセスできるようになります。・”使用しない”を選択した場合は，自ノード(A系)IPアドレスとB系IPアドレスを使用してアクセスします。RJ71EN71使用時は下記の点に注意してください。・ポートグループ設定を使用する場合，ポート1とポート2の”制御系IPアドレスの使用可否”は同じ設定にしてください。 | ・使用しない・使用する(デフォルト: 使用しない) |
| 制御系IPアドレス\*2 | 制御系IPアドレスを設定します。”制御系IPアドレスの使用可否”で”使用する”を選択したあと設定します。システムで使用しているIPアドレスと同じクラス，サブネットアドレスになるように設定します。IPアドレスは，ネットワーク管理者に相談の上，設定してください。システムで使用しているIPアドレスと重複しないように設定してください。IPアドレスのクラスは，クラスA，B，Cの範囲内で設定してください。A系のP1とB系のP1またはA系のP2とB系のP2は同じ制御系IPアドレスを設定してください。 | ・空白・0.0.0.1~223.255.255.254(デフォルト: 空白) |
| 自ノード(A系)ユニット動作モード | ”応用設定”の”ユニット動作モード設定”で設定したユニット動作モードが表示されます。 | — |
| B系ユニット動作モード\*1 | B系のユニット動作モードを設定します。ユニット動作モードの詳細については，下記を参照してください。395ページ ユニット動作モード設定 | ・オンラインモード・オフラインモード・単体通信テストモード(デフォルト: オンラインモード) |
| ポートグループ設定\*1\*2 | ポートのグループ設定を設定します。ポート1とポート2は同じ値を設定してください。”設定なし”を選択した場合は，どちらかのポートで系切替えエラーが発生したときに系切替えを実施します。RJ71EN71のネットワーク種別を”Q互換Ethernet”に設定した場合は設定できません。 | ・設定なし・ポート1で系切替えエラー発生時に系切替えする・ポート2で系切替えエラー発生時に系切替えする・ポート1/ポート2両方で系切替えエラー発生時に系切替えする(デフォルト: 設定なし) |
| 断線検出時の系切替え要求発行有無\*1 | 断線検出で系切替え要求を発行するかを設定します。 | ・有効・無効(デフォルト: 有効) |
| 断線検出監視時間\*1 | 正常に通信を開始したあとに，断線を検出してから制御系CPUユニットに対して系切替え要求を発行するまでの時間を設定します。 | 単位[s]: 0.0~30.0単位[ms]: 0~30000(100ms単位)(デフォルト: 2s) |
| 通信異常時の系切替え要求発行有無\*1 | 通信異常で系切替え要求を発行するかを設定します。 | ・有効・無効(デフォルト: 無効) |

原本の表行数(目視カウント): 13行。上表は全13行を転記。

\*1 CPUユニット(内蔵Ethernetポート部)では設定できません。
\*2 RJ71EN71のネットワーク種別を”Q互換Ethernet”に設定した場合は設定できません。
