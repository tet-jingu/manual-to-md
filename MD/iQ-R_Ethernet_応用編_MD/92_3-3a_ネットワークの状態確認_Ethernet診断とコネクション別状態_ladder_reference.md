## 3.3 ネットワークの状態確認 (原本 p.406)

## Ethernet診断 (原本 p.406)

Ethernet診断によって，Ethernet搭載ユニットと相手機器の通信状態を確認できます。

[診断][Ethernet診断]

”対象ユニット指定”でEthernet診断を行うEthernet搭載ユニットを設定します。

- ”接続先指定 Connection”画面の”他局指定”で”他局指定(異種ネットワーク)”を指定し，”異種ネットワーク通信経路”で”CC-Link”，または”C24”を指定した場合，Ethernet診断は起動できません。
- ”接続先指定 Connection”画面の”他局指定”において”他局指定無し”以外を指定してEthernet診断を起動する場合は，エンジニアリングツールのバージョン1.035M以降を使用してください。
- ”接続先指定”の”他局指定”において”他局指定無し”以外を指定している場合は，”接続先指定”の”他局指定”で診断を実施するEthernet搭載ユニットを指定してください。他のEthernet搭載ユニットを指定した場合，同一ベース上のEthernet搭載ユニットであってもEthernet診断を起動することはできません。また，エンジニアリングツールを直結している局が所属するネットワークを含め，最大8ネットワーク先(中継局数: 7局)の局まで，Ethernet診断を起動できます。
- 二重化システム構成時，”接続先指定 Connection”画面の”対象システム”の”二重化CPU指定”で系を指定していると，Ethernet診断は起動できません。診断したい局にエンジニアリングツールを直結接続し，自号機を指定(”二重化CPU指定”が”系指定なし”)して起動してください。
- リモートヘッドユニットの二重化システム構成時に，エンジニアリングツールを待機系のリモートヘッドユニットに接続している場合，Ethernet診断が起動できません。制御系のリモートヘッドユニットに接続して起動してください。
- 二重化システム構成時，”システムモニタ”の”基本ベース情報”でA系/B系の表示を切り替えると，ユニット診断画面からEthernet診断は起動できません。

**注意事項**

通信経路に下記が含まれる場合，Ethernet診断は起動できません。

- MELSECNET/H
- シリアルコミュニケーションユニットのマルチドロップ接続
- パソコン用インタフェースボード
- GOT(トランスペアレント機能使用)
- MELSEC-Q/Lシリーズネットワークユニット

## コネクション別状態 (原本 p.408)

選択したEthernet搭載ユニットの各コネクションの状態を確認できます。

コネクション別状態の表示項目を示します。

\*1 RJ71EN71およびRnENCPU(ネットワーク部)のみ表示されます。
\*2 RJ71EN71のネットワーク種別で”Q互換Ethernet”を選択した場合，”基本設定”の”相手機器接続構成設定”で相手機器に”MELSOFT接続機器”を設定時のみ表示されます。
\*3 CPUユニット(内蔵Ethernetポート部)のみ表示されます。

[最新エラーコードをクリア]ボタンをクリックすることで，各コネクションの”最新エラーコード”に表示されているエラーをすべてクリアします。

RJ71EN71のネットワーク種別で”Q互換Ethernet”を選択した場合，コネクションNo.17~64，FTPサーバ，MELSOFTの直結接続の内容は表示されません。

| 項目 | 内容 |
|---|---|
| コネクションNo./機能 | コネクションNo.，機能(FTPサーバ，FTPクライアント\*3，MELSOFTの直結接続)が表示されます。 |
| 自局ポート番号 | 対象コネクションNo.で使用している自局のポート番号が表示されます。 |
| 交信相手交信手段\*2 | 対象コネクションNo.の交信手段が表示されます。 |
| 交信相手IPアドレス | 対象コネクションNo.のパラメータ設定で設定した，接続するセンサ・機器のIPアドレスが表示されます。 |
| 交信相手ポート番号 | 対象コネクションNo.のパラメータ設定で設定した，接続するセンサ・機器のポート番号が表示されます。 |
| 最新エラーコード | 対象コネクションNo.で発生した最新の異常内容を示すエラーコードが表示されます。 |
| プロトコル | 対象コネクションNo.のプロトコル(TCP/IP，またはUDP/IP)が表示されます。 |
| オープン方式 | 対象コネクションNo.のプロトコルがTCP/IPの場合，使用するオープン方式(Active，Unpassive，Fullpassive)が表示されます。 |
| TCP状態 | 対象コネクションNo.のプロトコルがTCP/IPの場合，センサ・機器との接続状態(オープン状態)が表示されます。 |
| ペアリングオープン\*1 | 対象コネクションNo.の交信手段が固定バッファの場合，ペアリングオープンの設定状態が表示されます。 |
| 生存確認\*1 | 対象コネクションNo.のパラメータ設定で設定した，生存確認方法が表示されます。 |
| リモートパスワード状態 | 対象コネクションNo.のリモートパスワードの設定状態が表示されます。 |
| 連続アンロック失敗回数 | 対象コネクションNo.のリモートパスワードのアンロックを連続で失敗した回数が表示されます。 |
| 強制無効化状態 | 対象コネクションNo.の強制無効化指定状態が表示されます。 |
