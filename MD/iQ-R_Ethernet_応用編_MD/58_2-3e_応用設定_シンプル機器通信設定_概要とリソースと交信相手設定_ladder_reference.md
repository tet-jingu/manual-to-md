## シンプル機器通信設定 (原本 p.330)

RJ71EN71またはRnENCPU(ネットワーク部)でシンプル機器通信機能を使用するための設定です。

まず”シンプル機器通信設定使用有無”で”使用する”を選択したあと，他の項目を設定します。

\*1 各タイマ設定単位により設定範囲が異なります。また，タイマの誤差は10msです。
\*2 ユニットがRJ71EN71(E+E)を使用し，”拡張2”に対応していない場合，他ポートの”シンプル機器通信使用有無”を”使用しない”に設定してください。(275ページ バージョンによる制約)

| 項目 | 内容 | 設定範囲 |
|---|---|---|
| シンプル機器通信使用有無 | シンプル機器通信を使用するかどうかを選択します。 | ・使用しない・使用する(デフォルト: 使用しない) |
| リソース設定 | 交信相手数，プロトコル数，パケット数の最大設定数を設定します。(331ページ リソース設定) | ・通常・拡張1\*2・拡張2(デフォルト: 通常) |
| 機能起動/停止指示初期値 | シンプル機器通信を起動状態で開始するか，停止状態で開始するかを選択します。 | ・起動する・停止する(デフォルト: 起動する) |
| CPU応答監視タイマ | CPUユニットからの応答監視時間を設定します。設定した時間内にCPUユニットから応答が無い場合は，Ethernet搭載ユニットの応答待ち状態を解除します。 | ・s: 1~16383・ms: 100~16383000(100ms単位)\*1(デフォルト: 5) |
| 単位 | CPU応答監視タイマの単位を選択します。”ms”にしたときは，100ms単位で値を設定してください。 | ・s・ms(デフォルト: s) |

原本の表行数(目視カウント): 5行。上表は全5行を転記。

”交信相手設定”画面 <詳細設定>をクリックすると表示されます。(332ページ ”交信相手設定”画面)

”デバイス一覧”画面 <確認>をクリックすると表示されます。(380ページ ”デバイス一覧”画面)

## リソース設定 (原本 p.331)

ユニットの形名(ネットワーク種別)によって選択肢の設定可否が決まります。

”リソース設定”を”拡張1”から”通常”に変更した場合，”通常”で設定できない範囲の交信相手情報は削除されます。

”リソース設定”を”拡張2”から”拡張1”または”通常”に変更した場合，交信相手情報はすべて削除されます。

\*1 ”拡張2”に対応していない場合，他ポートの”シンプル機器通信使用有無”が”使用する”に設定されている場合，設定できません。(275ページ バージョンによる制約)
\*2 1つの”交信相手設定”に対してプロトコル数は512まで設定できます。

**機能起動/停止指示初期値**

シンプル機器通信の初期化完了時，ʼ機能起動/停止指示ʼ(Un\G1249300.0)に格納する初期値を設定します。

- 起動する: ON(1)

## ”交信相手設定”画面 (原本 p.332)

シンプル機器通信の交信相手について設定します。

まずチェックボックス(交信相手設定有効)をチェックしたあと，他の項目を設定します。

| 項目 | 内容 | 設定範囲 |
|---|---|---|
| チェックボックス(交信相手設定有効) | 交信相手の”有効”または”無効”を設定します。 | ・無効(未チェック)・有効(チェック)(デフォルト: 無効(未チェック)) |
| 設定No.\*1 | 設定可能な交信相手の数を表示します。任意の設定No.に交信相手の設定ができます。 | ・1~16・1~32・1~64(デフォルト: 1~16，1~32，1~64) |
| 設定方法 | 交信相手の設定方法を選択します。 | ・ライブラリから選択・ユーザ設定(デフォルト: 空白) |
| メーカ\*2 | 交信相手のメーカ名称を設定します。 | ・ライブラリから選択時: シンプル機器通信ライブラリファイル・ユーザ設定時: 0~32文字(デフォルト: 空白) |
| 機器種別\*2 | 交信相手の機器種別を設定します。 | ・ライブラリから選択時: シンプル機器通信ライブラリファイル・ユーザ設定時: 0~32文字(デフォルト: 空白) |
| 機種\*2 | 交信相手の型式を設定します。 | ・ライブラリから選択時: シンプル機器通信ライブラリファイル・ユーザ設定時: 0~32文字(デフォルト: 空白) |
| IPアドレス | 交信相手のIPアドレスを入力します。 | 0.0.0.1~223.255.255.254(デフォルト: 空白) |
| ポート番号 自局\*3 | 自局のポート番号を設定します。 | 1~4999，5010~65534(デフォルト: 空白) |
| ポート番号 交信相手 | 交信相手のポート番号を設定します。 | 1~65534(デフォルト: 空白) |
| TCP/UDP | 交信に使用するプロトコルを選択します。 | ・TCP Active・UDP(デフォルト: 空白) |
| ”プロトコル設定”画面 | 交信に使用するプロトコルを設定します。(334ページ ”プロトコル設定”画面) | — |
| コメント\*2 | 任意のコメントを設定および表示します。 | 64文字まで(デフォルト: 空白) |
| 通信開始待ち時間\*4 | CPUユニットの立上げ完了後から，通信を開始するまでの時間を設定します。”設定No.”共通の設定で，”設定No.”ごとに変更はできません。 | 0~255(1s単位で設定)(デフォルト: 0) |

原本の表行数(目視カウント): 13行。上表は全13行を転記。

\*1 ”リソース設定”が”通常”の場合は1~16，”拡張1”の場合は1~32，”拡張2”の場合は1~64がデフォルトになります。
\*2 文字列として保存されるため，エンジニアリングツールの表示言語切替えには対応していません。常にパラメータ設定時の言語で表示されます。
\*3 自局のポート番号は1024~4999または5010~61439を使用してください。1~1023は一般的に予約されたポート番号(WELL KNOWN PORT NUMBERS)で，61440~65534は他の通信機能で使用します。
\*4 通信開始待ち時間を設定すると，通信開始タイミングを指定された時間分待ってからシンプル機器通信を行います。交信相手が通信可能となってから開始したい場合，意図的に開始時間を変更してシンプル機器通信が異常とならないようにできます。

## シンプル機器通信設定ファイルのインポート/エクスポート (原本 p.333)

設定済みの交信相手情報，およびデバイス割付け情報を含むプロトコル情報を，ファイルに保存する/ファイルからパラメータに復元する機能です。保存は交信相手単位で行い，1ファイルに複数の交信相手情報を含めることができます。

インポート/エクスポートを使用することで，プロトコル設定を含めた交信相手設定の複製，他のシステムや装置への流用を簡単に行えます。

**インポート手順**

1. [インポート]ボタンをクリックします。
2. インポートするシンプル機器通信設定ファイル(\*.gx3sc)を選択し，[開く]ボタンをクリックします。
3. 設定反映先の先頭設定No.を設定し，[OK]ボタンをクリックします。

設定No.の上限を超過した設定は，インポートされません。

**エクスポート手順**

1. [エクスポート]ボタンをクリックします。
2. 保存する設定No.の範囲を設定し，[OK]ボタンをクリックします。
3. 保存場所を選択し，[保存]ボタンをクリックします。

| 項目 | 内容 | 設定範囲 |
|---|---|---|
| 設定のインポート・エクスポート [インポート]ボタン | シンプル機器通信設定ファイルから設定を読み込み，画面に表示します。 | — |
| 設定のインポート・エクスポート [エクスポート]ボタン | 現在の設定をシンプル機器通信設定ファイルとして保存します。 | — |

原本の表行数(目視カウント): 2行。上表は全2行を転記。
