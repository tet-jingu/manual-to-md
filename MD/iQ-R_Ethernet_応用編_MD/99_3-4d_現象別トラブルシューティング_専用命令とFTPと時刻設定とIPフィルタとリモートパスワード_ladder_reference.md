## 専用命令が完了しない (原本 p.425)

RJ71EN71またはRnENCPU(ネットワーク部)で専用命令が完了しない場合は，”応用設定”の”ユニット動作モード設定”が”オンラインモード”以外に設定されていないか確認してください。

”オンラインモード”以外に設定されている場合は，”オンラインモード”に修正してください。

## リンク専用命令による交信ができない (原本 p.425)

リンク専用命令による交信ができない場合は，下記の内容を確認し，処置してください。

上記の処置でも解決できない場合は，単体通信テストを実施し，ハードウェアに異常がないか確認してください。(404ページ 単体通信テスト)

| 確認項目 | 処置方法 |
|---|---|
| Ethernet搭載ユニットにネットワークNo.，局番が設定されているか。 | ネットワークNo.，局番を設定してください。 |
| 再送回数は，命令実行時に毎回設定しているか。 | 命令実行時に再送回数を設定するようにプログラムを修正してください。 |
| 局番が重複していないか。 | 重複している局の局番を変更してください。 |
| ネットワーク上でネットワークNo.が重複していないか。 | ネットワークNo.が重複しないよう，パラメータを修正してください。 |
| 動的ルーチング機能による通信経路が確定しているか。 | ・電源をONし，少し時間を空けてからトランジェント伝送を開始してください。・通信経路上の局で”応用設定”の”動的ルーチング設定”が”無効”に設定されている場合は，”有効”に設定してください。 |
| 通過する中継局が動的ルーチング機能に対応しているか。 | 通過する中継局が動的ルーチング機能に対応していない場合は，通信経路上のすべての局に”CPUパラメータ”の”ルーチング設定”を設定してください。 |
| 同じチャンネル設定のリンク専用命令が同時に実行されていないか。 | ・別々のチャンネルを設定してください。・リンク専用命令を実行するタイミングをずらしてください。 |

## ファイル転送機能(FTPサーバ)でアクセスできない (原本 p.425)

ファイル転送機能(FTPサーバ)で相手機器(FTPクライアント)からEthernet搭載ユニットにアクセスできない場合は，下記の内容を確認し，処置してください。

上記の処置でも解決できない場合は，単体通信テストを実施し，ハードウェアに異常がないか確認してください。(404ページ 単体通信テスト)\*1

\*1 CPUユニット(内蔵Ethernetポート部)では単体通信テストができません。CPUユニットのトラブルシューティングを行い，ハードウェアに異常がないか確認してください。(使用するCPUユニットのマニュアル)

| 確認項目 | 処置方法 |
|---|---|
| Ethernet搭載ユニットはファイル転送機能(FTPサーバ)を使用する設定になっているか。 | ”応用設定”の”FTPサーバ設定”で”FTPサーバ使用有無”を”使用する”に修正してください。(321ページ FTPサーバ設定) |
| ログイン名，パスワードが間違っていないか。 | パラメータで設定したログイン名，パスワードを確認して，再度ログインしてください。(321ページ FTPサーバ設定) |
| ログイン時に間違ったIPアドレスを入力していないか。 | パラメータで設定したEthernet搭載ユニットのIPアドレスを確認して，再度ログインしてください。(309ページ 自ノード設定) |
| 実行したコマンドの使用方法が正しいか。 | コマンドの使用方法を確認して，正しい方法でコマンドを使用してください。(119ページ FTPコマンド) |
| マルチCPUシステム構成時で，アクセス先のCPUユニットが間違っていないか。 | cpuchgコマンドを実行してアクセス先のCPUユニットを変更してください。 |

## 内蔵Ethernetポート部による通信が遅い (原本 p.426)

内蔵Ethernetポート部による通信が遅い場合は，下記の内容を確認し，処置してください。

| 確認項目 | 処置方法 |
|---|---|
| 外部機器からの通信要求による負荷が高くないか。 | CPUユニット(内蔵Ethernetポート部)のバッファメモリUn\G100(単位時間(1秒)あたりの受信パケット数(現在))を確認し，本値が通常通信時に比べて著しく大きければ，下記の処置を行うことで処理速度が改善できる場合があります。・エンジニアリングツールやGOTからの通信要求を見直す。・シンプルCPU通信の転送先(実行元)からの通信要求を見直す。・ファイル転送機能(FTPサーバ)の操作を見直す。・SLMPによる交信を見直す。 |
| CPUユニットからの通信要求による負荷が高くないか。 | CPUユニット(内蔵Ethernetポート部)のバッファメモリUn\G102(単位時間(1秒)あたりの送信パケット数(現在))を確認し，本値が通常通信時に比べて著しく大きければ，下記の処置を行うことで処理速度が改善できる場合があります。・内蔵Ethernet機能用命令(ソケット通信用命令/通信プロトコル支援機能命令/SLMPフレーム送信命令/ファイル転送機能用命令)の実行頻度を見直す。・CC-Link IEフィールドネットワークBasicの設定(点数など)を見直す。・シンプルCPU通信の設定(実行間隔，点数など)を見直す。・iQSS(内蔵Ethernet)の設定(自動検出，バックアップの実行など)を見直す。・データロギングファイル転送の設定(実行数など)を見直す。 |

原本の表行数(目視カウント): 2行。上表は全2行を転記。
