## 3.7 イベント一覧 (原本 p.454)

Ethernetで発生するイベントを示します。

| イベントコード(16進) | イベント種別 | 概要 | 原因 |
|---|---|---|---|
| 00100H | システム | リンクアップ | 外部機器に接続されているネットワークケーブルの装着などによりリンクアップした。 |
| 00110H | システム | TCP接続の交信開始/終了 | 外部機器とのTCP接続による交信を開始した。または終了した。 |
| 00120H | システム | FTP接続開始/切断 | 外部機器からのFTP接続を開始した。または切断した。 |
| 00130H | システム | 受信フレーム異常 | ・受信フレームの異常を検出した。・Ethernet搭載ユニットをCC-Link IEコントローラネットワークまたはCC-Link IEフィールドネットワークに接続した。 |
| 00140H | システム | 時刻同期失敗 | 時刻情報サーバ(SNTPサーバ)からの返答が無く，時刻同期機能による時刻同期に失敗した。 |
| 00400H | システム | プログラムによる再起動 | プログラムにより，ユニットの再起動が行われた。 |
| 00800H | システム | リンクダウン | 外部機器に接続されているネットワークケーブルの取りはずしなどによりリンクダウンした。 |
| 00901H | システム | データ長異常 | 送受信データ長が許容範囲を超えている。 |
| 00902H | システム | イニシャル処理異常 | イニシャル処理が完了していない状態でソケット通信または固定バッファ交信を実行した。 |
| 00903H | システム | 指定IPアドレス異常 | Unpassive以外で相手機器のIPアドレスにブロードキャストアドレスを指定した。 |
| 00904H | システム | ソケット通信送信失敗 | ソケット通信の伝文送信に失敗した。 |
| 00905H | システム | オープン未実施 | ・相手機器とのコネクションはオープン処理が完了していない。・相手機器とのコネクションがクローズしている。 |
| 00906H | システム | 生存確認エラー | レスポンス監視タイマ値以内に，相手機器の生存確認ができなかった。 |
| 00907H | システム | 分割伝文受信タイムアウトエラー | ・レスポンス監視タイマ値以内に，すべてのデータを受信できなかった。・データ長分のデータを受信できなかった。・TCP/IPレベルで分割された伝文の残りを，レスポンス監視タイマ値以内に受信できなかった。 |
| 00908H | システム | IP組立てタイムアウトエラー | IP組立てタイムアウトエラーが発生した。(分割データの残りが受信できず，タイムアウトした) |
| 00909H | システム | TCP指定ポート番号異常 | オープンしているコネクションで使用しているポート番号を設定した。(TCP/IPの場合) |
| 0090AH | システム | UDP指定ポート番号異常 | オープンしているコネクションで使用しているポート番号を設定した。(UDP/IPの場合) |
| 00A00H | システム | 系切替え要求発行 | 系切替え要求が発生した。 |
| 00C02H | システム | 他局アクセス異常応答 | ・他局アクセス時に，他局から異常応答が返ってきた。・他局からのアクセス時に，他局に異常応答を返信した。 |
| 00D00H | システム | 固定バッファレスポンス送信失敗 | 固定バッファ交信のレスポンス送信に失敗した。 |
| 00D01H | システム | ペアリングオープンエラー | ペアリングオープンのコネクションは，すでにオープン処理されている。 |
| 00D02H | システム | 終了コード異常 | 固定バッファ，ランダムアクセスバッファによる送信に対して，異常終了のレスポンスを受信した。 |
| 00D03H | システム | レスポンス監視タイムアウトエラー | ・レスポンス監視タイマ値以内に，レスポンスを受信できなかった。・レスポンス待ち中に該当コネクションがクローズされた。 |
| 00D04H | システム | 固定バッファ送信失敗 | 固定バッファの伝文送信に失敗した。 |
| 00D05H | システム | ランダムアクセス交信エラー | ランダムアクセス交信にて受信したデータのパラメータ(先頭アドレス・データワード)異常 |
| 10200H | セキュリティ | リモートパスワードのロック | リモートパスワードのロック処理を行った。 |
| 10201H | セキュリティ | リモートパスワードのアンロック成功 | リモートパスワードのアンロック処理を行い成功した。 |
| 10202H | セキュリティ | リモートパスワードのアンロック失敗 | リモートパスワードのアンロック処理を行い失敗した。 |
| 10300H | セキュリティ | IPフィルタ設定で規制されたIPからのアクセス | IPフィルタ設定で規制されたIPアドレスからアクセスされた。 |
| 10500H | セキュリティ | 強制無効化設定 | 強制無効化の設定を行った。 |
| 10501H | セキュリティ | 強制無効化解除 | 強制無効化の設定を解除した。 |
| 24E00H | オペレーション | ERR LED消灯実行 | ユニットの出力信号Y17により，ERR LEDの消灯を実行した。 |

原本の表行数(目視カウント): 31行。上表は全31行を転記。
