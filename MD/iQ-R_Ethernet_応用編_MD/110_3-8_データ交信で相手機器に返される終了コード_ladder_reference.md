## 3.8 データ交信で相手機器に返される終了コード (原本 p.456)

各データ交信でレスポンスに付加される終了コードに格納されるエラーコードを示します。

| 終了コード(16進) | 異常内容と原因 | 処置方法 |
|---|---|---|
| 00H | 正常完了 | 各交信において正常完了の場合，エラーコード00Hが格納されます。 |
| 02H | 読出し/書込みするデバイス範囲の指定に誤りがある。 | 指定した先頭デバイスと点数を確認し，修正してください。 |
| 50H | ・サブヘッダのコマンド/レスポンス種別が規定以外のコードになっている。・固定バッファによる交信で，データ長設定が実際のデータ量より少ない場合，残りのデータを第2データと判断して処理する。この場合に，サブヘッダのコマンド種別未定義エラーとなることがある。 | ・相手機器で設定したコマンド/レスポンス種別を確認し，修正してください。(Ethernet搭載ユニットは，自動的にコマンド/レスポンス種別を付加するので，ユーザでの設定は不要)・データ長を確認して修正してください。 |
| 51H | ランダムアクセス用バッファによる交信で，相手機器からの指定先頭アドレスが0~6143の範囲以外で設定されている。 | 指定した先頭アドレスを確認し，修正してください。 |
| 52H | ・ランダムアクセス用バッファによる交信で，相手機器からの指定先頭アドレス+データワード数(読出し時は設定による)が0~6143の範囲を超える。・指定されたワード数分のデータ(テキスト)を1フレームで送信できない。(送受信するデータ長の値，テキスト量が許容範囲でない) | ・先頭アドレスおよびデータワード数を確認し修正してください。・読出し/書込み点数を修正してください。 |
| 54H | Ethernet搭載ユニットの”基本設定”の”自ノード設定”にある”交信データコード設定”で”ASCII”が選択されているとき，相手機器からバイナリコードに変換できないASCIIコードのデータが送信されてきた。 | 相手機器の送信データを確認し，修正してください。 |
| 55H | ・Ethernet搭載ユニットの”基本設定”の”自ノード設定”にある”RUN中の書込み許可/禁止設定”で”一括で禁止する(SLMP)”が選択されているときに，相手機器によりCPUユニットがRUN中にデータの書込みを要求した。・CPUユニットがRUN中に，相手機器よりパラメータ，プログラムの書込みを要求した。 | ・Ethernet搭載ユニットの”基本設定”の”自ノード設定”にある”RUN中の書込み許可/禁止設定”を”一括で許可する(SLMP)”に設定して，データ書込みを行ってください。(ただし，パラメータ，プログラム，マイコンプログラムは，RUN中の書込みは不可)・CPUユニットをSTOPにしてデータを書き込んでください。 |
| 56H | 相手機器からのデバイス指定に誤りがあるとき。 | デバイス指定を修正してください。 |
| 57H | ・相手機器からのコマンドの点数指定が各処理における最大処理点数(1回の交信で行える処理点数)を超えている。・先頭アドレス(先頭デバイス番号，先頭ステップ番号)~指定点数分が，各処理における最大アドレス(デバイス番号，ステップ番号)を超えている。・コマンドのバイト長が規定以外の長さである。・データ書込み時において，設定した書込みデータ点数が点数指定の値と異なる。・モニタデータ登録を行っていないのにモニタ要求した。 | ・指定点数または，先頭アドレス(デバイス番号，ステップ番号)を修正してください。・コマンドのデータ長を確認し，再度データ設定をしてください。・モニタデータ登録を行ってください。・最終アドレス以降の読出し/書込みは行えません。指定アドレスを修正してください。・ブロックNo.を修正してください。・拡張ファイルレジスタのブロックNo.指定において，該当メモリカセット容量を超えた範囲のブロックNo.を指定しないでください。 |
| 58H | ・相手機器からのコマンドの先頭アドレス(先頭デバイス番号，先頭ステップ番号)指定が，指定可能な範囲を超えて設定されている。・マイコンプログラム，ファイルレジスタ(R)の読出し/書込みにおいて，CPUユニットのパラメータ設定範囲外を指定している。・拡張ファイルレジスタのブロックNo.指定が，存在しないブロックの設定になっている。・ファイルレジスタを指定できない。・ビットデバイス用のコマンドにおいて，ワードデバイスを指定している。・ワードデバイス用のコマンドにおいて，ビットデバイスの先頭番号を16の倍数以外の値で指定している。 | ・各処理における指定可能な範囲内の値に修正してください。・ブロックNo.を修正してください。・デバイスを見直してください。・コマンドまたは指定デバイスを修正してください。 |
| 59H | 拡張ファイルレジスタを指定できない。 | デバイスを見直してください。 |
| 60H | CPUユニットとEthernet搭載ユニットとの交信時間が応答監視タイマ値を超えた。 | 応答監視タイマの値を長くしてください。 |
| 63H | 固定バッファによる交信で相手先Ethernetユニットのポートがリモートパスワードのロック状態になっている。 | ・SLMPによるリモートパスワードのアンロック処理後，固定バッファによる交信を行ってください。・固定バッファ交信用ポートはリモートパスワードチェックの対象にしないでください。 |
| A0H | 該当コネクションでは，指定できない要求である。 | ・要求内容を見直してください。・オープン設定を修正してください。 |
| A1H | テキスト部の長さ，または要求データ長が短いため，要求内容を解析できない。 | テキスト部の長さ，またはヘッダの要求データ長を見直し，再度Ethernet搭載ユニットへ送信してください。 |
| A2H | 処理できない要求である。 | 要求内容，コマンドを修正してください。 |
