## 16.1 システムのユニット状態の確認 (16.1 / 原本 p.876-879)

**システムモニタは，稼働中のシステムのユニット構成，および各ユニットの詳細情報を表示します。**
**また，エラー状態を確認し，エラーが発生しているユニットの診断ができます。**

### 画面表示 (16.1 / 原本 p.876)

[診断]⇒[システムモニタ]を選択します。

**例** — RCPU

【図】"システムモニタ 基本ベース(R35B)"画面(原本 p.876)

■ 左側: **ベース構成**
- `ユニット検索対象` 入力欄，[検索(F)] ボタン
- `基本ベース(R35B)`(⚠マーク付き) — ユニットのイメージ
- `増設ベース` ×7 — いずれも `未装着`

■ 右側: **ユニット構成**
- 上部: `CPU動作状態` — `1号機: STOP` / `2号機: -` / `3号機: -` / `4号機: -`
- [表示設定(D)...] ボタン / `モニタ中`(緑) / [モニタ停止(T)] ボタン
- 一覧の列: `電源` / `CPU` / `I/O0` / `I/O1` / `I/O2` / `I/O3` / `I/O4`
- 一覧の行:
  - `先頭I/O No.`: - / `3E00` / `0000` / `0010` / `0030` / `0050` / `0070`
  - `点数`: - / - / `16点` / `32点` / `32点` / `32点` / `16点`
  - `ユニット形名`: `R61P` / `R16SFCPU` / `R6SFM` / `RJ71EN71(E+E)` / `RJ71GP21-SX` / `RJ71GF11-T2` / -
  - `エラー状態`: - / ⚠`H1090` / - / - / - / - / -
  - `ユニット構成`: 各ユニットの外観イメージ
  - `管理CPU`: すべて -
  - `ネットワーク情報(ポート1)`: - / - / - / `0-0` / `2-2` / `1-1` / -
  - `IPアドレス(ポート1 IPv4)`: CPU列とI/O1列にIPアドレスの表示
  - `ユニット間同期状態`: すべて -
- 下部ボタン: [製品情報一覧(L)...] [イベント履歴(H)...] [ファイル作成(C)...] [閉じる]
- **`エラー状態凡例`**: ⚠(赤)`重度` / ⚠(オレンジ)`中度` / ⚠(黄)`軽度` / ⛔(赤丸)`ユニット・ベースへのアクセスエラー`

> 補足(本プロジェクト): エラー状態凡例の4段階(重度/中度/軽度/ユニット・ベースへのアクセスエラー)は
> 本文に記載がなく，原本 p.876 の画面図から目視で読み取ったもの。実務で最初に見る情報のため転記した。

### 表示設定 (16.1 / 原本 p.876)

下記は[表示設定]ボタンから設定できます。

- ポートが2つあるユニットのポート2のネットワーク情報およびIPアドレスの表示
- エラーコードの表示形式の切替え

### 表示されない内容 (16.1 / 原本 p.876)

**ユニットのシリーズによっては一部の内容が表示されません。** シリーズごとに表示されない内容を示します。

| シリーズ | 表示されない内容 |
|---|---|
| MELSEC-Q，MELSEC-L，およびMELSEC-iQ-L | 電源ユニットのユニット形名 |
| MELSEC-Q | 各ユニットのネットワーク情報とIPアドレス |
| MELSEC-L | 各ユニットの管理CPU，ポート1のIPアドレス，ポート2のネットワーク情報，およびポート2のIPアドレス |
| MELSEC-iQ-L | 各ユニットの管理CPU，ポート2のネットワーク情報，およびポート2のIPアドレス |

> 補足(本プロジェクト): 行数は原本の4行と一致。

### エラー状態の表示 (16.1 / 原本 p.876)

**MX-Fモデルに接続している場合のみ，電源断，またはユニット接続不良のエラーが検出されたユニットに ⛔(電源断/ユニット接続不良エラー)が表示されます。**

### ユニットのイメージに"?"が表示される場合 (16.1 / 原本 p.877)

**装着されているユニットが下記の状態の場合，ユニットのイメージに"?"が表示されます。**

- **故障している**
- **システムパラメータのI/O割付設定と実装状態が異なる**
- **管理CPUが未装着**
- **プロファイルが登録されていない**

**また，下記のユニットの動作状態によっては，そのユニットのイメージに"?"が表示される場合があります。**

- **MELSEC iQ-Rシリーズのシステムで使用しているMELSEC-Qシリーズのユニット**
- **MELSEC iQ-Lシリーズのシステムで使用しているMELSEC-Lシリーズのユニット**

### 二重化システム構成 (16.1 / 原本 p.878)

二重化システム構成のCPUユニットを使用している場合，システムモニタのベース構成に下記項目が表示されます。

【図】二重化システム構成のベース構成(原本 p.878)
- (1) `トラッキング状態: 正常`
- `1` `2` のマーク付き `基本ベース(R35B)`(`A`系アイコンと⚠マーク)
- (2) `基本ベース(R35B)`(`B`系アイコン)
- (3)(4) `増設ベース1(R68WRB)`(接続状態の線と ✕ マーク)

| No. | 項目 | 内容 |
|---|---|---|
| (1) | トラッキング状態 | **下記のいずれかの状態が表示されます。**<br>・正常<br>・異常<br>・メモリコピー中<br>・メモリコピー完了<br>・メモリコピー失敗 |
| (2) | 増設ケーブル(接続経路)<sup>*1</sup> | **二重化システム用増設ベースユニットのIN1に接続されている増設ケーブルが表示されます。** |
| (3) | 増設ケーブル(接続経路)<sup>*1</sup>(上記と同一セル) | **二重化システム用増設ベースユニットのIN2に接続されている増設ケーブルが表示されます。** |
| (4) | 接続状態<sup>*1</sup> | **増設ケーブルの接続状態が下記のとおり表示されます。**<br>・**実線: アクティブ**<br>・**点線: 非アクティブ**<br>・**✕: 異常** |

> 補足(本プロジェクト): 原本(p.878)の「項目」列は(2)と(3)がセル結合されている。
> 上表では結合を展開して転記した。`✕` はPDFのテキスト抽出では欠落するため画像から補った。
> 行数は原本の4行と一致。

> *1 **二重化システム用増設ベースユニットと基本ベースユニットを増設ケーブルで接続している場合にのみ表示されます。**

> **Point** (原本 p.878)
> **二重化システム用増設ベースユニットを使用している場合，[製品情報一覧]ボタンをクリックすると，"製品情報一覧"画面に二重化システム用増設ベースユニットに装着している増設ケーブルの接続経路とその状態が表示されます。**

#### 注意事項 (16.1 / 原本 p.878)

- **増設ベースユニットの増設段数設定に誤りがある場合，ベース構成は接続順どおりには表示されません。**
- **二重化システム構成のCPUユニットでは，接続先設定にかかわらず，他系のベースユニットを選択したタイミングで，接続先を切り換えています。そのため，システムモニタで他系を選択している場合は，他系を未サポートとする機能は起動しません。**
- **CPUユニットの電源がONしたときに基本ベースユニットに接続されていない二重化システム用増設ベースユニットは表示されません。**
- **CPUユニットの電源がONしたときに通信できなかった二重化システム用増設ベースユニットは未装着状態のユニットとして表示されます。また，パソコンを制御系のCPUユニットに接続している場合のみ，未装着状態のユニットに ⛔(ユニット・ベースへのアクセスエラー)が表示されます。**

### 診断自動機能 (16.1 / 原本 p.879)

**CPUユニットとのUSB接続時，システムモニタを自動で起動する機能です。**
**自動で起動するかどうかは，タスクトレイから切替え可能です。**
**FX5UCPUおよびFX5UCCPUでは対応していません。**

### ユニットのファームウェアバージョン，製造情報の確認 (16.1 / 原本 p.879)

**[製品情報一覧]ボタンから表示する"製品情報一覧"画面にてユニットのファームウェアバージョン，製造情報が確認できます。**

### ファイル作成機能 (16.1 / 原本 p.879)

**システムモニタに表示されている情報をCSVファイルに出力します。**

### ネットワークNo.，局番，およびIPアドレスの指定方法の確認 (16.1 / 原本 p.879)

**ネットワークNo.，局番，およびIPアドレスに対してIPアドレス変更機能を使用しているかどうかは，ツールチップで確認できます。**
**ツールチップは"ネットワーク情報"欄および"IPアドレス"欄の各項目にマウスカーソルを合わせると表示されます。**
IPアドレス変更機能の詳細は下記を参照してください。
📖 MELSEC iQ-R Ethernetユーザーズマニュアル(応用編)

### ユニット構成および稼働状態の確認 (16.1 / 原本 p.879)

**[割付/予約確認]ボタンから表示する"ユニット構成割付/予約確認"画面にて，システムパラメータのI/O割付設定，実際に装着されているユニット構成，ユニットの稼働状態が確認できます。**
**MX-Fモデルでのみ対応しています。**

## 16.2 センサ・機器の状態の確認 (16.2 / 原本 p.880-882)

**ネットワークに接続されているセンサ・機器の状態および現在値を表示します。**
対応ネットワーク: Ethernet(CPUユニット)<sup>*1</sup>，AnyWireASLINK，CC-Link IEフィールドネットワーク，CC-Link

> *1 **MXコントローラでは対応していません。**

### 画面表示 (16.2 / 原本 p.880)

1. [診断]⇒[センサ・機器モニタ]を選択します。
2. "ユニット選択(センサ・機器モニタ)"画面で，マスタユニットまたはマスタ局を選択し，[OK]ボタンをクリックします。

CC-Link IEフィールドネットワークのマスタ局を選択した場合の画面例です。

【図】"センサ・機器モニタ"画面(原本 p.880)
- (1) 局一覧
- (2) 機器構成図
- (3) "モニタ情報"ウィンドウ

### 操作手順 (16.2 / 原本 p.880)

**センサ・機器モニタ画面の局一覧(1)または機器構成図(2)で，モニタ対象のiQSS対応機器を選択します。**
**"モニタ情報"ウィンドウ(3)に，選択したiQSS対応機器の状態が表示されます。**

> **Point** (原本 p.880)
> - **iQSS対応機器のエラー状態は，ネットワークの診断機能で確認してください。**
> - **センサ・機器モニタ機能は，1度に多くの情報をCPUユニットから読み出します。そのため，設定した通信経路によってはセンサ・機器モニタの処理速度が低下する場合があります。**

### 注意事項 (16.2 / 原本 p.880)

**通信経路にMELSEC-Q/Lシリーズのネットワークユニットが含まれる場合，下記のユニットはセンサ・機器モニタを起動できません。**

- **Ethernet内蔵形CPU**
- **CC-Link IEフィールドネットワークユニット**

### ブリッジユニットに接続しているセンサ・機器の状態の確認 (16.2 / 原本 p.881)

CC-Link IE TSN―AnyWireASLINKブリッジユニットに接続しているセンサ・機器の状態を確認する場合，下記の操作でセンサ・機器モニタ画面を表示できます。
**FX5CPUでは対応していません。**

#### 操作手順 (16.2 / 原本 p.881)

1. [診断]⇒[CC-Link IE TSN/CC-Link IE Field診断]を選択します。
2. "CC-Link IE TSN/CC-Link IE Field診断"画面でCC-Link IE TSN―AnyWireASLINKブリッジユニットを選択します。
3. 右クリック⇒ショートカットメニュー [AnyWireASLINKセンサ・機器モニタ]を選択します。

詳細は，下記を参照してください。
📖 iQ Sensor Solution リファレンスマニュアル

### ブリッジユニットに接続している特小無線機器の状態の確認 (16.2 / 原本 p.882)

ブリッジユニット(NZ2WM-GFB)に接続している特小無線機器は，下記の操作でセンサ・機器モニタ画面を表示できます。
詳細は，下記を参照してください。
📖 CC-Link IEフィールドネットワーク-特小無線ブリッジユニットユーザーズマニュアル(応用編)

#### 操作手順 (16.2 / 原本 p.882)

1. センサ・機器モニタ画面の局一覧(1)または機器構成図(2)で，ブリッジユニット(NZ2WM-GFB)を選択します。
2. [センサ・機器モニタ]⇒[システム構成を開く]⇒[特小無線構成を開く]を選択します。

**"モニタ情報"ウィンドウ(3)に，選択した特小無線機器の状態が表示されます。**

## 16.4 ユニットの診断 (16.4 / 原本 p.884-889)

ユニットの状態，エラー情報を表示する方法を説明します。
**FX5CPUを使用している場合，FX5CPUおよび下記のユニットを診断できます。**

- **FX5-20PG-P，FX5-20PG-D，FX5-ENET，FX5-ENET/IP，FX5-EIP，FX5-CCLGN-MS，FX5-SF-MU4T5，FX5-SSC-G(S)，FX5-OPC**

**LHCPUを使用している場合，下記のユニットは診断できません。**

- **L6EXB，L6EXE，L6EC，L6EC-ET**

### 画面表示 (16.4 / 原本 p.884)

**■CPUユニット，リモートヘッドユニットの診断**
[診断]⇒[ユニット診断(CPU診断)]を選択します。
**二重化システム構成のCPUユニットおよびリモートヘッドユニットの場合，現在の接続先に指定しているユニットが対象になります。他系を診断する場合は接続先を変更するか，システムモニタから診断するユニットを指定してユニット診断を行ってください。**

**■入出力，インテリジェント機能ユニットの診断**
**システムモニタのユニット構成の中から診断するユニットを選択し，同列上のいずれかのセルをダブルクリックするとユニット診断が起動できます。**

### 注意事項 (16.4 / 原本 p.884)

**モニタ中にプロジェクト内のプログラムの変換を実行した場合，モニタが停止します。変換が完了すると，モニタを再開します。**

### エラージャンプ (16.4 / 原本 p.889)

- 詳細情報欄(FB階層情報)で選択した行のジャンプ先

**プログラム，ファンクションブロック，およびパラメータにのみジャンプできます。**
**また，一部のパラメータにはジャンプできません。ジャンプできるパラメータはユニットによって異なります。**
**ラダーエディタのインラインSTプログラムの場合は，エラーが発生している行にかかわらずインラインSTプログラムの先頭行にジャンプします。**

#### 注意事項 (16.4 / 原本 p.889)

**■ジャンプ先**

**下記の場合，ジャンプ先がエラーが発生している箇所でないことがあります。**

- **現在開いているプロジェクトと，CPUユニット内のデータが一致していない場合**
- **プロジェクトに設定されている接続先のシーケンサ以外を対象としたユニットの診断の場合**

**マクロ型ファンクションブロック(1)に接続されている出力引数(2)にジャンプした場合，出力引数(2)ではなくマクロ型ファンクションブロック(1)のプログラムにエラーが発生している可能性があります。**

【図】ラダー例(原本 p.889)
```
LD   M100                    ─┐
                              ├→ (1) FbPou_1_1 (FbPou)  B:EN ─ ENO:B
LD   M102                    ─┘                          B:i_Label1 ─ o_Label…
                                     ENO:B ──→ (2) OUT M101
                                     o_Label… ──→ OUT M108
```
> 補足(本プロジェクト): 下段コイルは `M108`。原本 p.889 の図では(2)の破線枠と重なって判読しづらいが，
> ユーザ確認済み。(1) は破線で囲まれたマクロ型ファンクションブロック `FbPou_1_1`，(2) は破線で囲まれた出力コイル `M101`。

- **MXコントローラのプロジェクトの場合**
  **マクロ型ファンクションブロックの呼び出し元のプログラムにジャンプした場合，マクロ型ファンクションブロック内のプログラムにエラーが発生している可能性があります。**

**■プロセス制御拡張を有効にしているプログラムファイル**

**プロセス制御拡張を有効にしているプログラムファイル内に作成されたシステムデータ(システムヘッダーまたはシステムフッター)でエラーが発生しても，これらのデータにはジャンプできません。**
**エラーが発生した原因は，下記いずれかのオプション設定の内容であると考えられます。設定内容を確認してください。**

- **"変換"⇒"プロセス制御拡張設定"⇒"イベント通知"で設定したユニットが存在しない，または設定内容が間違っている**
- **"変換"⇒"プロセス制御拡張設定"⇒"システムリソース"⇒"ファイルレジスタ: ZR"で設定したファイルレジスタの範囲の容量が，"CPUパラメータ"の"ファイルレジスタ設定"で設定したファイルレジスタの容量を超えている**

### 注意事項 (16.6 / 原本 p.902)

- **イベント履歴の発生日時は，"CPUパラメータ"の"動作関連設定"の"時計関連設定"で選択したタイムゾーンに依存するため，ご使用のパソコンの時間とは異なる場合があります。**
- **リモートパスワードを設定しているCPUユニットに対してシーケンサへの書込み/シーケンサからの読出し，または診断を行った場合，リモートパスワードのロック/アンロック成功のイベントが複数回登録されます。**
