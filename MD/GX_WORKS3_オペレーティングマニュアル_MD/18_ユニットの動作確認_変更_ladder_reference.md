## 18.1 CPUユニットの時計設定 (18.1 / 原本 p.943)

CPUユニットに内蔵されている時計を設定する方法を説明します。
**リモートヘッドユニットでは対応していません。**

### 画面表示 (18.1 / 原本 p.943)

[オンライン]⇒[時計設定]を選択します。

【図】"時計設定"画面(原本 p.943)
- `シーケンサのタイムゾーン` 枠: `タイムゾーン`: `UTC+09:00` / `コメント`: 入力欄
- `日付` 枠: カレンダー(図では `2020年12月`，`17` が選択)，☐ `今日: 2020/12/17`，日付入力欄 `2020/12/17`
- `時刻` 枠: アナログ時計の図，時刻入力欄 `11:48:28`
- [パソコンの時刻取得(T)] [シーケンサの時刻取得(P)] ボタン
- `実行先指定(S)` 枠: `現在局指定`(プルダウン) / `対象ネットワークNo指定(W)`: `1`(グレーアウト) / `グループNo指定(G)`: `1`(グレーアウト)
- `説明` 枠: **パソコンの時刻取得では，パソコンのタイムゾーンを加味した時刻を取得できます。実行する場合は，シーケンサのタイムゾーンとパソコンのタイムゾーンを合わせたうえで，実行してください。シーケンサの時刻取得では，シーケンサから時計設定を取得できます。**
- [実行(E)] [閉じる] ボタン

> 補足(本プロジェクト): 画面内の`説明`欄の文章は本文に記載がなく，原本 p.943 の画面図から目視で読み取った。
> タイムゾーンの扱いは時計設定で最も間違えやすい箇所のため転記した。

### 操作手順 (18.1 / 原本 p.943)

各項目を設定し，[実行]ボタンをクリックします。

| 実行先指定 | 内容 |
|---|---|
| 現在局指定 | 接続先で設定している局のみ時計設定をする場合に選択します。 |
| 全局指定<sup>*1</sup> | 接続先で設定している局と，指定したネットワーク上の全局に対して時計設定をする場合に選択します。"対象ネットワークNo.指定"で，対象ネットワークを設定します。 |
| グループNo.指定<sup>*1</sup> | 接続先で設定している局と，指定したネットワーク上の特定グループの各局に対して時計設定をする場合に選択します。<br>"対象ネットワークNo.指定"で，対象ネットワークを設定し，"グループNo. 指定"で，グループNo.を設定します。<br>**CC-Link IEフィールドネットワークはグループNo.を持たないため，グループNo.を指定しての時計設定はできません。** |

> 補足(本プロジェクト): 行数は原本の3行と一致。

> *1 **MXコントローラおよびFX5CPUでは対応していません。**

### 二重化システム構成のCPUユニット使用時の動作 (18.1 / 原本 p.943)

RnPCPU(二重化モード)は，運転モードにより動作が異なります。
RnPSFCPUの運転モードはバックアップモードで動作します。

| 運転モード | 動作 |
|---|---|
| バックアップモード | **両系(制御系→待機系の順番)に実行します。** |
| セパレートモード | **接続系のCPUユニットに対して実行します。** |

> 補足(本プロジェクト): 行数は原本の2行と一致。

### 注意事項 (18.1 / 原本 p.943)

- **時計設定用のデバイス"SM210"のON/OFF状態に関係なく時計設定できます。**
  **また，時計設定時，"SM210"のON/OFF状態は変化しません。**
- **時計設定は，転送時間分の誤差が生じます。**
- **接続局と他局でタイムゾーンの設定が異なる場合でも，同じ時刻が設定されます。**

**手の届かない場所にあるCPUユニットおよび制御盤内のCPUユニットを外部信号でRUN/STOP状態にする場合などに本機能を使用します。**
**リモート操作でRESETにする場合は，事前にCPUパラメータでリモートリセットを許可に設定する必要があります。**
詳細は，下記を参照ください。

📖 MELSEC MXコントローラ MX-Fモデルユーザーズマニュアル
📖 MELSEC MXコントローラ MX-Fモデル(安全機能対応)ユーザーズマニュアル
📖 MELSEC iQ-R シーケンサCPUユニットユーザーズマニュアル
📖 MELSEC iQ-R プロセスCPUユニットユーザーズマニュアル
📖 MELSEC iQ-R SIL2プロセスCPUユニットユーザーズマニュアル
📖 MELSEC iQ-R CPUユニットユーザーズマニュアル(応用編)

各項目を設定し，[実行]ボタンをクリックします。

| 実行先指定 | 内容 |
|---|---|
| 現在局指定<sup>*1</sup> | **■CPUユニットの場合**<br>接続先で設定している局のみリモート操作をする場合に選択します。<br>**■二重化システム構成のリモートヘッドユニットの場合**<br>・[オンライン]⇒[リモート操作]から起動した場合: 接続先で指定しているリモートヘッドユニットの系が対象となります。<br>・"CC IE Field診断"画面から起動した場合: 診断先として指定したリモートヘッドユニットの系が対象となります。 |
| 全局指定<sup>*2</sup> | 接続先で設定している局と，指定したネットワーク上の全局に対してリモート操作をする場合に選択します。"対象ネットワークNo. 指定"で，対象ネットワークを設定します。 |
| グループNo.指定<sup>*2</sup> | 接続先で設定している局と，指定したネットワーク上の特定グループの各局に対してリモート操作をする場合に選択します。<br>"対象ネットワークNo. 指定"で，対象ネットワークを設定し，"グループNo. 指定"で，グループNo. を設定します。<br>**CC-Link IEフィールドネットワークはグループNo.を持たないため，グループNo.を指定してのリモート操作はできません。** |
| 両系指定<sup>*2</sup> | 接続先指定で指定した経路で，両系(制御系/待機系)にリモート操作を実行する場合に選択します。二重化システム構成のCPUユニットで選択できます。 |

> *2 **MX-Fモデル，FX5CPU，およびリモートヘッドユニットでは対応していません。**

### リモート操作とRUN/STOPスイッチの動作について (18.2 / 原本 p.945)

**リモート操作，RUN/STOPスイッチ，またはリモートRUN/PAUSE接点によるCPUユニットへの操作が異なる場合，下記の優先順位に従ってCPUユニットは動作します。**

| CPUユニットへの操作 | 優先順位 |
|---|---|
| STOP | 1 |
| PAUSE | 2 |
| RUN | 3 |

> 補足(本プロジェクト): 行数は原本の3行と一致。

CPUユニットのRUN/STOP，またはリモートRUN/STOP接点によるリモート操作実行後の動作を示します。

| リモート操作 | CPUユニットのスイッチ: RUN | CPUユニットのスイッチ: STOP | リモートRUN/STOP接点がON<br>(CPUユニットはSTOP状態) |
|---|---|---|---|
| RUN | RUN | STOP | STOP |
| STOP | STOP | STOP | STOP |
| PAUSE<sup>*1</sup> | PAUSE | STOP | STOP |
| RESET<sup>*2</sup> | **操作不可**<sup>*3</sup> | RESET | RESET |

> 補足(本プロジェクト): 原本(p.945)の「CPUユニットのスイッチ」列は RUN/STOP の2段ヘッダ。
> 上表では2段ヘッダを展開した。行数は原本の4行と一致。

> *1 **リモートヘッドユニットでは対応していません。**
> *2 **"CPUパラメータ"の"動作関連設定"でリモートリセットを許可する必要があります。**
> *3 **リモート操作でSTOPにした場合は操作可能です。**

### 二重化システム構成のCPUユニット使用時の動作 (18.2 / 原本 p.945)

RnPCPU(二重化モード)は，運転モードにより動作が異なります。
RnPSFCPUの運転モードはバックアップモードで動作します。

| 運転モード | 動作 |
|---|---|
| バックアップモード | **■STOPの実行**<br>**両系(制御系→待機系の順番)に実行します。**<br>**■RUN，PAUSEの実行**<br>**両系(待機系→制御系の順番)に実行します。**<br>**■RESETの実行**<br>**実行時に制御系を指定した場合: 両系(制御系→待機系の順番)に実行します。**<br>**実行時に待機系を指定した場合: 待機系に実行します。** |
| セパレートモード | **接続系のCPUユニットに対して実行します。** |

> 補足(本プロジェクト): 行数は原本の2行と一致。
