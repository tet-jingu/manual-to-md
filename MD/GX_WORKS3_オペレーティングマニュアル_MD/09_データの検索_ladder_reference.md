### 注意事項 (9章冒頭 / 原本 p.560)

- **置換後は，未変換状態になります。**
- **ラベル名を置換する場合は，置換後の名前がすでに使用されていないかを確認してから行ってください。**
- **モニタ中は置換できません。モニタを終了してから行ってください。ただし，ラダーエディタのモニタ書込みモードの場合は置換できます。**
- **読出し禁止のデータは，検索/置換の対象外です。セキュリティを解除するなど，編集可能な状態にして操作してください。**

### エディタでの範囲の指定について (9章冒頭 / 原本 p.560)

ラダーエディタ，FBD/LDエディタ，およびデバイスコメントエディタにおいて，すべて検索およびすべて置換を実行する場合の範囲を指定できます。
指定できる範囲はエディタ上での操作によって異なります。

| 操作 | 範囲 |
|---|---|
| ・ラダーエディタ/デバイスコメントエディタ: 1つのセルのみを選択<br>・FBD/LDエディタ: 1つの部品のみを選択 | エディタ内のすべてのセルまたは部品 |
| ・ラダーエディタ: 複数のセルを選択<br>・FBD/LDエディタ: 複数の部品を選択<br>・デバイスコメントエディタ: 行または複数のセルを選択 | 選択したセル，部品，または行 |
| ・デバイスコメントエディタ: 列を選択 | 選択した列(表示されていないビット指定情報を含む) |
| ・デバイスコメントエディタ: 全選択(Ctrl + A) | すべて(表示されていない複数コメントの列を除く) |

> 補足(本プロジェクト): 原本(p.560)の `Ctrl` `A` はキーアイコンで表記されており，PDFのテキスト抽出では**完全に欠落する**。

- **Ctrl を押しながらセルまたは部品を選択すると，離れている複数のセルまたは部品を選択できます。**
- **デバイスコメントエディタで複数のセルをドラッグして選択した場合，エディタ上に表示されていないビット指定情報も検索または置換されます。**

## 9.1 デバイスおよびラベルの検索/置換 (9.1 / 原本 p.562-564)

### 装置動作のAI解析 (9.8 / 原本 p.591-596)

**AI解析とは，収集したシーケンサのデータを解析して装置動作によるデバイス間の物理的な関係性を推測し，データフロー図に表示する機能です。推測されたデバイス間の物理的な関係性を確認することで，異常が発生した場合のエラー原因の特定を容易にします。**
**R00CPU，RnPSFCPU，およびリモートヘッドユニットでは対応していません。**

【図】AI解析の全体像(原本 p.591)
- シーケンサ(RCPU)から収集したデータ(レコーディングファイル/ロギングファイル)を GX Works3(パソコン)が取り込む
- その結果がデータフロー図に反映される:
  - `ProgPou` 内に `X0`(拡張ブロック `R08CPU`，20ステップ)と `N0`(21ステップ)
  - `ProgPou` 内にプロセスブロック `MC`(21ステップ) → 基点 `M10`(オレンジ枠)
  - `ProgPou` 内に `Y1`(33ステップ)とプロセスブロック `DMOV`(37ステップ)，その先の `ProgPou` 内に `D10 - D11`(37ステップ)
  - **`AI解析` のプログラムブロック(ピンク背景)内に `X1`(拡張ブロック `R08CPU`)，`Y10`，`X2`(拡張ブロック `R08CPU`)** ← ここがAI解析で追加される部分

**例**

装置動作によるデバイス間の物理的な関係性の例を示します。
**Y1がONしてコンベアが稼働します。センサー(1)がワークを検出すると，X2がONします。**
**この場合，Y1とX2に物理的な関係性があります。**

【図】物理的な関係性の例(原本 p.591)
- 左のラダー: `X1`(接点，ON) → `Y1`(コイル，点灯。破線で囲まれている)
- 中央: コンベア上のワークと，それを上から検出するセンサー(1)
- 右のラダー: `X2`(接点，ON。破線で囲まれている) → `Y2`(コイル)
- Y1(コンベア稼働) → ワーク搬送 → センサー検出 → X2がON という物理的な因果を矢印で示している

**プログラム上でY1とX2に関係性がないと，デバイス/ラベルの解析を実行してもデータフロー図にY1とX2の関係性は表示されません。**
**AI解析を実行することで，Y1とX2のような物理的な関係性をデータフロー図に表示できます。**

#### 注意事項 (9.8 / 原本 p.591)

**AI解析はシーケンサのデータから推測したデバイス間の関係性を示す機能であり，データフロー図に表示される解析結果が正しいことを保証するものではありません。**

### 注意事項 (9.9 / 原本 p.603)

#### ブックマーク登録後に編集または変換操作を行った場合 (9.9 / 原本 p.603)

**ブックマーク登録後に編集または変換操作を行うと，ブックマークに登録された位置情報とプログラムが一致しなくなります。ブックマークを最新の状態にするには，ブックマークを削除し，再度登録してください。**

#### 機種/動作モードを変更する場合 (9.9 / 原本 p.603)

**プロジェクトの機種/動作モードを変更する場合，シリーズの変更でプロジェクトが新規作成されると，変更前のプロジェクトに登録されていたブックマークは削除されます。**
