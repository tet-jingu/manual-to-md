# 4 ユニット構成図の作成とパラメータの設定 (4章冒頭 / 原本 p.206)

GX Works3では"ユニット構成図"ウィンドウから，実際の機器を組み立てるような感覚でシーケンサのパラメータを設定できます。
GX Works2のようにナビゲーションウィンドウからパラメータを設定することもできます。

## ユニット構成図ウィンドウについて (4章冒頭 / 原本 p.206)

"ユニット構成図"ウィンドウを使用することで下記の操作を簡単に行えます。

| 項目 | 参照 |
|---|---|
| 実際のシーケンサシステムの構成をビジュアルに表示<sup>*1</sup> | 📖 207ページ ユニット構成図の作成 |
| 各種ユニットのパラメータ設定<sup>*1</sup> | 📖 212ページ ユニット構成図からのパラメータの設定 |
| 先頭XY/インテリユニットNo.一括入力<sup>*2</sup> | 📖 217ページ 先頭XY/インテリユニットNo.の一括入力 |
| デフォルト点数一括入力<sup>*2</sup> | 📖 217ページ デフォルト点数の一括入力 |
| 電源容量/入出力点数のチェック<sup>*1</sup> | 📖 217ページ 電源容量/入出力点数のチェック |
| システム構成のチェック<sup>*1</sup> | 📖 217ページ システム構成のチェック |

> *1 LHCPUでは対応していません。
> *2 LHCPUおよびFX5CPUでは対応していません。

## パラメータ設定について (4章冒頭 / 原本 p.206)

下記のいずれかの方法で，パラメータを設定できます。

| 方法 | 参照 |

| "ユニット構成図"ウィンドウを通じて表示した"構成詳細情報入力"ウィンドウで設定する<sup>*1</sup> | 📖 212ページ ユニット構成図からのパラメータの設定 |

## 4.1 ユニット構成図の作成 (4.1 / 原本 p.207-217)

"ユニット構成図"ウィンドウに実際のシステムと同じ構成でユニット部品(オブジェクト)を配置します。
GX Works3の"ユニット構成図"ウィンドウでは，プロジェクトのCPUユニットが管理するシステムの範囲内で，ユニット構成図を作成できます。

### ユニット構成図作成時のエディタ構成 (4.1 / 原本 p.207)

> **Point** (原本 p.207)
> 下記のオプション設定により，表示設定の変更が行えます。
> [ツール]⇒[オプション]⇒"その他のエディタ"⇒"ユニット構成図"

#### 画面表示 (4.1 / 原本 p.207)

ナビゲーションウィンドウ上の"ユニット構成図"をダブルクリックします。

【図】ツールバー(原本 p.207)
- 左から順にアイコンが並ぶ: ユニット構成読出し系アイコン / ユニット情報表示 / XY割付表示 / 直線 / 四角形 / 楕円 / テキストボックス / 接続ポイント(B)。末尾にオーバーフロー用の下向き矢印。
- 各アイコンの正確な機能名は原本 p.207 の図を参照(図中にアイコン名の注記なし)。

【図】"ユニット構成図"ウィンドウ(原本 p.207)
- タブ: 「ユニット構成図 *」
- 中央の編集エリアに2段のベースユニットを配置した例
  - 上段: 基本ベース(スロット表記 POW / CPU / 0 / 1 / 2 / 3 / 4)
    - 吹出し「基本ベース」…ベースユニット本体
    - 吹出し「接続ポイント」…ユニット右上のオレンジの点
    - 吹出し「空き」…色の薄いスロット
    - 吹出し「局番」…ベース左下の「局番 1」表示
    - 吹出し「汎用ユニット」
  - 下段: 増設ベース(スロット表記 POW / 0 / 2 / 3 / 4 / 5 / 6 / 7)
    - 吹出し「増設ベース」
    - 吹出し「装着エラー」…紫にハイライトされたスロット
  - 上下のベースは接続線(バスケーブル)で結ばれている
- 右上: "部品選択"ウィンドウ
  - 「(部品検索)」入力欄，"表示対象:" プルダウン「全て」
  - ツリー: iQ-Rシリーズ ⇒ 基本ベース / 増設ベース / RQ増設ベース / シーケンサCPU / モーションコントローラCPU / 電源
  - 選択中の部品: 「QX28」
  - 下部タブ: [部品一覧] [お気…] [履歴] [ユニ…]
- 右下: "構成詳細情報入力"ウィンドウ
  - 見出し「R08CPU」
  - 種別: CPU
  - 空きスロット点…: 16点
  - ネットワーク種…: Ethernet (グレーアウト)
  - IPアドレス: 192.168.3.39
  - [詳細設定]ボタン

### オブジェクトの配置 (4.1 / 原本 p.209-210)

#### ユニットオブジェクトの挿入 (4.1 / 原本 p.209)

**操作手順**

1. 部品選択ウィンドウで基本ベースユニットを選択し，"ユニット構成図"ウィンドウ上にドラッグ&ドロップします。
2. 部品選択ウィンドウでユニットを選択し，手順1で配置したベースユニット上にドラッグ&ドロップします。

ドラッグ&ドロップ中に配置可能な箇所がハイライト表示されます。

> **Point** (原本 p.209)
> ユニットオブジェクトのオブジェクト名は，"プロパティ"画面から変更できます。オブジェクト名を変更することで，同じ形名のユニットでも区別しやすくなります。

**注意事項** (原本 p.209)

- MELSOFT NavigatorでサポートするGOT2000/GOT1000シリーズ，汎用機器，イメージ図，リンクファイルはサポートしていません。
- バスケーブルでのみ接続でき，ネットワーク接続/シリアル接続はできません。
- FX5CPUの場合は，直接ユニットを選択して，"ユニット構成図"ウィンドウ上にドラッグ&ドロップしてください。

#### 1度配置したユニットの移動 (4.1 / 原本 p.209)

基本ベースユニットまたは増設ベースユニットに配置されたユニットをはずした場合(非配置状態)，先頭I/Oなどのオブジェクトの情報，パラメータ情報は保持されます。再度ベースユニットに配置した場合，パラメータ情報が再設定されます。
ベースユニットからはずしたユニットは，"システムパラメータ"の"I/O割付設定"から削除されます。
FX5CPUの場合は，CPUユニットからユニットをはずした状態では設定を確定できません。

#### 1度配置したユニットの削除 (4.1 / 原本 p.209)

ユニットを削除した場合，パラメータの確定後にナビゲーションウィンドウに表示されているユニット情報も削除されます。
シングルCPU構成の場合，CPUユニットは削除できません。
マルチCPU構成の場合，自号機のCPUは削除できません。

#### コピー&貼り付け (4.1 / 原本 p.209)

貼り付けたユニットのパラメータ情報は，貼り付け元のユニットの情報を引き継ぎます。
マルチCPU構成でベースユニットに配置されたCPUユニットをコピー&貼り付けした場合，号機番号は未確定状態になります。
別プロジェクトの"ユニット構成図"ウィンドウへの貼り付けが可能です。

#### 図形オブジェクトの挿入 (4.1 / 原本 p.209)

"ユニット構成図"ウィンドウ内に図形やテキストを挿入できます。
"ユニット構成図"ウィンドウに挿入した図形は，CPUユニットへの書込みの対象外です。プロジェクトにのみ保存されます。

**操作手順**

部品選択ウィンドウの"図形"から対象の図形を選択し，"ユニット構成図"ウィンドウ上にドラッグ&ドロップします。

> **Point** (原本 p.209)
> 図形オブジェクトの文字や色の変更は，"プロパティ"画面から設定します。

#### CPUユニットの形名変更 (4.1 / 原本 p.210)

ユニット構成図内に配置したCPUユニットの形名を変更できます。
MX-RモデルおよびRCPUでは対応していません。

**操作手順**

1. 配置したCPUユニットを選択し，右クリック⇒ショートカットメニュー [コントローラ形名変更]/[CPU形名変更]を選択します。
2. "コントローラ形名変更"画面/"CPU形名変更"画面で，変更後の形名を選択します。

**注意事項** (原本 p.210)

異なる機種の形名には変更できません。

#### ユニット状態設定(空き) (4.1 / 原本 p.210)

機器を入手できずに装着しない状態で稼働する場合に設定します。
設定したユニットは，色が薄く表示されます。
MX-FモデルおよびFX5CPUでは対応していません。

**操作手順**

空きに設定するユニットを選択し，[編集]⇒[ユニット状態設定(空き)]を選択します。

#### 実機からのユニット構成読出し (4.1 / 原本 p.210)

実機から読み出した情報から，ユニット構成図が作成できます。
FX5CPUの場合，形名が特定できないユニットは汎用ユニットとしてユニット構成図上に配置されます。
二重化システム構成のリモートヘッドユニットから読み出すとき，接続先のユニットが1号機のCPUユニット以外の場合でも，1号機のCPUユニットを自号機として読み出します。

**操作手順**

[オンライン]⇒[実機のユニット構成読出し]を選択します。

**注意事項** (原本 p.210)

- 増設段数設定に誤りがある増設ベースユニットに対して，実機のユニット構成読出しは行えません。
- MX-Fモデルに高速パルス入出力ユニット(FX5-16ET/ES-H，FX5-16ET/ESS-H)が5台以上連結されている場合，5台目以降の高速パルス入出力ユニットは，高速パルス入出力ユニット(FX5-16ET/ES-H(S)，FX5-16ET/ESS-H(S))として配置されます。

### ユニット情報の確認 (4.1 / 原本 p.211)

#### バルーンヘルプで確認する (4.1 / 原本 p.211)

"ユニット構成図"ウィンドウ内のオブジェクト(ユニットや図形)にマウスカーソルを合わせると，バルーンヘルプが表示されます。

#### ユニットオブジェクトに形名を表示する (4.1 / 原本 p.211)

**操作手順**

[編集]⇒[ユニット情報表示]を選択します。

【図】通常表示とユニット情報表示の比較(原本 p.211)
- 左: 「通常表示」…ユニットオブジェクトに形名が表示されない状態
- 右: 「ユニット情報表示」…ユニットオブジェクト上に形名が表示された状態

#### プロパティ画面で確認する (4.1 / 原本 p.211)

"プロパティ"画面からユニットの形名，オブジェクト名，概略仕様を確認できます。
また，コメントの入力もできます。

**操作手順**

ユニット構成図でユニットオブジェクトを選択し，右クリック⇒ショートカットメニュー [プロパティ]を選択します。

### ユニット構成図からのパラメータの設定 (4.1 / 原本 p.212)

ユニット構成図に配置したユニットのパラメータを"構成詳細情報入力"ウィンドウで設定できます。

**操作手順**

1. パラメータを編集するユニットオブジェクトを選択します。
2. [編集]⇒[パラメータ]⇒[構成詳細情報入力ウィンドウ]を選択します。
   "構成詳細情報入力"ウィンドウが表示されます。
3. "構成詳細情報入力"ウィンドウで，各項目を設定します。
4. [編集]⇒[パラメータ]⇒[確定]を選択します。

詳細を設定する場合は，"構成詳細情報入力"ウィンドウの[詳細設定]ボタンをクリックし，表示されたパラメータエディタで設定してください。

#### パラメータが未確定状態に変更される操作 (4.1 / 原本 p.212)

"ユニット構成図"ウィンドウ上でオブジェクトを操作すると，パラメータが未確定状態に変更される場合があります。
パラメータが未確定状態に変更される操作を示します。

- ユニット接続
- ユニット状態設定(空き)
- 元に戻す/やり直し
- 先頭XY/インテリユニットNo.一括入力
- デフォルト点数一括入力
- "構成詳細情報入力"ウィンドウでの操作
- ユニットの追加，削除
- ユニットの切り取り，貼り付け
- ユニットのプロパティ変更
- ベースユニットのスロットからユニットをはずす，または再度配置する
  FX5CPUの場合は，CPUユニットからユニットをはずす，または再度接続する

#### パラメータ確定後に更新されるデータ (4.1 / 原本 p.213)

パラメータが確定されると下記のデータが更新されます。

- ナビゲーションウィンドウ
  (新たに配置したユニットのパラメータが確定された場合，ナビゲーションウィンドウの"ユニット情報"にそのユニットのパラメータが追加されます。)
- パラメータエディタ
- "システムパラメータ"の"I/O割付設定"

#### パラメータ情報の引き継ぎ (4.1 / 原本 p.213)

切り取りまたはコピーしたユニットオブジェクトは，"ユニット構成図"ウィンドウへ貼り付け，パラメータを確定することで，パラメータ情報を引き継げます。

**注意事項** (原本 p.213)

下記の操作ではパラメータ情報を引き継ぐことができないため，貼り付けたユニットオブジェクトのパラメータ情報はデフォルト状態に戻ります。

- 切り取りまたはコピーしたユニットオブジェクトを異なるプロジェクトの"ユニット構成図"ウィンドウへ貼り付ける
- パラメータを確定する前に，"構成詳細情報入力"ウィンドウでユニットオブジェクトの局種別を変更する

#### 先頭XY番号変更時の変更箇所一覧表示 (4.1 / 原本 p.213)

ユニット構成図上でユニットの先頭XY番号を変更した場合，影響を受けるデータの一覧が"ユニット先頭I/O No.関連箇所"ウィンドウに表示されます。表示内容を確認し，データを修正してください。

- 影響を受けるデータ: プログラム，FBプログラム，システムパラメータ，CPUパラメータ，ユニットパラメータ，グローバルラベル(構造体を含む)，ユニットラベル
- 影響を受けるデバイス: FROM(P)，DFROM(P)，TO(P)，DTO(P)，TYPERD，およびTYPERDP命令の引数で指定している先頭XYのデバイス

MX-FモデルおよびFX5CPUでは対応していません。

### マルチCPU構成について (4.1 / 原本 p.214-215)

MXコントローラ，RnPCPU(二重化モード)，RnPSFCPU，FX5CPU，およびリモートヘッドユニットは，マルチCPUシステムを構成することはできません。

#### マルチCPU構成の設定 (4.1 / 原本 p.214)

マルチCPU構成は，ベースユニット上にCPUユニットを2つ以上配置します。
ユニットの管理CPUを変更する場合は，"構成詳細情報入力"ウィンドウで行ってください。
シングルCPU構成からマルチCPU構成への変更，マルチCPU構成からシングルCPU構成への変更方法を説明します。

**シングルCPU構成からマルチCPU構成へ変更する場合** (原本 p.214)

シングルCPU構成(ベースユニットにCPUが1つ配置されている)状態で，部品選択ウィンドウからCPUユニットをドラッグ&ドロップし，ベースユニットに2つ目のCPUユニットを配置します。

**マルチCPU構成からシングルCPU構成へ変更する場合** (原本 p.214)

マルチCPU構成(ベースユニットにCPUユニットが2つ以上配置されている)状態で，CPUユニットを削除(またはスロットからはずす)し，ベースユニットにCPUユニットを1つだけ配置した状態にします。

#### 自号機として設定したCPUユニットの号機番号の変更 (4.1 / 原本 p.215)

マルチCPU構成の場合，ベースユニットに配置したCPUユニットの号機番号が，左から順に設定されます。
号機番号を変更する場合はCPUユニットの位置を変更します。

**シングルCPU構成からの操作** (原本 p.215)

CPUスロットに配置されているCPUユニットを空きスロットに移動し，空いたCPUスロットに新しいCPUユニットを配置します。

【図】シングルCPU構成からの操作(原本 p.215)。図中の注記を原文のまま転記する。
- プロジェクトの新規作成直後は、作成時に指定したCPUユニットが配置されます。
- 自号機のCPUユニットを、配置した基本ベース上のスロット0に移動します。
- CPUスロットに新しくCPUユニットを配置します。
- 1号機=他号機，2号機=自号機
- 自号機(2号機)のCPUユニットで管理されるユニット

**マルチCPU構成時の操作** (原本 p.215)

CPUスロットに配置されているCPUユニットと，ほかのスロットに配置されているCPUユニットを入れ替えます。
入替えの際，ベースユニットから非配置状態にしたユニットはパラメータ情報を保持し，スロットの配置時に，保持していたパラメータ情報を引き継ぎます。

【図】マルチCPU構成時の操作(原本 p.215)。図中の注記を原文のまま転記する。
- 自号機(2号機)のプロジェクトを編集します。
- 自号機のCPUユニットをスロットからはずします。
- CPUユニット(1号機)=自号機
- CPUユニット(2号機)=他号機
- 自号機(1号機)のCPUユニットで管理されるユニット
- 他号機(2号機)のCPUユニットで管理されるユニット
- 自号機のCPUユニットを配置します。
- CPUユニット(2号機)=自号機
- CPUユニット(1号機)=他号機
- 号機番号が振り直されます。
- 自号機(2号機)のCPUユニットで管理されるユニット
- "管理CPU"が自号機の番号に変更されます。
- 他号機で管理されていたユニットは、"管理CPU"の号機番号が自号機と同じとなった場合、自号機で管理されるようになります。

#### RnENCPUのマルチCPU構成時の表示 (4.1 / 原本 p.215)

- ユニットを変更後，ナビゲーションウィンドウ上に (必須設定未確認)が表示されます。
  [ツール]⇒[パラメータチェック]を選択し，パラメータをチェックしてください。(📖 222ページ パラメータのチェック)

### 変更内容 (4.7 / 原本 p.306-307)

ユニットの変更に伴うデータの変更点を示します。
シンプルモーションユニットの変更点はシンプルモーションユニット設定機能のヘルプを，モーションユニットの変更点はモーション制御設定機能のヘルプを参照してください。
