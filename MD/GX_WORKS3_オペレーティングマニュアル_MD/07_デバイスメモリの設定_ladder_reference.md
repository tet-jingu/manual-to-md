# 7 デバイスメモリの設定 (7章冒頭 / 原本 p.546)

デバイスメモリの設定方法について説明します。

---

## 7.1 デバイスメモリについて (7.1 / 原本 p.546)

**GX Works3のデバイスメモリとは，CPUユニットのデバイスメモリに対して値を読み出す，および書き込むためのデータです。**
**デバイスメモリを読み出すことで，CPUユニットのデバイスメモリの状態を確認したり，そのデバイスメモリをオフラインのデバッグに使用したりできます。**
**また，デバイスメモリを書き込むことで，CPUユニットのデバイスメモリの現在値を一括で変更できます。**

### 設定可能なデバイス (7.1 / 原本 p.546)

デバイスメモリエディタで設定可能なデバイスおよび入力方法は，下記を参照してください。
📖 1100ページ GX Works3で編集可能なデバイス

### グローバルデバイスとローカルデバイスの違い (7.1 / 原本 p.546)

**デバイスメモリ自体には，グローバルデバイスとローカルデバイスの区別はありません。**
**デバイスメモリの名称によって，CPUユニットに書き込んだときに，下記の2種類のデバイスに区別されます。**

- **プログラムファイルと異なる名称のデバイスメモリ: グローバルデバイス**
- **プログラムファイルと同名のデバイスメモリ: ローカルデバイス**

**CPUユニットから読み出すときも，上記の区別によってグローバルデバイスとローカルデバイスが読み出されます。**

**FX5CPUは，ローカルデバイスには対応していません。**
**プログラム名との一致/不一致に関係なく，グローバルデバイスに書き込まれます。**

### プロセス制御拡張を有効にしている場合の注意事項 (7.1 / 原本 p.546)

**下記オプションでシステムリソースに設定した範囲のデバイスメモリの値は変更しないでください。**

- [ツール]⇒[オプション]⇒"変換"⇒"プロセス制御拡張設定"⇒"システムリソース"

## 7.3 デバイスメモリの設定 (7.3 / 原本 p.548-551)

デバイスとデバイス値を設定する方法を説明します。

### 注意事項 (7.3 / 原本 p.548)

- **セルを選択して削除を実行すると，デバイス値は"0"になります。**
- **デバイス名の先頭に#を付加してローカルデバイスとする入力方法はサポートしていません。**
  **デバイスメモリをCPUユニットから読み出すときに，グローバルデバイスまたはローカルデバイスを選択してください。**

### 1点単位の設定 (7.3 / 原本 p.548)

1点単位でデバイスとデバイス値を設定します。

**例**

下記の値をワード多点形式で設定します。
デバイス: D2，デバイス値: 12

#### 操作手順 (7.3 / 原本 p.548)

1. 表示形式を設定します。(📖 547ページ 表示形式の設定)
2. "デバイス名"に"D2"を入力します。
3. デバイス"D2"に"12"を入力します。

【図】設定後のデバイスメモリエディタ(原本 p.548)
- `デバイス名(N)`: `D2`
- 一覧の列: `デバイス名` / `+0` `+1` `+2` `+3` `+4` `+5`
- 行 `D2`: `+0` = **12**，他は `0`
- 行 `D10` / `D18` / `D26`: すべて `0`

### コピー&貼り付け (7.3 / 原本 p.548)

**デバイスメモリエディタ上でコピー&貼り付けする場合は，表示中の値がそのままタブ区切りの文字列として，コピー&貼り付けされます。**
**改行コードは，デバイスメモリで表示されている列幅に合わせて挿入されます。**
**数値(10進数形式，16進数形式，および実数)以外の文字列は，"0"が貼り付けられます。**
**Excelへ貼り付ける場合，コピーした文字列のまま表示させるには，Excelのセルの表示形式を"文字列"に設定してください。**

> **Point** (原本 p.548)
> **表示単位形式がビットの場合は，セルをダブルクリックするとデバイス値が切り替わります。**

### 一括設定 (7.3 / 原本 p.549)

連続したデバイスに同じ値を一括で設定します。

**例**

下記の値をワード多点形式で設定します。
デバイス: D8〜D11，デバイス値: 1234

#### 操作手順 (7.3 / 原本 p.549)

1. 表示形式を設定します。(📖 547ページ 表示形式の設定)
2. "デバイス名"に"D8"を入力し，デバイス値を設定する範囲を選択します。
3. [編集]⇒[FILL](ツールバーアイコン)を選択します。
4. "FILL"画面で各項目を設定し，[OK]ボタンをクリックします。

【図】操作の流れ(原本 p.549)

■ 操作前 + "FILL"画面
- デバイスメモリエディタ: `デバイス名(N)` = `D8`，行 `D8` の `+0` `+1` に `1234`，他は `0`
- "FILL"画面
  - `範囲`: `D8` 〜 `D11`
  - `値`: `1234`，`10進`
  - [OK] [キャンセル] ボタン

■ 操作後
- 行 `D8`: `+0` = **1234**，`+1` = **1234**，`+2` = **1234**，`+3` = **1234**，`+4` = `0`，`+5` = `0`
- 行 `D16` / `D24` / `D32`: すべて `0`

### 文字列の設定 (7.3 / 原本 p.550)

デバイスに文字列を設定します。

**例**

下記の値をワード多点形式で設定します。
デバイス: D20，文字列: デバイスメモリ

#### 操作手順 (7.3 / 原本 p.550)

1. 表示形式を設定します。(📖 547ページ 表示形式の設定)
2. "デバイス名"に"D20"を入力し，[編集]⇒[文字列入力]を選択します。
3. "文字列入力"画面で入力し，[OK]ボタンをクリックします。

【図】操作の流れ(原本 p.550)

■ 操作前 + "文字列入力"画面
- デバイスメモリエディタ: `デバイス名(N)` = `D20`，行 `D20`〜`D44` はすべて `0`
- "文字列入力"画面: 入力欄に `デバイスメモリ`，[OK] [キャンセル] [読出し](グレーアウト) ボタン

■ 操作後
- 一覧の列: `デバイス名` / `+5` `+6` `+7` / `文字列`
- 行 `D20`: `+5` = **12514**，`+6` = **12522**，`+7` = `0`，文字列列に `デバイスメモリ.`
- 行 `D28` / `D36` / `D44`: すべて `0`

> **Point** (原本 p.550)
> - **文字列欄への直接入力も可能です。**
> - **"文字列入力"画面の[読出し]ボタンをクリックすると，設定されているデバイスの値(文字列)が1文字ずつ読み出されます。**
>
> 【図】[読出し]ボタンの例(原本 p.550)
> - デバイスメモリエディタ: `デバイス名(N)` = `D20`
>   - 行 `D20`: `+0` = `12487`，`+1` = `12496`，`+2` = `12452`，`+3` = `12473`，`+4` = `12513`，`+5` = `12514`
> - "文字列入力"画面: 入力欄に `デバイ`(1文字ずつ読み出されている途中)，[OK] [キャンセル] [読出し] ボタン

#### 注意事項 (7.3 / 原本 p.550)

**デバイスメモリには，Unicode基本多言語面の文字を使用してください。**
**基本多言語面以外の文字を指定すると，プログラムで正常に表示できない場合があります。**

### デバイスメモリのオールクリア (7.3 / 原本 p.551)

**プロジェクト内で管理しているデバイスメモリデータに設定されているデータを一括で0にクリアします。**

#### 操作手順 (7.3 / 原本 p.551)

**デバイスメモリデータ内の全データを対象にする場合**
[編集]⇒[オールクリア(全デバイス)]を選択します。

**デバイスメモリエディタに表示中のデバイスを対象にする場合**
[編集]⇒[オールクリア(表示中デバイス)]を選択します。

### デバイス初期値との連携 (7.3 / 原本 p.551)

**デバイスメモリは，デバイス初期値への値の登録，およびデバイス初期値からの値の流用ができます。**
**あらかじめ，登録先のデバイス初期値データを作成しておいてください。**
**リモートヘッドユニットでは対応していません。**

#### 操作手順 (7.3 / 原本 p.551)

1. [詳細条件]ボタンをクリックします。
2. 詳細条件内の"デバイス初期値"で"範囲指定する"を選択します。
3. [編集]⇒[デバイス初期値の登録・流用]を選択します。

デバイス初期値エディタが表示されます。デバイス初期値エディタでの操作の詳細は，下記を参照してください。

- デバイスメモリの値をデバイス初期値へ登録する: 📖 558ページ デバイス初期値の設定
- デバイス初期値からデバイスメモリへ値を流用する: 📖 558ページ デバイスメモリへの登録

## 7.5 デバイスメモリデータのエクスポート/インポート (7.5 / 原本 p.553-554)

デバイスメモリデータをCSVファイルにエクスポートできます。
また，エクスポートしたCSVファイルをインポートできます。

### エクスポート (7.5 / 原本 p.553)

デバイスメモリデータをCSVファイルへエクスポートする操作手順を示します。
**データをエクスポートするには，あらかじめ"表示形式"画面の"表示単位形式"に"ワード多点"を設定する必要があります。**(📖 547ページ 表示形式の設定)

#### 操作手順 (7.5 / 原本 p.553)

1. デバイスメモリエディタでエクスポートするデバイスの範囲を選択します。
2. [編集]⇒[ファイルへエクスポート](ツールバーアイコン)を選択します。
3. "エクスポート設定"画面でエクスポートする範囲を選択します。
   **"範囲指定"を選択した場合はエクスポートする範囲の先頭デバイス番号と最終デバイス番号を入力してください。**
4. 必要に応じて"設定済みデバイスが含まれる行のみエクスポートする"にチェックを入れ，[OK]ボタンをクリックします。
5. "ファイルへエクスポート"画面で各項目を設定し，[保存]ボタンをクリックします。

> **Point** (原本 p.553)
> **デバイス値の表示形式に従って，デバイスメモリデータがCSVファイルへエクスポートされます。**
> **必要に応じて表示形式を設定してください。ただし，"表示単位形式"には"ワード多点"を設定する必要があります。**
> 表示形式を設定する方法は，下記を参照してください。
> 📖 547ページ 表示形式の設定

### インポート (7.5 / 原本 p.554)

デバイスメモリデータのCSVファイルをインポートする操作手順を示します。
**GX Works3でエクスポートしたデバイスメモリデータのCSVファイルのみをインポートできます。**

#### 操作手順 (7.5 / 原本 p.554)

1. [編集]⇒[ファイルのインポート](ツールバーアイコン)を選択します。
2. "ファイルのインポート"画面でインポートするCSVファイルを選択し，[開く]ボタンをクリックします。
3. 表示されたメッセージを確認し，必要に応じて"インポート実行前の設定"の"インポートするデバイス種別のメモリデータをすべてクリアする"にチェックを入れます。
4. [OK]ボタンをクリックします。

#### インポート前にデバイスメモリデータをクリアする (7.5 / 原本 p.554)

**"インポート実行前の設定"の"インポートするデバイス種別のメモリデータをすべてクリアする"にチェックを入れると，インポート前にデバイスメモリデータがクリアされます。**
チェック状態ごとの動作を示します。

| チェック状態 | 動作 |
|---|---|
| あり | **インポートするデバイス種別のすべてのデバイスメモリデータを一度クリアしてから，CSVファイルに記載があるデバイスメモリデータのみを書き込みます。**<br>(例)D0〜D39までがCSVファイルに記載がある場合，チェックを入れてインポートすると，Dデバイスのすべてのデバイスメモリデータをクリアします。その後，D0〜D39までのデバイスメモリデータを書き込みます。 |
| なし | **デバイスメモリデータをCSVファイルに記載があるデバイスメモリデータで上書きします。**<br>**CSVファイルに記載のないデバイスメモリデータは変更しません。** |

> 補足(本プロジェクト): 行数は原本の2行と一致。

#### 注意事項 (7.5 / 原本 p.554)

- **インポートするCSVファイルを編集した場合，正常にインポートできないことがあります。**
- **インポート後，意図したデバイスメモリデータが正しく反映されたことを確認してください。**
- **複数のデバイス種別のデバイスメモリデータは同時にインポートできません。**
  **デバイス種別ごとにデバイスメモリデータをインポートしてください。**
