## 2.1 起動と終了 (2.1 / 原本 p.55-56)

GX Works3の起動/終了の操作方法を説明します。

### 起動 (2.1 / 原本 p.55)

#### 操作手順 (2.1 / 原本 p.55)

Windowsのスタートで"MELSOFT"からGX Works3を起動します。

#### 重要なお知らせのメッセージ (2.1 / 原本 p.55)

**下記の条件を満たす場合，GX Works3の起動時に「重要なお知らせがあります。」と記載されたメッセージが表示されることがあります。**

- **Version 1.012N以降のMELSOFT Update Managerがインストールされている。**
- **パソコンをインターネットに接続している。**

このメッセージが表示された場合は，内容を確認し，必要に応じて処置を行ってください。

#### MELSOFTカスタマーエクスペリエンス向上プログラム (2.1 / 原本 p.55)

**GX Works3起動時，MELSOFTカスタマーエクスペリエンス向上プログラムへの参加を確認する画面が表示されます。(参加を確認済みの場合は表示されません。)**
参加いただいた場合，お客様の使用状況に関する情報を収集し，MELSOFT製品の品質およびパフォーマンスの向上に活用させていただきます。
使用状況に関する情報の収集にご協力ください。
**参加を確認した後，下記の操作により参加または不参加を変更できます。**

**操作手順**

1. [ヘルプ]⇒[MELSOFTカスタマーエクスペリエンス向上プログラム]を選択します。
2. 表示された画面で下記のいずれかの項目を選択し，[OK]ボタンをクリックします。
   - MELSOFTカスタマーエクスペリエンス向上プログラムに参加します。
   - 参加しません。

### 表示位置とウィンドウサイズを指定してGX Works3を起動する (2.1 / 原本 p.56)

**コマンドラインに下記のオプションを指定することで，GX Works3起動時の表示位置とウィンドウサイズを指定できます。**
**また，GX Works3起動後にオフラインモニタを開始することもできます。**

- **全画面表示で起動する。**
  `-WINDOWSIZE`
- **表示位置(left<sup>*1</sup>，top<sup>*2</sup>)とウィンドウサイズ(width，height)を指定して起動する。**
  `-WINDOWSIZE=left,top,width,height`
- **起動後，オフラインモニタで使用するレコーディングファイルの選択画面を表示する。**
  `-OFFLINEMONITOR`
- **起動後，ファイルのパス(path)に指定したレコーディングファイルのオフラインモニタを開始する。**
  `-OFFLINEMONITOR=path`

> *1 **「left」には，メインディスプレイの左上を座標(0,0)とし，右方向を正とした整数値を入力してください。**
> **0を指定した場合，Windowsの設定によりウィンドウ枠が透過表示されるため，画面左側に数ピクセル分の隙間が発生します。**
> **(Windowsの設定でハイコントラストをオンにすると，隙間は発生しません。)**
> *2 **「top」には，メインディスプレイの左上を座標(0,0)とし，下方向を正とした整数値を入力してください。**

**例** — コマンドプロンプトからGX Works3を起動する場合，下記のように「gxw3」の後ろにオプションを指定します。
**なお，カレントディレクトリには，GX Works3のインストールフォルダーを指定してください。**

```
・全画面表示で起動する。
gxw3 "-WINDOWSIZE"

・指定した表示位置とウィンドウサイズで起動し，GX Works3プロジェクト(D:\Files\Project1.gx3)を開く。
gxw3 "-WINDOWSIZE=10,20,800,600" "D:\Files\Project1.gx3"

・起動後，オフラインモニタで使用するレコーディングファイルの選択画面を表示する。
gxw3 "-OFFLINEMONITOR"

・起動後，レコーディングファイル(D:\Files\record.melrc)のオフラインモニタを開始する。
gxw3 "-OFFLINEMONITOR=D:\Files\record.melrc"

・全画面表示で起動し，レコーディングファイル(D:\Files\record.melrc)のオフラインモニタを開始する。
gxw3 "-WINDOWSIZE" "-OFFLINEMONITOR=D:\Files\record.melrc"
```

**例** — ショートカットからGX Works3を起動する場合，ショートカットのプロパティの"リンク先"に下記のようにオプションを指定します。

```
・全画面表示で起動する。
"C:\Program Files (x86)\MELSOFT\GPPW3\GXW3.exe" "-WINDOWSIZE"

・指定した表示位置とウィンドウサイズで起動し，GX Works3プロジェクト(D:\Files\Project1.gx3)を開く。
"C:\Program Files (x86)\MELSOFT\GPPW3\GXW3.exe" "-WINDOWSIZE=100,50,1200,900" "D:\Files\Project1.gx3"

・起動後，オフラインモニタで使用するレコーディングファイルの選択画面を表示する。
"C:\Program Files (x86)\MELSOFT\GPPW3\GXW3.exe" "-OFFLINEMONITOR"

・起動後，レコーディングファイル(D:\Files\record.melrc)のオフラインモニタを開始する。
"C:\Program Files (x86)\MELSOFT\GPPW3\GXW3.exe" "-OFFLINEMONITOR=D:\Files\record.melrc"

・全画面表示で起動し，レコーディングファイル(D:\Files\record.melrc)のオフラインモニタを開始する。
"C:\Program Files (x86)\MELSOFT\GPPW3\GXW3.exe" "-WINDOWSIZE" "-OFFLINEMONITOR=D:\Files\record.melrc"
```

## 2.2 表示言語の切替え (2.2 / 原本 p.57)

**GX Works3は複数の言語の表示に対応しているため，同じパソコンでメニューなどの表示言語を切り替えて使用できます。**

### 画面表示 (2.2 / 原本 p.57)

[表示]⇒[表示言語切替え(Display Language)]を選択します。

### 注意事項 (2.2 / 原本 p.57)

- **OSと，設定した表示言語が異なる場合には，文字切れなどが発生し画面が正しく表示できない場合があります。**
- **表示言語切替えを行う場合，切り替える言語の補助フォントが必要です。** 補助フォントの追加は下記で行います。
  - Windowsの設定で，[システム]⇒[オプション機能]⇒[オプション機能を追加する]
- **任意で入力した文字は，表示言語を切り替えても，切り替わりません。**

### ドッキングウィンドウのドッキング/フロートの切替え (2.3 / 原本 p.59)

- **ドッキング表示: フロート表示されているドッキングウィンドウのタイトルバーを，メインフレーム内のガイダンスへドラッグ&ドロップすると，メインフレームに組み込まれます。**
- **フロート表示: ドッキングされているウィンドウのタイトルバーを任意の場所へドラッグすると，メインフレームから独立して表示されます。**

### ワークウィンドウのドッキング/フロートの切替え (2.3 / 原本 p.59)

- **フロート表示: ドッキングされているワークウィンドウを選択し，[ウィンドウ]⇒[フローティング]を選択します。**

> **Point** (原本 p.59)
> **1度ドッキングしたウィンドウは，タイトルバーをダブルクリックすることで，ドッキング表示とフロート表示の切替えが可能です。**

### ワークウィンドウ同士の結合 (2.3 / 原本 p.60)

**フロート表示されているワークウィンドウ同士を近付けたときに，ガイダンスが表示されます。**
**このガイダンスへワークウィンドウをドラッグ&ドロップすると，ワークウィンドウ同士を結合できます。**

### ワークウィンドウの移動 (2.3 / 原本 p.60)

**フロート表示されているワークウィンドウを選択し，Windowsキー + ←/→/↑/↓ を押すと，ワークウィンドウを上下左右に移動できます。**

### ツールバーのカスタマイズ/リセット (2.3 / 原本 p.60)

### FX5CPUで「テンポラリエリア超過」エラーが発生する場合 (2.9 / 原本 p.99)

テンポラリエリアは，ファンクションブロックまたはファンクションの引数の受渡し，および計算のための一時領域として使用されます。
プログラムファイルのプログラムブロックごとに，テンポラリエリアとして確保できるメモリ容量は決まっています。その容量を超過するプログラムブロックを含むプログラムファイルをCPUユニットへ書き込んだ場合，「テンポラリエリア超過」エラーが発生します。
エラーが発生した場合，下記のいずれかの方法でプログラムブロックあたりのテンポラリエリアの使用量を減らしてください。

- [ツール]⇒[オプション]⇒"変換"⇒"基本設定"⇒"動作設定"⇒"ステップ数の最適化"⇒"テンポラリエリアをまとめて確保してステップ数を最適化する"を"いいえ"に設定する
- 1つのプログラムブロックを複数のプログラムブロックに分割する

また，下記のCPUパラメータを"128000ステップ"に設定することで，テンポラリエリアの容量を700ワードから32767ワードに拡張できます。

- "プログラム設定"⇒"プログラム容量設定"

詳細は，下記を参照してください。

#### 大量のデータを印刷する場合 (2.10 / 原本 p.104)

**大量のデータを印刷すると，全く印刷されない，または途中までしか印刷されない場合があります。これは，プリンタードライバやWindowsのプリントスプーラの制限によるものです。この場合は，下記のいずれかの方法で印刷してください。**

- **印刷範囲指定で範囲指定を設定するなどして分割**
- **プリンターのプロパティの詳細設定で，"プリンターに直接印刷データを送る"を設定**(Windowsの設定で[Bluetoothとデバイス]⇒[プリンターとスキャナー]から開く)
- **"プリンタの設定"画面の"印刷ジョブ"の"出力方法"で，"印刷項目別で出力する"を設定**

#### 印刷内容をファイルに出力する場合 (2.10 / 原本 p.105)

- **印刷内容をファイルに出力すると，"ファイル名を付けて保存"画面がほかの画面の背面に表示される場合があります。**
  **Alt + Tab または Alt + Esc の操作で，前面に表示してください。**
- **"ファイル名を付けて保存"画面が表示されている間，GX Works3の操作をすると，GX Works3が応答なしになります。**
  **メッセージが表示されたら，"プログラムの応答を待ちます"を選択してください。"プログラムを終了します"を選択すると，保存していないデータが失われます。**

> 補足(本プロジェクト): `Alt + Tab` `Alt + Esc` はキーアイコンで表記されており，
> PDFのテキスト抽出では**完全に欠落する**。原本 p.105 を200dpiで画像化し，目視で読み取って転記した。
