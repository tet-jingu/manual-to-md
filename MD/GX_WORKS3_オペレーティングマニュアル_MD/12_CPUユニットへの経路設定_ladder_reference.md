# 12 CPUユニットへの経路設定 (12章冒頭 / 原本 p.681)

GX Works3を使用してパソコンからCPUユニットにアクセスするときの，接続先を設定する方法を説明します。

---

## 12.1 接続先指定について (12.1 / 原本 p.681-682)

接続先指定での，パソコン側，シーケンサ側のI/Fや経由するネットワークなど，CPUユニットとアクセスするための通信経路の設定方法を説明します。
**接続先の設定は最大128個作成できます。**
**プロジェクトの機種は，アクセスするCPUユニットの機種に合わせる必要があります。**

### 接続先の設定を変更する (12.1 / 原本 p.681)

#### 画面表示 (12.1 / 原本 p.681)

接続先ウィンドウでデータを選択し，ダブルクリックします。
**[オンライン]⇒[現在の接続先]を選択した場合，現在の接続先を変更します。**

【図】接続経路の概念図と"接続先指定 Connection"画面(原本 p.681)

■ 概念図 — 左から順に
- `パソコン側I/F`(パソコン)
- `シーケンサ側I/F`(直結するCPUユニット) ← ここまでが **他局なし**
- `ネットワーク通信経路`(CC-Link IEフィールドネットワーク経由のCPUユニット)
- `異種ネットワーク通信経路`(さらにCC-Link経由のCPUユニット) ← ここまでが **他局**

■ 接続先ウィンドウ
- `現在の接続先`: `Connection`(黄色ハイライト)
- `すべての接続先`: `Connection`(◯=通常使う接続先) / `Connection1`(●) / `Connection2`(●)
- 下部タブ: `接続先` / `ナビゲーション`

■ "接続先指定 Connection"画面(行ごとにアイコンが並ぶ)
- `パソコン側 I/F`: **シリアル USB**(黄色=選択中) / `CC IE Cont NET/10(H) ボード` / `CC-Link ボード` / `Ethernet ボード` / `CC IE TSN/Field ボード` / `iQ-Rシリーズ バス`
  - 直下に `USB` の表示
- `シーケンサ側 I/F`: **CPUユニット**(黄色) / `CC IE Cont NET/10(H)` / `CC-Link` / `Ethernet` / `C24` / `GOT` / `CC IE TSN/Field` / `ヘッドユニット`
  - 右に `CPUモード`: `RCPU/MXR`
- `他局指定`: `他局指定無し` / `他局(単一ネットワーク)` / **`他局(異種ネットワーク)`**(黄色)
  - `タイムチェック(秒)`: `30`，`リトライ回数`: `0`
  - 右に [接続経路一覧(L)...] [CPUユニット直結設定(D)] [通信テスト(T)] ボタン
- `ネットワーク通信経路`: `CC IE Cont NET/10(H)` / **`CC IE TSN CC IE Field`**(黄色) / `Ethernet` / `CC-Link` / `C24`
  - `ネットワークNo`: `1`，`局番`: `0`
  - 右に `CPU形名` / `詳細` の表示欄と [システムイメージ(G)...] ボタン
- `異種ネットワーク通信経路`: `CC IE Cont NET/10(H)` / `CC IE TSN CC IE Field` / `Ethernet` / **`CC-Link`**(黄色) / `C24`
  - `他局アクセス中です。` `先頭 I/O`: `0`，`局番`: `0`
- `対象システム`: `マルチCPU指定`(1/2/3/4のアイコン)，`対象CPU`: `指定なし`，`二重化CPU指定`(プルダウン)
- [OK] [キャンセル] ボタン

> **Point** (原本 p.681)
> - **設定画面上でアンダーラインが付いている項目は，ダブルクリックして詳細設定が可能です。**
> - **アイコンが黄色になっている項目は，設定済みを示します。**
> - **MXコントローラおよびFX5CPUの場合，設定できない接続先経路のアイコンは表示されません。**
> - **FX5CPUのプロジェクトにおいて，下記のオプションを"はい"に設定している場合，"接続先指定"画面が表示される前に"簡易接続先設定"画面が表示されます。**
>   - [ツール]⇒[オプション]⇒"オンライン"⇒"接続先指定"⇒"動作設定"⇒"簡易接続先設定画面を表示する"

#### 表示内容 (12.1 / 原本 p.682)

| 項目(大) | 項目(小) | 説明 |
|---|---|---|
| 他局指定 | 他局指定無し | **パソコンに直接接続しているCPUユニットにアクセスする場合に指定します。** |
| 他局指定 | 他局(単一ネットワーク)<sup>*1</sup> | **1種類のネットワーク(多階層システムを含む)を経由して，他局のCPUユニットにアクセスする場合に指定します。**<br>**Ethernet，CC-Link IE コントローラネットワーク，およびCC-Link IEフィールドネットワークは同種とみなされます。これらが混在しているシステムにアクセスする場合は，単一ネットワークを指定してください。** |
| 他局指定 | 他局(異種ネットワーク)<sup>*1</sup> | **2種類のネットワークを介して他局のCPUユニットにアクセスする場合に指定します。** |
| ネットワーク通信経路 | (小項目なし) | 他局アクセスするときに経由するネットワークのネットワーク種別，ネットワークNo.，局番，先頭I/Oを選択します。設定項目は，選択したネットワーク種別により異なります。 |
| 異種ネットワーク通信経路 | (小項目なし) | アクセスするネットワークのネットワーク種別，ネットワークNo.，局番，先頭I/Oを選択します。設定項目は，選択したネットワーク種別により異なります。 |
| 対象システム | (小項目なし) | ・マルチCPU指定: マルチCPUシステムを構成しているときのアクセス先を指定します。<br>・二重化CPU指定: 接続するCPUユニットの系を選択します。 |

#### 注意事項 (12.1 / 原本 p.682)

- **"接続先指定"画面で設定できない接続先にはアクセスできません。**
- MELSECNET/Hネットワークユニットを使用する場合の注意事項は，下記を参照してください。

### 接続先の設定を追加する (12.1 / 原本 p.682)

接続先の設定を新規に追加します。

#### 操作手順 (12.1 / 原本 p.682)

1. 接続先ウィンドウで右クリック⇒ショートカットメニュー [新しい接続先作成]を選択します。
2. 各項目を設定し，[OK]ボタンをクリックします。

### 接続先を切り替える (12.1 / 原本 p.682)

通常使用する接続先の設定を切り替えます。

#### 操作手順 (12.1 / 原本 p.682)

1. 接続先ウィンドウの"すべての接続先"の中から使用する接続先を選択します。
2. 右クリック⇒ショートカットメニュー [通常使う接続先として指定する]を選択します。

### 設定した接続経路のイメージ表示 (12.1 / 原本 p.682)

**[システムイメージ]ボタンをクリックすると，設定した接続経路がイラストで表示され，内容が確認できます。**

#### 注意事項 (12.1 / 原本 p.682)

**LHCPUでは対応していません。**

### パソコン側のEthernetアダプタを指定する場合 (12.2 / 原本 p.684)

**Ethernetポート直結接続時に使用するパソコン側のEthernetアダプタを指定できます。**
**複数のEthernetアダプタが存在する場合，通信するEthernetアダプタを必ず指定してください。**

#### 操作手順 (12.2 / 原本 p.684)

1. "接続先指定"画面の[CPUユニット直結設定]ボタンをクリックします。
2. 表示される"CPUユニット直結設定"画面でアダプタを選択し，[はい]ボタンをクリックします。

下記はRCPUの画面例です。

> **Point** (原本 p.684)
> - **MXコントローラ，RCPU，またはLHCPUの場合，指定したEthernetアダプタに割り当てられたIPアドレスがプロジェクトファイルに保存されます。そのため，アダプタを変更しても，変更後のアダプタに割り当てられたIPアドレスが同じであれば，そのアダプタ名が設定内容に反映されます。**
> - **FX5CPUの場合，アダプタの設定はパソコンのログオンユーザ単位で保存されます。(プロジェクトファイルには保存されません)**

#### 注意事項 (12.2 / 原本 p.684)

**■警告メッセージが表示される場合**
**WindowsのファイアウォールによってGX Works3の機能がブロックされていることを示す警告メッセージが表示される場合があります。**
**[アクセスを許可する]ボタンをクリックし，アクセスを許可して操作を続けてください。**

**■同一のIPアドレスが複数表示される場合**
**"シーケンサ側I/F CPUユニット詳細設定"画面の[検索]ボタンをクリックすると，接続先CPUの一覧に重複したIPアドレスが表示される場合があります。**
**その場合，"CPUユニット直結設定"画面でアダプタを選択してください。**(📖 684ページ パソコン側のEthernetアダプタを指定する場合)

### WindowsファイアウォールでGX Works3の通信を許可していない場合 (12.2 / 原本 p.685)

**Windowsファイアウォールが有効でGX Works3の通信を許可していない場合は，通信できずにタイムアウトになる場合があります。**
通信を許可する場合は，下記の操作手順を参考に設定してください。
また，その他のファイアウォール機能付きのセキュリティソフトを使用している場合は，ソフトのマニュアルを参照し，GX Works3の通信を許可してください。

#### 操作手順 (12.2 / 原本 p.685)

1. Windowsのコントロールパネルで，[システムとセキュリティ]⇒[Windows ファイアウォールによるアプリケーションの許可]を選択します。
2. [設定の変更]ボタンをクリックし，[別のアプリの許可]ボタンをクリックします。
3. "アプリの追加"画面で[参照]ボタンをクリックし，GX Works3をインストールしたフォルダー内の`"GXW3.exe"`を選択後，[追加]ボタンをクリックします。
   インストール時にインストールフォルダーを変更していない場合は下記となります。
   - `C:\Program Files (x86)\MELSOFT\GPPW3`
4. 一覧に追加されたGX Works3<sup>*1</sup>の"ドメイン"，"プライベート"，"パブリック"にチェックを入れます。

> *1 **Ethernetポート直結接続の前にネットワーク上のCPUユニット/ネットワーク上のEthernetユニットを検索し，Windowsファイアウォールに対してアクセス許可を設定している場合，"gxw3"と表示されることがあります。**

### RCPU/LHCPUとGX Works3を接続している場合 (12.2 / 原本 p.685)

**指定したEthernetアダプタの内容は，その他のMELSOFT製品に反映されません。**
**Ethernetアダプタを指定しているプロジェクトを別のパソコンで開くと，"パソコン側I/F Ethernetボード詳細設定"画面の"アダプタ"の選択項目が"指定なし"に変更されます。**
**接続先を再度設定してください。**

また，"アダプタ"のプルダウンリストにアダプタ名が表示されない場合，次のような理由が考えられます。

- **Windowsの"アダプターの設定の変更"でEthernetアダプタが無効になっている**
- **LANケーブルが接続されていない**
- **電源に異常がある**
- **故障や誤作動が検出されている**

**設定内容やEthernetボードの接続および電源の状態を確認する，またはEthernetボードを交換するなどの処置を行ってください。**

### FX5CPUとGX Works3を接続している場合 (12.2 / 原本 p.686)

**[CPUユニット直結設定]ボタンをクリックして接続先を設定しても，通信が確立しない場合があります。**
**下記の手順で，パソコンのIPアドレスを設定してください。**

#### 操作手順 (12.2 / 原本 p.686)

1. Windowsのコントロールパネルで，[ネットワークとインターネット]⇒[ネットワークと共有センター]⇒[アダプターの設定の変更]を選択します。
2. 該当のネットワーク接続を選択し，右クリック⇒ショートカットメニュー [プロパティ]を選択します。
3. 表示されたプロパティ画面で，"インターネットプロトコルバージョン4(TCP/IPv4)"を選択し，[プロパティ]ボタンをクリックします。
   "インターネットプロトコルバージョン4(TCP/IPv4)のプロパティ"画面が表示されます。
4. **GX Works3をインストールしたパソコンとFX5CPUのネットワーク部が同一となるように設定します。**
5. **パソコンを再起動し，ネットワーク設定を有効にします。**

【図】IPアドレスの設定方法(原本 p.686)
```
          ネットワーク部   ホスト部        ネットワーク部   ホスト部
FX5CPUの  ┌──────────┐ ┌────┐        ┌──────────┐ ┌────┐  パソコン
デフォルト値 │          │ │    │        │          │ │    │
          └──────────┘ └────┘        └──────────┘ └────┘
               └──── 同じ値に設定します。 ────┘
                            └── 同じ値にならないように設定します。 ──┘
```

## 12.11 CPUユニットとの通信における注意事項 (12.11 / 原本 p.700)

CPUユニットとの通信における注意事項を説明します。
本節に記載の内容のほかに，各項で記載している注意事項も参照してください。

### ネットワークシステム(単一/複数)を経由して通信する場合 (12.11 / 原本 p.700)

**ネットワークシステムを経由してRCPUにアクセスする場合は，接続局をRCPUまたはQCPU(Qモード)で構成してください。**
**ただし，中継局はRCPUで構成してください。**

接続局: パソコンから直接接続する局
中継局: 経由するネットワークシステムの各局

### USBケーブルを使用してCPUユニットと通信する場合 (12.11 / 原本 p.700)

#### USBケーブルの脱着，CPUユニットのリセット，電源のON/OFF (12.11 / 原本 p.700)

**CPUユニットと交信中にUSBケーブルの脱着，CPUユニットのリセット，電源のON/OFFを頻繁に行うと，通信エラーが発生し復旧しない場合があります。**
**そのため，これらを操作する場合は，極力GX Works3をオフライン状態にします。** オフライン状態とは，下記以外の状態を示します。

- シーケンサへの書込み/シーケンサからの読出し，モニタ，診断など

**もし，通信エラーが復旧しない場合は，USBケーブルを1度完全に抜いて5秒以上経過後に再度装着してください。**(本操作後も，初回交信時にエラーとなる場合がありますが，2回目以降は正常に動作します。)
**警告メッセージの[OK]ボタンをクリックし，USBケーブルを1度はずしてください。**

#### パソコンの機種，USBケーブルの組合せ (12.11 / 原本 p.700)

**パソコンの機種，USBケーブルなどの組合せによっては，通信エラーが発生する場合があります。**
**その場合は，表示されるメッセージを参考に再度操作してください。**

### その他の注意事項 (12.11 / 原本 p.700)

#### RS-232ケーブルでの高速通信 (12.11 / 原本 p.700)

**パソコンのシリアルポート(パソコン側I/F)で，伝送速度を変更して高速通信を行う場合，パソコンの性能によっては交信ができない場合があります。または，交信リトライが発生し，交信が遅くなる場合があります。**
**高速通信で交信ができない場合は，伝送速度を下げて通信を行ってください。**

#### パソコンのレジューム機能，サスペンド設定，省電力機能，スタンバイモード (12.11 / 原本 p.700)

**上記を設定してCPUユニットと交信すると，通信エラーが発生する場合があります。**
**そのため，CPUユニットと交信する場合は，これらの設定を行わないでください。**
