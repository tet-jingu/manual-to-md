## 7. 共通事項 (7章 / 印刷 p.399 / 原本 p.407)

### 7.1 通信ケーブル (7.1 / 印刷 p.399 / 原本 p.407)

> CC-Link の通信ケーブルは、CC-Link Ver1.10 対応専用ケーブル（FANC-SBH、FANC-SB など）を使用してください。

#### 7.1.1 接続例 (7.1.1 / 印刷 p.399 / 原本 p.407)

【図】CC-Link 接続例(マスターユニット − スレーブ機器 − SCON-CC-Link 仕様)。詳細は原本 p.407 を参照。
- 左から「マスターユニット」「スレーブ機器」「SCON -CC-Link 仕様」の3台を接続。各ユニットの端子は上から DA、DB、DG、SLD、FG。
- DA、DB、DG は各ユニットの同名端子どうしを接続(ケーブルの DA・DB はツイスト線として描画)。SLD(シールド)も各ユニット間で接続。
- マスターユニットの DA−DB 間、および SCON の DA−DB 間に「終端抵抗」を接続。
- マスターユニット、スレーブ機器、SCON の FG はそれぞれ接地記号に接続。マスターユニット側に「D種接地（第三種接地）」の注記。
- 図中注記(原文): 「終端になる場合は、終端抵抗の接続が必要です。」
- 図中注記(原文): 「CC-Link 専用ケーブルの種類により終端抵抗は異なります。」
  - 「・ケーブル FANC-SBH…130Ω1/2W（CC-Link 専用高性能ケーブル）」
  - 「・ケーブル FANC-SB……110Ω1/2W（CC-Link 専用ケーブル）」
- 図中注記(原文): 「SLDとFGは内部で接続されています。」

#### 7.1.2 終端抵抗 (7.1.2 / 印刷 p.399 / 原本 p.407)

> CC-Link システムの両端ユニットには、終端抵抗を接続する必要があります。
> コネクターの DA、DB 間に付属の抵抗を接続します。
>
> （注）CC-Link 専用ケーブルの型式により、抵抗値は異なります。
> ①ケーブル：FANC-SBH ………………… 130Ω　1/2W（CC-Link 用高性能ケーブル）
> ②ケーブル：FANC-SB ………………… 110Ω　1/2W（CC-Link 専用ケーブル）
>
> 詳細については、［マスターユニット側の取扱説明書］参照
