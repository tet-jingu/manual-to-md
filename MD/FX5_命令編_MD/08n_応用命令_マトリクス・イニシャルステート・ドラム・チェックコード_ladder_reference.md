## 8.19 マトリクス入力命令 (原本 p.809-812)

### マトリクス入力 MTR (8.19 / 原本 p.809-812)

対応機種: FX5S / FX5UJ / FX5U / FX5UC

8点入力×(n)点出力(トランジスタ)のマトリクス入力を時分割で読み込みます。

#### 書式 (8.19 / 原本 p.809)

| 言語 | 記述 |
|---|---|
| ラダー | 【図】命令ボックス `MTR (s) (d1) (d2) (n)` |
| ST | ENO:=MTR(EN,s,n,d1,d2); |
| FBD/LD | 【図】EN・s・n 入力、ENO・d1・d2 出力のボックス |

#### 設定データ (8.19 / 原本 p.809)

#### 機能 (8.19 / 原本 p.810-811)

- 8点(n)列の入力信号を(s)で指定した8点の入力と(d1)で指定したトランジスタ出力を時分割制御して順次読込み(d2)で指定したデバイスへ出力します。
- 各出力は10msまたは20msごとに順次割込みで即時入出力処理が行われます。
- マトリクス入力の接続例は，下記マニュアルを参照してください。
  → MELSEC iQ-F FX5S/FX5UJ/FX5U/FX5UC ユーザーズマニュアル(ハードウェア編)

【図】マトリクス入力の接続例とタイミング(原本 p.810 上)
- CPUユニット: 入力(X)[シンク]、出力(Y)[シンク]。入力端子 24V / 0V / S/S / (S) / (S)+1 / (S)+2 / (S)+3 / (S)+4 / (S)+5 / (S)+6 / (S)+7。出力端子 COM / (d1) / (d1)+1 / (d1)+2 … (d1)+7。
- 第1列: スイッチ (d2)，(d2)+1 … (d2)+7 がダイオードを介して (S)～(S)+7 に接続され、列の共通線は出力 (d1) へ。
- 第2列: スイッチ (d2)+10，(d2)+11 … (d2)+17 がダイオードを介して (S)～(S)+7 に接続され、列の共通線は出力 (d1)+1 へ。
- ダイオード: 0.1A(50V)。出力は (n)点占有。
- タイミングチャート: 指令接点ON中、(d1) が ①③⑤、(d1)+1 が ②④⑥ と交互に20msずつON。①の間に「第１列入力取込み」、②の間に「第２列入力取込み」。
- SM8029(完了実行): 最終列(②)の取込み後にONし、その後ONを継続(図では指令接点OFFまでON)。

- (n)=3点の出力(Y20，Y21，Y22)が順次繰返してONし，そのつど第1列，第2列，第3列の入力8点が順次繰返して取込まれ，M30～M37，M40～M47，M50～M57へ格納されるプログラム例です。配線については，下記マニュアルを参照してください。
  → MELSEC iQ-F FX5S/FX5UJ/FX5U/FX5UC ユーザーズマニュアル(ハードウェア編)

```
     LD    M0
     MTR   X20 Y20 M30 K3     (s)入力番号 (d1)出力番号 (d2)ON出力先 (n)列数
```

【図】3列の配線例とタイミング(原本 p.810 下)
- CPUユニット(シンク入力/シンク出力): 入力 24V / 0V / S/S / X20～X27、出力 COM / Y20～Y27。
- 第1列: M30～M37 のスイッチ(ダイオード付き)が X20～X27 に接続、共通線は Y20 へ。
- 第2列: M40～M47 のスイッチが X20(図示なし)・X21～X27 に接続、共通線は Y21 へ。
- 第3列: M50～M57 のスイッチが X20(図示なし)・X21～X27 に接続、共通線は Y22 へ。
- ダイオード: 0.1A(50V)(各列)。
- タイミングチャート: M0 ON中、Y20 が ①④、Y21 が ②⑤、Y22 が ③⑥ の順に20msずつON。①④で「第1列入力取込み」、②⑤で「第2列入力取込み」、③⑥で「第3列入力取込み」。
- SM8029(完了実行): 第3列(③)の取込み後にONし、その後ONを継続。

- 関連デバイスを以下に示します。

| デバイス | 名称 | 内容 |
|---|---|---|
| SM8029 | 命令実行完了 | ON：第n列(最終)マトリクス入力動作後にONします。<br>OFF：第1列～第n列(最終)マトリクス入力中はOFFとなります。 |

#### 注意事項 (8.19 / 原本 p.811)

- (s)で指定された入力を先頭として8点の入力が占有されます。
- (d2)に出力を指定されるときは(d1)で指定された出力番号((n)点占有)と重複しないように注意してください。
- MTR命令は，プログラム中に1個のみ使用できます。
- スイッチ1個に対して必ず0.1A/50Vのダイオードが1本必要になります。
- 出力はトランジスタ出力を使用してください。
- 命令実行中にRUN中書込みをした場合は，END処理で制御権を解放します。次に制御権を獲得する命令は，次のスキャンで最初に実行したMTR命令となります。
- MTR命令は，通常指令入力を常時ONで使用してください。

```
     LD    M○○               (常時ON)
     MTR   X20 Y40 M0 K8
```

- MTR命令では通常下記の入力を使用してください。
  - FX5S/FX5UJ CPUユニット：X10以降
  - FX5U/FX5UC CPUユニット：X20以降
- 上記の入力以外の場合，取込みスピードは速くなりますが，出力トランジスの回復時間が長いこと，入力感度が高いことにより誤入力することがあります。10ms間隔で入力を行うため，ユニットパラメータ設定の入力応答時間は，5msに変更してください。そのためMTR命令で使用するトランジスタ出力にプルアップ抵抗(3.3kΩ/0.5W)を接続してください。プルアップに使う電源は，下表の電源を使用してください。

> 要確認: 「出力トランジスの回復時間」は原本(テキスト・画像とも)の表記のまま。「トランジスタ」の誤記と思われます。

| シーケンサ | トランジスタ出力のプルアップに使用する電源 |
|---|---|
| AC電源タイプのシーケンサ | サービス電源 |

**例**
FX5U-64MT/ES(シンク入力/シンク出力)の場合

【図】FX5U-64MT/ES のプルアップ接続例(原本 p.811)
- 入力端子 24V / S/S / 0V / X0～X7 がマトリクス回路(前ページ参照)に接続。
- トランジスタ出力 COM5 / Y20～Y27 がマトリクス回路に接続。
- Y20～Y27 の各出力に 3.3kΩ/0.5W のプルアップ抵抗(8本)を接続し、プルアップ抵抗の反対側は 24V(サービス電源)へ接続。

- 8行×8列=64点の入力で80ms，または160msの取込み周期で動作するため，各入力信号のON/OFF幅は次の値以上が必要となります。

【図】(1) ON幅 80ms・OFF幅 80ms / (2) ON幅 160ms・OFF幅 160ms

| | 条件 | |
|---|---|---|
| (1) | FX5S/FX5UJ CPUユニット: X0～X7使用時 | FX5U/FX5UC CPUユニット: X0～X17使用時 |
| (2) | FX5S/FX5UJ CPUユニット: X10以降を使用時 | FX5U/FX5UC CPUユニット: X20以降を使用時 |

- モード選択用スイッチは，すべて使用する必要がありません。使用しないスイッチは，空番(他の用途で使用できません)としてください。

#### IST命令等価回路 (8.20 / 原本 p.815)

- IST命令によって自動的に制御される特殊リレー (SM)やイニシャルステート(S0～S9)の詳細は，次の等価回路で示すとおりです。(参考知識としてご一読してください｡) なお，この等価回路は，プログラム作成をすることはできません。

【図】等価回路の書き起こし(プログラム作成はできない回路。`→[S n]` は図の二重枠のステート S n への移行を表す書き起こし用の表記)

```
     LD     X24          連続
     AND    SM8041
     OR     X26          自動スタート
     ANI    X27          ストップ
     LD     X22          歩進
     OR     X23          一巡
     OR     X24          連続
     ANB
     OUT    SM8041       移行開始

     LD     X26          自動スタート
     OR     X25          原復スタート
     ANI    X20          各個
     PLS    SM8042       スタートパルス

     LD     X21          原復
     AND    X27          ストップ
     OR     X22          歩進
     LD     X23          一巡
     AND    X27          ストップ
     ORB
     OR     SM8002       イニシャルパルス
     OR     SM8040       自己保持
     ANI    SM8042       スタートパルス
     OR     X20          各個
     OUT    SM8040       移行禁止

     LD     SM8000       RUNモニタ
     OUT    SM8047       STLモニタ有効

     LD     X20          各個
     →[S 0]
     LD     SM8044       原点条件      (S 0 の後段)
     OUT    SM8043       原復完了

     LD     X21          原復
     →[S 1]
     LD     X25          原復スタート  (S 1 の後段)
     LD     X22～X24     自動
     AND    SM8043       原復完了
     →[S 2]
     LD     SM8041       移行開始      (S 2 の後段)
     (S 1 後段の X25 と S 2 後段の SM8041 を並列接続)
     RST    SM8043       原復完了信号リセット
```

> SM8041は自動モードでスタートボタンを押したときに動作します｡特に連続モードのときは自己保持動作を行い，ストップボタンを押すと解除されます｡
> SM8040は歩進モードのときに動作し，スタートボタンを押すたびにOFFします｡原復や一巡モードではストップボタンを押すと自己保持動作し，スタートボタンを押すと解除されます｡
> 各モード入力に応じてイニシャルステートの切換えが行われるとともに，SM8043の制御も行います｡ただし，SM8044, SM8043はユーザプログラムでも制御する必要があります｡

- 各個，原復，自動間のモード切換えが行われると，機械が原点位置以外のときは全出力(ステートから駆動されていない出力(Y)，およびステートからOUT，SET命令で駆動されている出力(Y))および旧ステートの一括リセットが行われます。(SM8045駆動時は全出力リセットは行いません｡)

【図】モード切換え時のリセット(原本 p.816 上)
- 原復 X21 → S1(b接点)・SM8043 原復完了(b接点) → 「各個 X20へ切換え」
- 自動 X22～X24 → S2(b接点) → 「各個 X20へ切換え」
- 各個 X20 → 「原復 X21へ切換え」
- 自動 X22～X24 → S2(b接点) → 「原復 X21へ切換え」
- いずれの切換えでも → 「旧ステートの一括リセットおよびこれにつながるOUT出力のリセット」
- さらに SM8045(b接点)(全出力リセット禁止) を経由して → 「SM8045=OFFのとき，全出力Yがリセットされる」
- S2の動作中に自動→原復へ切換えても，イニシャルステート以外のステートや出力はリセットされません。

#### IST命令導入事例(ワーク移送機構の例) (8.20 / 原本 p.816-817)

- 運転モード

【図】操作盤(原本 p.816)
- ロータリスイッチ: 各個操作 X20 / 原点復帰 X21 / 歩進 X22 / 一巡運転 X23 / 連続運転 X24
- 押しボタン(PB): 原復 X25 / 上昇 X5 / 左行 X6 / アンクランプ X7 / 下降 X10 / 右行 X11 / クランプ X12 / スタート X26 / ストップ X27 / 電源(PB) / 非常停止(PB)
- 上昇〜クランプの押しボタン: 右図のようなロボットハンドの各個操作用
- 電源・非常停止: 負荷の電源を入/切する外部回路用の押しボタン
- ロボットハンドによりワークをA点からB点へ移送する機構: 右行 Y3(右限 X3)、左行 Y4(左限 X4)、上昇 Y2(上限 X2)、下降 Y0(下限 X1)、クランプ Y1、アンクランプ Y1(Y1のOFF)

| 運転モード | | 動作内容 |
|---|---|---|

| 手動 | 原点復帰: | 原復用押しボタンを押したときに，機械を自動的に原点へ復帰させるためのモードです。 |

- 移送機構

【図】移送機構の動作順(原本 p.816)
- 原点(スタート X26、左限 X4、上限 X2)から ①下降 Y0 → 下限 X1 → ②クランプ Y1 ON → ③上昇 Y2 → 上限 X2 → ④右行 Y3 → 右限 X3 → ⑤下降 Y0 → 下限 X1 → ⑥アンクランプ Y1 OFF → ⑦上昇 Y2 → 上限 X2 → ⑧左行 Y4 → 左限 X4(原点)
- 原点条件は？ 上限(X2=ON)，左限(X4=ON)，アンクランプ(Y1=OFF)となります

左上を原点とし，下降，クランプ，上昇，右行，下降，アンクランプ，上昇，左行の順でワークを左から右へ移します。
下降/上昇，左行/右行にはダブルソレノイド(駆動/非駆動の2入力)の電磁弁，クランプにはシングルソレノイド(通電中のみ動作)の電磁弁が用いられています。

| 特殊リレー | 内容 | 備考 |
|---|---|---|
| SM8040<br>(移行禁止) | この特殊リレーが働くとすべてのステートの移行が禁止されます。<br>各個: 常にSM8040が働きます。<br>原復，一巡: ストップボタンを押すとスタートボタンを押すまで動作保持されます。<br>歩進: 常にSM8040が働きます。ただし，スタートボタンを押したときのみ不作動となり移行が行われます。<br>その他: シーケンサのSTOP→RUN切換え時にも動作保持し，スタートボタンを押すと解除されます。<br>移行禁止状態時においても，ステート内の出力はそのまま動作を継続しています。 | IST命令が自動的に制御 |

| SM8042<br>(スタートパルス) | スタートボタンを押したときのみ一瞬だけ動作します。 | IST命令が自動的に制御 |
| SM8047<br>(STLモニタ有効) | IST命令を使用するとSM8047をONします。<br>SM8047がONすることでSTLモニタが有効となり，動作中のステート番号(S0～S899)が若い番号順に特殊レジスタSD8040～SD8047に格納されます。<br>これにより動作ステート番号を8点までモニタすることができます。<br>また，これらのステートのどれかが動作していると特殊リレー SM8046が動作するようになっています。 | IST命令が自動的に制御 |

**• 16ビット変換モード(SM8161=OFFのとき)**

下記プログラムの場合，次のとおり変換が実行されます。

```
     LDI    SM400
     OUT    SM8161       16ビット変換モード
     LD     X10

```

| D101 下 | K100 = 0 1 1 0 0 1 0 0 | |
| D101 上 | K 98 = 0 1 1 0 0 0 1 0 | |
| D102 下 | K123 = 0 1 1 1 1 0 1 ① | ← |
| D102 上 | K 66 = 0 1 0 0 0 0 1 0 | |
| D103 下 | K100 = 0 1 1 0 0 1 0 0 | |
| D103 上 | K 95 = 0 1 0 1 1 1 1 ① | ← |
| D104 下 | K210 = 1 1 0 1 0 0 1 0 | |
| D104 上 | K 88 = 0 1 0 1 1 0 0 0 | |
| 合計 | K1091 | |

【図】格納結果(b15→b0)
- D0 = 0000 0100 0100 0011 ← BCDでは1091
