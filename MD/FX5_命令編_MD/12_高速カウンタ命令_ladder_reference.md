## 32ビットデータ比較セット (12.1 / 原本 p.971-973)

### DHSCS (12.1 / 原本 p.971-973)

対応機種: FX5S / FX5UJ / FX5U / FX5UC

高速カウンタで計数した値と，指定した値をカウントごとに比較し，直ちにビットデバイスをセットする命令です。
高速パルス入出力ユニットは対応していません。

#### 書式 (12.1 / 原本 p.971)

| 言語 | 記述 |
|---|---|
| ラダー | 【図】命令ボックス `□ (s1) (s2) (d)`(□に DHSCS) |
| ST*1 | `ENO:=DHSCS(EN,s1,s2,d);`<br>`ENO:=DHSCS_I(EN,s1,s2,Pn);` |
| FBD/LD*1 | 【図】DHSCS: EN・s1・s2 入力、ENO・d 出力のボックス / DHSCS_I: EN・s1・s2・Pn 入力、ENO 出力のボックス |

*1 ST言語，FBD/LD言語でオペランド(d)に割込みポインタ(I)を指定する場合，DHSCS_I命令を使用してください。

#### 設定データ (12.1 / 原本 p.971)

■内容，範囲，データ型

| オペランド | 内容 | 範囲 | データ型 | データ型(ラベル) |
|---|---|---|---|---|
| (s1) | 高速カウンタの現在値と比較するデータまたは，比較するデータが格納されているワードデバイス番号 | -2147483648～+2147483647 | 符号付きBIN32ビット | ANY32 |
| (s2) | 高速カウンタのCH番号 | K1～8 | 符号付きBIN32ビット | ANY32 |
| (d) DHSCS | 一致するとセット(ON)するビットデバイス番号 | — | ビット | ANY_BOOL |
| (d) DHSCS_I*1 | 一致するとセット(ON)するビットデバイス番号 | — | — | POINTER |
| EN | 実行条件 | — | ビット | BOOL |
| ENO | 実行結果 | — | ビット | BOOL |

*1 ST言語，FBD/LD言語の場合，Pnと表示されます。

> 注: 原本では (d) の行が DHSCS / DHSCS_I*1 の2段に分かれ、「内容」「範囲」のセルは2段共通(結合セル)です。

■使用可能デバイス

| オペランド | ビット | ワード | U□￥G□ | Z | LC | LZ | 間接指定 | K，H | E | $ | その他(I) |
|---|---|---|---|---|---|---|---|---|---|---|---|
| (s1) | ○ | ○ | ○ | ○ | ○ | ○ | ○ | ○ | — | — | — |
| (s2) | ○ | ○ | ○ | ○ | ○*1 | ○ | ○ | ○ | — | — | — |
| (d) | ○ | — | — | — | — | — | — | — | — | — | ○*2 |

*1 FX3互換機能を有効にし，LC35～55の内，FX3互換の高速カウンタとして指定しているデバイスを指定してください。
FX3互換機能については，→MELSEC iQ-F FX5ユーザーズマニュアル(応用編)を参照してください。
*2 I16～I23のみ使用できます。

#### 機能 (12.1 / 原本 p.972)

- (s2)で指定したCHの高速カウンタの現在値が，比較値(s1)に変化した時(比較値K200の場合199→200や201→200)，ビットデバイス(d)がスキャンタイムとは無関係にセット(ON)されます。この命令は，高速カウンタの計数処理に続いて比較処理が行われます。詳細は，→MELSEC iQ-F FX5ユーザーズマニュアル(応用編)を参照してください。

```
     LD     指令入力
     DHSCS  (s1) (s2) (d)     (s1) = (s2) → (d)
```

**Point**
- CPUユニットのスキャンタイムの影響を受けず，計数一致によって出力したいときに使用してください。
- 同時使用制限を超える場合は，汎用の比較命令を使用してください。

高速比較一致割込みを使用する場合，下記のように(d)に割込みポインタ(I16～I23)を設定することで，対応する割込みプログラムを実行することができます。

```
     LD     M0
     EI
     LDP    M1
     HIOEN  K0 H1 H0          (1)
     LD     SM400
     DHSCS  K1000 K1 I16      (2)
     FEND                     (ここまで A)
I16: LD     M2
     OUT    Y10
     IRET                     (I16〜IRET が B)
     END
```

> A: メインルーチンプログラム
> B: I16の割込みプログラム
> (1): 高速カウンタCH1を開始します。
> (2): 高速カウンタCH1の現在値が1000になると，割込みプログラム(I16)を実行します。

#### 注意事項 (12.1 / 原本 p.972)

(s2)に指定できる値は，パラメータで設定した高速カウンタのCH(1～8)のみ有効です。
下記の場合，演算エラーになります。
- パラメータで設定していないCH，またはK1～8以外を指定した場合
- パラメータで設定していないLCデバイス番号を指定した場合

その他の注意事項については，→MELSEC iQ-F FX5ユーザーズマニュアル(応用編)を参照してください。

#### プログラム例 (12.1 / 原本 p.973)

- パラメータ

高速カウンタを使用したデータ比較を使用する場合，下記パラメータでCH1の"カウンタを使用する/しない"を"使用する"に設定してください。

ナビゲーションウィンドウ → [パラメータ] → ユニット形名 → [ユニットパラメータ] → [高速I/O] → "入力機能" → "高速カウンタ" → "詳細設定" → "基本設定"

【図】GX Works3「高速カウンタ」設定画面
- 設定項目一覧(ツリー): 基本設定 > カウンタを使用する/しない / 動作モード / パルス入力モード / プリセット入力 / プリセット値 / イネーブル入力 …
- 「簡易一括設定」ボタン: 高速カウンター括設定ウィザードを表示します。入力信号を選択した後、複数CHに一括でパラメータ設定が可能です。
- 設定項目表:

| 項目 | CH1 | CH2 | CH3 |
|---|---|---|---|
| カウンタを使用する/しない(カウンタを使用するか使用しないかを設定します。) | | | |
| 使用する/使用しない | 使用する(選択枠で強調表示) | 使用しない | 使用しない |
| 動作モード(動作モードを設定します。) | | | |
| 動作モード | 通常モード | 通常モード | 通常モード |
| パルス入力モード(パルス入力モードを設定します。) | | | |
| パルス入力モード | 1相1入力(S/W アップ/ダウン切替え) | 1相1入力(S/W アップ/ダウン切替え) | 1相1入力(S/W アップ/ダウン切替え) |
| プリセット入力 | (以下、図では切れていて判読不可。原本 p.973 参照) | | |

- プログラム

カウンタの現在値に対して任意の値2点でそれぞれ別の出力(Y10，Y11)をセット(ON)するプログラムです。

```
     LD     SM402
     HIOEN  K0 H1 H0          CH1の高速カウンタを開始します。
     LD     SM400
     DHSCS  K100 K1 Y10       SD4500=K100以上のときY10=ON
     DHSCS  K150 K1 Y11       SD4500=K150以上のときY11=ON
```

【図】タイミングチャート
- SD4500(CH1現在値)が 0 … 99 → 100 → 101 … 149 → 150 → 151 と階段状に増加(上限表示 K2,147,483,647)。
- Y10: SD4500 が 100 になった時点で ON し，以後 ON のまま。
- Y11: SD4500 が 150 になった時点で ON し，以後 ON のまま。

#### 機能 (12.1 / 原本 p.975)

- (s2)で指定したCHの高速カウンタの現在値が，比較値(s1)に変化したとき(比較値K200の場合199→200や201→200)，ビットデバイス(d)がスキャンタイムとは無関係にリセット(OFF)されます。詳細は，→MELSEC iQ-F FX5ユーザーズマニュアル(応用編)を参照してください。

```
     LD     指令入力
     DHSCR  (s1) (s2) (d)     (s1) = (s2) → (d)
```

- (d)に(s2)と同じCH番号あるいはLCデバイスを指定した場合，自己リセット動作します。

(d)に(s2)と同じCH番号を指定する例
CH1の高速カウンタの現在値が400になったとき，現在値をプリセット値に書き換えます。
[プログラム例]

```
     LD     指令入力
     DHSCR  K400 K1 K1
```

【図】CH1現在値が 0 から増加し，DHSCRのリセット値:400 に達するとプリセット値(図では0の位置)に戻る動作を繰り返すのこぎり波(3周期分を図示)。

(d)にLCデバイスを指定する例
LC55(CH4の高速カウンタ(2相2入力(1逓倍/4逓倍)))の現在値が300になったとき，LC55の出力接点がONします。LC55の現在値が400になったとき，現在値を0クリア，および出力接点をOFFします。
[プログラム例]

```
     LD     指令入力
     OUT    LC55 K300
     DHSCR  K400 LC55 LC55
```

【図】タイミングチャート
- LC55現在値(=CH4現在値)が 0 から増加し，カウントアップ値:300 を通過して DHSCRのリセット値:400 に達すると 0 に戻る動作を繰り返す(3周期分を図示)。
- LC55出力接点: 各周期で現在値が 300 になった時点で ON し，400 になって 0 クリアされた時点で OFF(3回のON区間を図示)。

**Point**
- CPUユニットのスキャンタイムの影響を受けず，計数一致によって出力したいときに使用してください。
- 同時使用制限を超える場合は，汎用の比較命令を使用してください。

#### 注意事項 (12.1 / 原本 p.975)

(s2)，自己リセット時の(d)に指定できる値は，パラメータで設定した高速カウンタのCH(1～8)のみ有効です。
下記の場合，演算エラーになります。
- パラメータで設定していないCH，またはK1～8以外を指定した場合

#### 機能 (12.1 / 原本 p.977)

- (s3)で指定した高速カウンタの現在値と２つの比較値(比較値1，比較値2)で帯域比較を行い，スキャンタイムとは無関係に比較結果(下，帯域内，上)によって，(d)，(d)+1，(d)+2のいずれかがONします。詳細は，→MELSEC iQ-F FX5ユーザーズマニュアル(応用編)を参照してください。

```
     LD     指令入力
     DHSZ   (s1) (s2) (s3) (d)     (s1) > (s3)          → (d)
                                   (s1) ≦ (s3) ≦ (s2)   → (d)+1
                                          (s3) > (s2)   → (d)+2
```

- 比較値1と比較値2は[比較値1]≦[比較値2]の関係となるように設定してください。設定が異なる場合は，演算エラーが発生し，DHSZ命令は動作しません。
- 下記の場合，高速カウンタCH1の現在値が次のように変化(計数)した時，比較結果を出力Y0，Y1，Y2のいずれかをONします。

```
     LD     SM400             RUNモニタ
     DHSZ   K1000 K2000 K1 Y0     ON
                                  K1000 > CH1現在値           → Y0
                                  K1000 ≦ CH1現在値 ≦ K2000   → Y1
                                          CH1現在値 > K2000   → Y2
```

| 比較パターン | CH1の現在値(s3) | 出力接点(Y)の変化 Y0 | Y1 | Y2 |
|---|---|---|---|---|
| (s1)>(s3) | 1000>(s3) | ON | OFF | OFF |
| (s1)>(s3) | 999→1000 | ON→OFF | OFF→ON | OFF |
| (s1)>(s3) | 1000→999 | OFF→ON | ON→OFF | OFF |
| (s1)≦(s3)≦(s2) | 999→1000 | ON→OFF | OFF→ON | OFF |
| (s1)≦(s3)≦(s2) | 1000→999 | OFF→ON | ON→OFF | OFF |
| (s1)≦(s3)≦(s2) | 1000≦(s3)≦2000 | OFF | ON | OFF |
| (s1)≦(s3)≦(s2) | 2000→2001 | OFF | ON→OFF | OFF→ON |
| (s1)≦(s3)≦(s2) | 2001→2000 | OFF | OFF→ON | ON→OFF |
| (s3)>(s2) | 2000→2001 | OFF | ON→OFF | OFF→ON |
| (s3)>(s2) | 2001→2000 | OFF | OFF→ON | ON→OFF |
| (s3)>(s2) | (s3)>2000 | OFF | OFF | ON |

> 注: 原本では「比較パターン」列は3グループ((s1)>(s3) / (s1)≦(s3)≦(s2) / (s3)>(s2))の結合セルです。

**Point**
- CPUユニットのスキャンタイムの影響を受けず，計数一致によって出力したいときに使用してください。
- 同時使用制限を超える場合は，汎用の比較命令を使用してください。

#### 注意事項 (12.1 / 原本 p.977)

下記の場合，演算エラーになります。
- (s3)にパラメータで設定していないCH，またはK1～8以外を指定した場合
- パラメータで設定していないLCデバイス番号を指定した場合

(d)に指定したデバイスを先頭に3点占有します。他の制御で使用しているデバイスと重複しないように注意してください。
また，Yデバイスを指定する場合，ユニットまたは16の倍数のデバイス番号をまたぐ設定はしないでください。

例
FX5U-64M□を使用した場合に，Y36またはY37を指定する

その他の注意事項については，→MELSEC iQ-F FX5ユーザーズマニュアル(応用編)を参照してください。

#### プログラム例 (12.1 / 原本 p.978)

- パラメータ

高速カウンタを使用したデータ帯域比較を使用する場合，下記パラメータでCH1の"カウンタを使用する/しない"を"使用する"に設定してください。

ナビゲーションウィンドウ → [パラメータ] → ユニット形名 → [ユニットパラメータ] → [高速I/O] → "入力機能" → "高速カウンタ" → "詳細設定" → "基本設定"

【図】GX Works3「高速カウンタ」設定画面(p.973 と同じ画面)。基本設定 > カウンタを使用する/しない の「使用する/使用しない」で CH1=使用する(選択枠で強調表示)，CH2・CH3=使用しない。動作モードは CH1～CH3 とも通常モード，パルス入力モードは CH1～CH3 とも 1相1入力(S/W アップ/ダウン切替え)。

- プログラム

カウンタの現在値に対して指定したデータ範囲(K1000～K1200)と比較し，比較結果により出力(Y10～Y12)をセット(ON)するプログラムです。

```
     LDI    X10
     DHCMOV K0 SD4500 K0
     ZRST   Y10 Y12                 Y10～Y12をリセット
     LD     SM402
     HIOEN  K0 K1 H0                CH1の高速カウンタを開始します。
     LD     X10
     DZCPP  K1000 K1200 K1 Y10      X10がONしたとき，1スキャンのみ比較実行
                                    K1000>SD4500            :Y10 ON
                                    K1000≦SD4500≦K1200     :Y11 ON
                                    K1200<SD4500            :Y12 ON
     DHSZ   K1000 K1200 K1 Y10      X10がONしたとき，X0からのパルス入力時
                                    割込みで比較実行
                                    K1000>SD4500            :Y10 ON
                                    K1000≦SD4500≦K1200     :Y11 ON
                                    K1200<SD4500            :Y12 ON
```

> 要確認: 原本のラダーでは DZCPP の第3オペランド(比較元)が `K1` になっていますが，コメントでは SD4500(CH1現在値)と比較する旨が書かれています。DZCPの(s3)は比較元データなので `SD4500` の誤記の可能性があります。原文のまま転記しています(原本 p.978)。

| PWM機能を実行したが，現在は停止している場合 | 停止した時の値が読み出されます。 |
| PWM機能を実行中の場合 | 現在動作している最新の値が読み出されます。 |

- 高速カウンタのSDデバイス(現在値/最大値/最小値)を個別に読み出したとき，読み出したSDデバイスのみ更新されます。そのため，一時的に高速カウンタのSDデバイスが最小値≦現在値≦最大値の関係にならないことがあります。高速カウンタのSDデバイスが更新されるタイミングについては，→MELSEC iQ-F FX5ユーザーズマニュアル(応用編)を参照してください。

**Point**
- DHCMOV命令は主に，高速カウンタ/パルス幅測定の現在値読出しや，位置決めの現在アドレス(ユーザ単位)，現在アドレス(パルス単位)の変更に使用します。
