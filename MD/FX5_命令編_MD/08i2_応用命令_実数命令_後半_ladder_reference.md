### EMOV(P)/DEMOV(P) (8.10 / 原本 p.691-692)

#### 機能 (8.10 / 原本 p.691)

- (s)で指定されたデバイスに格納されている単精度実数データを，(d)で指定されたデバイスへ転送します。
  - 【図】(s)+1，(s) = 4.23542(単精度実数) ⇒ (d)+1，(d) = 4.23542(単精度実数)

#### プログラム例 (8.10 / 原本 p.692)

X7をONしたとき，D11, D10の単精度実数をD1, D0に格納するプログラムです。

```
     LD      X7
     DEMOVP  D10  D0
```

【図】D11，D10 = 36.475 ⇒ D1，D0 = 36.475

X7をONしたとき，単精度実数-1.23をD11, D10に格納するプログラムです。

```
     LD      X7
     DEMOVP  E-1.23  D10
```

【図】-1.23 ⇒ D11，D10 = -1.23

演算エラーはありません。

#### プログラム例 (8.10 / 原本 p.694)

X1またはX2のONにより角度(45°または90°)を指定し，SIN値を演算するプログラムです。

```
     LD      X1
     MOVP    K45  D0                      (K45)→(D0)
     LD      X2
     MOVP    K90  D0                      (K90)→(D0)
                                          (上記2回路: X1またはX2で角度を選択)
     LD      SM400
     INT2FLT D0  D4                       (D0)→(D5，D4) 単精度実数値
     DEDIV   K31415926  K1800000000  D20  (π/180)→(D21，D20) 単精度実数値
     DEMUL   D4  D20  D30                 (D5，D4)角度×(π/180)→(D31，D30)RAD 単精度実数値
     DSIN    D30  D100                    (D31，D30)RAD→(D101，D100)SIN 単精度実数値
```

【図】DSIN命令のオペランド上に (s)，(d) の表示あり(D30 が (s)，D100 が (d))。
