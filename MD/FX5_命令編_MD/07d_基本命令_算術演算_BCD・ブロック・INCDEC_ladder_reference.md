#### プログラム例 (7.2 / 原本 p.278)

```
LD    X10
OR    M1
MOVP  K0 Z0        0→(Z0)
LD    X11
MPS
BCDP  C0Z0 K4Y0    (C0Z0)→(K4Y0)  BIN→BCD
MRD
INCP  Z0           (Z0)＋1→(Z0)
MPP
CMPP  K10 Z0 M0    (Z0)＝10の時 M1＝ON
```

> リセット入力X10でZ0をクリア
>
> カウンタC0～C9の現在値をBCD変換してK4Y0へ出力
>
> X11をONするたびにC0,C1…C9の現在値が順次出力

(ラダー図: X10 と M1 の並列 → MOVP K0 Z0。X11 から3分岐で BCDP C0Z0 K4Y0 / INCP Z0 / CMPP K10 Z0 M0。ニモニックのMPS/MRD/MPPは分岐を表すための書き起こしです。)
