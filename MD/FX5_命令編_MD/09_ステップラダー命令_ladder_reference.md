## 9.1 ステップラダー開始，終了 (9.1 / 原本 p.936-938)

### STL，RETSTL (9.1 / 原本 p.936-938)

対応機種: FX5S / FX5UJ / FX5U / FX5UC

STL：ステップラダーを開始します。
RETSTL：ステップラダーを終了します。

#### 機能 (9.1 / 原本 p.936-937)

- ステップラダー命令を用いたプログラムは，機械の動作を元に各工程ごとにステップリレー Sを割り付け，ステートの接点(STL接点)に続く回路として入力条件や出力制御のシーケンスをプログラムしていきます。
- ステップラダーでは，ステップリレー Sを1つの制御工程と見立て，この中に入力条件と出力制御のシーケンスをプログラムします。工程が進むと前工程が非実行となるため，各工程ごとの簡単なシーケンスで機械が制御できます。
- STL命令で指定したステップリレー番号がステートに割り付けられます。ステートの開始，終了はSET命令，OUT命令，RST命令，ZRST命令で行います。
- 一連のステップラダーはイニシャルステートを先頭に，移行するステートの順に従ってプログラムしてください。また，ステップラダーの最後にはRETSTL命令をプログラムしてください。ステップラダーを続けてプログラミングする場合，最終のステップラダー以外はRETSTL命令を省略することができます。

実際のステップラダープログラムは以下のようになります。

```
LD     SM402
SET    S0
STL    S0            S0の工程(STL命令で区切られたこの範囲をステートと呼びます。)
LD     X0            スタート
SET    S20
STL    S20           S20の工程
LDI    Y23
OUT    Y21           前進
LD     X1
SET    S21
STL    S21           S21の工程
LDI    Y21
OUT    Y23           後退
RETSTL
END
```

- ステップラダーはリレーラダーのような表現ですが，ステートを使用し，機械制御の流れをプログラムできます。ステートはリレーと同様に駆動コイルと接点(STL接点)から成り立つものとして考えることができます。コイル駆動にはSET命令やOUT命令を用い，接点にはSTL命令を用います。
- ステートにつながる内部回路の動作は，以下の通りです。

| 内部回路動作 | |
|---|---|
| ON実行 | ステートがONするとこれにつながる回路(内部回路)がSTL出力を介し動作します。 |
| OFF実行(1演算周期) | ステートの移行に設けられた条件(移行条件)が満たされると次のステートがONし，これまでONしていたステートがOFF(リセット)されます。(移行動作)ステートの移行過程では，1演算周期だけ両ステートが同時にONしています。<br>移行元ステートは，移行後，次の演算周期にOFF(リセット)されます。OFFされたステートの母線から接続された駆動命令は，駆動命令前までの接点の状態にかかわらず1演算周期だけOFF実行(接点がOFFのときと同様の動作)となります。<br>ただし，移行ステートを接点命令で使用している場合，移行条件が満たされた直後から接点イメージはOFFで実行されます。 |
| 非実行 | OFF実行した次の演算周期以降，命令のOFF実行を行わない動作です。(ジャンプの状態) |

- ステート(内部回路)実行状態のタイミングチャートは下記の通りとなります。

【図】ステート実行状態
- ステートON の間: 「ON実行」= 実行
- ステートOFF 直後の1演算周期: 「OFF実行」
- それ以降: 非実行(ジャンプ状態)

- 各ステートは負荷に対する駆動処理，移行先指定とその移行条件指定の三つの機能を備えています。以下のプログラムのように，負荷に対する駆動処理，つづいて移行処理の順で行います。負荷を伴わないステートでは駆動処理は必要ありません。

```
STL    S20
OUT    Y10           駆動処理
LD     X10
OR     X11
OUT    Y11           駆動処理
LD     X0
ANI    X1
STL    S21           移行処理
```

> 要確認: 原本の図では移行処理の行が「X0 ─┤├─ X1 ─┤/├─ [STL S21]」と描かれています。移行先の指定は通常 SET S21(またはOUT S21)で行うため、「STL S21」は「SET S21」の誤記の可能性があります。原本の図のまま転記しています。

#### プログラムの動作 (9.1 / 原本 p.938)

ステップラダープログラムは以下のように動作します。

```
LD     SM402
SET    S31
STL    S31           S31の工程
LD     SM400         *1
OUT    Y30           *2
LD     SM400         *1
SET    Y31
LD     X1
SET    S32           *3
STL    S32           *4  S32の工程
LD     SM400         *1 *5
MPS
OUT    Y30           *2
MPP
OUT    Y32
LD     X2
OUT    S33           *3
```

【図】動作(X1がONしたとき)
- 左図: S31 がON(STL S31 と、その中の Y30・SET Y31 が動作中)
- 右図: X1がONするとS32がONし，S31が自動的にリセットされます｡ STL S32 がON となり Y30・Y32 が動作
- SET命令でプログラムされたY31は，S31がリセットされてもそのまま出力を保持します｡

- *1 出力の駆動には必ず接点をプログラムする必要があります。
- *2 異なるステートには，出力コイルを重複してプログラムできます。
- *3 ステップリレーに対するOUT命令とSET命令は，いずれも移行元ステートを自動リセットします。また，自己保持機能を持っています。
- *4 同一ステップリレー番号を重複して使用することはできません。
- *5 STL命令の直後にポインタを配置することはできません。配置した場合，プログラムエラー (33E2H)になります。

**Point**
ラッチ設定したステップリレーは，その動作状態が不揮発メモリでバックアップされています。機械動作の途中で停電が生じた後，再通電時にここから継続運転したいような場合にこれらのステップリレーを用います。また，これらのステップリレーはRUN→STOP時も動作状態を保持するため，再度RUNするとSTOP直前のステートから運転を再開します。

#### 注意事項 (9.1 / 原本 p.938)

- ラッチ設定していないステップリレー (S)は電源ON→OFFおよびRUN→STOPでクリアされます。ステート有効時に電源ON→OFFおよびRUN→STOPすると，途中工程からの再開ができなくなります。
- SFCプログラムを含むプロジェクト内では，STL/RETSTL命令を使用できません。
