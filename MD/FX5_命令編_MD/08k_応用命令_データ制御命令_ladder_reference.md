#### 機能 (8.13 / 原本 p.733)

- (s3)で指定した入力値(BIN16ビット値)が，(s1)，(s2)で指定した上下限リミット値の範囲により，(d)で指定したデバイスに格納する出力値を制御します。出力値は下記のように制御されます。

| 条件 | 出力値に格納される値 |
|---|---|
| 下限リミット値(s1) >入力値(s3)のとき | 下限リミット値(s1) |
| 上限リミット値(s2) <入力値(s3)のとき | 上限リミット値(s2) |
| 下限リミット値(s1) ≦入力値(s3) ≦上限リミット値(s2)のとき | 入力値(s3) |

【図】入出力特性(横軸 (s3)、縦軸 (d))
- (s3) が (s1) 未満の範囲: (d) は (s1) の値で水平(負側の水平線。(s1) は原点より左・下側に表示)
- (s3) が (s1)〜(s2) の範囲: 原点0を通る右上がりの直線((d)=(s3))
- (s3) が (s2) を超える範囲: (d) は (s2) の値で水平(正側の水平線)

- 上限リミット値のみによる制御を行う場合は，(s1)で指定する下限リミット値に設定データ範囲の最小値を設定します。
- 下限リミット値のみの制御を行う場合は，(s2)で指定する上限リミット値に設定データ範囲の最大値を設定します。

#### プログラム例 (8.13 / 原本 p.733)

X0をONしたとき，X20～X37にBCD値で設定したデータに500～5000のリミット値制御を行い，D1に格納するプログラムです。

```
     LD     X0
     BIN    K4X20 D0
     LIMIT  K500 K5000 D0 D1
```

動作
- D0<500の場合，D1は500になります。
- 500≦D0≦5000の場合，D1はD0の値になります。
- 5000<D0の場合，D1は5000になります。

【図】入出力特性(横軸 入力(D0)、縦軸 出力(D1))
- 入力 500 未満: 出力 500 で水平
- 入力 500〜5000: 右上がりの直線(出力=入力)
- 入力 5000 超: 出力 5000 で水平

#### 機能 (8.13 / 原本 p.743)

- (s3)で指定した入力値(BIN32ビット値)に，(s1)または(s2)で指定したバイアス値を付加して，(d)で指定したデバイス番号に格納します。バイアス値は下記のように制御されます。

| 条件 | 出力値に格納される値 |
|---|---|
| 入力値((s3)，(s3)+1) < 0のとき | 入力値((s3)，(s3)+1) + 負のバイアス値(s1)，(s1)+1 |
| 入力値((s3)，(s3)+1) = 0のとき | 0 |
| 入力値((s3)，(s3)+1) > 0のとき | 入力値((s3)，(s3)+1) + 正のバイアス値(s2)，(s2)+1 |

【図】入出力特性(横軸 (s3+1, s3)、縦軸 (d+1, d))
- 入力<0: 左下から縦軸上の (s1+1, s1) の点(白丸，原点より下)へ向かう右上がりの直線
- 入力=0: 原点0に黒丸(出力0)
- 入力>0: 縦軸上の (s2+1, s2) の点(白丸，原点より上)から右上がりの直線

- (d)，(d)+1に格納される出力値が符号付きBIN32ビット値の場合，演算結果が-2147483648～2147483647を超えるときは，下記の例のようになります。

**例**
(s1)，(s1)+1が-1000で，(s3)，(s3)+1が-2147483648のとき，出力値 = -2147483648+(-1000) = 80000000H-FFFFFC18H = 7FFFFC18H = 2147482648となります。

> 要確認: 原本の表記どおり「80000000H-FFFFFC18H」と転記。32ビットで 80000000H+FFFFFC18H = 7FFFFC18H となり，「-」は「+」の誤記と思われる(原本 p.743)。

- (d)，(d)+1に格納される出力値が符号なしBIN32ビット値の場合，演算結果が0～4294967295を超えるときは，下記の例のようになります。

**例**
(s2)，(s2)+1が1000で，(s3)，(s3)+1が4294967295のとき，出力値 =4294967295+1000 = FFFFFFFFH-00003E8H = 000003E7H = 999となります。

> 要確認: 原本の表記どおり「FFFFFFFFH-00003E8H」と転記。FFFFFFFFH+000003E8H = 000003E7H となり，「-」は「+」の誤記と思われる。また「00003E8H」は他の例の桁数(8桁)と異なる(原本 p.743)。

- DZONE(P)_U命令の場合，(s1)，(s1)+1はダミーデータ扱いとして使用しません。

#### プログラム例 (8.13 / 原本 p.743)

```
     LD      X0
     DZONEP  K-10000 K10000 D0 D10
```

動作
- (D1, D0)<0の場合, (D11, D10)には(D1, D0)+(-10000)の値が格納されます。
- (D1, D0)=0の場合, (D11, D10)には0が格納されます。
- 0<(D1, D0) の場合, (D11, D10)には(D1, D0)+10000の値が格納されます。

【図】入出力特性(横軸 入力(D1, D0)、縦軸 出力(D11, D10))
- 破線: 原点を通る右上がりの直線(バイアスなし)
- 実線(入力>0): 縦軸 +10000 の点から右上がり(↑矢印で +10000 平行移動)
- 実線(入力<0): 縦軸 -10000 の点へ向かう右上がり(↓矢印で -10000 平行移動)
- 横軸には -10000 / +10000，縦軸には +10000 / -10000 の目盛りを表示
