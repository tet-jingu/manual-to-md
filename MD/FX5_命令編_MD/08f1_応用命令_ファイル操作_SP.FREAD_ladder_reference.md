対応機種: FX5S / FX5UJ / FX5U / FX5UC

#### 機能 (8.7 / 原本 p.488-489)

- 指定ファイルからデータを読み出します。コントロールデータの実行/完了タイプにより，ファイルの読出し形式を指定します。
- 読出しの対象は，SDメモリカードのみです。
- 処理完了(d3)のビットデバイスは，SP.FREAD命令の処理完了を検出したスキャンのEND命令実行時に自動的にONし，次のスキャンのEND命令にてOFFします。また，処理完了(d3)のビットデバイスがONしている場合，SP.FREAD命令実行時に自動的にOFFします。
- SP.FREAD命令が異常完了時には，異常完了(d3)+1のデバイスが，処理完了(d3)のデバイスと同じタイミングでON/OFFします。
- SP.FREAD命令実行中は，SM753(ファイルアクセス中)がONします。SM753がON中は，SP.FREAD命令は実行できません。(実行した場合は無処理となります。)
- 命令実行時にエラーを検出した場合は，処理完了(d3)，異常完了(d3)+1およびSM753はONしません。
- 奇数バイト指定時は，下記のようにデータが格納されます。(指定した最後のb8～b15には，命令実行前のデータが格納されています。)
  - 【図】(d2)〜(d2)+5 の6ワード(b15 … b8 / b7 … b0)。(d2)+5 の上位バイト(b8～b15)だけが網掛け(命令実行前のデータのまま)で、それ以外はすべて格納対象

#### タイミングチャート (8.7 / 原本 p.490)

SP.FREAD命令の実行から完了までのタイミングチャート(フラグ更新タイミング)を以下に示します。

【図】横軸: スキャン → END処理 → スキャン → END処理 → スキャン → END処理 → スキャン → END処理
- SP.FREAD命令: 1スキャン目の途中で OFF→ON し、(1)の区間(網掛け)が続く(以降は破線)。

- (2) 命令OFF→ON実行時にOFF更新する
- (3) 正常/異常完了時にONする*1
- (4) 正常完了時にOFF，異常完了時にONする*1

#### プログラム例 (8.7 / 原本 p.501-508)

SP.FREAD命令でバイナリデータ/CSVデータをSDメモリカードから読み出すプログラム例を示します。

##### ■バイナリ読出し (8.7 / 原本 p.501-504)

X0をONするとSDメモリカード内に格納されている"sample.bin"ファイルの先頭16ワード目から100個分のデータをD101～D200に格納します。

[プログラム動作]
1. RUN時にコントロールデータを作成する。

[STプログラム]

```

IF SM402 THEN
D0 := H0; //実行/完了タイプ(コントロールデータ先頭デバイス)
D1 := H0; //完了ステータス
D2 := 100; //要求読出しデータ数
D4:UD := H10; //ファイル位置
D7 := 2; //データタイプ指定
END_IF;

//(2)駆動接点(X0)の立ち上がりの処理
IF LDP(TRUE, X0) THEN
//ファイルアクセス中フラグがOFFであることをチェック
IF (SM753 <> TRUE) THEN
SET(TRUE, M0); //駆動接点保持
RST(TRUE, M100); //命令実行完了フラグの初期化
RST(TRUE, M101); //命令異常完了フラグの初期化
END_IF;
END_IF;

//(3)ファイルリード命令の実行
IF M0 THEN
//メモリカード強制使用停止要求がOFFであることをチェック
IF (SM606 <> TRUE) THEN
//EN = TRUE(イネーブル入力，常時実行)
//U = U1(ダミー )
//S1 = 2(ドライブ指定，2固定)
//S2 = "sample.bin"(ファイル名が格納されている先頭デバイス)
//D1 = D0(コントロールデータが格納されている先頭デバイス)
//D2 = D100(読み出したデータを格納する先頭デバイス)
//D3 = M100(処理完了にてONするビットデバイス)
SP_FREAD(TRUE, U1, 2, "sample.bin", D0, D100, M100);
END_IF;
END_IF;

//(4)命令実行完了フラグの確認
IF M100 THEN
SET((M101 <> TRUE), M150); //命令実行完了フラグの保持
SET(M101, M151); //命令異常完了フラグの保持
RST(TRUE, M0); //駆動接点の開放
END_IF;
```

##### ■CSV形式変換読出し (8.7 / 原本 p.505-508)

X0をONするとSDメモリカード内に格納されている"sample.csv"ファイルの2行目～5行目から5列，20ワード分のデータをD101～D120に格納します。

[プログラム動作]
1. RUN時にコントロールデータを作成する。
2. X0の駆動接点をM0で保持する。また，駆動接点ON時に命令実行完了フラグ，命令異常完了フラグを初期化する。
3. SP.FREAD命令を実行する。*1
4. 命令実行完了フラグ，命令異常完了フラグは1スキャンのみONするため，正常/異常を明確にするためにM150，M151デバイスに保持する。

*1 他のファイル操作命令と同時実行させないために，下記特殊デバイスがOFFであることを確認後に実行します。
- SM606(SDメモリカード強制使用停止指示)
- SM753(ファイルアクセス中)

[使用デバイス]

| デバイス | 内容 |

[ラダープログラム]

```
; ファイルリード命令用コントロールデータの作成
     LD     SM402                RUN後1スキャンON
     MOV    H100 D0              コントロールデータ格納先頭デバイス(実行/完了タイプ)
     MOV    H0 D1                完了ステータス
     MOV    K20 D2               要求読出しデータ数
     DMOV   K2 D4                ファイル位置
     MOV    K5 D6                列数指定
     MOV    K2 D7                データタイプ指定
; ファイルリード命令の実行
     LDP    X0                   SP.FREAD命令実行トリガ
     ANI    SM753                ファイルアクセス中
     SET    M0                   SP.FREAD命令実行保持デバイス
     RST    M100                 SP.FREAD命令実行完了フラグ
     RST    M101                 SP.FREAD命令異常完了フラグ
     LD     M0                   SP.FREAD命令実行保持デバイス
     ANI    SM606                メモリカード強制使用停止要求(ドライブ2)
     SP.FREAD U1 K2 D0 "sample.csv" D100 M100
                                 D0: コントロールデータ格納先頭デバイス(実行/完了タイプ)
                                 D100: 読出しデータ先頭デバイス(読出し結果データ数)
                                 M100: SP.FREAD命令実行完了フラグ
     LD     M100                 SP.FREAD命令実行完了フラグ
     MPS
     ANI    M101                 SP.FREAD命令異常完了フラグ
     SET    M150                 正常完了表示デバイス
     MRD
     AND    M101                 SP.FREAD命令異常完了フラグ
     SET    M151                 異常完了表示デバイス
     MPP
     RST    M0                   SP.FREAD命令実行保持デバイス
```

#### 注意事項 (8.7 / 原本 p.508)

- SP.FREAD命令は，ユーザ割込みプログラム内で実行できません。エラー (3582H)が発生します。
- SM606(SDメモリカード強制使用停止指示)がON中は，SP.FREAD命令を実行できません。また，命令実行時にSM606をONした場合，異常完了します。(SM606をONする前に読み込んだデータは，デバイスに格納されます。)
- CSV形式変換読出し時，複数の要素数を読み出す場合は，読出しデータエリアには各要素の合計サイズ分のデバイスをあらかじめ確保した上で命令を実行してください。読出しデータは(d2)+1から格納されるため，(d2)として確保が必要なワード数は((各要素の合計ワード数)+1)ワードとなります。
- システムフォルダ($MELPRJ$)内のファイルはSP.FREAD命令で扱うことができません。システムフォルダ内($MELPRJ$)のファイルにアクセス要求した場合，演算エラー (3405H)が発生します。
- 格納デバイスがデバイス領域の終端を超えた場合，エラー (2820H)が発生します。
- SP.FREAD命令はSP.DEVST命令，SP.FTPPUT命令，SP.FTPGET命令と同時に実行できません。
- SP.FREAD命令実行中の電源断，およびSDメモリカードの抜去などを行わないでください。(ファイルが破損，またはエラーとなる場合があります。)

**Point**
- 要求読出しデータ数(d1)+2の設定範囲は実行/完了タイプ(d1)+0で16ビットデータ(0000H，0100H，0120H)を指定している場合，下記になります。
  - ラベルのみ使用する場合，最大64512点です。
  - デバイスのみ使用する場合，最大32767点(ファイルレジスタ(R)使用時)です。
