## BIN16ビット乗算 (7.2 / 原本 p.235-238)

BIN16ビット乗算は，*(P)(_U)命令とMUL(P)(_U)命令があります。

### *(P)(_U) (7.2 / 原本 p.235-236)

対応機種: FX5S / FX5UJ / FX5U / FX5UC

- (s1)で指定されたBIN16ビットデータと，(s2)で指定されたBIN16ビットデータの乗算を行い，乗算結果を(d)で指定されたデバイスに格納します。

  - 【図】(s1) 5678 (BIN) × (s2) 1234 (BIN) → (d)+1,(d) 7006652 (BIN)
- (d)は桁指定(K1～8)を行うことができます。

**例**
K2の指定では積(32ビット)のうち下位8ビットを求めます。

```
LD   X0
MUL  K53 K15 K2Y0          (s1)=K53 (s2)=K15 (d)=K2Y0
```

【図】(7.2 / 原本 p.238)
- (s1) K53(0035H) × (s2) K15(000FH) → 指令接点=ON で K795(031BH)
- 32ビットの積 Y37〜Y0 相当のうち、(2) Y7〜Y0 = 0 0 0 1 1 0 1 1 が「K2Y0演算結果を出力します」
- (1) Y37〜Y10 側(上位)は「出力されません」
- 最上位ビットは「符号ビット(0=正数　1=負数)」

> (1): 出力されません
> (2): K2Y0演算結果を出力します
