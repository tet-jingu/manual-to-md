## 6.1 接点命令 (6.1 / 原本 p.118-125)

### 演算開始，直列接続，並列接続 — LD，LDI，AND，ANI，OR，ORI (6.1 / 原本 p.118-120)

対応機種: FX5S / FX5UJ / FX5U / FX5UC

- LD：a接点演算開始命令/ LDI：b接点演算開始命令
  (s)で指定したデバイスのON/OFF情報を取り込み，演算結果とします。
- AND：a接点直列接続命令/ ANI：b接点直列接続命令
  (s)で指定したデバイスのON/OFF情報を取り込み，それまでの演算結果とAND演算を行い，演算結果とします。
- OR：a接点1個の並列接続命令/ ORI：b接点1個の並列接続命令
  (s)で指定したデバイスのON/OFF情報を取り込み，それまでの演算結果とOR演算を行い，演算結果とします。

#### 書式 (6.1 / 原本 p.118)

| 言語 | 記述 |
|---|---|
| ラダー | 【図】LD=母線からa接点(s)、LDI=母線からb接点(s)、AND=接点の後にa接点(s)を直列、ANI=接点の後にb接点(s)を直列、OR=接点にa接点(s)を並列、ORI=接点にb接点(s)を並列 |
| ST | 代入文，オペレータ，制御構文などになります。<br>ST言語では，LD，AND，ORなどの接点に直接該当する命令(記号)がない場合があります。<br>代入文で構成した場合，下記例のように記述します。<br>例<br>`Y1:=(X0 OR X1) AND X2 AND NOT X3;`<br>`Y2:=NOT X4 OR NOT X5;` |
| FBD/LD | FBD/LD言語では，ラダー言語と同様に接点を使用して記述します。 |

#### 機能 (6.1 / 原本 p.119-120)

■LD，LDI
- LD命令はa接点演算開始，LDI命令はb接点演算開始命令で，指定デバイスのON/OFF情報*1を取り込み，演算結果とします。

*1 ワードデバイスのビット指定時は，指定ビットの1/0によりON/OFFします。

**例**
- LD命令(a接点演算開始): `LD X0 / OUT Y0`(X0 が「LD命令」、左端が「母線」)
- LDI命令(b接点演算開始): `LDI X0 / OUT Y0`

【図】タイミングチャート (6.1 / 原本 p.119)
- LD命令: X0 が ON の間 Y0 が ON、X0 が OFF になると Y0 も OFF(X0 に追従)
- LDI命令: X0 が OFF の間 Y0 が ON、X0 が ON の間 Y0 は OFF(X0 の反転)

■AND，ANI
- AND命令はa接点直列接続，ANI命令はb接点直列接続命令で，指定ビットデバイスのON/OFF情報*1を取り込み，それまでの演算結果とAND演算を行い，この値を演算結果とします。

*1 ワードデバイスのビット指定時は，指定ビットの1/0によりON/OFFします。

- 直列接点の個数には制限がなく，何度でも引き続いて，この命令を用いることができます。
- OUT命令後，接点を通じて他のコイルにOUTすることを縦続出力といい，順序をまちがわなければ何度でも繰り返すことができます。

**例**
- AND命令(a接点直列接続): `LD X2 / AND X0 / OUT Y3`(X2 が「LD命令」、X0 が「AND命令」)
- ANI命令(b接点直列接続): `LD X2 / ANI X0 / OUT Y3`

【図】タイミングチャート (6.1 / 原本 p.119)
- AND命令: X2 と X0 が両方 ON の区間だけ Y3 が ON
- ANI命令: X2 が ON かつ X0 が OFF の区間だけ Y3 が ON

■OR，ORI
- OR命令はa接点1個の並列接続，ORI命令はb接点1個の並列接続命令で，指定デバイスのON/OFF情報*1を取り込み，それまでの演算結果とOR演算を行い，この値を演算結果とします。

*1 ワードデバイスのビット指定時は，指定ビットの1/0によりON/OFFします。

- OR，ORI命令は，この命令のあるステップから，その前のLD，LDI命令のあるステップに対して並列接続されます。
- 並列接続の回数には制限はありません。

> **Point**
> - ワードデバイスのビット指定時，ビットの指定は16進数で行います。(たとえば，D0のb11は「D0.B」となります。)

**例**
- OR命令(a接点並列接続): `LD X0 / OR X1 / OUT Y0`(X0 が「LD命令」、X1 が「OR命令」)
- ORI命令(b接点並列接続): `LD X0 / ORI X2 / OUT Y1`

【図】タイミングチャート (6.1 / 原本 p.120)
- OR命令: X0 または X1 のどちらかが ON の区間 Y0 が ON
- ORI命令: X0 が ON、または X2 が OFF の区間 Y1 が ON(X0=OFF かつ X2=ON のときだけ Y1=OFF)

#### エラー (6.1 / 原本 p.120)

演算エラーはありません。

### パルス演算開始，パルス直列接続，パルス並列接続 — LDP，LDF，ANDP，ANDF，ORP，ORF (6.1 / 原本 p.121-123)

対応機種: FX5S / FX5UJ / FX5U / FX5UC

- LDP：立上りパルス演算開始命令
  (s)で指定したビットデバイスの立上り時(OFF→ON)のみ導通します。
- LDF：立下りパルス演算開始命令
  (s)で指定したビットデバイスの立下り時(ON→OFF)のみ導通します。
- ANDP：立上りパルス直列接続命令 / ANDF：立下りパルス直列接続命令
  それまでの演算結果と(s)で指定したビットデバイスとのAND演算を行い，演算結果とします。
- ORP：立上りパルス並列接続命令 / ORF：立下りパルス並列接続命令
  それまでの演算結果と(s)で指定したビットデバイスとのOR演算を行い，演算結果とします。

#### 書式 (6.1 / 原本 p.121)

| 言語 | 記述 |
|---|---|
| ラダー | 【図】LDP=母線から↑付き接点(s)、LDF=母線から↓付き接点(s)、ANDP/ANDF=直列に↑/↓付き接点(s)、ORP/ORF=並列に↑/↓付き接点(s) |
| ST | `ENO:=LDP(EN,s);`<br>`ENO:=LDF(EN,s);`<br>`ENO:=ANDP(EN,s);`<br>`ENO:=ANDF(EN,s);`<br>`ENO:=ORP(EN,s);`<br>`ENO:=ORF(EN,s);` |
| FBD/LD | 【図】EN・s 入力、ENO 出力のボックス |

#### 機能 (6.1 / 原本 p.122-123)

■LDP，LDF
- LDP命令は立上りパルス演算開始命令で，指定ビットデバイスの立上り時(OFF→ON)のみ導通します。ワードデバイスのビット指定時は，指定ビットが0→1に変化したときのみ導通します。LDP命令のみの場合は，ON中実行命令のパルス化命令(□P)と同一になります。

LDP命令を使用した回路を，LDP命令を使用しない回路に置き換えた場合は下記のようになります。

```
LDP  X0            ⇒   LD   X0
MOV  K0 D0             MOVP K0 D0

LDP  X0            ⇒   LD   X0
OUT  M0                PLS  M0
```

- LDF命令は立下りパルス演算開始命令で，指定ビットデバイスの立下り時(ON→OFF)に導通します。ワードデバイスのビット指定時は，指定ビットが1→0に変化したときのみ導通します。

■ANDP，ANDF
- ANDP命令は立上りパルス直列接続命令，ANDF命令は立下りパルス直列接続命令で，それまでの演算結果とAND演算を行い，演算結果とします。ANDP命令，ANDF命令で使用するON/OFF情報を下記の表に示します。

| ANDP,ANDFで指定のデバイス<br>ビットデバイス | ANDP,ANDFで指定のデバイス<br>ワードデバイスのビット指定 | ANDPの状態 | ANDFの状態 |
|---|---|---|---|
| OFF→ON | 0→1 | ON | OFF |
| OFF | 0 | OFF | OFF |
| ON | 1 | OFF | OFF |
| ON→OFF | 1→0 | OFF | ON |

**例**
- ANDP命令(立上りパルス直列接続): `LD SM400 / ANDP X2 / OUT M1`
- ANDF命令(立下りパルス直列接続): `LD SM400 / ANDF X2 / OUT M1`

【図】タイミングチャート (6.1 / 原本 p.122)
- ANDP: SM400 は常時 ON。X2 が OFF→ON になるたびに M1 が「1演算周期」ON
- ANDF: X2 が ON→OFF になるたびに M1 が「1演算周期」ON

■ORP，ORF
- ORP命令は立上りパルス並列接続命令，ORF命令は立下りパルス並列接続命令で，それまでの演算結果とOR演算を行い演算結果とします。ORP命令，ORF命令で使用するON/OFF情報を下記の表に示します。

| ORP,ORFで指定のデバイス<br>ビットデバイス | ORP,ORFで指定のデバイス<br>ワードデバイスのビット指定 | ORPの状態 | ORFの状態 |
|---|---|---|---|
| OFF→ON | 0→1 | ON | OFF |
| OFF | 0 | OFF | OFF |
| ON | 1 | OFF | OFF |
| ON→OFF | 1→0 | OFF | ON |

#### プログラム例 (6.1 / 原本 p.123)

- LDP，ORP命令(立上りパルス演算開始，パルス並列接続)

```
LDP  X0        LDP命令
ORP  X1        ORP命令
OUT  M0
```

【図】タイミングチャート (6.1 / 原本 p.123)
- X0 の立上り、X1 の立上りのそれぞれで M0 が「1演算周期ON」

> 上図では，X0またはX1がOFF→ONに変化したとき，M0が1演算周期分ONします。

- LDF，ORF命令(立下りパルス演算開始，パルス並列接続)

```
LDF  X0        LDF命令
ORF  X1        ORF命令
OUT  M0
```

【図】タイミングチャート (6.1 / 原本 p.123)
- X0 の立下り、X1 の立下りのそれぞれで M0 が「1演算周期ON」

> 上図では，X0またはX1がON→OFFに変化したとき，M0が1演算周期分ONします。

#### エラー (6.1 / 原本 p.123)

演算エラーはありません。

|---|---|---|---|
| OFF→ON | 0→1 | OFF | ON |

| ORPI,ORFIで指定のデバイス<br>ビットデバイス | ORPI,ORFIで指定のデバイス<br>ワードデバイスのビット指定 | ORPIの状態 | ORFIの状態 |
|---|---|---|---|
| OFF→ON | 0→1 | OFF | ON |
| OFF | 0 | ON | ON |

## 6.2 結合命令 (6.2 / 原本 p.126-132)

### 回路ブロック直列接続，並列接続 — ANB，ORB (6.2 / 原本 p.126-127)

対応機種: FX5S / FX5UJ / FX5U / FX5UC

AブロックとBブロックのAND演算またはOR演算を行い，演算結果とします。

#### 書式 (6.2 / 原本 p.126)

| 言語 | 記述 |
|---|---|
| ラダー | 【図】ANB=Aブロック(並列回路)とBブロック(並列回路)を直列につなぐ接続線、ORB=Aブロック(直列回路)とBブロック(直列回路)を並列につなぐ接続線<br>A: Aブロック<br>B: Bブロック |
| ST | 対応していません。 |
| FBD/LD | 対応していません。 |

#### 機能 (6.2 / 原本 p.126-127)

■ANB
- AブロックとBブロックのAND演算を行い，演算結果とします。
- ANB命令のシンボルは，接点シンボルではなく接続シンボルです。

**例** ANB命令(回路ブロックの直列接続)

```
LD   X0
OR   X1
LD   X2          ← LD(並列ブロックの開始)
AND  X3
LDI  X4
AND  X5
ORB              ← ORB
OR   X6
ANB              ← ANB(X0/X1 のブロックと並列ブロックを直列接続)
OUT  Y7
```

【図】原本 p.126 の回路図
- 左ブロック: X0 と X1 の並列
- 「並列ブロック」: (X2・X3 の直列) と (X4(b接点)・X5 の直列) と X6 が並列
- 左ブロックと並列ブロックの接続点に「ANB」、並列ブロック内の X2-X3 行と X4-X5 行の合流点に「ORB」、並列ブロック先頭に「LD」の指示がある
- 図の最下段に母線から X3(a接点)の行があり、並列ブロック右端の縦線につながっている。この行のニモニック上の位置は図からは判読できない(**要確認**: 原本 p.126)

■ORB
- AブロックとBブロックのOR演算を行い，演算結果とします。
- ORB命令は，2接点以上の回路ブロックの並列接続を行います。1接点のみの並列接続は，OR命令，ORI命令を使用し，ORB命令は必要ありません。
- ORB命令のシンボルは，接点シンボルではなく接続シンボルです。

> **Point**
> - ORB命令で接続できる並列回路数に制限はありません。(下記の好ましいプログラムのとき)
> - ORB命令は一括使用できますが，LD，LDI命令の繰り返し使用回数が8回以下に制限されているため，ご注意ください。(下記の好ましくないプログラムのとき)

【図】回路プログラム (6.2 / 原本 p.127)
- (X0・X1 の直列) と (X2・X3 の直列) と (X4(b接点)・X5 の直列) の3つの「直列回路ブロック」が並列に接続され Y6 を出力。合流点2か所が「ORB命令」

リストプログラム:

| ステップ | 好ましいプログラム | 好ましくないプログラム |
|---|---|---|
| 0 | LD X0 | LD X0 |
| 1 | AND X1 | AND X1 |
| 2 | LD X2 | LD X2 |
| 3 | AND X3 | AND X3 |
| 4 | **ORB** | LDI X4 |
| 5 | LDI X4 | AND X5 |
| 6 | AND X5 | **ORB** |
| 7 | **ORB** | **ORB** |
| 8 | OUT Y6 | OUT Y6 |

#### エラー (6.2 / 原本 p.127)

演算エラーはありません。

### 演算結果プッシュ，読出し，ポップ — MPS，MRD，MPP (6.2 / 原本 p.128-130)

対応機種: FX5S / FX5UJ / FX5U / FX5UC

- MPS：MPS命令直前の演算結果(ON/OFF)を記憶します。
- MRD，MPP：MPS命令で記憶した演算結果を読み出し，その演算結果で次のステップから演算を行います。

#### 書式 (6.2 / 原本 p.128)

| 言語 | 記述 |
|---|---|
| ラダー | 【図】MPS/MRD/MPP は接点の後の分岐点に置く命令ボックス |
| ST | `ENO:=MPS(EN);`<br>`ENO:=MRD(EN);`<br>`ENO:=MPP(EN);` |
| FBD/LD | 【図】EN 入力、ENO 出力のボックス |

#### 機能 (6.2 / 原本 p.128)

■MPS
- MPS命令直前の演算結果(ON/OFF)を記憶します。
- MPS命令は連続で16回まで使用できます。MPP命令を途中に使用した場合は，MPS命令の使用数を-1します。

■MRD
- MPS命令で記憶した演算結果を読み出し，その演算結果で次のステップから演算を行います。

■MPP
- MPS命令で記憶した演算結果を読み出し，その演算結果で次のステップから演算を行います。
- MPS命令で記憶した演算結果をクリアします。
- MPS命令の使用数を-1します。

**例**

```
LD   X4
MPS              MPS命令により演算の途中結果を記憶させてから出力Y2を駆動します。
AND  X5
OUT  Y2
MRD              MRD命令によりその記憶を読出し出力Y3を駆動します。
AND  X6
OUT  Y3
MRD              MRD命令は何回でもプログラムできます。
OUT  Y4
MPP              最終出力回路はMRD命令のかわりにMPP命令を使用します。
AND  X7          これにより，上記の記憶が読み出されると共に，これがリセットされます。
OUT  Y5
```

> MPS命令により演算の途中結果を記憶させてから出力Y2を駆動します。
> MRD命令によりその記憶を読出し出力Y3を駆動します。
> MRD命令は何回でもプログラムできます。
> 最終出力回路はMRD命令のかわりにMPP命令を使用します。
> これにより，上記の記憶が読み出されると共に，これがリセットされます。

#### プログラム例 (6.2 / 原本 p.129-130)

- MPS命令の連続使用1回

この例では，スタックは一段しか使用していません。

```
LD   X0
AND  X1
MPS
AND  X2
OUT  Y0
MPP
OUT  Y1

LD   X3
MPS
AND  X4
OUT  Y2
MPP
AND  X5
OUT  Y3

LD   X6
MPS
AND  X7
OUT  Y4
MRD
AND  X10
OUT  Y5
MRD
AND  X11
OUT  Y6
MPP
AND  X12
OUT  Y7
```

- MPS命令の連続使用1回(ANB，ORB併用)

```

MPS
LD   X1
OR   X2
ANB
OUT  Y0
MRD

AND  X4
LD   X5

OUT  Y1

```

※回路図(原本 p.129)から書き起こし: X0 の後で MPS → (X1∥X2)→Y0、MRD → ((X3・X4)∥(X5・X6))→Y1、MPP → X7→Y2、さらに X7 の後で (X10∥X11)→Y3。

- MPS命令の連続使用2回

```

```

- MPS命令の連続使用4回

### 演算結果反転 — INV (6.2 / 原本 p.131)

対応機種: FX5S / FX5UJ / FX5U / FX5UC

INV命令の直前までの演算結果を反転します。

#### 書式 (6.2 / 原本 p.131)

| 言語 | 記述 |
|---|---|
| ラダー | 【図】接点の後に斜線入りの命令シンボル |
| ST | `ENO:=INV(EN);` |
| FBD/LD | 【図】EN 入力、ENO 出力のボックス |

#### 機能 (6.2 / 原本 p.131)

- INV命令の直前までの演算結果を反転します。

| INV命令の直前までの演算結果 | INV命令実行後の演算結果 |
|---|---|
| OFF | ON |
| ON | OFF |

#### エラー (6.2 / 原本 p.131)

演算エラーはありません。

> **Point**
> - INV命令は，直前までの演算結果で動作しますので，AND命令と同一位置で使用してください。INV命令は，LD命令，OR命令の位置では使用できません。
> - 回路ブロックを使用している場合は，回路ブロックの範囲で演算結果を反転します。INV命令とANB命令を併用して回路を動作させる場合，反転する範囲に注意してください。

【図】INV と ANB の併用例 (6.2 / 原本 p.131)
- M0 の後に ANB で回路ブロックを接続。ブロックは (M1・M2 の直列) と (M10・M20 の直列) の並列で、各直列行の後ろに INV(斜線)が入り、Y10 を出力。その下に END
- 点線で囲まれた範囲 = 「反転する範囲」: 各 INV が反転するのは、それぞれの行の M1・M2 / M10・M20 の直列部分だけ(M0 は含まない)

> □(点線枠): 反転する範囲

### 演算結果パルス化 — MEP，MEF (6.2 / 原本 p.132)

対応機種: FX5S / FX5UJ / FX5U / FX5UC

- MEP：MEP命令までの演算結果が立上り時にONになり，立上り時以外の場合はOFFになります。
- MEF：MEF命令までの演算結果が立下り時にONになり，立下り時以外の場合はOFFになります。

#### 書式 (6.2 / 原本 p.132)

| 言語 | 記述 |
|---|---|
| ラダー | 【図】MEP=接点の後に↑付きの命令シンボル、MEF=接点の後に↓付きの命令シンボル |
| ST | `ENO:=MEP(EN);`<br>`ENO:=MEF(EN);` |
| FBD/LD | 【図】EN 入力、ENO 出力のボックス |

#### 機能 (6.2 / 原本 p.132)

■MEP
- MEP命令までの演算結果が立上り時(OFF→ON)に，ON(導通状態)になります。MEP命令までの演算結果が立上り時以外の場合は，OFF(非導通状態)になります。
- MEP命令を使用すると，複数の接点を直列に接続した場合のパルス化処理が容易になります。

■MEF
- MEF命令までの演算結果が立下り時(ON→OFF)に，ON(導通状態)になります。MEF命令までの演算結果が立下り時以外の場合は，OFF(非導通状態)になります。
- MEF命令を使用すると，複数の接点を直列に接続した場合のパルス化処理が容易になります。

#### エラー (6.2 / 原本 p.132)

演算エラーはありません。

> **Point**
> - MEP命令，MEF命令は，サブルーチンプログラムおよびFOR～NEXT命令などで，インデックス修飾した接点のパルス化を行うと，正常に動作しないことがあります。
> - MEP命令，MEF命令は，直前までの演算結果で動作しますので，AND命令と同一位置で使用してください。MEP命令，MEF命令は，LD命令，OR命令の位置では使用できません。
