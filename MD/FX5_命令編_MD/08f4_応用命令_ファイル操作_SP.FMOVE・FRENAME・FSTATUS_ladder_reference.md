## 指定ファイルの移動 (8.7 / 原本 p.550-559)

### SP.FMOVE (8.7 / 原本 p.550-559)

対応機種: FX5S / FX5UJ / FX5U / FX5UC

#### 機能 (8.7 / 原本 p.554)

- (s1)で指定したドライブの(s2)で指定したファイルまたはフォルダを，(s3)で指定したドライブの(s4)で指定したフォルダに移動します。(s2)にフォルダを指定した場合，移動先に同名のファイルまたはフォルダが存在するとき， (d1)のb1の値(上書き設定)が0でも異常完了となりません。(移動をスキップします。)
- (s4)で指定した移動先のフォルダがない場合，フォルダは自動で作成されます。
- SP.FMOVE命令実行中はSM753(ファイルアクセス中)がONします。SM753がON中は，SP.FMOVE命令は実行できません。(実行した場合は無処理となります。)
- 処理完了(d2)のビットデバイスは，SP.FMOVE命令の処理完了を検出したスキャンのEND命令実行時に自動的にONし，次のスキャンのEND命令にてOFFします。SP.FMOVE命令が異常完了時には，異常完了(d2)+1のデバイスが，処理完了(d2)のデバイスと同じタイミングでON/OFFします。また，処理完了(d2)のビットデバイスがONしている場合，SP.FMOVE命令実行時に自動的にOFFします。
- 命令実行時に演算エラーを検出した場合，処理完了(d2)，異常完了(d2)+1はONしません。

#### タイミングチャート (8.7 / 原本 p.555-556)

ファイル移動機能の動作仕様を示します。

【図】指令入力(a接点) → `SP.FMOVE (U) (d1) (s1) (s2) (s3) (s4) (d2)`

| 使用用途設定エリア(d1)+0 | ファイル名/フォルダ名(s2) | 移動先フォルダパス(s4) |
|---|---|---|
| 0H，1H，5H，7H | [ファイル指定時]<br>user1.csv<br>[フォルダ指定時]<br>folder1 | folder2 |

[SDメモリカード内]

【図】(各図の構成: ルートフォルダ(*1)の下に $MELPRJ$、folder1、folder2)
- ■使用用途設定エリアが0H(ファイル指定)の場合
  - 命令実行前: folder1 の中に user1.csv(*2、太枠)。folder2(*3、点線枠)は空。
  - 命令実行後: folder1 は空、folder2 の中に user1.csv(太枠)。
  - folder1/user1.csvのファイルをfolder2内に移動します。
- ■使用用途設定エリアが1H(フォルダ指定，指定フォルダごと移動する)の場合
  - 命令実行前: folder1(*4、太枠)の中に user1.csv。folder2(*3、点線枠)は空。
  - 命令実行後: ルート直下の folder1 はなくなり、folder2 の中に folder1(中に user1.csv)(太枠)。
  - 移動元のフォルダ構成をfolder2内に移動します。
- ■使用用途設定エリアが5H(フォルダ指定，指定フォルダ内のすべてのファイル，サブフォルダを移動する)の場合
  - 命令実行前: folder1(*4、太枠)の中に user1.csv。folder2(*3、点線枠)は空。
  - 命令実行後: folder1 は空のフォルダとして残り、folder2 の中に user1.csv(太枠)。
  - 移動元フォルダ内のファイルのみをfolder2内に移動します。
- ■使用用途設定エリアが5H(フォルダ指定，指定フォルダ内のすべてのファイル，サブフォルダを移動する，上書きしない)の場合 (原本 p.556)
  - 命令実行前: folder1(*4、太枠)の中に user1.csv。folder2(*3、点線枠)の中に user1.csv。
  - 命令実行後: folder1 の中に user1.csv、folder2 の中に user1.csv(点線枠)のまま。

  - 移動先に同名ファイルが存在しない場合，移動を行います。
- ■使用用途設定エリアが7H(フォルダ指定，指定フォルダ内のすべてのファイル，サブフォルダを移動する，上書きする)の場合

*1 ルートフォルダ
*2 移動元ファイル
*3 移動先フォルダ
*4 移動元フォルダ

SP.FMOVE命令の実行から完了までのタイミングチャート(フラグ更新タイミング)を以下に示します。

【図】タイミングチャート(スキャン → END処理 → スキャン → END処理 → スキャン → END処理 → スキャン → END処理 の区間に対して)
- SP.FMOVE命令: 1スキャン目の先頭でOFF→ON、3スキャン目の途中までON(網掛け) … (1)
- 命令実行完了フラグ(d2)+0: 命令OFF→ON実行時にOFF … (2) → 3回目のEND処理でON … (3) → 次(4回目)のEND処理でOFF(ON期間 … (5))
- 命令異常完了フラグ(d2)+1: 命令OFF→ON実行時にOFF … (2) → 3回目のEND処理でON(異常完了時) … (4) → 次(4回目)のEND処理でOFF(ON期間 … (5))
- ファイルアクセス中 SM753: 命令実行でON → 3回目のEND処理(命令実行完了フラグON時)でOFF(ON期間の矢印に (5) と表記)
- ファイル移動処理: 1回目のEND処理から3スキャン目にかけて「ファイルアクセス実行」(命令実行から矢印で開始、終了後に完了フラグONへ矢印)

> 要確認: 原本の図では SM753 のON期間に「(5)」が付いていますが、凡例上は「(6) 命令実行完了フラグON時にOFFする」に当たると思われます。原本どおり記載しています(原本 p.556)。

(1) OFF→ON実行時以外はスキャン時無処理
(2) 命令OFF→ON実行時にOFF更新する
(3) 正常/異常完了時にONする*5
(4) 正常完了時にOFF，異常完了時にONする*5
(5) 命令実行完了後の1スキャンのみONする
(6) 命令実行完了フラグON時にOFFする

*5 命令実行時にエラーを検出した場合，完了フラグはONしません。

#### プログラム例 (8.7 / 原本 p.557-558)

X0をONするとSDメモリカード内に格納されている”sample”フォルダを”sample1”フォルダに移動します。

[プログラム動作]
1. RUN時にコントロールデータを作成する。
2. X0の駆動接点をM0で保持する。また，駆動接点ON時に命令実行完了フラグ，命令異常完了フラグを初期化する。
3. SP.FMOVE命令を実行する。*1
4. 命令実行完了フラグ，命令異常完了フラグは1スキャンのみONするため，正常/異常を明確にするためにM150，M151デバイスに保持する。

*1 他のファイル操作命令と同時実行させないために，下記特殊デバイスがOFFであることを確認後に実行します。
- SM606(SDメモリカード強制使用停止指示)
- SM753(ファイルアクセス中)

[使用デバイス]

| デバイス | 内容 |
|---|---|
| X0 | SP.FMOVE命令実行トリガ |
| D0 | コントロールデータが格納されている先頭デバイス<br>・D0: 使用用途設定エリア<br>・D1: 完了ステータス |
| M0 | SP.FMOVE命令実行保持デバイス |
| M100 | SP.FMOVE命令実行完了フラグ |
| M101 | SP.FMOVE命令異常完了フラグ |
| M150 | 正常完了表示デバイス |
| M151 | 異常完了表示デバイス |

[SP.FMOVE命令オペランド設定]

| オペランド | 内容 | 設定値 |
|---|---|---|
| (U) | ダミー | U1 |
| (d1) | コントロールデータが格納されている先頭デバイス | D0: 1H(フォルダ指定)<br>D1: 0H(正常完了) |
| (s1) | 移動元ドライブ指定 | K2(SDメモリカード) |
| (s2) | フォルダ名が格納されている先頭デバイス | “sample” |
| (s3) | 移動先ドライブ指定 | K2(SDメモリカード) |
| (s4) | 移動先フォルダパスを格納するデバイス | “sample1” |
| (d2) | 処理完了にてONするビットデバイス | M100: 実行完了フラグ<br>M101: 異常完了フラグ |

[ラダープログラム] (原本 p.557-558)

```
; ファイル移動命令用コントロールデータの作成
     LD    SM402                    // RUN後1スキャンON
     MOV   H1 D0                    // D0: コントロールデータ格納先頭デバイス
     MOV   H0 D1                    // D1: 完了ステータス
; ファイル移動命令の実行
     LDP   X0                       // X0: SP.FMOVE命令実行トリガ
     ANI   SM753                    // SM753: ファイルアクセス中
     SET   M0                       // M0: SP.FMOVE命令実行保持デバイス
     RST   M100                     // M100: SP.FMOVE命令実行完了フラグ
     RST   M101                     // M101: SP.FMOVE命令異常完了フラグ
     LD    M0                       // M0: SP.FMOVE命令実行保持デバイス
     ANI   SM606                    // SM606: メモリカード強制使用停止要求(ドライブ2)
     SP.FMOVE U1 D0 K2 "sample" K2 "sample1" M100   // D0: コントロールデータ格納先頭デバイス / M100: SP.FMOVE命令実行完了フラグ
     LD    M100                     // M100: SP.FMOVE命令実行完了フラグ
     MPS
     ANI   M101                     // M101: SP.FMOVE命令異常完了フラグ
     SET   M150                     // M150: 正常完了表示デバイス
     MRD
     AND   M101                     // M101: SP.FMOVE命令異常完了フラグ
     SET   M151                     // M151: 異常完了表示デバイス
     MPP
     RST   M0                       // M0: SP.FMOVE命令実行保持デバイス
```

[STプログラム] (原本 p.558)

```
//(1)ファイル移動命令用コントロールデータの作成
IF SM402 THEN
D0:=H1; //使用用途設定エリア(フォルダ指定，フォルダごと移動)
D1:=H0; //完了ステータス
END_IF;

//(2)駆動接点(X0)の立ち上がりの処理
IF LDP(TRUE,X0) THEN;
//ファイルアクセス中フラグがOFFであることをチェック
IF (SM753 <> TRUE) THEN
SET(TRUE,M0); //駆動接点保持
RST(TRUE,M100); //命令実行完了フラグの初期化
RST(TRUE,M101); //命令異常完了フラグの初期化
END_IF;
END_IF;

//(3)ファイル移動命令の実行
IF M0 THEN
//メモリカード強制使用停止要求がOFFであることをチェック
IF (SM606 <> TRUE) THEN;
//EN = TRUE(イネーブル入力，常時実行)
//U = U1(ダミー )
//S1 = 2(ドライブ指定，2固定)
//S2 = "sample"(ファイル名が格納されている先頭デバイス)
//S3 = 2(ドライブ指定，2固定)
//S4 = "sample1"(ファイル名が格納されている先頭デバイス)
//D1 = D0(コントロールデータが格納されている先頭デバイス)
//D2 = M100(処理完了にてONするビットデバイス)
SP_FMOVE(TRUE, U1, 2, "sample", 2, "sample1", D0, M100);
END_IF;
END_IF;

//(4)命令実行完了フラグの確認
IF M100 THEN
SET((M101 <> TRUE), M150); //命令実行完了フラグの保持
SET(M101, M151); //命令異常完了フラグの保持
RST(TRUE, M0); //駆動接点の開放
END_IF;
```

#### 注意事項 (8.7 / 原本 p.559)

- SP.FMOVE命令は，割込みプログラム中では実行しないでください。割込みプログラムで実行した場合，誤動作の原因となります。
- SM606(SDメモリカード強制使用停止指示)がON中は，SP.FMOVE命令を実行できません。また，命令実行時の初回END処理終了後にSM606をONした場合，ON検出時点で異常完了します。
- システムフォルダ($MELPRJ$)，またはシステムフォルダ内のファイルを指定したSP.FMOVE命令は実行できません。
- 命令実行中にCPUユニットの状態をRUN→STOPに変更しても，本命令は処理を継続します。
- 移動後のフォルダパス+ファイル名およびフォルダパスが文字数の制限を超えないようにしてください。(ファイルが破損，またはエラーとなる場合があります。)
- 上書きが発生する場合，命令が完了するまでの時間が延びる場合があります。
- 上書きが発生する場合，操作対象ファイルと同等サイズの空き容量を確保してください。
- 命令が処理の途中で異常完了した場合，ファイル/フォルダが処理途中の状態で残ることがあります。
- 上書きが発生し，移動対象ファイルのファイルサイズやファイル数が大きくなる場合，命令が完了するまでの時間が長くなります。
- SP.FMOVE命令で操作中のファイルには，他機能からアクセスしないでください。(ファイルがアクセス不可，またはエラーとなる場合があります。)
- 他機能からアクセスしているファイル/フォルダへの操作は行わないでください。
- SP.FMOVE命令はSP.DEVST命令，SP.FTPPUT命令，SP.FTPGET命令と同時に実行できません。
- SP.FMOVE命令実行中の電源断，およびSDメモリカードの抜去などを行わないでください。(ファイルが破損，またはエラーとなる場合があります。)

#### 機能 (8.7 / 原本 p.563)

- (s1)で指定したドライブの(s2)で指定したファイル名，またはフォルダ名を(s3)で指定したファイル名，またはフォルダ名に変更します。(s3)で指定したファイル名，またはフォルダ名が既に存在している場合，異常完了します。
- SP.FRENAME命令実行中はSM753(ファイルアクセス中)がONします。SM753がON中は，SP.FRENAME命令は実行できません。(実行した場合は無処理となります。)
- 処理完了(d2)のビットデバイスは，SP.FRENAME命令の処理完了を検出したスキャンのEND命令実行時に自動的にONし，次のスキャンのEND命令にてOFFします。SP.FRENAME命令が異常完了時には，異常完了(d2)+1のデバイスが，処理完了(d2)のデバイスと同じタイミングでON/OFFします。また，処理完了(d2)のビットデバイスがONしている場合，SP.FRENAME命令実行時に自動的にOFFします。
- 命令実行時に演算エラーを検出した場合，処理完了(d2)，異常完了(d2)+1はONしません。
- 変更後のファイルパス+フォルダ名およびフォルダパスが文字数の制限を超える場合，異常完了します。((d1)+1に8006Hが格納されます。)

#### タイミングチャート (8.7 / 原本 p.563)

| 使用用途設定エリア(d1)+0 | 変更するファイル名(s2) | 変更後のファイル名(s3) |
|---|---|---|
| 0H | sample/sample.bin | sample_change.bin |

[SDメモリカード内]

【図】
- ■命令実行前: sampleフォルダの中に sample.bin
- ■命令実行後: sampleフォルダの中に sample_change.bin

SP.FRENAME命令の実行から完了までのタイミングチャート(フラグ更新タイミング)を以下に示します。

【図】タイミングチャート(スキャン → END処理 → スキャン → END処理 → スキャン → END処理 → スキャン → END処理 の区間に対して)
- SP.FRENAME命令: 1スキャン目の先頭でOFF→ON、3スキャン目の途中までON(網掛け) … (1)
- 命令実行完了フラグ(d2)+0: 命令OFF→ON実行時にOFF … (2) → 3回目のEND処理でON … (3) → 次(4回目)のEND処理でOFF(ON期間 … (5))
- 命令異常完了フラグ(d2)+1: 命令OFF→ON実行時にOFF … (2) → 3回目のEND処理でON(異常完了時) … (4) → 次(4回目)のEND処理でOFF(ON期間 … (5))
- ファイルアクセス中 SM753: 命令実行でON → 3回目のEND処理(命令実行完了フラグON時)でOFF(ON期間の矢印に (5) と表記)
- ファイル名変更処理: 1回目のEND処理から3スキャン目にかけて「ファイルアクセス実行」(命令実行から矢印で開始、終了後に完了フラグONへ矢印)

> 要確認: 原本の図では SM753 のON期間に「(5)」が付いていますが、凡例上は「(6) 命令実行完了フラグON時にOFFする」に当たると思われます。原本どおり記載しています(原本 p.563)。

(1) OFF→ON実行時以外はスキャン時無処理
(2) 命令OFF→ON実行時にOFF更新する
(3) 正常/異常完了時にONする*1
(4) 正常完了時にOFF，異常完了時にONする*1
(5) 命令実行完了後の1スキャンのみONする
(6) 命令実行完了フラグON時にOFFする

*1 命令実行時にエラーを検出した場合，完了フラグはONしません。

#### プログラム例 (8.7 / 原本 p.564-565)

X0をONするとSDメモリカード内に格納されている”sample.bin”ファイル名を”sample_change.bin”に変更します。

[プログラム動作]
1. RUN時にコントロールデータを作成する。
2. X0の駆動接点をM0で保持する。また，駆動接点ON時に命令実行完了フラグ，命令異常完了フラグを初期化する。
3. SP.FRENAME命令を実行する。*1
4. 命令実行完了フラグ，命令異常完了フラグは1スキャンのみONするため，正常/異常を明確にするためにM150，M151デバイスに保持する。

*1 他のファイル操作命令と同時実行させないために，下記特殊デバイスがOFFであることを確認後に実行します。
- SM606(SDメモリカード強制使用停止指示)
- SM753(ファイルアクセス中)

[使用デバイス]

| デバイス | 内容 |
|---|---|
| X0 | SP.FRENAME命令実行トリガ |
| D0 | コントロールデータが格納されている先頭デバイス<br>・D0: 使用用途設定エリア<br>・D1: 完了ステータス |
| M0 | SP.FRENAME命令実行保持デバイス |
| M100 | SP.FRENAME命令実行完了フラグ |
| M101 | SP.FRENAME命令異常完了フラグ |
| M150 | 正常完了表示デバイス |
| M151 | 異常完了表示デバイス |

[SP.FRENAME命令オペランド設定]

| オペランド | 内容 | 設定値 |
|---|---|---|
| (U) | ダミー | U1 |
| (s1) | ドライブ指定 | K2(SDメモリカード) |
| (d1) | コントロールデータが格納されている先頭デバイス | D0: 0H(ファイル指定)<br>D1: 0H(正常完了) |
| (s2) | 変更するファイル名が格納されている先頭デバイス | "sample.bin" |
| (s3) | 変更後のファイル名が格納される先頭デバイス | "sample_change.bin" |

[ラダープログラム] (原本 p.564-565)

```
; ファイル名変更命令コントロールデータの作成
     LD    SM402                    // RUN後1スキャンON
     MOV   H0 D0                    // D0: コントロールデータ格納先頭デバイス
     MOV   H0 D1                    // D1: 完了ステータス
; ファイル名変更命令の実行
     LDP   X0                       // X0: SP.FRENAME命令実行トリガ
     ANI   SM753                    // SM753: ファイルアクセス中
     SET   M0                       // M0: SP.FRENAME命令実行保持デバイス
     RST   M100                     // M100: SP.FRENAME命令実行完了フラグ
     RST   M101                     // M101: SP.FRENAME命令異常完了フラグ
     LD    M0                       // M0: SP.FRENAME命令実行保持デバイス
     ANI   SM606                    // SM606: メモリカード強制使用停止要求(ドライブ2)
     SP.FRENAME U1 K2 D0 "sample.bin" "sample_change.bin" M100   // D0: コントロールデータ格納先頭デバイス / M100: SP.FRENAME命令実行完了フラグ
     LD    M100                     // M100: SP.FRENAME命令実行完了フラグ
     MPS
     ANI   M101                     // M101: SP.FRENAME命令異常完了フラグ
     SET   M150                     // M150: 正常完了表示デバイス
     MRD
     AND   M101                     // M101: SP.FRENAME命令異常完了フラグ
     SET   M151                     // M151: 異常完了表示デバイス
     MPP
     RST   M0                       // M0: SP.FRENAME命令実行保持デバイス
```

[STプログラム] (原本 p.565)

```
//(1)ファイル名変更命令用コントロールデータの作成
IF SM402 THEN
D0:=H0; //使用用途設定エリア(ファイル指定)
D1:=H0; //完了ステータス
END_IF;

//(2)駆動接点(X0)の立ち上がりの処理
IF LDP(TRUE,X0) THEN;
//ファイルアクセス中フラグがOFFであることをチェック
IF (SM753 <> TRUE) THEN
SET(TRUE,M0); //駆動接点保持
RST(TRUE,M100); //命令実行完了フラグの初期化
RST(TRUE,M101); //命令異常完了フラグの初期化
END_IF;
END_IF;

//(3)ファイル名変更命令の実行
IF M0 THEN
//メモリカード強制使用停止要求がOFFであることをチェック
IF (SM606 <> TRUE) THEN;
//EN = TRUE(イネーブル入力，常時実行)
//U = U1(ダミー )
//S1 = 2(ドライブ指定，2固定)
//S2 = "sample.bin"(変更するファイル名が格納されている先頭デバイス)
//S3 = "sample_change.bin"(変更後ファイル名が格納されている先頭デバイス)
//D1 = D0(コントロールデータが格納されている先頭デバイス)
//D2 = M100(処理完了にてONするビットデバイス)
SP_FRENAME(TRUE, U1, 2, "sample.bin", "sample_change.bin", D0, M100);
END_IF;
END_IF;

//(4)命令実行完了フラグの確認
IF M100 THEN
SET((M101 <> TRUE), M150); //命令実行完了フラグの保持
SET(M101, M151); //命令異常完了フラグの保持
RST(TRUE, M0); //駆動接点の開放
END_IF;
```

#### 注意事項 (8.7 / 原本 p.566)

- SP.FRENAME命令は，割込みプログラム中では実行しないでください。割込みプログラムで実行した場合，誤動作の原因となります。
- SM606(SDメモリカード強制使用停止指示)がON中は，SP.FRENAME命令を実行できません。また，命令実行時にSM606をONした場合，異常完了します。(SM606をONする前にファイル名変更が完了していた場合は，ファイル名の変更は行われます。)
- システムフォルダ($MELPRJ$)，またはシステムフォルダ内のファイルを指定したSP.FRENAME命令は実行できません。
- 命令実行中にCPUユニットの状態をRUN→STOPに変更しても，本命令は処理を継続します。
- 変更後のフォルダパス+ファイル名およびフォルダパスが文字数の制限を超えないようにしてください。(ファイルがアクセス不可，またはエラーとなる場合があります。)
- SP.FRENAME命令で操作中のファイルには，他機能からアクセスしないでください。(ファイルが破損，またはエラーとなる場合があります。)
- 他機能からアクセスしているファイル/フォルダへの操作は行わないでください。
- SP.FRENAME命令はSP.DEVST命令，SP.FTPPUT命令，SP.FTPGET命令と同時に実行できません。
- SP.FRENAME命令実行中の電源断，およびSDメモリカードの抜去などを行わないでください。(ファイルが破損，またはエラーとなる場合があります。)

#### 機能 (8.7 / 原本 p.570)

- (s1)で指定したドライブの(s2)で指定したファイル，またはフォルダの状態を取得し，(d2)以降のデバイスに格納します。(s2)にフォルダを指定した場合，(d2)+2～(d2)+3には0を格納します。
- SP.FSTATUS命令実行中はSM753(ファイルアクセス中)がONします。SM753がON中は，SP.FSTATUS命令は実行できません。(実行した場合は無処理となります。)
- 処理完了(d3)のビットデバイスは，SP.FSTATUS命令の処理完了を検出したスキャンのEND命令実行時に自動的にONし，次のスキャンのEND命令にてOFFします。SP.FSTATUS命令が異常完了時には，異常完了(d3)+1のデバイスが，処理完了(d3)のデバイスと同じタイミングでON/OFFします。また，処理完(d3)のビットデバイスがONしている場合，SP.FSTATUS命令実行時に自動的にOFFします。
- 命令実行時に演算エラーを検出した場合，処理完了(d2)，異常完了(d2)+1はONしません。

> 要確認: SP.FSTATUS の処理完了デバイスは(d3)ですが、4つ目の項目は「処理完了(d2)，異常完了(d2)+1」となっています(他命令の文言の流用による誤記と思われます)。また3つ目の項目の「処理完(d3)」も原本の表記どおりです(「処理完了(d3)」の脱字と思われます)。原文のまま転記しています(原本 p.570)。

#### タイミングチャート (8.7 / 原本 p.571)

ファイル状態取得機能の動作仕様を示します。

【図】指令入力(a接点) → `SP.FSTATUS (U) (s1) (d1) (s2) (d2) (d3)`

| 使用用途設定エリア(d1)+0 | ファイル名(s2) | ファイル状態(d2) |
|---|---|---|
| 0H | sample.bin | D100～D109 |

【図】
- [SDメモリカード内] sample.bin の「ファイル情報」(・ファイル属性 ・ファイルサイズ ・最終更新日時) → 読出し(転送) → [CPU内蔵メモリ内] 読出し結果
- 読出し結果: ファイル属性(d2)+0 = D100、(d2)+1 = D101、(D101 と D108 の間は波線でつないだ表示)、最終更新日時: 分(d2)+8 = D108、最終更新日時: 秒(d2)+9 = D109

SP.FSTATUS命令の実行から完了までのタイミングチャート(フラグ更新タイミング)を以下に示します。

【図】タイミングチャート(スキャン → END処理 → スキャン → END処理 → スキャン → END処理 → スキャン → END処理 の区間に対して)
- SP.FSTATUS命令: 1スキャン目の先頭でOFF→ON、3スキャン目の途中までON(網掛け) … (1)
- 命令実行完了フラグ(d2)+0: 命令OFF→ON実行時にOFF … (2) → 3回目のEND処理でON … (3) → 次(4回目)のEND処理でOFF(ON期間 … (5))
- 命令異常完了フラグ(d2)+1: 命令OFF→ON実行時にOFF … (2) → 3回目のEND処理でON(異常完了時) … (4) → 次(4回目)のEND処理でOFF(ON期間 … (5))
- ファイルアクセス中 SM753: 命令実行でON → 3回目のEND処理(命令実行完了フラグON時)でOFF(ON期間の矢印に (5) と表記)
- ファイル状態取得処理: 1回目のEND処理から3スキャン目にかけて「ファイルアクセス実行」(命令実行から矢印で開始、終了後に完了フラグONへ矢印)

> 要確認: 図中の完了フラグのラベルが「命令実行完了フラグ(d2)+0」「命令異常完了フラグ(d2)+1」となっていますが、SP.FSTATUS の処理完了デバイスは(d3)/(d3)+1 です(図の表記どおり転記)。また SM753 のON期間の「(5)」は凡例上 (6) に当たると思われます(原本 p.571)。

(1) OFF→ON実行時以外はスキャン時無処理
(2) 命令OFF→ON実行時にOFF更新する
(3) 正常/異常完了時にONする*1
(4) 正常完了時にOFF，異常完了時にONする*1
(5) 命令実行完了後の1スキャンのみONする
(6) 命令実行完了フラグON時にOFFする

*1 命令実行時にエラーを検出した場合，完了フラグはONしません。

#### プログラム例 (8.7 / 原本 p.572-573)

X0をONするとSDメモリカード内に格納されている”sample.bin”ファイルのファイル状態をD100～D109に読み出します。

[プログラム動作]
1. RUN時にコントロールデータを作成する。
2. X0の駆動接点をM0で保持する。また，駆動接点ON時に命令実行完了フラグ，命令異常完了フラグを初期化する。
3. SP.FSTATUS命令を実行する。*1
4. 命令実行完了フラグ，命令異常完了フラグは1スキャンのみONするため，正常/異常を明確にするためにM150，M151デバイスに保持する。

*1 他のファイル操作命令と同時実行させないために，下記特殊デバイスがOFFであることを確認後に実行します。
- SM606(SDメモリカード強制使用停止指示)
- SM753(ファイルアクセス中)

[使用デバイス]

| デバイス | 内容 |
|---|---|
| X0 | SP.FSTATUS命令実行トリガ |
| D0 | コントロールデータが格納されている先頭デバイス<br>・D0: 使用用途設定エリア<br>・D1: 完了ステータス |
| D100 | ファイル状態を格納する先頭デバイス |
| M0 | SP.FSTATUS命令実行保持デバイス |
| M100 | SP.FSTATUS命令実行完了フラグ |
| M101 | SP.FSTATUS命令異常完了フラグ |
| M150 | 正常完了表示デバイス |
| M151 | 異常完了表示デバイス |

[SP.FSTATUS命令オペランド設定]

| オペランド | 内容 | 設定値 |
|---|---|---|
| (U) | ダミー | U1 |
| (s1) | ドライブ指定 | K2(SDメモリカード) |
| (d1) | コントロールデータが格納されている先頭デバイス | D0: 0H(ファイル指定)<br>D1: 0H(正常完了) |
| (s2) | ファイル名が格納されている先頭デバイス | "sample.bin" |
| (d2) | ファイル状態を格納する先頭デバイス | D100 |

[ラダープログラム] (原本 p.572-573)

```
; ファイル状態取得命令コントロールデータの作成
     LD    SM402                    // RUN後1スキャンON
     MOV   H0 D0                    // D0: コントロールデータ格納先頭デバイス
     MOV   H0 D1                    // D1: 完了ステータス
; ファイル状態取得命令の実行
     LDP   X0                       // X0: SP.FSTATUS命令実行トリガ
     ANI   SM753                    // SM753: ファイルアクセス中
     SET   M0                       // M0: SP.FSTATUS命令実行保持デバイス
     RST   M100                     // M100: SP.FSTATUS命令実行完了フラグ
     RST   M101                     // M101: SP.FSTATUS命令異常完了フラグ
     LD    M0                       // M0: SP.FSTATUS命令実行保持デバイス
     ANI   SM606                    // SM606: メモリカード強制使用停止要求(ドライブ2)
     SP.FSTATUS U1 K2 D0 "sample.bin" D100 M100   // D0: コントロールデータ格納先頭デバイス / D100: ファイル情報読出し格納先頭デバイス / M100: SP.FSTATUS命令実行完了フラグ
     LD    M100                     // M100: SP.FSTATUS命令実行完了フラグ
     MPS
     ANI   M101                     // M101: SP.FSTATUS命令異常完了フラグ
     SET   M150                     // M150: 正常完了表示デバイス
     MRD
     AND   M101                     // M101: SP.FSTATUS命令異常完了フラグ
     SET   M151                     // M151: 異常完了表示デバイス
     MPP
     RST   M0                       // M0: SP.FSTATUS命令実行保持デバイス
```

[STプログラム] (原本 p.573)

```
//(1)ファイル状態取得命令用コントロールデータの作成
IF SM402 THEN
D0:=H0; //使用用途設定エリア(ファイル指定)
D1:=H0; //完了ステータス
END_IF;

//(2)駆動接点(X0)の立ち上がりの処理
IF LDP(TRUE,X0) THEN;
//ファイルアクセス中フラグがOFFであることをチェック
IF (SM753 <> TRUE) THEN
SET(TRUE,M0); //駆動接点保持
RST(TRUE,M100); //命令実行完了フラグの初期化
RST(TRUE,M101); //命令異常完了フラグの初期化
END_IF;
END_IF;

//(3)ファイル状態取得命令の実行
IF M0 THEN
//メモリカード強制使用停止要求がOFFであることをチェック
IF (SM606 <> TRUE) THEN;
//EN = TRUE(イネーブル入力，常時実行)
//U = U1(ダミー )
//S1 = 2(ドライブ指定，2固定)
//S2 = "sample.bin"(ファイル名が格納されている先頭デバイス)
//D1 = D0(コントロールデータが格納されている先頭デバイス)
//D2 = D100(ファイル状態を格納する先頭デバイス)
//D3 = M100(処理完了にてONするビットデバイス)
SP_FSTATUS(TRUE, U1, 2, "sample.bin", D0, D100, M100);
END_IF;
END_IF;

//(4)命令実行完了フラグの確認
IF M100 THEN
SET((M101 <> TRUE), M150); //命令実行完了フラグの保持
SET(M101, M151); //命令異常完了フラグの保持
RST(TRUE, M0); //駆動接点の開放
END_IF;
```

#### 注意事項 (8.7 / 原本 p.573)

- SP.FSTATUS命令は，割込みプログラム中では実行しないでください。割込みプログラムで実行した場合，誤動作の原因となります。
- SM606(SDメモリカード強制使用停止指示)がON中は，SP.FSTATUS命令を実行できません。また，命令実行時にSM606をONした場合，異常完了します。
- システムフォルダ($MELPRJ$)，またはシステムフォルダ内のファイルを指定したSP.FSTATUS命令は実行できません。
- 命令実行中にCPUユニットの状態をRUN→STOPに変更しても，本命令は処理を継続します。
- SP.FSTATUS命令はSP.DEVST命令，SP.FTPPUT命令，SP.FTPGET命令と同時に実行できません。
- SP.FSTATUS命令実行中の電源断，およびSDメモリカードの抜去などを行わないでください。
