## 2 プログラミング時の注意事項 (2章 / 原本 p.41)

## 2.1 命令共通のエラー (2.1 / 原本 p.41)

下記に命令実行時にエラーとなる条件を示します。

| エラー内容*1 | エラーコード<br>(SD0/SD8067) |
|---|---|
| 対象ユニットが存在しない入出力番号を指定した。 | 2801H |
| • 範囲外の入出力番号0～1777(8進数)を指定した。<br>• 命令で指定したデバイスまたはラベルが使用可能な範囲を超えた。 | 2820H |
| 命令で指定したユニットが持つバッファメモリの範囲を超えた。 | 2823H |

*1 接点命令ではエラーは検出せず，演算結果が非導通状態となります。

## 2.2 命令実行時のデバイス，ラベルの範囲チェック (2.2 / 原本 p.41)

### デバイス，ラベルの範囲チェック (2.2 / 原本 p.41)

デバイスやラベルを命令で指定する場合，範囲のチェックを行い，該当デバイス/ラベル範囲を超える指定をした場合はエラーが発生します。
デバイスに割り付けたラベルをプログラム中の命令で指定した場合も同様となります。
演算結果が該当デバイス/ラベルの範囲内で収まるようなプログラムを作成してください。

**例** グローバルデバイスを指定した場合

```
LD   (接点)
BMOV D0 D1023 K10        (1)=D1023
```

【図】デバイス/ラベルメモリの割付けイメージ (2.2 / 原本 p.41)
- メモリ上の並び: D0 … D1022, D1023, W0 … W0007 … W03FF
- 「データが書き込まれる範囲」は D1023 のみ(W0 以降には書き込まれない)

> (1) 転送先はD1023～D1032に該当する範囲です。D1024～D1032が存在しないため，D1023のみ書き込まれます。

## 2.3 同一デバイスのOUT命令，SET/RST命令，PLS/PLF命令使用時の動作 (2.3 / 原本 p.42-47)

同一デバイスを使用したOUT命令，SET/RST命令，PLS/PLF命令を1スキャンに複数実行した場合の動作について説明します。

### 同一デバイスのOUT命令の場合 (2.3 / 原本 p.42)

1スキャン中に同一デバイスのOUT命令を複数回実行しないでください。
1スキャン中に同一デバイスのOUT命令を複数回実行した場合は，各々のOUT命令実行時に，OUT命令までの演算結果により，指定デバイスがON/OFFします。
各々のOUT命令の実行時に，指定デバイスのON/OFFが決まるため，1スキャン中にON/OFFを繰り返すことがあります。
入力のX0とX1で，同一の内部リレー (M0)をON/OFFする回路を作成した場合の動作を示します。

```
LD   X0
OUT  M0
LD   X1
OUT  M0
```

【図】タイミングチャート (2.3 / 原本 p.42)
- スキャン1: X0=ON, X1=OFF。`LD X0 / OUT M0` 実行時に M0=ON(1)、続く `LD X1 / OUT M0` 実行時に M0=OFF(2)。→ M0 は同一スキャン内で ON→OFF
- END後 X0=OFF, X1=ON に変化
- スキャン2: `LD X0 / OUT M0` 実行時 M0=OFFのまま(3)、`LD X1 / OUT M0` 実行時 M0=ON(4)

> (1) X0がONのため，M0はONします。
> (2) X1がOFFのため，M0はOFFします。
> (3) X0がOFFのため，M0はOFFのままになります。
> (4) X1がONのため，M0はONします。

OUT命令で出力(Y)を指定すると，1スキャンの最後に実行したOUT命令のON/OFF状態が出力されます。

### 同一デバイスのSET/RST命令を使用した場合 (2.3 / 原本 p.43)

■SET命令の場合
SET命令は実行指令がONのとき指定デバイスをONし，実行指令がOFFのときは無処理です。
このため同一デバイスのSET命令を1スキャンに複数回実行した場合は，1つでも実行指令がONしていると，指定デバイスはONになります。

■RST命令の場合
RST命令は実行指令がONのとき指定デバイスをOFFし，実行指令がOFFのときは無処理です。
このため同一デバイスのRST命令を1スキャンに複数回実行した場合は，1つでも実行指令がONしていると，指定デバイスはOFFになります。

■1スキャンに同一デバイスのSET命令とRST命令がある場合
1スキャンに同一デバイスのSET命令とRST命令がある場合，SET命令は実行指令がONのとき指定デバイスをONし，RST命令は実行指令がONのとき指定デバイスをOFFします。
SET命令とRST命令の実行指令がOFFの場合は，指定デバイスのON/OFF状態は変化しません。

```
LD   X0
SET  M0
LD   X1
RST  M0
```

【図】タイミングチャート (2.3 / 原本 p.43)
- スキャン1: X0=ON, X1=OFF。`SET M0` 実行時 M0=ON(1)、`RST M0` は無処理で M0=ONのまま(2)
- END後 X0=OFF, X1=ON に変化
- スキャン2: `SET M0` は無処理で M0=ONのまま(3)、`RST M0` 実行時 M0=OFF(4)

> (1) X0がONのため，M0はONします。
> (2) X1がOFFのため，M0はONのままになります。(RST命令は無処理になります。)
> (3) X0がOFFのため，M0はONのままになります。(SET命令は無処理になります。)
> (4) X1がONのため，M0はOFFします。

SET/RST命令で出力(Y)を指定すると，1スキャンの最後に実行したSET/RST命令のON/OFF状態が出力されます。

### 同一デバイスのPLS命令を使用した場合 (2.3 / 原本 p.44-45)

PLS命令は，実行指令のOFF→ON時に指定デバイスをONします。OFF→ON以外(OFF→OFF，ON→ON，ON→OFF)のとき，指定デバイスをOFFにします。
同一デバイスのPLS命令を1スキャンに複数実行した場合，各PLS命令の実行指令がOFF→ONのときに，指定デバイスをONします。OFF→ON以外のとき指定デバイスをOFFします。
このため同一デバイスのPLS命令を1スキャンに複数回実行した場合は，PLS命令でONしたデバイスが，1スキャンONしないことがあります。

```
LD   X0
PLS  M0
LD   X1
PLS  M0
```

- X0とX1のON/OFFタイミングが異なるとき(指定デバイスが1スキャンONしない。)

【図】タイミングチャート (2.3 / 原本 p.44)
- スキャン1: X0がOFF→ON、X1=OFF。1つ目の `PLS M0` で M0=ON(1)、2つ目の `PLS M0` で M0=OFF(2)。→ M0 は1スキャン持続しない
- END後 X0=OFF, X1がOFF→ON
- スキャン2: 1つ目の `PLS M0` で M0=OFFのまま(3)、2つ目の `PLS M0` で M0=ON(4)

> (1) X0がOFF→ONのため，M0はONします。
> (2) X1がOFF→ON以外のため，M0はOFFします。
> (3) X0がOFF→ON以外のため，M0はOFFのままになります。
> (4) X1がOFF→ONのため，M0はONします。

- X0とX1のOFF→ONが同一タイミングのとき

【図】タイミングチャート (2.3 / 原本 p.45)
- スキャン1: X0・X1が同時にOFF→ON。1つ目の `PLS M0` で M0=ON(1)、2つ目の `PLS M0` でも M0=ONのまま(2)
- スキャン2: X0・X1ともON継続。1つ目の `PLS M0` で M0=OFF(3)、2つ目の `PLS M0` で M0=OFFのまま(4)

> (1) X0がOFF→ONのため，M0はONします。
> (2) X1がOFF→ONのため，M0はONのままになります。
> (3) X0がOFF→ON以外のため，M0はOFFします。
> (4) X1がOFF→ON以外のため，M0はOFFのままになります。

PLS命令で出力(Y)を指定すると，1スキャンの最後に実行したPLS命令のON/OFF状態が出力されます。

### 同一デバイスのPLF命令を使用した場合 (2.3 / 原本 p.46-47)

PLF命令は，実行指令のON→OFF時に指定デバイスをONします。ON→OFF以外(OFF→OFF，OFF→ON，ON→ON)のとき，指定デバイスをOFFにします。

## 2.4 一般フラグの扱い (2.4 / 原本 p.47-49)

命令の種類によっては，下記のフラグが動作します。
- SM8020：ゼロフラグ
- SM8021：ボローフラグ
- SM8022：キャリフラグ
- SM8029：命令実行完了フラグ
- SM8090：ブロック比較信号
- SM8304：ゼロフラグ(MUL，DIV命令用)
- SM8306：キャリフラグ(MUL，DIV命令用)
- SM8328：命令非実行フラグ
- SM8329：命令実行異常完了フラグ

これらの一般フラグは，命令をON実行するたびにONまたはOFFで動作しますが，OFF実行時やエラー発生時は変化しません。
複数の命令でこのフラグが変化しますので，これらの命令を実行するたびにON/OFF状態が変化します。
一般フラグの接点は，各命令の直下にプログラムしてください。(→46ページ 複数のフラグのプログラム(SM8029(命令実行完了フラグ)の例))

### 複数のフラグのプログラム(SM8029(命令実行完了フラグ)の例) (2.4 / 原本 p.48)

同じフラグを動作させる命令に対してSM8029(命令実行完了フラグ)をまとめてプログラムすると，どの命令の実行内容でフラグの制御が行われているのかを判断するのが難しくなります。また，個々の命令に対応するフラグが正常に読み取れなくなります。
命令の直下以外で使用したい場合は，→47ページ 命令の直下以外で使用する方法(SM8029(命令実行完了フラグ)の例)を参照してください。

**良い例** (原本 p.48)

```
(～ 前略 ～)
LD   SM8000
DSW  X10 Y10 D0 K1
AND  SM8029              実行完了 ← SM8029はDSWの実行完了フラグとして動作
MUL  D0 K10 D20
(～ 中略 ～)
LD   X0
SET  M0
LD   M0
DPLSY K1000 D20 Y0
AND  SM8029              実行完了 ← SM8029はDPLSYの実行完了フラグとして動作
RST  M0
```

※原本の図では、SM8029 接点は各命令(DSW / DPLSY)と同じ実行条件(SM8000 / M0)から分岐した直下に置かれている。ニモニック化にあたり、分岐直下の直列接続として `AND SM8029` で表記した(原本図の接続: 実行条件の縦線から分岐 → SM8029 → 後続命令)。

**悪い例** (原本 p.48)

```
LD   SM8029              実行完了 (×) ← SM8029はDPLSY(下側)の実行完了フラグとして動作
RST  M0                  DPLSY(上側)命令用プログラム
(～)
LD   SM8000
DSW  X10 Y10 D0 K1
LD   X0
SET  M0
LD   M0
DPLSY K1000 D20 Y0       DPLSY命令(上側)
LD   SM8029              実行完了 (×) ← SM8029はDPLSY(上側)の実行完了フラグとして動作
MUL  D0 K10 D20          DSW命令用プログラム
LD   M1
DPLSY K1000 D22 Y1       DPLSY命令(下側)
```

【図】悪い例の説明ラベル (原本 p.48)
- 先頭の `SM8029 → RST M0`(DPLSY(上側)命令用のつもり)は、実際にはプログラム末尾の DPLSY(下側)の実行完了フラグとして動作
- `SM8000 → DSW` 〜 `M0 → DPLSY(上側)` の区間では SM8029 は DSW の実行完了フラグとして動作
- `SM8029 → MUL`(DSW命令用のつもり)は、実際には直前の DPLSY(上側)の実行完了フラグとして動作

### 命令の直下以外で使用する方法(SM8029(命令実行完了フラグ)の例) (2.4 / 原本 p.49)

複数の命令をプログラムすると，一般フラグがそれぞれの命令のON実行で変化します。
そのため，その命令の直下以外で使用する場合は，一般フラグを命令の直下で他のデバイスをON/OFFしてその接点を指令入力として使用します。

```
(～ 前略 ～)
LD   SM8000
DSW  X10 Y10 D0 K1
AND  SM8029              実行完了
OUT  M100                ← DSWの実行完了フラグSM8029をM100へ変更
LD   M0
DPLSY K1000 D20 Y0
AND  SM8029              実行完了
RST  M0
OUT  M200                ← DPLSYの実行完了フラグSM8029をM200へ変更
(～ 中略 ～)
LD   M100                ← DSW完了フラグとして動作
MUL  D0 K10 D20
LD   M200                ← DPLSY完了フラグとして動作
OUT  Y30
```

※原本の図では、DPLSY 側は M0 から分岐 → SM8029 → `RST M0` と `M200` の2出力に並列分岐している。上記ニモニックは同じ接続を `AND SM8029` の後に `RST M0` / `OUT M200` を並べて表記した。

## 2.5 汎用ファンクション/ファンクションブロックの戻り値について (2.5 / 原本 p.49)

汎用ファンクション/ファンクションブロックを使用した場合，出力変数には，必ずデバイスまたはラベルを設定し，戻り値を受け取るようにしてください。
出力変数を設定していない場合，シーケンサに書き込んだ際にエラーとなることがあります。

【図】GX Works3 のラダー編集画面の例 (2.5 / 原本 p.49)
- ×(悪い例): M0 → MAX_E(EN)、IN1=D0、IN2=D1、ENO → Y0。出力 `MAX_E` の端子に**デバイス/ラベルが設定されていない**
- ○(良い例): 同じ回路で、出力 `MAX_E` の端子に **D10** を設定して戻り値を受け取っている
