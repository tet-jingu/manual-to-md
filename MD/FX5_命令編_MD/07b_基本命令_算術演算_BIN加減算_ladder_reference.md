■フラグの動作と数値の正負の関係

| デバイス | 名称 | 内容 |
|---|---|---|
| SM700，SM8022 | キャリ | 演算結果が設定データ範囲の上限を超えるときにはキャリフラグが動作(ON)します。 |
| SM8020 | ゼロ | 演算結果が0のときにはゼロフラグが動作(ON)します。 |
| SM8021 | ボロー | 演算結果が設定データ範囲の下限未満になるときにはボローフラグが動作(ON)します。 |

【図】フラグと値の遷移 (7.2 / 原本 p.216)
- 負側: 値が -2, -1, 0 と変化する位置で「ゼロフラグ」、-32768 から下に行く位置で「ボローフラグ」(-32768 を下回ると最上位ビットが0の側へ回り込む)
- 中央: -1, 0, 1 の 0 の位置で「ゼロフラグ」。「データの最上位ビットが1になります」(負の側) / 「データの最上位ビットが0になります」(正の側)
- 正側: 32767 から上に行く位置で「キャリフラグ」(32767 → 0, 1, 2 と回り込む)、0 の位置で「ゼロフラグ」

#### 注意事項 (7.2 / 原本 p.216)

■ソースとデスティネーションに同一デバイス指定
ソースとデスティネーションに同一デバイス番号を指定することもできます。この場合，連続実行形のADD命令を使用すると毎演算周期ごとに加算結果が変化しますのでご注意ください。

```
LD   X1
ADD  D0 K25 D0        (D0)+25→(D0)
```

■+1加算プログラムによるADD(P)命令と+(P)命令およびINC(P)命令の違い
ADD(P)命令は，X1がOFF→ONに変化するたびにD0の内容に1が加算されるプログラムの場合，+(P)命令および後述のINC(P)命令と似ていますが，下記内容が異なります。

| | ADD(P)命令 | +(P)命令，INC(P)命令 |
|---|---|---|
| フラグ(ゼロ，ボロー，キャリ) | 動作します | 動作しません |
| 演算結果 (s)+1=(d) | +32767→0→+1→+2→… | +32767→-32768→-32767→… |

#### プログラム例 (7.2 / 原本 p.216)

```
LD   X1
ADDP D0 K1 D0         (D0)＋1→(D0)
```

LD   X1

※SUB(P)命令側の演算結果列は原文のまま転記(「-32768→0→-1→-2→…」)。

```

```

- -2, -1, 0, -2147483648 の位置にゼロフラグ・ボローフラグ

#### 注意事項 (7.2 / 原本 p.228)

■DADD命令使用時
ワードデバイスの指定では下位16ビット側のデバイスが指定され，これに続くデバイス番号のデバイスが上位側になります。番号が重複しないようにするために，指定デバイスは常に偶数番号にすることをおすすめします。

■ソースとデスティネーションに同一デバイス指定
ソースとデスティネーションに同一デバイス番号を指定することもできます。この場合，連続実行形のADD命令を使用すると各演算周期ごとに加算結果が変化しますのでご注意ください。

```
LD   X1
DADD D0 K25 D0        (D1, D0)+25→(D1, D0)
```

※本文は「連続実行形のADD命令」と原文のまま(例は DADD)。

■+1加算プログラムによるDADD(P)命令とD+(P)命令およびDINC(P)命令の違い
DADD(P)命令は，X1がOFF→ONに変化するたびにD0の内容に1が加算されるプログラムの場合，D+(P)命令および後述のDINC(P)命令と似ていますが，下記内容が異なります。

| | DADD(P)命令 | D+(P)命令，DINC(P)命令 |
|---|---|---|
| フラグ(ゼロ，ボロー，キャリ) | 動作します | 動作しません |
| 演算結果 (s)+1=(d) | +2147483647→0→+1→+2→… | +2147483647→-2147483648→-2147483647→… |
