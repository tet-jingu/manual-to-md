#### 機能 (8.7 / 原本 p.535)

- (s1)で指定したドライブの(s2)で指定したファイル，またはフォルダを削除します。
- SP.FDELETE命令実行中はSM753(ファイルアクセス中)がONします。SM753がON中は，SP.FDELETE命令は実行できません。(実行した場合は無処理となります。)
- 処理完了(d2)のビットデバイスは，SP.FDELETE命令の処理完了を検出したスキャンのEND命令実行時に自動的にONし，次のスキャンのEND命令にてOFFします。また，処理完了(d2)のビットデバイスがONしている場合，SP.FDELETE命令実行時に自動的にOFFします。
- SP.FDELETE命令が異常完了時には，異常完了(d2)+1のデバイスが，処理完了(d2)のデバイスと同じタイミングでON/OFFします。
- 命令実行時に演算エラーを検出した場合，処理完了(d2)，異常完了(d2)+1はONしません。

ファイル削除機能の動作仕様を示します。

| 使用用途設定エリア(d1)+0 | ファイル名/フォルダ名(s2) |
|---|---|
| 0H，1H，3H | [ファイル指定時]<br>sample/sample.bin<br>[フォルダ指定時]<br>sample |

[SDメモリカード内]

【図】
- ■使用用途設定エリアが0H(ファイル指定)の場合: sampleフォルダ内の sample.bin と file.bin のうち、sample.bin に×印(*1)。sampleフォルダと file.bin は残る。
- ■使用用途設定エリアが1H(フォルダ指定+空フォルダでない場合も削除する)の場合: sampleフォルダ(*1)、その中の sample.bin(*1)、file.bin(*1) すべてに×印。

【図】タイミングチャート(スキャン → END処理 → スキャン → END処理 → スキャン → END処理 → スキャン → END処理 の区間に対して)

(2) 命令OFF→ON実行時にOFF更新する
(3) 正常/異常完了時にONする*2
(4) 正常完了時にOFF，異常完了時にONする*2
(5) 命令実行完了後の1スキャンのみONする
(6) 命令実行完了フラグON時にOFFする

#### プログラム例 (8.7 / 原本 p.536-538)

X0をONするとSDメモリカード内に格納されている”\sample\sample.csv”ファイルを削除します。

[プログラム動作]
1. RUN時にコントロールデータを作成する。
2. X0の駆動接点をM0で保持する。また，駆動接点ON時に命令実行完了フラグ，命令異常完了フラグを初期化する。
3. SP.FDELETE命令を実行する。*1
4. 命令実行完了フラグ，命令異常完了フラグは1スキャンのみONするため，正常/異常を明確にするためにM150，M151デバイスに保持する。

*1 他のファイル操作命令と同時実行させないために，下記特殊デバイスがOFFであることを確認後に実行します。
- SM606(SDメモリカード強制使用停止指示)
- SM753(ファイルアクセス中)

[使用デバイス]

| デバイス | 内容 |
|---|---|
| X0 | SP.FDELETE命令実行トリガ |
| D0 | コントロールデータが格納されている先頭デバイス<br>・D0: 使用用途設定エリア<br>・D1: 完了ステータス |
| M0 | SP.FDELETE命令実行保持デバイス |
| M100 | SP.FDELETE命令実行完了フラグ |
| M101 | SP.FDELETE命令異常完了フラグ |
| M150 | 正常完了表示デバイス |
| M151 | 異常完了表示デバイス |

[SP.FDELETE命令オペランド設定]

| オペランド | 内容 | 設定値 |
|---|---|---|
| (U) | ダミー | U1 |
| (s1) | ドライブ指定 | K2(SDメモリカード) |
| (d1) | コントロールデータが格納されている先頭デバイス | D0: 0H(ファイル指定)<br>D1: 0H(正常完了) |

[ラダープログラム] (原本 p.537)

```
; ファイル操作命令 コントロールデータの作成
     LD    SM402                    // RUN後1スキャンON
     MOV   H0 D0                    // D0: コントロールデータ格納先頭デバイス
     MOV   H0 D1                    // D1: 完了ステータス
; ファイル削除命令の実行
     LDP   X0                       // X0: SP.FDELETE命令実行トリガ
     ANI   SM753                    // SM753: ファイルアクセス中
     SET   M0                       // M0: SP.FDELETE命令実行保持デバイス
     RST   M100                     // M100: SP.FDELETE命令実行完了フラグ
     RST   M101                     // M101: SP.FDELETE命令異常完了フラグ
     LD    M0                       // M0: SP.FDELETE命令実行保持デバイス
     ANI   SM606                    // SM606: メモリカード強制使用停止要求(ドライブ2)
     SP.FDELETE U1 K2 D0 "\sample\sample.csv" M100   // D0: コントロールデータ格納先頭デバイス / M100: SP.FDELETE命令実行完了フラグ
     LD    M100                     // M100: SP.FDELETE命令実行完了フラグ
     MPS
     ANI   M101                     // M101: SP.FDELETE命令異常完了フラグ
     SET   M150                     // M150: 正常完了表示デバイス
     MRD
     AND   M101                     // M101: SP.FDELETE命令異常完了フラグ
     SET   M151                     // M151: 異常完了表示デバイス
     MPP
     RST   M0                       // M0: SP.FDELETE命令実行保持デバイス
```

```

IF SM402 THEN
D0:=H0; //使用用途設定エリア(ファイル指定)
D1:=H0; //完了ステータス
END_IF;

//(2)駆動接点(X0)の立ち上がりの処理
IF LDP(TRUE,X0) THEN;
//ファイルアクセス中フラグがOFFであることをチェック
IF (SM753 <> TRUE) THEN
SET(TRUE,M0); //駆動接点保持
RST(TRUE,M100); //命令実行完了フラグの初期化
RST(TRUE,M101); //命令異常完了フラグの初期化
END_IF;
END_IF;

//(3)ファイル削除命令の実行
IF M0 THEN
//メモリカード強制使用停止要求がOFFであることをチェック
```

#### 注意事項 (8.7 / 原本 p.539)

- SP.FDELETE命令は，ユーザ割込みプログラム内で実行できません。エラー (3582H)が発生します。
- SM606(SDメモリカード強制使用停止指示)がON中は，SP.FDELETE命令を実行できません。また，命令実行後にSM606をONした場合，異常完了します。(SM606をONする前に削除したデータは復元されません。)
- システムフォルダ($MELPRJ$)，またはシステムフォルダ内のファイルを指定したSP.FDELETE命令は実行できません。SP.FDELETE命令を実行した場合，演算エラー (3405H)が発生します。
- 命令実行中にCPUユニットの状態をRUN→STOPに変更しても，本命令は処理を継続します。
- 命令が処理の途中で異常完了した場合，すでに削除されたファイル，またはフォルダは復元されません。
- 削除対象ファイルのファイルサイズやファイル数が大きくなる場合，命令が完了するまでの時間が長くなります。
- SP.FDELETE命令で操作中のファイルには，他機能からアクセスしないでください。(ファイルが破損，またはエラーとなる場合があります。)
- 他機能からアクセスしているファイル/フォルダへの操作は行わないでください。
- SP.FDELETE命令はSP.DEVST命令，SP.FTPPUT命令，SP.FTPGET命令と同時に実行できません。
- SP.FDELETE命令の使用用途設定エリアが1H(フォルダ指定+空フォルダでない場合も削除する)の場合，(s2)で指定するフォルダ内部にパスが244文字を超えるフォルダや，253文字を超えるファイルが存在する場合は8006Hエラーが発生します。
- SP.FDELETE命令の使用用途設定エリアが3H(フォルダ指定+空フォルダの場合のみ削除する)の場合，(s2)で指定するフォルダ内部にファイルまたはフォルダが存在している場合は8004Hエラーが発生します。
- SP.FDELETE命令実行中の電源断，およびSDメモリカードの抜去などを行わないでください。(ファイルが破損，またはエラーとなる場合があります。)

#### 機能 (8.7 / 原本 p.544)

- (s1)で指定したドライブの(s2)で指定したファイルまたはフォルダを，(s3)で指定したドライブの(s4)で指定したフォルダにコピーします。(s2)にフォルダを指定した場合，コピー先に同名のファイルおよびサブフォルダが存在するとき，(d1)のビット1の値(上書き設定)が0でも異常完了となりません。(コピーをスキップします。)
- (s4)で指定したコピー先のフォルダがない場合，フォルダは自動で作成されます。
- SP.FCOPY命令実行中はSM753(ファイルアクセス中)がONします。SM753がON中は，SP.FCOPY命令は実行できません。(実行した場合は無処理となります。)
- 処理完了(d2)のビットデバイスは，SP.FCOPY命令の処理完了を検出したスキャンのEND命令実行時に自動的にONし，次のスキャンのEND命令にてOFFします。SP.FCOPY命令の異常完了時，異常完了(d2)+1のデバイスが，処理完了(d2)のデバイスと同じタイミングでON/OFFします。また，処理完了(d2)のビットデバイスがONしている場合，SP.FCOPY命令実行時に自動的にOFFします。
- 命令実行時に演算エラーを検出した場合，処理完了(d2)，異常完了(d2)+1はONしません。

SP.FCOPY命令の実行から完了までのタイミングチャート(フラグ更新タイミング)を以下に示します。

【図】タイミングチャート(スキャン → END処理 → スキャン → END処理 → スキャン → END処理 → スキャン → END処理 の区間に対して)
- SP.FCOPY命令: 1スキャン目の先頭でOFF→ON、3スキャン目の途中までON(網掛け) … (1)
- 命令実行完了フラグ(d2)+0: 命令OFF→ON実行時にOFF … (2) → 3回目のEND処理でON … (3) → 次(4回目)のEND処理でOFF(ON期間 … (5))
- 命令異常完了フラグ(d2)+1: 命令OFF→ON実行時にOFF … (2) → 3回目のEND処理でON(異常完了時) … (4) → 次(4回目)のEND処理でOFF(ON期間 … (5))
- ファイルアクセス中 SM753: 命令実行でON → 3回目のEND処理(命令実行完了フラグON時)でOFF(ON期間の矢印に (5) と表記)
- ファイルコピー処理: 1回目のEND処理から3スキャン目にかけて「ファイルアクセス実行」(命令実行から矢印で開始、終了後に完了フラグONへ矢印)

> 要確認: 原本の図では SM753 のON期間に「(5)」が付いていますが、凡例上は「(6) 命令実行完了フラグON時にOFFする」に当たると思われます(SP.FDELETE の同じ図では (6))。原本どおり記載しています(原本 p.546)。

(1) OFF→ON実行時以外はスキャン時無処理
(2) 命令OFF→ON実行時にOFF更新する
(3) 正常/異常完了時にONする*5
(4) 正常完了時にOFF，異常完了時にONする*5
(5) 命令実行完了後の1スキャンのみONする
(6) 命令実行完了フラグON時にOFFする

*5 命令実行時にエラーを検出した場合，完了フラグはONしません。

#### プログラム例 (8.7 / 原本 p.547-548)

X0をONするとSDメモリカード内に格納されている”sample.bin”ファイルを”sample1”フォルダにコピーします。

[プログラム動作]
1. RUN時にコントロールデータを作成する。
2. X0の駆動接点をM0で保持する。また，駆動接点ON時に命令実行完了フラグ，命令異常完了フラグを初期化する。
3. SP.FCOPY命令を実行する。*1
4. 命令実行完了フラグ，命令異常完了フラグは1スキャンのみONするため，正常/異常を明確にするためにM150，M151デバイスに保持する。

*1 他のファイル操作命令と同時実行させないために，下記特殊デバイスがOFFであることを確認後に実行します。
- SM606(SDメモリカード強制使用停止指示)
- SM753(ファイルアクセス中)

[使用デバイス]

| デバイス | 内容 |
|---|---|
| X0 | SP.FCOPY命令実行トリガ |
| D0 | コントロールデータが格納されている先頭デバイス<br>・D0: 使用用途設定エリア<br>・D1: 完了ステータス |
| M0 | SP.FCOPY命令実行保持デバイス |
| M100 | SP.FCOPY命令実行完了フラグ |
| M101 | SP.FCOPY命令異常完了フラグ |
| M150 | 正常完了表示デバイス |
| M151 | 異常完了表示デバイス |

[SP.FCOPY命令オペランド設定]

| オペランド | 内容 | 設定値 |
|---|---|---|
| (U) | ダミー | U1 |
| (d1) | コントロールデータが格納されている先頭デバイス | D0: 0H(ファイル指定)<br>D1: 0H(正常完了) |
| (s1) | コピー元ドライブ指定 | K2(SDメモリカード) |
| (s2) | コピー元ファイル名が格納されている先頭デバイス | “sample.bin” |
| (s3) | コピー先ドライブ指定 | K2(SDメモリカード) |
| (s4) | コピー先フォルダパスを格納する先頭デバイス | “sample1” |
| (d2) | 処理完了にてONするビットデバイス | M100: 実行完了フラグ<br>M101: 異常完了フラグ |

[ラダープログラム] (原本 p.547-548)

```
; ファイルコピー命令用コントロールデータの作成
     LD    SM402                    // RUN後1スキャンON
     MOV   H0 D0                    // D0: コントロールデータ格納先頭デバイス
     MOV   H0 D1                    // D1: 完了ステータス
; ファイルコピー命令の実行
     LDP   X0                       // X0: SP.FCOPY命令実行トリガ
     ANI   SM753                    // SM753: ファイルアクセス中
     SET   M0                       // M0: SP.FCOPY命令実行保持デバイス
     RST   M100                     // M100: SP.FCOPY命令実行完了フラグ
     RST   M101                     // M101: SP.FCOPY命令異常完了フラグ
     LD    M0                       // M0: SP.FCOPY命令実行保持デバイス
     ANI   SM606                    // SM606: メモリカード強制使用停止要求(ドライブ2)
     SP.FCOPY U1 D0 K2 "sample.bin" K2 "sample1" M100   // D0: コントロールデータ格納先頭デバイス / M100: SP.FCOPY命令実行完了フラグ
     LD    M100                     // M100: SP.FCOPY命令実行完了フラグ
     MPS
     ANI   M101                     // M101: SP.FCOPY命令異常完了フラグ
     SET   M150                     // M150: 正常完了表示デバイス
     MRD
     AND   M101                     // M101: SP.FCOPY命令異常完了フラグ
     SET   M151                     // M151: 異常完了表示デバイス
     MPP
     RST   M0                       // M0: SP.FCOPY命令実行保持デバイス
```

[STプログラム] (原本 p.548)

```
//(1)ファイルコピー命令用コントロールデータの作成
IF SM402 THEN
D0:=H0; //使用用途設定エリア(ファイル指定)
D1:=H0; //完了ステータス
END_IF;

//(2)駆動接点(X0)の立ち上がりの処理
IF LDP(TRUE,X0) THEN;
//ファイルアクセス中フラグがOFFであることをチェック
IF (SM753 <> TRUE) THEN
SET(TRUE,M0); //駆動接点保持
RST(TRUE,M100); //命令実行完了フラグの初期化
RST(TRUE,M101); //命令異常完了フラグの初期化
END_IF;
END_IF;

//(3)ファイルコピー命令の実行
IF M0 THEN
//メモリカード強制使用停止要求がOFFであることをチェック
IF (SM606 <> TRUE) THEN;
//EN = TRUE(イネーブル入力，常時実行)
//U = U1(ダミー )
//S1 = 2(ドライブ指定，2固定)
//S2 = "sample.bin"(ファイル名が格納されている先頭デバイス)
//S3 = 2(ドライブ指定，2固定)
//S4 = "sample1"(フォルダパスが格納されている先頭デバイス)
//D1 = D0(コントロールデータが格納されている先頭デバイス)
//D2 = M100(処理完了にてONするビットデバイス)
SP_FCOPY(TRUE, U1, 2, "sample.bin", 2, "sample1", D0, M100);
END_IF;
END_IF;

//(4)命令実行完了フラグの確認
IF M100 THEN
SET((M101 <> TRUE), M150); //命令実行完了フラグの保持
SET(M101, M151); //命令異常完了フラグの保持
RST(TRUE, M0); //駆動接点の開放
END_IF;
```

#### 注意事項 (8.7 / 原本 p.549)

- SP.FCOPY命令は，割込みプログラム中では実行しないでください。割込みプログラムで実行した場合，誤動作の原因となります。
- SM606(SDメモリカード強制使用停止指示)がON中は，SP.FCOPY命令を実行できません。また，命令実行時の初回END処理終了後にSM606をONした場合，ON検出時点で異常完了します。(SM606をONする前にコピーしたデータはコピーされます。)
- システムフォルダ($MELPRJ$)，またはシステムフォルダ内のファイルを指定したSP.FCOPY命令は実行できません。SP.FCOPY命令を実行した場合，演算エラー (3405H)が発生します。
- 命令実行中にCPUユニットの状態をRUN→STOPに変更しても，本命令は処理を継続します。
- コピー後のフォルダパス+ファイル名およびフォルダパスが文字数制限を超えないようにしてください。(ファイルがアクセス不可，またはエラーとなる場合があります。)
- 命令が処理の途中で異常完了した場合，ファイル/フォルダが処理中の状態で残ることがあります。
- コピー対象ファイルのファイルサイズやファイル数が大きくなる場合，命令が完了するまでの時間が長くなります。
- SP.FCOPY命令で操作中のファイルには，他機能からアクセスしないでください。(ファイルが破損，またはエラーとなる場合があります。)
- 他機能からアクセスしているファイル/フォルダへの操作は行わないでください。((d1)+1に8001Hが格納されます。)
- SP.FCOPY命令はSP.DEVST命令，SP.FTPPUT命令，SP.FTPGET命令と同時に実行できません。
- SP.FCOPY命令実行中の電源断，およびSDメモリカードの抜去などを行わないでください。(ファイルが破損，またはエラーとなる場合があります。)
