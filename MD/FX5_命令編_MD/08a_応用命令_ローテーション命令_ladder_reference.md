#### 機能 (8.1 / 原本 p.427-428)

**■ROR(P)**

- (d)で指定されたデバイスの16ビットデータを，キャリフラグを含めないで(n)ビット右へ回転させます。キャリフラグは，ROR(P)実行前の状態によりONまたはOFFになっています。

【図】ROR(P) の動作
- 実行前: (d) = 0000 0000 0000 0101，キャリフラグ(SM700, SM8022) = 0
- ⇩ 1ビット右ローテーション: (d) = 1000 0000 0000 0010(b15にb0の値)，キャリフラグ = 1(b0の値)
- ⇩ 1ビット右ローテーション: (d) = 0100 0000 0000 0001(b15にb0の値)，キャリフラグ = 0(b0の値)
- ⇩ (n)ビット右ローテーション: b(n-1)の値がb15側へ回り込み，キャリフラグにはb(n-1)の値が入る

- (d)にビットデバイスが指定された場合は，桁指定で指定されたデバイス範囲で回転を行います。このとき実際に回転するビット数は，(n)÷(桁指定で指定された点数)の余りになります。たとえば，(n)=15，(桁指定で指定された点数)=12ビットのときは，15÷12=1余り3となるため，3ビット右へ回転します。
- (n)は0～15を指定します。(n)に16以上の値が指定された場合は，(n)÷16の余りの値で回転します。たとえば(n)=18のときは，18÷16=1余り2となるため，2ビット右へ回転します。

**■RCR(P)**

- (d)で指定されたデバイスのBIN16ビットデータを，キャリフラグを含めて(n)ビット右へ回転させます。キャリフラグは，RCR(P)実行前の状態によりONまたはOFFになっています。

【図】RCR(P) の動作
- 実行前: (d) = 0000 0000 0000 0101，キャリフラグ(SM700, SM8022) = 0
- ⇩ 1ビット右ローテーション: (d) = 0000 0000 0000 0010(b15にキャリフラグの値)，キャリフラグ = 1(b0の値)
- ⇩ 1ビット右ローテーション: (d) = 1000 0000 0000 0001(b15にキャリフラグの値)，キャリフラグ = 0(b0の値)
- ⇩ (n)ビット右ローテーション: キャリフラグを含めて回転し，キャリフラグにはb(n-1)の値が入る

- (d)にビットデバイスが指定された場合は，桁指定で指定されたデバイス範囲で回転を行います。このとき実際に回転するビット数は，(n)÷(桁指定で指定された点数)の余りになります。たとえば，(n)=15，(桁指定で指定された点数)=12ビットのときは，15÷12=1余り3となるため，3ビット右へ回転します。
- (n)は0～15を指定します。(n)に16以上の値が指定された場合は，(n)÷16の余りの値で回転します。たとえば(n)=18のときは，18÷16=1余り2となるため，2ビット右へ回転します。

#### 注意事項 (8.1 / 原本 p.428)

- 回転するビット数(n)に負の値を設定しないでください。
- 連続実行型命令(ROR，RCR)の場合，スキャンタイム(演算周期)ごとにシフト回転を実行しますので注意してください。

#### エラー (8.1 / 原本 p.428)

演算エラーはありません。

#### 機能 (8.1 / 原本 p.434-435)

**■DROL(P)**

- (d)で指定されたデバイスの32ビットデータを，キャリフラグを含めないで(n)ビット左へ回転させます。キャリフラグは，DROL(P)実行前の状態によりONまたはOFFになっています。
  - 【図】(d)+1,(d)(b31〜b0)を(n)ビット左ローテーション。b31側からあふれたビットはb0側へ回り込み，キャリフラグ(SM700, SM8022)にも入る
- (d)にビットデバイスが指定された場合は，桁指定で指定されたデバイス範囲で回転を行います。このとき実際に回転するビット数は，(n)÷(桁指定で指定された点数)の余りになります。たとえば，(n)=31，(桁指定で指定された点数)=24ビットのときは，31÷24=1余り7となるため，7ビット左へ回転します。
- (n)は0～31を指定します。(n)に32以上の値が指定された場合は，(n)÷32の余りの値で回転します。たとえば(n)=34のときは，34÷32=1余り2となるため，2ビット左へ回転します。

**■DRCL(P)**

- (d)で指定されたデバイスの32ビットデータを，キャリフラグを含めて(n)ビット左へ回転させます。キャリフラグは，DRCL(P)実行前の状態によりONまたはOFFになっています。
  - 【図】(d)+1,(d)(b31〜b0)とキャリフラグ(SM700, SM8022)を含めて(n)ビット左ローテーション
- (d)にビットデバイスが指定された場合は，桁指定で指定されたデバイス範囲で回転を行います。このとき実際に回転するビット数は，(n)÷(桁指定で指定された点数)の余りになります。たとえば，(n)=31，(桁指定で指定された点数)=24ビットのときは，31÷24=1余り7となるため，7ビット左へ回転します。
- (n)は0～31を指定します。(n)に32以上の値が指定された場合は，(n)÷32の余りの値で回転します。たとえば(n)=34のときは，34÷32=1余り2となるため，2ビット左へ回転します。

#### 注意事項 (8.1 / 原本 p.435)

- 回転するビット数(n)に負の値を設定しないでください。
- 連続実行型命令(DROL，DRCL)の場合，スキャンタイム(演算周期)ごとにシフト回転を実行しますので注意してください。

#### エラー (8.1 / 原本 p.435)

演算エラーはありません。
