#### 機能 (8.11 / 原本 p.723)

- 0～32767の疑似乱数を発生し，その値を乱数として(d)で指定されたデバイスに格納します。
- 疑似乱数系列では，毎回，乱数の元値を算出し，その乱数の元値を使用して疑似乱数を算出します。

  疑似乱数の算出式:
  - (SD8311，SD8310)=(SD8311，SD8310)<sup>*1</sup>×1103515245+12345
  - `(d) =「([SD8311，SD8310]>>16)&<論理積>00007FFFh」`

*1 この(SD8311，SD8310)には，STOP→RUN時に1度だけ非負の値(0～2147483647)を書込んでください。[(SD8311，SD8310)は，初期値として電源投入時にK1が書込まれます｡]

#### プログラム例 (8.11 / 原本 p.724)

STOP→RUN時に時間データを秒変換したものに｢(年＋月)×日｣の値を加えた値を(SD8311, SD8310)に書込みます｡
X10をONするたびに，乱数をD100に格納するプログラムです。

```
     LD      SM402
     TRD     D0                     時計データの読出し
     DHTOS   D3  D14                時分秒→秒
     ADD     D0  D1  D10            ┐
     MUL     D10  D2  D12           │｢(年＋月)×日｣の値に秒データを加え，
     DADD    D14  D12  SD8310       ┘SD8311, SD8310へ書込む
     LD      X10
     RNDP    D100
```

#### エラー (8.11 / 原本 p.724)

演算エラーはありません。

|---|---|---|---|---|---|---|---|---|---|---|---|
| (d) | — | ○ | — | — | — | — | ○ | — | — | — | — |

#### 機能 (8.12 / 原本 p.725-726)

- インデックスレジスタ，ロングインデックスレジスタの内容を，(d)で指定したデバイス以降に退避します。
- インデックスレジスタの内容を退避すると，退避回数(d)が+1されます。
- インデックスレジスタ，ロングインデックスレジスタは24ワード分を退避します。CPUユニットごとに点数が以下のとおり異なります。
  - FX5S/FX5U/FX5UC CPUユニット：インデックスレジスタ，ロングインデックスレジスタ点数の割付け範囲を退避します。
  - FX5UJ CPUユニット：インデックスレジスタ20点，ロングインデックスレジスタ2点分を退避します。
- データの復帰には，ZPOP(P)命令を使用します。ZPUSH(P)命令とZPOP(P)命令は対で使用し，(d)に同じデバイスを使用することにより入れ子構造にすることが可能です。(→726ページ インデックスレジスタの一括復帰)
- 入れ子構造にした場合，ZPUSH(P)命令を実行するごとに，(d)以降に使用する領域が追加されていくため，SD300，SD302によりインデックスレジスタ，ロングインデックスレジスタの点数を確認し，使用回数分の領域をあらかじめ確保しておいてください。
- (d)以降に使用される領域の構成は下記のとおりです。
  - 【図】(d)+0 = (1) / +1 = Z0 / +2 = Z1 / … / +24 = Z23 ((d)+1〜(d)+24 が (2)) / +25 = Z0 / +26 = Z1 / … ((d)+25以降が (3))
  - (1): 退避回数
  - (2): 1ネスティング目(1ネスティング分24ワード)
  - (3): 2ネスティング目

#### 注意事項 (8.12 / 原本 p.726)

- 入れ子の動作がない場合は，ZPUSH(P)命令の実行前に退避回数(d)をクリアしてください。
- 入れ子の動作がある場合は，初回の実行前に退避回数(d)をクリアしてください。
- ZPOP(P)にてインデックスレジスタの復帰を行う場合，退避を行ったZPUSH(P)命令に対応するZPOP(P)命令を使用してください。
  - ZPUSH(P) (設定データ1個)　→　ZPOP(P) (設定データ1個)
  - ZPUSH(P) (設定データ2個)　→　ZPOP(P) (設定データ2個)
- (d)で指定する退避先はデバイスの範囲を超えないように領域を確保してください。

#### プログラム例 (8.12 / 原本 p.727)

ポインタP0以降のサブルーチンプログラム内でインデックスレジスタを使用するとき，サブルーチンプログラムを実行する前のインデックスレジスタ(Z)の内容をD0以降に退避するプログラムです。

```
     LD      SM402
     RST     D0
     LD      X5
     MOVP    K5  Z0
     LDI     X5
     MOVP    K10  Z0
     LD      X0Z0
     OUT     Y0
     LD      X0
     CALL    P0
     FEND
P0:  LD      SM400              (SM400: RUNモニタ)
     ZPUSH   D0                 インデックスレジスタの内容をD0以降に退避します。
     LD      X6                 ┐
     MOVP    K5  Z0             │
     LDI     X6                 │インデックスレジスタを
     MOVP    K10  Z0            │使用したプログラム
     LD      X30                │
     OUT     T0  D100Z0         ┘
     LD      SM400
     ZPOP    D0                 D0以降に退避した内容をインデックスレジスタに読み出します。
     RET
```

#### 機能 (8.12 / 原本 p.729-730)

- (s)で指定した退避するインデックスレジスタ，ロングインデックスレジスタを，(d)で指定されたデバイス以降に退避します。また，退避したデータの末尾に，退避したインデックスレジスタ，ロングインデックスレジスタの種別を格納します。
- インデックスレジスタ，ロングインデックスレジスタの内容を退避すると退避回数(d)が+1されます。
- (s)で指定する値と，退避するインデックスレジスタ，ロングインデックスレジスタは下記になります。

| (s)の値 | 退避するZ，LZ |
|---|---|
| 0 | Z，LZ全範囲 |
| 1 | Z全範囲 |
| 2 | LZ全範囲 |

- データの復帰には，インデックスレジスタ/ロングインデックスレジスタ選択復帰命令(ZPOP(P)命令)を使用します。インデックスレジスタ/ロングインデックスレジスタ選択退避命令(ZPUSH(P)命令)とインデックスレジスタ/ロングインデックスレジスタ選択復帰命令(ZPOP(P)命令)は対で使用し，入れ子構造にすることが可能です。(→729ページ インデックスレジスタ/ロングインデックスレジスタ選択復帰)
- 入れ子構造にした場合，インデックスレジスタ/ロングインデックスレジスタ選択退避命令(ZPUSH(P)命令)を実行するごとに，(d)以降に使用する領域が追加されていくため，SD300，SD302によりインデックスレジスタ，ロングインデックスレジスタの点数を確認し，使用回数分の領域をあらかじめ確保しておいてください。
- (d)以降に使用される領域の構成は下記のとおりです。(Z0～13，LZ0～4の場合)

【図】(d)以降の領域構成

| デバイス | 内容 | 区分 |
|---|---|---|
| (d) | 退避回数 | — |
| (d)+1<br>(d)+2 | システム使用<br>(2ワード) | — |
| (d)+3 | Z0 | ZPUSH K0 D0(Z，LZ全範囲退避) / 1ネスティング目(1ネスティング分25ワード) |

#### 注意事項 (8.12 / 原本 p.730)

- 入れ子の動作がない場合は，ZPUSH(P)命令の実行前に退避回数(d)をクリアしてください。
- 入れ子の動作がある場合は，初回の実行前に退避回数(d)をクリアしてください。
- ZPOP(P)にてインデックスレジスタの復帰を行う場合，退避を行ったZPUSH(P)命令に対応するZPOP(P)命令を使用してください。
  - ZPUSH(P) (設定データ1個)　→　ZPOP(P) (設定データ1個)
  - ZPUSH(P) (設定データ2個)　→　ZPOP(P) (設定データ2個)
- (d)+1，(d)+2はシステムで使用するため，値を変更しないでください。また，(d)で指定されたデバイス以降に格納するZ，LZ退避種別もシステムで使用するため，値を変更しないでください。
- (d)で指定する退避先はデバイスの範囲を超えないように領域を確保してください。

## インデックスレジスタ/ロングインデックスレジスタ選択復帰 (8.12 / 原本 p.731)

### ZPOP(P) (8.12 / 原本 p.731)

対応機種: FX5S / FX5UJ / FX5U / FX5UC

(d)で指定されるデバイス以降に退避されているデータを，インデックスレジスタ，ロングインデックスレジスタに読み出します。

#### 書式 (8.12 / 原本 p.731)

| FBD/LD | 【図】EN・s 入力、ENO・d 出力のボックス<br>(□には，ZPOP_2，ZPOPP_2が入ります。) |

#### 機能 (8.12 / 原本 p.731)

- (d)で指定されるデバイス以降に退避されているデータを，インデックスレジスタ，ロングインデックスレジスタに読み出します。
- 退避されているインデックスレジスタ，ロングインデックスレジスタの内容を読み出すと，退避回数(d)が-1されます。
- (s)で指定したデータはダミーデータ扱いとし，無視します。
