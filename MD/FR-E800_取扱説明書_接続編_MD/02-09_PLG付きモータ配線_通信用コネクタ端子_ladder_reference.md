### 2.9 PLG 付きモータとの配線について（ベクトル制御） (2.9 / 印刷 p.107 / 原本 p.108)

PLG（エンコーダ）付きモータとベクトル制御対応オプション（FR-A8AP E キット）を組み合わせることで、オリエント制御や PLG フィードバック制御、本格的ベクトル制御運転による速度制御、トルク制御、位置制御ができます。IP67 仕様品、CC-Link 通信機能内蔵品は内蔵オプションを使用できません。
FR-A8AP E キットの接続例になります。

##### ◆ FR-A8AP のスイッチについて (2.9 / 原本 p.109)

- PLG 仕様選択スイッチ (SW3) は、差動ラインドライバと、コンプリメンタリの選択をします。
  初期状態は差動ラインドライバとなっています。出力回路に応じて切り換えてください。

【図】SW3 の位置と切換え (原本 p.109)
- FR-A8AP 基板上の SW3（端子台の右上）を丸で示す
- スライドスイッチ: レバー上側 = 「差動ラインドライバ（初期状態）」、レバー下側 = 「コンプリメンタリ」

- 終端抵抗選択スイッチ (SW1) は、内部終端抵抗の ON/OFF を選択します。
  PLG 出力タイプが差動ラインドライバの場合は「ON」（初期状態）、コンプリメンタリの場合は「OFF」にしてください。
  ON：内部終端抵抗あり（初期状態）
  OFF：内部終端抵抗なし

【図】SW1 の位置と切換え (原本 p.109)
- FR-A8AP 基板上の SW1（端子台の左、4極ディップスイッチ）を丸で示す
- 「内部終端抵抗-ON（初期状態）」: 1〜4 すべて ON 側
- 「内部終端抵抗-OFF」: 1〜4 すべて OFF 側

> **NOTE**
> - すべてのスイッチを同じ設定（ON/OFF）にしてください。
> - 差動ラインドライバで同一の PLG を他のユニット（NC（数値制御装置）など）と共用する場合、他のユニットに終端抵抗器が接続されているときは、「OFF」にしてください。

Ethernet ケーブル配線時の注意事項について説明します。

###### ■ Ethernet ケーブルの敷設 (2.10.2 / 原本 p.117)

- ケーブル側コネクタやインバータ側コネクタの芯線部分に手を触れたり、ゴミやほこりが付着したりしないようにしてください。手の油分、ゴミ、ほこりが付着すると、伝送損失が増えて正常にデータリンクできなくなることがあります。
- 使用する Ethernet ケーブルについて、下記を確認してください。
  断線がないか
  ショートしていないか
  コネクタの接続に問題がないか
- ツメが折れた Ethernet ケーブルは使用しないでください。ツメが折れた Ethernet ケーブルを使用すると、ケーブル抜けおよび誤動作の原因になります。
- 最大局間距離は 100m です。ただし、ケーブル使用環境により距離が短くなる場合があります。ケーブルの詳細は使用しているケーブルメーカにお問い合わせください。

###### ■ Ethernet ケーブルの取付け、取外し (2.10.2 / 原本 p.117)

Ethernet ケーブルのコネクタ部分を手に持って、取付けおよび取外しを行ってください。インバータに接続された状態でケーブルを引っ張ると、インバータやケーブルの破損、ケーブルの接触不良による誤動作の原因となります。

###### ■ ネットワーク構成 (2.10.2 / 原本 p.117)

配線時はネットワークの構成を確認し、不正な配線をしないように注意してください。

##### ◆ 通信運転 (2.10.2 / 原本 p.117)

- Ethernet コネクタを使用することによってパソコンなどから通信運転を行うことができます。パソコン・FA などの計算機と通信ケーブルで接続し、ユーザプログラムでインバータの運転・監視およびパラメータの読出し・書込みを行うことができます。
  詳細は、FR-E800 取扱説明書（通信編）を参照してください。

##### ◆ CC-Link のバージョンについて (2.10.3 / 原本 p.118)

###### ■ CC-Link Ver.1.10 について (2.10.3 / 原本 p.118)

従来の CC-Link の局間ケーブル長の制約を改善し、局間ケーブル長が一律 20cm 以上となったものを CC-Link Ver.1.10 と定義します。これに対して従来品を CC-Link Ver.1.00 と定義します。CC-Link Ver.1.00、Ver.1.10 の最大ケーブル総延長および局間ケーブル長については CC-Link マスタユニットのマニュアルを参照してください。

| CC-Link Ver.1.10 対応条件 |
|---|
| • CC-Link システムを構成するすべてのユニットが、CC-Link Ver.1.10 対応であること。<br>• すべてのデータリンクケーブルが、CC-Link Ver.1.10 対応 CC-Link 専用ケーブルであること。（CC-Link Ver.1.10 対応ケーブルには、[CC-Link ロゴ] のマーク、または Ver.1.10 と記載されています。） |

（注: [CC-Link ロゴ] は原本では CC-Link のロゴマーク画像）

> **NOTE**
> - CC-Link Ver.1.00、Ver.1.10 のユニットおよびケーブルが混在するシステムの場合、最大ケーブル総延長および局間ケーブル長は CC-Link Ver.1.00 での仕様になります。

###### ■ CC-Link Ver.2 について (2.10.3 / 原本 p.118)

FR-E800-NC は CC-Link Ver.2 に対応しています。
FR-E800-NC で CC-Link Ver.2 設定を使用する場合は、マスタ局も Ver.2 に対応している必要があります。CC-Link Ver.2 では、リモートレジスタ（RWw/r）点数を増やすために、2 倍、4 倍、8 倍設定を使用することができます。

【図】マスタ局バージョンとインバータ側設定の組合せによる通信可否 (原本 p.118)
- マスタ局(CC-Link Ver.1) 配下:
  - インバータ CC-Link Ver.1 設定 → ○ 通信可
  - インバータ CC-Link Ver.2 設定 → × 通信不可（LEDの“RUN”が点滅）
- マスタ局(CC-Link Ver.2) 配下:
  - インバータ CC-Link Ver.1 設定 → ○ 通信可
  - インバータ CC-Link Ver.2 設定 → ○ 通信可

##### ◆ 配線方法 (2.10.4 / 原本 p.126)

###### ■ 取付け (2.10.4 / 原本 p.126)

1. シーケンサおよびインバータの電源を OFF にします。
2. インバータの通信用コネクタの樹脂キャップを取り外します。
3. コネクタの向きに注意して、インバータの通信用コネクタに Ethernet ケーブルのコネクタを押し込みます。

###### ■ 取外し (2.10.4 / 原本 p.126)

1. シーケンサおよびインバータの電源を OFF にします。
2. インバータの Ethernet ケーブルを引き抜きます。
3. インバータの通信用コネクタに樹脂キャップを取り付けます。（締付けトルク：0.7N・m）

##### ◆ 配線時の注意事項 (2.10.4 / 原本 p.126)

Ethernet ケーブル配線時の注意事項について説明します。

###### ■ Ethernet ケーブルの敷設 (2.10.4 / 原本 p.126)

- ケーブル側コネクタやインバータ側コネクタの芯線部分に手を触れたり、ゴミやほこりが付着したりしないようにしてください。手の油分、ゴミ、ほこりが付着すると、伝送損失が増えて正常にデータリンクできなくなることがあります。
- 使用する Ethernet ケーブルについて、下記を確認してください。
  断線がないか
  ショートしていないか
  コネクタの接続に問題がないか
- ツメが折れた Ethernet ケーブルは使用しないでください。ツメが折れた Ethernet ケーブルを使用すると、ケーブル抜けおよび誤動作の原因になります。
- 最大局間距離は 100m です。ただし、ケーブル使用環境により距離が短くなる場合があります。ケーブルの詳細は使用しているケーブルメーカにお問い合わせください。

###### ■ Ethernet ケーブルの取付け、取外し (2.10.4 / 原本 p.126)

Ethernet ケーブルのコネクタ部分を手に持って、取付けおよび取外しを行ってください。インバータに接続された状態でケーブルを引っ張ると、インバータやケーブルの破損、ケーブルの接触不良による誤動作の原因となります。

###### ■ ネットワーク構成 (2.10.4 / 原本 p.126)

配線時はネットワークの構成を確認し、不正な配線をしないように注意してください。

##### ◆ 通信運転 (2.10.4 / 原本 p.126)

- Ethernet コネクタを使用することによってパソコンなどから通信運転を行うことができます。パソコン・FA などの計算機と通信ケーブルで接続し、ユーザプログラムでインバータの運転・監視およびパラメータの読出し・書込みを行うことができます。
  詳細は、FR-E800 取扱説明書（通信編）を参照してください。
