### 2.11 別置形オプションユニットとの接続（標準仕様品、Ethernet 仕様品、安全通信仕様品、CC-Link 通信機能内蔵品） (2.11 / 印刷 p.128 / 原本 p.129)

インバータは必要に応じて、様々な別置形オプションユニットを接続することができます。
接続を誤るとインバータの破損や事故の原因になりますので、各オプションユニットの取扱説明書に従い接続、運転してください。

##### ◆ ブレーキ抵抗器（MRS 形、MYS 形）、高頻度用ブレーキ抵抗器（FR-ABR）接続について (2.11.1 / 原本 p.131)

回生ブレーキ用トランジスタが破損した場合、ブレーキ抵抗器（MRS 形、MYS 形）、高頻度用ブレーキ抵抗器（FR-ABR）の過熱・焼損を防ぐためにも下図のようにサーマルリレーによりインバータの一次側電源を遮断する回路での使用を推奨します。（FR-E820(S)-0.1K(0008)、FR-E820(S)-0.2K(0015)、FR-E810W-0.1K(0008)、FR-E810W-0.2K(0015) には接続できません。）

- 共通：電源 → MC（主接点3極）→ インバータ R/L1、S/L2、T/L3。インバータ P/+ → サーマルリレー (OCR)(*1) → FR-ABR（R）→ インバータ PR
- 共通：電源2相から変圧器 T を介し、ヒューズ F → 操作回路。操作回路は ON（押しボタン、MC 自己保持接点を並列）→ OFF（押しボタン）→ MC コイル → OCR接点 の直列
- <例1>：操作回路は上記のみ（OCR接点で MC を遮断）
- <例2>：操作回路の OCR接点と直列に、インバータの異常出力端子 B－C 間（B、C）を接続（OCR接点またはインバータの B－C 開で MC を遮断）

##### ◆ ブレーキ抵抗器（FR-ABR 以外）を使用する場合 (2.12.1 / 原本 p.139)

ブレーキ抵抗器は、抵抗値および消費電力が下記の値より大きな抵抗器を使用してください。また、回生されるエネルギーを十分消費できる容量を持つ抵抗器を使用してください。

| 電圧クラス | インバータ | 最小抵抗値（Ω） | 消費電力（kW） |
|---|---|---|---|
| 3 相 400V クラス | FR-E846-0.75K(0026) | 236 | 2.4 |
| 3 相 400V クラス | FR-E846-1.5K(0040) | 205 | 2.8 |
| 3 相 400V クラス | FR-E846-2.2K(0060) | 180 | 3.2 |
| 3 相 400V クラス | FR-E846-3.7K(0095) | 130 | 4.4 |

下記パラメータを設定してください。
- **Pr.30 回生機能選択** =“1”
- 回生量、回生頻度などに応じて **Pr.70 特殊回生ブレーキ使用率**を設定して、抵抗器が問題なく回生エネルギーを消費できることを確認してください。（FR-E800 取扱説明書（機能編）参照）
- 回生ブレーキ用トランジスタが破損した場合、ブレーキ抵抗器の過熱・焼損を防ぐために下図シーケンスのようにサーマルリレーを設置してください。サーマルリレーは、回生頻度や抵抗器の定格電力、抵抗値に合わせて適切に選定してください。

【図】ブレーキ抵抗器のサーマルリレー設置シーケンス <例1> (原本 p.139)
- 電源 → MC（主接点）→ インバータ R/L1、S/L2、T/L3
- 電源側から分岐したトランス T の二次側にヒューズ F を介して操作回路を構成
- 操作回路：ON（押ボタン）、OFF（押ボタン）、MC コイル、OCR接点 を直列。ON に並列に MC の自己保持接点
- インバータ端子 P → サーマルリレー (OCR) → ブレーキ抵抗器 (R) → インバータ端子 PR

【図】ブレーキ抵抗器のサーマルリレー設置シーケンス <例2> (原本 p.139)
- 主回路・トランス T・ヒューズ F・ON／OFF／MC コイル／OCR接点・MC 自己保持接点の構成は <例1> と同じ
- インバータ端子 P → サーマルリレー (OCR) → ブレーキ抵抗器 (R) → インバータ端子 PR
- 操作回路はインバータの端子 B、C を経由する構成（図中、OCR接点の先がインバータ端子 B、C に接続）（注: 端子 B・C の詳細な配線経路は図から読み取れる範囲で記載）

> **注意**
> - 抵抗器選定が誤っている場合、インバータ内蔵ブレーキトランジスタは過電流により破損する可能性があります。また、抵抗器は過熱により焼損する可能性があります。
> - サーマルリレーの選定が誤っている場合、抵抗器は過熱により焼損する可能性があります。

#### 2.12.3 AC リアクトル（FR-HAL）の接続 (2.12.3 / 印刷 p.141 / 原本 p.142)

- インバータの電源用主回路コネクタに接続します。コネクタ仕様、ピン配列は 72 ページを参照して、コネクタケーブルで接続してください。
- 周囲温度が許容値（－ 10 ℃～＋ 50 ℃）を超えないようにしてください。また、リアクトル自身発熱しますので、周囲のスペースを十分に確保してください。( リアクトル取付け方向に関係なく上下方向 10cm 以上、左右方向 5cm 以上 )

【図】AC リアクトル（FR-HAL）の周囲スペース (原本 p.142)
- リアクトル上方：10cm以上
- リアクトル左右：それぞれ 5cm以上

【図】AC リアクトル接続図（3 相電源） (原本 p.142)
- 電源 → NFB → FR-HAL の R・S・T → FR-HAL の X・Y・Z → インバータの R・S・T（インバータ出力 U・V・W）

- 2 台以上のインバータに AC リアクトル (FR-HAL) を使用する場合には、必ずインバータ 1 台ごとに AC リアクトルを接続してください。まとめて 1 台のリアクトルで使用した場合には、全部のインバータが運転されないと、十分な力率改善効果が得られません。

【図】複数インバータへの AC リアクトル接続例 (原本 p.142)

- 各 FR-HAL の X・Y・Z を、それぞれのインバータの R・S・T に接続（インバータ 1 台につき FR-HAL 1 台）

- AC リアクトルは適用モータ容量に合わせて選定してください。0.4kW 未満のモータの場合は、0.4kW 用を選定します。（162 ページ参照）。
- 接地端子を使用して確実に接地してください。

> - 使用電線サイズの目安は電源線 (R/L1、S/L2、T/L3)、接地線と同等か、それ以上としてください。（74 ページ参照）
