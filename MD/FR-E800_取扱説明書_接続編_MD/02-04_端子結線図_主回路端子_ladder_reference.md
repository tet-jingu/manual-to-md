### 2.4 端子結線図 (2.4 / 印刷 p.51 / 原本 p.52)

##### ◆ 標準仕様品（シンクロジック） (2.4 / 原本 p.52)

【図】標準仕様品（シンクロジック）の端子結線図 (原本 p.52)

- 凡例: ◎ 主回路端子、○ 制御回路端子
- インバータ本体は上部「主回路」、下部「制御回路」の2ブロックで図示
- **主回路（電源入力）**
  - 3相交流電源 → NFB → MC → 端子 R/L1、S/L2、T/L3
  - 単相電源入力（囲み枠）: 単相交流電源 → NFB → MC → 端子 R/L1、S/L2
  - 本体左下の接地端子（⏚）→ 接地
- **主回路（DC部）**
  - 端子 P1 *6、P/+、PR、N/- が上辺に並ぶ
  - P1-P/+ 間に短絡片が接続されている
  - DCリアクトル (FR-HEL) *1（破線＝オプション）: P1 と P/+ に接続。DCリアクトルの筐体は接地
  - ブレーキ抵抗器 R *8（破線、サーマルリレー記号付き）: P/+ と PR に接続
  - ブレーキユニット（オプション）（破線）: P/+ と N/- に接続
  - PR-N/- 間に内蔵ブレーキトランジスタ *7 を図示
- **主回路（出力）**
  - 端子 U、V、W → モータ（M）。モータは接地
  - 本体右下の接地端子（⏚）
- **制御入力信号（電圧入力は不可）*2**（接点入力。各接点の一端を共通線で SD に接続）
  - 正転始動 → STF
  - 逆転始動 → STR
  - 多段速度選択: 高速 → RH、中速 → RM、低速 → RL
  - 出力停止 → MRS
  - リセット → RES
  - 接点入力コモン → SD
  - DC24V電源（外部電源トランジスタコモン）→ PC
  - 内部: 各入力はフォトカプラ入力。SINK/SOURCE 切換（図中の切換部「SOURCE」「SINK」、およびスライドスイッチ「SINK / SOURCE」*3）。内部 24V 電源は PC に接続
- **リレー出力 *9**
  - 端子 A、B、C: リレー出力（異常出力）
- **オープンコレクタ出力 *10**
  - RUN: 運転中
  - FU: 周波数検出
  - SE: オープンコレクタ出力コモン　シンク・ソース共通
- **セーフティストップ信号**
  - PC: セーフティストップ入力端子コモン
  - S1: セーフティストップ入力(系統1)
  - S2: セーフティストップ入力(系統2)
  - 短絡用電線: PC-S1 間、PC-S2 間を短絡（太線で図示）
  - S1、S2 → 内部の「出力遮断回路」
  - SO: セーフティモニタ出力
  - SOC: セーフティモニタ出力コモン
- **周波数設定信号（アナログ）**
  - 周波数設定器 1/2W1kΩ *5: 設定器の端子3 → 端子10(＋5V)、端子2（摺動子）→ 端子2、端子1 → 端子5（アナログコモン）
  - 端子2: DC0～5V（枠囲み）、（DC0～10V、DC0～20mA）*4
  - 端子4入力（電流入力）: (+) → 端子4、(-) → 端子5
  - 端子4: DC4～20mA（枠囲み）、（DC0～5V、DC0～10V）*4
  - 配線は破線の楕円（シールド）付きで図示され、シールドは端子5側に接続
  - 電圧/電流入力切換スイッチ *4: 上段「2」、下段「4」、左「V」右「I」。図では 2 側が V、4 側が I の位置
- **コネクタ類**
  - PU コネクタ
  - USB ミニB コネクタ
  - 内蔵オプション接続用コネクタ: オプションコネクタ
- **出力信号 パルス(端子FMタイプのみ)**
  - FM → 目盛校正抵抗器 *11 → 表示計(周波数計など)の＋、表示計の－ → SD
  - 表示計: 可動コイル形　1mAフルスケール
  - 出力波形はパルス（図中にパルス波形記号）
- **出力信号 アナログ(端子AMタイプのみ)**
  - AM → (＋)、5 → (－): アナログ信号出力 (DC0～±10V)（シールド付きで図示）

*1 DC リアクトルを接続する場合、P1-P/+ 間の短絡片を外してください。（単相 100V 電源入力仕様品は DC リアクトルの設置はできません。）
*2 入力端子割付（Pr.178 ～ Pr.184）によって端子機能変更可能です。（FR-E800 取扱説明書（機能編）参照）
*3 初期設定は仕様により変わります。
*4 アナログ入力仕様切換（Pr.73 ､ Pr.267）によって変更可能です。電圧入力にする場合は、電圧 / 電流入力切換スイッチを "V"、電流入力にする場合は、"I" にしてください。初期設定は仕様により変わります。（FR-E800 取扱説明書（機能編）参照）
*5 周波数設定変更の頻度が高いときは 2W1kΩ を推奨します。
*6 端子 P1 は、単相 100V 電源入力仕様品にはありません。
*7 FR-E820-0.1K(0008)、FR-E820-0.2K(0015)、FR-E820S-0.1K(0008)、FR-E820S-0.2K(0015)、FR-E810W-0.1K(0008)、FR-E810W-0.2K(0015) はブレーキトランジスタを内蔵していません。
*8 ブレーキ抵抗器（FR-ABR、MRS 形、MYS 形）
ブレーキ抵抗器の過熱・焼損を防ぐため、サーマルリレーを設置してください。（FR-E820-0.1K(0008)、FR-E820-0.2K(0015)、FR-E820S-0.1K(0008)、FR-E820S-0.2K(0015)、FR-E810W-0.1K(0008)、FR-E810W-0.2K(0015) はブレーキ抵抗器の接続はできません。）（128 ページ参照）
*9 Pr.192 ABC 端子機能選択によって端子機能変更可能です。
*10 出力端子割付（Pr.190、Pr.191）によって端子機能変更可能です。（FR-E800 取扱説明書（機能編）参照）
*11 操作パネルで目盛校正するときは不要です。

（注: *1～*3 は原本 p.52、*4～*11 は原本 p.53 に記載）

> **NOTE**
> - ノイズによる誤動作を防止するため、信号線は動力線と 10cm 以上離してください｡また、主回路配線の入力側と出力側は分離してください。
> - 配線時にインバータ内部に電線の切りくずを残さないでください。
>   電線の切りくずは、異常、故障、誤動作の原因になります。インバータはいつもきれいにしておいてください。
>   制御盤などに取付け穴をあけるときは、切粉などがインバータに入らないよう注意してください。
> - 電圧 / 電流入力切換スイッチを適切に設定してください。設定が異なると異常、故障、誤動作の原因になります。
> - 単相電源入力仕様品の出力は、3 相 200V となります。

（原本 p.53）

##### ◆ 標準仕様品（ソースロジック） (2.4 / 原本 p.54)

【図】標準仕様品（ソースロジック）の端子結線図 (原本 p.54)

- 凡例: ◎ 主回路端子、○ 制御回路端子
- **主回路**: シンクロジック図（原本 p.52）と同一
  - 3相交流電源 → NFB → MC → R/L1、S/L2、T/L3／単相電源入力: 単相交流電源 → NFB → MC → R/L1、S/L2
  - P1 *6 - P/+ 間に短絡片。DCリアクトル (FR-HEL) *1 を P1、P/+ に接続（リアクトルは接地）
  - ブレーキ抵抗器 R *8 を P/+、PR に接続。ブレーキユニット（オプション）を P/+、N/- に接続。PR-N/- 間に内蔵ブレーキトランジスタ *7
  - U、V、W → モータ（M）、モータ接地。本体の接地端子 → 接地
- **制御入力信号（電圧入力は不可）*2**（接点入力。各接点の一端を共通線で PC に接続）
  - 正転始動 → STF、逆転始動 → STR
  - 多段速度選択: 高速 → RH、中速 → RM、低速 → RL
  - 出力停止 → MRS、リセット → RES
  - 外部電源トランジスタコモン → SD
  - 接点入力コモン（DC24V電源）→ PC

#### 2.5.4 接地について (2.5.4 / 印刷 p.71 / 原本 p.72)

モータおよびインバータは必ず接地してください。

##### 接地の目的 (2.5.4 / 原本 p.72)

電気機器には一般的に接地端子が付いており、必ずこれを大地に接続して使用することになっています。
電気回路は、通常、絶縁物で絶縁されてケースに収納されております。しかし、完全に漏れ電流を遮断できる絶縁物を製作することは不可能であり、現実には僅かながらケースに電流が漏れることになります。人が電気機器のケースに触れたときに、この漏れ電流によって感電しないように、ケースを接地するのが接地の目的であります。
オーディオ、センサ、コンピュータなどのように、微弱な信号を扱うか、非常に高速で動作している機器においては、外来ノイズの影響を受けないようにするためにも、この接地が重要となります。

##### 接地方法と接地工事 (2.5.4 / 原本 p.72)

接地には、前述のように大別して感電防止のものとノイズによる誤動作防止のものがあります。したがって、この両者の接地を明確に区別し、誤動作防止のための接地にインバータの高周波成分の漏れ電流が侵入しないよう、下記のように処理する必要があります。
- インバータの接地はできるだけ専用接地とします。
  専用接地 (I) がとれないときは、接地点で他の機器と接続される共用接地 (II) とします。(III) のように他の機器と接地線を共通した接地は避けなければなりません。
  また、インバータおよびインバータで駆動されるモータの接地線には高周波成分の多い漏れ電流が流れますので、前述のノイズに敏感な機器の接地とは分離して専用接地とする必要があります。
  高層ビルにおいては、ノイズ誤動作防止用の接地を鉄骨に、感電防止用の接地を専用接地とするのも良策と考えられます。
  - 接地工事は、100V クラス、200V クラスインバータは D 種接地（接地抵抗 100Ω 以下）、400V クラスは C 種接地（接地抵抗 10Ω 以下）で行います。400V クラスインバータは、EN 規格に適合する場合、中性点接地された電源で使用してください。
  - 接地線はできるだけ太い線を使用します。接地線のサイズは 66 ページに示すサイズ以上のものを使用します。
  - 接地点はできるだけインバータの近くとし、接地線は極力短くします。
  - 接地線の布線は、ノイズに敏感な機器の入出力配線からできるだけ離し、かつ平行する距離を極力短くします。

【図】接地方式の比較 (原本 p.72)
- （Ⅰ）専用接地･･･最良: 「インバータ」と「他の機器（インバータ含む）」がそれぞれ個別の接地極に接地。「100Vクラス、200Vクラス D種接地 / 400Vクラス C種接地」
- （Ⅱ）共用接地･･･良: 「インバータ」と「他の機器（インバータ含む）」の接地線がそれぞれ単独で 1 点の接地極に接続。「100Vクラス、200Vクラス D種接地 / 400Vクラス C種接地」

#### 2.6.4 接地について (2.6.4 / 印刷 p.75 / 原本 p.76)

モータおよびインバータは必ず接地してください。

##### 接地の目的 (2.6.4 / 原本 p.76)

電気機器には一般的に接地端子が付いており、必ずこれを大地に接続して使用することになっています。
電気回路は、通常、絶縁物で絶縁されてケースに収納されております。しかし、完全に漏れ電流を遮断できる絶縁物を製作することは不可能であり、現実には僅かながらケースに電流が漏れることになります。人が電気機器のケースに触れたときに、この漏れ電流によって感電しないように、ケースを接地するのが接地の目的であります。
オーディオ、センサ、コンピュータなどのように、微弱な信号を扱うか、非常に高速で動作している機器においては、外来ノイズの影響を受けないようにするためにも、この接地が重要となります。

##### 接地方法と接地工事 (2.6.4 / 原本 p.77)

接地には、前述のように大別して感電防止のものとノイズによる誤動作防止のものがあります。したがって、この両者の接地を明確に区別し、誤動作防止のための接地にインバータの高周波成分の漏れ電流が侵入しないよう、下記のように処理する必要があります。
- インバータの接地はできるだけ専用接地とします。
  専用接地 (I) がとれないときは、接地点で他の機器と接続される共用接地 (II) とします。(III) のように他の機器と接地線を共通した接地は避けなければなりません。
  また、インバータおよびインバータで駆動されるモータの接地線には高周波成分の多い漏れ電流が流れますので、前述のノイズに敏感な機器の接地とは分離して専用接地とする必要があります。
  高層ビルにおいては、ノイズ誤動作防止用の接地を鉄骨に、感電防止用の接地を専用接地とするのも良策と考えられます。
  - 接地工事は、400V クラスは C 種接地（接地抵抗 10Ω 以下）で行います。400V クラスインバータは、EN 規格に適合する場合、中性点接地された電源で使用してください。
  - 接地線はできるだけ太い線を使用します。接地線のサイズは 74 ページに示すサイズ以上のものを使用します。
  - 接地点はできるだけインバータの近くとし、接地線は極力短くします。
  - 接地線の布線は、ノイズに敏感な機器の入出力配線からできるだけ離し、かつ平行する距離を極力短くします。

【図】接地方式の比較 (原本 p.77)
- （Ⅰ）専用接地･･･最良: 「インバータ」と「他の機器（インバータ含む）」がそれぞれ個別の接地極に接地。「400Vクラス C種接地」
- （Ⅱ）共用接地･･･良: 「インバータ」と「他の機器（インバータ含む）」の接地線がそれぞれ単独で 1 点の接地極に接続。「400Vクラス C種接地」
- （Ⅲ）共通接地･･･不可: 「インバータ」の接地線を「他の機器（インバータ含む）」の接地線に渡り接続し、共通の 1 本で接地。「400Vクラス C種接地」
