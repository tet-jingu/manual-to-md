### 2.1 周辺機器 (2.1 / 印刷 p.28 / 原本 p.29)

#### 2.1.1 インバータと周辺機器 (2.1.1 / 印刷 p.28 / 原本 p.29)

【図】インバータと周辺機器の構成図 (原本 p.29)
- 電源側の接続順（上から）: (b) 3相交流電源 → (c) ノーヒューズブレーカ(NFB) または 漏電ブレーカ(ELB)、ヒューズ → (d) 電磁接触器(MC) → (e) ACリアクトル(FR-HAL) → (g) ノイズフィルタ(FR-BSF01、FR-BLF) → インバータ端子 R/L1 S/L2 T/L3
- (h) ラジオノイズフィルタ(FR-BIF) はインバータ入力側（R/L1 S/L2 T/L3 の電源線）に接続
- (f) DCリアクトル(FR-HEL) はインバータ端子 P/+、P1 に接続
- インバータ端子 P/+、N/- に、(i) 高力率コンバータ(FR-HC2)、(j) 多機能回生コンバータ(FR-XC)、(k) 電源回生共通コンバータ(FR-CV)、(l) ブレーキユニット(FR-BU2、FR-BU) を接続。(l) ブレーキユニットの P/+、PR に (m) 抵抗器ユニット(FR-BR)、放電抵抗器(GZG、GRZG) を接続
- (o) ブレーキ抵抗器(FR-ABR、MRS形、MYS形) はインバータ端子 P/+、PR に接続
- (a) インバータ本体は接地
- (n) USB電源: パソコン (FR Configurator 2) とインバータの USBデバイス（ミニBコネクタ）を USB ケーブルで接続
- 出力側「IM接続」: インバータ U V W → (p) ノイズフィルタ(FR-BSF01、FR-BLF) → (q) 誘導モータ（接地）
- 出力側「PM接続」: インバータ U V W → (p) ノイズフィルタ(FR-BSF01、FR-BLF) → (r) 開閉器 例）ノーヒューズスイッチ（DSN形） → (s) PMモータ（接地）

### 2.2 表面カバーの取外しと取付け方 (2.2 / 印刷 p.35 / 原本 p.36)

##### ◆ 表面カバーの取外し (2.2 / 原本 p.36)

- FR-E820-0.1K(0008) の例

【図】表面カバーの取外し手順 (原本 p.36)
- (a): 操作パネル左下（USB コネクタ下）の表面カバー取付けねじを回して「緩める」（回転矢印）
- (b): 表面カバーの上部（ねじ部分）を手前へ倒すように引き出す（矢印は手前斜め下方向）。下部が支点
- (c): 表面カバーを取り外した状態。制御回路端子台・内蔵オプション用コネクタ等が露出

（a）表面カバーの取付けねじを緩めます。（ねじは取り外せません。）

#### 2.3.1 インバータの設置環境 (2.3.1 / 印刷 p.41 / 原本 p.42)

##### ◆ 温度 (2.3.1 / 原本 p.42)

標準仕様品、Ethernet 仕様品、安全通信仕様品、CC-Link 通信機能内蔵品の許容周囲温度は－ 20 ～＋ 60 ℃（50 ℃を超えて使用する場合は、定格電流低減が必要（45 ページ参照））です。IP67 仕様品の許容周囲温度は－ 20 ～＋ 50 ℃（40 ℃を超えて使用する場合は、定格電流低減が必要（46 ページ参照））です。必ずこの温度範囲で使用してください。この範囲をこえての使用は半導体、部品、コンデンサなどの寿命を著しく低下させます。次のような対策を施し、インバータの周囲温度が規定値内になるようにしてください。

###### ■ 高温対策 (2.3.1 / 原本 p.42)

• 強制換気方式などの冷却方式を採用する。(47 ページ参照）
• 空調してある電気室に盤を設置する。
• 直射日光をさえぎる。
• 熱源の輻射熱、温風が直接あたらないように遮蔽板などを設ける。
• 盤周辺の通気をよくする。

###### ■ 低温対策 (2.3.1 / 原本 p.42)

• 盤内にスペースヒータを設ける。
• インバータの電源を切らない。( インバータの始動信号は切っておく）

###### ■ 急激な温度変化 (2.3.1 / 原本 p.42)

• 急激な温度変化のない場所を選んで設置する。
• 空調設備の吹出し口の近くをさける。
• ドアの開閉によるものであればドアから離して設置する。

> **NOTE**
> • 標準仕様品、Ethernet 仕様品、安全通信仕様品、CC-Link 通信機能内蔵品のインバータユニットの発熱量については、43 ページを参照してください。
> • IP67 仕様品のインバータユニットの発熱量については、44 ページを参照してください。

##### ◆ 湿度 (2.3.1 / 原本 p.43)

インバータの使用周囲湿度は通常 45 ～ 90％（基板コーティングありの場合は 95% まで）の範囲で使用してください。湿度が高すぎると絶縁の低下および金属部の腐食の問題が発生します。一方、湿度が低すぎると空間絶縁破壊が生じることがあります。JEM1103「制御機器の絶縁装置」に規定している絶縁距離は湿度 45 ～ 85％とあります。

###### ■ 高湿度対策 (2.3.1 / 原本 p.43)

• 盤を密閉構造とし、吸湿剤を入れる。
• 乾燥空気を外部より盤内に吸込む。
• 盤内にスペースヒーターを設ける。

###### ■ 低湿度対策 (2.3.1 / 原本 p.43)

適度な湿度の空気を外部より盤内に吹込むなどの他に、この状態でユニットの装着や点検を行うときには、人体の帯電（静電気）を放電した後に行い、かつ部品やパターンに触れないようにすることも重要な点です。

###### ■ 結露対策 (2.3.1 / 原本 p.43)

頻度の高い運転停止により盤内の温度が急激に変化する場合や、外気温度の急激な変化がある場合には結露を生じることがあります。
結露は絶縁低下や錆の発生などの不具合を起こします。
• 高湿度対策を施す。
• インバータの電源を切らない。( インバータの始動信号は切っておく )

##### ◆ 塵埃、オイルミスト (2.3.1 / 原本 p.43)

塵埃は接触部の接触不良、たい積による吸湿での絶縁低下、冷却効果の低下、フィルタ目づまりによる盤内温度上昇などの不具合を生じます。また導電性の粉末の浮遊する雰囲気では、誤動作、絶縁劣化や短絡などの不具合が短時間で発生します。オイルミストの場合も同様な状況を生じますので十分な対策を施すことが必要です。

###### ■ 対策 (2.3.1 / 原本 p.43)

• 密閉構造の盤に収納する。
　盤内の温度が上昇する場合には対策を施す。(47 ページ参照）
• エアーパージを行う。
　盤内の内圧が外気より高くなるように外部より、清浄空気を圧送する。

##### ◆ 腐食性ガス、塩害 (2.3.1 / 原本 p.43)

腐食性ガスのある場所および海岸近くで塩害を受けやすい場所への設置は、プリント基板のパターンや部品の腐食、リレー、スイッチ部の接触不良を生じます。
このような場所での対策は、上記塵埃、オイルミストの対策を施します。

##### ◆ 爆発性、可燃性ガス (2.3.1 / 原本 p.43)

インバータは非防爆構造のため、必ず防爆構造の盤に収納しなければなりません。爆発性ガス、粉塵により爆発のおそれのある場所での使用は法令の基準指針に構造的に適合し、検定に合格したものでなければ使用できないことになっているため収納盤自体が高価（受検料も含む）になります。これらの場所での設置は避け、非危険場所に設置することが最良の方法といえます。

##### ◆ 高地 (2.3.1 / 原本 p.43)

インバータは標高 3000m 以下で使用してください。1000m を超える標高で使用する場合は、500m ごとに 3% の定格電流低減が必要です。
これは高度が高くなると空気の希薄による冷却効果の低下、気圧の低下による絶縁耐力の劣化が生じやすくなるためです。

##### ◆ 振動、衝撃 (2.3.1 / 原本 p.43)

インバータの振動耐力は、X、Y、Z 各方向、振動 10 ～ 55Hz、振幅 1mm で加速度 5.9m/s<sup>2</sup> までです。振動、衝撃が規定値以下でも長時間加えられると、機構部のゆるみ、コネクタの接触不良などが発生することがあります。
特に繰返し衝撃が加わる場合は部品取付け足の折損事故などがおこりやすいので注意が必要です。

###### ■ 対策 (2.3.1 / 原本 p.43)

• 盤に防振ゴムを設ける。
• 盤が共振しないよう構造を強化する。
• 振動源から盤を離して設置する。

#### 2.3.8 インバータ盤の冷却方式の種類 (2.3.8 / 印刷 p.47 / 原本 p.48)

インバータを収納する盤は、インバータおよびインバータ以外の機器（トランス、ランプ、抵抗器、その他）の発熱と直射日光など外部から入ってくる熱を効率よく放熱させて、その盤内温度をインバータを含む盤内機器の許容温度以下に保つ必要があります。
冷却の計算方法からみて冷却方式を分類すると次のようになります。
- 盤面からの自然放熱による冷却（全閉鎖形）
- 放熱フィンによる冷却（アルミフィンなど）
- 換気による冷却（強制通風形、管通風形）
- 熱交換器や冷却器による冷却（ヒートパイプ、クーラなど）

| 冷却方式（大分類） | 冷却方式 | 盤構造 | コメント |
|---|---|---|---|
| 自然冷却 | 自然換気 ( 閉鎖、開放形 ) | 【図】盤側面の上下に通気口（スリット）があり、下部から外気が入り INV の熱を受けて上部から出る流れ（矢印）。図中文字「INV」 | コストが安く一般的であるが、インバータ容量が大きくなると、盤寸法も大きくなる。比較的小容量向き。 |
| 自然冷却 | 自然換気 ( 全閉鎖形 ) | 【図】開口のない全閉鎖盤で、盤面（上面・側面）から熱が放散される（波線矢印）。図中文字「INV」 | 全閉鎖形のため、塵埃、オイルミストなどの悪環境には最適。インバータ容量によっては盤寸法が大きくなる。 |
| 強制冷却 | フィン冷却 | 【図】盤側面に外付けのフィン、盤内上部にファン、盤内で空気が循環。図中文字「フィン」「INV」 | フィンの取付け場所、面積の制約もあり、比較的小容量向き。 |
| 強制冷却 | 強制換気 | 【図】盤下部側面の吸気口（フィルタ）から外気を取り入れ、盤上部の換気ファンで排気（上向き矢印）。図中文字「INV」 | 一般的な室内設置用。盤の小形化、低コスト化に向いておりよく使用される方式。 |
| 強制冷却 | ヒートパイプ | 【図】盤上部にヒートパイプとファンを設け、盤内外それぞれで空気を循環させる全閉構造。図中文字「ヒートパイプ」「INV」 | 全閉鎖形で盤の小形化が可能。 |

##### インバータの取付け方向 (2.3.9 / 原本 p.50)

インバータは壁面に正規の取付けをしてください。水平、その他の取付けはしないでください。

##### インバータの上部 (2.3.9 / 原本 p.50)

インバータの上部には、ユニットに内蔵している小形ファンにより、インバータ内の熱が下から上に上昇しますので、上部に器具を配置させる場合は熱の影響を受けても支障のないものにしてください。

##### インバータを複数台収納する場合 (2.3.9 / 原本 p.50)

同一盤内に複数台のインバータを収納する場合、通常次の図 (a) のように横に並べてください。盤のスペースを少なくするために、やむをえず縦に並べる場合、下部のインバータの熱で上部インバータ内の温度が上昇し、インバータ故障の原因になりますので、ガイドを設けるなどの対策をしてください。
また、複数台収納する場合、インバータの周囲温度が許容値をこえないよう、換気、通風および盤サイズを大きくするなど十分に注意してください。

【図】インバータ複数台数収納 (原本 p.50)
- (a) 横に並べる場合: 制御盤内上部にインバータ2台を横に並べて配置
- (b) 縦に並べる場合: 制御盤内にインバータを上下2段×2列に配置し、上下段のインバータの間にそれぞれ「ガイド」を設置。右の側面図で、上下インバータ間に斜めの「ガイド」を設けている

##### 換気ファンとインバータの配置 (2.3.9 / 原本 p.51)

インバータ内で発生した熱は冷却ファンにより温風となってユニットの下部から上部へと流れます。その熱の換気にファンを取り付ける場合、風の流れを十分考慮の上、換気ファンの設置場所を決めてください。( 風の流れは抵抗の少ないところを通ります。インバータに冷風があたるように風道や整流板を作ってください）

【図】換気ファンとインバータの配置 (原本 p.51)
- <良い例>: 盤上部の換気ファンがインバータ（内蔵ファン）の真上にあり、インバータからの温風（点線矢印）がそのまま換気ファンへ排出される。盤下部側面の吸気口から入った冷風がインバータ下部に向かう
- <悪い例>: 換気ファンがインバータの真上からずれた位置にあり、吸気口からの冷風はインバータに当たらず盤内を上昇して換気ファンへ抜け、インバータからの温風（点線矢印）は換気ファンに直接向かわない
