##### プログラミング例のシステム構成 (8 / 印刷 p.78 / 原本 p.79)

【図】プログラミング例のシステム構成（原本 p.79）
- シーケンサ: 電源 Q61P-A1 / CPU Q02CPU / マスタ局 QJ61BT11N (X/Y00～1F) / 入力ユニット QX40 (X20～X2F) / 出力ユニット QY40P (Y30～Y3F)
- マスタ局側に「終端抵抗」を接続
- 入力ユニットに X20（スイッチ、a接点）、出力ユニットに Y30（ランプ記号）を接続

- 局番2 インバータ: Pr.542＝2、Pr.544＝0、終端抵抗選択スイッチ-ON（終端局）

### 8.1 インバータステータスの読出しのプログラム例 (8.1 / 印刷 p.81 / 原本 p.82)

局番 1 のインバータが運転中となったら、出力ユニットの Y00 を ON するプログラム例

【図】ラダー図（原本 p.82）。※ニモニックは原本に記載なし。図から書き起こしたもの

```
0   LDI  X0
    AND  X0F
    AND  X1
    ANI  SW80.0
    OUT  M0                      局番1のデータリンク状態の確認
7   LD   M0
    AND  X1002                   インバータ運転中(RX02)
    OUT  Y30                     出力ユニット(Y00)をON
10  END
```

【図】リモート入力とインバータステータスの対応（原本 p.82）
- 1局 リモート入力 RXF～RX0（RX1F～RX10）→ X100F（b15）～X1000（b0）
- 図中のビット値は b15～b0 すべて 0
- b0～b11 が [インバータステータス]

| ビット | インバータステータス |
|---|---|
| b0 | 正転中*2 |
| b1 | 逆転中*2 |
| b2 | 運転中(端子RUN機能)*1 |
| b3 | 周波数到達*2 |
| b4 | 過負荷警報*2 |
| b5 | 機能なし(端子NET Y1機能)*1 |
| b6 | 周波数検出(端子FU機能)*1 |
| b7 | 異常(端子ABC機能)*1 |
| b8 | 機能なし(端子NET Y2機能)*1 |
| b9 | 機能なし(DO0)*1 |
| b10 | 機能なし(DO1)*1 |
| b11 | 機能なし(DO2)*1 |

*1 信号は初期値の場合のものです。Pr.190 ～ Pr.196、Pr.313 ～ Pr.315（出力端子機能選択）により出力信号を換えることができます。
*2 信号は固定です。パラメータによる変更はできません。

### 8.2 運転モード設定時のプログラム例 (8.2 / 印刷 p.82 / 原本 p.83)

インバータへ各種データを書き込むプログラムについて説明します。

局番 1 のインバータの運転モードをネットワーク運転に変更するプログラム例
- 運転モード書込みコード：HFB（16 進）
- ネットワーク運転の設定データ：H0000（16 進）（70 ページ参照）
- D2 に命令コード実行時の返答コードがセットされます。（68 ページ参照）

【図】ラダー図（原本 p.83）。※ニモニックは原本に記載なし。図から書き起こしたもの

```
0   LDI  X0
    AND  X0F
    AND  X1
    ANI  SW80.0
    OUT  M0                      局番1のデータリンク状態の確認
7   LD   M0
    AND  X20
    PLS  M300
11  LD   M300
    SET  M301
13  LD   M301
    ANI  X100F
    MOV  H0FB W102               RWw2に運転モード書込みコード(HFB)をRWw3に
    MOV  H0 W103                 設定データ(H0000)を書き込む。
    SET  Y100F                   命令コード実行要求(RY0F)をON
    RST  M301
    SET  M302
22  LD   M302
    AND  X100F
    MOV  W2 D2                   命令コード実行完了(RX0F)がONとなったら、返答コード(RWr2)をD2に読み出す。
    RST  Y100F                   命令コード実行要求(RY0F)をOFF
    RST  M302

```

- Y100D が ON した後、ON 中に W101 の値が変化する

### 8.10 注意事項 (8.10 / 印刷 p.91 / 原本 p.92)

##### プログラム上の注意事項 (8.10 / 印刷 p.91 / 原本 p.92)

- マスタ局のバッファメモリのデータは、インバータと常時リンクリフレッシュ（送受信）されていますので、データの書込み、読出し要求には、TO 命令を毎スキャン実行する必要はありません。TO 命令を毎スキャン実行しても特に問題はありません。
- FROM/TO 命令を頻繁に行うと、確実にデータが書き込まれない場合があります。バッファメモリを介して、インバータとシーケンスプログラムとの間でデータのやりとりを行う場合は、ハンドシェイクをとり、確実にデータが書かれていることを確認するようにしてください。

【図】TO命令と書込み完了のハンドシェイク（正・誤）（原本 p.92）
- 正: TO命令 ON → 書込み完了 ON → TO命令 OFF → 書込み完了 OFF → 次の TO命令 ON（各エッジを矢印で順につなぐ。書込み完了の OFF を確認してから次の TO命令を ON）
- 誤: TO命令 ON → 書込み完了 ON → TO命令 OFF の後、書込み完了が OFF になる前に次の TO命令が ON している（破線の位置）。書込み完了の OFF はその後になる

##### 操作および取り扱い上の注意事項 (8.10 / 印刷 p.91 / 原本 p.92)

- CC-Link 通信による運転中には、シーケンサからの指令のみ受け付けます。

外部からの運転指令および操作パネルからの運転指令は無視されます。

- 複数のインバータにおいて局番設定が重なると、正常交信ができません。
- CC-Link 通信による運転中に、シーケンサの故障、CC-Link 専用ケーブルの断線などで、Pr.500 通信異常実行待ち時間で設定された時間以上データ交信が停止すると、インバータの保護機能（E.OP1）が動作します。
- CC-Link 通信による運転中に、シーケンサ（マスタ局）をリセットする、またはシーケンサの電源を OFF するとデータ交信が停止し、インバータの保護機能（E.OP1）が動作します。

シーケンサ（マスタ局）をリセットする場合は、運転モードをいったん、外部運転に切り換えてから、シーケンサをリセットしてください。

- Pr.340 ＝ “0” の場合、主電源が復電したインバータはリセットがかかって運転モードが外部運転に戻りますので、ネットワーク運転を再開する場合には、シーケンスプログラムでネットワーク運転モードにしてください。

インバータリセット後にネットワーク運転モードで立ち上げるには Pr.340 ≠ “0” に設定してください。（33 ページ参照）
