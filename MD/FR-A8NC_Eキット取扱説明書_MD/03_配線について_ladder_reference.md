## 3 配線について (3 / 印刷 p.20 / 原本 p.21)

### 3.1 CC-Link 専用ケーブルの接続 (3.1 / 印刷 p.20 / 原本 p.21)

#### 3.1.1 接続ケーブルの作製 (3.1.1 / 印刷 p.20 / 原本 p.21)

CC-Link システムでは、CC-Link 専用ケーブルを使用してください。CC-Link 専用ケーブル以外では、CC-Link システムの性能が保証されません。CC-Link 通信用ワンタッチコネクタプラグ（付属品）に挿入する CC-Link 専用ケーブルは下記を使用してください。

- CC-Link 専用ケーブル（2018 年 10 月時点。予告なしに変更される場合があります。）

| 形　　名 | メーカ名 |
|---|---|
| FANC-110SBH | 倉茂電工（株） |
| CS-110 | 大電（株） |
| FA-CBL200PSBH | 三菱電機エンジニアリング（株） |

> **NOTE**
> - CC-Link 専用ケーブルの仕様、お問い合わせ先については、CC-Link 協会ホームページを参照してください。
>   （CC-Link 協会ホームページ　http://www.cc-link.org/）

##### 1. ケーブル端末処理 (3.1.1 / 印刷 p.21 / 原本 p.22)

CC-Link 通信用ワンタッチコネクタプラグ（付属品）に挿入する CC-Link 専用ケーブルの端末に対して以下の処理を行ってください。

| 手順 | 内容 | 図から読み取れる事項 |
|---|---|---|
| 1. | 被覆をカットする。 | 外被をカットし、編組シールドが露出した状態 |
| 2. | シールド線とドレイン線を分け、シールド線をカットする。 | 図中ラベル: ドレイン線、シールド線 |
| 3. | アルミテープ、介在ひもをカットする。 | 図中ラベル: DA（青）、DB（白）、DG（黄）、ドレイン線 |
| 4. | ドレイン線をまっすぐ伸ばし、根元からよりあげる。（3cm を 7 回以上） | 図中ラベル: DA（青）、DB（白）、DG（黄）、ドレイン線（AWG20）、寸法 3cm（被覆端からドレイン線先端まで） |

【図】ケーブル端末処理の手順 1〜4 の図（原本 p.22）
- 芯線は DA（青）、DB（白）、DG（黄）の3本とドレイン線
- ドレイン線は AWG20、被覆端から 3cm

> **NOTE**
> - ニッパーなどで切った先端はなるべく丸くしてください。ケーブル挿入時、ケーブル断面が円形でない場合、途中で引っかかり奥まで入れにくい場合があります。
> - シールド線の CC-Link 通信用ワンタッチコネクタプラグに挿入されない部分については、必要に応じて絶縁処理を実施してください。

CC-Link 通信用ワンタッチコネクタプラグのプラグカバーがプラグ本体に組み込まれているか確認してください。

##### 3. ケーブルの挿入 (3.1.1 / 印刷 p.23 / 原本 p.24)

プラグカバーの後方を持ち上げ、プラグ本体に突き当たるところまでケーブルを挿入します。各信号用のケーブルは、CC-Link 通信用ワンタッチコネクタプラグへ下図のように挿入します。

【図】ケーブルの挿入とピン配置（原本 p.24）
- プラグのピン番号は図の左から 5 4 3 2 1

| ピン番号 | 信号名 |
|---|---|
| 1 | DA（青） |
| 2 | DB（白） |
| 3 | DG（黄） |
| 4 | 空き |
| 5 | SLD（ドレイン線） |

※ピン番号と信号名の対応表は図から読み取ったもの（原本は図のみ）。

> **NOTE**
> - ケーブルの挿入時、ケーブルを奥まで挿入してください。ケーブルが奥まで入っていないと、圧接不良の原因になります。
> - ケーブル挿入時、カバー前部より、ケーブルが突き出る場合があります。このときはケーブルの先端がプラグカバーの中に入るように引き戻してください。

##### 4. プラグカバーの圧接 (3.1.1 / 印刷 p.24 / 原本 p.25)

プライヤーなどでプラグカバーをプラグ本体に押し込み圧接します。圧接後、下図のようにプラグカバーがプラグ本体から外れないようにしっかりとはめ込まれていることを確認してください。

【図】圧接後のプラグ（原本 p.25）
- プラグカバーがプラグ本体にはめ込まれ、4本のケーブルが挿入された状態

> **NOTE**
> - 圧接時、プラグカバーとプラグ本体のラッチがかみ合わなく、カバーが浮き上がることがあります。この状態では圧接不十分ですので、プラグカバーがプラグ本体にしっかりとはめ込まれるまでカバーを押し込んでください。

#### 3.1.2 コネクタとの接続 (3.1.2 / 印刷 p.25 / 原本 p.26)

CC-Link 専用ケーブルを CC-Link 通信用コネクタに接続します。

【図】CC-Link 通信用コネクタへの接続（原本 p.26）
- 図中ラベル: CC-Link 通信用コネクタ、CC-Link 専用ケーブル
- CC-Link 通信用コネクタは2口（上下2段）で、それぞれにワンタッチコネクタプラグ付きの CC-Link 専用ケーブルを差し込む図

> **注意**
> - 電線にストレスがかからないように注意してください。
> - 配線時にインバータ内部に電線切りくずを残さないでください。異常、故障、誤動作の原因になります。

#### 3.1.3 オンライン交換を行う場合 (3.1.3 / 印刷 p.26 / 原本 p.27)

CC-Link 通信用コネクタに通信用オンラインコネクタを使用して接続してください。通信用オンラインコネクタを使用することにより通信をとめることなくユニット交換ができます。通信用オンラインコネクタは、必ず CC-Link 通信用コネクタのコネクタ 1（手前側）に接続してください。（CC-Link 通信用コネクタのコネクタ 2（奥側）には接続しないでください。インバータやコネクタなどの故障や破損の原因となります。）

また、終端局の FR-A8NC の CC-Link 通信用コネクタに終端抵抗付ワンタッチコネクタプラグを接続してください。

（内蔵の終端抵抗選択スイッチの設定を行った場合（19 ページ参照）は、オンライン交換できません。）

【図】オンライン交換時の接続（原本 p.27）
- 図中ラベル: コネクタ1、コネクタ2、通信用オンラインコネクタ、終端抵抗付ワンタッチコネクタプラグ、終端局のFR-A8NC
- 左の FR-A8NC: 通信用オンラインコネクタを CC-Link 通信用コネクタに接続（コネクタ1 / コネクタ2 の位置を矢印で図示）
- 右の終端局の FR-A8NC: 通信用オンラインコネクタ（ケーブル側）に終端抵抗付ワンタッチコネクタプラグを接続した状態

通信用オンラインコネクタと終端抵抗付ワンタッチコネクタプラグは下記を使用してください。（原本 p.28）

- 通信用オンラインコネクタ（2018 年 10 月時点。予告なしに変更される場合があります。）

### 3.2 システム構成例 (3.2 / 印刷 p.28 / 原本 p.29)

1. シーケンサ側
   マスタ局となるシーケンサ CPU の基本ベースユニットまたは増設ベースユニットに、RJ61BT11 形 /QJ61BT11N 形 /L26CPU-BT 形 /L26CPU-PBT 形 /LJ61BT11 形 /A1SJ61QBT11 形 /A1SJ61BT11 形「CC-Link システムマスタ・ローカルユニット」を装着します。
2. インバータ側
   インバータに内蔵オプション (FR-A8NC) を装着します。
3. シーケンサCC-Linkユニットマスタ局と、FR-A8NCのCC-Link通信用コネクタをCC-Link専用ケーブルで接続します。

【図】システム構成例（原本 p.29）
- マスタ局（QJ61BT11N など）を装着したシーケンサと、リモートデバイス局のインバータ（FR-A8NC 装着）を CC-Link 専用ケーブルで接続
- 両端（マスタ局側と末端のインバータ側）に終端抵抗
- インバータは最大42台まで接続可能（インバータのみ接続の場合）
- 各インバータに電源と M（モータ）を接続

CC-Linkマスタ局のマニュアル（図中の枠内記載）

| 形名 | マニュアル名 | 資料番号 |
|---|---|---|
| RJ61BT11形 | CC-Linkシステムマスタ・ローカルユニット ユーザーズマニュアル（応用編） | SH-081268 |
| QJ61BT11N形 | CC-Linkシステムマスタ・ローカルユニット ユーザーズマニュアル（詳細編） | SH-080395 |
| L26CPU-BT形/L26CPU-PBT形/LJ61BT11形 | CC-Linkシステムマスタ・ローカルユニット ユーザーズマニュアル | SH-080880 |
| A1SJ61QBT11形 | CC-Linkシステムマスタ・ローカルユニット ユーザーズマニュアル（詳細編） | SH-3604 |
| A1SJ61BT11形 | CC-Linkシステムマスタ・ローカルユニット ユーザーズマニュアル（詳細編） | SH-3603 |

※原本では図中の箇条書き。転記上、表に整理した。

> **NOTE**
> - 自動リフレッシュ機能搭載 CPU 時（例：QnA 系 CPU）
>   シーケンサ CPU の END 命令実行時、マスタ局のバッファメモリが自動リフレッシュされることによって、リモートデバイスとの交信が行われます。
> - 自動リフレッシュ機能未搭載 CPU 時（例：AnA 系 CPU）
>   シーケンスラダーで直接、マスタ局のバッファメモリとやり取りを行うことによって、リモートデバイスとの交信が行われます。

### 3.3 複数台のインバータを接続する場合 (3.3 / 印刷 p.29 / 原本 p.30)

CC-Link のリモートデバイス局の 1 局としてリンクシステムを共用し、シーケンサのプログラムで、制御監視することによって、複数台のインバータの FA 化を行います。

CC-Link 専用ケーブルのシールド線は、各ユニットの “SLD” に接続してください。

【図】複数台接続の配線図（原本 p.30）
- 左からマスタユニット、FR-A8NC*2（中間）、FR-A8NC（終端）
- 各ユニットの DA / DB / DG / SLD を渡り配線。DA=青、DB=白、DG=黄
- ユニット間はシールド付ツイストケーブル。シールドは各ユニットの SLD に接続（図中に接地記号あり）
- マスタユニット側: DA-DB 間に終端抵抗*1
- 終端の FR-A8NC: 終端抵抗選択スイッチ*3

*1 終端抵抗は、シーケンサに付属の終端抵抗を使用してください。  
*2 中間のユニットは終端抵抗選択スイッチを 1-OFF、2-OFF（終端抵抗なし）に設定してください。（19 ページ参照）  
*3 終端抵抗選択スイッチの設定を行ってください。（19 ページ参照）  
　　終端抵抗付ワンタッチコネクタプラグを使用する場合は、内蔵の終端抵抗選択スイッチは使用しないでください。(1-OFF、2-OFF)  
　　（終端抵抗付ワンタッチコネクタプラグの詳細は 26 ページを参照してください。）  

##### ◆ マスタ局 1 台に対しての最大接続台数 (CC-Link Ver.1.10) (3.3 / 印刷 p.29 / 原本 p.30)

42 台（インバータのみ接続の場合）
