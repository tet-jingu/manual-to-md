### 付3 ユニットラベル (付3 / 印刷 p.220 / 原本 p.222)

FX5-EIPのバッファメモリは，ユニットラベルを使用して設定できます。
一部のユニットラベルは最大コネクション数設定に応じて使用できるものが異なります。
最大コネクション数が64の場合は"EtherNet/IP共通エリア(64コネクション)"，最大コネクション数が128の場合は、"EtherNet/IP共通エリア(128コネクション)"のユニットラベルを使用してください。

##### ユニットラベルの構成 (付3 / 印刷 p.220 / 原本 p.222)

ユニットラベルの名称は，下記の構成で定義されます。
- “インスタンス名”_”データ型””ラベル名”_D
- “インスタンス名”_”データ型”“データ種別”_”ラベル名”_D

###### インスタンス名 (付3 / 印刷 p.220 / 原本 p.222)

FX5-EIPのインスタンス名は下記のようになります。

| ユニット形名 | インスタンス名 |
|---|---|
| FX5-EIP | FX5EIP |

例
FX5EIP_unStatus_LatestError_D

###### データ型 (付3 / 印刷 p.220 / 原本 p.222)

バッファメモリのデータのサイズを示します。下記のように種別されます。

| データ型 | 内容 |

| b | ビット |
| bn | 複数のバッファメモリのビット |
| u | ワード[符号なし]/ビット列[16ビット] |

###### データ種別 (付3 / 印刷 p.220 / 原本 p.222)

###### _D (付3 / 印刷 p.220 / 原本 p.222)

### 付4 バッファメモリ (付4 / 印刷 p.221 / 原本 p.223)（次ファイルへ続く）

- 'PINGテスト応答結果エリア'(Un￥G244~Un￥G256): 'PINGテスト実行要求'のONを受けて FX5-EIP が 0 にクリアし（破線）、テスト完了時に「PINGテスト結果」を格納する（破線）
