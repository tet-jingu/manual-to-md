## 7 パラメータ設定（続き） (7 / 印刷 p.97 / 原本 p.99)

### 7.4 EtherNet/IP構成（次ファイルへ続く） (7.4 / 印刷 p.97 / 原本 p.99)

EtherNet/IPの設定について説明します。

#### パラメータ設定手順 (7.4 / 印刷 p.97 / 原本 p.99)

EtherNet/IP構成機器のパラメータを設定します。パラメータは使用する通信方式によって異なります。

- 98ページ Class1インスタンス通信の設定
- 100ページ Class1タグ通信の設定
- 102ページ Class3インスタンス通信の設定
- 103ページ Class3タグ通信の設定
- 104ページ Class3/UCMMのタグ設定

共通の設定については，下記を参照してください。
97ページ 共通設定

##### 共通設定 (7.4 / 印刷 p.97 / 原本 p.99)

###### FX5-EIPをオリジネータ/クライアントとして使用する場合 (7.4 / 印刷 p.97 / 原本 p.99)

1. ”EtherNet/IP構成”画面を開きます。
   - ナビゲーションウィンドウ⇨[パラメータ]⇨[ユニット情報]⇨[FX5-EIP]⇨[EtherNet/IP構成(ユニット拡張パラメータ)]
2. 相手機器のEDSファイルを登録します。(120ページ EDSファイルの追加/削除)
3. ”ユニット一覧”から相手機器のEtherNet/IP機器を選択し，EtherNet/IP機器一覧にドラッグ&ドロップします。

【図】”EtherNet/IP構成”画面（原本 p.99）
- タイトルバー: EtherNet/IP構成 (装着位置No.：1[U1])
- メニュー: EtherNet/IP構成(I) / 編集(E) / 表示(V) / ツール(T) / ヘルプ(H) / 設定を破棄して閉じる(N) / 設定を反映して閉じる(R)
- [接続機器の自動検出]ボタン
- 機器一覧の列: No. / 形名 / 機器名 / IPアドレス / 予約ノード / コネクション設定 / モジュール構成設定 / 使用スロット数
- 行1: No.空欄 / 自ノード / （機器名空欄） / 192.168.3.251 / （空欄） / <詳細設定>
- 行2: No.1 / FX5-EIP / （機器名空欄） / 192.168.3.1 / 設定なし / <詳細設定>
- ”ユニット一覧”: EtherNet/IP機器(汎用) / EtherNet/IP機器(三菱電機) ＞ 通信アダプタ ＞ FX5-EIP 1.1 / RJ71GN11-EI… 3.1 / RJ71GN11-EI… 2.1 / RJ71GN11-EI… 1.1（FX5-EIP が選択状態）

4. 相手機器のEtherNet/IP機器の機器名やIPアドレスなどを設定します。
5. FX5-EIPの”コネクション設定”列の”<詳細設定>”をダブルクリックして，EtherNet/IP機器のコネクションを設定します。

###### FX5-EIPをターゲット/サーバとして使用する場合 (7.4 / 印刷 p.97 / 原本 p.99)

1. ”EtherNet/IP構成”画面を開きます。
   - ナビゲーションウィンドウ⇨[パラメータ]⇨[ユニット情報]⇨[FX5-EIP]⇨[EtherNet/IP構成(ユニット拡張パラメータ)]
2. FX5-EIPの”コネクション設定”列の”<詳細設定>”をダブルクリックして，EtherNet/IP機器のコネクションを設定します。

> **Point**
> FX5-EIPはオリジネータ/クライアントとターゲット/サーバは併用して設定可能です。

##### Class1インスタンス通信の設定 (7.4 / 印刷 p.98-99 / 原本 p.100-101)

EtherNet/IP機器に対してClass1インスタンス通信を実施する場合は，下記の手順で設定します。

###### FX5-EIPをオリジネータとして設定する場合 (7.4 / 印刷 p.98 / 原本 p.100)

1. 自ノードをオリジネータとして，ターゲットと通信する設定をします。
   ”コネクション一覧”から”オリジネータ”の下にあるEtherNet/IP機器を選択して，[コネクションを追加]ボタンをクリックします。

【図】”コネクション一覧”（原本 p.100）
- タブ: ユニット順 / コネクション詳細一覧 / 通信処理性能(PPS)一覧
- ツリー: 自ノード ＞ ターゲット / タグ / オリジネータ ＞ FX5-EIP(192.168.3.1)（選択状態）
- ボタン: [コネクションを追加(N)] / [コネクションを削除(D)]（無効表示）

2. ”追加コネクション選択”からインスタンス通信のコネクション*1を選択して，[OK]ボタンをクリックします。

【図】”コネクションを追加”画面（原本 p.100）
- 追加コネクション選択(S): Input Only(Class1 Instance)
- ボタン: [OK] / [キャンセル]

*1 EtherNet/IP機器のEDSによって表示内容が異なります。詳細は相手機器のマニュアルを参照してください。

3. ”コネクション詳細設定”からClass1インスタンス通信のパラメータを設定します。(111ページ オリジネータ: Class1 インスタンス通信)

> **Point**
> - ”入力 T->O”の”インスタンスID”には，ターゲットに設定する通信したいコネクションのインスタンスIDを設定してください。
> - ”入力 T->O”の”データサイズ”には，ターゲットに設定する通信したいコネクションのデータサイズを設定してください。

4. [OK]ボタンをクリックしてパラメータを反映します。
5. [設定を反映して閉じる]ボタンをクリックし，”EtherNet/IP構成”画面を閉じます。

###### FX5-EIPをターゲットとして設定する場合 (7.4 / 印刷 p.99 / 原本 p.101)

1. ”EtherNet/IP構成”画面から”コネクション設定”列の<詳細設定>をダブルクリックして，EtherNet/IP機器のコネクションを開きます。
2. 自ノードをターゲットとして，オリジネータと通信する設定をします。
   ”コネクション一覧”から”ターゲット”を選択して，[コネクションを追加]ボタンをクリックします。

【図】”コネクション一覧”（原本 p.101）
- タブ: ユニット順 / コネクション詳細一覧 / 通信処理性能(PPS)一覧
- ツリー: 自ノード ＞ ターゲット（選択状態） / タグ / オリジネータ ＞ FX5-EIP(192.168.3.1) ＞ (001)
- ボタン: [コネクションを追加(N)] / [コネクションを削除(D)]（無効表示）

3. ”追加コネクション選択”から”コネクション(ターゲット インスタンス通信)”を選択して，[OK]ボタンをクリックします。

【図】”コネクションを追加”画面（原本 p.101）
- 追加コネクション選択(S): コネクション(ターゲット インスタンス通信)
- ボタン: [OK] / [キャンセル]

4. ”コネクション詳細設定”からClass1インスタンス通信のパラメータを設定します。(109ページ ターゲット: インスタンス通信)

> **Point**
> インスタンスIDに100～199を設定する場合，オリジネータ側では"[FX5-ENET/IP compatible]"の付いたコネクションを選択してください。詳細は相手機器のマニュアルを参照してください。

5. [OK]ボタンをクリックしてパラメータを反映します。
6. [設定を反映して閉じる]ボタンをクリックし，”EtherNet/IP構成”画面を閉じます。

##### Class3タグ通信の設定 (7.4 / 印刷 p.103 / 原本 p.105)

###### 検出できるEtherNet/IP機器 (7.4 / 印刷 p.106 / 原本 p.108)

自局からブロードキャストフレームが届く範囲に接続中のEtherNet/IP機器が検出されます。(最大128台)
ただし，シャーシをベースとしたEtherNet/IP機器の場合，EtherNet/IP通信モジュールは検出されますが，シャーシ内のその他の接続モジュールは検出されませんので，手動で追加してください。*1

*1 シャーシをベースにした EtherNet/IP機器(シャーシ付きユニット)には下記の2つのタイプがあります。
- CPUモジュールをベースに，その横にI/Oモジュールなどのモジュールを結合していくタイプ
- ベースユニット上にCPUモジュールや通信I/Oなどを担うモジュールを装着するタイプ

ただし，EtherNet/IP機器の外観では判断できないため，EDSファイルに記載されているModularエリアの内容で判断してください。(詳細についてはEtherNet/IPの仕様書を参照してください)

###### FX5-EIPを検出させる場合 (7.4 / 印刷 p.107 / 原本 p.109)

FX5-EIPを本機能で検出させる場合は，ʼEtherNet/IP通信起動状態ʼ(Un￥G273)が1(起動中)であることを確認してください。(他製品から実行するEtherNet/IP機器の検出機能で，FX5-EIPを検出対象としたい場合も同様になります。)*1
EtherNet/IP機器の自動検出は， ListIdentityコマンドを使用してネットワーク上のEtherNet/IP機器の検出を行います。*2
そのため，FX5-EIPはEtherNet/IP通信を起動状態にしておく必要があります。

*1 ʼEtherNet/IP通信起動状態ʼ(Un￥G273)を1(起動中)にする方法については，下記を参照してください。
78ページ EtherNet/IP通信自動起動
*2 ListIdentitiyコマンドの詳細については，EtherNet/IPの仕様書を参照してください。

> **Point**
> 下記の理由などにより，EtherNet/IP通信のListIdentityコマンドに応答ができない機器は検出できません。
> - ListIdentityコマンドに対応していない機器である
> - EtherNet/IPのネットワークから断線している
> - EtherNet/IP通信の起動が完了していない
> - EtherNet/IP通信が停止している
> - EtherNet/IP機器のIPアドレスが重複している
>
> ListIdentityコマンドに応答可能な機器であるかは，相手機器のマニュアルを参照してください。

###### 注意事項 (7.4 / 印刷 p.107 / 原本 p.109)

- 本機能を実行した場合，完了後から次のEtherNet/IP機器の自動検出を実行するまで約10秒待ってください。(通信が切断された場合は，次のEtherNet/IP機器の自動検出を実行するまで約1分待ってください。)
- 本機能を実行中は，他のEtherNet/IP構成ツールからEtherNet/IP機器の自動検出はできません。
- ネットワークに接続されているEtherNet/IP機器が128台を超えている場合，128台を超える機器は検出結果に表示されません。また，検出は順不同になるため，検出される機器はランダムになります。
- 本機能を実行中にʼEtherNet/IP通信起動状態ʼ(Un￥G273)が1(起動中)から0(停止中)に移行した場合，一部のユニットがEtherNet/IP機器の自動検出の対象外になる場合があります。本機能を実行中はʼEtherNet/IP通信起動要求ʼ(Un￥G272)を操作したり，CPUユニットの状態をRUN→STOPなどに変化させないように注意してください。
- 本機能はユーザーパラメータ「最大コネクション数設定」の設定値が「64コネクション」「128コネクション」のどちらでも検出可能な機器数は128台までです。
