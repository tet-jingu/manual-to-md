### 9.6 エラーコード一覧 (9.6 / 印刷 p.189 / 原本 p.191)

FX5-EIPと相手機器の間でデータ交信するための各処理，および自局のCPUユニットからの処理要求で発生するエラーのエラーコード，異常内容と原因，および処置方法について説明します。

FX5-EIPのエラーコードは，下記があります。

| 種類 | 概要 | 参照先 |
|---|---|---|
| ユニットエラー | FX5-EIPの”ユニット診断”画面に表示されます。 | 189ページ ユニットエラー |
| コネクション別状態エラー | • FX5-EIPの”EtherNet診断”画面に表示されます。<br>• ’共通エリアエラーコード’(Un￥G108~Un￥G139)に格納されます。 | 193ページ コネクション別状態のエラーコード |
| PINGテスト実行時のエラーコード | ’PINGテスト応答エリア’(Un￥G244~Un￥G256)に格納されます。 | 195ページ PINGテスト実行時のエラーコード |
| SLMPSND命令完了異常時のエラーコード | SLMPSND命令の設定データのコントロールデータにある完了ステータスに格納されます。 | 196ページ SLMPSND命令完了異常時のエラーコード |
| EtherNet/IP通信エラー | ’サイクリック通信コネクションエラー状態’(Un￥G1392~Un￥G1903)に格納されます。 | 197ページ コネクション異常時のエラーコード |
| メッセージ通信機能(クライアント)のエラーコード | • メッセージ通信エリア(応答エリア)の結果格納エリアに格納されます。<br>• 各ユニットFBの通信異常のエラーコードに格納されます。 | 211ページ メッセージ通信機能(クライアント)のエラーコード |
| タグ通信機能(サーバ)のエラーコード | メッセージ通信エリア(応答エリア)のCIP応答コードに格納されます。 | 213ページ タグ通信機能(サーバ)のエラーコード |
