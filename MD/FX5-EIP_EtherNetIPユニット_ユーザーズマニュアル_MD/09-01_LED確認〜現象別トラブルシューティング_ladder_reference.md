## 9 トラブルシューティング (9 / 印刷 p.175 / 原本 p.177)

FX5-EIPと相手機器間の交信において発生するエラー内容，およびトラブルシューティングについて説明します。

### 9.1 LEDによる確認 (9.1 / 印刷 p.175-176 / 原本 p.177-178)

LEDによるトラブルシューティングについて説明します。

##### RUN LEDが消灯した場合 (9.1 / 印刷 p.175 / 原本 p.177)

FX5-EIPの電源投入後，RUN LEDが消灯した場合は，下記の項目を確認してください。

| 確認項目 | 処置方法 |
|---|---|
| FX5-EIPが正しく装着されているか。 | 正しく装着されていない場合は，FX5-EIPをCPUユニットに正しく装着し直してください。 |

上記の処置でも解決できない場合は，ハードウェアテストを実施し，FX5-EIPに異常がないか確認してください。(☞ 183ページ ハードウェアテスト)

##### ERROR LEDが点灯または点滅した場合 (9.1 / 印刷 p.175 / 原本 p.177)

ERROR LEDが点灯または点滅した場合は，下記の項目を確認してください。

| 確認項目 | 処置方法 |
|---|---|
| ユニット診断でエラーが発生していないか。 | ユニット診断での処置方法に従って処置してください。(☞ 177ページ ユニット診断) |

##### MS LEDが緑点滅した場合 (9.1 / 印刷 p.175 / 原本 p.177)

MS LEDが緑点滅した場合は，下記の項目を確認してください。

| 確認項目 | 処置方法 |
|---|---|
| ”EtherNet/IP構成”によるパラメータ設定を行ったか。 | ”EtherNet/IP構成”によるパラメータ設定を行っていない場合，設定を行ってください。 |
| パラメータの書込みが正常に行われたか。 | • シーケンサへの書込みでエラーが発生していないか確認してください。<br>• 再度パラメータ書込みを実施してください。 |

##### MS LEDが赤点灯または赤点滅した場合 (9.1 / 印刷 p.175 / 原本 p.177)

MS LEDが赤点灯または赤点滅した場合は，下記の項目を確認してください。

| 確認項目 | 処置方法 |
|---|---|
| ユニット診断でエラーが発生していないか。 | ユニット診断での処置方法に従って処置してください。(☞ 177ページ ユニット診断) |

##### NS LEDが緑点滅した場合 (9.1 / 印刷 p.176 / 原本 p.178)

NS LEDが緑点滅した場合は，下記の項目を確認してください。*1

| 確認項目 | 処置方法 |
|---|---|
| 下記のバッファメモリの値は正常か。<br>• ‘サイクリック通信ステータス’(Un￥G1328~Un￥G1351)<br>• ‘サイクリック通信コネクションエラー状態’(Un￥G1392~Un￥G1903) | ‘サイクリック通信コネクションエラー状態’(Un￥G1392~G1903)の値を確認して，処置してください。(☞ 241ページ サイクリック通信一時停止状態(Un￥G1368~Un￥G1375)) |
| ’EtherNet/IP通信起動状態’(Un￥G273) が1(起動中)になっているか。 | • ’EtherNet/IP通信起動要求’(Un￥G272)が0以外(起動要求)になっていることを確認してください。<br>• ユニット拡張パラメータが書き込まれていない場合は書き込んでください。<br>• ’サイクリック通信一時停止指定’(Un￥G1360～Un￥G1367)がすべて0(サイクリック一時停止要求なし)となっていることを確認してください。 |

*1 UCMM通信はコネクションを確立しないため，UCMM通信のみ通信している場合は，緑点灯になりません。

##### NS LEDが赤点滅した場合 (9.1 / 印刷 p.176 / 原本 p.178)

NS LEDが赤点滅した場合は，下記の項目を確認してください。

| 確認項目 | 処置方法 |
|---|---|
| EtherNet/IP機器との接続が正しく行われているか。 | • EtherNet/IP機器の動作状態が正常か確認してください。(☞ 177ページ ユニット診断)<br>• 回線状態に異常がないか確認してください。<br>• 回線が混雑状態である可能性があるため，時間をおいてリトライしてください。 |

##### データ送受信時にSD/RD LEDが点灯しない場合 (9.1 / 印刷 p.176 / 原本 p.178)

データ送受信時にSD/RD LEDが点灯しない場合は，下記の項目を確認してください。

| 確認項目 | 処置方法 |
|---|---|
| ERROR LEDが点灯または点滅していないか。 | ユニット診断での処置方法に従って処置してください。(☞ 177ページ ユニット診断) |
| Ethernetケーブルが正しく接続されているか。 | • Ethernetケーブルを接続し直してください。<br>• PINGテストを実施し，回線状態を確認してください。(☞ 182ページ PINGテスト) |
| パラメータ設定に誤りがないか。 | ”EtherNet/IP構成”の下記内容を見直してください。<br>• 接続するEtherNet/IP機器の機種，形名<br>• 接続するEtherNet/IP機器のIPアドレス<br>• 登録されたEDSファイルのバージョン |
| プログラムに誤りがないか。 | • ‘EtherNet/IP通信起動要求’(Un￥G272)がONしていることを確認してください。<br>• データ送受信用プログラムを見直し，誤りがある場合は修正してください。 |

上記の処置でも解決できない場合は，ハードウェアテストを実施し，FX5-EIPに異常がないか確認してください。(☞ 183ページ ハードウェアテスト)

### 9.2 ユニットの状態確認 (9.2 / 印刷 p.177-179 / 原本 p.179-181)

FX5-EIPのユニットの状態は，下記の方法で確認できます。
- ユニット診断
- Ethernet診断
- バッファメモリによる確認
- イベント履歴機能

#### ユニット診断 (9.2 / 印刷 p.177 / 原本 p.179)

FX5-EIPの”ユニット診断”画面で下記の機能が使用できます。

| 機能 | 用途 |
|---|---|
| エラー情報 | 現在発生しているエラーの内容が表示されます。<br>[イベント履歴]ボタンをクリックすると，FX5-EIPで発生したエラーのほか，各ユニットで検出したエラーの履歴が確認できます。 |
| ユニット情報一覧 | FX5-EIPの各種ステータス情報が表示されます。 |

##### エラー情報 (9.2 / 印刷 p.177 / 原本 p.179)

現在発生しているエラーの内容と処置方法を確認します。

操作: [診断]⇨[システムモニタ]で”FX5-EIP”をダブルクリック

【図】”ユニット診断(インテリユニット No. 01)”画面（エラー情報タブ）の表示例（原本 p.179）
- 上部: 形名 FX5-EIP、製造番号 -、F/Wバージョン 1.000、Booter F/Wバージョン A、H/Wバージョン -
- 補助機能: ”Ethernet診断”プルダウン＋[実行(T)]ボタン、[モニタ中]／[モニタ停止(O)]ボタン
- エラーコードの表示形式: 10進数(D) / 16進数(X)（例では16進数を選択）
- タブ: エラー情報 / ユニット情報一覧
- エラー一覧の列: No.、発生日時、状態、エラーコード、概要。例: No.1、1980/04/06 07:20:52.701、中度アイコン、H2160、IPアドレス重複検出
- 右側ボタン: [エラージャンプ(J)]、[イベント履歴(E)]、[エラー解除(R)]、[詳細(D)]
- 凡例: 重度 / 中度 / 軽度
- 下部の欄: 詳細情報（故障情報 MPU種別 :0010、エラー通知箇所判定用ID :500A）、原因「IPアドレスの重複を検出した。」、処置方法「・IPアドレスを修正してください。」
- 下端: [ファイル作成(C)...]、[閉じる]

| 項目 | 内容 |
|---|---|
| 状態 | 重度: ハードウェア異常やメモリ異常などにより，ユニットが動作を停止するエラーです。 |
| 状態 | 中度: ユニット動作に関わるパラメータ異常などにより，ユニットが動作を停止するエラーです。 |
| 状態 | 軽度: 通信失敗など，ユニットが動作を続行するエラーです。 |
| 詳細情報 | 各エラーの詳細情報が最大3つまで表示されます。 |
| 原因 | エラーの原因となる詳細な内容が表示されます。 |
| 処置方法 | エラーに対する処置方法が表示されます。 |

##### EtherNet/IP通信エラー (9.2 / 印刷 p.179 / 原本 p.181)

サイクリック通信時にエラーが発生した場合は，下記で確認してください。
- ☞ 180ページ インテリジェント機能ユニットモニタ
- ☞ 181ページ デバイス/バッファメモリ一括モニタ

##### ユニットエラー (9.2 / 印刷 p.179 / 原本 p.181)

FX5-EIPにエラーが発生した際，下記のバッファメモリを確認してください。

### 9.4 ハードウェアテスト (9.4 / 印刷 p.183 / 原本 p.185)

FX5-EIPのROM/RAMなどの，ハードウェアに関するテストを行います。

> **制約事項**
> - ハードウェアテスト中は，GX Works3およびプログラムでバッファメモリの値を参照できません。
> - ハードウェアテスト中にCPUユニットの動作状態を変更しないでください。CPUユニットの動作状態を変更した場合は，CPUユニットでユニット重度異常が発生します。

##### 操作手順 (9.4 / 印刷 p.183 / 原本 p.185)

1. GX Works3で，FX5-EIPのモード設定をハードウェアテストに設定します。
   - 操作: ナビゲーションウィンドウ⇨[パラメータ]⇨[ユニット情報]⇨[FX5-EIP]⇨[応用設定]⇨[モード設定]⇨[モード]⇨”ハードウェアテストモード”を選択
2. FX5-EIPのEthernetポートにケーブルが接続されている場合，ケーブルを抜きます。
3. CPUユニット(FX5-EIP)をSTOP状態にして，パラメータを書き込みます。
4. CPUユニット(FX5-EIP)の電源OFF→ONまたはリセットをします。
5. 自動的にハードウェアテストが実行されます。

   ハードウェアテスト時のFX5-EIPのLED表示は下記のとおりです。

| 状態 | RUN LED | ERROR LED |
|---|---|---|
| ハードウェアテスト実行中 | 点滅 | 消灯 |
| ハードウェアテスト正常完了 | 点灯 | 消灯 |
| ハードウェアテスト異常完了 | 点灯 | 点灯 |

6. 正常完了時は，GX Works3で，FX5-EIPのモード設定を”オンラインモード”に設定します。
   - 操作: ナビゲーションウィンドウ⇨[パラメータ]⇨[ユニット情報]⇨[FX5-EIP]⇨[応用設定]⇨[モード設定]⇨[モード]⇨”オンラインモード”を選択

   パラメータを書き込み，CPUユニット(FX5-EIP)の電源OFF→ONまたはリセットをします。
7. 異常完了時は，シーケンサシステムのノイズ対策が十分にされているか確認し，再度ハードウェアテストを実行してください。再度異常完了となった場合は，FX5-EIPのハードウェア異常の恐れがあります。最寄りの三菱電機システムサービス株式会社または当社の支社，代理店にご相談ください。

##### EtherNet/IP機器と通信ができない (9.5 / 印刷 p.184 / 原本 p.186)

EtherNet/IP機器と通信ができない場合は，下記の項目を確認してください。解決できない場合は，ハードウェアテストを実施し，ハードウェアに異常がないか確認してください。(☞ 183ページ ハードウェアテスト)

| 確認項目 | 処置方法 |
|---|---|
| FX5-EIPのRUN LEDが消灯していないか。 | RUN LEDが消灯している場合，CPUユニットをリセットしてください。リセットしてもRUN LEDが点灯しない場合，ハードウェア異常の恐れがあります。FX5-EIPを交換し，接続しているEtherNet/IP機器を再起動してください。 |
| Ethernetケーブルが正しく接続されているか。 | Ethernetケーブルを接続し直してください。 |
| EtherNet/IP機器が，FX5-EIPの通信機能(サイクリック通信，メッセージ通信)に対応しているか。 | EtherNet/IP機器の仕様を確認してください。 |
| EtherNet/IP機器の電源がONになっているか。 | EtherNet/IP機器の電源がONになっていない場合，電源をONにしてください。 |
| EtherNet/IP機器，産業用スイッチなどでエラーが発生していないか。 | EtherNet/IP機器，産業用スイッチなどでエラーが発生している場合，各機器のマニュアルを確認して処置してください。 |
| EtherNet/IP機器のIPアドレス設定は間違っていないか。 | PINGテストにてEtherNet/IP機器との接続を確認してください。(☞ 182ページ PINGテスト) |
| FX5-EIPのモード設定が，”オンラインモード”以外になっていないか。 | FX5-EIPのモード設定を”オンラインモード”に設定してください。 |
| イニシャル処理が正常完了しているか。<br>(‘ユニットREADY’(Un￥G34.F)および’通信READY’(Un￥G35.F)を確認してください。) | 'ユニットREADY'(Un￥G34.F)と'通信READY'(Un￥G35.F)がONしてから通信を開始してください。 |
| ’EtherNet/IP通信起動状態’(Un￥G273) が1(起動中)になっているか。 | • ’EtherNet/IP通信起動要求’(Un￥G272)が0以外(起動要求)になっていることを確認してください。<br>• ユニット拡張パラメータが書き込まれていない場合は書き込んでください。<br>• ’サイクリック通信一時停止指定’(Un￥G1360～Un￥G1367)がすべて0(サイクリック一時停止要求なし)となっていることを確認してください。 |
| 正常に通信しているコネクションがタイムアウトエラーになっていないか。 | EtherNet/IP機器によっては，正常に通信しているコネクションに対して，Encapsulation Inactivity Timeoutで設定した時間経過後に切断されてタイムアウトエラーが発生することがありますので，Encapsulation Inactivity Timeoutの設定を”0(無効)”にしてください。(☞ 257ページ TCP/IP Interface) |
| ターゲットのEtherNet/IP機器に対して，現在通信中のコネクション数が，消費コネクション数の最大値になっていないか。 | • FX5-EIPがターゲットの場合，通信を行うコネクション数が消費コネクション数の最大値以下となるようシステム構成を見直してください。*1<br>• FX5-EIPがオリジネータの場合，通信を行うコネクション数が，自ノードを含めて消費コネクション数の最大値以下となるようシステム構成を見直してください。 |
| ネットワーク上にIPアドレスの重複が起こっていないか。 | • IPアドレス重複ノードがネットワーク上に存在した場合，正常に通信が開始できなくなるため，IPアドレスの重複ノードをネットワークから外してください。<br>• 通信中にIPアドレスの重複が発生した場合，産業用スイッチがIPアドレス重複ノードに対して回線データを中継した結果，回線データが一時的に届かなくなるまたは通信が停止する場合があります。IPアドレスの重複ノードをネットワークから外しても通信が再開しない場合は自ノードをつなぎなおしてください。 |
| IPフィルタ設定で誤って相手機器のIPアドレスからの通信を遮断していないか。 | 相手機器のIPアドレスに対して通信を許可するようIPフィルタ設定のパラメータを変更してください。 |

*1 FX5-EIPで利用しているコネクション数は，’消費コネクション数’(Un￥G110116)で確認できます。

##### EtherNet/IP機器が検出できない (9.5 / 印刷 p.188 / 原本 p.190)

EtherNet/IP機器検出機能を利用した際，ネットワーク上に存在するはずの機器を検知できない場合は，下記の項目を確認してください。

| 確認項目 | 処置方法 |
|---|---|
| 検出対象となるEtherNet/IP機器の起動が完了しているか。 | • 検出対象となるEtherNet/IP機器の起動が完了していることを確認してください。<br>• 検出対象となるEtherNet/IP機器がFX5-EIPの場合，FX5-EIPのRUN LEDが点灯していることを確認してください。 |
| 検出対象となるEtherNet/IP機器が通信可能な状態か。 | • 検出対象となるEtherNet/IP機器がリンクアップしていることを確認してください。<br>• 検出対象となるEtherNet/IP機器がFX5-EIPの場合，’EtherNet/IP通信起動状態’(Un￥G273)が”1: 起動中”であることを確認してください。<br>• 検出対象となるEtherNet/IP機器がFX5-EIP以外の場合，EtherNet/IP通信が可能な状態になっていることを相手機器のマニュアルなどで確認してください。 |
| 検出対象となるEtherNet/IP機器はブロードキャストフレームが届く範囲にいるか。 | • 検出対象となるEtherNet/IP機器がFX5-EIPとは別ネットワークに属していないか確認してください。<br>• FX5-EIPと検出対象となるEtherNet/IP機器の間でブロードキャストフレームが届く設定になっていることを確認してください。産業用スイッチなどの設定により，ブロードキャストフレームが遮断されていないことを確認してください。 |
| 回線負荷が高くなっていないか。 | 回線負荷が高くなっていないか確認してください。回線負荷が高くなっている場合，検出用フレームが消失したり，相手機器が応答できなかったりする場合があります。 |
| CPUユニットやEtherNet/IP機器にエラーが発生していないか。 | • FX5-EIP，およびFX5-EIPを管理するCPUユニットに中度，重度のエラーが発生していないかを確認してください。エラーが発生している場合，エラーの原因を取り除いてください。<br>• 検出対象となるEtherNet/IP機器でエラーが発生していないかを確認してください。エラーが発生している場合，エラーの原因を取り除いてください。 |
| 検出対象となるEtherNet/IP機器はListIdentityコマンドに対応しているか。 | 検出対象となるEtherNet/IP機器がFX5-EIP以外の場合，ListIdentityコマンドに対応したEtherNet/IP機器であるかを相手機器のマニュアルなどで確認してください。 |
| 本機能を実行中に’EtherNet/IP通信起動状態’(Un￥G273)やCPUユニットの状態が変化したか。 | • EtherNet/IP機器の自動検出を実行中に，’EtherNet/IP通信起動要求’(Un￥G272)を操作していないかを確認してください。操作していた場合，やり直してください。<br>• EtherNet/IP機器の自動検出を実行中に，CPUユニットの状態がRUN⇨STOPに変化していないかを確認してください。変化していた場合，やり直してください。 |
