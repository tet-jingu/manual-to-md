# README - このフォルダの使い方

このフォルダは `MR-J4-_B_(-RJ) サーボアンプ技術資料集.pdf`(三菱電機 汎用ACサーボ MELSERVO-J4、SSCNETⅢ/Hインタフェース、全702ページ・全17章+付録)を、プロジェクトナレッジに常駐させるための参照用Markdownに変換したものです。

> 原本PDFは `manual-to-md` フォルダ直下にあります。編集・移動しないでください。

## 変換方針

当初は「設計に関係する章のみ」を対象としていましたが、ユーザーの依頼により方針を変更し、**第1章より前のフロントマター(p.1-17: 安全上のご注意・目次)を除く全章・付録**を対象としました。対象章の中身は**全文収録**します(保証・PL文言を含め、選択的な除外は行いません)。

## 参照上の注意

各ファイルは、表・ビット/パラメータ定義・プログラム例・機能説明・ON/OFFタイミング・注意事項を原文のまま全文転記しています。ただし、**同一構成図が形名バリエーションごとに繰り返される箇所**(例: 1.2節の機能ブロック図、1.8節の周辺機器構成図)は、図中の注記・接続先など内容面ではすべて残しつつ、バリエーション間で完全に重複する注記文だけを1箇所にまとめて記載しています(注記の文言自体は省略していません)。

第17章と付録は分量が大きいため節単位で分割変換し、後で1ファイルに結合しました。結合時に原本PDFと突き合わせて境界部分の欠落・重複を点検し、欠落1箇所(17.1.9(4)(b)の一部)は原本画像を目視のうえ補完、重複1箇所(17.1.9(5)〜(6)境界)は統合済みです。

設計判断の最終確認は、必ず原本PDFの該当ページで行ってください。
