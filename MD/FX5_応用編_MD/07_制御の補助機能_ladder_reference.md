## 7 制御の補助機能 (7章 / 原本 p.216)

本章では，主機能に機能を付加したり，組み合わせて使用する「補助機能」の詳細や使い方について説明しています。
補助機能には，機械原点復帰固有の補助機能や，制御の補正など全般的に関わる機能など，さまざまな機能があります。これらの補助機能を使うことで，より適正な，きめ細かい制御を行うことができます。
各補助機能は，パラメータの設定やプログラムの作成などによって，主機能と共に使用します。各補助機能の設定や実行手順をよくお読みになり，必要な設定を行ってください。

## 7.1 補助機能の概要 (7.1 / 原本 p.216-217)

「補助機能」は，主機能を実行する際，制御の補正，制限，機能の付加などを行う機能です。これらの補助機能は，パラメータの設定や，エンジニアリングツールからの操作，補助機能用のプログラムなどによって実行します。

## 7.2 機械原点復帰固有の補助機能 (7.2 / 原本 p.218-224)

機械原点復帰固有の補助機能には「原点復帰リトライ機能」，「原点シフト機能」があります。各機能は，パラメータの設定によって実行されます。

### 原点復帰リトライ機能[FX5-SSC-S] (7.2 / 原本 p.218-221)

位置決め制御中にワークが原点を越えてしまっていた場合など，ワークの位置によっては機械原点復帰を行っても原点方向にワークが動かないことがあります。このような場合，通常はJOG運転などで近点ドグの手前にワークを移動させて，再度，機械原点復帰を始動することになりますが，原点復帰リトライ機能を使うことで，ワークがどこにあっても，機械原点復帰を行うことができます。

#### 制御内容 (7.2 / 原本 p.218-220)

原点復帰リトライ機能の動作を以下に示します。

##### ワークが上下限リミットの範囲内にある場合の原点復帰リトライ動作 (7.2 / 原本 p.218)

【図】ワークが上下限リミットの範囲内にある場合の原点復帰リトライ動作(原本 p.218)
- 速度波形(横軸右向き): 1.(機械原点復帰始動)で原点復帰方向(図の右方向)へ加速・定速移動 → 2.(ハードウェアリミットスイッチのリミット信号OFF状態の開始位置)で減速 → 3.で停止
- 3.から逆方向(図の左方向，軸の下側の波形)へ加速・定速で移動 → 4.(近点ドグON区間の左端，近点ドグOFF)で減速 → 5.で停止
- 5.から再び原点復帰方向へ加速・定速 → 近点ドグONで減速しクリープ速度 → 近点ドグOFF後に一度停止し，再度動き始めて零点信号で停止 → 6.機械原点復帰完了
- 近点ドグ: ON区間(網掛け)を図示。図中注記「ON」
- ハードウェアリミットスイッチ: 図中注記「リミット信号OFF状態」(2.～3.の区間の右側に斜線で図示)
- 零点信号: 2個のパルス(2個目の位置が6.)

1. 機械原点復帰始動により"[Pr.44]原点復帰方向"へ移動を開始する。
2. リミット信号OFF検出により減速する。
3. リミット信号OFF検出で停止後，"[Pr.46]原点復帰速度"で"[Pr.44]原点復帰方向"と逆方向に移動する。
4. 近点ドグOFFで減速する。
5. 近点ドグOFFで停止後，"[Pr.44]原点復帰方向"へ機械原点復帰を行う。(原点復帰方式によってはエンコーダの零点を最低1回は通過する必要があります。)
6. 機械原点復帰完了。

##### ワークが上下限リミットの範囲外にある場合の原点復帰リトライ動作 (7.2 / 原本 p.219)

- 「ワーク → 原点」の方向が"[Pr.44]原点復帰方向"と同一方向の場合は，通常の機械原点復帰の動作を行います。"[Pr.44]原点復帰方向"を「0: 正方向」とした場合の例です。

【図】「ワーク → 原点」の方向が"[Pr.44]原点復帰方向"と同一方向の場合(原本 p.219)
- 機械原点復帰始動(ハードウェア下限リミットスイッチ付近)から[Pr.44]原点復帰方向(右方向)へ加速・定速移動 → 近点ドグONで減速しクリープ速度 → 近点ドグOFF後に一度停止し，再度動き始めて零点信号で停止 → 原点
- 図中の配置: ハードウェア下限リミットスイッチ(左端)，近点ドグ，ハードウェア上限リミットスイッチ(右端)，零点信号(2個のパルス)
- 移動範囲: ハードウェア下限リミットスイッチ～ハードウェア上限リミットスイッチの間

- 「ワーク → 原点」の方向が"[Pr.44]原点復帰方向"と逆方向の場合は，近点ドグOFFで減速停止し，"[Pr.44]原点復帰方向"に設定した方向へ機械原点復帰の動作を行います。"[Pr.44]原点復帰方向"を「0: 正方向」とした場合の例です。

【図】「ワーク → 原点」の方向が"[Pr.44]原点復帰方向"と逆方向の場合(原本 p.219)
- 機械原点復帰始動(ハードウェア上限リミットスイッチの右側，点線位置)から[Pr.44]原点復帰方向と逆方向(左方向，軸の下側の波形)へ加速・定速移動 → 近点ドグを通過し近点ドグOFFで減速停止
- 停止後，[Pr.44]原点復帰方向(右方向)へ加速 → 近点ドグONで減速しクリープ速度 → 近点ドグOFF後に一度停止し，再度動き始めて零点信号で停止 → 原点
- 図中の配置: ハードウェア下限リミットスイッチ，近点ドグ，ハードウェア上限リミットスイッチ，零点信号(2個のパルス)
- 移動範囲: ハードウェア下限リミットスイッチ～ハードウェア上限リミットスイッチの間

> **Point**
> - "[Pr.44]原点復帰方向"が「0: 正方向」の場合，原点復帰方向にあるリミットスイッチを上限リミットスイッチにしてください。
> - "[Pr.44]原点復帰方向"が「1: 負方向」の場合，原点復帰方向にあるリミットスイッチを下限リミットスイッチにしてください。
> - 上限／下限リミットスイッチの取付け位置を逆にした場合，原点復帰リトライ機能は正常に動作しません。なお，原点復帰動作に問題がある場合には，「回転方向選択／移動方向選択(PA14)」*1と上限／下限リミットスイッチの配線を見直してください。

*1 MR-J4(W)-Bの場合です。MR-J5(W)-Bでは，「移動方向選択(PA14)」になります。

##### 原点復帰リトライ時のドウェルタイム設定 (7.2 / 原本 p.220)

原点復帰リトライ機能では，"[Pr.57]原点復帰リトライ時ドウェルタイム"にて，上限／下限リミット信号の検出による逆転動作および近点ドグOFFで停止した後の機械原点復帰実行時にドウェルタイムを機能させることができます。
"[Pr.57]原点復帰リトライ時ドウェルタイム"が有効になるのは，下図の「A」と「B」の位置で停止したときです。(AとBの位置のドウェルタイムは同一の値で動作します。)

【図】原点復帰リトライ時のドウェルタイム(原本 p.220)
- 機械原点復帰始動 → [Pr.44]原点復帰方向(右方向)へ加速・定速移動 → リミット信号OFF(ハードウェアリミットスイッチ)で減速し「A」で停止(図中注記「リミット信号検出による停止」)
- A から逆方向へ移動(図中注記「リミット信号検出後の逆転動作」) → 近点ドグを通過し「B」で停止(図中注記「近点ドグOFFによる停止」)
- B から原点復帰方向へ再度移動(図中注記「機械原点復帰再実行」) → 近点ドグONで減速しクリープ速度 → 近点ドグOFF後に一度停止し，再度動き始めて零点信号で停止 → 原点
- 図中の信号: 近点ドグ(ON区間を網掛け)，リミット信号OFF(ハードウェアリミットスイッチ，斜線)，零点信号(1個のパルス)

### 電子ギア機能 (7.3 / 原本 p.226-232)

「電子ギア機能」は，シンプルモーションユニット／モーションユニットに設定したパラメータによって，実際の機械移動量とサーボアンプへ出力するパルス数の調整を行う機能です。
「電子ギア機能」には，[A]～[C]に示す3つの機能があります。

- [C] 「電子ギア」を調節することにより，指令移動量と実際の移動量の機械系の誤差を補正する。

#### 電子ギアの基本的な考え方 (7.3 / 原本 p.226-231)

電子ギアとは，プログラムで指令した移動量どおりに機械が動くようにするために，モータを何回転(何パルス分回転)させればよいのか決定する項目です。

【図】電子ギアの構成(原本 p.226)
- シンプルモーションユニット／モーションユニットの枠内: 指令値 →(制御単位)→ 電子ギア「AP / (AL × AM)」
- 電子ギア →(pulse)→ サーボアンプ →(pulse)→ モータ(M) → 減速機 → 機械(ボールネジ上のテーブル)
- モータのエンコーダ(ENC)から pulse がフィードバックパルスとしてサーボアンプへ戻る。サーボアンプから電子ギアへ pulse が戻る(逆向き矢印)

電子ギアの考え方の基本は，次式で表されます。
[Pr.2](モータ1回転あたりのパルス数) ＝ AP
[Pr.3](モータ1回転あたりの移動量) ＝ AL
[Pr.4](単位倍率) ＝ AM
単位倍率を考慮したモータ1回転あたりの機械の移動量 ＝ ΔSと置く。

```
電子ギア ＝ AP / ⊿S ＝ AP / (AL × AM)  ・・・(1)
```

となり，この関係式が成立するような，AP，AL，AMの値を設定します。
しかし，AP，AL，AMに設定できる数値には設定可能な範囲があるため，上記の関係式から計算(約分)した値をAP，AL，AMの設定範囲に入るようにする必要があります。

##### ボールネジ＋減速機の場合 (7.3 / 原本 p.227-228)

例
[FX5-SSC-S]
ボールネジピッチ10 mm，モータHG-KR(4194304 pulse/rev)，減速比9/44の場合

【図】ボールネジ＋減速機の構成(原本 p.227)
- モータ(M) → 減速機(減速比 9/44) → ボールネジ上のテーブル(機械)

まず，モータが1回転(AP)したときに，負荷(機械)が何 mm移動するか(ΔS)を求めます。
AP(モータ1回転あたりのパルス数) ＝ 4194304 [pulse]
ΔS(モータ1回転あたりの機械の移動量) ＝ ボールネジピッチ × 減速比 ＝ 10 [mm] × 9/44 ＝ 10000.0 [μm] × 9/44*1

*1 制御単位がmmの場合，最小指令単位は0.1 μmとなります。

> **Point**
> モータHK-KT(67108864 pulse/rev)を制御する場合は，MR-J5(W)-Bのサーボパラメータを以下のように設定します。
> 電子ギア分子(PA06): 16
> 電子ギア分母(PA07): 1
> したがって，AP(モータ1回転あたりのパルス数)は下記の値となります。
> AP(モータ1回転あたりのパルス数) = 67108864 [pulse] × 1/16 = 4194304 [pulse]
>
> 【図】MR-J5(W)-B使用時の構成(原本 p.227)
> - シンプルモーションユニットの枠内: 指令値 →(制御単位)→ AP / (AL × AM)
> - AP / (AL × AM) →(pulse)→ サーボアンプ(電子ギア分子(PA06): 16，電子ギア分母(PA07): 1) →(pulse×16)→ モータ(M) → 減速比 9/44 → 機械
> - エンコーダ(ENC)から pulse がフィードバックパルスとしてサーボアンプへ戻り，サーボアンプから pulse/16 がシンプルモーションユニットへ戻る(矢印ラベル「制御単位」「pulse/16」)

#### 誤差補正方法 (7.3 / 原本 p.232)

パラメータに設定した「電子ギア」によって位置制御を行った場合，指令移動量(L)と実際の移動量(L')に誤差が生ずる場合があります。シンプルモーションユニット／モーションユニットでは，この誤差を電子ギアで調節して補正します。
誤差補正を行うために使用する「誤差補正量」を以下のように定義します。

```
誤差補正量 ＝ 指令移動量(L) / 実際の移動量(L')
```

誤差補正量を盛り込んだ電子ギアは以下のようになります。

```
AP / (AL × AM) × L / L' ＝ AP' / (AL' × AM')
```

【図】誤差補正量を盛り込んだ電子ギア(原本 p.232)
- 上段(補正前): シンプルモーションユニット／モーションユニットの枠内で 指令値 →(制御単位)→ AP / (AL × AM) → L / L' →(pulse)→ サーボアンプ。L / L' の図中注記「誤差が生じない場合は1(通常)」
- 下向き矢印の図中注記「誤差分を見込んだ電子ギア」
- 下段(補正後): シンプルモーションユニット／モーションユニットの枠内で 指令値 →(制御単位)→ AP' / (AL' × AM') →(pulse)→ サーボアンプ

##### 計算例 (7.3 / 原本 p.232)

[条件]
1回転あたりのパルス数(AP): 4194304 [pulse]
1回転あたりの移動量(AL) : 5000.0 [μm]
単位倍率(AM) : 1

[位置決め結果]
指令移動量(L) : 100 [mm]
実移動量(L') : 101 [mm]

[補正値]

```
AP / (AL × AM) × L / L' ＝ 4194304 / (5000.0 × 1) × 100 / 101 ＝ 4194304(AP') / (5050(AL') × 1(AM'))
```

### 近傍通過機能 (7.3 / 原本 p.233-234)

補間制御を使った連続軌跡制御を行う場合は，近傍通過機能の動作を行います。
「近傍通過機能」は，補間制御による連続軌跡制御を行う場合，位置決めデータの切り換わり時に発生する機械振動を抑える機能です。

[近傍通過]
連続して実行されている各位置決めデータの最後に生じる移動量の余りを次の位置決めデータに受け渡します。位置合わせを行わないことにより，出力速度の低下をなくし，速度変更時に発生する機械振動を抑えることができます。
位置合わせを行わないため，"[Da.6]位置決めアドレス／移動量"に設定した位置の近傍を通過するような軌跡で制御されます。

#### 制御内容 (7.3 / 原本 p.233)

2軸直線補間制御で連続軌跡制御を行った場合の軌跡を以下に示します。

##### 近傍通過の軌跡 (7.3 / 原本 p.233)

【図】近傍通過の軌跡(原本 p.233)
- 軌跡図: 位置決めデータNo.3の軌跡(左下から右上へ) → 位置決めデータNo.4の軌跡(右方向)。No.3の終点である[Da.6]位置決めアドレス(点線の先端)には到達せず，その手前(丸で囲んだ部分)からNo.4の軌跡へ移る(点線はアドレスどおりの経路)
- 速度波形(V-t): 位置決めデータNo.3 と 位置決めデータNo.4 の区間を通して台形。No.3とNo.4の境界で速度は一定のまま
- 図中注記: 「速度の落込みは発生しない」(軌跡図の丸部分と速度波形の境界を指す)

#### 制御上の注意事項 (7.3 / 原本 p.234)

- 連続軌跡制御を行っているとき，位置決めデータで指定した移動量が小さい場合に，出力速度が指令速度に達しないことがあります。
- 補間運転時は移動方向のチェックを行っていないため，移動方向が変わっても減速停止しません。(下図参照)このため，移動方向が変わると急反転することがあります。急反転を回避する場合は，通過点の位置決めデータを連続軌跡制御「11」にしないで，連続位置決め制御「01」にしてください。

- 位置決めデータNo.1: 右上方向へ移動(相手軸は正方向) → 位置決めデータNo.2: 右下方向へ移動(相手軸は負方向)
- 図中注記: 「位置決めデータNo.1・・・・・連続軌跡制御」

【図】基準軸の動作(原本 p.234)

##### 補間の相手軸の動作 (7.3 / 原本 p.234)

【図】補間の相手軸の動作(原本 p.234)

#### ソフトウェアストロークリミットチェック上の注意事項 (7.4 / 原本 p.242-243)

- 「ソフトウェアストロークリミット機能」を正常に機能させるには，事前に機械原点復帰を実行する必要があります。
- 補間制御時は，基準軸と補間軸すべての現在値についてストロークリミットチェックを行います。いずれか1つの軸のみがエラーとなった場合でも，すべての軸が始動しません。
- 2軸円弧補間制御時は，制御の途中で"[Pr.12]ソフトウェアストロークリミット上限値"／"[Pr.13]ソフトウェアストロークリミット下限値"を超えることがあります。この場合，ストロークリミットを超えても減速停止を行いません。ストロークリミットを超える可能性がある場合は，必ず，外部にリミットスイッチを設置してください。

例

【図】2軸円弧補間制御でストロークリミットを超える例(原本 p.243)
- 縦軸: 軸1，横軸: 軸2。始点アドレスから円弧アドレス([Da.7])を経て終点アドレス([Da.6])へ円弧を描く。
- 軌跡の頂部が「軸1のストロークリミット」(破線)を超えている。図中注記「減速停止しません」。

> **Point**
> 2軸円弧補間制御時は，下記のアドレスについてソフトウェアストロークリミットチェックを行っています。(ただし，"[Da.7]円弧アドレス"は，補助点指定の2軸円弧補間制御時のみ)
> 現在値／終点アドレス([Da.6])／円弧アドレス([Da.7])

- 連続軌跡制御時に，エラーが検出された場合，エラーとなった位置決めデータの直前の位置決めデータの実行を完了した時点で，即停止します。

### ハードウェアストロークリミット機能 (7.4 / 原本 p.245-248)

> **警告**
> - ハードウェアストロークリミットの配線が必要な場合は，必ず負論理で配線し，b接点を使用してください。正論理に設定し，a接点を用いますと，重大な事故が発生する可能性があります。

「ハードウェアストロークリミット機能」は，物理的な可動範囲の上限／下限にリミットスイッチを設置し，リミットスイッチからの信号入力で制御を停止(減速停止)させる機能です。
物理的な可動範囲の上限／下限に達する前に制御を停止させることにより，機器の破損を防止します。
ハードウェアストロークリミットには，以下信号を使用できます。(→451ページ [Pr.116]FLS信号選択，[Pr.117]RLS信号選択，[Pr.118]DOG信号選択，[Pr.119]STOP信号選択)
- サーボアンプの外部入力信号
- CPU経由外部入力信号(シンプルモーションユニット／モーションユニットのバッファメモリ)
- CC-Link IE TSNネットワーク上の入力信号(リンクデバイス)[FX5-SSC-G]

### 速度変更機能 (7.5 / 原本 p.253-257)

### オーバーライド機能 (7.5 / 原本 p.258-260)

「オーバーライド機能」は，実行するすべての制御について，指令速度を指定した割合で変更する機能です。
速度を変更する割合(%)を"[Cd.13]位置決め運転速度オーバーライド"に設定することによって，速度変更を実行します。
"[Cd.13]位置決め運転速度オーバーライド"の設定範囲は機種ごとに異なります。

| 機種 | "[Cd.13]位置決め運転速度オーバーライド"の設定範囲 |
|---|---|
| FX5-SSC-S | 1～300% |
| FX5-SSC-G | バージョン1.001以前: 1～300%<br>バージョン1.002以降: 0～300% |

#### 制御内容 (7.5 / 原本 p.258)

オーバーライド機能の動作を以下に示します。
- "[Md.22]送り速度"はオーバーライド機能によって変更された値をモニタしています。
- "[Cd.13]位置決め運転速度オーバーライド"に「100(%)」を設定した場合は，速度は変化しません。
- "[Cd.13]位置決め運転速度オーバーライド"に「100(%)」未満の値を設定し，"[Md.22]送り速度"が「1」未満になる場合は，ワーニング「最低速度未満」(ワーニングコード: 0904H[FX5-SSC-S]，0D04H[FX5-SSC-G])となり，そのときの速度単位の「1」で制御されます。
- 位置制御中，速度・位置切換え制御，および位置・速度切換え制御の位置制御中に，オーバーライド機能によって速度変更を行う場合，変更を行うだけの残距離が確保できないときは，変更できる速度で動作します。
- オーバーライド機能によって変更された速度が"[Pr.8]速度制限値"以上の場合は，ワーニング「速度制限値オーバー」(ワーニングコード: 0991H[FX5-SSC-S]，0D51H[FX5-SSC-G])となり，速度は"[Pr.8]速度制限値"で制御され，"[Md.39]速度制限中フラグ"がONします。

[FX5-SSC-G]
- "[Cd.13]位置決め運転速度オーバーライド"に「0(%)」を設定した場合，速度0となり，速度変更0フラグ([Md.31]ステータス: b10)が「1」となります。このとき，ワーニング「最低速度未満」(ワーニングコード: 0D04H)は発生しません。

### 加減速時間変更機能 (7.5 / 原本 p.261-263)

「加減速時間変更機能」は，「速度変更機能」，「オーバーライド機能」により速度変更を行う場合，速度変更時の加減速時間を任意の値に変更する機能です。
通常(加減速時間の変更を行わない場合)の速度変更では，あらかじめパラメータに設定した加減速時間([Pr.9]，[Pr.10]，[Pr.25]～[Pr.30]の値)を位置決めデータの[Da.3]，[Da.4]に設定し，その加減速時間で制御されますが，変更後の加減速時間([Cd.10]，[Cd.11])を制御データに設定し，加減速時間変更許可指令([Cd.12]速度変更時の加減速時間変更値許可／不許可)によって加減速時間変更を許可した状態で速度変更を実行すると，変更後の加減速時間([Cd.10]，[Cd.11])で速度変更を実行します。

#### 制御内容 (7.5 / 原本 p.261)

以下の2項目を設定後，速度変更を行うことにより，速度変更時の加減速時間が変更されます。

- 「変更後の加減速時間」が有効となったあとに，加減速時間の変更を不許可に設定しても，「変更後の加減速時間」が有効となった位置決めデータは，継続して「変更後の加減速時間」で制御されます。(次の位置決めデータは，予めパラメータに設定された加減速時間で制御されます。)

#### 制御内容 (7.5 / 原本 p.265-266)

軸制御データのトルク変更値(正転トルク変更値，逆転トルク変更値)は常時変更可能で，トルク変更値を書き込んだ時点で変更した値でトルク制限を行います。

### 目標位置変更機能 (7.5 / 原本 p.268-271)

「目標位置変更機能」は，位置制御中(1軸直線制御)の目標位置を任意のタイミングで，新たに指定した目標位置に変更する機能です。また，目標位置変更と同時に指令速度の変更も可能です。
変更後の目標位置および指令速度は直接バッファメモリに設定し，"[Cd.29]目標位置変更要求フラグ"によって，目標位置変更を実行します。

#### 制御内容 (7.5 / 原本 p.268)

目標位置変更機能の制御内容を以下に示します。

##### 始点からの位置が位置決めアドレスより変更後アドレスの方が遠い場合 (7.5 / 原本 p.268)

【図】始点からの位置が位置決めアドレスより変更後アドレスの方が遠い場合(原本 p.268)
- 定速運転中に目標位置変更要求(パルス)。
- 本来の減速線(破線)は位置決めアドレスで停止。変更後は定速を継続し，変更後アドレスで停止。

##### アドレス変更と同時に速度が変更される場合 (7.5 / 原本 p.268)

【図】アドレス変更と同時に速度が変更される場合(原本 p.268)
- 変更前速度で定速運転中に目標位置変更要求(パルス) → 変更後速度まで加速して定速 → 変更後アドレスで停止。
- 破線: 変更前速度のまま位置決めアドレスで停止する場合。

##### 運転の向きが変化する場合 (7.5 / 原本 p.268)

【図】運転の向きが変化する場合(原本 p.268)
- 正方向定速運転中に目標位置変更要求(パルス) → 減速して折り返し位置で停止 → 逆方向に加速・定速・減速して変更後アドレスで停止。
- 破線: 変更しなかった場合に位置決めアドレスで停止する波形。

#### 制御上の注意事項 (7.5 / 原本 p.269-270)

- 運転の向きが変化する場合，位置決めの移動方向が反転する位置(折り返し位置)で一旦停止してから，変更後アドレスへの位置決めを行います(→266ページ 運転の向きが変化する場合)。この折り返し位置は，目標位置変更要求時の位置に減速停止に必要な距離を加えた位置です。

【図】折り返し位置(原本 p.269)
- 目標位置変更要求時の位置から減速し，折り返し位置で反転。
- 凡例: 灰色 = 減速停止に必要な距離(目標位置変更要求時の位置～折り返し位置の減速部分)

- 目標位置変更要求時に変更後アドレスが移動方向側にある場合でも，変更後アドレスまでの移動量が減速停止に必要な距離よりも小さい場合，運転の向きが反転します。その際は，目標位置変更要求を早めて変更後アドレスまでの移動量を大きくするか，減速時間を短くして減速停止に必要な距離を小さくするなどの調整を行ってください。

【図】変更後アドレスまでの移動量が減速停止に必要な距離よりも小さい場合(原本 p.269)
- 凡例: 灰色 = 減速停止に必要な距離(斜線の部分を含む)，斜線 = 変更後アドレスまでの移動量
- 変更後アドレスが折り返し位置より手前にあるため，折り返し位置で反転して変更後アドレスへ戻る。

【図】目標位置変更要求を早める場合(原本 p.269)
- 凡例: 灰色 = 減速停止に必要な距離，斜線 = 変更後アドレスまでの移動量(灰色の部分を含む)
- 目標位置変更要求を早めたことで，変更後アドレスまでの移動量が減速停止に必要な距離より大きくなる。点線は元の(要求が遅い場合の)波形で折り返し位置に至るもの。

【図】減速時間を短くする場合(原本 p.269)
- 凡例: 灰色 = 減速停止に必要な距離，斜線 = 変更後アドレスまでの移動量(灰色の部分を含む)
- 減速時間を短く(傾きを急に)することで減速停止に必要な距離が小さくなり，変更後アドレスで停止。点線は元の減速時間の波形で折り返し位置に至るもの。

- 指令速度を変更する場合，速度制限値を超える設定をした場合はワーニング「速度制限値オーバー」(ワーニングコード: 0991H[FX5-SSC-S]，0D51H[FX5-SSC-G])となり，変更後の速度は速度制限値となります。また，指令速度変更によって目標値までの残距離が確保できなくなる場合はワーニング「残距離不足」(ワーニングコード: 0994H[FX5-SSC-S]，0D54H，0D55H[FX5-SSC-G])となります。
- 以下の場合，目標位置変更要求は無視され，ワーニング「目標位置変更不可」(ワーニングコード: 099BH[FX5-SSC-S]，0D5BH～0D61H[FX5-SSC-G])となります。

> - 補間制御中
> - 目標位置変更値(アドレス)がソフトウェアストロークリミット範囲外
> - 停止要因による減速停止中
> - 運転パターンが連続軌跡制御の位置決めデータ実行時
> - 速度変更0フラグ([Md.31]ステータス: b10)がONしているとき

- 指令速度を変更した場合，カレント速度も変更されます。連続した位置決めで次の位置決め速度がカレント速度を使用するような場合は，次の位置決め運転は速度変更値での運転となります。これに対して，次の位置決めデータで速度が設定されている場合はその速度がカレント速度となりカレント速度で運転を行います。
- 位置制御で自動減速中に目標位置変更要求があり，かつ移動方向が反転する場合には，一旦停止後に変更後アドレスへの位置決め制御を行います。また，移動方向が反転しない場合には，再度指令速度まで加速して変更後アドレスへの位置決めを行います。
- "[Md.48]減速開始フラグ"がON中に目標位置変更を行って，再び定速になったり出力が反転しても減速開始フラグはONのままとなります。(→299ページ 減速開始フラグ機能)
- 単位degree時のABS直線1に対して目標位置変更を行うと，移動方向が反転しない場合でも，一旦減速停止した後に変更後アドレスへの位置決めを行うことがあります。

> **制約事項**
> 連続して目標位置変更を行う場合は，目標位置変更と目標位置変更の間隔が10 ms以上となるようにしてください。また，目標位置変更後の速度変更，オーバーライドや，速度変更後，オーバーライド後の目標位置変更も同様に10 ms以上の間隔をあけて行ってください。

## 7.6 始動に関連する機能 (7.6 / 原本 p.272-273)

始動に関連する機能には「先読み始動機能」があります。機能は，パラメータの設定やプログラムの作成・書込みによって実行します。

### 先読み始動機能 (7.6 / 原本 p.272-273)

「先読み始動機能」は，実行禁止フラグONの状態で位置決め始動要求を行うと，実行禁止フラグONの間はサーボ起動を行わず，実行禁止フラグOFFを検出すると，演算周期以内にサーボ起動を開始する機能です。軸が待機状態のうちに始動開始要求を行い，軸を動作させるタイミングで実行禁止フラグをOFFします。

#### 制御内容 (7.6 / 原本 p.272)

先読み始動機能は，実行禁止フラグ([Cd.183])ONの状態で位置決め始動信号をONすることにより行います。実行禁止フラグONの状態で位置決め始動を行うと位置決めデータ解析までは行いますが，サーボ起動は行いません。実行禁止フラグONの間は"[Md.26]軸動作状態"は「5: 解析中」のままとなります。実行禁止フラグがOFFすると，演算周期以内にサーボ起動を開始し，"[Md.26]軸動作状態"は各制御方式に合わせた状態(位置制御中，速度制御中など)となります。(下図参照)

##### 動作例 (7.6 / 原本 p.272)

【図】先読み始動機能の動作例(原本 p.272)
- 速度波形(V-t): 前回の位置決めが減速停止 → 停止中(速度0)の区間 → 実行禁止フラグOFF後に加速して再び定速
- [Cd.184]位置決め始動: 初期ON。前回位置決めの停止(BUSY OFF)を受けてOFF → 再度ON(新たな始動)
- [Cd.183]実行禁止フラグ: 初期OFF。[Cd.184]の再ONより前にON → 図中注記「位置決め始動タイミング」の時点でOFF
- [Md.141]BUSY: 初期ON → 前回位置決め停止でOFF → 実行禁止フラグOFFから「演算周期以内」にON(このとき速度立上り開始)
- [Md.26]軸動作状態: 位置制御中 → 待機中 → ([Cd.184]再ONで)解析中 → (実行禁止フラグOFFから演算周期以内に)位置制御中
- 図中区間: [Cd.184]ON後に「位置決めデータ解析」→「実行禁止フラグOFF待ち」。[Cd.184]ONから実行禁止フラグOFFまでが「Ta」，実行禁止フラグOFFからBUSY ONまでが「演算周期以内」

#### 制御上の注意事項 (7.6 / 原本 p.272)

- 位置決めデータ解析に要する時間は最大1演算周期です。
- 位置決めデータ解析後，実行禁止フラグOFF待ち状態となります。実行禁止フラグOFF待ち状態に位置決めデータの変更を行った場合，変更データは反映されません。位置決めデータの変更を行う場合は位置決め始動信号ONの前に行ってください。
- 位置決め始動信号がONしてから，位置決めデータ解析が完了する前に実行禁止フラグがOFFされる(Ta < 始動時間，Ta:上図参照)場合，先読み始動機能は無効です。
- "[Cd.3]位置決め始動番号"で，先読み始動機能により位置決め始動できるデータNo.はNo.1～600のみです。No.7000～7004，9001～9004を設定して先読み始動機能を行った場合は，エラー「始動番号範囲外」(エラーコード: 19A3H[FX5-SSC-S]，1AA3H[FX5-SSC-G])となります。
- 実行禁止フラグのONは，必ず位置決め始動信号と同時もしくは位置決め始動信号をONする前に行ってください。位置決め始動信号ON後，Taの間に実行禁止フラグをONしても先読み始動にならない場合があります。実行禁止フラグOFFの状態で位置決め始動後，実行禁止フラグをONしても先読み始動機能は無効です。(次の位置決め始動時に有効となります。)

[FX5-SSC-G]
- 絶対位置システムにおいてサーボアンプとの初回接続時，以下のいずれかの条件によりワーニング「原点データ不正」(ワーニングコード: 0D3CH)が発生し，原点復帰要求がONします。
  - ユニット内部のバックアップデータが破損している
  - サーボアンプの回転方向設定がバックアップデータのものと異なる
  - バックアップ時に原点復帰要求がONしていた
  - サーボアンプ側で絶対位置消失が発生している
  - HomeOffsetがバックアップデータのものと異なる
  - エンコーダ分解能がバックアップデータのものと異なる
  - サーボアンプの機種がバックアップデータのものと異なる
- サーボアンプの電子ギアにより切り捨てられた分の移動量は復元できません。
- サーボアンプで絶対位置を復元できない状態の場合，エラー「サーボアンプ電源投入時エンコーダ初期通信異常」(エラーコード: 1A7EH)となり，絶対位置を復元できません。サーボアンプの状態を確認し，再接続を実施することで絶対位置を復元できる場合があります。再接続時，原点復帰要求がONしている場合は，再度原点復帰を実施してください。

## 7.9 その他の機能 (7.9 / 原本 p.286-305)

### スキップ機能 (7.9 / 原本 p.286-288)

「スキップ機能」は，スキップ信号を入力した時点で実行中の位置決めデータの制御を減速停止し，次の位置決めデータを実行する機能です。
スキップはスキップ指令([Cd.37]スキップ指令)もしくは外部指令信号によって実行します。
「スキップ機能」は，位置決めデータを使った制御の場合に使用できる機能です。

#### 制御上の注意事項 (7.9 / 原本 p.287)

- 運転の最後でスキップ信号をONした場合は，減速停止して運転を終了します。
- 制御をスキップした場合(制御中にスキップ信号をONした場合)は，位置決め完了信号はONしません。
- ドウェルタイム中にスキップ信号をONした場合，残りのドウェルタイムを無視して，次の位置決めデータを実行します。
- 補間制御中に制御のスキップを行う場合は，基準軸のスキップ信号をONします。基準軸のスキップ信号をONすると，全軸とも減速停止し，基準軸の次の位置決めデータを実行します。
- Mコード出力がAFTERモードの場合MコードON信号はONしません。(この場合，Mコードは"[Md.25]有効Mコード"に格納されません。)
- 速度制御，位置・速度切換え制御では，スキップを行うことができません。
- Mコード信号がONしている状態でスキップ信号をONすると，Mコード信号がOFFするまで次データへの移行は行いません。

### Mコード出力機能 (7.9 / 原本 p.289-291)

「Mコード出力機能」は，実行中の位置決めデータに関連した補助作業(クランプ，ドリル回転，工具交換など)の指令を行うための機能です。
位置決め実行時にMコードON信号([Md.31]ステータス: b12)がONすると，Mコードと呼ばれる番号が"[Md.25]有効Mコード"に格納されます。
CPUユニットから，この"[Md.25]有効Mコード"を読み出して，補助作業の指令に使用します。Mコードは位置決めデータごとに設定することができます。(位置決めデータの設定項目"[Da.10]Mコード／条件データNo.／LOOP～LEND繰り返し回数"に設定します。)
また，「Mコード出力機能」では，Mコードを出力(格納)するタイミングを設定することができます。

#### MコードON信号の出力タイミング (7.9 / 原本 p.289)

「Mコード出力機能」では，Mコードを出力(格納)するタイミングを設定することができます。(Mコードは，MコードON信号がONされたとき，"[Md.25]有効Mコード"に格納されます。)
Mコードを出力するタイミングには，以下に示す「WITHモード」と「AFTERモード」の2種類があります。

##### WITHモード (7.9 / 原本 p.289)

位置決め開始時に，MコードON信号をONし，Mコードを"[Md.25]有効Mコード"に格納します。

例

【図】WITHモードのタイミング(原本 p.289)
- [Cd.184]位置決め始動・[Md.141]BUSY: OFF→ON，全位置決め終了でOFF
- MコードON信号([Md.31]ステータス: b12): 1つ目の位置決め(運転パターン01)開始と同時にON → [Cd.7]MコードOFF要求 0→1 でOFF → [Cd.7]は0に戻る。2つ目の位置決め(運転パターン00)開始と同時に再度ON → [Cd.7] 0→1→0 でOFF

*1 m1，m2は設定されているMコードを示す。

#### 制御上の注意事項 (7.9 / 原本 p.290)

- 補間制御時は基準軸のMコードON信号がONされます。
- "[Da.10]Mコード／条件データNo.／LOOP～LEND繰り返し回数"に「0」を設定すると，MコードON信号はONしません。(Mコードは出力されず，"[Md.25]有効Mコード"は前回出力された値が保持されます。)
- 位置決め始動時に，MコードON信号がONしている場合は，エラー「MコードON信号ON始動」(エラーコード: 19A0H[FX5-SSC-S]，1AA0H[FX5-SSC-G])となり，始動しません。
- "[Cd.190]シーケンサレディ "がOFFすると，MコードON信号をOFFし，"[Md.25]有効Mコード"に「0」を格納します。
- 連続軌跡制御の場合，位置決め動作時間が短いと，MコードON信号をOFFする時間が取れず，ワーニング「MコードON信号ON」(ワーニングコード: 0992H[FX5-SSC-S]，0D52H[FX5-SSC-G])となる場合があります。その場合は，その部分の位置決めデータの"[Da.10]Mコード／条件データNo.／LOOP～LEND繰り返し回数"に「0」を設定して，Mコードが出力しないようにすることにより，ワーニングを回避できます。
- 速度制御でAFTERモードの場合，Mコードは出力されずMコードON信号はONしません。
- "[Cd.3]位置決め始動番号"に「9003」を設定した現在値変更を行う場合，Mコード出力機能は無効となります。

### ティーチング機能 (7.9 / 原本 p.292-296)

「ティーチング機能」は，手動制御(JOG運転，インチング運転，手動パルサ運転)を使って位置合わせしたアドレスを，位置決めデータのアドレス("[Da.6]位置決めアドレス／移動量"，"[Da.7]円弧アドレス")に設定する機能です。

#### 制御内容 (7.9 / 原本 p.292)

##### ティーチングのタイミング (7.9 / 原本 p.292)

ティーチングは"[Md.141]BUSY"がOFFしているときに，プログラムを使って実行します。(手動制御中に，エラーやワーニングが発生した場合でも，軸がBUSYでなければティーチングを行うことができます。)

##### ティーチング可能なアドレス (7.9 / 原本 p.292)

ティーチング可能なアドレスは，原点を基準とした「送り現在値」([Md.20]送り現在値)です。インクリメント方式の位置決めに使用する「移動量」の設定はできません。また，ティーチング機能では，この「送り現在値」を位置決めデータの"[Da.6]位置決めアドレス／移動量"もしくは"[Da.7]円弧アドレス"に設定します。

【図】ティーチングされるアドレス(原本 p.292)

- 「送り現在値」B → 位置決めデータの [Da.7] 円弧アドレス

#### 制御上の注意事項 (7.9 / 原本 p.292)

- ティーチングを行う前に「機械原点復帰」を実行して，原点を確立しておく必要があります。(現在値変更などを行っていた場合，"[Md.20]送り現在値"は原点を基準とした絶対アドレスを示していない場合があります。)
- 手動制御によって移動できない位置(物理的にワークが移動できない位置)は，ティーチングを行うことはできません。(中心点指定の2軸円弧補間制御の場合などで，中心点がワークの可動範囲内にない場合は"[Da.7]円弧アドレス"のティーチングはできません。)
- フラッシュ ROMへは10万回まで書込み可能です。フラッシュ ROMへの書込みが10万回を超えると，フラッシュ ROMへの書込みができなくなる場合があります。(保証値は最大10万回)フラッシュ ROMへの書込みを行ったとき，エラー「フラッシュ ROM書込み回数エラー」(エラーコード: 1080H)になる場合は，連続でフラッシュ ROMへの書込みを行うプログラムになっていないか確認してください。

### 指令インポジション機能 (7.9 / 原本 p.297-298)

「指令インポジション機能」は，位置制御の自動減速時に停止位置までの残距離をチェックし，フラグを1にする機能です。
このフラグを「指令インポジションフラグ」と呼びます。指令インポジションフラグは，位置制御の完了を事前に示す前倒し信号として使用します。

#### 制御内容 (7.9 / 原本 p.297)

#### サーボON(サーボ動作可) (7.10 / 原本 p.307)

以下にサーボONの手順を示します。
1. サーボアンプのLED表示が下記の状態であることを確認する。("[Cd.191]全軸サーボON"の初期値は"OFF"です。)
   MR-J4(W)-B，MR-J5(W)-Bの場合[FX5-SSC-S]: "b_"
   MR-J5(W)-Gの場合[FX5-SSC-G]: "r_"
2. "[Cd.100]サーボOFF指令"に「0」を設定する。
3. "[Cd.191]全軸サーボON"をONする。

1. "[Cd.100]サーボOFF指令"に「1」を設定する。(サーボアンプのLED表示は，"c_"(MR-J4(W)-B，MR-J5(W)-Bの場合)または"r_"(MR-J5(W)-Gの場合)となります。)
   (そのあと，"[Cd.100]サーボOFF指令"に「0」を再び設定すると，サーボ動作可能状態になります。)
2. "[Cd.191]全軸サーボON"を"OFF"する。(サーボアンプのLED表示は，"b_"(MR-J4(W)-B，MR-J5(W)-Bの場合)または"r_"(MR-J5(W)-Gの場合)となります。)

> **Point**
> - サーボOFF中にサーボモータが外力で回った場合は，フォローアップ処理を行います。
> - サーボON/OFFは停止中(位置制御モード)に行ってください。位置制御モードの位置決め中，手動制御中，原点復帰中，速度制御モード中，トルク制御モード中および押当て制御モード中のサーボOFF要求は，無視されます。
> - 全軸をサーボOFFする場合，"[Cd.100]サーボOFF指令"を「0」のままで，"[Cd.191]全軸サーボON"をON → OFFにしても全軸サーボOFFになります。

#### PDS状態遷移[FX5-SSC-G] (7.10 / 原本 p.307)

- 領域と状態の対応:
  - 「未接続」: NotReadyToSwitchOn
  - 「サーボOFF中 ドライバレディOFF 各軸サーボOFF」: SwitchOnDisabled，ReadyToSwitchOn
  - 「サーボOFF中 ドライバレディON 各軸サーボOFF」: SwitchedOn

### フォローアップ機能 (7.10 / 原本 p.308)

#### フォローアップ機能 (7.10 / 原本 p.308)

「フォローアップ機能」は，サーボOFF状態でモータの回転量(実現在値)をモニタし，モータの回転量を送り現在値に反映させる処理です。
このためサーボOFF中にサーボモータが回転しても，次にサーボONしたときサーボモータは溜りパルス量だけ回転することがなく，停止位置から位置決めを行うことができます。

#### フォローアップの実行 (7.10 / 原本 p.308)

フォローアップ処理は，サーボOFF中常時行います。

【図】フォローアップ処理の実行タイミング(原本 p.308)
- [Cd.191]全軸サーボON: OFF→ON → OFF → ON → OFF
- 各軸サーボOFF指令: 0 → 1 → 0
- サーボON/OFF状態: [Cd.191] ONでON → 各軸サーボOFF指令=1でOFF → 指令=0でON → [Cd.191] OFFでOFF → [Cd.191] ONでON → 図中注記「サーボアラーム発生」でOFF
- サーボON/OFF状態がOFFの各区間で「フォローアップ処理実行」

> **Point**
> フォローアップ機能は絶対位置システムの有無に関わらず，シンプルモーションユニット／モーションユニットとサーボアンプの電源ON中でサーボOFF中のときには，フォローアップ処理を行います。
> [FX5-SSC-G]
> ただし以下の場合はサーボON中でもフォローアップ処理を行います。
> - サーボアンプの制御モードがモーションユニットの対応している制御モード以外*1の場合

*1 モーションユニットが対応している制御モード
- 位置制御モード
- 速度制御モード
- トルク制御モード
- 押当て制御モード
- 原点復帰モード
