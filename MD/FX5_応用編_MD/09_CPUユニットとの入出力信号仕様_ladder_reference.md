## 9 CPUユニットとの入出力信号仕様 (9章 / 原本 p.374)

## 9.1 CPUユニットとの入出力信号一覧 (9.1 / 原本 p.374-375)

シンプルモーションユニット／モーションユニットはCPUユニットとのデータ授受に，入力10点と出力10点を使用しています。下記にシンプルモーションユニット／モーションユニットの入出力信号一覧を示します。
- 4軸／8軸ユニット

#### 信号方向: シンプルモーションユニット／モーションユニット→CPUユニット (9.1 / 原本 p.374)

| バッファメモリアドレス | 信号名称 |
|---|---|
| 31500.b0 | 準備完了 |
| 31500.b1 | 同期用フラグ |
| 31501.b0 | 軸1 BUSY*1 |
| 31501.b1 | 軸2 BUSY*1 |
| 31501.b2 | 軸3 BUSY*1 |
| 31501.b3 | 軸4 BUSY*1 |
| 31501.b4 | 軸5 BUSY*1 |
| 31501.b5 | 軸6 BUSY*1 |
| 31501.b6 | 軸7 BUSY*1 |
| 31501.b7 | 軸8 BUSY*1 |

※原本では信号名称欄が「軸1」～「軸8」の列と「BUSY*1」の列に分かれており，「BUSY*1」が31501.b0～31501.b7の8行で結合セル。各行に展開。

#### 信号方向: CPUユニット→シンプルモーションユニット／モーションユニット (9.1 / 原本 p.374)

| バッファメモリアドレス | 信号名称 |
|---|---|
| 5950 | シーケンサレディ |
| 5951 | 全軸サーボON |
| 30104 | 軸1 位置決め始動*1 |
| 30114 | 軸2 位置決め始動*1 |
| 30124 | 軸3 位置決め始動*1 |
| 30134 | 軸4 位置決め始動*1 |
| 30144 | 軸5 位置決め始動*1 |
| 30154 | 軸6 位置決め始動*1 |
| 30164 | 軸7 位置決め始動*1 |
| 30174 | 軸8 位置決め始動*1 |

※原本では信号名称欄が「軸1」～「軸8」の列と「位置決め始動*1」の列に分かれており，「位置決め始動*1」が30104～30174の8行で結合セル。各行に展開。

*1 制御軸数を超える軸番号のBUSY信号，位置決め始動信号は使用不可です。

> **Point**
> - MコードON信号，エラー検出信号，始動完了信号，位置決め完了信号は，バッファメモリ中の"[Md.31]ステータス"にあります。
> - 軸停止信号，正転JOG始動信号，逆転JOG始動信号，実行禁止フラグは，バッファメモリ中の[Cd.180]～[Cd.183]にあります。

(原本 p.375 は「MEMO」ページ(空白)。本文なし。)
