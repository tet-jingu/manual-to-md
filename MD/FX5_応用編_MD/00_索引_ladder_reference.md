本マニュアルでは，特に明記する場合を除き，下記の用語を使用して説明します。

| 用語 | 内容 |
|---|---|
| 4軸ユニット | FX5-40SSC-S，FX5-40SSC-Gの別称です。 |
| 8軸ユニット | FX5-80SSC-S，FX5-80SSC-Gの別称です。 |
| CANopen | 非営利団体CiAが規格を推進するオープンネットワークです。通信プロファイルやデバイスプロファイルが定義されたアプリケーション層が定義されており，CC-Link IE TSN CANアプリケーションプロトコルは，このアプリケーション層を適用しています。 |
| CC-Link | フィールド系ネットワークの一つで，制御と情報を同時に扱えるネットワークです。 |
| CC-Link IE TSN | 標準Ethernet規格を拡張した「TSN(Time-Sensitive Networking)」を採用し，リアルタイム性を確保した制御と他オープンネットワークの情報を同時に扱えるオープンネットワークです。 |
| CC-Link IE TSN Class | CC-Link協会による，CC-Link IE TSNに対応した機器および産業用スイッチの，機能・性能によるランク分けです。CC-Link IE TSN Classについては，CC-Link協会から発行されているCC-Link IE TSN 敷設マニュアル(BAP-C3007-001)を参照してください。 |
| CC-Link IE TSNプロトコルバージョン2.0 | 時刻同期にIEEE802.1ASを使用した時分割方式に加え，タイムマネージド・ポーリング方式で通信するプロトコルです。 |
| CC-Link IEコントローラネットワーク | 制御系ネットワークの一つで，大規模なコントローラ分散制御への対応と各フィールド・モーションネットワークを束ねる基幹ネットワークです。 |
| CC-Link IEフィールドBasicネットワーク | ソフトウェアでサイクリック伝送を実現するネットワークです。高速制御が必要ではない小規模装置へ適用します。 |
| CC-Link IEフィールドネットワーク | Ethernet(1000BASE-T)を使用した高速かつ大容量なオープンフィールドネットワークです。 |
| GX Works3 | MELSECシーケンサソフトウェアパッケージの製品名です。 |
| IEEE802.1AS | 高精度で時刻／タイミング同期を行うプロトコルです。 |
| MR Configurator2 | サーボセットアップソフトウェアの製品名です。 |
| MR-J3(W)-B | MR-J3-_B_(-RJ)/MR-J3W-_B形サーボアンプです。 |
| MR-J4(W)-B | MR-J4-_B_(-RJ)/MR-J4W_-_B形サーボアンプです。 |
| MR-J4-B | MR-J4-_B_形サーボアンプです。 |
| MR-J5(W)-B | MR-J5-_B_(-RJ)/MR-J5W_-_B形サーボアンプです。 |
| MR-J5-B | MR-J5-_B_形サーボアンプです。 |
| MR-J5-G | MR-J5-_G_(-RJ)形サーボアンプです。 |
| MR-J5D-G | MR-J5D_-_G_形サーボアンプです。 |
| MR-J5W-G | MR-J5W_-_G形サーボアンプです。 |
| MR-J5(W)-G | MR-J5-_G_(-RJ)/MR-J5W_-_G/MR-J5D_-_G_形サーボアンプです。 |
| PDOマッピング | デバイス局のPDOマッピングオブジェクト(RPDO/TPDO)への書込み操作を指し，機器に割り当てるPDOの数とPDO内のオブジェクトの配置を決定します。 |
| SSCNETIII*1 | シンプルモーションユニット ↔ サーボアンプ間高速同期ネットワークです。 |
| SSCNETIII/H*1 | シンプルモーションユニット ↔ サーボアンプ間高速同期ネットワークです。 |
| 安全メインユニット | FX5-SF-MU4T5の別称です。 |
| インテリジェント機能ユニット | A/D，D/A変換ユニットなど，入出力以外の機能を持つユニットです。 |
| インテリジェントデバイス局 | CC-Link IEフィールドネットワークで，ビット単位の入出力信号とワード単位の入出力データをサイクリック伝送する局です。トランジェント伝送も可能です。<br>他局からのトランジェント伝送(要求)に対して応答を返します。また，他局へトランジェント伝送(要求)を発行します。 |
| オブジェクト | CANopen対応のデバイス局が保有する様々なデータです。 |
| オブジェクトディクショナリ | CANopenにおいて，機器が保持する制御パラメータ／指令値などの各種データは，Index，Sub Index，オブジェクト名，データタイプなどで構成されるオブジェクトとして扱われ，これらの集合をオブジェクトディクショナリと呼びます。 |
| 解列 | データリンク異常時に，データリンクを停止する処理です。 |
| 局 | ネットワークに接続されるノードの1台ずつを局と呼びます。 |
| 局番 | 局にはそれぞれ番号をつけて管理し，この番号を局番と呼びます。 |
| グランドマスタ | PTP(Precision Time Protocol)を使用した時刻同期における，時刻同期元となる機器です。 |
| グローバルラベル | プロジェクト内で複数のプログラムデータを作成したときに，すべてのプログラムデータに対して有効となるラベルです。グローバルラベルには，GX Works3が自動で生成するユニット固有のラベル(ユニットラベル)と任意で指定のデバイスに対して作成できるラベルがあります。 |
| ゲートウェイ | 一般に，互いに異なるネットワーク同士を接続しようとすると信号方式や機能が違うため，プロトコル変換が必要になります。この異なるネットワーク間の橋渡しを行い，相互に通信を可能にするための機能です。 |
| サイクリック伝送 | ネットワークの局間で定期的にデータ交信する機能です。 |
| サーボアンプ軸 | コントローラが制御しているサーボアンプまたは仮想サーボアンプを表します。「サーボアンプ軸」はコントローラの制御軸数に含まれます。 |
| 軸 | モーション制御を行う対象です。 |
| 時刻同期 | グランドマスタ(クロック源となる局)クロックに各局のクロックが同期します。 |
| 時分割 | 通信回線を一定時間ごとに区切り，各時間ごとに異なるデータを送受信する方法です。 |
| 指令生成軸 | 指令生成のみを行う軸です。「指令生成軸」はコントローラの制御軸数に含まれません。 |
| 専用命令 | ユニットの機能を使用するための命令です。 |
| 増設ユニット | CC-Link IE TSNネットワークの通信機能を持たないリモートユニットです。多軸サーボアンプの場合は，A軸以外の軸は増設ユニットとします。 |
| 中継局 | 他ネットワークへのトランジェント伝送を中継する局です。ネットワークユニットのリンクデバイスを他のネットワークユニットへ転送します。1台のシーケンサに複数のネットワークユニットが装着されています。 |
| 通信周期 | サイクリックマスタが，サイクリック伝送通信をする周期です。 |
| デバイス | ユニットが内部に持っている各種メモリです。ビット単位とワード単位で扱われるデバイスがあります。 |
| トランジェント伝送 | ネットワークのノード(局)間で非定期的にデータ交信する機能です。<br>リンク専用命令や，エンジニアリングツールからの要求時に，対象局にメッセージを送信するために使われる機能です。中継局またはゲートウェイを介して他ネットワークの局とも交信できます。 |
| ノード | データリンクの時の節点です。 |
| バッファメモリ | 設定値，モニタ値などのデータを格納するための，インテリジェント機能ユニットのメモリです。 |
| フィードバック速度 | 実軸におけるデバイス局からのフィードバック値を軸の単位系に変換したものです。 |
| フィールドネットワーク | FA分野において，各種センサや駆動系機器などの配線を少なくして効率的に制御するためのネットワークです。 |
| 復列 | 異常局が正常になったときに，データリンクを再開する処理です。 |
| プロファイル | 機器の固有情報(形名，モデル名など)や立上げ，運用／保守のために必要な情報を規定するファイルです。 |
| マスタ局 | ネットワークを管理する局で，1ネットワークに1局のみ存在します。マスタ局にサイクリック伝送の各局送信範囲を割り付けます。 |
| モーション管理局 | モーション制御によりサイクリックデータを交信するデバイス局です。 |
| モーションネットワーク | 高性能／高機能な駆動制御を実現するネットワークです。(SSCNETIIIなど) |
| ユニットラベル | 各ユニットが固有で定義しているメモリ(入出力信号やバッファメモリ)を，任意の文字列で表したものです。使用するユニットからGX Works3が自動で生成し，CPUユニット内のグローバルラベルとして使用できます。 |
| ラベル | プログラムで使用する変数です。 |
| リモートI/O局 | CC-Link IEフィールドネットワークで，マスタ局とビット単位の入出力信号をサイクリック伝送する局です。 |
| リモート局 | CC-Link IE TSNネットワークで，マスタ局と，ビット単位やワード単位でのサイクリック伝送とトランジェント伝送を行う局です。 |
| リモートデバイス局 | CC-Link IEフィールドネットワークで，ビット単位の入出力信号とワード単位の入出力データをサイクリック伝送する局です。他局からのトランジェント伝送(要求)に対して応答を返します。 |
| リンクアップ | 通信ポートにケーブルが接続され，接続先機器との通信が可能である状態です。 |
| リンク専用命令 | トランジェント伝送を使用し指定局にメッセージを送信するためのシーケンサ用の専用命令です。 |
| リンクダウン | 通信ケーブルが断線または未接続状態であり，相手先機器との通信が不可能である状態です。 |
| リンクデバイス | CC-Link IE TSNのユニットが内部に持っているデバイスです。 |
| ローカル局 | マスタ局および他ローカル局と，サイクリック伝送およびトランジェント伝送を行う局です。 |
