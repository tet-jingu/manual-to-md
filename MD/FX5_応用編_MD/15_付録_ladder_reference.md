#### ブロック始動データ (付1 / 原本 p.779-780)

ブロック始動データは，始動ブロック0~始動ブロック4の5つの始動ブロックで，それぞれ1~50ポイントまで割り当てられています。この始動ブロックは各軸に割り当てられています。ブロック始動データは，下記の構造になっています。

【図】ブロック始動データのバッファメモリ構造(始動ブロック0)(原本 p.779)

  - ●ブロック始動データは左に示すバッファメモリアドレスに，軸ごとに50ポイントまで設定(格納)することができます。
  - ●1つのブロック始動データは(太枠)の項目で構成されます。

##### [Da.11]形態，[Da.12]始動データNo. (付1 / 原本 p.779-780)

計算式は下記のとおりです。
- 22000 + (400 × (Ax - 1)) + (200 × M) + (P - 1)

各項目には，下記の値をいれて計算してください。

| 項目 | 処理内容 |
|---|---|
| Ax | 求めるバッファメモリアドレスの軸番号です。1~8をいれてください。 |
| M | 求めるバッファメモリアドレスの始動ブロックNo.です。0~1をいれてください。 |
| P | 求めるバッファメモリアドレスのブロック始動データのポイントです。1~50をいれてください。 |

例
下記の条件のバッファメモリアドレスを求める場合
- 軸3
- 始動ブロックNo.1
- ブロック始動データ ポイント40

22000 + (400 × (3 - 1)) + (200 × 1) + (40 - 1) = 23039

#### 汎用インバータFR-A800シリーズ (付2 / 原本 p.782-786)

内蔵オプションFR-A8APおよびFR-A8NSを使用することで，汎用インバータFR-A800シリーズをSSCNETⅢ/H経由で接続することができます。

##### 接続方法 (付2 / 原本 p.782-783)

###### システム構成 (付2 / 原本 p.782)

FR-A800シリーズを使用したシステム構成について以下に示します。
FR-A800シリーズを使用する場合，"[Pr.97]SSCNET設定"を「1: SSCNETⅢ/H」に設定してください。

【図】FR-A800シリーズを使用したシステム構成(原本 p.782)

###### FR-A800シリーズのパラメータ管理 (付2 / 原本 p.782)

FR-A800シリーズに設定するパラメータはシンプルモーションユニットで管理しません。インバータ正面の操作パネル(FR-DU08/FR-LU08/FR-PU07)またはインバータセットアップソフトウェアFR Configurator2を直接FR-A800シリーズに接続して設定します。FR-A800シリーズの設定項目の詳細は，FR-A800シリーズの取扱説明書を確認してください。

> **Point**
> FR-A800シリーズとシンプルモーションユニットを接続した状態において，インバータ側のパラメータ"[Pr.77]パラメータ書込選択"が初期状態では一部のパラメータしか設定できません。FR-A800シリーズのパラメータを書き換える場合は，「2: 運転中もパラメータを書き込む」を設定してください。

###### インポジション範囲 (付2 / 原本 p.782)

サーボパラメータ「インポジション範囲(PA10)」はインバータ側のパラメータ"[Pr.426]位置決め完了幅"で設定します。アドバンスト同期制御でカム軸の位置を復元する場合，サーボパラメータ「インポジション範囲(PA10)」によるチェックが行われますが，FR-A800シリーズではサーボパラメータの設定を行わないため「インポジション範囲」を100 [pulse](固定値)としてチェックします。

##### 制御上の注意事項 (付2 / 原本 p.785)

###### 絶対位置システム(ABS)／インクリメンタルシステム(INC) (付2 / 原本 p.785)

FR-A800シリーズを使用した場合，絶対位置システム(ABS)は使用できません。サーボパラメータ「絶対位置検出システム(PA03)」*1に「1: 有効(絶対位置検出システムで使用する。)」を設定した場合も，インクリメンタルシステムとして動作します。

*1 MR-J4(W)-Bの場合です。MR-J5(W)-Bでは，「絶対位置検出システム選択(PA03.0)」になります。

- シンプルモーションユニット電源投入時，原点復帰要求がONとなり送り現在値は0となります。(インバータのみ電源OFF → ONした場合も送り現在値は0となります。)
- 絶対位置システム時のワーニング「原点データ不正」(ワーニングコード: 093CH)，「SSCNET通信異常」(ワーニングコード: 093EH)は検出しません。

###### 制御モード (付2 / 原本 p.785)

使用可能な制御モードを以下に示します。
- 位置制御モード(位置制御，位置ループを含む速度制御)
- 速度制御モード(位置ループを含まない速度制御)
- トルク制御モード(トルク制御)

ただし，拡張制御「速度・トルク制御」の押当て制御モードへの切換えはできません。押当て制御モードへの切換えを行うとエラー「押当て制御未対応」(エラーコード: 19E7H)となり現在の制御を停止します。
また，"[Pr.90]速度・トルク制御モード動作設定"の「トルク初期値選択(b4～b7)」で，「1: フィードバックトルク」は設定できません。設定した場合，制御モード切換え時にワーニング「トルク初期値選択不可」(ワーニングコード: 09E5H)となり，切換え直後の指令値は「0: 指令トルク」を選択した場合と同じになります。

###### サーボパラメータ変更要求 (付2 / 原本 p.785)

サーボパラメータの変更要求("[Cd.130]サーボパラメータ読み出し／書き込み要求"～"[Cd.132]変更データ")は実行不可です。FR-A800シリーズに対して1ワード／2ワード書込みを実施した場合，パラメータ書込みが失敗し，"[Cd.130]サーボパラメータ読み出し／書き込み要求"に「0003H: 読出し／書込み失敗」が格納されます。

###### ドライバ間通信 (付2 / 原本 p.785)

ドライバ間通信には対応していません。

###### モニタデータ (付2 / 原本 p.785)

"[Md.107]パラメータエラー番号"には，常に「0」が格納されます。また，「絶対位置消失中」([Md.108]サーボステータス1: b14)は常時OFFします。

###### 指令速度 (付2 / 原本 p.785)

FR-A800シリーズの最大回転数以上の指令速度にて動作させると，停止位置がオーバーシュートする場合があります。

##### FR-A800シリーズが検出したエラー／ワーニング (付2 / 原本 p.786)

FR-A800シリーズでエラーが検出された場合，"[Md.23]軸エラー番号"にエラーコード(1C80H)が格納されます。また，"[Md.114]サーボアラーム"には，FR-A800シリーズのアラーム番号が格納されます。ただし，"[Md.107]パラメータエラー番号"には，常に「0」が格納されます。
FR-A800シリーズでワーニングが検出された場合，"[Md.24]軸ワーニング番号"にワーニングコード(0C80H)が格納されます。また，"[Md.114]サーボアラーム"には，FR-A800シリーズのワーニング番号が格納されます。
エラー，ワーニングの詳細については，FR-A800シリーズの取扱説明書を確認してください。

###### 絶対位置システム(ABS)／インクリメンタルシステム(INC) (付2 / 原本 p.795)

ABS/INC設定は，接続するVCⅡシリーズ／VPHシリーズで実施してください。

###### 無限長送り (付2 / 原本 p.795)

VCⅡシリーズ／VPHシリーズの仮想エンコーダパルス数機能を使用した場合，無限長送りが可能になります。本機能を使用しない場合は，エンコーダ多回転カウンタ × エンコーダ分解能 + エンコーダ1回転内位置が-2147483648～2147483647の範囲を超えるとサーボアラーム61468(F01CH)「アブソエンコーダオーバーフロー異常」が発生し，運転を停止します。

###### 原点復帰 (付2 / 原本 p.795)

VCⅡシリーズ／VPHシリーズのパラメータ「SSCNETⅢ通信モード時の機能選択」の1桁目に「1」を設定した場合，零点を通過していなくても原点復帰が可能です。(電源投入後の原点復帰は，モータZ相を通過不要で実行できます。)「0」に設定した場合，モータのZ相(モータ基準位置信号)を通過せず原点復帰を実行するとエラー「原点復帰零点未通過」(エラーコード: 197AH)が発生します。
VPHシリーズのパラメータ「マーカ通過選択」を「原点復帰可」に設定した場合，電源投入後にモータZ相を通過不要で原点復帰が実行可能になります。「マーカ通過後原点復帰可」に設定した場合，モータのZ相を通過せず原点復帰を実行すると，エラー「原点復帰零点未通過」(エラーコード: 197AH)が発生します。

- 速度制御モード(位置ループを含まない速度制御)
- トルク制御モード(トルク制御)

ただし，拡張制御「速度・トルク制御」の押当て制御モードへの切換えはできません。押当て制御モードへの切換えを行うとエラー「押当て制御未対応」(エラーコード: 19E7H)となり現在の制御を停止します。
また，"[Pr.90]速度・トルク制御モード動作設定"の「トルク初期値選択(b4～b7)」で，「1: フィードバックトルク」は設定できません。設定した場合，制御モード切換え時にワーニング「トルク初期値選択不可」(ワーニングコード: 09E5H)となり，切換え直後の指令値は「0: 指令トルク」を選択した場合と同じになります。

###### サーボパラメータ (付2 / 原本 p.796)

- サーボパラメータの管理

シンプルモーションユニットでは，VCⅡシリーズ／VPHシリーズのパラメータを管理しません。そのため，シンプルモーションユニットとVCⅡシリーズ／VPHシリーズが通信している状態で，VCⅡシリーズ／VPHシリーズ側のパラメータを変更してもシンプルモーションユニットのバッファメモリには反映されません。

- サーボパラメータ変更要求

サーボパラメータの変更要求("[Cd.130]サーボパラメータ読み出し／書き込み要求"～"[Cd.132]変更データ")は実行可能です。
ただし，VCⅡシリーズ／VPHシリーズのサーボパラメータは2ワード単位で管理されているため，必ず，"[Cd.130]サーボパラメータ読み出し／書き込み要求"を「0002H: 2ワード書込み要求」にしてパラメータ書込みを実施してください。VCⅡシリーズ／VPHシリーズに対して1ワード書込みを実施した場合，パラメータ書込みが失敗し，"[Cd.130]サーボパラメータ読み出し／書き込み要求"に「0003H: 読出し／書込み失敗」が格納されます。
サーボパラメータ変更要求によりVCⅡシリーズ／VPHシリーズのサーボパラメータを変更した場合，VCⅡ／VPHデータ編集ソフトからサーボパラメータ変更後のパラメータ値を確認することはできません。また，VCⅡシリーズ／VPHシリーズの電源をOFFした場合，サーボパラメータ変更要求により変更したパラメータは無効になり，VCⅡ／VPHデータ編集ソフトから書き込んだ値が有効になります。

##### IAI電動アクチュエータ用コントローラが検出したエラー／ワーニング (付2 / 原本 p.801)

###### エラー (付2 / 原本 p.801)

IAI電動アクチュエータ用コントローラでエラーが発生すると，エラー検出用信号がONし，"[Md.23]軸エラー番号"にエラーコード(1C80H)が格納されます。また，"[Md.114]サーボアラーム"には，IAI電動アクチュエータ用コントローラのサーボアラーム(0x00～0xFF)が格納されます。アラーム詳細番号の格納は行いません。ただし，"[Md.107]パラメータエラー番号"には，常に「0」が格納されます。
原点復帰方式でドライバ原点復帰式を選択した場合の原点復帰エラーが検出された場合，"[Md.23]軸エラー番号"にエラー「ドライバ原点復帰式エラー」(エラーコード: 194BH)が格納されます。また，「ドライバ運転アラーム中」([Md.500]サーボステータス7: b9)がONし，"[Md.502]ドライバ運転アラーム番号"に，IAI電動アクチュエータ用コントローラで発生した運転アラームが格納されます。
詳細については，IAI電動アクチュエータ用コントローラの仕様を確認してください。

###### ワーニング (付2 / 原本 p.801)

IAI電動アクチュエータ用コントローラでワーニングは発生しません。

#### MR-J5(W)-Bとの接続 (付2 / 原本 p.802-806)

###### サーボアンプ電子ギア設定 (付2 / 原本 p.804)

シンプルモーションユニットで回転型サーボモータを使用する場合，エンコーダ分解能を4194304 pulse/revとして制御します。そのため，HK-KTモータなどエンコーダ分解能が67108864 pulse/revであるサーボモータを使用する場合は，サーボパラメータ「電子ギア分子(PA06)」を16，「電子ギア分母(PA07)」を1に設定してください。
また，"[Pr.2]1回転あたりのパルス数(AP)"などの電子ギアは，エンコーダ分解能を4194304 pulse/revとして算出してください。設定の詳細は下記を参照してください。

【図】HK-KT使用時の電子ギアの構成(原本 p.804)

MR-J5(W)-Bとの接続時にサーボパラメータ「電子ギア分子(PA06)」，「電子ギア分母(PA07)」の設定が異なる場合は，エラー「アンプ電子ギア設定エラー」(エラーコード: 1C84H)が発生します。エラーが発生した場合，サーボパラメータ「電子ギア分子(PA06)」，「電子ギア分母(PA07)」を設定後，"[Cd.190]シーケンサレディ "をOFF → ONし，サーボアンプと再接続してください。

なお，エラー「アンプ電子ギア設定エラー」(エラーコード: 1C84H)が発生した軸以降に接続されたサーボアンプは，"[Cd.191]全軸サーボON"をONすると，サーボON状態となります。

##### 注意事項 (付3 / 原本 p.810)

- MR-J5(W)-Gシリーズに接続する場合，サーボアンプのソフトウェアバージョンをB02以降にしてください。B02以前のソフトウェアバージョンの場合，正常に接続できない場合があります。
- ネットワーク同期通信設定は「同期しない」に設定してください。「同期する」に設定しても設定値は無視されます。
- GX Works3のネットワーク構成設定でパラメータ自動設定を有効とした場合，MR Configurator2の通信にて複数の局に対してパラメータの変更を同時に行うと，通信負荷状況によってはCPUユニットへ変更後のパラメータが反映されない場合があります。1局ずつ変更を行ってください。またはGX Works3経由でMR Configurator2を起動しパラメータを変更後，CPUユニットにプロジェクトの書込みを行ってください。
- ネットワーク構成設定に設定されているモーション管理局と同一のIPアドレスを"[Pr.141]IPアドレス"に設定していない場合，モーション制御を行えません。パラメータ設定を見直してください。
- モータ動作中にモーションユニットにて演算周期オーバーが発生すると，演算周期オーバー発生前の指令と復帰後の指令の差が大きい場合，MR-J5(W)-Gにてサーボアラーム[AL.035_指令周波数異常]を検出することがあります。必要に応じて演算周期設定を大きくするか，プログラムを見直し負荷を削減してください。
- 現在値履歴モニタ時に表示される「エンコーダ1回転内位置」は，サーボアンプの電子ギア比の逆数が乗算された値(指令単位)が表示されます。
- 現在のネットワーク構成設定と実際のシステム構成を合わせてください。差異がある場合，モーションユニットが正しくデバイス局を認識できない場合があります。
  多軸サーボアンプの「制御軸無効スイッチ機能」により軸を一部無効にする場合，無効にした軸に対して下記のように設定してください。設定しない場合，モーションユニットが正しくデバイス局を認識できない場合があります。
  - 無効にした軸のIPアドレスとマルチドロップ番号を，"[Pr.141]IPアドレス"と"[Pr.142]マルチドロップ番号"にそれぞれ設定する。
  - "[Pr.101]仮想サーボアンプ設定"を「1: 仮想サーボアンプとして使用」に設定する。
- CC-Link IE TSN Class Aに設定したMR-J5(W)-Gを，軸に割り付けないでください。CC-Link IE TSN Class Aに設定したMR-J5(W)-Gを軸に割り付けた場合，接続時にMR-J5(W)-Gで[AL.19E.2_制御モード設定警告2]が発生します。

##### 注意事項 (付3 / 原本 p.814)

- プロファイルモードへの切換え前にサーボONしないでください。モータが急加速する等の不正動作をする可能性があります。
- プロファイルモードに切換え後，サイクリック同期モードに切り換えないでください。モータが急加速する等の不正動作をする可能性があります。
- サイクリック同期モード以外のモードで使用する場合，モーションユニットは指令のリミットチェック，緊急停止指令発行等を実施しません。ユーザプログラムまたはMR-J5(W)-G側で安全対策を実施してください。
- GX Works3のネットワーク構成設定でパラメータ自動設定を有効とした場合，MR Configurator2の通信にてパラメータの変更を行っても，CPUユニットへ変更後のパラメータが反映されません。デバイス局のパラメータを変更した場合には，GX Works3経由でMR Configurator2を起動し，サーボパラメータの読出しを実施してください。
- プロファイルモードで使用するものは軸を設定しないでください。設定した場合，エラーが発生します。

#### MELSERVO以外のドライブユニット接続方法(サイクリック同期モード) (付3 / 原本 p.815-818)

シンプルモーションユニット互換のCC-Link IE TSN対応ユニットに接続するMELSERVO以外のドライブユニット(以降，本項内ではドライブユニットと記載)を，サイクリック同期モードで接続する際の設定および各種機能の使用方法について記載します。
ドライブユニットをサイクリック同期モードで接続する方法については，使用するドライブユニットの接続ガイドを三菱電機FAサイトからダウンロードして参照してください。

> **Point**
> - ソフトウェアバージョン1.007以降で，ドライブユニットをサイクリック同期モードにて接続できます。ソフトウェアバージョン1.006以前では，ドライブユニット接続時にエラー「非対応デバイス局接続」(エラーコード: 1C4AH)が発生します。
> - モーションユニットがサポートしているドライブユニットをモーション管理局に設定できます。モーションユニットがサポートしていないドライブユニットをモーション管理局に設定した場合，ドライブユニット接続時にエラー「非対応デバイス局接続」(エラーコード: 1C4AH)が発生します。
