## 1 始動と停止 (1章 / 原本 p.23)

シンプルモーションユニット／モーションユニットの位置決め制御の始動と停止方法を示します。

## 1.1 始動 (1.1 / 原本 p.23-30)

シンプルモーションユニット／モーションユニットでは，制御ごとに始動トリガを動作させ，位置決め制御を開始させます。制御ごとの始動信号を下記に示します。本節では，位置決め始動信号と外部指令信号による始動を記載します。

| 制御内容 | | 始動トリガ |
|---|---|---|
| 主要な位置決め制御 | — | • "[Cd.184]位置決め始動"をONする。<br>• 外部指令信号(DI)をONする。 |
| 高度な位置決め制御 | — | • "[Cd.184]位置決め始動"をONする。<br>• 外部指令信号(DI)をONする。 |
| 原点復帰制御 | — | • "[Cd.184]位置決め始動"をONする。<br>• 外部指令信号(DI)をONする。 |
| 手動制御 | JOG運転 | "[Cd.181]正転JOG始動信号"または"[Cd.182]逆転JOG始動信号"をONする。 |
| 手動制御 | インチング運転 | "[Cd.181]正転JOG始動信号"または"[Cd.182]逆転JOG始動信号"をONする。 |
| 手動制御 | 手動パルサ運転 | 手動パルス発生器を操作する。 |

※原本では「始動トリガ」列が主要な位置決め制御／高度な位置決め制御／原点復帰制御の3行で結合、JOG運転／インチング運転の2行で結合。各行に展開して記載。

手動制御以外の制御では，下記の始動方式を選択できます。
- 通常始動(→139ページ ブロック始動)
- 複数軸同時始動(→27ページ 複数軸同時始動)

制御する際に指定する位置は，位置決めデータ，ブロック始動データ，条件データを使用します。使用できるデータは，始動方式によって異なります。

### 位置決め始動[Cd.184]による始動 (1.1 / 原本 p.25-26)

"[Cd.184]位置決め始動"によって始動した時の動作を示します。

- "[Cd.184]位置決め始動"のONにより，始動完了信号([Md.31]ステータス: b14)および"[Md.141]BUSY"がONし，位置決め運転が開始します。"[Md.141]BUSY"のONにより，軸が運転中であることがわかります。
- "[Cd.184]位置決め始動"がOFFすると始動完了信号([Md.31]ステータス: b14)もOFFします。位置決めを終了しても"[Cd.184]位置決め始動"がONの場合，始動完了信号([Md.31]ステータス: b14)もONのままです。
- "[Md.141]BUSY"がON中に，再度位置決め始動信号がONすると，ワーニング「運転中始動」(ワーニングコード: 0900H[FX5-SSC-S]，0D00H[FX5-SSC-G])となります。
- 位置決め運転終了時の処理は，次の位置決め制御の有無によって異なります。

| 次の位置決め制御の有無 | 処理内容 |
|---|---|
| 位置決めを行わない | • ドウェルタイムが設定されている場合は，設定した時間が経過するまでウェイトしたあと，位置決めが完了します。<br>• 位置決めが完了すると，"[Md.141]BUSY"がOFFし，位置決め完了信号([Md.31]ステータス: b15)がONします。ただし，速度制御の場合や位置決め完了信号出力時間が「0」の場合はONしません。<br>• "[Pr.40]位置決め完了信号出力時間"に設定した時間が経過すると，位置決め完了信号([Md.31]ステータス: b15)がOFFします。 |
| 位置決めを行う | • ドウェルタイムが設定されている場合は，設定した時間が経過するまでウェイトします。<br>• ドウェルタイムの設定時間が経過すると，次の位置決めの始動を行います。 |

#### 動作例 (原本 p.25)

【図】位置決め始動[Cd.184]による始動の動作例タイミングチャート(原本 p.25)
- 信号: 位置決め(速度波形 V-t)，[Cd.191]全軸サーボON，[Cd.184]位置決め始動，始動完了信号([Md.31]ステータス: b14)，[Md.141]BUSY，位置決め完了信号([Md.31]ステータス: b15)
- [Cd.191]全軸サーボON をONしたあと，[Cd.184]位置決め始動 をON → 始動完了信号(b14) と [Md.141]BUSY がON，位置決め運転開始
- 連続する複数の位置決め(速度が段階的に変化する連続パターン)の区切りごとに，位置決め完了信号(b15) が短時間ONしてOFFするパルスが出ている
- 位置決め完了後にドウェルタイムを経て次の位置決めが始動する区間が図示されている
- 最後の位置決め完了で [Md.141]BUSY がOFFし，同時に位置決め完了信号(b15) がON(一定時間後にOFF)
- [Cd.184]位置決め始動 をOFFすると，始動完了信号(b14) がOFF(位置決め終了後も[Cd.184]がONの間はb14はONのまま)

> **Point**
> 移動量0の位置制御を実行した場合も，"[Md.141]BUSY"はONしますが，ON時間が短いためプログラムでON状態を検出できない場合があります。(始動完了信号([Md.31]ステータス: b14)，位置決め完了信号([Md.31]ステータス: b15)，MコードON信号([Md.31]ステータス: b12)は，プログラムでON状態を検出できます。)

### 外部指令信号(DI)による始動 (1.1 / 原本 p.27-28)

[FX5-SSC-S]
外部指令信号(DI)の入力による位置決め制御の始動では，始動指令をダイレクトにシンプルモーションユニットに入力することができ，CPUユニットの1スキャンタイム分のバラツキ時間をなくすことができます。始動指令によって少しでも早く始動したいときや，始動のバラツキ時間を抑えたいときなど，有効な手段となります。

[FX5-SSC-G]
外部指令信号(DI)の入力による位置決め制御の始動では，ドライブユニット経由の始動指令をダイレクトにモーションユニットに入力できます。

### 複数軸同時始動 (1.1 / 原本 p.29-30)

「複数軸同時始動」は指定した同時始動対象軸を，始動した軸と同タイミングで指令出力開始します。最大4軸まで同時始動できます。

#### 制御内容 (1.1 / 原本 p.29)

軸制御データの複数軸同時始動制御用バッファメモリに同時始動用設定データを設定し，始動軸の"[Cd.3]位置決め始動番号"に「9004」を設定して，位置決め始動信号をONすることによって複数軸同時始動制御を行います。
"[Cd.43]同時始動対象軸"に同時始動する軸数と軸番号，"[Cd.30]同時始動自軸始動データNo."，"[Cd.31]同時始動対象軸1始動データNo."～"[Cd.33]同時始動対象軸3始動データNo."に同時始動対象軸の始動データNo.(同時始動させる軸ごとの位置決めデータNo.)を設定してください。

#### 制約事項 (1.1 / 原本 p.29)

- 始動された軸の軸制御データ内の同時始動対象軸始動データNo.が設定されていない場合または設定範囲外になっている場合は，エラー「同時始動前エラー」(エラーコード: 1990H[FX5-SSC-S]，1A90H，1A91H[FX5-SSC-G])となり，同時始動対象軸はすべて始動しません。
- 同時始動対象軸のいずれかの軸が軸BUSYの場合は，エラー「同時始動前エラー」(エラーコード: 1990H[FX5-SSC-S]，1A90H，1A91H[FX5-SSC-G])となり，同時始動対象軸はすべて始動しません。
- 同時始動対象軸の位置決めデータ解析中にエラーが発生した場合は，エラー「同時始動前エラー」(エラーコード: 1990H[FX5-SSC-S]，1A90H，1A91H[FX5-SSC-G])となり，同時始動対象軸はすべて始動しません。
- 同時始動対象軸が始動された軸のみの場合は，エラーまたはワーニングとはなりません。
- 補助機能(→270ページ 先読み始動機能)と組み合わせることはできません。

#### 手順 (1.1 / 原本 p.29)

以下に複数軸同時始動制御を行う手順を示します。

1. 下記の軸制御データを設定する。
   - [Cd.43]同時始動対象軸
   - [Cd.30]同時始動自軸始動データNo.
   - [Cd.31]同時始動対象軸1始動データNo.
   - [Cd.32]同時始動対象軸2始動データNo.
   - [Cd.33]同時始動対象軸3始動データNo.
2. [9004]を"[Cd.3]位置決め始動番号"に書き込む。
3. 始動する位置決め始動信号をONする。

### 停止処理の分類 (1.2 / 原本 p.33)

運転中の停止には，減速停止，急停止，即停止の3種類があります。

#### 減速停止 (1.2 / 原本 p.33)

「減速時間0～3」([Pr.10]，[Pr.28]，[Pr.29]，[Pr.30])による停止です。「減速時間0～3」の，どの時間を制御に使用するかは位置決めデータ([Da.4])に設定します。

#### 急停止 (1.2 / 原本 p.33)

"[Pr.36]急停止減速時間"による停止です。

#### 即停止 (1.2 / 原本 p.33)

減速処理を行わない停止です。
シンプルモーションユニット／モーションユニットは指令を即停止します。サーボアンプの停止方法については，各サーボアンプの技術資料集またはマニュアルを参照してください。

- 減速停止: 位置決め速度で運転中に停止要因 → 減速して停止。「設定減速時間」は[Pr.8]速度制限値から0までの時間として定義され，「実減速時間」は位置決め速度から0までの時間(設定減速時間より短い)
- 急停止: 急停止要因 → [Pr.36]急停止減速時間 の傾きで減速して停止。[Pr.36]急停止減速時間は[Pr.8]速度制限値から0までの時間，「実急停止減速時間」は位置決め速度から0までの時間
- 即停止: 停止要因 → 減速なしで速度0(垂直に停止)

## 1.3 再始動 (1.3 / 原本 p.35-36)

位置制御中に停止要因が発生して停止した場合，「再始動指令」([Cd.6]再始動指令)により，停止位置から位置制御の終点までの位置決めを再開することができます。(「連続運転の中断」の場合は，「再始動」はできません。)
INC直線1などインクリメント方式の位置制御において，停止位置から残りの位置決めを行う場合に有効です。(残距離の算出を行う必要がありません。)

### 動作 (1.3 / 原本 p.35)

停止指令による減速停止完了後，"[Md.26]軸動作状態"が「停止中」の状態で"[Cd.6]再始動指令"に「1: 再始動指令」を書き込むと，再始動を行います。

【図】再始動の動作(原本 p.35)
- 位置決めデータNo.10 → No.11 → No.12 の連続運転
- 位置決めデータNo.11の途中で「停止指令による停止処理」により減速停止
- 「再始動指令による位置決めデータNo.11の続行」で，停止位置からNo.11の残りを実行し，続けてNo.12を実行

### 制約事項 (1.3 / 原本 p.35)

- 再始動は，"[Md.26]軸動作状態"が「停止中(停止指令による減速停止が完了した状態)」のみ実行できます。軸動作状態が「停止中」以外になった場合は，再始動できません。この場合，ワーニング「再始動不可」(ワーニングコード: 0902H[FX5-SSC-S]，0D02H[FX5-SSC-G])となり，そのときの処理が続行されます。
- 停止指令がON中には，再始動を行わないでください。停止中に再始動を行うと，エラー「始動時停止信号ON」(エラーコード: 1908H[FX5-SSC-S]，1A08H[FX5-SSC-G])となり，"[Md.26]軸動作状態"が「エラー発生中」になります。このためエラーリセットを行っても，再始動できなくなります。
- 再始動は，位置決め始動信号がONのままでも実行できます。ただし停止中に，位置決め始動信号がOFF → ONしないようにしてください。
- "[Md.26]軸動作状態"が「停止中」に位置決め始動信号をOFF → ONした場合も，通常の位置決め始動("[Cd.3]位置決め始動番号"に設定されている位置決めデータの始動)を行います。
- 連続運転中断要求により位置決めを終了した場合は，再始動できません。再始動要求を行った場合は，ワーニング「再始動不可」(ワーニングコード: 0902H[FX5-SSC-S]，0D02H[FX5-SSC-G])となります。
- 補間運転で停止中のときは，基準軸の"[Cd.6]再始動指令"に「1: 再始動指令」を書き込み，再始動してください。
- 停止中に"[Cd.190]シーケンサレディ "をOFF → ONした場合は，再始動できません。再始動要求を行った場合は，ワーニング「再始動不可」(ワーニングコード: 0902H[FX5-SSC-S]，0D02H[FX5-SSC-G])となります。
- 機械原点復帰および高速原点復帰の停止時は，エラー「原点復帰再始動不可」(エラーコード: 1946H[FX5-SSC-S]，1A46H[FX5-SSC-G])となり，再始動できません。
- 補間運転停止後，補間相手軸のいずれかが1回でも位置決め動作した場合，ワーニング「再始動不可」(ワーニングコード: 0902H[FX5-SSC-S]，0D02H[FX5-SSC-G])となり，再始動できません。

### 再始動用タイムチャート (1.3 / 原本 p.36)

#### 動作例

【図】再始動用タイムチャート(原本 p.36)
- 前提: [Cd.190]シーケンサレディ ON → 準備完了信号([Md.140]ユニットステータス: b0) ON → [Cd.191]全軸サーボON ON
- [Cd.184]位置決め始動 ON → 始動完了信号([Md.31]ステータス: b14) ON，[Md.141]BUSY ON，[Md.26]軸動作状態 0 → 8(位置制御中)，位置決め開始
- 運転中に [Cd.180]軸停止 ON → 減速停止。停止完了で [Md.141]BUSY OFF，[Md.26]軸動作状態 8 → 1(停止中)
- [Cd.184]位置決め始動 と [Cd.180]軸停止 をOFF(始動完了信号 b14 もOFF)

- 再始動時，始動完了信号(b14) はONしない(図ではOFFのまま)
- エラー検出信号([Md.31]ステータス: b13) はOFFのまま
