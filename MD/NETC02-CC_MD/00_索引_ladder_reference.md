## この製品は何か（30秒で理解する）

```
CC-Linkマスタ局（PLC）
   │ CC-Link Ver.2（リモートデバイス局・4局占有・拡張サイクリック2/4/8倍）
   ▼
NETC02-CC（ネットワークコンバータ）
   │ RS-485（GWプロトコルVer.2、625 kbps、独自プロトコル）
   ▼
RS-485通信対応製品（ドライバ）× 最大16台 ＝ 号機番号0〜15
   AR / AZ / CRK / DRLⅡ / PKA / RKⅡ / BLE / BLV
```

**PLC側から見ると NETC02-CC は「4局占有のCC-Link Ver.2 リモートデバイス局」1台。**
ドライバの運転／停止は **リモートI/O（RX/RY）**、データの読み書きとモニタは **リモートレジスタ（RWw/RWr）＋要求信号** で行なう。

## AIがラダーを書くときの参照手順

```
① 02 でスイッチ設定（拡張サイクリック設定・レジスタ配置）を確定
        ↓  ← これが決まらないとアドレスが決まらない
② 03 で RX/RY のアドレスを確定（運転・停止・状態監視）
        ↓
③ 方式を選ぶ（下の「コマンド実行方式の選定」を参照）
        ↓
④ 04 で RWw/RWr のアドレスと命令コードを確定
        ↓
⑤ 09 の操作例をテンプレートにシーケンスを組む
        ↓
⑥ 05 でスキャンタイムを見積り、応答待ちタイムアウトを決める
        ↓
⑦ 08 で異常系（アラーム／通信エラー）の処理を追加
        ↓
⑧ ドライバ固有の命令コード・NET-IN/NET-OUT割り付けは
   各ドライバのユーザーズマニュアル／機能編で確認（本書には無い）
```

## 1. コマンド実行方式の選定

| やりたいこと | 方式 | 要求信号 | 参照 |
|---|---|---|---|
| モーターの運転・停止・原点復帰 | **リモートI/O**（どの方式でも共通） | `START` / `HOME` / `STOP` など | `03` |
| 任意のパラメータを任意のタイミングで読み書きしたい | **命令選択方式** | `D-REQ` | `04` 7-1、7-2 |
| メンテナンスコマンド（P-PRESET、NVメモリ書き込みなど）を実行したい | **命令選択方式のみ**（命令固定方式では不可） | `D-REQ` | `09` 1-1 |
| 決まったデータ（位置・速度など）を高頻度で更新したい | **命令固定方式** | `WR-REQ` / `RD-REQ` | `04` 7-3、7-4 |
| 現在位置などを常時モニタしたい | **命令選択方式**（D-REQをONのまま）または**命令固定方式**（RD-REQをONのまま） | `D-REQ` / `RD-REQ` | `04` |
| 電源投入時に決まった初期設定を一括で流したい | **データ転送機能** | `SDT-EXE` | `03` 6-1、`09` 1-3 |
| AZシリーズでダイレクトデータ運転したい | **命令選択方式（簡易ダイレクトデータ運転）** | `D-REQ` | `04` 7-2 例3 |

> **★命令選択方式と命令固定方式は同じリモートレジスタを使うため、同時に実行できない。**
> 切り替えるときは、使っていない方の要求信号を必ずOFFにする（`DREQ-SEL` / `RWREQ-SEL` で確認）。
> **データ転送機能は他方式より優先**され、実行中は他方式が一時停止する。

### 方式ごとの特徴比較

| | 命令選択方式 | 命令固定方式 | データ転送機能 |
|---|---|---|---|
| 命令コード | 実行時にRWwへ書く | **固定**（パラメータで事前設定） | 固定（MEXE02で事前設定） |
| 号機番号 | 実行時にRWwへ書く | **固定** | 固定（MEXE02で事前設定） |
| 1セットのワード数 | **4ワード** | **16ワード** | リモートレジスタ不要 |
| セット数（2倍/4倍/8倍） | 8 / 16 / 32 | 2 / 4 / 8 | SDT-EXE0〜7（8本） |
| パラメータ読み出し | ○ | ○ | ○（値の照合のみ） |
| パラメータ書き込み | ○ | ○ | ○ |
| モニタ | ○ | ○ | × |
| メンテナンス | ○ | **×** | ○ |
| ラダーの手間 | 多い（毎回命令コードを書く） | 少ない（値を書くだけ） | 最少（要求信号1本） |

## 2. 主要信号 早見表（RY00/RX00 から開始した場合の相対アドレス）

### 起動前に必ず確認する信号

| 信号 | 方向 | 2倍 | 4倍 | 8倍 | 意味 |
|---|---|---|---|---|---|
| `CRD` | RX | `RXDB` | `RX1BB` | `RX37B` | リモート局通信レディ（CC-Link正常） |
| `C-SUC` | RX | `RXA8` | `RXA8` | `RXA8` | RS-485通信の確立（全号機） |

## 4. エラーコード早見表

### NETC02-CC のアラーム（`08` 11-1）

| コード | LED点滅 | 種類 | ALM-RSTで解除 | RS-485通信 |
|---|---|---|---|---|
| `22h` | 3 | 過電圧 | 可 | 継続 |
| `41h` | 9 | EEPROM異常 | **不可** | **停止** |
| `6Eh` | 7 | 外部停止 | 可 | 継続 |
| `83h` | 7 | 通信用スイッチ設定異常 | **不可** | **停止** |

### 通信エラー（`08` 11-3）

| コード | 種類 | よくある原因（サブコード） |
|---|---|---|
| `84h` | RS-485通信異常 | `01h`フレーム異常／`02h`BCC異常／`03h`,`04h`未対応のフレーム |
| `85h` | RS-485通信タイムアウト | `01h`フレーム未受信 |
| `88h` | コマンド未定義 | `01h`命令選択方式のコマンド不正／`02h`RD-REQのコマンド不正／`03h`WR-REQのコマンド不正／`04h`データ転送のコマンド不正 |

## 5. ラダーを書くときの落とし穴（本文から抽出）

| # | 落とし穴 | 出典 |
|---|---|---|
| 1 | **`C-SUC` がOFFのときは、運転起動信号（`START`、`HOME`、`D-REQ` など）もOFFにする** | p.21 |
| 2 | **命令選択方式と命令固定方式は同時実行できない**。切り替え時は必ず一方をOFFにし、`DREQ-SEL`/`RWREQ-SEL` で確認 | p.49, 87 |
| 3 | **メンテナンスコマンドは命令選択方式でしか実行できない** | p.60, 137 |
| 4 | **メンテナンスコマンドはデータ領域に `1` をセットしないと実行されない** | p.130, 137 |
| 5 | **モニタは `D-REQ`（または `RD-REQ`）をONのまま保持する**。OFFにするとモニタが止まる | p.49, 53 |
| 6 | 書き込み後に運転起動するときは、**`D-REQ` をOFFにしてから `START` をON**するのが基本手順 | p.69 |
| 7 | ただし**同一スキャンで同時に受け付けさせれば、書き込み後のデータで運転が始まる**（コマンド→リモートI/Oの順に処理されるため） | p.71, 91, 95 |
| 8 | **`RWr-CLR` は、要求信号（`D-REQn`、`RD-REQn`、`WR-REQn`）がOFFのときに行なう** | p.58 |
| 9 | **`AXIS-ALMRST` は `CMD-BSY` がONのときは実行できない** | p.58 |
| 10 | 簡易ダイレクトデータ運転中は `CMD-BSY` がONのため、**`AXIS-ALMRST` と `SDT-EXE` が実行できない** | p.73 |
| 11 | **号機番号8以降のリモートI/Oは `RYE0` から始まる**（`n×16` の単純計算が使えない） | p.38 |
| 12 | **32bitデータは必ず2ワード単位で、偶数アドレスを先頭に配置**する（奇数先頭は不可） | p.104 |
| 13 | **NETC02-CC のパラメータはCC-Link通信では設定できない**（操作パネルかMEXE02のみ） | p.97 |
| 14 | **NETC02-CC のモニタもCC-Link通信では実行できない**（RX上に出ている項目を除く） | p.109 |
| 15 | **CC-Link通信で設定したデータはRAM**。電源を切ると消える。残すには `30C9h`（NVメモリ一括書き込み） | p.135 |
| 16 | **拡張サイクリック設定2倍にはアラームコード／インフォメーション／スキャンタイムのRX領域がない** | p.29, 35 |
| 17 | **`AXIS-ALM` を使うなら `NET-OUT7` を初期値（ALM）のままにする** | p.58, 107 |
| 18 | **スイッチ設定は電源OFF時に行なう**。通電中の変更は無効 | p.24 |
| 19 | 接続台数を変更したら**電源を再投入**する | p.95 |
| 20 | **NVメモリの書き込み可能回数は約10万回**。毎スキャン書き込むような設計にしない | p.97, 134 |
