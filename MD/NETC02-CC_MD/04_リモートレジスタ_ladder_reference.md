## 7 リモートレジスタ（概要／p.60）

リモートレジスタは、**パラメータの読み出しや書き込み、モニタ、メンテナンス**を行なう領域。
命令選択方式と命令固定方式は、**同じリモートレジスタ**を使う。要求信号によって、どちらのコマンド実行方式で行なうかを決定する。

> **命令選択方式と命令固定方式は、同時に実行できません。**

| コマンド実行方式 | 命令コード | 実行できるコマンド | 要求信号 | 内 容 |
|---|---|---|---|---|
| **命令選択方式** | 実行時に設定 | ・パラメータの読み出し<br>・パラメータの書き込み<br>・モニタ<br>・メンテナンス | `D-REQ` | 命令コード、号機番号、およびデータの読み出しと書き込みを実行します。 |
| **命令固定方式** | 固 定 | ・パラメータの読み出し<br>・パラメータの書き込み<br>・モニタ | `RD-REQ`、`WR-REQ` | データだけを設定して実行します。命令コードと号機番号は固定です。（パラメータで変更できます。） |

---

## 7-1 命令選択方式（p.60〜66）

命令選択方式の実行領域は、**命令コード、号機番号、およびデータ（上位・下位）の4ワードを1セット**として構成されている。
CC-Link Ver.2では、**最大32セット**のコマンドを並列に実行できる。

- 1つの実行領域に対して、1つの要求信号 `D-REQn` が存在する。`D-REQ` をONにすると、対応する実行領域が実行される。
- パラメータの書き込みや読み出し、およびメンテナンスは、**`D-REQ` のONエッジ**で実行される。
- **モニタを行なう場合は、`D-REQ` がONの間、モニタ値が自動で更新される。**
- **同じ号機へのコマンドも並列に実行できる。**

### コマンド実行領域の構造（1セット＝4ワード）

| 対応するD-REQ | RWw（マスタ局→NETC02-CC） | 内 容 | RWr（NETC02-CC→マスタ局） | 内 容 |
|---|---|---|---|---|
| D-REQ0 | RWw00 | 命令コード※ | RWr00 | 命令コード応答 |
| | RWw01 | 号機番号 | RWr01 | 号機番号応答 |
| | RWw02 | データ（下位） | RWr02 | データ応答（下位） |
| | RWw03 | データ（上位） | RWr03 | データ応答（上位） |

※ RS-485通信対応製品によって、命令コードは異なります。

### コマンド実行領域の最大セット数

| 拡張サイクリック設定 | 2倍 | 4倍 | 8倍 |
|---|---|---|---|
| セット数 | 8 | 16 | 32 |

### 例3：AZシリーズの簡易ダイレクトデータ運転（p.72〜74）

AZシリーズでは、**簡易ダイレクトデータ運転**（NETC02-CCを使用したダイレクトデータ運転）を実行できる。

- リモートI/Oで選択した運転データに、**位置または速度を書き込むだけで運転を起動**できる。
- レスポンスには、パラメータで指定したモニタ値が読み出される。

> **簡易ダイレクトデータ運転は、命令選択方式で行なってください。**

**設定例**：`D-REQ0` と `D-REQ1` を使用して、2台のドライバの位置データを変更し、運転を起動する。
- 号機番号0：現在位置0 step から1000 step に移動（`D-REQ0`、運転データNo.1 を使用）
- 号機番号1：現在位置0 step から2000 step に移動（`D-REQ1`、運転データNo.0 を使用）

**操作手順（号機番号0の場合）**

1. リモートI/Oの `M0` をONにして、運転データNo.1 を選択します。
2. 次のデータをリモートレジスタに設定します。

| 対応するD-REQ | アドレス | 値 | 内 容 | 説 明 |
|---|---|---|---|---|
| D-REQ0 | RWw00 | `1035h` | 命令コード | AZシリーズの簡易ダイレクトデータ運転モニタ |
| | RWw01 | `0h` | 号機番号 | − |
| | RWw02 | `1000` | データ（下位） | 移動量1000 step |
| | RWw03 | | データ（上位） | |

3. リモートI/Oの **`M0_R` と `READY` がONになっていることを確認し、`D-REQ0` をONにします**。
号機番号0の位置決め運転が始まります。また、`D-END0` がONになります。
4. `D-END0` がONの間、データ応答で**指令位置**をモニタできます。

| アドレス | 値 | 内 容 | 説 明 |
|---|---|---|---|
| RWr00 | `1035h` | 命令コード応答 | − |
| RWr01 | `0h` | 号機番号応答 | − |
| RWr02 | `1000` | データ応答（下位） | 指令位置のモニタ |
| RWr03 | | データ応答（上位） | |

5. 位置決め運転の終了後、`D-REQ0` をOFFにします。`D-END0` がOFFになり、指令位置のモニタが終了します。

**操作手順（号機番号1の場合）**

6. 次のデータをリモートレジスタに設定します。

| 対応するD-REQ | アドレス | 値 | 内 容 | 説 明 |
|---|---|---|---|---|
| D-REQ1 | RWw04 | `1035h` | 命令コード | AZシリーズの簡易ダイレクトデータ運転モニタ |
| | RWw05 | `1h` | 号機番号 | − |
| | RWw06 | `2000` | データ（下位） | 移動量2000 step |
| | RWw07 | | データ（上位） | |

| アドレス | 値 | 内 容 | 説 明 |
|---|---|---|---|
| RWr04 | `1035h` | 命令コード応答 | − |
| RWr05 | `1h` | 号機番号応答 | − |
| RWr06 | `2000` | データ応答（下位） | 指令位置のモニタ |
| RWr07 | | データ応答（上位） | |

**★簡易ダイレクトデータ運転の制約**

- 位置決め運転中に位置（移動量）を変更したい場合は、データをリモートレジスタに設定してから、**`D-REQ` を OFF→ON** にしてください。

- 簡易ダイレクトデータ運転中にパラメータを変更したいときは、いったん `D-REQ` をOFFにしてください。ただし `D-REQ` をOFFにすると、モニタも停止します。

## 7-3 命令固定方式（p.75〜85）

命令固定方式の実行領域は、**16ワード単位**で構成されている。
1つの実行領域に対して、要求信号 `RD-REQn` と `WR-REQn` が1つずつ存在する。
**命令コードと号機番号は固定**となり、要求信号の「n」が**実行領域番号**を示す。

- パラメータの読み出しは、**`RD-REQ` のONエッジ**で開始する。`RD-REQ` をONのままにしておくと、`WR-REQ` でパラメータを書き込むと同時に値が読み出される。
- パラメータの書き込みは、**`WR-REQ` のONエッジ**で開始する。`WR-REQ` をONのままにしておくと、**値を変更するだけで書き込まれる**。
- モニタを行なう場合は、`RD-REQ` をONにしておく。モニタ値が自動で更新される。
- **コマンドの実行中に通信エラーが発生したときは、再度同じコマンドが実行される。**

### レジスタ配置の種類

実行領域の16ワードは、接続するRS-485通信対応製品の数によって自由に割り当てられる。

| レジスタ配置 | 内 容 |
|---|---|
| **4ワード配置** | 1台当たり4ワードが割り当てられます。配置される内容は、RS-485通信対応製品ごとに決められています。 |
| **8ワード配置** | 1台当たり8ワードが割り当てられます。配置される内容は、RS-485通信対応製品ごとに決められています。 |
| **16ワード配置** | 1台当たり16ワードが割り当てられます。配置される内容は、RS-485通信対応製品ごとに決められています。 |
| **ユーザー指定配置** | 号機番号と命令コードのアドレス配置をお客様側で設定します。 |

### 例1：命令固定方式の開始

**設定例**
- RS-485通信対応製品の種類：ARシリーズ／号機番号：0
- 位置（移動量）：1000 step／運転速度：10,000 Hz／運転方式：アブソリュート

**操作手順**

1. `RD-REQ0` をONにして、モニタとデータ読み出しの開始を要求します。
2. `RD-REQ0` に対する応答信号 `RD-DAT0` がONになり、モニタとデータの読み出しが始まります。
   `RD-REQ0` をONにしている間、モニタが継続します。
   **運転データは、次のタイミングで読み出されます。**
   - `RD-REQ` がONになったとき。
   - `RD-REQ` をONにしている間、`WR-REQ` でデータが書き込まれたとき。

   エラーが発生したときは `RD-ERR0` がONになります。
3. 次のデータをリモートレジスタに設定します。

| アドレス | 値 | 内 容 | 説 明 |
|---|---|---|---|
| RWw02 / RWw03 | `1000` | 号機番号0の書き込みデータ | 号機番号0の位置（1000 step） |
| RWw04 / RWw05 | `10,000` | 号機番号0の書き込みデータ | 号機番号0の運転速度（10,000 Hz） |
| RWw06 / RWw07 | `1` | 号機番号0の書き込みデータ | 号機番号0の運転方式（1：アブソリュート） |

4. `WR-REQ0` をONにして、データ書き込みの開始を要求します。
5. `WR-REQ0` に対する応答信号 `WR-DAT0` がONになり、データの書き込みが始まります。
   エラーが発生したときは `WR-ERR0` がONになります。
   `RD-REQ0` によるモニタとデータ読み出しによって、書き込みが反映されたことが確認できます。

| アドレス | 値 | 内 容 | 説 明 |
|---|---|---|---|
| RWr02 / RWr03 | `1000` | 号機番号0の読み出しデータ | 号機番号0の位置（1000 step） |
| RWr04 / RWr05 | `10,000` | 号機番号0の読み出しデータ | 号機番号0の運転速度（10,000 Hz） |
| RWr06 / RWr07 | `1` | 号機番号0の読み出しデータ | 号機番号0の運転方式（1：アブソリュート） |

6. **`WR-REQ0` がONの間、書き込みデータを変更すると、すぐに値が反映されます。**

| アドレス | 値 | 内 容 | 説 明 |
|---|---|---|---|
| RWw02 / RWw03 | `2000` | 号機番号0の書き込みデータ | 号機番号0の位置（1000 step→2000 step） |

`RD-REQ0` によるモニタとデータ読み出しによって、書き込みが反映されたことが確認できます。

| アドレス | 値 | 内 容 | 説 明 |
|---|---|---|---|
| RWr02 / RWr03 | `2000` | 号機番号0の読み出しデータ | 号機番号0の位置（2000 step） |

> - **命令固定方式は、`RD-REQ` と `WR-REQ` をOFFにする必要がありません。** 命令固定方式を終了したいときに、これらのリモートI/OをOFFにしてください。
> - **命令固定方式から命令選択方式に切り替えるときは、`RD-REQ` と `WR-REQ` をOFFにして、命令固定方式を終了させてください。**

**設定例**

#### 例：WR-REQによるデータの変更とSTARTを同時に受け付けた場合（p.91）

`WR-REQ` による書き込みが行なわれた後に、位置決め運転が始まります。
位置決め運転は、**書き込み後のデータで行なわれます**。
ただし、**`WR-REQ` によるデータの変更と `START` を CC-Link通信上で同時に受け付けることが条件**となります。

## 命令コードの規則（本文から読み取れる範囲）

本マニュアルに現れた範囲では、次の対応が成り立っている。

| 用途 | 命令コードの形 | 例 |
|---|---|---|
| **パラメータ書き込み** | `1xxxh` | 位置No.0 ＝ `1200h` |
| **パラメータ読み出し** | `0xxxh`（書き込みコード − `1000h`） | 位置No.0 ＝ `0200h` |
| **モニタ** | `2xxxh` | フィードバック位置 ＝ `2066h`、指令位置 ＝ `2063h`、フィードバック速度 ＝ `2067h` |
| **未使用** | `FFFFh` | − |

> **要確認**：全命令コードの一覧は本マニュアルには収録されていない。
> **命令コードについては、RS-485通信対応製品のユーザーズマニュアルまたは機能編で確認すること**（原本 p.78、p.81、p.85 に明記）。
