## 1 設 定（p.24〜25）

> **スイッチを設定するときは、必ずNETC02-CCの電源を切ること。** 電源が投入されている状態で設定しても有効にならない。

### 1-1 RS-485通信対応製品の接続台数（`N-AXIS`）

出荷時設定：**1（1台接続）**

| N-AXIS | 接続台数 | N-AXIS | 接続台数 |
|---|---|---|---|
| 0 | 16 | 8 | 8 |
| 1 | 1 | 9 | 9 |
| 2 | 2 | A | 10 |
| 3 | 3 | B | 11 |
| 4 | 4 | C | 12 |
| 5 | 5 | D | 13 |
| 6 | 6 | E | 14 |
| 7 | 7 | F | 15 |

### 1-2 CC-Link局番の設定（`STATION No.`）

- 設定範囲：**01〜64**（62以上は使用できません。）
- 出荷時設定：1（×10：0、×1：1）
- ×10は10の位、×1は1の位。

> **要確認**：原本は「設定範囲 01〜64（62以上は使用できません。）」と記載。4局占有のため実質的に設定できる上限は 61。原本表記のまま記載する。

### 1-3 CC-Link伝送ボーレートの設定（`B-RATE`）

出荷時設定：**0（156 kbps）**

| B-RATE | 通信速度 |
|---|---|
| 0 | 156 kbps |
| 1 | 625 kbps |
| 2 | 2.5 Mbps |
| 3 | 5 Mbps |
| 4 | 10 Mbps |
| 5〜9 | 使用できません。 |

### 1-4 動作モードの設定（`SW2`）

| SW2 | 内 容 |
|---|---|
| No.1 | 使用しません。（OFFのままにしておいてください。） |
| No.2 / No.3 | CC-Link通信の**拡張サイクリック設定**を選択。出荷時設定：No.2、No.3ともにOFF（2倍） |
| No.4 | CC-Link通信の**リモートレジスタの配置**を設定。コマンドの実行方式が命令固定方式のときに使用。<br>OFF：1台あたり4ワードを配置／ON：1台あたり8ワードを配置。出荷時設定：OFF（4ワード） |

#### 拡張サイクリック設定（SW2 No.2 / No.3）

| No.2 | No.3 | 拡張サイクリック設定 |
|---|---|---|
| OFF | OFF | **2倍**（出荷時設定） |
| ON | OFF | 4倍 |
| OFF | ON | 8倍 |
| ON | ON | 使用しません。（設定しないでください。） |

> リモートレジスタを **1台あたり16ワード配置**にするときは、**操作パネルまたはMEXE02**で設定する（SW2では設定できない）。

### 1-5 RS-485通信の終端抵抗について
NETC02-CCはRS-485通信用の終端抵抗を内蔵している。**設定の必要はない。**

## 2 通信仕様（p.26〜27）

### 2-1 CC-Link通信仕様

| 項目 | 仕様 |
|---|---|
| 通信規格 | CC-Link Ver.2  拡張サイクリック設定 2倍、4倍、8倍 |
| 通信速度 | 156 kbps / 625 kbps / 2.5 Mbps / 5 Mbps / 10 Mbps |
| **局種別** | **リモートデバイス局** |
| **占有局数** | **4局占有** |
| 最大接続台数 | 64台（ただし下記の条件を満足すること） |
| 接続ケーブル | CC-Link専用ケーブル |

#### 最大接続台数の条件

1. **総局数**
   `(a + a2 + a4 + a8) + (b + b2 + b4 + b8)×2 + (c + c2 + c4 + c8)×3 + (d + d2 + d4 + d8)×4 ≦ 64`
2. **全リモート入出力点数**
   `(a×32 + a2×32 + a4×64 + a8×128) + (b×64 + b2×96 + b4×192 + b8×384) + (c×96 + c2×160 + c4×320 + c8×640) + (d×128 + d2×224 + d4×448 + d8×896) ≦ 8192`
3. **全リモートレジスタ点数**
   `(a×4 + a2×8 + a4×16 + a8×32) + (b×8 + b2×16 + b4×32 + b8×64) + (c×12 + c2×24 + c4×48 + c8×96) + (d×16 + d2×32 + d4×64 + d8×128) ≦ 2048`
4. **接続台数**
   `A×16 + B×54 + C×88 ≦ 2304`

記号の見方：

| 記号 | 意味 |
|---|---|
| a / b / c / d | 1局占有 / 2局占有 / 3局占有 / 4局占有 の **1倍**設定台数 |
| a2 / b2 / c2 / d2 | 同上の **2倍**設定台数 |
| a4 / b4 / c4 / d4 | 同上の **4倍**設定台数 |
| a8 / b8 / c8 / d8 | 同上の **8倍**設定台数 |
| A | リモートI/O局台数（最大64台） |
| B | リモートデバイス局台数（最大42台） |
| C | ローカル局、インテリジェントデバイス局台数（最大26台） |

> NETC02-CC は **4局占有のリモートデバイス局**なので、上式では `d2` / `d4` / `d8` に該当する。

#### ケーブル長

| 通信速度 | 156 kbps | 625 kbps | 2.5 Mbps | 5 Mbps | 10 Mbps |
|---|---|---|---|---|---|
| 局間ケーブル長 | 20 cm以上 | ← | ← | ← | ← |
| 最大ケーブル総延長 | 1200 m | 900 m | 400 m | 160 m | 100 m |

> NETC02-CCは CC-Link Ver.1.1 には対応していません。

### 2-2 拡張サイクリック設定

拡張サイクリック設定は **2倍が初期値**。初期値で扱える接続台数やリモートI/Oでは足りない場合に変更する。

| 拡張サイクリック設定 | 最大接続台数 | リモートI/O点数 | リモートレジスタ ワード数 |
|---|---|---|---|
| 2倍 | 8台 | 224点（16 bit×14） | 32ワード |
| 4倍 | 16台 | 448点（16 bit×28） | 64ワード |
| 8倍 | 16台 | 896点（16 bit×56） | 128ワード |

拡張サイクリック設定を変更すると、同時に使用できるコマンドやモニタの数が変わる。

| 拡張サイクリック設定 | リモートレジスタ ワード数 | 命令選択方式<br>コマンド実行領域の数 | 命令固定方式※1<br>データ設定/モニタの数 |
|---|---|---|---|
| 2倍 | 32ワード | 8 | 16 |
| 4倍 | 64ワード | 16 | 32 |
| 8倍 | 128ワード | 32 | 64※2 |

- ※1 32 bitのデータを使用した場合。
- ※2 4ワード配置の場合は32になります。

> 拡張サイクリック設定の違いは、リモートI/Oとリモートレジスタの**数**だけ。基本的な考え方は同じ。

#### 命令固定方式のリモートレジスタの配置 — 配置別の接続台数

| 拡張サイクリック設定 | 4ワード配置 | 8ワード配置 | 16ワード配置 | ユーザー指定配置 |
|---|---|---|---|---|
| 2倍 | 8台 | 4台 | 2台 | 8台 |
| 4倍 | 16台 | 8台 | 4台 | 16台 |
| 8倍 | 16台 | 16台 | 8台 | 16台 |

### 2-3 RS-485通信仕様

| 項目 | 仕様 |
|---|---|
| 電気的特性 | EIA-485準拠、ストレートケーブル。シールド付ツイストペア線（TIA/EIA-568B CAT5e以上を推奨）を使用し、総延長を50 mとする |
| 通信方式 | 半二重通信、調歩同期方式（データ：8 bit、ストップビット：1 bit、パリティ：なし） |
| 通信速度 | 625 kbps |
| プロトコル | GWプロトコル Ver.2（10 byte固定長フレーム、バイナリ転送）※当社専用のプロトコル |
| 最大接続台数 | 16台（CC-Link Ver.2の拡張サイクリック設定が4倍または8倍のとき） |
