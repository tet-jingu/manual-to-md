# 2 操作パネルによる操作（p.146〜166）

## 2-1 操作パネルの概要（p.146〜150）

- `OPERATION SW` を **「NETC」** → NETC02-CC のパラメータを設定したり、状態をモニタできる。
- `OPERATION SW` を **「ID0-15」** → RS-485通信対応製品の状態をモニタできる。

### 操作キー

| 操作キーの種類 | 内 容 |
|---|---|
| `MODE` | 操作モードを切り替えます。上の階層に移動します。 |
| `▲` / `▼` | 項目やデータを変更します。 |
| `SET` | 項目やデータを確定します。下の階層に移動します。 |

### 表示部の見方

表示部は7セグメントLED。（**アラビア数字の「5」とアルファベットの「S」は同じ表示です。**）

### 4桁以上の表示について

操作パネルでは最大10桁の数値と符号を表示できるが、7セグメントLEDが4つしかないため、5桁以上は分割表示される。
表示桁は［`▲`/`▼`］キーで切り替える。

| 数値の桁数 | 表示範囲 | 表示方法 |
|---|---|---|
| 3桁以下 | −999 〜 +999 | そのまま表示 |
| 4桁 | −9,999 〜 +9,999 | 符号 ＋ 下位4桁 |
| 5〜7桁 | −9,999,999 〜 +9,999,999 | 符号＋下位4桁 → 符号＋中位4桁（左端「M」）→ 下位4桁に戻る |
| 8〜10桁 | −9,999,999,999 〜 +9,999,999,999 | 符号＋下位4桁 → 符号＋中位4桁（「M」）→ 符号＋上位4桁（「H」）→ 下位4桁に戻る |

### 小数点と16進数の表示

- 小数点は、数字の右下に表示される。
- 数値を**16進数**で表示する場合は、**右端に丸印**が付く。
- 16進数の場合、操作パネルでは最大8桁を表示できる。5桁以上は上位4桁と下位4桁の2つに分けて表示する。
  **上位4桁の表示には、丸印が右から2桁目にも追加される。**

### 操作モードについて

操作パネルには複数の操作モードがあり、［`MODE`］キーで切り替える。

| `OPERATION SW` が「NETC」側 | `OPERATION SW` が「ID0-15」側 |
|---|---|
| モニタモード → パラメータモード → テストモード → システムモード → モニタモードに戻る | モニタモード → パラメータモード※ → テストモード → システムモード → アラームリセットモード → モニタモードに戻る |

※ 「操作パネルの接続製品初期化」パラメータ（ID：3420）が「無効」のときは遷移しません。

### 編集ロック機能

パラメータの編集などを禁止するときは、編集ロック機能を有効にする。

| モード | 制限される操作 |
|---|---|
| モニタモード | ・アラーム履歴のクリア<br>・通信エラー履歴のクリア<br>・インフォメーションのクリア |
| パラメータモード | 設定値の変更 |
| テストモード | 全操作 |

> 編集ロック機能は、`OPERATION SW` を**「NETC」側にして設定・解除**する。「ID0-15」側では設定・解除できない。

- **設定**：`OPERATION SW` が「NETC」側のときに、各モードのトップ画面で［`MODE`］キーを**5秒以上**押す。「`LK`」が表示され、編集ロック機能が有効になる。
- **解除**：再度、トップ画面で［`MODE`］キーを**5秒以上**押す。「`UnLK`」が表示され、解除される。

### 号機番号の選択（`OPERATION SW` が「ID0-15」側の場合）

- 号機番号は、各モードのトップ画面で選択する。いったん選択した号機番号は、モードを切り替えても有効。
- トップ画面から下の階層へ移る前に、［`▲`/`▼`］キーで号機番号を選択する。
- **号機番号は16進数で表示される。**
- **電源投入時に接続が確認された号機に対して、号機番号を選択できる。接続していない号機番号は表示されない。**

### エラー表示（p.150）★トラブル時の切り分けに使う

| エラーの内容 | 原因 |
|---|---|
| 操作パネルを操作したとき、ユーザーI/Fが通信中のため、実行不可 | ・MEXE02でダウンロードや初期化を実行しているときに、パラメータを書き込んだ。<br>・**マスタ局がリモートI/Oの入力をONにしているときに、リモートI/O入力テストを実行した。** |
| 操作パネルを操作したとき、NVメモリ処理中のため、実行不可 | NVメモリへの書き込み中に、操作パネルからNVメモリに書き込みを行なった。 |
| 操作パネルで設定したパラメータが設定範囲外 | IDを入力するパラメータで、範囲外の値を設定した。 |
| 操作パネルからのコマンド実行失敗 | ・テストモードでデータ転送を実行中、［`MODE`］キーを押してデータ転送を中止した。<br>・コマンドを実行したRS-485通信対応製品からエラーが返信された。 |
| 操作パネルからのコマンド実行不可 | NETC02-CCが処理中のときに、操作パネルを操作した。 |
| 操作パネルから、接続していない号機番号にアクセス | 接続していない号機番号を選択した。 |

> **要確認**：原本 p.150 の「エラー表示」列は7セグメント表示の画像で記載されており、テキストとして抽出できない。
> 本文中で判明している表示例：`Er.iF`（リモートI/O入力ONのまま入力テストを実行した場合、p.163）、`Er.FL`（データ転送を中止した場合、p.157）、`LK`（編集ロック）。
> 残りのコード文字列は原本 p.150 の図を参照すること。

## 2-2 モニタモードの操作（`OPERATION SW` が「NETC」側）（p.151〜153）

モニタモードでは、CC-Link通信の設定状態、アラーム、通信エラー、インフォメーションなどをモニタできる。

### モニタモードの階層

```
モニタモードのトップ画面
 ├ CC-Link関連
 │   ├ CC-Link局番
 │   ├ CC-Link伝送ボーレート   モニタ範囲：156k / 625k / 2.5M / 5M / 10M
 │   ├ CC-Linkサイクリック     モニタ範囲：cyc2（2倍）/ cyc4（4倍）/ cyc8（8倍）
 │   └ レジスタ配置            モニタ範囲：MAP.4 / MAP8 / MP.16 / MAP.U
 ├ RS-485通信スキャンタイム    0.1 ms単位で表示
 ├ 現在のアラーム → アラーム解除※1
 ├ アラーム履歴1〜9 → アラーム履歴クリア※2
 ├ 最新の通信エラー履歴
 ├ 通信エラー履歴1〜9 → 通信エラー履歴クリア※1
 ├ インフォメーション
 │   ├ 現在のインフォメーション → インフォメーション解除※2
 │   └ インフォメーション履歴1〜9 → インフォメーションクリア※1
 └ モニタ項目のID入力※3 → モニタ値
```

- ※1（アラーム解除）アラームが発生していないときは実行できません。
- ※2（アラーム履歴クリア／通信エラー履歴クリア／インフォメーションクリア）編集ロック機能が有効のときは表示されません。
- （インフォメーション解除）「インフォメーション自動クリア」パラメータ（ID：3375）が「有効」のときは表示されません。（初期値：有効）
- ※3 **モニタコマンドのIDを入力して、NETC02-CCをモニタします。** モニタコマンドのIDは `07_モニタ一覧`（原本 p.109）参照。

### 電源投入時の表示

NETC02-CCに電源を投入すると、初期表示として「**CC-Link局番**」が表示される。パラメータで変更できる。

| MEXE02ツリー表示 | ID | 名 称 | 内 容 | 初期値 |
|---|---|---|---|---|
| インターフェース | 3413 | 操作パネル初期モニタ（NETC） | 操作パネルの初期表示を設定します。<br>【設定範囲】0：CC-Link局番／1：RS-485通信スキャンタイム／2：最新の通信エラー履歴／3：現在のアラーム | 0 |

### インフォメーション履歴で確認できる内容

| 内 容 | 対応するビット出力 |
|---|---|
| コマンド処理中 | `INFO-CMDBSY` |
| PID異常 | `INFO-PID` |
| CC-Linkバージョン異常 | `INFO-CCVER` |
| 上位ネットワークバス異常 | `INFO-BUSOFF` |
| RS-485通信タイムアウト | `INFO-TMOUT` |
| パラメータライト制限 | `INFO-DATA` |
| テストモード | `INFO-TEST` |
| リブート要求 | `INFO-RBT` |
| なし | − |

> **要確認**：「表示」列（7セグメントの表示文字列）は原本が画像のため抽出できない。原本 p.153 参照。

## 2-3 パラメータモードの操作（`OPERATION SW` が「NETC」側）（p.154〜156）

パラメータモードでは、パラメータの設定および初期化を実行できる。

> 編集ロック機能が有効のときは、パラメータを変更できない。パラメータを確定しようとすると「`LK`」が表示される。

### パラメータモードの階層と設定範囲

```
パラメータモードのトップ画面
 ├ CC-Link通信の設定
 │   ├ CC-Link局番              設定範囲：-1（スイッチ設定を優先）、1〜64
 │   ├ CC-Link伝送ボーレート    設定範囲：-1、156k / 625k / 2.5M / 5M / 10M
 │   ├ CC-Link拡張サイクリック  設定範囲：-1、cyc.2 / cyc.4 / cyc.8
 │   └ レジスタ配置            設定範囲：-1、MAP.4 / MAP.8 / MP.16 / MAP.U
 ├ RS-485通信の設定
 │   ├ 接続台数設定源          設定範囲：-1（スイッチ設定を優先）、PAR.1（「接続台数」パラメータを優先）、
 │   │                                    PAR.2（「接続（号機番号）」パラメータを優先）
 │   └ 接続設定                設定範囲：1〜16
 ├ インフォメーションの設定
 │   ├ INFO LED表示            設定範囲：ON、OFF
 │   ├ INFO自動クリア          設定範囲：ON、OFF
 │   └ インフォメーションの機能（すべて設定範囲：ON、OFF）
 │       ├ コマンド処理中
 │       ├ プロダクトID異常
 │       ├ バージョン違い
 │       ├ バスオフ
 │       ├ RS-485通信タイムアウト
 │       ├ パラメータライト制限
 │       ├ テストモード中
 │       └ リブート
 ├ 操作パネルの設定
 │   ├ モニタ選択              設定範囲：ON（拡張）、OFF（基本）
 │   ├ テスト選択              設定範囲：ON（拡張）、OFF（基本）
 │   ├ テスト入力モニタ        設定範囲：ON（有効）、OFF（無効）
 │   └ モニタ更新周期          設定範囲：10〜2000（ms）
 ├ パラメータのID入力※1 → 設定
 └ パラメータ初期化※2 → 初期化実行
```

- ※1 **パラメータのIDを入力して、パラメータを選択します。** パラメータのIDは `06_パラメータ一覧`（原本 p.97）参照。
- ※2 編集ロック機能が有効のときは表示されません。

各項目は「入力（点滅）」→「確定（早い点滅）」で設定する。

## 2-4 テストモードの操作（`OPERATION SW` が「NETC」側）（p.157）

テストモードでは、**データ転送機能を実行できる**。MEXE02で設定したデータを、要求信号 `SDT-EXE` で送信する代わりに、操作パネルから書き込める。

> - **テストモードに移行している間は、MEXE02からNETC02-CCにアクセスできません。**
> - 編集ロック機能が有効のときは、テストモードを実行できない。トップ画面から下の階層に移ろうとすると「`LK`」が表示される。

```
テストモードのトップ画面
 └ データ転送実行
     ├ データ転送No.0 → 転送開始（点滅）
     ├ ・・・
     └ データ転送No.7 → 転送開始（点滅）
```

- データ転送が正常に終了すると、「`End`」が表示される。
- データ転送を中止するときは、［`MODE`］キーを押す。操作パネルには「`Er.FL`」が表示される。

## 2-6 モニタモードの操作（`OPERATION SW` が「ID0-15」側）（p.160〜162）

```
モニタモードのトップ画面（号機番号を選択）
 ├ 現在のアラーム → アラーム解除
 ├ リモートI/O入力モニタ（ビット表示）
 ├ リモートI/O出力モニタ（ビット表示）
 └ 基本モニタ※1 → モニタ値※2
```

- ※1 RS-485通信対応製品の種類によって、基本モニタの項目が異なります。
- ※2 基本モニタの項目によって異なります。

### リモートI/Oモニタ ★7セグの各セグメントが1ビットに対応

選択したRS-485通信対応製品のリモートI/O（NET-IO）のON/OFF状態を確認できる。
**7セグメントLEDがそれぞれの信号に対応**している。信号がONのときは点灯、OFFのときは消灯。

リモートI/O入力の場合の割り付け（4桁の7セグ、各桁7セグメント）：

| 桁 | 上セグメント群 | 下セグメント群 |
|---|---|---|
| 1桁目 | NET-IN0 / NET-IN1 / NET-IN2 / NET-IN3 | NET-IN7 / NET-IN6 / NET-IN5 / NET-IN4 |
| 2桁目 | NET-IN12 / NET-IN13 / NET-IN14 / NET-IN15 | NET-IN11 / NET-IN10 / NET-IN9 / NET-IN8 |

リモートI/O出力の場合も同様（NET-OUT0〜15）。

> **要確認**：原本 p.160 は7セグメントの各セグメント位置を図で示している。上表は原本のラベル並びをそのまま転記したもので、
> どのセグメント（a〜g）がどの信号に対応するかは原本の図を参照すること。
> 表示例（p.161）：NET-IN7、NET-IN10、NET-IN11、NET-IN14 がON、それ以外はOFFの場合。

## 2-8 テストモードの操作（`OPERATION SW` が「ID0-15」側）（p.163〜165）

> - 編集ロック機能が有効のときは、テストモードを操作できない。「`LK`」が表示される。
> - **リモートI/Oの入力がONになっているときは、リモートI/O入力テストを実行できない。**（エラー「`Er.iF`」が表示されます。）
>   → **テスト前にマスタ局側のラダーを停止するか、RYをすべてOFFにしておくこと。**

```
テストモードのトップ画面
 ├ リモートI/O入力テスト
 │   ├ NET-IN0（信号ON / 信号OFF）
 │   ├ ・・・
 │   └ NET-IN15（信号ON / 信号OFF）
 │       └ 「操作パネルのテスト入力モニタ」パラメータ（ID：3418）が「有効」のときは、
 │          信号名を表示した後にモニタ項目を選択できる※ → モニタ値の下位4桁
 └ メンテナンスコマンド選択 → コマンドの実行（点滅）
```

※ **出荷時に割り付けられているNET-INの入力信号を変更すると、信号名は表示されません。**

### リモートI/O入力テスト

［`SET`］ボタンでも入力信号をON/OFFできる。［`SET`］キーを押す、または押し続けると信号がON。［`SET`］キーを離すとOFF。

#### テスト入力モニタ（`●` ＝ 対応）

| モニタ内容 | AR | AZ | RKⅡ<br>PKA | CRK | BLE<br>BLV |
|---|---|---|---|---|---|
| 指令位置 | ● | ● | ● | ● | − |
| 指令速度（r/min） | ● | ● | ● | − | ● |
| 指令速度（Hz） | − | − | − | ● | − |
| フィードバック位置 | ● | ● | − | − | − |

# 3 MEXE02による設定とモニタ（p.167〜179）

> MEXE02 の基本操作やデータの保存については、MEXE02 の取扱説明書を参照。

## 3-1 パラメータの設定

### データ転送機能を使う場合（p.167）

1. データを設定します。データの入力方法は2種類。
   - **号機番号と命令コードを直接入力する**：MEXE02の画面上で、データを入力するセルをダブルクリックし、キーボードで数値を入力。
   - **「命令コード設定支援」で入力する**：
     1） 「設定号機（Hex）」でデータ転送する号機番号を選択します。
     2） 「シリーズ選択」で製品のシリーズを選択します。
     3） 「運転データ」、「パラメータ」、および「**メンテナンス**」のタブから、命令コードの種類を選択します。
     4） 「内容」の中から、実行する命令コードの名称を選択します。命令コードが「選択命令コード」に表示されます。
     5） 「設定データNo.」で、命令コードを設定するデータNo.を選択します。
     6） ［書き込み命令コード確定］または［読み出し命令コード確定］をクリックします。
2. ［データの書き込み］をクリックします。

> 「命令コード設定支援」はデータの入力を支援するもの。データの領域をクリックしても、内容は表示されません。

### 命令固定方式のレジスタ配置を「ユーザー指定配置」で使う場合（p.168〜169）

1. **「レジスタ配置モード」パラメータを「ユーザー指定」に設定**します。
   > 「レジスタ配置モード」パラメータは、**電源の再投入後に有効**になります。
2. 命令コードの設定をします。入力方法は2種類。
   - **号機番号と命令コードを直接入力する**
   - **「命令コード設定支援」で入力する**：
     1） 「設定号機（Hex）」で実行する号機番号を選択します。
     2） 「シリーズ選択」で製品のシリーズを選択します。
     3） 「運転データ」、「パラメータ」、および「**モニタ**」のタブから命令コードの種類を選択します。
     4） 「内容」の中から、実行する命令コードの名称を選択します。
     5） 「設定レジスタNo.」で、命令コードを設定するレジスタNo.を選択します。
     6） ［**32bit命令コード確定**］または［**16bit命令コード確定**］をクリックします。

   > **★命令コードのbitは、データの桁数に応じて決定してください。データが負の値、または5桁（32767：`7FFFh`）以上になる場合は、32bitを選択してください。**
3. ［データの書き込み］をクリックします。

> - **コマンド実行（命令固定方式）のレジスタ配置モードを「ユーザー指定」に設定しないと、データが書き込まれません。**
> - 「命令コード設定支援」はレジスタ配置（ユーザー指定）の入力を支援するもの。領域をクリックしても内容は表示されません。

## 3-2 モニタ（p.169〜179）★デバッグ用ツール一覧

| モニタ | 内 容 |
|---|---|
| **本体情報モニタ** | NETC02-CCの機器情報をモニタできます。 |
| **RS-485ステータスモニタ1** | RS-485通信対応製品との通信状態をモニタします。 |
| **RS-485ステータスモニタ2** | RS-485通信対応製品のアラームをモニタします。 |
| **通信エラーモニタ** | RS-485通信のエラー情報をモニタできます。通信エラーが発生したときは、アラームコード、原因、および処置を確認してください。 |
| **通信実行履歴モニタ** | RS-485通信の実行履歴をモニタできます。**コマンドの実行状態や履歴が残るため、デバッグに活用できます。** |
| **リモートI/Oモニタ** | RS-485通信対応製品のネットワークI/OのON/OFF状態をモニタできます。 |
| **リモートI/Oモニタ（制御）** | コマンドの制御入力と状態出力のON/OFF状態と、NETC02-CCの制御入力と状態出力のON/OFF状態をモニタできます。 |
| **リモートレジスタモニタ** | リモートレジスタへの書き込み（RWw）と読み出し（RWr）の状態をモニタできます。 |
| **アラームモニタ** | NETC02-CCのアラーム情報をモニタできます。 |
| **インフォメーションモニタ** | NETC02-CCのインフォメーション情報をモニタできます。 |

各モニタは、ツールバーのアイコンまたはショートカットボタンから起動し、［〜モニタを開始する］をクリックして開始、チェックを外して終了する。

### RS-485ステータスモニタ1 の表示内容

- ※1 **RS-485通信の接続状態**を表示します。
  - ON（緑色）：接続要求あり／接続応答あり
  - OFF（白色）：接続要求なし／接続応答なし
- ※2 モニタする内容が表示されます。
  - 「命令固定方式のモニタ選択」パラメータが「自動」の場合：命令固定方式の先頭に設定されているモニタの内容が表示されます。
  - 「命令固定方式のモニタ選択」パラメータが「自動」以外の場合：設定した内容が表示されます。モニタできる内容は製品ごとに異なります（`06_パラメータ一覧` 9-5 参照）。

### 通信エラーモニタ の表示内容

- ※1 コードの詳細は `08_保護通知機能` 11-3「通信エラーの内容」（原本 p.119）参照。
- ※2 サブコードの詳細は `08_保護通知機能` 11-3「通信エラーのサブコード一覧」（原本 p.120）参照。
- ※3 電源が投入されてから通信エラーが発生するまでの時間を表示します。

- ※1 コードの詳細は `08_保護通知機能` 11-4「要求コード一覧」（原本 p.121）参照。
