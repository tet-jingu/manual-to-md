# 3 操作編 / 1 ガイダンス（操作例）— NETC02-CC

> 原典 `HM-60286J.pdf` p.124〜145
> **★このファイルが「実アドレス付きのプログラム例」。ラダーを書くときはまずここを見る。**
> 原本の例は **マスタ局のデバイス割り付けを固定した実アドレス**で書かれているので、そのままラダーに落とせる。

## 全体の流れ（p.124）

```
STEP1 設置と接続        （p.126）
   ↓
STEP2 NETC02-CCの設定   （p.127）
   ↓
STEP3 ドライバの設定    （p.127）
   ↓
STEP4 電源の投入とLED確認（p.128）
   ↓
コマンド実行方式を選択してデータを設定
   ├─ 命令選択方式   （p.129）命令コード、号機番号、およびデータを設定して実行。要求信号「D-REQ」
   ├─ 命令固定方式   （p.136）データを読み込んだり書き込んで実行。命令コードと号機番号は固定。
   │                          要求信号「WR-REQ」で書き込み開始、「RD-REQ」で読み出しとモニタ開始
   └─ データ転送機能 （p.143）MEXE02でNETC02-CCにデータを設定。要求信号「SDT-EXE」で実行
```

> NETC02-CCに接続できるRS-485通信対応製品の**命令コードやリモートI/Oについては、該当するRS-485通信対応製品のユーザーズマニュアル、または機能編**を参照すること。

### この割り付けでのアドレス換算表

| マニュアル表記（相対） | 実デバイス | 換算 |
|---|---|---|
| RY00 | **RY1000** | `RY1000 + オフセット` |
| RX00 | **RX1000** | `RX1000 + オフセット` |
| RWw00 | **W100** | `W100 + オフセット` |
| RWr00 | **W0** | `W0 + オフセット` |

> **原本の表記について**：p.129以降の操作例では、書き込み側を `RWw100`〜`RWw10F`、読み出し側を `RWr0`〜`RWrF` と表記している。
> これは上のネットワークパラメータ（RWw→`W100`、RWr→`W0`）を反映した**実アドレス付きの表記**で、
> `RWw100` はマスタ局の `W100`、`RWr0` は `W0` に対応する。以下、原本の表記のまま記載する。

主要信号の実アドレス（この例での値）：

| 信号 | 相対 | 実デバイス |
|---|---|---|
| 号機番号0 の NET-IN3（START） | RY03 | `RY1003` |
| 号機番号0 の NET-IN15（RVS / AZは RV-POS） | RY0F | `RY100F` |
| 号機番号1 の NET-IN3（START） | RY13 | `RY1013` |
| 号機番号1 の NET-IN15（RVS） | RY1F | `RY101F` |
| D-REQ0 | RY80 | `RY1080` |
| D-REQ1 | RY82 | `RY1082` |
| D-REQ2 | RY84 | `RY1084` |
| D-REQ3 | RY86 | `RY1086` |
| D-END0 | RX80 | `RX1080` |
| D-END1 | RX82 | `RX1082` |
| D-END2 | RX84 | `RX1084` |
| D-END3 | RX86 | `RX1086` |
| WR-REQ0 | RY90 | `RY1090` |
| WR-DAT0 | RX90 | `RX1090` |
| RD-REQ0 | RY92 | `RY1092` |
| RD-DAT0 | RX92 | `RX1092` |
| SDT-EXE0 | RY98 | `RY1098` |
| SDT-END | RX98 | `RX1098` |

> **モーターを動かすときは周囲の状況を確認し、安全を確保してから運転してください。**
> NETC02-CCは、RS-485通信用の終端抵抗を内蔵しています。設定の必要はなく、そのままお使いいただけます。

## STEP 1 設置と接続を確認します（p.126）

- AZシリーズドライバ（号機番号0）：MOTOR にモーター用ケーブル、ENCODER にエンコーダ用ケーブル、CN6またはCN7 にRS-485通信ケーブル、主電源（L/N/PE）
- ARシリーズドライバ（号機番号1）：CN2 にRS-485通信ケーブル、モーター用ケーブル、主電源（L/N/PE）、**終端抵抗ON**
- NETC02-CC：CN1コネクタ（DC24 V電源、+24 V / 0 V、FG）、CN2 にCC-Link通信ケーブル、CN6 にRS-485通信ケーブル、USB通信コネクタにMEXE02（パソコン）
- マスタ局側：CC-Link通信ケーブル、**終端抵抗※**

※ 終端抵抗は付属していません。（110 Ω、1/2 W）

# 1-1 命令選択方式の操作例（p.129〜135）

```
STEP1 動作確認              RVS方向の連続運転を実行し、動作するか確認します。
STEP2 位置決め運転の実行    位置データをセットし、動作するか確認します。
STEP3 フィードバック位置のモニタ  STEP2の位置決め運転が正しく実行されたか確認します。
STEP4 NVメモリ書き込み      位置データをNVメモリに書き込みます。
```

## 要求信号の使い方（★D-REQ を用途で使い分ける）

操作例では、リモートレジスタにセットする内容によって、要求信号を使い分けている。

### 運転データ、メンテナンスコマンド用

| 要求信号 | 書き込み（RWw） | 読み出し（RWr） |
|---|---|---|
| D-REQ0 | RWw100, RWw101, RWw102, RWw103 | RWr0, RWr1, RWr2, RWr3 |
| D-REQ1 | RWw104, RWw105, RWw106, RWw107 | RWr4, RWr5, RWr6, RWr7 |

### モニタコマンド用

| 要求信号 | 書き込み（RWw） | 読み出し（RWr） |
|---|---|---|
| D-REQ2 | RWw108, RWw109, RWw10A, RWw10B | RWr8, RWr9, RWrA, RWrB |
| D-REQ3 | RWw10C, RWw10D, RWw10E, RWw10F | RWrC, RWrD, RWrE, RWrF |

> **設計パターン**：D-REQ0/1（号機0/1用）を「単発コマンド用（書き込み・メンテナンス）」、D-REQ2/3（号機0/1用）を「常時モニタ用」に固定して割り当てる。
> モニタ用の D-REQ は ON のまま保持し、単発用の D-REQ だけを OFF→ON→OFF する。

## STEP 1 リモートI/OでRVS方向へ連続運転を実行し、動作するか確認します（p.129）

1. RVS方向へ連続運転を開始します。
   号機番号0 はAZシリーズなので「`RV-POS`」を、号機番号1 はARシリーズなので「`RVS`」をONにしてください。

**マスタ局 → NETC02-CC**

| 号機番号 | リモートI/O | アドレス | 入力値 | 説明 |
|---|---|---|---|---|
| 0 | RV-POS | `RY100F` | 1 | 連続運転の実行 |
| 1 | RVS | `RY101F` | 1 | 連続運転の実行 |

2. 連続運転を停止します。`RV-POS` と `RVS` をOFFにしてください。

| 号機番号 | リモートI/O | アドレス | 入力値 | 説明 |
|---|---|---|---|---|
| 0 | RV-POS | `RY100F` | 0 | 連続運転の停止 |
| 1 | RVS | `RY101F` | 0 | 連続運転の停止 |

> 動作しないときは、**スイッチの設定、リモートI/O、およびリモートレジスタの割り付け**を確認してください。

## STEP 3 フィードバック位置をモニタします（p.133〜134）

1. モニタコマンド「フィードバック位置（`2066h`）」を `RWw108`〜`RWw10B`（号機0）／`RWw10C`〜`RWw10F`（号機1）にセット（STEP2 2-2 と同じ）。
2. `D-REQ2`（`RY1084`）／`D-REQ3`（`RY1086`）をON。
3. `D-END2`（`RX1084`）／`D-END3`（`RX1086`）が「1」になると、フィードバック位置のモニタが始まります。
   **`D-REQ` がONの間、モニタを継続します。**

| 号機番号 | アドレス | レスポンス | 説明 |
|---|---|---|---|
| 0 | `RWr8` | `2066h` | 命令コード応答（フィードバック位置） |
| 0 | `RWr9` | `0h` | 号機番号応答 |
| 0 | `RWrA` / `RWrB` | `5000`（`1388h`） | データ（下位）／データ（上位） |
| 1 | `RWrC` | `2066h` | 命令コード応答（フィードバック位置） |
| 1 | `RWrD` | `1h` | 号機番号応答 |
| 1 | `RWrE` / `RWrF` | `5000`（`1388h`） | データ（下位）／データ（上位） |

4. モニタを終了します。`D-REQ2`（`RY1084`）／`D-REQ3`（`RY1086`）をOFF。

| 0 | `RWw101` | `0h` | 号機番号 |
| 0 | `RWw102` | `1` | データ（下位） |
| 0 | `RWw103` | `0` | データ（上位） |
| 1 | `RWw104` | `30C9h` | 命令コード（NVメモリ一括書き込み） |
| 1 | `RWw105` | `1h` | 号機番号 |
| 1 | `RWw106` | `1` | データ（下位） |
| 1 | `RWw107` | `0` | データ（上位） |

**2. `D-REQ0`（`RY1080`）／`D-REQ1`（`RY1082`）をON → `D-END0`（`RX1080`）／`D-END1`（`RX1082`）が「1」になる。**

**3. ドライバに書き込まれた値（`RWr0`〜`RWr7`）が、セットした値と一致していることを確認 → `D-REQ` をOFF。**

> **CC-Link通信で設定したデータはRAMに保存されるため、電源を切ると消去されます。「NVメモリ一括書き込み」を行なうと、データはNVメモリに保存されるため、電源を切っても保持されます。**

### 本例で使用したメンテナンスコマンド

| 命令コード | 内 容 | データ領域 |
|---|---|---|
| `30C5h` | P-PRESET実行（現在位置を0にする） | **`1` をセットすること**（0だと実行されない） |
| `30C9h` | NVメモリ一括書き込み | **`1` をセットすること** |

## STEP 1 MEXE02を使って、データをNETC02-CCに設定します（p.143）

1. MEXE02 を起動します。「**NETC**」→「**NETC CC-Link Ver.2 対応**」を選択してください。
2. **データのNo.0 とNo.1 に、位置No.0 の命令コード（`1200h`）と位置データ「5000」を入力します。**
   運転データNo.0 の**順送り転送を「順送りあり（+1）」**にすると、1回の書き込みでデータを号機番号0 と号機番号1 に書き込むことができます。
   > 「命令コード設定支援」を利用すると、命令コードを簡単に入力できます。詳細は p.167。
3. データ転送の「**SDT-EXE0**」に、データ転送の起点となるデータNo.0 を入力します。
4. データをNETC02-CCに書き込みます。ツールバーの［データの書き込み］をクリックしてください。
