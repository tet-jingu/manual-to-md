## 4.1 運転の基本 (4.1 / 印刷 p.4-1 / 原本 p.125)

### 4.1.1 電源投入手順 (4.1.1 / 印刷 p.4-1 / 原本 p.125)

次の手順は、パラメーターが出荷時設定のままでエラーの発生や非常停止状態ではない場合の手順です。

#### 〔1〕電源投入手順 (4.1.1〔1〕 / 印刷 p.4-1 / 原本 p.125)

電源投入の順番は以下のとおりです。

① 配線が正しいことを確認し、あらかじめ周辺機器電源（PIO 用 24V 電源、フィールドネットワーク）を供給します。
② 制御電源を供給します。
③ モーター駆動源を供給します。

【図】電源投入タイミングチャート (4.1.1〔1〕 / 原本 p.125)
- 信号(上から): 周辺機器電源 / 制御電源（24V） / モーター駆動源（24V） / コントローラー状態
- 周辺機器電源: 制御電源投入(破線)より前に立ち上がる線に「先行投入」の矢印。もう1本、制御電源投入後(初期化の途中)に立ち上がる線があり、「初期化時に電源供給、接続状態などを診断」と注記
- 制御電源（24V）: 破線の位置で立ち上がる
- モーター駆動源（24V）: 制御電源の立上りの少し後に立ち上がる
- コントローラー状態: 制御電源投入後「初期化/自己診断」→「通常運転状態」

> 注 制御電源とモーター電源は、同時または制御電源を先に供給してください。モーター駆動源は、制御電源投入から 1 秒以内に投入してください。1 秒以上経過するとアラーム（モーター電圧低下）が発生します。（CON 系の 24V コントローラの場合、モーター電源電圧低下が起きてもアラームは発生しません。）

#### 〔2〕電源断手順 (4.1.1〔2〕 / 印刷 p.4-1 / 原本 p.125)

電源投入時と逆の順番に実施してください。

> 注 制御電源を遮断するときに、アラーム 0CE “制御電源電圧低下” が発生する場合がありますが、異常ではありません。

### 4.1.2 運転方法の基本 (4.1.2 / 印刷 p.4-2 / 原本 p.126)

運転方法にはポジショナーモードとパルス列制御モードの 2 種類があります。システムに合わせてどちらかを選択してください。
アクチュエーターには、スライダータイプ、ロッドタイプ、ロータリータイプ、グリッパータイプなど様々なタイプがありますが、本書の中で特別な記載のないかぎり、運転制御方法は同一です。

#### 〔1〕ポジショナーモード (4.1.2〔1〕 / 印刷 p.4-2 / 原本 p.126)

【図】ポジショナーモードのシステム構成イメージ (原本 p.126)
- 上位コントローラー → コントローラー: 信号「ポジションNo. ＋ スタート信号」
- コントローラー → 上位コントローラー: 信号「完了信号」
- ティーチングツール → コントローラー: 「ポジション・速度・加減速データ等を入力」「コントローラーのポジションテーブルを編集」
- コントローラー — アクチュエーター (ケーブル接続)
- ポジションテーブル例: No / 位置[mm] / 速度[mm/s] / 加速度[G] / 減速度[G]。No.0 空欄、No.1 = 100.00 / 100.00 / 0.30 / 0.30、No.2 = 200.00 / 200.00 / 0.30 / 0.30

**●運転準備・・ポジションデータの登録（パソコン専用ティーチングソフトの登録例）** (原本 p.126-127)

- 手順 1：コントローラーの電源を ON します。
- 手順 2：パソコン専用ティーチングソフトを起動し、コントローラーと接続します。

【図】接続手順の画面 (原本 p.126)
- 「接続軸チェック」画面(軸番号 0 = 接続、1 = (確認中)) → 接続可能なコントローラーに自動接続
- 「MANU動作モード選択」画面(ティーチモード1(セーフティ速度有効/PIO起動禁止)) → OK を押す（接続モード確認）
- → パソコン専用ティーチングソフト起動

- 手順 3：サーボを ON し、原点復帰を行います。(印刷 p.4-3 / 原本 p.127)

【図】サーボON・原点復帰の画面 (原本 p.127)
- メニューのポジション→編集/ティーチ → ポジションテーブルを開く
- ① サーボ を押す
- ② サーボランプ点灯
- ③ 原点 を押す
- ④ 原点ランプ点灯（アクチュエーターが停止した後）

- 手順 4：アクチュエーターのスライダーやロッドの移動先（位置）を決めます。
  - ① あらかじめ設定したい座標値がわかっている場合
    ポジジョンテーブルの位置の欄に移動先を書込みます。
    座標値を書込むと速度や加減速度の欄には、パラメーターでの設定値が自動入力されます。
    【図】No.0 の位置に 10 を入力 → No.0 = 10.00 / 150.00 / 0.20 / 0.20 と自動入力される画面例
  - ② 設定したい座標値がわかっていない場合
    インチング・ジョグ動作で直接位置に移動し、位置取込みを押します。
    【図】ポジションデータ編集画面: ジョグ（後退）＝「後退(-)」ボタン、ジョグ（前進）＝「前進(+)」ボタン、「位置取込み」ボタン
    ※インチング・ジョグ動作の代わりにダイレクトティーチで行うことも可能です。
- 手順 5：ポジションテーブルに書込んだデータをコントローラーに転送します。

【図】転送手順の画面 (原本 p.127)
- 転送前は赤文字 (例: No.0 = 10.00 / 150.00 / 0.20 / 0.20、No.1 = 50.00 / 150.00 / 0.20 / 0.20、No.2 = 100.00 / 150.00 / 0.20 / 0.20)
- コントローラー転送を押す → 確認ダイアログ「ポジションデータ(No.0～63)を転送します。よろしいですか?」で OK を押す
- 転送完了で黒文字となる

**●運転準備・・ポジションデータの登録（IA-OS の登録例）** (印刷 p.4-4 / 原本 p.128)

- 手順 1：コントローラーの電源を ON します。
- 手順 2： “IA-OS” を起動し、コントローラーと接続します。

【図】IA-OS 接続手順の画面 (原本 p.128)
- 通信方式（オンライン）を選択 (画面: シリアル通信(USB/TPポート) / Ethernet通信(LANポート)、通信速度 115,200[bps]、オフライン(コントローラーと通信しない))
- 接続するコントローラーを選択し、通信開始を押す (画面例: COM5 / No.0 PCON-CB)
- はいを押す（安全回路確認）
- ティーチモード、有効を選択し OK を押す (MANU動作モード設定画面: 制御方法 = ティーチモード(アプリケーションから動かす) / モニターモード(外部機器から動かす)、セーフティ速度 = 有効(最高速度を制限する) / 無効)
- IA-OS を起動

- 手順 3：サーボを ON し、原点復帰を行います。

【図】IA-OS のサーボON・原点復帰 (原本 p.128)
- メニューのポジションデータ→ポジションデータ編集を選択
- TEST 試運転を押す または、表示切替から試運転を選択

    TEST 試運転を押す、または、編集サポート機能表示選択 “試運転” を選択します。
    インチング・ジョグでスライダーやロッドを移動させます。

**●運転・・出荷時パラメーター（PIO パターン 0）の例** (印刷 p.4-6 / 原本 p.130)

- 手順 1：上位コントローラーなどから位置決めを行いたいポジション No.をバイナリーデータ（PC1～PC32）で入力後、スタート信号（CSTR）を ON します。

|---|---|---|---|

### 4.1.3 パラメーターの設定 (4.1.3 / 印刷 p.4-8 / 原本 p.132)

パラメーターはシステムやアプリケーションに合わせて設定するデータです。パラメーターとは変数の意味で携帯電話の着信音やマナーモードの設定、時計やカレンダーの設定などと同じで、使い方に合わせて設定します。

（パラメーターの例）

| パラメーター | 内容 |
|---|---|
| ソフトストロークリミット | ストロークエンドあるいは周辺装置との干渉や安全のために動作範囲を設定します。 |
| ゾーン出力 | 動作範囲の任意の位置範囲で信号出力の欲しいときに設定します。 |

パラメーターは運転の前に、あらかじめ使い方に合わせて設定するものであり、一度設定すれば、運転のたびに設定する必要はありません。

パラメーターの種類と詳細は、［第 6 章 パラメーター］を参照してください。

#### （5）減速度〔G〕： (4.2.2 項目5 / 印刷 p.4-14 / 原本 p.138)

停止時の減速度を設定します。

> **注意**
> ●カタログまたはアクチュエーターの取扱説明書に記載されている定格加減速度を超えないように設定してください。定格加減速度を超えて設定するとアクチュエーターの寿命を著しく損なう場合があります。
> ●アクチュエーターやワークに衝撃や振動が発生する場合は、加減速度を下げてください。このような場合、そのまま使用を続けますとアクチュエーターの寿命を著しく損ないます。
> ●搬送質量が定格可搬質量に対し著しく軽い場合、タクトタイム短縮のため定格加減速度以上の設定を行える場合があります。カタログまたはアクチュエーターの取扱説明書にて、仕様を確認してください。
> ●グリッパータイプの場合、速度・加減速度の設定は、片フィンガーを基準として設定を行ってください。したがって、両フィンガー間の相対速度、相対加減速度は 2 倍となりますので注意してください。

> **参考**
> ●加速度について説明します。減速度も考え方は同じです。
> 1G=9,800mm/s²：1 秒間に 9,800mm/s まで加速できる加速度
> 0.3G：1 秒間に 9,800mm/s×0.3＝2,940mm/s まで加速できる加速度

#### 〔3〕サーボ ON（SON、SV、PEND） (4.2.4〔3〕 / 印刷 p.4-24 / 原本 p.148)

① サーボ ON 信号 SON はアクチュエーターのサーボモーターを運転可能な状態にする入力信号です。
② サーボ ON が実行され運転が可能になると出力信号の SV 信号が ON します。同時に位置決め完了信号 PEND が ON します。

#### 〔4〕原点復帰（HOME、HEND、PEND、MOVE） (4.2.4〔4〕 / 印刷 p.4-25 / 原本 p.149)

| PIO 信号 | 入力 HOME | 出力 HEND | 出力 PEND | 出力 MOVE |
|---|---|---|---|---|

| パターン 2～4 | ○ | ○ | ○ | × |
| パターン 5 | ×（注 1） | ○ | × | × |

HOME 信号は原点復帰を行うための信号です。HOME 信号を ON するとこの信号は立上がり（ON エッジ）で処理され、原点復帰を開始します。原点復帰を完了すると原点復帰完了信号 HEND が ON します。
HEND の ON 後、HOME 信号を OFF してください。原点復帰完了信号 HEND は、一度 ON すると原点を外れても ON しています。（原点を失って未確定になった場合、HEND は OFF となります。）HEND が ON の状態でも、HOME 信号を ON することにより、再度原点復帰を行います。原点復帰動作中 HEND は OFF し、原点復帰を完了すると再度 ON します。

【図】原点復帰のタイミングチャート (4.2.4〔4〕 / 原本 p.149)
- 信号(上から): 原点復帰信号 HOME（PLC → コントローラー） / 原点復帰完了信号 HEND（コントローラー → PLC） / 位置決め完了信号 PEND（コントローラー → PLC） / 移動中信号 MOVE（コントローラー → PLC）
- HOME の立上り → 矢印で HEND OFF、PEND OFF、MOVE ON (同じタイミング、破線)
- HEND は HOME 立上り前は ON で描かれ、OFF レベルに破線がある (未確定時は OFF のケースを示す)
- 原点復帰完了 → HEND ON、PEND ON、MOVE OFF (同じタイミング、破線)
- HEND の ON → 矢印で HOME OFF (PLC 側で HOME を OFF する)

また原点復帰動作中は位置決め完了信号 PEND は OFF となり、移動中信号 MOVE は ON となります。

② PLC では、アラーム信号*ALM をストローブ信号としてバイナリーコードを読取り、アラーム内容を確認できます。

バイナリーコードの詳細は［8.3.1 簡易アラームコード］を参照してください。

#### 〔8〕ブレーキ解除（BKRL） (4.2.4〔8〕 / 印刷 p.4-34 / 原本 p.158)

| PIO 信号 | 入力 BKRL |
|---|---|
| パターン 0 | ○ |
| パターン 1（注 1） | × |
| パターン 2～7 | ○ |

○：あり、×：なし

> 注 1 パターン 1 には、本機能はありません。

BKRL 信号が ON の間、ブレーキが開放されます。ブレーキ付アクチュエーターの場合、ブレーキはサーボ ON/OFF により、自動的に制御されますが、装置への組付けや、ダイレクトティーチ※1 などを行う時、手でスライダーやロッドを動かすためにブレーキの解除が必要な場合があります。この操作は、コントローラー前面パネルのブレーキ解除スイッチのほか、ブレーキ解除信号 BKRL によっても行うことができます。

※1 ダイレクトティーチ：手でスライダーやロッドを動かしてポジションテーブルへ座標値を取込む操作

> **警告**
> ●ブレーキの解除は、十分に注意して行ってください。不用意に行うと、スライダーあるいはロッドの落下により、けがや、アクチュエーター本体、ワークまたは装置などの破損の原因となります。
> ●ブレーキの解除後は、必ずブレーキを有効状態に戻してください。ブレーキ開放状態のまま運転を行うとたいへん危険です。スライダーあるいはロッドの落下により、けがや、アクチュエーター本体、ワークまたは装置などの破損の原因となります。
> ●必ず本信号が必ず OFF（ブレーキ有効）の状態でコントローラーの電源を投入してください。
> ●本信号が ON（ブレーキ解除）の状態で、AUTO と MANU を切替えることは禁止しますリセット信号 RES は、アラーム発生中はアラームリセット、一時停止中は、動作を中断（残移動量のキャンセル）する二つの機能を持った信号です。
> 一時停止中の動作の中断については各パターンの運転説明の項を参照してください。

(4.2.5 ポジション No.入力運転（PIO パターン 0～3、6）は原本 p.159 から。別担当)
