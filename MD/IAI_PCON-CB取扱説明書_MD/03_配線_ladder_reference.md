## 3.1 ポジショナーモード(PIO 制御) (3.1 / 印刷 p.3-1 / 原本 p.76)

### 3.1.1 配線図(構成機器の接続) (3.1.1 / 印刷 p.3-1 / 原本 p.76)

【図】ポジショナーモードの構成機器の接続図 (原本 p.76)
- コントローラー(PCON)の SIO コネクターに、ティーチングボックス(別売)またはパソコン専用ティーチングソフト(別売)を接続(パソコンは USB ケーブル → 変換ユニット経由)
- PIO コネクター ← フラットケーブル → 上位システム(PLC など・・お客様準備)。I/O 制御電源(DC24V・・お客様準備)
- モーター・エンコーダーコネクター → アクチュエーター
- 電源コネクター → 非常停止回路、制御/駆動電源(DC24V・・お客様準備)

> **注意**
> ●パソコン専用ティーチングソフトやティーチングボックスとコントローラーの接続用コネクターの抜挿しは、コントローラーの電源を OFF してから行ってください。
> 電源 ON のまま抜挿しを行うとコントローラーの故障の原因となります。

### 3.1.3 配線 (3.1.3 / 印刷 p.3-7 / 原本 p.82)

#### 〔1〕電源コネクター部（電源および非常停止部） (3.1.3〔1〕 / 印刷 p.3-7 / 原本 p.82)

##### ① ティーチングボックスの停止スイッチを有効にし、アクチュエーターを動作させる (3.1.3〔1〕① / 印刷 p.3-7 / 原本 p.82)

●回路例

【図】ティーチングボックスの停止スイッチを有効にし、アクチュエーターを動作させる の回路例 (印刷 p.3-7 / 原本 p.82)
- DC24V電源の 24V → 電源コネクター S1。S2 → EMG-(外部で S2 と EMG- を接続)
- S1–S2 間は、コントローラー内部で SIO コネクター経由のティーチングボックスの停止スイッチにつながる
- MPI–MPO 間は「出荷時配線済」(ジャンパー)。MPI → 駆動源遮断回路 → モーター電源
- 24V / 0V → 制御電源。EMG- → 非常停止制御回路(駆動源遮断回路を制御)
- BK(破線): ブレーキリリース電源。図中注記「(注)ブレーキ付きアクチュエーター接続しブレーキを強制リリースする場合、24Vを供給」

EMG-端子に常時+24V を供給することでコントローラーへの非常停止入力を無効にします。
ティーチングボックスの停止スイッチを経由して、+24V を EMG-端子に接続します。

●配線イメージ

【図】配線イメージ: DC24V 電源（お客様準備）→ PCON の電源コネクター、ティーチングボックス → SIO コネクター。ティーチングボックスの「停止スイッチは有効です。」

(印刷 p.3-8 / 原本 p.83)

> **注意**
> ●DC24V を ON/OFF して電源を供給する場合、0V は接続したままとし、+24V を供給/切断（片切り）を行ってください。両切りの場合、0V が先に切れると電位が安定しなくなります。これにより、コントローラー内部の部品故障につながる恐れがあります。
> ●非常停止信号（EMG-）の定格は、DC24V、10mA 以下です。
> ●電源遮断後、再投入する際、1s 以上間隔をあけてください。
> ●制御電源を供給しない状態でモーター電源だけを供給しないでください。
> ●配線径、配線長などの要因でコントローラー供給電圧が低下、アラームになる場合があります。この場合、コントローラー供給電圧が 24V になるように電源の出力電圧を調整してください。

##### ③ 非常停止スイッチ ON 時、モーター電源を外部で遮断する (3.1.3〔1〕③ / 印刷 p.3-11 / 原本 p.86)

●回路例

### 3.2.3 配線 (3.2.3 / 印刷 p.3-29 / 原本 p.104)

#### 〔1〕電源コネクター部（電源および非常停止部） (3.2.3〔1〕 / 印刷 p.3-29 / 原本 p.104)

回路例として、次の 4 条件の場合を示します。CGB タイプは③④から選択してください。

① ティーチングボックスの停止スイッチを有効にし、アクチュエーターを動作させる  
② 装置の非常停止スイッチとティーチングボックスの停止スイッチを有効にし、アクチュエーターを動作させる  
③ 非常停止スイッチ ON 時、モーター電源を外部で遮断する  
④ 2 台以上のコントローラーを使用し、非常停止スイッチ ON 時モーター電源を外部で遮断する  

##### ① ティーチングボックスの停止スイッチを有効にし、アクチュエーターを動作させる (3.2.3〔1〕① / 印刷 p.3-29 / 原本 p.104)

●回路例

【図】ティーチングボックスの停止スイッチを有効にし、アクチュエーターを動作させる の回路例 (印刷 p.3-29 / 原本 p.104)
- DC24V電源の 24V → 電源コネクター S1。S2 → EMG-(外部で S2 と EMG- を接続)
- S1–S2 間は、コントローラー内部で SIO コネクター経由のティーチングボックスの停止スイッチにつながる
- MPI–MPO 間は「出荷時配線済」(ジャンパー)。MPI → 駆動源遮断回路 → モーター電源
- 24V / 0V → 制御電源。EMG- → 非常停止制御回路(駆動源遮断回路を制御)
- BK(破線): ブレーキリリース電源。図中注記「(注)ブレーキ付きアクチュエーター接続しブレーキを強制リリースする場合、24Vを供給」

EMG-端子に常時+24V を供給することでコントローラーへの非常停止入力を無効にします。
ティーチングボックスの停止スイッチを経由して、+24V を EMG-端子に接続します。

●配線イメージ

【図】配線イメージ: DC24V 電源（お客様準備）→ PCON の電源コネクター、ティーチングボックス → SIO コネクター。ティーチングボックスの「停止スイッチは有効です。」

(印刷 p.3-30 / 原本 p.105)

> **注意**
> ●DC24V を ON/OFF して電源を供給する場合、0V は接続したままとし、+24V を供給/切断（片切り）を行ってください。両切りの場合、0V が先に切れると電位が安定しなくなります。これにより、コントローラー内部の部品故障につながる恐れがあります。
> ●非常停止信号（EMG-）の定格は、DC24V、10mA 以下です。
> ●電源遮断後、再投入する際、1s 以上間隔をあけてください。
> ●制御電源を供給しない状態でモーター電源だけを供給しないでください。
> ●配線径、配線長などの要因でコントローラー供給電圧が低下、アラームになる場合があります。この場合、コントローラー供給電圧が 24V になるように電源の出力電圧を調整してください。

> ●電源遮断後、再投入する際、1s 以上間隔をあけてください。
> ●制御電源を供給しない状態でモーター電源だけを供給しないでください。
> ●配線径、配線長などの要因でコントローラー供給電圧が低下、アラームになる場合があります。この場合、コントローラー供給電圧が 24V になるように電源の出力電圧を調整してください。


##### ③ 非常停止スイッチ ON 時、モーター電源を外部で遮断する (3.2.3〔1〕③ / 印刷 p.3-32 / 原本 p.107)

●回路例

【図】非常停止スイッチ ON 時、モーター電源を外部で遮断する の回路例 (印刷 p.3-32 / 原本 p.107)
- DC24V電源の 24V → 「非常停止リセットスイッチ」(a接点)と CR 自己保持接点の並列回路 → 外部非常停止スイッチ(b接点) → 電源コネクター S1
- S2 → 外部駆動源遮断リレー CR のコイル → 0V。図中注記「外部駆動源遮断リレー（コイル電流0.1A以下）」
- S1–S2 間は SIO コネクター経由のティーチングボックスの停止スイッチと「ティーチングツール接続検出回路（接続で接点開）」
- MPI–MPO 間の出荷時ジャンパーの代わりに CR の a接点を接続。EMG- は CR 接点の MPI 側に接続(CR 閉で EMG- に +24V)
- 24V / 0V → 制御電源。EMG- → 非常停止制御回路。BK(破線): ブレーキリリース電源(図中注記: ブレーキ付きアクチュエーター接続しブレーキを強制リリースする場合、24Vを供給)

コントローラーの EMG-端子に+24V を供給すると非常停止解除、供給を停止すると非常停止状態となり、アクチュエーター動作停止、サーボ OFF、およびコントローラー内部でモーター電源の遮断を行います。

外部非常停止スイッチ、または、ティーチングボックスの停止スイッチを ON すると外部駆動源遮断リレーへの+24V が遮断されます。それにより駆動源遮断回路のリレーが開き、モーター電源が遮断されます。あわせて、EMG-端子への+24V も遮断され、非常停止状態となります。
非常停止スイッチを OFF に戻した後、非常停止リセットスイッチを ON すると、駆動源遮断リレーへ+24V が供給されます。それにより駆動源遮断回路のリレーが閉じ、モーター電源が供給されます。あわせて、EMG-端子にも+24V が供給され、非常停止が解除されます。

(印刷 p.3-33 / 原本 p.108)

> ●安全カテゴリー対応タイプ（CGB/CGFB/CGBP タイプ）は、ティーチングツールが挿込まれたことをコントローラーが自動認識し、配線を切替えるリレーを搭載していません。安全カテゴリー対応タイプ以外は自動認識します。
