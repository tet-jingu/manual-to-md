## 5.1 衝突検出機能 (5.1 / 印刷 p.5-1 / 原本 p.260)

アクチュエーターが運転中に物などに接触した場合、速やかに停止する機能があります。
本項の説明を十分理解したうえで、安全上、運転上の支障のないように使用してください。
衝突検出機能は、指令電流値が設定した値を超えた場合、アラームを発生させサーボ OFF させて動作を停止する機能です。検出範囲も設定することができます。

> **注意**
> - 本機能は、万一の場合にワークの破損などを軽減させる補助的な機能です。
> - 本機能は、以下のモードでは使用できません。
>   - ・パルス列仕様のパルス列制御モード（PIO パターン 6、PIO パターン 7）
>   - ・フィールドネットワーク仕様のハーフ直値モード
>   - ・モーションネットワーク対応仕様（I/O 種別：ML3）
> - 想定外の破損などが発生しても補償はいたしかねます。
> - 本機能の設定は、想定する衝突に合わせる必要があり、適正値はシステムにより異なります。十分な確認を実施のうえ、使用してください。

### 5.1.1 衝突判定 (5.1.1 / 印刷 p.5-2 / 原本 p.261)

【衝突判定】

現在位置がポジションゾーンの範囲内にあり、指令トルクがポジションテーブルの “しきい” に設定した値を超えた時間が、パラメーターNo.50 “負荷出力判定時間” を上回った場合、衝突と判定します。
判定後、負荷出力判定ステータス（LOAD）を ON にし、衝突検出アラームを発生します。その際、パラメーターNo.168 “衝突検出機能” の設定が “1” または “3” の場合自動でサーボ OFF します。

◎判定例（判定時間が 255ms の場合）

【図】衝突判定例のタイミングチャート (5.1.1 / 原本 p.261)
- 縦軸: 電流。横線2本: 上が「移動時 電流制限値」、下が「“しきい” 設定電流値」。横軸: 時間
- 移動開始位置で電流が立上り、加速時に “しきい” を超えるが、ポジションゾーン範囲外(網掛け区間)のため「範囲外によりカウントしない」
- 「ポジションゾーン範囲内（判定開始）」以降で判定を開始
- 「衝突発生」で電流が移動時電流制限値まで上昇 → 「カウント開始」
- 「200 までカウント」した時点で「負荷変動により電流が下がる」(しきい未満の区間 20ms) → 「180 まで減算」
- 電流が再び上昇し、そこから 75ms で「255 までカウントアップ」→「衝突判定」
- 衝突判定の時点で: LOAD が ON、衝突検出アラーム（0DF）が発生(アラーム発生)、サーボ制御が OFF（注 1）、コントローラー状態表示 LED が「緑点滅」から「赤点滅（1Hz）」に変化

（注 1）パラメーターNo.168 “衝突検出機能” が “1” または “3” の場合。

### 5.1.2 設定方法 (5.1.2 / 印刷 p.5-3 / 原本 p.262)

（1）使用する機能の選択

パラメーターで設定します。パラメーターNo.168 “衝突検出機能“ を設定してください。

| 設定値 | 内容 | アラームレベル |
|---|---|---|
| 0 | 検出を行いません（2、4、6 を設定した場合も同様） | － |
| 1 | ポジションゾーン設定範囲で検出を行います。 | 動作解除レベル（アラームコード 0DF） |
| 3（注 1） | ポジションゾーン設定範囲で検出を行いますが、次の場合は検出を行いません。<br>・一時停止解除後の最初の移動<br>・ポジションゾーン範囲内で停止した状態からの移動 | 動作解除レベル（アラームコード 0DF） |
| 5 | ポジションゾーン設定範囲で検出を行います。 | メッセージレベル（アラームコード 049） |
| 7（注 1） | ポジションゾーン設定範囲で検出を行いますが、次の場合は検出を行いません。<br>・一時停止解除後の最初の移動<br>・ポジションゾーン範囲内で停止した状態からの移動 | メッセージレベル（アラームコード 049） |

注 1：この設定で、加速時の電流値増大による誤検出を回避できます。

（2）検出電流値の設定

ポジションテーブルの “しきい” の欄に 0～100〔%〕で設定します。0 を設定すると検出を行いませんが、LOAD 信号は ON します。

（3）判定時間の設定

パラメーターで設定します。パラメーターNo.50 “負荷出力判定時間“ を設定してください。
設定範囲： 0～9,999〔ms〕 （初期値 255ms）

（4）判定範囲（ポジションゾーン）の設定

ポジションテーブルの “ゾーン＋” “ゾーン－” に範囲を設定してください。
設定の際、“ゾーン＋” より “ゾーン－” を小さな値に設定してください。
設定範囲： 0.00～アクチュエーターストローク長〔mm〕

### 5.1.3 調整方法 (5.1.3 / 印刷 p.5-4 / 原本 p.263)

以下の内容を目安に調整してください。

- ■判定範囲 ：多くの電流が必要となる加減速区間は避けて、衝突が発生する可能性がある範囲を設定します。
- ■検出電流値：移動速度やワークの質量などを考慮し、誤検出が発生しない範囲でできるかぎり低く設定します。（定速移動時に必要な電流値より少し高めに設定し、微調整を行ってください。）

【図】判定範囲と閾値電流の設定イメージ (5.1.3 / 原本 p.263)

## 5.2 節電機能 (5.2 / 印刷 p.5-5 / 原本 p.264)

### 5.2.1 自動サーボ OFF およびフルサーボ機能 (5.2.1 / 印刷 p.5-5 / 原本 p.264)

アクチュエーター停止中の電力消費量を低減するため自動サーボ OFF（全モーター仕様設定可能）およびフルサーボ機能（パルスモーター仕様限定）を搭載しています。本項の説明を十分理解いただき、安全上、運転上の支障のないように使用してください。

自動サーボ OFF 機能では、位置決め完了後、一定時間経過後に自動的にサーボ OFF します。
次の位置決めスタート信号 CSTR が指令されると自動的にサーボ ON し、位置決め動作を実行します。停止時の保持電流が流れないため、電力消費量を削減することができます。
位置決め完了からサーボ OFF までの時間は 3 種類設定できます。

フルサーボ機能では、停止時電流が比較的多いパルスモーターを停止時にもサーボ制御することで、電力消費量を削減することができます。
パルスモーターは、停止時の微振動を抑えて完全停止するため、一定の電流を流しています。
またエンコーダーの値が目標位置から±4 カウントの範囲のずれでは、目標位置への復帰は行いません。しかし、フルサーボ機能を有効にすると 1 カウントのずれでも復帰動作を行います。
なお、RCP6 シリーズはフルサーボ機能と同様に、1 カウントのずれでも復帰動作を行います。よって RCP6 は、フルサーボ機能は使用できません。

節電機能は、アクチュエーターの状態により、パラメーターNo.53 “停止モード初期値” またはポジションテーブルの “停止モード” のどちらの設定が有効になるか決まります。以下に詳細を示します。

| 状態 | 設定 |
|---|---|
| 原点復帰完了で待機中<br>（目標位置へ位置決めは行っていない状態） | パラメーターNo.53 に設定した値で節電機能実行<br>（ポジション No.の停止モード設定は無効） |
| 電源投入後、サーボ ON 状態で待機中<br>（目標位置へ位置決めは行っていない状態） | パラメーターNo.53 に設定した値で節電機能実行<br>（ポジション No.の停止モード設定は無効） |
| ポジションテーブルに設定している目標位置に位置決め完了した状態で待機中 | 各ポジション No.の “停止モード” に設定した値で節電機能実行<br>（パラメーターNo.53 の設定値は、無効） |

(以下 印刷 p.5-6 / 原本 p.265)

> **注意**
> - 自動サーボ OFF 後の動作がピッチ送り（相対移動）の場合は本機能を使用しないでください。
> - サーボ ON/OFF により微細な位置ずれを起こす場合があります。またサーボ OFF 中に外力が加わって位置がずれているような場合、ピッチ送りは起動時の位置を基点として運転しますので、正しい位置への位置決めができなくなります。
> - 自動サーボ OFF 機能は、押付け動作では無効です。使用しないでください。本機能は、位置決め動作の完了時に有効となる機能です。押付け動作の場合は、空振り（押当たらずに動作を完了＝位置決め時の完了と同じ状態になる）したときだけ有効となります。
> - 自動サーボ OFF 中は保持トルクがありません。外力が加わればアクチュエーターは動きます。設定の際は、干渉や安全に十分注意してください。
> - フルサーボ機能で動作中にジョグまたはインチングで動作させた場合、フルサーボ機能は無効となります。再びフルサーボ機能を有効に設定したポジション No.の移動を行えばフルサーボ機能は有効となります。

#### 〔3〕自動サーボ OFF 選択時の位置決め完了信号の状態 (5.2.1〔3〕 / 印刷 p.5-8 / 原本 p.267)

自動サーボ OFF を行うと、サーボ OFF によって位置決め完了状態ではなくなります。したがって位置決め完了信号 PEND は OFF します。PEND 信号を位置決め完了信号ではなく、位置決め幅の範囲に停止しているかを判定するインポジション信号に変更することによって、サーボ OFF 中も OFF しない信号にすることができます。

この設定はパラメーターNo.39 によって行います。

| パラメーターNo.39 設定値 | PEND 信号の内容 | 自動サーボ OFF 中の信号出力状態 PEND |
|---|---|---|
| 0 | 位置決め完了信号 | OFF |
| 1 | インポジション信号 | ON |

（注）自動サーボ OFF 中は、前面パネルのコントローラー状態表示 LED の SV が緑点滅します。

（1）パラメーターNo.39=0 のとき

| アクチュエーターの動作 | 位置決め動作 | 自動サーボ OFF 待機 | サーボ OFF | 位置決め動作 |
|---|---|---|---|---|
| サーボの状態 | ON | ON | OFF | ON |
| 完了ポジション No.出力（現在位置番号出力） | PM1~**=0 | PM1~**=出力 | PM1~**=0 | PM1~**=0 |
| 位置決め完了信号 PEND | OFF | ON | OFF | OFF |

- 「自動サーボ OFF 待機」の区間の長さ = サーボ OFF 遅延時間（パラメーターNo.36~38）
- 原本ではサーボ OFF 列の「PM1~**=0」の「0」と PEND の「OFF」に下線(No.39=1 との差異箇所)

（2）パラメーターNo.39=1 のとき

| アクチュエーターの動作 | 位置決め動作 | 自動サーボ OFF 待機 | サーボ OFF | 位置決め動作 |
|---|---|---|---|---|
| サーボの状態 | ON | ON | OFF | ON |
| 完了ポジション No.出力（現在位置番号出力） | PM1~**=0 | PM1~**=出力 | PM1~**=出力 | PM1~**=0 |
| 位置決め完了信号 PEND | OFF | ON | ON | OFF |

- 「自動サーボ OFF 待機」の区間の長さ = サーボ OFF 遅延時間（パラメーターNo.36~38）
- 原本ではサーボ OFF 列の「PM1~**=出力」と PEND の「ON」に下線(No.39=0 との差異箇所)

### 5.2.2 オートカレントダウン機能 (5.2.2 / 印刷 p.5-9 / 原本 p.268)

（1）機能選択パラメーター

位置決め動作後に完全停止する場合、オートカレントダウン機能を使用しないときは、外力の大きさに関係なく一定電流（注1）通電を行います。オートカレントダウン機能を使用すると外力の影響を考慮した通電を行いますので、搬送負荷の小さい場合などに消費電力を抑制する効果があります。
注 1：パラメーターNo.12 “位置決め停止時電流制限値“

オートカレントダウン機能の無効/有効は、パラメーターNo.182 で設定します。

| パラメーターNo. | 名称 | 単位 | 入力範囲 | 初期値 |
|---|---|---|---|---|
| 182 | オートカレントダウン機能選択 | － | 0：無効、1：有効 | 0 |

オートカレントダウン機能が無効の場合と有効の場合における位置決め動作時の通電量と速度指令の関係を以下に示します。

【図】●オートカレントダウン機能：無効 (5.2.2 / 原本 p.268)
- 縦軸: 電流・速度、横軸: 時間。実線=通電量、破線=速度指令(台形)
- 動作開始前の停止中: 通電量は一定レベル(赤丸囲み)
- 位置決め動作中: 通電量は速度指令に応じて変動
- 位置決め完了後(速度指令 0 以降): 通電量が上昇し「位置決め停止時電流制限値」で一定に保持
- 具体的な電流値・時間値は図から判読不可。原本 p.268 参照

【図】●オートカレントダウン機能：有効 (5.2.2 / 原本 p.268)
- 縦軸: 電流・速度、横軸: 時間。実線=通電量、破線=速度指令
- 動作開始前の停止中: 通電量は無効時より低いレベル(「外力の影響を考慮した停止時の通電量」)
- 位置決め完了後: 通電量はいったん上昇してピークに達したのち、徐々に減少していく(「外力の影響を考慮した停止時の通電量」)
- 具体的な電流値・時間値は図から判読不可。原本 p.268 参照

（2）機能有効時の制御 (印刷 p.5-10 / 原本 p.269)

①通電量が位置決め停止時電流制限値（パラメーターNo.12）となるまでは、既存の完全停止機能と同じ処理を行います。
②停止時電流通電完了後、目標位置偏差が未発生（ゼロ）となるまで状態維持します。
③目標位置偏差の有無に従い、通電量を操作します。
- ・目標位置偏差未発生時、一定量ずつ通電量減少
- ・目標位置偏差発生時、一定量ずつ通電量増加

通電量の操作には以下の制限があります。
- ・通電量の減少⇒増加の処理遷移が既定回数以上行われた時、増加処理のみ実行します。
- ・最小通電量はアクチュエーターごとに定義し、位置偏差未発生時は当該量まで通電量を減少させます。
- ・最大通電量は位置決め停止時電流制限値（パラメーターNo.12）であり、当該量まで通電量を増加させます。

（3）注意事項

①エンコーダー分解能による目標位置偏差量の違い

リード長 24〔mm/r〕のアクチュエーターの場合
- ■エンコーダー分解能が 800〔pulse/r〕の場合は、24÷800＝0.0300〔mm〕の目標位置偏差が生じるまで通電量を減少させます。
- ■エンコーダー分解能が 8,192〔pulse/r〕の場合は、24÷8,192＝0.0029…〔mm〕の目標位置偏差が生じるまで通電量を減少させます。

②高分解能エンコーダーでの注意点

高分解能エンコーダー搭載のアクチュエーターでは、位置決め完了状態が長時間継続すると本機能が有効設定であっても、最終的には通電量が位置決め停止時電流制限値（パラメーター）まで上昇します。

## 6.1 パラメーター (6.1 / 印刷 p.6-1 / 原本 p.272)

パラメーターはシステムやアプリケーションに合わせて設定するデータです。
パラメーターを変更する場合には、いつでも元に戻せるように変更前のデータをバックアップしてください。
パソコン専用ティーチングソフトを使用するとパソコンへのバックアップが可能です。ティーチングボックスは、メモリーカードへのバックアップが可能です。
また、故障の原因追及やコントローラーの交換など、迅速な復旧作業のために、設定後のパラメーターもバックアップあるいはメモの保管をしてください。
パラメーターは編集後、FeRAM への書込み処理を行った後、ソフトウェアリセットまたは電源の再投入で有効となります。ティーチングツール上で書込んだだけでは、有効になりませんので注意してください。

> **警告**
> - パラメーターの設定は、運転に重大な影響を与えます。誤った設定を行うと誤動作や故障の原因となり、非常に危険です。
> - 工場出荷時には、標準の運転が可能な状態となっています。システムに合わせた変更や設定を行う場合には、コントローラーの制御方法を十分に理解したうえで行ってください。不明な点がある場合は、当社まで問合わせしてください。
> - パラメーターの書換え中、コントローラーの電源を OFF しないでください。

#### 〔4〕押付け停止判定時間（パラメーターNo.6） (6.1.2〔4〕 / 印刷 p.6-10 / 原本 p.281)

押付け動作の完了判定

押付け動作の完了判定時間を設定するパラメーターです（PIO パターン 0～3）。
ポジションテーブルの “押付け“ にパーセント〔%〕で設定したトルク（電流制限値）を監視し、押付け動作中の負荷電流が次の条件となったとき、押付け完了信号 PEND を ON します。
ワークが停止していなくても、条件を満たすと PEND 信号は ON します。

（電流が押付け〔%〕に達した累積時間）－（電流が押付け〔%〕以下の累積時間）≧255ms（パラメーターNo.6）

【図】押付け完了判定のタイミング (6.1.2〔4〕 / 原本 p.281)
- 縦軸: 電流、横軸: 時間。点線: 押付け〔%〕
- 「動作開始」→ アプローチ動作 → 「アプローチ動作終了 押付け開始」で電流が低下
- 「ワークに接触」で電流が押付け〔%〕に達する → 200ms 継続
- 「ワークの移動により電流減少」で押付け〔%〕未満が 20ms
- 再び押付け〔%〕に達して 75ms
- 全体 295ms の時点で 200ms-20ms+75ms≧255ms（注 1）となり「押付け完了（PEND 出力）」

注 1：グリッパー一部機種は初期値 70ms に設定しています。

- ・出荷後に原点方向を逆にしたので原点位置を新たに設定したい。
