#### ラダープログラム (4-116 / 原本 p.364)

- 1行目: 「実行条件」の a接点を左母線に接続し、LDA(灰色表示) → RRNCA(上に [n]) → STA(灰色表示) を直列に右母線へ。
- 2行目: 「実行条件」の a接点を左母線に接続し、↑LDA(灰色表示) → ↑RRNCA(上に [n]) → ↑STA(灰色表示)(微分型)を直列に右母線へ。

> 補足(本ファイル作成者): LDA / STA は灰色表示で、内部レジスタへの読み込み・書き込みと組み合わせて使う例として描かれている。

#### オペランド (4-116 / 原本 p.364)

| オペランド | 説明 | 占有サイズ |

| [n] | ローテートするビット数を指定します。※1※2<br>RRNCA.Uは0～15、RRNCA.Dは0～31の範囲で指定できます。 | 16ビット |

- ※1 [n] に定数以外を指定した場合、[n] の値が16以上(.Uのとき)/32以上(.Dのとき)のときは以下のようになります。

#### 動作説明 (4-116〜4-117 / 原本 p.364-365)

**RRNCA(.U)**
> 実行条件がONのとき、16ビット内部レジスタのビット内容を [n] で指定したビット数だけ、ビット番号の小さい方へローテートします。
> ローテートした結果の最下位ビットの状態がキャリーフラグ(CR2009)に入ります。
> (次のビット操作を [n] 回繰り返します)。

【図】RRNCA(.U) のビット図 (原本 p.364)

| 段階 | bit15 ← → bit0 | 備考 |
|---|---|---|
| 実行前 16ビット内部レジスタ | 1111 0000 1111 0000 | bit0 の値が矢印で bit15 側へ回り込む(1ビットローテート) |
| 1ビットローテート後 | 0111 1000 0111 1000 | |
| [n] 回ローテート([n] ビット分ローテートします)後 16ビット内部レジスタ | 1000 0111 1000 0111 | 最下位ビット(bit0)から矢印で CR2009(キャリー) へ: 1 |

**RRNCA.D**
> 実行条件がONのとき、32ビット内部レジスタのビット内容を [n] で指定したビット数だけ、ビット番号の小さい方へローテートします。
> ローテートした結果の最下位ビットの状態がキャリーフラグ(CR2009)に入ります。
> (次のビット操作を [n] 回繰り返します)。

【図】RRNCA.D のビット図 (原本 p.365) — bit31 / bit16 / bit15 / bit0 の位置表示あり

| 1ビットローテート後 | 0111 1000 0111 1000 0111 1000 0111 1000 | |
| [n] 回ローテート([n] ビット分ローテートします)後 32ビット内部レジスタ | 1000 0111 1000 0111 1000 0111 1000 0111 | 最下位ビット(bit0)から矢印で CR2009(キャリー) へ: 1 |

**＠RRNCA.□**
> 実行条件の立ち上がりで、1スキャンだけ実行します。

> **参考**
> RRNCA命令を毎スキャン型で実行すると、実行条件がONの間、スキャンごとにローテートします。スキャンごとではなく、実行条件の立ち上がりで実行するときは、次のように微分型命令を使用してください。

参考のラダー図(図から書き起こし。接点のデバイス名は原本図に記載なし):
- 1行目: a接点 → ↑LDA(上に DM＊＊＊＊) → ↑RRNCA → ↑STA(上に DM＊＊＊＊)(@LDA / @RRNCA / @STA の微分型命令)
- 2行目: 立ち上がり微分の a接点(接点記号内に↑) → LDA(上に DM＊＊＊＊) → RRNCA → STA(上に DM＊＊＊＊)

#### 演算フラグ (4-117 / 原本 p.365)

| フラグ | 内容 |
|---|---|
| CR2009 | 演算後、キャリーが格納されたときON、それ以外OFF。 |
| CR2010 | 演算結果が0になったときON、それ以外OFF。 |
| CR2011 | 変化なし |
| CR2012 | 間接指定またはインデックス修飾の範囲が不適切な場合、オペランドの範囲外アクセスが発生した場合はON、それ以外OFF。<br>オペランドに間接指定、インデックス修飾を指定していない場合、およびオペランドの範囲外アクセスのチェックが行われない場合は変化しません。<br>→「オペランドの範囲外アクセス」（1-53ページ） |

- ※ CR2012がONした場合、命令は実行されません。
  - [KV-8000/7000/5000/3000シリーズ] CR2012がONした場合、CM5150～CM5176にエラーの詳細情報が格納されます。
  - [KV Nanoシリーズ] CR2012がONした場合、CM2250～CM2276にエラーの詳細情報が格納されます。
  - →「CR/CM一覧」（付-42ページ）

#### サンプルプログラム (4-118 / 原本 p.366)

> 入力リレーR30000～R30015に接続された異常検知センサのうち、異常出力しているセンサの台数をデータメモリDM0に格納します。

ラダー:
- ① CR2002 a接点 → DW #0 DM0 → LDA R30000
- ② FOR #16
- ③ CR2002 a接点 → RRNCA #1 → CR2009 a接点 → INC DM0
- NEXT

〈ニモニックリスト〉
```
LD CR2002
DW #0 DM0
CON
LDA R30000
FOR #16
LD CR2002
RRNCA #1
CON
AND CR2009
INC DM0
NEXT
```

> ① 入力リレーR30000～R30015を16ビット内部レジスタに格納する。
> ② 16回 FOR～NEXT命令を実行する。
> ③ 16ビット内部レジスタの内容を右シフト(キャリーフラグCR2009を含まず)して、CR2009がONのときDM0の内容を+1する。
