## マクロ命令 (3-44〜3-47 / 原本 p.192-195)

各ページ上部の見出しは「応用命令 マクロ命令」。右端インデックスタブ(MCALL / MSTRT / MEND)は転記省略。

### MCALL / MSTRT / MEND (3-44〜3-47 / 原本 p.192-195)

#### 対応機種 (3-44 / 原本 p.192)

| KV-8000 | KV-7000 | KV-5000/3000 | KV-1000 | KV Nano |
|---|---|---|---|---|
| 有効 | 有効 | 有効 | 有効 | 有効 |

#### 命令一覧 (3-44 / 原本 p.192)

| 命令語 | 記号 | 名称 | 概要 |
|---|---|---|---|
| MCALL | 右母線側に置く箱型要素。上に「MCALL」、箱の中は3つの枠(マクロ名称+引数) | マクロコール | 指定したサブルーチン型マクロを実行します。(モジュール内に記述) |
| MSTRT | 同上。上に「MSTRT」、箱の中は3つの枠 | マクロスタート | 指定した自己保持型マクロを実行します。(モジュール内に記述) |
| MEND | 右母線側に置く小さな箱型要素「MEND」(オペランドなし) | マクロエンド | 自己保持型マクロの実行を停止します。(自己保持型マクロ内に記述) |

#### ラダープログラム (3-44 / 原本 p.192)

- MCALL: 「実行条件」の a接点を左母線に接続し、右端に「MCALL」の箱(箱内に [S] と「実行するマクロによる※1※2」の引数欄)。
- MSTRT: 「実行条件」の a接点を左母線に接続し、右端に「MSTRT」の箱(箱内に [S] と「実行するマクロによる※1※2」の引数欄)。
- MEND: 「実行条件」の a接点を左母線に接続し、右端に「MEND」の箱。

#### 入力方法 (3-44 / 原本 p.192)

機種別の分け書きはなし(全機種共通)。

| 命令語 | 入力方法 |
|---|---|
| MCALL | `MCALL␣S〔␣引数1␣引数2…〕↵`(〔 〕の上に ※1※2) |
| MSTRT | `MSTRT␣S〔␣引数1␣引数2…〕↵`(〔 〕の上に ※1※2) |
| MEND | `MEND↵` |

#### オペランド (3-44 / 原本 p.192)

| オペランド | 説明 | 占有サイズ |
|---|---|---|
| [S] | マクロ名称を指定します。※3※4 | ー |

- ※1 マクロ名称以外のオペランドの個数や、指定できるデータは、実行するマクロに設定されている引数設定によって以下のとおり異なります。
  - P :デバイス、変数、ラベルを指定できます。定数は指定できません。
  - V :デバイス、変数、ラベル、定数を指定できます。
  - ユニット:定数のみ指定できます。
- ※2 マクロ内で使用する命令語によって、T、C、TIMER型変数、COUNTER型変数の扱いが異なります。
  例)MOV命令の場合は、現在値を扱います。詳細は各命令語の動作説明を参照してください。
- ※3 ""、#、$は使用できません。KV STUDIOで設定してマクロ名称を直接入力してください。
  半角英数字の場合は12文字、全角の場合は6文字まで指定できます。
  ただし、KV-8000/7000シリーズの場合は全角でも12文字まで指定できます。
- ※4 識別番号を使用する場合は、「(マクロ名)_(識別番号)」になります。 例)一括送信_2
  識別番号の詳細は、使用しているCPUユニットのユーザーズマニュアルを参照してください。

#### 動作説明 (3-45 / 原本 p.193)

| 命令語 | 動作 |
|---|---|
| MCALL | 実行条件がONの間、[S] で指定したサブルーチン型マクロを毎スキャン実行します。<br>指定したマクロは、OFF→ONになったスキャンから実行を開始します。 |
| MSTRT | 実行条件がONのとき、[S] で指定した自己保持型マクロを起動します。<br>指定したマクロは、OFF→ONになったスキャンから実行を開始します。<br>一旦実行を開始すると、実行条件がOFFでもマクロを実行し続けます。 |
| MEND | 実行条件がONのとき、MEND命令が記述されている自己保持型マクロを停止します。 |

> CPUユニットにより、停止時のOFF処理の動作が異なります。詳細は各CPUユニットのユーザーズマニュアルを参照ください。

> **ポイント**
> - MCALL/MSTRT命令の呼び出し個数や順序を変更すると、RUN中書き込みできません。
> - 自己保持型マクロの実行を停止するには、マクロ内のMEND命令を使用します。
>   MSTRT命令の実行条件がONのままの場合には、MEND命令は無視されます。
> - MEND命令は、モジュール内やサブルーチン型マクロ内に記述できません。
> - MEND命令で他のマクロを停止することはできません
> - マクロ内の微分実行型命令の前回状態は、マクロの実行開始時に毎回初期化されます。
>   (立ち上がり微分:ON、立ち下がり微分:OFF)
> - MCALL/MSTRT命令の属性が値のオペランドにT/C/CTH/CTCを指定した場合は、以下の値がマクロに引き渡されます。
>   - T/C : 現在値(32ビットデータ)
>   - CTH : 現在値(32ビットデータ)
>   - CTC : 設定値(32ビットデータ)
> - 以下の場合、各モジュールが停止もしくは各命令間の実行条件が OFFしたとき、実行中のマクロは停止します。
>   - MCALL/MSTRT命令をモジュールに記述した場合
>   - MCALL/MSTRT命令をマスターコントロール(MC～MCR命令間)に記述した場合
>   - MCALL命令をステージ(STG～JMP命令間)に記述した場合
> - 以下の場合、各命令間の実行条件がOFFしたとき、実行中のマクロは中断します。
>   次に各命令間が実行されたときにマクロの実行を再開します。
>   このときマクロ内の微分実行型命令の前回状態は、初期化されません。
>   (初期化モジュール内に記述した場合は、 運転開始時1スキャンのみ実行します。)
>   - MCALL/MSTRT命令をサブルーチン(SBN～RET命令間)に記述したとき
>   - MCALL/MSTRT命令を条件分岐(CJ/NCJ～LABEL命令間)に記述したとき
>   - MCALL/MSTRT命令をステップ(STP～STE命令間)に記述したとき
>   - MCALL/MSTRT命令を割り込み(INT～RETI命令間)に記述したとき
>   - MSTRT命令をステージ(STG～JMP命令間)に記述したとき
> - マクロ内で、MCALL命令、MSTRT命令は使用できません。
> - ファンクションブロック・ファンクション内でMCALL/MSTRT命令は使用できません。
> - マクロ内でサブルーチンプログラムを使用できますが、割り込みプログラムは使用できません。
> - プロジェクト内で同じマクロを複数回実行する場合、マクロ内で OUT/OUB 命令にグローバルデバイス/グローバル変数を使用すると、2重コイルになります。
>   使用しているCPUユニットのユーザーズマニュアルの「マクロ」を参照してください。

#### サンプルプログラム (3-61 / 原本 p.209)

メインプログラム内ではインデックスレジスタZ1, Z2の値を+01000,+02000で実行し、
サブルーチンプログラム内だけインデックスレジスタZ1, Z2の値を+03000,+04000で実行します。

ラダー図(枠「メインプログラム」と枠「サブルーチンプログラム」、右側に各回路の説明):

| 回路 | 説明(原文) |
|---|---|
| CR2008 → DW #0 DM0 | 退避回数をリセットします。 |
| CR2008 → DW.S +01000 Z1 / DW.S +02000 Z2 | インデックスレジスタZ1,Z2の値をそれぞれ+01000,+02000に設定します。 |
| CALL #0 | サブルーチンプログラムを実行します。 |
| END | (説明なし) |
| SBN #0 | (説明なし) |
| CR2002 → ZPUSH DM0 | 現在のインデックスレジスタZ1～Z10の値をDM0以降に退避します。 |
| CR2002 → DW.S +03000 Z1 / DW.S +04000 Z2 | サブルーチンプログラムで使用するインデックスレジスタZ1,Z2の値#3000,#4000を設定します。 |
| CR2002 → ZPOP DM0 | DM0以降に退避した値をインデックスレジスタZ1～Z10に復帰します。 |
| RET | サブルーチンプログラムを終了します。 |
| ENDH | (説明なし) |

(「値#3000,#4000を設定します」は原文ママ・要確認: 図とニモニックでは +03000 / +3000(10進)。原本 p.209)

〈ニモニックリスト〉
```
LD CR2008
DW #0 DM0
LD CR2008
DW.S +1000 Z1
CON
DW.S +2000 Z2
CALL #0
END
SBN #0
LD CR2002
ZPUSH DM0
LD CR2002
DW.S +3000 Z1
CON
DW.S +4000 Z2
LD CR2002
ZPOP DM0
RET
ENDH
```
