| 命令語 | 記号 | 名称 | 概要 |

| @LEN | 左端に上向き矢印(微分)の付いた、上辺に「LEN」と表示された2マスの箱型命令要素 | 文字列長検出 | 文字列の文字数を数えます。 |

#### ラダープログラム (4-268 / 原本 p.516)

- 1行目: 「実行条件」の a接点を左母線に接続し、上辺に「LEN」と表示された箱型命令(マス [S] / [D])へ接続、右母線へ。
- 2行目: 「実行条件」の a接点 → 左端に上向き矢印の付いた「LEN」の箱型命令(マス [S] / [D])。微分型(@LEN)。

#### 入力方法 (4-268 / 原本 p.516)

機種別の分け書きはなし(全機種共通)。

| 命令語 | 入力方法 |
|---|---|
| LEN | `LEN␣S␣D↵` |
| @LEN | `@LEN␣S␣D↵` |

#### オペランド (4-268 / 原本 p.516)

| オペランド | 説明 | 占有サイズ |
|---|---|---|
| [S] | 文字数を数える文字列、またはその格納先を指定します。※1※2 | 8ビット×(文字数+1) |
| [D] | 数えた文字数の格納先を指定します。 | 16ビット |

- ※1 ビットデータを指定する場合は、チャンネルの先頭を指定してください。
- ※2 定数で文字列を指定する場合は、" "で囲ってください(半角31文字まで)。 # や $ は使用できません。
  - 半角文字: ASCIIコード(1バイト)
  - 全角文字: 「プロジェクト言語設定」で指定した言語(KV-8000/7000シリーズ)
  - シフトJISコード(2バイト)(KV-5500/5000/3000/1000・KV Nano シリーズ)
  - →「ASCIIコード表」(付-96ページ)

#### 動作説明 (4-268 / 原本 p.516)

**LEN**
> 実行条件がONのとき、 [S] を先頭に格納されている文字列(文字列の最後にNULL(00H)が必要です。)の文字数を数えます。文字数は [D] にBINデータで格納されます。扱える文字列は1バイト文字で最大1999文字です。

図(バイト配置、[S] 側):

| ワード | 左 | 右 |
|---|---|---|
| [S] | a(61H) | b(62H) |
| [S]+1 | c(63H) | d(64H) |
| [S]+2 | e(65H) | f(66H) |
| : | (空欄) | (空欄) |
| — | w(77H) | x(78H) |
| — | y(79H) | z(7AH) |
| — | NUL(00H)(網掛け) | (空欄) |

→(太い矢印)→ [D] = 26(枠の下に「16ビット(1ワード)」の幅表示)

- a〜z の26文字+終端 NUL の文字列で、[D] に 26 が格納される例。[S]+2 の下は「:」で途中の行を示し、w/x、y/z、NUL の行にはワード番号の表示なし。

**@LEN**
> 実行条件の立ち上がりで、1スキャンだけ実行します。

#### ポイント (4-268 / 原本 p.516)

> **ポイント**
> 2バイト文字(シフトJIS等)は1文字で2カウントされます。

#### 演算フラグ (4-268〜4-269 / 原本 p.516-517)

| フラグ | 内容 |
|---|---|
| CR2009 | 変化なし |
| CR2010 | 変化なし |
| CR2011 | 変化なし |
| CR2012 | 以下のいずれかの条件が成立した場合はON、それ以外はOFF。<br>• 終端コード(NULL(00H))がない場合<br>• 終端コード(NULL(00H))を含む文字列が2000文字を超えた場合<br>• [S] に間接指定でビットデータを指定したときにチャンネルの先頭以外を指定した場合<br>• [S] に間接指定でタイマ・カウンタを指定した場合<br>• 間接指定・インデックス修飾の範囲が不適切な場合<br>• オペランドの範囲外アクセスが発生した場合<br>→「オペランドの範囲外アクセス」(1-53ページ) |

(CR2009〜CR2011 は p.516 下部、CR2012 は p.517 上部に分かれて掲載)

- ※ CR2012がONした場合、命令は実行されません。
  - [KV-8000/7000/5000/3000シリーズ] CR2012がONした場合、CM5150～CM5176にエラーの詳細情報が格納されます。
  - [KV Nanoシリーズ] CR2012がONした場合、CM2250～CM2276にエラーの詳細情報が格納されます。
  - →「CR/CM一覧」(付-42ページ)

#### サンプルプログラム (4-269 / 原本 p.517)

> データメモリDM0を先頭に格納されている文字列の長さ(文字数)を数えDM100に格納します。

ラダー: CR2002 a接点 → LEN(マス DM0 / DM100)。

〈ニモニックリスト〉
```
LD CR2002
LEN DM0 DM100
```

| ワード | 左(bit15側) | 右(bit0側) |
|---|---|---|
| DM0 | 1(31H) | 2(32H) |
| DM1 | A(41H) | B(42H) |
| DM2 | NUL(00H)(網掛け) | (空欄) |

→ DM100 = 4

> 文字列“12AB”の長さ(文字数)を数えDM100に格納します。

ラダー: CR2002 a接点 → LEN(マス “12AB” / DM100)。

〈ニモニックリスト〉
```
LD CR2002
LEN "12AB" DM100
```
