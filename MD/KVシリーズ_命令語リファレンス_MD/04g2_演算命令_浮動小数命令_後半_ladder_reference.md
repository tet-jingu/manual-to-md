#### 動作説明 (4-222〜4-223 / 原本 p.470-471)

**EXP(.F)** (p.470)
> 実行条件がONのとき、32ビット内部レジスタに格納されている単精度浮動小数点型実数を指数とした指数関数値を求めます。演算結果は、32ビット内部レジスタに単精度浮動小数点型実数として格納します。
> e=2.718282として演算します。

- 【図】e^( 32ビット内部レジスタ[単精度浮動小数点型実数](32ビット) ) → 32ビット内部レジスタ[単精度浮動小数点型実数](32ビット)

> **参考**
> 常用対数で演算する場合は、指数を0.434294で割った値を32ビット内部レジスタに格納して、EXP(.F)命令を実行してください。

**EXP.DF** (p.471)
> 実行条件がONのとき、64ビット内部レジスタに格納されている倍精度浮動小数点型実数を指数とした指数関数値を求めます。演算結果は、64ビット内部レジスタに倍精度浮動小数点型実数として格納します。
> e=2.718281828459045として演算します。

- 【図】e^( 64ビット内部レジスタ[倍精度浮動小数点型実数](64ビット) ) → 64ビット内部レジスタ[倍精度浮動小数点型実数](64ビット)

> **参考**
> 常用対数で演算する場合は、指数を0.434294481903252 で割った値を64ビット内部レジスタに格納して、EXP.DF命令を実行してください。

**LOG(.F)** (p.471)
> 実行条件がONのとき、32ビット内部レジスタに格納されている単精度浮動小数点型実数の自然対数を求めます。演算結果は、32ビット内部レジスタに単精度浮動小数点型実数として格納します。

- 【図】Loge( 32ビット内部レジスタ[単精度浮動小数点型実数](32ビット) ) → 32ビット内部レジスタ[単精度浮動小数点型実数](32ビット)

**LOG.DF** (p.471)
> 実行条件がONのとき、64ビット内部レジスタに格納されている倍精度浮動小数点型実数の自然対数を求めます。演算結果は、64ビット内部レジスタに倍精度浮動小数点型実数として格納します。

- 【図】Loge( 64ビット内部レジスタ[倍精度浮動小数点型実数](64ビット) ) → 64ビット内部レジスタ[倍精度浮動小数点型実数](64ビット)

**@□□□** 実行条件の立ち上がりで、1スキャンだけ実行します。
