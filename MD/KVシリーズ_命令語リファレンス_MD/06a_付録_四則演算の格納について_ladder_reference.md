## 四則演算の格納について (付-2〜付-8 / 原本 p.854-860)

> 四則演算命令(ADD, SUB, MIL, DIV) および平方根(ROOT命令) の実行によって、内部レジスタやテンポラリデータメモリ(TM)にどのようにデータが格納されるかを説明します。

(原文ママ・要確認: 「MIL」は MUL の誤記と思われる 原本 p.854)

### 内部レジスタ ・ テンポラリデータメモリの格納状態一覧 (付-2 / 原本 p.854)

| 命　令 | 格納状態 演算前 | 格納状態 演算後 | 参照ページ |
|---|---|---|---|
| ADD.U<br>ADD.S | 16ビット内部レジスタ ＋ S | ＝ 16ビット内部レジスタ | 4-40 |
| ADD.D<br>ADD.L | 32ビット内部レジスタ(上位・下位) ＋ S＋1(上位) : S(下位) | ＝ 32ビット内部レジスタ(上位・下位) | 4-40 |
| SUB.U<br>SUB.S | 16ビット内部レジスタ － S | ＝ 16ビット内部レジスタ | 4-44 |
| SUB.D<br>SUB.L | 32ビット内部レジスタ(上位・下位) － S＋1(上位) : S(下位) | ＝ 32ビット内部レジスタ(上位・下位) | 4-44 |
| MUL.U<br>MUL.S | 16ビット内部レジスタ × S | ＝ 32ビット内部レジスタ(上位・下位)<br>および TM000(上位) : 16ビット内部レジスタ(下位)<br>※上位16ビットは32ビット内部レジスタの上位とTM000の両方に格納されます。 | 4-48 |
| MUL.D<br>MUL.L | 32ビット内部レジスタ(上位・下位) × S＋1(上位) : S(下位) | ＝ TM001 : TM000(上位) ／ 32ビット内部レジスタ(下位) | 4-48 |
| DIV.U<br>DIV.S | TM000(上位) : 16ビット内部レジスタ(下位) ÷ S | ＝ 32ビット内部レジスタ(上位・下位)<br>および TM000(上位) : 16ビット内部レジスタ(下位)<br>余り TM001<br>※上位16ビットは32ビット内部レジスタの上位とTM000の両方に格納されます。 | 4-54 |
| DIV.D<br>DIV.L | TM001 : TM000(上位) ／ 32ビット内部レジスタ(下位) ÷ S＋1(上位) : S(下位) | ＝ TM001 : TM000(上位) ／ 32ビット内部レジスタ(下位)<br>余り TM003(上位) : TM002(下位) | 4-54 |
| ROOT.U<br>ROOT.S | √( TM000(上位) : 16ビット内部レジスタ(下位) ) | ＝ 16ビット内部レジスタ | 4-66 |
| ROOT.D<br>ROOT.L | √( TM001 : TM000(上位) ／ 32ビット内部レジスタ(下位) ) | ＝ 32ビット内部レジスタ(上位・下位) | 4-66 |
| ROOT.F | √( 32ビット内部レジスタ: 単精度浮動小数点型実数 ) | ➡ 32ビット内部レジスタ: 単精度浮動小数点型実数 | 4-66 |
| ROOT.DF | √( 64ビット内部レジスタ: 倍精度浮動小数点型実数 ) | ➡ 64ビット内部レジスタ: 倍精度浮動小数点型実数 | 4-66 |

(結合セル展開: 参照ページは ADD 2行で「4-40」、SUB 2行で「4-44」、MUL 2行で「4-48」、DIV 2行で「4-54」、ROOT 4行で「4-66」の各1セル。列見出しは原本では「格納状態」の下に「演算前」「演算後」の2段見出し)

図の読み取り補足:
- MUL.U/MUL.S の演算後は、上段に「32ビット内部レジスタ」(下に 上位 / 下位)、下段に「TM000 | 16ビット内部レジスタ」(下に 上位 / 下位)の2つの枠が縦に並び、右に「※上位16ビットは32ビット内部レジスタの上位とTM000の両方に格納されます。」の注記。
- MUL.D/MUL.L の演算後は「TM001 ┊ TM000 | 32ビット内部レジスタ」の1列で、TM001・TM000 の下に「上位」、32ビット内部レジスタの下に「下位」(64ビット結果)。
- DIV.U/DIV.S の演算前は「TM000 | 16ビット内部レジスタ」(下に 上位 / 下位)。演算後は MUL.U/MUL.S と同じ上下2枠と、右に「余り TM001」。注記はその下に「※上位16ビットは32ビット内部レジスタの上位とTM000の両方に格納されます。」。
- DIV.D/DIV.L の演算前は「TM001 ┊ TM000 | 32ビット内部レジスタ」(TM001・TM000 が上位、32ビット内部レジスタが下位)。演算後は上段「TM001 ┊ TM000 | 32ビット内部レジスタ」(上位 / 下位)、下段「余り TM003 ┊ TM002」(上位 / 下位)。
- ROOT.U/ROOT.S・ROOT.D/ROOT.L は、根号(√)の中に演算前の枠が入り、「＝」の右に演算後の枠。
- ROOT.F・ROOT.DF は、根号の中に「32ビット内部レジスタ / 単精度浮動小数点型実数」(ROOT.DF は「64ビット内部レジスタ / 倍精度浮動小数点型実数」)、太い右矢印(➡)の右に同じ名称の枠。

### 四則演算例 (付-3〜付-8 / 原本 p.855-860)

各ラダー図は、CR2002(常時ON)の a接点を左母線に接続し、関数型命令を CON で直列につないで右母線へ出力する構成です。

#### ■加算（ADD） (付-3 / 原本 p.855)

**① 符号無し16ビットBINデータ + 符号無し16ビットBINデータ = 符号無し16ビットBINデータ**

DM00000 + DM00001 = DM00010

ラダー: CR2002 a接点 → `< LDA DM00000 >` → `< ADD DM00001 >` → `< STA DM00010 >` → 右母線。

〈ニモニックリスト〉(図から書き起こし)
```
LD CR2002
LDA DM00000
CON
ADD DM00001
CON
STA DM00010
```
