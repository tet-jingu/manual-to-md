### MOV / @MOV (4-2〜4-5 / 原本 p.250-253)

#### 対応機種 (4-2 / 原本 p.250)

| KV-8000 | KV-7000 | KV-5000/3000 | KV-1000 | KV Nano |
|---|---|---|---|---|
| 有効 | 有効 | 有効 | 有効 | 有効 |

#### 命令一覧 (4-2 / 原本 p.250)

| 命令語 | サフィックス付き命令 | 読み(名称) | 概要 | 記号 |
|---|---|---|---|---|
| MOV | MOV(.U)<br>MOV.S<br>MOV.D<br>MOV.L<br>MOV.F<br>MOV.DF<br>MOV.A | データ転送 | 16/32/64ビットデータを格納します。 | 右母線側の箱型命令(上部に「MOV」、2区画の枠) |
| @MOV | @MOV(.U)<br>@MOV.S<br>@MOV.D<br>@MOV.L<br>@MOV.F<br>@MOV.DF<br>@MOV.A | データ転送 | 16/32/64ビットデータを格納します。 | 同上。箱の左側入口に上向き矢印(立ち上がり実行) |

(結合セル展開: 「データ転送」「16/32/64ビットデータを格納します。」は MOV と @MOV で共通の1セル)

#### ラダープログラム (4-2 / 原本 p.250)

- 1行目: 「実行条件」の a接点を左母線に接続し、右端に MOV 命令の箱(左区画 [S]、右区画 [D])。
- 2行目: 「実行条件」の a接点 → 左側入口に上向き矢印の付いた MOV 命令の箱([S] [D])= @MOV。

#### 入力方法 (4-2 / 原本 p.250)

| 命令語 | 入力方法 |
|---|---|
| MOV | `MOV␣S␣D↵` |
| @MOV | `@MOV␣S␣D↵` |

#### オペランド (4-2 / 原本 p.250)

| オペランド | 説明 | 占有サイズ※ |
|---|---|---|
| [S] | 転送元のデータを指定します。 | .U .S 16 ビット<br>.D .L .F 32ビット<br>.DF 64ビット |
| [D] | データの格納先を指定します。 | .U .S 16 ビット<br>.D .L .F 32ビット<br>.DF 64ビット |

- ※ サフィックスA 付加時の占有サイズは、データ型の変換ルールに基づき、占有サイズが変化します。
  - →「データ型の自動変換」(1-32ページ)

> **ポイント**
> - サフィックス.A付加時に配列型や構造体型変数を指定する場合は、要素番号、メンバまで指定してください。
> - サフィックス.AはCPU機能バージョン2.3以降のKV-8000シリーズで使用できます。
>   →「KV-8000シリーズ　CPU機能バージョンについて」(2ページ)

#### 動作説明 (4-2〜4-4 / 原本 p.250-252)

| 命令 | 動作 |
|---|---|
| MOV(.U) | 実行条件がONのとき、[S] に格納されている16ビット符号無しBINデータを [D] に格納します。 |
| MOV.S | 実行条件がONのとき、[S] に格納されている16ビット符号付きBINデータを [D] に格納します。 |
| MOV.D | 実行条件がONのとき、［[S]・[S]+1］に格納されている32ビット符号無しBINデータを［[D]・[D]+1］に格納します。 |
| MOV.L | 実行条件がONのとき、［[S]・[S]+1］に格納されている32ビット符号付きBINデータを［[D]・[D]+1］に格納します。 |
| MOV.F | 実行条件がONのとき、[S] で指定した単精度浮動小数点型実数を [D] に格納します。 |
| MOV.DF | 実行条件がONのとき、[S] で指定した倍精度浮動小数点型実数を [D] に格納します。 |
| MOV.A | 実行条件がONのとき、[S] で指定した変数を [D] で指定した変数のデータ型に型変換を行ったうえで、[S] で指定した変数を [D] に格納します。<br>型変換の詳細は →「データ型の自動変換」(1-32ページ)を参照してください。 |
| ＠MOV.□ | 実行条件の立ち上がりで、1スキャンだけ実行します。 |

##### 例: MOV.S (4-3 / 原本 p.251)

> **例**
> [S] に、定数を指定した場合。

ラダー: a接点(デバイス名なし) → MOV #12345 DM100

| データメモリ | 命令実行前 | 命令実行後 |
|---|---|---|
| DM98 | 0 | 0 |
| DM99 | 0 | 0 |
| DM100 | 0 | 12345 |
| DM101 | 0 | 0 |
| DM102 | 0 | 0 |

- 図: [S] : 12345 →「転送」→ [D] : DM100。各セルは 16ビット(1ワード)。

> [S] に、定数以外を指定した場合。

ラダー: a接点(デバイス名なし) → MOV DM99 DM101

| データメモリ | 命令実行前 | 命令実行後 |
|---|---|---|
| DM98 | 0 | 0 |
| DM99 | 12345 | 12345 |
| DM100 | 0 | 0 |
| DM101 | 0 | 12345 |
| DM102 | 0 | 0 |

- 図: DM99 が [S]、「転送」→ DM101 が [D]。各セルは 16ビット(1ワード)。

> 補足(本ファイル作成者): この「例」は原本では MOV.S の説明文の直後に置かれていますが、ラダーの命令語は「MOV」と表記されています(原文ママ)。

#### 動作説明 (4-14〜4-15 / 原本 p.262-263)

**PLDA(.U)**

> [S] がビットデータの場合
> 実行条件がONのとき、[S] から [n] で指定したビット数分を16ビット内部レジスタに格納します。未指定の上位側ビットには、0がロードされます。

ビット図(例は n=9 ビット相当):
- 転送元ビット列(左が上位): `0001111010101010`。[S] の矢印は右から2番目のビット(値1)を指し、そこから上位へ9ビット `101010101` が括弧 [n] で示される。右端の `0` は [S] より下位(範囲外)、左側の `000111`(左端は淡色)は範囲外。
- → 16ビット内部レジスタ bit15〜bit0: `0000000101010101`(下位9ビット `101010101` が括弧で対応、上位7ビットは0)

> [S] がワードデータまたは定数の場合
> 実行条件がONのとき、[S] で指定した16ビット符号無しBINデータの最下位ビットから [n] で指定したビット数分を内部レジスタに格納します。未指定の上位側ビットには、0がロードされます。

ビット図:
- [S] bit15〜bit0: `0000111101010101`(下位9ビット `101010101` が括弧 [n])
- → 16ビット内部レジスタ bit15〜bit0: `0000000101010101`

**PLDA.D**

> [S] がビットデータの場合
> 実行条件がONのとき、［[S]・[S]＋1］から [n] で指定したビット数分を32ビット内部レジスタに格納します。未指定の上位側ビットには、0がロードされます。

ビット図:
- 転送元ビット列(左が上位): `00011110101010101010101010101010`。[S] の矢印は右から2番目のビットを指し、そこから上位へ25ビットが括弧 [n]。右端の `0` と左側の `000111` は範囲外(淡色部分あり)。
- → 32ビット内部レジスタ bit31〜bit0: `00000001010101010101010101010101`(上位7ビットは0)

> [S] がワードデータまたは定数の場合
> 実行条件がONのとき、［[S]・[S]＋1］で指定した16ビット符号無しBINデータの最下位ビットから [n] で指定したビット数分を32ビット内部レジスタに格納します。未指定の上位側ビットには、0がロードされます。

ビット図:
- [S]+1・[S](左が [S]+1 の bit15、右が [S] の bit0): `00011101010101010101010101010101`(下位25ビットが括弧 [n])
- → 32ビット内部レジスタ bit31〜bit0: `00000001010101010101010101010101`

> 補足(本ファイル作成者): PLDA.D のワードデータの説明文は原本どおり「16ビット符号無しBINデータ」と書かれています(原文ママ・要確認: 図は32ビット［[S]・[S]+1］)。

| 命令 | 動作 |
|---|---|
| ＠PLDA.□ | 実行条件の立ち上がりで、1スキャンだけ実行します。 |

| CR2010 | 指定した対象から読み出した値が0のときはON、それ以外はOFF。 |

  - →「CR/CM一覧」(付-42ページ)

> 実行条件がONのとき、32ビット内部レジスタに格納されている32ビット符号無しBINデータの最下位ビットから、[n] で指定したビット数分を［[D]・[D]＋1］の最下位ビットを先頭として格納します。未指定のビットには書き込みません。

- → [D]+1・[D]: `00011101010101010101010101010101`(下位25ビットが格納部分。上位7ビット `0001110` は淡色=書き込まれない元の値)

| DW(.U) | 実行条件がONのとき、[S] で指定した16ビット符号無しBINデータを [D] に格納します。 |
| DW.S | 実行条件がONのとき、[S] で指定した16ビット符号付きBINデータを [D] に格納します。 |
| DW.D | 実行条件がONのとき、[S] で指定した32ビット符号無しBINデータを［[D]・[D]+1］に格納します。 |
| DW.L | 実行条件がONのとき、[S] で指定した32ビット符号付きBINデータを［[D]・[D]+1］に格納します。 |
| DW.F | 実行条件がONのとき、[S] で指定した単精度浮動小数点型実数を［[D]・[D]+1］に格納します。 |
| DW.DF | 実行条件がONのとき、[S] で指定した倍精度浮動小数点型実数を［[D]・[D]+1・[D]+2・[D]+3］に格納します。 |
| ＠DW.□ | 実行条件の立ち上がりで、1スキャンだけ実行します。 |

動作説明の図(値の流れ):
- DW(.U): [S] `1234` → [D] `1234`(16ビット(1ワード))
- DW.S: [S] `－1234` → [D] `－1234`(16ビット(1ワード))
- DW.D: [S] `12345678` → [D]+1・[D] `12345678`(32ビット(2ワード))
- DW.L: [S] `－12345678` → [D]+1・[D] `－12345678`(32ビット(2ワード))
- DW.F: [S] `+1.2345` → [D]+1・[D] `+1.2345`(32ビット(2ワード))
- DW.DF: [S] `+1.23456789` → [D]+3・[D]+2・[D]+1・[D] `+1.23456789`(64ビット(4ワード))

#### 演算フラグ (4-22 / 原本 p.270)

| フラグ | 内容 |
|---|---|
| CR2009 | 変化なし |
| CR2010 | 変化なし |
| CR2011 | 変化なし |
| CR2012 | 間接指定またはインデックス修飾の範囲が不適切な場合、オペランドの範囲外アクセスが発生した場合はON、それ以外はOFF。<br>オペランドに間接指定、インデックス修飾を指定していない場合、およびオペランドの範囲外アクセスのチェックが行われない場合は変化しません。<br>→「オペランドの範囲外アクセス」(1-53ページ) |

- ※ CR2012がONした場合、命令は実行されません。
  - [KV-8000/7000/5000/3000シリーズ] CR2012がONした場合、CM5150～CM5176にエラーの詳細情報が格納されます。
  - [KV Nanoシリーズ] CR2012がONした場合、CM2250～CM2276にエラーの詳細情報が格納されます。
  - →「CR/CM一覧」(付-42ページ)

#### サンプルプログラム (4-22 / 原本 p.270)

> 入力リレーR000がONしたとき、データメモリDM0に#100を格納します。

ラダー: R000 立ち上がり微分接点(↑付き a接点)→ DW #100 DM0

〈ニモニックリスト〉
```
LDP R000
DW #100 DM0
```
