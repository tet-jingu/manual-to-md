#### ラダープログラム (2-2 / 原本 p.76)

【図】ラダープログラム(原本 p.76)
- LD/LDB: `S` の接点を左母線に直接接続し、出力コイルへ。
- AND/ANB: 左母線に接続した接点(グレー表示)の後に `S` の接点を直列に接続し、出力コイルへ。
- OR/ORB: 左母線に接続した接点(グレー表示)に対して、`S` の接点を左母線から並列に接続し、出力コイルへ。
- 図中の注記: 「＊＊Bの場合は、□に/が入ります。」(接点記号の中の□が、LDB/ANB/ORB では「/」(b接点)になるという意味)

#### 入力方法 (2-2 / 原本 p.76)

| 命令 | 入力キー列 | 別入力(原本の括弧内) |
|---|---|---|
| LD | `LD␣S↵` | `A␣S↵` / `X␣S↵` / `XIC␣S↵` |
| LDB | `LDB␣S↵` | `B␣S↵` / `LDI␣S↵` / `LDNOT␣S↵` / `ANI␣S↵` / `ANDNOT␣S↵` / `XIO␣S↵` |
| AND | `AND␣S↵` | `A␣S↵` / `X␣S↵` / `XIC␣S↵` / `LD␣S↵` |
| ANB | `ANB␣S↵` | `B␣S↵` / `LDI␣S↵` / `LDNOT␣S↵` / `ANI␣S↵` / `ANDNOT␣S↵` / `LDBNOT␣S↵` / `XIO␣S↵` |
| OR | `OR␣S↵` | (なし) |
| ORB | `ORB␣S↵` | `ORI␣S↵` / `ORNOT␣S↵` |

(入力方法は機種別に分かれていない)

#### オペランド (2-2 / 原本 p.76)

| オペランド | 説明 | 占有サイズ |
|---|---|---|
| `S` | 左母線に接続するビットを指定します。※1※2 | 1ビット |

- ※1 DRでリレーを指定すると、スキャンタイムの影響を受けず高速でリフレッシュできます。
- ※2 `S` にワードデータを指定する場合、最下位ビットの状態がロードされます。
  - `[KV-8000/7000/5000/3000シリーズ、KV Nanoシリーズ]` ワードデータのビット指定が可能です。
  - `[KV-1000]` 最下位ビット以外の状態をロードするにはBLD/BLDB命令を使用します。

#### 動作説明 (2-2 / 原本 p.76)

| 命令 | 動作 |
|---|---|
| LD | `S` をa接点として母線に接続します。<br>`S` のON/OFF状態をLD以降の命令に伝えます。 |
| LDB | `S` をb接点として母線に接続します。<br>`S` のON/OFFを反転した状態をLDB以降の命令に伝えます。 |
| AND | `S` をa接点として回路に直列接続します。 |
| ANB | `S` をb接点として回路に直列接続します。 |
| OR | `S` をa接点として回路に並列接続します。 |
| ORB | `S` をb接点として回路に並列接続します。 |

#### タイミングチャート (2-3 / 原本 p.77)

【図】LD/AND/OR 命令と LDB/ANB/ORB 命令のタイミングチャート(原本 p.77)
- 上段に「スキャン」の目盛り、その下に `S`、「LD命令 AND命令 OR命令」、「LDB命令 ANB命令 ORB命令」の3段(各 ON/OFF)。
- `S` が OFF→ON→OFF→ON→OFF と2回ONする波形。
- LD/AND/OR 命令は `S` と同じタイミングで ON/OFF する(`S` がONの間ON)。
- LDB/ANB/ORB 命令は `S` の反転(`S` がONの間OFF、`S` がOFFの間ON)。
- 図では遅れ(スキャンのずれ)は描かれていない。

> **参考**
> 直列接続、並列接続する接点の数に制限はありません。

> **ポイント**
> 接点以外の命令を含む並列接続はできません。

【図】禁止回路の例(原本 p.77)
- 1段目: 左母線 → a接点 → 出力コイル。
- 2段目: 左母線 → a接点 → 接点以外の命令(点線の丸で囲まれたコイル記号。矢印で「接点以外の命令」と注記)を経て、1段目のa接点の後ろに並列に合流する回路。
- 合流部分に大きな×印があり、この接続はできないことを示す。

#### 演算フラグ (2-3 / 原本 p.77)

| フラグ | 内容 |
|---|---|
| CR2009 | 変化なし |
| CR2010 | 変化なし |
| CR2011 | 変化なし |
| CR2012 | 間接指定またはインデックス修飾の範囲が不適切な場合、DRを指定していて拡張入出力ユニットがダイレクト入出力に対応していない場合、オペランドの範囲外アクセスが発生した場合にON、それ以外OFF。オペランドに間接指定、インデックス修飾、DRを指定していない場合、およびオペランドの範囲外アクセスのチェックが行われない場合は変化しない。<br>→「オペランドの範囲外アクセス」（1-53ページ） |

- ※ CR2012がONした場合、接点はOFF します。
  - `[KV-8000/7000/5000/3000シリーズ]` CR2012がONした場合、CM5150～CM5176にエラーの詳細情報が格納されます。
  - `[KV Nanoシリーズ]` CR2012がONした場合、CM2250～CM2276にエラーの詳細情報が格納されます。
  - →「CR/CM一覧」（付-42ページ）

#### サンプルプログラム (2-3 / 原本 p.77)

> R000, DM0の0ビットのどちらかがONで（両方がONでも）、かつR001がOFFのときのみ出力リレーのR500がONします。

使用デバイス: R000, DM0, R001, R500
ラダー図: R000(a接点)と DM0(a接点)の並列回路 → R001(b接点) → R500(出力コイル)

〈ニモニックリスト〉
```
LD R000
OR DM0
ANB R001
OUT R500
```
