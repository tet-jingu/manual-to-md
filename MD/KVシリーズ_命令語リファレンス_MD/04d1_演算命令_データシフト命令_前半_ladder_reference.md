#### ラダープログラム (4-94 / 原本 p.342)

- 1行目: 「実行条件」の a接点を左母線に接続し、グレー表示の「LDA」→「SRA」(上に [n])→ グレー表示の「STA」と接続型命令を直列に並べる(LDA・STA は前後の命令の例としてグレー表示)。
- 2行目(@SRA): 「実行条件」の a接点 → グレー表示の「↑LDA」→「↑SRA」(上に [n])→ グレー表示の「↑STA」。

|---|---|

#### オペランド (4-94 / 原本 p.342)

| オペランド | 説明 | 占有サイズ |
|---|---|---|
| [n] | シフトするビット数を指定します。※1※2<br>SRA.Uは0～16、SRA.Dは0～32の範囲で指定できます。 | 16ビット |

- ※1 [n] の値が 0 のとき、最上位ビットの状態がCR2009に格納されます。
- ※2 [n] に定数以外を指定した場合、[n] の値が17以上(.Uのとき)/33以上(.Dのとき)のときは以下のようになります。
  - **内部レジスタの値=0、CR2009=OFF、CR2010=ON**

#### 動作説明 (4-94〜4-95 / 原本 p.342-343)

**SRA(.U)**

> 実行条件がONのとき、16ビット内部レジスタの状態を指定した [n] ビット分、ビット番号の小さい方へシフトします。
> 上位 [n] ビットには、0が格納されます。bit([n] － 1)の状態がCR2009に格納されます。結果は、16ビット内部レジスタに格納されます。

【図】SRA(.U) のビット図 (原本 p.342)(図中 n=5 の例)
- 実行前 16ビット内部レジスタ(bit15→bit0): `1110100000011001`
- 実行後 16ビット内部レジスタ(bit15→bit0): `0000011101000000`
- 上位 [n] ビット(5ビット)に「0を格納」。元の下位5ビット `11001` は右にはみ出して「消去」(網掛け)。
- bit([n]-1)(=元の bit4)の状態 `1` が CR2009(キャリー)へ。

**SRA.D**

> 実行条件がONのとき、32ビット内部レジスタの状態を指定した [n] ビット分、ビット番号の小さい方へシフトします。
> 上位 [n] ビットには、0が格納されます。bit([n] － 1)の状態がCR2009に格納されます。結果は、32ビット内部レジスタに格納されます。

【図】SRA.D のビット図 (原本 p.342)(図中 n=5 の例)
- 実行前 32ビット内部レジスタ(bit31→bit0): `1110100000011001 1110100000011001`
- 実行後 32ビット内部レジスタ(bit31→bit0): `0000011101000000 1100111101000000`
- 上位 [n] ビットに「0を格納」。元の下位5ビット `11001` は「消去」。
- bit([n]-1) の状態 `1` が CR2009(キャリー)へ。

**@SRA.□**

> 実行条件の立ち上がりで、1スキャンだけ実行します。

> **参考**
> SRA命令を毎スキャン型で実行すると、実行条件がONの間、スキャンごとにビットシフトします。スキャンごとではなく、実行条件の立ち上がりで実行するときは、次のように微分型命令を使用してください。

【図】参考のラダー図 (原本 p.343)
- 1行目: a接点 →(点線)→ 「↑LDA」(上にグレーで DM＊＊＊＊)→「↑SRA」→「↑STA」(上にグレーで DM＊＊＊＊)。
- 2行目: 立ち上がり微分接点(↑付き接点)→(点線)→「LDA」(DM＊＊＊＊)→「SRA」→「STA」(DM＊＊＊＊)。

#### 演算フラグ (4-95 / 原本 p.343)

| フラグ | 内容 |
|---|---|
| CR2009 | 演算後、キャリーが格納されたときON、それ以外OFF。 |
| CR2010 | 演算結果が0になったときON、それ以外OFF。 |
| CR2011 | 変化なし |
| CR2012 | 間接指定またはインデックス修飾の範囲が不適切な場合、オペランドの範囲外アクセスが発生した場合はON、それ以外OFF。<br>オペランドに間接指定、インデックス修飾を指定していない場合、およびオペランドの範囲外アクセスのチェックが行われない場合は変化しません。<br>→「オペランドの範囲外アクセス」(1-53ページ) |

- ※ CR2012がONした場合、命令は実行されません。
  - [KV-8000/7000/5000/3000シリーズ] CR2012がONした場合、CM5150～CM5176にエラーの詳細情報が格納されます。
  - [KV Nanoシリーズ] CR2012がONした場合、CM2250～CM2276にエラーの詳細情報が格納されます。
  - →「CR/CM一覧」(付-42ページ)

#### サンプルプログラム (4-96 / 原本 p.344)

> 入力リレーR30008～R30015に入力されたデジタルスイッチからのBCDデータ(2桁分)をデータメモリDM0に格納します。

ラダー図: MR000 の a接点 →「LDA R30000」→「SRA #8」→「STA DM0」。

〈ニモニックリスト〉
```
LD MR000
LDA R30000

SRA #8
CON
STA DM0
```

【図】データの流れ (原本 p.344)
- デジスイッチ「2」「4」が R30015〜R30008 に接続。
- R30000～R30015(R30015→R30000): `00100100` + 下位8ビットは空欄(図に値なし)
- ↓ LDA → 内部レジスタ: `00100100` + 下位8ビット空欄
- ↓ SRA → 内部レジスタ: `0000000000100100`
- ↓ STA → DM0: `0000000000100100`
