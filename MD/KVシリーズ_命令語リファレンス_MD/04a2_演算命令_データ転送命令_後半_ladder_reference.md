### BMOV / @BMOV (4-24〜4-25 / 原本 p.272-273)

#### 命令一覧 (4-24 / 原本 p.272)

| 命令語 | 記号 | 名称 | 概要 |
|---|---|---|---|
| BMOV(.U)<br>BMOV.D | 右母線側に置く箱型の命令要素(左上に「BMOV」、オペランド欄3つ) | ブロック転送 | 16/32 ビットデータを参照先にブロック転送します。 |
| @BMOV(.U)<br>@BMOV.D | 同上。左上の「BMOV」の左に上向き矢印(立ち上がり実行) | ブロック転送 | 16/32 ビットデータを参照先にブロック転送します。 |

#### ラダープログラム (4-24 / 原本 p.272)

- 1行目: 「実行条件」の a接点を左母線に接続し、右端に BMOV 命令ボックス(オペランド [S] [D] [n])。
- 2行目: 「実行条件」の a接点を左母線に接続し、右端に @BMOV 命令ボックス(上向き矢印付き、オペランド [S] [D] [n])。

#### 入力方法 (4-24 / 原本 p.272)

| 命令語 | 入力方法 |
|---|---|
| BMOV | `BMOV␣S␣D␣n↵` |
| @BMOV | `@BMOV␣S␣D␣n↵` |

#### オペランド (4-24 / 原本 p.272)

| オペランド | 説明 | 占有サイズ |
|---|---|---|
| [S] | 転送元データブロックの先頭を指定します。 | .U 16ビット×[n]<br>.D 32ビット×[n] |
| [D] | 転送先データブロックの先頭を指定します。 | .U 16ビット×[n]<br>.D 32ビット×[n] |
| [n] | 転送する数(データ数)を指定します。(1～65535：16ビット符号無しバイナリ) | 16ビット |

#### 動作説明 (4-24〜4-25 / 原本 p.272-273)

**BMOV(.U)**
> 実行条件がONのとき、[S] を先頭とする [n] ワードの内容を [D] を先頭とする [n] ワードにブロック転送します。

【図】転送矢印図 (原本 p.272):

| 転送元 | | 転送先 |
|---|---|---|
| [S] | 転送 → | [D] |
| [S]+1 | 転送 → | [D]+1 |
| [S]+2 | 転送 → | [D]+2 |
| ： | ： | ： |
| [S]+[n]-2 | 転送 → | [D]+[n]-2 |
| [S]+[n]-1 | 転送 → | [D]+[n]-1 |

> **例**
> [S] :DM100, [D] :EM104, [n] :#5の場合

ラダー: a接点 → BMOV DM100 EM104 #5

| 転送元デバイス | 転送元 16ビット(1ワード) | | 転送先 16ビット(1ワード) | 転送先デバイス |
|---|---|---|---|---|
| DM100 | 1 | → | 1 | EM104 |
| DM101 | 3 | → | 3 | EM105 |
| DM102 | 7 | → | 7 | EM106 |
| DM103 | 15 | → | 15 | EM107 |
| DM104 | 31 | → | 31 | EM108 |

**BMOV.D** (4-25 / 原本 p.273)
> 実行条件がONのとき、［[S]・[S]+1］を先頭とする [n] ×2ワードの内容を［[D]・[D]+1］を先頭とする [n] ×2ワードにブロック転送します。

【図】転送矢印図 (原本 p.273):

| 転送元 | | 転送先 |
|---|---|---|
| ［[S]・[S]+1］ | 転送 → | ［[D]・[D]+1］ |
| ［[S]+2・[S]+3］ | 転送 → | ［[D]+2・[D]+3］ |
| ： | ： | ： |
| ［[S]+2(n－2)・[S]+2(n－2)+1］ | 転送 → | ［[D]+2(n－2)・[D]+2(n－2)+1］ |
| ［[S]+2(n－1)・[S]+2(n－1)+1］ | 転送 → | ［[D]+2(n－1)・[D]+2(n－1)+1］ |

> **例**
> [S] :DM100、[D] :EM5、[n] :#3の場合

ラダー: a接点 → BMOV.D DM100 EM5 #3

| 転送元(上位:下位) | 転送元 上位 | 転送元 下位 | | 転送先(上位:下位) | 転送先 上位 | 転送先 下位 |
|---|---|---|---|---|---|---|
| DM101:DM100 | 0001 | 2345 | → | EM6:EM5 | 0001 | 2345 |
| DM103:DM102 | 0012 | 3456 | → | EM8:EM7 | 0012 | 3456 |
| DM105:DM104 | 0123 | 4567 | → | EM10:EM9 | 0123 | 4567 |

(各行とも 32ビット(2ワード))

**＠BMOV.□**
> 実行条件の立ち上がりで、1スキャンだけ実行します。

> **ポイント**
> - 転送元と転送先のブロックが部分的に重複していても、正しく転送されます。
> - [n] に大きな値を指定すると、スキャンタイムが大きく延びます。

#### 演算フラグ (4-25 / 原本 p.273)

| フラグ | 内容 |
|---|---|
| CR2009 | 変化なし |
| CR2010 | 変化なし |
| CR2011 | 変化なし |
| CR2012 | • 以下のいずれかの条件が成立した場合はON、それ以外はOFF<br>　- 間接指定またはインデックス修飾の範囲が不適切な場合<br>　- [n] に定数以外を指定し、転送元または転送先がデバイス、ワーク領域の範囲を超えた場合<br>　- [n] =0の場合<br>　- オペランドの範囲外アクセスが発生した場合<br>• [n] が定数で、間接指定またはインデックス修飾を使用していない場合、およびオペランドの範囲外アクセスのチェックが行われない場合は変化しません。<br>→「オペランドの範囲外アクセス」(1-53ページ) |

- ※ CR2012がONした場合、命令は実行されません。
  - [KV-8000/7000/5000/3000シリーズ] CR2012がONした場合、CM5150～CM5176にエラーの詳細情報が格納されます。
  - [KV Nanoシリーズ] CR2012がONした場合、CM2250～CM2276にエラーの詳細情報が格納されます。
  - →「CR/CM一覧」(付-42ページ)
