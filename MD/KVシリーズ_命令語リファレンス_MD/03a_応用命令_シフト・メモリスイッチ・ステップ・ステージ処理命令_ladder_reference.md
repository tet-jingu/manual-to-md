## シフト命令 (3-2〜3-3 / 原本 p.150-151)

各ページ上部の見出しは「応用命令 シフト命令」。右端インデックスタブ(SFT)は転記省略。

### SFT (3-2〜3-3 / 原本 p.150-151)

#### 対応機種 (3-2 / 原本 p.150)

| KV-8000 | KV-7000 | KV-5000/3000 | KV-1000 | KV Nano |
|---|---|---|---|---|
| 有効 | 有効 | 有効 | 有効 | 有効 |

#### 命令一覧 (3-2 / 原本 p.150)

| 命令語 | 記号 | 名称 | 概要 |
|---|---|---|---|
| SFT | 右母線側に置く箱型の要素。上辺に「SFT」、左辺に上から「D」「CLK」「RES」の3入力端子 | シフト | シフトレジスタの動作をします。 |

#### ラダープログラム (3-2 / 原本 p.150)

3行の入力を持つ1つの SFT ボックス:
- 1行目: 「データ入力」の a接点を左母線に接続し、SFT ボックスの D 端子へ。ボックス内 D の下に [D1]。
- 2行目: 「クロック入力」の a接点から CLK 端子へ。ボックス内 CLK の下に [D2]。
- 3行目: 「リセット入力」の a接点から RES 端子へ。

#### 入力方法 (3-2 / 原本 p.150)

機種別の分け書きはなし(全機種共通)。

| 命令語 | 入力方法 | 括弧内の別入力 |
|---|---|---|
| SFT | `SFT␣D1␣D2↵` | なし |

#### オペランド (3-2 / 原本 p.150)

| オペランド | 説明 | 占有サイズ |
|---|---|---|
| [D1] | 開始ビットを指定します。※1※2 | 1ビット×([D2]－[D1]+1) |
| [D2] | 終了ビットを指定します。※1※2 | 1ビット×([D2]－[D1]+1) |

- ※1 CR/CMは指定できません。
- ※2 ワードデータを指定した場合、最下位ビットがシフトします。最下位ビット以外は変化しません。
  ワードデータのビット指定は使用できません。

#### 動作説明 (3-2 / 原本 p.150)

> データ入力のON/OFFの状態をクロック入力の立ち上がりで読み出します。
> その状態を [D1] から [D2] で指定したビットに、クロックのタイミングでシフトします。
> リセット入力がONのとき [D1] から [D2] のビットはすべてOFFします。
> シフトするビットは [D1] ～ [D2] の範囲内のビットのみです。それ以外のビットはシフトしません。

【図】タイミングチャート (原本 p.150) — 信号: データ入力 / クロック入力 / リセット入力 / 対象ビット。対象ビットの行ラベルは2列あり、
「①」列: [D1]、[D1]+1、[D1]+2、[D1]+3、(波線で中略)、[D2]－1、[D2]
「②」列: [D1]、[D1]－1、[D1]－2、[D1]－3、(波線で中略)、[D2]+1、[D2]
- クロック入力は連続パルス。各立ち上がりに↑の矢印。
- データ入力が ON した後のクロック立ち上がりで [D1] が ON。以後クロック立ち上がりごとに [D1]+1(②では [D1]－1)、[D1]+2、[D1]+3 …と1ビットずつ遅れて ON が伝わる(図中の斜め矢印で伝搬を表示)。
- データ入力が OFF すると、次のクロック立ち上がりで [D1] が OFF し、OFF も同様に1クロックずつ後段へシフトする。データ入力の2回目の ON も同様に [D1] から順にシフトする。
- [D2]－1(②では [D2]+1)が ON した次のクロックで [D2] が ON する。
- リセット入力が ON した時点で、[D1] 〜 [D2] のすべてのビットが OFF し、リセット入力 ON の間は OFF のまま(データ入力・クロック入力が変化しても OFF)。

> 補足(本ファイル作成者): 「①」「②」の2列の意味は原本に文章の説明がない。①は [D1]＜[D2](番号が増える方向へシフト)、②は [D1]＞[D2](番号が減る方向へシフト)の場合の番号付けと読めるが、原本での明記はない(要確認 原本 p.150)。

> **ポイント**
> - 2つ以上のSFT命令間での [D1] どうし、[D2] どうしの重複使用はできません。
> - 割り込みプログラムおよび初期化モジュール内では、使用できません。

#### サンプルプログラム (3-3 / 原本 p.151)

**■繰り返しシフト回路**

> 出力を1秒ごとに順次ONさせ、繰り返します。CR2008(運転開始時1スキャンのみON)で内部補助リレーR1000をセットさせタイマT1で1秒ごとに出力リレーR500～R502の出力をシフトさせます。
> R1003がONすることでR1000をセットし、処理を繰り返します。

ラダー: CR2008 a接点 → R1000 SET。T1 b接点 → タイマ T1(設定値 #10)。SFT ボックス(D=CR2003 a接点、CLK=T1 a接点、RES=CR2003 a接点、[D1]=R1000、[D2]=R1003)。R1000 → R500、R1001 → R501、R1002 → R502 の各出力コイル。R1003 a接点 → R1000 SET。

使用デバイス: CR2008(運転開始時1スキャンのみON)、CR2003、T1、R1000～R1003、R500～R502

```
LD CR2008
SET R1000
LDB T1
TMR #1 #10
LD CR2003
LD T1
LD CR2003
```

#### 動作説明 (3-8 / 原本 p.156)

> [S] がONのとき、STP命令からSTE命令間(プログラム A)を実行します。
> [S] がOFFのときは、STP命令からSTE命令間のプログラムは実行されず、STE命令の次(プログラム B)にジャンプします。

> **例**
> 入力R000がONのとき、入力R001のON/OFFに連動して出力R500がON/OFFします。入力R000がOFFのときは、入力R001がONしても出力R500はONしません。

```
LD R001
OUT R500
STE
```

> **ポイント**
> - 実行されていないSTP命令からSTE命令間はスキャンタイムに影響しません。
> - STP ～ STE 命令間に微分実行型命令やタイマ命令、マクロ命令を使用するときは注意が必要です。

#### 動作説明 (3-12 / 原本 p.160)

**STG**
> [D] がONのとき、｜STG｜はONしている接点として動作します。
> [D] がOFFのとき、次のプログラムブロックの先頭にジャンプします。
> [D] がONからOFFに切り換わったとき、｜STG｜はOFFしている接点として動作します。
> - STG命令は、必ず母線より始めてください。
> - STG命令のオぺランド重複使用はできません。
> - 最初のSTGの [D] は微分型の条件でセットしてください。

> - 同一プログラムブロック内に、複数のSTG命令を置かないでください。
> - STGと同一プログラムブロック内に少なくとも1つはJMP/ENDS命令を配置してください。

**JMP**
> 直前の状態がONのとき、現在実行しているステージリレーをリセットし、[D]'をセットします。
> - STG命令を配置しているプログラムブロック内に配置してください。

**ENDS**
> 直前の状態がONのとき、現在実行しているステージリレーをリセットします。
> - STG命令を配置しているプログラムブロック内に配置してください。

#### ■ステージ命令とは (3-13 / 原本 p.161)

> ステージ命令とは、工程に合わせて順次処理(シーケンス処理)をするのに適しています。
> プログラム全体を細かい工程に分け、1つの工程ごとにプログラムを実行します。

【図】フローチャート (原本 p.161) — 「電源ON」→ 判断「スタートスイッチ ON?」→ Yes で 工程① → 工程② → 工程③ → 工程④。No は判断の左から出る矢印。工程④の下から左側の縦線で No の線につながる(戻り先の矢印の向きは図から判読不可。要確認 原本 p.161)。

- R1000 STG ─○(処理)… → R1001 JMP →工程①
- R1001 STG ─○(処理)… → R1002 JMP →工程②
- R1002 STG ─○(処理)… → R1003 JMP →工程③

#### 動作説明 (3-20 / 原本 p.168)

**W-UE**
> ① 実行条件がONのとき、[S] が立ち上がると、[D] をセットします。
> ② [S] がOFFしても、実行条件がOFFするまで、[D] はONし続けます。
> ③ 実行条件がOFFすると、[D] がOFFします。
> - 第2オペランド [D] の重複使用はできません。
>
> ④ 実行条件がONのとき、[S] がONでも、立ち上がりが検出されなければ、[D] はONしません。

【図】W-UE のラダーとタイミングチャート (原本 p.168) — ラダー: 実行条件 a接点 → ↑ 要素([S]/[D])。信号: 実行条件 / [S] / [D]。時点 ① ② ③ ④
- 実行条件が ON した後、① で [S] が立ち上がり(↑)→ [D] が ON。
- ② で [S] が OFF しても [D] は ON のまま。
- ③ で実行条件が OFF → [D] が OFF。
- 実行条件 OFF 中に [S] が立ち上がる(↑)が、[D] は OFF のまま。
- ④ で実行条件が ON(このとき [S] は ON のまま)→ 立ち上がりが検出されないので [D] は OFF のまま。

**W-DE**
> ① 実行条件がONのとき、[S] が立ち下がると、[D] をセットします。
> ② [S] がONしても、実行条件がOFFするまで、[D] はONし続けます。
> ③ 実行条件がOFFすると、[D] がOFFします。
> - 第2オペランド [D] の重複使用はできません。
>
> ④ 実行条件が ON のとき、[S] が OFF でも、立ち下がりが検出されなければ、[D] はONしません。

【図】W-DE のラダーとタイミングチャート (原本 p.168) — ラダー: 実行条件 a接点 → ↓ 要素([S]/[D])。信号: 実行条件 / [S] / [D]。時点 ① ② ③ ④
- 初め [S] は ON。実行条件が ON した後、① で [S] が立ち下がり(↓)→ [D] が ON。
- ② で [S] が ON しても [D] は ON のまま。
- ③ で実行条件が OFF → [D] が OFF。
- 実行条件 OFF 中に [S] が立ち下がる(↓)が、[D] は OFF のまま。
- ④ で実行条件が ON(このとき [S] は OFF のまま)→ 立ち下がりが検出されないので [D] は OFF のまま。

#### サンプルプログラム (3-21 / 原本 p.169)

> 入力リレーがONのとき、入力リレーR001～R003のONする順序がR001→R002→R003のとき、出力リレーR500をONします。

(冒頭の「入力リレーがONのとき」はデバイス名が抜けている(原文ママ・要確認: ラダー・ニモニックでは R000))

ラダー: R000 a接点 → W-UE(上 R001、下 R1000)。R1000 a接点 → W-UE(上 R002、下 R1001)。R1001 a接点 → W-UE(上 R003、下 R1002)。R1002 a接点 → R500 コイル。

使用デバイス: R000～R003、R1000～R1002、R500

〈ニモニックリスト〉
```
LD R000
W-UE R001 R1000
LD R1000
W-UE R002 R1001
LD R1001
W-UE R003 R1002
LD R1002
OUT R500
```

【図】タイミングチャート (原本 p.169) — 信号: スキャン(目盛り) / R000 / R001 / R1000 / R002 / R1001 / R003 / R1002 / R500
- R000 が ON。その後 R001 が立ち上がり(↑パルス)→ R1000 が ON。
- 続いて R002 が立ち上がり → R1001 が ON。
- 続いて R003 が立ち上がり → R1002 が ON、同時に R500 が ON(図中「ON」の網掛け)。
- R000 が OFF → R1000、R1001、R1002、R500 がすべて OFF。
- R000 が再び ON。まず R002 が立ち上がるが R1000 が OFF のため R1001 は OFF のまま。次に R001 が立ち上がり → R1000 が ON。
- 次に R003 が立ち上がるが R1001 が OFF のため R1002 は OFF のまま。さらに R003 が再度立ち上がるが同様に変化なし。
- 次に R002 が立ち上がり → R1001 が ON。続いて R001 が立ち上がる(R1000 は ON のまま)。
- R000 が OFF → R1000、R1001 が OFF。この2回目の区間では R1002・R500 は ON しない(順序が R001→R002→R003 にならなかったため)。
