## タイマ・カウンタ命令 (2-36〜2-59 / 原本 p.110-133)

各ページ上部の見出しは「基本命令 タイマ・カウンタ命令」。右端インデックスタブ(TMR / TMH / TMS / TMU / UDT / C / OUTC / ITVL / UDC)は転記省略。

### TMR / TMH / TMS (2-36〜2-39 / 原本 p.110-113)

#### 対応機種 (2-36 / 原本 p.110)

| KV-8000 | KV-7000 | KV-5000/3000 | KV-1000 | KV Nano |
|---|---|---|---|---|
| 有効 | 有効 | 有効 | 有効 | 有効 |

#### 命令一覧 (2-36 / 原本 p.110)

| 命令語 | 記号 | 名称 | 概要 |
|---|---|---|---|
| TMR | 右母線側に置く箱型の出力要素「┤T ├」(上に設定値 [S]、中に T [n]) | タイマ | 動作単位100ms 32ビットの減算式オンディレイタイマです。 |
| TMH | 同上。T の下に小さく H を付けた「┤T/H ├」 | 高速10msタイマ | 動作単位10ms 32ビットの減算式オンディレイタイマです。 |
| TMS | 同上。T の下に小さく S を付けた「┤T/S ├」 | 高速1msタイマ | 動作単位1ms 32ビットの減算式オンディレイタイマです。 |

#### ラダープログラム (2-36 / 原本 p.110)

3命令とも同じ形の2行回路:
- 1行目: 「実行条件」の a接点を左母線に接続し、右端にタイマ要素(上に [S]、中に TMR は「T [n]」、TMH は「T(下付き H) [n]」、TMS は「T(下付き S) [n]」)。
- 2行目: 「T [n]」の a接点から出力コイルへ(タイマ接点の使い方の例)。

#### 入力方法 (2-36 / 原本 p.110)

機種別の分け書きはなし(全機種共通)。

| 命令語 | 入力方法 | 括弧内の別入力 |
|---|---|---|
| TMR | `TMR␣n␣S↵` | `T␣n␣S↵`<br>`TIM␣n␣S↵`<br>`OUTT␣n␣S↵` |
| TMH | `TMH␣n␣S↵` | `TH␣n␣S↵`<br>`TIMH␣n␣S↵`<br>`OUTH␣n␣S↵` |
| TMS | `TMS␣n␣S↵` | `TS␣n␣S↵`<br>`TIMHH␣n␣S↵`<br>`OUTS␣n␣S↵` |

(TMS の別入力2行目は画像を拡大して確認済みで `TIMHH`(原文ママ))

#### オペランド (2-36 / 原本 p.110)

| オペランド | 説明 | 占有サイズ |
|---|---|---|
| [n] | タイマの番号(0～3999)を指定します。※1 | 16ビット |
| [S] | タイマの設定値を指定します。0～4294967295の範囲で設定します。 | 32ビット |

- ※1 定数、およびTIMER(タイマ)型に指定した変数/ラベルのみ指定可能です。

> **ポイント**
> タイマの番号 [n] は、以下の命令の番号と重複して使用できません。
> - [KV-8000/7000/5000/3000シリーズ、KV Nanoシリーズ] TMR, TMH, TMS, UDT, TMU
> - [KV-1000] TMR, TMH, TMS, C, OUTC, UDC, UDT

#### 動作説明 (2-37 / 原本 p.111)

> 実行条件がONのとき、[n] で指定したタイマを起動します。[S] で指定した値(設定値)がタイマ起動時の現在値となります。現在値は、100ms(TMR)/ 10ms(TMH)/ 1ms(TMS)おきに減算(－1)されます。
> 現在値が「#0」になると、タイマT [n] がONします。
> 実行条件がOFFすると、タイマT [n] がOFFし、現在値をリセットします。

【図】タイミングチャート (原本 p.111) — 信号: スキャン / 実行条件(ON/OFF) / 現在値(縦軸に「[S] で設定した値」と「#0」) / タイマ T [n]・T(H) [n]・T(S) [n]
- 実行条件 OFF の間、現在値は「[S] で設定した値」の高さ。
- 実行条件が ON すると、現在値が「[S] で設定した値」から階段状に1ずつ減っていく。
- 現在値が #0 に達した時点でタイマ接点が ON(図中「ON」の網掛け)。現在値は #0 のまま。
- 実行条件が OFF すると、タイマ接点が OFF し、現在値は「[S] で設定した値」の高さに戻る(リセット)。

> **ポイント**
> - TMRの誤差は、「±100ms+1スキャンタイム以内」となります。
> - TMHの誤差は、「±10ms+1スキャンタイム以内」となります。
> - TMSの誤差は、「±1ms+1スキャンタイム以内」となります。
> - [S] に定数以外を指定した場合、動作中は毎スキャン設定値が更新されます。
> - 設定値に0を設定すると、実行条件がONの間、タイマT [n] はON状態になります。
> - RUN中書き込みをおこなう場合は、注意が必要です。
>   使用しているCPUユニットのユーザーズマニュアルの「RUN中書き込みについて」を参照してください。
> - 割り込みプログラムおよび初期化モジュール内では使用できません。
>   使用しているCPUユニットのユーザーズマニュアルの「タイマ命令使用時の注意」を参照してください。

| フラグ | 内容 |

| CR2010 | 変化なし |

#### サンプルプログラム (2-38 / 原本 p.112)

**TMR**
> 入力リレーR000がONすると、3秒後にタイマT0がONし、出力リレーR500がONします。

ラダー: R000 a接点 → タイマ T0(設定値 #30)。T0 a接点 → R500 出力コイル。

〈ニモニックリスト〉
```
LD R000
TMR #0 #30
LD T0
OUT R500
```

**TMH**
> 入力リレーR000がONすると、0.5秒後にタイマT0がONし、出力リレーR500がONします。

ラダー: R000 a接点 → 高速10msタイマ T(H)0(設定値 #50)。T0 a接点 → R500 出力コイル。

〈ニモニックリスト〉
```
LD R000
TMH #0 #50
LD T0
OUT R500
```

**TMS**
> 入力リレーR000がONすると、7ms後にタイマT0がONし、出力リレーR500がONします。

ラダー: R000 a接点 → 高速1msタイマ T(S)0(設定値 #7)。T0 a接点 → R500 出力コイル。

〈ニモニックリスト〉
```
LD R000
TMS #0 #7
LD T0
OUT R500
```

#### タイマ現在値 ・ タイマ設定値の読み出しと変更 (2-38〜2-39 / 原本 p.112-113)

##### ①現在値の読み出し (2-38 / 原本 p.112)

> LDA.D命令またはMOV.D命令で読み出しできます。

> **例**
> T0の現在値をデータメモリ［DM0･DM1］に格納します。

ラダー(図から書き起こし。接点のデバイス名は原本図に記載なし):
- 1行目: a接点 → LDA.D T0 → STA.D DM0
- 2行目: a接点 → MOV.D T0 DM0

##### ②現在値の変更 (2-38 / 原本 p.112)

> MOV.D命令またはDW.D命令で変更できます。

> **例**
> T0の現在値を100000に変更します。

ラダー(図から書き起こし。接点のデバイス名は原本図に記載なし):
- 1行目: a接点 → MOV.D #100000 T0
- 2行目: a接点 → DW.D #100000 T0

> **ポイント**
> 現在値≦設定値のとき、現在値は書込んだ値に変更されます。
> 現在値＞設定値のとき、現在値は設定値と同じ値に変更されます。

##### ③設定値の読み出し (2-39 / 原本 p.113)

### UDC (2-56〜2-57 / 原本 p.130-131)

#### 対応機種 (2-56 / 原本 p.130)

| KV-8000 | KV-7000 | KV-5000/3000 | KV-1000 | KV Nano |
|---|---|---|---|---|
| 有効 | 有効 | 有効 | 有効 | 有効 |

#### 命令一覧 (2-56 / 原本 p.130)

| 命令語 | 記号 | 名称 | 概要 |
|---|---|---|---|
| UDC | 3入力(UP / DW / RES)を持つ箱型の命令ブロック(ブロック上辺に「UDC」) | アップダウンカウンタ | 32ビット加減算カウンタです。 |

#### ラダープログラム (2-56 / 原本 p.130)

- 「アップ入力」の a接点 → ブロックの UP 端子
- 「ダウン入力」の a接点 → ブロックの DW 端子
- 「リセット入力」の a接点 → ブロックの RES 端子
- ブロック上辺に「UDC [n]」、UP と DW の間に [S]
- 4行目: 「C [n]」の a接点から出力コイルへ。

#### 入力方法 (2-56 / 原本 p.130)

| 命令語 | 入力方法 | 括弧内の別入力 |
|---|---|---|
| UDC | `UDC␣n␣S↵` | `CNTR␣n␣S↵` |

#### オペランド (2-56 / 原本 p.130)

| オペランド | 説明 | 占有サイズ |
|---|---|---|
| [n] | カウンタの番号(0～3999)を指定します。※1 | 16ビット |
| [S] | カウンタの設定値を指定します。0～4294967295が指定できます。 | 32ビット |

- ※1 定数、およびCOUNTER(カウンタ)型に指定した変数/ラベルのみ指定可能です。

> **ポイント**
> カウンタの番号 [n] は、以下の命令の番号と重複して使用できません。
> - [KV-8000/7000/5000/3000シリーズ、KV Nanoシリーズ] C, OUTC, UDC
> - [KV-1000] TMR, TMH, TMS, C, OUTC, UDC, UDT

#### 動作説明 (2-56 / 原本 p.130)

> アップ入力の立ち上がりで、カウンタの現在値に1を加算(＋1)します。
> ダウン入力の立ち上がりで、カウンタの現在値から1を減算(－1)します。
> 現在値の桁上がり、桁下がり時に、カウンタUDC [n] がONします。
> リセット入力がONのとき、現在値を0にリセットします。

【図】ラダー例とタイミングチャート (原本 p.130)
- ラダー例(図から書き起こし): R001 a接点 → UP、R002 a接点 → DW、R003 a接点 → RES の UDC 0(設定値 #9)。C0 a接点 → 出力コイル(デバイス名の記載なし)。
- 信号: R001(アップ入力) / R002(ダウン入力) / R003(リセット入力) / 現在値(0〜設定値) / 接点 C0
- 最初 R003 が ON で、すぐ OFF。現在値 0。
- R001 の立ち上がりごとに現在値が 1, 2, 3, 4, 5, 6, 7, 8, 9(設定値)と増加。次の立ち上がりで桁上がりして現在値が 0 に戻り、このとき接点 C0 が短時間 ON(「桁上がり時」)。
- さらに R001 の立ち上がりで 1, 2, 3。R003(リセット入力)の ON で現在値 0。
- R002 の最初の立ち上がりで、現在値 0 から桁下がりして 9(設定値)になり、このとき接点 C0 が短時間 ON(「桁下がり時」)。以後 R002 の立ち上がりごとに 8, 7, 6, 5, 4, 3, 2, 1, 0 と減少。
- 次の R002 の立ち上がりで再び桁下がりして 9 になり、接点 C0 が短時間 ON(「桁下がり時」)。続いて 8, 7, 6。
- その後 R001 の立ち上がり2回で現在値が 7, 8 と増加し、続く R002 の立ち上がり2回で 7, 6 と減少(接点 C0 は ON しない)。

> **ポイント** (2-57 / 原本 p.131)
> - [S] に定数以外を指定した場合、動作中は毎スキャン設定値が更新されます。
> - 設定値に 0 を設定すると、アップ入力またはダウン入力 ON 後、常時カウンタ UDC [n] がON状態になります。OFFする場合は、リセット入力をONします。
> - RUN中書き込みをおこなう場合は、注意が必要です。
>   使用しているCPUユニットのユーザーズマニュアルの「RUN中書き込みについて」を参照してください。
> - 割り込みプログラムおよび初期化モジュール内では使用できません。

> **参考**
> アップダウンカウンタの現在値は、プログラムモード時や電源OFF時にも保持されます。
> - [KV-8000/7000/5000/3000シリーズ、KV Nanoシリーズ] CPUシステム設定で、電源OFF時にクリアできます。
> - [KV-1000] メモリスイッチ命令(MEMSW)を設定することにより、電源OFF時にクリアできます。
