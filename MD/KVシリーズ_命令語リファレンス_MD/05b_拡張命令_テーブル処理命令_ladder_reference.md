#### 動作説明 (5-66〜5-67 / 原本 p.668-669)

**データテーブル・データブロックについて**

> FIFOW, FIFOR命令は、データテーブルと呼ぶデータの集まりを使ってFIFO(First In First Out)処理します。データテーブルは、下図のような構造になっています。

データテーブル構造図(bit15〜bit0、左側の縦書きラベル「データテーブル」が [D]〜[D]+n+1 全体を括る):

| アドレス | 内容 | 区分 | 説明 |
|---|---|---|---|
| [D] | n | データ数 | データブロックに書き込まれたデータ数です。 |
| [D] +1 | max | 最大格納データ数 | データブロックに格納できる最大データ数です（ユーザー指定）。 |
| [D] +2 | Ⓐ | データブロック | FIFO処理されるデータを格納します。<br>Ⓐが、最初に格納されたデータ、Ⓒが最後に格納されたデータとなります。 |
| [D] +3 | Ⓑ | データブロック | 同上 |
| ⋮ | ⋮ | データブロック | 同上 |
| [D] +n+1 | Ⓒ | データブロック | 同上 |

(結合セル展開: 「データブロック」とその説明は [D]+2〜[D]+n+1 共通の1セル)

> 命令を実行する前に、[D] に格納されるデータ数(n) をリセット(0 を格納) してください。また、[D] +1に最大格納データ数を設定してください
> データテーブルの先頭 [D] は、対応するFIFOR命令のデータテーブルの先頭 [S] と同じ対象を指定してください。

(原文ママ・要確認: FIFOR のデータテーブル先頭オペランドは [D1]。原本は枠囲み「S」。また「設定してください」の後に句点なし)

**FIFOW(.U)**
> 実行条件がONのとき、[S] で指定した16ビットBINデータをデータブロックの最後に格納します。
> - データの格納先は、[D] +(n+2)となります。
> - 格納後、n は1加算(+1)されます。

図(16ビット、格納前 → 格納後。[S](bit15〜bit0)の値 Ⓓ が矢印で [D]+(n+2) へ):

| アドレス | 格納前 | 格納後 |
|---|---|---|
| [D] | n | n+1 |
| [D] +1 | max | max |
| [D] +2 | Ⓐ | Ⓐ |
| [D] +3 | Ⓑ | Ⓑ |
| ⋮ | ⋮ | ⋮ |
| [D] +(n+1) | Ⓒ | Ⓒ |
| [D] +(n+2) | 空き | Ⓓ |
| [D] +(n+3) | 空き | 空き |

(図中の括弧: 格納前は [D]+2〜[D]+(n+1) が「n個」、格納後は [D]+2〜[D]+(n+2) が「n+1個」)

**FIFOW.D**
> 実行条件がONのとき、[[S]・[S]+1]で指定した32ビットBINデータをデータブロックの最後に格納します。
> - データの格納先は、[D] +（2n＋4）・[D] +（2n＋5）となります。
> - 格納後、nは1加算（＋1）されます。

図(32ビット、bit31〜bit0。[S]+1(上位)・[S](下位)の値 Ⓓ が矢印で [D]+(2n+5)/[D]+(2n+4) へ。格納前の図 → 下向き矢印 → 格納後の図):

| アドレス(上位 / 下位) | 格納前 | 格納後 |
|---|---|---|
| [D] +1 / [D] | n | n+1 |
| [D] +3 / [D] +2 | max | max |
| [D] +5 / [D] +4 | Ⓐ | Ⓐ |
| [D] +7 / [D] +6 | Ⓑ | Ⓑ |
| ⋮ | ⋮ | ⋮ |
| [D] +(2n+3) / [D] +(2n+2) | Ⓒ | Ⓒ |
| [D] +(2n+5) / [D] +(2n+4) | 空き | Ⓓ |
| [D] +(2n+7) / [D] +(2n+6) | 空き | 空き |

(図中の括弧: 格納前は [D]+5〜[D]+(2n+3) が「n個」、格納後は [D]+5〜[D]+(2n+5) が「n+1個」)

**＠FIFOW.□** 実行条件の立ち上がりで、1スキャンだけ実行します。

#### 動作説明 (5-78〜5-79 / 原本 p.680-681)

**データテーブル・データブロックについて**

> LIFOW, LIFOR命令は、データテーブルと呼ぶデータの集まりを使ってLIFO(Last In First Out)処理します。データテーブルは、下図のような構造になっています。

データテーブル構造図(bit15〜bit0、縦書きラベル「データテーブル」):

| アドレス | 内容 | 区分 | 説明 |
|---|---|---|---|
| [D1] | n | データ数 | データブロックに書き込まれたデータ数です。 |
| [D1] +1 | max | 最大格納データ数 | データブロックに格納できる最大データ数です（ユーザー指定）。 |
| [D1] +2 | Ⓐ | データブロック | LIFO処理されるデータを格納します。<br>Ⓐが、最初に格納されたデータ、Ⓒが最後に格納されたデータとなります。 |
| [D1] +3 | Ⓑ | データブロック | 同上 |
| ⋮ | ⋮ | データブロック | 同上 |
| [D1] +n+1 | Ⓒ | データブロック | 同上 |

(結合セル展開: 「データブロック」とその説明は [D1]+2〜[D1]+n+1 共通の1セル)

> データテーブルの先頭 [D1] は、対応するLIFOW命令のデータテーブルの先頭 [D2] と同じ対象を指定してください。

(原文ママ・要確認: LIFOW のデータテーブル先頭オペランドは [D]。原本は枠囲み「D2」)

**LIFOR(.U)**
> ① 実行条件がONのとき、[D1] +n+1に格納されている16ビットBINデータを [D2] に格納します。
> ② 格納後、n は1減算（－1）されます。

図(16ビット、読み出し前 → 読み出し後。最後のデータ Ⓓ が [D2] へ、[D1]+n+1 には「0を格納」):

| アドレス | 読み出し前 | 読み出し後 |
|---|---|---|
| [D1] | n | n-1 |
| [D1] +1 | max | max |
| [D1] +2 | Ⓐ | Ⓐ |
| [D1] +3 | Ⓑ | Ⓑ |
| ⋮ | ⋮ | ⋮ |
| [D1] +n | Ⓒ | Ⓒ |
| [D1] +n+1 | Ⓓ | 空き(0) ← 0を格納 |
| [D2] | (空欄) | Ⓓ |

**LIFOR.D**
> ① 実行条件がONのとき、[[D1] +(2n+2)・[D1] +(2n+3)]に格納されている32ビットBINデータを[[D2]・[D2] +1]に格納します。
> ② 格納後、nは1減算(－1)されます。

図(32ビット、bit31〜bit0。①の図 → ②の図。Ⓓ が [D2]+1(上位)・[D2](下位)へ、[D1]+(2n+3)/[D1]+(2n+2) には「0を格納」):

| アドレス(上位 / 下位) | ① 読み出し前 | ② 読み出し後 |
|---|---|---|
| [D1] +1 / [D1] | n | n-1 |
| [D1] +3 / [D1] +2 | max | max |
| [D1] +5 / [D1] +4 | Ⓐ | Ⓐ |
| [D1] +7 / [D1] +6 | Ⓑ | Ⓑ |
| ⋮ | ⋮ | ⋮ |

#### 動作説明 (5-86 / 原本 p.688)

**FDEL(.U)**
> 実行条件がONのとき、[D] で指定した16ビットBINデータ用データテーブルのデータブロックの [n] 個目を削除します。

図(16ビット。削除前 → 削除後):

| 削除前アドレス | 区分 | 削除前 | 削除後 | 削除後アドレス |
|---|---|---|---|---|
| [D] | データ数 | N | N－1 | [D] |
| [D] +1 | 最大格納データ数 | max | max | [D] +1 |
| [D] +2 | データブロック(格納データ) 1 個目 | Ⓐ | Ⓐ | [D] +2 |
| [D] +3 | データブロック(格納データ) 2 個目 | Ⓑ | Ⓑ | [D] +3 |
| ⋮ | ⋮ | ⋮ | ⋮ | ⋮ |
| (アドレス表記なし) | データブロック(格納データ) [n] 個目 | Ⓒ(網掛け) | (削除) | — |
| ⋮ | ⋮ | ⋮ | ⋮ | ⋮ |
| [D] +N+1 | データブロック(格納データ) N 個目 | Ⓓ | Ⓓ | [D] +N |
| — | — | — | 0 (0が格納されます) | [D] +N+1 |

**FDEL.D**
> 実行条件ONのとき、[ [D]・[D] +1]で指定した32ビットBINデータ用データテーブルのデータブロックの [n] 個目を削除します。

図(32ビット。削除前 → 削除後):

| 削除前アドレス(上位 / 下位) | 区分 | 削除前 | 削除後 | 削除後アドレス(上位 / 下位) |

| [D] +1 / [D] | データ数 | N | N－1 | [D] +1 / [D] |
