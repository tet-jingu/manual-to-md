## 参照上の注意

各ファイルは、表・ビット/パラメータ定義・プログラム例・機能説明・ON/OFFタイミング・注意事項を原文のまま全文転記します。ただし、**同一構成図が形名バリエーションごとに繰り返される箇所**は、図中の注記・接続先など内容面ではすべて残しつつ、バリエーション間で完全に重複する注記文だけを1箇所にまとめて記載することがあります(注記の文言自体は省略しません)。

付録は分量が大きいため2分割して変換し、後で1ファイルに結合しました。結合時に原本PDFと突き合わせて境界部分の欠落・重複を点検し、いずれも無いことを確認済みです。

設計判断の最終確認は、必ず原本PDFの該当ページで行ってください。
