## 第17章 フルクローズドシステムを使用する場合 (章扉、原本 p.660)

> ポイント
> - フルクローズドシステムは，ソフトウエアバージョンA5以降のサーボアンプで使用できます。
> - このサーボアンプでフルクローズドシステムを使用する場合，"リニアエンコーダ技術資料集" が必要です。
> - フルクローズドシステムは，位置制御モードでのみ使用できます。
> - MR-J4-_A_サーボアンプでフルクローズドシステムを構築する場合，次の制約があります。ただし，MR-J4-_A_-RJサーボアンプの場合，これらの制約はありません。
>   - ABZ相差動出力タイプのエンコーダは使用できません。
>   - 機械端エンコーダおよびサーボモータエンコーダは，2線式通信方式のみに対応しています。4線式通信方式の機械端エンコーダおよびサーボモータエンコーダは使用できません。
>   - HG-KRおよびHG-MRシリーズを駆動用および機械端エンコーダ用に使用する場合，オプションの4線式エンコーダケーブル (MR-EKCBL30M-L，MR-EKCBL30M-H，MR-EKCBL40M-HおよびMR-EKCBL50M-H) は使用できません。このため，30 m ～ 50 mのエンコーダケーブルが必要な場合，付9を参照して2線式のエンコーダケーブルを製作してください。
> - MR-J4-03A6(-RJ)サーボアンプはフルクローズドシステムに対応していません。
> - 同期エンコーダQ171ENC-W8は，ソフトウエアバージョンA8以降のサーボアンプで使用できます。

## 17.1 機能と構成

### 17.1.1 機能ブロック図 (17.1.1 / 原本 p.661)

フルクローズドシステムブロック図を次に示します。フルクローズドシステムの場合，機械端エンコーダ単位で制御します。

【図】フルクローズドシステムブロック図 (17.1.1 / 原本 p.661)
- コントローラからの位置指令は，電子ギア (CMX/CDV) を経て位置制御の加算点 (+/-) に入力される。
- 加算点では，指令から (サーボモータ端) 溜りパルスを差し引いた値がアンプ (三角形の増幅器) を経てサーボモータへ出力される。
- サーボモータ端フィードバックパルス (機械端分解能単位) は，切換えスイッチS (注1，2: フルクローズド選択 [Pr. PE01] および [Pr. PE08]) を経て分岐する。
- 分岐した信号は，フルクローズドデュアルフィードバックフィルタ ([Pr. PE08]) を通り，機械端フィードバックパルスと合成 (+/-の加算点) される。
- サーボモータ側の実フィードバック信号は (サーボモータ端) 帰還パルス累積としてモニタされる。
- リニアエンコーダからの機械端フィードバックパルスは，機械端溜りパルスおよび機械端帰還パルス累積としてモニタされる。
- FBN/FBD (エンコーダパルス設定 [Pr. PA15]，[Pr. PA16] および [Pr. PC19]) は，サーボモータ・リニアエンコーダ側のフィードバック経路に接続されている。
- フルクローズド制御異常検知機能選択 ([Pr. PE03]) は，モニタ経路 (機械端フィードバックパルス側) に接続されている。
- 電子ギア (CDV/CMX) は制御経路の入口に配置される。
- 図中の実線矢印は「制御」，点線矢印は「モニタ」を表す。

注
1. セミクローズド制御/フルクローズド制御の切換えは [Pr. PE01] で設定できます。セミクローズド制御のときは，サーボモータ停止時，回転時にかかわらず常にサーボモータエンコーダの位置情報に基づいて制御されます。
2. [Pr. PE01] でフルクローズドシステムが有効のとき，フルクローズドデュアルフィードバックフィルタ ([Pr. PE08]) によってサーボモータフィードバック信号と機械端エンコーダフィードバック信号を合成するデュアルフィードバック制御になります。この場合，サーボモータ停止時はフルクローズド制御，サーボモータ運転時はセミクローズド制御になり制御性能を向上させることができます。[Pr. PE08 フルクローズドデュアルフィードバックフィルタ] の値を "4500" に設定すると常時フルクローズド制御になります。

各制御の特徴を次の表に示します。

| 制御 | | 内容 |
|---|---|---|
| セミクローズド制御 | 特徴 | サーボモータ端の情報により位置を制御します。 |
| | 長所 | 機械共振などの影響を受けにくいため，サーボアンプのゲインを上げ，整定時間を短縮できます。 |
| | 短所 | サーボモータ端が停止していても，機械端が振動していたり，機械端の精度が出ていない可能性があります。 |
| デュアルフィードバック制御 | 特徴 | サーボモータ端の情報と機械端の情報により位置を制御します。 |
| | 長所 | 運転中はサーボモータ端，停止時は機械端の情報に順次切り換えて制御することにより，運転中のゲインを上げることができ，整定時間を短縮することができます。停止時には機械端の精度で停止します。 |
| フルクローズド制御 | 特徴 | 機械端の情報により位置を制御します。 |
| | 長所 | 停止時だけでなく，運転中にも機械端の精度が出ます。 |
| | 短所 | 機械共振などの影響を受けやすいため，サーボアンプのゲインを上げられないことがあります。 |

### 17.1.2 制御モードの選択手順 (原本 p.662)

#### (1) 制御モードの構成 (17.1.2 / 原本 p.662)

このサーボは，制御方式としてセミクローズドシステム，フルクローズドシステムを選択することができます。
また，フルクローズドシステムにおいて，[Pr. PE08] の設定によりフルクローズド制御およびデュアルフィードバック制御を選択することができます。

【図】制御モードの選択手順 ブロック図 (17.1.2(1) / 原本 p.662)
- サーボアンプは，運転モード選択 ([Pr. PA01]) が "_ _0_" の場合セミクローズドシステム (セミクローズド制御) に直結される (17.3.1項(2)(a)参照)。
- 運転モード選択 ([Pr. PA01]) が "_ _1_" の場合，フルクローズド機能選択1 ([Pr. PE01]) 側に切り換わる。
- フルクローズド機能選択1 ([Pr. PE01]) が "_ _ _1" の場合，セミクロ/フルクロ切換え指令 (CLD (フルクローズド選択)) のオフ/オンにより，フルクローズドシステム内で「セミクローズド制御」と「デュアルフィードバック制御またはフルクローズド制御」に切り換わる (17.3.1項(2)(b)参照)。
- [Pr. PE01] が "_ _ _0" の場合，直接フルクローズドデュアルフィードバックフィルタ ([Pr. PE08]) 側に接続される。
- フルクローズドデュアルフィードバックフィルタ ([Pr. PE08]) の設定値が "1 ～ 4499" の場合デュアルフィードバック制御，"4500" の場合フルクローズド制御になる。

#### (2) デュアルフィードバックフィルタ等価ブロック図 (17.1.2 / 原本 p.662)

デュアルフィードバック制御におけるデュアルフィードバックフィルタ等価ブロック図を次に示します。

【図】デュアルフィードバックフィルタ等価ブロック図 (17.1.2(2) / 原本 p.662)
- 位置指令 (+) と，ローパスフィルタを通した機械端 (リニアエンコーダ) フィードバックとの加算点から位置制御器を経てサーボモータへ指令する。
- サーボモータの位置情報はハイパスフィルタ，リニアエンコーダの位置情報はローパスフィルタをそれぞれ通り，加算点 (+/+) で合成した信号をフィードバックとして使用する。
- 図下部には横軸を周波数 [rad/s] とした特性図があり，低域側はフルクローズド制御，高域側はセミクローズド制御の特性を示し，その境界の周波数を "ω" と表記している。
- 表 (デュアルフィードバックフィルタ):

| 運転状態 | 制御状態 |
|---|---|
| サーボモータ停止時 (0 ～ ω) | フルクローズド制御 |
| 運転中 (ω～) | セミクローズド制御 |

注. "ω" (デュアルフィードバックフィルタの帯域) は [Pr. PE08] で設定してください。

### 17.1.3 システム構成 (原本 p.663-664)

#### (1) リニアエンコーダの場合

**(a) MR-J4-_A_サーボアンプ (原本 p.663)**

【図】システム構成 (リニアエンコーダ・MR-J4-_A_) (17.1.3(1)(a) / 原本 p.663)
- コントローラ ⇔ サーボアンプ ⇔ サーボモータ (サーボモータエンコーダ信号はCN2へ)。
- 機械端エンコーダ信号 (2線式のシリアルインタフェース対応リニアエンコーダ) は，CN2コネクタから分岐して，リニアエンコーダヘッド (テーブルに取り付け) に接続される。

注. 絶対位置リニアエンコーダを使用した場合，絶対位置検出システムに対応可能です。その場合，バッテリは不要です。

**(b) MR-J4-_A_-RJサーボアンプ (原本 p.663)**

【図】システム構成 (リニアエンコーダ・MR-J4-_A_-RJ) (17.1.3(1)(b) / 原本 p.663)
- コントローラ ⇔ サーボアンプ ⇔ サーボモータ (サーボモータエンコーダ信号はCN2へ)。
- 機械端エンコーダ信号 (ABZ相パルス列インタフェース対応リニアエンコーダ，2線式または4線式のシリアルインタフェース対応リニアエンコーダ) は，CN2Lコネクタからリニアエンコーダヘッド (テーブルに取り付け) に直接接続される。

注. 絶対位置リニアエンコーダを使用した場合，絶対位置検出システムに対応可能です。その場合，バッテリは不要です。

#### (2) ロータリエンコーダの場合 (原本 p.664)

**(a) MR-J4-_A_サーボアンプ**

【図】システム構成 (ロータリエンコーダ・MR-J4-_A_) (17.1.3(2)(a) / 原本 p.664)
- コントローラ ⇔ サーボアンプ (CN2) ⇔ サーボモータ (HG-KR，HG-MRサーボモータ，4194304 pulses/rev)。
- 機械端エンコーダ信号 (2線式のロータリエンコーダ) は，CN2コネクタから分岐して駆動部側のロータリエンコーダに接続される。

注. 2線式のエンコーダケーブルを使用してください。4線式のエンコーダケーブルは使用できません。

**(b) MR-J4-_A_-RJサーボアンプ**

【図】システム構成 (ロータリエンコーダ・MR-J4-_A_-RJ) (17.1.3(2)(b) / 原本 p.664)
- コントローラ ⇔ サーボアンプ (CN2: サーボモータエンコーダ信号，CN2L: 機械端エンコーダ信号) ⇔ サーボモータ (HG-KR，HG-MRサーボモータ (4194304 pulses/rev) または同期エンコーダQ171ENC-W8 (4194304 pulses/rev))。
- 機械端エンコーダ信号は，CN2Lコネクタから駆動部側のABZ相差動出力，2線式または4線式のロータリエンコーダに直接接続される。

> ポイント
> フィードバックパルス電子ギア ([Pr. PE04]，[Pr. PE05]，[Pr. PE34] および [Pr. PE35]) に誤った値を設定した場合，[AL. 37 パラメータ異常] が発生し，正常に運転できない場合があります。また，位置決め運転時に [AL. 42.8 位置偏差によるフルクローズド制御異常] が発生する場合があります。


```
4096 (2^12) ≦ サーボモータ1回転あたりの機械端エンコーダパルス数 ≦ 67108864 (2^26)
```

### 17.3.2 原点復帰 (原本 p.676-679)

#### (1) 一般注意事項 (原本 p.676)

原点復帰は，機械端エンコーダのタイプに関係なく，すべて機械端エンコーダフィードバック情報で行われます。サーボモータエンコーダのZ相の位置には関係ありません。ドグ信号を使用する原点復帰の場合，原点復帰起動からドグ信号がオフになるまでの間に，インクリメンタルタイプのリニアエンコーダでは原点 (リファレンスマーク)，ロータリエンコーダではZ相を通過させる必要があります。
リニアエンコーダの場合，原点復帰方向にリニアエンコーダの原点 (リファレンスマーク) が1箇所必要です。

> ポイント
> 次の図を例にした場合，確実に原点復帰を実施させるためにLSNまでJOG運転で移動したあと，原点復帰を実施してください。

【図】原点復帰の可領域・否領域 (17.3.2(1) / 原本 p.676)
- LSN (左端) から，リニアエンコーダの原点 (リファレンスマーク) を経てドグまでの区間が「可領域」: この領域から原点復帰を開始した場合，原点復帰が可能。
- ドグからLSP (右端) までの区間が「否領域」: この領域から原点復帰を開始した場合，原点復帰はできません。
- 原点復帰方向は，LSN側からLSP側へ向かう方向として図示されている。

#### (2) 機械端エンコーダタイプと原点復帰方法

**(a) 絶対位置リニアエンコーダの近点ドグ式原点復帰 (原本 p.676)**

絶対位置リニアエンコーダの原点基準位置は，リニアエンコーダ原点 (絶対位置データ = 0) を基準としてサーボモータ1回転ごとの位置になります。
近点ドグ式原点復帰の場合，近点ドグ信号オフ後の最も近い位置が原点位置になります。
リニアエンコーダ原点の設置位置は，どの位置でも構いません。

【図】絶対位置リニアエンコーダの近点ドグ式原点復帰 タイミングチャート (17.3.2(2)(a) / 原本 p.676)
- サーボモータ回転速度: 0 r/minから原点復帰速度まで加速し，近点ドグ信号がONの区間でクリープ速度まで減速する。原点位置到達後，小さな山 (整定動作) を経て0 r/minで停止する。
- 近点ドグ信号: OFFからONに切り換わり，クリープ速度区間の途中でONからOFFに切り換わる。
- 原点基準位置: サーボモータ1回転相当の間隔で並ぶ縦線群として表示される。
- 機械位置: 「原点基準位置」の目盛りに対応して，近点ドグ信号OFF後最初に到達する原点基準位置が「原点位置」になる。

**(b) インクリメンタルリニアエンコーダの原点復帰について (原本 p.677)**

インクリメンタルリニアエンコーダを使用する場合，サーボアンプからのLZ (エンコーダZ相パルス) はリニアエンコーダの原点 (リファレンスマーク) 位置になります。原点の位置 (リファレンスマーク) は複数設置しないでください。また，原点 (リファレンスマーク) がない場合には実施できません。

【図】インクリメンタルリニアエンコーダの原点復帰 タイミングチャート (17.3.2(2)(b) / 原本 p.677)
- サーボモータ回転速度: 0 r/minから原点復帰速度まで加速し，近点ドグ信号がONの区間でクリープ速度まで減速する。原点位置到達後，小さな山を経て0 r/minで停止する。
- 近点ドグ信号: OFFからONに切り換わり，クリープ速度区間の途中でONからOFFに切り換わる。
- 原点基準位置: サーボモータ1回転相当の間隔で並ぶ縦線群として表示される。
- 機械位置: 「リニアエンコーダ原点」から，近点ドグ信号OFF後最初の原点基準位置が「原点位置」になる。

1) 原点 (リファレンスマーク) を通過する場合の注意事項
リニアエンコーダの原点 (リファレンスマーク) の信号オンの区間は，ある程度の幅を持っています。(リニアエンコーダごとに仕様が異なります。詳細についてはリニアエンコーダ技術資集を参照してください。)

例: 立上がりでZ相を認識する場合

【図】原点信号のオン区間と通過方向による認識位置の違い (17.3.2(2)(b)1) / 原本 p.677)
- 原点信号の立上がり (B) を左方向から通過したときの認識位置と，立下り (A) を右方向から通過したときの認識位置が異なる。
- Aをオン位置と認識: 右から左方向へ通過した場合。
- Bをオン位置と認識: 左から右方向へ通過した場合。

原点を通過する方向によって，信号オンの位置が異なるため，ドグ式原点復帰など原点復帰完了位置をいつも同じ位置に停止させたい場合は，必ず同一方向で原点復帰を起動するようにしてください。

2) 原点 (Z相) がないリニアエンコーダの場合の注意事項
原点 (Z相) がないリニアエンコーダの場合，サーボアンプのLZ (エンコーダZ相パルス) が出力されません。コントローラの仕様によっては，LZ (エンコーダZ相パルス) がない場合でも原点復帰を実施することができます。コントローラの原点復帰の仕様を確認してください。

**(c) シリアル通信サーボモータのロータリエンコーダを使用した場合のドグ式原点復帰 (原本 p.678)**

機械端エンコーダにシリアル通信サーボモータのロータリエンコーダを使用した場合の原点位置は，機械端のZ相の位置になります。

【図】シリアル通信サーボモータのロータリエンコーダを使用した場合のドグ式原点復帰 タイミングチャート (17.3.2(2)(c) / 原本 p.678)
- 機械端エンコーダZ相信号: 機械端1回転相当の一定間隔でOFF→ON→OFFのパルスを繰り返す。
- 原点基準位置: Z相パルスに同期して，機械端1回転ごとの縦線群として表示される。
- 機械位置: 「サーボアンプ電源投入位置」を起点とし，複数回の機械端1回転を経て，あるZ相パルスの位置が「原点位置」になる。

### 17.3.3 フルクローズド制御異常検知機能 (原本 p.679-680)

何らかの要因でフルクローズド制御が不安定になった場合，サーボモータ端の速度が異常に増大することがあります。これを未然に検知し，運転停止するための保護機能がフルクローズド制御異常検知機能です。
フルクローズド制御異常検知機能には，速度偏差と位置偏差の検出方法があります。[Pr. PE03 フルクローズド機能選択2] で検出方法を選択してください。
また，検出レベルの設定は，[Pr. PE06] および [Pr. PE07] で変更が可能です。

#### (1) パラメータ (17.3.3 / 原本 p.679)

フルクローズド制御異常検知機能を選択してください。

【図】[Pr. PE03] 設定桁 (フルクローズド制御異常検知機能) (17.3.3(1) / 原本 p.679)
- 0: 無効
- 1: 速度偏差異常検知
- 2: 位置偏差異常検知
- 3: 速度偏差異常，位置偏差異常検知 (初期値)

#### (2) フルクローズド制御異常検知機能 (17.3.3 / 原本 p.679-680)

- サーボモータ ⇔ リニアエンコーダの構成において，次の4つの値を取得・比較する。
  1. サーボモータ端フィードバック速度 [r/min]
  2. サーボモータ端フィードバック位置 [pulse] (機械端に換算した値)
  3. 機械端フィードバック速度 [r/min]
  4. 機械端フィードバック位置 [pulse]

**(a) 速度偏差異常検知**

[Pr. PE03] を "_ _ _1" に設定して，速度偏差異常検知を有効にしてください。

【図】[Pr. PE03] 設定 (速度偏差異常検知) (17.3.3(2)(a) / 原本 p.679)

サーボモータ端フィードバック速度 (1)) と機械端フィードバック速度 (3)) を比較し，[Pr. PE06 フルクローズド制御 速度偏差異常検知レベル] の設定値 (1 r/min ～ 許容回転速度) 以上の偏差がある場合，[AL. 42.2 速度偏差によるサーボ制御異常] を発生して停止します。[Pr. PE06] の初期値は400 r/minです。必要に応じて設定値を変更してください。

【図】[Pr. PE03] 設定 (位置偏差異常検知) (17.3.3(2)(b) / 原本 p.680)

サーボモータ端フィードバック位置 (2)) と機械端フィードバック位置 (4)) を比較し，[Pr. PE07 フルクローズド制御 位置偏差異常検知レベル] の設定値 (1 kpulses ～ 20000 kpulses) 以上の偏差がある場合，[AL. 42.1 位置偏差によるサーボ制御異常] を発生して停止します。[Pr. PE07] の初期値は100 kpulsesです。必要に応じて設定値を変更してください。

### 17.3.7 フルクローズドシステムにおける絶対位置検出システム (原本 p.681)

リニアエンコーダを使用したフルクローズド制御で絶対位置検出システムを構築する場合，絶対位置タイプのリニアエンコーダが必要です。この場合，サーボアンプにエンコーダ用バッテリを装着する必要はありません。ロータリエンコーダを使用する場合，サーボアンプにエンコーダ用バッテリを装着することで絶対位置検出システムを構築することができます。この場合，バッテリからサーボモータ端および機械端の2つのエンコーダに電源を供給するため，消費電流が増えてバッテリの寿命が短くなります。
リニアエンコーダを使用した絶対位置検出システムの場合，[Pr. PA03 絶対位置検出システム] で絶対位置検出システムを有効にし，次の制約条件内でこのサーボを使用してください。

#### (1) 使用条件 (17.3.7 / 原本 p.681)

(a) 機械端エンコーダに絶対位置タイプのリニアエンコーダを使用する。

(b) [Pr. PA01] を "_ _1_" に設定し， [Pr. PE01] を "_ _ _0" に設定してください。

#### (2) エンコーダによる絶対位置検出範囲 (17.3.7 / 原本 p.681)

| エンコーダの種類 | 絶対位置検出の可能な範囲 |
|---|---|
| リニアエンコーダ (シリアルインタフェース) | リニアエンコーダの可動長範囲 (絶対位置32ビットデータの範囲内) |

#### (3) アラーム検出 (17.3.7 / 原本 p.681)

絶対位置に関するアラーム ([AL. 25]) および警告 ([AL. 92]，[AL. 9F]) は検出されません。

#### (4) コントローラへの絶対位置データ転送

回転型サーボモータ使用時の処理と同様です。(12.8節参照)
