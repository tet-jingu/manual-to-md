## 1.1 GT Designer3とは (1.1 / 1-2 / 原本 p.44)

GT Designer3は，GOT2000シリーズとGOT1000シリーズ用の画面を作成するソフトウェアです。
プロジェクトの作成，シミュレート，GOTとのデータ転送を行います。

GT Designer3は，下記の2つの作画ソフトウェアで構成されています。

- GT Designer3(GOT2000): GOT2000シリーズ用の作画ソフトウェア
- GT Designer3(GOT1000): GOT1000シリーズ用の作画ソフトウェア

操作中の作画ソフトウェアでは編集できないプロジェクトの操作を行う場合，対応する作画ソフトウェアが起動します。
どちらを操作しているかは，作画ソフトウェアのタイトルバーで確認できます。

【図】GT Designer3のタイトルバー(1.1 / 原本 p.44)
- タイトルバーに「操作中の作画ソフトウェア名が表示されます。」

ヘルプは作画ソフトウェアごとに用意されています。
[F1]キーなどでヘルプを表示すると，操作中の作画ソフトウェアに対応するヘルプが表示されます。

### ■1 プロジェクト作成の概要 (1.1 ■1 / 原本 p.44)

GT Designer3は，GOTを動作させるデータをプロジェクト単位で管理します。
作成したプロジェクトに対して，GOTに表示する画面や，GOTで動作する機能などを設定します。
➟2. プロジェクトを作成する

### ■2 シミュレートの概要 (1.1 ■2 / 原本 p.44)

GT Designer3で作成中のプロジェクトを，GT Simulator3を使用し，パソコン上でGOTの操作をシミュレートします。
GT Designer3で作成したプロジェクトを，GT Simulator3単体でシミュレートすることもできます。
GT Simulator3単体でシミュレートする場合，GOT2000シリーズ，GOT1000シリーズ，GOT-A900シリーズのプロジェクトをシミュレートできます。
➟3. シミュレートする

### ■3 データ転送の概要 (1.1 ■3 / 原本 p.44)

作成したプロジェクトや，GOTの運転に必要なデータを，GT Designer3からGOTに書き込みます。
また，GOTに蓄積されたリソースデータを，GOTからGT Designer3に読み出します。
GT Designer3とGOT間のデータ転送には，通信ケーブルやネットワークを使用する方法や，データストレージを使用する方法があります。
➟4. GOTと通信する

【図】GT Designer3の概要(1.1 / 原本 p.44)
- パソコン(GT Designer3)で「プロジェクト作成」「シミュレート」を行い，「データ転送」でGOTへ送る流れを示す図。

### 1.2.2 プロジェクトとは (1.2.2 / 1-14〜1-15 / 原本 p.56-57)

プロジェクトは，GT Designer3で作成した画面や設定のデータです。
作成したプロジェクトはプロジェクト単位で管理します。
プロジェクトは，ワークスペース形式と1ファイル形式の2種類があります。
➟■1 ワークスペース形式のプロジェクト
　■2 1ファイル形式のプロジェクト

GT Designer3の保存時に，形式を選択して保存できます。
従来製品との互換性は，下記を参照してください。
➟12.13.1 プロジェクトの互換性

#### ■1 ワークスペース形式のプロジェクト (1.2.2 ■1 / 原本 p.56)

ワークスペース形式のプロジェクトは，複数のプロジェクトをワークスペースで管理するファイル形式です。
下記のように複数のフォルダやファイルで構成されています。

- ワークスペース管理ファイル(workspacelist.xml)
  保存先フォルダ内のワークスペースの管理情報です。
- プロジェクト管理ファイル(projectlist.xml)
  ワークスペース内のプロジェクトの管理情報です。
- プロジェクトフォルダ
  プロジェクトが格納されています。

【図】ワークスペース形式のフォルダ構成(1.2.2 ■1 / 原本 p.56)
- 保存先フォルダ直下に ワークスペース管理ファイル(workspacelist.xml) と ワークスペースフォルダ1，2 …。
- 各ワークスペースフォルダの中に プロジェクト管理ファイル(projectlist.xml) と プロジェクトフォルダ(1-1，1-2 … / 2-1，2-2 …)。
- 図の左側は GT Designer3上の表示例: ワークスペース1(プロジェクト1-1〜1-3)，ワークスペース2(プロジェクト2-1〜2-3)，ワークスペース3(プロジェクト3-1〜3-3)。

> **ワークスペース形式のプロジェクトの移動，名前の変更，削除など** (原本 p.56)
> Windowsのエクスプローラなどを使用して，ワークスペース内のフォルダやファイルを操作(移動，名前の変更，削除など)すると，プロジェクトを開けなくなります。
> プロジェクトの操作は，GT Designer3で行ってください。

#### ■2 1ファイル形式のプロジェクト (1.2.2 ■2 / 1-15 / 原本 p.57)

1ファイル形式のプロジェクトは，プロジェクトを単一のファイルとして管理するファイル形式です。
ファイルのコピー，移動，名前の変更などは，Windowsのエクスプローラなどで行います。
1ファイル形式のプロジェクトには，下記の種類(拡張子)があります。

- GTX
  プロジェクトのみを1ファイルにまとめたファイル形式です。
- GTXS
  プロジェクトと関連するシステムアプリケーション，通信ドライバを，パッケージデータとして1ファイルにまとめたファイル形式です。
  プロジェクトとシステムアプリケーション，通信ドライバのバージョンが固定されることで，GOTへの転送に使用するGT Designer3のバージョンが古くても，機能を落とさずにGOTで使用できます。
  完成したデータとしてプロジェクトを保存する場合に便利です。
- G2
  プロジェクトをGOTまたはデータストレージに格納時のファイル形式です。
- GTCNV
  GT Converter2で，GOT800用プロジェクトなどを，GOT2000用に変換したときのファイル形式です。

#### ■1 画面の種類 (1.2.3 ■1 / 1-16 / 原本 p.58)

GT Designer3で作成する画面と，GOTで表示する画面の関係を下記に示します。
➟(1) GT Designer3で作成する画面
　(2) GOTで表示する画面の表示順
　(3) GOTに表示する画面の重なりに関する仕様

【図】GT Designer3で作成する画面とGOTで表示する画面(1.2.3 ■1 / 原本 p.58)
- GT Designer3で作成する画面: ベース画面，ウィンドウ画面。
- GOTで表示する画面: ベース画面の上に スーパーインポーズウィンドウ，オーバーラップウィンドウ，キーウィンドウ，ダイアログウィンドウ が重なる。ウィンドウ画面から各ウィンドウが作られることを矢印で示す。

##### (1) GT Designer3で作成する画面 (1.2.3 ■1-1 / 原本 p.58-59)

GT Designer3で作成する画面には，下記の種類があります。

**(a) ベース画面**

GOTにベース画面として表示する画面です。
表示するベース画面は，画面切り換えデバイスで制御します。

**(b) ウィンドウ画面**

GOTにオーバーラップウィンドウ，スーパーインポーズウィンドウ，キーウィンドウ，ダイアログウィンドウとして表示する画面です。

- スーパーインポーズウィンドウ
  ベース画面上に合成し，ベース画面の一部分として表示するウィンドウです。
  同時に2画面(スーパーインポーズウィンドウ1，2)まで表示できます。
  表示するウィンドウ画面は，画面切り換えデバイスで制御します。
- オーバーラップウィンドウ
  ベース画面の前面にポップアップするウィンドウです。
  同時に5画面(オーバーラップウィンドウ1～5)まで表示できます。
  (GT21は2画面(オーバーラップウィンドウ1，2)まで表示できます。)
  タッチ操作または表示位置指定デバイスで表示位置を移動できます。
  表示するウィンドウ画面は，画面切り換えデバイスで制御します。
- キーウィンドウ
  数値入力などで入力を行う場合，ベース画面上にポップアップするウィンドウです。
  タッチ操作で表示位置を移動できます。
  GOTの標準キーウィンドウと，ユーザ作成キーウィンドウがあります。
- ダイアログウィンドウ
  システムとしてのエラーや警告などを最前面に表示するウィンドウです。
  GOTのシステムメッセージも，ダイアログウィンドウに表示されます。
  ダイアログウィンドウの表示中は，他の画面を操作できません。
  GT21は，ダイアログウィンドウの表示中も他の画面を操作できます。
  表示するウィンドウ画面は，画面切り換えデバイスで制御します。

**(c) レポート画面**

レポート機能で出力するための画面です。
GOTで表示する画面ではありません。

**(d) モバイル画面(GT27，GT25，GT SoftGOT2000)**

GOT Mobile機能使用時，タブレットなどの情報機器に表示する画面です。
GOTで表示する画面ではありません。

##### (2) GOTで表示する画面の表示順 (1.2.3 ■1-2 / 1-17 / 原本 p.59)

GOTで表示する画面の表示順を下記に示します。

- ベース画面
  最背面に表示されます。
- スーパーインポーズウィンドウ1，2
  ベース画面に合成され，ベース画面の一部として表示されます。
- オーバーラップウィンドウ1～5
  ベース画面の前面に表示されます。
  複数のオーバーラップウィンドウが表示されている場合，後から表示または最後に操作したオーバーラップウィンドウが前面に表示されます。
  オーバーラップウィンドウ間の表示順は，[環境設定]ウィンドウ([画面切り換え/ウィンドウ])の設定で指定することもできます。
- キーウィンドウ
  ベース画面，オーバーラップウィンドウの前面に表示されます。
- ダイアログウィンドウ
  最前面に表示されます。

【図】GOTでの画面表示順序(1.2.3 ■1 (2) / 原本 p.59)
- 背面→前面の順: ベース画面 → スーパーインポーズウィンドウ1，2(ベース画面に合成) → オーバーラップウィンドウ1～5 → キーウィンドウ → ダイアログウィンドウ(システムメッセージ)。

##### (3) GOTに表示する画面の重なりに関する仕様 (1.2.3 ■1-3 / 1-18 / 原本 p.60)

**(a) 画面間での図形，オブジェクトの表示順**

各画面上の図形，オブジェクトの表示順は，画面の表示順に従って保証されます。
ベース画面とスーパーインポーズウィンドウ間では，オブジェクトの表示順は設定により異なります。
➟5.1.5 [機種設定]ダイアログ

**(b) ベース画面とスーパーインポーズウィンドウ**

ベース画面上の入力オブジェクトは，スーパーインポーズウィンドウが重なっていても動作します。
GT21は，スーパーインポーズウィンドウが重なっている場合，動作しません。
ベース画面とスーパーインポーズウィンドウの入力オブジェクトが重なっている場合，タッチすると両方の入力オブジェクトが動作します。
(タッチする時間が短いと，スーパーインポーズウィンドウ上の入力オブジェクトのみ動作する場合があります。)

**(c) オーバーラップウィンドウ，キーウィンドウ**

- オーバーラップウィンドウ，キーウィンドウの背面にある図形，オブジェクトは表示されず，入力オブジェクトは動作しません。
  オーバーラップウィンドウの背面にある図形，オブジェクトを確認，操作する場合，オーバーラップウィンドウを閉じる，または移動してください。
- タイトルバーを表示したオーバーラップウィンドウ，キーウィンドウの周囲16ドット分は，タッチしても無効なエリアになります。
  タイトルバーを表示しない場合，タッチが無効になるエリアはありません。
  GT21の場合，タイトルバーの表示，非表示にかかわらず，タッチが無効になるエリアはありません。
- ユーザ作成キーウィンドウ上に配置した数値入力，文字列入力，拡張機能スイッチ(動作設定: キーウィンドウ)は動作しません。

【図】タッチしても無効なエリア(1.2.3 ■1 (3)(c) / 原本 p.60)
- オーバーラップウィンドウ1とオーバーラップウィンドウ2が重なり、ウィンドウ2の周囲(タイトルバー表示時の16ドット分)が「タッチしても無効なエリア」として示される。無効エリアに掛かる位置の入力オブジェクト(タッチスイッチ)は操作できないことを示す。

- 前面レイヤ

  - **GOT Graphic Ver.2**: 透過色設定には対応しません。

- 背面レイヤ
  前面レイヤの背面に表示されます。

### 1.2.4 描画の仕様 (1.2.4 / 1-31 / 原本 p.73)

#### ■1 画面と座標 (1.2.4 ■1 / 原本 p.73)

画面の横方向をX軸，縦方向をY軸に画面の左上を(0，0)として，座標を(X，Y)で表します。
座標の単位はドットです。

【図】画面と座標(1.2.4 ■1 / 原本 p.73)
- 例1) GT27-S(800×600)を横表示にした場合: 左上(0，0)、右下(799，599)、中央(400，300)。上辺中央(400，0)、左辺中央(0，300)。X軸は右向き、Y軸は下向き。
- 例2) GT27-S(800×600)を縦表示にした場合: 左上(0，0)、右下(599，799)、中央(300，400)。上辺中央(300，0)、左辺中央(0，400)。

### 1.2.5 フォントの仕様 (1.2.5 / 1-32〜1-40 / 原本 p.74-82)

図形やオブジェクトにより，使用できるフォントが異なります。
使用できるフォントは，各図形，オブジェクトの設定で確認してください。
