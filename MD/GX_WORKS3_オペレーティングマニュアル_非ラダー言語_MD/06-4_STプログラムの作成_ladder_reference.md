## STエディタの構成 (6.4 / 原本 p.413-416)

STエディタとは，ST言語でプログラムを作成するためのテキスト形式の言語エディタです。
制御構文のキーワードや変数名などの間には，スペース，タブ，改行などを自由に挿入できます。
プログラムを構成する単語や記号の最小単位をトークンと呼びます。

### 画面表示 (6.4 / 原本 p.413)

ナビゲーションウィンドウ⇒"プログラム"⇒"(実行タイプ)"⇒"(プログラムファイル)"⇒"(プログラムブロック)"⇒"プログラム本体"を選択します。

【図】STエディタの画面(原本 p.413)
- ツールバー(6アイコン)がエディタ上部に表示される。
- エディタ右上に**分割バー**がある((1)～(9)の引出し線で各部を指示)。
- 上段の画面例(構文エラー表示あり):

```

 4 ⊟FOR count := 0 TO 10 BY 2
 5 ⊞  IF...END_IF;
10  END_FOR;
11
12 ⊟IF(bInCond = FALSE) THEN
13      RETURN;
14  END_IF;
15
16  bRcvCond := (G_b5SSOpenFin <> 0) & (G_b5SRcvFin <> 0) & (wInOutRtn = 0);
17 ⊟IF (bRcvCond = TRUE) THEN
18      wInOutRtn := 1; (* Reset return value *)
19  END_IF;
```

  エラー箇所表示のツールヒントとして「構文が必要です。正しい構文を入力してください。」が表示されている。
- 下段の画面例はキーワードの強調表示((9))を示しており，16行目の `wInOutRtn` と18行目の `wInOutRtn` が同じキーワードとして強調表示されている。

### キーワードの強調表示 (6.4 / 原本 p.415-416)

下記のオプションを"はい"に設定している場合，カーソル位置のデバイス，ラベル，ファンクション，ファンクションブロック，および命令と同じキーワードが強調表示されます。

- [ツール]⇒[オプション]⇒"プログラムエディタ"⇒"STエディタ"⇒"エディタ表示項目"⇒"カーソル位置と同一のキーワードを強調表示する"

#### 注意事項 (6.4 / 原本 p.415-416)

- 定数および文字列は強調表示されません。
- 単語単位で文字列が一致するキーワードが強調表示されます。そのため，インスタンスおよびデータ型が異なるデバイス/ラベルが強調表示される場合があります。

  **例**
  構造体型ラベル「user_stLabel1」の構造体メンバ「member1」にカーソルがある場合
  下記すべての「member1」が強調表示されます。

  1. member1(構造体型ラベル: user_stLabel1，データ型: ワード[符号付き])
  2. member1(構造体型ラベル: other_stLabel1，データ型: ビット)
  3. member1(構造体型ラベル: なし，データ型: ビット)

  【図】強調表示の例(原本 p.415)

```
 1 user_stLabel1.member1 := 100;
 2 other_stLabel2.member1 := member1;
```

  - ❶のラベル一覧: member1=ワード[符号付き] / member2=ワード[符号付き] / member3=ワード[符号付き]
  - ❷のラベル一覧: member1=ビット / member2=ビット / member3=ビット
  - ❸のラベル一覧: user_stLabel1=userStruct / other_stLabel2=otherStruct / member1=ビット

- STエディタからフォーカスがはずれるなどの理由により，カーソルが表示されなくなった場合，最後にカーソルが表示されていた箇所のキーワードが強調表示されます。
- STエディタを上下に分割している場合，フォーカスのある画面内でのみキーワードが強調表示されます。
- インラインSTボックス内でもキーワードが強調表示されます。ただし，異なるインラインSTボックス内のキーワードは強調表示されません。
- インラインSTボックスからフォーカスがはずれた場合，キーワードの強調表示は解除されます。
- 下記の位置にカーソルがある場合，キーワードは強調表示されません。(下表の ▮ はカーソル位置を示す)

| カーソル位置 | 例 |
|---|---|
| 構造体型ラベルと構造体メンバの間に空白が存在し，カーソルとラベルが隣接していない。<sup>*1</sup> | `stLabel .▮Label` |
| 構造体型ラベルと構造体メンバの間の改行箇所にカーソルがある。<sup>*1</sup> | `stLabel` / 次行 `▮.Label := D0;` |
| 配列要素(数値)の中にカーソルがある。<sup>*2</sup> | `Label[0]` (カーソルが `0` の位置) |
| 配列要素の右側にカーソルがある。 | `Label[0]▮` |
| デバイス型指定子の区切り記号の右側にカーソルがある。 | `D0:▮D` |

*1 FBインスタンスとローカルラベルの場合も同様です。
*2 デバイス/ラベルを配列要素として使用している場合は，デバイス/ラベルと同じキーワードが強調表示されます。

## ファンクションブロックの挿入 (6.4 / 原本 p.418)

> **収録理由(本プロジェクトの注記):** 本マニュアルのMD化ではFB/ファンクション関連ページを除外しているが，
> この項は「STでFBを呼び出すときの記述構文」そのものを定義しており，ST言語の文法として必要なため収録する。
> FBの作成手順(p.606)・FBプロパティ(p.479, p.502)は除外のまま。

STプログラムにファンクションブロックを挿入します。
ファンクションブロックのプログラムの作成方法は，下記を参照してください。
☞606ページ ファンクションブロックの作成

### 操作手順 (6.4 / 原本 p.418)

1. ナビゲーションウィンドウまたは部品選択ウィンドウから，STエディタ上の任意の位置にファンクションブロックをドラッグ&ドロップします。
2. "FBインスタンス名入力"画面のプルダウンリストから，ローカルラベルまたはグローバルラベルのどちらに登録するか選択し，FBインスタンス名<sup>*1</sup>を入力します。
3. 入力変数，出力変数に値を指定します。

*1 ファンクションブロックの定義名に"+"，"-"，"!"，"("，")"，"\`"のいずれかが含まれる場合，その文字は"_"に置き換えられます。

**例**
ファンクションブロック定義が"MYTIMER"の場合

[ファンクションブロック定義内容]
- ラベル名: FB_MYTIMER
- 入力変数: 設定値1秒，設定値10秒，設定値100秒，タイマスタート，タイマストップ
- 出力変数: 動作中，タイマアップ1，タイマアップ2

STプログラムの記述例を示します。

```
FB_MYTIMER(設定値1秒:= X0,設定値10秒:= X1,設定値100秒:= X2,
    タイマスタート:= X3,タイマストップ:= X4,動作中 => Y70,
        タイマアップ1 => Y71,タイマアップ2 => Y72);
```

【図】記述例の引出し線(原本 p.418)
- `FB_MYTIMER` = ラベル名
- `設定値1秒` など `:=` の左側 = 入力変数
- `X0` など `:=` の右側 = 入力変数に値を代入するデバイス
- `動作中`，`タイマアップ1` など `=>` の左側 = 出力変数
- `Y70`，`Y71` など `=>` の右側 = 出力変数の値を代入するデバイス

ファンクションブロック名の後ろに"."を付けて出力変数名を指定すると，ファンクションブロック名の出力を取得できます。
出力の取得は，ファンクションブロックの呼び出しを実行後に記述してください。

```
Y70:= FB_MYTIMER.動作中;
```

## 複数行の同時編集 (6.4 / 原本 p.421)

矩形選択すると，選択した複数行を同時に編集できます。
デバイスに代入する値を変更する手順を例に説明します。

**例**
代入する値を100から500に変更する。

### 操作手順 (6.4 / 原本 p.421)

1. 下記いずれかの操作で複数行を矩形選択します。
   - `Shift` + `Alt` + `↑`/`↓` を押した後，`Shift` + `←`/`→` を押す。
   - `Alt` を押しながらマウスをドラッグする。

```
1 ⊟IF wLabel1 = 20 THEN
2      D1:=100;
3      D0:=100;
4      D2:=100;
5      D3:=100;
6  END_IF;
```

   (各行の `1` と `0` の間の位置に，縦方向の矩形選択カーソルがある)

2. 5を入力します。

```
1 ⊟IF wLabel1 = 20 THEN
2      D1:=500;
3      D0:=500;
4      D2:=500;
5      D3:=500;
6  END_IF;
```

> **Point (原本 p.421)**
> 文字列を含めずに矩形選択した場合，編集モードによって動作が異なります。
> 例: 演算子と100の間を矩形選択し，5を入力した場合
>
> - 挿入モード
>
>   | 編集前 | 編集後 |
>   |---|---|
>   | `D1:=100;` | `D1:=5100;` |
>   | `D0:=100;` | `D0:=5100;` |
>   | `D2:=100;` | `D2:=5100;` |
>   | `D3:=100;` | `D3:=5100;` |
>
> - 上書きモード
>
>   | 編集前 | 編集後 |
>   |---|---|
>   | `D1:=100;` | `D1:=500;` |
>   | `D0:=100;` | `D0:=500;` |
>   | `D2:=100;` | `D2:=500;` |
>   | `D3:=100;` | `D3:=500;` |
