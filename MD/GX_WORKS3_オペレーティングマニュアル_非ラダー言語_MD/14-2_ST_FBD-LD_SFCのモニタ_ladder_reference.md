# 14.2 ST (14.2 / 原本 p.760-762)

## モニタ (14.2 / 原本 p.760)

### 操作手順 (14.2 / 原本 p.760)

STエディタを開き，[オンライン]⇒[モニタ]⇒[モニタ開始]( )/[モニタ停止]( )を選択します。

【図】STエディタのモニタ画面(原本 p.760)
- 折りたたまれている範囲はモニタされません。

> **Point (原本 p.760)**
> - モニタ値などの色を変更できます。
>   ☞91ページ 色およびフォントの確認と変更
> - デバイス/ラベル名にマウスカーソルを合わせると，ツールヒントにモニタ値が表示されます。
>   配列型ラベルまたはビット指定したラベルを選択している場合，ツールヒントには配列要素またはビットNo.のモニタ値が表示されます。
>   例: 配列型ラベルiArray[0]のiArrayを選択しても，ツールヒントにはiArray[0]のモニタ値が表示されます。

## モニタの表示切替 (14.2 / 原本 p.761)

モニタ中は，下記のメニューにより画面を切り替えられます。

| メニュー | 内容 | 画面例 |
|---|---|---|
| [オンライン]⇒[モニタ]⇒[STモニタ表示切替(1画面)] | プログラムエディタ上でモニタ値を確認できます。 | 【図】原本 p.761。ビット型のラベルやビットデバイスのTRUE/FALSEが表示されます(TRUE: 反転表示の `TRUE`，FALSE: 黒地の `FALSE`)。ワード型はデバイス/ラベルの直後の黄色いボックスに値が表示される(例: `IF M0 FALSE & bit_switch TRUE THEN` / `counter0 [1] :=2;` / `FOR D0 [12] := 0 TO 10 BY 2 DO`)。 |
| [オンライン]⇒[モニタ]⇒[STモニタ表示切替(1画面-ビット型のみ)] | プログラムエディタ上で，ビット型のラベルやビットデバイスのモニタ値を確認できます。 | 【図】原本 p.761。TRUE: `bit_switch` が反転表示，FALSE: `M0` が通常表示。ワード型の値は表示されない。 |
| [オンライン]⇒[モニタ]⇒[STモニタ表示切替(分割)] | 分割ウィンドウ上でモニタ値を確認できます。<br>デバイスおよびラベルのデータ型によって，それらのモニタ値が表示される場所が異なります。<br>・ビット型: プログラム上<br>・ビット型以外: 分割ウィンドウの右半分 | 【図】原本 p.761。左半分にプログラム，右半分に `counter0 = 1;` `D0 = 12;` などのモニタ値が行対応で表示される。 |

> **Point (原本 p.761)**
> 下記のオプションを設定することで，モニタ開始時の画面表示形式を指定できます。
> - "モニタ"⇒"STエディタ"⇒"表示設定"⇒"モニタの初期表示形式"

## 現在値の変更 (14.2 / 原本 p.762)

モニタ中は，下記の操作により現在値を変更できます。

| 変更対象のデバイス/ラベル | 操作方法 |
|---|---|
| ビット型 | デバイス/ラベルのトークンを選択し，`Shift` + `Enter` を押します。 |
| ワード型 | ウォッチウィンドウに登録して値を変更します。(☞778ページ デバイス/ラベルを登録して現在値を確認する) |

# 14.2 FBD/LD (14.2 / 原本 p.763-766)

## モニタ (14.2 / 原本 p.763)

### 操作手順 (14.2 / 原本 p.763)

[オンライン]⇒[モニタ]⇒[モニタ開始]( )/[モニタ停止]( )を選択します。

【図】FBD/LDエディタのモニタ画面(原本 p.763)
- (1): モニタ値表示エリア
- 接点/コイルのON/OFFが表示されます。
- ビット型のラベルやビットデバイスのTRUE/FALSEが表示されます。
- FB部品の入出力ラベルの下，または左右にモニタ値が表示されます。

現在値をモニタできない場合は，モニタ値表示エリアに"---"が表示されます。

> **Point (原本 p.763)**
> モニタ値の背景やテキストなどの色を変更できます。
> ☞91ページ 色およびフォントの確認と変更

### 注意事項 (14.2 / 原本 p.763)

インラインST部品のプレビュー表示エリアでは，インラインSTプログラムをモニタできません。STエディタ上でモニタしてください。

## 表示形式 (14.2 / 原本 p.763-764)

### 接点 (14.2 / 原本 p.763)

接点は現在の導通状態が表示されます。
下記のオプションを設定することで，デバイス/ラベルの現在値でON/OFFを表示するように変更できます。

- [ツール]⇒[オプション]⇒"モニタ"⇒"FBD/LDエディタ"⇒"表示設定"⇒"接点の表示形式をデバイス/ラベルの現在値に合わせる"

### ワードデバイス (14.2 / 原本 p.763)

ワードデバイスは，ワード[符号付き]型で表示されます。
ワードデバイスにデバイス型指定子が付加されている場合は，デバイス型指定子に対応するデータ型でワードデバイスが表示されます。
デバイス型指定子の詳細は，下記を参照してください。

- MELSEC MXコントローラ MX-Rモデルプログラミングマニュアル
- MELSEC MXコントローラ MX-Fモデルプログラミングマニュアル
- MELSEC iQ-R プログラミングマニュアル(プログラム設計編)

### 接続線 (14.2 / 原本 p.764)

接続線は，現在のモニタ値によって異なる色で表示されます。
接続線の一部の色は，"色およびフォント"画面で変更できます。(☞91ページ 色およびフォントの確認と変更)
モニタ値と接続線の色を示します。

| モニタ値 | 接続線の色 |
|---|---|
| TRUE | "色およびフォント"画面の"パワーフロー(TRUE)"に設定した色(デフォルト: 青) |
| FALSE | "色およびフォント"画面の"パワーフロー(FALSE)"に設定した色(デフォルト: 黒) |
| 数値 | 深緑 |
| 文字列 | 黒 |
| 不正値 | 灰色 |

下記の部品を接続している場合，接続線は灰色で表示されます。

| 入力側 | 出力側 |
|---|---|
| ・接点(モニタ値: 不正値)<br>・コイル(モニタ値: 不正値)<br>・ファンクション<br>・コネクタ部品<br>・変数部品<sup>*1</sup> | ・接点<br>・コイル<br>・ファンクション<br>・マクロ型ファンクションブロック部品の入力ラベル(ビット型)<br>・コネクタ部品<br>・リターン部品<br>・ジャンプ部品<br>・変数部品<sup>*1</sup> |

*1 下記いずれかの条件に該当する変数部品のみが対象です。
- モニタ値が不正値である。
- モニタ値が存在しない。
- モニタ値が表示されない。
- バッファメモリ/リンクメモリを割り付けている，かつ下記のオプションを"いいえ"に設定している。
  [ツール]⇒[オプション]⇒"モニタ"⇒"FBD/LDエディタ"⇒"動作設定"⇒"バッファメモリ，リンクメモリをモニタする"

## 変数部品のモニタ値表示エリア (14.2 / 原本 p.765)

### 位置の変更 (14.2 / 原本 p.765)

変数部品のモニタ値表示エリアの位置を変更する操作手順を示します。

#### 操作手順 (14.2 / 原本 p.765)

1. 変数部品を選択します。
2. スマートタグ( )をクリックします。
   スマートタグをクリックするごとに，モニタ値表示エリアが変数部品の上下左右に移動します。<sup>*1</sup>
   モニタ値表示エリアは，プロジェクトを閉じるまで変更した位置に表示されます。

*1 ファンクションブロック部品またはファンクション部品がコンパクトな高さの場合は，モニタ値表示エリアが変数部品の上下左右および変数部品上に移動します。

> **Point (原本 p.765)**
> ファンクションブロック部品またはファンクション部品のスマートタグ( )をクリックすると，その部品に接続されている変数部品のモニタ値表示エリアの位置を一括で変更できます。

### 拡大 (14.2 / 原本 p.765)

変数部品のモニタ値表示エリアを拡大する操作手順を示します。

#### 操作手順 (14.2 / 原本 p.765)

変数部品のモニタ値表示エリアをクリックします。
モニタ値表示エリアは，プロジェクトを閉じるまで拡大されます。
元に戻す場合は，再度モニタ値表示エリアをクリックしてください。

### 注意事項 (14.2 / 原本 p.765)

Version 1.047Z以降のGX Works3を使用する場合，モニタ値の一部の数値が省略されて表示される場合があります。
この場合，下記のいずれかの操作によって，モニタ値のすべての数値を確認できます。

- ウォッチウィンドウにデバイス/ラベルを登録する(☞779ページ ウォッチウィンドウへの登録)
- デバイス/ラベル名にマウスカーソルを合わせる(ツールヒントにモニタ値が表示されます。)
- モニタ値表示エリアを拡大する(☞765ページ 拡大)

### 詳細表現の場合 (14.2 / 原本 p.767-768)

モニタ中のSFC要素の状態は，下記のように表示されます。

【図】モニタ中のSFC要素の表示(原本 p.767)
- 活性: ステップ `Step0`/`S2` が**濃い青**の塗りつぶしで表示
- 非活性: ステップ `Step0`/`S2` が**淡いベージュ**(通常色)で表示
- 保持: ステップ `Step0`/`S2`(属性 `SC`)が**黄緑**で表示
- ON: 移行条件 `M79`/`TR0` のデバイス名が反転表示，動作出力 `N`+`M256` が青の塗りつぶし
- OFF: 移行条件 `M79`/`TR0` のデバイス名が通常表示，動作出力 `N`+`M256` が通常色

FBD/LD要素は，FBD/LDエディタのFBD/LD部品と同様に表示されます。(☞763ページ FBD/LD)

## Zoomのモニタ (14.2 / 原本 p.770)

[表示]⇒[Zoom/起動先ブロックを開く]を選択し，Zoomを開いてからモニタしてください。
Zoomのモニタの操作/表示方法は，各プログラムエディタと同じです。
モニタ可能なデバイスは，ステップリレー(S)を除き各プログラムエディタと同じです。ステップリレー(S)<sup>*1</sup>は，Zoom内のみモニタできます。

*1 RCPUの場合，BRSET命令による対象ブロック切替え時に，正常にモニタできないことがあります。

### 注意事項 (14.2 / 原本 p.770)

移行条件が成立したスキャンでモニタが実行されると，実行していたステップ(移行元のステップ)が非活性，移行条件に接続された次のステップ(移行先のステップ)が活性の状態で表示されます。なお，連続移行なしの場合，移行先のステップは次のスキャンで実行されます。そのため，移行先のステップと動作出力を同時にモニタすると，移行先ステップは活性になりますが動作出力のモニタ値は変化しません。

## SFC自動スクロールモニタ (14.2 / 原本 p.770)

SFC図モニタ開始後，[オンライン]⇒[モニタ]⇒[SFC自動スクロールモニタ]( )を選択します。
モニタ中，画面上見えない位置にあるステップが活性した場合，自動的にスクロールして再び画面上に活性ステップを表示します。
複数ステップが活性している場合，イニシャルステップの列に近いステップを優先して表示します。
SFC自動スクロールモニタ中は，クロスリファレンスの自動追従およびウォッチウィンドウへの自動登録はできません。

### 自動スクロールモニタ中の起動先ブロックの表示 (14.2 / 原本 p.770)

自動スクロールモニタ中に活性ステップがブロック起動ステップに移動したときに，自動で起動先ブロックのSFC図エディタを開き，モニタを開始できます。
下記のオプションにより，自動で起動先ブロックを開くかどうかを設定できます。

- [ツール]⇒[オプション]⇒"モニタ"⇒"SFC図エディタ"⇒"自動スクロールモニタ設定"⇒"ブロック起動は新しいウィンドウを開いてモニタする"

### 自動スクロールモニタ中のZoomの表示 (14.2 / 原本 p.770)

自動スクロールモニタ中にZoomを開いていると，活性ステップの表示に合わせてZoomの表示内容も自動的に切り替わります。

### 注意事項 (14.2 / 原本 p.770)

モニタ周期よりステップの活性状態の更新速度が速いと，モニタのタイミングによってステップの活性状態を取得できない場合があります。
活性状態を取得できなかったステップには自動スクロールしません。

## 活性状態の変更 (14.2 / 原本 p.772)

モニタ中は，下記の操作によりブロック/ステップの活性状態を変更できます。
特定のブロック/ステップのみを起動/終了させ，動作を確認する場合に使用します。

| 対象 | 操作画面 | 操作 |
|---|---|---|
| ブロック | 各プログラムエディタ(Zoomを含む) | SFCブロックデバイス(BL)の現在値(TRUE/FALSE)を変更します。<sup>*1</sup> |
| ブロック | "デバイス/バッファメモリ一括モニタ"ウィンドウ | SFCブロックデバイス(BL)の現在値(TRUE/FALSE)を変更します。<sup>*1</sup> |
| ブロック | ウォッチウィンドウ | SFCブロックデバイス(BL)の現在値(TRUE/FALSE)を変更します。<sup>*1</sup> |
| ステップ | SFC図エディタ | ステップを選択し，[デバッグ]⇒[SFCステップ制御]⇒[選択ステップを活性する]/[選択ステップを非活性する]/[選択ステップのみ活性する]を選択します。 |
| ステップ | Zoom | ステップリレー(S)またはブロック指定付ステップリレー(BL□\S)の現在値(TRUE/FALSE)を変更します。<sup>*1</sup> |
| ステップ | 各プログラムエディタ(Zoomを除く) | ブロック指定付ステップリレー(BL□\S)の現在値(TRUE/FALSE)を変更します。<sup>*1</sup> |
| ステップ | "デバイス/バッファメモリ一括モニタ"ウィンドウ | ブロック指定付ステップリレー(BL□\S)の現在値(TRUE/FALSE)を変更します。<sup>*1</sup> |
| ステップ | ウォッチウィンドウ | ブロック指定付ステップリレー(BL□\S)の現在値(TRUE/FALSE)を変更します。<sup>*1</sup> |

*1 ブロック指定付ステップリレー(BL□\S)およびSFCブロックデバイス(BL)を割り付けたラベルの現在値を変更して，ブロック/ステップを活性化することもできます。

### 注意事項 (14.2 / 原本 p.772)

- ブロックまたはステップの活性状態の変更は，CPUユニットの制御に影響するため注意してください。
- SFCブロックのRUN中書込みを実行している場合，そのブロックは現在値を変更しても活性状態を変更できません。
