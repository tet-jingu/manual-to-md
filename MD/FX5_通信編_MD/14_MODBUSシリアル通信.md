## 0. 結論サマリ

- FX5のMODBUSシリアル通信は **RTUモードのみ**対応。マスタ・スレーブ両方に対応し、**1台のFX5でマスタとスレーブを同時に使用可能**。
- **マスタ側はラダーが必要**（`ADPRW` 命令）。**スレーブ側はラダー不要**（パラメータのMODBUSデバイス割り付けだけで動作）。
- RS-485で **スレーブ32局**まで（局番設定範囲は1〜247）、RS-232Cは1局。最大 **4チャンネル**。
- `ADPRW` の要点:
  - **駆動接点は命令完了までOFFしない**
  - 通信実行状態 `(d2)` は **3点占有**（動作中／正常完了／異常完了）
  - 対象CHに**GX Works3でMODBUSマスタ設定をしないと、命令を実行しても動作しない（エラーも出ない）**

## 1. パラメータ設定（GX Works3）

設定場所:

- **CPUユニット内蔵**: ナビゲーションウィンドウ → [パラメータ] → ユニット形名 → [ユニットパラメータ] → [485シリアルポート]
- **拡張ボード**: [ユニットパラメータ] → [拡張ボード]（FX5-232-BD / FX5-485-BD を選択）
- **拡張アダプタ**: [パラメータ] → [ユニット情報] → 新規ユニット追加 → ADP1〜ADP6 → [ユニットパラメータ]

### 基本設定

| 項目 | 設定値 | 使用局 |
|---|---|---|
| プロトコル形式 | **MODBUS_RTU通信** | マスタ/スレーブ |
| パリティ | なし / 奇数 / 偶数 | マスタ/スレーブ |
| ストップビット | 1bit / 2bit | マスタ/スレーブ |
| ボーレート | 300〜115200bps | マスタ/スレーブ |

### 固有設定

| 項目 | 設定値 | 使用局 |
|---|---|---|
| **自局番** | **0: マスタ局** / **1〜247: スレーブ局** | マスタ/スレーブ |
| スレーブ応答タイムアウト | 1〜32767ms | マスタ/スレーブ |
| ブロードキャストディレイ | 1〜32767ms | マスタ/スレーブ |
| リクエスト間ディレイ | 1〜16382ms | マスタ/スレーブ |
| リトライ回数 | 0〜20回 | マスタ |
| デバイス割り付け | MODBUSデバイス割り付け（§2） | スレーブ |

タイミング設定の実効値ルール:

- スレーブ応答タイムアウトが `(3.5キャラクタ時間+1)×2μs` 未満 → その値でタイムアウトする
- 同値以上かつリクエスト間ディレイ以下 → `(リクエスト間ディレイ+1)×2μs` でタイムアウトする
- **ブロードキャストディレイはスレーブ局のスキャンタイム以上に設定する**。3.5キャラクタ時間以下ならマスタは3.5キャラクタ時間待ちで次要求を送信、リクエスト間ディレイ以下ならリクエスト間ディレイ+1msで送信
- リクエスト間ディレイが3.5キャラクタ時間以下 → マスタは3.5キャラクタ時間待ちで次要求を送信

### ラッチ設定（自局番をプログラムで変更したい場合）

| 設定 | 動作 |
|---|---|
| ラッチしない | GX Works3のパラメータ値で動作（特殊レジスタはR） |
| ラッチする | 各CHの特殊リレーがONし、**特殊レジスタの値で動作**（プログラムで変更可・R/W） |

| CH | 特殊リレー | 特殊レジスタ | 対応パラメータ |
|---|---|---|---|
| CH1 | SM8861 | SD8861 | 自局番設定 |
| CH2 | SM8871 | SD8871 | 同上 |
| CH3 | SM8881 | SD8881 | 同上 |
| CH4 | SM8891 | SD8891 | 同上 |

> - 設定値が反映されるのは**電源OFF→ONまたはリセット時**。
> - パラメータでマスタ局(局番0)としたCHに特殊レジスタで1以上を設定しても**スレーブにはならない**。逆も同様。
> - 「ラッチする」設定時にメモリクリア等でSDラッチ設定有効情報をOFFにすると、次回電源投入時はパラメータ値が有効になる。

## 2. MODBUSデバイス割り付け（スレーブ側で必須）

[MODBUSデバイス割り付け]画面の<詳細設定>で、割付1〜16まで設定できる。

| 設定項目 | 内容 |
|---|---|
| デバイス | 割付デバイスの種類と先頭番号 |
| 先頭MODBUSデバイス番号 | 先頭MODBUSアドレス |
| 割付点数 | 割り付ける点数 |

### 制約（必ず守る）

- **デバイス番号・割付点数は16の倍数**にする（違反時はGX Works3でパラメータ設定エラー）。
- **コイルと入力に同一デバイスは設定できない。**
- **入力レジスタと保持レジスタに同一デバイスは設定できない。**
- 先頭デバイス番号＋割付点数がデバイス有効範囲を超えるとパラメータ設定エラー。
- LCN, LZ などロング型デバイスは**MODBUSデバイスを2点使用**する。

### 割り付け可能デバイス

| MODBUSデバイス | 割り付け可能なFX5デバイス |

| コイル（読出し/書込み） | SM, SD, X, Y, M, L, F, B, D, W, TC, TS, TN, STC, STS, STN, CC, CS, CN, LCC, LCS, LCN, SB, SW, S, Z, LZ, R, ER |

| 保持レジスタ（読出し/書込み） | 同上 |

## 3. 対応MODBUS標準ファンクション

| ファンクションコード | ファンクション名 | 1伝文でのアクセス点数 | ブロードキャスト |
|---|---|---|---|
| 01H | コイル読出し | 1〜2000点 | 不可 |
| 02H | 入力読出し | 1〜2000点 | 不可 |
| 03H | 保持レジスタ読出し | 1〜125点 | 不可 |
| 04H | 入力レジスタ読出し | 1〜125点 | 不可 |
| 05H | 1コイル書込み | 1点 | 可 |
| 06H | 1レジスタ書込み | 1点 | 可 |
| 0FH | 複数コイル書込み | 1〜1968点 | 可 |
| 10H | 複数レジスタ書込み | 1〜123点 | 可 |

**フレーム構成（RTUモード）**

```
[アドレスフィールド 1byte][ファンクションコード 1byte][データ 0〜252byte][エラーチェック(CRC) 2byte]
   ← 3.5キャラ時間以上の間隔で区切られる →
```

- アドレスフィールド: 要求時 `0`=ブロードキャスト、`1〜247`=指定スレーブ。応答時はスレーブ自局番。
- ファンクションコード: 異常完了時は**最上位ビットがON**して返る。
- エラーチェックはCRC。伝文が異常なら破棄される。

## 4. ADPRW命令（マスタ専用）

### 4.1 オペランド6個の形式（マスタが1chのみの場合）

```
[駆動接点]──[ ADPRW  (s1)  (s2)  (s3)  (s4)  (s5)/(d1)  (d2) ]
ST: ENO := ADPRW(EN, s1, s2, s3, s4, s5d1, d2);
```

| オペランド | 内容 | 範囲 |
|---|---|---|
| (s1) | スレーブ局番 | 0〜F7H（0=ブロードキャスト） |
| (s2) | ファンクションコード | 01H〜06H, 0FH, 10H |
| (s3) | MODBUSアドレス | 0〜FFFFH |
| (s4) | アクセス点数 | 1〜2000（FC別に上限あり） |
| (s5)/(d1) | データ格納デバイス先頭 | — |
| (d2) | 通信実行状態出力の先頭ビットデバイス | **3点占有** |

### 4.2 オペランド8個の形式（最大4chのマスタで使用）

```
[駆動接点]──[ ADPRW  (s1)  (s2)  (s3)  (s4)  (s5)  (d1)  (d2)  (n) ]
ST: ENO := ADPRW_8(EN, s1, s2, s3, s4, s5, d1, d2, n);
```

| オペランド | 内容 | 範囲 |
|---|---|---|
| (s5) | ライトデータ格納デバイス先頭 | — |
| (d1) | リードデータ格納デバイス先頭 | — |
| (n) | 通信CH | FX5S/FX5UJ: K2〜K4、FX5U: K1〜K4、FX5UC: K1, K3〜K4 |

> **6個形式と8個形式は併用できない。** 複数chでマスタを使うなら8個形式に統一する。
> ビット型ラベルの桁指定は使用できない。

### 4.3 ファンクションコード別のパラメータ割り付け

| (s2) | 内容 | (s3) MODBUSアドレス | (s4) アクセス点数 | データ格納デバイスの占有点数 |
|---|---|---|---|---|
| 01H | コイル読出し | 0000H〜FFFFH | 1〜2000 | ワード: ((s4)+15)÷16点（端数切捨て）／ビット: (s4)点 |
| 02H | 入力読出し | 0000H〜FFFFH | 1〜2000 | 同上 |
| 03H | 保持レジスタ読出し | 0000H〜FFFFH | 1〜125 | (s4)点 |
| 04H | 入力レジスタ読出し | 0000H〜FFFFH | 1〜125 | (s4)点 |
| 05H | 1コイル書込み | 0000H〜FFFFH | **0(固定)** | 1点（**最下位ビットが0でOFF、1でON**） |
| 06H | 1レジスタ書込み | 0000H〜FFFFH | **0(固定)** | 1点 |
| 0FH | 複数コイル書込み | 0000H〜FFFFH | 1〜1968 | ワード: ((s4)+15)÷16点／ビット: (s4)点 |
| 10H | 複数レジスタ書込み | 0000H〜FFFFH | 1〜123 | (s4)点 |

**データ格納デバイスに指定できるデバイス**

| 用途 | 指定可能デバイス |
|---|---|
| ワードデバイス指定 | T, ST, C, D, R, W, SW, SD, ラベルデバイス |
| ワードデバイス指定（定数可の箇所） | 上記 + K, H |
| ビットデバイス指定 | X, Y, M, L, B, F, SB, S, SM, ラベルデバイス |

> T, ST, C はオペランドのデバイス指定としては使用できない箇所がある（(d2) など）。

### 4.4 通信実行状態出力デバイス (d2)

| デバイス | 動作するタイミング | 同時に動作する特殊リレー |
|---|---|---|
| (d2)+0 | **命令動作中にON**、実行中以外はOFF | SM8800(CH1), SM8810(CH2), SM8820(CH3), SM8830(CH4) |
| (d2)+1 | **命令正常完了時にON**、通信開始時にOFF | SM8029（8個形式のみ・FX5U） |
| (d2)+2 | **命令異常完了時にON**、通信開始時にOFF | SM8029（同上） |

- `(d2)+1` と `(d2)+2` で正常／異常の判別ができる。
- FX3シリーズ互換用SM/SDを設定している場合は `SM8401(CH1)` / `SM8421(CH2)` がONする。
- **(d2) は先頭から3点占有する。他の制御で使用しているデバイスと重複させないこと。**

### 4.5 命令レベルの注意事項

- **対象チャンネルにGX Works3でMODBUSマスタの設定をすること。** 未設定のまま `ADPRW` を実行しても動作せず、**エラーも発生しない**。
- エラーでプログラムが停止したとき、通信状態出力デバイスに**非ラッチデバイス**を指定しているとデバイス値がOFFされる。状態を残したい場合は**ラッチデバイス**を指定する。

## 6. ラダー実装パターン（マスタ）

### 6.1 コイル読出し（FC=01H）

スレーブ02HのMODBUSアドレス100から8コイルを、マスタのD0の下位8ビットに読み出す。

```
M0(駆動接点)
──┤├──[ ADPRW  H2  H1  K100  K8  D0  M10 ]
                  │   │    │    │   │   └ M10:動作中 / M11:正常完了 / M12:異常完了
                  │   │    │    │   └ リードデータ格納先
                  │   │    │    └ アクセス点数 8
                  │   │    └ MODBUSアドレス 100
                  │   └ ファンクションコード 01H
                  └ スレーブ局番 02H

M11(正常完了)
──┤├──[ 正常完了処理 ]
          [ RST M0 ]     ; 駆動接点OFF
          [ RST M11 ]
M12(異常完了)
──┤├──[ 異常完了処理 ]
          [ RST M0 ]     ; 駆動接点OFF
          [ RST M12 ]
```

### 6.2 複数レジスタ書込み（FC=10H）

マスタのD1000〜D1003を、スレーブ03HのMODBUSアドレス0から書き込む。

```
M1(駆動接点)
──┤├──[ ADPRW  H3  H10  K0  K4  D1000  M20 ]
                                            └ M20:動作中 / M21:正常完了 / M22:異常完了
M21 ──┤├──[ 正常完了処理 ][ RST M1 ][ RST M21 ]
M22 ──┤├──[ 異常完了処理 ][ RST M1 ][ RST M22 ]
```

### 6.3 複数CHで使う場合（8個形式）

```
M0
──┤├──[ ADPRW  H2  H1  K100  K8  D900  D0  M10  K1 ]
                                    │     │        └ 通信CH = CH1
                                    │     └ リードデータ格納先
                                    └ ライトデータ格納先
```

### 6.4 複数の要求を順に投げる場合

```
- ADPRW命令を複数同時に駆動してもよい（先に駆動した通信の完了後に、後の通信が開始される）
- ただし「通信が完了するまで駆動接点をOFFしない」ことが絶対条件
- 完了フラグ (d2)+1 / (d2)+2 で駆動接点をリセットして次の要求へ進める
```

## 7. プログラム作成上の注意（違反するとバグになる）

1. **ADPRW命令が完了するまで駆動接点をOFFしない。**
2. `ADPRW` を単独で駆動した場合は**即時通信開始**。複数同時に駆動した場合は**先に駆動した命令の通信完了後**に次が開始される。そのため完了まで駆動接点を保持する。
3. **コイル読出し(01H)／入力読出し(02H)で読出し先にワードデバイスを指定した場合、アクセス点数で指定したビット分しか書き換わらない。** ワードデバイスの残りビットは変化しない（前回値が残る）。
4. `(d2)` は3点占有。他用途と重複させない。
5. 通信状態を保持したい場合は `(d2)` にラッチデバイスを指定する。
6. 対象CHにMODBUSマスタ設定がないと**無反応**（エラーも出ない）。動かないときは最初にここを疑う。
7. ブロードキャスト（(s1)=0）は**書込み系ファンクション(05H, 06H, 0FH, 10H)のみ**。読出しコマンドをブロードキャストにすると 730DH エラー。
8. `05H` / `06H` のアクセス点数 `(s4)` は **0固定**。
9. 同一CHを他の通信命令（RS2、インバータ通信命令など）と併用できない（1810H エラー）。

## 9. ラダー生成前チェックリスト

- [ ] 自局番設定は正しいか（マスタ=0 / スレーブ=1〜247）
- [ ] 対象CHのプロトコル形式を[MODBUS_RTU通信]にしたか
- [ ] マスタ設定をしたCHに対して `ADPRW` を発行しているか
- [ ] 6個形式と8個形式を混在させていないか
- [ ] `(s4)` がファンクションコード別の上限内か（01H/02H: 2000、03H/04H: 125、0FH: 1968、10H: 123、05H/06H: 0固定）
- [ ] `(d2)` に3点連続の空きビットデバイスを確保したか
- [ ] 駆動接点を完了フラグでリセットする回路になっているか（完了前にOFFしない）
- [ ] 読出し先にワードデバイスを使う場合、残りビットが変化しない点を考慮したか
- [ ] スレーブ側はMODBUSデバイス割り付けを16の倍数で設定したか
- [ ] ブロードキャストを読出し系に使っていないか
