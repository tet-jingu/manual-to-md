## 0. 結論サマリ

- 簡易PC間リンク＝**最大8台（マスタ局1＋ローカル局7）のFX間でM/Dデバイスを自動的に共有**する機能。
- **専用命令は存在しない。** パラメータでリンクデバイスを割り付ければ、あとは**通常のMOV等でリンクデバイスを読み書きするだけ**。
- ラダーで実際に書くのは次の3種類だけ:
  1. **自局の情報をリンクデバイスに書き込む**回路
  2. **他局のリンクデバイスから情報を読み出す**回路
  3. **リンクエラー監視・インタロック**回路
- **他局が使用するリンクデバイスを自局で書き換えてはならない**（正常に動作しない）。
- 通信仕様は**固定**（38400bps、データ長7bit、偶数パリティ、ストップ1bit）。変更できない。

## 1. 通信仕様（変更不可）

| 項目 | 仕様 |
|---|---|
| 接続台数 | 最大8台（マスタ局0局＋ローカル局1〜7局） |
| 伝送規格 | RS-485規格準拠 |
| プロトコル形式 | 簡易PC間リンク |
| 通信方式 | 半二重双方向 |
| ボーレート | 38400bps（固定） |
| データ長 | 7bit（固定） |
| パリティ | 偶数（固定） |
| ストップビット | 1bit（固定） |
| スタートビット | 1bit（固定） |
| ヘッダ/ターミネータ/サムチェック | 固定 |
| 制御手順 | 形式1（CR, LF付加なし） |
| 最大総延長距離 | FX5-485ADPのみ: 1200m以下 / FX5-485ADP＋FX3U-485ADP: 500m以下 / 上記以外: 50m以下 |

> **簡易PC間リンクは1チャンネルのみ設定可能。**

## 2. パラメータ設定（GX Works3）

設定場所: 内蔵RS-485→[485シリアルポート]、通信ボード→[拡張ボード]（FX5-485-BD）、通信アダプタ→ADP1〜6。

| 分類 | 項目 | 設定値 |
|---|---|---|
| 基本設定 | 拡張ボード（CH2のみ） | FX5-485-BD |
| 基本設定 | プロトコル形式 | **簡易PC間リンク** |
| 固有設定 | 自局番 | **0: マスタ局** / **1〜7: ローカル局** |
| 固有設定 | ローカル局総数 | 1〜7 |
| 固有設定 | リフレッシュ範囲 | 0: パターン0 / 1: パターン1 / 2: パターン2 |
| 固有設定 | リトライ回数 | 0〜10 |
| 固有設定 | 監視時間 | 50〜2550(ms) |
| リンクデバイス | リンクデバイスBit | FX5S: M0〜M32672 / FX5UJ: M0〜M7584 / FX5U・FX5UC: M0〜M32672 |
| リンクデバイス | リンクデバイスWord | D0〜D7986 |
| SM/SD設定 | ラッチ設定（自局番・ローカル局総数設定） | ラッチする / ラッチしない |
| SM/SD設定 | 互換用SM/SD | 使用しない / CH1 / CH2 |

**設定例（マスタ＋ローカル7局）**

| 項目 | マスタ(0局) | ローカル1〜7局 |
|---|---|---|
| 局番 | 0 | 1〜7 |
| ローカル局総数 | 7 | （マスタのみ設定） |
| リフレッシュ範囲 | 1（パターン1） | — |
| リトライ回数 | 3 | — |
| 監視時間 | 50 | — |
| リンクデバイスBit | M4000 | M4000 |
| リンクデバイスWord | D1000 | D1000 |

> リンクデバイス先頭番号は**各局ごとに違う値にすることも可能**だが、同じにしておくと理解しやすい。

### ラッチ設定（局番・ローカル局総数をプログラムで変更したい場合）

| 内容 | 対応デバイス（ラッチ有効情報） |
|---|---|
| 自局番 | SM9080 |
| ローカル局総数設定 | SM9081 |

「ラッチする」設定時は、対応ワードデバイスに値を書き込み、**電源OFF→ONまたはリセット**で反映される。

## 3. リンクデバイスの割付（最重要）

リンクデバイス先頭番号を基点に、リフレッシュ範囲（パターン）に応じて自動割付される。
下表は **ビット先頭=M(y)、ワード先頭=D(x)** としたときの割付。

| 局番 | パターン0<br>M: 0点 / D: 各局4点 | パターン1<br>M: 各局32点 / D: 各局4点 | パターン2<br>M: 各局64点 / D: 各局8点 |
|---|---|---|---|
| マスタ(0) | D(x)〜D(x+3) | M(y)〜M(y+31), D(x)〜D(x+3) | M(y)〜M(y+63), D(x)〜D(x+7) |
| ローカル1 | D(x+10)〜D(x+13) | M(y+64)〜M(y+95), D(x+10)〜D(x+13) | M(y+64)〜M(y+127), D(x+10)〜D(x+17) |
| ローカル2 | D(x+20)〜D(x+23) | M(y+128)〜M(y+159), D(x+20)〜D(x+23) | M(y+128)〜M(y+191), D(x+20)〜D(x+27) |
| ローカル3 | D(x+30)〜D(x+33) | M(y+192)〜M(y+223), D(x+30)〜D(x+33) | M(y+192)〜M(y+255), D(x+30)〜D(x+37) |
| ローカル4 | D(x+40)〜 | M(y+256)〜, D(x+40)〜 | M(y+256)〜, D(x+40)〜 |
| ローカル5 | D(x+50)〜 | M(y+320)〜, D(x+50)〜 | M(y+320)〜, D(x+50)〜 |
| ローカル6 | D(x+60)〜 | M(y+384)〜, D(x+60)〜 | M(y+384)〜, D(x+60)〜 |
| ローカル7 | D(x+70)〜 | M(y+448)〜, D(x+70)〜 | M(y+448)〜, D(x+70)〜 |

- **ワードデバイスは局ごとに10点刻み**（マスタ=+0、ローカルn=+10n）で先頭が決まる。
- **ビットデバイスはパターン1で64点刻み、パターン2でも64点刻み**（占有はパターン1=32点、パターン2=64点）。
- **パターン0ではビットデバイス（M）は使用できない。** ビット情報を送りたい場合はワードデバイスに置き換える。

**具体例**（パターン1、リンクデバイス先頭 D1000 / M4000、ローカル局3台）

| 局 | ビットリンクデバイス | ワードリンクデバイス |
|---|---|---|
| マスタ(0) | M4000〜M4031 | D1000〜D1003 |
| ローカル1 | M4064〜M4095 | D1010〜D1013 |
| ローカル2 | M4128〜M4159 | D1020〜D1023 |
| ローカル3 | M4192〜M4223 | D1030〜D1033 |

> この例では D1000〜D1033（34点）、M4000〜M4223（224点）を占有する。それ以外は一般の制御用デバイスとして使用できる。
> 接続しないローカル局のリンクデバイスも一般用に使えるが、**将来増設する予定があるなら空けておく**。
> FX3と混在する場合、FX3側のリンクデバイス番号は固定（D0〜、M1000〜）だが、**同局番同士でリンクされる**。

## 5. ラダー実装パターン

### 5.1 マスタ局

```
<<リンクデバイス（マスタ局→ローカル局）書込みプログラム>>
X0  ──( M4000 )                       ; 自局のビット情報をリンクデバイスへ
X2  ──( M4001 )
M10 ──( M4002 )
SM400 ──[ MOV K4M100 K4M4010 ]        ; M100〜M115 を M4010〜M4025 へ
        [ MOV D0     D1000    ]        ; D0 を D1000（自局ワードリンクデバイス）へ

<<リンクデバイス（ローカル局→マスタ局）読出しプログラム>>
SM9041(b接点)                          ; 局番1が正常なときだけ読む
──┤/├──[ MOV K4M4070 K4Y20 ]         ; ローカル1のリンクデバイスを読み出す
          [ MOV D1010    D10   ]
M4064 ──( M0  )
M4065 ──( Y11 )
M4066 ──( M15 )

SM9042(b接点)
──┤/├──[ MOV K4M4140 K4M20 ]         ; ローカル2のリンクデバイスを読み出す
          [ MOV D1020    D20   ]

<<リンクエラー表示プログラム>>
SM9041 ──( Y0 )    ; 局番1リンクエラー
SM9042 ──( Y1 )    ; 局番2リンクエラー
SM9056 ──( Y10 )   ; 簡易PC間リンク実行中
```

### 5.2 ローカル局（局番1の例）

```
<<リンクデバイス（自局→マスタ・他ローカル局）書込みプログラム>>
X0  ──( M4064 )                       ; 局番1の自局ビットリンクデバイス
X2  ──( M4065 )
M10 ──( M4066 )
SM400 ──[ MOV K4M100 K4M4070 ]
        [ MOV D0     D1010    ]        ; 局番1の自局ワードリンクデバイス

<<リンクデバイス（マスタ・他ローカル局→自局）読出しプログラム>>
SM9040(b接点)                          ; マスタ局が正常なときだけ読む
──┤/├──[ MOV K4M4010 K4Y20 ]
          [ MOV D1000    D10   ]
M4000 ──( M0  )
M4001 ──( Y11 )
M4002 ──( M15 )

SM9042(b接点)                          ; 局番2が正常なときだけ読む
──┤/├──[ MOV K4M4140 K4M20 ]
          [ MOV D1020    D20   ]

<<リンクエラー表示プログラム>>
SM9040 ──( Y0 )    ; 局番0(マスタ)リンクエラー
SM9042 ──( Y1 )    ; 局番2リンクエラー
SM9056 ──( Y10 )   ; 簡易PC間リンク実行中
```

### 5.3 立上げ時の通信テストプログラム（運転時は不要）

**マスタ局**

```
SM400 ──[ MOV K1X0   D1000 ]   ; 自局X0〜X3をリンクデバイスへ
        [ MOV D1010  K1Y4  ]   ; ローカル1の情報を Y4〜Y7 へ
        [ MOV D1020  K1Y10 ]   ; ローカル2 → Y10〜Y13
        …
        [ MOV D1070  K1Y34 ]   ; ローカル7 → Y34〜Y37
```

**ローカル局（局番1）**

```
SM400 ──[ MOV K1X0   D1010 ]   ; 自局X0〜X3を自局リンクデバイスへ
        [ MOV D1000  K1Y0  ]   ; マスタの情報を Y0〜Y3 へ
        [ MOV D1020  K1Y10 ]   ; 他ローカル局の情報
        …
```

| ローカル局番号 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|
| ワードリンクデバイス | D1010 | D1020 | D1030 | D1040 | D1050 | D1060 | D1070 |
| 表示出力(Y) | Y4〜Y7 | Y10〜Y13 | Y14〜Y17 | Y20〜Y23 | Y24〜Y27 | Y30〜Y33 | Y34〜Y37 |

**テスト手順**

1. 全局の通信設定・プログラムを書き込み、**電源OFF→ONまたはリセット**
2. 使用シリアルポートの **SD / RD LEDが点滅**しているか確認（消灯ならトラブルシューティングへ）
3. マスタ局の X0〜X3 を操作し、各ローカル局の Y0〜Y3 がONするか確認
4. 各ローカル局の X0〜X3 を操作し、マスタ局(Y0〜Y3)や他ローカル局の出力がONするか確認

## 6. プログラム作成上の注意（違反するとバグになる）

1. **簡易PC間リンクを使用すると、各シーケンサの演算周期が1局あたり約10%長くなる。**
2. **局番号は連続して設定する。** 重複や空き番号があると正常にリンクできない。
3. **他局のリンクデバイスの内容を自局で変更しない。**
4. **リンクエラー（データ伝送シーケンスエラー）発生時、リンクデバイスの情報はエラー発生前の状態を保持する。** → 古い値で動き続けるため、**エラーフラグ（SM9040〜SM9047）でインタロックし、安全に動作するようプログラムする**。
5. リンクデバイスの更新は**シーケンスプログラムと非同期**。ただし各局の送信データ更新は**END処理で実施**されるため、ラダー演算途中でリンクデバイスを変えても**END処理までは通信データに反映されない**（変化前の値でリンクする）。
6. パターン0ではビットデバイスが使えない。ビット情報はワードデバイスに置き換える。
7. **局番・ローカル局総数を変更する場合の注意**（ラッチ設定あり時のみ変更可、電源OFF→ONで反映）:

| 状況 | 動作 |
|---|---|
| ローカル局総数が増えてマスタ局のリンクデバイスが不足 | エラーコード **7705H** を SD8211 / SD9061 に格納。**リンクは継続**するが、足りないデバイスは更新されない |
| ローカル局総数が増えてローカル局のリンクデバイスが不足 | **7705H** を SD8212〜SD8218 / SD9062〜SD9068 の自局番のSDに格納。リンクは継続、足りない分は更新されない |
| ローカル局番号変更で自局リンクデバイスが範囲外 | **7715H** を自局番のSDに格納。足りない分は**すべて0（ワード:0、ビット:OFF）を送信**。7705Hと同時発生時は7715Hが格納される |

## 8. ラダー生成前チェックリスト

- [ ] プロトコル形式を[簡易PC間リンク]にし、1チャンネルだけに設定したか
- [ ] 自局番（マスタ=0 / ローカル=1〜7）を連続番号で割り当てたか（重複・空番なし）
