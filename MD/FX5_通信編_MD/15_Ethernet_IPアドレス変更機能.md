## 0. 結論サマリ

- **特殊レジスタにIPアドレスを書き、特殊リレーをONするだけでCPUユニットのIPアドレスを変更できる**機能。GX Works3がなくてもIPアドレスを変更できる。
- 変更できるのは **IPアドレス / サブネットマスクパターン / デフォルトゲートウェイIPアドレス** の3種類。
- **IPアドレス格納エリアの値が、ユニットパラメータの設定より優先される。**
- 値は **IPアドレス格納エリア**（CPUユニット: 内蔵FRAM、Ethernetユニット: 内蔵フラッシュROM）に保存される。**SDメモリカードには保存されない。**
- 反映には **電源OFF→ONまたはリセット**が必要。

---

## 1. 動作の流れ（CPUユニットの場合）

```
① デバイス書込み操作で特殊レジスタ SD8492〜SD8497 にIPアドレスなどを格納（16進数）
② IPアドレス格納エリア書込み要求 SM8492 を OFF→ON
   → SD8492〜SD8497 の内容がIPアドレス格納エリア（内蔵FRAM）に書き込まれる
③ CPUユニットの電源OFF→ONまたはリセット
④ IPアドレス格納エリアの値でCPUユニットが動作する
   → 実際に動作しているIPアドレスは SD10050, SD10051, SD10060, SD10061, SD10064, SD10065 で確認できる
```

**設定値の優先順位**

| IPアドレス格納エリアの状態 | 有効になる設定 | SM8498 |
|---|---|---|
| 値が格納されている（有効な値） | **IPアドレス格納エリアの値** | ON |
| クリアされている／無効な値／未設定 | ユニットパラメータの設定値 | OFF |

> 周辺機器（GOT等）、MX Component、MX Sheet、リンク機能から特殊デバイスの値を変更することでも本機能を使用できる。

| SD8496 | デフォルトゲートウェイIPアドレス設定(下位) | 同上 | R/W |
| SD8497 | デフォルトゲートウェイIPアドレス設定(上位) | 同上 | R/W |

| SM8493 | IPアドレス格納エリア書込み完了 | 書込みが完了するとON（**失敗時もON**）。SM8492がON→OFFするとOFF | R |
| SM8494 | IPアドレス格納エリア書込みエラー | 書込みが失敗するとON。**電源OFF→ON時に格納エリアの内容に異常がある場合もON**。SM8492がON→OFFするとOFF | R |

| SD10050, SD10051 | IPアドレス | 現在設定されているIPアドレス |
| SD10060, SD10061 | サブネットマスク | 現在設定されているサブネットマスク |

## 3. ラダー実装パターン

### 3.1 IPアドレスを変更する（CPUユニット）

例: IPアドレス 192.168.3.40 / サブネットマスク 255.255.255.0 / デフォルトゲートウェイ 192.168.3.254 に変更する。

```
<<設定値を格納（16進数で設定する）>>
X20(変更指示) の立上り
──┤↑├──[ DMOV HC0A80328 SD8492 ]   ; IPアドレス 192.168.3.40 = C0A80328H
          [ DMOV HFFFFFF00 SD8494 ]   ; サブネットマスク 255.255.255.0 = FFFFFF00H
          [ DMOV HC0A803FE SD8496 ]   ; デフォルトGW 192.168.3.254 = C0A803FEH
          [ SET M10 ]

<<書込み要求（OFF→ONで実行）>>
M10  SM8493(b接点)  SM8495(b接点)
──┤├────┤/├──────────┤/├──[ SET SM8492 ]

<<結果確認>>
SM8493(書込み完了)  SM8494(b接点)
──┤├────────────┤/├──[ SET M11 ]           ; 正常完了 → 電源OFF→ON/リセットへ
SM8493  SM8494
──┤├──┤├──[ MOV SD8498 D100 ][ SET M12 ]     ; 異常完了：エラーコード退避

<<要求のリセット（完了を確認してから落とす）>>
SM8493 ──[ RST SM8492 ][ RST M10 ]
```

**16進数変換の考え方**: `192.168.3.40` → `C0.A8.03.28` → 32bitで `C0A80328H`（`DMOV` で下位・上位の2ワードにまとめて格納する）。

### 3.2 IPアドレス格納エリアをクリアする（ユニットパラメータの設定に戻す）

```
X21(クリア指示)  SM8496(b接点)  SM8492(b接点)
──┤├──────────┤/├────────┤/├──[ SET SM8495 ]

SM8496(クリア完了)  SM8497(b接点) ──[ SET M21 ]                 ; 正常完了
SM8496              SM8497        ──[ MOV SD8499 D101 ][ SET M22 ] ; 異常完了
SM8496 ──[ RST SM8495 ]
```

### 3.3 現在どちらの設定で動いているか確認する

```
SM8498(IPアドレス変更機能動作中)
──┤├──( IPアドレス変更機能 有効表示 )
──┤/├─( ユニットパラメータ設定で動作中 )

; 実際に動作中の値
[ DMOV SD10050 D200 ]   ; IPアドレス
[ DMOV SD10060 D202 ]   ; サブネットマスク
[ DMOV SD10064 D204 ]   ; デフォルトゲートウェイ
```

## 4. プログラム作成上の注意（違反するとIPが変わらない・壊れる）

1. **設定値は16進数で格納する。**
2. **サブネットマスクとデフォルトゲートウェイを「設定なし(0.0.0.0)」にする場合は、両方とも0.0.0.0にする。** 片方だけ0.0.0.0にするとエラーになり、IPアドレス変更は行われない。
3. **書込み／クリア実行中に電源OFFやリセットをしない**（値が反映されないことがある）。**書込み要求 `SM8492`／クリア要求 `SM8495` のON→OFFを確認してから**電源OFF→ONまたはリセットする。
4. **書込み要求とクリア要求を同時にOFF→ONしない**（1921H）。同時にONした場合は**書込み操作が優先**され、クリア操作はエラーになる。
5. **要求を短い間隔でON→OFF→ON、OFF→ON→OFFのように操作しない**（処理が実行されないことがある）。
6. 書込み処理実行中に再度書込み要求をOFF→ONした場合、**先の書込みは正常完了し、後の操作は無視される**（クリアも同様）。
7. 書込み処理実行中にクリア要求をOFF→ONすると**クリア操作はエラー**になる（逆も同様）。
8. **IPアドレス格納エリアはSDメモリカードに保存されない。** SDメモリカードを差し替えても格納エリアの設定は変わらない。
9. IPアドレス格納エリアへの書込みは **CPUユニットがRUN中でもSTOP中でも可能**。
10. **ユニットパラメータで指定したIPアドレスを使いたい場合は、IPアドレス格納エリアをクリアする。**
11. `SD8492`〜`SD8497` は**書込みが正常完了すると0になる**ため、書込み後に値を読み返して確認する用途には使えない（現在値は `SD10050`〜 で確認する）。

## 5. トラブルシューティング（IPアドレス変更機能のみ）

### 5.1 確認するフラグ

| 内容 | CPUユニット | Ethernetユニット |
|---|---|---|
| 書込み完了 | SM8493 | — |
| 書込みエラー | SM8494 | — |
| 書込みエラーコード | **SD8498** | **Un\G61** |
| クリア完了 | SM8496 | — |
| クリアエラー | SM8497 | — |
| クリアエラーコード | **SD8499** | **Un\G62** |
| 機能動作中 | SM8498 | Un\G60 |

### 5.2 エラーコード

**CPUユニット**

| コード | 異常内容と原因 | 処置方法 |
|---|---|---|
| 1920H | IPアドレス設定など（SD8492〜SD8497）の値が設定範囲外 | SD8492〜SD8497 の値を見直す |
| 1921H | 書込み要求とクリア要求（SM8492, SM8495）が同時にOFF→ONした | 同時にOFF→ONしていないか確認する |
| 1810H | IPアドレス変更に失敗した | 再度IPアドレス変更機能を実行する |

**Ethernetユニット／EtherNet/IPユニット**

| コード | 異常内容と原因 | 処置方法 |
|---|---|---|
| 1920H | IPアドレス設定など（Un\G50〜Un\G55）の値が設定範囲外 | Un\G50〜Un\G55 の値を見直す |
| 1921H | 書込み要求とクリア要求（Un\G56, Un\G58）が同時にOFF→ONした（1を同時格納した） | 同時に1を格納していないか確認する |
| 1DC4H | IPアドレス変更に失敗した | 再度実行する。再発する場合はユニットのハードウェア異常の恐れがあるため、三菱電機システムサービスまたは支社・代理店に相談する |

### 5.3 電源投入時にSM8494がONしている場合

**電源OFF→ON時にIPアドレス格納エリアの内容に異常がある場合も `SM8494` がONする。** この場合は格納エリアをクリア（`SM8495`）してから、再度設定し直す。

## 6. ラダー生成前チェックリスト

- [ ] 設定値を**16進数**で `SD8492`〜`SD8497` に格納しているか
- [ ] サブネットマスクとデフォルトゲートウェイを片方だけ 0.0.0.0 にしていないか
- [ ] 書込み要求 `SM8492` を**パルス（OFF→ON）**で与えているか
- [ ] 書込み要求とクリア要求を同時にONする回路になっていないか
- [ ] 完了フラグ `SM8493` / `SM8496` を確認してから要求をリセットしているか
- [ ] 異常時に `SD8498` / `SD8499` を退避しているか
- [ ] 書込み/クリア実行中に電源OFF・リセットが起きない運用手順になっているか
- [ ] 反映には電源OFF→ONまたはリセットが必要であることを操作手順に含めたか
- [ ] パラメータ設定に戻す手段（格納エリアのクリア）を用意したか
