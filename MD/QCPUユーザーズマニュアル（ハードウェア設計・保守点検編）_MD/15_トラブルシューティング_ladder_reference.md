## 第15章 冒頭 (原本 p.275)

本章では，システムを使用するうえで発生する各種エラーの内容および原因究明，処置方法について説明します。
二重化システム（二重化 CPU 使用時）を構成した場合に関しては，下記マニュアルを参照してください。
- QnPRHCPU ユーザーズマニュアル（二重化システム編）

トラブルが発生した場合，下記の順にトラブルシューティングを実施します。
- 目視による確認（274ページ 15.1節）
- エラーの確認と処置方法（279ページ 15.2節）

**備考**

また，復旧前にトラブル発生時のプログラムやデバイスなどを保存しておくと，トラブル要因の解明などに役立ちます。
（302ページ 15.4節）

## 15.1 目視による確認 (15.1 / 原本 p.276-280)

下記に示す項目を確認してください。

### (1) LED の状態を確認 (原本 p.276)

ユニット本体に異常がないかを確認します。下記の手順に従って，各 LED を確認してください。
なお，LED 表示とユニットの状態については各ユニットの「各部の名称」を参照してください。
- CPU ユニット（115ページ 6.1節）
- 電源ユニット（189ページ 7.1節）

1. 電源を ON して，電源ユニットの POWER LED を確認してください。
   電源を ON しても POWER LED が点灯しない場合は，下記のトラブルシューティングを行ってくださ
   い。275ページ 15.1.1項
2. POWER LED の点灯色を確認してください。
   POWER LED が緑点灯していない場合は，下記のトラブルシューティングを行ってください。
   275ページ 15.1.2項
3. 寿命検出電源ユニットを使用している場合，LIFE LED を確認してください。
   LIFE LED が緑点灯または橙点灯していない場合は，下記のトラブルシューティングを行ってください。
   276ページ 15.1.3項
4. CPU ユニットの MODE LED を確認してください。
   MODE LED が点灯しない場合は，下記のトラブルシューティングを行ってください。
   277ページ 15.1.4項
5. CPU ユニットの RUN LED を確認してください。
   RUN LED が点灯しない場合は，下記のトラブルシューティングを行ってください。
   278ページ 15.1.5項
6. ハイパフォーマンスモデル QCPU，プロセス CPU，二重化 CPU 使用している場合は，BOOT LED を確
   認してください。
   BOOT LED が点滅している場合は，下記のトラブルシューティングを行ってください。
   278ページ 15.1.6項
7. CPU ユニットの ERR. LED を確認してください。
   ERR. LED が点灯または点滅している場合は，エラーが発生しています。
   プログラミングツールにてエラーの確認を行ってください。（279ページ 15.2節）
8. CPU ユニットの BAT. LED を確認してください。
   BAT. LED が点灯している場合は，バッテリの電圧が低下しています。
   バッテリを交換してください。（251ページ 13.3節）

### (2) 通信ケーブルと配線の確認 (原本 p.276)

通信ケーブルに異常がないか，コネクタや端子台などがはずれていないか，または配線が正しいか確認してく
ださい。（99ページ 4.8節）

### 15.1.1 POWER LED が点灯しない場合 (15.1.1 / 原本 p.277)

下記の項目を確認してください。

確認項目と処置方法(表・原本 p.277):

| 確認項目 | 処置方法 |
|---|---|
| CPU ユニットのMODE LEDが点灯している | 該当電源ユニットが故障しています。電源ユニットを交換してください。 |
| 適正な電圧の電源が供給されていない | 適正な電圧の電源を供給してください。（197ページ 7.2節） |
| システム全体の内部消費電流が電源ユニットの定格出力電流を超えている | システム構成を再検討し，内部消費電流を電源ユニットの定格出力電流以下に抑えてください。（606ページ 付10） |
| 電源ユニット以外のユニットをすべてはずした状態で電源を再投入したとき，POWER LEDが点灯した | システムに装着していたユニットを1台ずつ増やしながら，電源の再投入を繰り返してください。POWER LEDが点灯しなくなった時点の，最後に装着したユニットが故障しています。 |

上記の項目を確認しても POWER LED が点灯しない場合は，電源ユニット，またはベースユニットのハードウェア
異常の恐れがあります。
最寄りの三菱電機システムサービス株式会社または当社の支社，代理店にご相談ください。

### 15.1.2 POWER LED が緑点灯していない場合 (15.1.2 / 原本 p.277)

下記の POWER LED の点灯状態から該当する項目を確認してください。

#### (1) 赤点灯している場合 (原本 p.277)

該当の電源ユニットを取りはずして，正常なベースユニットに装着してから電源を再投入してください。
電源を再投入しても POWER LED が赤点灯する場合は，該当の電源ユニットが故障しています。
また，上記の確認中に，電源を投入しても POWER LED が点灯しなくなった場合は，275ページ 15.1.1
項の内容もあわせて確認してください。

#### (2) 橙点滅している場合 (原本 p.277)

電源を再投入してください。再投入しても橙点滅となる場合は，電源ユニットが故障しています。
また，上記の確認中に，電源を投入しても POWER LED が点灯しなくなった場合は，275ページ 15.1.1
項の内容もあわせて確認してください。

### 15.1.3 LIFE LED が緑点灯または橙点灯していない場合 (15.1.3 / 原本 p.278)

下記の LIFE LED の点灯状態から該当する項目を確認してください。

#### (1) 消灯している場合 (原本 p.278)

電源を再投入してください。再投入後に LIFE LED が1秒間赤点灯した場合は，電源ユニットが寿命に達して
いるため，該当電源ユニットを交換してください。
電源を再投入しても LIFE LED が点灯または点滅しない場合は，寿命診断ができないため，該当電源ユニット
の交換をお奨めします。

#### (2) 赤点灯している場合 / (3) 赤点滅している場合 (原本 p.278)

電源を再投入してください。再投入しても LIFE LED が緑点灯，または橙点灯とならない場合は，以下の項目
を参照し，LG-FG の配線状況を確認してください。
- シーケンサの接地処理（112ページ 4.8.4項）
- 電源線，接地線のとりまわし（585ページ 付8.1.2）
- 電源部の接地処理（594ページ 付8.1.5）

配線状況を確認しても改善されない場合は，該当電源ユニットを交換してください。

確認項目と処置内容(表・原本 p.278):

| 確認項目 | 処置内容 |
|---|---|
| 仕様周囲温度が0～55℃の範囲を超えている | 仕様周囲温度を0～55℃の範囲にしてください。 |
| 電源を再投入してもLIFE LEDが赤点灯する | しばらく電源ユニットの動作を停止し，ユニットの内部温度を下げてから電源を再投入してください。再投入してもLIFE LEDが緑点灯，または橙点灯とならない場合は，該当電源ユニットを交換してください。 |

### 15.1.4 MODE LED が点灯しない場合 (15.1.4 / 原本 p.279)

下記の項目を確認してください。

確認項目と処置内容(表・原本 p.279):

| 確認項目 | 処置内容 |
|---|---|
| 強制ON/OFFの設定を行っている | 強制ON/OFFの設定を解除してください。 |
| ハイパフォーマンスモデルQCPU，プロセスCPU，二重化CPUを使用している場合，RESET/L.CLRスイッチが中立位置にない | RESET/L.CLRスイッチを中立位置にしてください。 |
| 電源ユニットを交換して電源を再投入したとき，MODE LEDが点灯した | 交換前の電源ユニットに原因があります。最寄りの三菱電機システムサービス株式会社または当社の支社，代理店にご相談ください。 |
| 電源ユニットを交換して電源を再投入しても，MODE LEDが点灯しない | CPUユニットまたは装着されているユニットに原因があります。システムに装着していたユニットを1台ずつ増やしながら，電源の再投入を繰り返してください。MODE LEDが点灯しなくなった時点の，最後に装着したユニットが故障しています。 |
| 電源ユニット以外のユニットをすべてはずした状態で電源ユニットを再投入したとき，POWER LEDが点灯した | システムに装着していたユニットを1台ずつ増やしながら，電源の再投入を繰り返してください。POWER LEDが点灯しなくなった時点の，最後に装着したユニットが故障しています。 |
| 増設ケーブルの接続方向が正常になっていない（OUT-OUTに接続している） | 増設ケーブルを正しく接続してください。 |
| 電源ユニットにAC電源が供給されていない。 | 電源ユニットにAC電源を供給してください。 |

原因となったユニットについては，最寄りの三菱電機システムサービス株式会社または当社の支社，代理店にご相
談ください。

### 15.1.5 RUN LED が点灯しない場合 (15.1.5 / 原本 p.280)

下記の項目を確認してください。

確認項目と処置方法(表・原本 p.280):

| 確認項目 | 処置方法 |
|---|---|
| CPUユニットのRUN LEDが点滅している | CPUユニットをリセットするか，一度STOP→RUNにしてください。 |
| CPUユニットのERR. LEDが点灯または点滅している | プログラミングツールでエラーの確認を行ってください。（279ページ 15.2節） |
| CPUユニットをリセットし，再度RUNにしたとき，RUN LEDが点灯した | 過大なノイズが原因と考えられます。ノイズ源に対してノイズ対策を施してください。（583ページ 付8）ノイズ対策を施しても頻繁に発生する場合は，シーケンサの部品不良や接触不良が考えられます。最寄りの三菱電機システムサービス株式会社または当社の支社，代理店にご相談ください。 |

### 15.1.6 BOOT LED が点滅した場合 (15.1.6 / 原本 p.280)

シーケンサの電源を OFF にしてから，メモリカードを抜き取り，CPU ユニットのディップスイッチの SW2 と
SW3 を ON にしてください。
電源再投入後，BOOT LED が点灯した場合，標準 ROM からのブート運転を実施します。
BOOT LED が点灯しない場合は，CPU ユニットのハードウェア異常の恐れがあります。
最寄りの三菱電機システムサービス株式会社または当社の支社，代理店にご相談ください。

## 15.2 エラー内容の確認 (15.2 / 原本 p.281-283)

- 使用するプログラミングツールのオペレーティングマニュアル

### 15.3.1 PC 書込，PC 読出 (15.3.1 / 原本 p.285)

#### (1) PC 書込 (原本 p.285)

プログラミングツールから CPU ユニットにデータが書き込めない場合は，下記の項目を確認してください。

確認項目と処置方法(表・原本 p.285):

| 確認項目 | 処置方法 |
|---|---|
| ハイパフォーマンスモデルQCPU，プロセスCPU，二重化CPUを使用している場合，ディップスイッチ1がONになっている | ディップスイッチ1をOFFにしてください。 |
| パスワードが登録されている | プログラミングツールでパスワード登録を解除してください。 |
| 書込み対象をメモリカードまたはSDメモリカードとしている状態で，メモリカードまたはSDメモリカードにライトプロテクトがかかっている | メモリカードまたはSDメモリカードのライトプロテクトを解除してください。 |
| 書込み対象をメモリカードまたはSDメモリカードとしている状態で，メモリカードまたはSDメモリカードがフォーマットされていない | メモリカードまたはSDメモリカードのフォーマットを行ってください。 |
| 書き込むデータがメモリの容量を超えている | メモリの空き容量を確保してください。書込み対象のメモリを整理してください。 |

上記の項目を確認しても PC 書込ができなかった場合は，ハードウェア異常の恐れがあります。
最寄りの三菱電機システムサービス株式会社または当社の支社，代理店にご相談ください。

#### (2) 意図せずプログラムが書き換わる (原本 p.285)

ブート運転を行っている可能性があります。プログラミングツールにてパラメータを読み出し，ブートファイ
ル設定を見直してください。
ブート運転を行っていない場合は，ハードウェア異常の恐れがあります。
最寄りの三菱電機システムサービス株式会社または当社の支社，代理店にご相談ください。
ブート運転の詳細については下記のマニュアルを参照してください。

| USB接続に切り換えて，パラメータを読み出したとき，内蔵Ethernetポート設定で“MELSOFTとの直結接続を禁止する”にチェックが入っている | パラメータを修正してください。 |
| Ethernet診断画面のコネクション別状態で，MELSOFTの直結接続が強制無効化状態になっている | 強制無効を解除してください。 |
| Ethernet診断画面のエラー履歴で，直結接続のエラーが出ている | エラーコードに対応した処置を行ってください。 |
| 接続先指定の自局詳細設定で交信のタイムチェックを延ばす，またはリトライ回数を増やすと交信できた | 交信のタイムチェック，リトライ回数を再調節してください。ケーブル，接続機器（パソコン），CPUユニットの状態を確認してください。 |
| 接続機器（パソコン）が直結接続可能な仕様ではない | ハブ経由接続にて通信を行ってください。 |

＊1 パソコン側のネットワーク接続において，Ethernet ポートが2つ以上「有効」になっている場合，直結接続で交信で
きません。直結接続を行う Ethernet ポートのみ「有効」にして，残りの Ethernet ポートは「無効」になるように，
パソコン側の設定を見直してください。

上記の項目を確認しても Ethernet 通信ができなかった場合は，ハードウェア異常の恐れがあります。

#### (3) 相手機器と Ethernet 通信できない (原本 p.289-290)

相手機器と Ethernet 通信できない場合は，下記の項目を確認してください。

確認項目と処置方法(表・原本 p.289-290):

| 確認項目 | 処置方法 |
|---|---|
| ハブでエラーが発生している | ハブのエラーを取り除いてください。＊1 |
| 接続機器（パソコン）の設定が誤っている（IPアドレスの設定／Ethernetポートの設定／ファイアウォール設定／セキュリティソフトの交信設定） | 接続機器の設定を見直してください。 |
| 通信時にCPUユニットのSD/RD LEDが点滅していない | 配線を再確認してください。 |
| IPアドレスが重複している | 接続機器のIPアドレスを，CPUユニットと重複しないように修正してください。接続機器を回線から切り離し，切り離した接続機器のIPアドレスに対してPINGを行ってください。応答があった場合は，IPアドレスが重複しているため修正してください。 |
| 電源を再投入したとき，ERR. LEDが点灯または点滅した | エラー要因を取り除いてください。（279ページ 15.2節） |
| USB接続に切換えて，パラメータを読み出したとき，内蔵Ethernetポート設定が誤っている | パラメータを修正してください。 |
| Ethernet診断画面のコネクション別状態で，MELSOFTの直結接続が強制無効化状態になっている | 強制無効を解除してください。 |
| Ethernet診断画面のエラー履歴で，直結接続のエラーが出ている | エラーコードに対応した対処を行ってください。 |
| 接続機器（パソコン）からの接続数が，オープン設定の“MELSOFT接続”の数を超えている（TCPおよびUDPそれぞれの接続数） | 接続機器（パソコン）の接続数を，オープン設定の数以内にしてください。 |
| プロトコルの指定が誤っている／Ethernet直結接続を選択している | 接続先設定を修正してください。 |
| IPアドレス，ホスト名の指定が誤っている | (上記に同じく接続先設定を修正) |
| TCP/IP接続をしている状態で，機器の電源をOFFしたことがある | TCP/IPのコネクションが使われたままになっています。1分程度待ち，CPUユニットの生存確認機能によるクローズが行われてからリトライする。コネクションの設定数を増やして，必要な分の予備のコネクションを持つようにする。 |
| 接続先指定の自局詳細設定で交信のタイムチェックを延ばす，またはリトライ回数を増やすと交信できた | 交信のタイムチェック，リトライ回数を再調節してください。ケーブル，接続機器（パソコン），CPUユニットの状態を確認してください。 |
| CPUユニット側および相手機器側の下記の設定が誤っている（ネットワークアドレス／デフォルトルータIPアドレス／サブネットマスクパターン／ルータIPアドレス／サブネットマスク） | 設定を見直してください。 |
| ルータを経由する場合で，ルータでエラーが発生している | ルータのエラーを取り除いてください。 |
| ルータを経由する場合で，ルータの設定が誤っている | ルータの設定を見直してください。 |
| CPUユニット，接続機器（パソコン），ハブ，ルータなど，回線上の機器を交換した（同じIPアドレスの機器に交換した場合） | 回線上の機器をリセットしてください。＊2 |
| ハブ，ルータを他のものに交換すると交信できた | ハブ，ルータの異常が考えられます。ハブ，ルータを交換してください。 |

＊1 スイッチングハブにパソコンや CPU ユニットを接続しなおした場合や，スイッチングハブを交換した場合は，MAC
アドレスの読み込みに時間がかかる場合があります。
その場合は，時間を置いてリトライするか，ハブの電源を再投入してください。また，ソケット通信機能により UDP
のダミー電文を送信すると，スイッチングハブが MAC アドレスを再学習することがあります。
＊2 Ethernet 上の機器は，「ARP キャッシュ」という IP アドレスと MAC アドレスの対応表を保持しています。
回線上の機器を同じ IP アドレスの機器に交換すると，「ARP キャッシュ」に保持されている MAC アドレスと，交換
した機器の MAC アドレスが不一致になるため，正常に交信できなくなる場合があります。
「ARP キャッシュ」の更新は，機器のリセットまたは，一定時間が経過すると実施されます。なお，時間は機器に
よって異なります。

上記の項目を確認しても Ethernet 通信できなかった場合は，ハードウェア異常の恐れがあります。

電源単独システム，電源二重化システムにおける電源ユニットの ERR. 端子で，検出可能な異常内容を下記
に示します。

**電源単独システム**

ERR.端子で検出可能な異常内容(表・原本 p.302・電源単独システム):

| ベースユニット | CPUユニット＊1: ベーシックモデルQCPU，ハイパフォーマンスモデルQCPU，ユニバーサルモデルQCPU | CPUユニット＊1: プロセスCPU | CPUユニット＊1: 二重化CPU |
|---|---|---|---|
| 基本ベースユニット（Q3◇B） | AC電源未入力，電源ユニットのヒューズ断，CPUユニット停止エラー（リセット時含む）が検出可能 | 同左 | (二重化CPUとの組合せ不可のため対象外) |
| マルチCPU間高速基本ベースユニット（Q3◇DB） | AC電源未入力，電源ユニットのヒューズ断，CPUユニット停止エラー（リセット時含む）が検出可能 | 同左 | (対象外) |
| 増設ベースユニット（Q6◇B） | 異常内容は検出不可（常時OFF） | 同左 | 増設不可 |
| スリムタイプ基本ベースユニット（Q3◇SB） | AC電源未入力，電源ユニットのヒューズ断，CPUユニット停止エラー（リセット時含む）が検出可能 | 同左 | 組合せ不可 |

＊1 Q00JCPU，Q00UJCPUを除く。（ERR.端子なし）

**電源二重化システム**

ERR.端子で検出可能な異常内容(表・原本 p.302・電源二重化システム):

| ベースユニット | CPUユニット＊2: ベーシックモデルQCPU，ハイパフォーマンスモデルQCPU，プロセスCPU，ユニバーサルモデルQCPU | CPUユニット＊2: 二重化CPU |
|---|---|---|
| 電源二重化基本ベースユニット（Q3◇RB） | AC電源未入力，電源ユニットのヒューズ断，CPUユニット停止エラー（リセット時含む），二重化電源ユニットの故障が検出可能 | 同左 |
| 電源二重化増設ベースユニット（Q6◇RB） | 電源故障，AC電源未入力，電源ユニットのヒューズ断が検出可能 | 電源故障，AC電源未入力，電源ユニットのヒューズ断が検出可能＊3 |
| 二重化増設ベースユニット（Q6◇WRB） | 組合せ不可 | 電源故障，AC電源未入力，電源ユニットのヒューズ断が検出可能 |

＊2 Q00JCPU，Q00UJCPUを除く。（ERR.端子なし）
＊3 二重化CPUのシリアルNo.上5桁が“09012”以降の場合のみ，増設2段目以降で使用可能です。

**備考**

電源二重化システムにおける二重化電源ユニットの故障検出はプログラミングツールを使用することもできます。
＊注15.1＊注15.2
- PC 診断による検出
- システムモニタによる検出

PC 診断，システムモニタの詳細については，下記のマニュアルを参照してください。
- 使用するプログラミングツールのオペレーティングマニュアル

＊注15.1 ベーシックモデル QCPU では，二重化電源ユニットの故障検出はできません。(対象: Basic)
＊注15.2 ハイパフォーマンスモデル QCPU，プロセス CPU 使用時は，CPU ユニットとプログラミングツールのバージョンを確
認してください。
- ハイパフォーマンスモデル QCPU（571ページ 付6.2）
- プロセス CPU（576ページ 付6.4）
(対象: High performance, Process)

## 15.4 データの退避 (15.4 / 原本 p.304-307)

トラブル発生直後に下記の情報を退避させておくことで，エラー発生の要因を解析する際に役に立ちます。
- プログラムとパラメータ
- デバイスとバッファメモリ
- システム構成
- エラー履歴

### (1) プログラムとパラメータの退避 (原本 p.304)

退避手順を下記に示します。
[オンライン]→[PC読出]

【図】PC読出操作手順図(原本 p.304)。手順:
1. (プログラム・パラメータの選択)をクリックしてください。
2. (実行ボタン)をクリックしてPC読出を実行してください。

### (2) デバイスとバッファメモリの退避 (原本 p.305)

退避手順を下記に示します。
[オンライン]→[PC読出]
ファイルレジスタを使用している場合は，ファイルレジスタも他のデバイスと同様に退避させてください。

【図】デバイス・バッファメモリ退避操作手順図(原本 p.305)。手順:
1. "デバイスメモリ" のチェックボックスをクリックしてください。
2. (詳細設定ボタン)をクリックしてください。
3. "デバイスデータ名" を入力し，退避させるデバイスにチェックを入れてください。
4. "バッファメモリ先頭入出力番号" に先頭入出力番号を入力してください。
5. (OKボタン)を押して決定後，PC読出を行ってください。

### (3) システム構成の退避 (原本 p.306)

退避手順を下記に示します。
[診断]→[システムモニタ]

【図】システム構成退避操作手順図(原本 p.306)。手順:
1. (印刷ボタンなど)をクリックしてください。
2. (実行ボタン)をクリックしてください。

### (4) エラー履歴の退避 (原本 p.307)

退避手順を下記に示します。
[診断]→[システムモニタ]

【図】エラー履歴退避操作手順図(原本 p.307)。手順:
1. (エラー履歴表示ボタン)をクリックしてください。
2. (印刷／保存ボタン)をクリックしてください。
