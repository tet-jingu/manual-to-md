## 第3章 冒頭 (原本 p.56)

CPU ユニットを立ち上げる場合の手順を説明します。
なお，プログラムとパラメータは，別途作成されているものとします。

二重化 CPU で二重化システムを構成した場合の立上げ手順については，下記マニュアルを参照してください。
- QnPRHCPU ユーザーズマニュアル（二重化システム編）

## 立上げ手順フローチャート (原本 p.56-57)

【図】CPUユニット立上げ手順フローチャート(原本 p.56-57)。開始から終了までの各工程を文章化する。

**開始**
↓
**ユニットの装着** (参照: 57ページ第4章)
ベースユニットに，システム構成に必要な以下のユニットを装着する。
- 電源ユニット
- CPU ユニット（必要に応じてメモリカード，SD メモリカード，拡張 SRAM カセットを装着する）
- インテリジェント機能ユニット／特殊機能ユニット
- ネットワークユニット
- 入出力ユニット
↓
**配線／接続** (参照: 57ページ第4章，219ページ第8章，230ページ第9章，238ページ第10章，242ページ第11章)
1) 電源ユニットに電源を配線する。
2) インテリジェント機能ユニット／特殊機能ユニット，入出力ユニットに外部機器を配線する。
3) ネットワークユニット間を配線する。
4) CPU ユニットにバッテリを接続する。
5) 基本ベースユニット－増設ベースユニット間，および増設ベースユニット－増設ベースユニット間を増設ケーブルで接続し，増設ベースユニットの段数設定を行う。
↓
**ユニットの初期設定** (参照: 115ページ第6章)
1) CPU ユニットを停止状態にする。
2) インテリジェント機能ユニット／特殊機能ユニットのスイッチ設定を行う。
3) ネットワークユニットのスイッチ設定を行う。
↓
**システムの電源投入** (参照: 115ページ第6章，189ページ第7章，57ページ第4章)
システムの下記項目を確認後，電源を投入する。
- 電源の配線
- 電源電圧
- CPU ユニットの動作状態・・・停止状態（リセット解除）
- プログラミングツールをインストールしたパソコンと CPU ユニットを接続する。
↓
（次ページへ）
↓
**パソコンの電源投入**
プログラミングツールをインストールしたパソコン（CPU ユニットと接続したパソコン）の電源を投入する。
↓
**プログラミングツールの立上げ** (参照: 使用するプログラミングツールのオペレーティングマニュアル)
1) プログラミングツールをインストールしたパソコン（CPU ユニットと接続したパソコン）でプログラミングツールを立ち上げる。
↓
**メモリのフォーマット** (参照: 使用するプログラミングツールのオペレーティングマニュアル)
プログラミングツールの「PC メモリフォーマット」で，使用するメモリをフォーマットする。＊3
↓
**パラメータ，プログラムの書込み** (参照: 使用するプログラミングツールのオペレーティングマニュアル)
プログラミングツールで作成したパラメータ，プログラムを CPU ユニットに書き込む。
↓
**システム再立上げ** (参照: 115ページ第6章)
システムの電源を OFF→ON するか，CPU ユニットのリセット操作を行う。
↓
**エラー有無の確認** (参照: 273ページ第15章)
CPU ユニットの「ERR.」LED が消灯していることを確認する。
「ERR.」LED が点灯／点滅している場合は，プログラミングツールのシステムモニタまたは診断＊1 により，エラー要因を確認し，エラー要因を取り除く。
パラメータ，プログラムに関係するエラーの場合は，パラメータ，プログラムを修正する。
↓
**CPU ユニットの RUN＊2** (参照: 115ページ第6章)
CPU ユニットを RUN 状態にし，CPU ユニットの「RUN」LED が点灯することを確認する。
↓
**終了**

## 注記 (原本 p.58)

＊1 診断には以下のものがあります。
- PC 診断
- Ethernet 診断
- CC IE Control 診断
- CC IE Field 診断
- MELSECNET 診断
- CC-Link/CC-Link/LT 診断

＊2 プログラムメモリの容量が大きい CPU ユニットでは，RUN 状態になるまでに時間がかかることがあります。

＊3 機能バージョン B 以降のベーシックモデル QCPU では，標準 RAM のフォーマットは不要ですが，標準 RAM のクリ
ア操作が必要です。標準 RAM（ファイルレジスタ）のクリア操作については，下記マニュアルを参照してください。
- Qn(H)/QnPH/QnPRHCPU ユーザーズマニュアル（機能解説・プログラム基礎編）

インテリジェント機能ユニット／特殊機能ユニット，ネットワークユニットへの配線／接続，初期設定に関する詳細は，
使用するインテリジェント機能ユニット／特殊機能ユニット，ネットワークユニットのマニュアルを参照してください。
