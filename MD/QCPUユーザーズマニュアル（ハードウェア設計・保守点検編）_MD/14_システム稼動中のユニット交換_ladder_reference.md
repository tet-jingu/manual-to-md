## 14.1 オンラインユニット交換 (14.1 / 原本 p.264-273)

オンラインユニット交換は，プロセス CPU または二重化 CPU でシステムの制御を行いながら，基本ベースユニッ
トおよび増設ベースユニットに装着されている Q シリーズのユニットを交換する機能です。＊注14.1
オンラインユニット交換を使用すると制御中に故障したユニットを同一形名のユニットに交換することができます。

- オンラインユニット交換ではユニットの追加および他のユニットへの変更を行うことはできません。
- マルチ CPU システムのプロセス CPU でオンラインユニット交換を行う場合，PC パラメータのマルチ CPU 設定で “他
  CPU でのオンラインユニット交換許可” に設定する必要があります。
  また，マルチ CPU システムを構成する CPU ユニットのバージョンに制約があります。詳細は，下記マニュアルを参
  照してください。
  QCPU ユーザーズマニュアル ( マルチ CPU システム編 )
- オンラインユニット交換は，シーケンサ外部のシステムが誤動作しないことを確認して行ってください。
- オンラインユニット交換するユニットの外部電源は，感電や稼動中のユニットの誤動作などを防ぐため，スイッチなど
  で個別に切断できる手段を設けてください。
- 以下に示す内容を確認するために実際のシステムで事前にオンラインユニット交換を実施して，交換対象でないユニッ
  トの動作に影響がないことを検証しておくことを推奨します。
  - 外部機器との接続を切断する手段，構成に誤りはないか。
  - スイッチなどの ON/OFF による影響はないか。
- 下記の着脱は，製品ご使用後，50回以内（IEC 61131-2，JIS B 3502 に準拠）としてください。なお，50回を超えた
  場合は，誤動作の原因となる恐れがあります。
  - ユニットとベースユニット

＊注14.1 ベーシックモデル QCPU，ハイパフォーマンスモデル QCPU，ユニバーサルモデル QCPU は，オンラインユニット交
換に対応していません。(対象: Basic, High performance, Universal)

### (1) オンラインユニット交換可能なシステム構成 (原本 p.265-266)

オンラインユニット交換は次の場合に行うことができます。

#### (a) オンラインユニット交換可能ユニット (原本 p.265)

オンラインユニット交換可能ユニットを下記に示します。

オンラインユニット交換可能ユニット一覧(表・原本 p.265):

| ユニット種別 | 制約 |
|---|---|
| 入力ユニット | 制約なし |
| 出力ユニット | 制約なし |
| 入出力混合ユニット | 制約なし |
| インテリジェント機能ユニット - アナログ－デジタル変換ユニット | 機能バージョンCで対応＊1 |
| インテリジェント機能ユニット - デジタル－アナログ変換ユニット | 機能バージョンCで対応＊1 |
| インテリジェント機能ユニット - 温度入力ユニット | 機能バージョンCで対応＊1 |
| インテリジェント機能ユニット - 温度調節ユニット | 機能バージョンCで対応＊1 |
| インテリジェント機能ユニット - パルス入力ユニット | 機能バージョンCで対応＊1 |

＊1 二重化 CPU 使用時，増設ベースユニットを接続している場合は，基本ベースユニットに装着されたインテリジェント
機能ユニットはオンラインユニット交換ができません。

上記以外のユニットはオンラインユニット交換を行うことができません。
また上記インテリジェント機能ユニットのオンラインユニット交換の可否および交換手順は，使用するイン
テリジェント機能ユニットのマニュアルを参照してください。

#### (b) プログラミングツールの対応バージョン (原本 p.265)

オンラインユニット交換を行うには，プログラミングツールが必要です。
プログラミングツールのバージョンについては，使用するプログラミングツールのオペレーティングマニュ
アルを参照してください。
ネットワーク経由のプログラミングツールからもオンラインユニット交換を行うことができます。

#### (c) ベースユニットの制約 (原本 p.265)

- スリムタイプ基本ベースユニット (Q3◇SB) 使用時は，オンラインユニット交換を行うことはできませ
  ん。
- 電源ユニット不要タイプの増設ベースユニット (Q5◇B) 使用時は，接続されているすべてのベースユ
  ニット上のユニットに対してオンラインユニット交換を行うことができません。
- 二重化増設ベースユニット (Q6◇WRB) 使用時は，基本ベースユニットに接続されているすべてのユニッ
  トに対してオンラインユニット交換を行うことができません。

#### (d) CPU ユニットの制御状態 (原本 p.266)

オンラインユニット交換は，停止エラーが発生していないときに実行できます。
CPU ユニットの制御状態によるオンラインユニット交換の実行可否を下記に示します。

CPUユニットの制御状態とオンラインユニット交換の可否(表・原本 p.266):

| 制御状態 | RUN状態＊1 | STOP状態 | PAUSE状態 | 停止エラー時 |
|---|---|---|---|---|
| オンラインユニット交換の可否 | 可 | 可 | 可 | 否 |

＊1 RUN状態で続行エラー発生時も含みます。

オンラインユニット交換中に CPU ユニットの制御状態を STOP/PAUSE 状態に変更してもオンラインユ
ニット交換を継続できます。ただし次の場合には，オンラインユニット交換を継続できません。
- CPU ユニットをリセットしたとき
- 停止エラーが発生したとき

#### (e) オンラインユニット交換可能ユニット数 (原本 p.266)

1回のオンラインユニット交換で交換可能なユニット数は，CPU ユニット1台あたり1ユニットです。
複数のユニットを同時に交換することはできません。

### (2) オンラインユニット交換中の制約 (原本 p.267)

オンラインユニット交換中に次の操作を行うことはできません。
- 1台のCPUユニットに対して，複数のプログラミングツールからオンラインユニット交換の要求を行う。
- オンラインユニット交換中のCPUユニットにパラメータを書き込む。

オンラインユニット交換中の CPU ユニットに対し，別のプログラミングツールからオンラインユニット交換の要求を
行った場合，下記に示すのメッセージが表示されます。
メッセージを確認のうえ，“はい” または “いいえ” を選択してください。

“はい” を選択した場合
あとから要求を行った「プログラミングツール2)」にオンラインユニット交換の操作が切り換わります。（切り換わる
前の状態から操作を継続します。）

“いいえ” を選択した場合
あとから要求したオンラインユニット交換「プログラミングツール2)」の操作が中断されます。（先に実行中のオンラ
インユニット交換「プログラミングツール1)」は継続されます。）

【図】プログラミングツール競合時の動作図(原本 p.267)。
- ■“はい”選択：プログラミングツール2)ではオンラインユニット交換の継続。プログラミングツール1)ではオンライン
  ユニット交換の実行解除。
- ■“いいえ”選択：プログラミングツール2)ではオンラインユニット交換の中断。プログラミングツール1)ではオンライン
  ユニット交換実行中の継続。

### (3) オンラインユニット交換に関する特殊リレー，特殊レジスタ (原本 p.268)

オンラインユニット交換中の情報は，特殊リレー（SM235，SM236）と特殊レジスタ（SD235）に格納され
ます。
- SM235，SM236，SD235 をモニタすることにより，該当 CPU ユニットのオンラインユニット交換の実行
  ／非実行の確認ができます。
- SM235：オンラインユニット交換フラグ（オンラインユニット交換中 ON する。）
- SM236：オンラインユニット交換後1スキャンのみ ON フラグ（オンラインユニット交換完了後，1 スキャ
  ンのみ ON する。）
- SD235：オンラインユニット交換中ユニット（オンラインユニット交換中のユニットの先頭入出力番号
  ÷10H が格納される）。457ページ 付3

SM235，SM236 の詳細は420ページ 付2を，SD235 の詳細は457ページ 付3を参照してくだ
さい。

【図】SM235/SM236/SD235タイミングチャート(原本 p.268)。読み取れる事実:
- SM235（オンラインユニット交換フラグ）：オンラインユニット交換開始でON，オンラインユニット交換完了でOFF。
- SD235（オンラインユニット交換中ユニット）：SM235がONの間，オンラインユニット交換中のユニットの先頭入出力番号÷10Hの値を保持する。
- SM236（オンラインユニット交換後1スキャンのみONフラグ）：オンラインユニット交換完了直後の1スキャンのみON。

### (5) オンラインユニット交換中に系切替えが発生した場合の操作（二重化増設ベースユニット使用時） (原本 p.272-273)

二重化 CPU で増設ベースユニットに装着されているユニットに対してオンラインユニット交換中に系切替え
が発生した場合の操作の手順について説明します。

1. 新制御系に GX Developer を接続します。
2. システムモニタにてオンラインユニット交換を行っていたユニットの状態を確認します。
   (新制御系，新待機系の SM235 でオンラインユニット交換の状態を確認できます。)
3. ユニット交換中の状態で｢オンラインユニット交換」を選択すると下記の画面が表示されます。
4. 系切替え発生前に実行していた操作を継続して行います。

- 新制御系に接続し，オンラインユニット画面の “実行” ボタンをクリックすると，下記に示すメッセージが表示される
  ことがあります。その場合，“はい” を選択してオンラインユニット交換の操作を継続してください。
- オンラインユニット交換の完了時に，下記のエラーダイアログが表示されることがありますが，オンラインユニット交
  換は正常に完了しています。

## 14.2 二重化電源ユニットの交換 (14.2 / 原本 p.274)

以下に示すフローに従って，1台故障した二重化電源ユニットをオンライン（通電中）の状態で交換します。
（他方の二重化電源ユニットは正常運転していることが前提条件です。）

- 二重化電源ユニットが1台故障した場合，早めに（14日以内を目安に）正常な二重化電源ユニットと交換してくださ
  い。
  また，故障しない場合でも，5年経過後には新しい二重化電源ユニットに交換することを推奨いたします。
- 二重化電源ユニットの交換は，69ページ 4.2.3項(1)を参照のうえ，十分に注意して行ってください。
  二重化電源ユニットのユニット固定用突起が二重化ベースユニットのユニット固定穴から外れた状態の場合，コネクタ
  部の破損によりエラーが発生します。
- 電源二重化システムを使用している場合，二重化電源ユニットの故障により「続行エラー」となります。
  正常な二重化電源ユニットと交換後，エラー解除を行ってください。＊注14.2＊注14.3
- 電源二重化システムを使用している場合，GX Developer（Version 8.17T 以降品），GX Works2 のシステムモニタ，
  または特殊リレー SM1781／特殊レジスタ SD1781 により，二重化電源ユニットの故障状態を確認することができま
  す。＊注14.2＊注14.3
  システムモニタに関する詳細については，下記マニュアルを参照してください。
  使用するプログラミングツールのオペレーティングマニュアル

＊注14.2 ベーシックモデル QCPU では，二重化電源ユニットの故障検出はできません。(対象: Basic)
＊注14.3 ハイパフォーマンスモデル QCPU，プロセス CPU をプログラミングツールで使用する場合は，CPU ユニットとプログ
ラミングツールのバージョンを確認してください。（569ページ 付6）(対象: High performance, Process)
