## 第7章 冒頭 (原本 p.191)

シーケンサシステムに使用できる電源ユニット（Qシリーズ電源ユニット，スリムタイプ電源ユニット，二重化電
源ユニット，AnS/Aシリーズ電源ユニット）の仕様および選定について説明します。

## 7.1 各部の名称と設定 (7.1 / 原本 p.191-196)

各電源ユニットの各部の名称について説明します。

### Q61P-A1，Q61P-A2，Q61P，Q62P，Q63P，Q64P，Q64PN，Q61P-D，Q61SP (原本 p.191-193)

【図】電源ユニット外観図(原本 p.191)。以下の電源ユニットの前面図とNo.1)〜17)の部品配置:
- ■Q61P-A1（AC100-120V入力，DC5V 6A出力）
- ■Q61P-A2（AC200-240V入力，DC5V 6A出力）
- ■Q61P（AC100-240V入力，DC5V 6A出力）
- ■Q62P（AC100-240V入力，DC5V 3A/DC24V 0.6A出力）
- ■Q63P（DC24V入力，DC5V 6A出力）
- ■Q64P（AC100-120V/AC200-240V入力，DC5V 8.5A出力）
- ■Q64PN（AC100-240V入力，DC5V 8.5A出力）
- ■Q61P-D（AC100-240V入力，DC5V 6A出力） ■Q61SP（AC100-240V入力，DC5V 2A出力）

各部の名称と用途(表・原本 p.192):

| No. | 名称 | 用途 |
|---|---|---|
| 1) | 「POWER」LED＊2 | 点灯(緑)：正常（DC5V出力，20ms以内の瞬停時）。消灯：AC電源は入力されているが電源ユニットが故障(DC5V異常，過負荷，内部回路故障，ヒューズ断時)／AC電源の未入力／停電(20ms以上の瞬停時を含む) |
| 2) | 「POWER」LED | 点灯(緑)：正常（DC5V出力，10ms以内の瞬停時）。消灯：DC電源は入力されているが，電源ユニットが故障(DC5V異常，過負荷，内部回路故障，ヒューズ断時）／DC電源の未入力／停電（10ms以上の瞬停時を含む） |
| 3) | 「LIFE」LED | 点灯(緑)：使用開始時。点灯(橙)：ユニット残存寿命約50％。点滅(橙)：5秒点灯1秒消灯＝ユニット寿命到達まで残り約1年／0.5秒間隔＝ユニット寿命到達まで残り約半年。消灯：ユニット寿命到達時／周囲温度範囲外（ユニット周囲温度が仕様値以上となり，かつ寿命検出機能が停止した場合）。点灯(赤)：周囲温度範囲外（ユニット周囲温度が仕様値以上の場合）。点滅(赤)：機能異常時（1秒間隔） |
| 4) | ERR.端子 | システムが正常に稼動したときONする。電源未入力時，CPUユニット停止エラー（リセット時を含む）発生時，ヒューズ断時にOFF（開放）する。マルチCPUシステム構成時は，1台でも停止エラーが発生するとOFFする。増設ベースユニットに装着した場合は，常時OFF。 |
| 5) | LIFE OUT端子 | 寿命を検出（残存寿命1年以内の場合のみ）した場合はOFF（開放）する。寿命診断異常（検出処理異常を含む）を検出した場合はフリッカOFF（開放）する。＊1周囲温度範囲外を検出した場合はフリッカOFF（開放）する。ユニット内部のウォッチドッグタイマが異常を検出した場合はOFF（開放）する。増設ベースユニットに装着した場合も，上記4点の動作が可能。 |
| 6) | FG端子 | プリント基板上の遮蔽パターンと接続された接地端子 |
| 7) | LG端子 | 電源フィルタの接地。AC入力の場合，入力電圧の1/2の電位を持っている。 |
| 8) | +24V,24G端子 | 出力ユニット内部にDC24Vが必要なユニットへの供給用。（外部配線にてユニットへ供給） |
| 9) | 端子ネジ | M3.5×7ネジ |
| 10) | 端子カバー | 端子台の保護カバー |
| 11) | ユニット固定ネジ穴 | ユニットをベースユニットに固定するネジ穴。M3×12ネジ（ユーザ手配）(締付けトルク範囲0.36～0.48N･m) |
| 12) | ユニット装着用レバー | ベースユニットへユニットを装着するときに使用する。 |
| 13) | 電源入力端子 | Q61P-A1用電源の入力端子でAC100Vの交流電源を接続する。 |
| 14) | 電源入力端子 | Q61P-A2用電源の入力端子でAC200Vの交流電源を接続する。 |
| 15) | 電源入力端子 | Q61P，Q61P-D，Q61SP，Q62P，Q64PN用電源の入力端子でAC100VからAC200Vの交流電源を接続する。 |
| 16) | 電源入力端子 | Q63P用電源の入力端子でDC24Vの直流電源を接続する。 |
| 17) | 電源入力端子 | Q64P用電源の入力端子でAC100V/AC200Vの交流電源を接続する。 |

＊1 フリッカOFFとはOFF，ONを1秒間隔で3回繰り返した後，OFF（開放）することを指します。
＊2 増設ベースユニットを含むシステムでQ61P-Dを使用する場合は，増設ベースユニット上のQ61P-DのPOWER
LEDが，電源OFF時に薄く赤点灯することがありますが異常ではありません。

- Q61P-A1 は AC100V 入力専用です。
  AC200V を入力すると Q61P-A1 が故障しますので注意してください。
- Q64P は入力レンジを AC100V と AC200V で自動切替えしています。
  よって，中間電圧（AC133～169V）で使用できません。
  使用した場合は，CPU ユニットが正常に動作しないことがあります。
- 接地端子 LG，FG は必ず D 種接地（第三種接地）以上で接地してください。
- Q61P-A1，Q61P-A2，Q61P-D，Q61P，Q62P，Q63P，Q64P，Q64PN を増設ベースユニットに装着した場合，
  ERR. 端子によりシステムの異常を検出することはできません。
  （ERR. 端子は常時 OFF）
- ERR. 接点および LIFE OUT 接点用のケーブルは制御盤内に配置し，長さは 30ｍ 以下としてください。
- 電源入力端子 (L) 側にヒューズが内蔵されているので，電源ユニットに供給する電源が接地されている場合は，接地側
  の電源を N 端子に，非接地側の電源を L 端子に接続してください。
- DC24V 出力用のケーブルは，制御盤内に配置し，長さを 30m 以下としてください。

Q61P-A1/Q61P-A2への供給電源電圧誤りの影響(表・原本 p.193):

| 電源ユニット形名 | AC100V入力時 | AC200V入力時 |
|---|---|---|
| Q61P-A1 | 正常動作 | 電源ユニットが故障する。 |
| Q61P-A2 | 電源ユニットは故障しない。ただし，CPUユニットは動作不可。 | 正常動作 |

| 11) | ユニット装着用レバー | ベースユニットへユニットを装着するときに使用する。 |

＊3 電源投入直後および電源断直後に，一瞬「POWER」LED が赤点灯しますが，二重化電源ユニットは異常ではありま

### 7.2.2 仕様について (7.2.2 / 原本 p.212)

仕様に記載された項目の詳細について下記に示します。

#### (1) 過電流保護 (原本 p.212)

DC5V，DC24V 回路に仕様値以上の電流が流れると，過電流保護装置が回路を遮断し，システムをストップ
させます。電源ユニットの LED 表示は，電圧低下により消灯またはうす暗く緑点灯します。（ただし，二重化
電源ユニットの場合，電圧低下により消灯または赤点灯します。）
本装置が動作した場合は入力電源を OFF し，電流容量の不足，短絡などの要因を取り除いたのちに数分後 ON
させて，システムを立ち上げてください。電流値が正常値になると，システムはイニシャルスタートします。

#### (2) 過電圧保護 (原本 p.212)

DC5V の回路に DC5.5V 以上の過電圧が印加されると，過電圧保護装置が回路を遮断し，システムをストップ
させます｡電源ユニットの LED 表示は消灯します。
システムの再スタートは，入力電源を OFF したのち，数分後に ON してください。システムがイニシャルス
タートで立ち上がります。システムが立ち上がらず，LED 表示が消灯のまま（二重化電源ユニットの場合，赤
点灯）の場合は，電源ユニットの交換が必要になります。

#### (3) 許容瞬停時間 (原本 p.212)

AC 入力電源の場合
- 20ms 以内の瞬停時は，AC ダウン検出したのち，演算処理を中止しますが，瞬停解除後に継続運転しま
  す。
- 20ms を超える瞬停時は，電源の負荷によって継続運転する場合とイニシャルスタートする場合がありま
  す。継続運転する場合の動作は，20ms 以内の瞬停時の動作と同じになります。
- AC入力ユニット(QX10など)のAC供給を電源ユニットと同一にすることで，接続されたセンサのON状態
  が，瞬停によって OFF 状態になるのを防げます。
  ただし，AC ラインに電源ユニットと AC 入力ユニットのみを接続している場合，AC 入力ユニット内部の
  コンデンサによって，電源ユニットの AC ダウン検出が遅れることがあります。
  AC ダウン検出の遅れを防ぐために，AC 入力ユニット一台につき，30mA 程度の負荷を AC ラインに接
  続するようにしてください。
- 二重化電源ユニットを 2 台装着して運転している場合，片側の AC 入力電源のみ 20ms 以上の瞬停が発生し
  てもイニシャルスタートすることはありません。
  ただし，両方の AC 入力電源の瞬停が同時に 20ms 以上発生した場合には，イニシャルスタートする場合
  があります。

DC 入力電源の場合
- 10ms＊1 以内の瞬停時は，DC24V ダウン検出したのち，演算処理を中止しますが，瞬停解除後に継続運転
  します。
- 10ms＊1 を超える瞬停時は，電源の負荷によって継続運転する場合とイニシャルスタートする場合があり
  ます。継続運転する場合の動作は，10ｍｓ 以内の瞬停時の動作と同じになります。

＊1 DC24V 入力時です。DC24V 以下では 10ms 以下となります。

#### (4) 突入電流 (原本 p.212)

電源遮断直後（5 秒以内）に電源を再投入したときは，規定値を超える突入電流（2ms 以下）が流れる場合が
あります。電源を再投入するときは，遮断後，5 秒以上経過してから投入するようにしてください。
外部回路のヒューズやブレーカを選定する場合には，溶断・検知特性および上記事項を考慮の上，設計してく
ださい。

### 7.2.3 電源ユニットの選定 (7.2.3 / 原本 p.213-216)

電源ユニットの選定は，その電源ユニットにより供給されるベースユニット，CPU ユニット，各入出力ユニット，
インテリジェント機能ユニット，特殊機能ユニット，周辺機器の合計消費電流により行います。
ベースユニットの DC5V 内部消費電流は，219ページ 第8章を参照してください。
入出力ユニット，インテリジェント機能ユニット，特殊機能ユニット，周辺機器の DC5V 内部消費電流については，
各ユニットのマニュアルを参照してください。
また，ユーザ手配の機器については，各機器のマニュアルを参照してください。

#### (1) ベースユニットが Q3◇B，Q3◇DB，Q6◇B の場合 (原本 p.213)

＊1：基本ベースユニットに装着します。

ベースユニット (Q3◇B，Q3◇DB，Q6◇B) 上の消費電流は，Qシリーズ電源ユニットのDC5V定格出力電流
を超えないようにしてください。

Q65Bなど)＋CPUユニット＊1(Q02(H)CPU，Q06HCPUなど)＋入出力ユニット(QX10，QY10など)＋
インテリジェント機能ユニット(Q64AD，QJ71LP21-25など)＋周辺機器(CPUユニットとパソコンとの接続用)など。

##### (a) 増設ベースユニット (Q5◇B，QA1S5◇B) を使用する場合の注意事項

Q5◇B，QA1S5◇B を使用すると，DC5V 電源は基本ベースユニット上の電源ユニットから増設ケーブルを
通して供給されます。
したがって Q5◇B，QA1S5◇B を使用するときは次の点に注意してください。
- 基本ベースユニットに装着する電源ユニットの DC5V 定格出力電流は，Q5◇B，QA1S5◇B 上で使用す
  る DC5V もカバーできるものを選定してください。
  たとえば，基本ベースユニット上の消費電流が 3.0A，Q5◇B，QA1S5◇B 上の消費電流が 1.0A になる
  場合，下記に示す電源ユニットを基本ベースユニットに装着する必要があります。

DC5V定格出力電流と対応形名(表・原本 p.213、3.0A+1.0A=4.0A必要時の選定例):

| DC5V定格出力電流 | 形名 |
|---|---|
| 6.0A | Q61P-A1，Q61P-A2，Q61P，Q61P-D，Q63P |
| 3.0A | Q62P |
| 8.5A | Q64P，Q64PN |

- Q5◇B，QA1S5◇B へは増設ケーブルを通して DC5V が供給されますので増設ケーブルで電圧降下が発
  生します。
  Q5◇B，QA1S5◇B の “IN” コネクタの電圧が DC4.75V 以上になるように電源ユニットおよび増設
  ケーブルの選定を行う必要があります。
  電圧降下の詳細は 86 ページ 4.3.4 項を参照してください。

必要出力電流の目安(表・原本 p.213):

| DC5V定格出力電流 | 形名 |
|---|---|
| 6.0A | Q61P-A1，Q61P-A2，Q61P，Q61P-D，Q63P |
| 8.5A | Q64P，Q64PN |

#### (b) 電圧降下を少なくする工夫 (原本 p.214)

増設ケーブルの電圧降下を少なくするには次の方法が有効です。
1. ユニット装着位置の変更
   消費電流の大きいユニットは，基本ベースユニットに装着してください。
   消費電流の小さいユニットは，増設ベースユニット (Q5◇B) に装着してください。
2. 短い増設ケーブルを使用
   増設ケーブルが短いほど抵抗値が小さくなり，電圧降下も小さくなります。
   できる限り短い増設ケーブルを使用してください。

#### (2) ベースユニットが Q3◇SB の場合 (原本 p.214)

スリムタイプ基本ベースユニット (Q3◇SB) 上の消費電流は，スリムタイプ電源ユニット (Q61SP) の DC5V
定格出力電流を超えないようにしてください。

スリムタイプ電源ユニットのDC5V定格出力電流(表・原本 p.214):

| DC5V定格出力電流 | 形名 |
|---|---|
| 2.0A | Q61SP |

【図】スリムタイプ電源ユニット構成図(原本 p.214)。スリムタイプ電源ユニット(Q61SP)＋スリムタイプ基本ベースユニット
(Q32SB,Q33SB,Q35SB)＋CPUユニット(Q02(H)CPU，Q06HCPUなど)＋周辺機器(CPUユニットとパソコンとの
接続用)など＋入出力ユニット(QX10，QY10など)＋インテリジェント機能ユニット(Q64AD，QJ71LP21-25など)。

#### (3) ベースユニットが Q3◇RB，Q6◇RB の場合 (原本 p.215)

＊2：電源二重化基本ベースユニット (Q3◇RB) に装着します。

電源二重化システムを構成した場合，一方の二重化電源ユニットの故障によって，故障した二重化電源ユニットの交換中
は，他方の二重化電源ユニットのみで運転することになります。そのため，電源二重化ベースユニット
(Q3◇RB/Q6◇RB/Q6◇WRB) 上の消費電流は，二重化電源ユニット1台分のDC5V定格出力電流（8.5A）を超えない
ようにしてください。

##### (a) 増設ベースユニット (Q5◇B) を使用する場合の注意事項

Q5◇B を使用すると，DC5V 電源は電源二重化基本ベースユニット (Q3◇RB) 上の二重化電源ユニットから
増設ケーブルを通して供給されます。
したがって Q5◇B を使用するときは次の点に注意してください。
- Q3◇RB上の消費電流とQ5◇B上の消費電流の和が，二重化電源ユニット1台分のDC5V定格出力電流を
  超えないようにしてください。
- Q5◇B へは増設ケーブルを通して DC5V が供給されますので増設ケーブルで電圧降下が発生します。
  Q5◇B の “IN” コネクタの電圧が DC4.75V 以上になるように増設ケーブルの選定を行う必要がありま
  す。
  電圧降下の詳細は 86 ページ 4.3.4 項を参照してください。

二重化電源ユニットのDC5V定格出力電流(表・原本 p.215):

| DC5V定格出力電流 | 形名 |
|---|---|
| 8.5A | Q63RP，Q64RPN，Q64RP |

##### (b) 電圧降下を少なくする工夫 (原本 p.215)

1. ユニット装着位置の変更
   消費電流の大きいユニットは，電源二重化基本ベースユニット (Q3◇RB) に装着してください。
   消費電流の小さいユニットは，増設ベースユニット (Q5◇B) に装着してください。
2. 短い増設ケーブルを使用

   できる限り短い増設ケーブルを使用してください。

### 7.2.4 供給電源の電源容量に関する注意事項 (7.2.4 / 原本 p.216)

電源ユニットに対して電源を供給する場合は，電源容量が十分大きい供給電源を選定してください。
（目安として，AC 電源ユニットは 2 倍以上，DC 電源ユニットは 4 倍以上を推奨します。）

#### (1) Q64RP，Q64P 使用時 (原本 p.216)

Q64RP および Q64P は定格入力電圧波形を自動認識して，AC100V/200V を切替えています。
電源容量が十分でない供給電源を選定した場合には，AC200V 系の電源投入時に，電源ユニットが故障する恐
れがあります。

### 7.2.5 寿命検出電源ユニットについて (7.2.5 / 原本 p.217-220)

寿命検出電源ユニットは，ユニット内部でユニットの残存寿命を推定して表示できるユニットです。
ユニットの残存寿命は，ユニット前面の「LIFE」LED の状態，または LIFE OUT 端子の ON/OFF で確認できます。

#### (1) 稼動時の LED 表示とユニット動作状態 (原本 p.217)

稼動時の LED 表示状態とユニット動作状態を下記に示します。

LED表示とユニット動作状態(表・原本 p.217):

| POWER LED | LIFE LED | LIFE OUT端子 | ユニット動作状態 |
|---|---|---|---|
| 消灯 | 消灯 | OFF | 電源ユニットの故障／AC電源の未入力／停電（20ms以上の瞬停時を含む） |
| 緑点灯 | 緑点灯 | ON | ユニット正常 |
| 緑点灯 | 橙点灯 | ON | ユニット正常（残存寿命約50％）＊1 |
| 緑点灯 | 橙点滅（5秒点灯，1秒消灯） | OFF | ユニット正常（残存寿命約1年）＊1 |
| 緑点灯 | 橙点滅（0.5秒間隔） | OFF | ユニット正常（残存寿命約半年）＊1 |
| 緑点灯 | 消灯 | OFF | 寿命到達 |
| 緑点灯 | 赤点灯 | OFF，ONを1秒間隔で3回繰り返した後OFF | 周囲温度範囲外（仕様値以上の温度となった場合） |
| 緑点灯 | 赤点滅（1秒間隔） | OFF，ONを1秒間隔で3回繰り返した後OFF | 機能異常（ユニット内部の寿命診断回路が異常となり，正常な処理が不可能な状態） |
| 緑点灯 | 消灯 | OFF | 周囲温度範囲外（仕様値以上の温度となり，かつ寿命検出が停止した場合） |
| 橙点滅 | 消灯 | OFF | ユニット内部のウォッチドッグタイマが異常を検出 |

＊1 ユニットの残存寿命は，使用する周囲温度によって変動します。
（周囲温度が10℃上昇した場合，ユニットの残存寿命は1/2となります。）

#### (2) LIFE OUT 端子による寿命の監視 (原本 p.217-219)

LIFE OUT 端子の出力を使用して寿命を監視する方法として下記の2つを示します。
- 外部表示機器に接続して監視する
- 入力ユニットに取り込み，GOT で監視する

##### (a) 外部表示機器に接続して確認する方法 (原本 p.218)

LIFE OUT 端子を外部表示機器（外部 LED など）に接続することで，ユニットの残り寿命が 1 年以下となっ
たときに外部表示機器が OFF となります。
外部表示機器が OFF となった時点で，制御盤内の Q61P-D の LIFE LED により残存寿命を確認できます。

【図】外部表示機器接続例(原本 p.218)。制御盤内のQ61P-DのLIFE OUT端子を外部LEDに接続。
LIFE LEDが橙点灯→残り寿命が1年以下。

##### (b) 入力ユニットに取り込み，GOT で確認する方法 (原本 p.218-220)

LIFE OUT 端子の状態を入力ユニットに取り込むことで，シーケンスプログラムで寿命を監視できるように
なります。
この方法を使用して GOT で電源ユニットの寿命を監視する場合の使用例を下記に示します。

**1）システム構成 (原本 p.218)**

システム構成のデバイス割付(表・原本 p.218):

| 形名 | 先頭XY |
|---|---|
| Q02HCPU | ― |
| QX40 | 0000H |

【図】システム構成図(原本 p.218)。Q61P-D＋QX40(LIFE OUT端子接続)＋Q02HCPU＋GOT。

Q61P-D の寿命検出機能が故障している場合，起動時に LIFE OUT 端子が3回ON，OFFを繰返します。
ご使用のシステムによっては，Q61P-D の起動からシーケンスプログラムが動作開始するまでの遅延時間が原因で，起動
時の LIFE OUT 端子の3回のON，OFFが入力ユニットに取り込めない場合があります。
本プログラム例ではこのような場合，起動時に寿命検出機能が故障していても残存寿命1年以下と判断され，M11 が ON
になります。

**2）プログラム条件 (原本 p.219)**

電源監視のプログラムにて使用するデバイスを下記に示します。

出力デバイス(表・原本 p.219):

| 信号名 | デバイス | 機能 |
|---|---|---|
| 監視クリア指令 | X0F | 寿命監視処理をリセットする |
| 寿命警告信号 | M11 | 寿命監視により，Q61P-Dの残存寿命が1年以下とされたときにONする |
| 異常発生信号 | M12 | 寿命監視によりQ61P-Dの寿命検出機能が故障しているとされたときにONする |

内部使用デバイス(表・原本 p.219):

| 信号名 | デバイス | 機能 |
|---|---|---|
| LIFE OUT信号 | X00 | Q61P-DのLIFE OUT端子の状態 |
| 監視クリア要求 | M0 | 寿命監視処理をリセットするための内部信号 |
| 監視開始フラグ | M1 | LIFE OUT端子のOFFを検出するための内部信号 |
| 時間監視フラグ | M2 | LIFE OUT端子のON/OFF回数をカウントするための内部信号 |
| ON/OFF監視タイマ | T0 | このタイマの動作中にLIFE OUT端子のON/OFF回数をカウントする（6秒） |
| ON/OFF回数カウンタ | D100 | LIFE OUT端子がON/OFFした回数をカウントする |

**3）プログラム例 (原本 p.220)**

使用デバイスは上記(2)の表のとおり。ニモニックは以下のとおり(6秒間監視して，OFFのままなら寿命1年以下，
OFF→ONしただけなら監視続行，繰返しOFF/ONしたなら異常発生と判定する)。

```
* イニシャル
LD    SM402
SET   M0

* 監視状態クリア指令
LDP   X0F
SET   M0

* 監視状態クリア処理
LD    M0
RST   M11
RST   M12
SET   M1
RST   M0

* LIFE OUT監視
LD    M1
ANI   X0
MOV   K0    D100
MOV   K0    T0
SET   M2
RST   M1

LD    M2
OUT   T0    K60          ；6秒間監視する

LDP   X0
INC   D100

LD    T0
AND=  K0    D100
SET   M11                ；OFFのままなら寿命1年以下

LD    T0
AND=  K1    D100
SET   M1                 ；OFF→ONしただけなら，監視続行

LD    T0
AND<= K2    D100
SET   M12                ；繰返しOFF/ONしたなら異常発生

LD    T0
RST   M2

END
```
