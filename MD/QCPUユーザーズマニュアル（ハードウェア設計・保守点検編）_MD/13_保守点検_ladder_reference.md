## 13.3 バッテリの交換手順 (13.3 / 原本 p.253-259)

### 13.3.1 CPU ユニットのバッテリの交換手順 (13.3.1 / 原本 p.253-258)

CPU ユニットのバッテリに寿命がきたら次の手順によりバッテリを交換してください。

バッテリをはずす前には，シーケンサの電源を10分以上ONにしてください。
バッテリをはずしてもコンデンサにより多少の時間はメモリバックアップしておりますが，交換時間が停電保持時
間を超えますとメモリ内容が消えることがありますので手早く交換してください。

#### (1) ベーシックモデル QCPU の Q6BAT バッテリの交換手順 (原本 p.253)

停電保持時間：3分

【図】ベーシックモデルQCPUのQ6BATバッテリ交換手順図(原本 p.253)。手順:
1. SM51をモニタして，ON/OFFを確認 → 0ビット目がOFFの場合はバッテリの交換へ進む。SD52をモニタして，0ビット目がONか確認 → 0ビット目がONの場合はCPUユニットのバッテリの不良。
2. プログラム，データのバックアップを行う
3. シーケンサの電源をOFFする
4. CPUユニット正面のカバーを開ける
5. 使用中のバッテリをホルダから抜き取る
6. 新しいバッテリを正しい方向でホルダに挿入し，リードコネクタをコネクタに接続する
7. CPUユニット正面のカバーを閉じる
8. シーケンサの電源をONする
完了

#### (2) ハイパフォーマンスモデル QCPU，プロセス CPU，二重化 CPU，ユニバーサルモデル QCPU の Q6BAT バッテリの交換手順 (原本 p.254)

停電保持時間：3分

＊1 バッテリコネクタを取りはずすときには，バッテリケーブルを傷つけないようにコネクタ部を持って引き抜いてくだ
さい。

【図】ハイパフォーマンスモデルQCPU等のQ6BATバッテリ交換手順図(原本 p.254)。手順:
1. SM51をモニタして，ON/OFFを確認 → SD52をモニタして，0ビット目がONか確認 → 0ビット目がONの場合はCPUユニットのバッテリの不良、0ビット目がOFFの場合はバッテリの交換へ進む。
2. プログラム，データのバックアップを行う
3. シーケンサの電源をOFFする
4. CPUユニットをベースユニットから取りはずす
5. CPUユニット底部のカバーを開ける
6. バッテリコネクタを取りはずし，使用中のバッテリをホルダから抜き取る＊1
7. 新しいバッテリを正しい方向でホルダに挿入し，リードコネクタをコネクタに接続する
8. CPUユニット底部のカバーを閉じる
9. CPUユニットをベースユニットに取り付ける
10. シーケンサの電源をONする
完了

#### (3) Q7BATN/Q7BAT バッテリの交換手順 (原本 p.255)

停電保持時間：3分

＊1 バッテリコネクタを取りはずすときには，バッテリケーブルを傷つけないようにコネクタ部を持って引き抜いてくだ
さい。
＊2 取り付ける際には，Q7BATN-SET/Q7BAT-SET と CPU ユニットの間に，バッテリケーブルを挟み込まないよう
注意してください。

【図】Q7BATN/Q7BATバッテリ交換手順図(原本 p.255)。手順:
1. プログラム，データのバックアップを行う
2. シーケンサの電源をOFFする
3. CPUユニットをベースユニットから取りはずす
4. CPUユニット底部のバッテリホルダを取りはずす
5. バッテリコネクタを取りはずし，使用中のQ6BAT/Q7BATN/Q7BATをホルダから抜き取る＊1
6. 交換するバッテリの形名を確認
   - Q6BAT→Q7BATN/Q7BATに交換の場合: Q7BATN/Q7BATとCPUユニットのバッテリコネクタを接続し，バッテリホルダのコネクタ止めにセットする → バッテリホルダをCPUユニットに取り付ける＊2
   - Q7BATN/Q7BAT→Q7BATN/Q7BATに交換の場合: バッテリホルダ側面の片側のツメをはずしてホルダを2つに分解し，Q7BATN/Q7BATを抜き取る → 新しいQ7BATN/Q7BATを正しい方向でホルダに挿入し(Q7BATNの場合，図のように少し傾けて挿入する)，バッテリケーブルがホルダ接続部分の穴より出るように，バッテリホルダを組み合わせる(カチッと音がするまで押し込む)
7. CPUユニットをベースユニットに取り付ける
8. シーケンサの電源をONする
9. SM51をモニタして，ON/OFFを確認 → SD52をモニタして，0ビット目がONか確認 → 0ビット目がONの場合はQ7BATN/Q7BATバッテリの不良、0ビット目がOFFの場合は完了
完了

#### (4) Q8BAT バッテリの交換手順 (原本 p.256-257)

停電保持時間：3分

＊1 バッテリコネクタを取りはずすときには，バッテリケーブルを傷つけないようにコネクタ部を持って引き抜いてくだ
さい。
＊2 ユニット取付け位置の詳細については，下記を参照してください。58ページ 4.1.2項
＊3 Q8BAT 接続ケーブルは，クランプによる固定処理を行ってください。
クランプによる固定処理をしないと，ケーブルのふらつきや移動，不注意の引っ張りなどにより，Q8BAT 接続カ
バー，コネクタおよびケーブルを破損する恐れがあります。
＊4 Q8BAT 接続ケーブルは，最小曲げ半径として10mm以上を確保してください。
曲げ半径が10mm未満の場合は，特性劣化，断線などにより誤動作する恐れがあります。

【図】Q8BATバッテリ交換手順図(原本 p.256-257)。手順:
1. プログラム，データのバックアップを行う
2. シーケンサの電源をOFFする
3. CPUユニットをベースユニットから取りはずす
4. CPUユニット底部のカバー／バッテリホルダを取りはずす
5. バッテリコネクタを取りはずし，使用中のQ6BAT/Q7BATN/Q7BATをホルダから抜き取る＊1
6. 交換するバッテリの形名を確認
   - Q6BAT/Q7BATN/Q7BAT→Q8BATに交換の場合(①): Q8BAT接続ケーブルとCPUユニットのコネクタを接続する → Q8BAT接続用カバーをCPUユニットに取り付ける → Q8BATを盤に取り付ける＊2（取り付けネジによる固定とDINレールによる固定が可能）→ Q8BATにQ8BAT接続ケーブルを接続する
   - Q8BAT→Q8BATに交換の場合(②): Q8BATを盤から取りはずす → Q8BATからQ8BAT接続ケーブルを取りはずす → 新しいQ8BATを盤に取り付ける＊2（取り付けネジによる固定とDINレールによる固定が可能）→ 新しいQ8BATにQ8BAT接続ケーブルを接続する
7. 盤にQ8BAT接続ケーブルを固定する＊3
8. CPUユニットをベースユニットに取り付ける
9. シーケンサの電源をONにする
10. SM51をモニタして，ON/OFFを確認 → SD52をモニタして，0ビット目がONか確認 → 0ビット目がONの場合はQ8BATの不良、0ビット目がOFFの場合は完了
完了

（次ページへ継続する構成で、①②の分岐は前ページ・後ページにまたがって図示されている。）

### バッテリ交換に関する注意事項 (原本 p.258)

- バッテリ交換後，前面カバー裏側のシールに次回交換日付を記入してください。
  次回交換日付は，バッテリ寿命を目安に余裕のある日付にしてください。（537ページ 付4.2）
- CPU ユニットのバッテリを交換する場合は，次の点に注意してください。
  - 交換作業は，プログラミングツールにて CPU ユニットのデータをバックアップしてから開始してください。
  - 二重化 CPU のバッテリ交換は，制御系から待機系へのメモリコピー機能でプログラムなどのメモリをバック
    アップし，系切替え機能で待機系状態となった CPU ユニットに対して行ってください。
    制御系から待機系へのメモリコピー機能，系切替え機能については，下記マニュアルを参照してください。
    QnPRHCPU ユーザーズマニュアル（二重化システム編）
  - MELSEC-Q シリーズを UL 認定製品としてお使いになる場合は，Q6BAT，Q7BATN，Q7BAT，Q8BAT の交
    換は保全者が行ってください。
    ここで，保全者とは，適切な教育・訓練を受け，業務遂行上の危険を認知し，回避できる実務経験者を指しま
    す。

【図】CPU取扱上の注意シール(原本 p.258)。CPUユニット前面(RS-232/USB/STOP RUN/RESET L.CLR/
MODE/RUN/ERR./USER/BAT./BOOT/ON SW 1〜5)に貼付されたシールの記載内容:
「CPU取扱上の注意 Precautions ・電池は3分以内に交換して下さい。Replace the battery within 3 minutes
・次回交換日付 Date for next battery replacement」形名例：BD990D999H012

### 13.3.2 SRAM カードのバッテリの交換手順 (13.3.2 / 原本 p.259-261)

SRAM カードのバッテリ交換は次の手順で行ってください。

#### (1) Q2MEM-1MBSN，Q2MEM-1MBS，Q2MEM-2MBSN，Q2MEM-2MBS のバッテリの交換手順 (原本 p.259)

【図】SRAMカード(Q2MEM-1MBSN等)バッテリ交換手順図(原本 p.259)。手順:
1. プログラム，データのバックアップを行う
2. シーケンサの電源がONの状態でCPUユニットの前面カバーを開く
3. SRAMカードから電池ホルダを引き出す
4. マイナスドライバなどで電池ホルダ固定スイッチをLOCKの位置からはずす（RELEASE方向）
5. 使用中のバッテリを電池ホルダからはずす
6. 新しいバッテリを正しい方向で電池ホルダにセットする（＋を手前にしてください。）
7. 電池ホルダ固定スイッチがLOCKの位置にあることを確認する＊
8. 電池ホルダをSRAMカードにしっかり挿入する
9. エラーの解除を行う（388ページ 付1.10）
10. SM52をモニタして，ON/OFFを確認 → SD52をモニタして，1,2ビット目がONか確認 → 1,2ビット目がONの場合はSRAMカードのバッテリの不良、1,2ビット目がOFFの場合は完了
完了

＊：電池ホルダ固定スイッチは，電池ホルダをはずすと自動的にLOCKの位置になります。
その状態で，電池ホルダを奥まで挿入してください。

#### (2) Q3MEM-4MBS，Q3MEM-8MBS のバッテリの交換手順 (原本 p.260)

【図】SRAMカード(Q3MEM-4MBS等)バッテリ交換手順図(原本 p.260)。手順:
1. プログラム,データのバックアップを行う
2. シーケンサの電源がONの状態でCPUユニットのメモリカード保護カバーをはずす（上部と下部の固定爪を押しながら外す）
3. SRAMカードから電池ホルダを引き出す
4. マイナスドライバなどで電池ホルダ固定スイッチをLOCKの位置からはずす（LOCK解除）
5. 使用中のバッテリを電池ホルダからはずす
6. 新しいバッテリを正しい方向で電池ホルダにセットする（バッテリは＋（プラス）を上にして装着する）
7. 電池ホルダをSRAMカードにしっかり挿入する
8. 電池ホルダ固定スイッチをLOCKの位置にする
9. メモリカード保護カバーをCPUユニットに装着する
10. エラーの解除を行う（388ページ 付1.10）
11. SM52をモニタして，ON/OFFを確認 → SD52をモニタして，1,2ビット目がONか確認 → 1,2ビット目がONの場合はSRAMカードのバッテリの不良、1,2ビット目がOFFの場合は完了
完了

### SRAMカードのバッテリ交換に関する注意事項 (原本 p.261)

SRAM カードのバッテリを交換する場合は，次の点に注意してください。
- SRAM カードのバッテリ交換は，データを保持するためにシーケンサの電源が ONの状態で SRAMカードを装着した状
  態で行ってください。
- 交換作業は，プログラミングツールにて CPU ユニットのデータをバックアップしてから開始してください。
- 交換作業は，シーケンサの電源が ON の状態で行うため，感電しないように十分注意して行ってください。
- SRAM カードから電池ホルダを取りはずすとき，または装着するときは，電池ホルダからバッテリが落ちないように注
  意してください。
- シーケンサの電源が OFF の状態でバッテリ交換する場合は，必ず交換前にデータをバックアップしてください。

［バッテリ交換手順］
Q2MEM-1MBSN，Q2MEM-1MBS，Q2MEM-2MBSN，Q2MEM-2MBS の電池は，電池ホルダの固定ガイドに
沿って，水平方向に挿入，抜取りしてください。電池を電池ホルダに対し斜め方向に挿入，抜取りすると電池ホルダの
ツメの部分が破損する恐れがあります。

- SRAM カードのバッテリホルダが取り出しづらい場合は，下図のような「引っ掛かり溝(1)の入ったプラスチックピン
  セット」をご用意いただき，ピンセットの引っ掛かり溝を電池ホルダに引っ掛けて取り出してください。

1) プログラミングツールで SRAM カード内のデータをバックアップします。
2) バッテリの交換を行います。
3) プログラミングツールからバックアップしたデータをメモリカードに書き込みます。

【図】ピンセットによる電池ホルダ取り出し図(原本 p.261)。電池固定ガイド・電池ホルダ・電池ホルダのツメ部分・
引っ掛かり溝(1)の位置関係を示す。

## 13.4 保管後の運転再開について (13.4 / 原本 p.263)

バッテリをはずしてシーケンサを保管したあとに運転を再開する場合や，バッテリ寿命を超えてシーケンサを保管
したあとに運転を再開する場合，下記に示すバッテリバックアップしているメモリは，内容が不定になっている可
能性があります。

○：バッテリバックアップしている，×：バッテリバックアップしない

バッテリバックアップの対象メモリ一覧(表・原本 p.263):

| メモリ | CPUユニット本体のバッテリ | メモリカードに内蔵のバッテリ |
|---|---|---|
| CPUユニット - プログラムメモリ | ○＊1 | × |
| CPUユニット - 標準RAM（拡張SRAMカセットを含む） | ○ | × |
| CPUユニット - 標準ROM | ―（バッテリバックアップ不要） | ―（バッテリバックアップ不要） |
| メモリカード - SRAMカード | × | ○ |
| メモリカード - Flashカード | ―（バッテリバックアップ不要） | ―（バッテリバックアップ不要） |
| メモリカード - ATAカード | ―（バッテリバックアップ不要） | ―（バッテリバックアップ不要） |
| SDメモリカード | ―（バッテリバックアップ不要） | ―（バッテリバックアップ不要） |

＊1 ユニバーサルモデル QCPU はバッテリバックアップ不要です。

上記の表でバッテリバックアップしているメモリは，運転再開前にプログラミングツールでフォーマットしてくだ
さい。（使用するプログラミングツールのオペレーティングマニュアル）
フォーマットしたあとは，保管する前にバックアップしておいた内容を，各メモリに書き込んでください。
なお，ブート運転時にプログラムメモリをフォーマットする場合は，PC パラメータのブートファイル設定で，“プ
ログラムメモリをクリアする”にチェックを入れてください。

**Point**

- シーケンサを保管する場合は，保管前に各メモリの内容を必ずバックアップし，運転再開前にプログラミングツールで
  書き込んでください。
- CPU ユニットは，シーケンサの電源 ON または CPU ユニットのリセット解除時，下記データの状態をチェックし，異常
  を検出すると下記データをすべて初期化します。初期化された状態で運転再開すると，お客様の意図しない動作になる
  可能性があります。
  - プログラムメモリのデータ
  - 標準 RAM のデータ
  - エラー履歴
  - ラッチデータ（ラッチリレー(L)，パラメータで設定したラッチ設定範囲のデバイス，特殊リレー SM900～
    SM999，特殊レジスタ SD900～SD999）
  - サンプリングトレースデータ
- ユニバーサルモデル QCPU では，標準 ROM へのラッチデータバックアップ機能を使用した場合は，CPU ユニットのデ
  バイスデータやエラー履歴などのラッチデータを，バッテリを使用することなくバックアップできるため，バッテリを
  外してシーケンサを保管してもデータを消失しません。
