#### (1) Q00JCPU (原本 p.117-118)

【図】Q00JCPU外観図(原本 p.117)。CPUユニット前面・側面のNo.1)〜16)の部品配置を示す(RS-232コネクタ+
Q6HLD-R2コネクタ抜け防止ホルダの取付け例を含む)。カバーを開く場合，ここに指を掛けて開けてください。

各部の名称と用途(表・原本 p.117-118):

| No. | 名称 | 用途 |
|---|---|---|
| 1) | ベース取付け穴 | ユニットを制御盤などのパネルに取り付けるためのダルマ穴。（M4ネジ用） |
| 2) | カバー | 増設ケーブル用コネクタの保護カバー。増設を行うときは，カバーを取りはずす。 |
| 3) | 増設ケーブル用コネクタ | 増設ベースユニットとの信号接続用コネクタで増設ケーブルを接続する。 |
| 4) | 「POWER」LED | DC5Vの電源表示用LED。DC5V正常出力時に緑点灯。 |
| 5) | 「RUN」LED | CPUユニットの動作状態を示す。点灯：RUN/STOP/RESETスイッチが｢RUN｣で運転中のとき。消灯：RUN/STOP/RESETスイッチが｢STOP｣で停止中のとき。または運転を停止するエラーを検出したとき。点滅：STOP中にパラメータ／プログラムを書込み，RUN/STOP/RESETスイッチを｢STOP｣→｢RUN｣にしたとき。プログラムの書込み後に「RUN」LEDを点灯させるためには，次の操作を行う。・RUN/STOP/RESETスイッチを「STOP」→「RUN」→「STOP」→「RUN」にする。・RUN/STOP/RESETスイッチでリセットする。（184ページ6.4.1項）・シーケンサの電源の再立上げを行う。パラメータの書込み後に「RUN」LEDを点灯させるためには，次の操作を行う。・RUN/STOP/RESETスイッチでリセットする。・シーケンサの電源の再立上げを行う。（パラメータを変更後，RUN/STOP/RESETスイッチを「RUN」→「STOP」→「RUN」にした場合は，ネットワークパラメータなどインテリジェント機能ユニットに関係するパラメータがインテリジェント機能ユニットに反映されません。） |
| 6) | 「ERR.」LED | 点灯：運転を停止しない自己診断エラーを検出したとき。・パラメータ設定でエラー検出時運転続行に設定したとき・アナンシェータ(F)をSET/OUT命令でONしたとき・バッテリが低下したとき。消灯：正常。点滅：運転を停止するエラーを検出したとき。リセット操作を行ったとき。 |
| 7) | ユニットコネクタ | 入出力ユニット，インテリジェント機能ユニットを装着するコネクタ。（ユニットを装着しない予備スペースのコネクタには，じんあい侵入防止のため付属のコネクタカバーか，またはブランクカバーユニット(QG60)を装着してください。） |
| 8) | DINレール用アダプタ取付け穴 | DINレール用アダプタの取付け穴。 |
| 9) | FG端子 | プリント基板上の遮蔽パターンと接続された接地端子 |
| 10) | LG端子 | 電源フィルタの接地。入力電圧の1/2の電位を持っている。 |
| 11) | 電源入力端子 | 電源の入力端子でAC100VからAC200Vの交流電源を接続する。 |
| 12) | バッテリ | プログラムメモリ，標準RAM，停電保持機能を使用する場合のバックアップ用バッテリ。 |
| 13) | バッテリ固定用フック | バッテリ脱落防止用フック。 |
| 14) | バッテリコネクタピン | バッテリのリード線の接続用。(バッテリの消耗を防ぐため出荷時にはリード線をコネクタからはずしてあります。） |
| 15) | RS-232コネクタ＊1 | RS-232で周辺機器と接続するためのコネクタ。RS-232用接続ケーブル（QC30R2）で接続可能。 |
| 16) | RUN/STOP/RESETスイッチ＊2 | RUN：シーケンスプログラムの演算実行。STOP：シーケンスプログラムの演算停止。RESET：ハードウェアリセット，演算異常発生時のリセットと演算の初期化などを行う。（184ページ6.4.1項） |

＊1 RS-232 コネクタにケーブルを常時接続する場合，ケーブルはクランプによる固定処理を行ってください。ケーブル
のふらつきや移動，不注意の引っ張りなどによるコネクタのはずれを防止します。RS-232 コネクタのクランプとし
て，Q6HLD-R2 形コネクタ抜け防止ホルダがあります。
＊2 RUN/STOP/RESET スイッチの操作は，指先で行ってください。ドライバなどの工具を使用するとスイッチ部を破損
させる恐れがあるため，使用しないでください。

## 6.3 プログラム書込み後のスイッチ操作 (6.3 / 原本 p.184-185)

### 6.3.1 ベーシックモデル QCPU，ユニバーサルモデル QCPU (6.3.1 / 原本 p.184)

プログラミングツールでプログラム書込み後のスイッチ操作について説明します。

#### (1) CPU ユニットを STOP 状態にしてプログラムを書き込んだ場合＊1 (原本 p.184)

##### (a) デバイスメモリのデータをクリアして RUN 状態にするとき (原本 p.184)

1. RUN/STOP/RESET スイッチを RESET の位置に1回( 約1秒）倒し，STOP の位置に戻します。
2. RUN/STOP/RESET スイッチを RUN の位置にします。
3. CPU ユニットが RUN 状態（「RUN」LED：点灯）になります。

##### (b) デバイスメモリのデータをクリアしない（保持）で RUN 状態にするとき (原本 p.184)

1. RUN/STOP/RESET スイッチを RUN の位置にします。
2. 「RUN」LED が点滅します。
3. RUN/STOP/RESET スイッチを STOP の位置にします。
4. RUN/STOP/RESET スイッチを再度 RUN の位置にします。
5. CPU ユニットが RUN 状態（「RUN」LED：点灯）になります。

#### (2) CPU ユニットが RUN 状態でプログラムを書き込んだ場合（RUN 中書込）＊2 (原本 p.184)

CPU ユニットの RUN/STOP/RESET スイッチの操作は不要です。このときデバイスメモリのデータはクリア
されません。

＊1 ブート運転時にプログラムをプログラムメモリに書き込んだ場合は，ブート元メモリにもプログラムを書き込んでく
ださい。
ブート元メモリにプログラムを書き込まなかった場合，次回ブート運転時に古いプログラムが実行されてしまいます。
＊2 回路モードでの RUN 中書込をした場合，RUN 中書込をしたプログラムはプログラムメモリに書き込まれます。
ブート運転時には RUN 中書込後，ブート元メモリにもプログラムを書き込んでください。ブート元メモリにプログラ
ムを書き込まなかった場合，次回ブート運転時に古いプログラムが実行されてしまいます。
ブート運転の詳細は，下記マニュアルを参照してください。
- QnUCPU ユーザーズマニュアル（機能解説・プログラム基礎編）

プログラミングツールのリモート STOP 操作で STOP 状態にした場合は，プログラム書込み後プログラミングツールの
リモート RUN 操作で RUN 状態になります。
その場合は，CPU ユニットの RUN/STOP/RESET スイッチの操作は不要です。
プログラミングツールに関する詳細は，下記マニュアルを参照してください。
- 使用するプログラミングツールのオペレーティングマニュアル

## 6.4 リセットの操作方法 (6.4 / 原本 p.186-187)

### 6.4.1 ベーシックモデル QCPU，ユニバーサルモデル QCPU (6.4.1 / 原本 p.186)

ベーシックモデル QCPU，ユニバーサルモデル QCPU は，CPU ユニットの RUN/STOP/RESET スイッチで
“RUN 状態 ” と “STOP 状態 ” の切換え，“RESET 操作 ” を行います。

RUN/STOP/RESET スイッチをリセット側に倒しても，すぐにはリセットできません。
リセット処理が完了（「ERR.」LED 消灯）するまで RUN/STOP/RESET スイッチを RESET 側に倒したまま，手を離さ
ないでください。
リセット処理中（「ERR.」LED の点滅中）に RUN/STOP/RESET スイッチから手を離すと，STOP の位置に戻るため，
リセット処理を完了することができません。

RUN/STOP/RESET スイッチでのリセット操作は，下記に示す手順で行ってください。
RUN/STOP/RESET スイッチの操作は，指先で行ってください。
ドライバなどの工具を使用するとスイッチ部を破損させる恐れがあるため，使用しないでください。

【図】リセット操作タイミングチャート(原本 p.186)。開始から終了までの流れ:
- 開始: RUN/STOP/RESETスイッチを"RESET"側に倒したままにする。（1秒間以上）
- RUN/STOP/RESETスイッチによるリセット操作の開始:「ERR.」LEDが数回（3～4回）点滅する。
- リセットの受付けとリセット処理中:「ERR.」LEDが点滅する。
- リセットの完了:「ERR.」LEDが消灯する。
- RUN/STOP/RESETスイッチを"STOP"側に戻す＊。
- リセットの解除。
- 終了

＊：RUN/STOP/RESETスイッチから手を離すと，STOPの位置に戻ります。

### 6.4.2 ハイパフォーマンスモデル QCPU，プロセス CPU，二重化 CPU (6.4.2 / 原本 p.187)

ハイパフォーマンスモデル QCPU，プロセス CPU，二重化 CPU では CPU ユニットの RESET/L.CLR スイッチを
RESET 側に倒すことによりリセット操作を行います。
リセット操作後は，必ず RESET/L.CLR スイッチを中立位置に戻してください。RESET/L.CLR スイッチを RESET 側に
倒した状態で放置するとシステム全体にリセットがかかり，システムは正常に動作しません。

## 6.6 標準 ROM への自動書込み操作 (6.6 / 原本 p.189-190)

ハイパフォーマンスモデル QCPU，プロセス CPU，二重化 CPU ではメモリカードのデータを標準 ROM へ自動的
に書き込むことができます。＊注6.2
詳細は下記マニュアルを参照してください。
- Qn(H)/QnPH/QnPRHCPU ユーザーズマニュアル（機能解説・プログラム基礎編）

＊注6.2 ベーシックモデル QCPU，ユニバーサルモデル QCPU では，標準 ROM への自動書込みを使用できません。(対象: Basic, Universal)

### (1) 標準 ROM への自動書込みの実行手順 (原本 p.189-190)

標準 ROM への自動書込みは，下記手順で行います。

#### (a) プログラミングツールの操作（標準 ROM への自動書込みの設定） (原本 p.189)

プロジェクトウィンドウ[パラメータ]→[PCパラメータ]→[ブートファイル設定]

1. “メモリカード→標準ROM全データ自動書込”をチェックします。
2. ブートファイル設定でブートするパラメータ，プログラムを設定します。
   （転送元は“標準ROM”に設定します。）
3. 設定したパラメータとブートするプログラムをメモリカードに格納します。

【図】ブートファイル設定画面(原本 p.189)。“メモリカード→標準ROM全データ自動書込”をチェックする。
転送元は“標準ROM(ドライブ4)”に設定する。

#### (b) CPU ユニットでの操作（標準 ROM への自動書込み） (原本 p.190)

1. シーケンサの電源を OFF します。
2. CPU ユニットにパラメータとブートするプログラムを格納したメモリカードを装着します。
3. CPU ユニットのディップスイッチにより，パラメータ有効ドライブを装着するメモリカードに合致する
   設定にします。
   - SRAM カード装着時：SW2：ON，SW3：OFF
   - Flash カード／ATA カード装着時：SW2：OFF，SW3：ON
4. シーケンサの電源を ON します。
   メモリカードで指定されたファイルをプログラムメモリにブートし，ブート完了後プログラムメモリの
   内容を標準 ROM に書き込みます。
5. 標準 ROM への自動書込みが完了すると，“「BOOT」LED” が点滅し，CPU ユニットは停止エラー状
   態となります。
6. シーケンサの電源を OFF します。
7. メモリカードを抜き取り，CPU ユニットのディップスイッチにより，パラメータ有効ドライブを標準
   ROM に設定します。
   - 標準 ROM：SW2：ON，SW3：ON
8. シーケンサの電源を ON すると，標準 ROM からプログラムメモリへのブートを行い，実際の運転ができ
   ます。
