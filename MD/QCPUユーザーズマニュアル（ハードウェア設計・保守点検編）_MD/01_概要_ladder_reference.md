## 1.1 特長 (1.1 / 原本 p.26-32)

CPU ユニットの特長を次に示します。

### (1) 多点数の入出力が制御可能 (1.1 / 原本 p.26)

CPU ユニットは，ベースユニットに装着された入出力ユニットにアクセスできる実入出力点数として下記に示
す入出力点数をサポートしています。

#### (a) ベーシックモデル QCPU (原本 p.26)

- Q00JCPU：256 点（X/Y0～FF）
- Q00CPU，Q01CPU：1024 点（X/Y0～3FF）

なお，CC-Link のリモート I/O，MELSECNET/H のリンク入出力（LX,LY）のリフレッシュ用に使用でき
る入出力デバイス点数としては 2048 点（X/Y0～7FF）までをサポートしています。

#### (b) ハイパフォーマンスモデル QCPU (原本 p.26)

4096 点（X/Y0～FFF）をサポートしています。
なお，MELSECNET/H リモート I/O ネット，CC-Link データリンク，MELSECNET/MINI-S3 データリン
クなどのリモート I/O 局に使用できる入出力デバイス点数としては 8192 点（X/Y0～1FFF）までをサポー
トしています。

#### (c) プロセス CPU，二重化 CPU (原本 p.26)

4096 点（X/Y0～FFF）をサポートしています。
なお，MELSECNET/H リモート I/O ネット，CC-Link データリンクなどのリモート I/O 局に使用できる入
出力デバイス点数としては 8192 点（X/Y0～1FFF）までをサポートしています。

#### (d) ユニバーサルモデル QCPU (原本 p.26)

- Q00UJCPU：256 点（X/Y0～FF）
- Q00UCPU，Q01UCPU：1024 点（X/Y0～3FF）
- Q02UCPU：2048 点（X/Y0～7FF）
- Q03UDCPU，Q03UDVCPU，Q03UDHCPU，Q04UDHCPU，Q04UDVCPU，Q04UDPVCPU，Q04UDEHCPU，Q06UDHCPU，Q06UDVCPU，Q06UDPVCPU，Q06UDEHCPU，Q10UDHCPU，Q10UDEHCPU，Q13UDHCPU，Q13UDVCPU，Q13UDPVCPU，Q13UDEHCPU，Q20UDHCPU，Q20UDEHCPU，Q26UDHCPU，Q26UDVCPU，Q26UDPVCPU，Q26UDEHCPU，Q50UDEHCPU，Q100UDEHCPU：4096 点（X/Y0～FFF）

なお，MELSECNET/H リモート I/O ネット，CC-Link データリンクなどのリモート I/O 局に使用できる入
出力デバイス点数としては 8192 点（X/Y0～1FFF）までをサポートしています。

### (4) プログラミングツールとの高速通信によるデバッグの効率向上 (1.1 / 原本 p.29)

RS-232 による最大 115.2kbps の高速通信に対応し，プログラムの書込み／読出しやモニタなどの時間が短
縮され，デバッグ時の交信時間効率が向上しました。

さらに，ハイパフォーマンスモデル QCPU（Q02CPU を除く），プロセス CPU，二重化 CPU，ユニバーサル
モデル QCPU では USB 対応により 12Mbps の高速通信を行えます。

【図】書込み／読出し所要時間の比較(棒グラフ・原本 p.29)。単位は秒。
- Q25HCPU(USB)：12
- Q25HCPU(RS-232)：30
- Q2ASHCPU：86
- A2USHCPU-S1：94

### (5) AnS/A シリーズの入出力ユニット，特殊機能ユニットが使用可能 (1.1 / 原本 p.29)

ハイパフォーマンスモデル QCPU，ユニバーサルモデル QCPU＊1 は，AnS/A シリーズ対応の増設ベースユ
ニット（QA1S5◇B,QA1S6◇B,QA1S6ADP+A1S5◇B/A1S6◇B,QA6◇B,QA6ADP+A5◇B/A6◇B）によ
り，AnS/A シリーズの入出力ユニットや特殊機能ユニットを使用することができます。

＊1 シリアル No. の上 5 桁が “13102” 以降のユニバーサルモデル QCPU が対象です。（ただし，QnUDPVCPU は除
きます。）

### (6) 小形化による省スペースサイズ (1.1 / 原本 p.29)

Q シリーズの取付け面積は，AnS シリーズと比較して約 60％の小形化を実現しています。

【図】Qシリーズ/AnSシリーズの外形比較図(原本 p.29)。読み取れる寸法:
- 高さ(奥行き)：98mm(Qシリーズ)
- 5スロット基本ベース：245mm
- 8スロット基本ベース：328mm
- 12スロット基本ベース：439mm
- 図はQシリーズとAnSシリーズを並べて高さ方向のサイズ差を示している(詳細形状は原本 p.29 参照)

### (7) 最大 7 段の増設ベースユニットを接続可能 (1.1 / 原本 p.30)

CPU ユニットは，最大 7 段の増設ベースユニットを接続可能です。
また，増設ケーブルの総延長距離は最長 13.2m で，自由度の高い増設ベースユニットの配置が可能です。

### (8) メモリの拡張が可能 (1.1 / 原本 p.30)

CPU ユニットのメモリを拡張することで，大容量のファイル管理を行うことができ，全データデバイスへのコ
メントの設定，および過去のプログラムを修正履歴としてそのままメモリ内に保持することを可能にします。

#### (a) メモリカード (原本 p.30)

最大 32M バイトのメモリカードを装着できます。（32M バイトは ATA カード使用時）
メモリカードを使用することにより，下記のような使い方ができます。
- メモリカードからのブート運転
- バックアップデータのリストア
- プログラムの ROM 化

また，CPU ユニットの内蔵メモリに格納しきれないデータを保存できます。
- サンプリングトレースのデータ
- ファイルレジスタ

#### (b) SD メモリカード (原本 p.30)

SD メモリカードを使用することにより，下記のような使い方ができます。
- SD メモリカードからのブート運転
- バックアップデータのリストア
- SD メモリカードへのデータバックアップ
- データロギング

#### (c) 拡張 SRAM カセット (原本 p.30)

CPU ユニットの標準 RAM を拡張できます。
- 拡張 SRAM カセットは，SD メモリカードと同時に使用可能です。そのため，ブートデータを SD メモリ
  カード，デバイスデータを拡張 SRAM カセットに格納する使い方ができ，メンテナンス性が向上しま
  す。
- 従来は，標準 RAM と SRAM カードのファイルレジスタは連続アクセス不可でした。そのため，プログラ
  ミングの際に，それぞれの境界を意識する必要がありました。拡張 SRAM カセットを使用することで，
  デバイスを連番で拡張できます。

**備考**

CPU ユニットごとに，使用可能なメモリ拡張の方法が異なります。（ 33 ページ 2.2 節）

### (9) 標準 ROM への自動書込みが可能＊注1.1＊注1.2 (1.1 / 原本 p.31)

メモリカードまたは SD メモリカードのパラメータ・プログラムを，プログラミングツールを使用しないで
CPU ユニットの標準 ROM へ書き込むことが可能です。

標準 ROM によるブート運転を行っている場合，CPU ユニットにメモリカードまたは SD メモリカードを装着
し，メモリカードまたは SD メモリカードのパラメータ・プログラムを標準 ROM に書き込めます。これによ
り，パラメータ・プログラムの書換えのためにプログラミングツール（パソコン）を持ち歩く必要がなくなり
ます。

### (10) 外部入出力の強制 ON/OFF が可能＊注1.1 (1.1 / 原本 p.31)

CPU ユニットが RUN 状態でも，プログラムの実行状態に関係なくプログラミングツールの操作により，外部
入出力の強制 ON/OFF ができます。

また，CPU ユニットを STOP 状態にすることなく，出力の強制 ON/OFF により配線・動作テストを行うこと
ができます。

### (11) リモートパスワードの設定が可能 (1.1 / 原本 p.31)

Ethernet ポート内蔵 QCPU，Ethernet ユニット，シリアルコミュニケーションユニット，モデムインタ
フェースユニットに外部からアクセスがあった場合，リモートパスワードにより CPU ユニットへのアクセス
の可否の選択ができます。

リモートパスワードは，機能バージョン B 以降の Ethernet ユニット，シリアルコミュニケーションユニット，モデムイ
ンタフェースユニットを使用した場合に設定できます。

### (12) MELSECNET/H のリモート I/O ネットが可能＊注1.1 (1.1 / 原本 p.31)

MELSECNET/H のリモートマスタ局を装着し，MELSECNET/H のリモート I/O システムを構築することが
できます。

MELSECNET/H のリモート I/Oネットは，機能バージョン B 以降の MELSECNET/Hネットワークユニットを使用した
場合に実行できます。

**注1.1**：ベーシックモデル QCPU では，以下の機能は対応していません。
- 標準 ROM への自動書込み
- 外部入出力の強制 ON/OFF
- MELSECNET/H のリモート I/O ネット

**注1.2**：ユニバーサルモデル QCPU では，以下の機能は対応していません。
- 標準 ROM への自動書込みのパラメータ設定

### (13) マルチ CPU システムに対応 (1.1 / 原本 p.32)

CPU ユニットは，マルチ CPU システムに対応しています。
CPU ユニット，モーション CPU，パソコン CPU ユニット，C 言語コントローラユニットと組み合わせてマ
ルチ CPU システムの構築が可能です。

マルチ CPU システムについての詳細は，下記マニュアルを参照してください。
- QCPU ユーザーズマニュアル ( マルチ CPU システム編 )

### (14) 電源二重化システムに対応 (1.1 / 原本 p.32)

CPU ユニットは，二重化ベースユニット，二重化電源ユニットを使用することにより，電源ユニットの二重化
が可能です。
一方の電源ユニットが故障した場合でも，他方の電源ユニットから電源を供給することによって，継続運転で
きます。

### (15) CPU ユニットから Ethernet への直接接続が可能＊注1.3 (1.1 / 原本 p.32)

Ethernet ポート内蔵の CPU ユニットを使用することで CPU ユニットから直接 Ethernet への接続を行うこと
ができます。

機能の詳細については下記マニュアルを参照してください。
- QnUCPU ユーザーズマニュアル（内蔵 Ethernet ポート通信編）

**注1.3**：Ethernet ポート内蔵 QCPU のみ対応しています。
