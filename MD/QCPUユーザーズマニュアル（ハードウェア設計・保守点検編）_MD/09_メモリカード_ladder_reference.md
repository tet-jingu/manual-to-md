## 第9章 冒頭 (原本 p.232)

CPU ユニットに使用できるメモリカードの仕様および取扱いについて説明します。＊注9.1
メモリカードは，プログラム，ファイルレジスタの格納，およびトレース機能によるデバッグデータの格納などに
使用します。
また，メモリカードは標準 RAM に格納できる点数を超えるファイルレジスタを扱いたい場合にも使用します。
(139ページ 6.2節)

## 9.3 メモリカードの取扱いについて (9.3 / 原本 p.237-239)

### (1) メモリカードのフォーマット実施 (原本 p.237)

CPU ユニットで使用する SRAM カードおよび ATA カードは，すべてフォーマットされていることが必要で
す。
購入していただいた SRAM カードおよび ATA カードは未フォーマット状態ですので，プログラミングツール
でフォーマットしたあとご使用ください。
(Flash カードはフォーマット不要です。)
フォーマット方法は，下記マニュアルを参照してください。
- 使用するプログラミングツールのオペレーティングマニュアル

ATA カードはプログラミングツール以外でフォーマットしないでください。
（Microsoft Windows Operating System のフォーマット機能などによりフォーマットした場合は，CPU ユニットに
装着して使用できなくなる場合があります。）

### (2) SRAM カードのバッテリ装着 (原本 p.237)

購入していただいた SRAM カードには，停電保持用のバッテリが同梱されています。
SRAM カードを使用する場合は，最初にバッテリを装着してください。

CPU ユニット本体に装着しているバッテリでは，SRAM カードのメモリはバックアップされませんので，注意してくだ
さい。
また，SRAM カードに装着しているバッテリでは，CPU ユニットのプログラムメモリ，標準 RAM，ラッチデバイスは
バックアップされませんので，注意してください。

### (3) メモリカードに格納できるファイルの種類 (原本 p.237)

各メモリカードに格納できるファイルの種類については，下記マニュアルを参照してください。

### (4) 電源 ON 中にメモリカードを着脱するときの注意事項 (原本 p.237)

電源 ON 中にメモリカードを着脱するときは，94ページ 4.5節(3)，94ページ 4.5節(4) に記載の手順どお
りに行わない場合，メモリカード内のデータが破壊される恐れがあります。
また，パラメータでエラー発生時の CPU ユニットの動作を「停止」に設定した場合，ICM.OPE.ERROR 発生
により CPU ユニットは動作を停止します。

### 9.3.1 メモリカード用バッテリのメモリカードへの装着 (9.3.1 / 原本 p.238-239)

メモリカード (SRAM カード ) 用バッテリ装着方法

SRAM カード用のバッテリは，電池ホルダからはずして出荷されます。
CPU ユニットに SRAM カードを装着する前に，下記に示す手順で電池ホルダをセットしてください。

#### (1) Q2MEM-1MBSN，Q2MEM-1MBS，Q2MEM-2MBSN，Q2MEM-2MBS の場合 (原本 p.238)

バッテリは，電池ホルダの固定ガイドに沿って，水平方向に挿入，抜取りしてください。
バッテリを電池ホルダに対し斜め方向に挿入，抜取りすると電池ホルダのツメの部分が破損する恐れがあります。

【図】バッテリ装着手順図(原本 p.238)。手順:
1. 電池ホルダ固定スイッチをRELEASE位置にする
2. SRAMカードの電池ホルダをはずす
3. バッテリの＋面を上に向けて，電池ホルダにセットする
4. バッテリをセットした電池ホルダをSRAMカードの奥までしっかり挿入する
5. 電池ホルダ固定スイッチがLOCKの位置にあるか確認する
完了

電池ホルダ固定スイッチは，電池ホルダをはずすと自動的にLOCKの位置になります。
その状態で，電池ホルダを奥まで挿入してください。

#### (2) Q3MEM-4MBS，Q3MEM-8MBS の場合 (原本 p.239)

【図】バッテリ装着手順図(原本 p.239)。手順:
1. 電池ホルダ固定スイッチをRELEASE位置にする
2. SRAMカードの電池ホルダをはずす
3. バッテリの＋面を上に向けて，電池ホルダにセットする（＊1 バッテリの向きに注意）
4. バッテリをセットした電池ホルダをSRAMカードの奥までしっかり挿入する
5. 電池ホルダ固定スイッチをLOCK位置にする
完了

＊1 バッテリの向きを下記に示します。電池ホルダ側は＋側・－側の極性表示があり、バッテリ本体には
形名・電圧・極性・メーカ名・製造番号（製造日によって異なります）が記載されている。
