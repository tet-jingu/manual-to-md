## 2.1 全体構成 (2.1 / 原本 p.34)

構成する機器によって使用できるユニットの組合せが異なります。
組合せの可否については以下の項目を参照してください。
- CPU ユニットとベースユニット，バッテリ，メモリカード，SD メモリカード，拡張 SRAM カセットの組
  合せ（ 33 ページ 2.2 節）
- ベースユニットと電源ユニットの組合せ（ 189 ページ 第 7 章）
- 基本ベースユニットと増設ベースユニットの組合せ（ 219 ページ 第 8 章）

システムを構成する際は， 37 ページ 2.3 節の注意事項に従って，正しく構成してください。

## 2.3.1 GOT をバス接続するシステム構成 (2.3.1 / 原本 p.47-50)

CPU ユニットを使用したシステムでは，基本ベースユニット／増設ベースユニットの増設ケーブルコネクタを使用
して，GOT をバス接続することができます。
本項では，GOT をバス接続した場合のシステム構成について記載しています。

GOT のバス接続方法の詳細については，下記マニュアルを参照してください。
- GOT-A900 シリーズユーザーズマニュアル（接続編）
- GOT1000 シリーズ接続マニュアル ( 三菱電機機器接続編 ) GT Works3 対応
- GOT2000 シリーズ接続マニュアル ( 三菱電機機器接続編 ) GT Works3 Version1 対応

### (1) CPU ユニットから見た GOT の扱い (2.3.1 / 原本 p.47)

GOT をバス接続した場合，CPU ユニットは GOT を入出力点数 16 点のインテリジェント機能ユニットとして
認識します。
そのため，GOT のセットアップで，CPU ユニットに I/O 割付する必要があります。
（GOT バス接続時は，増設段数を 1 段（16 点 10 スロット分）占有させる必要があります。）

GOT のセットアップの詳細については，下記マニュアルを参照してください。
- GOT-A900 シリーズオペレーティングマニュアル（拡張機能・オプション機能編）
- GT15 本体取扱説明書
- GT16 本体取扱説明書（基本ユーティリティ編）

### (2) GOT の最大接続台数 (2.3.1 / 原本 p.47)

GOT をバス接続することのできる台数は，最大 5 台です。

### (3) 注意事項 (2.3.1 / 原本 p.48)

- GOT をバス接続する場合，必ずベースユニットの後段に接続してください。ベースユニット間に GOT は
  バス接続できません。

【図】GOTバス接続の可否(原本 p.48)。○: ベースユニット→ベースユニット→GOTの順に接続(正しい)。
×: ベースユニット→GOT→ベースユニットの順(ベースユニット間へのGOT接続は不可)。

- GOT をバス接続するための増設ケーブルは，増設ケーブルの総延長距離が最大 13.2m となるように選定し
  てください。
- バス接続する GOT の 1 台目を 13.2m 以上離れた場所に設置する場合は，バス延長コネクタボックス
  (A9GT-QCNB) が必要です。（ただし，Q00JCPU 使用時は，バス延長コネクタボックスを使用できませ
  ん。）
  A9GT-QCNB の詳細については，下記マニュアルを参照してください。
  - A9GT-QCNB 形バス延長コネクタボックスユーザーズマニュアル
- ベースユニットとして，二重化ベースユニット (Q3RB/Q6RB/Q6WRB) を使用した場合，GOT をバ
  ス接続することはできません。
- 増設ベースユニットに QA1S6B を使用する場合，ハードウェア的には増設ベースユニットの後段に GOT
  を接続しますが，入出力番号は Q6B/Q5B の後ろに割り付けてください。

入出力番号割付けの例(表・原本 p.48):

| 構成 | 増設段数 | 入出力番号 |
|---|---|---|
| Q38B形基本ベースユニット | ― | 00～7F |
| Q68B形増設ベースユニット | 1 | 80～FF |
| QA1S68B形増設ベースユニット | 3 | 1A0～21F |
| GOT | 2 | 100～19F |

- 増設ベースユニットに QA1S5B，QA1S6ADP+A1S5B/A1S6B，QA6B，QA6ADP+A5B/
  A6B を使用した場合，GOT をバス接続することはできません。
- CPU ユニットを立ち上げる前に，必ずバス接続する GOT の初期設定
  （使用する GOT のセットアップによる増設段およびスロット No. の設定）を行ってください。
- CPU ユニット，GOT への電源投入は，必ず以下のいずれかの方法で行ってください。
  1）CPU ユニット，GOT へ同時に電源を投入する。
  2）CPU ユニット→GOT の順で電源を投入する。
- 使用可能な GOT については，37 ページ 2.3 節 (1) を参照してください。
- シーケンサと GOT との接続ケーブルの FG 線を GOT 側で接地してください。
  接地方法については，使用する GOT のマニュアルを参照してください。
