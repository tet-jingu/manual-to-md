## 付9 フェールセーフ回路の考え方 (原本 p.604)

シーケンサの電源のON-OFF時は，シーケンサ本体電源と制御対象用外部電源（特にDC）の遅れ時間および立上がりが時間の差により制御出力が一時的に正常動作しない場合があります。
たとえば，DC出力ユニットにおいて制御対象用外部電源を通電したのち，シーケンサ本体電源を通電した場合，DC出力ユニットが，シーケンサの電源ON時に一瞬誤出力することがありますので，先にシーケンサ本体電源が通電できる回路を構成する必要があります。
また，外部電源の異常時やシーケンサ本体の故障時は異常動作となることが考えられます。
これらの異常動作がシステム全体の異常動作につながらないために，またフェールセーフの観点より異常動作による機械の破損や事故につながる部分（非常停止回路，保護回路，インタロック回路など）はシーケンサの外部で回路を構成してください。
次ページに上記観点によるシステム設計回路例を示します。

### (1) システム設計回路例（電源ユニットのERR.端子を使用しない場合，Q00JCPUの場合） (原本 p.605)

電源の立上げ手順は次のようにしています。

**ACの場合**
- [1] 電源を「ON」にする。
- [2] CPUユニットを「RUN」する。
- [3] 起動SW「ON」する。
- [4] 電磁接触器（MC)「ON」でプログラムにより出力機器駆動。

**AC・DCの場合**
- [1] 電源を「ON」にする。
- [2] CPUユニットを「RUN」する。
- [3] DC電源確立でRA2「ON」する。
- [4] DC電源100％確立でタイマ（TM)を「ON」する。（TMの設定値はRA2「ON」からDC電圧100％確立までの時間とする。設定値は0.5秒としてください。）
- [5] 起動SW「ON」する。
- [6] 電磁接触器（MC)「ON」でプログラムにより出力機器駆動。（RA2に電圧リレー使用の場合はプログラム上のタイマ（TM)は不要です。）

【図】システム設計回路例（ERR.端子未使用，Q00JCPU）(原本 p.605): 左側「ACの場合」・右側「AC・DCの場合」の2系統の回路図。

- ACの場合: 電源→トランス→ヒューズ→CPUユニット。CPUユニット内プログラムはSM52-Ym，SM403-Ynの接点／コイル対応（Yn:SM403によりRUNでON、警報用出力ランプまたはブザーへ）。起動・停止回路：起動SW－停止SW－MC(自己保持b接点)－RA1コイル（シーケンサのRUN出力であるRA1 ONで起動可能）。出力ユニット側：Ym→警報用出力(L)、Yn→RA1。別の出力ユニットでMC接点によるインタロック：非常停止時・極限リミットによる停止時に停止で出力機器の電源OFF、MC2/MC1の相互インタロック回路（正転，逆転などの相反する動作や機械の破損，事故につながる部分は外部でインタロック回路を組みます）。
- AC・DCの場合: 電源→トランス(2系統)→ヒューズ→CPUユニット、DC電源(-)(+)→ヒューズ。CPUユニット内プログラム：SM52-Ym、SM403-Yn、XM-TM(直流電流確立信号入力によりXM経由でTMを駆動。TMの設定はDC入力信号が確立するまでの時間とする)。TM-MC1-NO-M10の直列接点でNO(起動可能)信号を生成。起動・停止回路：起動SW-停止SW-MC-RA1コイル。RA2(電圧リレーを推奨)の接点でXMコイルを駆動。出力ユニット：Ym→警報用出力(L)、Yn→RA1。別の出力ユニットでMC接点によるインタロック回路（非常停止時・極限リミットによる停止時に停止で出力機器の電源OFF、MC2/MC1相互インタロック）。

### (2) システム設計回路例（電源ユニットのERR.端子を使用する場合） (原本 p.606)

電源の立上げ手順は次のようにしています。

**AC・DCの場合**
- [1] 電源を「ON」にする。
- [2] CPUユニットを「RUN」する。
- [3] DC電源確立でRA2「ON」する。
- [4] DC電源100％確立でタイマ（TM)を「ON」する。（TMの設定値はRA2「ON」からDC電圧100％確立までの時間とする。設定値は0.5秒としてください。）
- [5] 起動SW「ON」する。
- [6] 電磁接触器（MC)「ON」でプログラムにより出力機器駆動。（RA2に電圧リレー使用の場合はプログラム上のタイマ（TM)は不要です。）

【図】システム設計回路例（ERR.端子使用）(原本 p.606): 電源→トランス(2系統)→ヒューズ→CPUユニット，DC電源(直流電源)→ヒューズ。CPUユニット内プログラム：SM52-Ym、SM403-Yn、XM-TM（直流電流確立信号入力経由）。TM-MC1-NO-M10の直列接点でNO信号を生成。起動・停止回路：起動SW-停止SW-MC-RA1・RA3の並列接点-MCコイル（シーケンサのRUN出力であるRA1 ONで起動可能）。RA2(電圧リレーを推奨)の接点でXMコイルを駆動。出力ユニット：Ym→警報用出力(L)、Yn→RA1。電源ユニットのERR接点→RA3コイル（ERR接点OFF＝停止エラー発生でOFF）。別の出力ユニットでMC接点によるインタロック回路：非常停止時・極限リミットによる停止時・ERR接点OFF時のいずれかで停止して出力機器の電源OFF、MC2/MC1相互インタロック（正転，逆転などの相反する動作や機械の破損，事故につながる部分は外部でインタロック回路を組みます）。

### (3) シーケンサ故障時のフェールセーフ対策 (原本 p.607)

シーケンサのCPUユニットとメモリの故障は自己診断機能によって検出されますが，入出力制御部分などに異常があったときは，CPUユニットにより故障検出できないことがあります。
このような場合，故障の状態にもよりますが，全点ONしたり，あるいは全点OFFしたり，制御対象の正常な運転や安全が確保できない事態が発生することも考えられます。
メーカとして品質には万全を期しておりますが，何らかの原因によりシーケンサが故障した場合に，機械の破損や事故につながらないよう外部にてフェールセーフ回路を構成してください。
下記にシステム例とフェールセーフの回路例を示します。

【図】フェールセーフ用出力ユニットを含むシステム構成例(原本 p.607): 1台目のベースユニット（電源・CPU・入力×4・出力×1、各スロット16点）と、増設ケーブルで接続された2台目のベースユニット（電源・出力×4・アキ、各スロット16点）から成る構成。2台目の最終スロット（Y80〜Y8F）にフェールセーフ用出力ユニット＊1を装着。

- ＊1 フェールセーフ用出力ユニットは，システムの最終スロットに装着してください。（上記システムではY80～Y8Fとしています。）

【図】フェールセーフ回路例(原本 p.607): CPUユニット内部プログラムはSM412接点でY80コイルを駆動（Y80は0.5秒間隔でON/OFFを繰り返すパルス出力）。出力ユニット＊2側：Y80端子はオンディレイタイマT1(1s)とオフディレイタイマT2(1s)の並列回路に接続。Y81〜Y8F端子は負荷経由でMC(接点)に接続。24V/0V端子はDC24V電源に接続。T1・T2の接点（直列）でMCコイルを駆動する構成となっており、Y80のパルスが0.5秒間隔で継続していることをT1・T2で監視し、パルスが停止（＝CPU異常等でY80が固定値のままになる）するとMCがOFFして出力機器の電源を遮断するフェールセーフ動作を実現している。

- ＊2 Y80は0.5秒間隔でON/OFFを繰り返しますので，無接点の出力ユニット（上記例はトランジスタ）を使用してください。

## 付10 シーケンサの発熱量の計算方法 (原本 p.608-610)

シーケンサを収納した盤内の温度はシーケンサの使用周囲温度55℃以下に抑える必要があります。
収納盤の放熱設計にあたっては，内部に収納する装置・器具類の平均消費電力（発熱量）を知る必要があります。
ここでは，シーケンサシステムの平均消費電力の求め方について説明します。
消費電力より盤内温度上昇を算出してください。
シーケンサの電力消費部分は大別すると下記のブロックになります。

### (1) 電源ユニットの消費電力 (原本 p.608)

電源ユニットの電力変換効率は約70%であり，30%が発熱として消費されるため，出力電力の3/7が消費電力となります。
したがって計算式は，下記のようになります。

```
WPW = 3/7 × { (I5V×5) + (I15V×15) + (I24V×24) } (W)
```

- I5V：各ユニットのロジックDC5V回路の消費電流
- I15V：インテリジェント機能ユニットの外部供給電源部DC15Vの消費電流
- I24V：出力ユニット内部消費用電源DC24Vの平均消費電流
  （同時ON点数分の消費電流）
  外部からDC24Vを供給し，DC24V出力のない電源ユニットを使用の場合は該当しません。

> Point
> 電源二重化システムを構成した場合も，「電源ユニットの消費電力」の計算方法は電源単独システム時と同一です。
> （二重化電源ユニットは，2台並列で運転すると負荷電流を半分ずつ負担して運転します。）

### (2) 各ユニット（CPUユニットを含む）の合計DC5Vロジック部の消費電力 (原本 p.608)

電源ユニットのDC5V出力回路部が各ユニットの消費電力です。＊1
（ベースユニットの消費電流も含まれます。）

```
W5V = I5V × 5 (W)
```

- ＊1 モーションCPU，パソコンCPUユニットの消費電力は各ユニットの取扱説明書を参照してください。

### (3) 出力ユニットの合計DC24V平均消費電力（同時ON点数分の消費電力） (原本 p.608)

外部DC24V電源の平均電力が各ユニットの合計消費電力です。

```
W24V = I24V × 24 × 同時ON率 (W)
```

### (4) 出力ユニットの出力部ドロップ電圧による平均消費電力（同時ON点数分の消費電力） (原本 p.609)

```
WOUT = IOUT × Vdrop × 出力点数 × 同時ON率 (W)
```

- IOUT：出力電流（実使用上の電流）(A)
- Vdrop：各出力ユニットのドロップ電圧 (V)

### (5) 入力ユニットの入力部平均消費電力（同時ON点数分の消費電力） (原本 p.609)

```
WIN = IIN × E × 入力点数 × 同時ON率 (W)
```

- IIN：入力電流（交流の場合は実効値）(A)
- E：入力電圧（実使用上の電圧）(V)

### (6) インテリジェント機能ユニットの外部供給電源部の消費電力 (原本 p.609)

```
WS = I+15V×15 + I-15V×15 + I24V×24 (W)
```

以上により，各ブロック別に計算した消費電力を合計した値が，シーケンサシステム全体の消費電力になります。

```
W = WPW + W5V + W24V + WOUT + WIN + WS (W)
```

この全体の消費電力(W)より，発熱量の計算・盤内温度上昇の計算を行ってください。
盤内温度上昇の概略の計算式を次に示します。

```
T = W / (U×A) (℃)
```

- W：シーケンサシステム全体の消費電力（上記で求めた値）
- A：盤内の表面積〔m2〕
- U：ファンなどにより盤内の温度を均一にしているとき･･･6
  盤内の空気を循環させていないとき･･･4

盤内の温度が規定範囲を超える場合は，熱交換器を盤に取り付けて盤内温度を下げることを推奨します。
通常の換気扇を使用しますと，外部の空気と共にほこりなども吸い込みます。
ほこりなどにより，シーケンサへの影響が出ることがありますので，注意してください。

### (7) 平均消費電力の計算例 (原本 p.609-610)

#### (a) システム構成

【図】計算例のシステム構成(原本 p.609): 電源ユニットQ61P、CPUユニットQ02HCPU、ベースユニットQ35Bに、入力ユニットQX40、出力ユニットQY40P、アナログ出力ユニットQ62DA、通信ユニットQJ71LP21-25を装着した構成。

#### (b) 各ユニットのDC5V/DC24V消費電流 (原本 p.610)

| 形名 | DC5V | DC24V |
|---|---|---|
| Q02HCPU | 0.64A | － |
| QX40 | 0.05A | － |
| QY40P | 0.065A | 0.01A |
| QJ71LP21-25 | 0.55A | － |
| Q62DA | 0.33A | 0.12A |
| Q35B | 0.11A | － |

#### (c) 電源ユニットの消費電力

```
WPW = 3/7×(0.64 + 0.05 + 0.05 + 0.065 + 0.55 + 0.33 + 0.11)×5
    = 3.85(W)
```

#### (d) 各ユニットの合計DC5Vロジック部の消費電力

```
W5V = (0.64 + 0.05 + 0.05 + 0.065 + 0.55 + 0.33 + 0.11)×5
    = 8.98(W)
```

#### (e) 出力ユニットの合計DC24V平均消費電力 (原本 p.610)

```
W24V = 0.01×24×1 = 0.24(W)
```

#### (f) 出力ユニット出力部ドロップ電圧による消費電力 (原本 p.610)

```
WOUT = 0.1×0.2×16×1 = 0.32(W)
```

#### (g) 入力ユニットの入力部平均消費電力 (原本 p.610)

```
WIN = 0.004×24×32×1 = 3.07(W)
```

#### (h) インテリジェント機能ユニットの外部供給電源部の消費電力 (原本 p.610)

```
WS = 0.12×24 = 2.88(W)
```

#### (i) システム全体の消費電力 (原本 p.610)

```
W = 3.85 + 8.98 + 0.24 + 0.32 + 3.07 + 2.88 = 19.34(W)
```

> Point
> 二重化システム（二重化CPU使用時）を構成した場合の発熱量は，制御系側／待機系側の各々に対して，単独システムを構成した場合と同様の計算方法で計算した結果を加算した値となります。

## 付12 EU加盟国内でのバッテリおよびバッテリ組込み機器の取扱いについて (原本 p.612-613)

EU加盟国で使用済みバッテリを廃棄する場合，または EU加盟国にバッテリおよびバッテリ組込み機器を輸出する場合の注意事項について記載します。

### 付12.1 廃棄時の注意事項 (原本 p.612)

EU加盟国では使用済みのバッテリに対して分別収集システムがありますので，各地域の収集／リサイクルセンタにて，バッテリを正しく処理していただけるようお願いいたします。

三菱電機シーケンサでは，バッテリまたはバッテリ組込み機器の梱包に下記のシンボルマークを表示しています。

【図】シンボルマーク(原本 p.612): バッテリ（電池）の絵に大きな×印を重ねた、いわゆる「ゴミ箱に×」型の分別回収シンボルマーク。

注：このシンボルマークは，欧州電池規則（（EU）2023/1542）の第13条「電池のラベル表示およびマーキング」および付属書Ⅵにて指定されています。

上記シンボルマークは，バッテリを廃棄する際に，一般ゴミとは分別して処理する必要があることを意味しています。

### 付12.2 輸出時の注意事項 (原本 p.613)

欧州電池規則（（EU）2023/1542）の施行に伴い，バッテリおよびバッテリ組込み機器を EU加盟国に販売，輸出する場合は，下記の対応が義務づけられます。

- バッテリ（不可の場合マニュアルと包装）にシンボルマーク（A）（B）の表示
- マニュアルへのシンボルマーク（A）に関する説明の記載

なお，シンボルマーク（A）の表示および説明については欧州新電池指令（2006/66/EC）より継続の内容となります。

#### (1) シンボルマークの表示 (原本 p.613)
