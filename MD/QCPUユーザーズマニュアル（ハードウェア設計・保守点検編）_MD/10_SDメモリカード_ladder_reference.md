## 第10章 冒頭 (原本 p.240)

## 10.3 SD メモリカードの取扱いについて (10.3 / 原本 p.242)

SD メモリカードの取扱いについて，下記に示します。
- 三菱電機製の SD メモリカード（NZ1MEM-◇GBSD）を使用してください。＊1
  三菱電機製以外の SD メモリカードを使用した場合，SD メモリカード内のデータの破損，またはシステ
  ム停止などの問題が発生する恐れがあります。
- 三菱電機製 SD メモリカードは，使用可能ユニットに装着された状態で，IEC61131-2 に適合しています。
- 使用する SD メモリカードのカード種別が「SDHC」の場合は，SDHC ロゴが機器または取扱説明書に記載
  されている製品でのみ使用できます。「SD」のみに対応した製品では使用できませんのでご注意ください。
- CPU ユニットで使用する SD メモリカードは，すべてフォーマットされていることが必要です。
  なお，弊社の SD メモリカードは，フォーマット済みとなっています。 フォーマットされていない市販の
  SD メモリカードを使用する場合は，フォーマットしたあとに使用してください。
- SD メモリカードのフォーマットは，プログラミングツールで行ってください。（パソコンなどでフォー
  マットしないでください。）（使用するプログラミングツールのオペレーティングマニュアル）
- SD メモリカードへのアクセス中に電源 OFF，リセット，または SD メモリカードの取出しを行うと，SD メ
  モリカード内のデータが壊れる可能性があります。必ず SD メモリカードへのアクセスを停止してから電
  源 OFF，リセット，または SD メモリカードの取出しを行ってください。（96ページ 4.6節(2)）
  なお，SM606（SD メモリカード強制使用停止指示），SM607（SD メモリカード強制使用停止状態フラ
  グ）を用いることで，SD メモリカードの使用の一括停止および使用停止状態の確認ができます。
- 大切なデータは，CD や DVD など他のメディアに保存するなど定期的にバックアップすることを推奨しま
  す。

＊1 市販の SD メモリカードをご使用になる場合は，一般仕様（113ページ 第5章）における動作を弊社にて保証
いたしかねますので，対象システムにおける制御に問題がないことをお客様にて十分検証願います。

## 10.4 SD メモリカード強制使用停止について (10.4 / 原本 p.243)

CPU ユニットの電源 ON/OFF 前に，SD604（メモリカード使用状況）の ON 状態にかかわらず，SD メモリカー
ドの使用を停止できます。

### (1) 強制使用停止の方法 (原本 p.243)

1. SM606（SD メモリカード強制使用停止指示）を ON すると，SD604（メモリカード使用状況）の ON 状
   態にかかわらず，CPU ユニットに装着された SD メモリカードの使用を停止できます。
   SD メモリカード強制使用停止状態は，SM607（SD メモリカード強制使用停止状態フラグ）で確認し
   ます。
2. SD CARD LED が消灯します。

### (2) 強制使用停止の解除 (原本 p.243)

SD メモリカード強制使用停止状態は，下記操作で解除できます。
- CPU ユニットの電源 OFF→ON
- リセット操作
- SM606（SD メモリカード強制使用停止指示）の OFF＊1

＊1 SM606（SD メモリカード強制使用停止指示）の ON による停止指示後，SM607（SD メモリカード強制使用停止状
態フラグ）が変化するまでの間は，SM606（SD メモリカード強制使用停止指示）の ON/OFF 状態変化による指示
は無効となります。

### (3) 注意事項

- SD メモリカード強制使用停止中に，各機能で SD メモリカードへのアクセスを行った場合は，SD メモリ
  カードが未装着の場合と同様の動作となります。ただし，FREAD/FWRITE/COMRD(P)/QCDSET(P)
  命令に関しては，未装着時と動作が異なり無処理となります。
- SD メモリカードを装着し，SM606（SD メモリカード強制使用停止指示）を ON した状態の場合，SM606
  （SD メモリカード強制使用停止指示）を OFF することで，SD メモリカードを使用可能状態にできます。
- 外部機器からのファイル書込み中に SD メモリカード強制使用停止を行うと，ファイルの書込みに失敗する
  ことがあります。この場合，SD メモリカード強制使用停止状態を解除してから再度ファイルの書込みを
  行ってください。

【図】SM606/SM607タイミングチャート(原本 p.243)。読み取れる事実:
- SM606（SDメモリカード強制使用停止指示）：OFF→ONに立ち上げると強制使用停止指示が発効する。
- SM607（SDメモリカード強制使用停止状態フラグ）：SM606のON後，遅れてONする（強制使用停止状態になったことを示す）。
- 区間1「SM606の状態による指示有効」：SM606がOFFの間、SM606のON/OFF状態変化による指示は有効に働く。
- 区間2「SM606の状態による指示無効」：SM606がONからSM607がONに変化するまでの間、SM606の状態変化による指示は無効となる(前述＊1の注記に対応)。
- 区間3「SM606の状態による指示有効」：SM607がON状態になった後は、再びSM606のOFF状態による強制使用停止状態解除指示が有効となる。
