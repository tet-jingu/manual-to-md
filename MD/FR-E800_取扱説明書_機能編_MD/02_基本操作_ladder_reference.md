## 2 基本操作 (2 / 印刷 p.20 / 原本 p.21)

この章では、本製品の基本的な操作方法について説明しています。
注意事項など必ず一読してからご使用ください。

### 2.1 操作パネルについて (2.1 / 印刷 p.20 / 原本 p.21)

#### 2.1.1 操作パネルの各部の名称 (2.1.1 / 印刷 p.20 / 原本 p.21)

##### ◆ 標準仕様品、CC-Link 通信機能内蔵品 (2.1.1 / 原本 p.21)

操作パネルはインバータから取外しできません。

【図】操作パネル外観(標準仕様品、CC-Link 通信機能内蔵品)と各部番号 (原本 p.21)
- 上段左: (a) 4 桁 7 セグメント LED モニタ、その右に (b) 単位表示 Hz/A、(c) 運転モード表示 PU/EXT/NET、(d) MON/PRM、右端に (e) RUN、(f) PM、(g) P.RUN の各 LED。
- 中段: (i) PU/EXT キー、(j) MODE キー、(k) SET キー。右側に (h) M ダイヤル。
- 下段: (n) USB コネクタ(左下、カバー付き)、(l) RUN キー(緑)、(m) STOP/RESET キー(赤)。

| No. | 操作部 | 名称 | 内容 |
|---|---|---|---|
| (a) | 【図】4 桁 7 セグ LED | モニタ(4 桁 LED) | 周波数、パラメータ番号などを表示します。<br>(**Pr.52**、**Pr.774** ～ **Pr.776** の設定によりモニタ項目の変更が可能です。) |
| (b) | 【図】Hz / A LED | 単位表示 | Hz:周波数を表示するときに点灯します。(設定周波数モニタ表示時は点滅します。)<br>A:電流を表示するときに点灯します。<br>(上記以外を表示するときは「Hz」、「A」ともに消灯します。) |
| (c) | 【図】PU / EXT / NET LED | 運転モード表示 | PU: PU 運転モード時に点灯します。<br>EXT: 外部運転モード時に点灯します。(標準仕様品では初期設定時、電源 ON すると点灯します。)<br>NET: ネットワーク運転モード時に点灯します。(CC-Link 通信機能内蔵品では初期設定時、電源 ON すると点灯します。)<br>外部 /PU 併用運転モード 1、2 時は PU、EXT が同時に点灯します。 |
| (d) | 【図】MON / PRM LED | 操作パネル状態表示 | MON: 第 1 ～ 3 モニタ表示時のみ点灯します。<br>PRM: パラメータ設定モード時に点灯します。簡単設定モードを選択したときは点滅します。 |
| (e) | 【図】RUN LED | 運転状態表示 | インバータ動作中に点灯 / 点滅します。<br>点灯:正転運転中<br>ゆっくり点滅(1.4s サイクル):逆転運転中<br>速い点滅(0.2s サイクル):始動指令が入力されているが運転できない状態 *1 |
| (f) | 【図】PM LED | 制御モータ表示 | PM センサレスベクトル制御設定時に点灯します。<br>テスト運転を選択したときは点滅します。誘導モータ設定時は消灯します。 |
| (g) | 【図】P.RUN LED | シーケンス機能有効表示 | シーケンス機能が動作している場合に点灯します。(シーケンスエラー発生中は点滅します。) |
| (h) | 【図】M ダイヤル | M ダイヤル | 三菱電機インバータのダイヤルを表します。周波数設定、パラメータの設定値を変更します。<br>押すことで下記表示が可能です。<br>• モニタモード時の設定周波数表示(**Pr.992** で変更可能)<br>• 校正時の現在設定値表示 |
| (i) | 【図】PU/EXT キー | PU/EXT キー | 標準仕様品は PU 運転モード、PUJOG 運転モード、外部運転モードを切り換えます。<br>CC-Link 通信機能内蔵品は PU 運転モード、PUJOG 運転モード、ネットワーク運転モードを切り換えます。<br>[MODE] キーと同時押しすることで運転モードの簡単設定モードへ移行します。<br>PU 停止解除も行います。 |
| (j) | 【図】MODE キー | MODE キー | 各モードを切り換えます。<br>[PU/EXT] キーと同時押しすることで運転モードの簡単設定モードへ移行します。<br>長押し(2s)で操作ロックが行えます。**Pr.161** = “0”(初期値)ではキーロックモード無効です。(238 ページ参照) |
| (k) | 【図】SET キー | SET キー | 各設定を確定します。<br>運転中に押すとモニタ内容が変わります。<br>(**Pr.52**、**Pr.774** ～ **Pr.776** の設定によりモニタ項目の変更が可能です。)<br>【図】初期設定時:出力周波数 → 出力電流 → 出力電圧 → (出力周波数へ戻る) |
| (l) | 【図】RUN キー | RUN キー | 始動指令<br>**Pr.40** の設定により、回転方向が選択できます。**Pr.40** = “0”(初期値)では正転始動します。 |
| (m) | 【図】STOP/RESET キー | STOP/RESET キー | 運転指令を停止します。<br>保護機能動作時は、インバータのリセットを行います。 |
| (n) | 【図】USB コネクタ | USB コネクタ | USB 接続により FR Configurator2 を使用できます。 |

*1 MRS 信号、X10 信号が入力されている状態、瞬停再始動中、オートチューニング完了後、SE( パラメータ誤設定 ) 警報時など

##### ◆ IP67 仕様品 (2.1.1 / 原本 p.24)

操作パネルはインバータから取外しできません。IP67 仕様品は M ダイヤルやキーによる操作ができません。

【図】操作パネル外観(IP67 仕様品)と各部番号 (原本 p.24)
- 上段: (a) 4 桁 7 セグ LED モニタ、(b) Hz/A、(c) PU/EXT/NET、(d) MON/PRM、(e) RUN、(f) PM、(g) P.RUN。

#### 2.5.1 周波数を設定して運転する（30Hz で運転する） (2.5.1 / 印刷 p.35 / 原本 p.36)

- **Pr.79 運転モード選択**＝ "0（初期値）"（PU 運転モード）に設定します。

【図】操作パネル (原本 p.36)

- 操作パネル2種(M ダイヤル付きのものと、上下キー（↑↓）付きで NS/MS/LINK1/LINK2 表示のもの)の図。

30Hz で運転する場合の操作手順を示します。

##### 操作手順 (2.5.1 / 原本 p.36)

1. 電源投入時画面
   モニタ表示になります。
2. 運転モードの変更
   [PU/EXT] キーを押して PU 運転モードにします。[PU]LED が点灯します。
3. 周波数の設定
   M ダイヤルを回す、または上下キーを押して設定したい周波数 "30.00"（30.00Hz）を表示させます。約 5s 間点滅します。
   数値が点滅している間に [SET] キーを押して周波数を設定します。"F" と "30.00" が交互にフリッカーします。約 3s 間フリッカーした後表示は "0.00"（モニタ表示）に戻ります。（[SET] キーを押さないと約 5s 間点滅した後表示は "0.00"（0.00Hz）に戻ってしまいます。その際は、もう一度 M ダイヤルを回す、または上下キーを押して周波数を設定してください。）
4. 始動→加速→定速
   [RUN] キーを押して運転します。**Pr.40 RUN キー回転方向選択**＝ "0"（初期値）の場合は正転、"1" の場合は逆転となります。表示部の周波数値が **Pr.7 加速時間** に従って大きくなり、"30.00"（30.00Hz）を表示します。（設定周波数を変更する場合は " 操作 3" を行ってください。前の設定周波数から始まります。）
5. 減速→停止
   [STOP/RESET] キーを押すと停止します。表示部の周波数値が **Pr.8 減速時間** に従って小さくなり "0.00"（0.00Hz）を表示し、モータは運転を停止します。

##### NOTE (2.5.1 / 原本 p.37)

- 標準仕様品は、PU 運転モードおよび外部 /PU 併用運転モード 1（**Pr.79**="3"）のとき、M ダイヤルを押すと設定周波数を表示します。（350 ページ参照）
- **Pr.161 周波数設定 / キーロック操作選択**＝ "1、11" に設定すると、[SET] キーを押さなくても周波数を設定することができます。（238 ページ参照）
- **Pr.79** ＝ "1" に設定した場合でも運転可能です。

#### 2.5.2 周波数設定をスイッチで行う（3 速設定） (2.5.2 / 印刷 p.36 / 原本 p.37)

##### Point (2.5.2 / 原本 p.37)

- 始動指令は操作パネル（[RUN] キー）で行います。

- **Pr.79 運転モード選択**＝ "4"（外部 /PU 併用運転モード 2）に設定します。

【結線例】

【図】3 速設定の結線例と速度・信号のタイミング図 (原本 p.37)

- 結線（インバータ端子 ← スイッチ）:
  - 高速スイッチ → 端子 RH
  - 中速スイッチ → 端子 RM
  - 低速スイッチ → 端子 RL
  - スイッチのコモン → 端子 SD
- 操作パネル（M ダイヤル付き／上下キー付きの2種）の [RUN] キーを指で押す図。

  - RH が ON の間: 1速(高速)
  - RH OFF 後、RM が ON の間: 2速(中速)
  - RM OFF 後、RL が ON の間: 3速(低速)
  - RL OFF で減速して停止。出力周波数は 1速 > 2速 > 3速 の階段状。

低速（10Hz）で運転する場合の操作手順を示します。

4. 始動→加速→定速
   [RUN] キーを押して運転します。**Pr.40 RUN キー回転方向選択**＝ "0"（初期値）の場合は正転、"1" の場合は逆転となります。表示部の周波数値が **Pr.7 加速時間**に従って大きくなり、"10.00"（10.00Hz）を表示します。

- Ethernet 仕様品は外部入力端子を最大 2 つまで使用可能です。**Pr.178 STF/DI0 端子機能選択**、**Pr.179 STR/DI1 端子機能選択**で端子 DI0、DI1 に機能を割り付けて使用します。

   **Pr.79** を "3" に設定します。[PU]LED と [EXT]LED が点灯します。（設定値の変更については、29 ページを参照してください。）
3. 周波数の設定
   M ダイヤル回す、または上下キーを押して設定したい周波数 "30.00"（30.00Hz）を表示させます。約 5s 間点滅します。
   数値が点滅している間に [SET] キーを押して周波数を設定します。"F" と "30.00" が交互にフリッカーします。約 3s 間フリッカーした後表示は "0.00"（モニタ表示）に戻ります。（[SET] キーを押さないと約 5s 間点滅した後表示は "0.00"（0.00Hz）に戻ってしまいます。その際は、もう一度 M ダイヤル回す、または上下キーを押して周波数を設定してください。）
4. 始動→加速→定速
   始動スイッチ（STF または STR）を ON します。表示部の周波数値が **Pr.7 加速時間**に従って大きくなり、"30.00"（30.00Hz）を表示します。正転時は [RUN]LED が点灯、逆転時はゆっくり点滅します。（設定周波数を変更する場合は " 操作 2" を行ってください。前の設定周波数から始まります。）
5. 減速→停止
   始動スイッチ（STF または STR）を OFF します。表示部の周波数値が **Pr.8 減速時間** に従って小さくなり "0.00"（0.00Hz）を表示し、モータは運転を停止します。

- 正転スイッチ（STF）と逆転スイッチの（STR）両方が ON すると始動しません。また、運転中に両方が ON すると減速停止します。

- 外部運転中に操作パネルの [STOP/RESET] キーで停止すると PU 停止状態になります。（操作パネルに "PS" を表示します。）PU 停止状態は始動スイッチ（STF または STR）を OFF してから [PU/EXT] キーで解除できます。（233 ページ参照）

#### 2.7.1 外部からの信号で JOG 運転する (2.7.1 / 印刷 p.48 / 原本 p.49)

> **Point**
> - JOG 信号は制御回路端子入力でのみ有効です。
> - JOG 信号を ON しているあいだは JOG 運転できます。
> - **Pr.15 JOG 周波数、Pr.16 JOG 加減速時間**により運転します。
> - **Pr.79 運転モード選択** ＝ “0（初期値）”（外部運転モード）に設定します。

【結線例】

【図】結線例（スイッチによる JOG 運転） (原本 p.49)
- 正転始動スイッチ → 端子 STF
- 逆転始動スイッチ → 端子 STR
- JOG 信号スイッチ → 端子 RL(JOG)
- 各スイッチのコモン側 → 端子 SD

5Hz で運転する場合の操作手順を示します。

##### 操作手順 (2.7.1 / 原本 p.49)

1. 電源投入時画面  
   モニタ表示になります。
2. 運転モードの変更  
   [PU/EXT] キーを押して PU 運転モードにします。[PU]LED が点灯します。
3. JOG 信号の割付け  
   **Pr.180 RL 端子機能選択**に 5 を設定し、端子 RL に JOG 信号を割り付けます。（設定値の変更については、26 ページを参照してください。）
4. 運転モードの変更  
   [PU/EXT] キーを押して外部運転モードにします。[EXT]LED が点灯します。
5. JOG 信号の ON  
   JOG スイッチ（JOG）を ON します。JOG 運転が可能な状態になります。
6. 始動→加速→定速  
   始動スイッチ（STF または STR）を ON します。表示部の周波数値が **Pr.16 JOG 加減速時間** に従って大きくなり、“5.00”（5.00Hz）を表示します。正転時は [RUN]LED が点灯、逆転時はゆっくり点滅します。
7. 減速→停止  
   始動スイッチ（STF または STR）を OFF します。表示部の周波数値が **Pr.16 JOG 加減速時間**に従って小さくなり “0.00”（0.00Hz）を表示し、モータは運転を停止します。[RUN]LED が消灯します。JOG スイッチ（JOG）を OFF します。

> **NOTE**
> - 設定周波数を変更したい場合は、**Pr.15 JOG 周波数**を変更してください。（初期値 “5Hz”）
> - 加減速時間を変更したい場合は、**Pr.16 JOG 加減速時間** を変更してください。（初期値 “0.5s”）
> - JOG 信号は他の端子に割り付けることも可能です。**Pr.178 ～ Pr.184（入力端子機能選択）**に “5” を設定し、入力端子に機能を割り付けてください。（Ethernet 仕様品、IP67 仕様品は **Pr.178、Pr.179** で端子 DI0 または端子 DI1 に割り付けてください。）
> - JOG2 信号を使用すると通信による JOG 運転が可能です。（304 ページ参照）
> - Pr.79 ＝ “0” 設定で電源 ON 時に外部運転モードにするためには、**Pr.340 通信立上りモード選択**＝ “0” としてください。
> - Pr.79 ＝ “2” に設定した場合でも運転可能です。

**参照パラメータ** (原本 p.50)
- Pr.15 JOG 周波数、Pr.16 JOG 加減速時間 ☞ 304 ページ
- Pr.79 運転モード選択 ☞ 284 ページ
- Pr.178 ～ Pr.184（入力端子機能選択） ☞ 410 ページ
- Pr.340 運転モード選択 ☞ 293 ページ（※原本表記のまま。Pr.340 の名称は他箇所では「通信立上りモード選択」）

#### 2.7.2 操作パネルで JOG 運転する (2.7.2 / 印刷 p.49 / 原本 p.50)

> **Point**
> - [RUN] キーを押しているあいだだけ運転します。

【図】操作パネル (原本 p.50)
- 2 種類の操作パネル（M ダイヤル付きのもの、上下キー付きのもの）が描かれ、いずれもモニタに “JOG” が表示された状態で [RUN] キーを指で押している図

5Hz で運転する場合の操作手順を示します。

##### 操作手順 (2.7.2 / 原本 p.50)

1. 電源投入時画面  
   モニタ表示になります。
2. 運転モードの変更  
   [PU/EXT] キーを 2 回押して PUJOG 運転モードにします。モニタが ”JOG” を表示し、[PU]LED が点灯します。
3. 始動→加速→定速  
   [RUN] キーを押し続けます。**Pr.40 RUN キー回転方向選択**＝ “0”（初期値）の場合は正転、“1” の場合は逆転となります。表示部の周波数値が **Pr.16 JOG 加減速時間**に従って大きくなり、“5.00”（5.00Hz）を表示します。
4. 減速→停止  
   [RUN] キーを離します。表示部の周波数値が **Pr.16 JOG 加減速時間** に従って小さくなり “0.00”（0.00Hz）を表示し、モータは運転を停止します。

> **NOTE**
> - 設定周波数を変更したい場合は、**Pr.15 JOG 周波数** を変更してください。（初期値 “5Hz”）
> - 加減速時間を変更したい場合は、**Pr.16 JOG 加減速時間** を変更してください。（初期値 “0.5s”）
> - IP67 仕様品は操作パネルのキーおよびパラメータユニットを使用できないため、PUJOG 運転に対応しません。

**参照パラメータ**
- Pr.15 JOG 周波数、Pr.16 JOG 加減速時間 ☞ 304 ページ
