## 6.4 位置決めプログラム例（6.4 / 6-17〜6-43 / 原本 p.345-371）

### [No.1]～[No.4] パラメータ・データ設定プログラム（原本 p.345）

【枠内注記（原文）】
> ・パラメータやデータをシーケンスプログラムで設定する場合は，シーケンサCPUからTO命令を使ってシンプルモーションユニットに設定する。(設定はシーケンサレディ信号[Y0]OFFにて行う。）
> ・パラメータやデータをGX Works2で設定する場合は，[No.1]～[No.4]のプログラムは不要

#### No.1 パラメータ設定プログラム（原本 p.345-346）

```
; *
; * No.1　パラメータ設定プログラム
; * （基本パラメータ1<軸1>の場合）
; * 原点復帰パラメータ
; *
; *
; *
[ステップ0]
LD     SM402                          ;; RUN後1スキャンのみON
; ＊<変更速度設定(90.00mm/min)>
DMOVP  K9000     D1                   ;; D1: 速度（下位16ビット）
; ＊<変更後の移動量設定(5000.0μm)>
DMOVP  K50000    D3                   ;; D3: 移動量(下位16ビット)
; ＊<単位設定（0:mm）の設定>
MOVP   K0        D50                  ;; D50: 単位設定
; ＊<単位倍率（1倍）の設定>
MOVP   K1        D51                  ;; D51: 単位倍率:AM
; ＊<1回転あたりのパルス数(4194304PLS)>
DMOVP  K4194304  D52                  ;; D52: 1回転あたりのパルス数(下位16):AP
; ＊<1回転あたりの移動量(2500.0μm)>
DMOVP  K25000    D54                  ;; D54: 1回転あたりの移動量(下位16):AL
; ＊<QD77への基本パラメータ1の設定>
TOP    H0  K0    D50    K8            ;; D50: 単位設定
; ＊<外部指令機能選択(2:速度/位置)>
TOP    H0  K62   K2     K1
; ＊<原点復帰方法(データセット式)>
TOP    H0  K70   K6     K1
; ＊<原点復帰速度(15.00mm/min)>
DTOP   H0  K74   K1500  K1
; ＊<クリープ速度設定(12.00mm/min)>
DTOP   H0  K76   K1200  K1
; ＊<基本パラメータ1設定完了>
SET    M50                            ;; パラメータ設定完了デバイス

; * 単位Degree設定用プログラム
; * ＜軸1の場合＞
; * （速度・位置切換え制御（ABSモード）を実行する場合など
; * ＜X4Dは立上げ前にON＞
; *
[ステップ64]
LD     SM402                          ;; RUN後1スキャンのみON
AND    X4D                            ;; 単位(degree)の場合
; ＊<単位設定（2:degree）の設定>
TOP    H0  K0    K2         K1
; ＊<1回転あたりの移動量:AL>
DTOP   H0  K4    K9000000   K1
; ＊<速度制限値(20000.000deg/min)>
DTOP   H0  K10   K20000000  K1
; ＊<（S/Wストロークリミット上限）=0>
DTOP   H0  K18   K0         K1
; ＊<（S/Wストロークリミット下限）=0>
DTOP   H0  K20   K0         K1
; ＊<（速度制御時の送り現在値）=0>
TOP    H0  K30   K1         K1
; ＊<速度・位置機能選択（ABSモード）>
TOP    H0  K34   K2         K1
; ＊<JOG速度制限値(20000.000deg/min)>
DTOP   H0  K48   K20000000  K1
; ＊<原点復帰速度(1000.000deg/min)>
DTOP   H0  K74   K1000000   K1
; ＊<クリープ速度(800.000deg/min)>
DTOP   H0  K76   K800000    K1
```

#### No.2 位置決めデータ設定プログラム（原本 p.347-351）

分岐の途中にある接点（X4D）は `MPS`／`MRD`／`MPP` で表記しています（原本では SM402 の後の母線から各出力へ分岐し、一部の分岐にのみ X4D が入る）。

**No.2-1（位置決めデータNo.1）（原本 p.347）**
```
; *
; * No.2-1　位置決めデータ設定プログラム
; * （位置決めデータNo.1<軸1>の場合）
; * ＜位置決め識別子＞
; * 　　運転パターン：位置決め終了
; * 　　制御方式：1軸の直線制御（ABS）
; * 　　加速時間No.：1，減速時間No.：2
; *
[ステップ138]
LD     SM402                          ;; RUN後1スキャンのみON
; ＊<位置決め識別子の設定>
MOVP   H190      D100                 ;; 位置決め識別子
; ＊<Mコード（9843）の設定>
MOVP   K9843     D101                 ;; Mコード
; ＊<ドウェルタイム（300ms）の設定>
MOVP   K300      D102                 ;; ドウェルタイム
; ＊<（ダミーデータ）>
MOVP   K0        D103                 ;; (ダミー)
; ＊<指令速度（20.00mm/min）の設定>
DMOVP  K2000     D104                 ;; 指令速度（下位16ビット）
MPS
AND    X4D                            ;; 単位(degree)の場合
; ＊<指令速度（1200.000deg/min）>
DMOVP  K1200000  D104                 ;; 指令速度（下位16ビット）
MRD
; ＊<位置決めｱﾄﾞﾚｽ（-10000.0μm）設定>
DMOVP  K-100000  D106                 ;; 位置決めアドレス（下位16ビット）
MRD
AND    X4D                            ;; 単位(degree)の場合
; ＊<位置決めｱﾄﾞﾚｽ（270.00000deg）>
DMOVP  K27000000 D106                 ;; 位置決めアドレス（下位16ビット）
MRD
; ＊<円弧アドレス（0.0μm）の設定>
DMOVP  K0        D108                 ;; 円弧アドレス（下位16ビット）
MPP
; ＊<位置決めデータNo.1の設定>
TOP    H0  K2000  D100  K10           ;; D100: 位置決め識別子
```
