## 第6章 位置決め制御に使用するシーケンスプログラム（6-1 / 原本 p.329）

本章では，シンプルモーションユニットを使った位置決め制御を行うために必要なプログラムについて説明しています。

制御に必要なシーケンスプログラムは，「始動条件」，「始動タイムチャート」，「デバイス設定」，制御全体の構成などを考慮して作成します。
（実行したい制御に合わせて，パラメータや位置決めデータ，ブロック始動データ，条件データなどをシンプルモーションユニットに設定し，制御データの設定プログラムや各制御の始動プログラムを作成する必要があります。）

本章では，前半で制御全体のプログラムの構成を説明し，後半でプログラムの詳細について説明しています。「第２部」で説明している各制御の詳細や「第５章 位置決め制御に使用するデータ」を参照しながら，必要なプログラムを作成してください。

## 6.1 プログラム作成上の注意事項（6.1 / 6-2〜6-4 / 原本 p.330-332）

シーケンサCPUからシンプルモーションユニットのバッファメモリへデータを書き込むときの，共通の注意事項を示します。本マニュアルで紹介するプログラム例を実際のシステムへ流用する場合は，対象システムにおける制御に問題がないことを十分検証ください。

### (1) データの読出し／書込み（6.1 / 原本 p.330）

> 本章に示すデータの設定（各種パラメータ，位置決めデータ，ブロック始動データ）は，できるだけ GX Works2 で行われることをおすすめします。
> シーケンスプログラムで設定する場合，かなりのシーケンスプログラムとデバイスを使用しますので，複雑になると共に，スキャンタイムの増大につながります｡
> また，連続軌跡制御／連続位置決め制御中に位置決めデータを書換える場合は，4 つ前の位置決めデータを実行するまでに書換えてください。
> 4 つ前の位置決めデータを実行する前に位置決めデータの書換えが行われていない場合，データは書換えられていないものとして処理されます。

### (2) 速度変更実行間隔の制約（6.1 / 原本 p.330）

> シンプルモーションユニットで速度変更，またはオーバライドを行う場合は，100ms 以上の間隔で行ってください。

### (3) オーバラン時の処理（6.1 / 原本 p.330）

> 詳細パラメータ 1 でストロークリミット上限値および下限値の設定にて，オーバランの防止にはなります。
> ただし，これはシンプルモーションユニットが正常に動作している場合のみ有効です。
> システムの安全性からみて限界リミットスイッチを設け，リミットスイッチ作動によって，サーボアンプの主回路電源を OFF するような外部の回路を設けることをおすすめします。

### (4) システム構成（6.1 / 原本 p.330）

> 本章以降では特別に断りのない場合，QD77MS4 を使用した下記システムでのシーケンスプログラムを示しています。
> 使用するデバイスの用途については，6.2 節を参照してください。

### (5) 制御単位（6.1 / 原本 p.331）

> プログラムは，基本パラメータ 1 の設定単位は，“「0：mm」，「2：degree」”を設定した場合を示しています。

### (6) シンプルモーションユニットとの交信（6.1 / 原本 p.331-332）

> シーケンスプログラムによるシンプルモーションユニットとの交信には，“インテリジェント機能デバイス”を使用する方法と，FROM/TO 命令を使用する方法の 2 種類があります。
> 本章以降のシーケンスプログラムは，シンプルモーションユニットとの交信に FROM/TO 命令を使用しないで，“インテリジェント機能デバイス”を使用したプログラム例になっています。
> シンプルモーションユニットとの交信に FROM/TO 命令を使用する場合は，“インテリジェント機能デバイス”を使用した回路を次のように変更してください。

#### (a) MOV 命令のディスティネーション(D)側に“インテリジェント機能デバイス”を使用している回路は，TO 命令に変更します。（原本 p.331）

変更前：
```
LD    X21
MOVP  K1  U0\G1505          ; U0\G1505 = インテリジェント機能デバイス
```
変更後：
```
LD    X21
TOP   H0  K1505  K1  K1
```
- 図中の注記：`H0` ＝ U0 での指定値、`K1505` ＝ G1505 での指定値、第3オペランド `K1` ＝ MOVP のソース K1、第4オペランド `K1` ＝ 書込みデータ数(1)

#### (b) MOV 命令のソース(S)側とディスティネーション(D)側に“インテリジェント機能デバイス”を使用している回路は，FROM 命令と TO 命令に変更します。（原本 p.331）

変更前：
```
LD    X15
AND   X0C
MOVP  U0\G826  U6\G1
```
変更後：
```
LD    X15
AND   X0C
FROMP H0  K826  D100  K1     ; U0\G826 → H0 K826
TOP   H6  K1    D100  K1     ; U6\G1  → H6 K1
```
- 図中の注記：FROMP と TOP の `D100` は「同一デバイスを設定」

#### (c) 比較命令に“インテリジェント機能デバイス”を使用している回路は，FROM 命令と比較命令に変更します。（原本 p.331）

変更前：
```
LD    M0
AND=  U0\G1521  K0
RST   M0
```
変更後：
```
LD    M0
FROMP H0  K1521  D102  K1    ; U0\G1521 → H0 K1521
AND=  D102  K0               ; D102 = 読出したデータ
RST   M0
```
（変更後の回路は、M0 の後で分岐し、上段が FROMP、下段が `[= D102 K0]` → `RST M0`）

#### (d) WAND 命令に“インテリジェント機能デバイス”を使用している回路は，FROM 命令と WAND 命令に変更します。（原本 p.332）

変更前：
```
LD    M2
WANDP U0\G817  H8  D0
```
変更後：
```
LD    M2
FROMP H0  K817  D101  K1     ; U0\G817 → H0 K817
WANDP D101  H8  D0           ; D101 = 読出したデータ
```

### (7) QD77MS2/QD77MS4 から QD77MS16 へのシーケンスプログラムの変換（6.1 / 原本 p.332）

> QD77MS2/QD77MS4 のシーケンスプログラムを QD77MS16 に変換する場合は，配置の異なる入出力信号を以下のように変更してください。

#### (a) インデックス修飾を行っていない場合（6.1 / 原本 p.332）

変更前（QD77MS4）：
```
LD    M29        ; 停止指令パルス
AND   X0C        ; BUSY信号(QD77MS4軸1)
SET   Y4         ; 軸停止信号(QD77MS4軸1)
```
変更後（QD77MS16）：
```
LD    M29        ; 停止指令パルス
AND   X10        ; BUSY信号(QD77MS16軸1)
SET   U0\G30100.0   ; 軸停止信号(QD77MS16軸1)
```

#### (b) インデックス修飾を行っている場合（6.1 / 原本 p.332）

変更前（QD77MS4）：Z0：軸番号－1
```
LD    M29        ; 停止指令パルス
AND   X0CZ0      ; BUSY信号(QD77MS4軸1)
SET   Y4Z0       ; 軸停止信号(QD77MS4軸1)
```
変更後（QD77MS16）：Z0：軸番号－1，Z1：(軸番号－1)×10
```
LD    M29        ; 停止指令パルス
AND   X10Z0      ; BUSY信号(QD77MS16軸1)
MOV   K1  U0\G30100Z1   ; 軸停止信号(QD77MS16軸1)
```

## 6.3 プログラムの作成（6.3 / 6-12 / 原本 p.340）

> 本章では，実際に使用する「位置決め制御の運転プログラム」について説明します。「第２部」で説明している機能やプログラムは，本章で説明する「位置決め制御の運転プログラム」に組み込んで使用します。（制御のモニタを行う場合は，システムに応じて必要なモニタプログラムを追加してください。モニタ項目については「5.6節 モニタデータ一覧」を参照してください。）

### 6.3.1 プログラムの全体構成（6.3.1 / 6-12 / 原本 p.340）

> 以下に「位置決め制御の運転プログラム」の全体構成を示します。

【図】位置決め制御の運転プログラムの全体構成（フローチャート / 原本 p.340）
1. プログラム作成開始
2. 判断「パラメータやデータの設定は」
   - 「シーケンスプログラムを使って設定する」→ 「パラメータ・データ設定プログラム」→「サーボパラメータ」→ 3へ合流
   - 「GX Works2を使って設定する」→ そのまま3へ
3. 初期設定プログラム ……「初期設定を行うためのプログラム」
4. 始動内容設定プログラム → 5. 始動プログラム ……「「原点復帰制御」，「主要な位置決め制御」，「高度な位置決め制御」，「拡張制御」を行う場合に必要なプログラム」
6. JOG運転用プログラム → 7. インチング運転用プログラム → 8. 手動パルサ運転用プログラム ……「「手動制御」を行う場合に必要なプログラム」
9. 補助プログラム ……「「補助機能」や「共通機能」などに必要なプログラム」
10. 停止プログラム ……「制御を停止させるためのプログラム」
11. プログラム作成終了
- 2の判断から10までを括弧で括って「位置決め制御の運転プログラム」と表記
