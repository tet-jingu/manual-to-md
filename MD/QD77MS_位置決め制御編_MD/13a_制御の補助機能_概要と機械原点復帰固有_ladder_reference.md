## 第13章 制御の補助機能（13-1 / 原本 p.657）

本章では，主機能に機能を付加したり，組み合わせて使用する「補助機能」の詳細や使い方について説明しています。
補助機能には，機械原点復帰固有の補助機能や，制御の補正など全般的に関わる機能など，さまざまな機能があります。これらの補助機能を使うことで，より適正な，きめ細かい制御を行うことができます。
各補助機能は，パラメータの設定やシーケンスプログラムの作成などによって，主機能と共に使用します。各補助機能の設定や実行手順をよくお読みになり，必要な設定を行ってください。

## 13.1 補助機能の概要（13.1 / 13-2〜13-3 / 原本 p.658-659）

> 「補助機能」は，主機能を実行する際，制御の補正，制限，機能の付加などを行う機能です。これらの補助機能は，パラメータの設定や，GX Works2 からの操作，補助機能用のシーケンスプログラムなどによって実行します。

### 13.1.1 補助機能の概要（13.1.1 / 原本 p.658-659）

> 「補助機能」には以下に示すような機能があります。

| 区分 | 補助機能 | 内容 |
|---|---|---|
| 機械原点復帰固有の補助機能 | 原点復帰リトライ機能 | 機械原点復帰中，上限／下限リミットスイッチによって機械原点復帰をリトライする機能。JOG 運転などで近点ドグ以前に戻さなくても機械原点復帰が可能となる。 |
| 機械原点復帰固有の補助機能 | 原点シフト機能 | 機械原点復帰後，機械原点位置から指定の距離だけ位置を補正し，その位置を原点アドレスとする機能。 |
| 制御を補正する機能 | バックラッシュ補正機能 | 機械系のバックラッシュ量の補正を行う機能。移動方向が変わるごとに，設定されているバックラッシュ量だけ余分に指令を出力する。 |
| 制御を補正する機能 | 電子ギア機能 | 1 パルスあたりの移動量設定により，指令 1 パルスあたりの機械移動量を自由に変える機能。1 パルスあたりの移動量設定により，機械系に合わせたフレキシブルな位置決めシステムを構築することができる。 |
| 制御を補正する機能 | 近傍通過機能＊1 | 補間制御時の連続軌跡制御で，位置決めデータ切り換わり時の機械振動を抑える機能。 |
| 制御を制限する機能 | 速度制限機能 | 制御中に指令速度が“[Pr.8]速度制限値”を超えるような場合，指令速度を“[Pr.8]速度制限値”の設定範囲内に制限する機能。 |
| 制御を制限する機能 | トルク制限機能 | 制御中にサーボモータの発生トルクが“[Pr.17]トルク制限設定値”を超えるような場合，発生トルクを“[Pr.17]トルク制限設定値”の設定範囲内に制限する機能。 |
| 制御を制限する機能 | ソフトウェアストロークリミット機能 | パラメータに設定されている上限／下限ストロークリミットの設定範囲外への指令が与えられたとき，その指令に対する位置決めを実行しない機能。 |
| 制御を制限する機能 | ハードウェアストロークリミット機能 | ハードウェアストロークリミットスイッチによって，減速停止を行う機能。 |
| 制御を制限する機能 | 緊急停止機能 | 緊急停止用信号によって，サーボアンプの全軸を一括停止させる機能。 |
| 制御内容を変更する機能 | 速度変更機能 | 位置決め運転中の速度を変更する機能。速度変更用バッファメモリ（[Cd.14]速度変更値）に変更後の速度を設定し，“[Cd.15]速度変更要求”によって速度を変更する。 |
| 制御内容を変更する機能 | オーバライド機能 | 位置決め運転中の速度を 1～300％の割合で変化させる機能。“[Cd.13]位置決め運転速度オーバライド”を使って実行する。 |
| 制御内容を変更する機能 | 加減速時間変更機能 | 速度変更時の加減速時間を変更する機能。（速度変更機能，オーバライド機能の付加機能） |
| 制御内容を変更する機能 | トルク変更機能 | 制御中に「トルク制限値」を変更する機能。 |
| 制御内容を変更する機能 | 目標位置変更機能 | 位置決め実行中に目標位置を変更する機能。位置を変更すると同時に速度の変更も行える。 |
| 絶対位置システム | （同左） | 指定された軸の絶対位置を復元する機能。システム立上げ時に原点復帰を行うと，それ以降，システム電源投入時などの原点復帰が不要となる。 |
| その他の機能 | ステップ機能 | デバッグ時など，位置決め運転の動作を確認するために，運転を一旦停止する機能。「自動減速」もしくは「位置決めデータ」ごとに停止させることができる。 |
| その他の機能 | スキップ機能 | スキップ信号が入力された時点で実行中の位置決めを中断（減速停止）し，次の位置決めを行う機能。 |
| その他の機能 | M コード出力機能 | 位置決めデータごとに設定可能な 0～65535 までの番号で，コード番号に対応した補助作業（クランプやドリルの停止，工具交換など）の指令を行う機能。 |
| その他の機能 | ティーチング機能 | 手動制御によって位置決めしたアドレスを，指定した位置決めデータ No.の“[Da.6]位置決めアドレス／移動量”に格納する機能。 |
| その他の機能 | 指令インポジション機能 | 自動減速ごとに，シンプルモーションユニットが位置決め停止位置までの残距離を演算し，設定した値以下になったとき，「指令インポジションフラグ」を 1 にする機能。制御終了前に他の補助作業を行う場合，補助作業のトリガとして使用する。 |
| その他の機能 | 加減速処理機能 | 制御の加減速の調整を行う機能。 |
| その他の機能 | 先読み始動機能 | 見かけ上の始動時間を短縮する機能。 |
| その他の機能 | 減速開始フラグ機能 | 停止するタイミングを知るため，運転パターンが「位置決め終了」の位置制御時，定速または加速から減速に切り換わったときにフラグを ON する機能。 |
| その他の機能 | 減速停止時停止指令処理機能 | 速度 0 への減速停止処理中に停止要因が発生した場合の減速カーブを選択する機能。 |
| その他の機能 | degree 軸速度 10 倍指定機能 | 単位設定が degree 軸の場合に，指令速度，および速度制限値の 10 倍の速度で位置決め制御を行う機能。 |
| その他の機能 | 原点復帰未完時動作指定機能 | 原点復帰要求フラグ ON の場合に，位置決め制御を実行するか実行しないかを選択する機能。 |
| サーボ ON/OFF | サーボ ON/OFF | シンプルモーションユニットに接続されているサーボアンプのサーボ ON/OFF を行う機能。 |
| サーボ ON/OFF | フォローアップ機能 | サーボ OFF 状態でモータ回転量をモニタし，モータの回転量を送り現在値に反映させる機能。 |

> ＊1：近傍通過機能は標準装備で，位置制御の連続軌跡制御時のみ有効な機能です。パラメータにて無効とすることはできません。

## 13.2 機械原点復帰固有の補助機能（13.2 / 原本 p.660〜）

> 機械原点復帰固有の補助機能には「原点復帰リトライ機能」，「原点シフト機能」があります。
> 各機能は，パラメータの設定によって実行されます。

### 13.2.1 原点復帰リトライ機能（13.2.1 / 13-4〜13-7 / 原本 p.660-663）

> 位置決め制御中にワークが原点を越えてしまっていた場合など，ワークの位置によっては機械原点復帰を行っても原点方向にワークが動かないことがあります。このような場合，通常は JOG 運転などで近点ドグの手前にワークを移動させて，再度，機械原点復帰を始動することになりますが，原点復帰リトライ機能を使うことで，ワークがどこにあっても，機械原点復帰を行うことができます。
> 「原点復帰リトライ機能」について以下に示す内容を説明します。
> ［1］制御内容
> ［2］制御上の注意事項
> ［3］原点復帰リトライ機能の設定方法

#### [1] 制御内容（13.2.1 / 原本 p.660-662）

> 原点復帰リトライ機能の動作を以下に示します。

（1）ワークが上下限リミットの範囲内にある場合の原点復帰リトライ動作

> ① 機械原点復帰始動により“[Pr.44]原点復帰方向”へ移動を開始する。
> ② リミット信号 OFF 検出により減速する。
> ③ リミット信号 OFF 検出で停止後，“[Pr.46]原点復帰速度”で“[Pr.44]原点復帰方向”と逆方向に移動する。
> ④ 近点ドグ OFF で減速する。
> ⑤ 近点ドグ OFF で停止後，“[Pr.44]原点復帰方向”へ機械原点復帰を行う。（原点復帰方式によってはエンコーダの零点を最低 1 回は通過する必要があります。）
> ⑥ 機械原点復帰完了。

【図】図 13.1 リミット信号の検出による原点復帰リトライ動作（原本 p.660）
- 速度波形：①で原点復帰方向（図の上側）へ加速 → ハードウェアリミットスイッチのリミット信号OFF状態の範囲に入ったところ（②）で減速 → ③で停止
- ③から逆方向（図の下側）へ定速移動し，近点ドグ（ON 区間）を通り過ぎて近点ドグ OFF の位置（④）で減速 → ⑤で停止
- ⑤から再び原点復帰方向へ加速 → 近点ドグ ON で減速しクリープ速度 → 零点信号を検出して⑥で停止（機械原点復帰完了）
- 零点信号：パルス状（図では 2 回表示）

（2）ワークが上下限リミットの範囲外にある場合の原点復帰リトライ動作

> （a）「ワーク→原点」の方向が“[Pr.44]原点復帰方向”と同一方向の場合は，通常の機械原点復帰の動作を行います。

【図】（a）の動作（原本 p.661）
- ハードウェア下限リミットスイッチ〜ハードウェア上限リミットスイッチ間が移動範囲，[Pr.44]原点復帰方向は右向き（正方向）
- 下限リミットスイッチの外側で機械原点復帰始動 → 原点復帰方向へ移動 → 近点ドグ → 零点信号で原点

> （b）「ワーク→原点」の方向が“[Pr.44]原点復帰方向”と逆方向の場合は，近点ドグOFFで減速停止し，“[Pr.44]原点復帰方向”に設定した方向へ機械原点復帰の動作を行います。

【図】（b）の動作（原本 p.661）
- 上限リミットスイッチの外側で機械原点復帰始動 → 原点復帰方向と逆方向へ移動 → 近点ドグを通過し近点ドグ OFF で減速停止 → 原点復帰方向へ機械原点復帰 → 零点信号で原点

> ＊：上図（a），（b）は“[Pr.44]原点復帰方向”を「0：正方向」とした場合の例です。

> **備考**
> ・“[Pr.44]原点復帰方向”が「0：正方向」の場合，原点復帰方向にあるリミットスイッチを上限リミットスイッチにしてください。
> ・“[Pr.44]原点復帰方向”が「1：負方向」の場合，原点復帰方向にあるリミットスイッチを下限リミットスイッチにしてください。
> ・上限／下限リミットスイッチの取付け位置を逆にした場合，原点復帰リトライ機能は正常に動作しません。なお，原点復帰動作に問題がある場合には，「回転方向選択/移動方向選択(PA14)」と上限／下限リミットスイッチの配線を見直してください。

図 13.2 リミット上（リミット信号 OFF 状態）からの原点復帰リトライ動作（上記（a）（b）の図の図番）

（3）原点復帰リトライ時のドウェルタイム設定（原本 p.662）

> 原点復帰リトライ機能では，“[Pr.57]原点復帰リトライ時ドウェルタイム”にて，上限／下限リミット信号の検出による逆転動作，および近点ドグ OFF で停止した後の機械原点復帰実行時にドウェルタイムを機能させることができます。
> “[Pr.57]原点復帰リトライ時ドウェルタイム”が有効になるのは，下図の「A」と「B」の位置で停止したときです。（A と B の位置のドウェルタイムは同一の値で動作します。）

【図】図 13.3 原点復帰リトライ時のドウェルタイム設定（原本 p.662）
- 機械原点復帰始動 → [Pr.44]原点復帰方向へ移動 → リミット信号OFF（ハードウェアリミットスイッチ）検出による停止 = 位置「A」
- A からリミット信号検出後の逆転動作 → 近点ドグを通過 → 近点ドグOFFによる停止 = 位置「B」
- B から機械原点復帰再実行 → 近点ドグで減速 → 零点信号で原点

#### [2] 制御上の注意事項（13.2.1 / 原本 p.662-663）

> （1）“[Pr.43]原点復帰方式”による原点復帰リトライ機能の実行可否を以下に示します。

| [Pr.43]原点復帰方式 | 原点復帰リトライ機能の実行可否 |
|---|---|
| 近点ドグ式 | ○ ：実行可 |
| カウント式① | ○ ：実行可 |
| カウント式② | ○ ：実行可 |
| データセット式 | — |
| スケール原点信号検出式 | × ：実行不可 |
| ドライバ原点復帰式 | — |

> （2）機械の上限／下限位置には，必ず上限／下限リミットスイッチを設けてください。ハードウェアストロークリミットスイッチがないまま原点復帰リトライ機能を使用すると，ハードウェアストロークリミット信号を検出するまで，モータが回転し続けます。
> （3）上限／下限リミットスイッチによって，サーボアンプの電源が OFF するようなシステム構成にしないでください。サーボアンプの電源が OFF されると，原点復帰リトライを行うことができません。
> （4）ハードウェアリミット信号の検出で減速し反対方向への移動を開始しますが，この場合エラー「ハードウェアストロークリミット＋」（エラーコード：104）または「ハードウェアストロークリミット－」（エラーコード：105）は発生しません。

> **ポイント**（原本 p.663）
> 上限／下限ストロークリミット信号の設定は，以下の方法があります。いずれを選択しても，原点復帰リトライ機能を使用できます。（「13.4.4項 ハードウェアストロークリミット機能」参照）
> ・QD77MSの外部入力信号
> ・サーボアンプの外部入力信号
> ・CPU経由外部入力信号（QD77MSのバッファメモリ）

#### [3] 原点復帰リトライ機能の設定方法（13.2.1 / 原本 p.663）

> 「原点復帰リトライ機能」を使用するには，以下に示すパラメータに必要な内容を設定し，シンプルモーションユニットに書き込みます。
> パラメータの設定を行うと，機械原点復帰制御に原点復帰リトライ機能が付加されます。設定した内容は，シーケンサレディ信号[Y0]の立上がり（OFF→ON）時に有効になります。（“[Pr.57]原点復帰リトライ時ドウェルタイム”は必要に応じて設定します。）

| 設定項目 | | 設定値 | 設定内容 | 工場出荷時の初期値 |
|---|---|---|---|---|
| [Pr.48] | 原点復帰リトライ | 1 | 「1：リミットスイッチによる原点復帰リトライを行う」を設定する。 | 0 |
| [Pr.57] | 原点復帰リトライ時ドウェルタイム | → | 原点復帰リトライ中の減速停止時の停止時間を設定する（0～65535［ms］の任意の値）。 | 0 |

＊：設定内容の詳細については，「5.2節 パラメータ一覧」を参照してください。

> **備考**
> ・パラメータの設定は軸ごとに行います。
> ・パラメータの設定は，できるだけGX Works2によって行われることをおすすめします。シーケンスプログラムで実行させると，かなりのシーケンスプログラムとデバイスを使用します。複雑になるとともに，スキャンタイムの増大につながります。

### 13.2.2 原点シフト機能（13.2.2 / 13-8〜13-10 / 原本 p.664-666）

> 通常，機械原点復帰を行った場合の原点は近点ドグや零点信号を使って確立されますが，原点シフト機能を使うことによって，零点信号を検出した位置から，指定の移動量だけ移動させた点を機械的に確立された原点とみなすことができます。
> 「原点シフト機能」について以下に示す内容を説明します。
> ［1］制御内容
> ［2］原点シフト量の設定範囲
> ［3］原点シフト時の移動速度
> ［4］制御上の注意事項
> ［5］原点シフト機能の設定方法

#### [1] 制御内容（13.2.2 / 原本 p.664）

> 原点シフト機能の動作を以下に示します。

【図】図 13.4 原点シフト動作（原本 p.664）
- 機械原点復帰始動 → [Pr.44]原点復帰方向へ[Pr.46]原点復帰速度で移動 → 近点ドグで[Pr.47]クリープ速度へ減速 → 零点信号検出
- 零点信号検出位置から[Pr.53]原点シフト量だけ移動して停止（その位置が原点）
- シフト移動の速度は“[Pr.56]原点シフト時速度指定”で速度を選択する

#### [2] 原点シフト量の設定範囲（13.2.2 / 原本 p.664）

> 原点シフト量は，検出した零点信号から上限／下限リミットスイッチまでの範囲内で設定してください。

【図】図 13.5 原点シフト量の設定範囲（原本 p.664）
- 零点信号の位置を基準に，下限リミットスイッチ側（アドレス減少方向）までが「負の原点シフト量の設定範囲」，上限リミットスイッチ側（アドレス増加方向）までが「正の原点シフト量の設定範囲」
- 図では[Pr.44]原点復帰方向は下限側から上限側へ向かい，近点ドグは零点信号の手前にある

#### [3] 原点シフト時の移動速度（13.2.2 / 原本 p.665）

> 原点シフト機能を使用する場合，“[Pr.56]原点シフト時速度指定”に原点シフト時の移動速度を設定します。原点シフト時の移動速度は，“[Pr.46]原点復帰速度”と“[Pr.47]クリープ速度”のどちらかを選択します。加減速時間には，“[Pr.51]原点復帰加速時間選択”，“[Pr.52]原点復帰減速時間選択”で指定した値を使用します。
> 以下に，近点ドグ式の機械原点復帰を行った場合の，原点シフト時の移動速度を示します。

（1）“[Pr.46]原点復帰速度”での原点シフト動作（“[Pr.56]原点シフト時速度指定”が 0 の場合）

【図】図 13.6 原点復帰速度での原点シフト動作（原本 p.665）
- 機械原点復帰始動 → 近点ドグで減速 → 零点信号検出後，[Pr.46]原点復帰速度まで加速してシフト移動
- “[Pr.53]原点シフト量”が正の場合：原点復帰方向へ移動して原点
- “[Pr.53]原点シフト量”が負の場合：原点復帰方向と逆へ移動して原点

（2）“[Pr.47]クリープ速度”での原点シフト動作（“[Pr.56]原点シフト時速度指定”が 1 の場合）

【図】図 13.7 クリープ速度での原点シフト動作（原本 p.665）
- 機械原点復帰始動 → 近点ドグで減速 → 零点信号検出後，[Pr.47]クリープ速度でシフト移動
- “[Pr.53]原点シフト量”が正の場合：原点復帰方向へ移動して原点
- “[Pr.53]原点シフト量”が負の場合：原点復帰方向と逆へ移動して原点

#### [4] 制御上の注意事項（13.2.2 / 原本 p.666）

> （1）下記のデータは，原点シフト完了後にセットされます。
> ・原点復帰完了フラグ（[Md.31]ステータス：b4）
> ・[Md.20]送り現在値
> ・[Md.21]送り機械値
> ・[Md.26]軸動作状態
> 原点復帰要求フラグ（[Md.31]ステータス：b3）は，原点シフト完了後にリセットされます。
> （2）“[Md.34]近点ドグ ON 後の移動量”に“[Pr.53]原点シフト量”は加算されません。近点ドグ ON 時を「0」として，原点シフト動作直前までの移動量が格納されます。

#### [5] 原点シフト機能の設定方法（13.2.2 / 原本 p.666）

> 「原点シフト機能」を使用するには，以下に示すパラメータに必要な内容を設定し，シンプルモーションユニットに書き込みます。
> パラメータの設定を行うと，機械原点復帰制御に原点シフト機能が付加されます。設定した内容は，シーケンサレディ信号[Y0]の立上がり（OFF→ON）時に有効になります。

| 設定項目 | | 設定値 | 設定内容 | 工場出荷時の初期値 |
|---|---|---|---|---|
| [Pr.53] | 原点シフト量 | → | 原点シフト時のシフト量を設定する。 | 0 |
| [Pr.56] | 原点シフト時速度指定 | → | 原点シフト時の速度を選択する。0：[Pr.46]原点復帰速度／1：[Pr.47]クリープ速度 | 0 |

＊：設定内容の詳細については，「5.2節 パラメータ一覧」を参照してください。
